第一步：公司是干什么的？

一句话定位：全国安防门锁行业首家 A 股主板上市企业（2021 年上市），以钢质安全门为现金牛、智能锁为第二增长曲线，构建"安全门 + 智能锁 + 木门 + 医用门 + 智能门窗 + 智能家居 + 全屋定制"七大品类矩阵。

核心产品与能力
- 安全门：钢质入户门、防盗门（超 C 级圆柱体专利锁芯，防技术开启 360 分钟 = 国家 C 级标准的 36 倍；专利双向防撬倒钩锁体）；2003 年起"挑战开锁王"活动 23 年无人开启
- 智能锁：1.0 基础款 → 2.0 可视猫眼 → 3.0 自弹锁体 + 三防分立（采集/识别/控制分置于前后面板与锁体内）→ 4.0 遥感解锁（毫米波雷达"人至锁开"）
- 智能制造：五大基地（永康、武义、四川、杭州、湖北）；钢质门年产能 >600 万樘、智能锁年产能 >300 万套；永康长恬"未来工厂"入选工信部 5G 工厂名单（行业首家）；单樘门作业面积由 38.07㎡ 压缩至 12.33㎡；标门交付周期压缩至 1 天
- 研发：五大研发基地 + 六大研发中心 + 与北京大学联合实验室；研发团队 400 余人；年研发投入 >8,000 万元；累计 1,000+ 项国家专利（300+ 项发明专利）；门、锁国家标准与公安部标准双制定单位，参编近 100 项标准
- 品牌：2025 年品牌价值 376.59 亿元，连续 14 年行业第一；累计用户 2 亿+、全球 5,000 万+ 家庭

主要客户 / 下游：① 工程渠道（B 端）—— 房企、总包、保障房/安置房项目（12 年中国 500 强地产首选供应商）；② 零售渠道（C 端）—— 经销商门店、电商、家装公司、以旧换新渠道。终端为新建住宅、二手房翻新、老旧小区改造。

境内外收入占比：产品畅销全球 30 多个国家和地区，但以境内为主（未披露具体占比，构成次要不确定源）。

股东背景：民营，浙江永康，创始于 1996 年，董事长王跃斌；"12112"智造战略。

（3）产业链传导

上游 → 成本端：冷轧钢板、镀锌板、五金配件、电子元器件（智能锁）、木材。钢价是本股最大成本变量。2026H1 毛利率 26.22%（−0.71pct），在营收下滑、产能利用率下降背景下仅小幅回落，说明成本传导尚可。

下游 → 收入端：① 工程渠道（B 端）—— 房企/总包，受竣工 −23.7%、房企到位资金 −20.2% 直接冲击，销量下降 + 回款风险双杀；② 零售渠道（C 端）—— 经销商/电商/家装，受二手房翻新、旧改、以旧换新支撑，2025 年 +10.29%，是唯一的正增长来源。

议价权判断：中等偏强（品牌端）+ 弱（工程端）
- 强：品牌价值 376.59 亿、连续 14 年行业第一、国标与部标双制定单位、1,000+ 专利 → C 端议价权强（毛利率 26.22% 高于行业）
- 弱：工程渠道面对房企，账期长、议价权弱（2023/2025 年信用减值分别 −1.95 / −1.12 亿即为此买单）；2026H1 还有 1,722.39 万减值转回（说明此前计提充分）
- 净判断：C 端强、B 端弱，整体中等 —— 战略上应加速 B→C 迁移，而这正是公司"经销商赋能 + 全渠道获客"在做的事。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）——分渠道量化

渠道 / 品类 2026H1 表现 反推传导率
C 端（经销商 / 零售 / 电商） 2025 年营收 +10.29%；品牌溢价支撑 约 0.85–0.95：品牌力支撑大部分转嫁
B 端（工程 / 房企） 2026H1 工程销量下降；房企资金链紧（到位资金 −20.2%） 约 0.3–0.5：弱议价权，成本上涨大部分自担，还要接受降价
智能锁 毛利率未单独披露；行业价格战（德施曼/凯迪仕/小米） 约 0.4–0.6：新品类尚在抢份额，议价权弱

加权验证：综合毛利率 26.22%（−0.71pct）。在钢价高位、营收 −2.60%、产能利用率下降的三重压力下，毛利率仅回落 0.71pct → C 端的高传导率（0.85–0.95）对冲了 B 端的低传导率（0.3–0.5）。这说明渠道结构决定毛利韧性，B 端占比下降反而是好事。

关键结构迁移：钢质门以 58% 收入贡献 55% 毛利，但原料敏感权重高达 32%（钢价） —— 钢价每涨 10%、传导率 0.7，加权毛利侵蚀 = 32%×(1−0.7) = 0.96pct，这是毛利率最大的单一威胁。
智能锁虽毛利最高（30%）但权重仅 4.65%，原料（电子料）敏感权重仅 3% —— 智能锁放量既能提毛利，又能降低钢价敏感度，是结构性优化的正确方向。

因子3 库存与采购节奏（timing）
- 2026H1 经营活动现金流净额 1.87 亿（上年同期 −6,001.4 万，改善 2.47 亿），营业收入现金比 107.5%、净现比 269.45% —— 现金流大幅改善，说明公司在主动收缩账期、加速回款（而非靠囤货）。
- 但货币资金 2.62 亿（较上年末 −30.7%） —— 现金减少，同时筹资活动净流出 2.72 亿（同比多流出 2.5 亿）→ 公司在主动还债/分红，而非囤积现金。
- 判断：毛利率 −0.71pct 属真实成本压力 + 产能利用率下降，不是囤货收益也不是库存损失。2026H1 非经常中"应收款项减值准备转回 1,722.39 万"是前期计提的回冲（前期已高价计提），属财务 timing 而非经营 timing，已在第四步剔除。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正1 资产质量折扣（本股未破净，PB 2.56x 反向显著偏高）
- PB 2.56x 不破净，不存在"PB<1 推大空间"问题；反向风险必须显式说明：PB 2.56x 相对 ROE 7.6% 的组合明显偏高（合理 PB ≈ ROE/COE = 7.6%/10% ≈ 0.76x，即便给成长溢价也难支撑 2.56x）。
- 资产专用性：五大基地 + 长恬 5G 工厂的数字化柔性产线，虽可切换上百种款式，但门业产线专用性强（不能转产其他品类）；产能利用率仅 23%（钢质门）/ 33%（智能锁），大量固定资产闲置 → 重置成本不兜底，实际资产回报率远低于账面 ROE。
- 隐含负债 / 净资产虚高：① 应收账款（房企）占比高 —— 2023/2025 年信用减值 −1.95 / −1.12 亿，说明净资产含"房企应收水分"；② 货币资金仅 2.62 亿（较上年末 −30.7%），而净资产 16.59 亿，现金覆盖率低。
- 校正结论：对净资产给予 15%–20% 的质量折扣（对应有效每股净资产约 3.0–3.2 元），这解释了为何中性目标价（7.09 元）显著低于现价 —— 现价对应的有效 PB 高达 3.0–3.2x。

校正2 周期位置校正
- 王力安防属地产后周期 + 强周期股。当前周期位置：地产下行周期的中段（竣工 −23.7%、新开工 −23.4%，新开工领先竣工 2–3 年 → 2028—2029 竣工仍在负增长区间，但降幅收窄）。
- 中性净利已用周期归一化处理：
- ❌ 未用 2024 年好年景（归母 1.3884 亿，净利率 4.45%，当年减值仅 −0.551 亿，属"减值小年"）；
- ❌ 未用近三年均值（(0.55+1.39+1.26)/3 = 1.07 亿，被 2023 年减值大年拉低、被 2024 年减值小年拉高，均值无意义）；

校正3 杠杆下行情景（本股必附）
- 货币资金 2.62 亿（较上年末 −30.7%），2026H1 筹资活动净流出 2.72 亿（同比多流出 2.5 亿）；虽未披露资产负债率具体值，但经营现金流 1.87 亿、净现比 269.45%，偿债能力尚可，财务杠杆不算高。

- 负面情景（利率上行 + 需求下行双杀）：若竣工维持 −20%、房企应收再爆雷致年度减值 1.5 亿、钢价 +10%，2029E 归母降至 0.85 亿（悲观情景），按 22x → 18.7 亿 → 4.24 元（−56.0%）。

① 为什么亏 / 为什么利润塌陷？

- 产能利用率极低：钢质门产能 600 万樘，2029E 销量仅 137.5 万樘（利用率 23%）→ 大额折旧摊销持续压制净利率。

② 靠什么扭亏 / 恢复，触发时点？

- 下行保护：极弱。每股净资产 3.765 元（PB 1x 对应 3.765 元，距现价 −61%），且产能利用率低、资产专用性强，账面净资产不提供有效支撑
- 赔率结构：上行 +45.0%（乐观，低概率） vs 下行 −26.4%（中性，高概率）/ −56.4%（悲观） → 中性情景即为负空间，赔率为负

介入条件
1. 现价不介入。现价 9.64 元高于中性目标价 7.09 元 36%
2. 合理介入区间：6.5 元以下（正常化 PE <28x、PB <1.73x）才具备基本安全边际；5.5 元以下（PB <1.46x）为可考虑配置区
3. 重新评估信号：① 智能锁收入占比突破 10%（当前 4.65%）；② 浙江省或全国将以旧换新纳入安全门/智能防盗门；③ 单季营收同比转正；④ 年度信用减值降至 0.5 亿以下（B 端风险出清）
4. 排除信号：年度信用减值 >1.5 亿；毛利率跌破 24%；货币资金跌破 2 亿

最大风险（最可能破坏逻辑的因素）
1. ⚠️ 估值与基本面背离（首要）：34x 表观 PE / 42x 正常化 PE / 2.56x PB，对应的却是营收下滑、扣非下滑、产能利用率 23% 的基本面 —— 估值回归是最大风险
2. 地产竣工持续下行：新开工 −23.4% 领先竣工 2–3 年，2028—2029 竣工仍在负增长；工程渠道无翻身机会
3. 房企应收减值：历史 2023 年 −1.95 亿、2025 年 −1.12 亿，一次减值即吞掉全年利润；2026H1 的 1,722 万转回不可持续
4. 智能锁竞争：德施曼、凯迪仕、鹿客、小米、华为已先发，公司份额小（收入占比 4.65%），"安全"卖点能否对抗"生态/性价比"卖点存疑
5. 产能严重闲置：钢质门利用率 23%、智能锁 33%，固定成本摊薄不足持续压制净利率
6. 补贴"半开半闭"：浙江（总部与产业核心区）明确未纳入以旧换新，最大基本盘无政策红利

第五步进阶：上行想象力情景（四类，对冲系统性保守偏置）

类型A 行业调整剩者红利（本股最扎实的上行来源，且已在数据中出现）
- 逻辑：2026H1 公司营收 −2.60%，而同期房屋竣工面积 −23.7% → 超额 +21.1pct，这是极强的份额提升证据。地产下行 + 房企资金链紧张（到位资金 −20.2%）正在出清中小门厂（无品牌、无账期承受力、无 5G 工厂的成本优势）。王力作为 12 年地产首选供应商 + 品牌价值 376.59 亿 + 长恬 5G 工厂（单樘作业面积 38.07→12.33㎡、交付 1 天），是典型的"剩者"。
- 量化：若份额提升使公司营收在竣工 −23.7% 下仅 −2.60%（已实现），且该超额在 2027—2029 维持，则 2029 营收可达 34.5 亿（本测算中性值）。若超额扩大至 +25pct（竣工 −5% 时公司 +20%），2029 营收可达 38 亿，净利 +0.18 亿，对应股价 +1.0 元。
- 验证点：① 季度公司营收增速 vs 全国竣工增速的差值（维持 >15pct）；② 中小门厂退出/破产公告；③ 地产 500 强首选供应商榜单排名。
- 证伪：公司营收增速与竣工增速差值收窄至 <10pct → 说明剩者红利减弱。

类型B 政策反转期权（最高弹性，未过验证点）
- 逻辑：智能防盗门（含智能门锁、智能猫眼）已被大连等城市纳入 2026 年消费品以旧换新补贴（15%、每件 ≤1,500 元、2026-06-04 至 12-31），政策依据为《商务部等 5 部门办公厅关于做好 2026 年家电以旧换新、数码和智能产品购新补贴工作的通知》。但浙江省（公司总部 + 永康产业集群）明确"安全门产品暂未纳入今年省级以旧换新补贴范围"（2026-05-29） —— 这既是当前利空，也意味着若反转则弹性巨大。
- 量化：若 2027 年浙江及全国主要省份纳入，按 C 端收入 20 亿、补贴拉动增量 15% 计，新增收入 3 亿、净利 0.24 亿；叠加智能锁（换锁周期短）弹性，2029 归母可由 1.25 亿上修至 2.2 亿（乐观情景），对应股价 +6.9 元。
- 验证点：① 浙江省/全国补贴品类清单更新公告；② 商务部后续通知；③ 公司以旧换新渠道出货数据。
- 证伪：2027 年浙江仍未纳入 / 补贴退坡早于放量 → 该期权作废，中性下修。

类型C 市场错杀修复（本股不适用）
- 现价 PB 2.56x、正常化 PE 42.0x，估值分位明显偏高；且扣非 −17.55%、营收下滑为基本面真实承压，不是情绪错杀。本类明确排除 —— 若强行套用"错杀"逻辑将犯严重错误。

类型D 技术突破 / 技术代际跃迁期权（中弹性，未过验证点）
- 逻辑：公司智能锁 4.0 旗舰款配备遥感解锁（遥感识别 + 毫米波雷达检测人门距离，实现"人至锁开"）；三防分立专利（采集/识别/控制分置，前面板被破坏锁体仍锁死，抗"小黑盒"电磁攻击）；超 C 级圆柱体锁芯（防技术开启 360 分钟 = 国标 C 级 36 倍）。若"遥感无感入户"成为智能锁的下一代标准，公司具备先发技术卡位。
- 三要素共振检验：
- ① 政策驱动技术路线：❌ 智能锁无强制标准替代政策（仅有安防推荐性标准）
- ② 行业趋势向该技术收敛：⚠️ 部分成立 —— 无感入户是高端化方向，但德施曼三摄人脸、凯迪仕全自动可视、鹿客 AI 等路线并行，尚未收敛
- ③ 公司技术投产落地：⚠️ 部分达成 —— 4.0 遥感款已量产、23 年"挑战开锁王"无人开启、2026 第五届国际锁王争霸赛机械锁与智能锁全线守擂成功；但遥感款收入占比未披露、良率与返修率数据未披露、无大额客户定点公告
- 硬验证点（缺一不计入中性）：① 遥感款量产良率达标且返修率低于行业；② 头部房企/家装公司/电商平台的大额定点或集采公告（≥1 亿）；③ 遥感款量产成本不劣于人脸识别与指纹路线。
- 当前状态：① 未披露、② 未达成、③ 未披露 → 仅作机会情景，不计入中性锚。
- 证伪：遥感款良率长期不达标 / 被人脸识别路线压倒 / 成本打不过主流方案。

↑ 什么条件出现才上调至"重点关注"？
必须同时满足：① 智能锁收入占比突破 15% 且毛利率 ≥30%（第二曲线真正成立）；② 年度信用减值降至 0.5 亿以下（B 端风险出清）；③ 股价回落至 5.5 元以下（正常化 PE <24x、PB <1.46x）。
仅靠"以旧换新补贴"或"剩者红利"不足以支撑上调 —— 前者浙江未纳入、后者已被中性情景吸收。必须看到智能锁在报表上成为真正的第二增长极 + 估值回到与 ROE 匹配的水平。

结论：暂不介入

定级理由：中性远期空间 −26.4%（为负），不满足"纳入观察"的 >0 门槛，更不达"重点关注"的 >50%；悲观情景 −56.4%，赔率为负。
必须承认的三件对的事：① 剩者红利真实存在 —— 营收 −2.60% vs 竣工 −23.7%，超额 +21.1pct，品牌与成本优势（长恬 5G 工厂单樘作业面积降至 12.33㎡、交付 1 天）确立；② 智能锁是优质第二曲线 —— TAM >2,000 万套、渗透率 >40%、换锁周期短、抗地产周期、安全护城河真实（23 年无人开启）；③ 现金流优秀 —— 经营现金流 1.87 亿（改善 2.47 亿）、净现比 269.45%，生存无虞。
但三件事决定了"暂不介入"：① 估值显著偏高 —— 34.3x 表观 PE / 42.0x 正常化 PE / 2.56x PB，对应营收下滑 + 扣非 −17.55% + 产能利用率 23%；② 表观增利是假象 —— +1.99% 全靠非经常 2,323 万（占 33.6%），扣非实为 −17.55%；③ 周期位置未到底 —— 新开工 −23.4% 领先竣工 2–3 年，2028—2029 竣工仍在负增长，利润拐点最早 2028 年。
核心跟踪点：智能锁收入占比（当前 4.65%，需破 10%）+ 年度信用减值规模 + 浙江以旧换新是否纳入。
