（3）产业链传导

上游（钢材、水泥、沥青、砂石、人工）：施工成本中直接材料占大头，钢材与沥青价格是核心变量。2026H1 毛利率逆势提升 1.1pct，说明公司在"降本增效、强化成本管理"上取得成效（也可能是低价钢材期）。

下游（政府业主）：这是最关键的变量。地方政府财政承压 → 业主资金拨付放缓 → 工程款回款慢 → 应收账款与合同资产累积 → 经营现金流大幅为负。化债政策是解药：地方偿债能力提升 → 回款改善。

议价权：对上游中等（供应商众多，可压价、可账期）；对下游（政府业主）弱（施工总承包招投标定价、结算延迟、变更索赔周期长）。综合议价权：偏弱——这决定了净利率长期只有 1.5–2.4%。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）
施工总承包合同以工程量清单计价 + 固定单价为主，部分含"材料调差条款"（可按信息价或指数调差）：
- 省内高速/养护项目（政府定价，多含调差条款）：传导率 ≈ 0.5
- 省外竞争性项目（低价中标、调差条款少）：传导率 ≈ 0.25
- 海外项目（固定总价 + 汇率风险）：传导率 ≈ 0.15（公司自述海外毛利率低，受"竞争激烈、国际局势不稳、原材料价格上涨及汇率波动"影响）
→ 加权传导率约 0.35，即钢材/沥青涨价 10% 时公司实际毛利承压约 6.5%。

因子2 毛利结构再平衡
三条区域线的原料敏感度与毛利水平截然不同：

区域线 毛利率 材料/汇率敏感度 2026H1 收入权重
省内 较高（养护 16.7%+） 中（多为政府项目，含调差） 74.11%
省外 中（竞争激烈） 高 15.41%
海外 低（公司自述"海外市场毛利率较低"） 极高（钢材+汇率） 10.48%

结构变化："十五五"若海外占比从 10.48% 提升至 20%，综合毛利率可能被拉低——这是"规模增长 ≠ 毛利改善"的结构性风险。禁止用单一"综合毛利率 15.73%"推断全结构。

因子3 库存与采购节奏（timing）
施工企业无实物原料库存收益，真正的"类库存"是应收账款 + 合同资产：2026H1 长期应收与合同资产规模巨大（总资产 379 亿元主体为应收与合同资产），周转慢、减值风险高。公司在建工程为机械设备，无低价囤货逻辑。关键 timing 变量是"化债资金到位节奏"——回款提前即现金流与利润双改善。

因子4 政策/市场锚点
- 市场层：螺纹钢/沥青价格指数、水泥价格、黑龙江区域施工季（寒区施工窗口短）。
- 政策层：①化债政策（地方政府债务置换）——直接决定回款与减值计提，是最强正向变量；②交通强国/养护工程专项——直接释放订单；③高标准农田补贴——新增业务入口；④"一带一路"融资支持——海外订单落地条件；⑤钢材/沥青价格（市场层）——决定施工毛利。
- 验证点：季度经营现金流、应收账款周转率、"两金"压降进度、新增中标额、化债资金落地公告。
- 证伪信号：新增订单连续两年下滑、经营现金流连续两年大幅为负且货币资金下降、应收账款减值计提大幅增加。

本因子输出直接喂给第四步：中性情景将综合毛利率锚定 15–16%（略高于 2026H1，因省内高毛利养护占比上升），不沿用 2024 年的 11.75%。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

层1 现有业务：市场容量 × 份额变量
- 市场容量：全国公路建设投资总规模收缩（建筑业增加值同比下降），但养护工程随存量路网老化逆势增长（存量公路养护是"抗周期"细分）。
- 份额锚点①（供给侧）：公司在黑龙江省内为龙头，与央企形成地方国企的属地优势；2026H1 新增订单 +42.32% 说明份额在提升（逆行业周期）。
- 份额锚点②（需求侧/客户）：客户为省级交通主管部门与交投集团，准入资格（特级资质 + 业绩）构成黏性；公司在建投集团内为"压舱石与排头兵"，集团内协同优势明确。
- 份额锚点③（技术代际差）：寒区施工技术为差异化能力（黑龙江冬季施工、冻土路基），在西北等寒冷地区具备迁移优势——技术代际不落后，且具区域独占性。
- 份额锚点④（成本曲线位置）：凭借属地资源、自有精干施工队伍与规模采购，成本曲线位于区域内左侧；但对比央企，规模劣势明显。
- 份额锚点⑤（二阶导）：份额处于加速提升段（订单 +42.32% vs 行业收缩）。
- 三档假设：保守（份额守住，收入年降 1%）／中性（份额小幅提升，收入年增 2%）／乐观（省外占比 40% 目标提前达成，收入年增 5%）。验证点：季度新增中标额、省外/海外收入占比。

层2 扩展业务：主业迁移空间（新易盛范式）
- 能力可迁移性：较高。公路施工能力可迁移至 ①市政道路桥梁；②高标准农田（土方 + 水利，同源）；③海外公路（"1+7+N"布局）。
- 新 TAM 弹性：高标准农田为政策性新增市场（全国年投资规模千亿级）；海外基建（非洲/西亚/蒙古）受"一带一路"融资支持。
- 切入卡位：早期。高标准农田"取得一定突破"，海外占比 10.48%，均处起步期。
- 认证门槛：海外需属地资质与融资落地能力（既是护城河也是阻力）；高标准农田需地方准入。
- 信号验证：已有部分验证——2026H1 海外收入 5.16 亿（占比 10.48%）、省外占比 15.41%；"十四五"目标 6:3:1，实际约 7.4:1.5:1，省外与海外仍低于目标。"营收结构跳升"未完成 → 按中期期权处理，中性情景只给海外占比 15%、省外占比 25% 的谨慎假设。

层3 风险折扣：证伪信号
- 新增中标额同比转负 → 份额假设下修
- 经营现金流连续两年为负且恶化 → 利润质量与回款假设下修
- 毛利率跌破 12% → 成本传导假设失效
- 海外收入占比长期不升（<12%） → 迁移确定性折扣
- 应收账款减值大幅计提 → 中性净利下修

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

校正1 资产质量折扣（破净原因必须说明）
本股 PB 0.97x，破净。破净原因逐项举证：
1. 资产盈利能力中等偏低：ROE 10.03%（2025）尚可，但净利率仅 2.24%、且高度依赖回款；在利率上行时财务费用（有息负债 150.5 亿）迅速吞噬利润 → 破净部分反映盈利脆弱性；
2. 资产专用性强：总资产 379 亿元主体为应收账款 + 合同资产 + 长期应收款（工程款），清算价值远低于账面——一旦业主违约，账面净资产不兜底；
3. 隐含负债：应收账款减值、PPP 项目长期应收款的回收不确定性、可转债/永续中票的刚性偿付义务；
4. 资产负债率 81.53%：净资产仅 70 亿元，却支撑 379 亿元资产——净资产薄，放大波动。
→ 结论：破净是建筑行业的公允定价，不是"深度低估"。但 ROE 10% > 无风险利率 + 风险溢价的部分，构成有限的安全边际（PB 0.97 × ROE 10% ≈ 10.3% 的净资产回报），属"弱安全边际"，可保留但须配合回款改善验证。禁止单凭"PB<1"直接推导"空间大"。

校正2 周期位置校正（中性净利用周期归一化）
建筑施工业处于周期底部：全国建筑业增加值同比下降、投资规模收缩、行业收现能力普遍承压。中性净利不得用 2026H1 年化（1.47 亿）、也不得用 2024 年好年景（4.13 亿，当年经营现金流 +26.35 亿），须取"订单正常转化 + 回款中性 + 毛利率 15–16%"的周期归一化值——中性锚定 4.30 亿元（略高于 2025 年 3.89 亿，反映订单 +42% 的转化）。明确标注：当前处于周期底部，订单端已出现领先改善信号。

校正3 杠杆下行情景
资产负债率 81.53%、有息负债 150.50 亿元、财务费用刚性——经营杠杆与财务杠杆双高。下行情景：①利率上行 100BP → 财务费用 +1.5 亿 → 净利腰斩；②回款恶化致减值计提 3 亿 → 直接亏损；③海外汇率损失。负面情景下 2029E 净利可降至 1.5 亿以内、对应股价 0.9 元（−74%）。鉴于该情景可使空间深度转负，本股不得标"大空间/重点关注"，至多"纳入观察"且须注明高贝塔、高负债属性。

期权纪律
"B 项目特许经营 30 年收益""高标准农田放量""海外占比达 20%"均属未过验证点的中期期权，不计入中性 NAV / 中性净利，仅列入乐观情景（见第五步进阶）。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低（但非显著低估）。现价 3.41 元对应 2026E PE 8.7x、PB 0.97x、ROE 10%。在建筑板块中属中枢偏下，但PB<1 是行业常态，真正的折价幅度有限。

安全边际：
- 中性远期 3.91 元（摊薄后） / 4.24 元（未摊薄）→ 空间 +14.7% / +24.3%，满足"纳入观察"的 >0 门槛，但不达"重点关注"的 >50%（摊薄口径下）
- 悲观情景 1.91 元 → 下行 −44.0%，高负债放大风险
- 乐观情景 5.50 元 → +61.3%，需省外/海外目标达成 + 化债大额回款
- 下行保护：PB 0.97x + ROE 10% 构成弱安全边际；黑龙江省内龙头地位 + 在手订单 99.97 亿构成订单垫

介入条件：
1. 可小仓位左侧。现价接近净资产，PB<1 提供一定保护；等 3.10 元以下（PB < 0.89x）安全边际更足
2. 加仓信号：① 单季经营现金流显著收窄或转正；② 应收账款周转率提升、"两金"压降达标；③ 新增中标额持续高增；④ 化债资金大额到位公告
3. 观察指标：逐季营业收入现金比、应收账款减值计提额、"十五五"省外/海外收入占比

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 现金流与回款（首要）：2026H1 经营现金流 −17.45 亿元；业主拨付放缓，回款是利润能否兑现的命门；公司已将"两金"压降列为年度重点工作
2. ⚠️ 高杠杆反噬：资产负债率 81.53%、有息负债 150.5 亿元，利率上行或回款恶化即净利腰斩
3. 薄净利率放量陷阱：净利率仅 1.51%，"订单 +42%"若伴随低价中标，可能"增收不增利"
4. 海外与汇率风险：海外毛利率低、受汇率与国际局势影响
5. 可转债摊薄：10 亿元转债转股将摊薄 EPS 约 15–20%

结论：纳入观察

理由：中性远期空间摊薄后 +14.7%（未摊薄 +24.3%），满足"纳入观察"的 >0 门槛；公司逻辑正确（省内龙头、订单 +42.32%、化债改善回款、ROE 10% + PB<1 的弱安全边际），但短期现金流承压、负债率高、净利率极薄，需等回款与现金流拐点。
破净不等于低估（建筑行业常态），真正的重估需要"现金流改善 + ROE 维持"双验证。
核心跟踪点：① 单季经营现金流；② 应收账款周转率与减值计提；③ 新增中标额与省外/海外占比。

第五步进阶：上行想象力情景（调整型机会，只进乐观栏）

类型A 行业调整剩者红利
建筑施工行业在投资收缩与竞争加剧下加速出清，中小民营施工企业退出，地方国企 + 央企的份额被动提升。公司 2026H1 新增订单 +42.32%（行业收缩背景下）即为剩者红利的直接证据。用份额变量锚定上行：若行业 CR10 提升、公司省内份额与省外拓展同步推进，收入与毛利率可双升。验证点：季度新增中标额、行业集中度数据。证伪信号：新增订单转负、中标价持续走低。

类型B 政策反转期权
化债政策是被政策压制（地方政府债务管控）后的明确反转变量——地方政府偿债能力提升 → 工程款回款改善 → 应收账款减值转回 + 现金流修复 + 估值重估。重估弹性测算：若回款改善致减值转回 2 亿元、经营现金流转正，净资产与 ROE 双双提升，PB 从 0.97x 修复至 1.1x → 对应股价 3.85 元（+12.9%）。验证点：化债资金到位公告、季度现金流、减值计提方向。未过验证点，仅作机会情景，不计入中性锚。

类型C 市场错杀修复
地方国企建筑股因"地产链 + 地方债"标签被系统性低估（PB 0.5–1.0x 普遍），本股 PB 0.97x、ROE 10% 在板块中属"错杀较轻"的一类。若市场风格回归低估值高股息/国企价值，估值可修复。错杀证据：PB 破净 + ROE 10% + 订单 +42.32% 而基本面未恶化。修复触发点：市场企稳、国企估值重估行情、回款数据证伪悲观预期。

类型D 技术突破 / 技术代际跃迁期权
公司寒区施工技术（冬季施工、冻土路基处理）为差异化能力，在西北寒冷地区具备迁移优势——属"同源技术切入新区域"的主业迁移（第三步层 2），而非全新技术路线。三要素检查：①无政策强制技术路线；②无行业技术收敛趋势；③无"中试/量产成本优于旧路线"的硬验证点。三要素不共振 → 仅作机会情景，不计入中性锚。

纪律：以上四类只进"乐观/机会"栏，不进中性锚；每类配有验证点与证伪信号；只有当"单季经营现金流转正 + 应收账款周转率提升 + 新增中标额维持 30% 以上增长"三项同时出现时，才将结论上调至"重点关注"。
