第一步：公司是干什么的？

一句话定位：新希望集团旗下的低温鲜奶与特色酸奶龙头，用"鲜立方战略"把区域乳企的供应链优势（冷链+短保+送奶入户）复制到华东等新市场，主业高度聚焦液体乳。

产品结构拆解（液体乳内部）：低温鲜牛奶、低温酸奶、低温调制乳、低温乳饮料构成低温矩阵（"鲜酸双强"）；常温纯牛奶、常温乳饮料、常温调制乳、常温酸奶构成常温基本盘。公司口径披露液体乳"量 / 价"同比约 +11.1% / −1.5%——量增价微降，是典型的"以价换量、结构升级"组合。

核心产品与大单品：24 小时鲜奶（巴氏鲜奶标杆）、活润（肠道健康功能性酸奶）、朝日唯品（布丁、发酵酪乳等日式风味）、挪威红牛珍稀奶源鲜奶、城市名片系列。2026H1 新品收入占比维持 10% 以上。

主要客户 / 下游领域：以 C 端家庭消费为主，渠道分直销（37.38 亿，+10.36%）与经销（18.46 亿，+6.96%）；DTC（订奶入户 / 形象店）为核心壁垒，同时拥抱山姆会员店、盒马、零食量贩、即时零售；电商渠道 2026H1 营收 7.63 亿元，同比 +28.28%。

境内外收入占比：业务基本全部在中国境内（西南、华东、华北、西北为四大区域），无实质境外收入；2026 年 4 月递交 H 股发行上市申请，处于"资本国际化"而非"业务国际化"阶段。

（3）产业链传导

上游（原奶 + 包材 + 饲料）：
- 原奶占低温乳企营业成本约 50%–60%，是公司第一大成本项。2026 年 2 月第 4 周 3.03 元/公斤触底、环比持平后企稳；山东口径显示生乳收购均价 3.08 元/公斤仍低于养殖成本线 3.20–3.40 元/公斤，行业普遍亏损 → 产能去化具备强制性。
- 饲料端分化：2026 年 4 月全国玉米均价 2.50 元/公斤（环比 +0.8%、同比 +5.0%），豆粕 3.37 元/公斤（环比 −0.9%、同比 −7.2%）——能量料涨、蛋白料跌，养殖成本整体仍处高位，支撑原奶价格中枢上移。
- 包材：PET/纸/铝随油价与大宗波动，属次要成本项。

下游需求：整体消费需求疲软、常温奶增长遇冷，但低温鲜奶与功能性乳品逆势增长，行业结构从"喝奶"转向"吃奶 / 喝好奶"。渠道端，线下社区生鲜店、便利店优于传统商超，线上/即时零售、会员制仓储（山姆）成为大单品孵化器。

议价权判断：中等偏弱（上游）/ 中等偏强（终端结构）
- 对上游奶源：新乳业体量远小于伊利蒙牛，且原奶处于上行拐点，采购议价权偏弱，成本转嫁率估计仅 0.4–0.6（详见第二步进阶）。
- 对终端：低温赛道"鲜"属性带来区域定价权（短保 + 冷链 + 订奶入户形成地域粘性），但全国范围仍需以价换量，整体转嫁率中等。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1：成本传导弹性（pass-through 量化）
- 原奶占公司营业成本约 55%（估计），2026 年原奶预计从 3.02 元/公斤回升至 3.55–3.65 元/公斤，涨幅约 +18%。
- 传导率估计 0.5–0.6：依据是（a）低温奶提价空间有限——终端竞争激烈、量增靠"以价换量"；（b）公司未披露任何全面提价公告；（c）行业层面龙头以控费对冲而非提价。
- 则实际毛利承压 ≈ 18% × 55% × (1 − 0.55) ≈ 4.5pct（毛利率端，若不控费）。这就是 2027 年毛利率的最大压力源，也解释了为何 2026Q2 毛利率同比已 −0.98pct。
- 验证点：主产省生鲜乳月度均价（农业农村部监测）、公司季度毛利率、公司是否发布调价通知。
- 证伪信号：原奶价格在 2026H2 再度回落至 3.0 元/公斤以下（则成本压力解除、毛利率回升）。

因子 2：毛利结构再平衡（分业务线给毛利率 + 原料敏感权重）

业务线 占营收 估算毛利率 原奶敏感权重 说明
低温鲜奶 约 35% 约 35% 高 短保、冷链成本高，但定价能力强，原奶涨价冲击可由结构溢价部分对冲
低温酸奶 约 30% 约 32% 高 功能化（活润）提升附加值
常温奶 / 调制乳 约 25% 约 22% 中 竞争最激烈，毛利率最低，原奶涨价承受力最弱
奶粉 / 其他 约 10% 约 25% 中低 奶粉收入已下滑，占比持续压缩
  • 加权毛利率：约 29.5%–30.5%，与 2026H1 实际 29.73% 吻合。
  • 结构迁移方向：低温占比提升 → 加权毛利率结构性上移（低温比常温高 10pct 以上），可对冲原奶涨价的周期性下压。这是一个"结构向上、周期向下"的对冲结构——禁止用单一综合毛利率掩盖这一迁移。

因子 3：库存与采购节奏（timing）
- 公司以鲜奶为主（短保 7–21 天），原料与成品库存天然很低，不存在低价囤货的一次性收益，也不会有高价接货的巨额库存损失——这一点显著优于常温奶企业（后者可囤大包粉）。
- 采购以区域牧场直采 + 长期收购合同为主，山东、河北等地近年明确"应收账款、如期续签收购合同"，长协比例高。
- 因此当期毛利率不含库存 timing 噪声，可比性强；同时意味着原奶涨价会较快地、完整地反映到成本端（缺乏低价库存缓冲）。
- 验证点：存货周转天数、季度毛利率与现货奶价的相关性（若 2027 年奶价涨而毛利率不跌，说明结构升级足以覆盖成本）。

因子 4：政策 / 市场锚点（原料成本驱动变量）

份额二阶导 华东仍在加速渗透（+19.03% 远快于全国 +5.20%）；西南已近饱和（+2.32%） — 华东增速是否连续 3 个季度高于全国

（各档验证点：季度报告的分区域收入、低温品类收入增速、山姆/盒马等渠道 SKU 与动销数据。）

层 2：扩展业务 —— 主业迁移空间（新易盛范式）
1. 能力可迁移性：极高。低温冷链、短保运营、DTC 订奶网络、城市奶源组织能力，本质是"区域生鲜供应链"，可平移到风味饮料、鲜食、健康食品。
2. 新 TAM 弹性：风味饮料为千亿级赛道，远大于低温奶（低温奶约千亿级），但公司尚未披露产品与投入，TAM 弹性大而可信度低。
3. 切入时点与卡位：尚未推出产品，属"战略表述阶段"，非早期先发。
4. 客户认证门槛：快消品无认证门槛，但渠道与品牌认知门槛高，需重投入。
5. 信号验证：未见产品上市公告、未见产能投向从乳品转向饮料、未见新品类收入占比跳升。
→ 结论：该迁移仅为"中期期权"，未过任何验证点，不计入中性情景（第四步）。

层 3：风险折扣 —— 证伪信号
- 原奶价格上行幅度超预期（>+20%）且公司未提价 → 毛利率跌破 28%（阈值）。
- 华东收入增速连续两个季度回落至 10% 以下 → 份额提升假设被证伪。
- 新渠道（会员店/零食量贩）占比升而毛利率跌破 29% → 以价换量的负面效应显现。
- 可转债未能转股且以借款兑付 → 资产负债率升破 60%，触发杠杆情景。
- 低于阈值即下调对应增量。

方法说明：不使用"历史 CAGR 外推"。按 低温鲜奶 / 低温酸奶 / 常温乳品 / 其他 四条线，结合区域扩张节奏、渠道结构变化、原奶价格路径与费用率趋势分别测算，再给三情景。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1：资产质量折扣（非破净，但需说明承压项）
- PB 3.61x，远高于 1，不适用"破净 = 便宜"的逻辑，不存在伪空间问题；相反需警惕 PB 偏高的另一面：净资产回报要求高（ROE 需匹配）。
- 资产质量关注点：①商誉——历次区域并购（华东、西北）形成商誉，若被并购标的经营恶化存在减值风险；②冷链固定资产专用性强，处置价值低于账面；③可转债权益成分计入净资产，若兑付则净资产下降。
- 验证点：商誉规模与减值测试披露、固定资产周转率。
- 证伪信号：并购标的（华东/西北）出现收入下滑或计提商誉减值。

校正 2：周期位置校正（中性净利用周期归一化）
- 乳业当前周期位置：原奶价格处于周期底部、公司作为下游处于"成本底部红利"位置。
- 因此 2026E 的净利率（8.0%）含有"原料在底部"的顺周期成分，不得把它直接当作长期稳态。
- 中性净利归一化处理：以奶价中枢 3.2–3.4 元/公斤（而非 2026H1 的 3.02 元、也非顶部 4.38 元）作为成本基准反推——即在成本中枢条件下，公司净利率约 9.0%，对应 2029E 净利 12.3 亿。
- 明确标注：当前处于"下游成本底部、上游盈利底部"的双底部位置，中性假设已含奶价回升至中高位的影响，未采用单年好年景（2026H1）年化，也未采用近三年均值。
- 证伪信号：生鲜乳均价突破 4.0 元/公斤（超越中枢），则 2029E 净利需下调 20%–30%。

校正 3：杠杆下行情景（高负债必附负面情景区）
- 资产负债率 56.32%，接近 60% 阈值；7.18 亿元可转债 2026 年底到期。
- 负面情景：若可转债未转股、以银行借款兑付，且同期原奶涨价 + 终端价格战，则 2027 年财务费用 + 利息 0.3–0.4 亿、毛利率再降 1–2pct，叠加收入增速降至 0%——2027 年归母净利可能同比下滑至 6.5–7.0 亿，对应 PE 抬升至 18x 以上，该情景下远期空间收窄至 +20% 以内。
- 因此本报告结论不标注"大空间"，仅以"重点关注"配谨慎措辞，并注明其中等贝塔 + 消费防御属性。
- 验证点：可转债转股进度、资产负债率、财务费用同比。
- 证伪信号：负债率升破 60%、可转债违约或展期。

期权纪律：层 2 的"风味饮料新赛道""跨区域并购复制"均未过验证点，不计入中性净利与中性 NAV，仅出现在第五步的乐观 / 机会情景。

第五步：综合赔率判断（买不买？）

当前价格位置：偏低。现价 14.82 元对应 2026E PE 15.3x，低于乳业龙头 18–20x 中枢与本股历史区间，PB 3.61x 反映的是 ROE 上行的预期而非高估。

安全边际：
- 中性远期 24.29 元 → 空间 +63.9%
- 基准（2026 年底）17.46 元 → 空间 +17.8%，现价低于基准估值
- 悲观情景 13.82 元 → 下行 −6.7%，下行有限（因 2026E PE 仅 15x 已提供估值底）
- 乐观情景 34.84 元 → +135.1%
- 下行保护：2026H1 经营现金流净额 7.51 亿元（高于归母净利 4.65 亿，利润含金量足）、连续分红（近三年派现 7.62 亿）、北向资金增持 80%。

介入条件：
1. 现价即可分批介入（2026E PE 15.3x，已低于基准估值区间）。
2. 加仓信号：① 华东区域单季收入增速维持 15% 以上；② 公司季度毛利率在原奶上行背景下仍守住 29.5%；③ 可转债顺利完成转股（消除现金流与负债率压力）；④ H 股上市获批（带来估值重估与增量资金）。
3. 观察指标：生鲜乳月度均价（农业农村部）——若月度均价连续 3 个月突破 3.8 元/公斤，需立即下调中性情景。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 原奶价格上行超预期（首要）：2026 年被普遍视为原奶周期拐点，若 2027 年奶价涨幅 >20% 而终端不提价，毛利率承压约 4.5pct，中性净利需下修 20%–30%。这是本股唯一的结构性风险。
2. 可转债到期兑付压力：7.18 亿元若以借款兑付，资产负债率（现 56.32%）将进一步抬升，财务费用增加。
3. 常温奶价格战外溢：伊利蒙牛在常温端的价格竞争可能传导至低温端，压缩"以价换量"的空间。
4. 补缴税款类一次性扰动：2026H1 已因税收法规执行标准更新补税 0.59 亿元，若后续再有类似事项，将扰动利润节奏。
5. 华东整合的商誉风险：区域并购形成商誉，若标的经营恶化存在减值可能。

第五步进阶：上行想象力情景（四类调整型机会）

类型 A · 行业调整剩者红利
- 逻辑：原奶连续 4 年低迷 → 中小牧场与中小乳企加速出清（奶牛存栏两年减 55–60 万头，2026 再减 20–30 万头）→ 具备奶源组织能力与低温供应链的头部企业同时获得"上游供给稳定 + 下游份额集中"双重红利。
- 锚定：CR5 提升幅度、剩者低温产能占比。低温鲜奶份额已破 20% 并向上。
- 验证点：行业中小乳企注销数量、低温赛道 CR5、公司低温收入增速持续高于行业。
- 证伪信号：中小乳企未出清、价格战加剧导致行业毛利率整体下移。
- 弹性：这一情景正是"乐观"中净利率做到 10%–10.5% 的基础假设。

类型 B · 政策反转期权
- 具体政策：灭菌乳禁复原乳新国标（2025-09-16 实施） + 欧盟乳制品反补贴税（2026-02-13 起 5 年，7.4%–11.7%）。
- 反转信号：生鲜乳需求被政策强制抬升 → 原奶价格回升 → 对下游是"杀敌一千自损八百"，故本类对公司更像中性偏负（成本上行）；真正的正向反转在于生产许可细则扩至 11 类致中小产能出清，带来份额重估。
- 重估弹性：份额集中若使公司低温份额年提 0.8pct，2029E 净利可上修约 1.5 亿。
- 未过验证点前仅作机会情景，不计入中性锚；证伪信号：中小乳企产能未出清、行业价格战加剧。

类型 C · 市场错杀修复
- 错杀证据：①估值分位——2026E PE 15.3x 处乳业龙头历史低位区间；②相对折价——低于同业成长性相匹配的 18–20x；③基本面未恶化——H1 归母 +17.24%、扣非 +15.81%、经营现金流 7.51 亿，仅 Q2 因补税扰动显示为利润增速放缓。
- 修复触发点：市场企稳、消费风格回归、2026 年报确认补税为一次性事项后利润弹性释放、H 股上市催化。
- 本类为本股当前最主要的上行来源，已部分体现在中性情景中。

类型 D · 技术突破 / 技术代际跃迁期权
- 三要素检验：①政策驱动——无强制技术替代政策导向菌种自研；②行业趋势收敛——功能性乳品（肠道健康、控糖）确实是行业向该技术收敛的方向；③公司落地——自有乳酸菌资源库 2300 株、多株完成功能验证，但未见菌种外销收入、未见客户定点。
- 硬验证点：菌种对外授权/外销合同公告、自有菌株产品的收入占比跳升、菌种中试到量产良率达标。
- 三者缺其一，仅作机会情景，不计入中性锚。证伪信号：菌种项目长期无商业化收入、研发投入未能转化为产品溢价。

什么条件出现才上调至重点关注之上的更积极评级（本项目最高即"重点关注"，故此处给出维持重点关注的条件）：① 连续两个季度毛利率在原奶上行情况下守住 29.5%；② 华东单季增速维持 15% 以上；③ 可转债顺利转股。若三者同时满足，可确认"结构性净利率提升"逻辑成立。
什么条件下调至"纳入观察"：原奶均价连续 3 个月 >3.8 元/公斤，或华东增速跌破 10%，或资产负债率升破 60%。

结论：重点关注

理由：① 业绩增长明确（2026H1 归母 +17.24%、扣非 +15.81%、经营现金流 7.51 亿，利润含金量高）；② 行业景气结构性向上（低温鲜奶渗透率破 20%、政策强制托底需求、中小产能出清）；③ 估值合理偏低（2026E PE 15.3x，低于中枢与可比）；④ 远期空间 +63.9%，满足"重点关注"的 >50% 门槛；⑤ 悲观情景仅 −6.7%，风险收益高度不对称且偏正。
核心跟踪点：生鲜乳月度均价（成本端）+ 华东区域单季增速（份额端）+ 可转债转股进度（财务端）。
