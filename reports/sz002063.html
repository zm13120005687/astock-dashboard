第一步：公司是干什么的？

一句话定位：国家电网体系内核心的"管理软件 + 能源数字化"平台型企业，为电网、发电集团及大型央企提供集团财务管控、ERP、智慧能源（碳资产 / 储能 / 新能源运营）等数智化整体解决方案。

（3）产业链传导

上游：以人力（研发人员薪酬）为主，无大宗原料，成本刚性、随薪酬上涨。
下游：电网 / 发电央企，客户强势但关系稳定、回款有保障（央企信用）。
议价权：中高（国网系内部核心供应商，绑定深；但价格受集采与年度预算约束，软议价权）。

第二步进阶 · 原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：软件业成本以人力为主，无原料价格传导问题；但人工成本刚性上升，毛利率 49% 同比 -3.5pct 反映薪酬 / 费用压力，传导率≈0（自行承担），属"弱议价权 + 成本刚性"组合。
  • 因子2 毛利结构再平衡：数智企业（86%）毛利率 ~49%、智慧能源（13%）毛利率更高；结构稳定，无原料敏感权重问题，但高费用率（期间费用率 40.65%）吞噬净利，净利率仅 6.42%。
  • 因子3 库存与采购节奏：无存货成本波动；但应收账款高（2026H1 经营现金流 -5.43 亿，季节性，年底回款集中），需区分"当期利润"与"现金回收"的可比性。
  • 因子4 政策 / 市场锚点（需求驱动变量）：核心驱动是国网资本开支节奏与数字化预算（非原料）。情景：① 乐观——国网追加数字化预算、AI 订单放量；② 悲观——投资偏重硬件基建、软件占比下滑。验证点：国网年度数字化投资完成额、公司新签订单增速；证伪：国网投资不及预期 / 集采大幅降价致毛利破 45%。

第三步进阶 · 份额变量与主业迁移空间（三层法）

  • 层1 现有业务 市场容量 × 份额变量：在国网系内部信息化市占高（绑定深），但整体电力软件市场受华为云 / 阿里云等侵蚀。五锚点：① 供给侧——国网系内部供应商集中；② 客户份额——省网公司覆盖率；③ 技术代际——财务大模型国产领先；④ 成本曲线——央企研发规模优势；⑤ 份额加速度——信创替代利好国产、算力电网新需求。验证点：国网数字化招标中标份额公告。每档：保守守住现份额 / 中性小幅提升 / 乐观抢信创份额。
  • 层2 扩展业务 主业迁移空间（新易盛范式）：财务软件能力向"能源 AI 智能体"迁移，TAM 由企业管控扩至能源全域，新场景需重新认证（门槛高也是护城河）。未过验证点（订单未披露），仅作中期期权，不计入中性。
  • 层3 风险折扣 证伪信号：国网投资放缓、集采大幅降价、营收连续两季零增长、智慧能源收入占比未突破 20%。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 5.22 已高于基准估值区间（3.13–3.45 元）与远期中性（4.13 元）。
安全边际：中性远期 4.13 元 → 空间 −20.9%；乐观 6.79 元（+30.1%）需订单加速；下行保护弱（现金流季节性为负、无破净保护）。
介入条件：① 回落至 4.0 元以下（2026E PE < 22x）开始具备安全边际；② 加仓信号：国网数字化中标份额公告、智慧能源收入占比突破 20%、连续两季营收增速 > 15%。
最大风险（最可能破坏逻辑的因素）：① 国网投资 / 数字化预算不及预期；② 华为 / 阿里云等抢食央企数字化份额；③ 估值高位回撤（PE 33x 无业绩加速器支撑）。
结论：暂不介入（估值已反映预期，中性空间为负；若订单加速可上调至纳入观察）。

第五步进阶 · 上行想象力情景（四类，只进乐观 / 机会栏）

  • A 行业调整剩者红利：不适用（非过剩出清行业）。
  • B 政策反转期权：国网十五五 4 万亿超预期追加数字化预算 → 订单加速。验证点：国网年度数字化投资公告上调；证伪：投资偏硬件轻软件。上调重点关注条件：连续两季营收增速 > 15% 且新签订单披露。
  • C 市场错杀修复：若因风格切换跌破 4 元（PE < 22x），价值修复弹性大；验证点：股价回落 + 基本面未恶化。
  • D 技术突破 / 代际跃迁期权：光明电力大模型 / AI 财务智能体量产落地，打开新增长曲线；硬验证点：客户定点 + 大额订单 + 成本优于旧路线（三者缺一只作机会情景）。
