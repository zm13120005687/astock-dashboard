第一步：公司是干什么的？

一句话定位：扬州老牌国企药企（前身为 1958 年扬州制药厂），靠独家泌尿系统创新药"爱普列特"吃饭，近年砸钱并购低毛利流通/制药资产 + 重注一条糖尿病 SGLT-2 创新药管线，正处于"仿制药基本盘被集采侵蚀、创新药尚未接棒"的转型换挡期。

并购整合：2025 年斥资约 2.53 亿完成常乐制药 + 龙一医药两笔收购，意图打通"产线—流通"链条，但两者毛利率显著低于本部，直接导致公司综合毛利率从 49.41%（2024）跌至 28.67%（2026H1）。

（3）产业链传导 + 原料成本→毛利结构四因子

产业链位置：上游为甾体激素中间体/化学原料与包材（公司部分原料药自产，纵向一体化，成本可控性优于纯制剂厂）；下游为医院/药店终端（集采买方强势）与海外原料药客户。整体议价权弱——集采品种价格由招标决定，转嫁能力为零。

  • 因子1 成本传导弹性：集采降价 → 售价端无法转嫁（转嫁系数 ≈ 0）；原料端因公司自产地塞米松磷酸钠等原料药，部分成本内部消化（自供比例提升等效于转嫁系数 0.3–0.4）；2026H1 营业成本 +42.43% 超收入增速，主因是低毛利流通/常乐业务并表的结构性放大，非原料涨价主导。
  • 因子2 毛利结构再平衡：三条线毛利率——本部制造约 59%（曾 82.66%，被集采续标降价 + 高毛利品种占比下降侵蚀）、常乐/仿制药线约 30–40%（估）、流通约 17.9%。并表结构每多 1pct 流通占比，综合毛利率被动下移约 0.4pct——"综合毛利率 28.67%"掩盖了本部制造仍在 55%+ 的事实；估值必须分业务看。H1 本部收入收缩（证券之星口径母公司单体收入下降）是最需警惕的信号。
  • 因子3 库存与采购节奏：制药企业无大宗囤货逻辑；原料药产线（地塞米松磷酸钠 20000kg 新线、出口制剂/抗肿瘤药厂房、联环安庆产线）爬坡节奏决定单位成本。
  • 因子4 政策/市场锚点：①政策层——集采接续规则优化（降幅放缓，验证点：第八批以后续标平均降幅）、创新药支持（验证点：LH-1801 pre-NDA 沟通结果与申报受理）；②市场层——SGLT-2 竞品格局（8+ 款同类）与达格列净价格带。证伪信号：综合毛利率跌破 25%、本部收入连续两季下滑、续标再大幅降价、LH-1801 审评受阻。

增量三层法：

  • 层1 现有业务·份额变量：①泌尿基本盘——爱普列特 TOP2 品牌、独家品种无仿制冲击（13 连涨），份额守住即胜利（验证点：季度样本医院销售额）；②集采品种——续标中标=保留入场券，二次报量决定量增幅度（验证点：各省报量与发货数据）；③流通并购——龙一医药业绩承诺履行情况是并购增量的唯一锚（验证点：业绩承诺完成公告）。三档：保守（本部止跌）、中性（本部企稳+并表贡献全年）、乐观（仿制药新品种放量）。
  • 层2 主业迁移空间：从"仿制药+原料药"向"创新药平台"迁移——6 个创新药项目在手，SGLT-2 头对头数据为国内同类唯一完成的高质量对照。五问核查：能力可迁移（原料药+制剂一体，成本优势真实）✓、TAM 弹性（50 亿→若减重适应症拓展更大）✓、卡位（8+ 款竞品已上市，属后发但差异化定价）△、认证门槛（NDA 审评）△、信号验证（pre-NDA 已启动但获批未发生）——未过获批验证点前，LH-1801 不计入中性情景，仅作期权。
  • 层3 证伪信号：扣非净利连续下滑（H1 已 −55.14%）、本部收入持续收缩、并购标的业绩承诺不达标并引发商誉/减值、LH-1801 pre-NDA 沟通未获通过或审评发补超预期、垄断处罚后续合规风险再发。

合计增量（中性）：集采续标以量补价 + 并表完整化 + 仿制药新品种 → 2029 年归母净利约 1.0 亿；LH-1801 获批与放量不计入中性。

⚠️ 交叉校验：现价 15.58 元对应中性 2029E 估值溢价 56%——市场已经在为一个尚未获批的 SGLT-2 新药支付大部分对价。产能与订单校验：中性情景 0.95 亿净利对应收入约 25 亿，公司现有产线 + 安庆/地塞米松新线可支撑；但估值校验不通过：中性盈利锚（10.0 元）远低于现价，只有乐观情景（LH-1801 获批放量）才能支撑现价上方空间。PB 3.52x 对一个净利率 0.94% 的公司同样偏贵。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。中性盈利锚（2029E 10.0 元）较现价折让 36%；现价隐含的是"LH-1801 成功获批并快速放量"的乐观路径，而该路径尚未过 pre-NDA 与获批两个验证点。

安全边际：中性远期空间 −35.8%，悲观情景 −77.5%；PB 3.52x + 净利率 0.94% + 负债率 60.56%（流动比率 0.94、速动 0.64、现金比率 0.13，短期偿债指标紧绷）——下行缺乏缓冲。真正的"底"是扬州国资背景与爱普列特独家基本盘，但两者对不上现价。

上行想象力情景（只进乐观/机会栏，不计入中性锚）：
- 类型D 技术突破期权（核心）：LH-1801 为国内首个完成与达格列净头对头联合给药 III 期的 SGLT-2 抑制剂（HbA1c 降幅 0.79%/0.89% vs 达格列净 0.75%，伴约 2.5kg 减重获益），公司自建内分泌推广团队、原料药自供成本优势。若 2026H2 申报、2027 年获批、2029 年销售 3–5 亿 → 净利弹性 +0.6–0.8 亿，市值看向 72 亿（+62%）。硬验证点：①pre-NDA 沟通结论（2026Q3 应有公告）；②NDA 正式受理；③获批文号。三者缺一即只作机会情景。证伪信号：审评发补超预期、竞品再降价压缩定价空间、上市后进医保谈判价大幅低于预期。
- 类型B 政策期权：集采接续"反内卷"若使续标降幅显著收窄 + 商保创新药目录为 LH-1801 提供院外溢价通道。验证点：下一轮续标平均降幅数据、商保目录纳入名单。
- 类型C 错杀修复：若 2026 年报确认本部收入企稳 + 扣非环比连续改善，"盈利质量薄"的折价可部分修复。验证点：Q3 扣非环比为正。
- 什么条件才上调结论：LH-1801 获批（硬门槛）+ 扣非净利连续两个季度环比增长 + 综合毛利率回到 32% 以上，三者同时出现方可上调至"纳入观察"；若再叠加 LH-1801 首年销售超 2 亿数据，可讨论"重点关注"。

介入条件：
1. 价格：10 元以下（= 中性 2029E 锚）为价值区；若 LH-1801 获批公告后股价冲高回落至 12–13 元，属"利好兑现回踩"观察点
2. 信号：pre-NDA 沟通通过 + NDA 受理公告；Q3 扣非环比改善；本部收入同比转正；资产负债率降至 55% 以下

最大风险（最可能破坏逻辑的因素）：
1. LH-1801 商业化不及预期（首要）：上市前有 8+ 款同类竞品且已集采，上市后进医保定价与放量节奏存在双重不确定——而现价已预支了大部分成功预期
2. 盈利质量持续恶化：扣非 −55.14%、本部收入收缩、综合毛利率 28.67% 仍在下探通道
3. 财务结构脆弱：负债率 60.56%、现金比率 0.13，5 亿科创债与后续融资依赖度高；若创新药烧钱节奏超预期，财务费用将进一步吞噬利润
4. 并购整合风险：常乐/龙一业绩承诺若不达标，面临商誉/长期资产减值
5. 合规尾部风险：6103 万垄断罚款暴露的原料药定价合规缺陷，存在再调查可能

结论：暂不介入

结论自洽性：中性远期空间 −35.8% ≤ +50%，与"暂不介入"匹配。公司质地并非劣质——爱普列特独家基本盘稳固、管线有真东西（头对头优效数据）、国资背书——但现价把创新药的成功当成了大概率事件，而审评与商业化仍是未验证的小概率路径。这是一张"彩票赔率不错、彩票价格偏贵"的票，等价格或等验证点，二者居其一再谈介入。
