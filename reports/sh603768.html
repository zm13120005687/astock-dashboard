（3）产业链传导

因子1 成本传导弹性（pass-through）
- 客户结构决定弱议价权：前五大客户占销售 58.40%（江淮、奇瑞为绝对主力），主机厂对 Tier2 冲压件供应商普遍执行年度降价 2–3% + 钢材价格联动条款。
- 钢材价格联动条款是行业惯例（宝武为主要供应商，2024 年占采购额 34.02%），即钢价波动部分可传导——传导率 ≈ 0.5–0.7（中等）。
- 佐证：2025 年归母 −2.05 亿、毛利率从 17.03% 崩至 11.94%，主要因年末集中计提减值，但毛利率下滑亦反映传导不完全；2026H1 毛利率回升至 16.89% 则体现"自动化升级 + 规模效应 + 钢价温和"三者叠加。
- 量化：钢价若上涨 10%，×(1−0.6) = 实际毛利承压约 4%，对应综合毛利率约 −0.7pct。

因子2 毛利结构再平衡（分业务线毛利率 + 原料敏感权重）

→ 结构性判断：当前 88.83% 的收入来自毛利率 17.33% 的传统冲压件，毛利率最高的储能电箱（29.07%）仅占 1.85%。2027–2028 年压铸与壳体投产是毛利结构再平衡的唯一路径——若压铸（25–35% 毛利）与壳体（18–22%）合计占比提升至 15%+，综合毛利率可修复至 19–20%。单一综合毛利率 16.89% 完全掩盖了这一潜在的结构跃迁，必须分业务看。
→ 铝价风险提示：压铸业务投产时点（2027Q1）恰逢铝价上行周期（2026 年预计 +20–25%，霍尔木兹海峡封锁致海湾产能瘫痪，中国产能已近 4500 万吨天花板）——新业务一投产就面临高原料价，是压铸项目最大的不确定性。

因子3 库存与采购节奏（timing）
- 存货 5.06 亿 → 5.68 亿（+12.25%），存货周转率 1.35 次（H1），"以销定产"模式下库存随收入增长属正常。
- 低价囤货收益：2026H1 毛利率从上年同期 12.37% 升至 16.89%（+4.52pct），除自动化升级外，亦可能含低价钢材库存收益——需警惕其不可持续性。
- 高价接货风险：2026H2 起若钢价回升，而主机厂年降照旧，毛利将被两头挤压。
- 套保/长协：与宝武等签订年度框架协议（长协），对冲比例未披露——信息盲区。
- 验证点：季度毛利率、存货周转、宝武季度出厂价、公司章程是否新增套保业务。

因子4 政策/市场锚点（原料成本驱动变量）
- 市场层：①钢——2026 年亚洲钢价预计约 500 美元/吨（同比下跌），欧洲 700、北美 1150。公司采购以国内钢为主 → 钢价下行是当前毛利修复的重要助力，也意味着该助力在钢价拐头后消失。②铝——2026 年预计 +20–25%，直接抬高即将投产的压铸业务成本。③铜——+40%，影响电箱与线束。
- 政策层：①印尼镍配额从 380 万吨砍至 270 万吨（2026），抬升不锈钢成本；②中国能耗双控对电解铝限产（铝供给刚性）；③美国对华汽车零部件关税（公司境外收入仅 181.31 万，影响极小）。
- 验证点：LME 铝价（月）、国内冷轧板卷（周）、公司季度毛利率、压铸项目投产公告。
- 证伪信号：综合毛利率跌破 14%；或压铸投产首年毛利率低于 15%（高铝价 + 低良率双杀）。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务 = 市场容量 × 份额变量（5 锚点）
1. 供给侧份额：冲压利用率 82.71%、焊接 79.83%——仍有 17–20pct 提升空间，短期增量无需新增投资，靠订单填充即可。
2. 需求侧份额：已进入比亚迪、大众安徽、上汽、北汽等新客户配套体系，从"江淮+奇瑞双依赖"向多客户分散；但前五大客户仍占 58.40%，集中度风险未解。
3. 技术代际差：传统冲压为成熟工艺；一体化压铸为下一代工艺，公司是后来者（文灿、广东鸿图已量产），处于追赶位而非领先位。
4. 成本曲线位置：钢材加工子公司自营（合肥/马鞍山/唐山常茂，H1 净利合计 1463.28 万，唐山常茂半年 457.20 万已超 2025 全年 416.64 万）→ 向上游延伸形成局部成本优势，成本曲线略左移。
5. 份额二阶导数：2026H1 收入 +19.54%（远超行业 −4%），处于份额加速获取段（新客户 + 新项目），但需验证是否可持续。
- 三档：保守维持现有份额（2029 收入 52 亿）/ 中性小幅提升至 60 亿 / 乐观至 78 亿（压铸满产 + 壳体大客户定点）。
- 验证点：季度收入增速、新客户定点公告、压铸项目投产进度公告。

层2 扩展业务 = 主业迁移空间（新易盛范式五点）
迁移方向：冲压/焊接 → 一体化压铸 + 电池壳体 + 储能电箱（同属金属结构件/精密成型）。
- ①能力可迁移性：中高——金属成型、模具开发、焊接工艺同源；但大型压铸（6000 吨级以上设备、高真空压铸工艺、良率控制）是新的技术门槛，非简单延伸。
- ②新 TAM 弹性：一体化压铸件单车价值 2000–5000 元（远高于传统冲压件数百元）；电池壳体单车价值 1500–3000 元；储能电箱受益储能装机高增——新 TAM 显著大于旧池塘。
- ③切入卡位：中——2027Q1 投产时点偏晚（文灿/鸿图已量产 2–3 年），但安徽新能源集群（比亚迪合肥、大众安徽、蔚来）提供本地化配套窗口。
- ④客户认证门槛：既是护城河也是阻力——公司已有江淮/奇瑞/比亚迪合作关系，若能将冲压件的客户关系延伸到压铸件，导入会顺畅；但压铸件需重新认证（1–2 年）。
- ⑤信号验证：部分通过——储能电箱已实现收入 3535.50 万且毛利率 29.07%（营收结构新品类占比开始出现）；但压铸与壳体尚无客户定点公告、尚无收入（子公司合肥常捷 −1373.52 万、合肥常汇 −1667.79 万仍在亏损）。
- → 判定：储能电箱已过验证点，可计入中性；一体化压铸与电池壳体未过验证点（无定点公告、无收入），仅作中期期权，不计入中性净利。

层3 风险折扣：证伪信号
①压铸项目二次延期；②投产首年毛利率低于 15%；③应收账款继续快速增长（H1 已达 11.59 亿）并出现新的大额坏账（哪吒教训）；④综合毛利率跌破 14%；⑤经营现金流连续两年大额为负。命中即下调。

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

校正1 资产质量折扣
当前 PB 1.23x，未破净但接近。需回答"若回落至 PB<1 是否算便宜"：
- 资产构成：总资产 68.48 亿，主要为冲压/焊接设备、厂房、在建工程 4.17 亿；设备专用性强（整车配套专用模具与产线），转产能力弱。
- 隐含负债：①应收账款 11.59 亿（占 2026 年化收入约 30%），合众新能源/哪吒破产重整已证明客户信用风险实在；②有息负债规模快速扩张（见校正3）；③在建项目转固后年增折旧 0.9–1.1 亿。
- 超额投资警示：安庆项目计划投资 3.70 亿但累计已投入 4.47 亿（超预算 21%）；压铸项目已延期一次——资本开支控制力偏弱。
- 反面证据（是否"金融资产未重估型"）：无大额金融资产/上市公司股权 → 不适用真安全边际例外。
- → 结论：PB 1.23x 不构成安全边际；一旦破净（<9.27 元），大概率是"应收减值 + 压铸投产不及预期 + 利息负担"的公允定价，而非低估。禁止单凭 PB<1 推导空间。

校正2 周期位置校正
- 汽车零部件：当前处于周期底部区域——国内汽车产销 −4.0%/−4.1%、购置税退坡、主机厂年降压力大、2025 年公司毛利率一度跌至 11.94% 并计提大额减值。
- 2026H1 毛利率修复至 16.89% 属底部回升初期，但回升幅度中可能含低价钢材库存收益（一次性）。
- 周期归一化处理：中性情景净利率取 2.8%（1.90/67.5），低于公司历史最好年份 2023 年的 4.05%，已做周期归一化下调，未使用单年好年景或"拐点年化"。
- 当前周期位置标注：汽车零部件 = 底部回升初期 / 一体化压铸 = 导入期 / 储能电箱 = 成长期。

校正3 杠杆下行情景（负债率 63.66% > 60%，必附）
- 2025 年末资产负债率 63.66%、有息负债 19.44 亿、有息负债率 50.72%；2026H1 继续加杠杆：短期借款 9.12→12.01 亿（+31.70%）、长期借款 6.69→9.22 亿（+37.81%）、筹资活动现金流净额 5.22 亿（+136.40%）。
- 经营现金流持续为负：2025 全年 −1.81 亿、2026H1 −2.46 亿（上年同期 −3.60 亿）。"借钱扩产 + 经营失血"是本股最实质的风险。
- 负面情景：若利率上行 100bp（有息负债 24 亿 → 年利息 +0.24 亿）且汽车需求再降 5%（收入 −3.4 亿 → 净利 −0.10 亿），同时压铸延期一年（少贡献 0.3 亿）→ 2029E 归母降至 0.3 亿以下，对应市值不足 5 亿 → 空间深度转负（−60% 以上）。
- → 依纪律：该负面情景可使空间转负，故本股不得标注"重点关注"，至多"纳入观察"，并须注明高贝塔属性。

期权纪律：一体化压铸（无定点公告、无收入）、电池壳体（规划阶段）、200 万只产能规划——均未过验证点，不计入中性净利，仅出现在乐观情景。例外：储能电箱已过验证点（有收入、有毛利率披露），已计入中性。

交叉校验

现价 11.35 元 / 2026E 归母 0.45 亿 = 2026E PE 60x（扭亏首年 PE 失真）；PB 1.23x；PS(TTM) = 27.01 / 约 40 亿 = 0.68x。PS 0.68x 对汽车零部件行业属偏低水平（行业通常 0.8–1.5x），说明从资产与收入口径看并不贵，贵在净利率太低（2.8%）。若净利率能修复至 5%（行业正常水平），市值可达 67.5×5%×16 = 54 亿 → 22.7 元。本股的全部赌注在于"净利率能否从 2.8% 修复到 5%"。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低（资产口径）/ 中性（盈利口径）。PS 0.68x 偏低、PB 1.23x 接近净资产，但 2026E PE 60x 与 −2.46 亿经营现金流说明盈利质量尚未修复。

安全边际：
- 中性远期 12.77 元 → +12.5%，不达"重点关注"的 >50% 门槛
- 悲观 5.50 元 → −51.5%（杠杆 + 减值双杀）；乐观 20.50 元 → +80.6%
- 下行保护：每股净资产 9.27 元（PB 1.0）为第一道支撑，9.0 元附近具备一定安全边际
- → 风险收益不对称偏负：上行 +12.5% vs 下行 −51.5%，但乐观情景 +80.6% 提供了右侧弹性

介入条件：
1. 9.5 元以下（PB < 1.03） 才具备安全边际，可分批建仓
2. 加仓信号：①一体化压铸项目 2027Q1 如期投产且投产首年毛利率 ≥20%；②储能电箱全年收入突破 1 亿；③应收账款周转率回升（H1 应收 11.59 亿需压降）；④经营现金流转正
3. 观察指标：季度毛利率（是否站稳 17%）、在建工程转固进度、有息负债规模、前五大客户结构变化

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 经营现金流持续失血 + 有息负债快速扩张（首要）：H1 经营现金流 −2.46 亿、短期借款 12.01 亿、长期借款 9.22 亿，若压铸项目投产后订单不达预期，公司将陷入"高额折旧 + 高额利息"的双重挤压
2. ⚠️ 应收账款坏账：应收 11.59 亿（占年化收入 30%），哪吒汽车破产重整已是前车之鉴，新能源客户（振宜、合众等）信用风险高于传统主机厂
3. 一体化压铸投产不及预期：项目已延期一次（2026-03→2027-03），公司历史上募投项目多次延期（冲压技改与研发中心从 2019 一延再延至 2025），执行力存疑
4. 铝价高企侵蚀新业务：压铸业务 2027Q1 投产恰逢铝价上行周期（+20–25%），一投产即高成本
5. 客户集中度：前五大客户占 58.40%，江淮/奇瑞任一大客户波动即影响显著

结论：纳入观察

理由：中性远期空间 +12.5%，>0 但不达"重点关注"的 >50% 门槛；校正3 的杠杆下行情景（利率上行 + 需求下行 + 压铸延期）可使空间深度转负至 −60%，依纪律不得标"重点关注"。
公司处于明确的扭亏拐点：2026H1 归母 1860.88 万（上年 −2052.54 万）、毛利率从 12.37% 修复至 16.89%、Q2 单季归母 +143.79%、7 名董监高增持 ≥1360 万（管理层用现金投票）。但"扭亏"与"高质量盈利"之间还隔着三道坎：经营现金流 −2.46 亿、有息负债快速扩张至 24 亿级别、一体化压铸尚未产生收入。
核心跟踪点：①一体化压铸 2027Q1 能否如期投产；②经营现金流能否转正；③应收账款能否压降。
