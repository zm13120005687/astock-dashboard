实控人 / 控股股东：江西铜业集团有限公司（江西省国资委）

第一步：公司是干什么的？

一句话定位：国内大型黄金冶炼与有色金属综合利用企业，以"火法冶金"规模冶炼为底座，伴生回收银、铜、稀贵金属，并拥有部分自有矿山（辽上金矿）增厚利润。

主要产品收入（2026H1）：黄金 374.74 亿（60.27%）、电解铜 117.48 亿（18.89%）、白银 94.01 亿（15.12%）、硫酸 7.32 亿（1.18%）。

产能（设计）：黄金 109.817 吨/年、白银 1200 吨/年、电解铜 33.5 万吨/年、硫酸 168 万吨/年；建成 4 套火法冶金系统，可综合回收锑白、铋锭、碲锭、二氧化硒、金属砷等稀贵金属。

2026H1 实际产出：黄金 37.51 吨、白银 562.59 吨、电解铜 12.58 万吨、硫酸 80.30 万吨。

主要客户 / 下游：上海黄金交易所（综合类会员）、有色及贵金属贸易与加工商；自有矿（辽上金矿）提供部分原料。

境内外收入占比：国内为主（合并抵消后国内占主导），部分贸易 / 原料进口。

第二步：行业景气度 + 政策 / 市场数据

（1）政策端（近 6–12 个月）——中性偏多（贵金属战略属性）

  • 黄金战略地位提升：全球央行购金 + 地缘避险 + 去美元化，黄金价格处历史高位；国内"增储金"政策导向利好黄金产业链。
  • 稀贵金属回收：资源综合利用、循环经济受政策鼓励（公司绿色工厂 / 危废处置资质）。
  • 环保 / 能耗：冶炼环保排放标准趋严，合规产能稀缺，头部企业受益；但环保资本开支上升。

（3）产业链传导

上游：金精矿 / 含金银废料（国内自产 + 进口），原料价随金属价格联动；自产矿（辽上金矿）提供低成本原料增量。
下游：上期所 / 上金所交割、贵金属贸易与加工；价格随国际金属价格。
议价权：冶炼环节为来料加工 + 价差模式，对金属价格无定价权（价格接受者），利润来自加工费 + 库存价差 + 自产矿溢价；议价权弱，靠规模与综合回收降本。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：冶炼加工费（TC/RC）决定利润，转嫁系数低（约 0.2）——金属原料价涨跌主要由客户 / 市场承担，公司赚固定加工费 + 自产矿价差。2026H1 毛利率仅 2.60%，印证薄利属性。
  • 因子2 毛利结构再平衡：
    | 业务线 | 毛利率（2026H1） | 原料敏感权重 |
    |---|---|---|
    | 黄金冶炼 | 0.74% | 高（金价联动，加工费低） |
    | 电解铜 | 0.39% | 高（铜价联动） |
    | 白银 | 2.71% | 中高 |
    | 稀贵金属回收 | 较高（综合回收溢价） | 中 |
    | 自产矿（辽上） | 高（成本锁定，金价高位弹性大） | 低但增益大 |
    结构风险：主体冶炼毛利极薄（<1%），利润高度依赖自产矿（辽上金矿年产金 3–3.5 吨）与稀贵金属回收，综合毛利率对金属价格高度敏感。
  • 因子3 库存与采购节奏：冶炼企业持有在产金属库存，金价上行期享"库存收益"（当期毛利虚高），金价回落则库存损失；2026H1 高金价下存在库存收益成分，须区分当期 vs 远期可比性。
  • 因子4 政策 / 市场锚点：① 金价（全球央行购金、美元、地缘）；② 白银 / 铜价（工业 + 金融双重属性）；③ 环保 / 能耗政策（抬升合规成本、利好头部）；④ 进口原料关税 / 管制。验证点：国际金价、TC/RC 加工费、自产矿产量；证伪：金价高位回落 + 加工费压缩。

合计增量：核心增量 = 辽上金矿满产（自产矿溢价）+ 冶炼规模 + 稀贵金属回收。自产矿是唯一"高毛利"确定性增量；冶炼规模受加工费与金属价格约束。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：① 供给侧——国内黄金冶炼产能头部集中，公司居前；② 客户份额——上金所会员，份额稳定；③ 技术代际——富氧底吹等火法工艺先进，综合回收率领先；④ 成本曲线——规模 + 自产矿左移；⑤ 份额加速度——平稳。三档：保守守住现有份额 / 中性随行业微增 / 乐观进口矿替代放量。验证点：冶炼产量、自产矿产量公告。
  • 层2 主业迁移空间（新易盛范式）：从"纯冶炼"向"冶炼 + 资源（自产矿）"迁移，提升利润结构。能力可迁移性高（已有辽上金矿）；新 TAM 弹性中（资源端）；切入卡位已具备；信号验证——辽上金矿已投产放量。→ 中期已部分兑现，可计入中性边际。
  • 层3 证伪信号：自产矿产量不及预期、冶炼加工费大幅压缩、金属价格持续回落。

第四步：估值锚定（自下而上，非增速外推 · 重资产周期股校正）

方法：禁用单年好年景 / 拐点年化。2026H1 归母高增主要因非经常性 3.73 亿 + 金价高位库存收益；扣非仅 3.74 亿（−9.08%）。用"周期归一化扣非净利 + 自产矿增量"测算，并标注周期位置（金属价格历史高位）。

总股本：14.30 亿股

周期位置判断

当前处于金属价格历史高位（金价、银价均处多年高位）。中性净利不得按当前暴利年化，须周期归一化——假设金价部分均值回归但自产矿增量保留。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣：PB 1.27（未破净），资产以冶炼固定资产 + 在产金属库存为主，重置成本有支撑；非金融资产未重估型，估值靠经营盈利，合理。
  • 校正2 周期位置校正：当前金属价格处历史高位，中性净利取周期归一化（金价部分回落假设），严禁按 2026H1 高金价年化（否则会得出 15+ 元错误锚）。顶部位置下中性须保守。
  • 校正3 杠杆下行情景：资产负债率 63.6%（偏高），经营杠杆 + 财务杠杆双高；金价回落 + 加工费压缩 → 净利可降至 5 亿（悲观 4.20 元，−65.7%）。下行空间巨大，不得标"大空间 / 重点关注"。
  • 期权纪律：辽上金矿满产已计入中性；若金价创新高属机会情景（乐观 +0.6%，仍仅持平现价），不额外加成。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高 / 已透支高位金价。现价 12.24 元对应中性锚 6.85 元溢价约 79%，PB 1.27x 在冶炼股中偏贵。

安全边际：中性远期 6.85 元 → 空间 −44.0%；悲观 4.20 元（−65.7%）；乐观 12.31 元（+0.6%，仅持平现价）。三重情景均不提供正收益安全垫。

介入条件：回落至 7.0 元以下（对应中性盈利锚、PE<15x、PB<1.1x）才具配置价值；加仓信号：① 自产矿（辽上）产量公告超预期；② 冶炼加工费 TC/RC 回升；③ 金价趋势性站稳高位而非脉冲。

最大风险：① 金价 / 银价从历史高位回落（最大单一风险）；② 冶炼加工费压缩；③ 高负债（63.6%）+ 经营现金流大额为负（H1 −20 亿）的流动性 / 财务压力；④ 环保资本开支上升。

结论：暂不介入

公司是优质黄金冶炼平台（江铜背景、规模与综合回收优势、辽上金矿增量），但当前价格已充分定价高位金价，中性周期归一化盈利锚对应股价 6.85 元，较现价下行 44%。重资产 + 高负债 + 金属价格顶部，赔率不佳。若金价趋势性站稳高位且自产矿超预期，可重估。

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：不适用（非过剩出清，头部格局稳定）。
  • 类型B 政策反转期权：央行增持黄金 / 贵金属战略储备政策加码，托底金价。列具体政策名（央行购金、增储金导向）+ 反转信号（购金数据）；未过验证点仅作机会情景。
  • 类型C 市场错杀修复：若因金属价格短期波动股价跌至 PB<1.0x（~9.6 元以下对应更低压，当期 6.85 锚），按重置成本与自产矿价值存在修复弹性；触发点：金价企稳、风格回归资源。
  • 类型D 技术突破 / 代际跃迁期权：不适用（无全新技术路线）。
  • 上调至重点关注的条件：金价趋势性站稳历史高位 + 辽上金矿产量超 3.5 吨/年 + 冶炼加工费回升，使 2029E 扣非净利上修至 11 亿以上、远期空间转正并突破 +50%。
