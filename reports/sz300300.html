第一步：公司是干什么的？

一句话定位：聚焦"智慧城市精准发力 + 智慧医疗为第二增长曲线"的政府/企业信息化集成商，原汉鼎宇佑，现平潭国资背景，提供物联网/大数据/AI 综合解决方案。

核心产品：智慧城市（智慧农业/医院/交通/酒店）、公共数据运营、数字孪生、智慧医疗解决方案。

主要客户/下游：政府（平潭及各地城投/园区）、金融机构、医院。实控/股东背景含平潭国资（平潭创投），政府资源属性强。

境内外收入占比：以境内为主（未披露境外占比）。

资产规模：总资产 9.99 亿，归母净资产 2.48 亿（2026H1 末）。

（3）产业链传导

上游：硬件设备（服务器/网络设备）、人力（集成商外采）。成本随 ICT 硬件价格波动，但占比小。

下游：政府/医院付款周期长 → 应收账款高、回款慢，直接压制经营现金流（H1 −6114 万）。

议价权：弱。系统集成同质化严重，对政府客户无定价权；毛利率已降至近零（−0.66%）即为证据。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：集成商对政府/大客户无转嫁能力（转嫁系数 ≈ 0），硬件涨价/人力成本只能自担；当前毛利率近零说明成本已无法传导。
  • 因子2 毛利结构再平衡：智慧城市 90.5% + 智慧医疗 9.5%，两线毛利率均未披露分业务，但综合 −0.66% 表明主业务已无毛利安全垫，不能用综合数掩盖结构性失血。
  • 因子3 库存与采购节奏：集成项目按合同采购，无囤货收益；长账期导致"纸面收入、现金亏损"。
  • 因子4 政策/市场锚点：政府财政（城镇化/数据要素投资）是需求驱动变量；验证点：地方城投/数据局招标公告、平潭项目落地。政府开支收紧则需求证伪。

输出喂给第四步：当前毛利率不可持续，正常化需营收重回 3–4 亿且毛利率恢复至 15–20% 才可能盈利。

扭亏触发点（关键）：营收规模从 ~1.5 亿回升至 3 亿+（订单放量是前提），且费用率压降。当前扣非减亏 30.74% 是改善信号，但绝对值仍亏。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务 = 市场容量 × 份额变量：智慧城市市场大（万亿级），但公司份额极小（营收 <1 亿 vs 行业龙头百亿级）；供给侧分散、需求侧政府客户粘性低（无排他认证）。三档：保守（维持 1.5 亿）、中性（3 亿）、乐观（5 亿）。
  • 层2 扩展业务 = 主业迁移空间：智慧医疗/公共数据运营为"旧技术换新市场"，能力可迁移（集成→数据运营）；但新 TAM 变现早期、认证门槛（数据合规）高，未过验证点，仅作中期期权。
  • 层3 证伪信号：连续两季营收 <8000 万、毛利率持续为负、经营现金流未转正、无新增大额订单公告。

第四步：估值锚定（自下而上，非增速外推 + 正常化净利润法）

亏损股方法：估稳态营收 → 保守正常化净利率 → × 远期 PE → 目标市值。总股本 约 6.67 亿股。

交叉校验：现价 9.43 对应市值 62.88 亿，是正常化合理市值（7 亿）的 9 倍。即便乐观情景（21 亿）也仅 3.15 元，远低于现价。当前定价完全由"平潭国资 + 重组/资产注入"期权支撑，非基本面。

第四步进阶（重资产/周期校正）

  • 校正1 资产质量折扣（破净原因）：公司未破净（PB 25.32 为极高溢价），但这是期权溢价非资产溢价——净资产仅 2.48 亿，市值 62.88 亿全靠预期。若重组/订单落空，市值向净资产回归空间巨大（−95%）。
  • 校正2 周期位置：非强周期，处"业务萎缩 + 费用刚性"的结构性困境。
  • 校正3 杠杆下行情景：资产负债率约 75%（总资产 9.99 亿 − 净资产 2.48 亿），经营现金流持续为负（H1 −6114 万），高杠杆 + 现金流出 → 下行情景转负（悲观 −95%），不得标大空间。
  • 期权纪律：平潭重组/资产注入/公共数据运营均未公告兑现，不计入中性，仅作乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：严重高估（期权定价）。基本面仅支撑 1–3 元，现价 9.43 全靠重组/国资预期。

安全边际：无。中性 −88.9%，悲观 −95.2%。下行极大。

介入条件：仅当实质重组/资产注入公告 + 大额订单落地且股价回落至 3 元以下；或营收连续两季 >1.5 亿且经营现金流转正。否则不参与。

最大风险（首要）：① 营收持续萎缩、主业无法覆盖费用；② 高负债 + 现金流出导致资金链压力（亏得起吗见下）；③ 重组/注入预期落空（市值回归净资产）；④ 政府开支收紧。

亏损股三问（标准字眼写全）：
1. 为什么亏：营收规模过小（年化 ~1.5 亿）无法覆盖销售/管理/研发刚性费用（费用率 55.73%），主业毛利率近零（−0.66%），项目周期致阶段性亏损；非一次性减值为主（扣非 −3891 万亦亏，说明经营本质亏损）。
2. 靠什么扭亏，触发时点在哪一年：智慧城市/智慧医疗政策订单放量（十五五+城市更新+公共数据运营）+ 平潭国资资源协同，使营收恢复至 3 亿+；触发时点 2027–2028 年（若订单兑现），否则持续亏损。
3. 亏得起吗：账上净资产 2.48 亿，但经营现金流 H1 −6114 万、资产负债率 ~75%，生存能力偏弱；依赖再融资/国资支持续命。若 1–2 年无订单扭转，存在持续失血甚至 ST 风险。

结论：暂不介入

虽未达"确无扭亏可能 + 无重组预期"的坚决回避标准（平潭国资背景留期权），但基本面严重高估、现金流出、扭亏未见实质订单，当前价风险收益极差。等待重组/大额订单实质落地信号。

上行想象力情景（四类，对称于下行）

  • A 行业调整剩者红利：智慧城市出清，区域集成商剩者获份额（验证点：公司中标公告金额）。
  • B 政策反转期权：公共数据运营/城市更新政策加码，公司凭平潭资源获大单（验证点：平潭/数据局项目公告，未过验证点仅作机会情景）。
  • C 市场错杀修复：不适用（现价高估，非错杀）。
  • D 技术突破/代际跃迁期权：公共数据运营从 0 到 1 落地（硬验证点：数据运营收入占比跳升 + 客户定点，否则仅作机会情景）。

上调重点关注条件：实质重组/资产注入公告 + 营收连续两季 >1.5 亿 + 经营现金流转正。
