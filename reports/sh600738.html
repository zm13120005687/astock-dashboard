第一步：公司是干什么的？

一句话定位：一座以专业市场（服装批发）收租为利润基石、以兰州亚欧商厦与"商业+文旅"酒店为第二曲线的区域商业资产运营商——高毛利（综合 67%）、低负债（30.88%）、强现金流，但营收零增长是最大硬伤。

核心产品/服务：
- 专业市场收租 + 数字化双平台：向服装批发商户出租商铺收租金与管理费。杭州环北做采购商/商户资源增量与产学研合作；南京环北聚焦年轻化、品牌化升级（高校服装设计大赛、社交矩阵传播）。平台侧已落地 "丽潮购"（线上采批交易闭环）、"丽达通"（智慧物流）、"丽尚智管"（线上收费与智慧园区），公司整体运营自动化率超 80%。
- 商贸百货：兰州亚欧商厦 2026H1 落地乐刻运动等 23 个新品牌，融合敦煌美学完成国潮焕新；线上渠道销售额同比 +97%，会员消费占比同比 +近 20pct；自营亚欧超市优化商品结构与供应链。
- 商业及酒店：亚欧国际大厦（313 米"甘肃第一高楼"，5A 写字楼 + 酒店 + 政务服务 + 文旅消费）；亚欧国际云阁城际酒店（2025-05-28 开业，与华住集团合作运营，"亚欧城际数字大脑"），2026H1 为首个完整运营半年；亚欧大酒店推"住宿 + 景点通票"组合产品。

主要客户 / 下游：服装批发商户（B 端，杭州/南京）、兰州本地消费者与游客（C 端）、商旅与文旅客群（酒店）。客户高度分散，无单一大客户依赖——这是本股的结构性优势。

境内外收入占比：内需 100%，集中于杭州、南京、兰州三地，无出口敞口。

股东背景：控股股东浙江元明控股（直接持股 25.31%，合计控制表决权 35.46%），实际控制人为丽水经济技术开发区管理委员会——2020 年 7 月完成控制权变更，由民营控股转为国有控股（前身为兰州民百，1996 年上市）。国资背景带来信用与资源支撑：控股股东在 2025-12 至 2026-05 期间以集中竞价累计增持 1522.67 万股（占总股本 2%）、金额 7692.86 万元，并获工商银行浙江省分行不超过 1 亿元专项贷款支持，顶格完成增持承诺。第二大股东为红楼集团（12.27%）。

（3）产业链传导

上游（成本端）：公司是"收租型"商业运营商，没有大宗商品原料。真实成本项是：① 自有物业折旧与摊销（沉没、刚性）；② 物业维护与能耗；③ 自营超市/百货的商品采购成本（亚欧超市）；④ 人力成本。因此传统意义上的"原料涨价 → 毛利承压"传导链在本股几乎不存在——这是它与制造/资源型公司的根本区别。

下游（收入端）：① 服装批发商户的承租意愿（取决于服装批发大盘景气，2025H1 44 家重点市场成交 +10.67%）；② 兰州 C 端消费与文旅客流（甘肃文旅 +8%）；③ 商旅客群（酒店）。

议价权判断：专业市场强（核心商圈土地稀缺 + 商户转换成本高，毛利率 77.96%）；商贸百货中等偏弱（百货业态全行业零增长，毛利率 50.16% 靠品牌组合与会员运营维持）；酒店中等（RevPAR 随行就市，毛利率 19.14%）。整体议价权中偏强。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子 1 · 成本传导弹性（把议价权量化成转嫁系数）
  • 专业市场端：租金合同通常 1–3 年一签，到期重签可提租；核心商圈商户转换成本高 → 转嫁系数 ≈ 0.7–0.8。成本（折旧、人力、能耗）上行时，可通过续约提租对冲大部分。
  • 商贸百货端：线下零售价格战 + 百货业态零增长 → 转嫁系数 ≈ 0.4–0.5，提价能力弱，靠品类结构与会员运营"挤"毛利率。
  • 酒店端：房价随行就市、淡旺季波动 → 转嫁系数 ≈ 0.5–0.6。

  • 结论：公司整体转嫁系数 ≥ 0.7，明显优于制造型公司——这正是它能在营收零增长时把利润做到 +29.73% 的根本原因。

  • 因子 2 · 毛利结构再平衡（分业务线毛利率 + 敏感权重，禁用单一综合毛利率）

业务线 收入权重 毛利率 对成本变量的敏感权重
专业市场管理 66.82% 77.96% 折旧/人力/能耗 0.45；商户出租率 1.0
商贸百货零售 17.89% 50.16% 商品采购成本 0.60；客流 0.8
商业及酒店管理 11.02% 19.14% 人力/能耗 0.75；RevPAR 1.0

→ 综合毛利率 67.37%（+0.71pct）。注意一个易误读点：酒店业务（毛利率 19.14%）收入增速 +34.40%，快于专业市场（−1.97%），因此酒店占比上升会结构性稀释综合毛利率——但这不代表主业恶化，反而是第二曲线在做大。禁用单一综合毛利率代表全结构：若 2029 年酒店收入占比从 11% 升到 20%，即便各条线毛利率不变，综合毛利率也会自然下移 3–5pct。
→ 利润结构迁移的方向：从"专业市场单极（占利润 80%+）"转向"专业市场 + 酒店 + 百货 + 数字化服务"四元结构。估值时必须给高毛利的专业市场业务更高权重。

  • 因子 3 · 库存与采购节奏（timing）
  • 预收租金的现金前置效应：2026H1 经营现金流 1.02 亿（+98.96%），主因专业市场预收租金增加——即"先收钱、后提供服务"，属现金流的正向 timing，使公司现金流远好于利润表观感。
  • 自营商品存货：亚欧超市存货周转 1.55 次/半年，存货规模小、跌价风险低；不涉及低价囤货/高价接货的大宗节奏问题。
  • 减值节奏：2025 年已主动剥离部分亏损子公司（不再纳入合并），上年同期债务重组非经常性损失在 2026H1 未再发生——这是一次性的基数改善，不可年化。

  • → 结论：本股不存在把库存收益当真实盈利的风险；但须警惕把"2025 年剥离亏损子公司 + 债务重组损失消失"的一次性改善当作可持续增速。

  • 因子 4 · 政策/市场锚点（成本/收入驱动变量，市场层 + 政策层）

  • 市场层：服装批发大盘成交额、兰州商圈客流与文旅人次、商旅 RevPAR、线上渠道转化率。
  • 政策层：① 《提振消费专项行动方案》（→ 需求端托底）；② 商圈升级与零售创新的金融支持（→ 亚欧商厦改造可获资金）；③ "三新"试点与 86 亿元财政支持（→ 消费场景更新）；④ 以旧换新 2500 亿超长期特别国债（→ 线下客流）；⑤ 离境退税"即买即退"与免税探索（→ 入境消费）。
  • 情景：乐观=促消费政策显效 + 兰州文旅持续放量 → 酒店与商厦收入超预期（验证点：季度 RevPAR、甘肃旅游人次）；中性=消费温和复苏，专业市场收入零增长、酒店继续爬坡；悲观=百货与批发双双下滑、酒店 RevPAR 回落（验证点：专业市场租金单价与出租率）。
  • 验证点：季度专业市场营收增速（由负转正）、酒店板块毛利率（能否突破 25%）、线上销售占比。
  • 证伪信号：专业市场营收连续三期负增长且毛利率跌破 75%；酒店业务在开业第二年仍不达盈亏平衡；控股股东后续无新增资本运作。

四因子小结：公司是一家"转嫁系数高、毛利结构清晰、现金流前置、政策友好"的收租型资产运营商。它的核心矛盾不在成本端，而在收入端的天花板——专业市场与百货合计占收入 85% 却几乎零增长，全部增量押在占比仅 11% 的酒店与数字化上。

层 2 · 扩展业务：主业迁移空间（旧池塘 → 新池塘）
- 能力可迁移性：核心能力是"核心商圈商业物业的运营 + 招商 + 数字化"→ 可迁移到物管输出、园区商业运营、跨区域市场托管。能力同源度高，迁移成本低。
- 新 TAM 弹性：全国专业市场与商业物业运营市场规模远大于公司现有三城布局；但公司为区域型运营商，异地扩张需要资本开支与地方资源，TAM 弹性中等。
- 切入时点与卡位：国资入主后战略定位"美丽时尚消费产业平台 + 国潮文化传播平台"，仍处于战略早期；数字化平台尚在内部试点转推广阶段。
- 客户认证门槛：商业运营无强制认证，但地方政府与商户资源的获取门槛高（国资背景是加分项）。
- 信号验证：目前仅数字化提效可验证（自动化率 >80%、线上 +97%）；跨区域托管/资产注入/平台对外输出均无正式公告。
- 纪律：未过验证点的迁移部分一律按"中期期权"处理，不计入中性净利，只放乐观情景。

层 3 · 风险折扣：证伪信号
① 专业市场出租率或租金单价连续两期下滑；② 商贸百货线下收入降幅扩大至 5% 以上；③ 酒店开业第二年仍未实现板块盈利；④ 综合毛利率跌破 65%；⑤ 控股股东后续无新增资本运作、国资赋能停留在口号层面。命中任一条即下调对应增量。

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

校正 1 · 资产质量折扣（PB 1.58x，非破净，但仍须说明净资产质量）
- 本股 PB 1.58x，不属于破净，因此不存在"单凭 PB<1 推大空间"的问题；反过来要问的是——1.58x 的溢价是否有对应资产质量支撑。
- 净资产 21.33 亿的主体是杭州环北、南京环北、兰州亚欧商厦等核心商圈自有物业（按成本法计量的投资性房地产/固定资产）。这些物业位于凤起路、夫子庙、中山桥等不可复制的城市核心地段，账面价值大概率低于重置成本与市价——即存在隐性重估空间（这是与"破净但有隐含负债"的公司完全相反的方向）。
- 但有两点折扣：① 物业为经营性资产专用性强（专业市场楼面到商铺，转产困难），清算价值低于账面不可依赖；② 部分兰州物业为商住混合，去化与出租受区域经济制约。
- 结论：1.58x PB 有资产质量支撑，但禁止据此单独推导"空间大"；估值仍须以分部净利为主锚。

校正 2 · 周期位置校正
- 公司属弱周期消费型资产（收租 + 百货 + 酒店），非强周期股。
- 当前周期位置：消费处于温和复苏期（社零 +4% 左右，服务消费 +5.5%），百货业态处于结构性下行（限上百货 +0.1%），酒店处于爬坡期（新店开业第二年）。因此 2029E 中性净利用分部稳态口径，未使用单年好年景、近三年均值或拐点年化。
- 特别提示：2025 年归母 +126.02% 的增速含"剥离亏损子公司 + 债务重组损失不再发生"的一次性基数改善，绝不可作为趋势延续依据（2026H1 增速已回落至 +29.73%）。
- 证伪信号：若 2027–2028 年专业市场收入仍负增长且酒店板块仍亏损，则中性净利须下调至 2.0 亿以下。

校正 3 · 杠杆下行情景
- 资产负债率 30.88%（2025 年 38.20%，持续下降），有息负债 4.03 亿，经营现金流 1.02 亿/半年 → 杠杆风险极低，财务费用不构成主要风险源。
- 负面情景：即便专业市场收入下滑 10%、酒店 RevPAR 下滑 15%，公司仍可维持正现金流与正净利，不会出现"净利几倍跳负"的杠杆反噬。这是本股区别于高杠杆标的的核心优势。
- 纪律：因杠杆低、下行可控，悲观情景仅为 −23.0%（而非 −50% 以上），不构成"不得标大空间"的障碍；但受制于收入零增长，中性空间仍不足以支撑"重点关注"。

期权纪律：国资资产注入预期、数字化平台对外商业化、跨区域市场托管输出——三者均未过正式验证点（无公告、无签约），一律不计入 2029E 中性净利 2.6 亿，仅置于乐观情景（+86.5%）或单独列示。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵。现价 4.44 元对应 2026E PE 15.7x、PB 1.58x、TTM PE 18.01x；对于一家营收零增长、ROE 仅 4.81%（半年、未年化，2025 全年 8.15%）的区域商业运营商，15x 以上的估值已把"利润改善 + 酒店爬坡"定价到位。现价略高于基准合理区间上沿。

安全边际：
- 中性远期 5.47 元 → 空间 +23.2%，未达"重点关注"的 >50% 门槛；
- 悲观情景 3.42 元 → 下行 −23.0%，风险收益比约 1 : 1，基本对称、不占优势；
- 下行保护：PB 1.58x（有核心商圈物业支撑）、资产负债率仅 30.88%、经营现金流 1.02 亿且同比翻倍、中期分红已启动、控股股东刚完成 2% 增持（成本区间约 5.05 元/股，7692.86 万元 ÷ 1522.67 万股）。注意：控股股东增持均价约 5.05 元，现价 4.44 元低于大股东增持成本，这构成一定的"类安全垫"。

介入条件：
1. 价格：回落至 3.9 元以下（2026E PE < 13.8x、PB < 1.39x）才具备明确安全边际；现价可观察，不追高。
2. 加仓信号：① 季度专业市场营收增速由负转正（最关键——验证提租能力）；② 酒店板块毛利率突破 25% 或实现板块净利；③ 控股股东启动新一轮增持或公告资产整合；④ 综合毛利率维持 67% 以上。
3. 观察指标：专业市场出租率与租金单价、线上销售占比、会员消费占比、经营现金流/净利润比值（当前已达 98.96%）。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 收入零增长（首要）：专业市场（占收入 66.82%）营收 −1.97%、商贸百货 −3.02%，合计占收入 85% 的两块主业都在收缩，全部增量押在占比仅 11% 的酒店与数字化上——若酒店爬坡放缓，公司回到"零增长 + 估值下修"的双杀；
2. ROE 偏低：2025 年加权 ROE 仅 8.15%、2026H1 4.81%（半年），1.58x 的 PB 相对 8% 的 ROE 偏贵，缺乏"高质量"支撑；
3. 百货业态结构性逆风：限上百货零售额仅 +0.1%，亚欧商厦的国潮焕新属逆势挣扎，成效需持续验证；
4. 甘肃/兰州区域经济依赖：28.91% 收入来自兰州，受区域人口与消费力制约；
5. 国资赋能停留在预期层面：资产注入、平台输出目前无任何正式公告，属纯期权。

第五步进阶：上行想象力情景（四类，与下行校正对称）

类型 A · 行业调整剩者红利
- 建模：线下批发与百货业态正经历残酷出清（限上百货 +0.1%、传统批发市场被电商分流），但核心商圈的专业市场因地段稀缺性与商户粘性反而是受益方——2025H1 重点 44 家纺织服装专业市场成交额 +10.67%，验证"头部集中"逻辑。公司杭州环北（面向华东、辐射全国）与南京环北（夫子庙 5A 商圈）若在出清中承接周边市场溢出的商户与采购商资源，出租率与租金单价可同步提升。
- 量化：专业市场收入从 5.0 亿（中性）提升至 5.8 亿，毛利率维持 78% → 板块净利从 1.5 亿提升至 1.9 亿 → 归母 +0.4 亿 → 2029E 净利 3.0 亿，按 18x = 54 亿市值 → 7.10 元（+59.9%）。
- 验证点：专业市场出租率与租金单价环比、44 家重点市场成交额增速、采购商注册数。
- 证伪信号：出租率连续两期下滑、周边新建专业市场分流、租金单价下调。

类型 B · 政策反转期权
- 具体政策名：① 中办国办《提振消费专项行动方案》与城乡居民增收计划；② 商务部等三部门《关于加强商务和金融协同更大力度提振消费的通知》（首次提出扩大县域消费、升级农村消费）；③ 消费品以旧换新 2500 亿元超长期特别国债；④ 全国 [50] 个城市"三新"试点，首批 86 亿元财政支持资金已拨付；⑤ 离境退税"即买即退"与免税购物探索。
- 反转信号：① 兰州/杭州出台商圈升级专项资金细则；② 公司公告获得消费基础设施改造资金支持；③ 亚欧商厦纳入"三新"试点场景；④ 月度社零增速回升至 5% 以上。
- 重估弹性测算：若促消费政策使专业市场收入回到 5.5 亿 + 百货回到 1.5 亿，合计增收约 1.0 亿、净利弹性 +0.75 亿 → 2029E 净利 3.35 亿，按 17x = 57 亿 → 7.49 元（+68.7%）。
- 纪律：未过验证点（地方细则未出、无资金支持公告），仅作机会情景，不计入中性锚。

类型 C · 市场错杀修复
- 错杀证据：年初至今股价 −12.25%（跑输大盘），PB 1.58x 处于历史中枢附近偏低；控股股东增持均价约 5.05 元高于现价 4.44 元，大股东在更高价位真金白银增持 7692.86 万元；基本面未恶化（2026H1 扣非 +25.41%、现金流 +98.96%）。
- 修复触发点：① 市场风格回归红利/低估值资产型标的；② 公司提高分红率（当前中期分红仅 10 派 0.1 元、股息率约 2.2%，提升空间大）；③ 三季度报确认专业市场收入转正。
- 证伪信号：扣非净利同比转负（则"错杀"证伪，属基本面恶化）。

类型 D · 技术突破/技术代际跃迁期权（弱期权）
- 建模：公司将数字化转型深入运营全链条（丽潮购/丽达通/丽尚智管），整体自动化率超 80%，净利率从 10.89% 提升至 25.87%。若这三套平台从"内部工具"升级为对外的专业市场 SaaS / 供应链服务平台，则从"重资产收租商"跃迁为"轻资产平台服务商"，估值体系可重估。
- 三要素共振检查：① 政策驱动（数字化赋能流通 ✓）；② 行业趋势（专业市场数智化升级 ✓）；③ 公司落地（内部跑通 ✓，但对外商业化零客户、零收入）。
- 硬验证点：对外签约客户数与平台服务收入——当前缺失。
- 纪律：只作机会情景，不计入中性锚。证伪信号：平台长期仅服务自有市场、无外部客户。

什么条件出现才上调至"重点关注"：需同时满足——① 专业市场营收增速连续两个季度转正（提租能力被验证）；② 酒店板块实现板块净利或毛利率突破 25%；③ 控股股东启动新一轮资本运作/资产整合公告；④ 远期中性空间上修至 >50%（对应净利 ≥ 3.1 亿或 PE 上修至 19x）。四条中命中三条，方把结论由"纳入观察"上调为"重点关注"。

结论：纳入观察

理由：中性远期空间 +23.2%，不满足"重点关注"的 >50% 门槛；且悲观情景存在 −23.0% 下行，风险收益比接近 1:1，不构成显著的非对称赔率。
公司质感其实不差——高毛利（专业市场 77.96%）、低负债（30.88%）、现金流前置（预收租金）、利润质量高（扣非/归母 99%）、国资入主且顶格增持，且核心商圈自有物业存在隐性重估空间。真正的短板是收入零增长：85% 的收入来自两块停滞业务，全部增量押在 11% 的酒店与新业务上，而 15.7x 的 2026E PE 已把这部分改善定价完毕。
核心跟踪点：① 季度专业市场营收增速能否转正；② 酒店板块毛利率与盈亏；③ 控股股东后续资本运作。
