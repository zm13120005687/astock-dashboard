亏损股专项处理：经核实，2026H1 归母 −2496.44 万、2025 全年 −1560.87 万，为真实连续亏损（非 TTM 误标）。下述分析执行完整五步法 + 正常化净利润法 + 三问。

（3）产业链传导

上游（成本）：物业折旧（自有物业，折旧非现金）、人力成本（2026H1 管理费用人力 3819→5951 万，+56%）、营销费用（新六百 YOUNG 培育期）。议价权：对租户强（核心商圈稀缺），对人力/租金成本弱。

下游（需求）：上海本地消费，受宏观消费力+商圈客流影响；租赁业态需求刚性较强（品牌抢核心点位）。

→ 第二步进阶·原料成本→毛利结构（四因子）
- 因子1 成本传导弹性（转嫁系数）：租赁端对品牌租户转嫁系数高（0.7–0.9，核心点位稀缺）；商品销售端对供应商转嫁弱（0.2–0.3，被电商比价压制）。
- 因子2 毛利结构再平衡：商品销售毛利率低且下滑、租赁毛利率高（~60%+）且占比提升（40.5%），结构向高毛利迁移，中长期利好净利率，但短期被人力/营销费用淹没。
- 因子3 库存与采购节奏：零售库存风险低（自有物业+轻库存），无原料囤货问题；亏损主因是一次性职工安置（−2239 万）+ 培育期费用，属 timing 非持续。
- 因子4 政策/市场锚点：① 消费刺激→客流回升（利好，验证点：上海社零）；② 城市更新补贴→新六百HUB 减投入（利好）；③ 无关税/出口冲击。情景：消费回暖→租赁满租率升、租金涨；消费疲软→续亏（证伪信号：租赁收入转负）。

→ 第三步进阶·份额变量与主业迁移空间（三层法）
- 层1 现有业务：市场容量 × 份额变量
1. 供给侧：徐汇核心商圈自有物业稀缺，不可替代。
2. 需求侧：进上海核心消费客群，区位壁垒=粘性。
3. 技术代际：非技术驱动，靠运营效率。
4. 成本曲线：自有物业折旧固定，规模客流摊薄费用。
5. 份额加速度：传统百货份额流失（被电商），但租赁/体验份额稳。
→ 三档：保守（营收零增）→ 中性（租赁年增 10%）→ 乐观（HUB 开业引流+消费刺激，年增 15%）。验证点：逐季租赁收入、HUB 开业公告。
- 层2 扩展业务：主业迁移空间：从"商品销售"迁"商业运营/物业租赁"，能力同源（商圈运营+招商），新 TAM 为体验商业/首店经济；处转型验证期，未完全过验证点（新项目营收占比跳升公告），部分计入中性（租赁已占 40%）。
- 层3 证伪信号：租赁收入转负、HUB 开业延期/招商不及预期、消费持续疲软 → 下调。

第四步：估值锚定（自下而上，非增速外推）

亏损股方法：正常化净利润法（估稳态营收→保守正常化净利率→×远期 PE→目标市值→目标价）。同时因资产厚实，叠加资产净值（NAV）锚定。

总股本：约 4.16 亿股

正常化净利润推导（三步）

  1. 估稳态营收：租赁 H1 0.73 亿年化 1.45 亿（年增 16%）→ 2029 约 2.2 亿；商品销售企稳 ~1.5 亿；合计稳态营收 ~3.7 亿。
  2. 算正常化净利率：历史最好 2023 年净利 7523 万（营收约 4 亿，净利率 ~19%）；转型后租赁占比提升、费用正常化，取保守 12% → 正常化净利 ~0.45 亿（4500 万）。
  3. 正常化净利 × 远期 PE：零售/商业运营 20x → 盈利估值 9 亿 → 2.16 元/股。

资产锚（关键）

  • 净资产 21.44 亿（主要为徐汇核心商圈物业，按历史成本记账，市价远高于账面）；PB 1.41x → 现价对应 NAV 溢价 41%，已较充分反映资产价值。
  • 合理资产锚：PB 1.0–1.5x → 股价 5.16–7.74 元，当前 7.25 居中。

→ 第四步进阶·重资产/周期股估值校正
- 校正1 资产质量折扣：非破净（PB 1.41x）；净资产多为核心商圈物业（成本记账），真实清算/重估价值 ≥ 账面，属"真安全边际"型破净边缘，非伪空间。
- 校正2 周期位置校正：零售处消费弱周期底部，但公司亏损主因是主动转型阵痛非行业消亡；正常化净利已剔除一次性费用。
- 校正3 杠杆下行情景：无有息负债压力（总资产 26 亿/净资产 21.44 亿，负债率仅约 17.5%），经营现金流仍 +723 万，下行不转负、不破净，悲观仅 −28.8%。

第五步：综合赔率判断（买不买？）

当前价格位置：合理（资产锚定价）。现价 7.25 = PB 1.41x，处资产价值中枢，下行有 NAV 5.16 元托底。

安全边际：
- 中性远期 7.50 元 → 空间 +3.4%
- 悲观 5.16 元 → 下行 −28.8%（NAV 托底，不破净）
- 乐观 9.30 元 → +28.3%（HUB 成功+重估）
- 下行保护强：核心商圈物业+无有息负债+经营现金流转正。

介入条件：
1. 现价 7 元附近可小仓位布局（资产安全边际足）；回落至 6 元以下（PB~1.2x） 加仓。
2. 升级信号：① 2026H2 或 2027 单季扭亏（验证费用出清）；② 新六百 HUB 开业且招商满租；③ 租赁收入连续两季 >15% 增长。
3. 观察指标：逐季归母净利、租赁收入、经营现金流、HUB 工程进度。

最大风险：① 转型期延长、新项目培育不及预期；② 消费持续疲软致租赁空置；③ 国企效率偏低、费用控制不力；④ 电商/购物中心持续分流。

结论：纳入观察

逻辑：真亏损但"亏得起"——核心商圈物业净资产 21.44 亿（市价更高）、无有息负债、经营现金流转正，PB 1.41x 提供安全垫；亏损主因转型一次性费用（职工安置 −2239 万）+ 培育期投入，非主业崩塌。扭亏路径清晰（费用出清+新六百 HUB 开业+租赁占比提升）。中性空间 +3.4%、悲观仅 −28.8%（有 NAV 托底），风险不对称占优。等扭亏验证即可上调。

→ 亏损股三问（必答）
1. 为什么亏：主动业态转型阵痛——关闭低效门店优化人员（一次性职工安置 −2239 万）+ 新六百 YOUNG 培育期营销投入大 + 管理费用人力成本 3819→5951 万（+56%）；非主业持续恶化，毛利率仍 60% 维持。
2. 靠什么扭亏，触发时点：① 一次性费用出清（2026H2 起不再有大额安置费）；② 新六百 HUB（上海六百城市更新）2026H2–2027 开业带来新增销售/租金；③ 租赁业态占比持续提升（H1 +16.31%，高毛利）。触发时点：2026H2–2027 年扭亏为盈。
3. 亏得起吗：总资产 26.0 亿、净资产 21.44 亿（核心商圈物业）、经营现金流 +723 万、无有息负债，账上现金充裕，完全亏得起，不会倒在黎明前。

→ 第五步进阶·上行想象力情景（四类）
- A 行业调整剩者红利：线下体验/首店经济回归，核心商圈剩者定价权强化 → 验证点：租赁满租率/租金提升公告。
- B 政策反转期权：上海消费刺激/商圈提质/城市更新补贴加码 → 重估弹性 +15%；验证点：上海促消费发文、补贴落地。
- C 市场错杀修复：若因连续亏损被错杀至 6 元以下（PB<1.2x），资产底修复弹性大 → 验证点：市场企稳+扭亏预告。
- D 技术突破/代际跃迁期权：新六百 HUB 以"年轻化+体验商业"重构客流，或国企资产盘活注入 → 硬验证点：HUB 开业客流达标+营收占比跳升；未过验证点仅作机会情景，不计入中性。
