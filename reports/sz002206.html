（3）产业链传导

上游：PTA / MEG（聚酯原料）、钛白粉等。车用产品采用"原材料价格加成"定价（按季调价），传导率高（约 0.8–0.9）；2026H1 收到美国关税退回增加工业丝毛利。新能源车用丝毛利受原料传导保护。

下游：汽车（安全带 / 气囊 / 轮胎）、广告 / 建筑 / 光伏。下游新能源化 + 轻量化驱动高附加值丝需求；轮胎行业平台期致帘子布价格承压。

议价权：中强。车用丝 / 高模低缩丝差异化 + 严格客户认证（粘性）议价权强；普通工业丝 / 帘子布同质化议价权中等。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：车用产品"原材料加成 + 季度调价"，传导率 0.8–0.9（强），原料波动大部分转嫁；普通丝 / 帘子布传导率较低（约 0.5）。H1 工业丝毛利率提升即验证高传导。
  • 因子2 毛利结构再平衡：工业丝（高毛利、占比 53%且提升）vs 帘子布（承压）vs 塑胶（稳）。越南产能占比提升 + 高附加值产品占比提高 → 结构优化推升综合毛利率 +4.4pct。分业务线敏感性：帘子布价格每降 5% 拖累净利约 0.15 亿；工业丝每升 5% 增厚约 0.25 亿。
  • 因子3 库存与采购节奏：原料低位囤货收益有限（加成定价下库存收益弱）；越南基地降低关税 / 物流成本属结构性降本，非库存波动。
  • 因子4 政策 / 市场锚点：① 市场层——PTA/MEG 价格、钛白粉；② 政策层——美欧关税（越南规避）、再生材料补贴、光伏政策（反射膜）。情景：若关税退回应延续 + 越南满产，毛利结构稳；验证点：工业丝报价、越南投产公告、关税政策。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：工业丝产能行业调整期，公司差异化领先；
  • 需求侧：绑定全球轮胎 / 车企头部（认证周期长 = 粘性），份额稳；
  • 技术代际：车用丝国际先进，差异化溢价；
  • 成本曲线：越南基地左移（关税 + 人工 + 物流）；
  • 份额加速度：越南放量 + 高端认证（倍耐力）加速。
    三档：保守（营收年增 3%）/ 中性（5–8%）/ 乐观（新材料放量 10%+）。验证点：越南出货量、LCP 订单。
  • 层2 扩展业务：主业迁移空间（新材料范式）：LCP / PPS / 光伏反射膜由"丝"向"高端材料"迁移，能力可迁移（纺丝同源）；但 LCP 仅吨级、PPS 百公斤级、反射膜验证中，未过规模化验证点，仅作中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：帘子布价格战致毛利率破阈、越南投产延期、新材料无批量订单。命中则下调。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非重资产（轻资产制造 + 高 ROE），PB 1.56x 合理，无破净；越南资产为真产能投入，非虚高。
  • 校正2 周期位置校正：化纤处结构优化期（非极端周期），中性净利已用结构法（非单年好 / 坏年景），标注：行业中性偏上行（新能源 + 绿色）。
  • 校正3 杠杆下行情景：资产负债率稳健（2026H1 总资产 75.4 亿、净资产 40.2 亿）；若利率上行 + 需求下行，悲观情景空间 −5.8%，未转负，不降级。

第五步：综合赔率判断（买不买？）

当前价格位置：低估。现价 4.84 元对应 2026E PE 9.4x、PB 1.56x，处历史下沿，市场未充分定价越南产能释放。

安全边际：中性远期 8.39 元 → 空间 +73.3%（> 50% 重点关注门槛）；悲观 4.56 元 → 仅 −5.8%，下行极薄；乐观 12.05 元 → +149%。

介入条件：现价即可配置；4.5 元以下（2026E PE < 9x）加仓。加仓信号：① 越南 1.8 万吨帘子布投产公告；② 工业丝 / 帘子布毛利率连续两季提升；③ LCP / 反射膜批量订单。

最大风险：① 帘子布行业价格战超预期；② 越南基地投产延期或爬坡不顺；③ 汇兑损失（2026H1 拖累扣非）；④ 新材料放量不及预期（仅乐观情景计入）。

结论：重点关注（远期中性空间 +73.3% > 50% 且逻辑明确：越南具体项目 + 高附加值结构优化 + 新材料期权）。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：工业丝产能出清，公司差异化份额提升；验证点：低效产能退出 + 公司份额跳升。
  • B 政策反转期权：美欧关税进一步退让 + 新能源补贴延续，越南产能溢价放大；验证点：关税政策 + 越南出货；重估见乐观 +149%。
  • C 市场错杀修复：若因汇兑 / 季度波动被杀至 4.5 元以下，修复弹性大；验证点：估值分位 + 业绩证伪。
  • D 技术突破 / 代际跃迁期权：LCP 纤维、PPS 氢能隔膜、光伏反射膜从 0 到 1 规模化——硬验证点 = 中试良率达标 + 客户定点 + 量产成本优（LCP 吨级 / PPS 百公斤级已起步，反射膜 >5GW 验证中，部分接近验证）→ 若批量落地可计入乐观增量。

维持 / 上调重点关注：越南帘子布投产 + 新材料任一项批量订单落地，中性上修至 8.5 亿以上。
