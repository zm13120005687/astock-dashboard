（3）产业链传导

上游（成本端）：房地产开发的核心成本为土地款（历史存量项目已支付）与建安成本。当前公司不存在新增高价拿地的成本压力，成本端的核心矛盾是"已投入土地款的资金沉淀成本"——多年去化缓慢导致存货占用资金、抬高财务费用（H1 财务费用 1.20 亿元）。建安成本近期平稳，对毛利影响中性偏弱。

下游（收入端）：需求端受政策显著改善（沪八条、沪七条、二手房成交 +20%），但公司项目的签约金额仅 2.06 亿元、结转收入仅 1.03 亿元，说明行业β改善尚未传导到公司自身的项目去化上——这是"政策好、公司差"的典型错位。物业与租赁端需求刚性，是唯一稳定的下游。

议价权判断：弱。① 住宅销售端：买方市场，价格由周边竞品与二手房价格决定，公司项目在青浦/苏州非核心区位，无定价权；② 物业服务端：中等——3,317 万平方米在管规模带来议价基础，非住宅占比超 60% 说明客户粘性较高（医疗大健康等专业场景），但物业费提价受政府指导与业主大会约束；③ 租赁端：出租率 77.81% 低于理想水平（>90%），说明上海地区租赁也面临议价压力。

第二步进阶：原料成本 → 毛利结构传导（四因子）

适配说明：房地产公司无传统"原料"概念，本因子按 RULES 精神以"土地/建安成本 → 结转毛利结构"等效替换，四因子框架不变。

因子 1 · 成本传导弹性（pass-through）
房地产开发的成本转嫁系数 = 0.0–0.3（极低）。原因：售价由市场决定，而非由成本加成决定；在买方市场下，成本上涨无法转嫁，成本下降（如建安费回落）也不会带来毛利改善，反而会被售价下行吞噬。依据：2026H1 销售毛利率仅 12.35%，而 2025 年同期为 29.64%，同比暴跌 17.29 个百分点——这是售价下行（非成本上行）主导的结果，是"转嫁系数≈0"的直接证据。
→ 验证点：季报销售毛利率与签约均价；证伪信号：毛利率连续两个季度跌破 10% 则结转项目已无利可图。

因子 2 · 毛利结构再平衡（分业务线毛利率 + 成本敏感权重）

业务线 收入占比 毛利率（估） 土地成本敏感权重 说明
物业管理服务 62.46% 18–22% 0（轻资产） 人力成本为主，无土地成本；现金流最稳
房地产租赁 17.06% 70–80% 0（存量物业折旧） 高毛利但体量小、出租率仅 77.81%
房地产销售 10.11% ≈0 或为负 极高（1.0） 高成本存量地块，售价下行即亏损
酒店经营 9.90% 25–35% 0 稳定
综合 100% 12.35% — 被地产销售拖累

关键结构迁移：公司收入结构已由"地产销售为主"变为"物业服务为主（62.46%）"，但利润结构尚未同步——物业与租赁贡献了稳定毛利，而地产销售以 10.11% 的收入占比拖累整体毛利率至 12.35%。这正是公司当前亏损的结构性根源：轻资产板块的利润无法覆盖重资产板块（地产存货）的资金成本与减值压力。 单一"综合毛利率 12.35%"完全掩盖了"物业 20% + 租赁 75% + 地产销售 ≈0%"的结构断裂。
→ 估值必须分部给：物业板块可给 PE 15–20x，地产存货只能给折扣后 NAV。

因子 3 · 库存与采购节奏（timing）
- 高价存货（历史高价地与建安成本）：公司地产存货多为早年获取项目，账面成本锁定，在售价下行的市场环境中形成"高价接货"式毛利承压；
- 去化节奏：2026H1 签约仅 2.06 亿元，去化速度远低于资金成本累积速度，形成"存货持有成本 > 结转收益"的负向循环；
- 资产处置 timing：报告期内确认了部分非经常性损益（资产处置收益与政府补助），对净利润形成一次性补充——但扣非净利仍为 −2.72 亿元，说明主业盈利未实质扭转；
- 不得把处置收益当真实盈利：2026H1 归母 −2.58 亿元 vs 扣非 −2.72 亿元，差额 0.14 亿元即非经常性损益，占比小但方向明确——须剔除。
→ 验证点：季报"存货"科目余额与跌价准备计提；证伪信号：存货跌价准备大幅计提 → 净资产进一步缩水。

层 3 · 风险折扣：证伪信号
1. 地产签约金额连续两个半年度低于 3 亿元 → 结转持续空窗，扭亏时点后移；
2. 存货跌价准备大额计提 → 归母净资产（101.9 亿元）缩水，破净的"资产底"被击穿；

- 修复触发点：市场风格回归国资低估值板块、公司出现单季度扭亏、上海楼市外环外数据持续改善
- 证伪信号：亏损同比转为扩大、存货大额减值 → 错杀逻辑证伪（基本面实际恶化）
- 部分计入估值（体现为中性情景的 +13.3%），但不足以支撑"重点关注"。

类型 D · 技术突破 / 技术代际跃迁期权
地产开发与物业服务无技术路线跃迁的可能，本类不适用。唯一沾边的方向是"好房子"新规（安全舒适绿色智慧）带来的产品代差——公司若能借新规打造新一代产品，可形成对次新房的竞争优势。但这不是"从 0 到 1 的技术突破"，而是产品标准升级，不构成类型 D。
- 证伪信号：公司无新规产品落地、存量项目继续因产品代差滞销

什么条件出现才上调至“重点关注”：
需同时满足——① 股价回落至 3.10 元以下（折扣后 NAV 的 0.78x）；② 半年度签约金额回升至 5 亿元以上并出现集中结转；③ 2027 年实现单年度扭亏且扣非转正；④ 物业在管面积年增 ≥10%、租赁出租率回升至 85% 以上。四条缺一则维持当前结论。

结论：纳入观察

判断依据：中性远期空间 +13.3%（>0，满足"纳入观察"条件），但远低于"重点关注"的 +50% 门槛；同时悲观情景下行 −33.3%，风险收益偏负。
公司的核心事实是：亏损真实、但性质可救——2026H1 归母 −2.58 亿元系地产结转空窗 + 费用刚性所致，同比已大幅收窄 65.86%，经营现金流净流出同步改善，资产负债率 59.23% 远优于同业，国资背景确保流动性无虞，符合"亏损 + 有扭亏路径"的观察标准，不构成"坚决回避"。
但估值层面：PB 0.71x 的"便宜"是账面幻觉——按资产质量折扣后 NAV ≈ 3.96 元，与现价 3.90 元几乎一致，市场已完整定价了资产折价。真正的安全边际（3.10 元以下）尚未出现。
核心跟踪点：① 公司半年度签约金额（能否从 2.06 亿元回升）；② 上海青浦海源别墅的入市去化；③ 地产存货跌价准备计提；④ 物业在管面积与租赁出租率。
