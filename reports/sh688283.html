（3）产业链传导

上游：高端芯片（ADC/DAC/FPGA）、微波器件、结构件，部分依赖进口（美系），议价权中等偏弱（受供应链与汇率影响）。

下游：卫星/通信设备商、运营商、军工院所，需求受星座组网节奏驱动，议价权强（刚需+国产稀缺）。

议价权判断：对上游中等偏弱，对下游强（产品稀缺、国产替代刚需），毛利率 64% 印证。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数）：高端芯片/微波件占成本 35–45%，进口为主，转嫁系数约 0.5–0.6（部分自担）；但下游刚需下成品端可维持高毛利。
  • 因子2 毛利结构再平衡：信道仿真仪（毛利 ~65%）> 信号发生器/频谱仪（~60%）> HBI 组件（~55%）。卫星相关高毛利占比升，结构优化；禁以单一综合毛利掩盖品类迁移。
  • 因子3 库存与采购节奏：按订单生产，长协覆盖部分进口芯片，timing 影响小；汇率/出口管制是主要变量。
  • 因子4 政策/市场锚点：① 风险——美系芯片出口管制（验证点：禁运清单）；② 正向——国产替代补贴+星座组网加速（验证点：星网招标量、卫星发射节奏）。

输出喂第四步：中性给综合毛利 62–65%，悲观（管制）降至 55–58%。

结论：短期增量=商业航天测试订单放量（高确定性）；中期=手机直连卫星综测仪 + 收购微宇天导（期权）。无大规模在建产能瓶颈（轻资产研发型）。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：信道仿真仪国内市占 ~50%（第一），产能随研发平台化扩张。
  • 需求侧：绑定星网/航天/华为，客户粘性高。
  • 技术代际：67GHz/4GHz 带宽对标国际巨头，领先半代。
  • 成本曲线：平台化研发摊薄，国产成本低。
  • 份额二阶导数：国产化率 10%→提升，份额加速。
    → 三档：保守（份额守 45%，营收 +20%）；中性（国产替代+25%）；乐观（卫星+6G 双爆发 +40%）。验证点：星网招标中标额、季度营收。
  • 层2 扩展业务：主业迁移空间：从"卫星测试"迁移至"6G/NTN 终端综测+低空+导航"（新 TAM 数倍），能力可迁移（高，同源射频），新场景早期（先发红利），客户认证门槛高（已获星网/华为验证=信号强）。收购微宇天导过会前部分计入中性需谨慎，仅核心卫星测试计入。
  • 层3 证伪信号：星网招标丢失份额、研发占比持续 >40% 致扣非不转正、收购失败、美系管制升级。命中则下修。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（已透支远期）。现价 30.85 ≈ 2029 中性 32.80，市场提前定价卫星/6G 放量。

安全边际：
- 中性远期 32.80 元 → +6.3%（基本合理，无显著安全边际）
- 悲观 5.90 元 → −80.9%；乐观 59.10 元 → +91.6%（卫星+6G 兑现）
- 资产底：PB 3.89x、净资产约 9.66 亿，提供下行缓冲但非便宜

介入条件：
1. 不追高；回落至 26 元以下（2029E PE < 32x）才具观察价值
2. 上调至重点关注信号：① 卫星大额订单落地（单笔 >3000 万）；② 收购微宇天导过会；③ 扣非净利趋势性转正（研发占比回落至 <30%）

最大风险：① 卫星组网节奏不及预期；② 美系芯片管制升级；③ 收购失败/审核风险；④ 高研发致扣非长期薄利、估值消化靠预期。

结论：纳入观察（优质赛道国产龙头、刚需+国产替代，但现价已透支 2029、扣非薄利靠补助、收购审核中；等卫星大额订单+收购过会+扣非转正上调）

上行想象力（第五步进阶四类，仅进乐观/机会栏）：
- A 行业调整剩者红利：高端仪器进口替代（国产化率 10%），剩者（公司）份额跳升。
- B 政策反转期权：商业航天/6G 政策加码（星网发射加速、NTN 标准），估值重估。
- C 市场错杀修复：若卫星订单不及预期致回调，刚需属性修复弹性大。
- D 技术/代际跃迁期权：手机直连卫星综测仪从 0 到 1（单套 1000 万+），硬验证点=大客户订单+量产交付，未达仅作机会情景。
上调重点关注条件：卫星大额订单落地 + 收购微宇天导过会 + 扣非净利趋势转正三者验证。
