（3）产业链传导 + 第二步进阶：原料成本 → 毛利结构四因子

因子1 成本传导弹性（转嫁系数）：电力能源板块原材料为铜（电缆附件/母排）、硅钢、工程塑料、电子元器件；电网集招模式 + 技术门槛品类（辐射材料、继保）有定价权 → 转嫁系数约 0.6–0.7；智能装备（测试设备）为定制化项目制，成本加成报价 → 转嫁系数约 0.8。佐证：2026H1 铜价高位运行下毛利率仍 +1.30pct。

因子2 毛利结构再平衡：分板块看——电力能源毛利率历史约 32–35%（电网类稳定），智能装备约 35–38%（2026H1 增量为高毛利智能眼镜/医疗/半导体，板块毛利率向上迁移）；磷酸铁锂（毛利率 −9.10%）剥离后整体结构改善约 0.5–1pct。敏感权重：铜价每涨 10% → 电力能源板块毛利率约拖累 1.5pct → 综合约 1pct；智能装备占比每升 5pct → 综合毛利率约升 0.3pct。

因子3 库存与采购节奏：电网项目按招标节奏交付、材料按单采购为主；智能装备项目制需备料，2026H1 经营现金流 1.14 亿（上年同期 −2.26 亿）改善，盈利含金量修复中。验证点：经营现金流与扣非净利匹配度。

因子4 政策/市场锚点：①国网/南网投资节奏（2026H1 均双位数增长）为电力能源板块收入的第一驱动变量；②特高压招标放量主要利好一次设备龙头，公司弹性在配网与二次智能化；③铜价——全球库存周期 + 美元利率主导（市场层），收储/出口管制为潜在政策变量（情景假设）；验证点：季度电网招标中标公告、铜价走势；证伪信号：电网投资增速回落至个位数、毛利率跌破 30%。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务：市场容量 × 份额变量
- 市场容量："十五五"国网 4 万亿投资 + 2026H1 两大电网合计投资近 4000 亿 → 电网设备总盘子确定性扩张。
- 份额锚点：公司电力能源板块收入 25.32 亿在电网设备市场中份额很小，弹性来自细分品类（辐射功能材料为全球龙头、电网自动化细分供应商）；二次设备行业产量 +15.7% 是份额扩张的行业温床。
- 技术代际：辐射交联材料技术壁垒高、客户认证周期长（粘性强）。
- 份额三档：保守（跟随行业 8–10% 增长）/ 中性（智能化品类超行业，+12–15%）/ 乐观（微电网/虚拟电厂新场景突破）。验证点：国网/南网中标公告金额、电力能源板块季度收入增速；证伪信号：板块收入增速转负。

层2 主业迁移空间（电网设备 → 消费电子/医疗/半导体智能装备）
- 能力可迁移性：精密测试与自动化技术同源，迁移成本低。
- 新 TAM：智能眼镜（AI 硬件）、CGM（医疗）、均热板（AI 数据中心散热）均为高增速新池塘；智能眼镜已量产盈利、CGM 破冰、半导体在手订单 0.8 亿——三个细分均已出现"营收跳升"信号，部分过验证点，但绝对体量尚小（合计约 4 亿/H1）。
- 切入卡位：跟随大客户量产节点，属早中期。
- 纪律：智能装备已验证部分计入中性，未验证的管线扩张（新客户、新品类）只进乐观情景。证伪信号：智能眼镜客户砍单、CGM 破冰后无复购、半导体订单不增长。

层3 风险折扣（证伪信号）：①治理风险复发（历史关联交易/违规问题）；②商誉减值再起（账面商誉 5.19 亿，占归母净资产 28.33 亿的 18.3%）；③负债率 75.89% 下流动性压力；④电力能源板块毛利率破 30%。

第四步：估值锚定（自下而上，非增速外推）

方法说明：按电力能源/智能装备两线，以国网投资节奏、在手订单、客户量产节点逐线推算；减值出清进度作为单独变量。

总股本：约 13.19 亿股（2026H1 末归母净资产 28.33 亿，每股净资产约 2.15 元）

⚠️ PE(TTM) −8.69 的成因说明（非亏损股，仅口径问题）

TTM 归母净利 = 2025 全年（−11.40 亿）− 2025H1（−3.42 亿）+ 2026H1（+0.37 亿）≈ −7.61 亿，对应当前市值 66.20 亿即 PE(TTM) ≈ −8.69x。负值完全由 2025 年报计提的大额资产减值与历史亏损（商誉、应收、存货、磷酸铁锂业务）造成，该部分损失为一次性出清性质；2026H1 已实现归母 +0.37 亿、扣非 +0.85 亿（+216.35%），经营面已回到盈利状态。因此本报告以 2026H1/2026E 经营性利润为估值锚，TTM 口径不构成估值参考。

基准（2026E，自下而上）

  • 扣非：H1 已实现 0.85 亿；H2 智能装备旺季 + 电力能源交付集中（电网四季度结算）→ H2 扣非 1.1–1.3 亿 → 2026E 扣非约 2.0 亿
  • 归母：H1 已 0.37 亿 + H2 1.0–1.2 亿（减值损失大幅收敛后归母与扣非缺口缩窄）→ 2026E 归母约 1.5 亿
  • 合理估值：治理修复期、盈利刚回正，按扣非 2.0 亿给 28–32x（修复期高倍数、低基数）→ 市值 56–64 亿 → 4.2–4.9 元，取 4.6 元

第四步进阶·三道校正（本股重点）：
1. 资产质量折扣：PB 2.34x 不破净，但归母净资产 28.33 亿中含商誉 5.19 亿（占 18.3%），2024–2025 两年合计计提减值超 21 亿的历史说明账面资产质量曾系统性虚高；若 2026–2027 再计提 1–2 亿商誉减值，中性净利直接受损。验证点：季报减值损失科目；证伪信号：单年减值再超 3 亿。
2. 周期位置校正：电网投资处"十五五"开局上行期（非周期顶部），电力能源收入假设合理；智能装备处客户产品周期（智能眼镜）早段，放量与砍单风险并存，中性按已验证节奏计。
3. 杠杆下行情景（必须执行）：资产负债率 75.89%，显著高于 60% 警戒线。若利率上行或回款恶化，财务费用 + 减值双重挤压可使净利几倍级跳负——悲观情景（−60.8%）即为该情形定价。因此本股不得标"大空间/重点关注"，至多"纳入观察"且须注明高贝塔属性。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵。现价 5.02 元高于基准 4.6 元与中性远期 4.61 元；摘帽行情已兑现大半。

安全边际：
- 中性远期 4.61 元 → 空间 −8.2%（负值）
- 悲观 1.97 元（−60.8%）；乐观 8.34 元（+66.1%）
- 下行保护薄弱：负债率 75.89%、商誉 5.19 亿、经营现金流仅 1.14 亿；PB 2.34x 无破净缓冲

上行想象力情景（四类，均只进乐观/机会栏）：
- A 行业调整剩者红利：电网设备一次/传统品类出清（行业一次设备产量 −4.5%），二次智能化 + 头部集中后剩者定价权提升；公司同步出清自身亏损业务（金锂科技剥离）。验证点：行业 CR 提升 + 公司电力能源毛利率站上 35%；证伪信号：低价中标常态化。
- B 政策反转期权：微电网/虚拟电厂入市政策（国办 2026-02-11 文件）落地超预期 → 公司能源互联网服务重估；弹性：若该业务收入 3 年做到 8 亿 × 净利率 12% = 1 亿增量净利。未过验证点，不计入中性。
- C 市场错杀修复：摘帽 + 扣非 +216% 后，若市场风格转向"困境反转 + 低 PB 电网设备"，PB 从 2.34x 向行业均值回归即有修复空间；但当前并非错杀（PB 已高于行业），此情景仅在股价回落至 4 元下方（PB 1.86x）时成立。触发点：估值分位回落。
- D 技术突破/新品类期权：CGM（连续血糖监测）、半导体测试设备均为 0→1 新品类。硬验证点：CGM 获批量订单 + 半导体设备进入头部客户产线 + 收入占比跳升至 10%+；当前均未满足，只作机会情景。证伪信号：新品类收入停滞。
- 上调至"重点关注"的条件：①2026 年报归母 ≥2.5 亿且经营现金流 ≥2 亿；②负债率降至 70% 以下；③商誉减值清零——三者同时满足才重估。

介入条件：

3. 观察指标：单季减值损失、经营现金流/扣非净利比值、电力能源板块增速

最大风险（最可能破坏逻辑的因素）：
1. 高杠杆 + 商誉（首要）：75.89% 负债率下任何一次超预期减值都可能让报表再度恶化，估值立即坍塌
2. 治理修复反复：历史上的治理问题若复发，摘帽逻辑全面逆转
3. 智能装备客户集中：智能眼镜单一客户驱动的 3.05 亿增量，砍单即证伪
4. 电网投资节奏：若"十五五"执行前紧后松，电力能源板块增速中枢下移

结论：纳入观察
