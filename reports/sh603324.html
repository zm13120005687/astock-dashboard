第一步：公司是干什么的？

一句话定位：半导体厂务系统服务商——从"螺旋风管 + 工艺排气管道"起家，逐步切入半导体工艺废气治理（Central Scrubber → Local Scrubber），现向洁净室内部延伸做真空泵、温控设备、分子泵、低温泵、电子化学品材料，为晶圆厂/面板厂提供"绿色厂务"整体解决方案。

（3）产业链传导

上游——不锈钢/特种钢材（风管）、风机、泵阀、化学品原料、电子元器件：
- 公司采购内容为"材料、设备及配件 + 劳务服务"，绿色厂务系统大量使用不锈钢特种风管（成本敏感度高）。
- 应对：公司称"加强精细化成本管理及提高部分关键物料的自产化率，有效降低经营成本"。

下游——晶圆厂/面板厂资本开支（分化）、EPC 工程承包商：
- 2026H1 中报原文："半导体产业蓬勃发展，也面临着下游产线投资分化、行业竞争日趋激烈的局面"。
- 关键判断：下游不是没钱，而是投资分化 + 竞争加剧导致报价被压。这是"价格战"而非"需求消失"。

议价权判断：弱（当下）/ 中等（长期，取决于零部件国产替代）。
- 佐证：毛利率从 26–29% 崩至 10.60%；中报明确"差异化报价策略"——即主动降价换中标。
- 长期改善路径：从"特种风管（低壁垒）"向"L/S、真空泵、Chiller、分子泵、低温泵（高壁垒）"迁移，零部件国产替代 + 海外供给缺口 是议价权修复的关键。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）：把议价权量化成转嫁系数。
- 绿色厂务系统（招投标/竞争性谈判定价）：转嫁率 ≈ 0.1–0.2。合同多为固定总价 + 长周期（12–24 个月），原料涨价几乎无法转嫁，且行业竞争下"差异化报价"= 主动让利。上游涨 10% → 公司毛利承压 8–9%。
- 设备及关键零部件（竞争谈判 + 部分客户验证导入期）：转嫁率 ≈ 0.3–0.4。验证导入期为拿定点常主动压价，转嫁能力弱。
- 电子化学品材料（直销终端）：转嫁率 ≈ 0.5–0.6。化学品有配方溢价，转嫁能力相对最强。
- 加权传导率 ≈ 0.20（按 68.99%/25.04%/5.55% 权重）。含义：上游成本每上涨 10%，公司毛利实际承压 8%——这是极弱的议价权，也解释了为什么毛利率会从 26% 崩到 10.6%。

→ 结论：综合毛利率 10.60% 掩盖了"厂务系统近亏损 + 零部件/化学品尚有正毛利"的结构差异。
→ 关键推论：若 2029 年产品结构从"厂务 69% / 零部件 25% / 化学品 5.5%"迁移到"厂务 55% / 零部件 32% / 化学品 13%"，即使各线毛利率仅修复至历史中位（厂务 18%、零部件 28%、化学品 25%），综合毛利率可达 21.6%，比当前 10.6% 翻倍——这是本股扭亏的唯一结构性路径，也是第四步毛利率假设的核心依据。

因子3 库存与采购节奏（timing）
- 存货周转率 0.39 次（2026H1）、应收账款周转率 0.43 次 —— 周转极慢，属"项目制 + 长验收周期"特征。
- 采购模式：绿色厂务多为非标定制、以销定产，但公司"会根据未来市场预期、原材料价格波动、生产计划排期等因素，进行适量的备货"。
- 高价接货风险：2024–2025 年在行业景气高点签订的低价长周期合同，在 2026 年执行时遭遇成本刚性 → 这是毛利率崩塌的重要原因之一（合同错配），而非纯粹的竞争降价。
- 验证点：季度毛利率 + 存货周转率 + 新签订单毛利率披露；证伪信号：新签订单执行后毛利率仍不修复，说明是结构性竞争而非合同错配。

因子4 政策/市场锚点（原料成本驱动变量）
- 市场层：不锈钢/特种钢材价格、铜价、泵阀与风机采购价、半导体级化学品原料价格。
- 政策层：① 关税（进口泵阀/真空设备加税抬成本）；② 出口管制（海外零部件断供或涨价，同时是国产替代的催化剂）；③ 环保/能耗双控（抬升不锈钢等高耗能材料成本，但也抬升废气治理的合规需求）；④ 国产替代补贴/首台套政策（降低公司验证导入成本）。
- 情景 + 验证点：
- 基准：钢价平稳、国产零部件替代稳步推进 → 2027 年毛利率修复至 18–20%。验证点：季度毛利率环比上行。
- 上行：关键物料自产化率提升（公司已明确该举措）+ 海外订单占比提升（毛利率更高）→ 2027 年毛利率 22–25%。验证点：自产化率披露、海外收入占比突破 5%。
- 下行：钢价涨 15% + 价格战延续 → 毛利率持续低于 12%，亏损延续至 2028 年。证伪信号：2027 年中报毛利率仍低于 15%。

层2 主业迁移空间（"特种风管 → 洁净室内部核心装备"）
- 能力可迁移性：高。公司已在工艺排气管道技术领域深耕 20 年，L/S（POU 废气处理设备）是 Central Scrubber 技术的自然延伸；真空、温控同属洁净室环境支持系统，技术同源性较强。
- 新 TAM 弹性：极大。真空泵、Chiller、分子泵、低温泵的市场规模远大于特种风管，且海外真空设备出现供给缺口，为国产厂商打开替代窗口。
- 切入卡位：较早且窗口真实。海外厂商"主观无增产意愿、客观无扩产能力"，国产替代窗口已经打开；公司 L/S/真空泵/Chiller 已在多家客户验证。
- 客户认证门槛：高（双刃剑）。半导体设备认证周期长（1–2 年），一旦通过即形成强黏性（护城河），但也意味着短期无法放量。
- 信号验证：① L/S、真空泵、Chiller 取得批量订单公告；② 零部件收入占比从 25.04% 提升至 35%+；③ 海外收入占比突破 5%。目前仅"部分完成测试或开始批量交付"，无金额披露 → 迁移增值只作中期期权，不计入中性情景。

层3 风险折扣：证伪信号
- 毛利率持续低于 15%（说明是结构性竞争而非合同错配）；
- L/S、真空泵、Chiller 一年内无批量订单公告；
- 零部件收入占比未提升（若 2027 年仍停留在 25% 左右，则"结构升级"逻辑证伪）；
- 2026 年营收未达激励触发值 12.96 亿（则 2027–2028 目标更难达成，激励作废）；

第四步：估值锚定（自下而上，非增速外推）

方法说明：亏损股不适用 PE 外推，改用正常化净利润法三步推导：① 估稳态营收 → ② 算正常化净利率（行业正常 / 公司历史最好 / 爬坡后理论值，三者取保守）→ ③ 正常化净利 × 远期合理 PE = 目标市值 → 目标价。

① 为什么亏？ 四重叠加：

- (c) 费用刚性上升：期间费用率 30.9%（+13.03pct），销售 +50.73%、研发 +43.65%、管理 +17.5%；叠加股份支付摊销 8717 万（2026 年约 2833 万）；

② 靠什么扭亏？触发时点在哪一年？
- 收入端（已启动）：Q2 营收 3.33 亿，同比 +30.56%、环比 +180.85%——订单在执行，收入拐点已现。H2 若维持该节奏，全年营收 11.1–11.5 亿。
- 毛利率端（关键，未启动）：三条修复路径——① 产能爬坡（新产能利用率提升摊薄折旧）；② 关键物料自产化率提升（公司明确举措）；③ 产品结构升级（L/S、真空泵、Chiller、电子化学品占比提升，这些线毛利率 12–25%，高于厂务系统的 6–9%）。
- 硬约束：股权激励 2027 年营收触发值 16.07 亿 / 目标值 19.44 亿。若达成，规模效应将显著改善毛利。
- 触发时点：2027 年。2026 年确定亏损（E −1.10 亿）；2027 年若营收达 16–19 亿、毛利率修复至 18–22%，则可实现归母 0.4–1.2 亿。中性判断扭亏时点为 2027 年下半年至 2028 年。

③ 亏得起吗？

- 现金流：经营现金流 2026H1 −1.44 亿（同比改善 6222 万）、2025 全年 −1.03 亿；筹资现金流 H1 +1.61 亿（同比 +9907 万）——靠融资输血；

- 结论：亏得起（短期无生存危机），但"靠融资续命"的特征明显。若 2027 年仍不能扭亏，市场信心与融资能力将同步恶化 —— 倒在黎明前的风险中等偏低，但真实存在。

- 修复触发点：2026 年报营收接近触发值 12.96 亿；单季毛利率环比回升；L/S/真空泵批量订单公告。
- 证伪信号（错杀证伪 = 基本面恶化）：Q3 营收环比大幅回落；毛利率继续下行；激励目标确定无法达成。

类型D 技术突破 / 技术代际跃迁期权（本股最具想象力的一类）
- 逻辑：公司若完成从"特种风管（低壁垒、低毛利）"到"真空泵 + Chiller + L/S + 分子泵 + 低温泵（高壁垒、高毛利）"的技术跃迁，将从"厂务工程商"变为"半导体核心装备商"，估值体系可从环保设备（15–25x）切换至半导体设备零部件（30–45x）。海外真空设备供给缺口为此打开了真实窗口。
- 三要素共振检验：
- ① 政策驱动技术路线：国产替代强制要求 + 首台套政策 ✓
- ② 行业趋势向该技术收敛：海外真空设备供给缺口已出现，国产替代窗口打开 ✓
- ③ 公司技术投产落地：部分达标——L/S、多级爪式/罗茨真空泵、Chiller 已在多家国内外客户验证测试，部分已完成测试或开始批量交付；分子泵/低温泵仍在样机试制
- 硬验证点（三者缺一则只作机会情景，不计入中性锚）：
- ① 中试/客户验证跑通且良率达标 → 需"验证通过并进入批量交付"的正式公告（目前仅"部分开始批量交付"，无金额）
- ② 客户定点 / 大额订单 → 需披露具体金额的批量订单公告（目前缺失）
- ③ 量产成本优于旧路线 → 需零部件业务毛利率显著高于厂务系统（目前未披露分项毛利率）
- 证伪信号：验证失败或长期不通过；客户流失；成本打不过海外旧路线；国产替代政策退坡早于量产。

什么条件出现才把结论上调至"重点关注"：
需同时满足——① 单季毛利率回升至 18% 以上（证明爬坡与结构升级见效）；② L/S / 真空泵 / Chiller 任一款取得 ≥1 亿元批量订单公告；③ 2026 年报营收 ≥ 12.96 亿（激励触发值）。三条齐备时，2029E 中性营收可上修至 27 亿、净利率 9% → 2.43 亿 × 28x = 68 亿 → 44.5 元（+79.6%），届时可上调至"重点关注"。
在此之前，维持"纳入观察"——本股是"赔率极高但胜率待验证"的典型，适合小仓位试探而非重仓。

结论：纳入观察（中性远期空间 +23.6%，>0 但 ≤+50%；高不确定性，18 元以下才具安全边际）

盛剑科技是一只"逻辑真、时点未到、价格已含预期"的票。半导体厂务国产替代 + 从风管向核心装备跃迁的故事是真实的，Q2 营收同比 +30.56% 也证明订单在恢复。但毛利率从 26.6% 崩到 10.6% 这件事，究竟是"周期错配"还是"结构性竞争"，只有 2027 年的毛利率能回答。在答案揭晓前，2.2x PB 定价的是乐观情形。
操作建议：不追高，等 18 元以下 + 毛利率修复信号，小仓位试探，作为"半导体设备国产替代"的高弹性期权配置。
