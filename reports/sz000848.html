股东背景：万向系（万向三农集团）控股，民营资本，治理稳定。

（3）产业链传导

上游：苦杏仁（西北特产农产品）、白砂糖、包装（马口铁 / 铝）。杏仁占成本大头，近年价格总体平稳略降；公司通过直采基地 + 部分长协 + 产品结构升级对冲。
下游：C 端消费，需求韧性强但受宏观消费疲弱影响；北方"礼赠"场景突出，春节旺季集中在 Q4–Q1。
议价权：强。品牌溢价使其可对终端提价（2026H1 吨价 +2.6% 且销量仍增），毛利率连续两期逆势提升佐证转嫁能力强。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：杏仁露毛利率由 44.74%（2025）升至 47.86%（2026H1 整体）、杏仁露细分 49.39%（+2.65pct）。转嫁系数 ≈ 0.8–1.0（品牌强、可提价 + 结构升级吸收原料波动）。依据：连续两期毛利率逆势提升，且非靠降价走量（吨价 +2.6%）。
  • 因子2 毛利结构再平衡：分业务线毛利率——杏仁露 49.39%（贡献利润绝对主体，占利润 95%+）、果仁核桃约 27%、养生水约 42%、杏仁奶约 25%。杏仁露毛利率每变动 1pct 影响整体净利约 0.30 亿；原料敏感权重高度集中于杏仁露线，禁止用单一综合毛利率代表结构。
  • 因子3 库存与采购节奏：公司直采 + 季节性储备，2025 经营现金流 10.12 亿（+60.58%）显示渠道库存健康、回款强；毛利率提升来自结构升级而非低价囤货收益（无显著库存收益扭曲）。验证点：后续季度毛利率若回落需警惕原料涨价。
  • 因子4 政策 / 市场锚点：杏仁为国内自给农产品，不受关税 / 出口管制影响；成本驱动变量为气候与产量（市场层）。情景：杏仁主产区减产 → 原料涨价 → 毛利承压；验证点：杏仁批发价格指数；证伪信号：杏仁露毛利率跌破 45%。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量：杏仁露细分 TAM 约 30–40 亿，露露份额 >60%（细分寡头）。增量来自①北方份额稳固 + 年均提价 2–3%；②南方渗透率从 <4% 提升。三档：保守守住（南方停滞）、中性小幅提升（南方 +1–2pct）、乐观抢份额（南方突破 + 电商放量）。验证点：南方营收占比披露、电商增速、季度销量。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：从"杏仁露"向"植物蛋白全家桶"（核桃 / 养生水 / 杏仁奶）迁移，新 TAM 更大但 3 年未跑通（杏仁奶快卖不动、养生水 H1 −12.1%）。未过验证点，仅作中期期权，不计入中性净利。
  • 层3 风险折扣：证伪信号：杏仁露销量连续下滑、南方渗透率停滞、养生水持续负增 → 下调增量。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。PE 仅 12x、股息率 TTM 6.20%，在消费板块中估值处于历史低位。
安全边际：中性远期 11.0 元 → 空间 +36.5%；悲观 7.65 元 → 下行仅 −5.1%（高股息 + 强现金流提供厚垫）；乐观 15.0 元 → +86.1%。风险收益比不对称偏优。
介入条件：① 现价 8.06 已具配置价值，< 7.5 元（2026E PE < 11x）加仓；② 加仓信号：南方营收占比披露提升、养生水企稳转正、杏仁露销量连续双位数增长。
最大风险（最可能破坏逻辑的因素）：① 第二曲线（杏仁奶 / 养生水）持续失败，增长天花板显性化；② 宏观消费疲弱压制礼赠需求；③ 苦杏仁主产区减产致原料涨价、毛利率跌破 45%。
结论：纳入观察（高股息防守 + 低估值提供安全边际，但中性远期空间 +36.5% 不满足"重点关注"的 >50% 门槛；若南下全国化验证突破，可上调至重点关注）。

核心跟踪点：南方市场渗透率 / 电商增速、养生水企稳信号、毛利率走势。
