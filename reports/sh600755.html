（3）产业链传导（原料成本 → 毛利结构）

供应链企业的"原料"即其经营的大宗商品本身，价格波动通过期现结合机制传导，不由单向成本挤压，而是通过基差与套保效率决定利润。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：供应链是"价格过手型（pass-through≈1）"模式——采购成本几乎全额向下游转移，公司赚取固定服务费与集拼价差，因此大宗商品涨跌本身不直接改变毛利率中枢，而是改变绝对毛利额与营运资金占用。依据：H1 毛利率 2.37%（同比 +0.97pct）在 BPI 下跌 4.49% 的背景下仍上升，证明价格波动并非毛利主变量。转嫁系数≈0.95–1.0。
  • 验证点：季度期现毛利率是否稳定在 1.9%–2.1% 区间。

  • 证伪信号：期现毛利率跌破 1.5%（说明套保失效或被迫承担价格风险）。

  • 因子2 毛利结构再平衡（分品类敏感权重）：必须分品类而非用"综合毛利 2.37%"掩盖结构迁移：

  • 金属及金属矿产（1,078.80 亿元，占 55%）：与钢材/铁矿/铜价强相关，交易收益弹性最大；H1 同比 +45.86%，是营收增长主引擎，但对价格下行最敏感。
  • 能源化工（415.97 亿元，占 21%）：与原油、煤化工价格相关，新能源品类（碳酸锂/锂矿/电芯）为本期最大"出血点"——行业竞争加剧与价格波动导致期现毛利亏损，侵蚀了金属矿产与造船板块贡献（集团口径披露，Q2 已主动调整套保策略）。
  • 农林牧渔（436.60 亿元，占 22%）：与粮价、汇率相关，木片签约量 +100%，稳定性较好。
  • 结构迁移方向：低毛利的能源化工/新能源占比上升 → 加权毛利率被摊薄，这解释了"营收 +29% 而净利率 −0.13pct"。
  • 验证点：新能源品类是否在 H2 实现期现毛利扭亏（公司已表态"止血"）。

  • 证伪信号：碳酸锂/锂矿价格继续下行且套保再次亏损。

  • 因子3 库存与采购节奏（timing）：这是本股最重要的 timing 因素。供应链企业的当期利润高度受低价囤货收益 / 高价接货损失 / 套保时点影响：

  • H1 衍生品套保亏损 6.62 亿元（计入非经常性），对应现货端盈利（计入经常性）——两者是同一笔风险对冲的两条腿，合并看期现毛利率 1.99% 才是真实盈利能力。
  • 因此，不得把"扣非 8.26 亿元"当作可持续盈利，也不得把"归母 4.26 亿元"当作真实下滑；应以期现合并口径（约 1.99% × 营收）为锚。
  • 验证点：H2 是否继续出现大额衍生品套保损失（若连续两期同向大额亏损，说明套保策略存在系统性偏差）。

  • 证伪信号：期现毛利率连续两期低于 1.5%。

  • 因子4 政策/市场锚点（价格驱动变量）

  • 市场层：全球地缘冲突推高避险（贵金属成交额领跑）、美元指数波动压制有色金属、季节性淡季压制需求。BPI 1022 点（6 月底）。
  • 政策层：①"反内卷"推动中游流通领域整合 → 头部份额扩张；②"十五五"新质生产力 → 铜/镍/锂等新能源金属需求增量；③"一带一路"与 RCEP 提供海外资源与仓储节点制度保障；④国资委 79 号文不直接影响本股，但体现信创/国产替代的政策节奏。
  • 情景假设：若美元走弱 + 国内需求修复 → BPI 回升 → 交易收益弹性向上；若美元持续走强 + 需求疲弱 → 交易收益转负。
  • 验证点：BPI 走势、碳酸锂价格、钢材表观消费量。
  • 证伪信号：BPI 跌破 950、或新能源品类期现毛利连续两期亏损。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

层1 现有业务：市场容量 × 份额变量（5 锚点）

  1. 供给侧份额：中国大宗供应链市场规模约 40–55 万亿元，CR5 货量市占率由 4.81%（2021）升至 6.24%（2025）；厦门国贸在 CR5 中营收体量居中（2026Q1 869.01 亿元，低于建发 1,401 亿元、物产中大 1,342 亿元、象屿 991 亿元），份额约 1% 量级。行业分散、集中度提升趋势清晰，头部企业份额有扩张空间。
  2. 需求侧/客户份额：与钢厂、纸厂、能源化工与新能源电池头部客户深度绑定（"深"度绑定头部产业客户）；客户粘性体现在货量与资质壁垒（期货交割库、进出口经营权）。客户认证周期长、替换成本高。
  3. 技术代际差：行业竞争已从"搬砖头"转向"数智化 + 全产业链运营"；公司已上线数智化管理体系，但相对象屿（服务收益占比 >70% 的成熟模型）仍有差距。
  4. 成本曲线位置：规模壁垒（年营收数千亿的集拼采购成本优势）+ 资金壁垒（存货与信用证资金占用）+ 风控壁垒（期现结合、跨境对冲）。厦门国贸的资金成本因国企信用而占优，但 H1 经营现金流 −285.55 亿元、筹资 +409.86 亿元说明其依赖外部融资滚动，成本曲线位置受利率与信用环境约束。
  5. 份额变化的二阶导：货量份额处于加速渗透期（CR5 从 4.81%→6.24%，四年 +1.43pct），但公司自身营收增速（+29.37%）快于行业，份额小幅提升。三档假设：保守守住现有份额 / 中性份额小幅提升 0.1–0.2pct / 乐观受益于中小主体出清、份额提升 0.3pct 以上。

层2 扩展业务：主业迁移空间（新易盛范式）

  • ①能力可迁移性：供应链核心能力（期现结合、跨境对冲、多币种结算、全球物流节点）高度可迁移至新品类与新市场——公司已从钢材/铁矿/浆纸迁移至碳酸锂、锂矿、电芯、氧化铝、木片。
  • ②新 TAM 弹性：新能源金属与绿色低碳供应链为全新池子（铜/镍/锂/钴需求高增），TAM 弹性大；海外属地化运营（由"通道式出海"转向"属地化运营"）打开第二市场。
  • ③切入时点与卡位：新能源品类属早期切入但已进入红海（本期即录得期现毛利亏损，是证据）。
  • ④客户认证门槛：新能源电池客户的认证与账期管理要求高，门槛中高。
  • ⑤信号验证：新能源品类尚未实现期现毛利转正，验证点未过。
  • 结论：新能源品类迁移与海外属地化运营均为"中期期权"，未过"新能源期现毛利转正 + 海外业务单列盈利"验证点前，不计入中性情景。

层3 风险折扣：证伪信号

  • 期现毛利率连续两期低于 1.5% → 主营盈利能力证伪。
  • 经营现金流连续两期大额净流出、且筹资净流入无法覆盖 → 流动性证伪（本股 H1 已现 −285.55 亿元经营现金流的极端值）。
  • 衍生品套保连续两期同向大额亏损 → 风控能力证伪。
  • 新能源品类 H2 未能"止血" → 品类迁移证伪。

第四步：估值锚定（自下而上，非增速外推）

方法说明：本股 PE 因盈利极薄而严重失真（TTM PE 29.89x），故采用双锚：①盈利锚（期现合并口径的稳态净利润 × 供应链合理 PE）；②净资产锚（普通股净资产 × 破净修复系数）。两者交叉取中性。全文使用"稳态净利润/中性净利润"口径，不涉及历史线性外推。

总股本：约 21.32 亿股。

净资产口径说明（破净举证的核心）：
- 归母权益合计 352.23 亿元（2026-06-30），但其中含其他权益工具（永续债等）约 162.5 亿元（本期对应永续债利息 2.19 亿元/半年，年化约 4.4 亿元）；
- 剔除永续债后，普通股股东净资产约 189.7 亿元，每股净资产约 8.90 元 → 现价对应 PB 0.65x（行情商口径）；若含永续债口径则 PB 仅 0.35x。两种口径均深度破净，以下以普通股口径 0.65x 为准。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正1 资产质量折扣（破净原因必须说明）——本股核心

破净必须逐项举证，禁止单凭 PB<1 推导"空间大"。本股 PB 0.65x 的原因拆解：

破净原因 举证 是否属"真安全边际"
① ROE 过低（资产盈利能力差） 2026H1 加权 ROE 仅 1.08%（年化约 2.2%），2025 年 ROE 0.24%。按 ROE/COE 定价（COE≈9%），公允 PB ≈ 0.25–0.35x 否——属公允定价，非低估
② 商业模式高杠杆、薄利 资产负债率 74.66%（2026H1）；净利率 0.19%；营收 1,962 亿元而归母仅 4.26 亿元 否——薄利高周转模式的合理折价
③ 营运资金占用激增、现金流恶化 经营现金流 −285.55 亿元（H1），筹资 +409.86 亿元；应收账款/预付/存货规模巨大，实际资产质量存疑 否——净资产存在减值与流动性风险，虚高
④ 永续债计入权益 归母权益 352.23 亿元中含其他权益工具约 162.5 亿元，实质为类负债，年化利息约 4.4 亿元（直接摊薄普通股股东回报） 否——净资产口径虚高，须还原
⑤ 金融资产/股权未重估 公司持有部分金融资产与股权，但未查到"持股市值 ≈ 总市值"的典型真破净特征 不适用

结论：本股破净属"资产盈利能力差 + 高杠杆 + 权益口径虚高"三重叠加，不是"金融资产未重估型"的真安全边际。因此：
- 不得给 1.0x PB 的修复目标，中性仅给 0.75x；
- 须明确标注：若净资产再打 20% 折扣（反映应收/存货风险），则 PB 将升至 0.81x，"低估"幅度大幅收窄。

校正2 周期位置校正：大宗商品处于 2026H1 高位运行、结构分化、6 月起边际回落的位置（BPI 从 1070 跌至 1022，−4.49%），非底部、非顶部，属中段偏弱。中性净利已使用期现合并毛利率 2.0% 的跨周期中枢（2026H1 实际 1.99%、2025 全年更低），未使用任何单年好年景或拐点年化。

校正3 杠杆下行情景（高负债必附负面情景）——本股核心风险

资产负债率 74.66%，且 H1 经营现金流 −285.55 亿元、筹资 +409.86 亿元，属"经营杠杆 + 财务杠杆双高 + 依赖融资滚动"的极端类型：
- 利率上行情景：有息负债按 800 亿元估算，利率每上行 50bp，年财务费用增加约 4 亿元——直接吃掉中性净利 11 亿元的 36%。
- 需求下行情景：若 BPI 跌破 950、下游钢厂/纸厂减产 → 货量收缩 + 存货跌价 → 归母净利可跌至 3–4 亿元，同时营运资金占用进一步扩大，PB 可下修至 0.45x（对应股价约 4.0 元，空间 −31%）。
- 该负面情景使空间转负，故本股不得标"大空间 / 重点关注"，至多"纳入观察"且须注明高贝塔属性。

期权纪律：第三步中的"新能源品类期现毛利转正""海外属地化运营盈利""永续债置换"三项期权，未过验证点，不计入中性 2029E 稳态净利 11.0 亿元与 PB 0.75x 的定价，仅放入乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：低估但有重大瑕疵。PB 0.65x 深度破净，但破净原因是 ROE 仅 2.2% 的资产盈利能力差型+高杠杆+权益口径虚高，属部分公允折价，而非纯错杀。

安全边际：
- 中性远期 7.08 元 → 空间 +22.5%，满足"纳入观察"（>0），不满足"重点关注"（>+50%）。
- 悲观情景 4.60 元 → 下行 −20.4%；乐观 8.85 元 → +53.1%。风险收益大致对称。
- 下行保护：普通股每股净资产 8.90 元（现价仅 0.65x）；2024 年分红率 57.6%、股息率约 6.4%（华创证券测算）；国企信用融资成本占优。
- 上行触发：期现毛利率稳定 ≥2.0%、新能源品类止血、份额提升。

介入条件：
1. 价格：现价可入但仅作"红利 + 折价修复"配置，加仓区间 5.20 元以下（PB <0.60x）。
2. 信号：① 期现毛利率稳定在 1.9%–2.1%；② H2 新能源品类期现毛利环比转正；③ 经营现金流净额环比大幅收窄（H1 −285.55 亿元为极端值）；④ 衍生品套保不再出现单期超 5 亿元同向亏损。
3. 观察指标：BPI、碳酸锂价格、钢材表观消费量、季度经营现金流与筹资现金流净额、永续债规模变化。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 现金流与杠杆风险（首要）：H1 经营现金流 −285.55 亿元、筹资 +409.86 亿元，若融资环境收紧或信用评级下调，流动性压力急剧放大。
2. 期现套保亏损重演：H1 衍生品亏损 6.62 亿元，Q2 扣非单季 −6.74 亿元，说明套保策略存在时点性大额偏差。
3. ROE 长期低位：ROE 仅 2.2% 意味着即使 PB 修复，长期回报仍依赖分红与估值波动，缺乏内生复利。
4. 永续债利息刚性：年化约 4.4 亿元利息直接摊薄普通股股东回报，且永续债有重定价/赎回条款风险。

结论：纳入观察

本股是"高股息 + 破净折价修复"型标的，弹性来自 PB 修复与集中度提升，而非利润成长。但 ROE 2.2%、经营现金流 −285.55 亿元、永续债 162.5 亿元三大瑕疵使其破净属部分公允，中性空间 +22.5% 未达"重点关注"门槛，故纳入观察。

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：大宗供应链市场规模 40–55 万亿元、CR5 市占率由 4.81%（2021）升至 6.24%（2025），"反内卷"推动上下游与中游流通整合，中小主体加速出清。厦门国贸作为 CR5 之一，份额提升空间大。验证点：CR5 市占率突破 7%、公司货量增速持续快于行业。证伪信号：中小主体出清停滞、公司份额下滑。重估弹性：份额提升 0.3pct → 货量与毛利额提升约 25–30%，可支撑 PB 上修至 0.9x。
  • 类型B 政策反转期权：本股对应的是"稳增长/扩内需 + 反内卷"政策组合。若专项债与基建提速带来钢材/铁矿需求回升、或"反内卷"落地严控低价竞争，则交易收益与期现毛利同步改善。验证点：基建投资增速回升、BPI 重回 1100 以上。证伪信号：需求持续走弱、BPI 跌破 950。重估弹性：期现毛利率由 2.0% 升至 2.3% → 稳态净利提升约 6–8 亿元。
  • 类型C 市场错杀修复：PB 0.65x、PE(TTM) 29.89x 反映市场对薄利模式与现金流的极度悲观；若经营现金流恢复正常（非 −285.55 亿元的水平），市场可能重新给予 PB 0.8–0.9x。验证点：季度经营现金流转正或大幅收窄。证伪信号：现金流持续大额外流且融资受阻。
  • 类型D 技术突破/技术代际跃迁期权：本股不适用——供应链不涉及全新技术路线从 0 到 1 的投产。数智化（AI 货权管理、智能决策）属效率工具，可小幅提升周转与风控，不构成新赛道。据实说明，不做强行建模。

什么条件出现才上调至"重点关注"：① 期现毛利率稳定 ≥2.2% 且经营现金流转正（验证商业模式已具备真实造血能力）；② ROE 回升至 8% 以上（则公允 PB 可达 0.9x，空间 +38%）；③ 股价同时回落至 5.0 元以下，则 PB 0.9x 对应空间将突破 +60%，且下行有净资产保护。三者需同时成立，方可上调。
