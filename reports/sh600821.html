（3）产业链传导

上游：光伏组件、风机、储能设备。组件价格在 2023–2025 年大幅下跌后处于历史低位，对电站运营商是重大利好（单位千瓦造价下降 → 新建项目 IRR 提升）。但公司 2025 年计提固定资产减值 4.8 亿元，反映早期高价建设资产的账面价值需要向下修正。

下游：电网与电力市场。消纳是核心矛盾——2025 年全国电源投资 +10.3%、电网投资仅 +7.1%，电网建设滞后于电源，导致限电率攀升；2026H1 公司发电量下滑 10.45% 即部分源于限电与资源因素。

议价权：弱（对电网）／ 中（对终端绿电用户）。佐证：① 2026H1 电价 −3.0%、2025 年综合电价 −45 元/MWh，公司几乎无定价权；② 但绿电交易（4.3 亿千瓦时）与跨省外送（13.2 亿千瓦时）打开新的成交渠道，且数据中心 80% 绿电强制要求带来刚性需求；③ 99.58% 市场化比例意味着收入完全由市场电价决定，议价权天然弱于拥有机制电量保护的存量大基地。

第二步进阶：原料成本 → 毛利结构传导（四因子）

新能源发电无实物原料，"原料成本"即折旧摊销与财务费用（占营业成本绝大部分），四因子按发电运营口径映射如下。

因子 1 成本传导弹性（pass-through）
电站的"成本"主要是固定资产折旧（一次性锁定，不随电价变动）+ 财务费用（利率敏感），属完全刚性。因此电价下行时成本无法压缩，毛利直接承压——传导率≈0.1。佐证：2026H1 电价仅 −3.0%，但毛利率 −9.57pct、归母 −81.66%，杠杆效应极端放大。

验证点：季度电价与毛利率；证伪信号：电价企稳而毛利率继续下滑。

因子 2 毛利结构再平衡（分业务线，禁用单一综合毛利率）

业务线 2026H1 收入 毛利率方向 关键成本敏感度
光伏发电 8.47 亿元（50.14%） 大幅承压（2025 光伏电价 −57 元/MWh） 折旧刚性 + 电价（高敏感）
风力发电 7.79 亿元（46.07%） 相对稳（2025 风电电价 +2 元/MWh，存量补贴机组为主） 折旧刚性 + 电价（中敏感）
算力服务 0.326 亿元（1.93%） 较高（智算租赁） 折旧 + 电力成本
其他（服务器代采） 0.314 亿元（1.86%） 低（贸易性质） —

结论："光伏拖累、风电托底、算力待放量"。光伏占收入 50.14% 却是毛利下滑主因；风电存量以补贴机组为主、电价相对稳；算力服务占比仅 1.93%。估值必须分业务给毛利，不能只看 46.60% 的综合毛利率。

因子 3 库存与采购节奏（timing）
新能源电站无"库存"概念，"节奏"体现为减值时点与补贴回款节奏：① 2025 年一次性计提减值 7 亿元（固定资产 4.8 亿 + 商誉 2.2 亿）——这是 TTM 亏损的直接原因，属"财务洗澡式"出清，反而为后续轻装上阵创造条件；② 2026H1 经营现金流 7.82 亿元（+108%），主因国家可再生能源补贴资金回收金额增加，属"历史应收补贴集中到账"，性质上偏一次性但改善了现金流质量；③ 无套保披露（电价无对冲工具）。

验证点：补贴回款是否持续、是否再有减值；证伪信号：减值二次计提。

因子 4 政策 / 市场锚点（成本驱动变量）
- 市场层：光伏组件/风机价格（影响新建造价）、消纳率（限电）、利率（财务费用，公司负债率 72.42% 高度敏感）。
- 政策层：① 136 号文机制电价——2026 年多省竞价结果显示光伏/风电机制电价同比上调（山东光伏 +3.6 分、甘肃 +20%），"电价大幅下降的预期正在被市场逐步修正"；② 机制执行年限 10–12 年 → 为存量项目提供长期价格锚；③ 消纳责任权重（电解铝强制 + 数据中心 80% 绿电）→ 打开刚性绿电需求；④ 2026 年《政府工作报告》首提"算电协同" → 直接利好公司伊吾/乌兰察布项目。

验证点：各省机制电价竞价结果、限电率、公司绿电交易量；证伪信号：机制电价再度大幅下调、限电率继续攀升。

层 3 风险折扣：证伪信号
① 电价若继续下行（2025 综合电价 −45 元/MWh）→ 毛利继续被侵蚀；
② 限电率若继续攀升 → 发电量进一步下滑；
③ 算力服务若无法从 1.93% 提升 → 第二主业证伪；
④ 若再次大额计提减值 → 资产质量恶化，净资产缩水。

第四步：估值锚定（自下而上，非增速外推）

方法说明：公司 TTM 为负（PE −48.6x），无正 PE 可锚，采用亏损股专项估值口径（正常化净利润法）三步推导：① 估稳态营收（现有电站满发 + 在建/核准装机并网 + 算力服务兑现）；② 取保守正常化净利率；③ 正常化净利润 × 远期合理 PE = 目标市值 → 目标价。不使用历史增速外推——公司 2022–2025 归母净利为 7.32 → 8.02 → 8.03 → 1.01 亿元，历史曲线因减值而断裂，无预测价值。

亏损股必答三问

  1. 为什么亏？（TTM 口径）TTM = 2025H2 + 2026H1 = −2.60 亿元。根因是 2025 全年计提减值 7 亿元（固定资产减值 4.8 亿元 + 商誉减值 2.2 亿元），叠加新能源市场电价下行（2025 综合电价 −45 元/兆瓦时）、限电损失电量增加、联营企业受光伏产业链阶段性供需失衡影响出现亏损（权益法投资收益同比下降），以及部分税收优惠退出。注意：2026H1 公司已实现归母净利 +0.81 亿元（扭亏），TTM 为负纯属 2025H2 高基数拖累。
  2. 靠什么扭亏、触发时点？ 已经扭亏——2026Q1 亏 0.19 亿元 → 2026Q2 单季盈 1.00 亿元 → 2026H1 归母 +0.81 亿元。四条路径：① 装机增长（并网 6.25 GW，核准 7,961 MW，风电并网同比 +22.9%）；② 电价企稳回升（2026 年多省机制电价同比上调：山东光伏 0.225→0.261 元、甘肃 0.1954→0.2447 元，涨幅超 20%）；③ 算电协同放量（伊吾 2000P 已投运并签约）；④ 减值出清后轻装上阵。触发时点：2026H1 已兑现，2026 全年有望恢复至 2 亿元量级。
  3. 亏得起吗？ 亏得起，但杠杆偏高需警惕。① 2026H1 经营现金流 7.82 亿元（+108%），主因国家可再生能源补贴资金回收；② 资产负债率 72.42%（电力运营商属重资产，行业普遍偏高），但股东含国开金融、通用技术集团，融资渠道通畅（2026H1 筹资活动现金流 −6.6 亿元，主动降杠杆）；③ 总资产 393.30 亿元、净资产 87.4 亿元。结论：短期无生存风险，但高负债率放大了电价/利率波动的利润弹性（双刃剑）。

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

新能源发电为典型重资产（固定资产占比极高）+ 受电价周期影响的行业，必须逐条校正。

校正 1 资产质量折扣（PB 1.44x，非破净，但须核验资产质量）
虽未破净，但资产质量存在明确瑕疵：① 2025 年计提固定资产减值 4.8 亿元 + 商誉减值 2.2 亿元，说明早期高成本建设资产的账面价值需要向下修正（电价下行使旧资产 IRR 无法支撑原账面值）；② 电站资产专用性极强（光伏/风场不能转产、清算价值远低于账面）；③ ROE 仅 0.89%（2026H1）——PB 1.44x 对应不足 2% 的 ROE，估值与资产盈利效率严重不匹配。→ 属"资产盈利能力差"型高 PB，不能视为安全边际。

验证点：ROE 是否回升至 5% 以上、是否再有减值；证伪信号：二次大额减值、ROE 三年不改善。

校正 2 周期位置校正（中性净利用周期归一化）
新能源发电处"电价市场化下行 + 消纳承压"的周期底部（2025 年公司综合电价 −45 元/MWh、2026H1 发电量 −10.45%）。中性净利不取单年好年景（2024 年归母 8.03 亿元为近年峰值）、不取近三年均值（2022–2024 恰为电价高位期）、不取拐点年化（2026Q2 单季 1.00 亿元年化不可持续），采用周期中位净利率 16%（介于底部与峰值 22–24% 之间，偏保守）。当前处底部，故不过度悲观——2026 年机制电价多省上调是修复信号。

验证点：各省机制电价竞价结果、限电率、季度毛利率；证伪信号：机制电价再降、限电率继续攀升。

校正 3 杠杆下行情景（高负债必附负面情景）
资产负债率 72.42%（2025），属显著偏高，且电站运营为"经营杠杆 + 财务杠杆"双高模式（折旧固定 + 利息固定）。下行情景：若电价继续下行 + 限电加剧 + 算力不及预期，2029E 净利降至 2.88 亿元 → 目标 1.76 元（−72.4%）。该负面情景使空间大幅转负，故不得标"大空间/重点关注"，至多"暂不介入"并注明高贝塔属性。

期权纪律：算电协同（乌兰察布）、源网荷储一体化、零碳园区、绿电直连等未过验证点（算力收入占比仅 1.93%），一律只放乐观情景，不计入中性净利。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 6.37 元对应 PB 1.44x、2026E PE 约 63x、ROE（2026H1）0.89%。中性远期 5.04 元对应 −20.9% 空间；乐观情景 8.30 元仅 +30.3%。

安全边际：
- 中性远期 5.04 元 → 空间 −20.9%，无安全边际
- 乐观情景 8.30 元 → +30.3%，需电价回升 + 算力放量 + 限电改善三方共振
- 悲观 1.76 元 → −72.4%，风险不对称显著偏负
- 下行保护：每股净资产 4.44 元（PB 1.44x → 净资产打 7 折为 3.11 元）；国开金融/通用技术集团股东背景；补贴回款改善现金流

介入条件：
1. 不追高。现价 PB 1.44x 对应 ROE 仅 0.89%，估值与盈利效率严重不匹配。
2. 潜在观察信号（仅列示）：① ROE 连续两季回升至 2% 以上；② 算力服务收入占比突破 5%（当前 1.93%）；③ 综合毛利率企稳回升至 50% 以上。
3. 观察指标：季度上网电价、发电量/限电率、经营现金流、装机并网进度、机制电价竞价结果。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 电价市场化下行（首要）：2025 年综合电价 −45 元/MWh、光伏电价 −57 元/MWh（河北 −308 元），99.58% 的市场化比例意味着公司完全暴露于电价风险；2026 年机制电价上调能否持续尚待验证。
2. 消纳与限电：2025 年电网投资（+7.1%）滞后于电源投资（+10.3%），2026H1 发电量 −10.45%，限电侵蚀有效收入。
3. 高杠杆放大波动：资产负债率 72.42%，折旧与利息刚性，电价小幅下行即导致利润大幅波动（2026H1 电价 −3.0% → 归母 −81.66%）。
4. 算力业务占比过低：仅 1.93%，若无法放量则第二主业证伪，市场给的"算力溢价"需回吐。

结论：暂不介入

公司并非"无扭亏路径"——2026H1 已扭亏为盈（+0.81 亿元，Q2 单季 +1.00 亿元），装机持续增长（6.25 GW）、机制电价 2026 年多省上调、算电协同从 0 到 1，因此不判"坚决回避"。
但现价 6.37 元对应 PB 1.44x、ROE 仅 0.89%、2026E PE 约 63x；中性远期空间 −20.9%，乐观仅 +30.3%，赔率不划算；且高负债（72.42%）放大电价波动，风险收益不对称偏负。
什么条件出现才上调至"纳入观察/重点关注"：ROE 连续两季回升至 2% 以上 + 算力服务收入占比突破 5% + 股价回落至 4.4 元以下（PB <1.0x），三者同时出现可将结论上调。
