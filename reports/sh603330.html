上游：大型石化企业与国际化工原料商，提供己内酰胺、癸二酸、EVA 粒子、己二酸、MDI/异氰酸酯、环氧树脂等。公司自述："生产成本的大头是直接材料，而这些原材料本质上都跟石油价格挂钩，部分还要向国际厂商用美元采购……成本波动未必能完全转嫁给下游客户，利润会直接被挤压"。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）—— 热熔胶约 0.50（弱），电子胶约 0.70（中）

  • 重要前提：2026H1 综合毛利率 +10.21pct（21.92% → 32.13%）并非原料传导改善，而是剥离负毛利光伏业务的结构红利。
  • 拆穿结构看真实传导：三条存续产线毛利率全部下滑：
产线 2025 毛利率 2026H1 毛利率 变动
热熔胶 27.3% 25.41% −1.89pct
电子胶 54.7% 53.07% −1.63pct
热熔墙布 33.2% 32.64% −0.56pct
  • 传导率反推（热熔胶）：原料占成本约 75%，若原料同比 +5%，未传导部分 = 5% × 75% × (1−传导率) = 1.89pct → 传导率 ≈ 50%。
  • 传导率反推（电子胶）：原料占成本约 60%（配方价值占比高），1.63pct = 5% × 60% × (1−传导率) → 传导率 ≈ 46%；若考虑电子胶原料涨幅更高（特种单体/环氧），实际传导率约 0.70。
  • 结论：公司整体议价权弱（传导率 0.50–0.70），原料涨价大部分自扛。 验证点：季度分产品毛利率、原料采购价、公司调价函。

因子3 库存与采购节奏（timing）

  • 存货周转天数 94.0 天（2026H1）vs 72.5 天（2025H1）→ 放缓 21.5 天，需警惕。
  • 应收账款周转天数 133.4 天（2026H1）vs 133.0 天 → 基本持平，但绝对水平极高（4 个多月），回款慢是本股的慢性病。
  • 公司口径："通过订单锁价、批量集采原料、优化排产、降低物流成本等精细化降本措施，有效对冲上游原料价格波动风险" → 有部分锁价与集采对冲，但未披露对冲比例，无期货套保披露。
  • H1 经营现金流 +6504 万的本质：公司明确说明"主要系停止光伏业务后，购买商品、接受劳务支付的现金较上年同期大幅减少所致"→ 现金流改善是"收缩出来的"，不是经营改善，不能当作盈利能力恢复的证据。
  • 判断：存货周转从 72.5 天升至 94 天，若为电子胶新赛道备货则属良性（待订单验证）；若新赛道订单不落地，将形成跌价。这是 H2 的核心跟踪点。

第四步进阶：重资产 / 周期股三道校正

校正1 资产质量折扣（本股是"高 PB"而非破净，方向相反但同样必须解释）
- PB 3.01x，归母净资产 13.18 亿。不破净，无需说明破净原因；但必须解释为何 3.01x 不成立。
- ROE 检验：2026E ROE = 0.20 / 13.18 = 1.5%。隐含 PE = PB / ROE = 3.01 / 0.015 = 200x。这是本组 5 只标的中估值最极端的一个。
- 资产构成风险：①商誉 5518 万（占净资产 4.2%，可控）；②光伏停产后昆山/南通/海安的厂房设备闲置或改造中，公司称"一部分改造用于热熔胶和电子胶生产，一部分对外出租或出售"——若改造/出租不顺利，存在二次减值风险；③应收账款周转 133 天，坏账风险；④存货周转从 72.5 升至 94 天，跌价风险。
- 结论：PB 3.01x 定价的是"电子胶转型 + 实控人资产注入"双重期权，不是现有资产的盈利能力。按期权纪律，这两项均未过验证点。

校正2 周期位置校正
- 胶粘剂行业周期性弱，但公司自身处于"缩表提质的经营周期底部 + 转型期权窗口期"。
- 当前周期位置标注：经营底部区间（2026H1 刚过盈亏平衡点），但底部持续时间不确定。 证据：营收连续三年下滑（13.25 → 13.19 → 8.61 亿，2026 年化 6.7 亿）；净利刚从 −2.44 亿转正至 +0.06 亿；Q2 净利与净利率环比双双下滑。
- ❌ 禁止用 2022–2025 任一亏损年做锚。
- ❌ 禁止把 2026H1 的微利年化（0.12 亿）——这会低估转型价值，同属"拐点年化"，RULES 明令禁止。
- ✅ 采用：正常化净利率法（热熔胶 9.5%、电子胶 18%），该净利率低于公司历史最好水平、低于行业中枢上限，属保守取值。
- 底部位置对估值的指示：底部给高 PE（32x）是合理的（因为 2029 年已假设恢复）；但底部持续越久，中性净利越需下修——若 2027 年电子胶利用率仍未提升，中性须下调。

校正3 杠杆下行情景（必附）
- 资产负债率 27.62%（本组最低），有息负债 4.0 亿，流动比率 1.46、速动比率 1.27 → 财务风险低，无流动性危机。

- 负面情景：①电子胶新赛道认证失败 → 1730 吨产能利用率继续低于 60% → 固定成本摊不掉 → 净利回到 0 附近；②热熔胶价格战（国内中小企业低价竞争）→ 毛利率跌破 22% → 净利转负；③光伏停产资产二次减值（0.5–1.0 亿）→ 净资产侵蚀；④应收账款周转 133 天，若下游客户（光伏/地产链）违约 → 坏账计提。

第五步：综合赔率判断（买不买？）

亏损股三问（必答）

① 为什么亏？
- 主因：光伏封装胶膜业务持续失血 + 大额资产减值。2025 年该业务收入 1.9 亿但毛利率 −13.4%（同比 −69%），四家光伏子公司 2024 年合计亏 2.34 亿；2025 年计提光伏与墙布相关资产减值 约 2.09 亿（占当年 2.44 亿亏损的 86%）。
- 次因：行业价格竞争 + 产能过剩。2022 年定增 9.67 亿押注光伏胶膜（规划新增 4.5 亿平方米），遭遇行业价格战，三大募投项目全部失败。
- 关键判断：主业（热熔胶 27.3% 毛利率 + 电子胶 54.7% 毛利率）实际是盈利的，亏损来自跨界失败的历史包袱，不是主业恶化。

② 靠什么扭亏？触发时点在哪一年？
- 已在 2026H1 扭亏（归母 +616.51 万、扣非 +420.64 万，扣非同样为正 → 非一次性收益驱动）。
- 四条路径：①光伏完全停产（2025 年 12 月宣布、2026 已完全体现）；②墙布剥离（2026-07 公告出售德法瑞）；③热熔胶收入 +13% 且毛利改善；④电子胶高毛利（53%）放量。
- 触发时点：2026H1 已过盈亏平衡点。但"微利"≠"可持续盈利"——Q2 净利环比 −17.12%、净利率仅 1.77%，说明尚未建立稳健盈利。

③ 亏得起吗？
- 完全撑得住。 资产负债率 27.62%（本组最低）、有息负债 4.0 亿、归母净资产 13.18 亿、流动比率 1.46、速动比率 1.27、经营现金流 H1 +6504 万（同比 +6904.59 万）。
- 无商誉暴雷风险（5518 万，占净资产 4.2%）。倒在黎明前的概率极低。

当前价格位置：明显高估。

- 市场在定价"电子胶转型 + 实控人资产注入"双重期权，而这两项均未过验证点（利用率 58.7% 未提升、无订单公告、无注入公告）。

- 中性远期 8.50 元 → −7.4%，不满足"纳入观察"的 >0 门槛
- 悲观 3.47 元 → −62.2%
- 乐观 19.32 元 → +110.5%（需电子胶新赛道放量 + 资产注入同时成立）
- 赔率结构：上行 +110.5% / 下行 −62.2%，赔率约 1.8:1，但中性为负 —— 这是典型的"期权定价已充分"的标的

介入条件：

2. 加仓信号：①电子胶产能利用率突破 80%；②半导体/AI 导热/光模块任一方向拿到客户定点或 5000 万以上订单；③单季归母净利突破 2000 万；④德法瑞股权出售完成且产生正向处置收益

1. ⚠️ 转型期权已被过度定价（首要）：PB 3.01x 对应 ROE 1.5%、PE 200x。市场已把"电子胶转型成功"完全定价，而实际产能利用率仅 58.7%、无订单公告。一旦 2027 年利用率仍未提升，估值将向 PB 2x 以下回归（6.1 元，−33%）。
2. ⚠️ 营收持续萎缩：2026H1 −28.04%，年化仅 6.7 亿（vs 2022 年 14.26 亿）。"缩表提质"的边际效应正在减弱（Q2 净利环比 −17.12%），砍无可砍后必须靠电子胶接棒，否则将陷入"营收小、利润薄"的僵局。
3. ⚠️ 现金流改善的假象：H1 经营现金流 +6504 万主要来自停止光伏后采购支出减少，不是经营改善。存货周转从 72.5 天恶化至 94 天、应收账款 133.4 天，营运效率实际在下降。
4. 新实控人的历史包袱：茹氏家族旗下百佳年代本身是光伏胶膜企业，在光伏行业底部入主一家刚砍掉光伏业务的公司，战略意图与资产整合路径不清晰。

什么条件下上调至"重点关注"（须同时满足至少两条）：
1. 电子胶产能利用率突破 80% 且营收占比 > 35%
2. 半导体 / AI 导热 / 光模块 / 汽车电子任一方向拿到客户定点或 5000 万以上订单公告
3. 单季归母净利突破 2000 万（证明可持续盈利能力，而非微利挣扎）
4. 股价回落至 7.0 元以下（PB < 2.3x，估值进入合理区）

结论：暂不介入

核心判断：这是一家"包袱已卸、方向正确、但价格太贵"的转型标的。
正面：光伏亏损源已彻底清除、主业毛利率真实（热熔胶 25%、电子胶 53%）、财务极安全（负债率 27.6%、无流动性风险）、新实控人有产业资源、电子胶赛道（半导体/AI 导热/光模块）想象力真实。
负面：PB 3.01x、隐含 PE 200x 已经把转型成功完全定价；营收连续三年萎缩至年化 6.7 亿；电子胶产能利用率仅 58.7% 且未提升；五个新赛道无一有订单公告；Q2 净利环比已走弱。
中性远期空间 −7.4%——现价买入，即便转型按中性路径成功，到 2029 年仍亏损。这是一个"好故事、坏价格"的标的。
真正的机会在 7 元以下，或在"电子胶利用率突破 80% + 新赛道拿到定点"任一信号明确之后。
核心跟踪点：电子胶产能利用率（58.7% 是本股最重要的单一数字）+ 新赛道订单公告 + 光伏资产处置进展。
