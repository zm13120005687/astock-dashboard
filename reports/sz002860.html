（3）产业链传导

上游：家电零部件的主要原料为铜、银、钢、工程塑料（银用于触点）；光伏组件的主要原料为硅料、硅片、电池片、玻璃、边框（铝）、EVA/POE 胶膜。2026H1 光伏产业链各环节价格震荡下降，对组件厂而言原料跌价理论上有利，但组件售价同步下跌更快，导致组件毛利率仅 4.02%。

下游：家电（海尔/美的/海信等压缩机与整机厂，需求平稳）；光伏电站与分布式客户（2026H1 装机 −66%，需求阶段性塌陷）。

议价权判断
- 家电零部件侧：中偏强。热保护器/起动器属安全件，认证周期长、切换成本高，毛利率 32.47% 佐证；但下游为海尔/美的等强势整机厂，2026H1 收入 −0.85% 显示提价能力有限。
- 光伏组件侧：极弱。毛利率仅 4.02%、行业产能严重过剩、组件同质化 → 完全的价格接受者。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1 成本传导弹性（pass-through）——分板块差异巨大

板块 核心原料 议价权 转嫁系数（估计） 依据
家电零部件 铜、银、钢、工程塑料 中偏强 约 0.6–0.8 安全件认证壁垒高、与大客户有年度调价机制（铜价联动）；但 2026H1 收入 −0.85% 显示只能部分转嫁
光伏组件 硅料/硅片/电池片/玻璃/铝边框 极弱 约 0.1–0.3 组件为标准品、产能过剩，售价由市场拍卖决定，成本下跌的收益被价格战吃掉
光通信/光传感 光纤、芯片、塑料件 弱 约 0.3 收入 −5.70%、毛利率仅 2.57%

量化：若铜价上涨 10%，家电板块 2026H1 收入 4.99 亿元中铜相关成本占比按 20% 估算，则成本增厚约 0.10 亿元，按 0.7 转嫁率后公司实际承压约 0.03 亿元（对半年 1.0 亿元归母的影响约 3%）。光伏板块同理，硅料价格波动几乎全额由公司承担。

因子 2 毛利结构再平衡（分业务线毛利率 + 原料敏感权重）

业务线 2026H1 毛利率 收入占比 原料敏感度 利润贡献（估算）
家电零部件 32.47% 45.57% 中（铜/银） 约 1.0 亿元归母（绝对主力）
光伏组件 4.02% 51.36% 极高（硅料/玻璃/铝） 接近盈亏平衡
光通信/光传感 2.57% 1.43% 中 基本不贡献

核心结论：51.36% 的收入只贡献了接近于零的利润，45.57% 的收入贡献了几乎全部利润。用"综合毛利率 17.27%"看星帅尔会严重误判——一旦光伏硅料/玻璃价格反向波动 1–2 个百分点，就能让光伏板块从微利转为亏损，而家电板块稳如磐石。估值必须按分板块净利，不能沿用综合毛利率。

因子 3 库存与采购节奏（timing）
- 光伏库存风险（重要）：2026H1 组件价格先反弹后回落，若公司持有高价硅料/电池片库存，Q2 毛利率环比 −4.4pct 即可能是高价接货损失的体现，属一次性、不可持续，不应外推。
- 家电侧：铜、银价格 2026 年相对平稳，公司对大宗采用随行就市 + 部分年度锁价，无重大囤货收益/损失。
- 警惕：不可把任何单季因原料 timing 造成的毛利波动当成"盈利能力改善/恶化"的趋势。

因子 4 政策 / 市场锚点（原料成本驱动变量）

类型 变量 情景 验证点
政策层 光伏三项强制性国标 + 产能调控 20–30% 低效产能退出 → 组件价格修复 → 光伏板块毛利率从 4% 修复至 8–12% 强标正式实施时间表、行业协会月度价格数据
政策层 家电以旧换新补贴 补贴延续 → 压缩机需求托底 → 家电板块收入止跌 月度家电零售/排产数据
市场层 硅料/玻璃/铝边框价格 下跌 → 组件成本改善；上涨 → 组件毛利被吃（转嫁率仅 0.1–0.3） 硅料周度报价、光伏玻璃价格
市场层 铜价 上涨 10% → 家电板块承压约 0.03 亿元/半年 LME 铜价、公司调价公告

证伪信号：① 光伏强标落地推迟、产能退出不及预期 → 组件价格无法修复，光伏板块持续拖累；② 铜价大幅上涨且转嫁受阻 → 家电板块毛利率跌破 28%；③ 以旧换新退坡 → 家电收入转负增长扩大。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

层 1 现有业务：市场容量 × 份额变量

锚点 现状 三档份额假设 验证点
① 供给侧份额 热保护器/起动器/接线柱为全球主要供应商；光伏组件产能为行业中游 保守：守住压缩机零部件份额；中性：温控器/电机扩份额；乐观：新能源车电机进入一线客户 客户定点公告、细分收入
② 客户份额 覆盖海尔/海信/美的/美菱/小米/惠而浦/松下 保守：大客户份额持平；中性：进入更多整车厂电机供应链；乐观：温控器进入海外高端品牌 前五大客户占比、新客户公告
③ 技术代际差 热保护器/起动器为成熟技术，公司处第一梯队；光伏组件为成熟标准品（无代差） 中性：零部件维持代际领先；光伏靠大尺寸（800W+）卡位 大尺寸组件出货占比
④ 成本曲线位置 家电零部件规模优势明显；光伏无成本优势 保守：光伏成本居行业中游；中性：靠大尺寸摊薄；乐观：进入行业成本曲线前 30% 板块毛利率
⑤ 份额二阶导 家电收入 −0.85%（份额趋稳），光伏 +2.43%（行业 −35%，逆势跑赢，份额实为提升） 中性：光伏份额小幅提升；乐观：光伏份额显著提升 组件出货量 vs 行业产量

层 1 结论：光伏板块在行业产量 −35.1% 的背景下收入 +2.43%，说明份额在提升（成本曲线位置优于尾部产能），这是被市场忽略的正面信号；但份额提升≠盈利，因为 4.02% 的毛利率意味着"增量不增利"。

层 2 扩展业务：主业迁移空间（新易盛范式检验）

五要素 评估
① 能力可迁移性 低。家电零部件的核心能力是"金属冲压/触点/注塑 + 家电客户认证"；PCB 刀具设备属于精密刀具 + 数控设备 + PCB 钻孔工艺，技术不同源。属跨界并购，非能力复用。
② 新 TAM 弹性 高。AI 服务器/高速交换机推动高多层板、HDI 板需求，PCB 钻孔工序的刀具 + 耗材属高消耗、高复购领域，赛道景气度显著高于家电与光伏。
③ 切入时点与卡位 中。通过并购直接获得标的的客户与工艺卡位，但非自研先发；标的规模（三年承诺 2.1 亿）对应 8.4 亿元估值约 12x 2028 年承诺利润，定价不算便宜。
④ 客户认证门槛 高（双刃剑）。PCB 刀具/耗材需通过下游 PCB 大厂的供应商认证，认证周期长 → 一旦进入即形成粘性；但作为新进入者，认证进度是慢变量。
⑤ 信号验证 未过。截至 2026-10-01：未签正式交易协议、未见标的经审计财务数据、未见客户订单公告。仅有公告与业绩承诺。

层 2 结论：迁移空间作为"中期期权"，未过验证点，不计入中性情景。一旦通过（正式协议 + 股东大会 + 监管注册 + 并表），则 2027 起可贡献 0.75 亿元量级的扣非净利，是公司利润体量的一次阶梯式跳升。

层 3 风险折扣：证伪信号
- 交易失败（最直接）：未在 10 交易日窗口内披露方案 → 复牌并终止筹划（公告已明确此风险）；
- 监管否决：发行股份购买资产需交易所审核 + 证监会注册，跨界并购审核不确定性高；
- 承诺变脸：标的 2026 年扣非 <5500 万元；
- 家电份额流失：板块收入连续两年负增长且毛利率跌破 28%；
- 光伏持续失血：强标落地后组件毛利率仍 <5%。
- 命中任一 → 中性情景下修，乐观情景剔除对应增量。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1 资产质量折扣（PB 与破净）
- 星帅尔 PB 2.75x，非破净；归母净资产 23.56 亿元，2026E 归母 1.80 亿元 → ROE 约 7.6%（2025 年报加权 ROE 9.36%），属正常偏低。
- 不存在"单凭 PB<1 推大空间"的问题；相反，PB 2.75x 对 7.6% 的 ROE 并不便宜（隐含市场对并购与光伏修复的溢价）。
- 结论：估值锚必须落在分板块盈利上，不能用净资产。

校正 2 周期位置校正（光伏为强周期，必须归一化）
- 星帅尔的光伏板块是典型强周期资产：2026H1 组件毛利率仅 4.02%，处于周期底部。
- 禁止用：① 单年好年景（如 2023 年组件高盈利）；② 近三年均值（跨越周期顶底，会高估）；③ "拐点年化"（把刚出现的单季修复直接年化）。
- 本报告采用行业正常单位盈利法：组件稳态单 W 净利取 0.02–0.04 元/W（历史中枢偏下沿，保守），对应 2029E 光伏板块归母 0.25–0.50 亿元。
- 当前周期位置：底部（出清中）。按"底部不过度悲观"原则，中性未剔除光伏的修复弹性，但修复幅度给得保守（毛利率 8–12%，而非回到 20%+）。

校正 3 杠杆下行情景（高负债必附负面情景）
- 资产负债率 40.33%（2026H1）、2025 年报有息负债率 23.88%、有息负债 3.26 亿元——杠杆不高。
- 但并购本身会改变杠杆结构：8.4 亿元对价若以"股份 + 现金"形式支付，现金部分与配套融资会增加债务/股本压力。
- 负面情景：若光伏需求继续下行 + 铜价上行，家电与光伏双承压，叠加并购现金支付 → 归母可能降至 1.90 亿元，对应目标价 9.71 元（−47.2%）。该情景下中性空间已为负，故结论不标"大空间/重点关注"。

期权纪律（本报告关键）
- PCB 刀具并购：截至分析日仅停牌筹划、未签正式协议、无审计数据、无客户订单公告 → 未过验证点，不计入中性 2.70 亿元，仅在乐观情景（3.65 亿元）计入 0.95 亿元。
- 若把未落地的并购计入中性，等于把"可能"当"已发生"——按 RULES 明确禁止。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（且已含并购预期）。现价 18.39 元对应 2026E PE 36.0x、PB 2.75x；中性远期（2029E，不含并购）目标价 15.33 元，空间 −16.6%。停牌前的涨停正是市场在为并购定价。

安全边际：
- 中性远期 15.33 元 → 空间 −16.6%，无安全边际；
- 悲观情景 9.71 元 → 下行 −47.2%；乐观情景 26.95 元 → +46.5%（需并购落地并超承诺，属未过验证点的期权）；
- 下行保护：PB 2.75x + ROE 7.6% + 停牌前涨停已透支一部分预期，不构成硬支撑。

介入条件：
1. 复牌后先观察。停牌复牌若因方案细则（发行价、配套融资比例、标的审计净利）出现回落，参照点重置；
2. 加仓信号：① 正式交易协议签署 + 标的经审计 2025/2026 年扣非净利达标；② 股东大会通过 + 交易所/证监会审核注册完成；③ 光伏组件毛利率连续两个季度站上 8%；④ 家电板块收入恢复正增长；
3. 观察指标：并购完成后合并报表中"PCB 刀具耗材"收入占比——若一年内占比未达 10%，说明迁移未兑现，须下调。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 并购交易终止（首要且最直接）：公告已明确"若未在 10 个交易日内披露方案，最晚 2026-10-14 复牌并终止"；跨界并购还需交易所审核 + 证监会注册，环节多、不确定高。交易一旦终止，股价可能回吐停牌前的涨停；
2. 光伏板块持续失血：51.36% 的收入仅 4.02% 毛利率，行业出清若慢于预期，公司将持续"增收不增利"；
3. 家电基本盘收入转负：2026H1 −0.85%，若以旧换新退坡则利润基本盘受损；
4. 商誉风险：并购形成大额商誉，若标的承诺不达标 → 减值冲击利润。

第五步进阶：上行想象力情景（四类）

  • 类型 A 行业调整剩者红利：光伏在三项强制性国标 + 产能调控下，20–30% 低效产能将退出。星帅尔光伏板块在 2026H1 行业产量 −35.1% 时收入仍 +2.43%，说明其产能位于成本曲线左侧（剩者）；出清完成后组件价格修复，剩者单位盈利中枢抬升。验证点：强标正式实施、行业协会月度价格与集中度数据、公司组件毛利率连续两季 >8%；证伪：价格未修复、公司份额回落。
  • 类型 B 政策反转期权：家电以旧换新延续 + 新能源车政策，托底压缩机与电机需求。反转信号：补贴扩容发文、公司家电板块收入转正。重估弹性：家电板块净利率每提升 2pct，对应约 +0.22 亿元归母（约 +8% 中性净利）。未过验证点，仅作机会情景。
  • 类型 C 市场错杀修复：公司因光伏拖累导致归母同比 −17.6% 而被市场按"光伏亏损股"打折，但其 45.57% 收入来自毛利率 32.47% 的家电零部件，ROE 仍有 7.6%——存在认知错位。错杀证据：剔除光伏后家电板块可支撑约 2.0 亿元/年的归母，对应存量业务 PE 约 32x 并不极端（但也不便宜）；修复触发点：光伏板块毛利率转正上行、并购落地、市场重新按"零部件 + PCB"重估。弹性：中性 + 悲观之间，修复空间约 +20–40%。
  • 类型 D 技术突破 / 技术代际跃迁期权（本股最大的上行来源）：通过并购从 0 到 1 切入 AI 服务器 PCB 刀具设备与耗材这一全新赛道（公司原不在该赛道），若成功将重构成长曲线。三要素共振检验：
  • ① 政策驱动技术路线：AI 算力/数据中心政策强驱动 PCB 高多层化 → 部分满足；
  • ② 行业趋势向该技术收敛：AI 服务器推动高多层板、HDI 需求，PCB 钻孔耗材需求放大 → 满足；
  • ③ 公司技术投产落地：不满足——尚未签正式协议、无审计数据、无客户定点/大额订单公告、无量产良率验证。
  • 硬验证点（防画饼）：正式交易协议签署 + 标的 2026/2027 扣非达标 + 合并报表中 PCB 收入占比跳升。三者缺一则只作机会情景，不计入中性锚。
  • 证伪信号：交易终止、承诺变脸、PCB 收入占比一年内未达 10%。
  • 弹性：若全部兑现，2029E 归母可达 3.65 亿元（中性 2.70 亿 + 0.95 亿），对应 +46.5% 空间。

⛔ 纪律自查：四类情景全部只进乐观/机会栏，不进中性锚；每类均配验证点与证伪信号。什么条件出现才上调至"重点关注"：① 并购完成并表且 2027 扣非 ≥7500 万元；② 光伏组件毛利率连续两季 ≥8%；③ 家电板块收入恢复正增长；④ 中性远期空间修复至 >+50%。四条同时满足方可上调。

结论：暂不介入

判定理由：公司基本盘不差（制冷压缩机零部件全球龙头、毛利率 32.47%、ROE 7.6%、经营现金流 +33.38%），光伏板块在行业下行 35% 时逆势抢份额，AI-PCB 并购则提供了高弹性期权。但：① 现价（含停牌前涨停）已把一项尚未签署正式协议的 8.4 亿元跨界并购提前定价；② 剔除并购后，中性远期空间为 −16.6%，无安全边际；③ 悲观情景 −47.2%，交易终止风险直接可见。按 RULES 五级排序，"基本面尚可但估值已高 / 不确定性大"对应 暂不介入（远期空间 −16.6% ≤ +50%，符合一致性规则）。
核心跟踪点：2026-10-14 前的交易方案披露（发行价 / 配套融资 / 标的审计净利）+ 光伏组件毛利率修复斜率 + 家电板块收入拐点。
