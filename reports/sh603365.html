（3）产业链传导

上游：棉花（长绒棉/细绒棉）、羽绒、化纤（涤纶）、功能材料（生物基纤维、微胶囊缓释材料）。公司采用"成本 + 加工费"定价，成本传导能力中等。
下游：C 端消费者 + 电商平台。电商渠道占比 58.6%，平台佣金与流量投放是主要"渠道税"。
议价权：中等。对上游——家纺行业原材料完全市场化，公司是价格接受者，靠"前置采购 + 研判"对冲而非定价权；对下游——品牌力支撑毛利率从 41.4%（2024）提至 44.95%（2025）再到 46.28%（2026H1），说明对 C 端有一定提价能力，但被销售费用率上升（28.00%，+3.56pct）部分抵消。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）：家纺属"可选消费 + 品牌定价"，传导率估 0.5–0.6。
- 依据：①2025 年营业成本同比仅 +1.44%，而营收 +7.99%，说明成本端压力下公司通过提价 + 结构升级把大部分成本上涨转嫁给了消费者；②但传导并非免费——销售费用率同期 +3.56pct 至 28.00%，"转嫁成本"的代价是营销投放加码，真实净传导率需扣掉这部分。
- 定量：上游原料上涨 10% → 营业成本上涨约 5%（原料占成本约 50%） → 若无提价，毛利率承压约 2.75pct；按 0.55 传导率，实际毛利率承压约 1.24pct，剩余由营销与结构消化。

因子2 毛利结构再平衡（分业务线，禁单一综合毛利率）

业务线 2025 毛利率 原料敏感权重（棉花/化纤/羽绒） 2026H1 边际变化
电商（58.6%） 47.36%（+4.40pct） 中（套件用棉高、被芯用羽绒/化纤高） 大单品占比提升 → 继续上行
加盟（28.4%） 39.78%（+2.39pct） 高（中低价位套件为主，棉花权重最大） 产品结构下沉，弹性最弱
直营（6.4%） 58.22%（+5.36pct） 低（高毛利形象店，原料占比小） 关店提效，毛利最高
被芯（48.3%） +4.12pct 羽绒 + 化纤敏感（2025 羽绒成本涨约 20%） 泡芙鹅绒被放量，羽绒敏感权重上升
枕芯（9.4%） +4.94pct 化纤/记忆棉敏感（棉花权重低） 增速最高（+34.92%），摊薄棉花敏感

结论：羽绒涨价（2025 约 +20%）主要冲击被芯线，但被芯毛利率反而 +4.12pct，说明提价 + 大单品组合成功对冲；长绒棉降价 15% 主要利好套件线（加盟渠道），但套件收入仅 +1.51%，说明降价红利没有转化为销量——这是加盟渠道疲软的真实信号。综合毛利率 46.28% 掩盖了"被芯强、套件弱、加盟弱"的结构迁移，估值必须分渠道拆分。
验证点：① 半年报/年报分品类毛利率；② 羽绒与长绒棉现货报价；③ 电商渠道占比与毛利率。
证伪信号：套件品类收入连续两季负增长 + 加盟毛利率跌破 38%，说明大单品外溢效应失败。

因子3 库存与采购节奏（timing）
- 2026Q1 末存货 10.66 亿元（同比 −1.34%），存货周转天数 177 天（同比 −4 天）；2026H1 营业成本同比 −1.57%——公司明确披露"加强上游原材料价格走势研判、前置采购"。
- 判断：2025 年长绒棉降价 15%，公司若在低位补库，则 2026 年毛利率提升中有一部分是"低价库存收益"而非真实盈利改善。2026 年棉价重新上行（3128B 现货从 1 月底 16183 元/吨升至 4 月中旬 16977 元/吨，一季度皮棉均价 15602 元/吨、同比 +9.48%），低价库存红利将在 2026H2–2027 逐步消退。
- 定量折扣：假设低价库存贡献 H1 毛利率提升中的 0.6–0.9pct，则"真实结构性毛利率改善"约为 1.5–1.8pct。
- 验证点：存货周转天数与存货绝对额；棉花 3128B 现货价；公司采购策略披露。证伪信号：存货周转天数回升至 185 天以上 + 毛利率环比回落，说明库存红利耗尽且真实盈利未改善。

因子4 政策/市场锚点（原料成本驱动变量）
- 市场层：全球棉花 2026/27 年度 USDA 预测产量 2526.6 万吨、消费 2649.5 万吨，库消比降至六年低位；新疆棉花目标价格 18600 元/吨，郑棉 15900 元/吨附近深度贴水 → 棉价下方有政策底，上方有天气升水（NOAA 预判厄尔尼诺 6–8 月形成概率 92%）。
- 政策层：①国储轮出传闻——若落地将压制棉价，利好公司成本端；②新疆目标价格补贴延续——稳定棉农种植，避免供应大幅波动；③以旧换新补贴（15%、封顶 2000 元）——这是需求侧变量，但对公司而言等效于"降价促销不用自己出钱"，属于"补贴替代毛利"的正向因子。
- 情景：中性——棉价 16000–17500 元/吨区间震荡，公司毛利率维持 45.5%–46.5%；乐观——国储轮出 + 厄尔尼诺未兑现，棉价回落至 15000 元/吨，毛利率上看 47.5%；悲观——天气炒作 + 印度零关税抢购，棉价冲 19000 元/吨，若公司无法提价，毛利率回落至 44%。
- 验证点：郑棉主力合约、中国棉花价格指数 3128B、国储轮出公告、以旧换新品类清单调整公告。
- 证伪信号：棉价单季涨幅超 15% 且公司未发提价公告 → 毛利率破 44%。

层2 扩展业务：主业迁移空间
- 能力可迁移性：从"家纺制造"迁移到"睡眠解决方案"，技术同源（纤维/填充/人体工学），迁移成本低——已落地产品为人体工学枕、闪睡被。
- 新 TAM 弹性：睡眠经济（助眠产品）市场大于传统家纺替换市场，且功能性溢价更高。
- 切入时点与卡位：早期。亚朵已验证"单品突破—品类扩张—品牌溢价"路径，公司跟进时点不晚，但尚未形成品牌独占心智。
- 客户认证门槛：C 端无认证门槛，这既是优势（无阻力）也是劣势（无护城河）。
- 信号验证：① 功能性新品营收占比跳升；② 毛利率持续高于行业 5pct 以上；③ 单品年销售额突破 3 亿。
- 结论：迁移空间仅作中期期权，不计入中性情景。当前仅"枕芯高增"这一个弱验证点。

层3 风险折扣：证伪信号
1. 大单品增速回落至 10% 以下 → 抽掉收入增长主引擎；
2. 销售费用率继续上行至 30% 以上而毛利率不再提升 → 说明"用营销买增长"，净利率将被侵蚀；
3. 套件品类连续两季负增长 → 占 32.7% 的基本盘失守；
4. 加盟渠道毛利率跌破 38% → 下沉市场打价格战。

第四步：估值锚定（自下而上，非增速外推）

方法说明：不用历史增速外推。按电商 / 加盟 / 直营 / 其他四条线分别以"渠道规模 × 渠道净利率"自下而上测算 2029E 净利，并用行业规模 × 份额变量做交叉校验。

总股本：约 2.625 亿股

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正1 资产质量折扣（破净说明）：本股 PB 1.38x，不破净，不适用破净折扣。资产结构极轻——2025 年末固定资产仅 4.07 亿、总资产 40.21 亿，货币资金 8.74 亿、存货 9.99 亿，无商誉、无有息负债压力（短期借款 0.50 亿、长期借款 0.07 亿）。资产质量干净，无"净资产虚高"问题。

校正2 周期位置校正：家纺属弱周期可选消费，非强周期股。当前位置判断：行业处于成熟期底部偏右侧——2026H1 限额以上针纺织品零售 +6.7%、电商渠道 34.4%，需求端已过 2022–2024 低谷。中性净利 4.97 亿采用"份额 × 行业规模"结构性推导，未使用任何单年好年景或近三年均值外推，周期位置标注为底部回升初期。

校正3 杠杆下行情景：资产负债率 22.11%（2025 年末）→ 18.54%（2026H1 末，持续优化），有息负债 0.908 亿（2025）、有息负债率 10.21%，2026H1 总资产 37.91 亿。无杠杆反噬风险，不必附利率上行负面情景。这是本股相对多数消费股的核心安全垫。

期权纪律：海外/跨境电商、睡眠经济迁移（层2）未过验证点，不计入中性净利，仅放入乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：明显偏低。PE(TTM) 10.22x、PB 1.38x、2025 年静态股息率 6.1%、2026E PE 仅 9.9x。市场给的是一个"零增长、无弹性"的成熟消费股定价，但公司扣非增速 22.15%、毛利率创阶段新高、ROE 12%–13%，定价与基本面明显错配。

安全边际：
- 中性远期 25.40 元 → +56.9%，超过"重点关注"的 >50% 门槛；
- 悲观情景 16.00 元 → 仅 −1.2%，下行几乎被高股息与低 PB 封死，风险收益高度不对称（上行 57% vs 下行 1%）；
- 乐观情景 33.10 元 → +104.4%；
- 硬支撑：每股净资产约 11.93 元（2025），PB 1.0x 对应 11.93 元；6% 股息率在 10 年期国债收益率低位环境下提供极强底部。

介入条件：
1. 现价 16.19 元即可分批建仓（2026E PE 9.9x、股息率 6%+）；
2. 加仓信号：① 2026 年报电商收入增速 ≥12% 且毛利率 ≥47%；② 人体工学枕 / 雪糕被合计销售额突破 3 亿；③ 套件品类恢复正增长（说明大单品外溢）；④ 以旧换新政策明确 2027 年延续；
3. 观察指标：季度分渠道毛利率、存货周转天数、销售费用率是否见顶。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 收入增速掉到零以下（首要）：2026H1 营收仅 +2.83%、Q2 仅 +0.12%。家纺是存量替换市场，若大单品红利消退而新单品未接力，收入停滞会让"低 PE"变成"价值陷阱"；
2. 销售费用率失控：2025 年销售费用率已达 28.00%（+3.56pct），若继续上行至 30%+ 而毛利率不再提升，净利率将被侵蚀；
3. 低价库存红利消退：2026 年棉价重新上行（3128B 从 16183 → 16977 元/吨），H1 成本 −1.57% 的红利不可持续，2027 年毛利率可能回落；
4. Q2 归母 −12.32% 的警示：虽扣非 +38.29%，但归母与扣非背离说明非经常性项目波动加大，需持续跟踪。

第五步进阶：上行想象力情景（四类，认真建模上行侧）

类型A 行业调整剩者红利：家纺 CR5 仅 3.7%，属极度分散行业，白牌与区域品牌在"流量见顶 + 合规成本上升 + 平台规则变化"下加速出清。若 CR5 在 2029 年前提升至 5%–6%，头部四家（罗莱/水星/富安娜/梦洁）份额平均提升约 0.5pct，公司收入可额外增厚 15–19 亿。验证点：行业 CR5 数据、白牌商家数量、平台类目集中度。证伪信号：CR5 停滞或下降、白牌通过补贴继续扩张。

类型B 政策反转/延续期权：以旧换新品类清单若 2027 年继续扩围（家纺从"地方自主"升格为"全国统一品类"），等效于全行业获得 15% 的价格补贴能力，公司作为线上占比最高的家纺品牌弹性最大（线上补贴直达、履约链路最短）。重估弹性：若政策延续带动收入增速从 +3% 提升至 +8%，2029E 净利可上修至 5.5 亿，对应 PE 15x → 82.5 亿 → 31.4 元（+94%）。验证点：2027 年以旧换新品类清单、商务部表态。证伪信号：2026 年底政策到期不再延续（上海细则明确至 2026-12-31，这是明确的时间窗风险）。

类型C 市场错杀修复：现价对应 2026E PE 9.9x、股息率 6.1%、PB 1.38x，而扣非增速 22%、ROE 12%–13%。错杀证据：① 估值处于历史低分位；② 相对家纺同业（罗莱/富安娜）存在折价；③ 基本面未恶化反而改善（毛利率创新高）。修复触发点：市场风格从高估值成长切向高股息价值、中报后盈利质量被重新定价。证伪信号：扣非增速转负、毛利率见顶回落。

类型D 技术突破/代际跃迁期权：公司自研方向为"功能纤维 + 温湿调控 + 抗菌防敏 + 人体工学 + 助眠科技"，若某一代际产品（如具备真实临床背书的助眠系统）实现从"家纺"到"健康消费品"的跃迁，估值体系可从消费制造（13x）切换至健康消费（20x+）。硬验证点：① 中试/量产良率达标；② 拿到权威机构认证或大额 B 端采购；③ 单价与毛利率显著优于旧品类。当前三条均未满足 → 仅作机会情景，不计入中性锚。证伪信号：竞品率先推出同代际产品、公司研发投入停滞（2026H1 研发费用 0.209 亿，仅占营收 1.06%，投入强度偏弱，是该项期权的最大短板）。

上调/下调纪律：
- 维持"重点关注"的条件已满足（远期 +56.9% > 50%）；
- 若出现以下情形则下调至"纳入观察"：2026 年报营收增速转负 + 销售费用率突破 30%；或棉价单季涨超 15% 而公司未提价、毛利率跌破 44%；
- 上行再加码条件：2027 年以旧换新明确延续 + 大单品合计销售额破 3 亿 + 电商毛利率站上 48%，则乐观情景（33.10 元）概率显著上升。

结论：重点关注

理由：① 估值低（PE 10.2x、PB 1.38x）+ 股息率高（6.1%），下行被硬资产与分红封死（悲观情景仅 −1.2%）；② 盈利质量在改善而非恶化——扣非 +22.15%、毛利率 46.28% 创阶段新高、营业成本绝对值下降；③ 远期空间 +56.9%，跨过重点关注门槛；④ 无杠杆、无商誉、资产干净，属"低风险中等赔率"里的优质结构。
核心跟踪点：季度营收增速是否守住正增长 + 销售费用率是否见顶 + 2027 年以旧换新政策是否延续。
