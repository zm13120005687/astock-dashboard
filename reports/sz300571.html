上游：GPU/服务器组件（受英伟达/国产芯片供给与价格影响），采购资金占用大；下游：运营商、云服务商按月/季付费，回款较稳但账期长。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）
    算力服务成本主要为 GPU 服务器折旧 + 电费 + 资金利息，属"重资产运营"模式，传导率约 0.3–0.5（客户按月付费，成本端 GPU 价格/电费上涨难实时转嫁）。验证点：2026H1 净利率 −1.51%，成本传导弱致盈利承压。证伪信号：若服务费单价下行 + GPU 折旧刚性，净利率持续为负。

  • 因子2 毛利结构再平衡
    分业务：算力服务（高毛利但重折旧）、通信设备（中毛利）、运营商权益（稳定）。2026H1 算力占比升至 38.56% 但综合毛利率反降 2.77pct，说明算力业务财务费用（折旧+利息）侵蚀了毛利，单一综合毛利率掩盖了"毛利高但净利低"的结构。验证点：分业务毛利率与财务费用率；证伪：算力毛利率持续低于通信业务。

  • 因子3 库存与采购节奏（timing）
    算力设备为项目制采购，无存货囤积收益；资本开支前置（2025 购建固定资产 14.19 亿 +960%）致财务费用刚性，属"投入期阵痛"非库存收益。验证点：在建工程转固节奏与折旧压力；证伪：定增补血滞后致财务费用继续攀升。

  • 因子4 政策/市场锚点（原料成本驱动变量）
    市场层：GPU 供给（英伟达/国产）与电价决定算力单位成本；政策层：国产算力补贴、算力券降低采购成本，绿色算力/算电协同抬高服务溢价。情景：国产芯片放量降本（乐观）；芯片限供+电价涨（悲观）。验证点：国产智能算力中心建设进度、定增落地；证伪：定增失败、芯片成本不降。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量

  • 供给侧：算力服务商资质壁垒高，公司处第一梯队；2. 需求侧：三大运营商+科技公司订单集中，前五大客户粘性高；3. 技术代际：国产算力芯片适配先发；4. 成本曲线：规模交付摊薄单位成本；5. 份额二阶导数：算力收入同比 +195% 加速渗透。三档：保守（订单确认 60%）/ 中性（80%）/ 乐观（100%+新单）。验证点：下季度算力收入确认额。

  • 层2 扩展业务：主业迁移空间（新易盛范式）
    能力可迁移性：通信设备 → 算力服务（同源服务器/网络）；新 TAM：AI 算力数倍于传统通信；切入卡位：早中期（2023 年切入）；客户认证：运营商集采壁垒（护城河）；信号验证：47 亿订单 + 定增自建算力中心。部分过验证点（订单落地），可计入中性偏乐观，但财务兑现仍待确认。

  • 层3 风险折扣：证伪信号
    订单违约/坏账、定增失败致财务费用失控、GPU 供给中断、回款恶化。命中则下调。

第四步：估值锚定（自下而上，非增速外推）

亏损股估值方法：正常化净利润法（稳态营收 → 正常化净利率 → 正常化净利 × 远期 PE）。
总股本：约 1.40 亿股（按 2026H1 EPS −0.07 元倒推：949.66 万 / 0.07 ≈ 1.36 亿股，考虑定增摊薄取 1.40 亿）。

亏损股三问

  1. 为什么亏：2022 年盈利 1.22 亿后连续三年亏损（2023 −3878 万、2024 −1.16 亿、2025 −2.00 亿、2026H1 −950 万）。主因：①算力业务资本开支暴增（2025 购建固定资产 14.19 亿，+960%）致财务费用飙升；②运营商投资节奏放缓、通信收入受限；③新签订单未完全确认收入；④2026H1 财务费用继续上升。主业未重大恶化，持续经营能力无重大风险。

  2. 靠什么扭亏，触发时点：①47 亿算力订单按月/季确认收入，规模效应摊薄单位成本；②定增 10 亿（7 亿算力中心）补血降低财务费用；③资本开支高峰过去后财务费用回落。触发时点：2026 全年或微亏/微利，2027 年有望扭亏（2026H1 仅亏 950 万，较 2025 全年 −2 亿大幅收窄）。

  3. 亏得起吗：总资产 52.80 亿、净资产 12.20 亿，但经营现金流 −2938 万（上年同期 +1.86 亿，恶化），依赖筹资（定增+借款）。账面资产规模大（算力设备+应收），融资平台尚在（定增推进中）。结论：短期可承受，但现金流质量差，需关注回款与定增进度。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣：平治非重资产破净型（PB 3.5），估值为订单预期驱动；但总资产 52.8 亿中算力设备/应收占比高，需关注资产减值风险。
  • 校正2 周期位置校正：算力基建处上行周期早期，但公司处"投入兑现期"，中性净利取保守正常化值（47 亿订单按 80% 确认），未线性外推。
  • 校正3 杠杆下行情景：定增前依赖借款，若定增失败+订单回款慢，财务费用可吞噬全部毛利、净利转负，空间 −75%，故不得标大空间。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（已充分定价 47 亿订单）。现价 28.61 元对应中性远期 −9.1%，安全边际为负。

安全边际：
- 中性远期 26.00 元 → 空间 −9.1%，不达"重点关注"门槛
- 悲观情景 7.14 元 → 下行 −75.0%，风险极大
- 乐观情景 57.14 元 → +99.6%，但需订单加速+定增落地

介入条件：
1. 不追高。现价已反映订单预期，等回落至 18 元以下（对应 PS<3x、PB<1.5）
2. 加仓信号：① 定增获批落地；② 单季归母转正（扭亏确认）；③ 算力收入确认加速（季营收回升至 4 亿+）
3. 观察指标：经营现金流转正、财务费用率回落、47 亿订单确认进度

最大风险：
1. 订单交付/回款风险（首要）：47 亿订单按月确认、节奏不均，Q2 营收环比 −53.63% 警示确认波动
2. 定增失败致财务费用的杠杆反噬：资本开支前置，若补血不及预期，亏损扩大
3. GPU 供给与电价：上游芯片/电力成本刚性，传导弱
4. 现金流恶化：经营现金流由正转负，资金链压力

结论：暂不介入（中性远期空间为负，当前价格已透支订单预期；近三年连续亏损、现金流质量差，需等更低价格或扭亏确认）

公司卡位算力服务优质赛道、47 亿订单储备真实、亏损大幅收窄，2027 扭亏可期，弹性可观（乐观 +99.6%）；但现价 28.61 元已充分定价，中性空间 −9.1%、悲观 −75%，风险收益不对称。核心跟踪点：定增落地 + 单季扭亏 + 订单确认加速。跌破 18 元（安全边际重现）再上修至纳入观察。
