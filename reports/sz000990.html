第一步：公司是干什么的？

一句话定位：清华背景的"一体两翼"企业——以南京诚志煤制烯烃（MTO）清洁能源为核心（占收 77.5%），以诚志永华液晶材料 + 诚志华青 UHMWPE 为新材料第二曲线，以江西诚志生物（D-核糖）为生命医疗。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：清洁能源（烯烃）传导率 ≈ 0.5（产品价格随油 / 煤价波动，部分顺价）；液晶 ≈ 0.9（认证壁垒可顺价）。验证点：产品价格 vs 煤炭 / 原油；证伪：烯烃价差收窄致毛利率破 10%。
  • 因子2 毛利结构再平衡：清洁能源（占 77%）毛利率随周期波动，新材料（15.6%）毛利率高且升。综合毛利改善靠"低毛利能源稳 + 高毛利材料升"。验证点：两板块毛利率。
  • 因子3 库存与采购节奏：煤炭低价囤货曾带来库存收益（2026H1 价差扩大部分源于低价原料）；需区分当期 vs 远期。验证点：煤炭库存 / 采购价。
  • 因子4 政策 / 市场锚点：原油价格（烯烃成本锚）、煤炭价格（成本优势）、出口管制（液晶上游材料）。情景：油价上行 + 煤价低位→价差扩；验证点：油价、煤炭指数。

  • 份额加速度：TFT 销量 +30% 加速。

第四步进阶·重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣（破净原因）：总资产 276.27 亿、归母净资产 180.20 亿，市值 107.86 亿 < 净资产 → 破净。原因：① 重资产（MTO 装置、液晶产线）在 2025 化工周期底部市场给资产质量折价；② 公司盈利历史不稳（2022–2025 归母 5092 万→1.77 亿→2.31 亿→−7814 万）；③ 非金融资产多为专用化工装置，清算价值 < 账面。非"金融资产未重估型"破净，破净部分含公允定价成分，但 2026 反转改善。
  • 校正2 周期位置校正：当前处于周期上行 / 修复阶段（2025 亏损→2026H1 盈利）。中性净利取周期归一化 7.0 亿（禁用 2026Q2 单季年化、禁用 2025 亏损年），已标注当前周期位置为"从底部修复"。
  • 校正3 杠杆下行情景：资产负债率约 35%（总资产 276 / 净资产 180），不算高，但重资产经营杠杆高。若烯烃价差回落至 2025 低位，净利润可缩至 4 亿甚至微利，悲观情景空间 −55.5%，不得标大空间，故中性结论不上调重点关注。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低（破净修复窗口）。现价 6.34 元 ≈ 0.6x PB，贴近资产净值，下行有净资产托底；2026E PE 19.6x 合理。

安全边际：中性远期 6.17 元 → 空间 −2.7%（近乎持平）；但 PB 0.60 提供下行保护（悲观 2.82 元 −55.5%）；乐观破净修复 +9.53 元 +50.3%。风险收益不对称偏向有利（下行有限、上行有修复弹性）。

介入条件：现价即具破净安全边际，可逢低布局；加仓信号：① 化工景气持续（烯烃价差维持）；② 液晶 / UHMWPE 放量兑现；③ PB 修复至 0.8x 以上。更优买点：回落至 5.5 元以下（PB < 0.55）。

最大风险：
1. 烯烃价差回落（原油跌 / 煤涨）致清洁能源净利缩水（首要）；
2. 液晶国产替代价格战；
3. UHMWPE 客户导入不及预期；
4. 重资产折旧 / 财务杠杆在下行周期放大。

结论：纳入观察

逻辑正确（扭亏反转 + 破净修复 + 国产替代），但中性远期空间仅 −2.7% 未达 >50% 门槛，且周期股下行情景可达 −55.5%，故不上调重点关注。破净提供安全边际，适合逢低观察布局。

第五步进阶·上行想象力情景（四类）

  • 类型A 行业调整剩者红利：化工老旧装置出清利好合规煤制烯烃龙头份额。验证点：落后产能退出；弹性：价差 + 份额。
  • 类型B 政策反转期权：显示材料国产替代政策加码 / 新材料补贴。验证点：政策发文；计入机会情景。
  • 类型C 市场错杀修复：不适用（当前为破净折价而非错杀，修复方向向上）。
  • 类型D 技术突破 / 代际跃迁期权：诚志永华从 TFT 向 OLED / 光刻胶材料迭代，硬验证点（量产良率 + 客户定点 + 成本优于旧路线）已部分满足（OLED 翻倍供货），可部分计入中期。验证点：新产线大客户长单。
  • 上调至重点关注的条件：PB 修复至 0.9x 以上 + 2027E 净利确定性 > 8 亿 + 烯烃价差维持。
