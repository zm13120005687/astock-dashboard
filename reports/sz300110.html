第一步：公司是干什么的？

一句话定位：国有控股的大输液 + 肾科特色药企，围绕肾科、呼吸科、精麻科三大主线，形成"原料药—制剂—包材"一体化布局，核心产品是腹膜透析液（尿毒症透析，国产品牌市占率第一）和血液滤过置换液。

境内外收入占比：以内销为主，产品与包材已进入欧洲、亚洲、非洲、中东多国市场（占比小）。

结构要点：基础输液（集采降价重灾区，毛利率 −10.80pct）收缩，肾科（腹透液 + 血滤液）是增长引擎，驱动产品结构升级。

（3）产业链传导

上游：原料药、药用包材（非 PVC 软袋膜材）——公司"原料—制剂—包材"一体化，部分对冲成本。

下游：医院、透析中心、集采中标市场。集采降价 → 存量品种毛利承压，但中标带来量增。

议价权：弱偏中。基础输液同质化、集采议价力弱（毛利率 −10.80pct）；腹透液国产品牌第一具备一定壁垒，但集采下仍承压（−2.07pct）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：原料药/包材成本相对刚性，但集采降价下公司对下游传导能力弱（传导率≈0.2），毛利率下行主要来自集采降价而非原料涨价——基础输液毛利率 −10.80pct 即为印证。
  • 因子2 毛利结构再平衡：分板块毛利率差异大——治疗制剂 41.05%（高）、腹透液 35.98%、基础输液 28.25%（低且快速下滑）、医疗器械 23.23%（+12.11pct）。结构升级（肾科占比提升、基础输液收缩）对冲集采降价，禁单一综合毛利率。
  • 因子3 库存与采购节奏：药品库存周转快，无大宗囤货；真正的一次性因素是商誉/资产减值——2024 年减值 13.78 亿、2025 年减值 5.25 亿，是连续两年巨亏主因，剔除后主业是盈利的。
  • 因子4 政策/市场锚点：核心利润驱动 = 集采降价幅度（政策层） + 肾科渗透率提升（市场层）。情景假设：若后续集采续约价格趋稳、腹透/血滤放量 → 毛利结构改善；若集采继续降价 → 基础输液毛利进一步承压。验证点：集采中标价格、腹透液季度销量；证伪信号：工业毛利率跌破 30%、腹透液销量增速转负。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务 = 市场容量 × 份额变量：腹透液国内渗透率低（远低于发达国家），市场容量本身在扩容（尿毒症患者增长 + 腹透政策推广），公司在国产品牌中市占率第一，份额与市场同步扩张（二阶导数为正）。验证点：腹透液季度销量增速、国产渗透率。
  • 层2 主业迁移空间（精麻科/呼吸科/大健康）：肾科→呼吸科（多索茶碱）→精麻科（枸橼酸咖啡因、氯甲西泮立项）是同源制剂能力的横向延展，迁移成本低、认证门槛中等；大健康（VE 焕颜霜受托生产等）是第二曲线期权。未过验证点，仅作中期期权，不计入中性净利。
  • 层3 证伪信号：腹透液销量增速转负、集采再降价致毛利率跌破 30%、商誉再度减值、负债进一步攀升。

第四步：估值锚定（自下而上，非增速外推）

方法说明：华仁药业 2024/2025 连续两年巨亏（商誉/资产减值主导，一次性），2026H1 扭亏。主锚用正常化净利润法：估稳态营收 → 正常化净利率（剔除减值后的主业净利率）→ × 远期合理 PE → 目标市值 → 目标价。需同时做杠杆下行情景（负债率 65.83% 偏高）。

准亏损从严：正常化净利润法 + 三问

  • 为什么亏：2024 年 −13.68 亿、2025 年 −4.63 亿，主因商誉减值 + 资产减值（2024 年 13.78 亿、2025 年 5.25 亿），属历史并购包袱一次性出清，非主业恶化——2025 年剔除商誉减值后归母 6182 万。
  • 靠什么扭亏：历史包袱出清 + 肾科核心产品（腹透液/血滤液）放量 + 集采中标量增 + 降本增效（销售费用 −34.23%）。触发时点：2026 年已扭亏（2026H1 归母 +2854 万，连续两季盈利）。
  • 亏得起吗：需警惕——负债率高达 65.83%（短期借款 4.30 亿 + 长期借款 4.01 亿，合计 8.31 亿）、净资产仅 8.66 亿（BPS 0.73 元）、商誉仍有 2.08 亿。经营现金流 2026H1 7507 万（−55.80%）。能撑住但财务弹性弱，若主业再承压或再度减值，风险敞口较大。

总股本：11.822 亿股（现价 2.68 元对应总市值 31.68 亿）

第四步进阶：重资产/周期股估值校正三道闸

  • 校正1 资产质量折扣：PB 3.66x 非破净（是溢价而非折价），不存在"PB<1 推大空间"问题；但需警惕商誉 2.08 亿（历史减值的残留风险）与应收账款 4.56 亿的质量。
  • 校正2 周期位置校正：医药非典型周期股，但集采降价是长期趋势性压制，中性净利用"剔除减值后的正常化净利 0.55–0.85 亿"，未用单年好年景。
  • 校正3 杠杆下行情景：负债率 65.83%（短期 4.30 亿 + 长期 4.01 亿），若利率上行/需求下行，财务费用（2026H1 1926 万）侵蚀利润，悲观情景净利 0.40 亿（空间 −84.7%）已含此负面假设。转负则不得标大空间——本股中性空间本就为负，符合纪律。

第五步：综合赔率判断（买不买？）

当前价格位置：高估。现价 2.68 元对应正常化净利 PE 约 58x、PB 3.66x，高负债 + 商誉残留 + 净利率仅 5%，市场已把"减值出清 + 肾科放量"预期打满。

安全边际：
- 中性远期 1.44 元 → 空间 −46.3%
- 悲观 0.41 元 → 下行 −84.7%
- 乐观 2.42 元 → −9.7%（最乐观也不及现价）
- 下行保护：净资产 8.66 亿（BPS 0.73 元），但商誉 2.08 亿若再减值，净资产将进一步缩水

介入条件：
1. 现价不介入。需回落至 1.5 元以下（正常化净利 0.85 亿对应 PE 约 21x）才具安全边际
2. 上调信号：① 腹透液/血滤液销量持续高增（季度 +20% 以上）；② 商誉彻底出清无减值风险；③ 负债率降至 60% 以下
3. 观察指标：工业毛利率、腹透液季度销量、财务费用/商誉减值公告

最大风险（最可能破坏逻辑的因素）：
1. 高负债 + 商誉残留：负债率 65.83%、商誉 2.08 亿，若再度减值或利率上行，利润被吞噬
2. 集采持续降价：基础输液毛利率已 −10.80pct，若波及腹透液/治疗制剂，毛利结构恶化
3. 盈利质量弱：正常化净利率仅 5%，扣非半年 2545 万，抗风险能力弱
4. 估值透支：PB 3.66x、正常化 PE 58x，安全边际为负

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：大输液行业集中度提升，公司非 PVC 软袋领先，集采出清小厂后享份额。验证点：集采中标量、行业 CR 提升；证伪：集采价格战延续。
  • 类型B 政策反转期权：若集采政策边际缓和（续约价格企稳/量价挂钩优化），估值重估弹性大。验证点：后续集采续约价格企稳；证伪：集采继续大幅降价。
  • 类型C 市场错杀修复：不成立——现价 PB 3.66x 是溢价而非错杀，无"错杀证据"。
  • 类型D 技术突破期权：精麻科（氯甲西泮等麻精药品立项）、新药过评是管线期权，弹性中等，未过验证点（CDE 审评中），仅作机会情景。证伪：品种审评失败。
  • 什么条件出现才上调重点关注：腹透液/血滤液持续高增 + 商誉出清 + 负债率下降 + 股价回落至 1.5 元以下。

结论：暂不介入

公司有真实看点（腹透液国产第一 + 血滤液高增 + 历史包袱出清），2026 年连续两季盈利，但高负债（65.83%）+ 商誉残留（2.08 亿）+ 净利率仅 5% + PB 3.66x 的组合，撑不起 31.7 亿市值。中性远期空间 −46.3%，最乐观情景也低于现价，符合"暂不介入"标准。
