第一步：公司是干什么的？

一句话定位：国内白羽肉鸡产业链一体化企业，以"父母代种鸡 → 商品代鸡苗"为核心弹性业务，配套商品代肉鸡饲养屠宰与鸡肉制品加工。

第二步：行业景气度 + 政策 / 市场数据

（1）政策端（近 6–12 个月）——中性偏托底

  • 生猪 / 禽类产能调控：农业农村部持续引导畜禽产能合理区间，白羽肉鸡以市场化调节为主。
  • 饲料原料：玉米 / 豆粕价格 2026 年下行，养殖成本端改善（行业报告明确"饲料原料价格下行成为盈利修复核心支撑"）。
  • 国产种源替代：海外引种受扰，2026 年 1–5 月祖代累计更新 −20.67%，国产自繁品种占比升至 72.52%，长期利好自主可控，短期供给仍充裕。

（3）产业链传导

上游：饲料（玉米 / 豆粕）成本下行 → 养殖端成本改善；但公司核心成本是种鸡饲养与孵化，饲料占比相对可控。
下游：终端消费需求恢复偏弱（线上鸡肉制品营收 −11.75%），屠宰 / 食品加工采购积极性不高。
议价权：商品代鸡苗为高度同质化大宗、价格随行就市，公司议价权弱（价格接受者）；但鸡苗价格回升时利润弹性极大（量价齐升）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：鸡苗 / 鸡肉为农产品大宗，转嫁系数 ≈0（价格由供需决定，公司无定价权）。2026H1 雏鸡毛利率 5.25%（+4.66pct）来自价格回升而非成本传导；鸡肉制品毛利率仅 2.71%，终端需求弱致传导失效。
  • 因子2 毛利结构再平衡：
    | 业务线 | 毛利率 | 原料敏感权重 |
    |---|---|---|
    | 雏鸡（商品代鸡苗） | 5.25%（价格驱动，强弹性） | 中（饲料 + 种鸡折旧） |
    | 鸡肉制品 | 2.71%（终端弱） | 中高（鸡肉原料 + 加工） |
    | 有机肥 / 电力 | 稳定微利 | 低 |
    结构风险：雏鸡毛利刚爬出亏损线（5.25%），鸡肉制品持续孱弱，两者修复节奏分化（上游暖、下游冷）。
  • 因子3 库存与采购节奏：种鸡存栏为"活库存"，无囤货收益；鸡苗必须即时销售（不能库存），价格随行就市，无套保对冲，timing 风险全暴露。
  • 因子4 政策 / 市场锚点：① 祖代引种缺口（海外断供）→ 传导至父母代（2026Q4）→ 商品代（2027H1）供给收缩，是核心价格驱动变量；② 饲料原料价格（豆粕 / 玉米）下行托底成本；③ 消费复苏政策（促内需）影响终端。验证点：商品代鸡苗均价、祖代引种量、父母代存栏；证伪：引种恢复 + 存栏高企 + 价格回落至 2.5 元/羽以下。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：① 供给侧——公司父母代存栏规模居前，商品代鸡苗市占率约 5–8%（头部）；② 客户份额——养殖户粘性中（活禽现款交易）；③ 技术代际——种鸡繁育效率行业中等；④ 成本曲线——规模 + 自繁降本，处于行业中游偏上；⑤ 份额加速度——销量同比 +12.5%，份额小幅提升。三档：保守守住现有份额 / 中性份额微升 / 乐观引种缺口下抢份额。验证点：月度鸡苗销量与均价公告。
  • 层2 主业迁移空间（新易盛范式）：从"卖鸡苗"向"鸡肉深加工 / 食品"迁移，提升附加值。能力可迁移性中（已有屠宰加工）；新 TAM 弹性中（食品消费）；切入卡位中；认证门槛低；信号验证——深加工收入占比仍低、未跳升。→ 中期期权，不计入中性。
  • 层3 证伪信号：鸡苗均价回落至 2.5 元/羽以下、父母代存栏高企、线上鸡肉制品持续下滑。

第四步：估值锚定（自下而上，非增速外推 · 亏损股正常化净利润法）

方法：公司亏损，禁用 PE 硬套。用"正常化净利润法"：估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价。

正常化净利润推导

  1. 估稳态营收：H1 10.27 亿，年化约 20 亿（季节性，H2 略弱）；含雏鸡 ~9 亿、鸡肉制品 ~10 亿、其他 1 亿。
  2. 算正常化净利率（取保守）：
  3. 雏鸡：中性均价 3.5 元/羽、成本 2.8 元、单位净利 0.7 元 × 年销 3 亿羽 = 2.1 亿
  4. 鸡肉制品：正常净利率 3% × 10 亿 = 0.3 亿
  5. 合计正常化净利 ~2.5 亿（保守，不含深加工期权）
  6. 远期合理 PE：农业周期股，给 15x（周期底部谨慎）。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣：PB 1.63（未破净），资产以生物性资产（种鸡）、固定资产为主，清算价值尚可；无金融资产未重估溢价，估值靠经营恢复正常化盈利支撑。
  • 校正2 周期位置校正：白羽鸡处于周期底部右侧——鸡苗价格已从 2.4 元回升至 3.5 元，但供给仍充裕（父母代存栏 +9.6%），全面反转需祖代缺口传导（2027H1）。中性净利取"价格 3.5 元常态"而非"8 月 3.51 元脉冲"或"历史峰值"，避免拐点年化。
  • 校正3 杠杆下行情景：资产负债率约 45–50%（畜禽业中等），经营杠杆高；若鸡苗价回落至 2.5 元/羽，净利转负（悲观 5.73 元，−26.6%）。下行空间可控（PB 有底），不构成资不抵债。

亏损股三问

  1. 为什么亏：商品代鸡苗处于价格周期底部（虽回升但仍低），叠加鸡肉制品终端需求弱（毛利率仅 2.71%）。属"周期底部 + 需求弱"型亏损，非主业持续恶化。
  2. 靠什么扭亏 + 时点：鸡苗价格站上 3 元/羽即大幅减亏，冲击 4 元/羽关口方有望扭亏；祖代引种缺口（2026 海外 −20.67%）传导至商品代预计 2027 年上半年，中性判断 2027 年扭亏为盈。
  3. 亏得起吗：2026H1 经营现金流 +5813 万（正！主业造血改善），总资产 36 亿、归母净资产 16.75 亿，账面厚实，撑到扭亏无虞。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。现价 7.81 元对应 PB 1.63x，已部分反映鸡苗回暖预期，但较 2029 正常化盈利锚仍有空间。

安全边际：中性远期 10.74 元 → 空间 +37.5%；悲观 5.73 元（−26.6%，PB 有底）；乐观 20.6 元（+164%）。上行弹性显著大于下行。

介入条件：现价 7.81 元已进入可配置区间（中性空间 +37.5%）；加仓信号：① 商品代鸡苗均价连续站稳 3.5 元/羽；② 父母代存栏见顶回落（供给收缩验证）；③ 鸡肉制品毛利率回升至 5%+。

最大风险：① 鸡苗价格回落（祖代引种恢复 / 存栏高企）；② 终端消费持续疲软拖累鸡肉制品；③ 禽流感等疫病冲击；④ 饲料原料价格反弹。

结论：纳入观察

亏损股中质地较优者：鸡苗价格已现底部右侧、经营现金流转正、净资产厚实撑得住。中性正常化盈利锚对应 +37.5% 空间，达"纳入观察"门槛。核心跟踪鸡苗价格与祖代引种传导节奏，若 2027 扭亏确认可上修至重点关注。

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：祖代引种持续收缩（海外断供）+ 父母代去化，商品代供给缺口放大，剩者（含民和）量价齐升。验证点：祖代引种量、父母代存栏拐点；弹性见乐观 +164%。
  • 类型B 政策反转期权：促内需 / 消费复苏政策拉动鸡肉终端需求，鸡肉制品毛利率修复。列具体政策名（促消费专项行动）+ 反转信号（餐饮 / 商超补库）；未过验证点仅作机会情景。
  • 类型C 市场错杀修复：若因板块恐慌股价跌至 PB 1.0x（~4.8 元），按净资产底 + 周期修复存在修复弹性；触发点：市场企稳、鸡苗价格继续上行证实。
  • 类型D 技术突破 / 代际跃迁期权：不适用（无全新技术路线，深加工为同源延伸）。
  • 上调至重点关注的条件：鸡苗均价稳定站上 3.5 元/羽 + 2027H1 确认扭亏 + 正常化净利上修至 3 亿以上，使远期空间突破 +50%。
