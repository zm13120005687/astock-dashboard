第一步：公司是干什么的？

一句话定位：国产射频前端芯片龙头之一，主攻射频功率放大器（PA）模组与接收端模组，应用于智能手机、汽车电子、卫星通信，正从分立器件向高集成度模组 + 新兴连接（卫星/车载/Wi-Fi7）升级。

（3）产业链传导

上游：晶圆代工（SOI/GaN）、封测、滤波器件。2026 上游成本持续增长 + 汇率波动（汇兑损失）抬升成本，传导弱（fabless 议价有限）。

下游：手机品牌（强议价、压价）、车载/卫星（新兴、溢价较高）。高端模组对品牌客户有一定黏性但价格竞争仍烈。

议价权：中（国产替代窗口期有卡位，但国际巨头 Skyworks/Qorvo/博通仍主导，前端器件买方强）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：对晶圆/封测涨价传导率≈0.3（fabless 自身扛），毛利率 −3.09pct 印证；汇兑损失进一步吃利。综合转嫁系数低。
  • 因子2 毛利结构再平衡：PA 模组（占 85%，毛利承压）vs 接收端 vs 卫星/车载新兴（毛利较高但占比小）。结构向高毛利新兴迁移但体量尚小，加权综合毛利 21.45% 偏弱。
  • 因子3 库存与采购节奏：为保供应安全主动增库存备料（存货 7.67 亿），致经营现金流 −1.44 亿，属"高价接货"timing 压力，非真实盈利改善。
  • 因子4 政策/市场锚点：①出口管制（断供风险抬成本，验证点：美管制清单）；②汇率（验证点：人民币走势）；③存储芯片价格（终端需求锚，验证点：DRAM 价格）；④卫星互联网组网节奏（订单锚）。每项配情景+验证点，证伪：上游成本续涨、终端需求续弱。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：全球 RF 前端 314.6 亿美元、国产化率 22.7%（低），公司国内份额靠前。供给侧（代工产能利用率 89%）；需求侧（品牌客户认证=粘性）；技术代际（L-PAMiD 达国际主流）；成本曲线（规模+良率）。三档：保守守住 20% 国产份额 / 中性升至 28% / 乐观 35%（滤波器突破）。验证点：下季度出货量、客户公告。
  • 层2 扩展业务（主业迁移空间）：从"手机 PA"迁移至"卫星通信+车载+Wi-Fi7"全连接，能力可迁移（射频同源）、新 TAM 弹性大（卫星/车载从 0 到 1）。车载/卫星已量产属中期期权，未全面达产不计入中性。
  • 层3 证伪信号：高端模组份额流失、毛利率续破 20%、新兴业务无量产订单、滤波器整合成败 → 下调。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非重资产（fabless，轻资产），PB 2.57x 由净资产 43 亿支撑，无破净，属成长股合理。
  • 校正2 周期位置校正：半导体有周期但国产替代为结构成长，中性净利取正常化（非景气高点、非单季年化），已防外推。
  • 校正3 杠杆下行情景：资产负债率约 15%、现金充沛，无高负债下行风险；但经营现金流 −1.44 亿（备货）若需求续弱，悲观情景 −73% 已附。期权纪律：卫星/车载/Wi-Fi7 未全面达产不计入中性净利。

亏损股三问

  1. 为什么亏：存储芯片涨价→终端需求低迷+供应链成本升+汇兑损失；研发 2.17 亿（22% 营收）高企；毛利率 −3.09pct；主动备货致现金流负。
  2. 靠什么扭亏 / 时点：高端 L-PAMiD/Phase 8L 放量（单价毛利更高）+ 卫星通信芯片量产 + 车载射频导入 + Wi-Fi7/UWB 落地 → 产品结构升级提毛利、规模降费用率；触发 2027–2028 年单季扣非转正。
  3. 亏得起吗：净资产 43.35 亿、资产负债率 ~15%、现金充裕，可支撑多年研发与备货，亏得起，无退市/破产风险。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低（远期视角）。现价 25.67 对应亏损，但净资产 43 亿 + 国产替代期权支撑，远期中性 35.9 元（+39.9%）。

安全边际：中性远期 35.90 元 → 空间 +39.9%；悲观 6.90 元 → 下行 −73.1%（小概率，需需求崩）；乐观 77.50 元 → +201.9%。下行靠净资产兜底（PB 2.57x 在 fabless 不极端）。

介入条件：① 现价 22 元以下（接近资产锚）更具安全边际；② 加仓信号：单季扣非转正、毛利率回升至 25%+、L-PAMiD 占出货比提升、卫星/车载订单公告。

最大风险：① 毛利率持续承压（成本/汇率）；② 高端模组放量不及预期、国际巨头价格战；③ 研发高企短期难出利润；④ 备货致现金流压力。

结论：纳入观察

国产射频前端核心标的、净资产厚实、亏损可承受、扭亏路径清晰（高端模组+卫星/车载），远期 +40% 空间可观；但近端仍亏、毛利率未稳，需确认单季扣非转正后再上调。非"坚决回避"（明确扭亏触发点+资产兜底）。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：Skyworks/Qorvo 合并、中小厂出清，国产份额从 22.7% 跳升 → 验证点：公司份额公告；弹性 +20%。
  • B 政策反转期权：出口管制倒逼国产替代加速、大基金扶持 → 重估；验证点：国产化率突破 30%；未过验证点仅作机会情景。
  • C 市场错杀修复：若因亏损被错杀，资产 43 亿兜底 → 修复触发：毛利率企稳+扣非转正；证伪：主业续亏。
  • D 技术突破/代际跃迁：L-PAMiD 高端突破 + 卫星通信芯片从 0 到 1 量产 + 滤波器（偲百创）协同 → 硬验证点：中试良率达标+客户定点+量产成本优旧线；卫星芯片已量产（部分验证），可计入机会情景。
  • 上调至重点关注的条件：连续两季扣非转正且毛利率 ≥25%、L-PAMiD 占出货比显著提升、现价回落至 22 元以下。
