维信诺（002387）五步法分析报告

分析日期：2026-09-29 ｜ 现价 6.63 元（2026-09-29 收盘） ｜ 总市值 92.49 亿 ｜ PE(TTM) 负值（深度亏损） ｜ 总资产 480.8 亿 ｜ 总股本 13.95 亿股
行业：电子 / 光学光电子（OLED 显示面板）｜ 板块：深市主板
数据校正：队列行业标签误标"食品行业"、标"TTM 亏损"——真实主业为 OLED 显示面板厂商；2026H1 真实归母净利 −15.19 亿元（同比扩大亏损），确为深度亏损，按亏损股规则做完整五步法 + 正常化净利润法 + 三问。

第一步：公司是干什么的？

一句话定位：国产 OLED 显示面板龙头（AMOLED 小尺寸 + 中尺寸 + 穿戴），技术路线以自研 ViP 无 FMM 为核心差异化，深度绑定荣耀 / 小米 / OPPO / vivo 等头部终端。

核心产品：柔性 AMOLED 智能手机面板、智能穿戴 OLED、中尺寸（笔电 / 车载 / AR）OLED、ViP 无掩模 OLED 面板。
主要客户 / 下游：荣耀、小米、OPPO、vivo 等头部智能终端；智能家居、工控、游戏机等新兴场景量产供货。
境内外收入占比（2026H1）：境内 38.30 亿（95.66%）、境外 1.74 亿（4.34%）。
股东背景：国有控股（合肥建曙投资 11.45% 为重要股东，昆山经开区管委会拟通过定增入主）；拟定增 ≤30 亿，合肥建曙拟认购约 4.19 亿股，完成后持股由 11.45%→31.89%。

（2）市场端（量价数据）

  • 行业格局：2025 三星显示 41.5%、京东方 16.3%，国内头部合计 >50%，国产替代持续推进。
  • 价格：行业周期底部，手机端备货保守致产能利用率不足，面板价格承压。
  • 中尺寸 OLED：笔电 / 车载 / AR 为新增量，维信诺广州中尺寸试验线已首批出货验证。

（3）产业链传导

  • 上游：有机材料、设备（蒸镀机）、FMM 掩模板（长期被日本 DNP 垄断）。维信诺 ViP 无 FMM 技术绕开掩模依赖，降本 + 供应链安全。
  • 下游：智能手机 / 穿戴 / 中尺寸终端，客户集中度高（荣耀 / 小米等）。
  • 议价权：中等偏弱（行业产能过剩、买方强势），但 ViP 差异化 + 头部客户绑定提升议价空间。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：面板厂对上游设备 / 材料议价权弱（传导率≈0），成本端靠自身良率 + 技术降本（非转嫁）。ViP 无 FMM 使开口率 29%→69%，材料蒸镀偏移 / 溢色改善，等效降本。验证点：ViP 良率、单片成本。
  • 因子2 毛利结构再平衡：主业 OLED 毛利率 −7.94%（倒挂），其他业务 +29.58% 但占比仅 4.9%。结构高度依赖 OLED 扭亏；中尺寸（高附加值）占比提升是毛利修复关键。禁止用综合毛利率 −6.10% 单值代表结构。
  • 因子3 库存与采购节奏：行业下行期存在存货跌价（2026H1 存货跌价减值 2.14 亿），属接货损失，非真实盈利；高世代线设备调试期资本开支大。
  • 因子4 政策 / 市场锚点：① 韩系退出中小尺寸产能（市场层，利好份额）；② 国产替代补贴 / 采购倾斜（政策层）；③ 关税 / 出口管制对材料的反向风险。验证点：韩厂退产节奏、国内终端国产屏采购比例。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 市场容量 × 份额变量：① 供给侧——全球 AMOLED 份额 10.4%（+0.6pct），穿戴 27% 第一；② 客户份额——荣耀 / 小米 / OPPO / vivo 深度绑定；③ 技术代际——ViP 无 FMM 国际领先，差异化卡位；④ 成本曲线——ViP 降本左移；⑤ 份额二阶导数——穿戴已领先、中尺寸渗透早期。三档：保守守住（小尺寸份额稳）/ 中性小幅提升（中尺寸突破）/ 乐观抢份额（ViP 放量 + 8.6 代投产）。验证点：下季度出货份额、中尺寸客户认证数。
  • 层2 主业迁移空间：中小尺寸→中尺寸（笔电 / 车载 / AR）迁移，能力同源（OLED 技术），新 TAM 数倍于手机；客户认证门槛高（既是护城河也是阻力）。信号验证：广州线首批出货、车载 UDIR 方案发布。未过大规模量产验证点→仅作中期期权，不计入中性。
  • 层3 证伪信号：ViP 良率长期不达标、中尺寸客户认证流产、8.6 代线延期、份额连降。命中则下调。

第四步：估值锚定（自下而上，正常化净利润法）

亏损股方法：无正净利可锚，用三步推导——① 估稳态营收；② 算正常化净利率（行业景气年 / 历史最好 / 产能爬坡理论，取保守）；③ 正常化净利 × 远期 PE = 目标市值。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 5.25x 看似"贵"，实因归母净资产仅 17.62 亿被三年累计亏损（2023−2025 各亏 37/25/24 亿）侵蚀至极低；真实资产基础 480.8 亿（产线 / 设备）。非金融资产未重估型——巨额 PP&E 在持续亏损下面清算价值低于账面，非"真破净安全边际"。须列明：总资产 480.8 亿 vs 市值 92.5 亿，市场定价的是"反转期权"而非账面价值。
  • 校正2 周期位置校正：面板处周期底部（柔性 OLED 七年首降、稼动率不足）。中性净利采用正常化（非单年好年景、非拐点年化），取景气正常年 3.5%，并标注当前底部位置——底部不过度悲观、但顶部未至不得高估。
  • 校正3 杠杆下行情景：带息债务 218 亿（短期 110.64 + 长期 107.51），担保余额 169 亿 = 归母净资产 9.6 倍，年财务费用约 4–5 亿。高负债 + 高经营杠杆，下行时净利几倍跳负（悲观情景直接转重整风险），空间可转负，结论不得标"大空间 / 重点关注"。
  • 期权纪律：ViP 技术突破、8.6 代线、中尺寸放量、国资定增均未过完全验证点→仅放乐观情景，不计入中性净利。

亏损股三问

  1. 为什么亏：① 面板周期底部、手机端备货保守→产能利用率不足（刚性折旧 + 利息无法被收入覆盖）；② 巨额折旧（480 亿资产年折旧 20 亿+）；③ 高财务费用（H1 4.22 亿，带息债务 218 亿）；④ 存货跌价减值 2.14 亿；⑤ 参股合肥维信诺科技亏损致投资损失 3.16 亿；⑥ 递延所得税影响。刚性成本远超收入。
  2. 靠什么扭亏，时点：① 稼动率全面提升（合肥 6 代已 93.7% 满产，其余爬坡）；② ViP 无 FMM 降本（开口率 29%→69%）+ 高端化提 ASP；③ 中尺寸 OLED（笔电 / 车载 / AR）放量打开新 TAM；④ 定增 ≤30 亿补血降财务费用；⑤ 韩系退出 + 国产替代改善供需。触发时点：2027–2028（8.6 代 2027 投产 + 稼动率全面修复），但券商预测 2028 仍亏 −15 亿，中性假设 2029 小幅正常化扭亏。
  3. 亏得起吗：危险但短期靠输血。归母净资产 17.62 亿、H1 亏 15.19 亿（年化侵蚀），债务 218 亿、担保 169 亿。但经营现金流 H1 +17.66 亿（回款好）、筹资现金流 +21.17 亿（持续融资），且合肥建曙 / 昆山经开区国资定增兜底——短期能撑，长期取决于定增落地与扭亏。若定增失败 + 面板持续低迷→资金链 / 重整风险。

第五步：综合赔率判断（买不买？）

当前价格位置：高风险博弈区间（市值 92.5 亿定价反转期权，但净资产仅 17.6 亿、深亏 + 高杠杆）。
安全边际：几乎无传统安全边际；中性远期 +28.7%（未达 >50%）；悲观 −39.7%（重整风险）。
介入条件：须硬证据——① 定增落地；② 连续两季环比减亏；③ 稼动率全面修复 + 中尺寸客户认证突破；④ 合肥 V5 线按计划 2027 投产。
最大风险：① 定增失败 / 国资兜底不及预期；② 面板周期持续底部、价格战；③ 218 亿债务 + 169 亿担保反噬；④ 8.6 代线延期或良率不达标。
结论：暂不介入（当前债务与亏损结构不支持介入，须等定增落地与连续减亏硬证据；若定增失败则实质接近回避）。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：韩系退出 + 低端产能出清，剩者（维信诺等）份额与定价权跳升。验证点：韩厂退产公告、公司份额提升。
  • B 政策反转期权：新型显示国产替代加码、终端国产屏采购倾斜。验证点：政策发文、大客户采购比例。
  • C 市场错杀修复：周期底部情绪修复，盈利证伪恐慌。验证点：连续季度减亏、毛利率翻正。
  • D 技术代际跃迁（核心期权）：ViP 无 FMM 从 0 到 1 全球首发量产 + 8.6 代线投产，重构竞争格局。硬验证点：中试 / 量产良率达标 + 客户定点（小米等）+ 量产成本优于 FMM 旧路线——三者缺一则只作机会情景。证伪：良率长期不达标 / 客户流失 / 成本打不过旧路线。
  • 上调至纳入观察 / 重点关注条件：定增成功落地 + 2027 起连续减亏 + 中尺寸认证突破，则反转期权计入、可上调。
