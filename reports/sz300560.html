（3）产业链传导

上游：设备（华为/中兴）、辅材。原材料占比低，成本端无铜/钢等大宗敞口，主要成本是人力和外包代维。
下游：三大运营商/铁塔/政府。议价权弱——客户集中且强势，代维合同年降、回款周期长（应收账款高）。
议价权结论：中下。公司毛利率长期 15–22%，盈利弹性取决于费率管控而非提价。

第二步进阶：原料成本 → 毛利结构（四因子）

  • ① 成本传导弹性（pass-through）：人工/外包成本系数 ≈ 0.15（弱议价，难转嫁）；但原材料（辅材）占比小，大宗涨价对其几无直接冲击。反而人力成本刚性上行 + 运营商压价是毛利主要侵蚀源，转嫁系数≈0。
  • ② 毛利结构再平衡：高毛利板块（软件 51%、集成 51%）体量仅 ~17%，且集成受验收周期波动大（2025 集成收入 −70%）；主体通信运维 15.5% 毛利难提升，结构再平衡方向是提软件/边缘计算占比，但短期难改综合毛利。
  • ③ 库存与采购节奏：轻资产、低库存，无囤货收益/接货损失问题；但应收账款高 + 经营现金流转负，体现回款 timing 风险而非库存 timing。
  • ④ 政策/市场锚点：政策驱动变量为运营商 capex 节奏（算力/5G-A 倾斜）与政府采购（数字政务/公安）；无关税/收储类成本驱动。验证点：运营商年度集采框架、公司中标公告；证伪信号：代维中标份额下降、回款进一步恶化。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务·市场容量 × 份额变量：通信代维市场随运营商 capex 温和增长，公司份额受头部代维商挤压，给三档：保守守住（份额持平，营收 0 增长）/中性小幅提升（边缘计算拉动，营收 +3%）/乐观抢份额（+6%）。验证点：运营商集采中标公告、英博达订单。
  • 层2 扩展业务·主业迁移空间（新易盛范式）：从"通信代维"向"算力网络运维 + AI 视觉"迁移，能力部分同源（通信+软件），但尚未过验证点（收入占比 <8%、无大额订单公告），列为中期期权，不计入中性。
  • 层3 风险折扣·证伪信号：运营商 capex 再压缩、代维中标流失、应收账款坏账、英博达增长不及预期。

第四步进阶：重资产/周期股校正（三道闸）

  • ① 资产质量折扣：轻资产（净资产 8.98 亿多为应收+现金），非破净，无重估型折价问题；但应收账款质量（运营商/政府回款）是隐性风险。
  • ② 周期位置校正：通信服务弱周期，但行业 capex 从铺量转质效、代维价格年降，处于"温和下行/平价"位置，中性净利不做上行外推。
  • ③ 杠杆下行情景：2026H1 长期借款 +14567%、资产负债率 ~65%，高负债必附负面情景——若利率上行/回款恶化，净利率再降 1pct 即可使中性净利腰斩，空间转负更深（悲观 −87%）。
  • 期权纪律：边缘计算/算力运维/出海均未过验证点，不计入中性，仅列乐观/机会栏。

交叉校验：现价 18.03 元对应市值 41.4 亿，是 2029E 中性净利（0.52 亿）支撑市值的 3.8 倍。即便乐观情景（0.8 亿×23x=18.4 亿）也仅对应 8 元。现价已严重透支转型预期，无安全边际。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。现价 18.03 元对应 2026E PE ≈ 56x、2029E 中性 PE ≈ 35x，而业务实质是低毛利（2.8%）通信代维，市场定价的是"算力/AI 转型期权"。

安全边际：中性远期 4.75 元 → 空间 −73.7%；资产底（净资产 8.98 亿 ÷ 2.297 亿股 ≈ 3.9 元 PB1.0x）为理论下限，但高负债+应收质量削弱支撑。下行远大于上行。

介入条件：① 深度回调至 PB < 1.5x（≈5.9 元以下） 才具资产安全边际；② 加仓信号＝边缘计算/算力运维中标大额订单、海外业务从 0 突破、资产负债率回落至 50% 以下。

最大风险：① 代维主业价格年降 + 份额流失，净利率继续压缩；② 高负债（长期借款暴增）在利率上行时侵蚀利润；③ 应收账款坏账；④ 转型（边缘计算/AI）长期不兑现，期权归零。

上行想象力情景（第五步进阶，仅进乐观/机会栏，不进中性）：
- A 行业出清剩者红利：代维行业集中度提升、中小代维商出清，公司守份额——验证点：运营商集采集中度数据；证伪：份额连降。
- B 政策反转期权：算力网/数字政务财政加码拉动运维与集成订单——验证点：运营商算力 capex 落地、政务订单公告。
- C 市场错杀修复：若因风格切换错杀至 PB<1.5x，估值分位极低——验证点：相对行业 PB 折价。
- D 技术突破/代际跃迁期权：边缘计算 AI 视觉从项目制走向产品化、海外"一带一路"通信服务突破——硬验证点（中试/量产不适用，此处为）：大额订单公告 + 海外收入跳升 + 英博达净利占比 >20%。缺一则仅作机会情景。
- 上调至"重点关注"的条件：边缘计算/算力运维收入占比突破 20% 且持续盈利、海外收入从 0 跳升至亿级、资产负债率回落至 50% 以下。

结论：暂不介入（估值显著高于内在价值，中性空间 −73.7%；转型期权未验证，须等深度回调至 PB<1.5x 或订单兑现）。
