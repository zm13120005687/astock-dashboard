一句话定位：山西省属"发电 + 配电 + 参股煤炭"一体化电力企业——主体是火电机组发电（阳光公司）与省属独立供电营业区配电（地电公司），并向阳泉市及平定县承担约 70% 的供热份额，同时参股煤炭企业获取投资收益。

（3）产业链传导

上游（煤炭）：公司火电燃料为动力煤。2026H1 煤价上行对煤电形成挤压（约 −1,350 万元），但公司同时参股煤炭企业（榆树坡等），形成天然对冲——煤价涨，火电成本升，但投资收益增。这是本股区别于纯火电股的关键结构。

下游（用电需求）：① 配电业务受益于区域内用户用电量增加、新能源接入、供电企业投资界面延伸、煤改电等；② 火电受新能源挤出与电价市场化下行双重压制，电量与电价均不占优；③ 供热业务具备区域垄断性（阳泉约 70% 份额），现金流稳定。

议价权判断：
- 配电：强（区域垄断）。独立供电营业区 = 特许经营，售电量 101.03 亿千瓦时、收入稳定，是公司的"现金牛"基本盘。市场交易层面测算"配电业务单年约赚 5 亿元"。
- 火电：弱（价格接受者）。电量受调度与新能源挤出、电价受市场化竞价压制，公司自身风险提示明确"报价趋近变动成本"；好消息是容量电价提供"保底工资"（165 元/千瓦·年）。
- 参股煤炭：被投企业议价权取决于煤价周期，本期量价齐升贡献可观。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：煤电的燃料成本传导率 约 0.5–0.7（受山西省燃煤发电上网电价市场化机制影响，煤价波动部分可通过市场化电价与容量电价回收）。量化说明：按 2026H1 拆解，煤价上行约 −1,350 万元，而电价上涨约 +1,600 万元，电价上行完全覆盖并超出煤价冲击，说明公司当期传导率 > 1（原因：容量电价 165 元/千瓦·年上调 + 折旧到期双重利好叠加）；但这属于当期结构性红利，非可持续——一旦容量电价政策进入稳定期、折旧释放完毕，传导率将回落至 0.5–0.7，煤价上行会实质压缩毛利。依据：公司自身口径、山西省容量电价文件、市场交易层面拆解。

  • 因子2 毛利结构再平衡（须分业务线，禁单一综合毛利率）：

板块 毛利特征 对煤价敏感度 对电量敏感度 加权后利润贡献迁移
火电（含供热） 低毛利（毛利率约 8%–10%） 高（煤价主导成本） 高（电量下滑直接冲击） 2026H1 净利增量仅约 +1,500 万元，贡献占比下降
配电 中高毛利、稳定 极低（几乎不消耗燃料） 中（随区域内用电量） 净利增量约 +1,200 万元，且为利润压舱石
参股煤炭（投资收益） 高弹性 — — 净利增量约 +3,900 万元，成为最大增量来源

→ 关键结论：公司综合毛利率（约 9%–10%）被火电板块拉低，单一综合毛利率完全掩盖了"利润重心从火电向配电 + 参股煤炭迁移"的结构变化。估值必须分板块给，不能用一个 9% 毛利率套全公司。

  • 因子3 库存与采购节奏（timing）：火电燃料煤库存周期短（公司存货账面价值仅 7,101.8 万元，占净资产 0.83%），且计提存货跌价准备 2,452.35 万元、计提比例 25.67%——说明公司对煤价与燃料库存采取审慎态度，不存在"低价囤货收益虚高"。同时公司主动"加强燃料管理"以对冲煤价上行。timing 判定：当前煤价上行期，公司以低库存 + 审慎计提应对，无库存收益粉饰利润；反之若煤价进入下行通道，低库存会错失囤货红利（略偏保守）。

  • 因子4 政策/市场锚点（原料成本驱动变量）：

  • 政策层：① 容量电价机制（发改价格〔2026〕114 号 + 山西 165 元/千瓦·年）——直接对冲电量与电价下行，是火电成本的"制度性减负"；② 环保与碳管控——排放标准持续收紧、超低排放常态化、火电纳入全国碳排放权交易市场（2026 年为履约元年），抬升高碳资产运营成本；③ 能源结构转型——金融机构对高碳资产融资趋严（公司风险提示）。
  • 市场层：① 动力煤价格（秦皇岛 5500 大卡等）；② 山西电力现货市场价格与长协电价中枢；③ 区域内用电量增速与新能源接入规模；④ 参股煤矿的量价表现。
  • 情景与验证点：情景 A（煤价稳中有降 + 容量电价落地） → 火电毛利稳、参股煤炭略降但被火电对冲，整体利润平稳（中性）；情景 B（煤价大涨） → 火电承压但参股煤炭大赚，天然对冲，利润波动被显著平滑（本股核心优势）；情景 C（电价中枢大幅下移） → 容量电价仅覆盖固定成本 50%，电量电价下行难以完全对冲（悲观）。
  • 验证点：逐季火电与配电的分部利润、参股煤炭投资收益明细、山西电力现货价格中枢、动力煤价格。
  • 证伪信号：① 火电板块由盈转亏且参股煤炭收益不足以对冲；② 容量电价政策被下调或考核趋严导致扣减；③ 配电网区域用电量负增长。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量（5 锚点）
  • 供给侧份额：配电端区域独占（独立供电营业区，区域内无竞争者），份额 = 100%，无提升空间亦无流失风险；火电端省内同业众多、新能源挤出，火电份额被动下降。
  • 需求侧/客户份额：配电用户为营业区内全部终端用户，粘性极高（电力属刚需）；供热占阳泉市场约 70%，具备区域垄断。
  • 技术代际差：火电机组技术非瓶颈，但灵活性改造（调峰能力）是新型电力系统下的新"技术代际"要求，公司明确"加速灵活性改造，强化调峰能力"——若完成，可从"电量电源"切换为"调节电源"，享受辅助服务收益。
  • 成本曲线位置：山西省内火电成本受煤价主导；公司参股煤炭形成纵向对冲，成本曲线位置优于纯火电同业；折旧到期进一步左移成本曲线。

  • 份额二阶导数：配电份额已饱和（100%，S 曲线末端）；火电份额处于下行通道。合计判定：份额层面无增长引擎，增量来自"单位盈利改善"而非"份额提升"。
    → 三档假设：保守（配电售电量零增长、火电电量继续下滑 3%–5%）/ 中性（配电售电量小幅增长 1%–2%、火电电量持平）/ 乐观（区域内用电量加速增长 + 灵活性改造带来辅助服务收益）。验证点：逐季售电量、火电发电量、辅助服务收入。

  • 层2 扩展业务：主业迁移空间（新易盛范式）——弱适用（能力可迁移性中等）。

  • 能力可迁移性：高。公司核心能力是"区域电网运营 + 电力购销 + 重资产运营"，可迁移至新能源电站运营（光伏、储能），技术与运营高度同源。
  • 新 TAM 弹性：山西是全国能源革命综合改革试点，新能源装机高速扩张，TAM 显著大于现有火电增量空间。
  • 切入时点与卡位：公司已布局新能源分部（光伏），并明确"推进煤电与新能源多能互补"，属早期卡位。
  • 客户认证门槛：电网消纳与并网审批是门槛，公司作为省属供电企业具备天然优势。

  • 信号验证：尚未见新能源分部的规模化营收跳升与项目并网公告 → 未过验证点，不计入中性情景，仅作中期期权。

  • 层3 风险折扣：证伪信号：① 火电板块由盈转亏且参股煤炭无法对冲；② 配电售电量负增长；③ 山西电力现货价格中枢大幅下移；④ 容量电价政策被下调或考核扣减。命中则下调中性情景。

第四步：估值锚定（自下而上，非增速外推）

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

  • 校正1 资产质量折扣（破净原因必须逐条举证，PB 0.85x）：
  • 资产盈利能力是否差？ 2025 年加权 ROE 8.08%、2026H1 加权 ROE 4.56%，并不算差（高于负债成本、高于多数火电同业）。但拆分看，火电板块本身仅薄利（2026H1 净利增量仅约 1,500 万元），公司整体 ROE 由配电与参股煤炭支撑。→ 破净的第一因是"火电资产盈利弱 + 市场对电价下行的预期"，而非整体资产不赚钱。
  • 资产专用性是否强？ 强。火电机组、配电网、供热管网均为高度专用资产，不能转产，清算价值远低于账面净值；配电网更是受监管的特许经营资产，无法自由处置。→ 重置成本不构成兜底，这是破净的第二因。
  • 是否隐含负债？ 资产负债率 30.20%（2026H1）、有息负债率 26.20%（2025 年报），处于低位；2026H1 长期借款较上年末 +40.78%，需关注但绝对水平低；存货跌价准备计提比例 25.67%，资产端较为干净，无重大隐含负债。 → 破净的第三因不成立。
  • 是否存在金融资产未按市价重估型"真破净"？ 部分成立。公司长期股权投资（参股煤炭等）2026H1 较上年末 +15.85%、占总资产比重 +1.78pct；但未披露"持股上市公司市值 ≈ 公司总市值"的情形，不构成典型的"金融资产未重估型真安全边际"。→ 判定：破净为"火电资产专用性强 + 盈利弱 + 电价下行预期"三因叠加的公允定价为主，叠加配电/参股煤炭的价值未被市场识别；不能单凭 PB<1 直接推导大空间。

  • 可观测验证点：① 火电板块分部利润是否转亏；② 参股煤矿投资收益披露；③ 长期股权投资规模与标的资产质量。证伪信号：火电资产出现大额减值、配电营业区被重组、参股煤炭亏损。

  • 校正2 周期位置校正（中性净利用周期归一化）：火电是强周期行业（煤价 + 电价双周期）。当前周期位置判定：煤价中高位 + 电价下行初期 + 容量电价政策红利期，整体处 "盈利尚可但趋势向下"的中性偏上位置。中性净利禁用 2026H1 单季年化（约 7.8 亿），也禁用"折旧释放 + 容量电价上调"的当期红利直接外推（这两项会随折旧释放完毕与政策进入稳定期而衰减）。采用周期归一化：以火电正常周期单位盈利（度电净利中枢）+ 配电稳定盈利 + 参股煤炭常态收益测算，得 7.5 亿。标注：当前处中性偏上位置，故中性不给过高 PE（13x，考虑到电量电价下行风险）。

  • 校正3 杠杆下行情景：资产负债率 30.20%、有息负债率 26.20%，杠杆低、现金厚（2025 年报现金比率 106.85%、流动比率 1.58），无杠杆反噬风险。但需附"电价下行"负面情景：若山西电力现货价格中枢大幅下移、容量电价覆盖不足，火电板块可转亏，此时中性（7.5 亿）须下修至悲观（5.0 亿）→ 目标股价 4.36 元（−31.7%）。因杠杆低，该负面情景不至于使空间"转负到无法承受"，故仍可给"纳入观察"，但须注明高贝塔属性。

  • 期权纪律：新能源大基地与灵活性改造辅助服务收益未过验证点（无并网/容量公告），不计入中性净利，仅体现在乐观情景（+91.4%）中。参股煤炭的投资收益按煤价常态计入中性（1.0 亿），若煤价大幅上行则上调、下行则下调。

第五步：综合赔率判断（买不买？）

当前价格位置：低估（PB 0.85x 破净、PE 11.3x、股息率 2.82%），但"低估"程度受制于破净原因（火电资产专用性强）。现价 6.38 元低于每股净资产 7.49 元约 15%，且公司 ROE（8% 左右）高于合理 PB 定价所隐含的水平，属"利润结构已迁移但市场仍按纯火电定价"的错配。

安全边际：
- 中性远期 8.50 元 → 空间 +33.2%，未达"重点关注"的 >50% 门槛
- 悲观情景 4.36 元 → 下行 −31.7%，因低杠杆，下行可控
- 乐观情景 12.21 元 → +91.4%，需新能源大基地 + 辅助服务收益兑现
- 下行保护：每股净资产 7.49 元（PB 0.85x）、资产负债率 30.20%、有息负债率 26.20%、现金比率 106.85%、股息率 2.82%（2025 年度 10 派 1.8 元）；6 元以下（PB < 0.80x）具备较强配置价值

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利——弱适用。火电行业无"去产能出清后剩者份额跳升"逻辑（电力属公用事业、区域垄断）。但山西省内煤电与新能源的多能互补整合可能带来区域资产整合机会。验证点：山西省煤电资产整合公告。不计入中性。

  • 类型B 政策反转期权——中等适用。容量电价从 100 元提升至 165 元/千瓦·年（回收固定成本比例 30%→50%）是已落地的政策红利（已计入中性）；进一步的期权在于"适时建立发电侧可靠容量补偿机制"若落地加码，乃至辅助服务市场扩容。反转信号：山西省/国家层面发布容量补偿或辅助服务新政。未过验证点部分不计入中性，仅作机会情景。

  • 类型C 市场错杀修复——强适用（本股主要上行来源之一）。

  • 错杀证据：① PB 0.85x，破净幅度约 15%，处自身历史低位；② 利润结构已由火电主导迁移至配电 + 参股煤炭主导（2026H1 增量约 5,100 万元来自非火电），但市场仍按纯火电给折价；③ 基本面未恶化——2026H1 归母净利同比 +24.66%，是少数上半年火电仍盈利的企业。
  • 修复触发点：① 市场对"容量电价 + 配电稳定盈利"重新定价；② 参股煤炭收益与新能源项目披露更透明；③ 中特估/电力板块估值修复行情。

  • 修复弹性：若市场按"配电 + 投资收益主导"重估至 PB 1.0x–1.1x（即每股净资产 7.49 元的 1.0–1.1 倍），对应股价 7.49–8.24 元（+17.4%～+29.2%）——与中性情景吻合。本项已隐含在中性情景，未过"分部利润披露验证点"部分不额外加成。

  • 类型D 技术突破 / 技术代际跃迁期权——弱适用。火电灵活性改造（深度调峰）是"技术代际"升级，若机组调峰能力达标（最低负荷率下降、爬坡速率提升），可从电量电价切换至辅助服务收益。硬验证点：调峰能力测试达标 + 辅助服务收入进入报表。未过验证点，仅作机会情景，不计入中性。

⚠️ 什么条件出现才上调至"重点关注"：① 分部利润披露显示配电 + 参股煤炭合计贡献占比 > 80% 且火电不再拖累；② 新能源项目并网公告且规模可测算；③ 股息率提升至 4% 以上（对应分红大幅提升）；④ 股价回落至 5.7 元以下（PB < 0.76x）。以上四条中至少满足两条 + 价格条件，方可上调。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 电价中枢持续下行（首要）：公司风险提示明确"火电现货与长协电价中枢继续下行，报价趋近变动成本"，若容量电价无法覆盖，火电板块可转亏
2. 煤价上行挤压火电：虽有参股煤炭对冲，但对冲比率未披露，无法验证完整对冲
3. 资产专用性强导致 PB 不修复：破净可能长期存在（火电机组/配电网不能转产、清算价值低）
4. 参股煤炭收益不透明：投资收益占利润增量比重上升，但披露颗粒度低，构成主要不确定源

结论：纳入观察

逻辑正确（破净 15% + ROE 8% + 利润重心已迁移至配电与参股煤炭 + 容量电价政策已落地 + 股息率 2.82%），但中性远期空间仅 +33.2%，不满足"重点关注"的 >50% 门槛；破净原因为"火电资产专用性强 + 盈利弱 + 电价下行预期"三因叠加，属公允定价为主、结构错配为辅，不能单凭 PB<1 推导大空间。
真正的机会在于"分部利润结构被市场识别"（中性 +33.2%）与"新能源大基地 + 辅助服务收益"（乐观 +91.4%）：一旦新能源项目并网并披露可测算规模，或分红大幅提升使股息率突破 4%，可上调评级。
核心跟踪点：逐季分部利润（火电/配电/投资收益拆分）、山西电力现货价格、动力煤价格、新能源项目并网公告。
