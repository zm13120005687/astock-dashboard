第一步：公司是干什么的？

一句话定位：重药控股是销售规模稳居全国医药流通行业前五的全国性医药商业龙头，以"医药批发 + 零售（DTP 药房）+ 仓储物流 + 器械/中药/新兴业务"为主，背靠重庆国资。

核心产品/服务：药品/器械分销、DTP 处方药房（231 家）、仓储物流（11 个省级基地、184 个仓储中心、近 80 万㎡）、中药饮片、医美、特医食品、放射性药品。

主要客户/下游：各级医院（占营收主体，账期长）、零售药店、基层医疗、患者（DTP）。覆盖 30 省市、178 地级市。

境内外收入占比：基本内销。

股东背景：重庆市国资委下属重庆医药健康产业集团控股，国有背景利于医院端配送准入。参股工业子公司重庆药友（2026H1 营收 22.38 亿、归母 4.32 亿）。

（3）产业链传导

上游：制药企业（集采压价），公司采购成本受集采中标价约束。

下游：医院（账期 6~12 个月，强势）、零售、患者。医院端议价强，公司转嫁能力弱。

议价权：弱。医药流通为"垫资 + 配送"低壁垒环节，对医院无定价权，毛利被集采与账期双重挤压。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：流通环节转嫁系数 ≈ 0（集采锁价 + 医院强势），成本/费用无法转嫁，毛利刚性下行。2026H1 毛利率 −0.52pct 即印证。
  • 因子2 毛利结构再平衡：批发（毛利率或 5%~6%，占 94%）VS 零售/DTP（毛利率或 15%~20%，占 6%）。原料/采购敏感权重在批发端（集采品种降价）。结构改善依赖提升 DTP/零售高毛利占比。
  • 因子3 库存与采购节奏：医药流通库存周转快、囤货收益有限；核心成本是资金成本（垫资给医院）。2026H1 经营现金流 −36 亿反映垫资扩大。
  • 因子4 政策/市场锚点：① 集采（压价，利空）；② 利率（资金成本，影响财务费用，验证点：贷款利率）；③ 处方外流（利好 DTP）；④ 医疗反腐（短期扰动医院采购）。情景：集采深化 + 利率上行 → 毛利与现金流双杀；处方外流加速 → DTP 高毛利增量。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：全国前五，份额约 5%~6%，集中度缓升。
  • 客户份额：重庆大本营 34% + 全国 178 地市渗透，医院端粘性强。
  • 技术代际：物流数字化（重药云商 + 药东东 +80%），处行业前列。
  • 成本曲线：规模 + 全国仓储网络，具配送成本优势。

  • 份额加速度：重庆外子公司营收占 65.75%，全国渗透加速——验证点：外省营收占比续升。
    → 中性：份额小幅提升，DTP/新兴高毛利占比改善净利率。

  • 层2 扩展业务：主业迁移空间：从"纯配送"向"DTP 处方承接 + 工业（药友）+ 特医/医美"迁移，能力可复用（医药供应链），新 TAM 更大——部分已兑现（DTP +35%），但工业利润主要源于参股药友，未完全计入中性主业净利。

  • 层3 风险折扣（证伪信号）：医院回款恶化、集采压价超预期、DTP 增长失速、利率上行致财务费激增——命中则下调。

第四步：估值锚定（自下而上，非增速外推）

方法说明：不使用增速外推。医药流通低毛利低 ROE，按"营收缓增 + 净利率微升（DTP 占比提升）"测算，并以 PB 资产锚校验。2026H1 归母 2.54 亿，年化约 5 亿；扣非 2.43 亿。

总股本：约 17.13 亿股（总市值÷现价推算）。归母净资产 ≈ 总市值 ÷ PB = 88.89 ÷ 0.76 ≈ 117 亿。

第四步进阶：重资产 / 周期股三道闸

  • 校正1 资产质量折扣（破净原因）：PB 0.76 破净，原因是资产盈利能力差（ROE 仅 2.18% H1，年化约 4.4%）+ 低毛利 + 高应收（医院账期）。净资产中大量应收账款（医院）清算价值打折、存货（药品）有保质期损耗，不是金融资产未重估型。破净为公允定价，禁止单凭 PB<1 推导大空间。

  • 校正2 周期位置校正：医药流通弱周期，但受政策（集采）与利率周期影响；中性净利 6.5 亿取行业稳态，未用单年外推。

  • 校正3 杠杆下行情景：资产负债率约 75%~80%（流通业高负债 + 垫资），财务杠杆高。经营现金流 −36 亿若持续，悲观情景空间 −59.5% 已体现，不得标大空间/重点关注。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。现价 5.19 元 PB 0.76 破净，但破净源于低 ROE 与高应收，非错杀。盈利锚（2026E 净利 5 亿 / 14x = 70 亿，对应 4.09 元）显示当前价已略高于盈利锚，主要靠 PB 资产底支撑。

安全边际：PB 0.76 提供一定资产保护（净资产 117 亿），但应收质量存疑；中性远期 5.72 元（+10.2%）空间有限；悲观 −59.5%。

介入条件：① 回落至 ≤ 4.5 元（接近盈利锚 4.09、PB 0.65）才具安全边际；② 加仓信号：经营现金流转正、DTP 占比显著提升、净利率回升至 1.5%+；③ 回避：回款恶化、负债率攀升。

最大风险：① 医院回款周期拉长致现金流恶化（首要，H1 已 −36 亿）；② 集采压价致毛利下滑；③ 高负债 + 利率上行财务费激增；④ 应收账款减值。

上行想象力情景（四类）：
- A 行业调整剩者红利：中小流通商退出，前五集中度提升——验证点：CR5 升、公司份额升；证伪：份额流失。
- B 政策反转期权：处方外流加速 + DTP 支持政策——验证点：院外处方占比升；证伪：政策停滞。
- C 市场错杀修复：PB 破净 + 现金流转正预期，估值修复——验证点：现金流转正；证伪：回款恶化。
- D 技术突破：重药云商/药东东数字化提效、工业（药友）新品获批——未过验证点，仅作机会情景。

上调重点关注的条件：经营现金流持续转正 + 净利率稳于 1.5%+、对应市值 130 亿+（7.6 元，+46%），方可上调。

结论：暂不介入（破净为公允定价、盈利锚低于现价、现金流恶化，中性空间仅 +10%；需等现金流转正与盈利质量改善信号）。
