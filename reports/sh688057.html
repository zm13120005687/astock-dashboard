金达莱（688057）五步法分析报告

分析日期：2026-09-21 ｜ 现价 16.24 元（2026-09-18 收盘，腾讯行情实测）｜ 总市值 44.82 亿 ｜ PE(TTM) 约 70–130x（微利高估值） ｜ PB 1.42x ｜ 总股本 约 2.76 亿股
行业：水环境治理（FMBR / JDL 污水处理工艺）｜ 板块：科创板
口径说明：2026H1 归母净利 +611.26 万元（为正，扣非 +214 万），TTM 口径亦已盈利（8 月末 PE 约 134x），按盈利股估值但保守处理——主业承压、盈利依赖投资收益与政府补助，估值以资产兜底 + 保守盈利为锚。

第一步：公司是干什么的？

一句话定位：以自主 FMBR（碳氮磷同步深度去除）+ JDL（重金属废水）核心工艺见长的水环境治理综合服务商，覆盖村镇 / 市政 / 工业 / 黑臭水体，并战略布局新兴产业股权投资。

第二步：行业景气度 + 政策/市场数据

（1）政策端（近 6–12 个月）——中长期强利好，但行业由增量转存量

  • 《土壤、地下水和农业农村生态环境保护"十五五"规划》（生态环境部等六部门，2026-07）：到 2027 年底美丽乡村整县建成比例 40%、农村黑臭水体基本消除；2030 年整县建成 55%、农村生活污水治理率提升至 70%；2026 年底基本完成低效无效设施摸底、2028 年底完成优化调整，设施正常运行率稳定 90% 以上。
  • 《群众身边水体保护治理行动方案》（国办函〔2026〕65 号，2026-07）：治理重点向县城、乡村延伸，基本消除县乡黑臭水体，加强工业园区水污染整治。
  • 《美丽中国建设"十五五"规划》（国务院，2026-07）：优良水体比例指标提高到 85%，完成 8 万个行政村环境整治。
  • 量化指标：全国农村生活污水治理率已超 55%；5042 条较大面积农村黑臭水体基本消除；到 2030 年治理率 70%——存量优化 + 补短板为主，新增量有限。

（3）产业链传导

  • 上游：设备材料（钢材、膜、泵阀）、工程分包，标准化采购，议价权中低。
  • 下游：政府 / 工业企业甲方，回款受财政约束；公司主动规避高垫资长周期项目（谨慎承接）→ 牺牲规模保现金流。
  • 议价权：中低（环保工程乙方、政府甲方、行业集中度提升压价）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（≈0.2）：工程 + 设备集成，钢材 / 膜材涨价自担，政府项目难转嫁。
  • 因子2 毛利结构再平衡：村镇 / 市政（40%+）为主，工业废水（成本较高、毛利低）占比提升拖累结构；Q2 毛利率降至 31.17% 反映结构恶化 + 价格压力，单一综合毛利率掩盖了工业废水低毛利稀释。
  • 因子3 库存与采购节奏：无大宗库存，以项目备货；无囤货收益，反而项目垫资产生现金流占用（但经营现金仍 +1.13 亿，因收缩项目）。
  • 因子4 政策 / 市场锚点：① 地方环保专项债 / 财政支付能力（直接影响订单与回款）；② 美丽乡村 / 黑臭水体专项投资节奏；③ 设备材料价格。情景：财政资金回暖 → 订单与毛利率修复；证伪：财政持续紧 → 营收继续下滑、毛利率破 30%。验证点：单季新签、专项债环保投向、Q2 毛利率趋势。

自下而上测算：2025 营收约 3.4 亿、2026H1 1.367 亿（年化约 2.7 亿且下滑，Q2 已单季转亏）。中性假设 2029 年营收恢复至 2.8–3.0 亿（工业废水 + 存量治理贡献，保守、非历史峰值回归），稳态净利率 10–12%（FMBR 高毛利工艺、但工业废水低毛利稀释）→ 2029 年净利 2800–3300 万（较 H1 年化约 2.3 倍，已属保守恢复）。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务·市场容量 × 份额变量：水处理行业分散 → 集中度提升，公司凭 FMBR 差异化技术有份额提升空间；五锚点：供给侧无产能约束、客户份额区域型、技术代际领先（FMBR 自主知识产权）、成本曲线（工艺优势）、份额加速度中等。三档：保守营收 2.8 亿、中性 3.3 亿、乐观 4.0 亿。验证点：工业废水新签订单、村镇项目中标。
  • 层2 扩展业务·主业迁移：由"政府水务"向"工业废水 + 企业客户"迁移，能力可复用（同工艺），新 TAM（工业废水）更大；认证门槛（企业供应商准入）中高，未过验证点（工业废水未形成明显利润贡献），仅作中期期权。
  • 层3 证伪信号：营收持续下滑、Q2 毛利率破 30%、工业废水无实质订单 → 下调增量。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 1.42x（净资产 31.66 亿），非破净；净资产含现金 / 理财 / 长期股权投资（1.8 亿）+ 私募股权（2.06 亿），资产质量较好，1.42x 有资产兜底，可保留但须证明——列示：净资产 31.66 亿 >> 市值对应安全边际，长期股权投资 + 私募股权合计 3.86 亿已部分反映在账面。
  • 校正2 周期位置校正：非强周期，不适用。
  • 校正3 杠杆下行情景：资产负债率 = (35.5−31.66)/35.5 ≈ 10.9%，极低杠杆；下行情景（主业持续弱化）空间仅至 14.49 元（−10.8%），不致转负，可保留观察级。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高，但资产兜底。现价 16.24 元，盈利薄（TTM PE 70–130x），但 PB 1.42x、净现金 / 投资类资产丰厚，下行有底。
安全边际：中性远期 22.10 元 → +36.1%（依赖盈利温和恢复，假设保守）；悲观 10.87 元 → −33.1%（资产兜底，下行有限）。
介入条件：① 现价 16.24 元已接近合理，可小仓观察；② 加仓信号：工业废水新签大单、单季归母扣非转正、Q2 毛利率重回 38%+；③ 观察：股权投资的战略性新兴产业是否兑现。
最大风险：① 主业持续弱化（Q2 已单季转亏）、盈利恢复不及预期；② 政府财政紧导致回款与订单双杀；③ 工业废水 / 新兴赛道拓展失败，盈利长期微利化。
结论：纳入观察（资产厚、PB 1.42x 安全边际，等工业废水拐点与盈利恢复验证；中性空间为正但假设偏乐观，故不列重点关注）。
