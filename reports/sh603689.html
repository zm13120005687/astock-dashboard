皖天然气（603689）五步法分析报告

分析日期：2026-09-13 ｜ 现价 7.73 元 ｜ 总市值 40.65 亿 ｜ PE(TTM) 11.78x ｜ PB 1.09x ｜ 总股本 约 5.258 亿股

第一步：公司是干什么的？

一句话定位：安徽省唯一的省级天然气长输管网平台，靠"管输费 + 城市燃气配气费 + 贸易价差"赚钱，是典型的受政府定价管制的区域公用事业资产。

核心产品/服务：
1. 长输管线：安徽省内天然气长输管道的投资、建设与运营，向 16 个省辖市、42 个县（市）供气；省内建成投运长输管线占全省总里程约 56%。
2. 城市燃气：在合肥、池州等地拥有特许经营权，协议接驳用户 34.33 万户（2026Q1），燃气管道 2,963 公里。
3. CNG/LNG：加气站与液态销售。
4. 综合能源：子公司安徽省充换电有限责任公司（期末总资产 6.89 亿，2026H1 营收 0.658 亿），布局大型储能、用户侧储能、充换电。

主要客户/下游：省内工业用户（非居民为主）、城市居民、电厂、化工企业。2025 年城市燃气销售气量 5.12 亿方，其中非居民 4.75 亿方（占 92.8%）——工商业敞口大，顺价机制是否通畅是关键。

境内外收入占比：100% 境内（安徽省内），无海外业务。

股东背景：安徽省天然气开发股份有限公司，实际控制人为安徽省国资委体系（皖能集团体系），省级国企平台。

政策解读（关键）：
- 配气价格"准许收益率 ≤7%"是硬上限，直接锁定城市燃气板块的长期 ROE 天花板。
- "上下游价格联动 + 每季度调整 + 幅度 ≤10%" 意味着成本传导制度性通畅，但有 1 个季度滞后 + 10% 幅度封顶——这是本股成本传导弹性的核心制度依据。
- 苏皖豫干线是安徽省"十五五"首个开工的国家级油气管道项目，将显著改变安徽气源格局（承接沿海 LNG），对省网公司既是增量机遇也存在被国家干线分流的风险。

（3）产业链传导

  • 上游：中石油、中石化、沿海 LNG。气源采购成本受国际油气价格影响，2026 年国际气价高位运行但边际回落。
  • 下游：工商户（占城市燃气售气 92.8%）、居民、电厂。工商业需求受安徽制造业景气度影响。
  • 议价权：上游弱、下游受管制但可顺价。省网具有区域先入优势与天然垄断属性（占全省 56% 里程），对下游有定价权，但定价权被发改委的"准许收益率 ≤7%"和"联动幅度 ≤10%"双重封顶。
  • 竞争替代：生物质供热、电能替代等多元化用能方式分流（公司半年报自述风险）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）
- 传导率估算：0.75–0.85（较强），但有制度性上限与时滞。依据：
1. 制度保障：安徽省已建立上下游价格联动机制（非居民气价原则上每季度调整一次），成本变动可传导。
2. 制度上限：联动幅度不超过上一季度销售价格的 10%，超出部分"在后续联动周期适时疏导"——即极端气价波动无法一次传导完。
3. 时滞：1 个季度。
4. 居住用气：需走听证/政府调价程序，传导更慢（固镇县 2026-07 才调整居民气价）。
- 定量：假设上游气源涨价 10%，传导率 0.80 → 公司实际毛利承压 = 10% × (1−0.80) = 2.0%；按气源成本占营业成本约 85% 折算，综合毛利率下降约 1.7pct（尚未触及配气价格管制下限，因配气费是"成本加成"）。
- 验证点：各市发改委季度配气价格/联动价格公告、公司季度毛利率。证伪信号：气源涨价 2 个季度后毛利率仍未修复 → 传导失败。

因子2 毛利结构再平衡（分业务线）

→ 关键洞察：长输管线是"高收入占比 + 高气源敏感"的组合，是利润的最大波动源；城市燃气是"制度性保护"的稳定器。2026H1 长输管线毛利率 10.89%、城市燃气 11.76%，两者接近，说明当前处于价差正常年份。不能用 14.29% 的综合毛利率代表全结构——若气源涨价，长输管线毛利塌陷会主导整体，而城市燃气的制度性保护只能部分对冲。

因子3 库存与采购节奏（timing）
- 燃气属"即产即销"商品，存货周转率 27.28 次（2026H1），几乎无库存，因此不存在低价囤货收益/高价接货损失问题——这是燃气行业相对制造业的盈利质量优势。
- 未查到公司有天然气期货/掉期套保的公开披露，对冲比例视为 0。
- 采购结构：与中石油、中石化签长期合同 + 沿海 LNG 现货补充。长协比例未披露。
- 验证点：年报"前五名供应商采购额占比"、采购合同公告；证伪信号：采购集中度大幅上升（议价权恶化）。

因子4 政策/市场锚点（原料成本驱动变量）
- 国际油气价格：2026 年国际油气价格高位运行，直接决定气源采购成本。
- 苏皖豫干线（2026-03 开工，安徽段 56 亿、+40 亿方/年）：建成后将承接沿海 LNG 资源并与西气东输管网互联互通，形成多气源互补——中长期降低安徽气源成本、提升保供能力，是最大的成本端正向变量。但公司是否为该干线的投资/运营主体未披露，存在"被国家干线分流省网输气量"的双向可能。
- 公司自建苏皖天然气管道联络线（宣城广德市，16.096km，D610mm，设计输气规模 2.3 亿方/年，2026-07-31 环评报批前公示）：直接接入江苏方向气源，是明确的自主增量。
- 环保/能耗双控："双碳"战略推动天然气在一次能源消费占比提升，属需求侧长期利好。
- 情景：若 2027–2028 年国际气价回落 15% + 苏皖豫干线投产 → 安徽气源成本下台阶，公司购销价差扩大 0.01–0.02 元/方 → 按 45 亿方计增厚毛利 0.45–0.90 亿（乐观情景）。验证点：国家发改委/海关 LNG 进口均价、苏皖豫干线投产公告。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务：市场容量 × 份额变量
1. 供给侧份额：公司在安徽省内建成投运长输管线占全省 56%，是省内绝对主导者；新增两条支线（2027 投产）将进一步巩固。
2. 需求侧/客户份额：2025 年输售气量占安徽省天然气消费量 32.77%——这是最强的份额锚点。目标：随管网覆盖扩大（42 个县市 → 更多未接入县市），份额有望小幅提升。
3. 技术代际差：管网运营无技术代际差，属资产型垄断。
4. 成本曲线位置：省级管网具有自然垄断 + 规模效应，单位输气成本随气量上升而下降——公司在成本曲线左侧。
5. 份额二阶导数：2023 年 38.82 → 2024 年 44.95 → 2025 年 39.65 亿方，波动较大（2024 高基数为转售贸易气量）。扣除非经常性贸易气量后，份额处于缓慢上升期，非加速渗透期。

档位 2029E 输售气量 假设 可观测验证点
保守（守住） 44 亿方 皖北支线爬坡慢，工业需求疲软 季度气量同比 <3%
中性（小幅提升） 47 亿方 两条支线 2027 投产 + 工业需求稳增 2027 年报气量 >43 亿方

层2 扩展业务：主业迁移空间
1. 能力可迁移性：从"输气"迁移到"综合能源服务"（充换电、储能、能源聚合）——客户资源可复用（同一批工商户），技术部分可复用（能源站运营），迁移成本中等。
2. 新 TAM 弹性：安徽充换电与用户侧储能市场远大于单一燃气配气市场——TAM 弹性大。
3. 切入卡位：子公司安徽省充换电有限责任公司已成立（总资产 6.89 亿），卡位较早。
4. 客户认证门槛：充换电/储能无强制认证，门槛低 → 护城河弱，竞争激烈。
5. 信号验证：①充换电 2026H1 毛利率 −6.01%，仍亏损；②营收 0.658 亿，占比仅 2.54%；③无盈亏平衡公告。

→ 结论：综合能源是"未过验证点的中期期权"，不计入中性净利，且当前为负贡献。

层3 风险折扣：证伪信号
- 输售气量连续两年下滑（份额流失）
- 长输管线毛利率跌破 9%（价差被压缩）
- 两条支线投产延期超过 1 年
- 充换电业务亏损连续扩大且营收占比未提升
- 苏皖豫干线由其他主体运营并分流公司输气量

第四步：估值锚定（自下而上，非增速外推）

方法说明：不使用历史增速外推。按气量 × 单方毛利自下而上测算长输管线与城市燃气，用已披露的在建项目投产节奏（2027 年 7 月）与产能（设计输气规模）校验，另对充换电按零贡献处理。

总股本：5.258 亿股（525,813,345 股，2026 年中期分红以该股本为基数）

第四步进阶：重资产 / 周期股估值校正（本股触发：重资产 + 高负债 + 破净边缘）

校正1 资产质量折扣（PB 1.09x，接近破净，必须说明原因）
- 总资产 75.24 亿（2025 年末），净资产 42.92 亿，资产负债率 42.96%（2026H1 降至 42.69%）。
- 为什么接近破净？ ①资产专用性强：长输管网为埋地专用资产，除输气外几乎无其他用途，清算价值远低于账面；②公用事业定价管制：准许收益率 ≤7% 的制度上限直接压制 ROE 与估值中枢，市场给低 PB 是公允定价而非错杀；③重折旧：管网折旧年限不低于 30 年，长期折旧压制账面利润释放速度。
- 反向核查（是否存在金融资产未重估型真折价）：公司对联营/合营企业投资 2026H1 贡献收益近 2,000 万，但未持有大额上市公司股权，不存在"持股市值≈总市值"型安全边际。
- 结论：PB 1.09x 属合理的公用事业估值，不得单凭"接近破净"推导大空间。

校正2 周期位置校正
- 燃气属弱周期 + 政策管制型，非强周期。当前周期位置：气源成本高位回落的中段、需求温和复苏期。
- 2023–2025 年归母分别为 3.44 / 3.33 / 3.25 亿，三年中枢 3.34 亿；本报告中性 2029E 归母 3.80 亿，仅较中枢高 13.8%，未使用"单年好年景"或"拐点年化"，符合周期归一化要求。
- 明确标注：当前处于价差正常偏改善位置，非底部也非顶部，中性不做过度乐观或悲观调整。

校正3 杠杆下行情景（有息负债 20.10 亿，负债率 42.96%，必须附负面情景）
- 利率上行情景：有息负债 20.10 亿，若平均融资成本上升 100bp → 年增财务费用 0.20 亿，对应归母减少约 0.16 亿（−4.2%）。影响可控。
- 需求下行 + 利率上行双杀情景：气量降至 38 亿方（−15%）+ 利率 +100bp → 长输管线毛利减少 0.90 亿 + 财务费用增加 0.20 亿 → 归母降至约 2.55 亿，按 11x PE = 28.1 亿 → 5.34 元（−30.9%）。
- 两条支线投产风险情景：14.38 亿投资若投产延期且气量不达预期，年新增折旧约 0.48 亿（14.38 亿/30 年）而无对应收入 → 归母减少约 0.38 亿 → 3.42 亿 × 11x = 37.6 亿 → 7.15 元（−7.5%）。
- 结论：下行情景最坏 −30.9%，不转巨幅负值（因配气价格制度性保护），但足以吞噬全部上行空间，故不得标"大空间"。

期权纪律：苏皖豫干线（公司参与度未披露）、综合能源扭亏 → 均不计入中性 NAV，仅列入乐观情景。

⚠️ 交叉校验：现价 7.73 元对应 2026E PE 11.4x、PB 1.09x、股息率约 4.5%（按 2025 年每股股利 0.35 元）。A 股省级管网/城市燃气可比公司 PE 中枢约 12–16x。现价处于合理区间下沿，市场未充分定价两条支线 2027 年投产的增量，但也未过度悲观——属"合理偏低估"而非"深度低估"。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低估。现价 7.73 元对应 2026E PE 11.4x、PB 1.09x、股息率 4.5%，位于公用事业合理区间下沿。

安全边际：
- 中性远期 9.76 元 → 空间 +26.3%，不达"重点关注"的 >50% 门槛
- 悲观情景 6.28 元 → 下行 −18.8%，下行有限（配气价格制度性保护 + 4.5% 股息托底）
- 乐观情景 13.69 元 → +77.1%，需苏皖豫干线接入 + 综合能源扭亏共振
- 赔率结构良好：上行 +26.3%（中性）/ +77.1%（乐观）vs 下行 −18.8%（悲观），风险收益比约 1.4:1（中性） / 4.1:1（乐观），胜率高但弹性有限
- 下行保护：PB 1.09x 接近破净；每股净资产 6.97 元（2025 年末），距现价仅 9.8% 的账面价值缓冲；4.5% 股息率提供持有收益

介入条件：
1. 可现价分批建仓：7.73 元对应 2026E PE 11.4x，安全边际已具备
2. 加仓区间：7.00 元以下（PE < 10.4x、股息率 >5.0%）为较优加仓位
3. 加仓信号：①两条支线（固镇-灵璧-泗县、宿州-淮北-萧县-砀山）2027 年 7 月如期投产公告；②单季输售气量同比 >6%；③苏皖豫干线接入公司管网的正式协议
4. 减仓/止损信号：长输管线毛利率跌破 9%；或年度气量同比转负且连续两个季度

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 配气/管输价格管制下调（首要）：安徽省配气价格校核周期 3 年，若下一轮成本监审下调准许收益率或核定价格，直接压缩毛利。"准许收益率 ≤7%"是硬天花板。
2. 上游气源成本反弹且传导受阻：非居民联动幅度封顶 10%/季度，若气价单季暴涨 >15% 将无法一次传导，形成 1–2 个季度的价差倒挂。
3. 两条支线投产延期或气量不达预期：14.38 亿投资已投 4.56 亿（31.7%），若延期将产生"折旧先行、收入滞后"的剪刀差。
4. 苏皖豫干线分流风险：国家干线若由其他主体运营，可能分流公司省网输气量，反而成为负面变量（当前市场多视为正面）。
5. 综合能源持续失血：充换电子公司总资产 6.89 亿、毛利率 −6.01%，若持续扩大投入而迟迟不盈利，将拖累 ROE。
6. 工商业需求受电能替代/生物质供热分流。

第五步进阶：上行想象力情景（四类）

类型A 行业调整剩者红利（适用性：低）
省级管网属自然垄断，不存在行业出清逻辑。

类型B 政策反转期权（适用性：中高，本股最现实的上行来源）
- 被压制的点：①配气价格"准许收益率 ≤7%"硬上限；②管输价格受省发改委核定；③居民气价调整需听证。
- 反转信号：①安徽省发改委启动新一轮管输价格核定并上调（历史上省级管网管输费有上调先例）；②气源成本下降而终端联动滞后 → 价差被动扩张（这是当前正在发生的事，2026H1 毛利率 +1.39pct 即为此）。
- 重估弹性测算：若单方毛利从 0.128 元提升至 0.145 元（+13%），按 45 亿方计增厚毛利 0.77 亿，归母增厚约 0.58 亿 → 2029E 归母 4.38 亿 × 14x = 61.3 亿 → 11.66 元（+50.8%）。
- 验证点：安徽省发改委管输价格核定文件、季度单方毛利；证伪信号：新一轮成本监审下调准许收益率。

类型C 市场错杀修复（适用性：中）
- 错杀证据：①PE 11.4x 处历史低位区间；②PB 1.09x 接近破净；③2026H1 归母 +11.18%、毛利率连续 4 年上涨，基本面未恶化反而改善；④公用事业板块整体被市场冷落（高股息资产在成长风格占优时易被抛弃）。
- 修复触发点：市场风格回归红利/价值；或高股息资产因利率下行而重估。
- 修复弹性：若 PE 修复至 14x（行业中枢上沿），2026E 归母 3.55 亿 → 49.7 亿 → 9.45 元（+22.3%）。

类型D 技术突破 / 技术代际跃迁期权（适用性：不适用）
省网运营无技术路线性突破可能。

⚠️ 什么条件出现才上调至"重点关注"（需远期空间 >+50%）：
需同时满足——①苏皖豫干线正式接入公司管网（气量跳升至 50 亿方以上）；②安徽省发改委上调管输价格或准许收益率；③综合能源业务盈亏平衡。三者至少满足两项，且股价仍在 8 元以下，方可上调。

结论：纳入观察

理由：中性远期空间 +26.3%，为正但不达"重点关注"的 >50% 门槛。公司质地稳健（省级管网垄断、ROE 9.56%、现金流好、股息率 4.5%、负债率持续下降），下行有限（−18.8%），适合作为防御性红利仓位配置，而非高弹性进攻品种。
真正的上行弹性来自"苏皖豫干线接入 + 管输价格上调"两项均为政策/项目驱动的变量，目前均未落地——在它们明确之前，只能给"纳入观察"。
