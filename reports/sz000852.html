第一步：公司是干什么的？

一句话定位：中石化集团旗下唯一"油气装备 + 氢能装备"研发制造基地，主营石油机械设备、油气钢管、钻头钻具，并培育 LNG / 绿氢装备第二曲线；强周期、重资产、低净利、集团订单背书。

上游：钢材、碳化钨（钻头原料，2026 大涨）、电子元器件。碳化钨涨价直接压制钻头钻具毛利。

议价权：中偏弱。同质性装备低价竞争加剧，国内油企"提速降本增效"刚性压价；海外与差异化产品溢价能力略强。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：转嫁系数 ≈ 0.4–0.6（国内集采压价，成本难全转嫁）。依据：2026H1 毛利率仅 13.11%，碳化钨涨价直接拖累钻头钻具盈利；海外 / 差异化产品转嫁力较强（北美调价对冲）。
  • 因子2 毛利结构再平衡：分业务线毛利率——石油机械设备（偏低，受压裂设备投资缩减）、油气钢管（相对稳定，+8.31%）、钻头钻具（受碳化钨涨价承压）、氢能装备（培育期负毛利）。原料（钢 / 碳化钨）敏感权重集中于机械设备 + 钻头（合计约 68%），结构脆弱。
  • 因子3 库存与采购节奏：未披露显著囤货；2026H1 经营现金流 −6.99 亿（回款放缓 + 两金占用），无低价囤货收益扭曲。验证点：毛利率与现金流。
  • 因子4 政策 / 市场锚点：钢材 / 碳化钨受全球供需 + 运费（市场层）；无显著关税 / 出口管制。氢能受"十五五绿氢 200 万吨"政策驱动（政策层，需求侧）。情景：碳化钨继续涨价 → 毛利承压；证伪信号：综合毛利率跌破 12%。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量：国内油服装备存量市场，公司在中石化体系内份额高（集团唯一基地），中石油 / 国家管网 / 海外为份额增量。三档：保守守住（集团内）、中性小幅提升（海外 + 国家管网）、乐观抢份额（北美 / 中东突破）。验证点：季度境外营收占比、国家管网订单披露。
  • 层2 扩展业务：主业迁移空间（氢能 / LNG）：从传统油服装备向绿氢制储运装备迁移，新 TAM（十五五绿氢 200 万吨）数倍放大，但市场化节奏慢（2026H1 氢能营收 −44%），未过"批量订单 / 营收占比跳升"验证点，仅中期期权，不计入中性。
  • 层3 风险折扣：证伪信号：境外营收占比回落、国家管网订单不及预期、碳化钨持续涨价致毛利率破 12%、氢能无重大合同 → 下调增量。

第四步：估值锚定（自下而上，正常化净利润法）

方法说明（亏损股）：2026H1 归母 −641 万，亏损为周期底部 + 汇兑 + 减值叠加。采用正常化净利润法：估稳态营收 → 保守正常化净利率 → × 远期 PE → 目标市值。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 1.62 未破净，但重资产（固定资产占比高）、ROE 长期低（2024 净利仅 9688 万 / 净资产 31 亿 ≈ 3%）。破净未现但"低 PB"反映的是重资产低盈利，非安全边际；无金融资产未重估型折价（主业净资产即清算价值偏低）。
  • 校正2 周期位置校正：强周期（油服装备），当前周期位置 = 底部（油企资本开支优化、营收 −10%、新增订货 −5.1%）。中性净利已用周期归一化（正常化 1.75 亿，介于 2024 好年景 9688 万与亏损之间），未用单年好年景外推，也未用亏损年化。
  • 校正3 杠杆下行情景：经营现金流 −6.99 亿（H1）、应收账款高（信用减值 +1071 万），若利率上行 / 需求继续下行，净利可转负（悲观情景 1.2 亿仍正，但极端情景可转负）。下行保护弱，不得标"大空间"。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（相对中性锚）。现价 5.32 元高于正常化中性锚 3.30 元，PB 1.62 已含氢能 / 集团期权溢价。
安全边际：中性 −38.0%，悲观 −64.3%；乐观 +10.9%（需氢能放量）。风险收益不对称偏负，下行保护弱（现金流大幅负）。
介入条件：① 股价 < 3.5 元（接近正常化锚）才具安全边际；② 加仓信号：乌兰察布绿氢重大合同落地、氢能装备营收放量、经营现金流转正、境外占比持续突破 30%。
最大风险：① 油服周期持续底部、国内集采压价；② 碳化钨等原料涨价侵蚀毛利；③ 经营现金流持续大额负、应收账款减值；④ 氢能商业化慢于预期。
结论：暂不介入（中性远期空间 −38%，估值不具吸引力；但央企氢能装备基地期权显著，列入重点跟踪，待氢能合同兑现可重估）。

亏损股三问：① 为什么亏——油企资本开支优化致订货 / 营收降 + 汇兑损失 1797 万 + 信用减值 1071 万 + 所得税 478 万，属周期 + 一次性叠加，非主业崩塌。② 靠什么扭亏 / 时点——油服资本开支回暖 + 海外高毛利订单（占比已 25.6%）+ 氢能 / LNG 新业务放量，触发时点 2027–2028。③ 亏得起吗——净资产 31.4 亿、央企中石化背景融资能力强、集团订单背书，亏得起（非资不抵债）。
