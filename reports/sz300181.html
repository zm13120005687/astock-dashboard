佐力药业（300181）五步法分析报告

盈利股处置：联网核实 2026H1 归母净利 +3.75 亿元（盈利、健康），PE_TTM 14.6x 合理。按盈利股做常规 PE / 分部估值，不使用"正常化净利润"表述。

一句话定位：以乌灵菌粉为核心技术的药用真菌中药龙头，手握乌灵胶囊（独家一类新药）、灵泽片、百令系列等基药大品种，依托"院内下沉 + 院外向 C"双轮驱动，并推进可转债融资扩产。

（3）产业链传导

上游：乌灵菌粉自产（深层发酵技术，菌种自主保藏），原料成本可控；中药饮片药材价格波动但占比小。

下游：等级医院（基药 + 集采续约身份下沉）+ OTC / 电商（C 端品牌化）。下游需求刚性（失眠 / 情绪 / 慢病），议价权强（独家品种 + 基药壁垒）。

议价权：强。乌灵胶囊独家一类新药、基药 + 集采身份，集采后价格稳定未再降，品牌 + 渠道双壁垒。

第二步进阶：原料成本→毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：量化转嫁系数 ≈ 0.9（强）。中药独家品种集采后价稳，原料（菌粉自产）涨价可内部消化，毛利稳定。验证点：综合毛利率维持 60%+。证伪：毛利率破 55%（集采续约大幅降价）。
  • 因子2 毛利结构再平衡：乌灵系列（高毛利主力，占比 ~50%）、百令系列（中高）、灵泽片（高）、饮片（中）。各线对药材价格敏感低（自产菌粉 + 规模化），结构稳定无恶化。禁单一综合毛利率——分线看乌灵 / 灵泽均具提价 / 放量空间。
  • 因子3 库存与采购节奏：菌粉自产、库存周期可控，无囤货收益干扰；集采以价换量属真实放量非库存。长协 / 套保：无大宗套保需求。
  • 因子4 政策 / 市场锚点：①市场层——中药消费刚需、老龄化；②政策层——基药目录（托配备）、集采（以量换价）、饮片集采（增量）。情景：基药下沉兑现 → 乌灵放量；集采续约价稳 → 利稳。验证点：基层覆盖家数、集采执行量。证伪：集采续约大幅降价、基药红利不及预期。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：乌灵菌粉独家产能，扩产靠可转债募投；
  • 需求侧：1.6 万家等级医院 + 基层下沉（基药 986），覆盖广度提升；
  • 技术代际：独家一类新药 + 国家秘密技术，代际领先；
  • 成本曲线：菌粉自产规模化，成本曲线左移；
  • 份额加速度：失眠 / 情绪赛道渗透率仍低，处加速期。
    → 保守守住 / 中性（基药下沉 + 集采放量）/ 乐观（乌灵院外 C 端破圈）。验证点：基层覆盖家数、乌灵营收增速。
  • 层2 扩展业务：主业迁移空间：从院内处方向"院外 C 端消费"迁移（一路向 C），能力同源（品牌 + 渠道复用），新 TAM = OTC 安神助眠消费（远大于院内）；切入卡位早期（108 粒大包装 + 头部连锁）；认证门槛 = 品牌信任；信号验证 = 院外营收占比跳升。未过验证点仅作中期期权，但路径清晰。
  • 层3 证伪信号：集采续约大幅降价、乌灵增速降至个位数、灵泽片增长失速。

第四步：估值锚定（自下而上，非增速外推）

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非破净（PB 2.78），净资产 33.26 亿多为现金 / 应收 / 产能（轻资产中药，清算价值接近账面），无专用性折价；PB 合理。
  • 校正2 周期位置校正：中药消费为非强周期，用稳态分产品净利率（25% 量级）替代单年，已标注当前处于"基药红利释放期"，非周期底部。
  • 校正3 杠杆下行情景：资产负债率约 35%，财务稳健；即便集采续约降价，净利率仍有安全垫，下行情景（悲观 +12.5%）空间仍正，不触发转负。
  • 期权纪律：在研 1.1 类中药（灵香片 / 参灵颗粒）未过验证点，不计入中性净利，仅作乐观增量。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低（性价比高）。现价 13.16 元对应 PE(TTM) 14.6x，显著低于中药消费品牌同类估值，且 2026H1 在行业微增 0.4% 下仍稳健增长。

安全边际：中性远期 23.4 元 → 空间 +77.8%（>50% 重点关注门槛）；悲观 14.8 元 → +12.5%（仍正）；乐观 31.4 元 → +138.6%。

介入条件：① 现价 13.16 元已具安全边际，可分批；② 加仓信号：乌灵院外营收占比跳升、灵泽片增速维持双位数、可转债发行落地；③ 跌破 11 元（PE<12x）为强支撑加仓区。

最大风险：① 中成药集采续约大幅降价（虽历史集采后价稳，仍为首要风险）；② 医药代表合规趋严短期影响推广节奏；③ 中药消费政策控费；④ 单一大品种（乌灵）依赖度较高。

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：中药行业集中度提升、不规范推广出清，规范龙头（佐力）凭基药 + 循证优势份额提升。验证点：基药配备率、等级医院覆盖家数。证伪：份额流失。
  • 类型B 政策反转期权：基药目录（2026 版）2026-09-01 施行 + 饮片集采中选，政策红利刚落地，推动基层放量。验证点：基层销量同比。证伪：基药红利不及预期。
  • 类型C 市场错杀修复：若市场因医药控费情绪错杀，当前 PE 14.6x 已处历史低位，修复弹性大。验证点：估值分位、相对行业折价。证伪：基本面恶化。
  • 类型D 技术突破 / 代际跃迁期权：乌灵菌粉独家发酵技术（国家秘密技术）构成护城河；在研 1.1 类中药（灵香片Ⅲ期、参灵颗粒、灵莲花颗粒）若获批将打开新适应症曲线。硬验证点：临床进展 + 获批 + 量产。证伪：临床失败。
  • 上调重点关注的触发条件：当前中性已 +77.8% 达重点关注；若乌灵院外 C 端破圈 + 灵泽冲 10 亿兑现（乐观情景），可进一步上调目标价至 30 元+。

结论：重点关注（远期中性空间 +77.8% > 50%，基药 + 集采放量确定性高、估值合理偏低、财务稳健）。
