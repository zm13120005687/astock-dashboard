（3）产业链传导

上游：碳纤维原丝（含国产 T800/T1100 级）、树脂、芳纶纸。公司通过参股长盛科技推动高端碳纤维复合材料研发，向上游延伸；国产碳纤维预浸料批产供货是公司核心能力。高端碳纤维价格与国产化进度直接影响成本。

下游：① 军机主机厂（航空工业集团内部，需求由装备计划决定）；② 中国商飞（C919 批产，民机复材需求从研制转向批产）；③ 中国航发商发（商用发动机零组件）；④ 民航维修/高铁（优材百慕）；⑤ eVTOL 整机企业（低空经济）。

议价权判断：强。理由：① 航空复材技术壁垒极高、认证周期极长（民机认证需多轮测试与试验数据积累），一旦进入型号配套，客户替换成本极高、粘性极强；② 公司为航空工业集团旗下复材核心平台，军机领域近乎独家配套；③ 35.49% 的高毛利率与 25.98% 的低负债率佐证其产业链地位；④ 弱项在于民机复材初期利润率低于传统主力产品（公司明确说明"民机业务利润率低于传统主力产品，对整体利润形成一定影响"）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1｜成本传导弹性（pass-through）
- 军机复材（主力产品）：传导率≈0.8–1.0——型号定价机制（军品定价成本加成 + 审价）下，成本上行基本可传递；客户为单一集团内主机厂，议价权强；
- 民机复材（C919/发动机）：传导率≈0.5–0.7——批产初期为拿份额可能让利，公司明确"民机业务利润率低于传统主力产品"；
- 优材百慕（刹车盘副）：传导率≈0.7–0.9，国产替代逻辑下有一定定价权（+25.84% 净利增速佐证）；
- 低空经济预浸料：传导率≈0.6–0.8（80% 份额带来定价权，但赛道早期、客户议价）。
- 量化依据：2026H1 毛利率 35.49%（−2.30pct），降幅源于"产品结构调整（民机/研制任务占比上升）"而非成本失控——这是结构性而非周期性毛利承压。

因子 2｜毛利结构再平衡
- 分业务毛利率与原料/结构敏感权重：
| 业务 | 收入权重 | 毛利率（估） | 对碳纤维成本敏感度 | 对交付节奏敏感度 |
|---|---|---|---|---|
| 军机预浸料/构件（主力） | 约 80% | 38–45% | 高 | 高（批产节奏） |
| 民机复材构件（研制转批产） | 约 10–15% | 20–30% | 高 | 极高（认证与批产） |
| 优材百慕（刹车盘副/闸片） | 4.5% | 25–35% | 中 | 中 |
| 低空经济预浸料 | <2% | 30–40% | 高 | 高（早期） |
- 结构迁移结论：利润贡献正从"高毛利军机复材"向"低毛利民机复材"迁移（阶段性），压制综合毛利率；而民机复材一旦放量并进入批产稳态，毛利率有望回升。禁止用单一"35.49% 综合毛利率"外推未来结构——公司正处于"军机主导向军民并重"的结构切换期。

因子 3｜库存与采购节奏（timing）
- 军工复材长周期、按型号备货，库存与交付节奏匹配军品计划；
- 2026H1 经营现金流 13.72 亿元（+53.43%）远高于净利润（4.39 亿），反映预收款/应收改善、回款质量提升（公司自述"考虑早挂账争取回款"）；
- 纪律：现金流优异是军工复材的应有特征，不宜简单当作"利润改善前置"；同时不得将回款节奏变化当作盈利趋势。

因子 4｜政策 / 市场锚点（成本驱动变量）
- 市场层：碳纤维原丝价格与国产化率（公司参股长盛科技向上游延伸）、树脂价格、国产碳纤维产能扩张节奏。
- 政策层（本股核心变量）："十五五"新材料技术攻关与产能优化、低空经济产业政策与 eVTOL 适航取证、C919 批产与国产大飞机供应链自主化、商用航空发动机重大专项、国防装备投入计划。
- 情景与验证点：
| 情景 | 触发条件 | 验证点 | 影响 |
|---|---|---|---|
| 民机放量（乐观） | C919 批产提速 + 民机构件项目投产 | 民机复材收入、上发复材认证进度 | 打开第二增长曲线 |
| 军品节奏修复（中性偏乐观） | 预浸料交付恢复 | 季度营收与毛利率 | 收入与毛利率企稳回升 |
| 交付持续偏慢（悲观） | 军品节奏延后 + 民机尚未放量 | 营收同比 | 营收继续下滑、毛利率承压 |
| 低空经济放量（期权） | eVTOL 适航取证 + 商业化 | 深圳轻快世界收入 | 弹性大但确定性低 |
- 证伪信号：预浸料交付连续两季低于预期、民机认证进度延后、低空经济订单无公告、毛利率跌破 33%。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

层 1｜现有业务：市场容量 × 份额变量
- 市场容量：军机复材受装备投入驱动稳定增长；民机复材随 C919 批产打开；商用发动机复材从 0 到 1。
- 份额 5 锚点：
1. 供给侧份额：航空工业复材为航空工业集团复材核心平台，军机预浸料近乎独家配套，产能（北京/长三角/粤港澳三大园区 + 国内唯一大规格自动化芳纶纸蜂窝线）为国内领先；
2. 需求侧/客户份额：深度绑定航空工业主机厂、中国商飞、中国航发商发，认证周期极长 = 极高粘性；
3. 技术代际差：突破国产高性能 T1100 级碳纤维预浸料关键技术，T800 级在国产民机主结构完成验证——处行业主流及领先代际；
4. 成本曲线位置：规模效应 + 国产化降本，成本曲线偏左；
5. 份额变化二阶导：军机份额稳固饱和，民机份额处加速渗透早期（S 曲线左端，随 C919 批产爬坡）。
- 三档假设：保守"军品交付维持低位、民机尚未放量" / 中性"军品节奏修复 + 民机逐步批产" / 乐观"军品提速 + 民机放量 + 低空经济共振"。
- 验证点：季度营收与毛利率、民机构件项目投产进度、上发复材认证进度。

层 2｜扩展业务：主业迁移空间（新易盛范式）
- 判断"旧池塘（军机复材）→新池塘（民机 + 商用发动机 + 低空经济）"：
1. 能力可迁移性：技术同源、迁移成本低——同一套预浸料/复材工艺可复用于军机、民机、发动机、eVTOL；
2. 新 TAM 弹性：民机复材市场是军机复材的数倍（C919 批产 + 国产替代），低空经济为全新市场，弹性极大；
3. 切入时点与卡位：民机切入属早期但卡位核心（国产大飞机复材自主配套）；低空经济 80% 份额属先发；
4. 客户认证门槛：极高（民机认证需多轮测试与试验数据积累）——既是护城河也是放量阻力；
5. 信号验证：技术侧已过验证点（T800 民机主结构验证、蜂窝用于国产发动机短舱、国产大飞机前机身上壁板推进）；产能侧在建（民机构件项目 50% 基础施工）；收入侧尚未体现。
- 结论：主业迁移（军机 → 民机/发动机/低空）方向明确、能力可迁移、卡位核心，属"中期期权"；其中技术验证已过点、产能建设在途，但收入贡献需等 2028+。可按保守体量计入中性情景，大规模放量作乐观情景。

层 3｜风险折扣：证伪信号
- 军品预浸料交付持续低于预期、民机认证进度延后、民机构件项目投产推迟、低空经济订单无正式公告、毛利率跌破 33%、上游碳纤维供应或价格不利变动。
- 命中即下调/剔除增量。

  • 校正 1｜资产质量折扣（破净情形不适用）：本股 PB 3.35x，非破净。高 PB 需高 ROE 支撑：2026H1 加权 ROE 5.47%（年化约 11%）——PB 3.35x 对应 ROE 约 11%，处于合理偏高区间（戈登模型：ROE 11%、r 10%、g 3% → 隐含 PB 约 1.1–1.5x，说明当前 PB 已包含较高的成长预期）。归母净资产 78.12 亿元，以固定资产（三大生产园区、预浸料产线）+ 应收款项为主，资产专用性强但盈利能力扎实。
  • 校正 2｜周期位置校正：军工新材料为计划驱动、弱周期行业，但交付节奏具有周期性。禁止用单季年化（2026H1 × 2）。本报告采用"分业务线稳态净利率自下而上"（军机 20%、民机/发动机 12%、刹车 15%、低空 10%），已标注当前处于"军品交付节奏低点 + 民机切换期"。
  • 校正 3｜杠杆下行情景：资产负债率仅 25.98%，几乎无有息负债压力，经营现金流 13.72 亿/半年，杠杆下行情景不适用。悲观情景下 2029E 归母 8.00 亿、目标价 13.21 元（−29.8%），下行相对可控（低负债 + 高现金流提供缓冲）。
  • 期权纪律：低空经济大规模商业化、上发复材放量、民机批产超预期等未过验证点的期权，不计入中性净利（本报告仅按小体量保守计入低空经济 4 亿收入、发动机 3 亿收入），更大弹性放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：合理，略偏高。现价 18.81 元对应 2026E PE 约 35.4x（因 2026 年为业绩低点而显高）、PE(TTM) 29.86x、PB 3.35x，处于基准估值区间（18.1–19.1 元）上沿。

安全边际：
- 中性远期 23.47 元 → 空间 +24.8%，满足"纳入观察（>0）"但不达"重点关注（>+50%）"；
- 悲观情景 13.21 元 → 下行 −29.8%；
- 乐观情景 32.27 元 → +71.6%（C919 批产 + 商用发动机 + 低空经济共振）；
- 下行保护：资产负债率仅 25.98% + 经营现金流 13.72 亿/半年 + 股份回购（约 1 亿）+ 分红（约 3.09 亿）+ 航空工业集团背书。

介入条件：
1. 不追高。现价处于基准区间上沿，等回落至 17 元以下（2026E PE < 32x）安全边际更佳；
2. 加仓/上调信号：① 季度营收同比转正（军品交付节奏修复的确认）；② 民机构件项目进度加速（钢结构安装完成、设备进场）；③ 上发复材通过客户认证（商用发动机复材零组件放量的前置条件）；④ 低空经济获大额订单公告；⑤ 综合毛利率企稳回升至 37% 以上；
3. 观察指标：季度营收与毛利率、四大产能项目投资进度、民机复材收入占比、优材百慕增速。

最大风险（最可能破坏逻辑的因素）：
1. 军品交付节奏延后（首要）：2026H1 营收 −13.96%，主因"预浸料交付减少及产品结构调整"，若军品交付持续偏慢，基本盘承压；
2. 民机放量慢于预期：民机构件项目仍在基础施工（50%），认证周期长（上发复材认证仍在进行），收入贡献需等 2028+；
3. 产品结构切换压制毛利率：民机业务利润率低于传统主力产品，军转民的结构调整将持续压制综合毛利率（2026H1 −2.30pct）；
4. 估值已包含较高成长预期：PB 3.35x 对应 ROE 约 11%，成长预期已部分定价；
5. 低空经济商业化不确定：eVTOL 适航取证与商业化节奏存在较大不确定性。

结论：纳入观察

理由：中性远期空间 +24.8%（>0），符合"纳入观察"标准；公司质地优秀（航空复材龙头、技术领先、客户粘性极强、高毛利、低负债、强现金流、集团背书），四大产能项目（17.55 亿）正从建设期走向收获期；但2026 年处于业绩低点（军品交付节奏 + 结构切换）、当前估值已处基准区间上沿，故不达"重点关注"门槛。属"逻辑正确但短期承压、需等军品节奏修复与民机放量"的观察型标的。
核心跟踪点：季度营收同比转正 + 民机构件项目进度 + 上发复材认证进度 + 低空经济订单。

第五步进阶：上行想象力情景（四类，只进乐观栏）

  • 类型 A｜行业调整剩者红利：本股不属过剩出清行业，但航空复材呈寡头格局，公司作为航空工业集团核心平台，在国产大飞机供应链自主化中份额与地位进一步巩固。验证点：民机复材订单/收入占比提升；证伪信号：民机配套被其他厂商替代。
  • 类型 B｜政策反转期权："十五五"新材料技术攻关 + 低空经济产业政策 + C919 批产供应链自主化 + 商用航空发动机重大专项。具体政策已列示；反转/兑现信号：C919 年交付量爬坡公告、上发复材认证通过、低空经济适航取证落地；重估弹性：民机复材收入从 0 向 10 亿+ 放量，对应可支撑归母 13–15 亿。部分兑现中（技术验证已过，产能在建）。
  • 类型 C｜市场错杀修复：本股 2026 年因军品交付节奏下滑被市场压制（营收 −13.96%、归母 −27.44%），若交付节奏属"节奏问题"而非"需求问题"，则存在错杀修复机会。错杀证据：2026Q2 营收降幅已收窄至 −4.72%、经营现金流 +53.43%（回款质量优异）、四季度产能项目集中投产。修复触发点：季报营收同比转正、毛利率回升。这是本股最有现实性的上行来源之一。
  • 类型 D｜技术突破 / 技术代际跃迁期权：碳纤维复材技术代际跃迁——公司突破国产高性能 T1100 级碳纤维预浸料关键技术，T800 级在国产民机主结构完成验证，蜂窝材料用于国产大涵道比发动机短舱。三要素共振：① 政策驱动技术路线（"十五五"新材料攻关 + 大飞机国产替代）；② 行业趋势向国产高性能复材收敛（C919 批产 + 商用发动机）；③ 公司技术已投产落地（T1100/T800 预浸料研制成功、发动机零组件项目已具备投产条件）。硬验证点：中试/产线跑通（已具备）、客户定点（部分具备：民机主结构验证、商飞配套）、量产成本优于旧路线（待验证）。三者有两项已具备 → 可按保守体量计入中性（民机 6 亿 + 发动机 3 亿收入），更大跃迁作乐观情景。
  • （额外）低空经济期权：eVTOL 预浸料 80% 市占率 + 28 家核心客户，若低空经济商业化提速，弹性极大但确定性低，仅按小体量计入中性，大放量作乐观情景。

纪律：上述情景只进"乐观/机会"栏，不进中性锚。什么条件出现才把结论上调至重点关注：① 季度营收连续两季同比正增长 + 毛利率回升至 37% 以上；② 上发复材通过客户认证并获批量订单；③ 低空经济获大额订单公告；④ 在此基础上 2029E 归母达 14 亿以上（对应目标价 >28 元、空间 >+50%），方可升级。
