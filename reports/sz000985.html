大庆华科（000985）五步法分析报告

分析日期：2026-09-24 ｜ 现价 17.23 元（2026-09-24 收盘价，腾讯行情核验）｜ 总市值 22.34 亿 ｜ PE(TTM) 1032.67x（失真，利润极薄）｜ PB 3.67x ｜ 总股本 1.296 亿股（全流通）
行业：石化新材料 / 精细化工（C5/C9 石油树脂、聚丙烯）｜ 板块：深市主板
微亏处理声明：2026H1 归母 +380.12 万元看似微利，但扣非净利润 −37.56 万元且 Q2 单季归母 −185.52 万、扣非 −548.85 万，盈利主要来自资产处置 372.57 万 + 政府补助。主业处于盈亏平衡线下方、强周期薄利状态，本报告按实质微亏框架（正常化净利润法）处理，回答三问。

第一步：公司是干什么的？

一句话定位：中石油旗下（大庆石化持股 55.03%）的石化新材料 / 精细化工企业，以乙烯裂解装置的 C5、C9 馏分为原料，生产石油树脂、聚丙烯、异戊二烯等，拥有八套主要生产装置。

股东背景：央企中石油体系 + 大庆高新国资（8.47%），典型小盘国资化工平台。

（3）产业链传导

上游：乙烯 / 丙烯裂解装置（中石油内部供应），C5/C9 为裂解副产，原料成本随油价与裂解负荷波动。

议价权：弱。毛利率 4.48% 印证——成本端难转嫁、产品端无定价权。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：传导率 ≈ 0.1–0.2（聚丙烯等大宗品完全竞争，成本自扛）。验证点：产品售价 vs 原料成本同步性；证伪：毛利率持续 <3%。
  • 因子2 毛利结构再平衡：分产品——聚丙烯（占 38%）毛利率最低（大宗商品），石油树脂（占 9%+其他树脂）毛利率较高；综合 4.48% 掩盖"聚丙烯拖累、树脂支撑"结构。验证点：各产品分部毛利率。
  • 因子3 库存与采购节奏：原料多为内部长约，库存损失风险中；但产品价格随石化景气快速回落（Q2 毛利率 2.66%）。
  • 因子4 政策 / 市场锚点：原油价格（成本驱动）、出口退税（树脂出口利好）、双控（高耗能限制）。情景：若油价上行 + 树脂出口退税率提高，毛利可修复 1–2pct；验证点：油价、退税政策发文。

第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：C5/C9 分离产能国内中等，利用率平稳。
  • 客户份额：树脂出口欧洲 / 东南亚，客户分散。
  • 技术代际：拥有多项国家发明专利（C5/C9 分离、氢化树脂），技术中等偏上。
  • 成本曲线：依托中石油内部原料，成本曲线略优。
  • 份额加速度：精细化工国产替代缓慢渗透。
    → 中性：守成 + 小幅替代；乐观：氢化树脂放量抢份额。验证点：出口订单、树脂销量。
  • 层2 扩展业务：主业迁移空间：从大宗聚丙烯向高附加值氢化树脂 / 特种材料迁移（技术同源），属"中期期权"，验证点：高附加值产品营收占比跳升。
  • 层3 证伪信号：聚丙烯景气续降、树脂出口受阻、扩能未达产。

第四步进阶·重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣（破净原因）：公司未破净（PB 3.67x），但八套老旧石化装置专用性强、清算价值低，3.67x 的高 PB 反映"小盘国资 + 重组题材"溢价而非资产质量。
  • 校正2 周期位置校正：石化下游强周期，2026H1 毛利率 4.48% 处于周期底部偏弱；中性净利取历史正常化中枢（0.20 亿），禁用 2022 高油价年或单季恶化年外推。
  • 校正3 杠杆下行情景：资产负债率低（国资背景、现金充裕，经营现金流 7355 万为正），下行风险主要为景气进一步恶化致扣非扩大亏损，空间转负但幅度有限（最悲观 −91%）。

亏损股三问

  1. 为什么亏（薄利）：① 聚丙烯等大宗品产能过剩、毛利率极低；② 综合毛利率仅 4.48%、Q2 2.66%；③ 期间费用刚性；④ 归母靠资产处置 372 万 + 补助转正，扣非已微亏。
  2. 靠什么扭亏·触发时点：① 异戊二烯扩能提升高附加值产量；② 氢化石油树脂放量改善结构毛利；③ 出口退税率提高。预计 2026H2–2027 扣非转正。
  3. 亏得起吗：经营现金流 7355 万为正、国资背景、无大额有息负债，完全亏得起，无生存风险。

第五步：综合赔率判断（买不买？）

当前价格位置：严重高估。正常化 PE 111x、PB 3.67x，与薄利 / 微亏的基本面背离，市值 22.34 亿对应年化正常化净利仅 0.20 亿。

安全边际：中性远期 3.40 元 → 空间 −80.3%；悲观 1.54 元 → −91.1%。

介入条件：仅当股价回落至 4 元以下（对应正常化 PE < 25x、PB < 1x）且扣非连续两季转正时考虑。

最大风险：
1. 石化景气持续低迷，聚丙烯 / 树脂价格战致毛利率破 3%；
2. 小盘国资"重组题材"退潮后的估值回归；
3. 营收持续收缩（26→18 亿趋势）未被逆转。

结论：暂不介入

公司国资背景、现金充裕、无生存风险，具备边际改善路径，故不判"坚决回避"；但现价较正常化估值高估 4–5 倍，风险收益不对称，暂不介入。回落至 4 元以下且扣非转正可重新评估。

第五步进阶·上行想象力情景（四类）

  • 类型A 行业调整剩者红利：老旧装置退出（七部门行动方案）利好合规精细化工集中度提升。验证点：中小企业退出公告；弹性：份额 + 毛利修复。
  • 类型B 政策反转期权：出口退税提高 / 石化更新改造补贴。验证点：退税政策发文；仅作机会情景。
  • 类型C 市场错杀修复：不适用（当前为题材溢价）。
  • 类型D 技术突破 / 代际跃迁期权：氢化树脂 / 特种材料技术升级，硬验证点（量产良率 + 大客户定点）未满足，仅作机会情景。
  • 上调至重点关注的条件：氢化树脂营收占比跳升 + 扣非净利连续两季 > 500 万 + 股价回落至 PB < 1.5x。
