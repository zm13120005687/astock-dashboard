一句话定位：乘用车车身结构件与防撞系统零部件供应商（冲压/焊接/轻量化），客户以一汽大众等合资品牌为基本盘，正艰难地向新能源（比亚迪/小鹏/北美新能源）与飞行汽车（小鹏汇天）客户迁移。

（3）产业链传导

上游：车用钢材、铝材成本占产品总成本比重高（年报风险提示），价格波动直接影响毛利。

下游：主机厂（合资/新能源），议价权弱——整车价格战向零部件传导，公司被动承受降价。

议价权：弱。客户集中（前五 65.64%）、产品同质化，成本传导不顺，毛利率持续被挤压。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：整车价格战下，零部件议价权弱，钢材/铝材涨成本传导率≈0.3–0.4（主要靠 VAVE 内部降本对冲，难转嫁客户）。
  • 因子2 毛利结构再平衡：分业务毛利率分化极大——金属件 4.67% < 综合 9.22% << 非金属件 19.48% ≈ 模具 19.43%。金属件占营收 72% 且毛利塌方，是整体盈利主要拖累；高毛利非金属/模具占比提升是结构性改善方向。禁单一综合毛利率代表全结构。
  • 因子3 库存与采购节奏：原材料按需采购 + 长协锁定部分，但金属件跌价/存货跌价准备 1.86 亿（计提比例 15.76%）显示资产端风险。
  • 因子4 政策/市场锚点：① 市场层——钢/铝价格；② 政策层——以旧换新补贴（托底合资出货）、新能源补贴（驱动轻量化需求）。验证点：钢铝价格、以旧换新效果、新能源渗透率。证伪信号：原材料大涨且无法转嫁、价格战致金属件毛利破 3%。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：合资品牌（一汽大众等）中国份额持续下滑，公司在合资体系内份额守成但总量收缩；新能源客户为新份额来源。三档：保守守合资份额／中性新能源抢量／乐观主导轻量化品类。验证点：一汽大众等季度出货、比亚迪/小鹏定点公告。
  • 层2 扩展业务（主业迁移空间）：从"合资金属结构件"迁移到"新能源轻量化总成 + 飞行汽车 + 两轮车"，新 TAM 弹性大。五点：① 能力可迁移（冲压/焊接/轻量化同源）；② 新 TAM 数倍；③ 切入早（新能源 86% 订单）；④ 认证门槛（主机厂定点）；⑤ 信号验证（120+ 新项目、客户名单扩张）。中期期权，未量产不计入中性。
  • 层3 风险折扣（证伪信号）：合资出货续降、新能源项目量产延期/丢单、金属件毛利破 3%、客户集中度风险暴露。命中则下调增量。

第四步：估值锚定（正常化净利润法）

亏损股方法：无正净利可锚，按 RULES 三步推导——① 估稳态营收 → ② 算正常化净利率（取保守）→ ③ × 远期合理 PE = 目标市值 → 目标价。禁硬套 PE。

总股本：约 15.86 亿股（2025 年报实收资本 15.86 亿、EPS −0.053 倒算一致；以现价 3.38 元 × 15.86 亿 = 53.6 亿市值、PB 1.32 交叉验证）。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣：PB 1.32，净资产 41.75 亿，但含存货 9.92 亿（跌价准备 1.86 亿、计提 15.76%）、应收+应收款项融资等，真实清算价值低于账面，非"金融资产未重估型破净"，无安全边际加成。
  • 校正2 周期位置校正：处盈利周期底部且仍在恶化（净利 2023 +1.02 亿 → 2025 −0.85 亿 → 2026H1 −0.81 亿），中性采用保守正常化净利（不按 2023 峰值外推、不按单季扭亏年化）。
  • 校正3 杠杆下行情景：资产负债率仅 36.4%（低），但有息负债 ~8 亿、连续亏损侵蚀净资产，若转型证伪净资产持续缩水，悲观情景空间至 −86.7%。
  • 期权纪律：新能源/飞行汽车/两轮车迁移属中期期权，仅计入乐观情景，不计入中性 NAV。

亏损股三问（必答）

  1. 为什么亏：① 市场竞争加剧致主营产品销量减少、价格战传导；② 前期资本投入高、部分项目产能未充分释放、规模效应不明显；③ 金属件（占营收 72%）毛利率仅 4.67% 且持续下滑（2026Q2 综合毛利率 4.23%）；④ 车用钢材/铝材成本占比高；⑤ 叠加信用/资产减值计提（2026H1 减值 1380 万）。
  2. 靠什么扭亏，触发时点在哪一年：① 新能源订单占比升至 86%（120+ 新项目，电池壳体/铝副车架/镁合金件）；② 客户由合资向比亚迪/小鹏/北美新能源/小鹏汇天（飞行汽车）迁移；③ 募投"新能源零部件智造中心"产能释放；④ 高毛利非金属件（19.48%）、模具（19.43%）占比提升 + VAVE 降本。触发时点：新项目定点→量产需 1–2 年，预计 2027–2028 年逐步放量兑现扭亏。
  3. 亏得起吗：能撑。经营现金流持续为正（2025 年 6.14 亿、2026H1 2.53 亿，回款强、应收从 8.49 亿降至 6.11 亿）；账面货币资金 14.78 亿；资产负债率仅 36.4%、有息负债 ~8 亿，短期不缺钱。但若转型持续不及预期，净资产将被连续亏损侵蚀，长期承压。

第五步：综合赔率判断（买不买？）

当前价格位置：显著偏贵（对亏损股）。现价 3.38 元对应市值 53.6 亿，而正常化盈利（2029E 中性 1.25–1.5 亿 × 15–18x）仅支撑 19–27 亿市值，透支一倍有余；当前仍处亏损扩大通道。

安全边际：
- 中性远期 1.18–1.70 元 → 空间 −64.5% ～ −49.7%（远低于现价）
- 悲观 0.45 元 → 下行 −86.7%
- 乐观 2.71 元 → 仍 −19.8%（需完美转型）

介入条件：仅当① 新能源项目量产公告 + 单季扭亏信号；② 股价回落至 1.5 元以下（接近正常化/净资产价值）；③ 非金属件/模具营收占比突破 40%。否则不介入。

最大风险：
1. 转型证伪：86% 新能源订单量产延期/丢单，金属件持续失血
2. 合资基本盘塌缩：一汽大众等份额加速下滑，营收总量续降
3. 毛利破阈：价格战致综合毛利率长期 <5%，无固定成本覆盖
4. 净资产侵蚀：连续亏损 + 存货/应收减值，PB 向 1 以下滑

上行想象力（四类情景，仅进乐观/机会栏）：
- A 行业出清剩者红利：零部件价格战后中小厂出清，头部（含英利）份额与定价权回升（验证点：行业集中度；证伪：价格战持续）
- B 政策反转期权：以旧换新加码/新能源补贴延续托底合资与轻量化需求（验证点：补贴政策；证伪：政策退坡）
- C 市场错杀修复：亏损股情绪修复 + 单季扭亏催化估值反弹（验证点：扭亏公告；证伪：亏损扩大）
- D 技术突破期权：轻量化（铝/镁/复合材料）总成 + 飞行汽车（小鹏汇天）从 0 到 1 放量（验证点：定点/量产；证伪：技术或客户流失）

上调至重点关注的条件：连续两季扣非扭亏 + 新能源营收占比破 50% + 经营现金流稳正，三者兑现方可重估。

结论：暂不介入
