泰坦科技（688133）五步法分析报告

第一步：公司是干什么的？

一句话定位：国内科学服务一站式龙头，为高校、科研院所、创新药 / 半导体 / 新材料企业的实验室提供"科研试剂 + 特种化学品 + 科研仪器及耗材 + 科研信息化"全栈产品与技术集成解决方案，对标赛默飞、默克等进口巨头做国产替代。

核心产品：自主品牌科研试剂（通用试剂、高纯溶剂、电子级溶剂）、特种功能化学品、实验室仪器（生物 / 化学 / 分析耗材）、智能实验设备、科研信息化软件（探索平台）。

主要客户 / 下游：高校科研院所、创新药 / CXO、半导体、新材料、新能源企业。报告期末探索平台数据对接企业 126 家、高校科研院所 16 所；前三百存量重点客户 + 二百增量重点客户双轮覆盖。

产能基地：松江小昆山（生物 / 化学试剂小批量）、奉贤（仪器耗材子公司）、宜昌（通用试剂及特种功能化学品放大生产）、安庆（高纯溶剂、电子级溶剂）；另有大量 OEM 厂商。

（3）产业链传导

上游：基础化学品、电子化学品原料、仪器核心零部件。公司对上游为买方，部分大宗原料随油价 / 化工品周期波动。
下游：科研与产业研发客户，需求刚性但价格敏感（经费约束）。
议价权：中等偏弱——科研试剂自主品牌有溢价（毛利率 31.21%），但仪器耗材贸易属性强、对下游转嫁有限。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：科研试剂自主品牌转嫁系数约 0.5–0.6（原料涨可部分传导至协议客户）；仪器耗材贸易业务转嫁系数约 0.2–0.3（买方强势、竞争激烈，自己扛）。加权实际毛利承压 = 上游变动 ×(1−0.4) 左右。
  • 因子2 毛利结构再平衡：高毛利科研试剂（31.21%）占比提升、低毛利仪器贸易（主动压缩）占比下降，是结构优化方向；但 2026H1 综合毛利率仍 −1.28pct，因新增基地产能未充分利用拉低单位毛利。分业务线看：试剂稳增、仪器耗材下滑，加权结构迁移正在进行。
  • 因子3 库存与采购节奏：公司按订单预测 + 库存计划采购，无大规模低价囤货收益；新增基地投产带来"产能闲置 + 折旧"而非库存收益，当期毛利被折旧掩盖真实盈利能力，需区分"折旧拖累"与"经营毛利"。
  • 因子4 政策 / 市场锚点（原料成本驱动变量）：①进口高端试剂 / 半导体材料受出口管制与汇率影响（成本端）；②国产替代补贴与"首台套"采购倾斜（降本 + 需求端）；③化工原料价格周期（影响特种化学品毛利）。情景：若化工原料下行 → 特种化学品毛利改善；若出口管制收紧 → 进口替代加速、自主品牌量增。验证点：季度分业务毛利率、宜昌 / 安庆基地产能利用率。证伪信号：综合毛利率连续跌破 20%、试剂占比下滑。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：公司是国内科学服务全栈龙头，相对外资份额仍低（国产化率 <30%），国产替代是份额主升浪。
  • 需求侧：前三百 + 二百重点客户深度覆盖，探索平台绑定提升复购。
  • 技术代际：自主试剂配方 + 信息化平台构成差异化。
  • 成本曲线：新基地满产摊薄单位成本，规模效应左移。
  • 份额加速度：国产替代处于加速渗透早期（S 曲线中段）。
    → 三档：保守守住 25 亿 / 中性 33 亿 / 乐观 38 亿营收（2029E）。
  • 层2 扩展业务：主业迁移空间：从"科研试剂"向"半导体级电子溶剂 + 科研信息化平台"迁移，能力同源（化学合成 + 平台软件），新 TAM（半导体材料 + 数字化）弹性大；信号验证：安庆半导体级溶剂验厂通过、探索平台对接企业 126 家。未过规模销售验证点，仅作中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：基地产能利用率持续 <50%、综合毛利率破 20%、重点客户流失 → 下调增量。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高。现价 22.04 已高于基准估值 18 元，市场在定价 2027–2029 基地满产后的盈利，但 2026 仍亏损、折旧压力未消。

安全边际：
- 中性远期 28.76 元 → 空间 +30.5%，未达"重点关注" >50% 门槛
- 悲观 14.5 元 → 下行 −34.2%
- 乐观 42.0 元 → +90.6%（需半导体溶剂与平台超预期）
- 下行保护：PB 1.34x、净资产 27.94 亿、资产负债率 43.7%、现金类资产可覆盖亏损与折旧

介入条件：
1. 回落至 18 元以下（PB < 1.1x）具安全边际
2. 加仓信号：宜昌 / 安庆基地产能利用率突破 70%、半导体级溶剂规模订单落地、探索平台对接企业数跳升
3. 观察指标：分业务毛利率是否回升至 22% 以上、经营现金流转正

最大风险：①新增固定资产折旧持续压制利润、扭亏晚于预期；②科研试剂价格战致毛利率破 20%；③宏观科研经费放缓拖累需求。

第五步进阶：上行想象力情景（四类，对冲系统性保守偏置）

  • 类型A 行业调整剩者红利：科学服务国产替代加速、进口品牌份额退潮，公司作为全栈龙头凭借产品矩阵 + 探索平台，份额与定价权跳升。验证点：国产化率提升、自主品牌营收占比跳升；证伪：进口降价反扑、份额流失。
  • 类型B 政策反转期权：科研经费加码 / 半导体材料国产化补贴 / "首台套"采购倾斜，若进口试剂受限则替代加速。验证点：相关扶持发文、半导体级溶剂订单；证伪：政策退坡。
  • 类型C 市场错杀修复：2026H1 由盈转亏致股价承压（PB 1.34x），一旦 2027 扭亏兑现，估值从"亏损折价"修复至正常化 PE。触发点：单季扭亏、经营现金流转正。
  • 类型D 技术突破 / 代际跃迁期权：安庆半导体级电子溶剂 + 探索平台从 0 到 1 投产，重构竞争格局。三要素：政策（半导体国产化）+ 趋势（国产替代）+ 落地（验厂通过、量产降本）。硬验证点：中试 / 量产良率达标、客户定点、量产成本优于进口；否则仅作机会情景。
  • 上调至"重点关注"的条件：基地满产验证（产能利用率 >70%）+ 半导体级溶剂规模订单 + 单季扭亏，且远期空间重估 >50%。

亏损股三问：
1. 为什么亏：2026H1 由盈转亏（−4269 万），主因新增固定资产（宜昌 / 安庆 / 奉贤基地）尚未充分利用、折旧摊销大增（管理费用 +47.4%），叠加财务费用 +23.66%（借款增加）、营业成本增速（+5.51%）高于收入（+3.8%）。
2. 靠什么扭亏、时点：基地满产摊薄折旧 + 高毛利试剂占比提升 + 探索平台客户扩张；2026Q2 归母仅亏 1030 万、环比改善 68%，预计 2027 年扭亏。
3. 亏得起吗：净资产 27.94 亿、资产负债率 43.7%，账面货币资金 + 筹资能力（H1 筹资 +1.6 亿）足以支撑 2–3 年亏损期，无退市风险（PB 为正）。

结论：纳入观察

资产质量扎实、国产替代逻辑清晰、扭亏路径可见，但 2026 仍亏损且当前价格已部分透支远期，需等基地满产与扭亏兑现确认。跌破 18 元（PB 1.1x 以下）再重点考虑。
