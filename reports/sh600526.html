（2）市场端（量价数据）

  • 需求结构切换：钢铁行业大规模超低排放改造已近尾声（公司半年报原文提示），传统非电除尘增量收缩；煤电"关停改造+灵活性改造+跨代升级"接棒——截至 2024 年煤电超低排放机组颗粒物/SO₂/NOx 排放较 2014 年已减 91%/92%/87%，存量优化替代增量建设成为主逻辑。
  • 行业竞争：污染治理市场主体众多、集中度低，价格竞争白热化（公司半年报原文风险提示）——装备毛利率承压是常态。
  • 公司最新季度量价（2026H1）：营收 −2.78%（减收）但归母 +15.30%、扣非 +14.88%（增利）；综合毛利率 27.31%→29.20%（+1.89pct）——项目执行管理改善 + 高毛利业务占比提升；管理费用 −8.88%、所得税 −33.81%。
  • 订单（核心前瞻指标）：H1 新增环保设备类订单 24.24 亿；海外订单 9.62 亿，同比 +264%；已签订合同尚未履约收入 59.57 亿元，预计未来 1–3 年确认——订单能见度极高（在手订单/年收入 ≈ 1.2x）。

（3）产业链传导 + 第二步进阶：原料成本 → 毛利结构四因子

因子1 成本传导弹性（转嫁系数）：原材料为钢材（型钢/钢板，占成本大头）、保温材料、电气件。电力央企客户招标制 + 竞争白热化 → 转嫁系数约 0.4–0.5（投标锁价为主，钢价上涨仅部分通过新增招标价格传导）。佐证：2026H1 钢价低位震荡是毛利率 +1.89pct 的外部顺风；若钢价回升 10%，综合毛利率约拖累 1.5–2pct。验证点：钢价指数（Myspic）与公司毛利率季环比；证伪信号：毛利率跌破 26%。

因子2 毛利结构再平衡：分业务毛利率——环保运营（水务）约 30%+ 且稳定（现金流型）；设备类历史约 25–28%（2026H1 项目毛利率改善）；海外订单毛利率显著高于国内（出口设备惯例溢价 5–10pct）。敏感权重：海外收入占比每升 5pct → 综合毛利率约升 0.3–0.5pct；H1 海外新签 9.62 亿已占设备订单约 40%，2027 年起收入结构将显著向高毛利海外倾斜。设备:运营收入比约 2:1，运营盘提供约 1.5 亿/年的类固定利润垫。

因子3 库存与采购节奏：H1 经营现金流 −3.84 亿（上年同期 +0.28 亿），主因在执行项目采购增加与结算方式变化——存货 8.24 亿（较年初 +52.54%）、预付款 2.76 亿（+89.10%）。这是低价钢周期主动备料 + 订单放量前置投入，属"备产型"现金流消耗而非恶化信号，但需逐季验证能否随项目结算回收。验证点：2026 年报经营现金流回正幅度；证伪信号：全年经营现金流持续为负 + 应收激增。

因子4 政策/市场锚点：①市场层——钢价（成本端，当前低位有利）、火电盈利（容量电价上调+碳市场，需求端支付能力）；②政策层——《节能降碳行动计划》2026–2028 直接列明改造清单（60 万千瓦级跨代升级、CCUS、灵活性改造"应改尽改"），为设备订单提供了 3 年可见的政策合同池；生态环境法典使碳排放评价成为新建项目强制环节（增量装备需求）。情景：煤电改造招标节奏 2026–2027 高峰、2028 回落 → 公司设备订单前高后稳。证伪信号：煤电核准/改造招标量连续两季下滑、海外订单增速转负。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务：市场容量 × 份额变量
- 市场容量：政策合同池（节能降碳行动计划 3 年清单）+ 海外新兴市场煤电建设（东南亚/中东/土耳其）双引擎；"十五五"城市污水 2500 万 m³/日改造托底水务。
- 份额锚点：①供给侧——全球燃煤电站电除尘装备最大供应商，技术标准制定者（电除尘器国家标准获省政府质量奖标准创新奖）；②客户份额——五大六小电力集团核心供应商，信用体系内竞争者少；③技术代际——高效节能型电除尘器获中国专利优秀奖，智慧环保清灰机器人为行业首创（工信部榜单）；④成本曲线——电除尘国产化基地，成本显著低于海外对手（海外 +264% 订单即成本曲线优势的体现）。
- 份额三档：保守（国内守住、海外 H1 节奏不持续）/ 中性（海外年新签 15–18 亿，国内政策合同池正常释放）/ 乐观（海外翻倍 + 智慧环保规模化）。验证点：季度新签订单公告、海外收入确认节奏；证伪信号：在手订单余额降至 45 亿以下。

层2 主业迁移空间（火电除尘 → CCUS/船舶降碳/智慧环保）
- 能力可迁移性：烟气处理技术同源，向 CCUS（碳捕集装备）与船舶尾气处理迁移成本最低。
- 新 TAM：CCUS 为火电存量改造政策点名方向（度电降碳 10% 要求）；船舶减污降碳受 IMO 碳强度法规驱动，为远大于国内电除尘的新池塘。
- 切入时点：CCUS 国家示范期、船舶装备认可期——早期卡位。
- 纪律：三者均未形成规模收入，未过验证点，不计入中性情景，只进乐观栏。证伪信号：CCUS 示范项目无商业化订单、船舶型式认可 2 年内无实船订单。

层3 证伪信号汇总：钢价上行 + 传导失败致毛利率破 26%；经营现金流连续为负；在手订单余额持续下降；海外订单增速转负。

第四步进阶·三道校正（本股重点）：
1. 资产质量折扣（破净原因必须说明）：PB 0.91x 破净的原因是资产盈利能力差而非资产虚高——ROE 仅 3.15%（低于资金成本），归母净资产约 46.6 亿对应的收入产能利用率不足、行业价格战压低资产回报，破净属公允定价，不能单凭 PB<1 推导"大空间"。正向因素：商誉近零（180 万元）、固定资产为在用环保装备产能（重置成本有效）、杭钢国企信用支撑应收回款——资产本身不虚。结论：破净给出的是"下行有限"而非"上行空间"，估值回归依赖 ROE 修复（海外高毛利占比提升是主要路径）。
2. 周期位置校正：钢铁改造周期尾声（需求下坡段）vs 煤电改造周期开局（需求上坡段）——公司处两条周期的换挡位，中性测算按"国内订单平稳 + 海外上行"的换挡完成态计，未按 H1 海外 +264% 的爆发态年化（拐点年化禁令）。
3. 杠杆下行情景：资产负债率 58.47%（<60%，杠杆风险中等偏低），有息负债以短期借款 6.63 亿为主且在压降（−18.61%）；但H1 经营现金流 −3.84 亿是真实约束——若回款恶化 + 存货跌价，悲观情景（−27.3%）需兑现。验证点：年报现金流回正。

上行想象力情景（四类，均只进乐观/机会栏）：
- A 行业调整剩者红利：价格战淘汰尾部环保装备厂 + 钢铁改造出清后，具备国家级技术平台（国家工程实验室、国家标准制定权）的头部企业份额与定价权跳升。验证点：行业集中度数据 + 公司毛利率站上 31%；证伪信号：低价中标进一步恶化。
- B 政策反转期权：《节能降碳行动计划》执行加码（煤电改造清单扩容、CCUS 示范扩围）或海外煤电建设政策窗口（新兴市场电力缺口）打开 → 设备订单再上台阶。重估弹性：设备收入 2029 年 +10 亿 × 净利率 8% = 0.8 亿增量净利 ≈ 市值 +11 亿（+26%）。未过验证点不计入中性。
- C 市场错杀修复：H1 现金流 −3.84 亿引发短期抛压属"节奏错杀"（订单与毛利率均在改善），若年报现金流回正即证伪恐慌、触发修复。触发点：2026 年报经营现金流转正。
- D 技术突破期权：CCUS（168 运行 + 省首台套）与船舶降碳（多国船级社认可）为 0→1 赛道。硬验证点：CCUS 获商业化订单 ≥1 亿 + 船舶环保实船订单落地 + 量产成本经第三方验证——当前均未满足，只作机会情景。证伪信号：示范后无商业订单。
- 上调至"重点关注"的条件：①海外订单年化 ≥30 亿（占比 >30%）确认高毛利结构固化；②ROE 回升至 6% 以上；③CCUS 或船舶赛道出现亿元级商业订单——三者满足其二才重估。

介入条件：
1. 价格：现价 4.77 元已在合理区间下沿，4.5 元以下（2026E PE < 12.5x、PB < 0.86x）为安全边际区；不追高至 5.2 元以上
2. 信号：① 年报经营现金流转正（验证备产投入回收）；② 三季报在手订单余额维持 60 亿上下；③ 海外收入确认落地（中报后首份海外收入占比数据）
3. 观察指标：毛利率阈值 26%、经营现金流、新签订单季度披露

最大风险（最可能破坏逻辑的因素）：
1. 现金流回款（首要）：−3.84 亿若延续至全年，备产投入无法回收，将侵蚀分红能力与国企信用溢价
2. 价格战：行业集中度低，海外订单放量引来更多竞争者压价，+264% 的高基数难以持续
3. 政策节奏：煤电改造招标若"前热后冷"，2028 年后订单断档
4. 钢价反转：当前毛利改善部分依赖钢价低位，成本传导系数仅 0.4–0.5

结论：纳入观察

中性远期空间 +25.6%，不满足"重点关注">50% 门槛；现价处合理区间、破净 + 订单能见度提供较厚下行缓冲，属"下有底、上需验证"的左低右稳型标的。核心跟踪点：年报现金流回正与海外收入确认，二者兑现是上调评级的前置条件。
