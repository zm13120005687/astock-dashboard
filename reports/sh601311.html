骆驼股份（601311）五步法分析报告

分析日期：2026-09-11 ｜ 现价 7.44 元 ｜ 总市值 约 87 亿 ｜ PE(TTM) 15.36x ｜ PB 0.90x ｜ 总股本 约 11.8 亿股
行业：电气设备 / 汽车低压电池（铅酸 + 锂电 + 再生铅）｜ 板块：沪市主板
核心特征：破净（PB 0.90）+ 铅酸稳底盘 + 低压锂电第二曲线（86% 增速、36 个新定点）。

第一步：公司是干什么的？

一句话定位：国内汽车低压电池（启停电池）龙头，给燃油车与新能源车做"启动 + 驻车供电"的低压电源系统——以铅酸（AGM/EFB 启停）为基本盘，正把车用低压锂电做成第二增长曲线，并配套铅回收闭环降本。

核心产品：
- 铅酸：汽车起动电池、AGM/EFB 启停电池（适配自动启停车型，单价与毛利高于普通电池）；
- 锂电：12V/24V 低压锂电池（PHEV/EV 驻车供电、智能座舱、48V 轻混系统），含软包电芯与 PACK；
- 再生铅：废旧电池回收→精铅→回流自供，形成"生产—回收—再生"闭环。

主要客户 / 下游：国内主机厂（上汽、一汽、东风、长城等）、海外车企（奔驰、宝马、大众、阿维塔、蔚来、小鹏、上汽大众）、售后替换市场（线上 + 线下渠道）。

境内外收入占比（2026H1）：国内约 84%，海外约 16%；海外受美国关税壁垒、中东反倾销税及地缘冲突冲击，上半年整体销量 -18.27%（中东区域 -85%）。

结构变化：铅酸（78.6%）仍是绝对主体但量价承压；锂电（7.2%）增速 +56.5%、毛利率 14.51%，是利润结构里唯一高速放量且持续改善的板块。

（3）产业链传导

上游：① 铅（LME 铅价）决定铅酸 + 再生铅成本，公司自有回收闭环可对冲约 30–40% 原料需求；② 锂电材料（锂/镍/钴/电解液）决定低压锂电成本，当前锂价低位利好毛利爬坡。

下游：主机厂（账期长、年降压力大）+ 售后替换（价格敏感度低、毛利高）。高端 AGM/EFB 与锂电客户议价权强于普通铅酸。

议价权：铅酸中低端偏弱（年降 + 产能过剩），但 AGM/EFB 高端化与锂电定点提升结构性议价权；再生铅亏损（-1.39%）反映回收端价差收窄，需靠规模与铅价回升修复。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）
    铅价上涨时，铅酸电池因客户年降 + 竞争，传导率约 0.5–0.7（部分自扛）；但公司再生铅自供对冲，实际毛利承压小于纯外采对手。锂电端锂价低位，成本传导压力小、毛利改善弹性大。验证点：LME 铅价走势、公司铅酸毛利率是否守住 18%+；证伪信号：铅价持续上行且毛利率跌破 17%。

  • 因子2 毛利结构再平衡
    三业务毛利率分化剧烈：铅酸 18.92% / 锂电 14.51% / 再生铅 -1.39%。随锂电营收占比从 7.2% 提升、再生铅占比下降，加权毛利率将从 16.03% 结构性上移。验证点：锂电营收占比是否逐季跳升；证伪信号：锂电毛利率跌破 10% 或再生铅持续深度亏损拖累整体。

  • 因子3 库存与采购节奏（timing）
    铅价低位时低价囤货→当期毛利虚高、远期回落；铅价高位接货→库存损失。锂电材料低位备货利好 2026H2–2027 毛利。验证点：存货周转与铅/锂采购均价；证伪信号：高价库存致下季度毛利率骤降。

  • 因子4 政策 / 市场锚点（原料成本驱动变量）

  • 市场层：LME 铅库存周期、锂盐期货价格；
  • 政策层：废铅回收环保核查（抬升违规小厂成本、利好合规龙头）、美国关税 / 中东反倾销（直接压缩海外毛利）、以旧换新补贴（拉动替换需求）。
    验证点：回收核查发文、关税税率变动、补贴接续公告；证伪信号：关税进一步扩大或补贴退坡。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 铅酸：乘用车启停电池国内 CR5 ~60%+，骆驼为龙头，份额稳中略升；AGM/EFB 高端化提升单值。保守守住 / 中性小幅提升 / 乐观抢份额三档：验证点=下季度 AGM/EFB 出货占比、主机厂定点公告。

  • 锂电：低压锂电早期，公司凭 36 定点卡位，份额随客户量产快速提升。验证点=量产定点数、出货 KWH。

  • 层2 扩展业务：主业迁移空间（铅酸→低压锂电）
    技术同源（电化学电源）→ 迁移成本低；新 TAM（新能源车低压电源）远大于存量替换；切入时点早（先发卡位）；客户认证门槛高（既是护城河也是阻力）；信号验证=奔驰/宝马量产、36 定点落地。这是"旧池塘→新池塘"的中期主线，已在手订单验证，可计入中性情景（非纯期权）。

  • 层3 风险折扣：证伪信号
    锂电毛利率持续 <10%、定点量产延期、海外关税进一步扩大致海外营收占比跌破 10%、铅价单边上行击穿铅酸毛利。命中则下调增量。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（破净原因）
    PB 0.90 破净主因：① 铅酸成熟行业、增长预期低导致市场给低溢价；② 再生铅短期亏损拖累净资产回报率（ROE 仅 ~8.7%）；③ 经营现金流 2026H1 阶段性转负（-8287 万）。但非资产专用性清算折价（电池产线可转产），亦非隐含负债虚高——属"周期 + 情绪"型破净，含真安全边际，可保留评级。

  • 校正2 周期位置校正
    铅酸处成熟稳定期、锂电视为早期渗透；当前盈利因海外逆风 + 高基数处阶段底部，中性净利已用 2026E 6.5 亿（底部年）而非高点外推，2029E 9.0 亿为产能 + 定点驱动，非"拐点年化"。

  • 校正3 杠杆下行情景
    资产负债率处制造业中等水平，但 2026H1 经营现金流转负、筹资净流入，提示回款与杠杆压力。悲观情景（海外逆风 + 量产延期）已给 -33.3% 下行，空间未转负，不构成"坚决回避"；但若现金流持续恶化需下调。

  • 期权纪律
    欧洲工厂满产、低压锂电渗透率超预期属乐观情景，不计入中性锚；但 36 定点已签且 18 个量产，其放量计入中性（非纯画饼）。

第五步：综合赔率判断（买不买？）

当前价格位置：低估（破净 + 低 PE）。现价 7.44 元对应 PB 0.90、2026E PE 13.4x，处历史底部区间；市场过度定价了 2026 年海外逆风与利润下滑。

安全边际：
- 远期中性 11.44 元 → 空间 +53.8%，满足"重点关注" >50% 门槛
- 悲观 4.96 元 → 下行 −33.3%，但破净提供一定缓冲
- 乐观 16.27 元 → +118.8%，需锂电超预期 + 海外修复
- 下行保护：PB 0.90、账面净资产约 96 亿（>市值 87 亿），破净本身即安全垫

介入条件：
1. 现价即可配置底仓：PB 0.90 已反映悲观预期，7.44 元下方越跌越具安全边际
2. 加仓信号：① 2026Q3 锂电出货延续 +80% 以上、毛利率站稳 15%；② 海外（中东外）销量转正、关税出现缓和信号；③ 经营现金流回正
3. 观察指标：逐季锂电营收占比、再生铅毛利率是否转正、海外销量同比

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 海外逆风持续扩大（首要）：美国关税 + 中东反倾销致海外 -18.27%、中东 -85%，若扩大将压制估值修复
2. 锂电量产不及预期：36 定点虽签，但客户年降 + 产能爬坡可能拖累毛利与节奏
3. 现金流阶段性转负：2026H1 经营现金流 -8287 万，若持续恶化将削弱"亏得起"与分红能力
4. 铅价单边上行：击穿铅酸毛利（传导率仅 0.5–0.7），再生铅修复不及预期

上行想象力情景（仅进乐观/机会栏）：
- A 行业出清剩者红利：废铅回收环保核查趋严，不规范小厂出清，合规龙头份额与定价权跳升。验证点=回收行业集中度数据；证伪=小厂出清慢、价格战持续。
- B 政策反转期权：美国/中东关税若因谈判缓和或贸易转向，海外营收占比回升。验证点=关税税率下调/豁免公告；证伪=关税进一步扩大。
- C 市场错杀修复：当前 PB 0.90 破净、PE 处历史底部，情绪修复弹性大。验证点=估值分位回升、机构上调评级；证伪=基本面恶化。
- D 技术突破期权：低压锂电从 0 到 1 第二曲线，靠自研软包电芯 + PACK 切入新能源，已获奔驰/宝马定点（硬验证点：量产交付 + 客户定点已落地）。证伪=良率/成本打不过旧路线、客户流失。

上调至重点关注的条件：锂电按 36 定点持续放量且毛利率站稳 15% 以上、海外销量转正、经营现金流转正——三者确认则远期 +53.8% 空间可靠。

结论：重点关注

理由：PB 0.90 破净 + 2026E PE 13.4x 已处历史底部（估值合理偏低）；锂电第二曲线 86% 增速、36 新定点、奔驰/宝马量产（业绩增长明确）；远期中性空间 +53.8% 达重点关注门槛。主要风险为海外关税逆风与现金流阶段性转负，但破净提供安全垫，属"低位布局、等锂电兑现"型标的。
