一句话定位：老牌 IT 服务商（1998 年成立），业务分两块：内地业务正在从传统系统集成向"AI 智算中心建设与运营 + AI 智能体行业应用"转型（本部 2026H1 收入 +29.7%）；香港业务（控股子公司 ASL，港股上市公司）贡献一半以上收入，属传统 IT 分销/集成，同时持有一笔美股 SaaS 投资（GDYN）。

（3）产业链传导

上游：GPU/AI 服务器（英伟达/国产算力卡）、网络设备、液冷散热——算力建设为资金密集 + 硬件采购占大头，硬件价格波动直接决定集成毛利（上游议价权弱，靠规模拿货）。下游：政府/运营商/金融资本开支，受财政与运营商 capex 节奏影响（应收回款 2026H1 已改善）。议价权：建设环节弱、运营/服务环节中——从"卖硬件集成"转向"卖 Token/运维服务"是毛利修复关键。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：算力建设中 GPU/服务器占成本 70–80%，硬件价格波动几乎全额传导（集成商赚服务费/管理费，约 8–15% 毛利），但传导方向不利——硬件涨价挤压集成毛利，客户预算刚性又限制合同价上调，传导率 ≈ 0.5；算力运营/服务（Token 工厂、运维、智能体订阅）毛利率 25–40%，是公司对冲硬件波动的结构性出路。2026H1 综合毛利率 10.43%（H1 单季）/11.96%（2025 年），处于 IT 服务低端。
  • 因子2 毛利结构再平衡：传统系统集成（ASL 为主）毛利率低（10% 上下）、增长停滞（ASL H1 -1.12%）；内地算力建设高增长（+29.7%）但毛利率同样低；真正的高毛利是 AI 智能体软件（投标大王/尽调智能体，毛利 50%+）与算力运营服务——目前占比尚小。公司必须实现"收入结构从集成向软件+服务迁移"，否则增收不增利（2025 年净利率仅 1.39%、扣非为负即为结构失衡之证）。
  • 因子3 库存与采购节奏：算力项目为"以销定采"模式（先中标后采购 GPU/服务器），存货与硬件价格波动风险由项目背书；2026H1 经营现金流 +2.35 亿（上年末大项目集中验收回款）说明回款节奏改善。无囤货投机收益，利润口径干净，但应收账款与存货占用仍大（总资产周转率 0.15 次偏低）。
  • 因子4 政策/市场锚点：市场层——GPU 供给与价格（国产算力卡供给改善直接利好交付毛利）、运营商/政府智算 capex 节奏；政策层——算力国产化替代进度、信创采购清单、Token 工厂集采若从电信复制到移动/联通（行业级订单放大）、美国对华 AI 芯片管制放松/收紧（影响硬件路线）。情景假设：移动/联通若跟进 Token 集采 → 行业订单空间×3；验证点=运营商集采公告、公司中标金额、毛利率季度变化。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 市场容量锚：国内智算中心建设/算力服务年市场数千亿级；Token 工厂集采新模式刚起步（电信宁夏 174 亿为首例）。容量不是约束，份额与订单转化率才是。
  • 供给侧份额：智算集成竞争者众（中科曙光、浪潮信息、紫光股份等体量远大于华胜），华胜市占率不足 1%；但在"Token 生成能力服务"新品类中，华胜以 18% 居标包一第一——新品类先发卡位是真实的份额变量。
  • 客户份额：政府（天津/宿州/无锡智算标杆）+ 运营商（移动天津、电信 Token）+ 金融（多家银行）三重认证关系，客户粘性强但单客户金额小、复购待验证。
  • 技术代际差：公司不自研 GPU/大模型基座，做"集成+调度+服务"，处于代际跟随位（绑定 MiniMax 等模型厂商），无代际领先但"懂场景+交付能力"有差异化。
  • 份额二阶导：内地收入 +29.7% 连续放量，份额在加速渗透早期（低基数）。三档：保守——年算力收入 8–10 亿（维持 2026 中报节奏）；中性——Token 集采全国复制中华胜保持 10%+ 份额，年 15–20 亿；乐观——移动/联通 Token 大单落地 + 运营服务占比提升。
  • 层2 扩展业务：主业迁移空间
  • 系统集成 → Token/算力运营服务（最实质的迁移）：能力同源（数据中心集成经验延伸至运营），新 TAM（Token 服务计价）弹性大，卡位=宁夏首单第一份额，认证门槛低，信号已验证（电信中标）——已过验证点，但商业模式（按 Token 计费的回款与毛利）还需 2–3 个季度数据确认。
  • IT 服务 → AI 智能体产品化：能力同源（行业 know-how + 大模型适配），投标大王/尽调智能体已商业化落地（银行/政务），复制门槛=行业模板可复用性，信号=产品收入占比是否跳升（尚未披露）——未过验证点，中期期权。
  • 内地 → 出海（ASL 东南亚/非洲网络）：已有 18 国网络，AI 出海项目起步——期权。
  • 层3 证伪信号：Token/算力新签金额连续两季下滑、智能体产品收入占比 <5%（无跳升）、扣非继续亏损扩大、GDYN 二次减值、光模块概念无营收落地。

纪律：中性情景只计入"已中标订单 + 本部现有增速的保守延续"，智能体产品化与出海只进乐观栏；光模块、GDYN 反弹一律不计入。

第四步：估值锚定（自下而上，非增速外推）

方法说明：真实亏损但剔除一次性减值后经营层面为正，需回答三问 + 正常化净利润测算。华胜的复杂性在于：一半收入在低增长低毛利的香港传统业务（ASL），一半在内地转型业务——用分部估值（SOTP）比单一 PE 更贴切。

总股本：约 10.965 亿股

亏损股三问

  1. 为什么亏：2026H1 归母 -2.45 亿的核心是子公司 ASL 持有的 GDYN（美股 SaaS 公司）长期股权投资减值 5.31 亿元——AI 技术迭代冲击传统软件商业模式、美国 SaaS 板块估值整体下行致 GDYN 股价大跌，属会计谨慎性原则下的非现金一次性损失（另有处置 ISH 股权收益 +1.64 亿部分对冲）。剔除减值与处置后，经营层面实际盈利：内地本部 +29.7% 增长、经营现金流 +2.35 亿为正。更深层原因：传统 IT 集成/分销业务利润率极薄（2025 年扣非仍 -1.94 亿，扣非已连亏 5 年累计超 10 亿），公司造血能力先天不足，盈利高度依赖投资收益与公允价值，经不起一次资产减值。
  2. 靠什么扭亏、触发时点：靠 ①算力业务放量（本部 +29.7%、Token/智算订单 2026–2027 集中交付）；②GDYN 一次性减值出清后 2026H2 无此包袱 → 2026 全年归母有望回到盈亏平衡至微利（H1 -2.45 亿 + H2 剔除减值后正常经营利润 2 亿+）；③若 2027 年算力收入 15 亿+ 且服务占比提升，归母可上 1.5–2.5 亿。触发时点：2026 年报扭亏或微亏、2027 年确认结构性盈利（扣非转正为硬信号）。
  3. 亏得起吗：亏得起。归母净资产 41.64 亿、总资产 92.25 亿、负债率约 48%、2026H1 经营现金流 +2.35 亿、账上现金充足（Q1 现金比率 52.52%）；财务费用因算力项目扩有息负债上升但绝对额可控（H1 0.21 亿）。5.31 亿减值后 GDYN 剩余账面仍在，除非再暴跌否则二次减值压力有限。与动力源/安泰的本质区别：净资产厚、无生存危机，问题只在"贵不贵"。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。PB 3.84x / 隐含 2029 PE ~100x，对一家净利率 1.4%、扣非连亏 5 年、一半收入在低增长香港传统业务的公司而言，现价几乎完全由题材（算力/AI/光模块）与市场情绪定价。2026-08-27 半年报亏 2.45 亿当日股价涨停即为"题材定价脱离基本面"的典型表现。

安全边际：
- 中性 SOTP 约 4.01 元 → 空间 -72.5%；悲观 3.65 元 → -75.0%；乐观 11.2–12.8 元 → -23% 至 -12%——三个情景无一为正；
- 净资产 41.64 亿（每股 3.80 元）+ 经营现金流为正构成硬底（约 3.6–4.0 元），即现价下方有约 70% 的理论回撤空间才到净资产支撑；
- 唯一正回报路径 = "AI 服务真兑现成 4 亿+ 净利"的乐观情景，且仍需 35x 高估值维持——赔率极差。

介入条件（必须等基本面证伪题材，而非追题材）：
1. 等业绩兑现：连续两季扣非转正 + 算力收入占比 >40%（证明内生造血而非概念）；
2. 等订单验证：移动/联通 Token 集采中标公告（订单模式全国复制的硬信号）；
3. 等估值回归：股价回落至 5–6 元以下（对应 2027E 中性净利 1.5 亿 × 30x = 45 亿附近）才出现基本面支撑；
4. 证伪线：光模块若始终无量产订单 + 智能体收入占比不跳升 → 题材证伪，维持回避判断。

最大风险（最可能破坏逻辑的因素）：
1. 题材定价崩塌：算力/AI/光模块主题退潮时，PB 3.84x → 净资产支撑（PB 1.0x）的理论回撤约 70%，流动性冲击下杀伤巨大；
2. 扣非持续为负：传统集成薄利 + 期权费用 + 财务费用上升，若算力业务毛利不足以翻转扣非，盈利逻辑证伪；
3. GDYN 二次减值：美股 SaaS 估值若继续下杀，ASL 剩余持股再计提减值，2026 年报盈利目标落空；
4. 订单确认节奏：智算大项目验收跨期长，收入确认与回款存在时间差（虽 2026H1 现金流转正）。

结论：暂不介入

判断逻辑：真实亏损但为一次性减值所致（剔除后经营为正、现金流 +2.35 亿、净资产 41.64 亿，不命中"坚决回避"标准）；算力/AI 转型方向真实（Token 集采 18% 第一份额、本部 +29.7%），但现价 159.8 亿已将最乐观情形定价完毕，中性 SOTP 仅约 44 亿，全部情景空间为负——"好方向，坏价格"。列为"暂不介入"，重点跟踪扣非转正与算力收入占比。

第五步进阶：上行想象力情景（调整型机会，供触发条件对照）

  • 类型A 行业调整剩者红利：Token 工厂集采若从电信复制到移动/联通（运营商全面转向 Token 服务），先发者华胜（宁夏标包一 18% 第一份额）在"算力建设—调度—Token 生成—运维"全链路有交付样板，可享新品类扩散红利。验证点：运营商集采公告中华胜中标份额、Token 服务收入季度确认。兑现条件 = 集采订单全国落地 + 运营毛利占比提升。
  • 类型B 政策反转期权：算力国产化/信创清单若将"Token 生成能力服务"纳入政府采购目录，或国产算力卡供给大幅改善（降低硬件依赖），公司毛利结构上移。反转信号：部委智算采购政策文件、国产 GPU 大规模交付。重估弹性：毛利率每 +3pct → 净利 +1.5 亿。未兑现，仅机会情景。
  • 类型C 市场错杀修复：不适用——现价是对基本面的"溢价"，若未来因订单兑现（2026 年报扭亏、扣非转正）后股价反被忽视，届时才是错杀买点；当前无错杀证据。
  • 类型D 技术突破/代际跃迁期权：光模块 TeamsunLink 400G/800G 若从"展示"走向量产并拿到客户定点——硬验证点：①获得头部云厂商/设备商批量订单（非演示）；②量产良率与成本曲线对标中际旭创/新易盛量产水平；③光互连资产权益归属明确归华胜（当前核心资产在合资方）。三者缺一则仅作机会情景。证伪信号：持续停留展示阶段、无定点公告。本期权是市场炒作"光模块概念"的根源，但距离真实贡献营收尚远。

纪律：想象情景只进乐观/机会栏。什么条件出现才把结论上调至"纳入观察"：股价回落至 6 元以下（对应 SOTP 合理市值 44–65 亿附近）或连续两季扣非转正 + 算力收入占比 >40%。上调"重点关注"需上述条件 + 移动/联通 Token 大单落地共同触发。
