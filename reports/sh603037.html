第一步：公司是干什么的？

一句话定位：汽车聚氨酯减震元件（缓冲块）的隐形冠军——新能源乘用车减震元件国内市占约 35.8%；同时做轻量化踏板总成，正向线控制动踏板与机器人软包零部件延伸。

- 踏板总成：上汽乘用车、比亚迪、长城、零跑、理想、奇瑞、吉利新车型项目；雷诺制动踏板项目突破；电子加速踏板纳入雷诺等

境内外与产能布局：
- 海外：墨西哥（2025 通过客户审核并量产交付缓冲块/踏板项目，通过 ISO14001&45001 与 IATF16949 审核）、美国、德国、摩洛哥（工厂筹建中）、日本办事处
- 国内：上海、江苏南通（二次搬迁完成，整合国内运营资源）、福建宁德、重庆、广东广州
- 2024 年产能利用率：减震元件 121.87%、踏板 112.10%（满负荷）

股东与资本结构：总股本 2.665 亿股；2026-06-30 净资产约 9.63 亿元（市值 26.09 / PB 2.71）；2025-08 发行可转债 3.08 亿元（净额 3.02 亿），其中 2.18 亿投南通扩产、0.90 亿补流。

结构判断：典型的"高份额 + 产能饱和 + 正在扩产"的成长型 Tier2。2026H1 收入 +10.87% 但归母 −19.04%、扣非 −29.97%，利润下滑主因：① 可转债利息与汇兑致财务费用由负转正至 906 万；② 政府补助减少；③ 毛利率 −3.58pct（原料涨价 + 年降）。
这是"费用一次性 + 成本周期性"的下滑，而非需求端恶化——新项目价值 3.2 亿、新产品收入 1.04 亿，需求端依然强劲。

因子2 毛利结构再平衡（禁止用单一综合毛利率掩盖迁移）
2026H1 综合毛利率 29.02%，但内部已发生明显的毛利贡献迁移：
- 减震元件：收入占 67.61%，毛利率估计 30–33%（成熟产品、份额高、规模效应）→ 毛利贡献约 0.85 亿（占公司毛利约 76%）
- 踏板总成：收入占 29.86%，毛利率估计 22–25%（金属件占比高、竞争更激烈）→ 毛利贡献约 0.27 亿（占 24%）
- 胶轮：收入占 2.11%，毛利率较高（估计 35–40%，非汽车领域无年降）→ 毛利约 0.03 亿
- 电池包辅材：新产品，为抢市场毛利率偏低（估计 15–20%），但增速 +50%
- 迁移方向：踏板总成与电池包辅材（低毛利）收入占比上升 → 结构性拉低综合毛利率，这是毛利率 −3.58pct 中约 1.0–1.5pct 的来源，其余来自原料与年降
→ 第四步必须分业务给毛利率，并显式考虑"低毛利新品占比上升"的结构性稀释。

因子3 库存与采购节奏（timing）
- 公司无期货套保披露，MDI/聚醚为现货或长协采购。
- 2026Q2 毛利率环比 −3.97pct（Q1 31.31% → Q2 27.34%），恰逢 MDI/聚醚 7–9 月快速上涨前的补库窗口，说明 Q2 已开始承接高价原料。
- 2026Q3（当前）：万华烟台检修 + 金九旺季，原料继续上行 → Q3 毛利率仍有压力；若万华 9 月中下旬复产，Q4 有望缓解。
- 不能把库存收益当真实盈利：公司通过"新材料研发及自动化改造"缓解成本压力，这部分是真实的结构性改善，可在第四步中保留（自动化降本）但不夸大规模。

份额三档假设 + 验证点
- 保守（守住 33%）：行业价格战导致部分定点流失 → 验证点：半年报新能源减震件销量（现 966.7 万件/半年）
- 中性（维持 35–36%）：随新能源销量增长而同步增长，份额持平 → 验证点：件数增速与新能源销量增速同步（现 +10% 左右）
- 乐观（升至 40%+）：海外（墨西哥/摩洛哥）+ 电池包辅材放量 → 验证点：海外收入占比披露、摩洛哥投产公告

层2 主业迁移空间（中期期权，未过验证点不计入中性）

迁移方向 A：轻量化踏板 → 线控制动踏板（EMB 踏板）
- 能力可迁移性：高（同为踏板总成，公司已完成同步开发与产线搭建，仅新增传感器与电子件）
- 新 TAM 弹性：传统制动踏板单车约 100–150 元；线控制动踏板（含踏板感觉模拟器与行程传感器）单车约 300–600 元，是传统的 3–4 倍。若 2029 年线控渗透率达 30%（L3 自动驾驶落地），对应市场约 30–50 亿元
- 切入卡位：较早（已完成实验测试 + 基础产线 + 至少两轮主机厂路试）
- 客户认证门槛：需通过功能安全（ISO 26262 ASIL-D）认证，门槛极高（既是护城河也是阻力）
- 信号验证：已完成两轮路试但未获量产定点公告 → 未过验证点，不计入中性净利，列入乐观情景

迁移方向 B：聚氨酯材料 → 机器人零部件软包
- 能力可迁移性：中（聚氨酯配方与生产工艺同源，但机器人软包需全新的结构设计、耐久与阻燃标准）
- 新 TAM 弹性：人形机器人/具身智能若放量，软包（缓冲、包覆、减震）市场空间大
- 切入卡位：早期（2025 年才组建团队）
- 客户认证门槛：整机厂认证，周期长
- 信号验证：无客户、无订单、无收入、无中试良率数据 → 完全未过验证点，不计入中性净利

层3 证伪信号
- 减震元件销量连续两季负增长 → 份额流失，中性情景下修
- 南通扩产项目进度公告延期（若 2027 年底仍未投产）→ 产能增量剔除
- 线控制动踏板 2027 年底前未获量产定点 → 该期权剔除
- 综合毛利率跌破 25% → 成本传导彻底失败 + 年降失控
- 可转债回售压力（若股价长期低于转股价 12.70 元的 70% 即 8.89 元）→ 现金流风险信号

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正1 资产质量折扣
- PB 2.71x，不破净。需核查是否存在资产虚高：
- 净资产约 9.63 亿，其中含可转债募资 3.02 亿（2025-08 到账，尚未完全形成产能）→ 在建工程占比阶段性偏高，若南通项目投产不及预期存在转固后折旧压力
- 商誉：2022 年非同一控制下合并普科马形成商誉，规模未披露 → 需关注减值风险（2026H1 无减值计提）
- 结论：资产质量中等，无虚高，但PB 2.71x 隐含了较高的成长预期，若南通项目延期则存在"高 PB + 低 ROE"的双杀风险（2026 年化 ROE 约 7.3%）

校正2 周期位置校正
- 行业属性：汽车零部件，弱周期。当前位置：新能源渗透率 60.6%（8 月单月）已处高位，行业从"渗透率红利"转向"存量竞争 + 年降"阶段；国内零售 −21.4%，出口 +66.7% 对冲。
- 中性净利禁止用"单年好年景"（2024 归母 0.904 亿）或"近三年均值"。采用产能 + 订单驱动的自下而上法得出 1.70 亿，未使用历史均值外推 → 归一化处理完成。
- 周期位置标注：行业渗透率高位、公司产能扩张初期 → 中性净利不过度乐观。

校正3 杠杆下行情景（必附负面情景）
- 资产负债率：可转债 3.08 亿发行后，负债率由约 20% 升至约 35–40%（估计），未超 60%，但需给出负面情景。
- 负面情景：若国内新能源销量增速降至 5% 以下且年降加码至 5%，叠加 MDI/聚醚维持高位（毛利率跌至 26%），南通项目延期至 2029 才投产 → 2029 收入仅 9.5 亿、归母 0.95 亿，对应 PE 18x = 17.1 亿 → 6.42 元（−34.4%）。
- 若同时触发可转债回售（股价长期低于 8.89 元，即转股价 70%），公司将面临 3.08 亿现金流出压力 → 流动性风险。
- 下行情景 −34.4%，不得标注"重点关注"，至多"纳入观察"。

期权纪律：线控制动踏板（未获量产定点）、安徽拓盛并购（未完成）、机器人软包（无订单）均未过验证点，不计入中性净利，仅列入乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。 现价 9.79 元对应 2026E PE 37.3x、PB 2.71x，而 2026 年归母预计同比下滑（0.736 → 0.70 亿）。市场已充分定价"新能源减震元件 35.8% 份额 + 南通扩产 + 线控踏板 + 机器人"的多重预期，但这些预期中只有南通扩产是可验证的硬增量。

安全边际：
- 中性远期 13.39 元 → +36.8%，不达"重点关注"的 >50% 门槛
- 悲观 7.43 元 → −24.1%（叠加回售风险情景 6.42 元 → −34.4%）；乐观 25.36 元 → +159.0%
- 下行保护：净资产约 9.63 亿（BVPS 3.61 元）、可转债转股价 12.70 元形成"心理锚"、客户结构优质且分散
- 风险收益比：+36.8% / −34.4% ≈ 1.07，接近 1，赔率一般

介入条件：
1. 价格：8.5 元以下（2026E PE < 32x、PB < 2.35x）分批；8.0 元以下（接近可转债回售触发价 8.89 元的下方，安全边际更足）为较优赔率位
2. 加仓信号：① 南通扩产项目投产公告（2027–2028）；② 线控制动踏板获得首个量产定点公告（金额 ≥ 5000 万）；③ 单季毛利率回升至 30% 以上；④ 安徽拓盛并购完成并表；⑤ 电池包辅材年收入突破 8000 万
3. 减仓信号：股价跌破 8.89 元触发可转债回售预期；单季毛利率跌破 25%；减震元件销量连续两季负增长

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 估值与业绩背离（首要）：PE(TTM) 39.3x 而 2026 年净利下滑，若 2027 年业绩未能兑现扩产红利，将面临"戴维斯双杀"
2. 份额已饱和（容易被忽视）：新能源减震元件份额已达 35.8%，S 曲线接近顶部，继续提升空间有限。增量必须依赖单车价值量（线控踏板）与新市场（电池包辅材、海外、机器人），而这些均未过验证点
3. 年降 + 原料双重挤压：MDI 行业开工率仅 60–65%、万华检修、金九旺季 → 原料易涨难跌；主机厂年降刚性 → 毛利率修复不确定
4. 可转债回售风险：转股价 12.70 元，现价 9.79 元已低于转股价 23%；若长期低于 8.89 元（70%）触发回售，3.08 亿现金流出压力
5. 经营现金流恶化：2026H1 经营现金流 1567 万（−80.24%），系票据管理与货款支付增加 → 现金流质量需持续跟踪
6. 商誉与并购风险：普科马商誉 + 安徽拓盛并购（未完成）存在减值/整合风险

第五步进阶：上行想象力情景（四类，与下行校正对称）

类型A 行业调整剩者红利
- 逻辑：聚氨酯减震元件行业在新能源渗透率见顶后进入存量竞争，中小供应商因无法满足主机厂同步开发与全球化配套（IATF16949 + 海外工厂）要求而退出，头部（公司份额 35.8%）进一步集中。
- 份额变量锚定：份额由 35.8% 提升至 42–45%（退出者份额转移）→ 收入 +1.5–2.0 亿 → 归母 +0.35–0.45 亿。
- 验证点：中小聚氨酯件企业退出/被并购公告；公司定点数量（2026H1 新获项目 3.2 亿）持续增长；海外收入占比提升。
- 证伪信号：份额停滞在 35% 以下、新进入者（如聚氨酯原料巨头向下游延伸）增加。

类型B 政策反转期权
- 具体政策：① 《汽车行业价格行为合规指南》若由征求意见稿转正式稿并强制约束年降与账期；② L3 级自动驾驶法规落地（工信部推进中）——线控制动（EMB）是 L3 冗余制动的强制配置，一旦法规落地，线控踏板需求将指数级启动；③ 以旧换新加码。
- 重估弹性：L3 法规落地 + 线控踏板量产，单车价值量由 120 元升至 400 元，按 2029 年踏板 350 万件测算 → 收入 +9.8 亿（极端乐观），中性按 30% 渗透 → +2.9 亿收入、+0.7 亿归母。
- 验证点：工信部 L3 准入法规发布；公司线控踏板量产定点公告；年降幅度收窄。
- 证伪信号：L3 法规推迟、公司未获线控定点、年降未收窄。
- 纪律：未过验证点，仅作机会情景，不计入中性锚。

类型C 市场错杀修复
- 错杀证据（成立度偏低）：PB 2.71x、PE(TTM) 39.3x 均不便宜，当前不构成错杀。但若出现：① 可转债回售预期引发恐慌性抛售；② 2026 年报业绩下滑引发情绪杀；③ 小盘成长风格系统性回撤 → 股价若跌至 7 元以下（2026E PE 27x、PB 1.94x），则可能出现"业绩拐点前夜 + 极度悲观"的错杀修复机会。
- 修复触发点：南通项目投产公告 + 单季毛利率回升 + 风格回归。
- 证伪信号：业绩继续下滑、可转债回售实际发生 → 则不是错杀。

类型D 技术突破 / 技术代际跃迁期权
- 方向：① 线控制动踏板（EMB）——从机械踏板到"踏板感觉模拟器 + 行程传感器"的电子化跃迁，是技术代际跃迁而非简单迁移；② 机器人软包零部件（聚氨酯弹性体在具身智能中的缓冲/包覆应用）
- 三要素检验（线控踏板）：① 政策驱动——L3 自动驾驶法规（部分成立，法规在研）；② 行业趋势——线控制动渗透率向 30%+ 收敛（趋势成立）；③ 公司落地——已完成实验测试 + 基础产线搭建 + 至少两轮主机厂路试，但无量产定点、无良率数据、无成本对比
- 三要素检验（机器人软包）：① 政策——具身智能是国家未来产业（部分成立）；② 趋势——人形机器人产业化（趋势成立但未放量）；③ 落地——仅"已成功开发相关产品"，无中试良率、无客户定点、无量产成本
- 硬验证点双双缺失 → 只作机会情景，不计入中性锚。
- 证伪信号：线控踏板 2027 年底前无定点；机器人产品长期无客户；成本打不过现有方案；L3 法规推迟。

什么条件出现才上调至"重点关注"：需同时满足 ① 股价回落至 8.5 元以下（2026E PE < 32x）；② 线控制动踏板获得首个量产定点公告；③ 南通扩产项目投产公告；④ 单季毛利率回升至 30% 以上。四者齐备则中性归母可上修至 2.1 亿以上，空间超 +50%，可上调评级。

结论：纳入观察
