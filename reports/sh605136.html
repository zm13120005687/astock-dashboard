第一步：公司是干什么的？

一句话定位：国内老牌化妆品网络零售服务商——以天猫为大本营帮外资/海外美妆品牌做线上代运营与经销，2024 年起战略转型海外品牌中国总代理（总代）+ 全域分销，从"服务商"向"品牌管理商"迁移。

（3）产业链传导

上游：海外品牌方 + 流量平台。对代运营商/总代而言，真正的"原料"是两样：
- ① 货品：向品牌方采购（买断经销/总代），采购成本与品牌方议价权决定毛利率
- ② 流量：平台佣金 + 达人佣金 + 投流费用，是运营端最大的可变成本

下游：C 端消费者（通过天猫/抖音等平台触达）。

议价权：
- 对品牌方：弱→中，且正在变强。传统代运营（服务商）议价权极弱（品牌随时可自播/换运营商）；总代模式因取得独家授权 + 承担库存 + 自建分销体系，议价权显著强于纯代运营，这是公司转型的核心逻辑。
- 对平台：弱。抖音/天猫掌握流量分配，佣金与投流成本刚性上升。
- 佐证：2025 年毛利率 39.76%（vs 2024 年 35.89%，+3.87pct）；2026Q2 毛利率 40.24% —— 毛利率持续提升，说明总代占比提升确实在改善议价权结构，这是转型有效的最硬证据。

第二步进阶：原料成本 → 毛利结构传导（四因子）

本股为服务商/总代，"原料"= 货品采购成本 + 流量采购成本。四因子按此适配。

因子 1 成本传导弹性（pass-through）

成本项 成本变动 传导机制 传导率（估）
货品采购成本（总代/经销） 品牌方提价、汇率（人民币贬值抬升进口成本） 可调整终端零售价，但受平台比价与促销节奏约束 ≈ 0.55–0.65
流量成本（佣金 + 投流 + 达人） 平台提佣、投流竞价加剧 纯代运营模式下由品牌方承担（传导率 ≈ 0.9）；总代模式下自担（传导率 ≈ 0） 代运营 0.9 / 总代 0.0
存货减值 滞销、效期临近 无法转嫁，全额自担 0.0
  • 加权判断：随着总代占比提升，公司成本传导率在系统性下降（从"品牌方扛流量"变为"自己扛流量 + 扛库存"）。这是总代模式的双刃剑：换来更高毛利率（50–55% vs 35–40%）与独家权，但吃下全部经营风险。
  • 实际承压测算：流量成本上涨 10%，总代业务（假设占总成本 25%）传导率 0 → 综合毛利承压 ≈ 10% × 25% × (1−0) = 2.5% 的成本增量自担。
  • 验证点：半年报/年报毛利率（2025 39.76% → 2026Q2 40.24%，需持续站上 40%）；销售费用率；存货周转率。
  • 证伪信号：毛利率跌回 37% 以下 → 说明总代未带来结构改善，转型失败。

因子 2 毛利结构再平衡（分业务线，禁单一综合毛利率）

业务线 毛利率（估） 2025 收入占比（估） 2029E 收入占比（中性） 敏感权重
传统电商零售（买断经销） 35–38% 约 70% 约 47% 货品成本敏感高、流量成本敏感中
品牌营销运营服务 60%+ 约 15% 约 10% 成本敏感低（轻资产）
海外品牌总代（新） 50–55% 约 5–8% 约 43% 货品 + 流量 + 存货三重敏感

→ 结论：单一"综合毛利率 39.76%"完全掩盖了正在发生的结构跃迁——高毛利总代占比从 5–8% 提升至 40%+，是 2026—2029 毛利率与净利率改善的唯一结构性来源。第三步/第四步按分业务线给定，不使用综合毛利率外推。

因子 3 库存与采购节奏（timing）—— 本股最大的隐藏风险
- 2026H1 存货周转率仅 0.72 次（年化约 1.44 次），2025 年 2.39 次、2024 年 1.68 次 → 周转显著放缓。
- 成因：总代模式需要买断备货，新品牌（邱园、7th Heaven、安多可、吉儿玛）首年铺货必然压库。
- 风险定性：这是"主动战略备货"而非"滞销积压"——但二者在报表上初期难以区分。若新品牌动销不及预期，将直接转为存货跌价损失，吞噬利润。
- 不得把库存当作真实盈利：2026H1 利润改善主要来自毛利额增加 + 销售/管理费用下降 + 资产减值损失减少（公司口径），需警惕"减值基数效应"带来的利润虚增。
- 验证点：半年报存货周转率（阈值：年化回到 2.0 次以上）；存货跌价准备计提比例；总代品牌动销数据（如温丽慈在妆前乳细分的排名）。
- 证伪信号：存货周转率连续两期低于 1.2 次（年化）→ 总代模式证伪，估值需大幅下调。

因子 4 政策 / 市场锚点（成本驱动变量）
- 市场层：① 抖音投流竞价（增速从 24% 降至 14.5%，平台进入存量博弈，流量成本大概率继续上行）；② 人民币汇率（进口品牌采购成本）；③ 天猫佣金政策（天猫回暖后议价权回升）。
- 政策层：① 《化妆品监督管理条例》功效宣称评价 —— 海外品牌合规成本上升，反而增强对总代的依赖（利好）；② 跨境电商保税政策（影响清关效率与资金占用）；③ 进口化妆品关税/消费税调整（若下调，直接改善总代毛利）。
- 情景假设：
- 基准：流量成本温和上行（年 +5%），总代占比提升至 43%，综合毛利率 2029 达 42%
- 悲观：抖音投流成本年涨 15% + 新品牌动销失败 + 存货减值，综合毛利率回落至 37%，净利下修至 0.6 亿
- 乐观：进口化妆品关税下调 + 天猫继续回暖 + 总代跑通，综合毛利率达 45%
- 验证点：半年报毛利率与销售费用率、存货周转、关税调整公告、天猫/抖音美妆季度 GMV。
- 证伪信号：销售费用率持续上升而收入不增 → 流量成本失控。

准亏损从严：正常化净利润法 + 盈利塌陷三问

问一：为什么亏？（2025 年归母 −7,999 万）
1. 主因——营收断崖式收缩：2023 年 27.62 亿 → 2024 年 17.28 亿（−37.44%）→ 2025 年 16.92 亿（−2.08%）。这是主业恶化型亏损，不是一次性减值型。
2. 收缩的底层原因（结构性）：品牌方自播化（抖音兴起后品牌自建直播团队，不再需要代运营）+ 国货崛起挤压外资（国货增速是外资 6.5 倍，公司以海外品牌为主）→ 代运营这门生意的 TAM 在被侵蚀。
3. 次因——费用刚性：代运营需要持续的营销投放与人力，收入下滑时费用无法同比例压缩，2025 年净利率 −4.72%。
4. 不是: 一次性大额减值主导、财务费用拖累（有息负债仅 447 万）、商誉爆雷（商誉极小）。

问二：靠什么扭亏？触发时点在哪一年？
1. 靠海外品牌总代业务：2024 年起布局，2026H1 同比增长超 200%，已签温丽慈、邱园（华独家线上总代）、7th Heaven、安多可、吉儿玛等 5+ 个品牌。
2. 靠毛利率结构升级：2025 年 39.76% → 2026Q2 40.24%，总代（毛利率 50–55%）占比提升是唯一驱动力。
3. 靠费用精细化管控：公司口径"提升自有品牌营销费用投放效率、科学控制投入规模"。
4. 触发时点：已经发生，不是未来预期。2026H1 归母 +2,252.29 万、扣非 +2,321.47 万，利润总额从上年同期 −4,049.51 万改善至 +3,420.70 万。全年 2026E 归母约 0.48 亿，2026 年即为扭亏年。
5. 二次确认点：2026 年报若全年归母为正且总代收入 ≥ 3 亿元，则扭亏趋势正式确立。

2. 利润质量被低估：归母（2,252 万）< 扣非（2,321 万），非经常性损益为负，利润 100% 来自主业，市场却按"微利股"定价。
3. 资产价值未重估：净资产 24.0 亿 vs 市值 33.64 亿，其中几乎无有息负债、现金比率 302.81%，PB 1.39x 对一家净现金服务业公司并不贵；若 TTM 转正后被动资金回补，PB 修复至 1.6x → 38.4 亿 → 9.59 元（+14.2%）。
- 修复触发点：2026 年报全年归母为正 → TTM PE 由负转正，这是最确定的时间点（预计 2027 年 3—4 月年报披露后）
- 证伪信号：2026H2 重新亏损（TTM 无法转正）；总代收入披露不及预期

类型 D 技术突破 / 技术代际跃迁期权 —— 不适用
本股为服务/渠道型公司，无自研硬技术、无中试线、无工艺代际跃迁。但存在一个等价的"模式跃迁"：从"代运营商"升级为"品牌管理商/品牌孵化平台"（类似南极电商、若羽臣的转型路径）——若公司能孵化出自有品牌或完成品牌收购，估值体系将从"服务业 20x"切换至"品牌公司 30–40x"。
- 硬验证点：① 自有品牌收入占比突破 10%；② 完成品牌收购或孵化品牌年销破亿；③ 模式跑通后毛利率突破 45%
- 当前状态：三条均未达成（公司未披露任何自有品牌数据）→ 仅作机会情景，计入乐观情景
- 证伪信号：公司明确表示不做自有品牌；孵化品牌连续亏损

什么条件出现才上调至"重点关注"：
1. 2026 年报披露总代业务收入 ≥ 3 亿元（转型从"相对增速"变为"绝对金额"，验证点通过）→ 2029E 中性净利上调至 1.7 亿，目标价 11.9 元，空间 +41.6%
2. 或 总代收入 ≥ 3 亿 且 存货周转率年化回升至 2.0 次以上（模式健康度双确认）→ PE 可给 30x，空间 > +50%，上调至重点关注
3. 或 股价回落至 7.0 元以下（PB < 1.17x，接近净资产），中性空间自然超过 +40%
4. 或 完成自有品牌孵化 / 品牌收购公告（类型 D 验证点通过）
满足 2 或 4 即上调至重点关注。

结论：纳入观察

理由：中性远期空间 +16.5%，未达"重点关注"的 >50% 门槛。但本股属于"赔率结构尚可、下行有硬底、验证点即将触发"的典型观察标的：
看多理由：① 2026H1 已实质扭亏（归母 +2,252 万、扣非 +2,321 万、非经常为负，利润干净）；② 总代业务 +200% 已放量，5+ 个海外品牌在手；③ 毛利率从 35.89%（2024）→ 39.76%（2025）→ 40.24%（2026Q2）持续改善，转型有效的最硬证据；④ 资产负债表极健康（负债率 12.21%、有息负债 447 万、现金比率 302.81%），下行有 6.00 元/股的资产底；⑤ TTM 负 PE 造成的错杀，2026 年报转正后被动资金可回补。
不能给重点关注的原因：① 中性空间仅 +16.5%；② 总代业务绝对金额未披露，这是估值的核心不确定源；③ 存货周转率年化降至 1.44 次，买断模式风险未验证；④ 抖音流量成本上行 + 国货挤压外资两大逆风未解。
核心跟踪点：2026 年报总代收入的绝对金额（阈值 3 亿）+ 存货周转率（阈值年化 2.0 次）+ 综合毛利率（阈值 42%）。
