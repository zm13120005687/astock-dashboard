通裕重工（300185）五步法分析报告

分析日期：2026-09-15 ｜ 现价 2.82 元（2026-09-15 收盘价） ｜ 总市值 约 109.2 亿 ｜ PE(TTM) 约 135x（利润极薄） ｜ PB(LF) 1.48x ｜ 总股本 约 38.72 亿股
行业：大型高端装备核心部件（风电主轴、管模、锻件、粉末冶金）｜ 板块：创业板
强周期股提示：利润极薄（2026H1 归母仅 7744 万、净利率 2.22%），PE_TTM 135x 为周期谷底假象。估值须用"周期中枢净利/多年 trough-to-peak 中值净利"表述（即剔除单年波动的稳态净利），并标注当前周期位置。

第一步：公司是干什么的？

一句话定位：大型高端装备核心部件制造商，风电主轴（轮毂/机架）国内领先，并覆盖管模、压力容器锻件、军工锻件、粉末冶金，是风电铸锻件 + 军工 + 石化装备的重资产供应商。

核心产品：风电主轴、轮毂、机架、轴承座；大型锻件（压力容器、船用、军工）；离心铸管模；粉末冶金制品。

主要客户/下游：风电整机商（金风、明阳、运达、三一等）；核电/石化/军工装备；管模出口。

境内外收入占比：以境内风电/装备为主，管模等有一定出口。

股东背景：国有控股（珠海港/国资背景），重资产制造，总资产 144.9 亿、净资产 72.9 亿，资产负债率约 49.7%。

（3）产业链传导

上游（钢/生铁/中厚板）：原料占成本大头，2026H1 中厚板平稳（约 3653 元/吨），成本端温和；若钢价上行则毛利承压（传导率≈0.3–0.5，整机厂压价难转嫁）。

下游（风电整机/军工）：整机厂招标定价强势，铸锻件厂议价弱；海风起量 + 价格企稳改善盈利。议价权弱：重资产、产能分散、买方强势。

议价权判断：下游整机厂集采压价，上游钢价波动难转嫁——夹心层，盈利靠规模 + 利用率 + 价格周期。

第二步进阶：原料成本→毛利结构（四因子）

  • 因子1 成本传导弹性：钢材/生铁占成本 60%+，整机厂集采压价使涨价难转嫁（传导率≈0.3），钢价上行直接吃毛利；2026H1 钢价平稳故毛利小升 +0.69pct。量化：钢价 +10% → 毛利承压约 4–6pct（按成本占比×未传导部分）。
  • 因子2 毛利结构再平衡：分业务毛利率差异——军工/压力容器锻件（高）> 风电主轴（中，约 14%）> 管模（中）。2026H1 综合 14.03% 掩盖结构：风电主轴占比最大且价格周期敏感。中性须假设海风高价值量产品占比升（改善结构）。
  • 因子3 库存与采购节奏：钢价低位锁货可获库存收益（当期毛利虚高），高位接货则损失。2026H1 钢价平稳，无显著库存波动；需区分"低价锁货收益"与"真实盈利"。
  • 因子4 政策/市场锚点：
  • 市场层：中厚板/生铁价格、海风招标节奏、铸件加工费；
  • 政策层：十五五风电 120GW/年、深远海 80GW、反内卷价格修复、军工装备放量。
  • 情景：若海风招标恢复 + 钢价平稳（验证点：海风月度招标、中厚板均价），盈利修复；若钢价大涨 + 招标再下滑（证伪），毛利破阈。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：风电主轴/锻件产能分散，公司为头部之一，份额稳（约 10–15%）；
  • 需求侧/客户份额：绑定金风/明阳等整机龙头，认证周期长；
  • 技术代际差：大兆瓦主轴锻造技术处行业中上；
  • 成本曲线：规模 + 自有冶炼/铸造降本，成本曲线中等；
  • 份额加速度：海风大兆瓦化使份额向大产能厂集中（S 曲线平稳）。

  • 三档：保守（份额守住）／中性（海风份额小升）／乐观（大兆瓦份额跳升）。验证点：整机厂中标公告、海风主轴出货。

  • 层2 扩展业务：主业迁移空间（新易盛范式）

  • 能力可迁移性：风电锻件 → 军工/压力容器/船用锻件（同源锻造），迁移成本低；
  • 新 TAM 弹性：军工/核电装备较风电附加值高；
  • 切入卡位：已有军工资质，先发；
  • 客户认证门槛：军工认证高（护城河+阻力）；

  • 信号验证：军工锻件稳定贡献——已落地，但规模化增量未确认。
    → 军工/压力容器为"中期期权"，计入边际，大放量仅作乐观。

  • 层3 风险折扣（证伪信号）：海风招标再延、钢价大涨、整机厂压价加剧、产能利用率下滑。命中则下调。

第四步：估值锚定（自下而上，非增速外推）

方法说明：不使用"历史增速外推"，亦不硬套 PE_TTM（135x 为谷底假象）。按"风电装机 + 海风 + 价格修复 + 军工"自下而上测算，并用产能利用率校验。因强周期，盈利用周期中枢净利 / 多年 trough-to-peak 中值净利表述（当前周期位置：底部回升初期）。

总股本：约 38.72 亿股；每股净资产约 1.88 元（PB 1.48x，净资产 72.9 亿）；现价 2.82 元对应市值 109.2 亿。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：重资产（固定资产占比高），PB 1.48x 未破净。资产含专用锻造设备（清算价值 < 账面），但国资背景 + 持续经营，净资产质量尚可；估值未单凭 PB<1 推导空间（实际 PB>1），且周期中枢 PE 已反映盈利波动。
  • 校正2 周期位置校正（核心）：当前处风电周期底部回升初期（2026H1 并网弱但 6–7 月回暖）。中性净利用周期中枢净利/多年 trough-to-peak 中值（约 3.2 亿），未用 2026H1 单季年化（谷底）、未用历史好年景、未用拐点年化。明确标注：若 2029 处下行周期，净利低于中枢。
  • 校正3 杠杆下行情景：资产负债率约 49.7%（中等），重资产 + 经营杠杆高，下行时净利几倍跳负；悲观情景空间 −33.3%（触及净资产），不得标大空间。
  • 期权纪律：军工锻件大放量、海风超预期未完全过验证点，仅计入乐观，不计入中性周期中枢净利（中性 3.2 亿基于风电十五五 + 已落地军工边际）。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（相对周期中枢盈利）。现价 2.82 元对应周期中枢 PE 约 34x、PB 1.48x，对低 ROE 重资产公司偏贵；每股净资产 1.88 元为硬支撑。

安全边际：
- 中性远期 2.07 元 → 空间 −26.6%（周期中枢盈利仍低于现价）；
- 悲观 1.88 元（净资产）→ 下行 −33.3%；
- 乐观 3.62 元 → +28.4%（需海风放量+价格修复验证）。

介入条件：
1. 等回落至 1.90 元附近（接近净资产 PB<1.1x） 才具安全边际；
2. 加仓信号：① 海风月度招标持续放量；② 铸件加工费涨价函；③ 中厚板价格平稳 + 产能利用率跳升；
3. 观察指标：风电月度并网/招标、钢材价格、单吨净利。

最大风险：① 风电需求再下滑/海风招标延后（首要）；② 钢价大涨难转嫁；③ 整机厂压价致毛利破阈；④ 重资产高经营杠杆，下行时净利跳负。

结论：暂不介入（周期中枢中性空间为负，现价相对重资产低 ROE 偏贵；等 PB 回到净资产附近或海风招标确认放量再重评）

通裕是风电铸锻件头部 + 军工多元化，十五五风电 + 海风为真实长期驱动。但当前利润极薄、周期位置底部回升初期，现价 2.82 元（PB 1.48x）相对周期中枢盈利偏贵，中性空间 −26.6%。触发"上调至纳入观察"条件：海风招标持续放量 + 价格修复兑现，使 2029E 周期中枢净利上修至 5 亿档且 PB 回落至 1.2x 以下。
