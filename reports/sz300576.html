（3）产业链传导

上游：基础化工原料（树脂、光引发剂、溶剂）。部分原材料价格波动，新产能生产成本阶段性偏高。

下游：PCB / 面板 / 半导体。AI 算力驱动高阶板材需求，下游景气向上、客户粘性强（核心份额 80%）。

议价权判断：强（PCB 光刻胶国内龙头、核心客户高份额、国产替代壁垒）；高端干膜 / 半导体光刻胶尚在导入期，议价权待验证。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）
    PCB 光刻胶：原料（树脂 / 光引发剂）变动 ×（1 − 传导率）。凭借龙头地位与核心客户 80% 份额，传导率约 0.7–0.8（可转嫁大部）。高端干膜 / 半导体光刻胶国产替代期，客户认证溢价高，传导率 0.8+。H1 PCB 毛利率仅降 0.16pct，印证强传导。

  • 因子2 毛利结构再平衡
    分业务毛利率：PCB 光刻胶 38.36%（占比 83.73%，稳健）、显示 / 半导体光刻胶附加值更高但占比小。综合毛利率降 3.45pct 并非 PCB 主业恶化（−0.16pct），而是新产能折旧 + 坏账 + 原料波动的结构性拖累。不能单一"综合 34.17%"代表全结构——PCB 主业毛利依旧坚挺。

  • 因子3 库存与采购节奏（timing）
    珠海新产能 2025.12 达预定状态、尚处爬坡，折旧前置、良率 / 成本阶段性偏高，属"产能投放阵痛"而非库存收益。客户盛隆电子破产单项计提坏账 770 万（信用减值 +129.69%）为一次性非经常性损失，须剔除趋势。

  • 因子4 政策 / 市场锚点（原料成本驱动变量）
    政策层：半导体 / 显示自主可控 → 高端光刻胶国产替代加速（需求变量）；市场层：AI 算力 capex → 高阶 HDI / IC 载板用高端油墨量价齐升。情景：若 AI 服务器需求超预期，高端干膜 / IC 载板阻焊订单弹性大。验证点：珠海产能利用率、高端产品营收占比。证伪信号：PCB 毛利率跌破 35%、高端产品客户导入停滞。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：珠海达产将大幅提升干膜 / 半导体光刻胶产能，份额提升确定性高。
  • 需求侧 / 客户份额：核心 PCB 客户份额 80%，AI 算力驱动高阶板材增量。
  • 技术代际差：PCB 光刻胶国内领先；半导体处中低端国产替代。
  • 成本曲线：规模效应 + 国产化降本，位于曲线左端。

  • 份额二阶导数：PCB 主业稳定，高端干膜处渗透早期（加速）。
    → 三档：保守（产能利用率 70%）、中性（85%）、乐观（满产 + 份额提升）。

  • 层2 扩展业务：主业迁移空间（显示 / 半导体范式）
    能力可迁移性：从 PCB 光刻胶向显示 / 半导体光刻胶，技术同源（感光化学平台复用），迁移成本低。新 TAM 弹性：半导体光刻胶市场数倍于 PCB、国产替代空间大。切入卡位：已与 TCL 华星 / 三安光电等合作，g/i 线进入供应链。客户认证门槛：面板 / 半导体认证周期长（护城河）。信号验证：显示及半导体光刻胶 2024 营收 3336 万、客户稳定合作——部分过验证点，可作中期期权计入乐观，但不计入中性（KrF 未量产）。

  • 层3 风险折扣：证伪信号
    PCB 毛利率跌破 35%；珠海产能利用率长期低于 60%；高端产品客户导入停滞；KrF 研发失败。命中则下调增量。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵 / 估值已高。现价 29.69 元对应 PE(TTM) 132x、PB 6.89x，市场已充分预期珠海达产与国产替代，下行保护弱。

安全边际：
- 中性远期 31.00 元 → 空间 +4.4%（微正，安全边际薄）
- 悲观 22.00 元 → 下行 −25.9%
- 乐观 45.00 元 → +51.5%（需半导体光刻胶突破，属机会情景）
- 下行保护：PB 6.89x 无破净缓冲，估值主要靠成长预期支撑

介入条件：
1. 不追高。当前价接近中性估值上沿。
2. 介入 / 加仓信号：① 股价回落至 22 元以下（悲观区、PE 合理）；② 珠海产能利用率稳定站上 80%；③ 半导体光刻胶（KrF）量产 / 大客户定点公告；④ 高端干膜营收占比跳升。
3. 观察指标：逐季毛利率（剔除爬坡后）、珠海产线销量、半导体光刻胶客户认证。

最大风险（最可能破坏逻辑的因素）：
1. 估值消化风险（首要）——PE 132x / PB 6.89x，若成长不及预期，戴维斯双杀。
2. 珠海产能爬坡慢于预期，折旧持续压制利润。
3. 半导体光刻胶突破不及预期（KrF 未量产），第二曲线证伪。
4. AI 算力资本开支周期回落，高端油墨订单放缓。

结论：暂不介入

理由：中性远期空间仅 +4.4%，不满足"重点关注" >50% 门槛；当前 PE(TTM) 132x、PB 6.89x 已充分定价未来成长，安全边际薄，悲观情景 −25.9%。公司质地优秀（PCB 龙头、AI 算力卡位、国产替代），但价格已贵。若回调至 22 元以下或半导体光刻胶实质突破，可上调至"纳入观察 / 重点关注"。
核心跟踪点：珠海产能利用率 + 半导体光刻胶（KrF）量产验证 + 回调至悲观区。
