第一步：公司是干什么的？

一句话定位：合肥国资委旗下高分子功能膜新材料平台，主营薄膜材料（BOPP/BOPET）、新能源汽车配套材料、新型木塑材料，并战略突围聚酰亚胺（PI）膜；当前处行业周期底部 + 新产线爬坡期，连续亏损，但卡脖子 PI 膜 + 资产重组构成期权。

（3）产业链传导

上游：BOPP/BOPET 原料（PP/PTA/PET 树脂，受原油价格传导）、PI 膜原料（二酐 / 二胺，进口依赖部分）。原油涨 → 树脂涨 → 薄膜成本升。
下游：包装、电子光电、新能源整车。下游买方强势、价格战。
议价权：弱。中低端薄膜产能过剩、同质化，议价权低；PI 膜（高端）议价力强但尚在爬坡。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：大宗薄膜转嫁系数 ≈ 0.3（弱，成本难转嫁）；PI 膜 / 高端光学膜转嫁系数 ≈ 0.7–0.9（强，国产替代稀缺）。依据：BOPET 毛利率仅 7.33%、新能源配套 −5.12%，成本端难传导；PI 膜为战略稀缺品溢价高。
  • 因子2 毛利结构再平衡：分业务线毛利率——薄膜 7.33%（营收 73%，利润主体但薄）、新能源配套 −5.12%（拖累）、木塑 20.70%（高毛利小体量）。原料（树脂）敏感权重集中于薄膜（73%），结构性脆弱；PI 膜达产后将重构毛利结构（高毛利占比提升）。
  • 因子3 库存与采购节奏：2025 薄膜库存 +120%（期末备货 / 去库存意愿弱），存在潜在跌价风险；2026H1 现金流改善。验证点：存货周转与毛利率。
  • 因子4 政策 / 市场锚点：树脂受原油（市场层）+ 产能周期；PI 原料受进口 / 国产替代政策（政策层）。情景：原油上涨 → 薄膜毛利承压；PI 膜国产化政策加速 → 毛利重构。证伪信号：薄膜毛利率跌破 6% 或 PI 膜量产延期。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量：BOPET 大宗膜产能过剩、份额分散，公司靠成本 / 规模守住；PI 膜（高端）国产替代份额从低基数提升。三档：保守守住、中性小幅提升（PI 膜放量）、乐观抢份额（PI 膜国产替代加速）。验证点：PI 膜营收披露、薄膜毛利率。
  • 层2 扩展业务：主业迁移空间（PI 膜 / 光学膜）：从大宗薄膜向高端 PI 膜 / 光学膜迁移，新 TAM（半导体 / 柔性显示 / 新能源）数倍放大，但爬坡期、未过"批量订单 / 营收占比跳升"验证点，仅中期期权，不计入中性。
  • 层3 风险折扣：证伪信号：PI 膜量产延期 / 良率不达标、薄膜毛利率破 6%、新能源配套持续亏损、金张科技重组终止 → 下调增量。

第四步：估值锚定（自下而上，正常化净利润法）

方法说明（亏损股）：2026H1 归母 −3181 万，亏损为周期底部 + 新产线爬坡折旧 + 新能源配套下滑。采用正常化净利润法：估稳态营收 → 保守正常化净利率 → × 远期 PE。

总股本：约 8.96 亿股。2026H1 归母净资产 26.87 亿（总资产 45.58 亿，资产负债率约 41%）；无显著金融资产未重估。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 3.01 未破净，但重资产（薄膜 / PI 产线），净资产 26.87 亿含新产线（部分未达产、折旧拖累）。高 PB 反映新材料 / 重组期权溢价，非主业清算价值；无金融资产未重估型折价。
  • 校正2 周期位置校正：薄膜（BOPET）强周期，当前周期位置 = 底部（产能 756 万吨、内卷、价格战）。中性净利用周期归一化（正常化净利率 4%，介于 2022 peak 9.3% 与亏损之间），未用 peak 外推。
  • 校正3 杠杆下行情景：资产负债率约 41%（中等），若需求继续疲软 / PI 爬坡失败，净利仍可转负（悲观情景已接近归零）。下行保护中等，不得标"大空间"。

第五步：综合赔率判断（买不买？）

当前价格位置：显著偏贵（相对主业锚）。现价 9.02 元高于正常化中性锚 2.80 元，PB 3.01、市值 80.82 亿，已充分计入 PI 膜 + 金张科技重组期权。
安全边际：中性 −68.9%，悲观 −89.1%；乐观 −44.6%（仍低于现价，需重组 + PI 双兑现）。主业层面风险收益严重不对称偏负。
介入条件：① 仅适合博弈"PI 膜量产 + 金张科技重组"期权者；② 若重组 / PI 无实质进展，< 3 元（接近主业锚）才具安全边际。
最大风险：① 薄膜周期持续底部、价格战；② PI 膜爬坡延期 / 良率不达标；③ 金张科技重组终止（期权证伪则估值回归主业）；④ 新能源配套持续亏损。
结论：暂不介入（主业中性空间 −68.9%，估值不具吸引力；现价实为 PI / 重组期权定价，确定性不足，仅适合事件驱动博弈）。

亏损股三问：① 为什么亏——BOPET 行业周期低谷（产能过剩内卷）+ PI 膜新产线爬坡折旧 + 新能源配套材料客户订单下降，属周期 + 爬坡叠加，非一次性。② 靠什么扭亏 / 时点——行业出清提价 + PI 膜（1600 吨）达产贡献高毛利 + 新能源配套修复 + 金张科技并表，触发时点 2027–2028。③ 亏得起吗——净资产 26.87 亿、合肥国资背景、经营现金流 3114 万（好转），亏得起（非资不抵债）。
