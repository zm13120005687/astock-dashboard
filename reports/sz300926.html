第一步：公司是干什么的？

一句话定位：汽车精密零部件与精密模具专业制造商，掌握冲压、热成型、激光焊接、注塑、一体化压铸及装配工艺，是国内新能源整车厂核心配套供应商。

（3）产业链传导

上游：钢材、铝、镁等大宗商品。成本受供需与能耗双控影响。下游：整车厂（强势、年降 / 压价常态）。

议价权：对下游——中等偏弱（整车厂年降压价，但深度绑定头部新能源、同步开发能力构筑粘性）；对上游——中等偏弱（金属被动接受，按需采购 + 部分长协平滑）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（转嫁系数）：钢 / 铝 / 镁传导系数约 0.4–0.5（整车厂年降压价，仅部分传导），是冲压毛利 15.68% 偏低的主因；高强钢 / 铝价波动直接吃毛利。
  • 因子2 毛利结构再平衡：冲压 15.68%（占 89.83%，压舱石但低毛利）vs 注塑 32.44%（占比小）。一体化压铸 / 热成型产线若放量（高毛利）将显著改善结构——禁止用单一综合毛利代表全结构，须跟踪压铸 / 热成型收入占比。
  • 因子3 库存与采购节奏：公司按需采购原材料、有效控制库存积压；金属价格波动以长协 / 套保对冲部分，无囤货收益 / 接货损失问题。
  • 因子4 政策 / 市场锚点（成本驱动变量）：①市场层——铝 / 镁价格（SMM：9 月镁锭 ~16000 元/吨、铝 ~24380 元/吨）、钢价、运费；②政策层——能耗双控（抬高铝镁成本）、新能源以旧换新（托底需求）、出口关税 / 贸易壁垒（影响出口）。验证点：金属价格走势、新能源渗透率、以旧换新销量；证伪：金属大涨且无法转嫁、毛利破 14%。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：全国五大集群布局，产能快速扩张，份额提升；
  • 客户份额：深度绑定头部新能源（单一客户依赖风险并存）；
  • 技术代际差：一体化压铸（9000T）/ 热成型领先；
  • 成本曲线：规模 + 良率 + 就近配套，成本左移；
  • 份额二阶导数：新能源渗透率 ~60% 增速放缓但仍正，份额加速期。
    三档：保守守住（维持现有客户）/ 中性小幅提升（新基地产能转化）/ 乐观抢份额（压铸放量 + 新客户）。
  • 层2 扩展业务：主业迁移空间（冲压 → 一体化压铸 / 热成型 / 轻量化）：能力可迁移（工艺同源）、新 TAM（轻量化单车价值量数倍提升）、切入早（9000T 压铸岛已投）、认证门槛高（车规认证）。未过验证点（压铸大单定点 / 量产成本优于旧路线）仅作中期期权。
  • 层3 风险折扣（证伪信号）：价格战加剧致毛利破 14%、单一大客户流失、压铸爬坡失败、金属涨价失控。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（破净原因）：不适用破净——PB 1.94x，未破净。但资产重（固定资产 + 在建占比高）、资产负债率约 64%，须关注厂房设备专用性（清算价值 < 账面）与折旧压力；净资产质量按重资产打折看待，PB 不能简单等同于安全边际。
  • 校正2 周期位置校正：汽车非强周期，但处新能源价格战周期（中下部）——行业利润率 3.4% 近五年新低。中性净利已按净利率由 14.5% 压缩至 11% 测算，未用单年好年景；当前非周期顶部，不过度悲观。
  • 校正3 杠杆下行情景（高负债必附）：资产负债率 64%，经营杠杆 + 财务杠杆双高。若利率上行 / 需求下行 / 价格战加剧，净利可由 10.5 亿降至 6 亿（杠杆反噬），目标市值 72 亿 → 16.6 元（+1%）——空间近零但未转负，故中性 >50% 空间成立；但须明示高贝塔属性，上行弹性与下行弹性均大。

交叉校验：现价 16.41 元对应 TTM PE 仅 9.18x、2026E PE 约 9.5x——市场已把价格战与高负债充分定价，中性远期（不含压铸期权）仍有 +121% 空间，安全边际充足。

第五步：综合赔率判断（买不买？）

当前价格位置：显著低估。PE(TTM) 9.18x、PB 1.94x，现价低于基准目标（20.7 元），处历史估值低位。

安全边际：中性远期 +121.2%；乐观 +228%；即便杠杆下行情景仍 +1%（高贝塔但下行有限）。账面支撑：净资产 37.35 亿、经营现金流转正、分红率提升（+52%）。

介入条件：① 当前 16.4 元以下即可分批建仓（已低于基准）；② 加仓信号——重庆基地投产兑现（2026-10）、压铸大单定点公告、单季净利率回升至 12%+；③ 风控：若单一大客户（如赛力斯 / 理想）份额异常下滑则减仓。

最大风险：① 新能源价格战超预期致毛利破 14%（首要）；② 高负债（64%）+ 利率上行 / 需求下行杠杆反噬；③ 单一大客户依赖与流失；④ 一体化压铸爬坡不及预期、金属涨价。

结论：重点关注（业绩增长明确 + 估值显著偏低 + 远期空间 >50%，高贝塔但下行有限）。

第五步进阶：上行想象力四类情景

  • A 行业出清剩者红利：价格战出清中小零部件厂，博俊凭规模 + 技术 + 就近配套成为剩者，份额与定价权提升。验证点：行业集中度数据、公司份额跳升；证伪：份额流失。
  • B 政策反转期权：以旧换新 2500 亿特别国债延续、新能源渗透率向 70% 进、技术门槛抬高利好头部。验证点：政策续期、渗透率跳升；重估弹性：乐观 53.9 元（+228%）。未过验证点仅作机会情景。
  • C 市场错杀修复：新能源 / 汽车零部件板块因价格战恐慌系统性错杀（估值分位低位）。验证点：板块企稳、PE 回归 12x+。
  • D 技术突破 / 代际跃迁期权：一体化压铸（9000T 压铸岛、后底板 / 减震塔）+ 半固态镁合金从 0 到 1 量产，重构单车价值量与竞争格局。三要素：政策（轻量化 / 双积分）+ 趋势（渗透率拐点、减重需求）+ 落地（中试良率达标 + 客户定点 + 量产成本优于旧路线）。硬验证点缺一则只作机会情景。触发上调（维持）重点关注条件：压铸大单定点且量产成本曲线优于旧冲压路线。
