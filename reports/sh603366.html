上游：铜（换热器/压缩机/管路核心料）、钢/铝板、压缩机、制冷剂（R32 主力，R290 切换中）。公司无长协套保公开披露，属价格接受者。

议价权：海外中等偏弱（代工为主、品牌溢价未兑现，出口均价 −4.2%）；国内弱（地产链买方强势）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）：传导率估 0.35–0.45。
- 依据：①2026H1 营业成本 +17.70% vs 营收 +12.85%，成本增速超收入 4.85pct，说明铜价上行大部分由公司自己扛；②出口端整机均价 −4.2%（行业数据），证明不仅没提价反而在降价抢单；③国内地产链买方强势，无提价空间。
- 定量：铜价上行 15% → 营业成本上行约 6%（铜占成本约 40%）→ 若完全不转嫁，毛利率承压约 4.4pct；按 0.40 传导率，实际毛利率承压约 2.6pct，与实际 −3.00pct（含年降与结构）基本吻合。
- 验证点：LME 铜/沪铜主力价、公司季度毛利率、出口均价（海关热泵出口单价）。证伪信号：铜价回落 10% 而公司毛利率未回升 → 说明压力来自年降/竞争而非原料，估值需再下调。

因子2 毛利结构再平衡（分业务线，禁单一综合毛利率）

业务线 2026H1 状态 铜/钢敏感权重 边际变化
空气能热泵（出口为主） 营收高增，广东空气能净利率 4.6% 高（换热器/压缩机用铜密集） 量增价减，毛利被年降吃掉
太阳能热水器（内销） 四季沐歌洛阳 亏 1801 万 中（水箱用钢、集热管用铜） 地产下行 + 补贴退坡，失血
厨电（帅康） 亏 3182 万 中（不锈钢/铜电机） 地产强绑定，全渠道 −10.7%
供热/光伏工程 + 特许经营 稳定，阿康营收 3.19 亿 中（EPC 用铜缆/组件） 预付账款 +202.68%，在施项目增加
储能 增长中 中高（电芯非铜，但 PCS/线束用铜） 全球化布局初显

结论：27.26% 的综合毛利率掩盖了"热泵微利放量、光热与厨电双失血"的结构迁移。利润表上 3665 万的归母，是"广东空气能 +2106 万 + 四季沐歌系 +3741 万"对冲"帅康 −3182 万 + 洛阳 −1801 万"后的残值。估值必须按子公司/业务线拆分，不能用一个综合毛利率推全局。
验证点：半年报子公司净利润表、分产品毛利率、出口占比。证伪信号：广东空气能净利率跌破 3% 或帅康亏损扩大至 4000 万以上。

因子3 库存与采购节奏（timing）
- 2026H1 末存货 7.95 亿（较期初 +30.33%），占总资产从 7.53% 升至 9.67%；同期营收仅 +12.85% → 存货增速是收入增速的 2.4 倍，存在高价接货风险。
- 铜价 2026 年上行，若 Q2–Q3 在高位补库，则 H2 与 2027 年毛利率将继续承压；反之若铜价回落，前期高价库存会形成跌价压力。
- 应付票据 4.64 亿（+43.15%）——公司在用票据延长付款账期对冲现金压力，属经营性加杠杆信号。
- 验证点：存货周转率（H1 为 1.31 次）、存货绝对额、铜价走势、应付票据规模。证伪信号：存货周转率跌破 1.2 次 + 计提存货跌价准备（H1 未计提则为隐患）。

因子4 政策/市场锚点（原料成本驱动变量）
- 市场层：铜价受全球制造业补库 + 电网投资拉动；欧洲天然气价格（2026-03 TTF 一度 +92.4%）决定热泵经济性，气价越高热泵渗透越快。
- 政策层：①欧盟 GBER 豁免延至 2028-12-31（需求侧利好，同时也是补贴"可预期"信号，渠道商敢压库存）；②F-Gas 2027-01-01 执行（GWP≥750 禁售）→ R290 冷媒切换，未切换企业 2027 年丢欧盟市场，切换企业有认证壁垒红利；③欧盟《工业加速器法案》原产地要求 → 若落地，纯出口模式受冲击，必须靠海外产能；④国内以旧换新退坡。
- 情景：中性——铜价高位震荡、GBER 豁免执行、F-Gas 切换期订单前移，公司毛利率维持 26.5%–28%；乐观——铜价回落 + 欧洲补库 + 公司 R290 机型通过 KEYMARK/MCS 认证，毛利率回 29%+；悲观——工业加速器法案设原产地门槛 + 铜价再涨 15%，出口受阻且毛利破 25%。
- 验证点：公司 R290 机型认证公告、欧盟 F-Gas 执行细则、海外产能公告、LME 铜价。证伪信号：2026Q4 前未启动 R290 欧盟认证 → 2027 采暖季大概率赶不上，出口增量打折。

层2 扩展业务：主业迁移空间（新易盛范式）
- 能力可迁移性：热泵（热能）→ 光储热一体化（源网荷储），技术同源度高（终端用能场景一致）；公司已落地零碳园区示范。迁移成本低，成立。
- 新 TAM 弹性：工商业储能 + 零碳园区 EPC，TAM 显著大于家用热水器；但项目制、回款慢、毛利低。
- 切入时点与卡位：早期。2026-07 零碳园区刚启用，尚无规模化订单。
- 客户认证门槛：工业/工商业客户需 EPC 资质与案例，门槛中等。
- 信号验证：① 光储 EPC 订单金额公告；② 储能业务单独披露收入且占比 >10%；③ 特许经营新项目中标公告。
- 结论：仅作中期期权，不计入中性情景。当前仅"零碳园区启用"这一个弱验证点。

层3 风险折扣：证伪信号
1. 帅康与洛阳子公司亏损不收敛（H1 合计 −4983 万）→ 每年吃掉约 1 亿利润；
2. 欧洲 H1 销量 −6.8% 若延续到 2027，出口增速回落至个位数 → 增长主引擎熄火；

4. 存货 +30.33% 而周转率下滑 → 后续计提跌价。

方法说明：不使用历史增速外推。按热泵 / 太阳能光热 / 厨电 / 工程+特许经营 / 储能五条线分别以"收入 × 业务线净利率"自下而上测算 2029E，并叠加类现金资产 SOTP（公司主业盈利能力弱，净资产中约 18.23 亿为类现金，必须与主业分开定价）。因主业处于准亏损状态，同时给出正常化净利润法与 PE 法双轨校验。

问1 为什么亏（主业实亏的根因）
- 结构性亏损源：帅康电气 −3182 万（地产链厨电）、四季沐歌洛阳 −1801 万（太阳能光热），合计半年 −4983 万；

- 长期证据链：2025 全年营业利润 1.814 亿 < 投资净收益 3.140 亿；2024 营业利润 2.544 亿 < 投资净收益 3.074 亿；2023 营业利润 2.318 亿 < 投资净收益 2.892 亿 —— 连续三年主业（剔除投资收益）为亏，靠投资收益与政府补助撑正。

问2 靠什么扭亏、触发时点
- 主引擎：空气能热泵出口。广东空气能 H1 净利 2106 万已是第一利润源；欧盟 GBER 豁免延至 2028 年底 + 东南亚 18.6 亿美元市场（+23.4%）→ 2027 年是关键时点（F-Gas 切换带来订单前移 + 认证壁垒红利）；
- 减亏：帅康。若厨电板块从 −3182 万/半年 收窄至盈亏平衡，年化增厚约 0.6 亿；

- 触发时点判断：2027 年（热泵出口放量 + R290 认证通过 + 帅康减亏）为最可能的利润拐点年；2026 年仍是过渡年。

问3 亏得起吗
- 类现金资产 18.23 亿（货币 7.99 + 交易性金融资产 4.43 + 债权投资 2.04 + 其他流动资产 3.77），短期借款仅 2.24 亿 → 净现金约 16 亿；

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正1 资产质量折扣（破净说明）：本股 PB 1.40x，不破净。但需说明资产质量：商誉仅 0.634 亿（占净资产 1.5%，减值风险小）；存货 7.95 亿（+30.33%）为最大隐忧，若铜价回落需计提跌价；应收账款 3.30 亿（−25.51%，回款改善，为正面）。净资产无虚高，但存货是需持续跟踪的软肋。

校正2 周期位置校正：热泵属政策+能源价格驱动的强周期成长，当前位置判断：外需上行中段、内需底部。欧洲 H1 销量 −6.8% 说明外需二阶导已转负，但 2026 年低基数为 2027 年政策确定性留出空间。中性净利 2.60 亿采用业务线自下而上加总（热泵 1.05 + 光热 0.11 + 厨电 0.02 + 工程 0.72 + 储能 0.25 + 现金收益 0.45），未使用任何单年好年景或近三年均值外推（近三年归母 2.09/2.12/1.75 亿均在下滑，若用均值反而会高估）。周期位置标注为外需上行中段 + 内需底部。

校正3 杠杆下行情景：Q1 资产负债率 47.55%、产权比率 0.91、速动比率 0.76（偏紧）、有息负债率 20.88%。
- 下行情景：铜价再涨 15% + 欧洲订单下滑 20% → 毛利率破 25%，主业净利从 2.60 亿降至 1.2 亿 → 1.2×15x=18 亿 + 净现金 14 亿 = 32 亿 → 3.94 元（−47%）；
- 应付票据 4.64 亿（+43.15%）说明公司在用票据延长账期，若信用环境收紧，现金流会快速恶化；
- 该下行情景使空间大幅转负，因此不得标"大空间/重点关注"。

期权纪律：欧盟 R290 认证、海外产能、储能 EPC、帅康剥离——均未过验证点，不计入中性净利，仅进乐观情景（12.79 元）。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 7.45 元对应 2026E PE 40.5x（1.50 亿）、2029E 中性 PE 23.4x（2.60 亿）；剔除净现金 16 亿后主业市值 44.6 亿 / 主业净利 1.30 亿 = 34x 主业 PE。而主业 ROE 仅 3.5%、毛利率还在下滑——市场已按"热泵出口成长股"而非"微利家电制造商"定价，属于预期先行、业绩未至。

安全边际：
- 中性远期 8.24 元 → +10.6%，不达"重点关注"门槛；
- 悲观 4.67 元 → −37.3%；乐观 12.79 元 → +71.7%；
- 硬支撑：净现金 16 亿（占市值 26.4%）+ 净资产 43.23 亿（每股 5.32 元）。PB 1.0x 对应 5.32 元，为极端下行底；PB 1.2x 对应 6.38 元。
- 风险收益不对称偏负：上行 10.6%（中性）vs 下行 37.3%（悲观）。

介入条件：
1. 现价 7.45 元不介入。等回落至 6.0 元以下（PB < 1.13x、主业市值 33 亿对应主业 PE 25x）才具安全边际；
2. 加仓信号：① 公司公告 R290 机型通过欧盟 KEYMARK/MCS 认证；② 帅康剥离或单季亏损收窄至 500 万内；③ 单季毛利率回到 29% 以上；④ 储能/EPC 单独披露收入且占比 >10%；
3. 观察指标：月度海关热泵出口额、EHPA 季度销量、LME 铜价、公司存货周转率。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 欧洲需求开关在外部变量手里（首要）：EHPA 2026H1 14 国销量 −6.8%，补贴退坡+渠道去库存，Q1 的 +17% 不可外推；若 2027 年补库未至，出口引擎熄火；
2. 欧盟《工业加速器法案》原产地条款：若落地且公司无海外产能，纯出口模式受制度性限制；
3. 两块失血业务不收敛：帅康 + 洛阳半年合计 −4983 万，年化约 −1 亿，吃掉净利润的一大半；
4. 利润长期靠投资收益撑：2023–2025 连续三年营业利润 < 投资净收益，主业造血能力存疑；一旦投资收益回落（2025 年 3.14 亿的高基数不可持续），报表会很难看。

第五步进阶：上行想象力情景（四类，认真建模上行侧）

类型A 行业调整剩者红利：热泵行业正在经历"补贴退坡淘汰欧洲本土中小厂商 + F-Gas 冷媒切换 + ErP 能效门槛提高"三重出清。2027-01-01 起 GWP≥750 机型禁售，是一次硬性供给侧出清——未完成 R290 切换的厂商直接失去欧盟市场。若公司在 2026Q4 前完成 R290 认证并进入安装商推荐清单，可承接退出者的份额。重估弹性：出口收入若从 2025 年约 10.27 亿增至 2029 年 25 亿（公司 2030 出口 50 亿目标的一半路径），对应净利增量约 0.7 亿 → 中性目标价上修至约 10 元（+34%）。验证点：R290 认证公告、出口订单公告、海关出口额份额。证伪信号：2026Q4 前无认证公告 → 2027 采暖季赶不上，红利归零。

类型B 政策反转期权：①欧盟 GBER 豁免延至 2028-12-31 已是明确政策反转（原计划收口反而延长），审批从 142 天压缩至 38 天，直接提升渠道商压库存意愿；②气价上行期权：欧洲天然气 2026-03 TTF 一度 +92.4%，气价越高热泵回本越快（德国测算 11–14 年，高气价下缩短近半）；若地缘冲突再起推高气价，需求弹性会再次释放。重估弹性：气价中枢上移 30% 情景下，2029E 出口净利可从 1.05 亿上修至 1.6 亿，对应目标价约 9.8 元（+32%）。验证点：TTF 天然气期货价、欧盟补贴预算、EHPA 季度数据。证伪信号：气价回落至冲突前水平 + 补贴预算进一步缩减 → 需求二次探底。

类型C 市场错杀修复：本股属"高 beta + 主题属性（热泵/储能/机器人概念外溢）"，在风格切换中波动大。但当前不构成错杀——PE(TTM) 35.62x、2026E PE 40.5x、主业 ROE 3.5%，估值分位不低；且毛利率、扣非质量均在下行，基本面恶化未被证伪，因此"错杀修复"这一条在本股不成立，仅作记录。

类型D 技术突破/代际跃迁期权：①R290 冷媒 + 超低温工况热泵（−25℃ 以下 COP 保持）是热泵的技术代际点，已获国家级制造业单项冠军背书；②光储热一体化（源网荷储） 从"卖设备"转向"卖系统+运营"，商业模式跃迁（零碳园区 2026-07 已启用）。硬验证点：R290 机型量产良率达标 + 欧盟客户定点/大额订单 + 系统方案单位成本优于单纯卖设备。当前三条均未满足 → 仅作机会情景，不计入中性锚（已计入乐观 12.79 元）。证伪信号：2027 年 F-Gas 执行后公司仍无 R290 批量出货、零碳园区无外部复制订单。

上调/下调纪律：
- 当前中性远期 +10.6%，结论为"纳入观察"；
- 上调至"重点关注"的条件（需同时满足两条以上）：① R290 欧盟认证公告落地；② 帅康剥离公告或单季扭亏；③ 单季毛利率回到 29%+；④ 股价回落至 6.0 元以下（届时中性空间重回 +37%）；
- 下调至"暂不介入"的条件：欧洲 H1 销量降幅扩大至 −15% 以上，或存货计提跌价准备，或 2026 年报归母低于 1.2 亿。

结论：纳入观察

理由：① 主业实亏被投资收益与补助掩盖，2026E PE 40.5x、主业 PE 34x，当前价格已把 2027 年的好消息定完了；② 但净现金 16 亿（占市值 26%）+ 净资产 43.23 亿构成硬底，悲观情景 −37.3% 有边界，无生存风险；③ 中性远期 +10.6% > 0 但不达 50%，且杠杆下行情景使空间可转负，因此不给"重点关注"；④ 真正的机会在 2027 年 F-Gas 切换窗口 + 帅康减亏的双击，届时需重新评估。
核心跟踪点：R290 认证进度 · 帅康亏损是否收敛 · 欧洲 EHPA 季度销量 · 铜价与单季毛利率。
