第一步：公司是干什么的？

一句话定位：湖南国资背景的盐业全产业链龙头，以食盐（民生刚需）+ 盐化工（纯碱/烧碱/氯化铵）为基本盘，并通过控股美特新材切入锂电正极材料，向"新能源材料"迁移。

主要客户/下游：食盐销往全国商超/电商/餐饮（C 端 + B 端）；工业盐/盐化供化工、玻璃、氧化铝、化肥等；美特新材供锂电/储能客户。

股东背景：湖南省国资委（湖南盐业集团），盐业专营历史背景，渠道与资源强。

资产规模（2026H1）：总资产 131.51 亿、归母净资产 76.50 亿、ROE 1.04%。

（3）产业链传导

上游：原盐（自产为主）、煤炭/电力（化工耗能）、锂钴镍（正极材料）——原盐自给对冲，能源成本受煤价影响，锂原料受大宗影响。
下游：食盐 C 端（刚需、弱周期）、盐化下游（玻璃/氧化铝/化肥，周期）、锂电（新能源，高增）。
议价权：食盐端强（定点 + 品牌 + 渠道）；盐化端弱（周期品，买方强）；正极端中等（认证壁垒）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：食盐有品牌溢价，部分成本可传导（传导率≈0.5–0.7）；盐化品（纯碱/烧碱）为大宗，成本传导率≈0.3（难顺价）；正极材料随锂价波动，传导率中等。综合毛利对煤/电价与锂价敏感。
  • 因子2 毛利结构再平衡：食盐（稳、高毛利）占比提升改善结构；盐化（周期）占比下降平滑波动；正极（高增长）占比上升打开弹性。三板块毛利贡献权重随价格迁移，须分业务给毛利率（食盐 ~30%+、纯碱 ~15%、烧碱 ~25%、正极 ~10–15%）。
  • 因子3 库存与采购节奏：原盐自产库存稳定；锂原料随采随用以规避跌价；盐化品低价囤货收益有限。无显著库存收益扭曲。
  • 因子4 政策/市场锚点：① 市场层——纯碱/烧碱价格、锂盐价格、煤价；② 政策层——食盐质量安全标准（抬升门槛）、新能源补贴/储能政策、能耗双控（约束纯碱产能、托底价格）。情景：纯碱价格触底回升 + 锂价企稳 → 验证点看商品价格指数。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务·份额变量：
  • 供给侧份额：6 家食盐定点（湘赣渝冀），区域龙头；
  • 客户份额：全国营销网 + 电商，C 端粘性；
  • 技术代际：食盐品质/品牌领先；
  • 成本曲线：自有矿 + 全产业链，处左侧；
  • 份额加速度：中高端份额提升。
    → 中性份额稳中略升，验证点：小包盐销量、市占率。
  • 层2 扩展业务·主业迁移空间（新易盛范式）：从"盐"向"锂电正极材料"迁移，能力可迁移（盐化工→电化学材料同源），新 TAM（新能源）弹性大数倍；切入时点早（钠电/高电压钴酸锂先发），认证门槛高（客户认证=护城河也是阻力）。信号验证：美特百公斤级销售、客户认证 → 中期期权，未过大规模验证不计入中性。
  • 层3 风险折扣（证伪信号）：纯碱价格持续低迷、锂价再跌、美特放量不及预期、衡碱投产延期 → 下调增量。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：公司重资产（化工装置 + 矿权），PB 1.30x 未破净，但盐化装置专用性较强；新能源材料（美特）为成长溢价，非资产重估，须区分。
  • 校正2 周期位置校正：盐化为强周期（纯碱价格低位），中性净利采用周期中性价格而非高点，周期位置标注为"盐化筑底、食盐稳态、材料成长"。
  • 校正3 杠杆下行情景：负债率约 41.8%（适中），但衡碱项目 capex 推升负债，若盐化价格再跌，净利可腰斩（悲观 2.44 元，−59.6%），须提示周期 + 项目风险。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高。现价 6.04 元对应 2029E 中性 PE 33x、市值 99 亿，已透支美特/衡碱乐观预期，中性内在价值仅 4.57 元。

安全边际：
- 中性远期 4.57 元 → 空间 −24.3%，无安全边际；
- 悲观 2.44 元 → 下行 −59.6%；
- 乐观 8.23 元 → +36.3%，需盐化回升 + 新能源放量；
- 下行保护：PB 1.30x、净资产 76.5 亿、食盐刚需现金流提供底线。

介入条件：
1. 不追高。回落至 4.8 元以下（2029E 中性 PE < 28x）才具安全边际；
2. 加仓信号：① 美特新材营收/利润规模化（正极销量跳升）；② 衡碱项目投产且达产；③ 纯碱/烧碱价格触底回升；
3. 观察指标：逐季食盐中高端占比、美特营收、盐化品价格。

最大风险：
1. 盐化周期持续低迷（首要）：纯碱/烧碱价格若继续下行，主业盈利承压；
2. 新能源材料放量不及预期：美特仍小基数，钠电/高电压路线商业化节奏不确定；
3. 衡碱项目 capex 与投产风险：大额投资、投产延期或消化不足；
4. 锂价波动：影响正极材料盈利与库存。

结论：暂不介入

雪天盐业食盐基本盘稳健、新能源材料（美特）与衡碱项目提供想象空间，资产质量尚可。但当前 6.04 元已大幅透支远期乐观预期（中性内在价值仅 4.57 元），且主业仍处周期低位，风险收益不对称。仅当回落至 4.8 元以下或美特/衡碱兑现验证时再评估。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • 类型A 行业调整剩者红利：能耗双控淘汰纯碱落后产能，头部份额与定价权提升 → 验证点：产能出清、纯碱价格。
  • 类型B 政策反转期权：新能源/储能补贴加码 + 钠电标准落地 → 重估弹性：美特放量，净利冲 4.5 亿（乐观 8.23 元）。验证点：钠电政策、客户定点。
  • 类型C 市场错杀修复：若随大盘回落至 PB<1.0x（<4.7 元），估值分位极低 → 修复触发点：食盐稳盈利证伪恐慌。
  • 类型D 技术突破期权：4.5V 高电压钴酸锂/聚阴离子材料从百公斤级跳升至吨级量产 → 硬验证点：客户大额订单、良率达标、成本优于旧路线。证伪：放量失败、锂价崩。

    上调至"纳入观察/重点关注"的条件：美特新材营收规模化（正极销量跳升）+ 衡碱项目投产达产验证，或现价回落至 4.5 元以下。
