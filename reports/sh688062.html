（3）产业链传导

上游：研发外包（CRO/CDMO）、培养基 / 填料、抗体序列合成。迈威自有生产基地（符合 NMPA/FDA/EMA GMP），部分环节自产降本；上游成本占收入比低（高毛利结构），成本传导弹性强（创新药定价权高，成本端不敏感）。

下游：患者支付（医保 + 商保）、医院准入、海外合作方分销。已商业化产品需求刚性，价格受国谈约束但销量弹性大。

议价权：强（创新药差异化 + 已上市产品刚需）。BD 端凭 9MW2821 潜在 BIC 地位具备对外授权议价能力（机构测算潜在 BD 里程碑 >20 亿美元）。

第二步进阶·原料成本 → 毛利结构（四因子）
- 因子1 成本传导弹性（转嫁系数≈0.9+）：创新药成本端以研发费用为主、原材料占比极低，毛利对上游波动不敏感；终端定价由临床价值决定，转嫁系数高。验证点：毛利率长期维持 70%+（2026H1 75.46%）。证伪：若集采大幅压价致毛利率破 60%，则议价权证伪。
- 因子2 毛利结构再平衡：当前 68% 药品销售（毛利 75%+）+ 32% BD 许可（毛利近 100% 但一次性）。结构风险在于 BD 收入不可持续——若后续无新 BD 首付款，稳态毛利结构将回落至纯药品销售的 75% 档。分业务线：已商业化药品毛利 75%、BD 许可 95%+（一次性）、在研管线 0（费用化）。验证点：H2 是否再有新 BD 首付款确认。
- 因子3 库存与采购节奏：创新药无大宗原料囤货收益问题；主要"库存"是临床样品与在产药品，timing 影响小。无低价囤货虚增毛利风险。
- 因子4 政策 / 市场锚点：原料成本驱动变量主要为①医保谈判降价（每年一次，降幅趋缓为正面锚）；②出海政策（支持 BD，正面）；③汇率（H 股募资港元，汇率波动影响净资产）。情景：国谈降幅扩大=毛利承压；BD 大单落地=一次性收益。验证点：每年医保谈判结果、BD 公告。

（3）第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：
  • 地舒单抗国内生物类似药市场：供给侧迈威双品 + 多家类似药竞争；需求侧骨质疏松 / 肿瘤骨转移人群大、渗透率提升。份额锚点：迈威凭先发与产能，份额稳中有升（验证点：双品季度销量）。
  • 9MW2821：Nectin-4 ADC 全球市场，竞品 EV 已上市；迈威凭差异化载荷 + 多适应症布局争取 BIC 份额。保守份额假设：国内 UC 二线 + 宫颈癌 + TNBC 合计峰值 8–12 亿（验证点：III 期数据、获批后处方量）。
  • 三档：保守（仅 UC 获批，峰值 6 亿）/ 中性（UC+CC 获批，10 亿）/ 乐观（多适应症 + 海外授权，15 亿+）。验证点：2026H2 期中分析、pre-NDA 沟通、2027 获批。
  • 层2 主业迁移空间（新易盛范式）：迈威核心能力=抗体 / ADC 发现与产业化，可迁移至更多 ADC 靶点（B7-H3、CDH17 等）与双抗 / TCE。但属"同赛道技术复用"，非跨市场迁移；9MW1911（自免）、6MW5311（血液瘤）为能力延伸。未过验证点（早期临床）仅作中期期权，不计入中性。
  • 层3 证伪信号：9MW2821 III 期数据未达终点 / 安全性问题 / pre-NDA 沟通失败 / 竞品（EV、其他 Nectin-4 ADC）率先抢占 → 下调或剔除该增量。

亏损股三问

  1. 为什么亏：高研发投入（2026H1 研发费用占营收 137.99%，约 4.3 亿）+ 已上市产品尚处放量早期、规模效应未到 + 港股上市中介费。亏损为"投入期"性质，非主业恶化（营收 +209% 高增、毛利率 75%）。
  2. 靠什么扭亏，触发时点：①已上市产品（地舒双品 / 君迈康 / 阿柏西普）持续放量，2027 年经营亏损显著收窄；②9MW2821 于 2027–2028 国内获批上市，2029 年形成规模化收入，系扭亏核心支点；③BD 首付款 / 里程碑补充现金流。中性触发扭亏时点 2028–2029 年。
  3. 亏得起吗：亏得起。截至 2026-06-30 现金及现金等价物 22.94 亿 + 总资产 52.95 亿 + 归母净资产 8.73 亿（H 股募资后 +149.92%）；H 股募资净额 11.97 亿港元已到账；经营现金流半年 −5.09 亿（年化约 −10 亿），22.94 亿现金可支撑 约 2 年；叠加 2026H2 起 9MW2821 NDA 催化 + 潜在 BD 首付款 + 银行授信，资金链安全。但需关注持续融资稀释（H 股已增发，后续或再融资）。

第四步进阶·重资产 / 周期股校正（三道闸）
- 校正1 资产质量折扣：迈威为轻资产研发型（固定资产占比低），PB 13.61 高系净资产小（8.73 亿）且含 H 股溢价，非破净，无需破净说明；但高 PB 反映"管线期权定价"，若 9MW2821 失败则 PB 虚高。验证点：管线审批进展。
- 校正2 周期位置校正：创新药非强周期，但受"临床 / 审批周期"影响；当前处于 9MW2821 注册兑现前窗口，属"预期高位"。中性净利已用"获批后稳态"而非"单季扭亏年化"，未用拐点年化。验证点：2026H2 期中分析。
- 校正3 杠杆下行情景：负债率不高（净资产 8.73 亿、现金 22.94 亿），但依赖股权融资；下行情景（9MW2821 失败）市值可回撤至现金 floor 约 5 元/股（−80%）。因下行极深，不得标"大空间 / 重点关注"，至多纳入观察。
- 期权纪律：9MW1911 / 7MW3711 / 6MW5311 等早期管线未过验证点，不计入中性净利，仅放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高。现价 26.62 元对应中性目标 28.76 元，上行仅 +8%；但内含约 21 元/股的"9MW2821 及管线期权"价值，下行至现金 floor 约 5 元/股（−80%），风险收益不对称偏负。

安全边际：中性 +8.0%；悲观 −66.3%；乐观 +57.8%。现金 floor 5.13 元/股提供绝对底，但距现价深。

介入条件：①现价回落至 20 元以下（贴近现金 + 已商业化资产）再具安全边际；②加仓信号：2026H2 9MW2821 期中分析阳性 + pre-NDA 顺利 + 新 BD 首付款落地；③观察指标：已上市药品季度销量、H2 亏损收窄幅度、现金消耗速度。

最大风险：①9MW2821 III 期数据 / 安全性不及预期（首要，可致市值腰斩）；②持续融资稀释（H 股已增发）；③已商业化产品国谈降价超预期；④现金消耗快于预期。

结论：纳入观察（逻辑正确、管线强、现金可撑，但现价已反映管线成功预期、中性空间仅 +8%、下行深，须等 NDA / 销售验证才上调重点关注）

上调至重点关注的触发条件：9MW2821 顺利获批且国内年销售突破 8 亿 + 海外 BD 首付款 ≥5 亿美元落地，使 2029 正常化净利上修至 6.5 亿+（目标市值 ≥160 亿，空间 >+50%）。
