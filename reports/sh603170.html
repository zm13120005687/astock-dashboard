口径校验：队列标记"盈利"。核查真实财报——2026 年半年报归母净利润 +1.2847 亿、扣非 +1.2587 亿，两者均为正且扣非增速（+13.20%）快于归母（+10.13%），盈利质量扎实，无反向漏标。按盈利公司处理，采用自下而上分业务测算。

第一步：公司是干什么的？

一句话定位：给连锁餐饮和食品工业做"风味解决方案"的 B 端定制型调味品公司，同时以"空刻"品牌做 C 端意面，是国内少有的 B/C 双轮、直销占比近 87% 的复调企业。

核心产品/品牌：
- C 端：「空刻」意面（主流电商平台意面品类零售额市占率约 54.2%），产品线延伸烤肠、西式浓汤、手拍薄底披萨，并推出黑松露、蟹黄等时令臻享系列；「厨房阿芬」（避风塘炒料等中式调料，进入爬坡阶段）。
- B 端：复合调味料、轻烹解决方案、饮品甜点配料（植脂末类）。2025 年 B 端在售 SKU 超 2,700 种，近三年新增产品占比近 60%。

主要客户/下游：百胜中国等连锁餐饮集团（最核心大客户）、食品工业企业、新零售渠道（山姆、盒马、量贩折扣连锁）、电商平台个人消费者。

境内外收入占比：以境内为主（约 95%+），境外收入占比极小且未单独披露。承担的关税/地缘政治风险极低。

产能布局：
- 山东宝莘食品科技有限公司（募投项目）：集农产品初加工、复合调味料、轻烹解决方案于一体的全产业链基地，2025 年正式投产，投产首年即晋升规模以上企业，产业链向上游延伸强化成本控制；这是当前最主要的产能红利来源。
- 上海金山亭林镇约 27.6 亩工业用地：已签署《上海市国有建设用地使用权出让合同》及《产业发展合作协议》，拟建智能化生产基地（二期），管理层称"项目全面开工指日可待"。
- 原有上海/浙江基地。

研发投入：2025 年 5,783.81 万元（+9.15%）；2026H1 3,351.86 万元（+21.93%）；研发人员 151 人（占总人数 10.36%），硕士及以上 40 人。

股东回报：2025 年度每 10 股派 3.00 元（含税），全年累计派现 1.76 亿元，分红率 67.02%；2026 年中报拟每 10 股派 1.50 元（含税）——现金分红属性明确。

（3）产业链传导

上游：农产品初加工品（番茄、洋葱、香辛料）、油脂（棕榈油/大豆油）、包材（纸箱、铝塑复合）、糖/盐/味精，以及乳制品相关配料。公司以山东宝莘基地向上游延伸（初加工自给），这是主动的对冲动作：自建初加工环节意味着把原本属于供应商的那一段毛利内部化，同时削弱原料价格波动冲击。

下游：①连锁餐饮集团——议价权在客户侧（百胜等客户的年降要求与集采谈判），但认证周期长、切换成本高，一旦进入供应链粘性极强；②新零售渠道（山姆/盒马/量贩）——需要"渠道定制"能力，是增量但账期/毛利条件各异；③电商平台个人消费者——份额领先但平台流量费用持续上涨。

议价权：中等。证据：Q2 直销占比升至 87.06% 说明大客户依赖度在提高（负面：单一大客户风险；正面：粘性强）；同时毛利率能维持 33.6% 不降，说明对 B 端客户有一定成本转嫁能力（定制品的粘性换来的）。

第二步进阶：原料成本 → 毛利结构四因子

因子 1 · 成本传导弹性（pass-through）
- B 端定制复调：传导率 0.6–0.8。依据：①定制品有配方/口味壁垒，客户切换成本高；②但大型连锁客户有年度降价要求，转嫁不完全；③2026H1 在原料端有波动的背景下毛利率仅 −0.05pct，证明传导基本成功。季度可视验证点：季度毛利率。
- B 端标准品（大宗调味）：传导率 0.2–0.4，受集采式谈判约束。
- C 端轻烹（空刻）：传导率 0.0–0.3。线上零售价由平台算法与竞争决定，几乎无法直接提价——成本上升只能通过"换包装规格/缩克重/推高价新品"间接消化。这是 C 端的结构性弱点。依据：2025 年线上渠道毛利率 55.31%，明显高于整体 33.28%，但公司无法通过提价完全抵消投流费用上涨。
- 加权传导率 ≈ 0.5–0.65（按 2026H1 收入结构：轻烹 47.27%、复调 45.96%、配料 4.60%）。

因子 2 · 毛利结构再平衡（分业务线，禁单一综合毛利率）
单一"综合毛利率 33.63%"会掩盖两条完全不同的曲线：

业务/渠道 收入占比 估算毛利率 对综合毛利贡献 敏感原料权重
复合调味料（B 端定制为主） 45.96% 约 30%–33% 稳定贡献 中（农产品/油脂）
轻烹解决方案（C 端+B端混合，线上部分 55.31%） 47.27% 约 36%–40%（含线上高毛利拉动） 最大毛利来源 中低（面饼/酱包）
饮品甜点配料 4.60% 约 25%–30% 次要 高（乳制品/糖）
渠道口径：线上销售 约占 29%（2025 年 8.69/29.34） 55.31% 高毛利但高费用：25%+ 的投流费用吃掉大部分 —

结构性结论：①公司毛利的上行来自"线上高毛利 + C 端占比提升"，下行来自"投流费用同步上涨"，二者近乎相抵（2026H1 毛利率 −0.05pct、销售费用率 +1.62pct → 营业利润率被压约 1.7pct）；②真正能改变结构的是山东宝莘的农产品初加工自给率提升（把上游毛利内部化）与健康+高毛利新品放量，而非简单提价。→ 第四步的毛利率假设 34.5%（2029E）正是建立在这两点上，而不是"假设历史毛利率延续"。

因子 3 · 库存与采购节奏（timing）
- 存货周转天数：2025 年末 57.5 天 → 2026H1 62.1 天（存货周转率 6.26→2.90），小幅上升，与收入扩张节奏匹配，无明显囤货/滞销迹象。
- 应收账款周转天数 39.3 天（2025 年末 40.6 天）——账期健康且略有改善，说明直销大客户回款纪律好。
- 应付账款周转率 5.58（半年）/10.74（全年）——占用上游资金能力正常。
- 未见套保披露；但由于原料以农产品为主、单位价值低、周转快，套保必要性不高；真正的风险敞口是油脂与包材的价格周期性。
- 验证点：季度存货周转天数是否继续上升（>75 天为警示）；证伪信号：存货周转变慢同时毛利率下滑 → 说明高价库存积压。

因子 4 · 政策/市场锚点（原料成本驱动变量）
- 农产品价格（市场层）：情景 A（基准）——番茄/香辛料等农产品价格温和，公司通过山东宝莘初加工自给对冲 30%–40% 波动；情景 B（上行）——极端天气/减产导致原料涨 20%+，B 端按 0.6 传导 → 实际毛利承压约 8%（=20%×(1−0.6)），吞噬约 2.6pct 毛利率；情景 C（下行）——原料跌价，公司因已有终端定价不降，毛利率被动扩张 1–2pct。
- 油脂价格（市场层）：棕榈油/大豆油与全球大宗联动，属主要敏感项。
- 包材（瓦楞纸/铝箔）：受上游纸价与铝价影响。
- 能耗双控/环保（政策层）：山东基地属食品加工，能耗压力中等；政策趋严主要利好"合规产能替代小作坊"，对本股是净正面。
- 关税/出口管制：基本不适用（原料以国内农产品为主，收入以内销为主），这是本股区别于化工/资源类公司的显著优势。
- 验证点：季度毛利率、销售费用率、政府补助金额；证伪信号：毛利率跌破 32% 且销售费用率突破 19% → 传导失效 + 线上费用失控。

四因子输出 → 第四步假设：2029E 综合毛利率 34.5%（自给率提升 1.0pct + 健康+新品结构上移 0.4pct），销售费用率 17.5%（线上费用仍上涨但被规模效应部分对冲）。

层 2 · 扩展业务：主业迁移空间（"调味能力能否迁移到健康食品/功能配料"）
1. 能力可迁移性：中高。风味解决方案的配方数据库 + 客户共创机制 → 可迁移到"功能性配料/天然植提/代谢健康"方向（本质仍是"把某种功能做进食品里"）；但与药品级功能配料相比，缺少临床验证能力与法规资质。
2. 新 TAM 弹性：大。代谢健康（体重管理/控糖）、天然植物提取物、功能性配料是千亿级赛道，远大于复调本身。
3. 切入卡位：早期。公司自己表述仍在"前瞻性研究与差异化开发"阶段，四款 C 端新品刚上市。
4. 客户认证门槛：新赛道需要食品法规备案/功能声称合规，门槛高于传统调味品，且需要新的渠道（健康食品专营 vs 现有餐饮渠道不通用）。
5. 信号验证：需看到"健康+系列单品年销 >1 亿"或"与头部健康食品企业的代工/供应协议"。当前仅有"获目标客群良好反馈"（定性），未达验证点 → 严格作为中期期权，不计入中性情景。

层 3 · 风险折扣：证伪信号
- 大客户依赖：直销占比近 87%，若百胜等核心客户削减订单或引入二供，影响重大（2026H1 非直销已 −7.17%，需观察是否蔓延至直销）。
- 线上平台费用失控：销售费用率已升至 17.07%（+1.62pct），若继续攀升至 20% 以上，C 端高毛利的优势会被完全对冲。
- 行业竞争加剧：颐海、天味等均在扩产能，定制型赛道可能陷入价格战。
- 食品安全风险（本报告认为概率低但后果重）。
- 42% 以上收入来自 C 端（线上部分），对平台算法变化高度敏感。

第四步进阶：重资产 / 周期股估值校正三道闸（本股适用性逐条说明）

  • 校正 1 · 资产质量折扣：本股 PB 3.27x，远未破净，不适用破净陷阱分析。但须反向检查"3.27x PB 是否隐含减值风险"：①商誉 3,060.59 万元（占净资产 2.1%，规模小、无减值迹象）；②存货周转 62.1 天、应收周转 39.3 天，均无积压/坏账迹象；③资产负债率仅 25.93%、有息负债极低；④无"金融资产未按市价重估"这类隐藏价值的问题，也无"破净=真便宜"的伪空间可作主张。结论：资产干净、无隐藏负债，3.27x PB 由 18% 的 ROE 而非虚高资产支撑，此处无扣分。
  • 校正 2 · 周期位置校正：本股属弱周期必需消费（调味品），非强周期品。当前位置是"餐饮需求温和复苏通道中"（判断依据：2026H1 营收 +16.08%，较 2025 全年 +10.66% 加速，且饮品甜点配料增速由负转正）。因此中性净利既未使用单年好年景（如 2023 年 3.01 亿的高点，当年含一次性因素），也未使用近三年均值，而是用"2029E 收入 × 重建后的费用结构"，并在14.5pct 的费用率假设上给足了保守空间（销售费用率假设 17.5%，高于 2025 年的约 15.5%）。此闸风险低。
  • 校正 3 · 杠杆下行情景：资产负债率 25.93%，权益乘数约 1.35，无财务杠杆风险。做情景测试：①利率上行 2pct → 因几乎无有息负债，影响 <500 万/年，对 3.60 亿净利润的冲击 <1.5%；②需求下行 → 已体现在悲观情景（营收 38 亿、PE 16x、目标 9.10 元），下行情景空间为 −25.3%，未出现"空间转负且不可控"的情形。此闸风险极低，是本股最大的财务优势。
  • 期权纪律：主业迁移（健康+/功能性配料）未过验证点（仅"获目标客群良好反馈"，无单品销售金额、无战略客户协议），严格不计入中性净利，仅列为乐观情景的构成要素之一。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。现价 12.19 元对应 2026E PE 17.9x、PB 3.27x（对应 ROE 18.1%）。相比调味品同业（颐海国际、天味食品、日辰股份常见 15–25x），处于合理区间的中下沿，且叠加 67% 分红率与接近 1.0 的净现比，估值有支撑、无泡沫。

安全边际：
- 中性远期 18.00 元 → 空间 +47.7%（另有三年累计约 20% 的现金分红，含息总回报约 +68%）
- 悲观 9.10 元 → 下行 −25.3%
- 乐观 26.00 元 → +113.3%
- 赔率结构健康：上行/下行比约 1.9:1，且中性情景概率最高（公司订单节奏稳定、现金流优秀）

介入条件：
1. 价格：现价可建底仓；11.00 元以下（2026E PE<16x）为较好的加仓位；若跌至 9.5 元（悲观情景价位附近且基本面未变）为重仓机会
2. 信号（触发加仓）：① 单季扣非增速回升至 15% 以上；② 销售费用率见顶回落（跌回 16.5% 以下）；③ 健康+ 系列任一单品半年收入破 5,000 万；④ 新零售渠道（山姆/盒马/量贩）出现明确的大额定制订单公告
3. 观察指标（逐季必看）：销售费用率（最关键）、毛利率、直销 vs 非直销增速差、空刻意面线上份额

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 线上投流费用失控（首要）：销售费用率已升至 17.07%（+1.62pct），管理层明确归因"线上推广加大、平台结构变化影响整体 ROI"。若电商平台的流量成本继续上升而公司无法通过提价转嫁（C 端传导率仅 0.0–0.3），则"高毛利优势被高费用吃光"，利润结构会系统性恶化。这是本股的第一大变量。
2. 核心客户依赖：直销占比 87.06%，若百胜等核心客户削减订单、压价或引入二供，影响直接且重大。
3. C 端份额已近天花板：空刻意面线上份额 54.2%，继续提升空间有限；2026 年增量主要靠品类外延，执行风险高于原有主业。
4. 健康+ 新赛道的不确定性：客户认证门槛高于调味品，且需要新的渠道能力，目前仅有定性反馈。
5. 数据缺口：募投项目与上海金山二期均未披露设计产能与对应收入金额，本报告的三情景区间已相应放宽，但构成中长期测算的主要不确定源。

结论：纳入观察

核心理由：公司质地优秀——ROE 约 18%、资产负债率仅 25.93%、经营性现金流/净利接近 1.0、分红率 67%、空刻意面线上份额 54.2%、直销占比升至 87.06% 显示大客户粘性增强。

因此给予"纳入观察"——适合在 11.00 元以下逐步建仓，重点盯销售费用率是否见顶。一旦费用率回落信号确立，即可上调至"重点关注"。
