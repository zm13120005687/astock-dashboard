一句话定位：国内电子支付设备（POS 机）龙头，向下游延伸至收单及增值服务，并依托跨境支付平台 PayKKa 打造"支付硬件 + 支付服务"双出海，受益人民币国际化。

（3）产业链传导

上游：存储芯片、主控芯片、显示屏等电子物料。2026 年存储涨价是毛利率下滑主因，议价权弱（存储由三星、海力士等寡头定价）。

下游：银行、收单机构、商户、跨境电商。公司作为支付全链路服务商，对下游有一定议价权（增值服务提升粘性）。

议价权：中等偏强。硬件端受存储涨价挤压（上游强势），但服务端（收单 + 跨境支付）靠增值服务与合规能力形成壁垒，能通过产品结构升级对冲。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：电子支付硬件成本中存储芯片占比高，存储涨价向售价传导率 ≈ 0.5–0.6（部分转嫁，部分自担），致硬件毛利率 35.69% 仍承压；服务类业务无原料成本，不受影响。这是"硬件承压、服务稳"的分化。
  • 因子2 毛利结构再平衡：收单服务（28.71%）、硬件（35.69%）、技术服务（92.89%）毛利率差异显著。利润贡献正向高毛利服务迁移（收单 + 增值占比 60%、持续提升），存储涨价只砸硬件线，服务线对冲。禁以综合毛利率 31.54% 代表全结构。
  • 因子3 库存与采购节奏：存储涨价期若提前备货可对冲，但 2026H1 经营现金流 −1.25 亿（上年同期 +1.38 亿），或含备货资金占用，需观察 Q3/Q4 库存消化。
  • 因子4 政策/市场锚点：存储价格（市场层，需求+厂商减产）、人民币汇率（外销毛利率）、跨境支付政策（需求层）。验证点：存储现货价走势、公司硬件毛利率环比、跨境支付流水公告。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务 = 市场容量 × 份额变量：全球电子支付硬件 + 跨境支付市场随人民币国际化扩容。份额锚点：①供给侧——公司 POS 出货全球前列，海外渠道成熟；②客户侧——服务全球支付机构，认证粘性强；③技术代际差——智能 POS、软硬一体化领先；④成本曲线——规模效应显著；⑤份额二阶导数——海外份额加速渗透。验证点：海外硬件出货、跨境支付流水季度数据。
  • 层2 主业迁移空间：从"支付硬件"向"跨境支付服务 + 支付 AI"迁移，能力可迁移性高（支付牌照 + 技术同源），新 TAM（跨境支付）弹性大。PayKKa 已过初步验证（流水快速增长），但仍处早期，部分计入中性、主要作成长期权。
  • 层3 证伪信号：跨境支付流水增速放缓、硬件毛利率持续下滑（存储涨价传导失败）、监管收紧、汇兑持续损失。

第四步：估值锚定（自下而上，非增速外推）

方法：盈利成长股，按"收单服务 + 硬件 + 跨境支付"三线自下而上测算，结合订单/流水增速与毛利率假设，给三情景。

第四步进阶：估值校正

  • 资产质量：PB 2.31x，净资产 45.3 亿（含商誉 5.58 亿，占总资产 12.3%）。商誉主要来自收单业务收购，需跟踪减值风险，但收单业务盈利稳定，减值概率低。
  • 周期/杠杆：非重资产、非强周期，资产负债率 29.26%（低杠杆），有息负债率约 2%，财务稳健，无杠杆下行风险。
  • 一次性因素：2026H1 汇兑损失为一次性扰动，应剔除；2023 年 7.55 亿高净利含一次性收益，不作稳态锚。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。现价 17.86 元对应 2026E PE 17.5x，低于成长股中枢，市场对存储涨价 + 汇兑的短期利空定价偏充分，对跨境支付 + 硬件出海的中长期成长定价不足。

安全边际：
- 中性远期 29.1 元 → 空间 +62.9%，超过"重点关注"50% 门槛
- 悲观情景 15.9 元 → 下行仅 −11.0%，风险收益不对称偏正
- 下行保护：PB 2.31x、资产负债率 29%、持续分红（10 派 2.5），16 元附近支撑较强

介入条件：
1. 现价即可分批介入。17.86 元对应 2026E PE 17.5x，具备安全边际
2. 加仓信号：① 存储芯片价格见顶回落（硬件毛利率环比回升）；② PayKKa 跨境流水单季增速 ≥50%；③ 海外硬件出货持续高增
3. 观察指标：逐季综合毛利率（若持续下滑至 <29% 需下修）、跨境支付流水、汇兑影响

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 存储涨价超预期（首要）：若存储芯片持续涨价，硬件毛利率进一步承压，压制整体盈利
2. 跨境支付监管/合规：跨境支付牌照与合规成本上升，PayKKa 出海受阻
3. 人民币汇率波动：外销占比 39%，汇率大幅波动侵蚀利润
4. 硬件价格战：POS 硬件竞争加剧，量增利不增

结论：重点关注（成长逻辑清晰 + 估值合理偏低 + 远期空间 +62.9%）

第五步进阶：上行想象力情景（四类）

  • 类型A 行业出清剩者红利：支付硬件行业若出清小厂，新国都作为龙头份额与定价权提升。验证点：硬件行业集中度提升、毛利率企稳回升。
  • 类型B 政策反转/加码期权：人民币国际化加速（CIPS 扩容、数字人民币跨境），跨境支付 PayKKa 直接受益。验证点：跨境支付牌照落地、人民币跨境结算政策加码。
  • 类型C 市场错杀修复：2026H1 归母 −1.64%（存储 + 汇兑）若被市场过度反应，随 Q2 环比改善延续，估值修复。验证点：扣非增速回正并扩大。
  • 类型D 技术突破/代际跃迁期权：支付 + AI（智能客服、风控、场景数字化）若落地，打开增值服务新空间。硬验证点（产品落地 + 客户付费）未过，仅作机会情景。

上调"重点关注"的条件已满足（中性远期空间 +62.9% > 50%），无需额外上调。若跨境支付流水持续高增 + 毛利率修复确认，可进一步上调远期目标价至乐观情景。
