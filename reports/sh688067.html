第一步：公司是干什么的？

一句话定位：国内显微镜自动化形态学检验的先行者，基于机器视觉技术的"尿液 / 粪便 / 生殖道分泌物"有形成分医学显微图像自动识别，做检验仪器 + 配套试剂 + 耗材的研发产销，并转型"AI 辅助诊断 + 医学检验服务 + 高端医学影像"综合方案商。

（3）产业链传导

上游：光学部件、电子元件、试剂原料。公司"已投资设立多家控股 / 参股公司，完成从上游核心光学部件到下游医学检验服务全产业链布局"，上游部分自供，成本传导弹性中等（试剂原料涨价可部分转嫁，但仪器价格受竞争约束）。

下游：医院检验科（政府预算采购），价格受集采 / 招投标约束，议价权中（细分龙头但客户为强势买方）。

议价权：中等。细分赛道有先发与数据库壁垒（医学显微图像数据库领先），但面对医院大客户定价偏弱；出口业务毛利率更高，占比提升改善结构。

第二步进阶·原料成本 → 毛利结构（四因子）
- 因子1 成本传导弹性（转嫁系数≈0.5）：仪器为资本开支品，医院招标压价，成本难全转嫁；试剂耗材复购属性强、转嫁系数高（≈0.8）。综合转嫁系数中等。验证点：毛利率 61.10%（稳）。证伪：若招标价格战致毛利率破 55%。
- 因子2 毛利结构再平衡：仪器 33.5%（毛利中）、试剂 46.5%（毛利高）、耗材 18.5%（毛利高）。结构优化方向=试剂耗材占比升 + 出口占比升 → 加权毛利稳中向上。验证点：H1 出口 +75% 已带动结构改善。
- 因子3 库存与采购节奏：H1 经营现金流 0.04 亿（−63.84%）系"战略备货"致采购支出增，属主动囤货（非高价接货损失），若备货对应后续订单则合理；验证点：H2 现金流是否回正。
- 因子4 政策 / 市场锚点：原料成本驱动=①试剂原料（酶 / 抗原）价格波动；②设备更新财政补贴节奏（正面，抬升需求）；③汇率（出口用，正面）。情景：财政补贴退坡=需求下行；验证点：县域医共体采购招标量。

（3）第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：
  • 供给侧：形态学检验自动化细分赛道竞争者少（爱威先发），份额稳。
  • 需求侧 / 客户份额：二级医院 + 基层 + 海外，客户分散；出口占比从 13%→目标 20%+（验证点：季度出口收入）。
  • 技术代际差：医学显微图像数据库领先，AI 识别准确率构成壁垒（验证点：装机量、复购率）。
  • 三档：保守（出口稳 15%，营收 CAGR 3%）/ 中性（出口 20%，CAGR 6%）/ 乐观（出口 30% + 检验服务放量，CAGR 12%）。
  • 层2 主业迁移空间（新易盛范式）：从"设备商"→"检验服务 + 高端影像 + AI 诊断"，能力可迁移（光学 + AI 同源）。但未过验证点（检验服务收入未披露量化），仅作中期期权，不计入中性。
  • 层3 证伪信号：出口增速回落至 <20%、毛利率破 55%、检验服务无收入落地 → 下调增量。

- 期权纪律：检验服务 / 高端影像未过验证点，不计入中性净利。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 22.66 元对应 2026E PE 41.6x、中性远期 17.35 元（−23.5%），估值已透支温和增长。

安全边际：中性 −23.5%；悲观 −57.2%（至 PB 1 附近）；乐观 +22.7%。PB 2.93 提供有限下行保护。

介入条件：①回落至 16 元以下（对应 2026E PE <30x、接近 PB 2x）才具安全边际；②加仓信号：出口收入连续两季 +50%+、检验服务收入正式披露、毛利率稳于 60%+；③观察指标：季度出口占比、经营现金流回正。

最大风险：①估值回归（PE 47 对 3% 增速不可持续，首要）；②医院招标价格战致毛利下滑；③出口高增不可持续；④战略备货致现金流波动。

结论：暂不介入（增速慢、估值偏高，中性空间 −23.5%，须等估值回落或出口持续超预期）

第五步进阶·上行想象力情景（四类）
- A 行业调整剩者红利：细分赛道出清，爱威凭数据库壁垒份额提升。验证点：竞品退出、装机份额升。
- B 政策反转期权：设备更新财政加码 + 基层检验下沉加速，需求跳升。验证点：县域医共体招标放量；证伪：补贴退坡。
- C 市场错杀修复：若因风格切换被错杀至 PB 2x 以下，凭 61% 毛利 + 低负债修复弹性大。验证点：估值分位回落。
- D 技术突破 / 代际跃迁期权：AI 辅助诊断 + 检验服务从"设备商"跃迁为"服务 + 数据"平台，打开新 TAM。硬验证点：检验服务收入占比跳升 + 客户认证放量 + 服务毛利优于设备。当前未过验证点，仅作机会情景，不计入中性。
