一句话定位：集研发、生产、销售一体的医药制造企业，以中药制剂为主、化药为辅，靠两款独家核心品种（四磨汤口服液、天麻醒脑胶囊）形成"消化+心脑血管"双轮驱动。

（3）产业链传导

上游：中药材（四磨汤原料）、化药原料——受药材价格周期影响，但独家品种成本传导较强。下游：医院/药店/基层，集采压价但以量补价。议价权：独家品种（四磨汤、天麻醒脑）强（无直接竞品，医保乙类刚需）；普药/集采品种中等。

第二步进阶·原料成本→毛利结构（四因子）
- 因子1 成本传导弹性：独家中成药（四磨汤/天麻醒脑）对下游强议价，药材涨价传导率≈0.8（部分转嫁+费用消化）；集采品种传导率≈0（以价换量）。实际毛利承压 = 药材变动×(1−传导率)。验证点：中药材价格指数、集采中选价。
- 因子2 毛利结构再平衡：分产品——四磨汤 80.19%、天麻醒脑 81.39%、缩泉 78.31%、固体口服 62.56%。四磨汤占比 52.6% 为利润主源，天麻醒脑（高毛利、连续增长）占比提升将结构性抬升综合毛利；固体口服（低毛利）占比下降。禁止用综合 78.37% 代表全结构。原料敏感权重：四磨汤对药材敏感、天麻醒脑次之。
- 因子3 库存与采购节奏：中药材低价囤货收益（如药材下行期）可虚高当期毛利；集采以价换量存在"量未起、价已降"timing 风险。验证点：存货、集采执行量。
- 因子4 政策/市场锚点：①市场层——中药材价格周期；②政策层——集采（压价，双刃）、医保/基药目录（进目录放量）、中医药振兴补贴（利好）、药材种植补贴。情景：集采以价换量兑现→量增（正面）；药材飙涨+集采降价→毛利破阈值（负面）。验证点：集采出货量、药材价。

第三步进阶·份额变量与主业迁移空间（三层法）
- 层1 现有业务：市场容量 × 份额变量：①供给侧——四磨汤为独家（无直接竞品，份额=细分市场主导）；②需求侧——进核心医院/医共体供应链（认证周期=粘性）；③技术代际——独家配方壁垒（领先一代）；④成本曲线——规模+高毛利位于左端；⑤份额二阶导数——四磨汤成熟（S 曲线顶部），天麻醒脑仍渗透期。三档：保守（守成）、中性（集采以价换量+5–8%）、乐观（基层下沉抢量）。验证点：集采出货量、医院覆盖数。
- 层2 扩展业务：主业迁移空间：①能力可迁移——中药独家品种经验→化药/新剂型；②新 TAM——慢病/基药广阔市场；③卡位——已上市品种延伸；④认证门槛——医保/基药准入（高）；⑤信号验证——恩格列净等中选（已验证）。属"中期期权"，计入中性。
- 层3 证伪信号：集采降价超预期致净利下滑、四磨汤增长停滞、药材飙涨、产品退目录 → 下调增量。

- 校正1 资产质量折扣：轻资产制药，PB 1.90（无破净）；商誉仅 0.15 亿（极低），资产质量干净。

- 校正3 杠杆下行情景：负债率低，无高杠杆下行；悲观情景 7.16 元（−18.8%）来自集采降价，非杠杆反噬。期权纪律：新化药/院外为已验证中期期权，计入中性偏乐观。
- 估值合理性论证：现价 8.82 对应 TTM 18.8x、2026E 约 19x，对独家中药高毛利（78%）现金牛属合理；但近期连续涨停炒作已部分透支，须等回调。

第五步：综合赔率判断（买不买？）

当前价格位置：合理略贵。现价 8.82 对应 TTM 18.8x、2026E ~19x，估值合理；但近期连续五日涨停（最高 12.33 元）后回落，存在炒作回撤风险。

安全边际：
- 中性远期 11.37~13.12 元 → 空间 +28.9%~+48.8%（保守口径未达 >50%）
- 悲观 7.16 元 → 下行 −18.8%
- 乐观 19.68 元 → +123.1%
- 下行保护：PB 1.90x、商誉极低、高毛利（78%）现金牛、净利增速>营收

介入条件：
1. 不追高（规避连板炒作回撤）。等回落至 7.5 元以下（PB<1.7x） 再布局
2. 加仓信号：① 集采以价换量出货量兑现；② 天麻醒脑增速维持 >15%；③ 新品类（恩格列净等）放量
3. 观察指标：逐季毛利率、集采执行量、机构持仓

最大风险（最可能破坏逻辑的因素）：
1. 集采降价超预期（首要）：以价换量不及预期，净利承压
2. 近期炒作回撤：连续涨停后估值透支，情绪退潮
3. 单品依赖：四磨汤占比 >50%，若增长停滞影响大
4. 药材价格上涨：成本传导不及

第五步进阶·上行想象力情景（四类，对冲系统性保守偏置）
- A 行业调整剩者红利：中医药行业集中度提升，独家品种（四磨汤/天麻醒脑）为剩者，集采以价换量放大份额。验证点：集采出货量、医院覆盖。证伪：份额流失。
- B 政策反转期权：中医药振兴 + 基药/医保目录调整（进目录放量）。验证点：目录调整发文、进目录公告。证伪：未进目录/集采压价超预期。
- C 市场错杀修复：中药板块估值从低位修复（近期连板已部分反映，但回撤后仍有修复空间）。验证点：估值分位、机构回流。证伪：炒作退潮证伪=基本面恶化。
- D 技术突破/代际跃迁期权：独家品种新适应症/新剂型延展（天麻醒脑延伸）。硬验证点：临床/审批进展 + 客户定点。计入机会情景。证伪：研发失败。
- 上调"重点关注"条件：回落至 7.5 元以下 + 集采以价换量出货量兑现 + 天麻醒脑增速维持 >15% → 中性上修至乐观（+123.1%）。

结论：纳入观察

理由：中性远期空间 +28.9%（保守），未达"重点关注">50% 门槛；且近期连板炒作已部分透支，须等回调至 7.5 元以下。公司质地优秀（独家品种壁垒、高毛利、净利高增），但当前价安全边际不足。若回落至 7.5 元以下或集采放量验证，可上调至重点关注。
核心跟踪点：集采以价换量出货量 + 天麻醒脑增速 + 股价回调幅度。
