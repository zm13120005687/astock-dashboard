第一步：公司是干什么的？

一句话定位：以金刚石工具起家、涂附磨具为基本盘、轨交装备零部件（制动盘/闸片）为高毛利延伸的"耗材+装备"型制造企业，本质是机械加工与轨交维保的上游供应商。

主要客户/下游：涂附磨具→建材、木材、金属加工、汽车制造等通用制造业（客户分散）；金刚石工具→石材加工、建筑工程、海外建材渠道（出口占该板块约一半）；轨交零部件→国铁集团、中车系主机厂及维保体系。

实控人/股东：控股股东为博深工具有限公司（创始人系国有改制背景），股权结构稳定；需重点关注商誉 11.30 亿——主要来自收购金牛研磨（涂附磨具）等，占归母净资产约 32%，是估值的核心隐性风险。

第二步：行业景气度 + 政策/市场数据

（1）政策端（近 6–12 个月）——中性偏利好，但非强驱动

  • 设备更新/工业母机：2024 年《推动大规模设备更新和消费品以旧换新行动方案》延续至 2026 年，通用制造业资本开支边际企稳，利好涂附磨具等耗材需求（消耗属性，与制造业开工率正相关）。
  • 轨交维保：国铁集团"十四五"末高铁保有量超 4.8 万辆，制动盘/闸片进入维修更换周期；但 2026H1 国铁采购节奏波动导致公司轨交订单减少（收入 −37.84%），政策长逻辑在、短节奏弱。
  • 出口关税：美国对部分金刚石工具加征关税，但公司 2026H1 获美国海关关税退还+汇兑收益，反而增厚板块利润（金刚石工具归母 +22.21%）。

（3）产业链传导

上游：刚玉/碳化硅磨料、布基/纸基基材、金属粉末（金刚石工具）、合金钢/铸铁（轨交）。磨料价格处历史低位，低价囤货对当期毛利有正贡献；金刚石工具用金属粉随钢价波动。

下游：通用制造业（议价中弱）、海外建材渠道（溢价较强）、国铁/中车（议价中等偏强、订单节奏主导）。

议价权：涂附磨具中弱（下游分散、同质化）；金刚石工具中强（出口品牌+退税红利）；轨交零部件中等（绑定国铁认证，但客户强势、价格年降）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数）：涂附磨具转嫁系数 ≈ 0.4（布基砂带毛利率仅 10.32%，成本难转嫁）；金刚石工具转嫁系数 ≈ 0.7（毛利率 46.63%，出口溢价+退税兜底）；轨交零部件转嫁系数 ≈ 0.5（年降压力抵消部分成本传导）。
  • 因子2 毛利结构再平衡：三业务毛利率分化极大（10.32% / 46.63% / 38.71% / 26.89%），单一综合毛利率 26.08% 掩盖结构。原料敏感权重：涂附磨具对磨料+布价敏感（占成本 60%+）、金刚石工具对金属粉+金刚石敏感、轨交对合金钢敏感。若磨料涨价 10%，涂附磨具毛利承压约 4–5pct，但因其占比 57.6%，会拉低综合毛利约 2.5pct。
  • 因子3 库存与采购节奏：磨料低位时公司低价备货产生"库存收益"，2026H1 经营现金流 +67.31%（含关税退回），部分毛利高来自库存收益而非真实盈利改善；需区分当期 vs 远期可比性。
  • 因子4 政策/市场锚点：①市场层——钢价/磨料期货低位；②政策层——美国关税（已通过退还对冲，但若退还退坡则金刚石工具毛利回落）、设备更新补贴（托底涂附磨具需求）。情景：关税退还延续则金刚石工具维持高毛利；退坡则该板块净利率回落 3–4pct。验证点：海关退税公告、磨料价格走势。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务份额变量：①供给侧——涂附磨具国内分散，公司布基砂带居前，份额稳定；②客户侧——金刚石工具海外渠道认证粘性中；③技术代际——涂附磨具处成熟代，无代差；④成本曲线——规模+金牛研磨协同，成本居中；⑤份额加速度——涂附磨具微增（+1.35%），近 S 曲线平台。中性：守住份额、微提。验证点：下季涂附磨具出货、金刚石工具海外订单。
  • 层2 主业迁移空间：轨交零部件→维保后市场是"池塘扩大"，但受制国铁认证节奏，未过验证点（2026H1 订单反降），仅作中期期权，不计入中性。
  • 层3 证伪信号：轨交订单连续两季下滑、涂附磨具价格战致毛利率破 15%、商誉减值公告。命中则下调增量。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 0.91x（破净边缘）主因商誉 11.3 亿（占净资产 32%）未出清+轨交重资产盈利波动，非金融资产重估型安全边际，破净含"虚高净资产"风险，故不简单视为低估。
  • 校正2 周期位置：涂附磨具处制造业弱周期、轨交处国铁采购低谷，中性净利已偏保守（未用景气年外推），合理。
  • 校正3 杠杆下行：资产负债率不高（无有息负债压力），但商誉减值属隐性下行期权，若金牛研磨业绩不达标触发减值，净利可转负，故悲观情景空间 −20.3% 已体现。

第五步：综合赔率判断（买不买？）

当前价格位置：合理略偏高，现价 6.06 已兑现 2026E 业绩，PB 0.91 含商誉折价。

安全边际：中性远期 8.68 元 → 空间 +43.2%（未达重点关注 >50% 门槛）；悲观 4.83 元 → 下行 −20.3%。

介入条件：回落至 5.4 元以下（PB<0.85、2026E PE<17x）再具安全边际；加仓信号——轨交订单恢复公告、涂附磨具毛利率守住 18%、商誉无减值。

最大风险：①商誉减值（11.3 亿）；②轨交订单持续低迷；③美国关税退还退坡致金刚石工具毛利回落；④涂附磨具价格战。

结论：纳入观察

质地平庸但估值不贵，中性空间 +43.2% 未达重点关注门槛。核心跟踪点：轨交订单恢复 + 商誉减值风险。若轨交明确恢复（乐观情景 +105%），可上调重点关注。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：涂附磨具低端产能出清，公司凭规模+金牛协同份额提升 → 验证点：中小磨企退出公告；证伪：价格战加剧。
  • B 政策反转期权：设备更新补贴加码+国铁维保放量 → 验证点：国铁招标回暖；重估弹性 +20%。
  • C 市场错杀修复：PB 0.91 处历史低位，若轨交企稳情绪修复 → 验证点：估值分位回升。
  • D 技术突破期权：轨交闸片新配方/认证突破 → 硬验证点：获新车型定点；未过验证点仅作机会。
  • 上调重点关注条件：轨交订单连续两季恢复增长 + 商誉无减值 + 股价回落至 5.4 以下。
