（3）产业链传导（银行的"原料"= 负债成本）

上游（负债/资金）：存款是核心负债（付息率主动压降），同业与央行借款补充。2026 年降准+降存款利率预期下，负债成本有望继续下行，但资产端贷款收益率随 LPR 同步下行，净息差能否企稳取决于"存贷利差"管理。

下游（资产/信贷）：甘肃基建、新能源、科创、普惠、民生领域信贷需求；区域集中度高风险（西部经济波动、城投/小微敞口）。

议价权：中。对存款客户（居民/企业）定价权有限（存款竞争），对贷款客户有一定风险定价权但在区域竞争中受挤压。

第二步进阶：负债成本 → 净息差结构传导（四因子，银行"原料"类比）

银行无实物原料，其"原料"是负债资金成本，直接决定净息差（毛利结构）。以下四因子对应规则要求，将"原料成本→毛利结构"适配为"负债成本→净息差结构"。

  • 因子1 成本传导弹性（pass-through）：资产端贷款收益率随 LPR 下行（传导率≈1，客户受益）；负债端存款付息率主动压降（公司 −19BP、个人 −40BP）。当前"资产端降速 > 负债端降速"导致 NIM 收窄——传导不对称。验证点：逐季 NIM 是否守住 1.30%；证伪：NIM 破 1.20%。
  • 因子2 毛利结构再平衡：利息净收入（净息差）占营收 76.6%、非息收入 23.4%（+9.8% 更快）。NIM 敏感权重极高（1.30% 的 NIM 对应 2590 亿贷款）。分业务给"息差贡献"：对公/零售贷款、金融市场。禁单一综合 NIM 代表——非息收入提升正在改善结构。2029 测算分"息差收入+非息"。
  • 因子3 库存与采购节奏：银行"库存"= 可配置资产（贷款 vs 金融投资）。兰州银行投资活动现金流 −90.72 亿（债券配置），负债成本下行期"早配早受益"；但若利率继续降，存量高息资产再投放收益降低。验证点：生息资产收益率、债券配置节奏。
  • 因子4 政策/市场锚点：①市场层——市场利率/债券收益率；②政策层——降息降准（降负债成本但压资产收益）、存款自律机制（压付息率）、金融监管资本要求。情景：降息 20BP 若负债端跟降则 NIM 持平；若存款竞争加剧则 NIM 再降。验证点：LPR、存款付息率、央行操作；证伪：NIM 持续下行至 1.1% 以下。

第三步进阶：份额变量与主业迁移空间（三层）

  • 层1 现有业务·市场容量×份额变量：①供给侧——甘肃存贷款市场，公司存款市占 12.28%（第2）、贷款 10.05%（第3），区域龙头但非垄断；②客户份额——730 万零售客户、12.31 万对公，粘性高（本土网点壁垒）；③技术代际——数字银行（手机银行 406 万）处区域中上；④成本曲线——负债成本压降使净息差优于部分同业；⑤份额加速度——市占稳中有升。三档：保守（份额持平、资产 CAGR~3%）/中性（份额微升、CAGR~4%）/乐观（五篇大文章放量、CAGR~6%）。验证点：逐季存贷款市占、NIM。
  • 层2 扩展业务·主业迁移空间（新易盛范式）：传统存贷 → 非息/财富管理/数字金融，是"老池塘→新池塘"。①能力可迁移（客户基础复用）；②新 TAM 弹性（财富管理中收空间大）；③切入卡位（区域早中期）；④认证门槛（金融牌照，高）；⑤信号验证（非息 +9.8% 已现）。结论：中期期权，未过验证点不计入中性（中性仍以传统息差为主）。
  • 层3 风险折扣·证伪信号：不良率回升破 2.0%、拨备覆盖率破 150%、NIM 破 1.2%、区域信用事件——命中则下调。

第四步进阶：重资产/周期/杠杆校正

  • 校正1 资产质量折扣（破净原因必须说明）：
    兰州银行 PB 0.38 破净，原因非"资产被严重低估的金融资产"（银行资产是贷款而非可交易股权，无"持股未重估"安全边际），而是公允定价反映：
    ① ROE 过低：H1 ROE 仅 2.83%（年化 ~5.66%）、2025 ROE 5.36%，远低于股权成本，账面净值的内生增长能力差，市场不愿给净资产溢价；
    ② 净息差极致压缩：NIM 1.30% 处历史低位，盈利弹性弱；
    ③ 资产质量隐忧：西部区域性银行，城投/小微/产业贷敞口集中，不良率 1.78% 虽可控但拨备 191.69% 空间有限，净资产含"潜在不良"水分；
    ④ 行业性破净：A 股银行板块普遍 PB<1（净息差周期底部+地产/城投风险折价），非个股特有错杀。
    → 结论：破净主要是公允定价，非"免费安全边际"；但 PE 6.98x + 191% 拨备 + 稳定区域特许经营 + 高分红，提供下行有限的保护。禁止单凭 PB<1 推"大空间"。
  • 校正2 周期位置校正（中性净利用周期归一化）：银行业处净息差周期底部（NIM 历史低位、LPR 长停、降息预期压制），同时资产质量周期中性偏谨慎。中性扣非净 20.5 亿已用"息差企稳+信用成本稳健"的周期归一化值（非单季好年景、非拐点年化），并明确标注当前处息差底部、资产质量中性。顶部未至，底部不过度悲观。
  • 校正3 杠杆下行情景（高负债必附负面情景）：银行负债率 93.16% 是行业固有高杠杆（存款/同业负债），并非经营激进扩产。但高经营杠杆下，若 NIM 进一步压缩 + 不良率跳升（区域信用事件），净利可数倍下挫——悲观情景 PB 0.32x、空间仅 +8.2%（未转负，因银行 ROE 难为负）。该负面情景若恶化（不良破 2.5%、拨备破 150%），空间可转负（PB 0.28x → 1.96 元，−5.3%）。→ 因高杠杆属性，虽 PB 低，但不得标"大空间/重点关注"作为主结论，至多"纳入观察"并注明高贝塔+区域风险。

第五步：综合赔率判断（买不买？）

当前价格位置：低估（绝对估值）但折价有因。PB 0.32x、PE 6.98x、191% 拨备，绝对便宜；但破净反映低 ROE+区域风险，非无风险套利。

安全边际：
- 中性远期 3.24 元 → 空间 +56.5%（源于 PB 从 0.32x 修复至 0.45x，非盈利爆发）
- 悲观 2.24 元 → 下行仅 +8.2%（银行 PB 难破 0.3x，下行有限）
- 乐观 4.44 元 → +114.5%，需 NIM 回升+板块重估

介入条件：
1. 现价 2.07 已具配置价值（PB 0.32x 历史低位），但建议 1.90 元以下（PB 0.30x）加大仓位
2. 加仓信号：①NIM 连续两季企稳回升（破 1.30% 向上）；②不良率降至 1.7% 以下、拨备稳定；③板块估值系统性修复（银行 PB 均值回升）
3. 观察指标：逐季净息差、不良率、存款付息率、区域信用事件

最大风险：
1. 净息差继续压缩（降息周期资产端降速>负债端），ROE 进一步下滑
2. 西部区域经济/城投/小微信用风险暴露，不良率跳升
3. 板块性破净长期化（银行股估值中枢下移）
4. 分红可持续性若利润下滑受影响

结论：纳入观察（绝对低估但破净有因，等 NIM 企稳+资产质量验证，不盲目"破净即买"）

兰州银行破净是公允定价（低 ROE 5–6% + NIM 极致压缩 1.30% + 西部区域风险折价），非"资产被低估的免费安全边际"。但 PE 7x + 191% 拨备 + 稳定区域特许经营，下行有限（悲观仅 +8%）。中性远期 +56.5% 来自估值修复而非盈利爆发，且高杠杆（负债率 93%）下负面情景需警惕。结论纳入观察：现价可小仓位配置，但须等 NIM 企稳与资产质量持续验证，方可上调重点关注。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • 类型A 行业调整剩者红利：银行业供给侧（中小银行兼并、资本补充），区域龙头市占提升。验证点：存贷款市占率续升、并购预期；证伪：份额流失。
  • 类型B 政策反转期权：货币宽松（降息降准）若使 NIM 企稳甚至负债成本降幅超资产端，息差触底反弹；监管资本补充红利。验证点：NIM 回升、存款付息率续降；证伪：LPR 单边降+存款竞争。
  • 类型C 市场错杀修复：银行板块 PB 均值从 0.6x 修复、机构增配高股息，兰州银行从 0.32x 向板块均值靠拢。验证点：板块 PB 均值回升、南向/机构持仓；证伪：板块估值中枢再下移。
