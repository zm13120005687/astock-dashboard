（3）产业链传导

  • 上游：研发成本（人力/美术外包/服务器/买量）、IP 授权金（付给集英社/圆谷/SNK）。IP 授权金为固定+分成，强 IP 抬高成本但带来流量确定性。
  • 下游：应用商店（苹果/安卓渠道抽成约 30%）、买量平台（抖音/腾讯广告）。渠道强势 → 公司议价权中等偏弱（毛利率仅 13% 的游戏分成即受渠道挤压）。
  • 议价权判断：中偏弱。版权运营（50% 毛利率）与技术服务（85%）议价权高，但占比小；游戏分成占比 80% 且渠道抽成刚性，是盈利结构短板。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：游戏业"原料"= 买量流量 + IP 授权金。流量成本（CPI）由抖音/腾讯拍卖决定，公司转嫁系数≈0（只能内部优化素材 ROI），故流量涨价直接吃毛利；IP 授权金为合约锁定，短期刚性。→ 议价权量化为转嫁系数 0~0.1。
  • 因子2 毛利结构再平衡：分业务毛利率差异极大（游戏 13% / 版权 50% / 技术 85%）。2026H1 版权运营占比由近 0 跳至 14.46%，直接拉高综合毛利 24pct——这是结构迁移而非单价上涨。验证点：版权运营能否持续（看后续 IP 授权签约数）。
  • 因子3 库存与采购节奏：游戏无实物库存；"库存"体现为已上线游戏的生命周期现金流。2026H1 经营现金流 −725 万（买量前置），属 timing 性，非真实盈利恶化。
  • 因子4 政策/市场锚点：① 游戏出海战略（政策利好，降低出海合规成本）；② 版号节奏（市场层，影响上线时点）；③ 小游戏平台分成政策（微信小游戏抽成低于 APP，利好轻量化产品）。情景：出海政策加码→海外占比提升→结构性毛利改善；证伪：版号收紧/出海合规摩擦→新品延后。

第三步进阶：份额变量与主业迁移（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：中国移动游戏市场约 2000+ 亿，公司份额 <0.5%（长尾）。锚点：① 供给侧——公司靠 IP 差异化而非规模，份额提升靠"拿到头部 IP"；② 客户侧——腾讯/朝夕光年绑定（渠道即份额）；③ 技术代际——AI 美术降本提升 ROI；④ 成本曲线——小游戏轻量化降低获客成本；⑤ 份额加速度——版权运营占比跳升为正信号。三档：保守守住（份额 ~0.4%）、中性小幅提升（0.5–0.7%，靠新品）、乐观抢份额（>1%，靠现象级《遮天世界》）。验证点：单款新游首月流水、版权运营签约数。
  • 层2 主业迁移（新易盛范式）：能力可迁移性=强（研发/发行同赛道复用）；新 TAM=小游戏 + 海外市场（弹性大）；卡位=早期出海经验；认证门槛=版号 + IP 授权（已是护城河）；信号验证=境外收入 +36.99%、小游戏上线。→ 视为中期期权，计入乐观情景，不计入中性。
  • 层3 风险折扣（证伪信号）：新游上线流水不及预期、版号延后、买量 CPI 失控、IP 授权续约失败 → 下调增量。

第四步：估值锚定（自下而上，非增速外推）

总股本：约 10.67 亿股。

亏损股特别处理：正常化净利润法（三步）

  1. 估稳态营收：现有长线 2 亿 + 新品/版权/出海，2029 稳态 8–9 亿（产能=研发+发行能力已验证，非外推）。
  2. 算正常化净利率：取保守——公司历史最好年份（2021）净利率高但含一次性；考虑游戏分成 13% 毛利 + 版权 50% 毛利结构，稳态综合净利率 15–18%（成本：买量+IP 分成+研发摊销）。
  3. 正常化净利润 × 远期 PE = 目标市值。

交叉校验：现价 3.12 元对应 2026E PE 33x、2029E 中性 PE 仅 21x——市场已提前定价 2027–28 兑现，中性情景下 2029 仍有 +34.6% 空间，但悲观情景 −69.9% 反映扭亏尚不稳固。账上商誉仍 12.74 亿（占净资产 51%），未来若再减值将重击利润——这是核心估值风险。

亏损股三问

  1. 为什么亏：2024/2025 连续巨亏（−5.28 亿 / −5.58 亿）主因商誉及资产减值（收购酷牛互动、天上友嘉形成的高商誉），叠加老游戏衰退、买量费用高。2026H1 减值出清后已扭亏 +499 万。
  2. 靠什么扭亏 / 时点：① 新 IP 游戏（《全明星觉醒》《奥特曼》）2026 年上线兑现；② 版权运营从 0 到 4526 万（50% 毛利）成为利润池；③ 出海（境外 +37%）。扭亏已于 2026H1 兑现，后续看利润从 0→1→N 的爬坡。
  3. 亏得起吗：账上货币资金 0.64 亿 + 经营现金流转正能力（H1 经营现金流 −725 万系买量前置，历史年度为正）；总资产 28.9 亿、净资产 24.7 亿，无有息负债压力；国资/合伙人背景融资能力强，可撑到扭亏兑现。但现金偏紧，需持续经营现金流转正验证。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高。3.12 元已反映 2027–28 年改善预期，中性 2029 仅 +34.6%，悲观 −69.9%。

安全边际：中性 4.20 元（+34.6%）不达"重点关注 >50%"；下行保护弱（商誉 12.74 亿悬顶，现金仅 0.64 亿）；乐观 8.20 元（+162.8%）依赖现象级新品。

介入条件：① 不追高，等回落至 2.40 元以下（接近 2026E 估值底）；② 加仓信号：《遮天世界》《航海王》上线首月流水超预期、版权运营收入连续两季 >5000 万、境外收入占比突破 35%、经营现金流转正。

最大风险：① 新游上线表现不及预期（Q2 已转亏预警）；② 商誉再减值；③ 买量 CPI 失控侵蚀毛利；④ 核心 IP 授权续约失败。

结论：纳入观察（远期 >0 但 ≤50%，需等新品验证）

公司质地从"减值黑洞"转向"IP 兑现期"，2026H1 扭亏是真实拐点，但盈利结构仍脆弱、估值已提前反映预期。真正的机会在于《遮天世界》等头部 IP 能否跑出超额——验证后具备上调"重点关注"条件。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：游戏行业版号常态化 + 尾部出清，精品 IP 厂商份额集中。验证点：公司份额提升、TOP 新品排名；证伪：行业量价双杀。
  • B 政策反转期权："十五五"游戏出海国家战略加码，文化出海补贴/税收支持。验证点：出海专项政策发文；重估弹性 +20~30%。
  • C 市场错杀修复：若因 Q2 转亏等情绪冲击跌至 2.4 元以下（PB<1.1x），具备修复弹性。验证点：经营现金流转正 + 新游流水。
  • D 技术突破/代际跃迁期权：AI 生成式美术 + 小游戏轻量化发行，降本提效打开利润率曲线。硬验证点：AI 工具使研发周期缩短 30%+、小游戏单款 ROI 转正。三类（B/C/D）只进乐观/机会栏，不进中性锚。
  • 上调至"重点关注"的条件：《遮天世界》上线后稳态月流水 >1 亿、版权运营年收入 >1.5 亿、2027E 净利 >2 亿且经营现金流转正 → 中性远期空间可上修至 >50%。
