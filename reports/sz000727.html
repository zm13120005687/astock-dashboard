股东背景 / 实控人：最终控制方为国务院国资委体系（中国电子 / 冠捷科技国际架构），为国有控股海外上市架构回 A 的显示制造平台。

（3）产业链传导

上游：液晶面板、存储芯片（DRAM/NAND）、PCB、结构件。2026 上半年 AI 算力挤占晶圆产能 → 存储与 PCB 全产业链涨价；地缘冲突推高能源与大宗。公司作为整机制造中间环节，议价权中等偏弱——面板/存储涨价难以全部转嫁终端（消费者价格敏感），成本压力自己扛大部分。

下游：品牌商与渠道。需求端受补贴与赛事脉冲拉动，但存储涨价抑制 DIY 与终端出货总量（全球面板销售额 −1.8%）。

议价权判断：弱（代工模式、客户集中、产品同质化），转嫁系数低；仅高端电竞/OLED 子品类有一定溢价能力（AOC/AGON 品牌）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：上游面板/存储/PCB 涨价，公司转嫁系数约 0.3–0.4（弱议价），即上游涨 10%，公司实际毛利承压约 6–7%。验证点：H1 综合毛利率 −0.68pct 而面板价格上行，说明成本未有效转嫁；Q2 毛利率环比 +1.78pct 源于结构升级（高端占比提升）而非全面提价。

  • 因子2 毛利结构再平衡：分业务看，显示器（59.81% 营收）毛利率约 9–10%，电视（31.91%）受面板涨福更敏感；高端电竞/OLED 子线毛利显著高于传统 LCD 代工。当前单一综合毛利率 9.37% 掩盖了"传统 LCD 代工微利 + 高端线贡献弹性"的结构。原料敏感权重：面板/存储占显示器 BOM 约 60–70%，电视更高。若高端占比由当前约 15% 提至 25%，综合毛利率可升 1–1.5pct。

  • 因子3 库存与采购节奏（timing）：H1 经营现金流 −22.87 亿（同比扩大），反映为保供抢料、囤积高价面板/存储与应收账款占用，存在"高价接货"压力；泰国/墨西哥产能转移期物流与制造成本前置，库存收益为负。验证点：若后续面板价格回落，前期高价库存将转化为毛利负担，当期盈利不可简单线性外推。

  • 因子4 政策 / 市场锚点（原料成本驱动变量）：

  • 市场层：面板控产保价（供给侧自律）→ 成本中枢高位；存储受 AI 需求长期偏紧 → 成本易涨难跌；运费随地缘波动。
  • 政策层：一级能效电视 15% 补贴（托需求但不降成本）；无直接降成本补贴。出口美国关税若升级，泰国/墨西哥产能可部分对冲但转移成本仍在。
  • 情景：① 面板/存储价格 2026H2 高位回落（悲观成本端）→ 毛利修复；② 存储持续紧缺（乐观成本端）→ 毛利继续承压。验证点：65 寸面板报价、DRAM 现货价、公司毛利率逐季变化。

自下而上营收推导（2029E）：显示器稳态 ~330 亿（份额守成 + 高端化提价）、电视 ~200 亿（量增 + 结构）、其他 ~10 亿 ≈ 540 亿。产能约束：以销定产、代工无硬性产能天花板，约束在订单与需求，非产能。

增量三层法（第三步进阶）
- 层1 市场容量 × 份额变量：显示器全球存量稳中有降（销售额 −1.8%），公司份额已 31%（供给侧领先，但逼近天花板，份额二阶导数走平）；电视靠海外份额小幅提升。验证点：逐季显示器市占率、电视出货增速。保守守住 / 中性微升 / 乐观抢份额三档。
- 层2 主业迁移空间（新易盛范式）：能力可迁移至 AI 显示终端、商用交互屏——技术同源（显示制造），新 TAM（AI PC/会议屏）弹性中等；切入卡位靠品牌与制造，客户认证门槛中等；信号验证：AI 终端新品与订单公告。未过验证点 → 仅作中期期权，不计入中性。
- 层3 证伪信号：面板/存储涨价致毛利率破 9%、电视出货转负、高端化占比不升反降、泰国/墨西哥投产延期。

第四步：估值锚定（自下而上，非增速外推）

方法：亏损股用正常化净利润法（估稳态营收 → 保守正常化净利率 → × 远期合理 PE）。不硬套 PE，因 TTM 为负。

总股本：约 45.30 亿股（总市值 98.29 亿 ÷ 2.17 元）。

基准（2026 年底）

2026 全年归母仍小幅亏损（H1 −3.996 亿，H2 靠电视与高端化减亏但难转正），PE 不可用。改用 P/S：2026E 营收 ~530 亿，合理 P/S 0.18–0.20x → 市值 95–106 亿 → 股价 2.10 元。基准空间 = (2.10 / 2.17 − 1) = −3.2%。

第四步进阶：重资产 / 周期股校正（三道闸）

  • 校正1 资产质量折扣：公司非重资产制造但资产负债率极高（总资产 398 亿、净资产仅 16.71 亿，负债率约 95.8%），属高杠杆代工模式，净资产虚薄导致 PB 高达 5.88x（非真破净，但账面权益极低，安全垫薄）。不可凭"低 PB 错觉"判断便宜——此处 PB 高是风险信号而非低估信号。
  • 校正2 周期位置校正：显示行业 2026 处景气上行初期（面板控产保价 + 补贴拉动），但公司盈利仍亏，属"行业回暖但代工环节最后受益"。中性净利未用单年好年景，已用稳态净利率 1.4% 保守化。
  • 校正3 杠杆下行情景：负债率 ~95.8% + 经营现金流 −22.87 亿，若需求下行或汇率恶化（财务费用已因汇兑 +637%），净利可加速转负，悲观情景空间 −51%。该下行使标的不得标"大空间/重点关注"。

亏损股三问（必须回答）
1. 为什么亏：① 面板/存储/PCB 全产业链涨价，弱议价权下成本自己扛（转嫁系数仅 0.3–0.4）；② 泰国/墨西哥产能转移推高短期物流与制造成本；③ 财务费用同比 +637%（汇兑损益）；④ H1 资产减值 1.18 亿。属"周期底部 + 成本端挤压 + 转型阵痛"叠加，非主业崩塌。
2. 靠什么扭亏 · 触发时点：① 面板/存储价格高位回落后毛利修复（2026H2–2027）；② 高端化（电竞/OLED）占比提至 25% 抬升综合毛利率；③ 泰国/墨西哥产能 2027 后释放、规避关税并降本；④ 费用率随规模效应回落。中性触发 2027 年扭亏为盈。
3. 亏得起吗：账面净资产 16.71 亿但负债率 ~95.8%，经营现金流 −22.87 亿为负——生存能力偏弱，依赖授信与股东支持。好在全球市占率第一带来订单与银行授信粘性，倒闭风险低但"倒在黎明前"的财务压力真实存在。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵。现价 2.17 元对应 P/S 0.18x（按 530 亿营收），已隐含温和复苏预期；但净资产仅 16.71 亿、负债率 95.8%、经营现金流为负，财务质量差。

安全边际：中性远期 2.34 元 → 空间 +7.8%（不达重点关注 >50%）；悲观 1.06 元 → 下行 −51%；乐观 4.52 元 → +108%（需高端化与成本回落共振）。

介入条件：① 回落至 1.8 元以下（P/S < 0.15x，安全边际充足）；② 连续两季毛利率回升至 10.5%+ 且经营现金流转正；③ 高端化营收占比破 20%。

最大风险：① 面板/存储持续高价吞噬毛利（首要）；② 汇率波动致财务费用再恶化；③ 高杠杆下现金流断裂；④ 泰国/墨西哥投产延期。

结论：暂不介入（中性远期空间仅 +7.8%，且高杠杆+负经营现金流使下行风险（−51%）远大于上行，赔率不划算；列入观察，等毛利率与现金流转正再评估）。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • A 行业调整剩者红利：面板供给侧自律持续 → 终端价格稳，代工议价改善，剩者（冠捷全球第一）份额与定价权提升。验证点：面板厂产能利用率维持 80–88%、公司份额稳 31%+。证伪：价格战重启。
  • B 政策反转期权：一级能效补贴若加码或扩至显示器，刺激换机。验证点：补贴扩围发文。证伪：补贴退坡。
  • C 市场错杀修复：若面板/存储回落，市场重新定价扭亏，估值由 P/S 切回 PE。验证点：单季转正。
  • D 技术突破/代际跃迁期权：AI 显示终端、OLED/Mini LED 从 0 到 1 放量，重构产品组合。硬验证点：AI 终端大额订单 + 良率达标 + 量产成本优于旧线。未过验证点仅作机会情景，不计入中性。

上调至"重点关注"的条件：高端化占比稳定破 25% 且稳态净利率 ≥2%，同时经营现金流转正、负债率降至 85% 以下。
