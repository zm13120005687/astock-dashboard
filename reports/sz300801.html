第一步：公司是干什么的？

一句话定位：国内水处理药剂龙头（水处理剂年产能 74.85 万吨），以"水处理药剂基本盘 + 氯碱配套 + 新能源材料 / 电子化学品"三线布局，正向"精细化工 + 新材料"双轮驱动转型。

核心产品：有机膦系阻垢剂（HEDP / ATMP）、聚丙烯酸类、杀菌灭藻剂、清洗预膜剂；氯碱（烧碱、液氯、副产氢气）；在研磷酸焦磷酸铁钠（NFPP，钠电正极）、高纯溶剂（G4 级异丙醇 / PGMEA / NMP）、光刻胶用酚醛树脂。

主要客户 / 下游：电力、石化、冶金、造纸、日化、半导体等工业水处理场景。水处理药剂内销 4.86 亿 + 外销 6.22 亿（外销占该业务 56%）；氯碱供下游化工。

境内外占比：水处理药剂外销占比过半（约 56%）；整体出口以美元结算，汇率敏感。

股东背景：实控人程终发（创始团队），民营精细化工企业。

（2）市场端（量价数据）

  • 全球水处理药剂市场为成熟刚需赛道（行业规模数百亿元，增速低个位数，仅作行业背景，非公司增速外推依据）；国内产能偏过剩、价格竞争是 2025 年主业承压主因。
  • 钠电正极 NFPP：2026 年处于产业化早期，市场小但增速高（仅作行业背景）。
  • 公司 2026H1 量价信号：水处理药剂营收 +4.36%、毛利率 +13.35pct，表明在原料大涨背景下公司通过提价 + 降本实现单价与收入同步提升（量稳价升）。
  • 价格趋势：水处理药剂 2026H1 触底回升；氯碱（烧碱）价格仍弱，公司氯碱毛利率 -4.41%。

（3）产业链传导

上游：水处理药剂原料 = 丙烯酸 / 丙烯酸酯、有机磷（磷矿→磷酸）、液氯（自产氯碱副产氢气）；氯碱原料 = 原盐、电。
下游：工业客户（需求强刚需但买方分散、议价中等偏强）。
议价权：水处理药剂 中偏强（规模 74.85 万吨 + 成本传导成功，2026H1 提价落地）；氯碱 弱（毛利率转负，自己扛成本）。

（2）进阶 · 原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（转嫁系数）：水处理药剂 转嫁系数 ≈ 0.7–0.8（2026H1 原料大涨但毛利率 +13pct，说明约 70–80% 成本向客户传导 + 降本吸收）；氯碱 转嫁系数 ≈ 0（毛利率 -4.41%，自行消化）。依据：2026H1 中报"销售单价、营业收入同步提升"。
  • 因子2 毛利结构再平衡：综合毛利率 19.42% 掩盖结构——高毛利水处理（80.8% 收入、24.92%）vs 负毛利氯碱（18.16%、-4.41%）。加权后结构性利润贡献高度集中于水处理；若氯碱持续亏，收入权重向水处理集中，综合毛利率被动抬升。
  • 因子3 库存与采购节奏：2026H1 公司"把握原料低位窗口集中采购 + 氢能改造节约蒸汽 1720 万 + 氢力热量回用年省 600 万"，属真实降本而非低价囤货虚增毛利（无库存收益证据）；长协 / 集采比例提升对冲原料波动。
  • 因子4 政策 / 市场锚点：原盐 / 电价（双控抬成本）、磷矿（出口管制 / 价格）、副产氢回收（政策鼓励氢能、降本）。验证点：原料价格走势、公司涨价 / 集采公告；证伪：原料单边大涨且传导失败致水处理毛利率破 20%。

（3）进阶 · 份额变量与主业迁移空间三层法

  • 层1 现有业务（市场容量 × 份额变量）：水处理药剂供给侧 74.85 万吨（国内前列），需求刚性；份额变量用 5 锚点——①供给侧产能（头部集中）、②客户份额（外销 56% 绑定海外经销商）、③技术代际（规模化 / 智能化领先）、④成本曲线（左移，降本胜出）、⑤份额加速度（行业出清期份额提升）。三档：保守守住 / 中性小幅提升 / 乐观抢份额。验证点：中小产能退出公告、公司出货量；证伪：价格战致毛利率破 20%。
  • 层2 扩展业务（主业迁移·新易盛范式）：从水处理 → 新能源材料（钠电 NFPP）/ 电子化学品（光刻胶树脂）。能力可迁移（精细化工合成同源）、新 TAM 大（钠电 / 半导体材料），但处于中试 / 试生产，未过验证点 → 中期期权，不计入中性净利。验证点：NFPP 客户定点订单、电子化学品营收占比跳升 >10%。
  • 层3 风险折扣（证伪）：水处理价格战复发、NFPP 无正式订单、电子化学品营收占比未升 → 下调 / 剔除该增量。

（4）进阶 · 重资产 / 周期股估值三道闸

  • 校正1 资产质量折扣：净资产 26.7 亿，PB 1.78x，未破净；ROE 5.42% 回升，资产质量健康（无专用资产清算折价、无隐含负债）。
  • 校正2 周期位置校正：水处理 2025 为价格战底部，2026H1 已回升（毛利率 +13pct），当前处复苏中段非顶部；氯碱处周期底部（毛利率负）。中性净利用复苏后稳态，不过度乐观、不按 2025 谷底外推。
  • 校正3 杠杆下行情景：资产负债率 15.1% 极低、经营现金流 1.74 亿为正，无财务杠杆下行风险；利率 / 需求下行负面情景下空间最小约 -17%（悲观），不构成大风险。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低（2026E PE 18.3x，水处理龙头复苏 + 新材料期权）。

安全边际：中性远期 +19.8%；悲观 -16.9%（PB 1.78x 有底）；上行期权（新材料）提供 +93.8% 乐观弹性。

介入条件：
1. ≤ 19 元（2026E PE < 16x）具安全边际，可建仓；
2. 上调至"重点关注"条件：NFPP / 电子化学品获正式大额客户定点订单、新材料营收占比跳升至 >10%、水处理份额在出清期明显提升。

最大风险（最可能破坏逻辑）：
1. 水处理价格战复发，毛利率回落破 20%；
2. 氯碱持续亏损拖累综合盈利；
3. NFPP / 电子化学品产业化不及预期（中试 ≠ 量产）；
4. 磷矿 / 丙烯酸等原料大涨且传导失败。

第五步进阶 · 上行想象力情景（四类，对冲系统性保守偏置）

  • 类型A 行业调整剩者红利：水处理药剂产能过剩出清后头部集中，公司 74.85 万吨产能 + 成本优势份额提升。验证点：中小产能退出公告、公司出货量份额；证伪：价格战致毛利率破 20%。
  • 类型B 政策反转期权：石化化工老旧装置更新（2026—2029）+ 储能 / 电子化学品国产替代政策加码，驱动水处理配套与 NFPP / 光刻胶树脂需求。验证点：政策发文、招标落地；未过验证点仅作机会情景。
  • 类型C 市场错杀修复：2025 价格战致估值低位，2026H1 已修复部分；若市场系统性回调错杀，PB 1.78x 有底。验证点：毛利率稳守、估值分位。
  • 类型D 技术突破 / 代际跃迁：NFPP 量产成本优于 LFP、电子化学品（光刻胶酚醛树脂）客户放量，打开第二曲线。硬验证点：中试良率达标 + 客户定点 + 量产成本优于旧路线；三者缺一只作机会情景，不计入中性。

上调至"重点关注"条件：NFPP / 电子化学品获正式大额定点订单、新材料营收占比 >10%，中性远期空间突破 +50%。

结论：纳入观察（现价已反映 2026 修复，2029 中性 +19.8% 未达重点关注 >50% 门槛；等回调至 19 元以下或新材料验证后上调）。
