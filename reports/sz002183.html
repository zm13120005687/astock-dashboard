（3）产业链传导

上游：国际原厂（美光、东芝、英特尔等），分销模式赚取价差与服务费；下游：科技客户、智算中心、政企。

议价权：分销环节中偏弱（赚流水价差，毛利率仅 5.65%）；科技 / 算力集成环节中（资质壁垒，英特尔聚合商、卓优云智中标中科院项目），毛利结构优于传统分销。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：分销业务成本即采购价，传导系数近 1（原厂定价，公司转嫁客户），但毛利绝对额薄（5.65% 综合毛利率）；科技 / 算力集成毛利率较高但项目制波动大。
  • 因子2 毛利结构再平衡：传统分销（92% 营收）毛利约 5% 以下；科技赛道（半导体 + 算力，合计约 6% 营收）毛利 8%–12%；政企采购（4%）约 6%–8%。结构再平衡方向：提高科技 / 政企占比（2026H1 科技订单占比已超 93%），整体净利率由 0.1% 向 1%+ 修复。验证点：科技 / 政企营收占比、综合毛利率。
  • 因子3 库存与采购节奏：分销长协 + 套保为主，半导体存储价格周期（涨价周期利好库存收益），但 2025 年业务调整致营收大降、库存去化。
  • 因子4 政策 / 市场锚点：① 市场层——存储芯片价格波动（美光 / 铠侠供给端）；② 政策层——国产替代（信创 CPU）、普惠算力（智算中心投资）。验证点：存储现货价、智算中心招标量。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：分销行业高度分散，公司属第一梯队，份额稳定。
  • 需求侧：科技 / 政企客户粘性高（资质 + 资本合作"链上被投"）。
  • 技术代际：算力集成 / 信创适配属中高壁垒。
  • 成本曲线：国资信用 + 规模采购，资金成本优势。
  • 份额加速度：科技赛道占比快速提升（2026Q1 科技订单占比超 93%）。
    → 三档：保守（传统分销企稳）/ 中性（科技占比升至 15%+）/ 乐观（科技占比 25%+ 且毛利显著修复）。
  • 层2 扩展业务：主业迁移空间：由"流通分销"向"科技产业组织者 + 信创生态"迁移（新 TAM 远高于传统分销），能力可迁移（供应链整合同源）、卡位早、认证门槛高（英特尔 / 原厂资质）。属中期期权，未过验证点（科技净利规模化公告）不计入中性。
  • 层3 证伪信号：科技订单无持续公告、传统分销继续失血、资产处置收益不可持续、毛利率未修复。

第四步：估值锚定（自下而上，盈利恢复股）

方法说明：2026H1 已扭亏（+2746 万），但净利极薄（净利率 0.11%），TTM 仍负（2025 全年 −3.19 亿为业务调整 + 减值一次性）。按盈利恢复股处理，采用正常化净利润（剔除 2025 一次性损失，回归 2022–2024 水平 1.0–2.6 亿）自下而上测算。
总股本：约 25.97 亿股。当前 PB 1.17（净资产 90.27 亿），净资产为估值锚。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣：公司非重资产，净资产 90.27 亿主要为应收账款 + 存货 + 长期股权投资（联芸科技等上市股权）。PB 1.17 接近净资产，下行有净资产托底，但资产多为营运资本，重估空间有限。
  • 校正2 周期位置校正：供应链行业处弱周期（社零 +1.3%），盈利处"调整修复"位置；中性净利未用 2025 亏损年、未用 2022 高景气年，采用修复常态。
  • 校正3 杠杆下行情景：资产负债率约 83%（供应链高杠杆经营），若利率上行 / 需求下行，净利与现金流承压；乐观情景仍仅 −7.6%，说明向上缺乏盈利驱动、向下有净资产托底但弹性弱。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（相对盈利）。现价 4.08 元对应中性目标价 2.16 元（−47%），PE 对微利无意义，估值靠净资产（PB 1.17）支撑。

安全边际：中性远期 −47.1%，悲观 −79.2%；但 PB 1.17 提供下行锚——跌破净资产（3.8 元）即进入账面价值区间，下行有限。乐观 −7.6%（即便转型兑现也仅回到当前价附近）。

介入条件：① 跌破 3.8 元（PB<1，破净）方入价值区间；② 加仓信号：科技 / 政企营收占比突破 20%、综合毛利率稳定站上 6%、经营现金流转正且持续。

最大风险：① 营收持续萎缩（2026H1 −30.9%，传统业务出清阵痛）；② 科技转型进度慢于预期；③ 高负债（83%）利率 / 流动性风险；④ 资产处置收益一次性、不可持续。

结论：暂不介入（盈利薄、估值靠净资产托底，向上缺盈利驱动；仅当跌破净资产 3.8 元进入价值区间，或科技转型净利规模化兑现，再重新评估）。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • A 行业调整剩者红利：供应链出清后头部集中，公司国资背景 + 规模优势份额提升。验证点：行业集中度、公司分销市占率公告。
  • B 政策反转期权：全国统一大市场 + 普惠算力 + 深圳国资"千亿市值培育"推动科技转型。验证点：转型进度公告、算力订单落地。
  • C 市场错杀修复：若科技净利规模化、PB 回归 1.3x+（对应 4.5 元），估值修复。验证点：净资产收益率回升、PB 走势。
  • D 技术突破期权：参股联芸科技（存储控制器芯片，已上市）+ 星火半导体，半导体国产替代从 0 到 1 放量；硬验证点 = 自研芯片量产 + 大客户定点。缺一则仅作机会情景。
