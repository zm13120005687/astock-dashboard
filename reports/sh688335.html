上游：钢材、机电设备、催化剂——受钢价/化工原料波动影响；公司议价权中等，规模化采购对冲。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：环保装备为项目制招标，成本转嫁率约 0.5（钢/机电涨价部分自担）。验证点：毛利率稳定 25%+；证伪信号：毛利率跌破 22%。

  • 因子2 毛利结构再平衡：高端装备（~26%）vs 运维备件（高毛利、持续性）vs 废气（承压）。运维占比提升（+60.92%）改善结构。原料敏感权重：装备制造端对钢敏感，运维端不敏感。验证点：分业务毛利率；证伪信号：综合毛利跌破 22% 且运维占比未升。

  • 因子3 库存与采购节奏（timing）：项目制交付，无囤货收益；研发投入转固带来折旧增加是 H1 亏损因素（一次性 timing，非持续）。

  • 因子4 政策/市场锚点：① 市场层——钢价；② 政策层——环保立法（扩需求、稳价）、绿色燃料补贴/认证（ISCC，拓需求）。情景：立法执行→市政需求稳；钢价上行→毛利承压。验证点：钢价、绿色燃料补贴政策；证伪信号：钢价上行 + 地方财政支付恶化。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：污泥处理装备集中度中等，复洁技术领先（国家科技进步二等奖）；
  • 需求侧：市政项目受财政分化，公司审慎筛选项目保毛利；
  • 技术代际：污泥全链条低碳技术国际先进，份额溢价；
  • 成本曲线：浙江智造产能爬坡降本；

  • 份额加速度：海外 +145% 显示份额外扩加速。
    → 三档：保守（份额维稳）、中性（海外+运维扩份额）、乐观（热泵+工业场景放量）。验证点：海外收入占比、运维收入增速。

  • 层2 扩展业务：主业迁移空间：从"治污装备"迁移到"绿色燃料（绿色甲醇/航油）"新池塘，新 TAM（航运燃料、化工）弹性极大；技术同源（有机固废资源化），但产业化认证门槛高（ISCC）。未过验证点（绿色甲醇规模化订单前）仅作中期期权，不计入中性净利。

  • 层3 证伪信号：市政订单持续延期、毛利率跌破 22%、海外无持续订单、绿色甲醇中试后无量产。

  1. 为什么亏：2026H1 归母 −0.05 亿（由盈转亏），主因"项目交付/验收进度延迟 + 研发投入转固折旧增加 + 研发费用同比 +132.85%"，Q2 已单季扭亏（+0.10 亿，剔除研发影响因素盈利优于同期）。属"阶段性研发投入 + 验收节奏型"亏损，非主业崩坏。
  2. 靠什么扭亏，触发时点：扭亏靠"装备交付恢复 + 运维备件持续化（H1 +60.92%）+ 海外高增（H1 +145%）+ 热泵新场景"。若 H2 项目确认恢复，2026 全年有望微利，明确扭亏时点在 2026H2–2027；绿色甲醇量产为 2028–2029 中长期期权。

复洁非重资产周期股，但需注意：① 资产质量：净资产 11.13 亿、PB 2.64x 合理；② 杠杆：资产负债率 19.89%（低），现金 2.34 亿、无有息借款压力小，生存无虞；③ 期权纪律：绿色甲醇中试成功但未量产，仅计入乐观情景，不计入中性锚（中性已保守剔除）。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估（按保守正常化）。现价 18.26 元隐含绿色燃料量产的全部乐观预期，中性目标价仅 8.11 元。

安全边际：中性远期空间 −55.6%，悲观 −83.4%；仅乐观情景（+24.3%）覆盖现价，需绿色甲醇量产 + 海外高增。下行保护来自低负债（19.89%）+ 现金 2.34 亿（亏得起）。

介入条件：① 观察绿色甲醇产业化示范订单落地（硬验证点）；② 稳态营收可见路径至 6–8 亿；③ 现价回落至 8.5 元以下（接近中性目标价）才具安全边际。

最大风险：
1. 绿色燃料落空：中试成功≠量产盈利，成本曲线若打不过旧路线则期权归零（首要风险）；
2. 市政订单延期/回款：地方财政分化，H1 已现验收延期致亏；
3. 低价竞争：行业同质化加剧，毛利率承压；
4. 研发投入拖累：研发费用 +132%，短期压制利润。

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：环保立法（生态环境法典）淘汰低效产能，技术领先者（复洁）份额提升——验证点：行业集中度、公司份额。
  • 类型B 政策反转期权：不适用（政策已强力利好）。
  • 类型C 市场错杀修复：若因短期亏损被错杀（实际 Q2 已扭亏、运维高增），修复弹性——验证点：全年扭亏公告。
  • 类型D 技术突破/代际跃迁期权（核心）：绿色甲醇千吨级中试纯度 99.99%、ISCC 双认证、科技成果评价"国际领先"——硬验证点：量产装置跑通且良率达标、客户定点/大额订单、量产成本优于旧路线（绿醇 vs 化石甲醇）。三者缺一仅作机会情景。当前中试达标但缺"客户定点大额订单 + 量产成本验证"，故仅作机会/乐观情景。

上调至"重点关注"的条件：绿色甲醇获客户定点大额订单且量产成本曲线验证优于旧路线 + 稳态营收可见至 8 亿，届时重做正常化（乐观情景上调为中性）。

结论：暂不介入

理由：2026H1 真实亏损，中性保守正常化估值 8.11 元较现价 −55.6%；当前价格已大幅透支绿色燃料期权（中试成功但未量产）。公司"亏得起"（低负债+现金充裕），但估值贵，等绿色甲醇硬验证点兑现与回调。
