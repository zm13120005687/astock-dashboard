天府文旅（000558）五步法分析报告

分析日期：2026-09-25 ｜ 现价 3.57 元（2026-09-24 收盘）｜ 总市值 46.01 亿 ｜ PE(TTM) −93.39x（亏损）｜ PB 4.49x ｜ 总股本 约 12.88 亿股
行业：文化旅游 + 影视 + 存量资产运营（原莱茵体育转型）｜ 板块：深市主板
重要结论前置：2026H1 真实归母净利 −2106.6 万（真亏，由盈转亏），营收 1.41 亿同比 −31.11%。本报告按亏损股完整五步法 + 正常化净利润法 + 三问；房地产/重资产属性须做第四步周期位置校正 + 杠杆下行情景。

第一步：公司是干什么的？

一句话定位：由体育（莱茵体育）转型而来的文旅运营平台，业务涵盖文化旅游、影视、会务会展、存量资产租赁与体育，重心在成都及西南区域文旅资源运营，市值中含较强"重组/资产注入"期权预期。

（3）产业链传导

上游：影视内容制作成本、景区/物业运营成本、人力。影视项目成本前置、收入后置，波动大。

下游：居民文旅消费意愿（顺周期），政府会展预算。行业高景气但公司未受益，反映自身项目获取/运营能力短板。

议价权：弱。文旅/影视高度竞争，C 端定价权弱；存量资产租赁受商业地产供需影响，毛利率仅 0.21%。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数 ≈ 0.2）：文旅/影视为服务与内容，成本（制作、运营、租金）难向 C 端转嫁，系数为低；价格战普遍。
  • 因子2 毛利结构再平衡：分业务毛利率分化极大（文旅 34.47% vs 影视 11.54% vs 租赁 0.21%）。H1 综合毛利率 19.63%（−14.51pct）是结构恶化的结果（高毛利文旅占比降、影视成本集中）。估值须分业务，禁用单一综合毛利率。
  • 因子3 库存与采购节奏：影视存货（在制内容）存在减值风险；文旅项目投入期成本前置，确认节奏决定季度波动（Q2 毛利率 −49.23% 即影视成本集中确认）。
  • 因子4 政策/市场锚点：① 消费券/补贴（暑期发放超 4.5 亿、各地促消费）利好需求；② 商业地产供需（存量资产租赁）为成本/收入双驱动变量。情景：若文旅消费券拉动需求 → 验证点（节假日客流/收入）；证伪：行业高景气但公司营收续降。

合计判断：现有业务年化营收约 2.8 亿（H1 1.41 亿 × 2，但 H1 含项目集中，保守取 2.5–3.0 亿）。无明确在手大单/在建产能支撑增长，增量主要靠资产整合期权而非经营性扩张。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：区域文旅运营商，份额小。
  • 客户份额：C 端分散，无核心客户粘性。
  • 技术代际：无显著代际优势。
  • 成本曲线：规模小，无成本优势。
  • 二阶导数：主业处萎缩（营收 −31%）。→ 中性：份额持平或下滑；验证点：下季度营收增速回正。
  • 层2 扩展业务：主业迁移空间：从体育转型文旅已发生，下一步看国资文旅资产注入（新 TAM 大）。但未过验证点（无正式公告），仅作中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：营收持续下滑、影视减值扩大、资产注入无实质进展。

第四步：估值锚定（自下而上，非增速外推）

亏损股估值（正常化净利润法）：估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价。注意当前 PB 4.49x（市值 46 亿 vs 净资产 10.25 亿）主要由重组期权支撑，非经营基本面。

总股本：约 12.88 亿股；净资产 10.25 亿；总资产 27.27 亿，资产负债率约 62.4%（高）。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：公司不破净（PB 4.49x），但高 PB 源于期权而非资产质量——净资产 10.25 亿中存量资产（商业/物业）受地产周期压制，存在减值风险；非"金融资产未重估型真安全边际"。高 PB 在此是风险信号而非低估。
  • 校正2 周期位置校正：文旅消费处政策友好上行期，但公司自身处"转型阵痛 + 主业萎缩"，与行业背离。中性净利已用保守净利率，未用行业 Beta 外推。
  • 校正3 杠杆下行情景（高负债必附）：资产负债率约 62.4%，财务费用 H1 738 万。若文旅需求下行 / 融资收紧 / 资产减值，净利进一步转负、空间可转负——悲观情景 −44.3% 已体现。此情形不得标大空间，至多"暂不介入"。

亏损股三问

  1. 为什么亏：营收 −31.11%（主业萎缩）+ 综合毛利率 −14.51pct（影视成本集中、高毛利文旅占比降）+ 财务费用 738 万 + 信用减值 752 万，属"主业持续弱化型亏损"。
  2. 靠什么扭亏，触发时点：① 自身文旅运营能力提升使营收回正（2027 观察）；② 成都国资文旅资产注入/重组（核心期权，时点不确定）。中性预计 2029 年勉强正常化至 1400 万净利。
  3. 亏得起吗：净资产 10.25 亿尚可，但高负债率 62% + 经营现金流转弱（H1 经营现金流 −6179 万），若持续亏损 + 资产减值，安全垫将被侵蚀。亏得起但缓冲有限。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（期权定价）。现价 3.57 元对应 PB 4.49x、中性目标价 2.72 元（−23.8%），当前价主要由重组期权支撑。

安全边际：中性 2.72 元（−23.8%）；悲观 1.99 元（−44.3%）；乐观（资产注入）3.49 元（−2.2%）。上行空间极小、下行空间大，赔率不利。

介入条件：① 股价回落至 2.50 元以下（PB 约 3.1x，期权折价后）；② 或成都国资文旅资产注入正式公告且规模超预期。

最大风险：① 重组/资产注入落空（当前高 PB 无支撑）；② 主业持续萎缩 + 资产减值；③ 高负债率下融资/利率下行情景；④ 影视项目减值。

结论：暂不介入（估值已高/空间有限/不确定性大——当前价由未验证期权支撑，基本面难支撑）。

上调至"纳入观察/重点关注"的条件：资产注入正式公告落地且增厚净利显著，或连续两季营收正增长且扭亏为盈。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：不适用（非出清行业，公司为弱势方）。
  • B 政策反转期权：文旅消费补贴加码带动需求。验证点：公司营收回正；不计入中性。
  • C 市场错杀修复：不适用（当前非错杀，是期权溢价）。
  • D 技术突破/代际跃迁期权：成都国资文旅资产证券化/重磅IP注入，重构公司。硬验证点：正式重组公告 + 注入资产评估 + 业绩承诺；缺一则仅作机会情景。这是公司唯一的大上行来源，但未过验证点不计入中性锚。
