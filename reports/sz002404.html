（3）产业链传导

上游：蚕茧、生丝、棉花、涤纶（油价驱动）。蚕茧收烘环节自控股价，但外购丝/化纤受市场价影响。
下游：欧美品牌商（强势、压价）、国内零售。柬埔寨生产基地承接增量订单。
议价权：中等偏弱——普通丝绸服装缺乏核心议价（金蚕网数据：普通生丝/绸缎出口利润微薄）；设计型外贸 + 自有品牌"金三塔"提升部分溢价；柬埔寨产能增强接单弹性。

【第二步进阶：原料成本 → 毛利结构四因子】

  • 因子① 成本传导弹性（转嫁系数）：服装业务对美客户多为品牌商，汇率与关税成本转嫁系数 ≈ 0.3–0.4（2026H1 汇兑损失使财务费从 −840 万升至 +3817 万，毛利改善被吞噬）；"设计型外贸"+金三塔品牌转嫁系数略高 ≈ 0.5。丝类/五金转嫁系数低 ≈ 0.3。加权转嫁系数 ≈ 0.4 → 上游（汇率/原料）涨价 ×(1−0.4)=实际承压 60%。
  • 因子② 毛利结构再平衡（分业务线）：服装（毛利率 20.87%，占比 58%）+ 丝类（毛利率约 10–12%，占比 25%）+ 五金（低毛利，占比 6% 且下滑）+ 供应链金融（高毛利、占比 11%）。结构正向迁移：高毛利服装占比提升（58%）+ 金蚕网服务（高毛利）占比提升 → 加权毛利从 12.28%(2025H1) 升至 13.38%。禁单一综合毛利率：五金占比下降掩盖结构优化。
  • 因子③ 库存与采购节奏（timing）：蚕茧收烘季低价囤货 → 当期丝类毛利受益；但 2026H1 存货未见异常收益，利润承压主因汇兑（账面）非库存。柬埔寨基地爬坡期成本略高，远期随产能释放降本。
  • 因子④ 政策/市场锚点：① 市场层——生丝/油价周期；② 政策层——人民币升值（央行汇率政策）直接吃利润；③ 政策层——美国 301 关税（高压制，订单转移）；④ 政策层——中瑞自贸/RECP 多元化机会。情景：若人民币回落至 7.1+，汇兑损失转收益（验证点：美元中间价）；若对美关税进一步缓和，订单回流（验证点：关税公告）。

【第三步进阶：份额变量与主业迁移三层法】

  • 层1 现有业务：市场容量 × 份额变量：① 供给侧——中国丝绸全球产量第一但份额受印/越关税优势挤压；② 客户侧——欧美中高端品牌认证 + 设计型外贸粘性；③ 技术代际——设计/品牌溢价领先普通代工；④ 成本曲线——柬埔寨基地左移；⑤ 份额加速度——出口额增速 13.65% 高于行业均值，份额小幅提升。三档：保守守住（出口 +8%）、中性小幅提升（+12%）、乐观抢份额（+18%，关税缓和+柬埔寨满产）。验证点：下季度出口额、柬埔寨出货。
  • 层2 扩展业务：主业迁移空间：从"代工"迁移至"品牌 + 平台"（金三塔 + 金蚕网），新 TAM（国潮/产业互联网）弹性大；能力可迁移（产业链一体化）；切入时点早（品牌百年积淀）；认证门槛低（消费品牌）；信号验证=金三塔营收稳健增长。→ 中期期权，部分已兑现（金蚕网已贡献），但品牌盈利转化未完全验证，谨慎计入中性。
  • 层3 风险折扣（证伪信号）：对美关税加码、人民币继续升值、柬埔寨爬坡不及预期、金三塔费用拖累扩大。命中则下调。

【第四步进阶：轻资产/弱周期校正】 嘉欣丝绸非重资产（PB 1.74x 未破净），纺织为弱周期消费出口；当前处于"汇率逆风 + 关税高压"底部，非周期顶部。负债率 41.76%（合理），短期借款 7.80 亿需关注结构。期权纪律：金三塔品牌盈利转化、关税全面缓和为期权，不计入中性净利上限。

交叉校验：现价 5.84 元对应 2026E PE ≈ 17x、TTM PE ≈ 19x，处于合理偏低；2029 中性 8.93 元对应 +52.9%，唯一风险是汇率/关税持续恶化。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。现价 5.84 元 ≈ 2026E PE 17x、PB 1.74x，纺织出口中估值不贵；2029 中性 +52.9% 达重点关注门槛（需汇率配合）。

安全边际：
- 中性远期 8.93 元 → +52.9%（达重点关注 >50% 门槛，但依赖汇率/关税改善）
- 悲观 4.64 元 → −20.5%，下行有服装基本盘 + 净资产托底（PB 1.74x）
- 乐观 12.86 元 → +120.2%（关税缓和 + 品牌转化）
- 下行保护：PB 1.74x、经营现金流 +2.25 亿、国资背景

介入条件：
1. 5.5 元以下更优（2026E PE < 16x），当前 5.84 元已可分批
2. 加仓信号：① 人民币回落至 7.0+（汇兑收益）；② 对美关税实质性互降公告；③ 金三塔品牌净利率转正且营收跳升
3. 观察指标：逐季汇兑损益、出口额增速、服装毛利率是否稳于 20%+

最大风险：① 人民币持续升值（行业净利率仅 4%，升值 4% 即吃掉全年利润）；② 美国 301 关税加码或印/越抢单；③ 金三塔高费用投入长期不兑现；④ 欧美消费疲软。

结论：纳入观察（中性空间 +52.9% 达重点关注门槛，但汇率/关税两大变量未明确反转，需跟踪验证）

嘉欣丝绸是全产业链丝绸龙头，服装主业毛利改善 + 柬埔寨爬坡 + 金蚕网平台构成确定增量，中性远期 +52.9% 具备重点关注潜质。但汇率与关税为外生硬约束，当前宜"纳入观察、回调加仓"，待人民币贬值或关税缓和信号确认后上调重点关注。

【第五步进阶：上行想象力情景（四类）】
- A 行业调整剩者红利：纺织出口中小企业（无柬埔寨产能/无设计能力）在汇率+关税双重挤压下出清，嘉欣凭借全产业链+海外产能份额提升（验证点：同行退出、公司出口份额跳升；证伪：份额连降）。
- B 政策反转期权：中美元首会晤设关税"天花板"后若进一步互降 300 亿美元商品关税、或人民币因外部冲击贬值 → 利润弹性极大（硬验证点：关税公告/美元中间价 7.1+；证伪：关税加码、人民币续升）。
- C 市场错杀修复：2026H1 因汇兑杀利润（净利 −9.59% 但经营毛利改善），若 H2 汇兑转正估值修复（验证点：季报汇兑转正；证伪：继续大额汇兑损失）。
- D 技术突破/代际跃迁期权：金三塔品牌从"代工"跃迁至"国潮高端品牌"、金蚕网从交易平台升级为产业数据/供应链金融基础设施，新 TAM 远超代工。三要素：政策（国潮/新中式）+ 趋势（品牌化）+ 落地（百年庆典营销）。硬验证点=品牌净利率转正+平台服务费高增，缺一则仅作机会情景。→ 上调重点关注条件：人民币贬值/关税缓和落地 + 金三塔盈利验证。
