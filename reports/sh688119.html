（3）产业链传导

上游：铝矾土、刚玉、碳化硅、电熔镁砂、金属硅等耐火原料。2026H1 铝矾土小幅下降，刚玉/碳化硅/金属硅/电熔镁砂相对稳定；原料价格受矿山开采、环保政策影响波动上涨（长期趋势）。

下游：钢铁（60–70%）、建材、有色、石化。下游高温工业周期下行直接压制耐材量与价；客户降本意愿强，议价权向客户倾斜。

议价权：对下游钢企弱（客户集中、强势、降本压价）；对上游原料中等（部分自产/长协但受环保政策抬价）。整体在周期下行期盈利受压。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：耐材对钢企传导率≈0.2（客户强势压价，成本难转嫁）。2026H1 毛利率仅 16.35% 印证低传导。依据：下游降本意愿强、同质化竞争。
  • 因子2 毛利结构再平衡：耐火材料（67.85%）毛利低且承压；工程与技术服务（19.83%）毛利较高但占比有限；高端特种（军工/航空航天）毛利高但占比小。综合 16.35% 反映低端主导、结构未优化。
  • 因子3 库存与采购节奏：耐火原料（铝矾土等）有库存收益/损失 timing；2026H1 铝矾土降价为利好，但被售价下降抵消。
  • 因子4 政策/市场锚点（成本驱动变量）：① 市场层——铝矾土/电熔镁砂供需与价格；② 政策层——环保/矿山开采政策抬升原料成本（长期）、战略新兴（军工/航空航天）托底高端需求。情景：原料涨 + 售价跌→毛利破 12%；验证点：铝矾土价格、公司毛利率季度。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：耐火材料行业分散，政策鼓励集中度提升，中钢洛耐为央企龙头有望提升份额。
  • 客户份额：绑定大型钢企，但钢企降本压价削弱粘性。
  • 技术代际差：先进耐火材料全国重点实验室，高端产品技术领先。
  • 成本曲线：规模 + 技术，但刚性成本（人工）压力大。
  • 份额加速度：行业下行期小厂出清，龙头份额或逆势提升（但短期营收仍降）。

  • 三档：保守（钢铁继续下行，营收 18 亿）/中性（企稳 22 亿）/乐观（复苏+份额 26 亿）。验证点：粗钢产量、公司营收、行业集中度。

  • 层2 扩展业务：主业迁移空间：从"钢铁耐材"→"军工/航空航天/节能环保高温材料"新池塘。能力可迁移（同源高温材料），新 TAM（军工/航空航天）高壁垒高毛利。切入卡位早（已有布局），认证门槛高（军工准入）。中期期权，不计入中性。

  • 层3 风险折扣（证伪信号）：粗钢产量持续负增、毛利率破 12%、钢铁客户进一步压价。命中则下调。

第四步：估值锚定（自下而上，非增速外推）

方法说明：中钢洛耐 2026H1 亏损、且为重资产/周期股，先按规则做三道校正，再做正常化净利润估值。亏损期基准用 PB/PS。

总股本：11.25 亿股（确认）

三道校正（重资产/周期股必做）

  • 校正1 资产质量折扣（破净须说明原因）：当前 PB 约 1.64x（接近破净），归母净资产 27.29 亿 vs 市值 42.86 亿，仍溢价。破净风险源于：① 行业周期底部（钢铁减量、利润压缩）；② 资产专用性强（耐材产线不能转产，清算价值 << 账面）；③ 隐含减值风险（存货跌价、应收）。非金融资产未重估型破净（无大额股权类金融资产兜底），故接近破净是公允定价信号，非低估。若景气回升 ROE 恢复则 PB 合理。
  • 校正2 周期位置校正（中性净利用周期归一化）：钢铁处长周期减量调结构阶段，耐火材料需求减弱——当前周期位置：底部/下行。中性净利禁止用单年好年景或拐点年化，采用周期归一化：参考正常年份（2024/2025 盈利期）净利中枢约 1.0–1.5 亿，取周期中值 1.5 亿 作为中性正常化净利（而非用 2026H1 亏损年化或 2025H1 盈利年化）。
  • 校正3 杠杆下行情景（高负债必附负面情景）：负债率 42.75%（中等），经营杠杆 + 财务杠杆双高（重资产、刚性人工）。负面情景：钢铁进一步下行 + 售价跌 → 净利转负扩大（2026H1 已 -0.86 亿）。该负面情景使空间转负，故不得标"大空间/重点关注"。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（周期底部却仍 1.64x PB）。作为周期/重资产亏损股，当前价格未反映周期下行与盈利压力，仅在乐观复苏情景下合理。

安全边际：中性远期 2.3 元 → 空间 −39.6%；悲观 3.2 元（−16%）；乐观 4.8 元（+26%）。当前价格无安全边际，且破净风险悬顶。

介入条件：
1. 不追高。需回落至 3.0 元以下（接近破净 PB 1.2x 以下） 才具安全边际，届时周期底部价值凸显。
2. 加仓信号（周期反转）：① 粗钢产量同比转正；② 公司毛利率回升至 20%+；③ 单季扭亏；④ 行业兼并重组落地（份额提升）。
3. 观测指标：月度粗钢产量、铝矾土/镁砂价格、公司毛利率、负债率。

最大风险：① 钢铁长周期减量致需求持续弱；② 破净（PB<1）触发估值重估；③ 同质化竞争 + 客户压价致毛利破 12%；④ 刚性人工成本 + 减值（存货/应收）。

亏损股三问：
1. 为什么亏：钢铁需求弱（粗钢 -3%）+ 客户降本压价 + 同质化竞争 + 计提辞退福利 + 部分工程延期，属"周期下行 + 竞争 + 一次性费用"型亏损。
2. 靠什么扭亏、时点：下游钢铁触底回升 + 高端新材（军工/航空航天）放量 + 降本增效，使周期中值净利恢复至 1.5 亿+。时点取决于钢铁周期，预计 2027–2028 随稳增长/产能出清逐步修复。
3. 亏得起吗：净资产 27.29 亿、负债率 42.75%、央企背景融资能力强，亏得起，无退市风险。

结论：暂不介入（周期底部但估值未充分反映下行、破净风险悬顶；需等钢铁周期反转信号或价格回落至破净附近再重估；若跌破净资产且钢铁复苏确认则升级为"纳入观察"）。
