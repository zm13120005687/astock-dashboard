（3）产业链传导

上游：钢材、发动机、液压件、电池。钢材价低位利好成本；发动机/液压件部分进口（议价权中）。电池成本随碳酸锂下行改善电动化毛利。

下游：基建、矿山、地产（弱）、农业。矿山与海外需求强，地产链弱。

议价权判断：对上游 中（规模采购+国产替代）；对下游 中高（龙头品牌+服务网络，海外定价优于国内）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性
  • 国内转嫁系数 ≈ 0.6：竞争烈，钢材降价红利部分让利客户；海外转嫁系数 ≈ 0.85（品牌+稀缺性，海外毛利率高于国内）。
  • 验证点：钢材指数 vs 公司毛利率；证伪：钢价跌而毛利率未升 = 传导失败（价格战）。
  • 因子2 毛利结构再平衡
  • 土石方占 65%（毛利率受钢价+结构影响），其他工程机械 28%，预应力 6%，租赁 1%。
  • 原料敏感权重：钢材/发动机占整机成本 50–60%，集中于土石方+其他工程机械（合计 93%）。电动化产品电池成本占比升，但碳酸锂下行对冲。
  • 禁单一综合毛利率：20.69% 综合毛利率掩盖「海外高毛利 + 国内承压」结构；海外占比 50.6% 且升，结构向高毛利迁移。
  • 因子3 库存与采购节奏
  • 钢材低价囤货 → 当期毛利受益；长协/套保部分对冲。汇兑：H1 汇兑损失 3.10 亿（ timing 冲击），公司通过远期锁汇降低，属一次性非经营波动。
  • 验证点：钢材库存周期 + 套保损益；证伪：钢价涨而毛利未承压 = 套保有效。
  • 因子4 政策 / 市场锚点
  • 市场层：钢材、碳酸锂、汇率。
  • 政策层：设备更新国债、禁用区淘汰、新能源补贴、矿山节能补贴。
  • 情景：国债+禁用区驱动更新潮 → 内销放量（乐观）；地产链拖累+汇率不利 → 承压（悲观）。验证点：国债下达公告、地方补贴细则、钢价/锂价。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：全球工程机械万亿级，柳工产能利用率提升，土方市占率 +1pct+。
  • 需求侧：海外大客户业务 +34%，占比 +3pct；经销商近 400 家覆盖升。
  • 技术代际：电动化领先（装载机全球销量 +95%），代际优势。
  • 成本曲线：规模+国产替代→左移，降价时以价换量扩份额。
  • 份额二阶导：海外渗透加速期。三档：保守守住 / 中性份额 +1~2pct / 乐观矿山+电动化抢份额。
  • 层2 扩展业务：主业迁移空间
  • 矿山机械：从土石方→矿山成套（铲装运一体化+智慧矿山 4.0），能力可迁移（同源工程机械），新 TAM 大，客户认证中（已批量交付），信号验证：收入盈利双位数增长 → 部分过验证点，计入中性。
  • 电动化：从燃油→电动（含光储充），技术同源，政策+成本交叉，已批量出口 → 计入中性偏乐观。
  • 层3 证伪信号
  • 海外份额连降、矿山订单中止、电动化渗透率不及预期、汇率持续不利 → 中性下修。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣（破净原因）
  • PB 0.81 破净，主因重资产（厂房/设备）+ 市场对工程机械周期底部担忧，非资产虚高（净资产为真实设备净值，ROE 约 10%+ 盈利能力稳健）。属「周期错杀型破净」，可保留估值，但大空间须由盈利增长驱动而非单纯 PB 修复。
  • 校正2 周期位置校正
  • 工程机械处上行周期中段（出口+电动化+矿山+设备更新四轮驱动），非单年好年景。中性净利 25 亿取周期归一化（2023–2025 中枢 13 亿 + 结构性增量），未用单年高点或拐点年化。
  • 校正3 杠杆下行情景
  • 资产负债率约 57%（重资产制造业中高位），附利率上行/需求下行负面情景：悲观净利 18 亿、PE 10x → 180 亿 → 8.83 元（+17.7%，仍正但收窄）。若全球衰退致净利 <15 亿，则接近现价，结论降级至「纳入观察」。

第五步：综合赔率判断（买不买？）

当前价格位置：低估。现价 7.50 元对应 2026E PE 8.5x、PB 0.81x（破净），显著低于合理区间。

安全边际：中性远期 15.94 元 → 空间 +112.5%（>50%，达重点关注门槛）；悲观 8.83 元 → +17.7%（下行有限）；乐观 23.55 元 → +214%。

介入条件：现价 7.50 元即具备配置价值；加仓信号：① 海外收入连续双位数增长确认；② 矿山机械订单公告；③ 汇兑转正（Q3 起）；④ 设备更新国债项目落地。

最大风险：
1. 全球工程机械需求下滑 + 汇率不利（H1 汇兑已损 3.1 亿）；
2. 国内地产链持续疲软拖累内销；
3. 钢价/锂价反转压缩毛利；
4. 高负债（57%）在利率上行期财务杠杆反噬。

结论：重点关注

低 PE（8.5x）+ 破净（0.81x）+ 海外/矿山/电动化三增量明确，中性远期空间 +112.5% 远超 50% 门槛。下行有悲观情景 +17.7% 托底。唯一约束为高负债，已附下行情景。
