（3）产业链传导

上游：算力/模型（Seedance 2.5 等外部生成能力）+ 实景搭建（横琴国际影视城 90+ 组欧美实景集群）。成本结构：AI 生成替代真人拍摄，边际制作成本下降 80%–90%，但算力采购（推理 token）构成新变动成本，受模型 API 定价影响。

下游：海外流媒体/应用商店（抽成）、品牌方（IP 联名）、智能电视/车机/电信运营商（新分发渠道）。C 端付费意愿决定 ARPU。

议价权：中等偏强——凭 560 万种 IP 库 + 自研 AI 平台形成"内容+技术"壁垒，但下游渠道（应用商店/平台）集中度较高，分账议价仍受压；海外 FlareFlow 自营平台提升话语权（已盈亏平衡）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • ① 成本传导弹性（转嫁系数）：内容行业无"原料"概念，对应为算力/模型 API 成本 + 实景区搭建成本。算力端：公司多模型协同（接入 Seedance 等），对单一模型厂商议价权中（转嫁系数约 0.5）——部分成本可经提价/广告加载转移至 C 端，部分自行消化。实景端：横琴自建集群锁定供给，议价权强（转嫁系数≈0.8）。综合内容成本占收入比下降主因是 AI 提效（结构性），非涨价转嫁。
  • ② 毛利结构再平衡：分业务看毛利率——短剧及 IP 衍生品 48.62%（高、且提升）、网络文学（授权型，毛利率更高但收入下滑）、IP 衍生品（高毛利）。权重迁移：高毛利的短剧/IP 占比从 2025 约 55% 升至 2026H1 71%，拉动综合毛利结构优化；但若网文基本盘持续萎缩，长期 IP 供给（上游素材）或受限，须持续观察。
  • ③ 库存与采购节奏（timing）：内容行业无实物库存，但算力采购节奏与实景搭建前置投入存在 timing——横琴影视城资本开支前置，短期折旧/摊销压制利润，长期摊薄单集成本。2026H1 现金流为正说明回款质量改善，非"囤货收益"。
  • ④ 政策/市场锚点（成本驱动变量）：a) 监管合规成本：9 月 1 日《办法》实施后，内容审核、AI 标注、肖像授权合规成本上升（情景：合规成本 +5%–10%，验证点=单集制作费用率是否跳升）；b) 模型 API 价格战：若大模型推理降价（市场层），公司毛利受益（验证点=Seedance 等 API 报价）；c) 出海关税/数据合规：各国内容监管（政策层）可能抬高出海合规成本（情景：欧美内容审查收紧，验证点=FlareFlow 单用户获客成本）。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：微短剧 2025 千亿市场、2026 前 8 月 43 万部（13 倍放量），公司 AI 剧产能 3000 部/年属头部，份额约 1%–2%（按部数）但按精品/出海份额更高。验证点：公司年产量占行业比重。
  • 需求侧/客户份额：FlareFlow 5200 万用户 vs 行业 8 亿用户，海外份额领先（出海 8 成中占显著比例）。验证点：MAU、付费率。
  • 技术代际差：自研"逍遥 AI"+ 次元神笔，领先多数中小制作方 1 代（工业化产能）。验证点：单集成本是否持续低于行业 50%+。
  • 成本曲线位置：AI 提效使成本曲线左移 80%–90%，价格战中可"以价换量"扩份额。验证点：制作成本率。
  • 份额二阶导数：出海 + AI 剧处于 S 曲线加速段（前 8 月 AI 剧占 9 成）。验证点：AI 剧产量环比。
    → 三档：保守守住（份额稳定，营收 14 亿）/ 中性小幅提升（17–18 亿）/ 乐观抢份额（25 亿+）。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：能力从"文字 IP"迁移到"视频 IP + 全球分发"，TAM 从网文（百亿）扩至短剧+出海+衍生品（千亿级）。五点：① 能力可迁移（同源 IP+AI，强）；② 新 TAM 弹性（10 倍+）；③ 切入卡位（FlareFlow 已盈亏平衡，早中期）；④ 客户认证门槛（平台入驻即门槛，中）；⑤ 信号验证（5200 万用户 + 月度盈亏平衡 = 已过初步验证，但规模化盈利验证点未满分）。→ 计入"中期期权偏乐观"，不计入中性净利。
  • 层3 风险折扣（证伪信号）：网文素材供给萎缩、FlareFlow 单用户获客成本飙升、监管致 AI 剧下架（2026 已下架 6.8 万部）、单集成本率不降反升。命中则下调增量。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：中文在线为轻资产内容平台，非破净（PB 66.9x，净资产 2.63 亿但市值 176 亿）。高 PB 反映市场对"AI+IP"叙事的极高溢价，但净资产薄、累积亏损大（2023–2025 合计亏约 9.8 亿），一旦 AI 叙事退潮，估值锚缺失。不适用"破净真安全边际"逻辑。
  • 校正2 周期位置校正：内容行业非强周期，但受监管周期 + 流量成本周期影响。当前处于"政策扶持 + AI 降本"蜜月期（周期上行），中性净利已隐含此假设；若监管收紧（内容红线）或流量成本上行，净利率假设须下修。
  • 校正3 杠杆下行情景：资产负债率 74.8%（偏高），经营现金流刚转正，若内容监管致收入断崖，费用刚性将放大亏损。该负面情景下市值可跌至 15–20 亿（悲观 1.92 元），空间转负，故不得标"大空间/重点关注"。
  • 期权纪律：主业迁移（出海 + 衍生品）中"规模化盈利"验证点未满分，仅作乐观情景，不计入中性 NAV/净利。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。现价 24.19 元已高于乐观情景（18.0 元），估值锚完全依赖"AI+IP"叙事而非盈利。

安全边际：中性远期 7.28 元 → 空间 −69.9%；悲观 1.92 元（−92.1%）；乐观 18.0 元（−25.6%）。无任何安全边际，下行风险远大于上行。

介入条件：
1. 不追高。基本面合理区间 8–10 元（对应 2026 PS 6x / 2029 中性），现价高估 2.4 倍。
2. 加仓/关注信号：① 2026 全年确认扭亏且经营现金流持续为正；② FlareFlow 单季度经营性盈利持续（非仅月度平衡）；③ 2027 年净利兑现 ≥1 亿（验证盈利拐点）。
3. 观察指标：短剧/IP 毛利率是否守住 45%+；网文基本盘是否止跌；AI 剧监管下架比例。

最大风险（最可能破坏逻辑的因素）：
1. 估值回归：176 亿市值对应 73x 远期 PE，叙事退潮即戴维斯双杀。
2. 监管收紧：9 月 1 日《办法》后内容审核/AI 标注合规成本上升，2026 已下架违规微短剧 6.8 万部（9 成以上为 AI 剧）。
3. 出海获客成本失控：海外流量成本波动曾致 Q1 网文承压。
4. 盈利兑现不及预期：Q2 单季扭亏仅 283 万，全年微利，规模化盈利仍需验证。

结论：暂不介入（估值已透支未来三年乐观情景，缺乏安全边际；待回落至 12 元以下且扭亏确认后再评估）。

公司质地与行业景气确属上乘（AI 短剧工业化 + 出海 8 成份额 + 政策单列），但好公司不等于好价格。当前价位风险收益严重不对称，仅适合作为"强逻辑观察池"，不满足"重点关注"的 >50% 空间门槛，亦非"坚决回避"（存在真实扭亏路径）。
