（3）产业链传导

上游：钢材、电子元器件、传感器芯片。设备制造对钢价敏感度中等；MEMS 业务上游为晶圆 / 封测，受半导体周期影响。

下游：车检机构与监管平台。下游议价权偏弱——政策直接压缩需求，设备厂与检测站被动承接量价压力；检测运营服务毛利率仅 12.75% 印证盈利被挤压。

议价权判断：传统设备端中等偏弱（行业内卷、客户分散）；监管系统毛利率 46.94% 显示政府 / 平台类项目仍有壁垒。新兴 MEMS 端依托矽睿技术储备，面向国产化替代，潜在议价权较强但未兑现。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）
    传统检测设备：上游钢价 / 电子件变动 ×（1 − 传导率）≈ 实际毛利承压。设备端传导率约 0.3–0.4（客户为中小检测机构，议价能力弱，成本多自担）；监管系统 / 软件端传导率约 0.6–0.7（项目制、定制性强，可部分转嫁）。MEMS 传感器端：若实现车规级国产替代，传导率可达 0.7+（缺货周期 + 技术壁垒）。

  • 因子2 毛利结构再平衡
    分业务毛利率：检测系统 35.89%、监管系统 46.94%、增值服务 21.95%、检测运营 12.75%。H1 高毛利设备占比提升（69.78%）本应抬升结构，但综合毛利率仍降 1.49pct，说明检测运营（12.75%）的下拉与设备端成本上升抵消了结构优化。不可单一"综合毛利率 29.92%"代表全结构——运营服务占比回落才是真实盈利隐忧。

  • 因子3 库存与采购节奏（timing）
    设备制造按订单生产，库存收益 / 损失不显著；但电子元器件存在采购周期，若低价囤货可短期抬毛利、高价接货则侵蚀。H1 未披露明显库存收益，毛利率下滑更可能是真实成本上升 + 运营服务价格战，非库存虚高。

  • 因子4 政策 / 市场锚点（原料成本驱动变量）
    政策层：年检频次优化 / 以旧换新 = 直接压缩需求（非原料但同属成本端驱动，列为需求变量）；"一单一库"资质管理 = 抬高中小机构合规成本、利好头部。市场层：半导体周期影响 MEMS 晶圆成本；人民币贬值利好出口型传感器。情景：若 2027 年设备更新政策（参考七部门老旧装置更新思路向检测设备外溢）落地，则传统主业估值重估。验证点：GB/T 28529-2025 推动的设备更新订单公告。证伪信号：传统检测收入连续两季双位数下滑、运营服务毛利率破 10%。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：检测设备行业分散，安车为头部，受益"一单一库"资质收紧带来的中小出清 → 份额有望小幅提升（验证点：H2 设备订单增速）。
  • 需求侧 / 客户份额：检测运营受政策压缩，份额提升难抵总量下滑。
  • 技术代际差：GB/T 28529-2025 驱动设备升级，安车技术领先一代 → 份额溢价。
  • 成本曲线：规模 + 智能化生产 → 行业降价时以价换量。

  • 份额二阶导数：传统主业处饱和下行 S 曲线，靠政策更新脉冲维持。
    → 三档：保守（传统营收零增长）、中性（设备更新脉冲 +5%）、乐观（新能源检测放量 +10%）。

  • 层2 扩展业务：主业迁移空间（矽睿范式）
    能力可迁移性：从"检测设备制造"迁移至"MEMS 传感器 + 物联网解决方案"，技术同源度低、属跨界，迁移成本高。新 TAM 弹性：MEMS / 传感器市场为原检测设备市场的数倍。切入卡位：借助控股股东矽睿（MEMS 十强）资源，卡位较好。客户认证门槛：车规 / 工业级认证周期长（既是护城河也是阻力）。信号验证：尚未见 MEMS 业务收入公告、未见独立产线量产，仅处战略启动期。→ 未过验证点，仅作中期期权，不计入中性。

  • 层3 风险折扣：证伪信号
    MEMS 业务连续两年无规模化收入公告；传统检测营收连续双位数下滑；运营服务毛利率破 10%；控制权变更后整合不及预期。命中则下调 / 剔除增量。

亏损股三问

  1. 为什么亏：① 股权激励股份支付费用（H1 影响约 3700 万，扣除后仅 −110 万）；② 传统检测主业受年检频次优化 + 以旧换新政策压缩，运营服务收入 −12.96%、毛利率仅 12.75%；③ 新兴 MEMS / 物联网处于投入期，研发与整合费用前置。
  2. 靠什么扭亏，触发时点：① 股份支付费用随激励计划执行完毕自然回落；② 传统主业靠 GB/T 28529-2025 设备更新脉冲 + 检测运营集中度提升企稳；③ MEMS 协同业务从 2027 年起若获头部客户认证并量产，贡献增量。中性扭亏时点看 2027 年（主业近盈亏平衡 + 费用正常化）。
  3. 亏得起吗：账上净资产 16.16 亿、总资产 22.53 亿，资产负债率约 28%，无有息负债压力，经营现金流 H1 为 −5246 万（转型投入 + 回款节奏），但账面资产厚实，可支撑到扭亏，不存在退市 / 破产警示风险。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵 / 已透支转型预期。现价 24.13 元对应 PB 3.42x、隐含 PE（中性）~99x，市场把矽睿 MEMS 注入视为大概率事件定价。

安全边际：
- 中性远期 10.50 元 → 空间 −56.5%（主业价值支撑弱）
- 悲观 6.50 元 → 下行 −73.1%
- 乐观 36.00 元 → +49.2%（需 MEMS 资产注入兑现，属期权非中性）
- 下行保护：PB 3.42x、净资产 16.16 亿（每股净资产约 7.06 元），但亏损期 PB 不提供强安全边际

介入条件：
1. 不追高。当前价等于押注未验证的 MEMS 注入，安全边际为负。
2. 加仓 / 介入信号：① 矽睿 MEMS 资产明确注入或并表公告；② MEMS 业务独立营收公告（≥ 5000 万）；③ 传统主业单季扭亏且运营服务毛利率回升至 15%+；④ 股价回落至 14 元以下（接近净资产、PB<2x）。
3. 观察指标：逐季扣非净利润（剔除股份支付）、MEMS 业务进展公告、设备更新订单。

最大风险（最可能破坏逻辑的因素）：
1. MEMS 注入落空 / 进度远低于预期（首要）——中性估值已剔除该期权，若落空则现价无支撑。
2. 传统主业持续收缩：政策压缩 + 行业内卷，运营服务毛利率破 10%。
3. 股份支付费用延续 + 整合不及预期，扭亏时点后移。
4. 现金流恶化：H1 经营现金流 −5246 万，若回款持续恶化影响投入能力。

结论：暂不介入

理由：中性锚（10.50 元，−56.5%）远低于现价，当前价格已把矽睿 MEMS 转型期权近乎"确定性"定价；而 MEMS / 物联网业务尚未产生收入、未过验证点，依规则不得计入中性。公司主业近盈亏平衡、资产厚实、亏得起，不构成"确无扭亏可能"，故非坚决回避。若后续 MEMS 资产注入 / 并表或独立业务收入公告落地，中性假设需上修，可上调至"纳入观察 / 重点关注"。
核心跟踪点：矽睿 MEMS 资产注入或并表公告 + MEMS 独立营收验证。
