（3）产业链传导

上游：农药原药、化工原料（液氨等）；价格波动 + 环保成本。
下游：种植端（农资需求刚性但价格敏感）、石化供应链客户。
议价权：中等偏弱（制剂竞争激烈、农资电商压价；石化供应链区域化）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：农药制剂成本中原药 + 化工料占比高，涨价时转嫁系数约 0.5–0.6（农资端难提价）；石化供应链（液氨）受能源价影响，转嫁系数约 0.7。H1 综合毛利率仅 5.5% 印证毛利薄。
  • 因子2 毛利结构再平衡：分业务——农药制剂及肥料（占比 53%，毛利中低）、小分子肥（高增但占比小）、石化供应链（占比 ~36%，毛利受能源与贸易价差影响）。若原药涨，制剂毛利塌、供应链占比提升但价差不稳。不能只用综合毛利率 5.5% 代表全结构。
  • 因子3 库存与采购节奏：农药原料可低价囤货（库存收益），但公司历史存货减值大（2025 年存货减值计入亏损）；液氨低温罐为新建，投产前无库存收益。
  • 因子4 政策/市场锚点：①市场层——原药/液氨期货价、农产品景气；②政策层——农药减量增效（压传统、扶生物）、环保双控（抬升合规成本）、绿氨/氢能补贴（利好新方向）、出口退税。验证点：原药价、绿氨项目备案/开工；证伪信号：原药暴涨致制剂毛利破阈、绿氨政策退坡。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量：农药制剂/生物农资市场容量随农业稳增（需求侧锚点中）；公司为老牌但份额非龙头（供给侧锚点中）；技术代际差中（生物农资早期）；成本曲线位置中；份额二阶导数——尚微生态并表带来份额跳升（已验证）。保守守住 / 中性小幅提升 / 乐观抢份额（生物农资渗透）。验证点：下季度制剂出货、销量公告。
  • 层2 扩展业务：主业迁移空间：由"农药生产"迁移至"生物农资 + 石化供应链 + 氨氢新能源"——能力部分可迁移（化工同源）、新 TAM 弹性大（绿氨/氢能）、切入时点早、认证门槛高（危化品资质既是护城河也是阻力）。氨氢新能源未过验证点（仅备案），仅作中期期权，不计入中性；生物农资已验证可计入。
  • 层3 风险折扣（证伪信号）：农药价格战、制剂毛利破阈、液氨项目无实质开工、农一网继续亏损，则下调。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣（破净原因说明）：PB 2.66x，未破净，但净资产 12.65 亿中含持续经营不确定性——未分配利润 −12.42 亿（累计巨亏）、流动资产 2.75 亿 < 流动负债 7.95 亿（流动性缺口约 5.2 亿），短期偿债压力大；且尚欠证券虚假陈述诉讼赔偿 1.37 亿、实控人业绩补偿 1.67 亿待收回。净资产质量弱，2.66x PB 不可简单视为低估。
  • 校正2 周期位置校正：农药行业处周期底部偏弱（价格战 + 生物农资早期），中性正常化净利率取 6%（低于历史较好年份），已标注"底部修复"。
  • 校正3 杠杆下行情景：负债率 41.85%（中高），且流动性缺口大、诉讼待付，悲观情景空间 −94.3%，不得标大空间，至多"暂不介入/纳入观察"且注明高不确定性。

⚠️ 交叉校验：当前市值 34.52 亿 vs 中性合理市值 7.8 亿，现价溢价约 343%；即便乐观情景 1.19 元仍低于现价（−43.1%）。PE(TTM) 仍为负（2025 −2.14 亿拖累），估值完全由"摘帽 + 氨氢期权"主题驱动，严重脱离基本面。

第五步：综合赔率判断（买不买？）

亏损股三问（虽 2026H1 归母转正，仍须审视）：
1. 为什么此前亏：2023–2025 连续三年亏损（−4.67 / −1.55 / −2.14 亿），主因股权投资公允变动损失、固定资产及存货减值、诉讼赔偿等非经营，叠加主业（农药制剂）盈利能力弱。
2. 靠什么扭亏：生物农资（尚微生态并表）放量 + 石化供应链增长 + 处置低效资产回血；2026H1 归母 +0.1871 亿已初步体现，但扣非仍 −0.1269 亿，主业尚未真正盈利。
3. 亏得起吗：存疑——流动性缺口约 5.2 亿（流动 < 流动），未决诉讼赔偿 1.37 亿待付，实控人补偿 1.67 亿回收不确定；靠处置农商行股权等筹资应对，生存能力边际改善但脆弱。

当前价格位置：估值极度透支 / 主题炒作。现价 2.09 元对应市值 34.52 亿，而正常化净利仅 0.31 亿级，PE(TTM) 仍为负，纯粹由"摘帽 + 氨氢新能源期权"驱动。

安全边际：
- 中性远期 0.47 元 → 空间 −77.5%
- 悲观 0.12 元 → 下行 −94.3%
- 乐观 1.19 元 → −43.1%（需液氨项目实质落地）
- 下行保护：极弱的净资产质量 + 流动性缺口，几乎无兜底

介入条件：
1. 等回落至 1.3 元以下（对应中性 ~40x 以内、PB ~1.6x）才具安全边际
2. 加仓信号：扣非净利连续转正、流动性缺口收敛（诉讼/补偿了结）、液氨低温罐实质性开工
3. 观察指标：逐季扣非净利率、经营现金流、诉讼赔偿支付进度、农商行股权处置回款

最大风险：① 扣非主业持续亏损（首要）；② 流动性缺口引发偿债危机；③ 未决诉讼赔偿 1.37 亿 + 实控人补偿 1.67 亿难以兑现；④ 氨氢新能源项目无实质落地（画饼）；⑤ 主题退潮估值双杀。

结论：暂不介入（摘帽与氨氢期权提供想象，但扣非仍亏、流动性承压、估值严重脱离基本面；须待扣非转正且流动性改善后重评）。

第五步进阶：上行想象力情景（四类，只进乐观/机会栏）

  • 类型A 行业出清剩者红利：农药小厂出清，合规头部（辉丰）份额提升。验证点：行业 CR5 提升、份额公告。→ 计入乐观情景。
  • 类型B 政策反转期权：绿氨/氢能补贴 + 生物农药扶持加码，估值重估。验证点：绿氨项目开工、补贴发文。→ 机会情景（未过验证点不计入中性）。
  • 类型C 市场错杀修复：若因保壳恐慌错杀至 1.3 元以下，修复弹性大。验证点：市场企稳、扣非转正。→ 机会情景。
  • 类型D 技术突破/代际跃迁：大丰港液氨低温罐 + 绿氨储运销若投产并量产成本优于旧路线，打开全新曲线（硬验证点=中试/开工+客户定点+成本优，目前仅备案未过），仅作机会情景，不计入中性。

上调至"重点关注"的条件：现价回落至 1.3 元以下，且扣非净利连续转正、流动性缺口收敛、液氨项目实质开工，使 2029E 中性空间转正并 >50%。
