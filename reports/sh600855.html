第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）
- 军品段：实行审价/成本加成定价，原材料成本可在下次审价中体现，但存在时滞（1–2 年），传导率 ≈ 0.6。
- 公共安全段：工程项目总包，传导率 ≈ 0.7（成本加成报价）。
- 高端医疗段：ECMO 未上市，无传导对象。
→ 加权传导率约 0.6。传导弹性并非公司亏损主因——真正的亏损来源是"固定费用率过高"而非"成本传导失败"。

因子2 毛利结构再平衡
三条线对成本与规模的敏感度截然不同：

业务线 毛利率（估） 成本敏感要素 2026H1 收入权重 盈亏状态
军工电子 较高（25–35%） 元器件、芯片 68.54% 收入下降、盈利下滑
公共安全 中（20–25%） 设备 + 工程施工 25.44% 毛利率改善 → 净利润同比增长
高端医疗 低/负 研发注册投入 3.49% 持续亏损

结构变化：高毛利的军工电子占比最高但正在失血；亏损的高端医疗占比虽小却是长期拖累。综合毛利率 24.77% 掩盖了"军工下滑、公共安全改善"的内部迁移——禁止用单一综合毛利率代表全结构。

因子3 库存与采购节奏（timing）
存货 6.61 亿元（较年初 +19.5%），跌价准备 1.07 亿元（计提比例 14.0%）——在收入下滑 28% 的同时存货增长 19.5%，说明公司为"订单交付回补"提前备货，属"以库存换交付节奏"的主动选择。若 2026H2 电源交付如期结算，则库存转化为收入；若交付继续延期，存货跌价风险将上升。这是本股最需要跟踪的 timing 变量。

因子4 政策/市场锚点
- 市场层：军工装备交付节奏、红外探测器价格、元器件（芯片）价格与国产化率。
- 政策层：①军工"十五五"与 2027 建军百年——决定电源/红外需求总量；②低空经济政策与反无人机监管——决定低空反无订单放量节奏；③ECMO 注册审批新规（增加临床评价同品种比对）——是导致取证延迟的直接政策变量，也是最大的正向期权来源；④医疗设备更新政策——利好呼吸机等。
- 验证点：季度电源交付结算额、公共安全中标与结算、ECMO 注册受理/获批公告、存货与跌价准备变化。
- 证伪信号：电源交付连续两年延期、ECMO 取证再度推迟或失败、低空反无无批量订单、应收账款减值继续大额计提。

本因子输出直接喂给第四步：正常化情景将毛利率锚定在 25–28%（军工电子结构不变的合理水平），不沿用 2022 年 营收高点时的低净利率，也不假设毛利率大幅跃升。

亏损三问（必答）

问一：为什么亏？
1. 收入端：军工电子电源业务受产品交付延期影响，上半年结算较上年同期短期下滑；红外光电业务受最终用户需求放缓，传统机载产品收入不及预期；公共安全部分重点项目未到结算期。
2. 费用端（核心）：毛利率 24.77% vs 期间费用率 53.8%——期间费用 1.38 亿元远超毛利 0.64 亿元，固定费用（研发、人工、管理费用）无法被当前收入规模覆盖，是持续亏损的根本机制（前三年度亏损 2.35/2.46/1.72 亿元亦源于此）。
3. 减值端：上半年应收账款回款不足，应收账款计提减值准备增加（坏账准备余额 2.13 亿元、计提比例 19.9%）。
4. 子公司拖累：长峰医科、长峰科威、航天柏克合计拖累利润约 5200 万元。

问二：靠什么扭亏、触发时点？
1. 电源交付结算回补（最快）：公司称"全力推进电源产品交付，确保产品尽快完成结算，快速回补收入缺口"——触发时点为 2026H2–2027 年；若 H2 电源集中结算，全年有望大幅减亏。
2. 公共安全"十五五"边防建设任务：已中标多个重点项目，毛利率改善，触发时点为 2027 年。
3. 低空反无由签约转批量：已签约，触发时点为 2027–2028 年。
4. ECMO 取证：五项产品注册推进中，触发时点为 2028 年（若获批，打开百亿级市场）。
5. 航天柏克剥离：2026-08 已征集受让方，触发时点为 2026H2（减少约 5000 万元/年亏损）。
→ 综合判断：2026 年大概率仍亏损（H1 −0.52 亿），2027 年具备大幅减亏条件，中性假设下 2028 年实现扭亏。 若要覆盖固定成本，盈亏平衡点对应年营收约 14–16 亿元（按毛利率 25%、期间费用 3.2–3.6 亿元测算）。

问三：亏得起吗？
- 账面现金：期末货币资金 5.90 亿元（较年初 −22.1%，其中受限资金 2929 万元）
- 经营现金流：2026H1 −1.26 亿元（同比改善 825 万元）
- 负债结构：资产负债率 53.31%、有息负债 1.52 亿元（有息负债率 8.61%），长期借款压力可控
- 融资能力：实控人为中国航天科工集团，军工央企信用背书，融资渠道畅通（半年报显示筹资活动现金流仅 −456 万元）
- 测算：按年经营现金净流出 2.0–2.5 亿元、在手现金 5.90 亿元，可支撑约 2.5–3 年；叠加航天柏克剥离减亏与母公司信用，"倒在黎明前"的概率较低。→ 结论：亏得起，但时间窗口不容反复（若交付与取证再延两年，压力将显著上升）。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

层1 现有业务：市场容量 × 份额变量
- 市场容量：军工电源与红外光电受"十五五"装备建设驱动，总量刚性；低空安防为新增长赛道；ECMO 国产替代空间被描述为百亿级。
- 份额锚点①（供给侧）：公司为航天科工体系内电源与光电配套单位，份额靠体系内配套关系而非产能规模；模块电源"订单充足"说明份额未流失。
- 份额锚点②（需求侧/客户）：客户为军方与军工总体单位，准入资质与体系内地位构成高黏性（新客户签约约 2000 万元说明在开拓体系外客户）。
- 份额锚点③（技术代际差）：红外光电受"最终用户需求放缓"拖累，技术代际未落后但需求端走弱；电源为通用配套，技术差异化有限。
- 份额锚点④（成本曲线位置）：无规模成本优势，靠体系内配套定价（审价机制）守位。
- 份额锚点⑤（二阶导）：份额基本饱和，收入下降源于交付节奏而非份额流失（"订单充足"佐证）。
- 三档假设：保守（份额守住，收入持平）／中性（交付回补，收入年增 5%）／乐观（低空反无放量，收入年增 12%）。验证点：季度电源结算额、新签合同额。

层2 扩展业务：主业迁移空间（新易盛范式）
- 能力可迁移性：较高。模块电源能力可迁移至 ①低空经济配套电源；②卫星配套电源；③新能源及数据中心电源；④核电领域（公司已推动对接）。红外光电能力可迁移至低空反无人机（同源探测 + 识别）。
- 新 TAM 弹性：低空经济与数据中心电源的市场规模数倍于传统军工电源；ECMO 为百亿级医疗新市场。
- 切入卡位：早期。低空反无"已实现签约"；数据中心电源处"客户沟通与技术对接"阶段；ECMO 在注册中。
- 认证门槛：军工配套资质 + ECMO 医疗器械注册（NMPA）——认证门槛极高，既是护城河也是当前阻力（ECMO 取证延迟即为证据）。
- 信号验证：低空反无已签约（过第一验证点），但未到"批量销售/营收占比跳升"；ECMO 未取证。→ 按中期期权处理，中性情景只给军工电子温和回补，不给低空/ECMO 的显著收入贡献。

层3 风险折扣：证伪信号
- 电源交付连续两年延期、收入连续两年降幅 >15% → 份额与回补假设下修
- ECMO 注册再度推迟或失败 → 期权剔除
- 低空反无长期停留"签约"无批量订单 → 迁移假设剔除
- 应收账款减值继续大额计提（坏账准备 >2.5 亿）→ 净资产与利润双下修
- 存货跌价准备继续上升 → 备货逻辑证伪

第四步：估值锚定（自下而上，非增速外推）

方法说明：公司当前亏损（TTM 归母 −1.71 亿元、PE 为负），无法直接套用 PE，改用正常化净利润法：①估稳态营收（现有产能 + 已查明订单/项目）→ ②算正常化净利率（行业正常水平 / 公司历史最好水平 / 产能爬坡后理论值，三者取保守）→ ③正常化净利 × 远期合理 PE = 目标市值 → 目标价。

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

校正1 资产质量折扣
公司未破净（PB 4.68x，反而大幅溢价），但资产质量与高 PB 严重不匹配：① 应收账款 8.57 亿元（占总资产 27.5%），坏账准备 2.13 亿元、计提比例 19.9%——净资产存在进一步被侵蚀的风险；② 存货 6.61 亿元（+19.5%），跌价准备 1.07 亿元——在收入下滑 28% 的背景下存货逆势增长，跌价风险上升；③ 净资产仅 13.82 亿元（每股 2.95 元），且累计未分配利润 −1.64 亿元；④ ROE 为负（−3.70%）——PB 4.68x 对负 ROE 而言是纯粹的"期权定价"，不构成任何安全边际，反而是估值风险。→ 禁止用"净资产/资产规模"推导安全边际。

校正2 周期位置校正（中性净利用周期归一化）
公司所处军工电子与公共安全行业处于装备交付节奏的低谷期（收入连续下行），同时低空经济处于渗透率拐点前夜。中性净利不得用 2026H1 年化（−1.04 亿，更亏）、也不得用 2022 年 营收高点外推，须取"稳态营收 16 亿 × 正常化净利率 4.3%"的归一化值——中性锚定 0.69 亿元。明确标注：当前处于收入低谷 + 期权集中期，中性净利为"正常化后"水平，不是当年度水平。

校正3 杠杆下行情景
资产负债率 53.31%、有息负债仅 1.52 亿元（有息负债率 8.61%），财务杠杆不高；但经营杠杆极高：期间费用率 53.8% 且刚性，收入每下滑 10% 即扩大亏损约 0.25 亿元。下行情景：电源交付继续延期 + ECMO 取证失败 → 稳态营收仅 11 亿元、正常化净利 0.22 亿元，叠加净资产减值，对应股价可至 4.50 元（−67.3%）。→ 该负面情景使空间深度转负，本股不得标"大空间/重点关注"，至多"暂不介入"并注明高波动、高估值属性。

期权纪律
"低空反无批量销售""ECMO 取证放量""航天科工体系资产注入"均属未过验证点的中期期权，不计入中性 NAV / 中性净利，仅列入乐观情景（见第五步进阶）。尤其注意：ECMO 尚未取证，未过"硬验证点"，其百亿级市场空间不得计入中性锚。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。现价 13.75 元对应 PB 4.68x、PS 5.2x，中性正常化价值仅 7.70 元（−44.0%）。市场定价的是"低空经济 + 军工 + ECMO"的主题溢价，而非当前基本面。

安全边际：
- 中性远期 7.70 元 → 空间 −44.0%，既不满足"纳入观察"的 >0，也不达"重点关注"的 >50%
- 悲观情景 4.50 元 → 下行 −67.3%
- 乐观情景 20.00 元 → +45.5%（需 ECMO 取证放量 + 低空反无批量 + 电源高增三者同时兑现）
- 无实质下行保护：PB 4.68x 对负 ROE 属期权定价，扣掉商誉与减值后的真实资产价值约 2.0–2.5 元/股

介入条件：
1. 不介入。现价远超正常化价值区间
2. 重新评估门槛：股价回落至 8.0 元以下（PB < 2.7x）才接近正常化估值上沿
3. 上调信号：① 单季度电源交付集中结算并确认收入（收入环比大幅回升）；② ECMO 注册受理/获批公告；③ 低空反无由签约转为批量订单公告；④ 单季亏损显著收窄至 −0.1 亿元以内
4. 观察指标：逐季营收与毛利率、期间费用率、应收账款坏账准备、存货跌价准备

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 估值透支（首要）：PB 4.68x、PS 5.2x 对一家连续四年亏损、ROE 为负、营收下滑 28% 的公司严重偏高，任何主题降温都可能带来 40%+ 的估值回归
2. ⚠️ 交付与取证双重延期：电源交付延期、ECMO 取证延迟已连续发生；若再延两年，"亏得起"的时间窗口将被压缩
3. 资产减值风险：应收账款坏账准备 2.13 亿（计提比例 19.9%）、存货跌价准备 1.07 亿，若继续上升直接侵蚀净资产
4. 期间费用率刚性：53.8% 的费用率意味着收入不回到 14–16 亿元就无法扭亏，而收入恢复完全依赖外部节奏
5. 子公司拖累：长峰医科、长峰科威、航天柏克合计拖累约 5200 万元（航天柏克剥离中）

结论：暂不介入

理由：中性正常化价值 7.70 元，对应空间 −44.0%，不满足"纳入观察"所需的 >0 门槛；同时悲观情景存在 −67.3% 下行，风险收益严重不对称。
公司并非"确无扭亏可能"——电源订单充足、公共安全毛利率改善、低空反无已签约、ECMO 在注册推进、航天柏克剥离落地，具备明确的扭亏路径，故不判"坚决回避"。但当前价格已把 2029 年的乐观情形提前定价，介入的赔率极差。
核心跟踪点：① 季度电源交付结算进展；② ECMO 注册受理/获批公告；③ 低空反无缝批量订单；④ 应收账款减值与现金余额。

第五步进阶：上行想象力情景（调整型机会，只进乐观栏）

类型A 行业调整剩者红利

类型C 市场错杀修复
本股 2026 年区间振幅 54.25%，属高波动主题股，当前不存在错杀（估值高于正常化价值）。本类型不适用；若未来市场系统性调整将股价砸至 7 元以下而电源交付/ECMO 进度未恶化，则本项可重新适用。

类型D 技术突破 / 技术代际跃迁期权
ECMO 是公司唯一符合"技术突破期权"定义的方向：①政策驱动——高端医疗装备国产化被列为国家专项，"卡脖子"设备强制替代；②行业趋势——ECMO 长期进口依赖，国产化渗透率拐点前夜；③公司落地——主机及耗材五项产品研制注册推进中。硬验证点检查：中试/型式检验是否通过（未披露）、NMPA 注册证（未取得）、量产成本是否优于进口（未披露）——三者均未达标 → 仅作机会情景，不计入中性锚。 证伪信号：注册再度推迟或失败、无渠道建设进展、无批量订单。
