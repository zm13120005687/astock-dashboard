上游：芯片、电子元器件、软件中间件；价格随半导体周期波动（影响较小）。

议价权：中等——电网客户粘性强但议价强；高毛利（~50%）体现产品差异化。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：软件 / 设备项目制为主，芯片等硬件成本占比低，原料涨价对毛利冲击小，转嫁系数约 0.5–0.6（硬件部分）。
  • 因子2 毛利结构再平衡：工业物联网设备毛利高（~50%+），数字化解决方案毛利稍低；并购双洲 / 启泰后结构变化需跟踪，但整体维持高毛利区间。分业务线：设备 > 解决方案。
  • 因子3 库存与采购节奏：轻资产、按项目采购，无囤货收益 / 损失；项目验收节奏影响收入确认（季节性）。
  • 因子4 政策 / 市场锚点（原料成本驱动变量）：①芯片进口与出口管制（成本端，影响小）；②电网 5 万亿投资 + 信创国产替代（需求端强驱动）；③量子科技政策（中长期技术溢价）。验证点：电网招标金额、在手订单。证伪信号：毛利率跌破 40%、订单不及预期。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：电力信息安全参与者中等，公司卡位电网客户具粘性。
  • 需求侧：国网 / 南网 + 主要电力设备商认证壁垒高。
  • 技术代际：配网信息安全 + AI 设计处行业前列。
  • 成本曲线：轻资产、高毛利，规模摊薄研发。
  • 份额加速度：电网投资上行 + 信创，份额提升。
    → 三档：保守营收 2 亿 / 中性 3.5 亿 / 乐观 5 亿（2029E）。
  • 层2 扩展业务：主业迁移空间：从"电力信息安全"向"数字城市 + 党政军信息安全 + 量子加密"迁移，能力同源（信息安全 / 软件）；新 TAM（信创 + 量子）弹性大。信号验证：启泰中标电信 / 移动、双洲获行业认可。部分已过验证点（已并表贡献），可计入中性增量。
  • 层3 风险折扣（证伪信号）：电网订单放缓、并购整合不及预期、应收账款坏账 → 下调。

第四步进阶：重资产 / 周期股校正（三道闸）

  • 校正1 资产质量折扣：PB 3.24x，净资产 8.97 亿为正、轻资产无破净，无破净伪空间；但市值 26.4 亿相对营收 / 利润偏高，主要由期权溢价支撑。
  • 校正2 周期位置校正：非强周期，处电网投资上行 + 信创替代期，中性净利用 2029 稳态、未用单年好年景。
  • 校正3 杠杆下行情景：资产负债率仅 8.38%，几乎无杠杆，下行主要为估值压缩与订单不及预期（悲观 −76%），不触发财务反噬。

第五步：综合赔率判断（买不买？）

当前价格位置：估值已偏高、期权溢价透支。现价 22.59 对应 2029 中性 18.0 元已低 20%，市场定价 AI / 量子 / 并购期权，但期权未过验证点。

安全边际：
- 中性远期 18.0 元 → 空间 −20.3%
- 悲观 5.3 元 → 下行 −76.4%（小市值流动性 + 期权证伪）
- 乐观 30.8 元 → +36.4%（需信创 + 量子超预期）
- 下行保护：PB 3.24x、资产负债率 8.38%、现金充裕，但估值压缩空间大

介入条件：
1. 回落至 16 元以下（PS <10x、接近基本面）具性价比
2. 加仓信号：双洲 H2 结算兑现、启泰央国企订单放量、量子 / AI 商业化落地
3. 观察指标：季度毛利率维持 45%+、经营现金流转正、并购协同验证

最大风险：①当前市值透支过多期权，估值压缩风险大；②并购整合不及预期；③应收账款坏账（H1 经营现金流 −959 万）；④AI / 量子产业化回报不确定。

亏损股三问（2026H1 阶段性亏损）：
1. 为什么亏：2026H1 归母 −778 万，主因子公司双洲科技（党政军）业务季节性（项目验收集中在下半年，H1 亏损）+ 股权激励股份支付摊销 + 研发投入 +55.33%（848 万）；属阶段性、非经营恶化（2025 全年盈利 +1189 万）。
2. 靠什么扭亏、时点：双洲 H2 集中结算 + 启泰并表全年贡献 + 费用管控；预计 2026 全年重回盈利，2026H1 为季节性低点。
3. 亏得起吗：资产负债率仅 8.38%、现金充裕、净资产 8.97 亿，完全可支撑短期季节性亏损与研发，无退市风险（PB 为正）。

结论：暂不介入

资产质量优（轻资产、现金充裕、电网 + 信创政策强驱动），但当前 22.59 元已透支并购与 AI / 量子期权，2029 中性估值仅 18 元。等回落至 16 元以下或并购协同 / 期权验证落地再转"纳入观察"。
