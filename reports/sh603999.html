- 队列未标亏损、PE_TTM 为正 —— 但 41.7x 的 TTM PE 必须穿透核查失真形态。
- 实查 2026 年半年报：归母净利 +3235.18 万元（同比 −16.20%）、扣非净利 +2310.44 万元（同比 −1.30%）、Q2 单季归母 +2283.92 万元（同比 −21.87%，环比 +140.09%）。

（3）产业链传导

上游：纸张（文化用纸/胶版纸）是最大成本项。2026 年纸张价格下降，是毛利率 +4.48pct 的主因。印刷加工（绿色印刷认证厂，成本更高）。

议价权综合判定：上游中等偏强（纸张集中采购 + 纸价下行受益）、下游弱（定价受管制，需求受政策约束）。公司实际是"夹在纸价与政策之间的加工厂"，只能通过压缩品种、提高单品种印数来对冲。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）
  • 教材：传导率 = 0（双向）。中小学教材实行政府定价/政府指导价（湘发改办法明确"不执行政府定价"属价格违法），纸价涨跌 100% 由公司自担/自留 → 本轮毛利率 +5.21pct（教材教辅）完全是纸价下行的被动红利，纸价一旦反弹将原路吐回。
  • 教辅：进评议目录的受价格管理，传导率 ≈ 0；市场化教辅（正在被政策消灭的部分）传导率约 0.5。
  • 期刊：自主定价 + 提价空间有限（提价加速发行量下滑），传导率 ≈ 0.4。
  • 一般图书：完全市场化，传导率 ≈ 0.6。

  • → 综合传导率约 0.25–0.35：纸价下行 10%，公司留存 6.5%–7.5% 毛利改善；纸价上行 10%，自担同等幅度。毛利率对纸价是极高敏感度的双向杠杆，且无对冲工具。

  • 因子3 库存与采购节奏（timing）
  • 存货周转率 0.70 次（半年），图书库存周转慢是行业通病；图书/期刊库存跌价准备是出版企业的常态减值项（2025Q4 单季即出现扣非转负，部分源于年末计提）。
  • 纸张采购：公司未披露长协/套保。2026H1 享受的是纸价下行周期中的现货采购红利，若 2027–2028 纸价进入上行周期且公司无长协锁定，毛利率将反向承压。

  • 判断：2026H1 的高毛利含明确的 timing 成分（纸价下行 + 年末减值未计提），不可外推。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务 = 市场容量 × 份额变量（五锚点）

锚点 现状 三档假设 可观测验证点
① 供给侧份额 出版为牌照管制 + 区域割据，甘肃省内基本盘稳固 保守守住省内 / 中性省外小幅提升 / 乐观全国评议目录突破 省外收入占比是否突破 50%

→ 中性份额假设：2029 年教材收入较 2026E 增长约 15%（省外拓展），教辅再降 10%–15%（政策不可逆），期刊降幅收窄至年降 3%，一般图书持平。不做"教材全国份额突破"的乐观假设。

层2 扩展业务 = 主业迁移空间
1. 能力可迁移性：内容策划 + 编辑 + 品牌 IP → 可迁移到数字内容、知识服务、文创授权。技术同源度中等（内容能力可复用，渠道能力需重建）。
2. 新 TAM 弹性：数字教育/知识付费市场远大于纸质出版。
3. 切入卡位：已晚。教育数字化由头部平台（国家智慧教育平台、区域教育局平台）主导，公司只能做"配套数字资源"，且政策明确要求"不强制收费" —— 卡位极差。
