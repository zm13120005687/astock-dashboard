第一步：公司是干什么的？

一句话定位：国内重型装备一体化龙头，给港口、矿山、冶金、风电、造船提供"整机 + 核心零部件 + 工程总包 + 全生命周期服务"的成套解决方案，是国内少数具备风电核心零部件全链条（齿轮箱、机舱框架、轮毂、塔筒等）的平台型供应商。

（3）产业链传导

上游：钢材（板材 / 锻件）、生铁、铜、有色金属——成本占比高。大连基地可自产重达 500 吨巨型部件，成本较外协低约 20%，向上游延伸对冲部分波动。

下游：港口、矿山、冶金、风电整机厂、水电 / 调水工程。下游资本开支节奏决定交付量；风电整机涨价订单（2024.11 起）2026 年交付释放盈利弹性，但产业链价格传导仍挤压零部件企业。

议价权：中等偏强。翻车机单项冠军 + 整机智能化覆盖 + 全生命周期服务构筑客户粘性；但风电价格战使新能源设备议价权偏弱（毛利率仅 7.23%），冶金设备随行就市。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：重工设备采用"成本加成 + 招标定价"，大型项目调价机制有限，传导率约 0.5–0.7；风电零部件处价格战，传导率偏低（上游钢材涨多由自身消化）；港口 / 冶金高端定制传导率较高（约 0.7）。量化依据：H1 综合毛利率仅 −0.59pct，说明钢材波动大体被精益降本对冲，未完全转嫁。
  • 因子2 毛利结构再平衡：分业务毛利率差异极大（核心零部件 22.44% > 物料搬运 20.07% > 冶金 18.63% >> 新能源 7.23%）。新能源设备占比提升（24.51%）但毛利率最低，是综合毛利率被结构性拉低的主因；物料搬运（+36.92%）高毛利放量改善结构。禁止用单一 17.87% 综合毛利率代表全结构。
  • 因子3 库存与采购节奏：大连基地自产重部件降本 20% 属"产能降本"非"囤货收益"；钢材低位时集中采购锁价形成阶段性毛利红利，须区分当期 vs 远期可比性（高价接货期将承压）。
  • 因子4 政策 / 市场锚点：① 市场层——钢材价格（双控 / 能耗政策影响）、风电装机节奏、欧洲能源转型出海；② 政策层——能耗双控抬升钢材成本、设备更新补贴降成本、海风审批提速。情景：若钢价 +10% 且传导率 0.6，则实际毛利承压约 4pct；验证点：我的钢铁网钢价、风电中标价、出口订单公告。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：重机行业部分领域产能过剩，但风电大兆瓦齿轮箱 / 铸件产能偏紧，公司头部地位稳固；
  • 需求侧：绑定金风 / 远景 / 运达等核心客户（认证周期 = 粘性）；
  • 技术代际：大兆瓦 + 轻量化 + 智能化领先一代 → 份额溢价；
  • 成本曲线：大连基地自产重部件成本低 20%，左侧位置；
  • 份额加速度：出口 +38.8%、物料搬运 +36.92% 处于加速渗透。
    三档：保守守住（营收年增 3–5%）/ 中性小幅提升（5–8%）/ 乐观抢份额（风电出海 + 港口智能化共振，8–12%）。验证点：逐季出口订货、风电齿轮箱出货量。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：由"设备"向"制造 + 服务 + 数字化"综合方案商迁移，海洋工程装备、智能运维机器人属能力可迁移（技术同源）；但客户认证门槛高、信号验证不足（仅研发阶段），未过验证点，仅作中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：冶金持续低谷致订单连降、风电价格战使毛利率破 6%、出口地缘 / 汇率风险。命中则下调增量。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：固定资产占比高（重机属性），但 PB 1.24x > 1，非破净，净资产含设备 / 厂房真实产能，非虚高；安全边际来自产能而非壳。
  • 校正2 周期位置校正：当前处"风电上行 + 港口智能化上行 + 冶金底部"组合，中性净利已用结构法（非单年好年景、非拐点年化），冶金底部已保守处理；标注：周期位置中性偏上行。
  • 校正3 杠杆下行情景：国企背景，资产负债率稳健（经营现金流 H1 +1652%），财务杠杆低；若利率上行 + 冶金需求再降，悲观情景空间 −9.6%，未转负，不因高负债降级。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。现价 5.21 元对应 2029E PE 10.6x，处重机估值下沿；但短期（2026E）仅 13.4x，弹性有限。

安全边际：中性远期 7.38 元 → 空间 +41.7%（未达"重点关注" >50% 门槛）；悲观 4.71 元 → 下行 −9.6%，回撤可控（国企 + 订单保障）；乐观 10.56 元 → +102.7%。

介入条件：现价 5.21 元已具配置价值；回落至 4.8 元以下（2026E PE < 12x）加仓更优。加仓信号：① 中革基地齿轮箱项目达产公告；② 出口订货连续两季 > +30%；③ 冶金设备收入同比转正。

最大风险：① 风电整机价格战向零部件传导致新能源设备毛利率破 6%；② 冶金行业持续低迷；③ 应收账款增速高于营收（信用减值）；④ 出口地缘 / 汇率波动。

结论：纳入观察（远期中性 +41.7% < 50% 门槛，但确定性高、下行可控，属"逻辑对、空间有限"型）。

第五步进阶：上行想象力情景（四类，对称对冲保守偏置）

  • A 行业调整剩者红利：重机产能过剩出清，公司凭规模 / 技术 / 管理（自产降本 20%）份额提升；验证点：中小厂商退出公告、公司份额跳升；证伪：价格战加剧。
  • B 政策反转期权：设备更新 / 海风审批提速超预期，订单放量；验证点：新一轮设备更新专项、海风核准放量；重估弹性见乐观情景 +102.7%。未过验证点仅作机会情景。
  • C 市场错杀修复：若因大盘风格切换被杀至 4.5 元以下（PB < 1.1x），修复弹性大；验证点：估值分位触底 + 业绩证伪恐慌。
  • D 技术突破 / 代际跃迁期权：海上风电核心零部件、智能运维机器人从 0 到 1 投产；硬验证点 = 中试良率达标 + 客户定点 + 量产成本优于旧路线（目前仅研发，缺验证）→ 仅作机会情景，不计入中性。

上调至"重点关注"的条件：中革基地齿轮箱达产并披露明确批量订单 + 出口订货连续两季 > +30% + 冶金收入转正，使 2029E 净利上修至 11 亿以上（中性空间 > 50%）。
