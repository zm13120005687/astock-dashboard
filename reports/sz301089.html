第一步：公司是干什么的？

一句话定位：国内核苷(酸)类原料药及医药中间体龙头（化学合成 + 生物发酵双技术路线），正从"传统原料药"向"功能食品原料 + CMO/CDMO + 非核苷特色原料药"多板块协同转型。

核心产品：核苷系列（胞磷胆碱钠、肌苷、鸟苷、腺嘌呤等）、医药中间体、抗氧剂级单品；新业务为功能食品营养强化剂（D-核糖、NMN）及 CMO/CDMO 定制。

主要客户/下游：国药国际医药科技、辰欣药业、华润双鹤利民、齐鲁制药等制剂/原料药客户；CMO/CDMO 及功能食品面向保健品与跨国供应链。境外收入 0.71 亿（占比 33.6%，同比 +43.08%），为新补充。

境内外占比：境内约 66.4%，境外约 33.6%（境外增速显著高于境内，是增量方向）。

股东背景：实控人杨海霞家族，总部河南新乡；2021 年创业板上市，IPO 募资净额 5.43 亿，目前推进 2.29 亿定增（内蒙古基地）。

（3）产业链传导

上游：化工基础原料（苯酚、酶制剂等），价格波动直接抬升成本；新乡基地电价 0.78–0.80 元/度、蒸汽 222 元/吨，能源成本偏高。

下游：制剂企业/保健品渠道，需求刚性但压价能力强，公司议价权中等偏弱（毛利率持续下滑佐证）。

议价权判断：传统品种弱（价格被挤压）；CMO/CDMO 与功能食品客户黏性较强（毛利 25.88%/定制化）属强议价端，但占比仍低。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数 ≈ 0.3）：传统原料药/中间体同质化，客户压价，成本上涨仅约 30% 可转嫁，其余自我消化，毛利被吃。CMO/CDMO 转嫁系数高（≈0.8，定制排他）。
  • 因子2 毛利结构再平衡：当前利润结构从"高毛利传统原料药（32.8%）"向"低毛利功能食品（4.9%）+ 中毛利 CMO（25.9%）"迁移，加权综合毛利率被新业务稀释，但这是收入结构升级而非单纯恶化；分业务线看，传统原料药毛利仍厚，中间体（12.08%）为拖累项。
  • 因子3 库存与采购节奏：新乡能源成本高 + 夏季高温影响发酵稳定性，公司计划将鸟苷、D-核糖等产线北迁内蒙古以降本；当前处于"接货/爬坡"阶段，无显著囤货收益，反而折旧摊销前置。
  • 因子4 政策/市场锚点：① 环保/能耗双控抬升新乡基地成本（倒逼北迁降本）；② 仿制药专利到期为特色原料药带来需求增量（正向锚）；③ 出口管制/汇率波动为成本与汇兑风险变量（2026H1 汇兑损失同比 +10 倍）。验证点：内蒙古项目能源成本实测下降幅度、专利到期品种订单落地；证伪信号：北迁移产降本不及预期、价格战持续致毛利破 12%。

本因子输出喂给第四步毛利率假设：中性情景给予稳态净利率 12%（高于当前 −13%，低于历史最好 29%），已含价格温和修复 + 新业务占比提升。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务·市场容量 × 份额变量：核苷类国内"品种全、规模大"，但行业价格战使份额价值下降；CMO/CDMO、功能食品从低基数提升份额（三档：保守守住 / 中性小幅提升 / 乐观抢份额）。验证点：下季度 CMO 营收占比、食品原料客户数。
  • 层2 扩展业务·主业迁移空间（新易盛范式）：从核苷原料药 → 功能食品（NMN）/ CMO-CDMO / 非核苷特色原料药，技术同源（化学合成+生物发酵），迁移成本低；新 TAM（保健品、CDMO）数倍于旧池塘。未过验证点（产能利用率/订单未跳升），仅作中期期权，不计入中性。
  • 层3 风险折扣·证伪信号：前次募投利用率连续 <40%、内蒙古项目延期、新业务订单无正式公告 → 下调增量。

第四步：估值锚定（自下而上，非增速外推）

方法说明（亏损股）：2026H1 真实亏损 −2796 万，不用 PE。采用正常化净利润法：估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价。基准（2026 年底）用 2026E 正常化锚 9.50 元（仍处亏损期，按部分恢复常态估算）；远期（2029E·中性）为完整恢复后锚。

总股本：约 1.27 亿股；净资产 14.58 亿；总资产 16.32 亿；资产负债率约 10.6%（轻资产、低负债）。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：轻资产（固定资产以厂房设备为主），净资产 14.58 亿无大隐负债，PB 1.95x 反映"亏损但资产实"，非破净伪便宜；无金融资产未重估情形。
  • 校正2 周期位置校正：医药非强周期，但处"产品价格下行 + 产能爬坡"阶段，中性净利已用保守 12% 净利率，未把 2023 年 29% 高景气外推。
  • 校正3 杠杆下行情景：资产负债率仅 ~10.6%，无有息负债压力，经营/财务杠杆双低，下行不致净利跳负，无高贝塔风险。

亏损股三问（必须回答）

  1. 为什么亏：① 下游需求弱 + 同质化竞争致产品降价（综合毛利 −11.76pct）；② 前次募投 2025-06 转固，折旧摊销前置（新增固定成本）；③ 汇兑损失同比 +10 倍；④ 营收 +16% 但成本 +36%，剪刀差扩大。
  2. 靠什么扭亏 + 时点：募投产能利用率从 14–37% 爬坡至 50–60% 盈亏平衡线 + 内蒙古北迁移产降本 + CMO/CDMO 与功能食品放量。触发时点预计 2027–2028 年（产能负荷达 60%+ 后固定成本摊薄）。
  3. 亏得起吗：净资产 14.58 亿、账面资金充足（上市募资 + 定增储备），2026H1 经营现金流 −455 万（同比收窄 80%），亏得起，无退市或破产风险。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 22.37 对应中性目标价 14.6 元，已隐含对产能 fully ramp + 新业务成功的较乐观预期。

安全边际：中性远期空间 −34.7%，悲观情景 7.1 元（−68%）；乐观情景 33 元（+47.5%）但需强兑现。下行保护来自净资产 14.58 亿（每股净资产 ~11.5 元，PB 1.95x）。

介入条件：① 价格回落至 14 元以下（接近中性价值）；② 加仓信号：前次募投利用率突破 50%、CMO/CDMO 大单公告、内蒙古项目正式开工且降本兑现、欧盟高端原料药认证落地。

最大风险：① 产能爬坡持续慢于预期（前次项目已 1 年仍 <40%）；② 原料药价格战致毛利破 12%；③ 定增审批/北迁移产不及预期；④ 汇兑与原料成本波动。

结论：暂不介入

公司具备真实扭亏路径（产能爬坡 + 降本 + 新业务），且亏得起、无退市风险，但当前价格已透支修复预期，中性空间为负。属"高弹性观察仓"，待产能利用率与订单验证后再行介入。

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：原料药供给侧出清（能耗/环保淘汰小产能），剩者份额与定价权跳升。验证点：行业产能退出公告、公司份额提升；证伪：价格战持续。
  • 类型B 政策反转期权：仿制药专利到期潮带来特色原料药放量（已发生，偏需求端）。验证点：专利到期品种订单；不计入中性。
  • 类型C 市场错杀修复：若 H2 亏损收窄超预期引发重估。验证点：单季扭亏公告。
  • 类型D 技术突破/代际跃迁：内蒙古酶促法降本 + 欧盟高端原料药认证，打开欧美高毛利市场。硬验证点：中试/产线良率达标、客户定点、降本实测；三者缺一则仅作机会情景。
  • 上调至"重点关注"的条件：产能利用率稳定突破 60% 且单季扣非转正，正常化净利上修至 1.2 亿以上（中性股价 ≈ 21 元，空间转正）。
