广大特材（688186）五步法分析报告

分析日期：2026-09-21 ｜ 现价 14.32 元 ｜ 总市值 40.17 亿 ｜ PE(TTM) 约 114.6x ｜ PB 0.83x（破净） ｜ 总股本 约 2.81 亿股
行业：高端装备特钢材料与零部件（风电 / 能源装备 / 航空航天 / 核电）｜ 板块：科创板
数据基准：2026 年半年度报告（2026-08-25 披露）+ 公开政策与行业资料。

第一步：公司是干什么的？

一句话定位：专注高品质特种合金材料的高新技术企业，产品横跨风电机械部件、能源装备铸锻件、特殊合金，是"特钢材料 + 高端装备零部件"双轮驱动的重资产制造平台。

主要客户 / 下游：新能源风电（整机厂及零部件）、能源电力装备（德阳基地铸钢件）、轨道交通、机械装备、军工装备、航空航天、核能电力、海洋石化。子公司布局：广大特材本部 + 鑫盛智造（精密加工）+ 如皋 + 德阳三大基地。

结构看点：传统风电铸件 / 主轴受行业装机波动拖累（鑫盛智造风电齿轮箱零部件亏损 5220 万），而德阳基地能源电力装备铸钢件保持盈利；特殊合金、核电转子、航空航天材料已实现批量供货，是未来增量。

（3）产业链传导

上游：废钢、铁合金、镍、钼等特钢原料。2026H1 铁水熔炼配方调整试验取得突破（压缩熔炼成本），部分对冲原料波动。上游成本随黑色系周期波动，传导率中等（长约 + 成本加成部分转嫁）。

下游：风电整机厂（交付节奏决定订单）、能源电力（德阳基地）、军工 / 航空航天 / 核电（认证后粘性高）。2026H1 风电新增装机下滑致下游需求走弱，订单交付量锐减。

议价权结论：风电端弱、特钢 / 新业务端中等，整体中等偏弱。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：特钢原料（废钢 / 镍 / 钼）占成本大头，风电零部件长约定价 传导率约 0.4–0.6（成本加成部分转嫁，过剩时自扛）。依据：2026H1 毛利率同比 -7.21pct 至 13.50%，成本端承压明显但非全损。
  • 因子2 毛利结构再平衡：合金制品（毛利率受风电拖累低）占 67%，合金材料占 32%。风电铸件毛利率塌缩拉低综合，而德阳能源电力铸钢件、特殊合金 / 核电 / 航空（高毛利）占比提升可再平衡结构。单一"综合毛利率 13.50%"掩盖了新业务高毛利增量。
  • 因子3 库存与采购节奏：铁水熔炼配方调整为低成本采购 timing；风电订单后置致库存与产能利用波动。需区分"低价熔炼收益"与"真实盈利"。
  • 因子4 政策 / 市场锚点（原料成本驱动变量）：① 市场层——黑色系 / 镍钼价格周期；② 政策层——能耗双控（特钢高耗能，抬升成本）、出口管制（镍等战略金属）、绿色制造补贴（降成本）。情景：原料高位 → 毛利率承压 12–13%；原料回落 + 大兆瓦放量 → 修复至 15–17%。验证点：上海有色镍 / 钼价、公司季度毛利率。

本因子输出喂给第四步毛利率假设：风电铸件中性毛利率 14–16%，特殊合金 / 新业务 18–22%。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：特钢 / 风电铸件产能行业居中，大兆瓦铸件技术储备领先；
  • 需求侧份额：风电整机厂认证周期长、粘性高；
  • 技术代际差：大兆瓦（18–26MW）铸件 / 主轴技术领先；
  • 成本曲线：模锻工艺 + 熔炼配方优化左移成本；
  • 份额加速度：海上风电翻番驱动大兆瓦份额提升。
    → 三档：保守（风电守成）/ 中性（海上风电份额提升）/ 乐观（风电强复苏 + 大兆瓦抢占）。
  • 层2 扩展业务：主业迁移空间（特钢 → 核电/航空/能源）：能力可迁移性高（同属特钢冶炼锻造）；新 TAM（核电 / 航空 / 石油高端合金）弹性中高；客户认证门槛高（已跨过：17-4PH、N07041 批量）；信号验证（已批量供货）。→ 已过验证点，可计入中性增量，但当前体量小，保守计。
  • 层3 证伪信号：风电装机继续下滑 / 毛利率破 12% / 新业务订单未放量 / 高负债致财务费用恶化。命中则下调。

第四步：估值锚定（自下而上，非增速外推）

方法声明：本报告业绩预测采用自下而上订单 / 产能推导，非历史增速外推。分风电主业 + 特殊合金/核电/航空新业务两条线，并用"十五五"风电规划与已批量供货订单校验。给三情景，目标价取中性。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（破净原因必须说明）：公司破净（PB 0.83x）原因：① 资产盈利能力差——2026H1 ROE 仅 0.26%、净利率 1.77%，周期底部盈利薄；② 资产专用性强——特钢冶炼 / 风电铸件设备不能转产，清算价值 << 账面；③ 无金融资产未重估型"真破净"（未持上市公司股权）。→ 破净是公允定价，非低估、非安全边际，不得单凭 PB<1 推大空间。
  • 校正2 周期位置校正：风电零部件当前处于周期底部 / 弱复苏（2026H1 新增装机下滑拖累交付）。中性净利 3.1 亿采用周期归一化（正常年份净利率 5–6%），而非单年 0.35 亿微利外推，亦非顶点年化。当前位置：底部偏左，不过度悲观。
  • 校正3 杠杆下行情景：特钢重资产，资产负债率偏高（历史约 55%–65% 区间），经营 + 财务杠杆双高。悲观情景（需求下行 + 利率上行 → 净利降至 1.5 亿、空间 −55.2%）已体现，该负面情景使空间转负，故不得标"重点关注"，至多"纳入观察"且注明高贝塔属性。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低（周期底部定价）。现价 14.32 元对应 PB 0.83x、2029 中性 PE 约 13x，但破净本质是盈利薄而非资产低估。

安全边际：
- 中性远期 15.32 元 → 空间 +7.0%，不达"重点关注" >50% 门槛（且杠杆下行情景转负）
- 悲观 6.42 元 → 下行 −55.2%（高负债 + 需求下行）
- 乐观 25.67 元 → +79.3%（风电强复苏 + 新业务放量）
- 下行保护：PB 0.83x 提供一定账面支撑，但资产专用性削弱清算价值

介入条件：
1. 观察建仓：现价附近可小仓位布局，但需确认风电复苏信号
2. 加仓信号：① 风电新增装机同比转正、公司风电订单环比持续回升；② 核电 / 航空 / 石油高端合金营收占比跳升至 15% 以上；③ 毛利率连续两季 >15%
3. 撤离信号：资产负债率突破 70%、毛利率破 12%

最大风险：
1. 风电装机复苏不及预期（核心变量）
2. 高负债（特钢重资产）在利率上行时财务费用反噬
3. 鑫盛智造风电齿轮箱零部件持续亏损拖累
4. 特钢行业产能过剩、年降压力持续

结论：纳入观察（风电"十五五"万亿投资托底 + 核电/航空新业务已批量供货，逻辑成立但当前处周期底部、破净为公允定价，需等风电装机复苏拐点与高毛利新业务占比跳升验证；属高贝塔周期反转期权）

注：若 2027 起风电装机强复苏 + 新业务放量使 2029 净利向乐观 4.5 亿靠拢，则具备上调至"重点关注"条件。
