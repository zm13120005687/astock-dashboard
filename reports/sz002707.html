第一步：公司是干什么的？

一句话定位：国内出境游批发 + 零售 + 整合营销龙头，为终端游客与政企客户提供"资源采购—产品设计—地接交付—营销服务"一体化旅游服务。

（3）产业链传导

上游（成本端）：机票、酒店、地接为可变成本，旅行社无定价权、转嫁有限；规模采购享折扣但难完全对冲旺季涨价。
下游（收入端）：终端需求受收入预期、签证、地缘影响；长线/小众目的地溢价高。
议价权：中偏弱——毛利率仅 12% 佐证，对上游资源方议价有限，靠产品设计与规模采买维持。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：机票/酒店占成本大头，转嫁系数≈0.3–0.4（旺季成本上涨仅部分转嫁，余下吃毛利）。依据：H1 净利率降至 0.69%、毛利率微升但费用率升，说明成本未充分转嫁。
  • 因子2 毛利结构再平衡：分业务毛利率——批发 12.18%、零售 15.33%、整合营销 8.99%、其他 89.78%。零售毛利率显著高于批发，结构向零售倾斜（零售 +20.66%）可小幅抬升综合毛利；但批发占 70% 主导，结构改善有限。
  • 因子3 库存与采购节奏：旅游无实物库存，但"包机/包位"提前锁资源属看涨期权——旺季前低价锁位收益、淡季接货损失；H1 费用率升部分源于前置资源投入，需区分一次性与持续。
  • 因子4 政策/市场锚点：免签扩容（巴西/中亚）= 需求驱动变量（正面，验证点：赴相关目的地客流）；地缘冲突（中东）= 目的地风险（负面，验证点：赴中东客流）；汇率（人民币升值）降出境成本、利好需求。

第三步进阶：份额变量与主业迁移空间（三层）

  • 层1 市场容量×份额变量：出境游总盘 2026H1 +10.7%，众信长线预订 +100%+（份额提升锚：免签目的地先发 + 产品矩阵）。五档锚：①供给侧重庆/云南资源方合作；②需求侧前五大客户占比低、散客为主；③技术代际：产品力中等；④成本曲线：规模采买左侧；⑤份额加速度：正（验证点：下季度出境营收增速、零售同店）。
  • 层2 主业迁移空间：旅行社能力→文旅目的地营销/入境游（新 TAM），认证门槛低、竞争激烈，属中期期权，未过验证点不计入中性。
  • 层3 证伪信号：机票/酒店成本大涨致毛利率破 11%、零售同店转负、出境客流增速<5%。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。现价已反映 2029 乐观情景附近的预期。
安全边际：中性远期 3.27 元 → 空间 −35.0%；悲观 1.44 元 → −71.4%。下行远大于上行。
介入条件：回落至 3.0 元以下（2026E PE<25x）且零售/整合营销高毛利占比持续提升验证。
最大风险：① 净利率长期低于 1.5%（低毛利商业模式）；② 地缘/签证逆转；③ 在线平台分流零售。
结论：暂不介入

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：中小旅行社出清，众信份额提升 → 验证点：CR5 提升、批发毛利率破 13%。
  • B 政策反转期权：免签进一步扩容至欧美 → 重估弹性，未过验证点仅机会情景。
  • C 市场错杀修复：若情绪错杀至 3 元以下（PB<3.5），修复触发点：出境数据持续高增。
  • D 技术/主业迁移：入境游+文旅目的地营销从 0 到 1，硬验证点=入境营收占比>5%、文旅订单落地。
