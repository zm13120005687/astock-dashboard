第一步：公司是干什么的？

一句话定位：国内锂电涂布模头龙头（国产化替代），平台化布局"新能源+泛半导体"——核心产品为涂布模头及智能装备（锂电、钙钛矿、显示面板、半导体封装）、储能系统（集中式/工商业/用户侧），并向固态电池干法/湿法设备延伸。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：高端模头/涂布装备技术壁垒高，传导率 ≈0.7–0.9（可转嫁）；储能系统（PACK）竞争红海，传导率 ≈0.3（自扛）→ 能源系统毛利率仅 7.90%。
  • 因子2 毛利结构再平衡：涂布应用 37.05% / 能源系统 7.90% 极致分化。禁单一综合毛利率（H1 22.19% 掩盖储能塌陷）。盈利修复靠涂布占比提升+储能毛利修复。
  • 因子3 库存与采购节奏：存货占总资产 32.35%（约 15.7 亿）——储能电芯/材料库存，若电芯跌价则接货损失/减值；采购 timing 风险高。
  • 因子4 政策/市场锚点：① 容量电价（储能收益锚，上行）；② 电芯价格（成本锚，2025 紧缺致确收放缓）；③ 风险：储能价格战持续。验证点：电芯价格、储能确收、存货周转；证伪：存货减值扩大。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：模头国产替代，曼恩斯特技术领先（4 米模头）。
  • 需求侧：锂电+钙钛矿客户认证粘性高。
  • 技术代际：涂布装备处国产前列（代际领先海外部分）。
  • 成本曲线：规模+良率，左移。
  • 份额加速度：泛半导体新签订单 +明显，份额提升。
    → 三档：保守（营收 8 亿）/中性（10 亿）/乐观（13 亿+钙钛矿量产）。验证点：季度新签订单/确收。
  • 层2 扩展业务：主业迁移空间：由锂电模头向钙钛矿/显示/半导体涂布迁移（能力同源：精密涂布），新 TAM（钙钛矿 28.7 亿美元+显示）大；认证门槛高（面板/半导体）。信号验证中（GW 级订单突破）。中期期权，部分计入乐观。
  • 层3 证伪信号：储能确收续停滞、存货减值扩大、泛半导体订单未规模化。命中则下修。

第四步：估值锚定（自下而上，正常化净利润法）

方法：亏损股无正 PE 可锚，用正常化净利润法——估稳态营收（涂布恢复+储能部分修复）→ 保守正常化净利率 → × 远期合理 PE。钙钛矿/固态期权不计入中性。

亏损股三问

  1. 为什么亏：能源系统类收入 −83.02%（储能电芯紧缺/价格波动致订单交付与确收节奏放缓）+ 管理/研发费用刚性 + 信用减值 1857 万 + 公允价值变动收益缩减（1214 万→119 万）。属业务结构失速（储能）+ 费用刚性，非资产减值一次性。
  2. 靠什么扭亏，触发时点：① 20 亿在手订单确收（泛半导体/涂布主导）；② 涂布应用持续回增（H1 +9.41%）；③ 泛半导体/钙钛矿订单规模化。触发时点 2026H2–2027（订单转化确收）。
  3. 亏得起吗：净资产 26.01 亿、总资产 48.55 亿，但经营现金流 −4.15 亿（H1 大额流出）、存货 15.7 亿（32.35% 总资产，去化/减值风险）。账面厚但现金流承压；已完成两期回购（258.68 万股）显信心。短期靠资产厚度支撑，但现金流为首要风险。

第四步进阶：重资产/周期股校正（三道闸）

  • 校正1 资产质量折扣：PB 1.78 未破净，但存货 15.7 亿（占资产 32%）若跌价则净资产虚高；非"破净伪空间"，但须盯减值。
  • 校正2 周期位置：处下行/筑底（储能失速+锂电设备周期低谷），中性净利取保守正常化 9%，非单年好年景（2023 峰值 43% 净利率不 extrapolate）。
  • 校正3 杠杆下行：资产负债率约 46%，经营现金流 −4.15 亿 → 下行情景（悲观 −88.3%）转负，不得标大空间；无高负债破产但现金流风险高。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（相对正常化）。现价 32.14 对应正常化稳态仅 11.7–16.3 元，市场定价含"20 亿订单+泛半导体"高预期。

安全边际：中性远期 16.26 元 → 空间 −49.4%（无安全边际）；乐观 33.35 元（+3.8%）即现价附近，说明当前已 price-in 订单兑现。下行保护弱（PB 1.78 但未破净、现金流为负）。

介入条件：等单季归母转正（验证扭亏）+ 能源系统确收恢复 + 存货去化；届时若回落至 16 元以下（正常化 26x 以下）再考虑。

最大风险：① 储能确收续停滞；② 存货跌价（15.7 亿）；③ 经营现金流持续大额流出；④ 泛半导体订单规模化不及预期。

结论：暂不介入

亏损扩大 + 正常化估值远低于现价（中性 −49.4%）+ 现金流大额流出，不满足重点关注/纳入观察。但 20 亿在手订单+泛半导体新签订单 +50% 提供清晰扭亏路径（非"确无扭亏可能"），故不判坚决回避；需等单季扭亏验证。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：锂电设备出清，模头国产替代份额提升（曼恩斯特技术领先）。验证点：份额升；证伪：流失。
  • B 政策反转期权：容量电价+储能收益修复，能源系统确收恢复。验证点：储能收入回正；重估至乐观 33.3 元。
  • C 市场错杀修复：若错杀至 16 元以下（正常化 <26x），修复弹性大。
  • D 技术突破/代际跃迁：钙钛矿 GW 级涂布+固态电池设备从 0 到 1 量产。硬验证点：中试良率达标+客户定点+量产成本优；未过验证点仅作机会情景。
  • 上调至"纳入观察"条件：连续两季归母转正 + 能源系统确收恢复 + 存货周转改善（减值可控）。
