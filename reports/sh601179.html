第一步：公司是干什么的？

一句话定位：国内唯一具备特高压交直流一次设备成套交付能力的央企龙头，主营变压器、高压开关（GIS）、换流阀、电力电子器件，产品覆盖特高压全品类，是国内约 80% 国家级特高压重点工程的核心主设备供应商。

（3）产业链传导

上游：铜、硅钢片、钢材。公司央企属性 + 特高压订单长协定价，成本传导弹性高（毛利连升佐证）。研发费用 6.90 亿（+59.88%）投向电力电子等先进方向。

议价权：网内强（特高压独家成套能力），海外单机出口议价权提升（缺货周期）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：特高压 / 国网订单定价权强，硅钢、铜涨价可通过长协 + 调价条款部分转嫁。实证：综合毛利率从 2022 年 16.43% → 2025 年 22.6% → 2026H1 24.54% 连续抬升，传导率偏高（估 0.7–0.9）。验证点：各季毛利率走势；证伪：招标竞价致毛利率破 22%。
  • 因子2 毛利结构再平衡：变压器（毛利 18.43%）+ 开关（27.32%）+ 电力电子（分部净利 13.8%）敏感度不同。高毛利的开关 / 电力电子占比提升 + 特高压高毛利订单结构改善，推动加权毛利上行。禁止用单一综合毛利率掩盖结构迁移。
  • 因子3 库存与采购节奏（timing）：2026H1 存货 62.82 亿（+26%）为交付备货（合同负债 62.25 亿 +17% 佐证订单饱满），非低价囤货收益；经营现金净流出 2.97 亿系主动加快付款保供应链，非经营恶化（公司 IR 确认）。
  • 因子4 政策 / 市场锚点：① 市场层——全球变压器短缺、铜价周期；② 政策层——美国加征关税仍挡不住抢购（对美出口 +200%，量价齐升）；碳双控抬升高耗能料成本；出口管制（高端 SiC）影响 SST 成本。列为情景变量。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：特高压 CR5 ~70.8%，西电市占 17.5% 居首（换流变 29% / 换流阀 15% / GIS 25%）；
  • 需求侧：十五五特高压规模翻倍 → 份额稳守即增量；
  • 技术代际：全电压等级成套能力领先一代；
  • 成本曲线：规模 + 智慧产业园降本；

  • 二阶导数：特高压仍在渗透率上行期（十五五新工程）。
    → 三档：保守守住 17% / 中性 17–18% / 乐观抢份额至 20%+（验证点：下批中标公告）。

  • 层2 扩展业务：主业迁移（SST = 新易盛范式）

  • 能力可迁移：高压大功率电力电子同源（特高压换流阀技术迁移至 SST）；
  • 新 TAM：AI 数据中心 800V 供电，市场数倍于传统输变电；
  • 卡位：北美 AIDC 首单（国产 SST 海外商业化零突破）；
  • 认证：海外数据中心客户定点 + 西高院检测能力；

  • 信号：4 台订单 + 适配英伟达 800V HVDC 的 SST 已完成研制。
    → 中期期权，未过"批量交付 + 量产成本优于旧路线"验证点，不计入中性情景。

  • 层3 证伪信号：SST 量产成本打不过旧路线 / 客户流失 / 政策退坡早于量产 / 特高压核准不及预期 → 下调增量。

第五步：综合赔率判断（买不买？）

当前价格位置：略贵，已反映高增长。现价 12.56 对应 2026E PE 41x，高于基准合理价 12.1 元；市场已把"十五五"特高压 + 出海 + SST 预期部分定价。

安全边际：
- 中性远期 15.6 元 → 空间 +24.2%，不达"重点关注"的 >50% 门槛
- 悲观情景 10.5 元 → 下行 −16.4%，PB 2.75x 提供一定支撑，风险不对称偏温和
- 乐观情景 21.8 元 → +73.6%，需 SST 放量 + 特高压超预期

介入条件：
1. 不追高。现价已反映 2026 年业绩，等回落至 11 元以下（2026E PE < 35x）才具安全边际
2. 加仓信号：① 特高压新批工程超预期（"三直四交"以上）；② SST 拿到批量订单 / 客户定点公告；③ 海外单机出口金额披露且规模跳升
3. 观察指标：逐季合同负债与毛利率——若合同负债回落或毛利率跌破 22%，中性情景需下修

最大风险（最可能破坏逻辑的因素）：
1. 电网投资 / 特高压核准节奏不及预期（首要）：中标尚未签正式合同，条款存不确定性
2. 招标竞价加剧致毛利率下行：CR5 集中但价格战风险存在
3. 出海与 SST 商业化不及预期：SST 收入占比仍 <2%，处于早期
4. 估值高位回调：近 60 日已 −22.7%，PE(TTM) 47x 仍不低

结论：纳入观察

理由：中性远期空间 +24.2% 不满足"重点关注">50% 门槛；现价已高于基准合理价，安全边际有限。但公司是特高压一次设备真龙头（市占居首、成套能力唯一），"十五五" + 出海 + SST 期权构成真实上行，质地优秀。机会在于回调至 11 元以下或 SST / 特高压超预期兑现后上调至重点关注。
核心跟踪点：特高压新批工程节奏 + SST 批量订单 / 客户定点 + 海外单机出口金额。

第五步进阶：上行想象力情景（调整型机会，与下行校正对称）

  • 类型A 行业调整剩者红利：特高压 CR5 ~70.8% 高集中，西电居首；十五五投资翻倍 + 集中度提升 → 剩者份额与定价权红利。验证点：各批中标份额；证伪：份额跌破 15%。
  • 类型B 政策反转期权：电网投资加码已是利好（非"反转"），暂不列为反转型。
  • 类型C 市场错杀修复：近 60 日 −22.7% 回落，估值从高位消化；若市场企稳、风格回归央企红利，修复弹性大。验证点：估值分位回落 + 基本面未恶化。
  • 类型D 技术突破 / 代际跃迁（SST）：政策（AI 供电）+ 趋势（800V HVDC）+ 落地（4 台海外订单 + 800V 研制）三要素共振，弹性极大；硬验证点仅部分满足（未达中试良率批量 / 客户定点 / 量产成本优于旧路线全验证）→ 仅作机会情景，不计入中性锚。证伪：量产成本打不过旧路线 / 客户流失 / 政策退坡。

纪律：想象情景只进"乐观 / 机会"栏，不进中性锚；每类配验证点 + 证伪信号；明确"什么条件出现才上调至重点关注"——SST 批量订单落地或特高压超预期致中性空间 >50%。
