分析日期：2026-09-16 ｜ 现价 3.67 元（2026-09-15 收盘） ｜ 总市值 约 68.7 亿 ｜ PE(TTM) −9x ｜ PB 约 1.56x ｜ 总股本 约 18.73 亿股

议价权：弱（各业务均处过剩/买方市场，煤焦油深加工毛利率仅 0.3%、石墨电极负毛利、光伏边框被动降价）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子 1 成本传导弹性（pass-through）：煤焦油涨价（原料）→ 传导率 ≈ 0.2–0.3（弱），深加工毛利率被压缩至 0.3%；石墨电极对针状焦涨价传导也弱（负毛利）。整体议价权弱，成本难转嫁。
  • 因子 2 毛利结构再平衡：煤焦油深加工（收入占 44% 但毛利率 0.3%）与石墨电极（毛利率 −5.6%）为两大拖累，光伏边框（−86.82%）急剧萎缩。各业务毛利率分化剧烈，禁止用单一综合毛利率 1.54% 掩盖结构问题——实际是"煤焦油微利 + 石墨电极/光伏亏损"的结构。
  • 因子 3 库存与采购节奏（timing）：煤焦油价格高位，高价接货风险（当期毛利承压）；负极石墨化自供（梅山湖收购）可对冲外协涨价。2026H1 经营现金流 −2024 万（同比改善 2.43 亿），现金流压力边际缓解。
  • 因子 4 政策/市场锚点：十五五储能 3 亿千瓦（利好但项目延后）、独立储能容量电价（利好长时储能）、能耗双控（石墨化高耗能）。验证点：储能项目开工恢复、石墨电极价格企稳回升、针状焦价格走势。证伪信号：石墨电极负毛利持续、煤焦油深加工毛利率转负、光伏边框收入进一步萎缩。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层 1 现有业务（市场容量 × 份额变量）：
  • 供给侧份额：石墨电极行业产能过剩，公司通过"链主+工厂制"（开封炭素统一调度）整合多基地；负极二三线，全国产能过剩。
  • 客户份额：石墨电极客户为钢厂（分散），负极客户电池厂（集中），光伏边框客户组件厂。
  • 技术代际差：全钒液流电池、煤系碳纤维处技术探索期，主流业务（石墨电极/负极）无代际领先。
  • 成本曲线位置：梅山湖收购（电价/天然气优势）+ 煤焦油一体化，成本曲线左移，但尚未验证规模效应。
  • 份额二阶导数：多数业务份额在萎缩（光伏边框 −86.82%、石墨电极 −21.53%），处 S 曲线下行段。
    → 份额假设：保守（守住煤焦油 + 负极基本盘）/ 中性（梅山湖并表 + 储能恢复，营收企稳 35 亿）/ 乐观（储能 3 亿千瓦目标兑现 + 负极涨价，营收回升 45 亿），验证点为石墨电极价格与储能项目开工。
  • 层 2 主业迁移空间（煤焦油深加工 → 高端碳材料/碳纤维）：能力可迁移（碳材料技术同源），煤系碳纤维 TAM 弹性大，但处研发探索期，未过验证点，仅作中期期权，不计入中性。
  • 层 3 证伪信号：石墨电极负毛利持续、光伏边框收入归零、储能项目持续延后、梅山湖收购失败、碳纤维中试失败。

第四步：估值锚定（自下而上，非增速外推）

方法说明：易成新能真实持续亏损，采用正常化净利润法（估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价），并交叉重资产 PB 校正。严禁用历史增速外推（2023 年营收 98.84 亿为剥离前口径，不可作基数）。

总股本：约 18.73 亿股（每股净资产 2.36 元，2025 年报；资产负债率 63.05%，有息负债 38.7 亿）

第四步进阶：重资产/周期股估值校正

  • 校正 1 资产质量折扣（破净原因）：现价 PB 1.56 倍未破净，但存在破净风险——净资产 43 亿中含大量专用性资产（石墨电极产线、光伏边框产线），专用性强、清算价值远低于账面；且煤焦油深加工（毛利率 0.3%）等资产盈利极弱，PB 1.56 倍是"盈利差 + 专用资产"下的高估，非真便宜。若持续亏损侵蚀净资产，PB 可能被动抬升或走向破净。
  • 校正 2 周期位置校正：石墨电极（负毛利，周期底部）、负极（涨价周期，回暖）、光伏（深度过剩，底部）、煤焦油（原料高位、微利）。公司整体处周期底部偏左，正常化净利已用保守（未用单年好年景/拐点年化，未用 2023 年剥离前 98.84 亿营收）。
  • 校正 3 杠杆下行情景：资产负债率 63.05%、有息负债 38.7 亿（高）。利率上行/需求下行负面情景：若石墨电极/光伏继续亏损 + 财务费用高企，净利进一步跳负、净资产被侵蚀，空间转负（悲观情景 −54.2%）。该负面情景使空间转负，不得标"重点关注"。
  • 期权纪律：煤系碳纤维、储能铝型材、梅山湖收购等未过验证点期权，不计入中性净利。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 3.67 元对应 PB 1.56 倍，对连续亏损、负债率 63%、净资产盈利质量差的周期股而言偏高。

安全边际：
- 中性远期 2.51 元 → 空间 −31.6%，远期空间为负
- 悲观 1.68 元 → 下行 −54.2%
- 乐观 2.99 元 → −18.5%，即使乐观情景也无正空间
- 下行保护：国资背景（平煤神马）提供融资与重组支撑，但非估值底线

介入条件：仅当股价回落至 2.20 元以下（对应 PB 0.95 倍、接近破净）才具观察价值；需同时满足：① 石墨电极毛利率转正（价格企稳）；② 储能项目招标/开工恢复；③ 梅山湖收购完成并表且降本见效。

最大风险（最可能破坏逻辑的因素）：
1. 持续大额亏损侵蚀净资产（首要）：2026H1 已亏 2.89 亿（增亏 70%），石墨电极（−5.6%）与光伏边框（−86.82%）短期难扭转，若亏损延续，净资产缩水、PB 被动抬升。
2. 财务杠杆反噬：负债率 63.05%、有息负债 38.7 亿，经营+财务杠杆双高，下行时净利几倍跳负。
3. 业务过杂、缺乏聚焦：六大板块均处周期底部或过剩，无一强盈利支柱，转型方向（碳纤维/储能）不确定。
4. 储能项目持续延后：十五五 3 亿千瓦目标兑现节奏慢于预期。

第五步进阶：上行想象力情景（仅进乐观栏，不进中性锚）

  • 类型 A 行业调整剩者红利：石墨电极/负极行业出清后，梅山湖低成本产能 + 煤焦油一体化使成本曲线左移，若二三线产能退出，公司份额与盈利中枢跳升。验证点：石墨电极价格持续回升、行业 CR5 提升；证伪：石墨电极毛利率长期为负。
  • 类型 B 政策反转期权：储能 3 亿千瓦目标 + 独立储能容量电价若加速兑现，储能板块（锂电 + 全钒液流）从延后转恢复。验证点：储能项目招标放量公告；证伪：项目持续延后。
  • 类型 C 市场错杀修复：当前非错杀而是基本面恶化；若系统性恐慌跌至 2 元以下（PB 0.85 倍）或构成修复机会。
  • 类型 D 技术突破期权：煤系高性能碳纤维、全钒液流电池若中试跑通 + 客户定点 + 量产成本优于旧路线，可打开全新曲线。硬验证点：中试良率达标 + 客户定点 + 量产——三者缺一，仅作机会情景，不计入中性。

上调"重点关注"条件：需同时出现——① 股价回落至 2.20 元以下；② 石墨电极毛利率转正 + 储能项目恢复；③ 梅山湖并表降本见效。当前无一满足。

结论：暂不介入（远期空间 −31.6%，为负，按规则负空间应判"暂不介入"）

理由：易成新能真实持续亏损（2026H1 归母 −2.89 亿、增亏 70%），主业六大板块全面承压（石墨电极负毛利、光伏边框 −86.82%、储能延后），仅煤焦油深加工微利（毛利率 0.3%）。重资产 + 高负债（63.05%）+ 连续亏损，正常化净利润法 + PB 校正测算远期目标价 2.51 元，远期空间 −31.6%。核心跟踪点：石墨电极毛利率转正 + 储能项目恢复 + 梅山湖并表。
