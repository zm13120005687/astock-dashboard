第一步：公司是干什么的？

一句话定位：血液制品企业（派斯菲科 + 双林生物整合），主营白蛋白、静丙、凝血因子类等血液制品的研发生产销售，拥有浆站资源壁垒，受 2026 行业政策与税负双重压制但牌照稀缺属性未变。

（3）产业链传导

上游：血浆（献浆人群，原料稀缺，企业难取得进项抵扣 → 增值税改革直接侵蚀利润）。

下游：医院终端（集采/医保控费压价）；需求刚性（重症/免疫/罕见病）但短期处方收缩。

议价权：浆站牌照稀缺赋予中长期强壁垒，但短期政策压制下弱（被迫降价走量）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：血浆成本刚性（传导率≈0）；增值税改革（3%→13%）使每瓶税负 +10pct，完全无法转嫁 → 毛利直接承压。验证点：毛利率（H1 32.92% -14.71pct）；证伪：税负政策回调。
  • 因子2 毛利结构再平衡：白蛋白（量大、价跌）、静丙（高附加值、亦跌）、凝血因子（高毛利占比小）。结构向高附加值迁移可缓冲，但短期全线下行。
  • 因子3 库存与采购节奏：血浆库存（投浆周期）影响成本 timing；增值税改革为一次性结构冲击。
  • 因子4 政策/市场锚点：集采（政策层）、采浆量（市场层）。情景：集采周期结束（2028.12）+ 税负政策调整 → 毛利修复。验证点：产品中标价、浆站采浆量。

输出喂第四步：中性净利率取保守恢复值 15%。

第三步进阶：份额变量与主业迁移空间

  • 层1 份额变量：浆站数量/采浆量决定份额（供给侧锚点）；行业采浆 +10% 公司受益。中性：采浆稳步增；乐观：新浆站获批加速。验证点：公司采浆量公告。
  • 层2 主业迁移：重组/高附加值产品（如纤原、凝血因子Ⅷ）提升吨浆产值，新 TAM 有限，属存量升级。未过验证点不计入中性。
  • 层3 证伪信号：集采续降价、税负不调、采浆成本升、处方量续缩。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价对应 2026E PE 44.9x，血制品虽稀缺但短期盈利承压，估值未充分反映政策压制。

安全边际：
- 中性远期 11.05 元 → +11.4%（>0，<50%）
- 悲观 5.79 元 → −41.6%
- 乐观 18.95 元 → +91.0%（浆站放量 + 出海）
- PB 1.17x 提供一定缓冲

介入条件：
1. 回落至 8 元以下（2026E PE < 38x）具安全边际
2. 加仓：H2 净利验证前低后高、集采周期见底信号、税负政策松动
3. 观察：采浆量、产品中标价、毛利率能否企稳

最大风险：
1. 集采续降价 + 增值税改革压制毛利（首要）
2. 行业采浆放量致供过于求、价格战
3. 终端处方量持续收缩

结论：纳入观察（牌照稀缺 + 长期需求，但短期政策压制致空间有限）

第五步进阶：上行想象力四类情景

  • A 行业调整剩者红利：浆站牌照壁垒 → 中小企业退出，头部份额提升。验证点：行业集中度、公司采浆份额；证伪：并购逻辑遇冷。
  • B 政策反转期权：集采周期 2028.12 结束 + 税负政策调整 → 毛利修复。验证点：政策发文/纠偏；触发上调重点关注条件：集采续约降价幅度收窄或增值税优惠恢复。
  • C 市场错杀修复：H1 净利腰斩致估值恐慌，若 H2 前低后高兑现则修复。验证点：H2 财报。
  • D 技术突破/出海期权：重组血制品、国际注册出口（当前 0.32%）。硬验证点：海外大订单/新品类获批；未过验证点仅作机会情景。
