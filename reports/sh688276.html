第一步：公司是干什么的？

一句话定位：长春高新旗下的人用疫苗平台，国产带状疱疹疫苗首家获批者，拥有水痘、鼻喷流感、带状疱疹三大核心品种，并布局百白破、狂犬、HSV-2、重组带状疱疹等 16 项在研管线。

（3）产业链传导

上游：培养基、佐剂、包装材料等，供应商分散、成本占比小，议价权强（毛利率 78% 印证）。

下游：接种端受支付意愿与渠道库存影响。公司主动对带状疱疹降价提升可及性，属"以价换量"策略。

议价权判断：对上游强；对下游（疾控/消费者）中等——靠品牌与首发优势，但面临竞品（智飞/GSK 等）挤压。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数）：疫苗原料成本占比低（<15%），毛利率 78%，成本波动对毛利影响极小，转嫁系数近似 1（成本端非主要矛盾）。
  • 因子2 毛利结构再平衡：水痘（85% 毛利，现金牛）+ 带状疱疹（80%，价降量升）+ 鼻喷流感（75%，新放量）。结构变化：高毛利带状疱疹占比因降价略降、鼻喷流感占比升。综合 78% 毛利稳定，但净利被 33.7% 研发费用率吞噬——毛利结构稳、费用结构才是痛点。
  • 因子3 库存与采购节奏：疫苗效期管理严格，渠道库存公司主动管控（截至 Q1 库存合理可控），无囤货收益/接货损失显著 timing。
  • 因子4 政策/市场锚点：① 风险——价格治理/集采预期压价（验证点：省级采购价下行）；② 正向——出海关税友好（东南亚）、WHO GAP 背书（验证点：出口收入持续 +100%+）。

输出喂第四步：中性给稳态毛利率 75–78%，核心变量在费用率（研发/销售）能否随收入规模下降。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：带状疱疹国产首家，但竞品（智飞代理 GSK、其他在研）增多。
  • 需求侧：40 岁+ 渗透率个位数，量增空间大。
  • 技术代际：减毒活路线 vs 重组路线（公司在研重组），当前代际中不领先但成本优。
  • 成本曲线：自产成本低，降价后仍盈利。
  • 份额二阶导数：渗透率早期，份额随价格下沉加速提升。
    → 三档：保守（量微增覆盖降价，营收 +5%）；中性（量增 15%，营收 +10%）；乐观（出海+液体剂型，营收 +25%）。验证点：逐季出货量与批签发。
  • 层2 扩展业务：主业迁移空间：HSV-2 mRNA、重组带状疱疹属"老疫苗技术换新适应症"，能力可迁移（高），新 TAM 弹性大（全球 HSV-2 感染 4.91 亿），但临床早期、未过验证点，仅作中期期权不计入中性。
  • 层3 证伪信号：带状疱疹量增不及预期（价降量不升）、出口增速回落至 <50%、在研管线临床失败。命中则下修。

第四步：估值锚定（正常化净利润法，亏损股）

方法：亏损期无正 PE 可锚。估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价。并回答三问。

总股本：约 4.137 亿股

稳态营收与正常化净利（2029E·中性）

  • 稳态营收：2025 约 5.75 亿 → 2026E 约 6.2 亿 → 2029E 中性 9.5 亿（带状疱疹量增+鼻喷流感放量+出口持续，非增速外推，基于已上市品种放量节奏）
  • 正常化净利率：疫苗成熟品种 25% 附近，保守取 24%（费用率随规模回落但维持高研发）
  • 正常化净利 = 9.5 亿 × 24% = 2.28 亿
  • 远期合理 PE：创新疫苗平台 30–35x，取 32x
  • 目标市值 = 2.28 亿 × 32 = 73 亿 → 目标价 17.6 元

亏损股三问（必答）

  1. 为什么亏：带状疱疹疫苗主动降价（以价换量）+ 研发费用率高达 33.7% + 行业竞争/接种意愿不足 → 营收仅微增但费用高，H1 亏 5210 万（同比减亏）。
  2. 靠什么扭亏，触发时点：① 带状疱疹价格管理带动终端接种回暖、量增覆盖降价；② 液体鼻喷流感疫苗（8 秒接种、WHO GAP）2026 放量；③ 出口收入 +184% 持续（印度/印尼/巴基斯坦）；④ 在研 16 项梯次推进。→ 2026H2 单季接近盈亏平衡，2027 全年扭亏。
  3. 亏得起吗：净资产约 37.8 亿、经营现金流 +4836 万（转正、+418.9%）、账面现金+理财充裕（筹资流入 2.04 亿），半年仅亏 5210 万，完全撑得住，无持续经营风险。

- 中性远期 17.60 元 → 空间 −0.8%（基本合理）
- 悲观 5.90 元 → −66.8%；乐观 28.40 元 → +60.0%（管线+出海兑现）

介入条件：
1. 现价附近可小仓位观察，不追高
2. 上调至重点关注信号：① 单季归母扭亏确认；② 鼻喷流感液体剂型批签发/收入跳升；③ 出口收入连续两季 +100%+

最大风险：① 带状疱疹量增不及预期（价降量不升）；② 在研管线临床失败；③ 疫苗价格治理/集采压价；④ 行业接种意愿持续疲软。

结论：纳入观察（扭亏路径清晰、现金充裕能撑，但需单季扭亏确认；当前价格已反映 2027 恢复，上行靠管线期权）
