（3）产业链传导

上游：化工原料（树脂、颜料、电荷调节剂等）、铝基材（OPC 鼓）、电子元件。原料成本随大宗商品波动，公司推进原材料国产化替代降本。

下游：打印机 OEM 厂、政企办公、军工特种。OEM 客户强、议价权中等；政企国产替代采购溢价较高。

议价权量化：墨粉 / OPC 鼓国产龙头，对中小客户转嫁系数 ≈0.5；OEM 大客户压价，转嫁系数 ≈0.3。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（pass-through）：核心原料（树脂 / 颜料 / 铝基）占成本主体，对 OEM 大客户转嫁系数 ≈0.3（承压），对政企国产替代采购转嫁系数 ≈0.5。验证点：H1 主业毛利率 18.29%（−1.14pct），营业成本增速（+2.37%）快于收入（+0.94%），印证弱传导。
  • 因子2 毛利结构再平衡：分业务线——耗材主业 18.29%、精密加工 10.27%。信息安全复印机（高毛利新业务）占比提升可拉高结构毛利。禁单一综合毛利率：若高毛利信息安全复印机放量，加权毛利可上修 1–2pct。
  • 因子3 库存与采购节奏（timing）：公司推进原材料国产化替代 + 供应商考核，锁价降本；无显著囤货收益。H1 经营现金流骤降 98.39% 至 28 万，主因应收账款增加 + 存货，非库存收益（需跟踪回款）。
  • 因子4 政策 / 市场锚点：① 市场层——化工原料价格、铝价；② 政策层——"国货国用"20% 优惠（直接抬国产份额）、商务部进口设备安全调查（信息安全复印机替代）、国产化补贴。情景：国产替代加速 → 份额 + 毛利双升；证伪：进口设备调查未落地、原料大涨致毛利破阈。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：国内墨粉 / OPC 鼓产能集中，公司为双料量产龙头，份额稳。
  • 需求侧：OEM 大客户 + 政企框架采购（认证壁垒 = 粘性）。
  • 技术代际：国产适配性 / 质量稳定性领先一代。
  • 成本曲线：原材料国产化 + 规模效应使成本左移。
  • 份额加速度：国产替代处 S 曲线早期（政策驱动加速）。
    → 三档：保守守住（12 亿）/ 中性小幅提升（13.5 亿）/ 乐观抢份额（16 亿）。验证点：海外收入增速、政企框架采购中标、信息安全复印机订单。
  • 层2 扩展业务：主业迁移空间：从"通用耗材"迁移到"信息安全复印机 + 特种精密"——技术同源（成像 / 精密制造复用），新 TAM（信创 / 军工）溢价高，但客户认证门槛高（涉密资质）。信号验证：信息安全复印机营收占比——未过验证点（新业务），仅作中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：价格战致毛利破阈、海外拓展不及预期、进口设备调查未落地、应收账款减值扩大。命中则下调。

第四步：估值锚定（自下而上，非增速外推）

第四步进阶说明：① 资产质量折扣——PB 2.69x 未破净，净资产 15.15 亿以现金 / 经营资产为主，无隐性负债，非伪破净；② 周期位置——耗材属成熟稳定行业，非强周期，中性净利取稳态净利率 9.5%（非单年好年景）；③ 杠杆下行——负债率仅 8.9%，无高杠杆反噬风险。三道校正均不构成压制。

交叉校验：现价 13.78 元对应市值 40.8 亿，是中性目标市值 25.6 亿的 1.59 倍，TTM PE 约 36x（远高于成熟耗材合理 18–22x）。即便乐观情景（13.62 元）也仅与现价持平——当前价格已透支信息安全复印机国产替代期权。

第五步：综合赔率判断（买不买？）

当前价格位置：估值偏高。现价隐含 36x PE，而成熟耗材稳态合理 18–22x，溢价来自信息安全复印机期权。

安全边际：中性远期 8.65 元 → 空间 −37.2%；乐观 13.62 元（−1.2%）；悲观 6.22 元（−54.9%）。中性下行明显，上行需期权兑现。

介入条件：① 不追高，等回落至 9.5 元以下（对应市值 ~28 亿、接近中性目标）才具安全边际；② 加仓信号：信息安全复印机订单落地、海外收入占比突破 25%、经营现金流转正修复。

最大风险：① 耗材价格战持续致毛利破阈；② 经营现金流骤降（应收账款 / 存货）若持续恶化；③ 信息安全复印机订单不及预期（期权落空）；④ 进口设备安全调查未落地致替代延迟。

结论：暂不介入（基本面稳健、低负债、央企背景，但估值已高、盈利微降，需等信息安全复印机期权验证或价格回落至 9.5 元以下）。

公司质地优良（净现金、央企、国产替代 + 信创双催化），若信息安全复印机订单实质性放量（乐观情景 13.62 元附近），可上调至"纳入观察 / 重点关注"。当前不追高。
