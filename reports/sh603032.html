（3）产业链传导

上游：模具钢、硬质合金、陶瓷材料（致宏陶瓷模具核心）、精密加工设备。
下游：锂电池生产企业（比亚迪/宁德新能源/中创新航/蜂巢/清陶）、锂电设备制造商；光伏跟踪支架厂商；机器人本体厂。
议价权：中偏强（模具）/ 弱（减速器）。
- 佐证（强）：模具是产线关键耗材，停机损失大 → 客户价格敏感度低于供货稳定性；陶瓷模具寿命 3 倍于合金；深度参与头部电池厂新品开发，定制化粘性强
- 佐证（弱）：汉普斯减速器跟随光伏景气大起大落，2026H1 盈利下滑 → 议价权弱

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）
- 主要原料：模具钢/硬质合金/陶瓷粉体（占模具成本约 30—40%）；2026 年钢材与特种陶瓷价格总体平稳
- 传导率测算：2026H1 毛利率 +4.42pct（40.92%），而营收 +22.69%、Q2 营收仅 +3.91% → 毛利率提升主要来自规模效应（固定成本摊薄）与产品结构（高毛利模具占比上升），而非原料降价
- 模具属定制化 + 耗材 + 高切换成本 → 传导率 ≈ 0.7—0.8（高）：客户更在意稳定供货与毛刺控制，对小幅涨价不敏感
- 减速器属标准件 + 光伏强周期 → 传导率 ≈ 0.3—0.4（低）
- 验证点：分板块毛利率（致宏 vs 汉普斯）、模具钢/陶瓷粉体价格、公司调价公告
- 证伪信号：精密制造板块毛利率跌破 36%（价格战或从定制转向标准件）

因子2 毛利结构再平衡（分业务线，禁单一综合毛利率）

→ 关键洞察：单一"综合毛利率 40.92%"掩盖了两个反向力量 —— ①高毛利模具（43%）占比上升推升综合毛利率；②低毛利减速器（27%）放量拉低综合毛利率。中性情景下模具占比 58%、减速器 37% → 综合毛利率 35.1%，低于 2026H1 的 40.92%。这个"毛利率下行但净利上行"的结构，正是估值必须分业务测算的原因。

因子3 库存与采购节奏（timing）
- 生产模式：致宏"根据在手订单情况动态调整产能规划，适应交付需要"；汉普斯"根据客户需求动态调整产能"→ 订单驱动，无大规模囤货
- 存货周转率 1.06（H1），应收账款周转率 0.76（H1，年化约 1.5，偏慢——锂电客户账期长）
- 无库存收益虚增问题：净现比 102.05%，经营现金流与净利匹配
- 验证点：存货周转、应收账款账龄、经营现金流/净利比
- 证伪信号：净现比连续 2 期 < 70% → 收入质量恶化

因子4 政策/市场锚点（原料成本驱动变量）
- 锂电扩产节奏（决定性）：下游电池厂资本开支直接决定模具采购量；2026 年储能爆发是主要增量
- 固态电池产业化：半固态/全固态极片工艺与液态完全不同，裁切精度要求更高 → 若产业化，致宏技术壁垒进一步加固（但时点不确定）
- 光伏装机（汉普斯）：2026H1 国内新增装机 −66% → 回转减速器需求承压；"反内卷"政策落地有望使价格回归
- 出口/关税：公司推进海外拓展，若目标市场（欧洲/东南亚电池厂）加征关税或要求本地化 → 影响出口
- 情景：悲观（锂电扩产停滞 + 光伏持续低迷）→ 综合毛利率 31%；中性（储能驱动 + 光伏企稳）→ 35.1%；乐观（固态产业化 + 机器人放量）→ 38%
- 验证点：国内锂电池月度产量/装机、储能招标量、光伏月度装机、公司海外订单

本因子输出：2029E 中性综合毛利率 35.1%，喂给第四步。

层2 扩展业务 = 主业迁移空间

迁移类型1：锂电裁切模具 → 固态电池极片模具（B 类，老能力换新工艺）
- 能力可迁移性：高（同为极片裁切，只是精度要求更高）
- 新 TAM 弹性：固态电池产业化后，单 GWh 模具价值量可能提升
- 切入卡位：早期（清陶、卫蓝等试产线配套）
- 客户认证门槛：中（已有客户关系的固态企业可直接延伸）
- 信号验证：🔴 未过验证点 —— 2025 年相关收入占比不足 1%，公司明确"短期内不会对公司经营业绩产生重大影响"
