第一步：公司是干什么的？

一句话定位：A 股极少数"自己种地"的规模化农垦龙头——自主经营约 95.5 万亩耕地 + 约 40.7 万亩流转托管土地（合计超 130 万亩），把种出来的稻麦一部分直接卖原粮，一部分深加工成种子、大米、麦芽、食用油，再依托种植基地的规模采购优势对外做农资贸易与农技服务，形成"产前—产中—产后"全产业链闭环。

主要客户 / 下游：
- 种子：江苏及长三角种业经销商、农户；大华种业常规小麦种子销量全国第一、常规水稻全国第二，配套约 80 万亩标准化繁种基地。
- 大米：比亚迪、雪花啤酒、思念食品等头部 B 端客户（2026H1 新开拓）。
- 麦芽：百威、华润雪花，并布局精酿赛道与出口。
- 食用油：华东商超 / 电商 / 新零售渠道。
- 全农服务：苏北等传统优势区小农户与新型经营主体。

（3）产业链传导

上游：化肥（氮磷钾）、农药、柴油、种子原粮、进口大豆/菜籽。公司对上游的议价权呈结构性分化：
- 农资采购端：强——130 万亩规模集中采购，议价能力显著（这也是为什么公司要把农资做成对外销售的第二大业务）。
- 进口油料端：弱——大豆/菜籽对外依存度高，价格由 CBOT/国际供需决定，公司纯被动接受。

下游：粮商、加工企业、终端消费者。定价机制（公司调研原话）：
- 原粮销售：参考产地现货市场价格，随行就市 → 无定价权；
- 种子："成本 + 合理毛利"并结合品种稀缺性定价 → 有定价权；
- 大米等加工品：紧贴终端消费与品牌定位 → 弱定价权。

议价权总判断：综合中等偏弱。唯一种子业务具备"成本加成"定价能力，且毛利率 13.19% 显著高于其他板块——这解释了为什么公司战略重心正往种业迁移。

第二步进阶：原料成本 → 毛利结构传导（四因子）

本组核心原料：化肥（种植成本）、进口油料（食用油）、啤酒大麦（麦芽）。

因子1 成本传导弹性（pass-through）——把议价权量化为转嫁系数：

业务线 核心原料 传导率（估） 依据
农资贸易 化肥/农药（进货成本） 0.85–0.95 随行就市的贸易模式，进价涨则售价同步涨，属"过手"业务，毛利率 6.35% 稳定即佐证
种植（原粮/农产品） 化肥、柴油、人工、流转费 ≈ 0 售价由现货市场 + 最低收购价决定，公司零定价权；成本上涨 100% 自己扛
食用油 进口大豆/菜籽 0.40–0.50 终端品牌竞争激烈、商超渠道强势，涨价滞后且要打折传导；毛利率仅 3.25% 即"传导失败"的证据
种子 自产原粮 ≈ 1.0 "成本+合理毛利"定价，成本可 100% 加成转嫁

→ 加权结论：上游化肥每涨 10%，公司实际毛利承压 = 10% ×（1 − 加权传导率约 0.35）≈ 6.5% 直接吃毛利。这是 2026H1 毛利率同比 −0.72pct 至 11.31% 的结构性解释。

因子2 毛利结构再平衡——禁止用单一综合毛利率（11.31%）代表全结构：

业务线 收入占比 毛利率 毛利贡献占比（估算） 原料敏感权重
食用油 30.55% 3.25% 约 8.8% 最高（占比大 + 毛利极薄，油料涨 1% 可吞掉近半毛利）
农资 26.19% 6.35% 约 14.7% 低（传导率高）
原粮 13.89% 3.87% 约 4.8% 中（成本刚性、售价随市）
种子 12.79% 13.19% 约 14.9% 最低（成本加成）
农产品 11.16% — — 中

→ 结构性结论：种子以 12.79% 的收入贡献了约 14.9% 的毛利，单位收入毛利产出是食用油的 4 倍。种子收入占比每提升 1pct，综合毛利率提升约 0.019pct；若 2029 年种子占比从 12.79% 提至 18%（+5.2pct），仅结构迁移即可贡献毛利率 +0.10pct，叠加种子绝对放量，是"毛利结构再平衡"最明确的抓手。

因子3 库存与采购节奏（timing）：
- 存货周转率仅 0.61 次（2026H1），库存主要是当季收获待售粮食。
- 粮价下行期：前期库存粮按跌后价出售 → 库存损失，当期毛利承压；2026H1 公司未计提大额存货跌价（与东贝集团计提 2,624 万形成对比），说明跌价幅度尚在可承受区间，但也意味着后续若粮价继续下行，跌价准备是潜在的利润地雷。
- 粮价上行期：低价库存 + 涨价出售 → 库存收益。公司 H2 销售节奏（是否压粮惜售）将放大或缩小这一效应。
- 纪律：本报告不把任何潜在库存收益计入中性利润——库存收益是一次性的、不可外推的。

因子4 政策/市场锚点（原料成本驱动变量）：

变量 类型 情景假设 验证点（可观测） 证伪信号
小麦/稻谷最低收购价 政策（托底） 中性：维持或微涨；乐观：上调 2–3% 每年国家发改委公布的次年最低收购价公告 连续持平 + 现货价跌破托底价
政策性收储启动节奏 政策（托底） 中性：主产区常规启动 中储粮收储库点公告、启动时间 收储延后或不启动 → 粮价失守
化肥保供稳价政策 政策（降本） 中性：化肥价格高位回落 5–10% 尿素/磷酸二铵现货周度价格 春耕旺季化肥再度冲高
进口大豆/菜籽关税与到港价 政策+市场 中性：国际油料价格高位盘整 海关到港价、CBOT 豆油期货 地缘冲突推高油料 > 20%
生物育种产业化推进节奏 政策（增量） 中性：转基因玉米大豆试点扩大 品种审定公告、公司性状许可公告 产业化进度低于预期

→ 本因子输出（喂给第四步毛利率假设）：中性情景下 2026–2029 综合毛利率维持 11.0%–12.0%（2026 约 11.3%，随种子占比提升与油脂内部整合缓慢修复），不假设粮价大幅反转。

⑤ 信号验证 ✅ 江苏种业 10 亿引战落地、注册资本增至 20 亿 ✅ 华丰种业 51% 并购完成 ✅ 政策明确点名 ❌ 尚无种业收入占比跳升（仍为 12.79%）

→ 判定：种业迁移已过"资金+资质+政策"三项验证点，但未过"收入结构跳升"验证点，因此按纪律仅按已落地项目的内生贡献计入中性，外延并购增量不计入。

层3 风险折扣：证伪信号
- ❌ 种子收入占比连续两个报告期未提升（当前 12.79%）→ 迁移证伪，下修中性
- ❌ 耕地流转面积净减少或流转成本大幅上涨 → 基本盘证伪
- ❌ 食用油毛利率跌破 3% → 油脂整合失败
- ❌ 存货跌价准备大额计提 → 粮价二次探底

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正1 资产质量折扣：公司 PB 2.02x，不破净，此条不适用；但需反向警惕——农垦土地按历史成本入账，账面净资产 72 亿 vs 市值 146 亿，隐含 74 亿的"土地资源溢价"。该溢价缺乏可变现路径（农垦土地不得擅自改变用途、不可自由转让），属"市场愿意给的溢价"而非"可验证的安全边际"。因此本报告不因土地重估逻辑上调目标价。

校正2 周期位置校正（关键）：公司归母 2023 约 8.16 亿 → 2024 7.30 亿 → 2025 5.48 亿 → 2026E 4.6 亿，连续四年下滑且降幅扩大。
- 当前周期位置：底部区域（粮价弱稳、连续丰产压制价格、H1 净利创近年新低）。
- 周期归一化净利：取 2023–2026E 四年均值 = (8.16+7.30+5.48+4.6)/4 = 6.39 亿；取 trough-to-peak 中值 = (4.6+8.16)/2 = 6.38 亿。两者高度一致 → 归一化净利 6.4 亿。
- 本报告 2029E 中性 7.3 亿 = 归一化 6.4 亿 + 种业/油脂已落地项目增量 0.9 亿。未把周期反转的乐观假设计入中性，符合"底部时不过度悲观、也不过度乐观"的纪律。
- 证伪信号：若 2027 年归母仍在 4.5 亿以下且粮价未回升 → 周期底部判断错误，需下修至悲观情景。

校正3 杠杆下行情景：资产负债率 48.88%（2025年末），有息负债 45.57 亿、有息负债率 65.34%。有息负债率偏高需附负面情景：
- 若利率上行 100bp，年增利息约 0.46 亿 → 侵蚀净利约 0.35 亿（税后），对 2029E 中性 7.3 亿影响 −4.8%，不足以使空间转负。
- 但若叠加粮价二次探底（净利跌至 5.0 亿）→ 对应悲观情景 6.89 元，−34.9% 下行。这是本股票最大的不对称风险。

期权纪律：种业外延并购、智慧农业对外输出、土地重估——三者均未过验证点，全部不计入中性锚，仅列入乐观情景。

交叉校验：现价 10.59 元对应 2026E PE 31.7x、PB 2.02x，而 2026E ROE 仅约 6.4%。PB 2.02x / ROE 6.4% 的组合明显偏贵（合理组合应约 PB 1.2–1.5x）。市场当前定价已包含"周期反转 + 种业重估"的双重预期，本报告中性目标价 11.65 元意味着大部分预期已被定价。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价对应 2026E PE 31.7x、PB 2.02x，而 2026E ROE 仅 6.4%。周期底部用高 PE 定价属常见现象（分母被压低），但 PB 2.02x 已难言安全边际。

安全边际：
- 中性远期 11.65 元 → 空间 +10.0%，远不达"重点关注"的 >50% 门槛
- 悲观情景 6.89 元 → 下行 −34.9%，风险收益明显不对称（10% 上行 vs 35% 下行）
- 乐观情景 17.78 元 → +67.9%，但需"粮价上行 + 种业外延并购落地"双重条件
- 下行保护：股息率约 2.6%（2025 全年分红率 52.82%）、每股净资产 5.24 元；PB 1.5x ≈ 7.86 元为较强支撑位

介入条件：
1. 不追高。现价 10.59 元已把"周期反转 + 种业重估"定完，回落至 9.0 元以下（对应 2026E PE 27x / PB 1.72x）才具备安全边际
2. 加仓信号：① 小麦/稻谷现货价连续两个季度回升；② 种子收入占比突破 16%（当前 12.79%）；③ 江苏种业披露具体并购标的
3. 观察指标：逐季毛利率（当前 11.31%，跌破 10.5% 需下修）、存货跌价准备计提情况

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 粮价二次探底（首要）：全国夏粮连续丰产（3,014.9 亿斤创新高）→ 供给宽松→价格中枢下移；公司原粮销售"随行就市、零定价权"，是最直接的受损环节
2. 食用油业务毛利极薄：占比 30.55% 却只有 3.25% 毛利率，进口油料一旦冲高即可能转亏；内部整合（金垦油脂 51% 转让）不改变合并报表、不产生处置收益，市场若误读为"剥离亏损"将形成预期差
3. 种业放量慢于预期：政策与资金已到位，但品种审定周期 3–5 年，收入结构跳升最早 2028 年才能验证
4. 高有息负债率（65.34%）：利率若上行将放大周期底部的利润压力

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

类型A 行业调整剩者红利 — 不适用（种植业非过剩出清行业）。

类型B 政策反转期权（本股最相关）
- 具体政策：小麦/稻谷最低收购价上调 + 政策性收储加码 + 生物育种产业化提速
- 反转信号：国家发改委公布的次年最低收购价公告（若上调 2–3%）、转基因品种审定公告
- 重估弹性测算：粮价每上涨 5%，原粮 + 农产品（合计约 28.5 亿收入，2029E）毛利率提升约 2.5–3.5pct → 增厚净利约 0.6–0.8 亿 → 对应市值弹性 13–18 亿（+8%–11%）
- 验证点：最低收购价公告、公司调研披露的价格预判转向
- 证伪信号：连续两年最低收购价持平 + 现货价跌破托底价

类型C 市场错杀修复 — 有限。当前 PB 2.02x 处于自身历史中高位，不存在错杀证据；相对种植业可比公司也无折价。

类型D 技术突破 / 代际跃迁期权
- 内容：农业农村部农业低空技术创新与集成应用重点实验室 + "神农慧种"农业大模型 + 130 万亩连片高标准农田的独有 AI 落地场景
- 三要素检验：①政策驱动 ✅（智慧农业、AI+ 农业均在"十五五"规划）；②行业趋势收敛 ⚠️（智慧农业仍处示范阶段，未到渗透率拐点）；③公司落地 ❌（无独立收入、无客户定点、无量产成本优势验证）
- 硬验证点未达标 → 仅作机会情景，不计入中性锚

什么条件出现才上调至"重点关注"：需同时满足——① 小麦或稻谷现货价连续两个季度回升（周期反转确认）；② 种子板块收入占比突破 18% 且毛利率维持 13% 以上（迁移验证）；③ 股价回落至 9.0 元以下（估值留出安全边际）。三者缺一，维持"纳入观察"。

结论：纳入观察

理由：逻辑正确（种业平台化 + 全产业链 + 政策强驱动），但当前价格已把周期反转与种业重估的预期定完——中性远期空间仅 +10.0%，而悲观情景存在 −34.9% 下行，风险收益不对称。
真正的机会在周期拐点：一旦粮价确认回暖，公司 130 万亩自营耕地的毛利弹性会快速释放（乐观 +67.9%）。当前是"等"而非"买"的时点。
核心跟踪点：小麦/稻谷现货价走势 + 种子收入占比能否突破 16%。
