第一步：公司是干什么的？

一句话定位：国内心血管植介入器械龙头（冠脉支架/球囊/封堵器起家），正从"心血管耗材 + 仿制药"向"神经调控/脑机接口 + 代谢创新药 + 皮肤科医美"三线延伸的平台型医疗企业。

（3）产业链传导

上游：镍钛合金、不锈钢/钴铬、铂铱贵金属、可降解高分子（PLLA）、药物涂层原料（雷帕霉素类）、原料药化工中间体。公司自产比例高（支架/球囊/封堵器自主生产，原料药自产），上游分散度高，单一原料不构成瓶颈。

下游：医院 + 经销商。集采后下游变为"医保 + 集采办"定价，医院议价权被行政力量替代，经销商在集采落地前存在观望不补货行为（这正是 2026Q1 封堵器业务受冲击的机理）。

议价权：
- 集采品类（冠脉、金属封堵器、仿制药制剂）：弱，传导率≈0，成本与降价均由公司承担
- 非集采创新品类（可降解封堵器、DBS、医美）：强，传导率 0.7–0.9，自主定价空间保留
- 海外市场：中等偏强（注册证壁垒 + 自主定价）

第二步进阶：原料成本 → 毛利结构四因子

因子1 成本传导弹性（pass-through）：把议价权量化成系数——
- 冠脉植介入（已集采）：传导率 0.0–0.1，成本上涨 100% 由公司吸收；佐证：2025 国内集采续约后毛利率持续下移
- 结构心金属封堵器（2026-04 起集采）：传导率 0.0–0.15；佐证：2026H1 器械毛利率 −3.31pct
- 可降解封堵器 / TAVR / DBS（未集采或价格治理温和）：传导率 0.7–0.9；佐证：可降解封堵器植入 +35% 且未跟随降价
- 医美（消费医疗、自主定价）：传导率 ≈1.0；佐证：射频仪/PDRN 无集采属性
- 药品制剂（集采接续）：传导率 0.0–0.1；药品原料药（市场化）：传导率 0.8–0.9
→ 加权传导率估算约 0.40–0.50：即上游每涨 10%，综合毛利承压 5–6%。这是本报告毛利假设的定量基础。

因子2 毛利结构再平衡（禁止单一综合毛利率）：

业务线 2026H1 收入 估算毛利率 原料敏感权重 净利贡献性质
冠脉植介入 8.57 亿 约 62–65%（集采后稳态） 中（金属 + 药物涂层） 现金牛，量稳价稳
结构性心脏病 3.13 亿 约 72–75%（金属）→ 可降解更高 中高（镍钛） 2026 承压，2027 修复
其余器械（外周/电生理/IVD/神经调控） 5.45 亿 约 55–60% 低—中 增量主力，DBS 高毛利
药品制剂 8.06 亿 约 55%（−6pct） 中（化工中间体） 持续萎缩
原料药 1.55 亿 约 30–35% 高（化工品价格） 逆势 +8.74%

→ 关键结构变化：医美 + 神经调控两条高毛利、低原料敏感业务占比提升，正在对冲集采品类的毛利塌陷。综合毛利率 60.86% 掩盖了"内部两升两降"，这正是必须分业务线建模的原因。

因子3 库存与采购节奏：存货 19.52 亿（占总资产比重不低）、存货周转偏慢（器械行业特性 + 经销商备货节奏）。封堵器集采落地前经销商观望不补货 → 2026Q1 公司出货受阻、库存被动累积；4 月落地后通路恢复。此处存在"库存节奏错配"而非"需求消失"的判断——Q2 归母降幅收窄（−19.12% vs Q1）即为渠道库存去化接近尾声的证据。验证点：2026Q3 存货周转天数是否回落、封堵器出货是否恢复正增长。证伪信号：若 2026Q3 存货继续累积且封堵器收入仍同比下滑，则说明需求端而非渠道端出问题，中性情景需下修。

因子4 政策/市场锚点（原料成本驱动变量）：
- 市场层：镍钛/钴铬/铂铱大宗价格、人民币汇率（海外收入占比提升后暴露加大）、化工中间体价格（原料药毛利）
- 政策层：①集采接续/扩围（直接改写售价，是最大变量）；②《医药工业"十五五"发展规划》（工信部编制中，定位"创新医药 + 数智医药"）；③医保目录谈判（创新药放量通道）；④美国 301/关税对出口器械的潜在影响（公司海外以新兴市场为主，直接敞口有限）
→ 情景假设：中性 = 集采"反内卷"口径延续，存量价格年降 3–5%、不再出现单品类断崖式降价；悲观 = 2027 年启动新一轮高值耗材国家集采（如神经调控、电生理）。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务：市场容量 × 份额变量（5 锚点）
1. 供给侧份额：冠脉支架/球囊国内产能充裕，公司为主要供应商之一，产能利用率中等；无显著扩产计划 → 供给侧不构成份额抓手
2. 需求侧/客户份额：PCI 手术量国内仍有个位数增长，公司冠脉份额已稳态；结构心份额是可变量——金属封堵器集采后中小厂商出清，龙头份额被动提升
3. 技术代际差：可降解封堵器 vs 金属封堵器 = 领先一代（公司是国内可降解封堵器最主要推手），带来份额溢价且未纳入集采；TAVR/PFA/DBS 属同代跟进，非领先
4. 成本曲线位置：规模 + 垂直一体化（自产支架、球囊、原料药）使公司在集采降价中仍能保住 60%+ 综合毛利率，位于成本曲线左侧
5. 份额二阶导数：冠脉 = 已饱和（一阶导≈0）；结构心 = 加速渗透期（可降解替代金属，二阶导为正）；医美 = 从 0 到 1 的 S 曲线起点
→ 三档：保守守住（冠脉份额不变、可降解渗透放缓）/ 中性小幅提升（可降解封堵器 2029 年占结构心收入 40%+）/ 乐观抢份额（可降解 + 左心耳 + TAVR 三线共振，结构心收入翻番）。验证点：逐季可降解封堵器植入量增速、左心耳封堵器注册证获批公告。证伪信号：可降解封堵器植入增速连续两季 <15%，或被纳入新一轮集采。

层2 扩展业务：主业迁移空间（新易盛范式）
- 能力可迁移性：心血管植入器械的"电极 + 脉冲发生器 + 植入工艺"能力 → 神经调控（DBS/VNS/SCS/SNM）技术同源度高，迁移成本低；公司已自述希望形成"脑机接口闭环体系中的医疗级干预技术平台"
- 新 TAM 弹性：神经调控国内市场规模显著大于结构性心脏病细分，且国产化率低（进口主导），替代空间大
- 切入时点与卡位：DBS 2025-11 才获批，属早期但非首发（国产已有先发者），卡位中等
- 认证门槛：植入式神经刺激器需 NMPA 三类证 + 多中心临床，门槛高（既是护城河也是放量阻力）；VNS/SCS/SNM 均在临床阶段
- 信号验证：①DBS 是否已进入三甲医院批量装机（待公告）；②VNS/SCS/SNM 注册进度；③神经调控收入是否在定期报告中单独披露
→ 判定：中期期权，未过验证点（收入未单列、装机量未披露），不计入中性情景，仅计入乐观情景。
- 医美属于"能力可迁移 + 新 TAM"的另一条迁移线：从 B 端器械（医院）迁移到 B+C 端（医美机构 + 消费），技术同源度中等（材料/射频/注射填充），但渠道完全不同（需重建医美机构渠道）——迁移成本低但渠道成本高。

层3 风险折扣：证伪信号
①仿制药制剂收入跌幅连续扩大（H1 已 −17.32%）；②特色新品获批时点连续推迟（PDRN/肉毒素）；③神经调控装机无公告且收入未单列；④集采新一轮把可降解封堵器/DBS 纳入；⑤应收账款 23.42 亿回款恶化；⑥少数股东损益 H1 由 +844 万转为 −4288 万（非全资子公司研发投入加大），若持续扩大将侵蚀归母。命中任两条则下调中性假设。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（PB 1.27x，未破净）：不适用破净折扣，但需检查净资产质量。2026H1 资产负债率 31.75%，货币资金 41.61 亿，商誉与无形资产（资本化研发 1.27 亿/半年）占比可控；应收账款 23.42 亿（约为半年营收的 73%）偏高，是主要资产瑕疵——已在悲观情景中以"2029 净利降至 9.5 亿"部分反映。
  • 校正2 周期位置校正：医疗器械非强周期，但受政策周期（集采）主导。当前位置 = 政策冲击的中后段（冠脉已稳态、封堵器 2026-04 刚落地、神经调控/医美尚未被集采）。因此中性净利 13.5 亿既未采用 2023 年高点（12.58 亿）也未采用 2025 年低点（9.62 亿），而是自下而上重算——未做"拐点年化"。
  • 校正3 杠杆下行情景：资产负债率 31.75%，不构成高负债；但 2026 年可转债到期已抬高当年财务费用（利息保障倍数由 17.57 降至 8.70）。负面情景：若利率上行 100bp + 集采再降价，2029 净利可降至 9.5 亿以下 → 悲观情景 9.28 元（−17.9%）。该负面情景不会使空间转为极端负值，但会侵蚀全部上行，故不给予"重点关注"。
  • 期权纪律：GLP-1 Ⅲ 期、siRNA、脑机接口、VNS/SCS/SNM 均未过验证点（无收入单列、无客户定点、无获批），全部计入乐观情景，零计入中性 13.5 亿。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵。现价 11.31 元对应 2026E PE 22.7x，高于基准区间上沿（10.85 元）。PB 1.27x 提供一定下行保护（器械龙头 + 41.61 亿现金 + 6.33 亿/半年经营现金流），但 PE 端已提前反映 2027 年"一次性因素消失 + 集采扰动减弱"的修复。

安全边际：
- 中性远期 15.38 元 → 空间 +36.0%，未达"重点关注"的 >50% 门槛
- 悲观 9.28 元 → 下行 −17.9%（有 PB 1.27 与现金流托底，下行有限）
- 乐观 22.79 元 → +101.5%，需医美 + 神经调控 + GLP-1 三重兑现
- 赔率特征：下行有限、上行中等、中性不达门槛 → 典型"质地好但价格不够便宜"

介入条件：
1. 价格条件：回落至 9.8 元以下（2026E PE < 19.5x，PB ≈ 1.10）具备安全边际
2. 信号条件（任一即上调）：①PDRN 复合溶液 / 含聚左旋乳酸交联透明质酸钠凝胶 2026Q4 如期获批；②可降解封堵器 2026Q3/Q4 植入量增速维持 30%+；③神经调控 DBS 装机量首次正式披露且季度环比放量与；④2026 年报显示财务费用率回落至 2% 以下（可转债影响消失的实证）
3. 观察指标：逐季存货周转天数、应收账款回款、少数股东损益是否继续扩大

最大风险（最可能破坏逻辑的因素）：
1. 新一轮集采把可降解封堵器或神经调控纳入——这是本报告"可降解封堵器对冲金属封堵器降价"这一核心逻辑的命门
2. 医美获批时点推迟——若 PDRN/童颜针从 2026Q4 推迟到 2028，中性 2029 净利将下调约 1.5 亿（目标价降至约 13.7 元）
3. 研发投入失控：H1 研发 6.04 亿（+13.40%），少数股东损益由 +844 万转 −4288 万，非全资子公司（民为生物等）持续失血会侵蚀归母
4. 应收账款 23.42 亿回款风险
5. 创新药临床失败（GLP-1 Ⅲ 期、纳米/脑机接口）——不伤中性锚，但消灭乐观情景

第五步进阶：上行想象力情景（四类）

类型A 行业调整剩者红利：高值耗材集采连续推进后，中小器械厂商因无法满足"成本 + 质量 + 保供"三重要求而退出（国家医保局已对 15 个集采药品取消中选资格、490 个品种全覆盖 GMP 检查）。剩者份额与定价权跳升。验证点：封堵器集采执行一年后，中选企业数量是否减少、公司份额是否提升（看 2026 年报/2027 年中报的植入量口径）。证伪：中选企业不减反增、招标规则继续唯低价。弹性：若结构心份额从当前水平提升 5pct，2029 收入 +1.5–2 亿、净利 +0.33–0.44 亿，目标价 +3~4%。

类型B 政策反转期权：《关于健全药品价格形成机制的若干意见》（国办发〔2026〕9 号）已明确"创新不集采，集采非创新"、高水平创新药上市初期自主定价；医保局《全民医疗保障"十五五"规划》提"规则优化、反内卷"。若"反内卷"落实为取消唯低价中标、引入综合评价，则存量集采价格年降幅度有望从 5% 收窄至 2–3%。验证点：下一轮集采招标文件是否引入综合评价/质量分层、是否取消最低价唯一中标。证伪：继续沿用最低价中标。弹性：存量价格年降收窄 2pct → 2029 收入 +2 亿、净利 +0.4 亿，目标价 +3%。未过验证点，仅作机会情景。

类型C 市场错杀修复：现价 PB 1.27x 处于历史低位，PE(TTM) 27.06x 因 2026 年利润被一次性财务费用（0.83 亿）压低而虚高。错杀证据：剔除可转债影响后 2026H1 扣非 5.64 亿，年化对应 PE 约 18.5x，显著低于表观 27x；经营现金流 6.33 亿几乎未下滑（−0.60%），证明盈利质量未恶化。修复触发点：2026 年报披露财务费用率回落（可转债影响消失）+ 2027Q1 归母恢复正增长 → 市场按"真实 PE 18–19x"重定价。证伪：2027Q1 归母仍同比下滑且经营现金流恶化。

类型D 技术突破 / 技术代际跃迁期权：介入型多通道脑机接口已完成动物实验并进入人体 IIT 临床研究；控股子公司睿瀚医疗已有脑电/肌电/康复 NMPA 产品；生物可降解封堵器属材料代际领先。硬验证点三要素：政策驱动（工信部《医药工业"十五五"规划》"创新医药"方向 — 已部分具备）＋行业趋势收敛（脑机接口 2026 年多省纳入医保收费立项 — 需核实）＋公司落地（中试/临床跑通 + 客户定点 + 成本优于旧路线 — 目前仅到"人体 IIT"，尚未拿到任何产品或订单）。判定：缺两项硬验证点，属纯机会情景，零计入中性锚。证伪信号：IIT 研究长期无进展公告、动物实验数据未发表、监管路径不明。弹性（若 2030 年前跑通）：极高，但概率低。

什么条件出现才上调至"重点关注"：需同时满足 ①股价回落至 10 元以下（中性空间重新 >50%），或 ②PDRN/童颜针 2026Q4 获批 + 可降解封堵器保持 30%+ 增速 + DBS 收入单独披露且年化 >2 亿（三者至少两项成立 → 2029 中性净利可上调至 15 亿以上，中性空间 >50%）。

结论：纳入观察

理由：中性远期空间 +36.0%，超过"纳入观察"的 >0 门槛但未达"重点关注"的 >50%；现价 22.7x 2026E PE 已在合理区间上沿，安全边际不足。
公司质地扎实——集采冲击最大阶段已过（Q2 降幅收窄）、现金流未恶化（6.33 亿）、可降解封堵器（+35%）与医美（+13.24%）构成两条真实的对冲增长线、可转债一次性拖累 2027 年消失。
但价格还没到"必须下手"的位置：等 9.8 元以下，或等 2026Q4 医美获批落地后再评估。
