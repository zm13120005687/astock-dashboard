分析日期：2026-09-12 ｜ 现价 15.50 元（2026-09-11 收盘）｜ 总市值 41.64 亿 ｜ PE(TTM) 52.37x ｜ PB 2.92x ｜ 总股本 2.687 亿股
行业：装饰复合材料（饰边条 / 饰面板）+ 智慧水务（膜材料 / 装备 / 平台）｜ 注册地：广东东莞
重要提示：2026H1 归母 7603 万元（+319.74%）中，含收购升辉清洁 19% 股权形成的折价收益 4134.19 万元（占利润总额 39.40%，不可持续）；扣非归母仅 3295.64 万元（+99.59%），须以扣非为真实盈利基准。

第一步：公司是干什么的？

一句话定位：从"板式家具封边条 / 饰面板"起家的装饰复合材料企业，2024 年底收购苏州尚源智能 51% 股权后形成"装饰建材（基本盘）+ 智慧水务（增长引擎）"双主业，正在把水务从"卖设备"升级为"膜材料—膜组件—装备—智慧平台—运维"全产业链 + 分质供水长周期运营。

结构判断：公司正处于"传统建材承压、水务高增拉动"的转型期。2026H1 收入 +26.20%，综合毛利率 32.98%（+4.2pct），提升主因是高毛利智慧水务收入占比上升——这是典型的结构性改善，而非产品或原料层面的改善，第四步必须按分业务拆解。

（3）产业链传导

  • 上游（建材）：PVC 树脂、ABS、PMMA、三聚氰胺浸渍纸、基材（OSB/刨花板/中纤板）、无醛胶。核心敏感变量为 PVC 与 MMA（PMMA 原料），跟随原油与电石。
  • 上游（水务）：PVDF/PVC 膜材料、不锈钢/碳钢壳体、泵阀仪表、电控元件。膜材料成本占膜组件成本约 30–40%。
  • 下游（建材）：定制家居与板式家具厂。行业 −4.39%、集中度低、低端价格战，公司靠外销与高端精板逆势增长。
  • 下游（水务）：市政水务、农村安全饮水、工业废水。客户为地方水务平台 / 政府，回款周期长（2025 年曾因回款滞后导致经营现金流承压），2026H1 已建专项清收体系。
  • 议价权：建材端 弱（行业分散、低端价格战）；水务端 中等（膜技术自研 + 全产业链 + 数字化平台形成差异化，"膜性能对标国际主流、成本仅为其 1/10"是核心卖点）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（把议价权量化为转嫁系数）

业务线 核心原料 传导率（估计） 依据 实际毛利承压
饰边条（PVC/ABS/PMMA） PVC 树脂、MMA ≈0.40 行业集中度低、低端价格战，向下游定制家居厂转嫁能力弱 原料 +10% × 0.60 = 6.0pct
饰面板（三聚氰胺纸 + 基材） 浸渍纸、OSB/刨花板、无醛胶 ≈0.50 高端精板（差异化产品）有一定溢价能力 原料 +10% × 0.50 = 5.0pct
膜组件 PVDF/PVC 膜材料、壳体 ≈0.65 自研膜技术、成本仅为国际 1/10 → 成本曲线极左，议价权较强 原料 +10% × 0.35 = 3.5pct
水处理设备（撬装/模块化） 钢壳体、泵阀、电控 ≈0.70 项目制定价，随项目报价联动 原料 +10% × 0.30 = 3.0pct
软件与运维服务 人力为主 ≈0.90 几乎无原料，毛利率最高（估计 50%+） 可忽略

因子2 毛利结构再平衡（禁止用单一综合毛利率掩盖迁移）
2026H1 综合毛利率 32.98%（+4.2pct），但这个数字完全由业务结构迁移驱动：
- 智慧水务：收入 2.05 亿（占 30.5%），毛利率估计 38–42%（膜组件自研 + 装备 + 软件 + 运维）
- 家居建材：收入 4.54 亿（占 67.5%），毛利率估计 24–27%（行业分散、价格战）
- 毛利贡献拆分（估算）：智慧水务毛利约 0.80 亿（占 36%）、建材毛利约 1.16 亿（占 52%）、其他约 0.26 亿 → 智慧水务以 30.5% 的收入贡献了 36% 的毛利
- 迁移结论：智慧水务收入占比每提升 5pct，综合毛利率约提升 0.6–0.7pct。2026H1 毛利率 +4.2pct 主要由此而来 → 第四步的毛利率假设必须是"水务占比提升"的函数，而非固定综合毛利率。

因子3 库存与采购节奏（timing）
- 建材端：PVC/浸渍纸采购以随行就市为主，无套保披露；2026 年原油与电石价格波动直接影响饰边条毛利。
- 水务端：项目制，膜材料采购与项目交付匹配；在建工程 1.05 亿（+143.37%）说明超级工厂尚在建设期，产能释放的 timing 在 2027–2028，2026H1 的装备收入仍依赖现有产能。
- 不能把库存收益当真实盈利：2026H1 经营现金流由 −1179 万转正至 +6923 万，管理层归因于"专项应收账款清收"——这是存量回款的一次性改善，不是新增盈利能力的证据。若 2027 年新增项目继续形成长账期应收，现金流可能再次承压。
- 研发费用 −11.08%（2024 万）与 2025 全年 +39.49% 形成反差，管理层解释为"本期研发投入减少" → 短期利润有被研发费用压降"美化"的成分，第四步需警惕。

⑤ 份额二阶导数 建材：份额缓慢流失（行业 −4.39%、低端价格战）；水务：处于加速渗透早期（2025 +70.82%、2026H1 占比升至 30.5%） 关键：增长完全来自水务

份额三档假设 + 验证点
- 保守：建材份额持平、水务增速降至 20% → 2029 收入 16 亿 → 验证点：膜组件收入连续两季下滑
- 中性：建材持平略增、水务 2025–2029 保持年增 25–30% → 2029 收入 20.5 亿（水务 43%）→ 验证点：超级工厂投产公告、膜组件收入年增 >30%
- 乐观：分质供水全域复制 + 纳滤膜产业化 → 2029 收入 25 亿 → 验证点：东莞项目开工公告、第二个分质供水城市落地

层2 主业迁移空间（中期期权，未过验证点不计入中性）

迁移方向 A：装饰建材 → 智慧水务（已完成迁移，是主逻辑）
- 能力可迁移性：低（建材与水务技术完全不同源）——这不是"能力迁移"，而是并购式转型（2024 年底收购苏州尚源智能 51%）。因此整合风险高于内生迁移
- 新 TAM 弹性：显著大于建材（"十五五"水网、地下管网、饮用水提标）→ TAM 弹性高
- 切入卡位：较早（行业"从试点示范向规模化建设转型"）
- 客户认证门槛：水务项目需地方国资平台合作 + 卫生许可 + 涉水产品认证，门槛高 → 既是护城河也是阻力
- 信号验证：东莞分质供水政企合作已落地（过验证点）→ 计入中性，但因金额未披露给保守假设

迁移方向 B：超滤膜 → 纳滤膜 / 罐式超滤膜系统
- 能力可迁移性：高（膜材料研发同源）
- 新 TAM 弹性：纳滤用于高品质饮用水与工业分离，单价高于超滤
- 切入卡位：早期（联合高校产学研攻关）
- 客户认证门槛：需重新进行涉水产品认证
- 信号验证：研发试制阶段，无中试良率、无客户订单 → 未过验证点，不计入中性净利

层3 证伪信号
- 膜滤超级工厂投产延期（若 2028 年底仍未投产）→ 产能增量剔除
- 东莞分质供水项目无后续开工/投资公告 → 运营型收入证伪

- 建材业务收入连续两年下滑超 10% → 基本盘加速萎缩
- 商誉减值（苏州尚源智能 51% 收购形成商誉）→ 需关注

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正1 资产质量折扣
- PB 2.92x，不破净。需核查：
- 商誉风险：2024 年底收购苏州尚源智能 51% 形成商誉，规模未披露；2026H1 无减值计提 → 若水务业绩不及承诺将触发减值，净资产虚高
- 应收账款风险：水务业务回款周期长（2025 年曾因"智慧水务回款滞后导致经营现金流承压"）；2026H1 靠专项清收使现金流转正 → 应收质量是净资产的最大隐患
- 在建工程 1.05 亿（+143.37%）：尚未转固，若项目延期则存在减值或长期不达产风险
- 结论：资产质量中等偏弱，净资产存在"商誉 + 应收"双重虚高风险 → PB 2.92x 缺乏安全边际

校正2 周期位置校正
- 行业属性：建材为地产后周期（下行）、水务为政策驱动逆周期（上行）。当前位置：建材端周期底部（卖场销售额 −4.39%、行业洗牌）；水务端上行早期（试点转规模化）。

- 周期位置标注：建材底部 + 水务上行早期 → 中性净利已反映建材承压（收入仅给 +13%/三年）与水务增长（+138%/三年）。

校正3 杠杆下行情景（必附负面情景）
- 资产负债率未披露（估计约 45–50%，含并购与在建投入）。2026H1 财务费用存在。
- 负面情景：若① 膜滤超级工厂延期至 2029 后；② 东莞分质供水项目因地方财政压力推进缓慢；③ 地产竣工继续下滑致建材收入年降 8%；④ 水务应收账款计提大额减值（假设 1.0 亿）→ 2029 收入仅 15 亿、归母降至 0.85 亿，对应 PE 20x = 17.0 亿 → 6.33 元（−59.2%）。

- 纪律：未过验证点，仅作机会情景，不计入中性锚。

类型C 市场错杀修复
- 错杀证据不足：PE 52.37x、PB 2.92x 均处高位，当前不是错杀。但若出现：① 2026 年报因"高基数（含 4134 万一次性）"导致增速大幅回落引发情绪杀；② 小盘成长风格系统性回撤 → 股价若跌至 10 元以下（PE 18.5x、PB 1.88x），届时可能出现"转型逻辑未变 + 情绪超跌"的错杀修复机会。
- 注意区分：2026 年报增速回落是会计现象（一次性收益高基数），不是基本面恶化——若市场误读，正是错杀机会。
- 修复触发点：超级工厂投产公告 + 2027Q1 扣非净利同比高增（因 2026Q1 基数低）。
- 证伪信号：扣非净利实际下滑 → 则不是错杀。

类型D 技术突破 / 技术代际跃迁期权
- 方向：纳滤膜产业化与新一代标准化超滤膜组件 / 罐式超滤膜系统
- 三要素检验：① 政策驱动——"十五五"水网、饮用水提标（成立）；② 行业趋势——膜法水处理渗透率快速提升，纳滤用于高品质饮用水（趋势成立）；③ 公司落地——已完成新一代标准化超滤膜组件研发试制、MBR 膜组器结构优化，纳滤膜处于"联合高校产学研攻关"阶段 → 无中试良率数据、无客户订单、无量产成本对比
- 硬验证点缺失 → 只作机会情景，不计入中性锚。
- 已有优势（可确认的部分）：自研超滤膜"核心性能对标国际主流产品，成本仅为其 1/10"——这是已实现的成本代际优势，但仅体现在现有产品，不等于纳滤膜突破。
- 证伪信号：纳滤膜长期停留在产学研阶段、中试良率不达标、成本打不过进口膜、客户流失。

什么条件出现才上调至"重点关注"：需同时满足 ① 股价回落至 11.5 元以下；② 膜滤超级工厂投产公告且披露设计产能；③ 东莞分质供水项目披露投资额与运营模式；④ 连续两季扣非净利同比 +40% 以上。四者齐备则中性归母可上修至 1.9 亿以上，空间将超过 +50%，可上调评级。
反之，若超级工厂延期或分质供水无实质进展，则维持"暂不介入"并进一步下修目标价至 8 元附近（悲观情景）。

结论：暂不介入

核心判断：公司转型方向正确（从低毛利、缩量的装饰建材切向高毛利、增量的智慧水务，且自研膜成本仅为国际 1/10 的成本代际优势真实存在），2026H1 扣非归母 +99.59% 也是真实的。
但三个问题使其当前不具备投资价值：① 估值严重透支——经营性 PE 高达 62x，中性远期空间 −9.5%；② 少数股东吞噬——苏州尚源仅 51% 持股，水务占比越高，归母增速越低于净利润增速；③ 核心增量不可验证——超级工厂设计产能、分质供水投资额与收费模式均未披露，无法做可靠的自下而上测算，而这两个恰恰是 2027–2029 的全部增量来源。
更需警惕的是：2026H1 归母 +319.74% 中 4134 万（占利润总额 39.40%）是不可持续的并购折价收益，若以此线性外推将严重误判。
核心跟踪点：膜滤超级工厂投产公告（含设计产能）、东莞分质供水项目披露投资额与运营模式、扣非净利的季度趋势、应收账款周转天数。
