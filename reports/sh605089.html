第一步：公司是干什么的？

一句话定位：A 股稀缺的 C 端预制菜（半成品菜）加盟连锁龙头——在华东开了 1,658 家加盟门店，把牛肉、家禽、水产做成"免洗免切免调味、加热即食"的半成品菜，卖给家庭餐桌，同时做批发、商超与团餐。

- 批发端：酒店、团餐食堂、餐饮定制，推"1+N"模式（协助大批发商开发二批、三批客户）

股东背景：苏州吴中民营企业，实控人夏靖（董事长兼总经理，高级经济师）。资产负债率仅约 12.1%（总资产 14.08 亿、净资产 12.37 亿），几乎无杠杆，账上现金充裕，2026 年中期分红每 10 股派 2.80 元（合计 3,825 万元）。

（3）产业链传导

上游：牛肉（占比最大，41.76% 收入来自牛肉类）、家禽、水产（鱼/虾）、猪肉、辅料包材。
- 牛肉是本轮的核心变量：公司实施战略储备，预付款 + 存货同步增加 → 短期锁定成本红利，但这笔收益是 timing 收益，不可持续
- 议价权：上游偏弱。牛肉全球定价，公司是价格接受者，只能靠"规模化集中采购 + 长期稳定上游合作 + 战略储备"对冲，用资产负债表换成本稳定（这解释了经营现金流转负）

下游：C 端消费者（加盟门店）、团餐食堂、酒店、商超。
- 议价权：C 端中等偏强（品牌 + 冷链 + 门店网络，消费者价格敏感度低于 B 端集采）；B 端偏弱（团餐/酒店议价能力强、账期长，应收增加）
- 核心矛盾：华东 89.61% 集中度，本地品牌认知是护城河，但也意味着华东消费景气度 = 公司收入天花板

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）
- C 端（加盟门店 + 线上）传导率约 0.7–0.8：消费者对单品价格不敏感（客单几十元），公司 H1 明确做了"部分产品价格调整"且未出现销量下滑，证明传导顺畅
- B 端（团餐/批发/商超）传导率约 0.3–0.4：团餐是集采招标，价格刚性，原料涨了基本自己扛
- 加权传导率约 0.6（假设 C 端占 55%、B 端占 45%）→ 牛肉涨价 10%，公司实际毛利承压 ≈ 10%×(1−0.6)×牛肉成本占比(约 35%) ≈ 1.4pct 毛利率
- 验证点：①单季毛利率能否守住 23%；②公司是否再发调价函；③牛肉/鸡肉/白虾现货价格走势
- 证伪信号：毛利率跌破 21%（2025 全年水平）且收入仍零增长 → 传导失败 + 需求疲软双重打击

因子2 毛利结构再平衡（分产品线敏感权重）

产品线 收入占比 主要原料 原料敏感权重 敏感度
牛肉类 41.76% 牛肉（进口为主） 最高 高价 + 强周期，是毛利率第一驱动
家禽类 17.39% 鸡肉 中 国内自给，价格波动小
水产鱼类 13.91% 鱼/虾 中高 虾价波动大
其他（羊/猪等） 26.94% 羊肉、猪肉 中 猪肉国内周期

→ 牛肉类占四成收入、且是价格弹性最大的原料，公司实质上是"牛肉 Beta 的反向暴露 + 传导能力 0.6"的组合。
→ 关键结构判断：2026H1 毛利率回升 2.7pct 主要来自牛肉储备的 timing 收益（低价囤货）而非结构性提价能力。若牛肉价格 2027 年反转上行，这条线会最先塌。
→ 禁单一综合毛利率：2026H1 综合毛利率看起来是 24%，但拆开是"牛肉线受益储备 / 家禽水产线平稳 / 新品线爬坡"，一旦储备红利耗尽，综合毛利率会回落。

因子3 库存与采购节奏（timing）——本例的核心
- 低价囤货收益：公司"针对牛肉原料实施战略储备，预付款项与存货同步增加"→ 当期毛利虚高、经营现金流 −1.187 亿
- 这在会计上是真实的，但在经济意义上是"把未来的成本优势提前兑现"：若牛肉后续涨价，储备价值兑现为超额毛利；若牛肉后续跌价，则形成存货跌价损失
- 对冲比例未披露：公司称"依托规模化集中采购及长期稳定上游合作，稳定原材料价格"，但未披露长协比例与套保规模，构成不确定源
- 验证点：①中报存货与预付款项明细（牛肉储备规模）；②Q3/Q4 毛利率是否维持 23%+；③经营现金流是否转正
- 证伪信号：存货周转率持续下滑（H1 存货周转率 2.01 次，Q1 为 2.85 次，已明显放缓）+ 经营现金流连续两期为负 → 库存收益正在变成库存损失

因子4 政策 / 市场锚点（原料成本驱动变量）
| 层级 | 变量 | 情景 | 验证点 |
|---|---|---|---|
| 市场层 | 进口牛肉价格（巴西/澳洲/阿根廷） | 中性：H2 持平；乐观：继续下行；悲观：反转上行 15%+ | 农业部牛肉批发价、进口冷冻牛肉到岸价 |

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务：市场容量 × 份额变量

锚点 当前位置 保守（守住） 中性（小幅提升） 乐观（抢份额） 可观测验证点
① 供给侧份额 份额约 1.8%（2020 年口径），行业 CR5 仅 9.2%–18% 份额持平 1.8% 1.8% → 2.3% 1.8% → 3.0%（出清红利） 半年报/年报门店数、收入增速 vs 行业 +21.3%
② 需求侧客户份额 C 端加盟 1,658 家，华东 89.61% 门店零净增 门店 1,658 → 2,600（3 年净增 942） 门店 → 3,200+，华中/华北破局 季度门店净增数（公司未逐季披露，构成主要不确定源）
③ 技术代际差 益生菌锁鲜专利 + 五大体系认证（ISO9001/ISO22000/HACCP 等）+ 自有冷链 无代际差 短保鲜品技术领先半代 短保成为新行业标准 短保产品收入占比是否披露并跳升

⑤ 份额二阶导数 收入 +0.69%，份额实际在下滑（行业 +21.3%） 继续下滑 2027 年恢复至行业增速 超越行业增速 季度营收同比 vs 行业增速——最关键的单一指标

⚠️ 最刺眼的事实：2026H1 公司营收 +0.69%，而同期行业规模增速 +21.3%。这意味着公司的市场份额正在被稀释——国标出清的红利暂时没有落到它头上。这是本报告对"份额变量"给出的最重要判断。

② 新 TAM 弹性 大。团餐食材供应链市场规模突破万亿，远超 C 端零售 中高。短保方便菜增速 >35%，全行业最快 大，但公司无布局
③ 切入卡位 中期。团餐已进入，但面临千味央厨等专业 B 端龙头的正面竞争 早期偏中期。公司已定制化开发短保系列 未切入
④ 客户认证门槛 中。团餐客户需资质审核 + 账期，切换成本中等 低。走现有渠道 高
⑤ 信号验证 H1 明确"团餐渠道表现尤为亮眼"，带动应收账款相应增加（收入真实性佐证） 已开发短保系列，未披露收入 无

→ 判定：团餐与短保部分通过验证（有收入、有应收账款佐证），但未披露收入规模，无法量化贡献 → 只进乐观情景，不计入中性锚。出海未切入，不计。

层3 风险折扣：证伪信号
- 门店数连续两个半年报零净增或净减少 → 城市合伙人计划失败
- 季度营收增速持续低于行业 +21.3% → 份额被稀释（当前已命中）
- 毛利率跌破 21% → 储备红利耗尽 + 传导失败

- 团餐收入占比未在年报中单列跳升 → 迁移故事未兑现

校正1 资产质量折扣

校正2 周期位置校正
公司不属强周期股（食品消费），但存在明显的"行业景气周期 + 原料周期"双重波动：

校正3 杠杆下行情景（高负债必附负面情景）
资产负债率 12.1%，远低于 60% 阈值，杠杆风险极低，不需做高杠杆负面情景。

准亏损从严：正常化净利润法 + 盈利塌陷三问

说明：味知香 2026H1 归母 +4,118 万、扣非 +3,314 万，当期明确盈利。但本报告估值锚采用"正常化净利率法"（周期归一化 13.0%），且公司经营现金流为负、非经常性损益占归母 19.5%，按规则须从严作答以下三问。

问1：会不会塌陷（为什么可能由盈转亏）？
- 不会结构性塌陷，但存在单季亏损可能。公司几乎没有有息负债（0.38 亿），固定成本以折旧 + 人工为主，收入 7 亿量级对应毛利约 1.6 亿，盈亏平衡点收入约 5.5 亿（对应当前收入下滑 22% 才触及）
- 真实风险点：①收入已连续 3 年零增长/负增长（2022 年 7.98 亿 → 2025 年 7.02 亿），若继续下滑 22% 并非不可能；②经营现金流 −1.187 亿，若牛肉储备形成减值，单季转亏存在可能

问2：靠什么维持盈利、触发时点？
- 靠门店净增 + 单店提效 + 团餐放量三条腿，全部是渐进变量，无单一触发时点
- 最近的可观测节点：2026 年报披露的门店净增数与团餐收入占比

问3：亏得起吗？
- 完全亏得起。净资产 12.37 亿、负债率 12.1%、账上现金充裕（现金比率 409.9%）、还能每 10 股派 2.80 元分红（3,825 万）
- 按当前成本结构，即使收入再降 20%，公司仍能维持正现金流与正利润，不存在生存问题
- 结论：下行风险是估值风险，不是生存风险

交叉校验：现价 20.48 元对应 2026E PE 33.0x（EPS 0.62 元）、2029E 中性 PE 18.5x。PE(TTM) 36.24x 高于 2026E 的 33.0x，说明市场已对"利润改善"给了溢价，当前定价不便宜。

- 相对行业折价：无——预制菜板块整体承压，公司 PE 高于安井（约 20x）、接近千味央厨，无显著折价

- 证伪信号：专利收入未在年报中体现 / 竞品快速复制 / 消费者不买账

什么条件出现才上调至"重点关注"：① 季度营收同比恢复至两位数（份额不再稀释——这是最关键的一条，权重最高）；② 股价回落至 16 元以下使中性空间扩大至 +80% 以上；③ 年报首次单列团餐收入且占比 ≥15%（证明主业迁移从故事变收入）。三者满足其一（①或③）+ 价格条件（②）即上调。

结论：纳入观察

核心矛盾：一家资产负债表极干净（负债率 12%）、利润正在改善（+28.89%）、但收入停滞（+0.69% vs 行业 +21.3%）的公司。
它的问题不是"会不会死"——绝对亏得起，也不是"会不会赚"——门店与团餐的逻辑成立。它的问题是份额正在被稀释，而当前 33x 的 2026E PE 已经把"份额回升"提前定价了。
真正的买点是两者之一：要么营收增速恢复两位数（证明剩者红利到账），要么股价跌到 16 元以下（把乐观假设挤出去）。在此之前，观察。
