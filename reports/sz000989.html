九芝堂（000989）五步法分析报告

分析日期：2026-09-24 ｜ 现价 8.52 元（2026-09-24 收盘价，腾讯行情核验）｜ 总市值 72.93 亿 ｜ PE(TTM) 22.17x ｜ PB 1.98x ｜ 总股本 8.56 亿股（流通 7.34 亿）

第一步：公司是干什么的？

一句话定位：300 余年中华老字号中药企业（始创 1650 年），以 OTC + 处方药中成药为基本盘，2025 年 11 月并表多肽原料药龙头吉象隆，形成"传统中药 + 多肽原料药 + 创新药 + 细胞治疗"多轮驱动。

核心产品：OTC——六味地黄丸、驴胶补血颗粒、足光散；处方药——疏血通注射液、注射用鹿瓜多肽；36 个独家中成药（疏血通、天麻钩藤颗粒、裸花紫珠片、补肾固齿丸、玉泉丸等）。吉象隆多肽原料药（生殖辅助、肝肾、消化、心血管领域）。

主要客户 / 下游：OTC 零售终端 + 医院处方 + 多肽原料药下游制剂厂。吉象隆为国家级专精特新"小巨人"。

境内外收入占比：国内为主，境外约 267 万（香港 / 美国 / 韩国 / 西班牙）。

股东背景：李振国（辰能创投）控股，2025 年完成控制权变更并签三年扣非 ≥ 9 亿对赌。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：OTC 传导率 ≈ 0.7（品牌可年提价）；处方药 ≈ 0.3（医保控费难转嫁）；多肽 ≈ 0.9（需求紧俏可顺价）。验证点：OTC 提价公告、处方药中标价；证伪：OTC 毛利率破 50%。
  • 因子2 毛利结构再平衡：分业务——处方药毛利率 70.48%（最高但下滑）、OTC 52.39%（改善）、多肽 54.92%（新支柱）。综合 59.33% 掩盖处方药承压；若处方药续降、多肽占比升，结构再平衡。验证点：各产品线毛利率。
  • 因子3 库存与采购节奏：中药材按季采购，库存收益有限；吉象隆多肽原料随行就市。验证点：中药材价格指数。
  • 因子4 政策 / 市场锚点：集采（处方药降价压力）、中药材战略收储（托底）、GLP-1 需求（多肽上行）。情景：若处方药集采扩围，毛利 −2pct；多肽需求续旺，毛利 +。验证点：集采目录、GLP-1 终端销量。

第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：OTC 六味地黄丸等细分市占率领先。
  • 客户份额：OTC 零售终端覆盖广；吉象隆进 GLP-1 多肽供应链。
  • 技术代际：36 个独家 + 多肽合成技术领先。
  • 成本曲线：OTC 规模 + 品牌，成本曲线左。
  • 份额加速度：华东 / 西南高增长渗透中。
    → 中性：吉象隆份额稳 + OTC 修复；乐观：处方药的再平衡。验证点：各区域 / 产品出货量。
  • 层2 扩展业务：主业迁移空间：从中药向多肽原料药（技术不同源，属并购切入新 TAM）迁移，吉象隆已验证（满产 + 大客户），已部分计入但扩产期权仍属中期。
  • 层3 证伪信号：吉象隆对赌未兑现、GLP-1 需求退潮、处方药集采致毛利破 60%。

第四步进阶·重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣（破净原因）：公司未破净（PB 1.98x），资产以现金 / 中药固定资产 / 吉象隆商誉为主，质量良好，高 PB 反映成长溢价，非风险。
  • 校正2 周期位置校正：中药属弱周期消费，不适用强周期校正；但处方药受政策周期（集采）影响，中性已保守处理处方药略降。
  • 校正3 杠杆下行情景：资产负债率低（净资产 36.78 亿、无大额有息负债），下行情景（悲观）空间仅 −1.3%，安全边际充足。

第五步：综合赔率判断（买不买？）

当前价格位置：低估 / 合理偏低。现价 8.52 元对应 2026E PE 14.0x，低于成长股合理 18–22x。

安全边际：中性远期 17.76 元 → 空间 +108.5%（> 50% 门槛）；悲观 8.41 元 → −1.3%（近乎保本）；乐观 25.70 元 → +201.6%。下行保护强。

介入条件：当前价位即具安全边际，可分批建仓；加仓信号：① 吉象隆对赌 2026 全年兑现；② 处方药降幅收窄；③ 创新药 YB211 进展公告。止损参考：跌破 7 元（2026E PE < 12x）。

最大风险：
1. 吉象隆对赌基数效应后增长不及预期（2026H1 已近三年累计额）；
2. 中药处方药集采扩围致毛利下滑；
3. GLP-1 多肽赛道竞争加剧（价格战）；
4. 东北大本营收入 −25.64% 持续萎缩。

结论：重点关注

业绩增长明确（归母 +74%）、行业景气向上（中医药扶持 + GLP-1 多肽爆发）、估值合理偏低（2026E PE 14x）、远期中性空间 +108.5% > 50%，满足"重点关注"全部标准。核心跟踪吉象隆对赌兑现与处方药修复。

第五步进阶·上行想象力情景（四类）

  • 类型A 行业调整剩者红利：中药老字号出清、集中度提升，公司品牌份额受益。验证点：中小药企退出；弹性：OTC 份额 +。
  • 类型B 政策反转期权：中医药扶持加码 / 处方药控费纠偏。验证点：扶持发文；计入机会情景。
  • 类型C 市场错杀修复：不适用（当前低估而非错杀）。
  • 类型D 技术突破 / 代际跃迁期权：吉象隆多肽从仿制向创新药 / GLP-1 新分子迭代，硬验证点（新产线良率 + 大客户定点 + 成本优于旧路线）已部分满足（满产 + 国家级小巨人），可部分计入中期。验证点：新产能投产 + 大客户长单。
  • 维持重点关注的条件：吉象隆对赌如期兑现 + 2026E PE 维持 < 18x。
