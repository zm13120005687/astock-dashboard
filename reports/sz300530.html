（3）产业链传导

上游：锂盐、正极、电解液、结构件。储能电芯成本中锂盐占比高，2026 年锂价低位运行利于降本，但系统价格同步下行（成本传导不完全），毛利被"量增价跌"对冲。

下游：源网侧 / 工商业 / 户储 / EPC。需求侧由容量电价与电力现货峰谷价差驱动，工商业储能在电价市场化后经济性改善。公司下游议价权弱——中小品牌、全国性大客户稀缺，订单体量偏小，价格被动跟随头部。

议价权判断：弱。依据：产能利用率极低、品牌弱、订单以区域中小项目为主，缺乏长协锁价能力；成本端锂价下行红利被系统价格战吃掉，转嫁系数（pass-through）偏低。

第二步进阶·原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（pass-through）：储能系统售价随锂价与行业价格战同步下行，公司无长协锁价、无规模优势，转嫁系数估计 ≈0.2–0.3（成本下降红利大部分被售价下行吞噬）。验证点：季度储能系统 ASP 与锂价背离幅度；证伪信号：若 ASP 跌幅持续大于锂成本跌幅，毛利率破 5% 以下。
  • 因子2 毛利结构再平衡：公司毛利高度依赖传统涂镀添加剂（毛利率 40.38%、占收入 23%）托底，新能源电池（74% 收入却仅 5.56% 毛利率）是毛利拖累项。加权后综合毛利率 14%，结构性"高增长低毛利"明显。正常化测算须对储能业务单独给保守毛利率（8–12%），对化工给 35–40%。
  • 因子3 库存与采购节奏：2025 年总资产从 13.43 亿骤降至 2026H1 的 6.50 亿（−51.60%，资产剥离 / 处置动力电池产线），存货与在制品大幅出清，不存在囤货收益干扰；但低稼动下单位折旧沉重，当期毛利不可简单外推为稳态。
  • 因子4 政策 / 市场锚点（成本驱动变量）：① 市场层——锂盐期货价格、碳酸锂库存周期；② 政策层——114 号文容量电价（提升储能项目 IRR，间接稳需求）、出口管制（若锂资源受限抬成本）、能耗双控（抬升高耗能材料成本）。情景：若容量电价各省落地加速 → 需求托底；若锂价反弹 +20% → 低成本库存耗尽后毛利率承压。验证点：13 省容量电价细则、碳酸锂期货价格。

第三步进阶·份额变量与主业迁移空间三层法

  • 层1 现有业务：市场容量 × 份额变量。供给侧：全国储能装机 1.53 亿千瓦，公司 3GWh 产能占比极小（<0.2%）；需求侧：靠衡阳国资区域项目背书拿单，但全国大客户缺失；技术代际：磷酸铁锂 314Ah 主流代，无代差优势；成本曲线：规模远落后于头部，处于曲线右侧（高成本）；份额加速度：负（行业集中度提升挤压中小厂）。三档：保守（份额守住区域）、中性（份额小幅提升）、乐观（区域示范项目放量）。验证点：逐季储能产量、在手订单金额披露。
  • 层2 扩展业务：主业迁移空间（新易盛范式）。公司从"卖电芯"向"电芯 + 系统集成 + 光储充 EPC"迁移，能力可迁移（同产业链），新 TAM（EPC+服务）大于纯电芯，但切入卡位为区域红海、客户认证门槛低。未过验证点，仅作中期期权，不计入中性净利。
  • 层3 风险折扣：证伪信号。若储能系统 ASP 跌破成本线、稼动率连续两季低于 20%、净资产因持续亏损转负（退市风险），则下调 / 剔除增量。

第四步：估值锚定（自下而上，非增速外推）

方法说明：公司 2026H1 仍亏损，PE 无意义，采用正常化净利润法（RULES 第四节）：估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价。明确声明：本研究不使用历史增速外推，营收来自产能稼动率与订单测算。

总股本约 1.80 亿股；2026H1 归母净资产 0.87 亿，资产负债率约 86%（高），连续五年亏损。

正常化净利润测算（2029E·中性）

  • 稳态营收：假设 3GWh 产能稼动率提升至约 50%（中性），储能系统 + EPC 营收约 13–14 亿（按 0.65 元/Wh 系统口径），加化工约 1.2 亿 → 合计约 15 亿。
  • 正常化净利率：储能业务保守 3%（价格战 + 低稼动），化工 12%，加权 ≈4%（取保守）。
  • 正常化净利润：15 亿 × 4% ≈ 0.60 亿（中性）；乐观（稼动率 80%、净利率 5%）≈ 1.10 亿；悲观（稼动率仍低、净利率 1%）≈ 0.15 亿。

⚠️ 第四进阶·重资产 / 困境股三道校正
- 校正1（破净原因）：公司 PB 高达约 33x（净资产仅 0.87 亿），并非破净而是净壳式高估；净资产单薄、连续亏损，当前市值 34.7 亿主要反映"国资保壳 + 储能反转期权"，非资产兜底。禁止凭 PB 推空间。
- 校正2（周期位置）：储能行业处于价格战出清底部，中性净利已用保守稼动率，未用单年好年景。
- 校正3（杠杆下行情景）：负债率约 86%、经营现金流持续为负，若利率上行 / 需求下行 / 融资断裂，公司可能净资产转负触发退市风险，净利可转负，不得标大空间。

亏损股必须回答的"三问"

  1. 为什么亏：① 产能利用率极低（3GWh 产能仅小幅利用），单位折旧沉重；② 储能系统价格战，新能源电池毛利率仅 5.56%；③ 减值与爬坡期费用拖累；④ 2025 年剥离动力电池产生一次性损失。属"产能爬坡期 + 行业价格战"型亏损，非主业彻底恶化。
  2. 靠什么扭亏，触发时点：核心看储能稼动率提升 + 规模效应 + 降本。路径：衡阳区域储能 / 光储充示范项目落地、海外户储放量、化工业务稳现金流。触发时点：中性假设 2027–2028 年扭亏，2029 年达正常化盈利。
  3. 亏得起吗（生存能力）：高风险但暂未濒危。账面净资产 0.87 亿、经营现金流 −0.35 亿（H1），靠衡阳国资背书持续融资输血；总资产 6.50 亿仍有缓冲。但连续五年亏损、净资产单薄，若 2 年内稼动率无实质提升，持续经营能力存疑——这是首要风险。

⚠️ 交叉校验：当前市值 34.7 亿，即便乐观情形（净利 1.30 亿 × 28x = 36.4 亿）也仅勉强覆盖现价；中性情形目标 6.67 元显著低于现价，现价已透支反转预期。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估 / 投机定价。现价 19.30 元对应中性目标价 6.67 元存在约 −65% 的安全边际缺口，市值主要反映"国资保壳 + 储能反转期权"。

安全边际：中性远期 6.67 元（−65.4%）；悲观 1.25 元（−93.5%）；乐观 20.2 元（+4.7%，需稼动率与海外双突破）。下行风险远大于上行。

介入条件：仅当① 储能稼动率连续两季 >40% 且单季扭亏；② 披露亿元级新增订单；③ 股价回落至 8 元以下（对应市值 <14 亿、接近乐观情形折扣）才具安全边际。

最大风险：① 连续亏损致净资产转负 / 退市风险；② 高负债 + 负经营现金流的融资断裂；③ 储能价格战致毛利破成本线；④ 区域订单依赖、全国大客户缺失。

上行想象力四类（调整型机会，仅进乐观 / 机会栏，不进中性锚）
- A 行业出清剩者红利：储能价格战出清后，具备国资背书与区域资源的中小厂若存活，份额与定价权跳升。验证点：行业 CR5 提升、公司稼动率跳升；证伪：持续价格战、稼动率不升。
- B 政策反转期权：114 号文容量电价各省落地、湖南区域储能示范加码，直接改善项目 IRR。验证点：13 省容量电价细则、湖南专项补贴；证伪：政策落地慢于预期。
- C 市场错杀修复：若随创业板小盘情绪错杀至 PB 接近 1x（约 2–3 元），存纯壳 / 重组期权。验证点：市值跌破 10 亿；证伪：基本面无改善。
- D 技术突破 / 代际跃迁期权：布局 587/588Ah 大容量电芯或固态电池中试。硬验证点（防画饼）：中试良率达标 + 客户定点 + 量产成本优于旧路线，三者缺一只作机会情景。证伪：研发无实质进展。

上调至"重点关注"的条件：储能稼动率连续两季 >50% 且单季归母转正、披露亿元级长协订单、经营现金流转正——届时重估中性目标价。

结论：暂不介入
