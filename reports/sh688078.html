第一步：公司是干什么的？

一句话定位：煤矿智能化软件龙头，以"龙软时空大模型（LoongModel）"为核心，提供井工 / 露天煤矿智能化解决方案、非煤矿山智能化、政府监管与智慧应急、绿色低碳等"多位一体"产品，处智能矿山工业软件赛道。

（3）产业链传导

上游：算力 / 数据 / AI 工具（外部采购），成本占比低；研发人力为主。成本传导弹性强（软件毛利高、原料影响小）。

下游：煤炭企业（国企，预算制），价格受招投标竞争约束，议价权中（先发技术壁垒但客户强势）。

议价权：中等偏强（透明地质 / 灾害预警核心技术壁垒 + 标准参与），但初中级项目同质化致降价。

第二步进阶·原料成本 → 毛利结构（四因子）
- 因子1 成本传导弹性（转嫁系数≈0.7）：软件业无大宗原料，成本以研发人力为主；下游国企招标压价时毛利被吃（H1 毛利率 −14.37pct 实证竞争降价）。验证点：毛利率能否回 30%+；证伪：破 20%。
- 因子2 毛利结构再平衡：定制软件 58.78%（毛利受降价冲击大）、技术服务 36.32%（复购、稳）、硬件 3.71%（低毛利）。结构优化=提升技术服务复购占比 + AI 高毛利新业务。验证点：AI 新业务毛利率 / 占比。
- 因子3 库存与采购节奏：软件无库存收益问题；主要"timing"是项目确认节奏（H1 营收仅 +1.82% 因项目确认延后）。验证点：Q3 收入确认。
- 因子4 政策 / 市场锚点：原料成本驱动=①财政（煤矿安全改造预算，正面托底需求）；②国企 CAPEX 节奏（煤炭景气影响智能化投资意愿）。情景：煤炭景气下行致智能化投资延后=需求风险；验证点：煤炭企业智能化招标量。

（3）第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：
  • 供给侧：智能矿山软件竞争者多（华为 / 龙软 / 其他），龙软凭透明地质 / 灾害预警壁垒居先发。份额锚点：核心产煤省验收项目占比（验证点：中标公告）。
  • 需求侧 / 客户份额：绑定大型煤企，客户集中度高、粘性强的（验证点：复购率）。
  • 技术代际差：时空大模型 LoongModel 领先一代（验证点：AI 场景入选）。
  • 三档：保守（订单稳、毛利 25%）/ 中性（AI 新业务占比 20%、毛利 32%）/ 乐观（AI 占比 35%、毛利 38%）。
  • 层2 主业迁移空间（新易盛范式）：从"煤矿软件"→"非煤 + 政府应急 + 绿色低碳"跨场景迁移，能力（时空智能 / CAE）可复用。但未过验证点（收入未披露量化），仅作中期期权。
  • 层3 证伪信号：煤炭智能化投资延后、毛利率破 20%、AI 新业务占比停滞 → 下调增量。

亏损股三问

  1. 为什么亏：初中级智能矿山建设项目竞争加剧（客户理性审慎、定价下降致毛利率 −14.37pct）+ 研发投入持续高位。属"竞争降价 + 投入期"性质，非主业消失（营收仍 +1.82%、Q2 环比改善）。
  2. 靠什么扭亏，触发时点：①2026 硬指标（智能化产能 ≥60%）+ 2030 目标驱动订单在 2026H2–2027 释放；②时空智能（AI）新业务（H1 订单 3000 万）占比提升、毛利结构改善；③费用管控。中性触发扭亏时点 2027 年。
  3. 亏得起吗：亏得起。轻资产软件公司、负债率低（无重资产 / 高有息债），2025 仍盈利 481 万，2026H1 亏 1488 万系经营性小幅亏损（经营现金流 −1377 万），现金消耗可控；净资产 ~6.6 亿提供安全垫。无断裂风险。

第四步进阶·重资产 / 周期股校正（三道闸）
- 校正1 资产质量折扣：轻资产，PB 3.19 反映无形资产 / 研发积累，非破净；无资产虚高。
- 校正2 周期位置校正：受"煤炭景气 + 智能化投资周期"影响，当前处政策冲刺期（2026 硬指标）需求上行，但初中级项目竞争加剧致毛利下行。中性净利已用"政策订单正常化"而非"单季亏损年化"，标注周期位置=需求上行但竞争加剧并存。
- 校正3 杠杆下行情景：负债率低，无杠杆反噬；下行主要来自竞争降价致毛利破 20%（悲观 −64.5%），非负债崩溃。
- 期权纪律：非煤 / 应急 / 绿色低碳未过验证点，不计入中性。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高。现价 28.96 元对应中性目标 23.7 元（−18.2%），且 2026 仍亏损；政策强但竞争压制短期盈利。

安全边际：中性 −18.2%；悲观 −64.5%（至净资产附近）；乐观 +19.5%（AI 转型成功）。PB 3.19 提供有限下行支撑。

介入条件：①回落至 22 元以下（接近基准 NAV、2026E 转盈预期 PE 合理）才具安全边际；②加仓信号：2026H2 归母转正、AI 新业务订单超 8000 万、毛利率回 30%+；③观察指标：煤矿智能化中标公告、Q3 盈利。

最大风险：①初中级项目竞争加剧致毛利持续下滑（首要）；②煤炭景气下行致智能化投资延后；③AI 新业务放量不及预期；④应收账款 / 回款风险（政府 / 国企客户）。

结论：暂不介入（当前亏损 + 竞争压制，中性空间 −18.2%；政策强但须等盈利拐点验证，若 2026H2 扭亏 + AI 订单放量可上调至纳入观察）

上调至纳入观察 / 重点关注的触发条件：2026H2 或 2027 归母转正且毛利率回 30%+，AI 新业务订单破亿，使 2029 正常化净利上修至 0.7 亿+（目标市值 ≥22 亿，空间转正并趋 +50%）。

第五步进阶·上行想象力情景（四类）
- A 行业调整剩者红利：煤矿智能化进入"深化期"，中小集成商出清，龙软凭透明地质 / 灾害预警壁垒份额与定价权跳升。验证点：份额数据、验收项目。
- B 政策反转期权：2026 硬指标 + 2030 目标（智能化产能 75%）硬约束，若考核加码 / 财政加码，订单跳升。验证点：政策发文、招标量；证伪：指标放松。
- C 市场错杀修复：若因风格切换被错杀至 PB 2x 以下（~14 元），凭政策刚需 + 低负债修复弹性大。验证点：估值分位。
- D 技术突破 / 代际跃迁期权：LoongModel 时空大模型从"煤矿"跃迁为"全矿山 / 应急 / 工业"通用时空智能平台，打开新 TAM。硬验证点：中试（AI 场景）跑通 + 客户定点（非煤 / 政府）+ 量产成本优于旧路线。当前硬验证点"非煤客户定点"待兑现，仅作机会情景。
