亏损股处理声明：2026H1 归母净利 +3082.96 万元看似为正，但扣非净利润 −3.49 亿元，盈利完全由债务重组损益 5.06 亿元（非经常性损益合计 3.8 亿）支撑。公司汽车零部件主业自 2023 年更名以来从未实现年度盈利，本报告按亏损股框架（正常化净利润法）处理，并回答"为什么亏 / 靠什么扭亏·时点 / 亏得起吗"三问。

（3）产业链传导

上游：钢铁、铝合金、火药药剂（气体发生器）、精密铸件。邦奇动力总成受欧洲能源与人工成本拖累。

下游：整车厂强议价，年降压力持续；安全气囊发生器因强制安全属性议价权相对较好（ARC 毛利率 22.43% 印证）。

议价权：ARC 中等偏强（安全件认证壁垒）；邦奇 弱（CVT 红海 + 新能源替代）。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：ARC 安全件传导率 ≈ 0.6–0.7（部分年降可转嫁）；邦奇动力总成传导率 ≈ 0.2（弱议价，成本自扛）。验证点：年报披露产品售价年降幅度；证伪信号：毛利率跌破 10%。
  • 因子2 毛利结构再平衡：分业务看——ARC（占收 67%）毛利率 22.43% 为正贡献，邦奇（26%）毛利率 11.48% 微利/亏损。综合毛利率 18.78% 掩盖了"一强一弱"结构；若邦奇持续亏损，合并毛利将被结构性拉低。验证点：邦奇分部毛利率转正；证伪：邦奇毛利率续降至 <8%。
  • 因子3 库存与采购节奏：汽车件按订单生产，库存损失风险低；但欧洲邦奇能源成本高点接货曾压制 2024–2025 毛利。验证点：欧洲能源价格指数。
  • 因子4 政策 / 市场锚点：关税（中美 / 欧美汽车件加税）抬升出口成本；原材料（铝 / 钢）期货波动。情景：若欧美加征汽车关税，ARC 出口毛利承压 2–3pct；验证点：关税清单发文。

第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：ARC 全球第二，产能利用率高；邦奇 CVT 全球份额小。
  • 客户份额：ARC 进全球主流车厂供应链，认证周期 = 粘性。
  • 技术代际：ARC 混合式发生器（PH-10）领先；邦奇 CVT 处行业中游。
  • 成本曲线：ARC 规模效应明显；邦奇左移困难。
  • 份额加速度：ARC 销量 +10.6%（加速）；邦奇持平。
    → 中性假设：ARC 份额稳、邦奇守成；乐观：邦奇减速器放量抢份额。验证点：下季度 ARC/邦奇 出货量与毛利率。
  • 层2 扩展业务：主业迁移空间：邦奇从 CVT 迁移至电驱减速器（技术同源），属"中期期权"，未过验证点（仅物流车小批量），不计入中性净利。
  • 层3 证伪信号：邦奇毛利率续降、ARC 大客户流失、债务重组不可持续致账面转亏。

第四步：估值锚定（自下而上，非增速外推）

方法说明：公司 2026H1 归母靠债务重组转正、扣非 −3.49 亿，属亏损股。采用正常化净利润法：估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价。明确剔除一次性债务重组 / 资产处置。

总股本：约 95.13 亿股（流通）/ 99.98 亿股（总）——股本庞大，是估值的核心压制因素（重整时大幅增发）。

第四步进阶·重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣（破净原因）：山子未破净（PB 9.48x 反而极高），但这是股本摊薄 + 题材炒作的结果，非资产安全垫。重整形成 95 亿股本，净资产仅 28.89 亿，BVPS 0.30 元。高 PB 是风险而非低估。
  • 校正2 周期位置校正：汽车零部件弱周期，但公司处于"债务重组续命"特殊状态，不能用任何单年（含 2025 债务重组年）外推；中性净利取"ARC 稳 + 邦奇平衡"的保守正常化值。
  • 校正3 杠杆下行情景：账面货币资金仅 3.1 亿，短期借款 3.8 亿，一年内到期非流动负债高达 9 亿，经营现金流 −1.47 亿。若债务重组中断 + 再融资受阻，存在流动性断裂风险，中性情景下行的下行可达 −95%。高贝塔属性明确。

亏损股三问

  1. 为什么亏：① 邦奇动力总成毛利率仅 11.48%、规模不足行业平均一半，持续经营亏损；② 期间费用率高达 40.99%；③ 整车业务（已剥离）曾亏损；④ 2026H1 归母靠债务重组 5.06 亿，扣非 −3.49 亿。
  2. 靠什么扭亏·触发时点：① ARC 满产稳定贡献正现金流（已具备）；② 邦奇欧洲重组 + 减速器电驱量产降本，预计 2027–2028 年分部扭亏；③ 持续资产处置 / 债务重组缓冲。触发条件：邦奇分部毛利率转正 + 费用率降至 30% 以下。
  3. 亏得起吗：净资产 28.89 亿尚可覆盖，但流动性承压严重（短债 + 一年内到期 12.8 亿 vs 货币资金 3.1 亿），依赖再融资与债务重组续命。短期不会资不抵债，但"倒在黎明前"风险高。

第五步：综合赔率判断（买不买？）

当前价格位置：严重高估。现价 2.74 元隐含正常化 PE 137x+，PB 9.48x，与扣非持续亏损、95 亿股本的基本面完全背离。

安全边际：中性远期 0.32 元 → 空间 −88.3%；悲观 0.13 元 → −95.3%。下行几乎无底，上行取决于不可持续的债务重组与题材。

介入条件：仅当股价回落至 0.4 元以下（对应市值 < 40 亿、正常化 PE < 20x）且邦奇分部出现连续两季扭亏证据时，才具安全边际。当前价位绝不介入。

最大风险：
1. 债务重组不可持续 → 账面转亏、流动性断裂（首要）；
2. 邦奇动力总成持续亏损，95 亿股本摊薄使每股盈利难修复；
3. 题材退潮（半导体 / 华为汽车无实质业务）后估值回归；
4. 短期债务集中到期（9 亿一年内到期）再融资风险。

结论：暂不介入

公司具实质业务（ARC 全球第二、邦奇 CVT），存在扭亏路径，故不判"坚决回避"；但现价较正常化估值高估 4–7 倍，且扣非从未年度盈利、流动性承压，风险收益极度不对称，暂不介入。若未来邦奇扭亏 + 股价回落至 0.4 元以下，可重新评估。

第五步进阶·上行想象力情景（四类）

  • 类型A 行业调整剩者红利：全球气体发生器 CR3 集中，ARC 若收购整合小厂可提份额。验证点：并购公告；证伪：份额流失。
  • 类型B 政策反转期权：汽车以旧换新加码刺激安全件需求。验证点：补贴加码发文；仅作机会情景。
  • 类型C 市场错杀修复：不适用（当前为题材溢价而非错杀）。
  • 类型D 技术突破 / 代际跃迁期权：邦奇减速器从 0 到 1 切入电驱，硬验证点（中试良率 + 客户定点 + 量产成本优于旧路线）尚未满足，仅作机会情景，不计入中性。
  • 上调至重点关注的条件：邦奇分部连续两季扭亏 + 股价回落至正常化 PE < 20x + 债务重组退出后账面仍盈利。
