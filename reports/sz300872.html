天阳科技（300872）五步法分析报告

分析日期：2026-09-19 ｜ 现价 15.16 元（2026-09-18 收盘）｜ 总市值 73.98 亿 ｜ PE(TTM) 约 −55.7x（2025 全年亏损致 TTM 为负）｜ PB 2.07x（净资产 35.76 亿）｜ 总股本 4.881 亿股
行业：金融科技（银行 IT）+ 算力租赁（第二曲线）｜ 板块：创业板
盈利股处理（审慎核对扣非）：队列标"亏损"为 TTM 误标——2026H1 归母 +0.60 亿、已扭亏，但扣非仅 −0.07 亿（仍微亏）且经营现金流 −3.41 亿。按盈利股做五步法，但从严：估值以扣非+主业为锚，剔除一次性补助，并单列现金流与期权风险。

第一步：公司是干什么的？

一句话定位：以银行为主的金融机构提供咨询、金融科技、场景运营服务的金融 IT 厂商，正把"算力租赁"与"航空互联网"列为第二增长曲线，是典型的"传统主业承压 + 新故事未兑现"型软件公司。

本步关键判断（失血 vs 弹性）：
- 失血点：传统技术开发类收入 −19.73%、毛利率仅 26.13%，银行 IT 投入放缓致主业收缩；2026H1 扣非仍亏 −693 万，盈利靠 6594 万政府补助撑起；经营现金流 −3.41 亿（应收账款/合同资产占用，同比恶化）。
- 弹性点：算力租赁（4–5 年长期协议、首批资源交付就绪）、航空互联网（10 年合同）、海外（香港/东南亚）为潜在第二曲线，但均未形成规模收入。

（3）产业链传导

上游：人力（研发/实施人员，占成本 ~70%）、算力设备（GPU 服务器等，重资产投入）。人力成本是核心，刚性且随薪酬上涨。

下游：银行（议价权强，压价 + 长账期），导致公司应收账款高、现金流差。

议价权判断：弱。面对大客户银行，公司在定价与回款上均处弱势（毛利率仅 26%、经营现金流 −3.4 亿即验证）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（转嫁系数）：人力成本无法转嫁（转嫁系数≈0，软件业通病）；算力设备折旧由新业务自担。综合转嫁系数≈0.1，成本刚性吞噬毛利。
  • 因子2 毛利结构再平衡：技术开发类毛利率 26.13%、其他技术服务类更高（整体 24.73%）。新业务（算力租赁）毛利率结构不同（重折旧、规模效应后高毛利），但当前未放量，不能用整体 24.73% 代表新业务结构。
  • 因子3 库存与采购节奏：软件业无存货但合同资产/应收账款等同"已发生未回款成本"——2026H1 应收 +34.86%、经营现金流 −3.41 亿，显示"做单不等于收钱"，须区分账面收入与真实回款。
  • 因子4 政策/市场锚点：① 银行科技预算（负向，压降则收入缩）；② 算力 GPU 供给/价格（影响算力租赁成本与回报）；③ 信创节奏（正向，国产替换订单）。情景：银行预算回暖+算力需求强 → 主业企稳+新业务放量；预算继续压降+GPU 跌价 → 双杀。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：银行 IT 厂商众多（宇信、长亮、天阳等），份额分散；2. 需求侧：银行客户集中，前五大客户占比高；3. 技术代际：AI 原生平台属行业中游，无代际领先；4. 成本曲线：规模效应弱（人力密集型）；5. 份额二阶导数：技术开发类 −19.73%，份额在流失。中性：守住存量；乐观：信创订单抢份额；悲观：继续流失。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：① 能力可迁移：金融 IT 技术 → 算力租赁（弱相关，需重资产）/航空互联网（场景运营，中相关）；② 新 TAM：算力租赁（千亿）、航空互联网零售金融（新）；③ 卡位：先发布局但竞争激烈；④ 客户认证：银行/航空客户认证门槛高（护城河也是阻力）；⑤ 信号验证：未形成规模收入、合同金额未披露。属中期期权，未过验证点，不计入中性。
  • 层3 证伪信号：技术开发类收入继续双位数下滑、经营现金流持续为负、算力租赁/航空合同无收入确认、海外订单无批量落地。

第四步：估值锚定（自下而上，非增速外推）

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非破净（PB 2.07x），但净资产 35.76 亿中含大额应收账款/合同资产与商誉类无形资产（2026H1 无形资产 +119.51%、应收 +34.86%），资产质量需打折；算力设备新增重资产若回报不及预期将计提减值。
  • 校正2 周期位置校正：非强周期，但银行 IT 处"预算放缓"下行段，中性净利已用保守扣非，未用 2026H1 含补助的虚高归母外推。
  • 校正3 杠杆下行情景：资产负债率约 24%（表观低），但经营现金流 −3.41 亿、货币资金 −55.79%，真实流动性压力被低负债率掩盖；若新业务持续烧钱+主业回款恶化，现金流可进一步转负、估值下修，悲观情景空间 −94.6%，不得标大空间。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。现价隐含中性 PE 74x，已把算力租赁/航空互联网期权全部定价，而期权均未形成收入。

安全边际：
- 中性远期 5.12 元 → 空间 −66.2%
- 悲观 0.82 元 → −94.6%
- 乐观 15.37 元 → +1.4%（需三曲线全部放量）
- 下行保护：PB 2.07x、净资产 35.76 亿（但含质量存疑资产），实际安全边际薄弱

介入条件：
1. 现价 15.16 远高于所有情景，不追高；
2. 价值介入区：回落至 5–6 元（接近中性锚）且需新业务收入兑现验证；
3. 加仓信号：① 算力租赁确认规模收入（年化 >1 亿）；② 经营现金流回正；③ 技术开发类收入止跌回升。

最大风险：① 盈利依赖政府补助（扣非仍微亏）；② 经营现金流持续大额为负、回款恶化；③ 算力租赁/航空互联网投入大、回报不及预期；④ 传统银行 IT 订单继续流失。

结论：暂不介入

公司真实盈利能力弱（扣非微亏、现金流 −3.4 亿），当前 74 亿市值完全建立在对算力/航空/海外三条未兑现曲线的期权定价上。属"概念多但基本面支撑不足、安全边际缺失"，不符合重点关注/纳入观察条件。仅当新业务实质放量且股价回落至 5–6 元，才值得重新评估。

第五步进阶：上行想象力四类（对称补回上行侧）

  • 类型A 行业调整剩者红利：银行 IT 中小厂商出清，头部（宇信/长亮/天阳）份额提升 → 验证点：行业集中度、公司订单份额；但当前公司技术开发类 −19.73%，暂未受益。
  • 类型B 政策反转期权：若银行科技预算回暖（金监总局鼓励金融科技）+信创加速 → 主业修复；验证点：银行资本开支指引上调。
  • 类型C 市场错杀修复：若市场将"含补助的归母增长"误读为真实改善后证伪而超跌，反之若新业务兑现则为重估 → 双向，非单纯修复。
  • 类型D 技术突破/代际跃迁期权：算力租赁从 0 到 1（AI 算力需求爆发）+航空互联网运营落地，政策（算力基建）+趋势（AI）+落地（长期协议/10年合同）三要素部分共振；硬验证点：规模收入确认+量产回报优于旧路线——未满足（无规模收入），仅作机会情景。若三曲线共振兑现，则上调"重点关注"。
