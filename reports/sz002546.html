行业：电器/智能用电（用电信息采集 + 工业大数据云服务）｜ 板块：深市主板 ｜ 实控人：自然人（胡敏等）
盈利但主业薄：2026H1 归母 4.53 亿中 3.81 亿为非经常性金融资产公允价值变动，扣非仅 0.72 亿——估值须正常化至主业。

第一步：公司是干什么的？

一句话定位：国网/南网用电信息采集设备核心供应商，主业为电力终端与智能用电云服务，账面大额利润来自闲置资金理财与金融资产公允价值变动。

核心产品：集中器/采集器/专变终端、配用电监测终端、环保设施工况用电监测系统、综合能源服务平台。

主要客户/下游：国家电网、南方电网及其成员企业（主）、环保/工业企业（数据服务）。客户集中度高、依赖电网招标节奏。

境内外收入占比：几乎全部国内（华东 56.91%、华中 26.75%、华南 7.41%）。

财务特征：资产负债率仅 8.50%，货币资金充裕，账面金融资产规模大（驱动公允价值变动收益）；经营现金流 2026H1 转负（−0.35 亿）。

（3）产业链传导

上游：芯片/电子元器件/结构件 → 成本随半导体与金属价格波动，转嫁能力中（国网招标定价）。
下游：电网（强议价，账期长）、环保企业（分散）。公司议价权中偏弱（招标制、价格战）。
议价权判定：对电网弱（买方定价的集采），对环保客户中。主业利润被招标压价侵蚀。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：芯片/元器件涨价时，国网集采价锁价，转嫁系数≈0.3，毛利承压；当前格局是"价稳量缩+竞争"，毛利靠结构（高毛利数据服务占比小）。
  • 因子2 毛利结构再平衡：电力产品（87% 收入）毛利率 35.4% 但占比绝对主导；数据服务（2%）毛利率 67.8% 高但体量小，无法撬动整体。单一综合毛利率 37.98% 掩盖——真实盈利靠金融资产而非结构改善。
  • 因子3 库存与采购节奏：电子料无显著囤货收益；主业按订单生产，无库存套利。金融资产"公允价值变动 4.36 亿"属未实现收益，非经营盈利。
  • 因子4 政策/市场锚点：①市场层——芯片价格、招标竞价强度；②政策层——电网投资节奏（决定订单）、环保监测强制覆盖（决定数据服务）。情景：电网投资加速→主业订单回升；验证点：国网招标公告、公司新签订单。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：用电信息采集行业成熟，份额稳定，公司居国网核心供应商；
  • 需求侧：国网/南网份额粘性高（认证壁垒）；
  • 技术代际：中游，无代际领先；
  • 成本曲线：无显著左侧优势；
  • 份额加速度：持平（招标平缓）。验证点：下季度中标份额。
  • 层2 扩展业务：主业迁移空间：从"硬件终端"向"用电云/综合能源服务"迁移，能力可迁移（同源），新 TAM（工业大数据/虚拟电厂）弹性大，但数据服务占比仅 2%、信号未跳升 → 未过验证点，仅作中期期权。
  • 层3 证伪信号：电网招标继续零增长、扣非利润再降、金融资产收益回撤 → 下调。

第四步：估值锚定（自下而上，非增速外推）

总股本 8.01 亿股。正常化方法：剔除一次性金融资产公允价值变动，用扣非主业 + 可持续投资收益锚定。

正常化净利润拆解

  1. 主业（扣非）：2026H1 扣非 0.72 亿 → 年化 ~1.4 亿（假设 H2 持平，非增速外推，系订单节奏）。
  2. 可持续金融收益：账面大额金融资产，按 3—4% 稳健回报估 ~1.0—1.5 亿/年（区别于一次性公允价值跳动）。
  3. 正常化净利（中性）：~2.0—2.5 亿（主业 1.4 + 可持续投资 0.6—1.1，剔除一次性 4.36 亿）。

基准（2026E）

  • 归母账面 ~6—7 亿（含金融资产收益），但正常化口径 ~2.3 亿。
  • 给 PE：主业成长平淡，综合 18—20x → 市值 41—46 亿 → 5.1—5.7 元。

交叉校验：现价 7.28 对应市值 58.3 亿，是正常化目标市值 44 亿的 1.33 倍；市场按"账面归母 4.53 亿 × 8.5x"定价，但该利润 84% 为金融资产公允价值变动（不可持续）。若收益回撤，公允价值亦可能反向拖累。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（相对正常化盈利）。7.28 元已反映金融资产收益的一次性高利润，主业仅支撑 ~5.5 元。

安全边际：中性远期 5.49 元 → 空间 −24.6%；悲观 2.25 元（−69.1%）；乐观 9.61 元（+32.0%，需主业+投资双升）。

介入条件：① 现价回至 5.5 元以下（正常化 PE<18x） 才具安全边际；② 加仓信号：电网招标放量、扣非利润恢复正增、金融资产收益结构转为稳定利息而非公允价值跳动；③ 观察：经营现金流转正、数据服务占比跳升。

最大风险：① 金融资产公允价值变动回撤（首要，2026H1 占利润 84%）；② 电网招标持续平缓、主业扣非再降；③ 理财收益受市场波动扰动；④ 低负债但主业增长乏力。

结论：暂不介入

公司账面利润与主业严重背离，84% 来自不可持续的金融资产公允价值变动。正常化后公允值约 5.5 元，现价透支。仅当电网投资加速使主业扣非修复、且金融资产收益转为稳定利息，才上调至纳入观察。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：用电信息采集行业出清，公司凭国网核心供应商份额提升 → 验证点：中标份额公告。
  • B 政策反转期权：电网投资若由"平缓"转"加速"（配网/虚拟电厂政策加码），主业订单放量 → 验证点：电网投资规划上调、招标大增；满足则上调纳入观察。
  • C 市场错杀修复：若因金融资产收益波动被错杀至 PB<1x（<4.2 元），修复弹性大。
  • D 技术代际跃迁期权：用电云/综合能源向虚拟电厂、AI 能效跃迁，数据服务占比跳升 → 硬验证点：数据服务收入占比>10%、大额平台订单；未达仅作机会情景。
