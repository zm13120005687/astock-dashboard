上游：基础油（占润滑油成本约 70–80%）、添加剂（四大添加剂公司：路博润/润英联/雪佛龙奥伦耐/雅富顿）、乙二醇（防冻液）、尿素（尾气处理液）。

- 公司与世界四大添加剂公司保持战略合作，开发多种油源，大宗物资由招标委员会统一招标竞价。

下游：经销商（三级体系）、终端门店、商用车队、工业客户、车企。

议价权判定：中等偏弱。依据：
- 基础油 +12.1% 而车用润滑油售价仅 +1.6% → 成本传导率仅约 13–18%，绝大部分成本上涨由公司自行消化；
- 尾气处理液售价 −18.4%（在需求刚性的情况下仍被压价）→ 该品类完全无定价权；
- 唯一有提价能力的是防冻液（+8.9%），因新能源热管理低电导率冷却液稀缺。

关键结构迁移：2026H1 综合毛利率 24.52% 同比 +1.55pct，完全掩盖了 Q1（约 29.4%）→ Q2（17.25%）的断崖式下滑。真正的结构变化是：①高毛利防冻液（新能源热管理）占比正在上升（唯一亮点）；②低毛利、无定价权的尾气处理液占比高达 25% 且在恶化；③主力车用润滑油因基础油涨价毛利被吞噬。用单一综合毛利率会严重误判——实际盈利能力在 Q2 已经崩塌。

因子 3｜库存与采购节奏（timing）
- 公司在投资者关系活动中明确："紧盯行业动态、判断行情适时调整采购策略，集中采购大宗物资全部由招标委员会统一招标、竞价"；"开发多种油源保证采购价格竞争力"。
- 无任何套期保值披露 → 对冲比例视为 0。
- 低价囤货收益：Q1 毛利率高达约 29.4%，很可能有 2025 年低价基础油库存的贡献 → Q1 的高毛利含不可持续的库存收益；Q2 高价基础油入库后毛利率立即回落至 17.25%，完美验证了库存收益的 timing 效应。
- 结论：不能把 Q1 的盈利水平当作真实盈利能力，Q2 才是基础油 +12.1% 完全传导后的真实状态。
- 验证点：存货余额环比、季度毛利率与基础油现货价的错配。证伪：基础油价格回落但毛利率不修复（说明是竞争而非成本问题）。

因子 4｜政策/市场锚点（原料成本驱动变量）
- 市场层：①OPEC+ 与地缘冲突 → 原油；②韩国 SK、埃克森美孚等亚太基础油产能与减产；③尿素价格（受化肥出口政策影响）；④乙二醇（煤制/油制路线成本）。
- 政策层：①关税/贸易政策——基础油进口关税与反倾销；②《能源法》与氢能补贴——影响氢能业务投入回报；③国六 B 强制标准——推动高端油品迭代（正向）；④环保监管趋严——劣质散装车用尿素出清（正向，利好头部）。
- 情景：①乐观——原油回落、基础油 −10%，同时防冻液/工业油结构提升 → 毛利率回到 27%；②中性——基础油高位震荡，产品结构改善部分对冲 → 毛利率 24–25%；③悲观——基础油继续 +10% 且传导失败 → 毛利率跌破 18%，全年亏损。
- 验证点：季度经营数据中的基础油采购均价、各产品线售价、综合毛利率。证伪：连续两季毛利率 < 18%。

→ 本因子输出（喂给第四步）：2026 全年毛利率约 22–23%（H2 继续承压）；2029 中性 25–26%（靠防冻液/工业油结构提升对冲，但不回到 Q1 的 29.4%）；悲观 19–20%。

第三步进阶：份额变量与主业迁移空间（三层法）

层 1｜现有业务：市场容量 × 份额变量
1. 供给侧份额：润滑油行业产能总体过剩，公司非产能龙头（龙蟠科技营收规模超百亿），份额提升靠渠道下沉而非产能。
2. 需求侧/客户份额：渠道覆盖 31 省、下沉至县域，"骑士荟"终端门店网络扩容 → 渠道密度是核心份额锚点。国际品牌难以触达县域，本土头部在国产替代中获益。
3. 技术代际差：与壳牌/美孚在高端全合成上仍有一代差距；但在新能源专用油液（低电导率冷却液）上处于同一起跑线——这是唯一可能形成代际优势的赛道。
4. 成本曲线位置：规模小于龙蟠，采购议价权中等（靠"开发多种油源 + 招标委员会竞价"），成本曲线居中偏右。
5. 份额二阶导数：传统内燃机油已饱和且开始下滑；新能源热管理液处于加速渗透前段；车用尿素处于价格战出清中段。
- 三档：保守（车用油份额守住、总量 −3%/年）／中性（防冻液与工业油合计占比从 18.5% 提至 25%）／乐观（新能源热管理液拿到 3 家以上车企定点，占比突破 35%）。
- 验证点：季度分品类销量与均价、车企定点公告、"骑士荟"门店数量。证伪：车用润滑油销量连续三季同比负增长且防冻液均价回落。

层 2｜扩展业务：主业迁移空间（氢能）
1. 能力可迁移性：润滑油（催化剂/添加剂配方 + 精细化工）与燃料电池催化剂、膜电极有一定技术同源性，但工艺与认证体系差异大 → 迁移成本中等偏高。
2. 新 TAM 弹性：氢能 TAM 远大于润滑油，且受《能源法》与国家能源局氢能试点政策支持 → 弹性极大。
3. 切入卡位：早期（2021 年起布局，参股新能催化 + 控股氢启科技）。
4. 客户认证门槛：极高——燃料电池催化剂/膜电极需通过电堆厂与整车厂长周期认证（2–4 年）。
5. 信号验证：部分通过但未达硬标准——公司称"参股的氢能催化公司已经具备稳定的量产交付能力"，但半年报未披露氢能业务收入金额、无大额订单公告、无车企定点公告。
- 结论：仅作中期期权，未过验证点 → 不计入中性情景。

层 3｜风险折扣：证伪信号
- 氢能业务连续两年收入未过 5,000 万 / 无车企定点公告
- 车用润滑油销量连续三季同比负增长
- 综合毛利率跌破 18%（成本传导彻底失败）
- 控股股东/一致行动人继续减持（当前已顶格减持 1%，剩余持股 51.98%）
- 单季归母净利连续两季为负（Q2 已出现一次）

第五步：综合赔率判断（买不买？）

当前价格位置：明显偏贵，属主题定价。现价 12.81 元对应 2026E PE 63.2x、2029E PE 51.3x、PB 2.70x。基本面：营收 −8.54%、归母 −19.32%、Q2 单季转亏 −309 万、ROE 3.56%、控股股东刚顶格减持。价格与基本面严重背离——市场在为"氢能第二曲线 + 新能源热管理液"两个尚未兑现的故事付钱。

安全边际：
- 中性远期 7.00 元 → 空间 −45.4%，三年年化约 −18.2%
- 悲观 5.00 元 → 下行 −61.0%（对应 PB 1.0 的资产硬底）
- 乐观 19.50 元 → 上行 +52.2%（但需氢能与热管理液双双兑现）
- 赔率结构：上行 +52.2% vs 下行 −61.0%，且上行概率显著低于下行（因两个故事均未过验证点）
- 唯一的下行保护：负债率 15.17%、净资产 12.15 亿（每股 4.74 元）、经营现金流 0.96 亿 → 公司不会出事，只是不值这个价

介入条件：
1. 当前不介入。回落至 7.50 元以下（PB < 1.6、2027E PE < 31x）才进入可讨论区间；6.00 元以下（PB < 1.3）才具备安全边际。
2. 加仓信号（必须同时看到至少两条）：① 氢能业务首次单独披露收入 ≥ 5,000 万，或拿到电堆厂/整车厂定点公告；② 新能源热管理液获得 ≥ 3 家车企定点；③ 单季综合毛利率回升至 25% 以上且连续两季。
3. 观察指标：季度经营数据中的"基础油采购均价 vs 各产品售价"剪刀差；单季归母净利是否连续为负。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 成本传导失败（首要）：基础油 +12.1% 而售价仅 +1.6%（传导率约 15%），Q2 毛利率已从 29.4% 崩至 17.25%、单季转亏。若基础油维持高位而公司无法提价，全年利润将被吞掉。
2. ⚠️ 尾气处理液价格战失控：占收入 25% 的品类均价 −18.4%，若继续恶化将由"低毛利"转为"负毛利"。
3. ⚠️ 估值主题退潮：市值 63% 是主题溢价，氢能若迟迟不兑现，PB 从 2.70 向 1.0–1.5 回归即 −45% 至 −60%。
4. 控股股东减持信号：在"营收净利双降"背景下顶格减持，剩余持股 51.98% 仍有继续减持空间。
5. 新能源渗透率超预期：加速侵蚀传统内燃机油基本盘。

类型 A 行业调整剩者红利 ✅ 部分适用（车用尿素）
车用尿素（尾气处理液）行业正经历"劣质散装产品加速出清"的监管驱动整合，头部企业凭稳定原料、油站与车队直供渠道抢占市场。康普顿已布局 237 个智能加注驿站（APP 预约 + 自动识别 + 电子发票，单次加注 47 秒），是"低价换流量、流量带生态"的打法。
- 上修测算：若出清后行业 CR5 提升、价格战见底，尾气处理液均价从 700 元/吨修复至 850 元/吨，可给 2029E 收入 +0.48 亿、净利 +0.10 亿 → 中性净利至 0.74 亿，目标价升至 8.10 元（−36.8%）。

类型 B 政策反转期权 ✅ 适用（氢能，最强上行来源）
- 具体政策：①《氢能产业发展中长期规划（2021—2035年）》；②《能源法》（2025-01-01 施行，首次将氢能纳入能源管理体系）；③国家能源局氢能试点。
- 反转信号：燃料电池汽车示范城市群扩容、国家氢能补贴细则落地、绿氢强制替代比例出台。
- 重估弹性测算（已量化进乐观情景）：公司已布局"制氢催化剂 → 储氢催化剂 → 燃料电池催化剂 → 工业副产氢发电 → 氢气制储运装备 → 氢燃料电池核心部件"全链条，参股的新能催化已具备稳定量产交付能力。若催化剂/膜电极在 2028–2029 年实现 3 亿收入（净利率 15% = 0.45 亿），叠加估值体系从"润滑油 25x"切换至"氢能材料 40x"，可给市值 +15~20 亿 → 乐观 19.50 元（+52.2%）。
- 证伪信号：氢能业务连续两年收入未过 5,000 万、无车企/电堆厂定点、氢能补贴退坡早于量产。
- 纪律：未过验证点，仅作机会情景，不计入中性锚。 ✅ 已遵守。

类型 C 市场错杀修复 ❌ 不适用
现价 PB 2.70、PE(TTM) 80.80，处于自身估值高位分位；相对同业（龙蟠科技、德联集团）为溢价而非折价；且基本面在恶化（营收 −8.54%、Q2 转亏）。不存在错杀证据，此项不成立。

类型 D 技术突破/技术代际跃迁期权 ⚠️ 仅作机会情景（新能源热管理液）
- 公司完成蔚蓝新能源商用车全系油液开发，布局低电导率长效型新能源专用冷却液（新能源车电池热管理刚需），并在氢燃料电池空压机专用润滑脂、风电齿轮箱长效合成油完成小批量验证。
- 三要素共振检验：①政策驱动——新能源车渗透率政策明确，但非"强制替代"；②行业趋势收敛——热管理系统从防冻介质升级为整车热管理综合方案，趋势成立但未到渗透率拐点；③公司落地——"小批量验证"不等于中试良率达标，且无车企定点公告、无量产成本优于旧路线的证据。
- 硬验证点（防画饼）：①拿到 ≥ 3 家车企/主机厂正式定点；②新能源冷却液年收入 ≥ 1 亿；③量产毛利率 > 35%（证明成本优于旧路线）。三者缺一 → 只作机会情景，不计入中性锚。
- 证伪：定点流失、毛利率打不过传统防冻液、竞品（龙蟠等）率先规模化。

什么条件出现才上调至"重点关注"：必须同时满足——① 氢能业务首次单独披露年收入 ≥ 1 亿，或拿到电堆厂/整车厂正式定点；② 新能源热管理液获 ≥ 3 家车企定点且年收入过 1 亿；③ 股价回落至 7.50 元以下（此时中性空间转正、乐观空间 >+150%）。
目前三条均未满足 —— 氢能与热管理液两个期权全部停留在乐观栏，中性锚 −45.4% 不调整。

结论：暂不介入

理由：中性远期空间 −45.4%（不满足"纳入观察"所需的 >0），且上行依赖两个均未过验证点的期权。

问题在于价格：现价把"氢能第二曲线"这个连收入金额都未披露的期权，按 20 亿市值提前定价了。
核心跟踪点：① 季度基础油采购均价 vs 产品售价的剪刀差；② 单季归母净利是否连续为负；③ 氢能业务收入是否首次单独披露。
