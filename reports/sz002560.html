第一步：公司是干什么的？

一句话定位：中西部线缆骨干企业，三大板块——电线电缆（含特高压/超高压工程线缆）、航空器零部件精密加工及装配、铝基复合新材料，是国家电网/特高压核心供应商之一。

（3）产业链传导

上游（原料成本——核心矛盾）：铝（占线缆成本主体）、铜。2026H1 国内铝价持续高位，公司部分"闭口价"中标订单（投标到交付有周期）在 Q2 集中交付时采购成本显著高于合同基准，形成阶段性成本倒挂。→ 议价权：对上游弱（铝价随行就市，闭口价锁死售价），对下游中等（电网客户强，难转嫁）。

下游：电网央企资本开支强，订单充足；但电网压价+闭口价机制使成本波动由制造商承担。

→ 第二步进阶·原料成本→毛利结构（四因子）
- 因子1 成本传导弹性（转嫁系数）：闭口价订单转嫁系数 ≈0（成本自担）；价格联动型订单转嫁系数 0.8–1.0。2026H1 倒挂因历史低价闭口订单占比高，转嫁系数极低是利润塌方主因。
- 因子2 毛利结构再平衡：线缆毛利率（含特高压）为利润主体但 Q2 转负；铝板带（有色金属）本来毛利率极低（商品属性）；航空零部件毛利率较高但收入占比小。结构上一旦线缆倒挂，综合毛利被铝板带稀释，整体净利率逼近 0。
- 因子3 库存与采购节奏：H1 存货 +42.92%（7.56 亿），部分高位接货（库存损失）；Q2 用高价库存交付闭口订单→毛利承压。若后续铝价回落，则库存收益反哺——当期与远期毛利不可比，须剔除库存 timing。
- 因子4 政策/市场锚点：① 铝价（LME/沪铝）为第一成本变量（验证点：沪铝主力合约）；② 电网投资规划托底需求（利好）；③ 无出口管制直接冲击。情景：铝价回落 10%→特高压毛利率修复 3–4pct；铝价续涨→倒挂延续（证伪信号：毛利率连续两季 <1%）。

→ 第三步进阶·份额变量与主业迁移空间（三层法）
- 层1 现有业务：市场容量 × 份额变量
1. 供给侧：特高压线缆产能头部集中，通达为中型，扩产节奏温和。
2. 需求侧：进国网/南网核心供应商名录（认证壁垒=粘性）。
3. 技术代际：特高压线缆技术成熟，代际差异小，比拼交付与成本。
4. 成本曲线：规模化+铝价套保能力决定成本曲线位置。
5. 份额加速度：电网招标放量期份额稳中有升。
→ 三档：保守（营收零增）→ 中性（线缆年增 10–12%）→ 乐观（特高压份额提升+航空恢复，年增 18%）。验证点：逐季中标公告、国网招标份额。
- 层2 扩展业务：主业迁移空间：航空零部件由线缆能力延伸（精密加工同源），新 TAM 为军工/大飞机；目前收入下滑，处"客户认证+节奏"阶段，未过验证点（航空收入跳升公告），仅作中期期权，不计入中性。
- 层3 证伪信号：铝价续涨且联动切换慢、中标份额下滑、经营现金流持续大额负、航空需求再降 → 下调。

→ 第四步进阶·重资产/周期股估值校正
- 校正1 资产质量折扣：非破净（PB 1.79x），不适用；但 47.87 亿市值对应 26.79 亿净资产，溢价来自电网预期。
- 校正2 周期位置校正：公司处铝价周期+电网周期叠加——铝价高位（成本压力）、电网高位（需求利好），当前属成本压制期。中性净利 2.0 亿 为正常化（剔除倒挂异常），已保守，未用单季年化。
- 校正3 杠杆下行情景：资产负债率约 50.6%（总资产 54.18 亿/净资产 26.79 亿），经营现金流 −4.83 亿（重资产+营运资金占用），若利率上行+铝价续涨+需求下行，净利可转负，悲观情景 −62%，不得标大空间。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵 / 已反映电网预期。现价 6.51 对应 2029E 中性 PE 24x，中性目标仅 5.44 元，低于现价。

安全边际：
- 中性远期 5.44 元 → 空间 −16.4%（中性无正收益）
- 悲观 2.45 元 → 下行 −62.4%，风险极大（现金流+杠杆）
- 乐观 8.98 元 → +37.9%（需多重利好共振）
- 下行保护弱：经营现金流大额为负、资产负债率 50%+、低毛利。

介入条件：
1. 暂不追高。仅当回落至 4.5 元以下（市值约 33 亿，对应 2029E 16x，PB~1.2x）才具安全边际。
2. 升级信号：① 季报毛利率回升至 8% 以上（验证倒挂出清）；② 经营现金流转正；③ 特高压中标份额公告提升。
3. 观察指标：沪铝主力价格、国网招标中标公告、资产负债率。

最大风险：① 铝价高位持续致倒挂延续；② 闭口价订单余额大、出清慢；③ 经营现金流持续负、杠杆压力；④ 电网招标价格竞争加剧；⑤ 航空零部件需求再降。

结论：暂不介入

逻辑：电网"十五五"5 万亿+特高压招标放量是真强催化，通达为线缆核心供应商，这是真逻辑；但公司低毛利重资产、H1 因铝价倒挂 Q2 已亏损、经营现金流 −4.83 亿，中性情景（2029E 2.0 亿）目标 5.44 元低于现价，悲观 −62%，缺乏安全边际。属"逻辑对、价格错、质地偏弱"——等股价回落至 4.5 元以下或毛利率/现金流拐点确认后再评估。

→ 第五步进阶·上行想象力情景（四类）
- A 行业调整剩者红利：特高压线缆集中度提升，头部/中型优质产能份额跳升 → 验证点：中标份额公告、CR5 提升。
- B 政策反转期权：若电网投资进一步加码或特高压新线密集批复 → 重估弹性 +20%；验证点：国网新批次招标公告。
- C 市场错杀修复：若因铝价回落+季报扭亏，情绪修复 → 验证点：毛利率回 8%+、现金流转正。
- D 技术突破/代际跃迁期权：航空零部件切入大飞机/军工新机型供应链 → 硬验证点：获主机厂定点+批量订单；未过验证点仅作机会情景，不计入中性。
