股东背景：广州国资（广州商贸控股集团体系），区域零售龙头，国资信用背书。

（3）产业链传导

上游：品牌供应商（联营 / 租赁）；下游：终端消费者（理性消费、渠道分流）。

议价权：区域龙头中（核心商圈位置强，但品牌专柜渠道多元化削弱）；租赁业务中偏强（购物中心统一规划）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：零售端成本即采购 / 联营扣点，传导系数近 1（供应商承担）；公司通过降费用、调结构提升净利率（2026H1 费用率仍 35% 但费用额同比大降）。验证点：费用率、毛利率。
  • 因子2 毛利结构再平衡：商品销售（78%）毛利较低、租赁（13%）毛利近 100%；提升租赁 / 服务占比（购物中心化）可抬升综合毛利（2026H1 毛利率已 +16.61pct 印证）。验证点：租赁收入占比、综合毛利率。
  • 因子3 库存与采购节奏：零售库存短周期，以旧换新带动电器周转；无显著库存损益。
  • 因子4 政策 / 市场锚点：① 市场层——消费弱复苏；② 政策层——以旧换新（电器专门店受益）、百货转型扶持。验证点：社零数据、补贴规模。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：广州区域龙头，份额稳固。
  • 需求侧：广州占 98.78%，区域深耕粘性。
  • 技术代际：无技术代际，靠区位 + 品牌。
  • 成本曲线：规模采购微弱优势。
  • 份额加速度：饱和（区域天花板）。
    → 三档：保守（区域稳守）/ 中性（新业态贡献）/ 乐观（广州份额微升）。
  • 层2 扩展业务：主业迁移空间：由"传统百货"向"购物中心 + 社区商业 + 体验消费"迁移（新 TAM 大于纯百货），能力可迁移（零售运营同源）、卡位区域。属中期期权，未过验证点（新业态营收占比跳升公告）不计入中性。
  • 层3 证伪信号：新业态拓展失败、同店持续下滑、电商 / 购物中心分流加剧。

第四步：估值锚定（自下而上，盈利恢复股 + 破净校正）

方法说明：2026H1 扭亏（+2155 万），但净利薄、营收因主动调整大降。采用盈利恢复股自下而上；同时 PB 0.95 破净，须说明破净原因并以净资产为重要估值锚。

破净校正（资产质量折扣）：PB 0.95 破净主因 = 百货业态结构性衰退致盈利微薄（ROE 0.54%）、市场对传统零售折价。但公司持有广州核心商圈物业（历史成本计量，未重估），属"金融资产 / 物业未重估型"部分真破净——按广州核心商圈物业市价重估，净资产隐性价值高于账面，提供安全边际。然资产专用性强（商业物业难快速变现），不构成大幅低估。故估值以净资产（PB）为主锚、盈利为辅。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣：破净已说明（上）——物业未重估型部分真破净，但资产专用性限制，安全边际有限。
  • 校正2 周期位置校正：零售处消费弱周期 + 业态结构性衰退，中性采用 1.10x PB（略高于账面，反映转型 + 物业隐含价值）。
  • 校正3 杠杆下行情景：负债率低（净现金型），下行不致命；悲观仅 −15.7%，下行可控。

第五步：综合赔率判断（买不买？）

当前价格位置：便宜（破净）。现价 5.40 元对应 PB 0.95，已低于净资产，破净提供下行安全垫。

安全边际：中性远期 +15.7%，悲观 −15.7%（物业价值托底）；乐观 +47.4%（转型 + 资产重估）。下行有限、上行有弹性，风险收益对称偏正。

介入条件：① 现价 5.40 元已近净资产，可逢低布局；② 加仓信号：新业态营收占比突破 30%、同店转正、租金收入持续增长、资产重估 / REITs 进展公告。

最大风险：① 百货业态持续结构性衰退（首要，王府井等已大规模关店）；② 电商 / 购物中心 / 即时零售分流；③ 转型进度慢于预期；④ 区域集中度过高（广州 98.78%）。

结论：纳入观察（破净提供安全垫、广州核心物业隐含价值，中性空间 +15.7%；但业态衰退 + 转型不确定，须等新业态兑现或资产重估信号再加重；若转型成功 + 物业重估，可上调重点关注）。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • A 行业调整剩者红利：区域百货出清后龙头份额集中，公司广州第一地位强化。验证点：市占率、同店增长。
  • B 政策反转期权：以旧换新 + 实体零售扶持 + REITs / 上市支持，估值修复。验证点：REITs 公告、补贴规模。
  • C 市场错杀修复：破净（PB 0.95）若被认知为物业未重估，估值从 0.95x 修复至 1.3x+。验证点：资产重估 / 物业价值披露。
  • D 技术突破期权："零售+"业态从 0 到 1 跑通（社区超市 + 主题集合店规模化）；硬验证点 = 新业态营收占比跳升 + 同店转正。缺一则仅作机会情景。
