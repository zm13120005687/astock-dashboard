（3）产业链传导（成本/价格 → 毛利结构四因子）

  • 因子1 成本传导弹性：地产结转毛利取决于"土地成本（已锁定）+ 建安成本 + 售价"三者差。公司土储均为早年获取，土地成本已锁定（传导率对本轮边际影响≈0）；售价端被动（城市更新限价 + 遵义刚需价格敏感），公司基本无提价能力。毛利能否修复取决于结算结构而非成本端。
  • 因子2 毛利结构再平衡：毛利结构 = 上海（高毛利，未结转）× 苏州（中高毛利尾盘）× 遵义（低毛利城市更新，当前结转主力）。遵义占比越高 → 综合毛利率越低（H1 23.1%）；只有当上海兰桂坊大规模结转时毛利率才会上台阶——该节点在 2027 年后、且体量未知，构成主要不确定源。
  • 因子3 库存与采购节奏：地产存货（开发成本）已在账上沉淀多年，无"囤货-抛货"操作空间；经营现金流由签约回款驱动（H1 +0.56 亿靠压缩购建支出与费用实现），是去化回款而非业务造血。土地 5.29 万㎡ 按两年开发周期估算仅够约 2–3 年结转，之后无新增货值。
  • 因子4 政策/市场锚点：① 上海/苏州房价与成交量（验证点：月度成交数据）→ 兰桂坊定价与去化；② 遵义市场价格（验证点：区域成交套数）→ 结转毛利；③ 收储/城市更新专项资金是否覆盖遵义项目；④ 厦门国际银行分红决议 → 投资收益项。每个锚点的情景与证伪信号已列于第三步与第五步。

核心结论：无任何"在手订单/新项目/新产能"意义上的确定性增量。 公司所有可预期收入都来自 5.29 万㎡ 存量土储的滚动结转，且结转节奏取决于两个不可控变量（遵义拆迁进度、上海高端盘去化）。

层1 现有业务：市场容量 × 份额变量

  • 现有业务的市场容量即"公司剩余货值"，是存量衰减型而非成长型：土储持平两期、无新增拿地、管理层自认"项目储备不足风险"。
  • 五锚点中四个不适用（无产能、无客户份额逻辑、无技术代际、成本曲线无意义），唯一有效的是"货值释放节奏"：上海项目入市 + 遵义二期拆迁 = 未来收入唯一变量。
  • 验证点：上海兰桂坊首次开盘去化率（若 2026 下半年取证入市）、遵义二期拆迁公告、季度签约金额。
  • 证伪信号：上海项目取证再推迟、遵义拆迁停滞、签约金额持续低于 0.5 亿/季。

层2 主业迁移空间

  • 历史迁移尝试（地产 → 乙肝疫苗/石墨烯/机器人/临近空间飞行器/创新药）全部未成气候：石墨烯十年累计亏损超 4 亿（2024 年石墨烯营收仅约 17 万元级）、南江机器人拟注销、临近空间飞行器无商业化、海和药物持续亏损。
  • 当前管理层战略明确为"收缩"而非"迁移"：清理非主业敞口、压缩费用、守住现金流——公司自己都放弃了迁移叙事。
  • 小结：层2 无有效增量，不构成任何买入理由。

层3 风险折扣（证伪信号）

  • 存货减值（遵义/苏州项目若继续跌价 → 一次性吞噬净资产）；
  • 上海项目去化证伪（高端盘销售不及预期 → 结转推迟）；
  • 参股资产减值（海和药物/厦门国际银行股权公允价值下修）；
  • 无新增土储 → 收入与净资产进入自然衰减通道。

第三步小结：中性情形下公司未来 3 年收入体量维持 2–4 亿/年波动（依赖结转时点），任何"增量"都缺乏自下而上的订单/项目底稿支撑——这是判断其是否命中"确无扭亏可能"排除标准的关键证据链（见第五步）。

第四步：估值锚定（自下而上，非增速外推）

总股本：约 16.02 亿股。

亏损股专用三问（为什么亏？靠什么扭亏？亏得起吗？）

（一）为什么亏？
- 毛利率结构性塌陷：2026H1 营业成本 +58% 而收入仅 +4.8%，低毛利遵义结转占比提升、高端（苏州/上海）缩量，毛利不足以覆盖税费与期间费用（销售费用虽 −42.5%、管理费用 −11.5%，但缺口仍在）；
- 收入体量过小：年收入 3.8 亿而固定费用（管理+销售）近 1 亿级，规模效应不存在；
- 参股/非主业持续失血：宁波墨西、重庆墨希石墨烯持续亏损（累计亏损超 4 亿量级），南江机器人清算注销拖累；
- 非经常性收益缺位：2024 年起厦门国际银行未分红，投资收益中断，盈利对参股分红的依赖暴露无遗。
- 亏损连续性：2024 −0.34 亿 → 2025 −0.73 亿 → 2026H1 −0.16 亿（年化约 −0.32 亿，亏损收窄但未扭转方向）。

（二）靠什么扭亏？触发时点在哪一年？
- 路径 a（账面扭亏）：上海兰桂坊若在 2027 年形成结转，高毛利项目单年可把利润拉回正值——但金额/分成比例未披露、高端盘去化不确定，无法量化、无法验证时点；
- 路径 b（投资收益脉冲）：厦门国际银行恢复分红或处置参股股权 → 单年投资收益脉冲扭亏——但 2024 年已中断过，属外生不可控；
- 路径 c（持续性盈利）：不存在——遵义低毛利结转 + 无新增土储决定公司无法靠主业回到稳态盈利；
- 触发时点判断：任何一类扭亏都是"单年脉冲"，不存在可验证的持续扭亏路径；即便 2027 年因兰桂坊结转账面转正，次年又将回到亏损（货值耗尽）。

（三）亏得起吗？
- 现金与低杠杆：资产负债率仅 24.1%、总负债 11.1 亿、账面净资产 35.04 亿（含少数股东），无有息压顶风险——短期亏得起；
- 现金流：2026H1 经营现金流 +0.56 亿（靠压缩开支与回款），尚能自持 3–5 年；
- 但"亏得起"不等于"值得持"：净资产趴在低效地产存货+财务性股权上，每年以小幅亏损+机会成本消耗，净资产回报率持续为负。

正常化净利润估值（亏损股方法）

亏损股方法要求"稳态营收 × 正常化净利率 × 远期 PE"。对华丽家族该方法难以成立：公司不存在"稳态营收"（存量尾盘结算完即归零），按规则如实测算并给结果：

  • 2029E 稳态营收：上海兰桂坊若 2027–2029 结转（体量未知，按现土储 5.29 万㎡ 与可售货值粗估年结转 3–6 亿）+ 遵义二期（视拆迁）→ 取 4–5 亿/年；
  • 正常化净利率：参考其自身历史最好综合净利率与可比区域房企（遵义低毛利结构）——若上海高毛利盘占结转 50%+，净利率约 5–8%；若仍以遵义为主则 ≤2%。取保守值 4%；
  • 正常化归母净利 ≈ 0.18 亿（4.5 亿 × 4%）——该盈利仅约等于 35 亿净资产的 0.5% ROE，对估值的支撑趋近于零；
  • 因此本股估值必须用净资产/清算价值锚定，净利润法仅作交叉验证：每股净资产（归母 34.40 亿/16.02 亿股）≈ 2.15 元。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高（相对资产价值）。PB 1.02x、年收入仅 3 亿级、主业持续亏损，价格已包含"题材期权"与"地产情绪 beta"，未给"资产质量折扣"留出空间。

安全边际：
- 中性远期 2.05 元 → −8.5%（<0，不足以"纳入观察"）；
- 悲观 1.60 元（−28.6%）对应减值情景；乐观 3.00 元（+33.9%）需上海项目+分红+题材三重兑现；
- 下方真实支撑 = 净资产清算折扣（约 1.8–2.0 元），距现价约 −10%～−20%，谈不上厚。

关于"确无扭亏可能"排除标准的逐项举证（这是本报告结论的定性基石）：
1. 主业持续萎缩：✅ 年收入由历史高峰数十亿萎缩至 3.8 亿级，土储连续两期持平于 5.29 万㎡、无新增拿地，可售货值进入自然耗尽通道；
2. 无在手订单/新项目：✅ 地产项目均为存量结转，无新开工大项目；上海在建为合作存量项目，金额与分成未披露；
3. 现金流枯竭：❌ 不枯竭——负债率 24%、H1 经营现金流 +0.56 亿，尚可自持数年（"确无扭亏可能"四要素未全命中，故不直接判"坚决回避"，按估值给"暂不介入"）；
4. 无重组/资产注入预期：✅ 近两年无重大重组公告，管理层战略为收缩清理，无注入迹象；
5. 题材无业务支撑：⚠️ 石墨烯（十年未产业化、研发近乎为零）、机器人（拟注销）、临近空间（无商业化）均属"财务参股/早年投资"，无自主技术迭代能力——具"纯概念"成分，但其收入真实性（地产结转）使其不至于命中"无实质业务"的纯概念炒作标准。

介入条件（给出明确的重新评估触发点）：
1. 现价不介入。合理买入区间应在 1.9 元下方（对应 PB ≤ 0.9x、为资产质量折扣留出安全垫）；
2. 基本面触发点：上海兰桂坊取证开盘且去化率超预期（届时结转结构上移、毛利率可验证）、厦门国际银行分红落地、遵义二期拆迁开工——任一兑现后再以"存货周转"逻辑重估；
3. 题材触发点：若仅因地产板块情绪或石墨烯等题材异动放量上涨，不参与（历史上题材脉冲后均回落的教训）。

最大风险（最可能破坏逻辑的因素）：
1. 存货减值（首要）：遵义市场 −17.6% 成交若传导至价格，存货跌价将直接冲击净资产——对 PB≈1 的标的即是股价同比例下跌；
2. 上海项目高端盘去化证伪：体量、分成、时点三重不确定，若入市失败则公司连"账面扭亏"的脉冲机会也失去；
3. 参股资产（海和药物等）继续失血/减值；
4. 题材资金撤离后的均值回归：散户占比 87%+、机构 12%，情绪退潮时缺乏承接。

上行想象力（第五步进阶·类型 B 政策反转期权为主）：
- 地产政策若从"企稳"走向"强刺激"（限购全面放开 + 收储落地 + 上海豪宅市场转热），上海兰桂坊这类内环稀缺盘将直接受益——反转信号：上海高端新房成交放量、公司项目取证/开盘公告；弹性粗测：兰桂坊货值若 30–50 亿（未披露，估算），5–8% 净利率对应 1.5–4 亿利润体量（乐观情景上沿）。
- 类型 D（技术期权）不适用：公司无任何自主技术投入与团队，石墨烯/机器人均已证伪，不存在"0 到 1"的研发管线。
- 什么条件出现才上调评级：出现可量化的持续盈利路径（如新增土储 + 上海项目结转占比过半且毛利率 >35%）或股价回落至 1.9 元下方，两者其一才考虑上调——否则维持不介入。

结论：暂不介入

判断要点：PB 1.02x 看似"破净有底"，实为"低效资产 + 持续亏损 + 无新增土储 + 题材空转"的净值陷阱——正常化盈利趋近于零、NAV 需打折至 1.8–2.1 元，现价 2.24 元安全边际为负。虽然现金流尚未枯竭、未达"坚决回避"四要素全命中标准，但赔率与确定性都不支持介入，维持"暂不介入"，待上海项目结转或股价回落至 1.9 元下方再评估。
