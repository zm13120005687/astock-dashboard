（3）产业链传导

上游：游戏研发成本（美术/代码/买量）。公司已搭 AI 全流程生产管线，美术/代码效率提升 → 研发成本下降（转嫁系数视角：成本端受益，非涨价传导）。

下游：全球玩家/发行渠道（App Store/Google Play/各地区安卓渠道）。买量成本（流量）是核心变量——AI 赋能投放转化效率优化，但海外买量竞争仍激烈。

议价权：游戏 IP 端中（依赖爆款，单品风险高）；信息技术端弱（毛利率 10.77% 显示低议价、价格竞争）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：游戏业无"原材料涨价"问题，核心成本是买量/研发。买量成本上涨时公司难以转嫁（玩家付费刚性），转嫁系数 ≈ 0.2–0.3；但 AI 管线使研发成本结构性下降，部分对冲。
  • 因子2 毛利结构再平衡：游戏 74.41% vs 信息技术 10.77%——结构极度分化。利润 100% 来自游戏（4252 万 vs 信息技术近乎盈亏平衡）。若单看综合 53% 会严重误判：信息技术业务实质是低毛利流量入口，估值应主要锚定游戏。
  • 因子3 库存与采购节奏：游戏无库存概念，收入按道具/订阅分期确认；《秦时明月》收回自营后流水集中确认带来季度波动（Q2 归母 2115 万环比 +73%），属运营节奏非囤货。
  • 因子4 政策/市场锚点：版号（供给端，已常态化利好）、出海贸易政策（数据合规/地区准入，验证点：各国版号/合规公告）、AI 监管（生成式 AI 内容审核，验证点：监管发文）。

输出喂给第四步：游戏净利率取 25–30%（高毛利但波动大），信息技术取 3–5%，综合中性净利率约 18–20%（2026H1 为 15.11%，随游戏占比提升改善）。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务 = 市场容量 × 份额变量
  • 供给侧：游戏研发产能（AI 提效扩产）；
  • 需求侧：全球手游市场，公司靠《RO》出海切欧洲/中东空白；
  • 技术代际：AI 管线领先同业降本；
  • 成本曲线：AI 使单位研发成本左移；
  • 份额加速度：出海区域从东南亚→欧洲/中东，加速。
  • 三档：保守（维持现有 IP 流水）、中性（1–2 个新区域/新 IP 成功）、乐观（多 IP 全球化矩阵）。
  • 层2 扩展业务 = 主业迁移空间：能力可迁移（游戏研发→多品类出海）、新 TAM（全球手游数倍于国内）、卡位（欧洲/中东先发）、认证门槛（地区合规）、信号验证（16 国登顶已验证）。部分过验证点，但单品依赖高，新 IP 未证明前仅作中期期权。
  • 层3 证伪信号：《RO》流水环比腰斩、新 IP 表现不及预期、买量 ROI 恶化、版号/出海合规受阻。

准亏损从严：正常化净利润法 + 盈利塌陷三问（补小节）

虽 2026H1 已扭亏，但 2025 全年仍亏、盈利刚恢复，按"准亏损从严"补充：

正常化净利润法：稳态营收（游戏 4.5 亿 + 信息技术 1.5 亿 = 6 亿）× 保守正常化净利率 18%（取游戏历史最好水平与行业保守值之低者）= 1.08 亿；× 远期 PE 25x = 27 亿 → 3.9 元。与上方中性 4.78 元接近，验证中性偏保守。

盈利塌陷三问（改写版）：
1. 为什么利润塌陷：2025 年游戏业务处新游爬坡 + 出海前期投入期，老产品衰减、新品未放量，全年归母 −970 万；信息技术低毛利未能补位。
2. 靠什么恢复：《仙境传说RO》出海欧洲/中东登 16 国榜首（H1 游戏净利 4252 万）、收回《秦时明月》自营、AI 全流程管线降本——恢复触发点 已在 2026H1 兑现，非远期假设。
3. 生存能力：总资产/净资产稳健（PB 9.55 反映市值含期权溢价），经营现金流 H1 为 −861 万（买量投入期），需关注回款；但无重大债务风险，能支撑到出海兑现。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 5.49 对应 2026E PE 52x，中性远期 4.78 元（−12.9%），已透支出海预期。

安全边际：中性 −12.9%，悲观 −68.3%（单品衰减极致风险），乐观 +74.3%（多 IP 成功）。下行不对称偏大。

介入条件：< 4.0 元（对应 2026E PE <38x、接近中性锚）才具安全边际；上调确认信号：① 《RO》欧洲/中东流水连续两季环比正增长；② 新 IP 上线首月流水破亿；③ 经营现金流转正。

最大风险：① 游戏单品依赖（《RO》流水自然衰减）；② 买量 ROI 恶化/流量成本上升；③ 版号与出海合规；④ 信息技术低毛利拖累；⑤ 高波动小市值（PB 9.55 含期权溢价，易回撤）。

结论：暂不介入（远期空间 −12.9% 为负，按规则"负空间一律判暂不介入"；RO 流水与新 IP 验证后中性空间转正再上调至纳入观察）。

已扭亏、出海逻辑真实验证，但现价已反映较多预期（中性空间为负），且盈利高度依赖单品。等待《RO》流水持续验证与新 IP 兑现后，再上调。

上行想象力情景（四类）

  • A 行业调整剩者红利：游戏行业出清小厂，精品 IP 厂商份额提升（验证点：行业集中度、公司市占率）。
  • B 政策反转期权：版号常态化 + 文化出海扶持加码（已落地，部分兑现）。
  • C 市场错杀修复：若因市场风格被杀至 4 元以下，forward PE 回到合理，修复弹性大（验证点：估值分位）。
  • D 技术突破/代际跃迁期权：AI 全流程管线使研发效率跨越式提升 + 多 IP 全球化矩阵从 0 到 1（硬验证点：新 IP 首月流水破亿 + 自研引擎降本达标，否则仅作机会情景）。

上调重点关注条件：《RO》流水连续正增 + 新 IP 成功 + 现金流转正，且股价回落至 4 元以下。
