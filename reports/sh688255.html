第一步：公司是干什么的？

一句话定位：国内少数同时掌握"工业机器人整机 + 自研控制器 + 伺服 + 焊接电源"全链条技术的焊接机器人供应商，并战略切入具身智能（人形/四足机器人 + 六维力传感器）。

核心产品：自产六轴工业机器人（KC30 新运动控制算法控制器）、协作机器人 KX950（小批量试制）、弧焊/激光焊接机器人系统、全数字弧焊电源、伺服焊接设备。

关键结构信号：工业机器人板块中"自产机器人"销量 1406 台（+44.21%），占机器人总销量 3385 台的 41.5%（2025 全年仅 36.98%）。自产整机毛利率 30%+，而代理外购整机毛利率仅 10–15%，自产占比每提升 1pct，综合盈利能力修复一分。

主要客户/下游：汽车（比亚迪）、船舶海工（广船国际）、工程机械、钢结构、3C 电子；海外以 ODM/经销为主（外销中 ODM 占比约 87%）。

股东背景：凯尔达集团（34.40%）为控股股东；安川电机（中国）持股 8.75%（上游本体供应商，外购整机中安川占比 57.90%，供应链单一依赖风险）；实控人一致行动人 2026-08 发生内部调整，不影响控制权。

（3）产业链传导

上游：机器人核心零部件（减速器、伺服、控制器）——进口谐波减速器占设备成本约 28%，国产替代率有望突破 50%；公司自研 KC30 控制器已降本。外购整机中安川占比 57.90%，供应链单一依赖。

下游：汽车、船舶、工程机械、钢结构——均处自动化率提升周期，造船业上行周期有望持续至 2032 年，钢结构/造船是智能焊接两大主力场景。

议价权：中等偏强（自产端）/ 中等偏弱（外购端）。自产整机因全链自研具备定价与毛利优势；外购安川整机则受制于供应商，毛利仅 10–15%。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（转嫁系数）：工业机器人成本中减速器/伺服占比较高且部分进口，公司对下游以"产品定价"为主，成本端上涨难以短期全转嫁（转嫁系数 ≈ 0.4–0.6）；但自产占比提升本身即对冲——自产毛利率 30%+ 远高于外购，结构迁移比价格传导更关键。验证点：单季综合毛利率（2026H1 未单独披露综合，工业机器人板块 18.66% 含外购拖累）。
  • 因子2 毛利结构再平衡：分业务线毛利率——自产机器人 30%+ / 外购整机 10–15% / 焊接设备 23.50% / 其他 12.83%。当前综合被外购摊薄；2029 目标自产占比 ≥50%，毛利结构将明显上移。禁止用单一综合毛利率掩盖：自产放量 → 利润弹性远大于收入弹性。
  • 因子3 库存与采购节奏：外购安川整机按订单采购，库存收益/损失有限；自产核心零部件国产化降低囤货成本波动。经营现金流为负主因应收账款高增（铺货信用期），非原料囤货，需区分。
  • 因子4 政策/市场锚点：① 设备更新/税收优惠 → 下游资本开支扩张（利好）；② 进口减速器若受贸易摩擦涨价 → 成本承压（风险变量）；③ 安川断供风险（实体清单类）→ 验证点：自研/国产减速器导入进度。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：国内焊接机器人国产化率 35%→50%，公司凭全链自研抢份额；
  • 客户侧：进入比亚迪、广船国际供应链，认证粘性；
  • 技术代际：KC30 新算法控制器对标进口，自产占比提升即份额溢价；
  • 成本曲线：自产综合成本低于外购，降价时能以价换量；
  • 份额二阶导数：自产占比仍处 S 曲线爬坡段（41.5%→50%+），加速渗透。
    → 中性：2029 自产占比 55%，工业机器人市占率小幅提升；保守 50% / 乐观 60%。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：从焊接机器人 → 六维力传感器（凯维力）→ 四足/人形（镜识）。能力可迁移性高（运动控制 + 力控同源）；新 TAM（人形机器人核心部件）弹性大；但客户认证/量产门槛高。未过量产验证点，仅作中期期权，不计入中性净利。
  • 层3 风险折扣（证伪信号）：自产占比停滞、安川断供致外购成本飙升、应收账款坏账、人形机器人量产延期。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高。现价 26.43 对应 2026E PE 约 44.7x，已反映 H1 反转预期。

安全边际：
- 中性远期 36.4 元 → 空间 +37.8%（未达"重点关注">50% 门槛）
- 悲观 19.1 元 → 下行 −27.7%，风险不对称偏负
- 乐观 53.7 元 → +103.3%（依赖自产占比超预期 + 人形部件放量）
- 下行保护：PB 2.72x、负债率低、无重大有息负债；但经营现金流为负、应收账款高增需警惕

介入条件：
1. 不追高，回落至 22 元以下（2026E PE < 34x）具安全边际
2. 加仓信号：自产占比突破 50%、单季经营现金流转正、凯维力传感器批量订单
3. 观察指标：逐季自产机器人销量占比与综合毛利率

最大风险：
1. 应收账款高增（1.40 亿 +93.61%）→ 经营现金流转负，增长"含金量"存疑
2. 安川电机单一供应依赖（外购占比 57.90%），断供/涨价风险
3. 人形机器人布局短期只烧钱、无营收贡献

结论：纳入观察（盈利拐点已现、国产替代逻辑清晰，但中性空间 <50% 且现金流待验证；自产占比持续突破 + 人形部件量产落地可上调至重点关注）
