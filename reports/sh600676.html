（3）产业链传导

上游：赛事 IP 授权方（F1 管理公司、ATP、世界斯诺克）、场馆（自有/受托运营，部分为划拨用地）、演艺内容方与艺人、船舶与燃油、物流运力与人力。
下游：C 端消费者（观赛、健身、演艺、游船票务）、B 端（赞助商、商业配套租户、政府与机构客户）、G 端（政府赛事采购、场馆托管）。
议价权判断：强（赛事端）+ 中（场馆端）+ 弱（保留业务端）。
- 赛事端：顶级 IP 独家运营权 = 强议价权（F1 票房 +30% 即为佐证）；
- 场馆端：上海核心场馆稀缺，场馆托管外拓具备定价能力；
- 保留业务端：公路货运"供强需弱"、燃油车退网，议价权弱——这是扣非亏损的核心来源。

第二步进阶：原料成本 → 毛利结构传导（四因子）

文体旅平台的"原料"是赛事 IP 授权费 + 场馆折旧/租金 + 内容（艺人/演出）成本 + 人力；保留业务的"原料"是运力/燃油/车辆采购成本。四因子按此重构。

因子 1｜成本传导弹性（pass-through）——分板块差异极大

板块 传导率（估） 依据
赛事运营 0.7–0.9 顶级 IP 稀缺，票务与赞助定价权强（F1 票房 +30%）
场馆运营 0.6 场馆稀缺 + 全民健身刚需，但政府指导价与公益属性限制提价
演艺 0.8 票务市场化定价，需求旺盛时可通过档期与票价转嫁
浦江游览 0.6 独家运营权 + 旅游消费属性，但价格受政府指导
保留物流/汽车销售 0.2 公路货运"供强需弱"、燃油车退网，成本无法转嫁，只能承受亏损
  • 量化含义：公司整体毛利承压的根源不在文体旅业务，而在保留的传统业务——2025 年整体毛利率仅 2.52%（销售毛利 1.09 亿元 / 营收 43.46 亿元），说明传统业务几乎零毛利运行。2026H1 毛利率回升至 6.25%，正是文体旅资产并表的直接体现。

因子 2｜毛利结构再平衡——"高毛利新资产 + 零毛利老资产"并存

业务线 估算毛利率 成本敏感度 收入权重（2026H1） 毛利贡献权重
赛事运营 约 40–50% 低（IP 授权为固定成本） 1.4% 约 10%
场馆运营 约 25–35% 中（折旧、人力） 10.1% 约 50%

  • 合并毛利率 6.25%（2025 全年 2.52%）。
  • 结构迁移含义：收入结构尚未完成切换——保留的传统业务仍占收入约 80%，但其毛利贡献极低甚至为负；文体旅资产收入占比仅约 26.75%（2025 备考口径），毛利贡献却远超其收入权重。这正是"净利润占比 143.08% 而收入占比仅 26.75%"的原因。禁止用"综合毛利率 6.25%"单一数字外推，必须分板块建模。
  • 关键推论：公司整体盈利能力的改善路径 = 文体旅资产收入占比提升 + 保留业务减亏/处置，两者缺一不可。

因子 3｜库存与采购节奏（timing）——本股的 timing 因素是"非经常性损益"而非库存

项目 2026H1 金额 性质
归母净利润 +2214.17 万元 含非经常性损益
扣非归母净利润 −14443.49 万元 真实经营
非经常性损益（倒算） 约 +1.67 亿元 ① 土地、房屋搬迁补偿较上年同期增加；② 资产置换交割完成后，置入标的企业期初至合并日的当期净损益（同一控制下企业合并，会计上计入非经常性损益）
  • ⚠️ 关键判断：归母 +2214 万并非经营改善的结果，而是"会计口径 + 一次性补偿"的组合——置入资产 1–6 月的经营利润在合并报表中被计入非经常性损益，因此扣非口径反而"漏掉"了新资产的真实贡献。
  • 因此："扣非 −1.44 亿"并不等于"公司上半年真实亏损 1.44 亿"——它反映的是保留业务（物流+汽车销售）上半年的亏损 + 置入资产贡献被剔除。2027 年起置入资产完整并表，扣非口径才能反映真实盈利能力。
  • 验证点：2027 年半年报扣非是否转正；年报中置入资产完整年度的贡献。证伪信号：2027 年扣非仍大幅为负。

- 悲观情景 3.06 元 → 下行 −55.0%，风险收益严重不对称；
- 乐观情景 16.34 元 → +140.3%，但需保留业务成功置出 + 集团继续注入资产 + 跨地域复制落地，三重条件同时满足；
- 下行保护：有限——PB 1.42x 无折扣、场馆多为划拨用地、保留业务持续亏损；唯一的硬支撑是业绩承诺（3.402 亿元现金补偿条款）与文体旅资产的稀缺性。

介入条件：
1. 当前不介入。现价已把转型预期与整合期权定价进去，中性空间仅 +0.7%；
2. 可考虑的信号（需同时满足 2 项以上）：① 股价回落至 5.20 元以下（对应 2029E 中性 PE < 33x）；② 2027 年半年报扣非归母净利显著收窄（亏损 < 0.5 亿）或转正（新旧业务切换验证）；③ 保留业务（物流/汽车销售）披露处置或置出方案；④ 集团披露进一步资产注入方案；
3. 观察指标：季度扣非归母净利、保留业务营收与毛利率、场馆出租率与使用效率、演唱会落地场次、业绩承诺年度完成进度。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 保留业务拖累（首要）：2026H1 扣非 −1.44 亿；2025 年备考扣非 −1.97 亿，说明即使置入资产全部并表，保留业务 + 总部费用仍形成约 3 亿元/年的拖累——"扣非何时转正"是本股最大的不确定源；
2. 业绩承诺不覆盖上市公司整体：3.402 亿元承诺仅针对赛事、场馆、演艺三家，不覆盖保留业务——完全可能出现"承诺资产达标、上市公司整体扣非仍难看"的情形；
3. 跨地域复制未验证：公司自述"资产重组目前仍处于探索试点阶段，暂未形成可复制推广的国资国企改革模式"，运营能力能否走出上海尚无证据；
4. 估值缺乏盈利支撑：PE 43.7x、正常化 ROE 3.25%，若 2027 年扣非未改善，估值有向下收敛压力；
5. 资产权属与政策限制：大量城市场馆、文旅配套为划拨用地，公益性与经营性边界缺少清晰政策标准，资产盘活与后续注入存在制度阻力；
6. 赛事与演艺的季节性波动：文体旅业务高度依赖线下场景，赛事、演艺筹备周期长、单项目盈亏波动大。

第五步进阶：上行想象力情景（四类，与下行校正对称）

类型 A｜行业调整剩者红利
- 逻辑：文体旅行业优质线下消费场景供给稀缺（公司自述"市场对赛事和文化演出需求旺盛，供给处于稀缺状态"），行业调整期大量中小运营方退出，头部 IP 运营商份额与定价权提升。
- 锚定：F1、ATP1000、斯诺克上海大师赛的独家运营权 = 排他性份额；浦江游览运力占比 51.4%。
- 验证点：新签场馆托管项目、新赛事 IP 引入公告、演唱会落地场次。证伪信号：IP 续约失败、托管项目流失。

类型 B｜政策反转期权
- 逻辑：体育消费与赛事经济已被提升至国家扩内需战略高度；上海建设"全球著名体育城市/国际体育赛事之都"；国资"两非两资"清理鼓励优质城市资源证券化。
- 重估弹性测算：若集团将剩余文体旅资产（如智慧体育公司等）注入，按置入资产 2025 年净利 1.2 亿、作价 16.20 亿的估值倍数（约 13.5x 净利）测算，每注入 1 亿元净利资产可增厚市值约 13.5 亿元（对应 +1.31 元/股）。
- 验证点：集团资产注入预案公告、上海市国资整合配套政策。证伪信号：无后续整合动作。

类型 C｜市场错杀修复
- 逻辑：部分适用。公司 2026H1 归母转正但扣非大亏，市场对"扣非 −1.44 亿"的解读可能过度悲观（因置入资产贡献被会计口径剔除）。若 2027 年完整并表后扣非显著改善，存在认知修复弹性。
- 错杀证据：扣非亏损被误读为"经营恶化"，而真实原因是同一控制下企业合并的会计处理；PE(TTM) −33.36x 显示市场按亏损定价。
- 修复触发点：2027 年半年报扣非大幅收窄、业绩承诺资产完成年度考核。
- 证伪信号：2027 年扣非仍大幅为负（则"错杀"被证伪，属真实恶化）。

类型 D｜技术突破 / 技术代际跃迁期权
- 逻辑：不适用。文体旅运营无"技术代际跃迁"属性。明确排除该类型，避免为看涨强行套用。

类型 E（补充）｜保留业务置出 + 平台化复制期权（本股最大的想象力来源）
- 逻辑：① 保留业务（物流 + 汽车销售/后服务）若整体置出，可立即消除约 3 亿元/年的拖累，上市公司扣非将直接转正；② "文体旅交"运营模式若能复制到长三角乃至全国，则从"上海本地运营商"跃升为"全国性平台"，打开全新增长曲线。
- 重估弹性：若保留业务置出（消除 3 亿拖累），上市公司稳态净利可达 4.5–5.0 亿元；按 40x PE 计，目标市值 180–200 亿元 → 17.5–19.5 元（+157% 至 +187%）。
- 验证点：① 保留业务置出/处置公告；② 上海以外城市的赛事或场馆托管项目落地；③ 单城模型净利率维持。
- 证伪信号：保留业务长期不处置、跨地域复制无进展、公司长期停留在"试点阶段"。

什么条件出现才把结论上调至"重点关注"：① 2027 年半年报扣非归母净利亏损收窄至 0.5 亿以内或转正（新旧业务切换的核心验证点）；② 保留业务（物流/汽车销售）披露处置或置出方案；③ 跨地域复制落地（上海以外城市的赛事/场馆托管项目）。三者同时满足时，稳态净利可上修至 3.5 亿、中性空间将超过 +100%，方具备"重点关注"条件——在此之前，本股不具备介入价值。

结论：纳入观察

理由：① 公司转型方向清晰、资产稀缺性突出——F1、ATP1000、斯诺克上海大师赛独家运营权 + 上海核心场馆 + 浦江游览 51.4% 运力，是 A 股唯一的"文体旅交"平台；② 业绩承诺（3.402 亿元现金补偿条款）提供一定托底；③ 但中性远期空间仅 +0.7%，而悲观情景下行 −55.0%，风险收益严重不对称；④ 保留业务约 3 亿元/年的拖累是硬伤——2026H1 扣非 −1.44 亿、2025 年备考扣非 −1.97 亿，"扣非何时转正"完全未经验证；⑤ 现价 PE 43.7x、PB 1.42x、正常化 ROE 仅 3.25%，估值已充分反映转型预期。真正的机会在于"保留业务置出 + 跨地域复制"（乐观情景 +140.3%），而这两点均未过验证点——按纪律不计入中性，仅作机会情景跟踪。
