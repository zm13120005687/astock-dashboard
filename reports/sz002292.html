（3）产业链传导

上游：IP 内容制作+原材料（塑料/电子元件）。原材料成本受石化价格影响，可部分转嫁。

下游：商超/母婴/潮玩店/电商/游戏厂商（授权）。潮玩需求由 Z 世代情绪消费驱动，溢价能力强。

议价权：中强。国民 IP 有定价权，潮玩（玩点无限）毛利率 >50%，高于传统玩具。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（转嫁系数）：玩具原材料（塑料/电子）占成本大头，公司转嫁系数≈0.6——可通过产品升级（中高端占比提升）转嫁约 60%，潮玩因溢价高转嫁更强（~0.8）。依据：H1 综合毛利率 51.6%，中高端玩具占比提升拉动。
  • 因子2 毛利结构再平衡：分业务线毛利率——潮玩/授权 >50%、玩具 39.6%、影视中等、婴童中低。潮玩+授权占比提升（H1 ~22%→目标 30%+）将结构性抬升整体毛利。原料敏感权重：传统玩具对塑料价格敏感（权重高），潮玩对原料不敏感（IP 溢价主导）。
  • 因子3 库存与采购节奏：影视内容成本前置、玩具季节性备货（下半年旺季）；低价原料备货收益 vs 高价接货损失需区分。H1 含出口退税（一次性），非持续。
  • 因子4 政策/市场锚点（成本驱动变量）：① 石化原料（市场层）：油价下行利好玩具毛利；② 文化出海补贴（政策层）：国漫出海若获补贴降成本；③ 关税（政策层）：海外婴童出口退税费已返还（一次性），若贸易摩擦再起则成本升。输出：第四步毛利率假设取 48%~54% 区间（结构优化主线）。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：全球授权商中国榜第 48 位，国内动漫 IP 第一梯队。
  • 需求侧份额：绑定腾讯/网易等十+游戏联名，年轻客流份额提升。
  • 技术代际差：IP 运营能力领先，潮玩设计迭代快。
  • 成本曲线：规模化+IP 复用，边际成本低。
  • 份额加速度：潮玩处于渗透早期，份额加速。
    → 三档：保守守住（营收 33 亿）/中性（37 亿）/乐观（42 亿）。验证点：潮玩季度营收增速、授权客户数。
  • 层2 扩展业务：主业迁移空间：玩具 IP → 潮玩/文旅/元宇宙（新易盛范式）。能力可迁移（IP 同源），新 TAM（潮玩 1200 亿）远大于传统玩具，早期卡位。部分验证（潮玩已规模化），中期期权可部分计入乐观情景。
  • 层3 证伪信号：潮玩增速跌破 30%、IP 老化授权流失、游戏联名中止→下调。

第四步：估值锚定（自下而上，非增速外推）

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 4.17x 高，但轻资产（IP 无形资产为主），无破净问题；IP 价值未完全入账，估值含期权溢价。
  • 校正2 周期位置校正：非周期，业绩随文娱消费情绪波动，当前处景气修复位，中性已按常态净利率。
  • 校正3 杠杆下行情景：负债率 29.3% 低，下行主要为"成长不及预期"估值压缩（悲观 −70%），非杠杆反噬；中性不得标大空间（已负）。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。126 亿市值对应扣非盈利仅 ~1 亿，PE（扣非）超 100x，情绪定价明显。

安全边际：中性远期 7.58 元（−11.3%），悲观 2.54 元（−70%）；仅乐观 +42%，且依赖潮玩持续高增。

介入条件：① 回调至 6.5 元以下（对应 2029E 中性 ~25x）；② 潮玩连续 4 季翻倍且扣非净利率 >8%；③ 员工持股目标（2026 扣非≥1 亿）兑现且可持续。

最大风险：① 潮玩竞争加剧（布鲁可等）、增速不及预期；② IP 老化、授权流失；③ 非经常性不可持续致表观利润塌缩；④ 文娱消费疲软。

结论：暂不介入

理由：中性远期空间 −11.3%，当前估值透支未来 3 年成长；质地优秀但价格贵，等回调至 6.5 元以下或潮玩验证持续高增再观察。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：潮玩/动漫行业集中度提升，头部 IP 份额溢价。验证点：CR5、公司份额；证伪：份额降。→ 触发且估值回落可上调重点关注。
  • B 政策反转期权：文化出海/促消费加码若细化补贴，利润弹性。验证点：补贴政策、出海数据；证伪：政策落空。
  • C 市场错杀修复：若因风格切换超跌至 PB<3x，修复弹性大。验证点：估值分位；证伪：基本面恶化。
  • D 技术代际跃迁期权：IP×AI/元宇宙新形态从 0 到 1。硬验证点：新品规模化收入+客户定点+成本优于旧路线；当前未过验证点，仅作机会情景。

上调重点关注条件：股价 <6.5 元 + 潮玩连续高增兑现 + 扣非净利率 >8%。
