一句话定位：专注工业信息化与自动化的系统集成商与自主产品商，业务围绕"数字化（工业电气自动化 + 工业信息化）+ 绿色化（新能源大功率电力电子）"两大方向，卡位国产替代与算力基础设施配套。

主要客户 / 下游：算力中心建设方、船舶制造、机械设备出口商、煤矿 / 水务 / 市政等工业客户、新能源电力设施（海外）。

（3）产业链传导

上游：工控元器件（芯片、功率器件），国产替代降低依赖；下游：算力中心、船舶、机械设备、矿山 / 水务市政。

议价权：系统集成环节中（项目制定价）；自主产品（PLC / 边缘控制器 / 交换机）中偏强（国产替代刚需、信创门槛），毛利率高于集成。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：工控元器件（尤其进口芯片）涨价传导系数约 0.7–0.8，但国产替代（自主 PLC）降低对外依赖、提升毛利确定性。验证点：芯片价格、国产产品占比。
  • 因子2 毛利结构再平衡：2026H1 综合毛利率 15.57%（+2.48pct）。工业电气自动化（73% 营收）毛利较高且提升；工业信息化（18%）稳健；新能源（8%）出表后拖累减小。若自主产品占比由当前提升，综合毛利率有望至 17%–18%。验证点：分业务毛利率、自主产品营收占比。
  • 因子3 库存与采购节奏：项目制交付，库存以备货为主；芯片国产替代降低采购波动风险。
  • 因子4 政策 / 市场锚点：① 市场层——算力 / 船舶资本开支周期；② 政策层——信创国产替代、工业互联网 2.5 万亿目标。验证点：算力招标、船舶订单、国产化工控渗透率。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：工控国产替代空间大，公司自主产品份额低基数、提升空间大。
  • 需求侧：算力 / 船舶 / 出口三大新兴需求共振。
  • 技术代际：第二代 PLC 达国产替代代际。
  • 成本曲线：自主可控降低采购成本。
  • 份额加速度：新兴场景渗透率早期。
    → 三档：保守（维持现份额）/ 中性（自主产品占比升至 30%+）/ 乐观（国产替代加速抢份额）。
  • 层2 扩展业务：主业迁移空间：由"工控集成"向"AI 工业互联网平台 + 算力基础设施服务商"迁移（新 TAM 数倍），能力可迁移（软件 + 硬件同源）、卡位早。属中期期权，未过验证点不计入中性。
  • 层3 证伪信号：传统工业信息化需求持续下滑、自主产品无大客户定点、算力 / 船舶需求退潮。

第四步：估值锚定（自下而上，盈利恢复股）

方法说明：2026H1 扭亏（+1931 万），但营收 −21.8%（业务调整年）。采用盈利恢复股自下而上：以工业电气自动化复苏 + 国产替代为锚，回归 2022–2023 历史常态净利 1.2–1.4 亿并适度上调。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣：轻资产（净资产 12.82 亿，负债率约 50%），无破净问题；PB 2.69 反映成长预期，资产质量健康。
  • 校正2 周期位置校正：工控处"弱复苏 + 结构性高景气（算力 / 船舶）"位置；中性净利采用修复常态 1.38 亿（非 2024–2025 亏损年、非 2022 高景气极端），不过度乐观。
  • 校正3 杠杆下行情景：若利率上行 / 制造业需求再下行，净利可回落至 0.6 亿（悲观 −65%），故中性不标大空间；但负债率可控，下行不致命。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低（边际）。现价 9.81 元对应中性目标价 10.20 元（+4%），已反映复苏预期但空间有限。

安全边际：中性远期 +4.0%，悲观 −65.2%（若复苏证伪）；乐观 +78.4%（国产替代 + 政策大年）提供高弹性。小市值（34.5 亿）高贝塔属性明显。

介入条件：① 回落至 8.5 元以下（对应 2029E 约 20x，安全边际增厚）再加仓；② 加仓信号：经营现金流转正（2026H1 为 −2.34 亿，须改善）、自主产品营收占比突破 30%、算力 / 船舶订单持续公告。

最大风险：① 经营现金流为负（2026H1 −2.34 亿，营运资本占用，首要风险）；② 新能源业务出表后仍存减值；③ 传统工业信息化需求持续下滑；④ 小市值高波动。

结论：纳入观察（扭亏恢复 + 政策强驱动 + 小市值弹性，但中性空间仅 +4% 且现金流待改善，须等回调或现金流转正再介入；若国产替代订单规模化 + 净利达 2 亿+，可上调重点关注）。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • A 行业调整剩者红利：工控国产生态出清，公司自主 PLC / 交换机份额提升。验证点：国产产品市占率公告。
  • B 政策反转期权：十五五智能制造 + 工业互联网 2.5 万亿政策加码，订单放量。验证点：政策细则、公司订单公告。
  • C 市场错杀修复：若 2026H1 扭亏被市场低估（TTM 仍负），估值从"亏损折价"修复。验证点：连续季度盈利、TTM 转盈。
  • D 技术突破期权：第二代 PLC + AI 边缘控制器从国产替代 0 到 1 规模化（信创刚需）；硬验证点 = 大客户定点 + 量产交付 + 成本优于进口。缺一则仅作机会情景。
