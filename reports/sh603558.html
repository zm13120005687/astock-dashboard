第一步：公司是干什么的？

一句话定位：全球针织运动服饰制造领先企业，以运动针织棉袜为核心（占比约 65%），无缝运动内衣为第二曲线（占比约 22%），为国际运动品牌做 ODM/OEM，形成"中国（江山/贵州）+ 越南 + 埃及（筹建）"三地协同的全球化产能布局。

主要客户/下游：国际运动品牌与大众服饰零售商（典型如迪卡侬、PUMA、优衣库、H&M、GAP 等，具体客户名单公司未逐一披露，该数据未披露，构成次要不确定源）。

产能布局：
- 国内：江山针织、江山思进（棉袜主基地）；江山智能制造工厂已完成基础建设及设备引进；贵州鼎盛（无缝主基地）
- 海外：越南健盛、越南清化（棉袜海外基地，2026H1 净利同比 +96%）；埃及生产基地筹建中
- 三地协同，抗风险与保交付能力突出

财务特征：2025 年 ROE 16.47%（显著高于行业）、毛利率 30.20%、净利率 15.64%、资产负债率 39.43%、有息负债 11.11 亿。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（出口占比 87%，关税与汇率必须显式建模）

变量 传导率估计 依据 实际影响
棉纱/化纤涨价 约 0.70 品牌客户长约 + 成本加成报价为主；公司毛利率在原料上行期仍 +2.2pct 原料 +10% → 毛利 −2.0pct
人民币汇率（升值） 约 0.10 出口美元计价，人民币升值直接侵蚀人民币口径收入，几无转嫁空间。Q2 财务费用率 +2.43pct 即为实证 人民币升值 3% → 年收入 −2.6 亿、毛利 −0.8 亿
美国关税（12.5% vs 竞品 10%） 约 0.50 关税通常由品牌方与供应商分担；健盛作为优质 ODM 议价能力较强，但越南被排除 TRQ，劣势难完全转嫁 2.5pct 税率差 → 若公司承担一半，年化毛利 −0.3 亿

→ 加权传导率约 0.55；但汇率与关税属"准不可转嫁"变量，合计对毛利的潜在侵蚀（人民币升 3% + 关税差额）约 1.1 亿/年，相当于 2025 年归母净利（4.05 亿）的 27%——这是本标的最大的盈利不确定性。

因子3 库存与采购节奏（timing）

  • 公司未披露棉花/棉纱套保比例，该数据未披露，构成次要不确定源。
  • 存货数据：2026H1 存货周转率 0.60 次（半年），较 2025H1 的 0.63 次略降 → 有小幅累库。若棉价后续下跌，形成高价接货损失；若棉价上涨，形成库存收益。
  • 2026H1 经营现金流：每股 −0.03 元（Q2），净利润现金含量 −13.52% → H1 经营现金流为负，利润未转化为现金。这是本报告识别的重要质量警讯（2025 全年经营现金流 6.06 亿、净现比 149.62%，属正常季节性波动，但需在 H2 验证回款）。

层2 扩展业务：主业迁移空间（新易盛范式）

迁移方向：从"越南制造"→"中国 + 越南 + 埃及三地协同制造"（产能地理迁移）。

判断维度 评估
① 能力可迁移性 高：针织工艺、质量管理体系、品牌客户认证可跨国产能复用；越南基地从 0 到净利 +96% 已证明复制能力
② 新 TAM 弹性 中：迁移本身不创造新 TAM，但规避关税 = 保住客户份额，相当于保住 87% 的出口收入基数
③ 切入时点与卡位 早期：埃及基地筹建中，若 2028 年前投产，可在 TRQ 全面生效前完成卡位
④ 客户认证门槛 中：品牌方对新工厂需重新验厂认证（通常 6–12 个月），但已有合作关系的品牌认证可加速
⑤ 信号验证 未通过：埃及基地仅"筹建中"，无投产时点、无产能披露、无客户定点

→ 结论：埃及基地属中期期权，未过验证点，不计入中性净利，仅进乐观情景。中性情景只给"江山智能工厂爬坡 + 越南基地效率提升 + 无缝业务爬坡"这些已验证的增量。

层3 风险折扣：证伪信号

  • 越南基地净利率回落（关税转嫁失败）
  • 单季营收同比转负（Q2 已仅 +4.0%）
  • 毛利率跌破 29%（31.6% 是当前核心优势）
  • H2 经营现金流仍为负（H1 已为负，净现比 −13.52%）
  • 埃及基地 2027 年底前仍未投产

第四步进阶：重资产/周期股三道校正

  • 校正1 资产质量折扣：PB 1.94x > 1，不存在破净，无需破净归因。但需标注：公司有息负债 11.11 亿（2025 年末），占总负债（15.27 亿）的 72.79% → 高有息负债结构是实质性风险。
  • 校正2 周期位置校正：公司不属于强周期股（针织服饰 ODM，需求由品牌补库周期驱动，波动小于商品周期），中性净利不适用 trough-to-peak 归一化。但需标注当前周期位置：美国服装进口 −12.06% 的主动去库存底部区域；越南对美出口均价 −4.92%、行业增加值率 47.07%（下降）→ 行业处于价格与利润的底部区间。公司逆势提毛利，说明个体周期位置优于行业。
  • 校正3 杠杆下行情景（有息负债 11.11 亿，必须做负面情景）：
  • 资产负债率 39.43%（2025 年末），未触发 >60% 阈值，但有息负债/总负债 = 72.79%，杠杆结构偏债。
  • 利率上行 100bp：有息负债 11.11 亿 → 财务费用 +0.11 亿/年 → 净利 −2.5%，影响可控。
  • 需求下行（美国进口再降 15%）+ 关税全额承担：营收 −12%、毛利率 −3pct → 净利降至 2.75 亿（悲观情景），目标价 7.23 元，空间转负 −40.5%。
  • → 结论：单因子（利率）冲击可控，但"需求下行 + 关税"双因子共振会使空间显著转负。按纪律，因此不得标"大空间"，至多"纳入观察"并注明高贝塔属性（Beta 来源：出口占比 87% + 有息负债 11.11 亿）。
  • 期权纪律：埃及基地（未过验证点：无投产时点、无产能、无客户定点）不计入中性净利，仅进乐观情景（乐观情景中埃及贡献 2.0 亿收入 / 0.30 亿净利）。
