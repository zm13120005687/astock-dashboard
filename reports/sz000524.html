第一步：公司是干什么的？

（3）产业链传导

上游：机票、酒店客房、地接资源（外采），成本随航司 / 酒店价格波动；旅行社对上游议价权中等（规模采购有折扣）。

下游：终端游客、企业客户，需求随消费意愿 / 假期波动；出境游受汇率、签证、国际局势影响。

议价权判断：旅行社对 C 端 中（品牌 + 渠道），对上游 中（集采折扣）；酒店管理对业主 中高（品牌输出轻资产，毛利高）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性
  • 旅行社转嫁系数 ≈ 0.7：机票 / 酒店涨价可向客转嫁大部分（包价产品调价灵活），但竞争导致部分自担。
  • 酒店经营转嫁系数 ≈ 0.5：房价随市场，成本（人工 / 能耗）刚性。
  • 酒店管理转嫁系数 ≈ 0.9：轻资产收管理费，成本几乎固定。
  • 验证点：出境游产品报价 vs 成本变动；证伪：成本涨而毛利未同步改善 = 传导失败。
  • 因子2 毛利结构再平衡
  • 旅行社占收入 73% 但毛利率低（约 8–10%）；酒店管理占 6% 但毛利率高（约 40–50%）。
  • 原料敏感权重：旅行社对机票/酒店成本敏感（占其成本 70%+），酒店管理几乎无原料敏感。
  • 禁单一综合毛利率：18.54% 综合毛利率掩盖「低毛利旅行社 + 高毛利管理」结构；估值须分业务净利率。
  • 因子3 库存与采购节奏
  • 旅行社无库存（按订单采购）；酒店管理无库存；酒店经营有易耗品库存，影响小。
  • 汇率：出境游结汇受人民币波动影响（公司未披露套保比例，视为 timing 风险）。
  • 因子4 政策 / 市场锚点
  • 市场层：国际航油价格 → 机票成本；汇率 → 出境成本。
  • 政策层：免签政策、文旅消费券、设备更新补贴。
  • 情景：免签扩围 + 航油回落 → 出境游量价齐升（乐观）；地缘冲突 / 汇率不利 → 需求下滑（悲观）。验证点：免签公告、航油期价。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：旅行社行业极度分散，广之旅为华南龙头，全国份额低但可提。
  • 需求侧：前五大客户占比低（散客 + 企业），门店 215 家覆盖提升。
  • 技术代际：无；成本曲线：集采规模优势 → 获客成本低于中小社。
  • 份额二阶导：出境游恢复早期，渗透率仍在提升。三档：保守守住华南 / 中性全国门店增至 300+ / 乐观出境游份额翻倍。
  • 层2 扩展业务：主业迁移空间
  • 酒店管理「轻资产输出」= 从自营到管理输出的能力迁移，新 TAM（存量酒店改造）大，认证门槛低（品牌即门槛），信号验证：新签约超 50 项目/半年 → 已部分过验证点，可计入中性偏乐观。
  • LN LIFE 新零售：未过验证点（收入占比小），仅作中期期权。
  • 层3 证伪信号
  • 门店扩张但单店产出下滑、酒店管理新签数骤降、出境游政策收紧 → 中性下修。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 8.93 元对应 2026E PE 54x，已高于中性远期估值（7.46 元）。

安全边际：中性远期 7.46 元 → 空间 −16.5%；乐观 12.54 元 → +40.4%（需文旅强复苏）；悲观 4.27 元 → −52.2%。风险收益不对称偏负。

介入条件：回落至 7.0 元以下（2026E PE < 35x）且酒店管理新签持续高增、出境游量价验证时，方具配置价值。

最大风险：
1. 旅行社低毛利（2.56% 净利率），规模扩张难显著提净利；
2. 酒店管理轻资产竞争加剧（华住/锦江等），新签约放缓；
3. 汇率 / 国际局势冲击出境游；
4. 当前 PE 54x 已透支复苏预期，题材退潮即回归。

结论：暂不介入

逻辑正确（商旅复苏 + 酒店管理轻资产扩张 + 全国化），但现价已反映乐观预期，中性远期空间 −16.5%，不满足「重点关注 / 纳入观察」>0 门槛。等回落至 7 元以下或业绩超预期再评估。
