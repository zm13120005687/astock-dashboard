行业：水务环保（供水/污水/固废）+ 光伏导电银浆（新能源新材料）｜ 板块：沪市主板
反向核查结论：队列 PE 为正。2026H1 归母 +3382.68 万、扣非 +3040.42 万、Q2 单季归母 +2995.83 万、Q2 扣非 +2798.16 万——四项口径全部为正，不存在"表内藏着实亏"。但需警示：H1 经营性现金流 −4.01 亿、有息负债 39.79 亿、资产负债率已升至 66.28%（2026Q1），属"账面盈利 + 现金流承压 + 高杠杆"组合，第四步必须做重资产三道校正。

第一步：公司是干什么的？

一句话定位：从四川简阳起家的区域性水务环保公司，2025 年 3 月以 5.02 亿元收购德国贺利氏原光伏事业部（光伏银浆资产）后，形成"环保（供水+污水+固废）+ 新能源新材料（光伏导电浆料）"双主业格局——目前新能源新材料已占收入七成，但利润仍全部来自环保。

（3）产业链传导

因子1 成本传导弹性（pass-through）
银浆行业采用 "银价 + 加工费"定价模式，即银价波动绝大部分直穿转嫁给电池片客户，公司赚的是加工费。因此传导率 ≈ 0.85–0.95（高）——这解释了为什么银价两年涨 3 倍，海天银浆板块毛利率没有被打穿。但传导率不等于 1：传导缺口 = 银价上涨 ×(1−0.9) 仍会侵蚀加工费绝对额；且 2026Q1 增值税出口免税政策调整（公司明确点名为亏损原因之一）是政策性不可传导项。→ 结论：银价上行对海天是"收入放大器"而非"毛利杀手"，真正的毛利杀手是研发投入与产品迭代成本（研发费用 4620.14 万，+96.51%）。

因子2 毛利结构再平衡（分业务线毛利率 + 原料敏感权重）

业务线 2026H1 收入 收入权重 毛利率/净利率 核心原料 原料敏感权重
污水处理 4.38 亿 15.2% 净利率约 24.9%（净利 1.09 亿） 药剂、电耗 低（约 15%）
供水+固废 3.37 亿 11.7% 净利率约 4%（子公司合计 1481 万） 药剂、运输 低

→ 综合毛利率从 2024 年 48.94% 崩到 2026H1 的 12.09%，不是因为原有业务变差，而是结构迁移：73% 的收入换成了"低毛利的银浆加工"。若再用单一综合毛利率判断公司，会得出"主业崩坏"的错误结论——实际环保板块净利还在 +10.85%。分业务看，利润 100% 来自只占收入 27% 的环保板块。

因子3 库存与采购节奏（timing）
银浆是典型"银价波动敞口"业务：①低价囤货——若公司在银价 7000→20000 元/kg 上涨途中持有低价银粉库存，当期毛利会虚高；②高价接货——2026 年银价站上 28000 元/kg 后采购，远期加工费被压缩；③套保——公司未明确披露白银套保比例，这是最大的信息盲区与不确定源。→ 判断：2026Q2 毛利率环比 +3.25pct 部分可能来自低价库存收益，不可视为趋势性改善。

因子4 政策/市场锚点（原料成本驱动变量）
- 市场层：白银受光伏 + AI + 新能源车三领域需求同步拉动，2025 年缺口 1.2 万吨；铜代银（银包铜、纯铜浆）产业化加速，若 2027–2028 铜代银规模化，白银需求将被砍，银价可能回落 → 对海天是"收入下降但加工费率提升"的双刃剑。
- 政策层：①2026Q1 增值税出口免税政策调整已直接造成当期损失（公司披露）；②美国对华关税与欧洲本土制造补贴影响海外出货节奏；③铜代银若纳入产业政策支持目录将加速银价拐点。
- 验证点：上海白银现货价（周度）、公司季度毛利率、公司是否公告白银套保/长协、BC 电池渗透率（2026 年已破 40%）。
- 证伪信号：银价急跌 30% 以上但公司收入下滑快于价格（份额丢失）；或公司毛利率跌破 8%（加工费被挤压）。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务 = 市场容量 × 份额变量（5 锚点）
1. 供给侧份额：银浆行业 2026 年中小厂商批量停产退出，供给从过剩转向有序，龙头议价能力抬升——海天作为全球专利持有者（108 件），属"剩者"之一。
2. 需求侧份额：通威战略合作锁至 2030 年底，Q2 采购额 +2836% 是最硬的份额锚点；隆基、爱旭、英发、中润为长期客户。
3. 技术代际差：公司四条技术路线全覆盖，银包铜已出货、纯铜浆在测——处于行业主流代（未落后），但纯铜浆落后于头部测试进度。
4. 成本曲线位置：作为原贺利氏资产，全球化采购与配方积累使其成本曲线位于行业中位偏左，但规模不及聚和/帝科。
5. 份额二阶导数：份额处于加速渗透段（海外 +259.90%、通威 +2836%），而非饱和段。
- 三档：保守守住现有客户（份额 5–6%）/ 中性小幅提升至 8–10% / 乐观抢至 12%+。验证点：季度前五大客户收入占比、BC 浆出货占比、海外收入占比。

层2 扩展业务 = 主业迁移空间（新易盛范式五点）
- 潜在迁移：银浆配方能力 → 铜浆/银包铜/电子浆料（MLCC、半导体封装浆料）。
- ①能力可迁移性：高（同为粉体-有机载体-印刷配方体系）；②新 TAM 弹性：电子浆料市场与光伏浆料同量级，且毛利率更高；③切入卡位：中（纯铜浆尚在客户测试，未量产）；④认证门槛：高（电子浆料认证周期 1–2 年）；⑤信号验证：未出现——无正式定点公告、无产能投向转向公告、无营收占比跳升。
- → 判定：中期期权，未过验证点，不计入中性情景。

层3 风险折扣：证伪信号
①通威采购额环比回落至个位数增长；②海外销量增速跌破 50%；③公司毛利率跌破 8%；④环保板块净利同比转负；⑤银价急跌但公司收入下滑更快（份额丢失）。命中任一条即下调中性。

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

校正1 资产质量折扣（破净/低 PB 原因）
当前 PB 1.17x，未破净。但需回答"若回落至 PB<1 是否算便宜"：
- 资产结构：总资产 84.67 亿，以水务特许经营权、供排水管网、污水处理厂构筑物为主——专用性极强，不能转产，清算价值远低于账面。
- 隐含负债：有息负债 39.79 亿、有息负债率 75.18%；环保整改与提标改造存在持续资本开支义务。
- 反面证据（是否"金融资产未重估型破净"）：公司无大额可供出售金融资产/上市公司股权，不适用真安全边际例外。
- → 结论：PB 1.17x 不构成安全边际；一旦破净（<6.9 元），大概率是"负债率恶化 + 银浆持续失血"的公允定价，而非低估。禁止单凭 PB<1 推导空间。

校正2 周期位置校正
- 银浆/白银：当前处于周期顶部区域（银价两年涨 3 倍至历史新高，缺口 1.2 万吨）。因此中性情景不使用周期顶部盈利，银浆净利率只给 2.6%（低于行业龙头正常水平 3–4%），已做周期归一化下调。
- 水务：无周期性，处于稳定运营期，可用当期盈利直接年化。
- 当前周期位置标注：银浆 = 顶部 / 水务 = 中枢。

校正3 杠杆下行情景（负债率 62.50% > 60%，必附）
- 2026Q1 资产负债率已升至 66.28%，有息负债 39.79 亿，2026H1 经营性现金流 −4.01 亿（上年同期 −0.96 亿），自由现金流持续为负。
- 负面情景：若利率上行 100bp 且下游需求下行，年利息增加约 0.40 亿，同时银浆收入下滑 20%（−10 亿收入 × 2.6% = −0.26 亿净利），合计侵蚀约 0.66 亿 → 2029E 归母降至 1.2 亿以下，对应股价跌破净资产 6.9 元，空间转负。
- → 依纪律：该负面情景可使空间转负，故本股不得标注"重点关注"，至多"纳入观察"，并须注明高贝塔属性。

期权纪律：污水处理费提价（未落地）、川滇提价（未公告）、纯铜浆量产（测试中）、电子浆料迁移（无公告）——四项均属未过验证点期权，全部不计入中性净利，仅出现在乐观情景。

交叉校验

现价 7.24 元 / 2026E 归母 1.09 亿 = 2026E PE 30.7x；PB 1.17x。对一个净利同比 −44.90%、经营现金流 −4.01 亿、负债率 66% 的公司，30.7x 的 2026E PE 已偏贵——现价已把 2027–2028 年的修复预期部分计入。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。2026E PE 30.7x、PB 1.17x，且利润结构上"73% 收入不赚钱"。市场在为银浆的周期弹性付费，但银浆周期已在顶部。

安全边际：
- 中性远期 9.16 元 → +26.5%，不达"重点关注"的 >50% 门槛
- 悲观 6.5 元 → −10.2%（净资产托底），乐观 14.94 元 → +106.4%
- 风险收益：上行 +26.5%（中性）/ 下行 −10.2%（悲观），但杠杆负面情景可击穿净资产底 → 不对称性偏正但脆弱

介入条件：
1. 不追高。现价 7.24 元已含 2027 年修复预期，回落至 6.3 元以下（PB < 0.92） 才具备安全边际
2. 加仓信号：①连续两个季度银浆板块净利转正；②海外收入占比突破 30% 且毛利率回升至 15%+；③公司公告白银套保或长协（消除最大盲区）；④川滇任一主体污水项目提价落地
3. 减仓/止损信号：资产负债率突破 70%；经营现金流连续两年为大额负数；通威采购额环比转负

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 高杠杆 + 负现金流的反噬（首要）：有息负债 39.79 亿、H1 经营现金流 −4.01 亿，若银浆继续失血，公司将陷入"借钱养新业务"的负循环
2. ⚠️ 银价周期见顶：银价两年 3 倍已在顶部，一旦回落，银浆收入（占 73%）将同步缩水，而加工费绝对额难补
3. 铜代银技术替代：银包铜/纯铜浆产业化将砍白银需求，公司虽在跟进但落后于头部
4. 商誉与减值风险：5.02 亿收购贺利氏资产，若银浆持续亏损存在减值压力

结论：纳入观察

理由：中性远期空间 +26.5%，>0 但不足"重点关注"的 >50% 门槛；且校正3 的杠杆下行情景显示空间可转负，依纪律不得标"重点关注"。公司质地有亮点——环保板块是稳定现金牛（净利 1.09 亿，+10.85%）、通威长约锁至 2030 年底（Q2 采购 +2836%）、海外 +259.90% 且新加坡子公司 7 月已扭亏——但当前价格已为 2027 年的修复预期付费，且银价周期位于顶部。
核心跟踪点：①银浆板块单季能否转正；②白银套保/长协是否披露；③资产负债率与经营现金流。
