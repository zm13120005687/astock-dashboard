一句话定位：全球压滤机产销量第一（连续多年），压滤机国家标准主起草单位，从单一压滤机厂商向"过滤成套装备系统解决方案提供商"转型的制造企业——用压滤机把固液混合物"拧干"，服务矿物加工、环保污泥、新能源锂电、化工四大场景。

- 世界压滤机产销量第一、压滤机国家标准主起草单位、中国制造业单项冠军示范企业

（3）产业链传导

上游：钢材（中板/型钢）、聚丙烯（滤板注塑原料）、电机减速机、液压件、橡胶密封件、滤布原料。公司自用滤布从拉丝到成型全线自有（引进德国生产线），是重要的上游延伸。

下游：矿业、市政/工业环保、新能源（锂电）、化工、砂石。这是本票最大的变量来源（见（1）（2））。

议价权：中等偏强（正被削弱中）。三条依据：
① 全球产销量第一 + 国家标准主起草单位 → 行业地位带来定价基准权 ✓
② 但毛利率从 31.75% 跌至 20.16%（−11.59pct），说明竞争激烈程度远超"龙头溢价"所能覆盖 ✗
③ 配件/耗材（滤板滤布）随存量设备增长且为高毛利长尾，形成"设备卖出后的持续变现能力" ✓

净判断：议价权存在但在下行周期中被持续稀释。这是典型的"周期性议价权"——上行周期时龙头有溢价，下行周期时龙头也被迫让价。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）→ 传导率取 0.40
    依据：①2026H1 原料端（焦炭 8 轮提涨、焦煤紧张）明显上行，而公司毛利率反而暴跌 5.7pct → 成本未能转嫁，且被下游竞争二次挤压；②但公司有费用控制能力（期间费用率 −1.0pct、销售费用 −22.02%、管理费用 −9.05%），说明内部转嫁能力强，只是对外部客户的提价能力弱；③2026H1 隐含营业成本约 21.98 亿元（27.57 亿 ×（1−20.16%））。

分业务/应用线传导率：
| 板块 | 传导率 | 依据 |
|---|---|---|
| 矿物及加工（31%） | 0.55 | 矿业高景气 + 大型项目定制化，议价空间较大 |
| 新能源（15%） | 0.25 | 锂电企业降本压力大，且多家设备厂商竞争 |
| 环保（28%） | 0.30 | 市政招标制，价格透明，基本无传导 |
| 化工（12%） | 0.45 | 技术要求高，议价能力中等 |
| 配件/耗材（滤板滤布） | 0.70 | 存量设备后市场，客户切换成本高，议价权最强 |

测算：假设钢材 + 聚丙烯综合上涨 10%，则各板块加权后综合毛利率承压约 3.0–3.5pct。
反向验证：若上游下行周期到来（钢材 −10%），综合毛利率可回补约 3pct → 这正好可以支撑第四步中"2029E 毛利率从 20.16% 恢复到 23.5%"的假设之一。

关键洞察：公司 20.16% 的综合毛利率里，真正稳定且高毛利的是"配件/耗材"（估 35–40%），它贡献了约 15–17% 的总毛利份额但收入占比不到 10%。这也是为什么尽管整机毛利率崩了，公司仍能维持盈利。
第四步含义：随着存量设备池扩大（年销售数万台，累计服务全球数万用户），配件/耗材占比会自然上升 → 这是一个被市场低估的结构性利好，本报告在 2029E 毛利率恢复中给它 0.5pct 的贡献。

  • 因子3 库存与采购节奏（timing）
  • ⚠️ 2026H1 经营现金流仅 0.33 亿元（−92.18%），公司解释"主要系原材料采购增加、电汇付款比例提升" → 这是主动备货，与"销量修复"的信号一致（2026H1 压滤机整机销量同比增加）✓
  • 低价囤货收益：2026 年焦炭上行通道中备货，若锁的是低价则有短期收益，否则反之。无法验证（公司未披露采购时点）→ 本报告在毛利率假设中不给予囤货收益的额外加成
  • 高价接货损失风险：若 2026H2–2027 钢价继续上行而售价未修复，存货跌价将成为额外压力
  • 长协/套保：公司未披露钢材长协或套保安排 → 原料敞口基本裸露。这是重资产 + 钢材密集型企业的固有弱点，须在第四步作为悲观情景的一部分

  • 应收账款管理有效：期末应收票据及款 6.73 亿元，低于上年末的 7.30 亿元 → 回款质量未恶化，现金流的骤降是"备货"而非"回款难" ✓

  • 因子4 政策/市场锚点（原料成本驱动变量）

  • 市场层：①焦炭：2026 年因山西沁源煤矿事故后安监升级，连续 8–9 轮提涨，河钢一级湿熄焦 2026-09 报 2,230 元/吨（同比 +590 元）→ 抬升钢材综合成本；②铁矿石：2026-06 主力 747 元/吨震荡，港口高库存压制 → 相对平稳；③聚丙烯：滤板原料，受原油影响。
  • 政策层：①钢铁行业粗钢产量调控 / "反内卷"：若 2027 年出台新一轮粗钢产量调控 → 钢材价格上行 → 对公司不利（成本端）；②制造业设备更新政策：利好公司自己的设备需求（收入端）；③出口退税 / 目标市场国贸易政策：公司明确列为风险 → 影响海外拓展，对配件出海成本有影响；④能耗双控：可能抬升高耗能钢材成本。
  • 验证点：季度综合毛利率（是否止跌并回到 22% 以上）；MySteel 中厚板季度均价；是否有钢材长协/套保公告；季度经营现金流是否恢复（备货是否进入尾声）
  • 证伪信号：①单季毛利率跌破 17% → 说明连成本控制都失效；②经营现金流连续两季为负 → 备货失败；③钢价上行 15% 而公司售价未动 → 传导率远低于假设

  • 重估弹性测算：净利 10.5 亿 × 16x = 168 亿 → 29.15 元（+155.3%）；保守打折后取 25.0 元（+118.9%）
