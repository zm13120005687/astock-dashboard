（3）产业链传导

上游：
- 芯片：晶圆代工（台积电/中芯/华虹等）、封测（自有江苏鼎茂 + 外协）、EDA/IP。晶圆产能与代工价格是核心变量；2026 年半导体景气上行 → 代工涨价 → 成本压力
- 户外：面料（GORE-TEX/自研纳米膜/极地仿生材料）、鞋底橡胶、羽绒。公司披露上半年新准入 10 家合格供应商、综合成本有效压降

下游：
- 芯片：面板厂、ODM/OEM 厂、消费电子品牌（三星/戴尔/惠普/小米/荣耀）、车载 Tier1、智能门锁厂、AI 算力客户。下游集中度较高（大客户制）
- 户外：C 端消费者 + 集团客户团购 + 航天装备

议价权：
- 芯片（IP/驱动 IC）：中等偏强——技术壁垒 + 认证周期长（导入三星/戴尔供应链需 1–2 年验证），且 IP 授权模式毛利极高；但触控 IC、Mini LED 驱动面临价格战（国内竞争激烈）
- 指纹识别：中等——通过涨价修复毛利率（说明有一定定价权，但也反映此前价格战惨烈）
- 户外：中等——品牌力仍在但行业存量竞争，靠渠道优化与产品科技化（智能外骨骼）维持溢价
- 综合传导率估算 0.5–0.6

第二步进阶：原料成本 → 毛利结构四因子

因子1 成本传导弹性（pass-through，量化）

业务线 传导率 依据
IP 授权（通途） ≈1.0 授权模式几乎无边际成本，议价权来自技术独特性；H1 净利率极高
触控 IC / 指纹（贝特莱） 0.6–0.7 已导入国际大客户，认证粘性高；公司披露指纹产品"通过涨价修复毛利率"，证明有传导能力
Mini LED 驱动（芯能） 0.3–0.4 国内玩家多、价格战激烈，代工涨价难转嫁
封测（鼎茂） 0.4–0.5 产能利用率与良率决定，议价权弱
户外服装/鞋品 0.7–0.8 品牌定价 + 供应链成本压降；公司披露"综合成本在品质不降前提下有效压降"
→ 加权传导率约 0.65：晶圆代工每涨价 10%，芯片业务毛利承压约 3.5pct（未传导部分）。

因子2 毛利结构再平衡（禁单一综合毛利率）

业务线 2026H1 收入 估算毛利率 晶圆/原料敏感权重 利润贡献性质
IP 授权 + 桥接（通途） 估算 ~1.5 亿 55–65% 极低（无流片成本） 最高质量利润
触控 + 指纹 + MCU（贝特莱） 估算 ~1.5 亿 35–45% 高（需流片） 主力，受代工价影响
Mini LED 驱动（芯能） 估算 ~0.4 亿 25–35% 高 价格战敏感
车载触控（G2） 估算 ~0.1 亿 40–50% 高 增量，爬坡中
封测（鼎茂） 估算 ~0.1 亿 15–25% 中 低毛利，配套

户外鞋品 0.93 亿 约 45–50% 中 —

→ 关键结构变化：H1 综合毛利率约 50% 看似稳定，实则内部三升三降——IP 授权（极高质量）与车载触控（高毛利）占比上升，Mini LED 驱动与封测（低毛利、高敏感）占比亦在上升，户外毛利率靠成本压降维持。单一"综合毛利率 50%"完全掩盖了"利润质量在改善但波动性在加大"这一事实，必须分线建模。

因子3 库存与采购节奏：2026H1 存货周转率 0.43 次（半年度口径），处于低位——芯片业务备货（晶圆 + 成品）与户外季节性备货叠加。判断：①芯片侧 2026 年景气上行，若提前锁定低价晶圆产能，则为库存收益，当期毛利虚高、远期回落；②户外侧存货需关注跌价（行业普遍问题）。验证点：2026 年报存货跌价准备计提比例、存货周转率是否回升。证伪信号：存货周转率持续低于 0.5 次（半年）且跌价计提比例上升 → 说明备货变成了积压。

因子4 政策/市场锚点（原料成本驱动变量）
- 市场层：晶圆代工报价（成熟制程 2026 年涨价压力）、存储/逻辑产能紧张度、金属/稀土（户外辅料）、棉/化纤价格
- 政策层：①出口管制（若美方扩大对华半导体设备/EDA 管制 → 间接推高代工与流片成本）；②国产替代补贴与税收优惠（集成电路设计企业所得税优惠 — 直接降成本，公司芯片子公司净利率高即有此因素）；③关税（户外品出口美国关税，海外占比极低故影响小）
→ 情景：中性 = 晶圆代工年涨 5–8%、税收优惠延续；悲观 = 出口管制升级导致代工涨价 15%+ 且优惠退坡；乐观 = 成熟制程产能释放、代工降价。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务：市场容量 × 份额变量（5 锚点）

芯片侧
1. 供给侧份额：触控 IC / 指纹 / Mini LED 驱动国内玩家众多（汇顶、敦泰、集创北方、明微等），供给侧拥挤，公司靠"差异化场景（笔电触控板、智能门锁指纹、车载 OLED）+ IP 授权"避开正面价格战
2. 需求侧/客户份额：已进核心客户供应链——三星、戴尔、惠普、华硕、小米、荣耀（触控）；京东方、三星显示（车载）；凯迪仕、德施曼、小米、绿米、萤石（指纹）。认证周期 1–2 年 = 强粘性，这是份额的最可靠锚点
3. 技术代际差：分层——通途的大模型压缩 IP（输入数据压缩至 1/5、中间态再压缩 50%、模型参数压缩 30% 且即插即用）属全球范围内稀缺能力（公司称"尚无同类产品上市"的纳米炭铁是莱美的，这里是通途的压缩 IP）；触控 On-Cell 公司自称"全球领先"；Mini LED "国内首家同时具备直显+背光主动式驱动设计能力" → 局部领先一代
4. 成本曲线位置：设计 + IP 轻资产模式，位于成本曲线左侧；但封测（鼎茂）属重资产、规模小，位于右侧
5. 份额二阶导数：触控/指纹 = S 曲线中段（已导入头部客户，正在放量，二阶导仍为正）；Mini LED 背光 = 加速段起点；IP 授权 = 早期高斜率段
→ 三档：保守守住（芯片 2029 收入 13 亿）/ 中性小幅提升（18 亿）/ 乐观抢份额（25 亿，需 AI 端侧 IP 大规模落地）

什么条件出现才上调至"重点关注"：需同时满足 ①股价回落至 7.0 元以下（使中性空间重新 >50%）；②贝特莱 + 通途 2026 年度业绩承诺足额兑现（证明并表质量）；③端侧 AI 压缩 IP 首次披露 ≥1 亿元授权/订单金额（把类型D从机会情景升格为可计入中性的确定性增量）。三者齐备则中性 2029E 归母可上调至 2.5 亿以上。

结论：纳入观察

理由：中性远期空间 +7.4%，虽为正但年化不足 3%，且需以承担 −63% 的悲观下行风险为代价——风险收益严重不对称。
公司转型方向正确且已见实效：芯片收入占比 38.6%、通途+贝特莱贡献 61.3% 净利、通途 IP 授权 20+ 家、与地平线合作、户外毛利率稳在 50%+、研发强度 5.60%（芯片 9.98%）。技术卡位是真的，客户名单是真的。
但价格把这个"真"提前透支了：86x 2026E PE、4.23x PB，市场已经按"2029 年赚 2 亿、给 50 倍"定价完毕。而 Q2 单季归母 −519 万、扣非 −1808 万、芯片收入环比零增长——内生增长尚未接力并表增长，业绩承诺能否兑现（对应约 4–5 亿商誉）是悬在头上的剑。
核心矛盾：好故事 + 坏价格。 建议等 7.0 元以下，或等 2026 年报验证业绩承诺后再评估。
