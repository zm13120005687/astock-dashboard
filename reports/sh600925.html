第一步：公司是干什么的？

一句话定位：江苏省属特大型能源上市平台，以"煤炭开采 + 电力生产 + 新能源"煤电一体化协同为主业，构建"以煤稳电、以电促煤"的闭环，是江苏能源保供的核心载体。

境内外收入占比：基本为境内（新疆/陕西/甘肃矿井 + 江苏电厂），无海外收入。

股东背景：江苏省国资委通过徐矿集团控股，央企/省属信用背书，融资成本低、资源获取能力强。

（3）产业链传导

上游：煤炭自给为主（新疆/陕西低成本的坑口矿），上游煤炭价格变动对电力端燃煤成本形成内部对冲；外购部分煤炭受市场煤价影响。
下游：电力售予江苏电网/用户，电价受市场化交易竞价影响（传导率中等，非完全顺价）；煤炭下游为电力自用 + 外销。
议价权：煤炭端中等（长协为主、价格受政策指导）；电力端偏弱（市场化竞价、买方为电网强势）。产业链位置为"资源端强、销售端中"，一体化对冲了部分周期波动。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：煤炭自给率高，煤价上涨时电力公司燃煤成本可被自产煤对冲（内部转移，传导率≈0.5）；但电力售价受市场化竞价约束，煤价→电价传导率≈0.4（不能全额顺价）。综合毛利承压弹性中等。
  • 因子2 毛利结构再平衡：煤炭毛利率受采矿权出让收益一次性抬升成本而阶段性下滑；电力毛利率因锡电超超临界低煤耗而改善。两板块毛利贡献占比从"煤强电弱"向"电增煤稳"迁移，结构再平衡利好长期稳定性。
  • 因子3 库存与采购节奏：自有煤矿库存稳定，长协覆盖大部分煤炭销售（平滑价格波动）；电力燃煤按需用采购，无显著囤货收益/损失。一次性采矿权出让收益属 timing 因素，不反映持续盈利能力，需在估值中剔除。
  • 因子4 政策/市场锚点：① 市场层——环渤海动力煤价格指数、江苏电力市场化交易电价；② 政策层——容量电价（托底火电固定成本）、煤炭保供核增（增产量）、能耗双控（约束落后机组）。情景：煤价中枢 650–750 元/吨、容量电价足额回收 → 验证点看季度电价结算与煤价走势。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务·市场容量 × 份额变量：
  • 供给侧份额：江苏区域能源供应，公司作为省属核心平台份额稳固（CR 高）；
  • 客户份额：电力独家供苏、煤炭内部协同，客户粘性极高；
  • 技术代际：锡电超超临界为行业先进代际，煤耗优于旧机组；
  • 成本曲线：西部自有矿 + 超超临界低煤耗，处于成本曲线左侧；
  • 份额加速度：能源保供政策下份额稳定，无快速扩张。
    → 中性份额小幅提升，验证点：锡电发电量、煤炭外销量季度数据。
  • 层2 扩展业务·主业迁移空间：从"单纯煤炭"向"煤电一体化 + 绿电"迁移，能力可迁移（同一能源赛道），新 TAM（绿电/储能）弹性中等；切入时点早，认证门槛低（自有资源）。未过验证点仅作中期期权。
  • 层3 风险折扣（证伪信号）：煤价跌破 600 元/吨且电价竞价恶化、锡电利用小时不达预期、容量电价退坡 → 下调增量。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：公司重资产（固定资产 + 在建占比高），PB 1.88x 不破净，资产以矿井 + 发电机组为主（专用性强，清算价值低于账面），但资源储量（20 亿吨）提供隐性安全垫。非金融资产未重估型破净，无额外安全边际。
  • 校正2 周期位置校正：煤炭处价格中枢下行周期、电力市场化竞价压制，中性净利采用产能/装机测算而非单年好年景，已剔除一次性，周期位置标注为"煤价中低位、电力竞价中性"。
  • 校正3 杠杆下行情景：资产负债率约 63.6%（有息负债重，财务费用 +61%），利率上行或煤价大跌时净利可几倍跳负，悲观情景空间 −66.9%，不得标"大空间/重点关注"。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。现价 4.20 元对应 2026E PE 96x、2029E 中性 PE 26x，远超煤电一体化 12–18x 合理区间，市场已提前定价锡电乐观预期。

安全边际：
- 中性远期 2.61 元 → 空间 −37.9%，无安全边际；
- 悲观 1.39 元 → 下行 −66.9%；
- 乐观 4.70 元 → 仅 +12.0%，且需锡电超产 + 煤价回升双重兑现；
- 下行保护：PB 1.88x、账面净资产 153.66 亿、经营现金流 14.83 亿（+78.68%）提供一定底线，但重资产清算价值有限。

介入条件：
1. 不追高。回落至 2.80 元以下（2029E 中性 PE < 18x）才具安全边际；
2. 加仓信号：① 锡电单季发电量达设计值 80% 以上；② 煤价回升至 750 元/吨以上且电价竞价改善；③ 财务费用率回落（有息负债压降）。
3. 观察指标：逐季煤炭销量、锡电利用小时、容量电价回收额。

最大风险：
1. 锡电爬坡/利用小时不及预期（首要）：乐观情景的全部逻辑依赖锡电达产，若电力竞价恶化则增量落空；
2. 煤价持续低位 + 一次性成本常态化：采矿权出让收益虽一次性，但若后续仍有类似计提将压制利润；
3. 高负债财务杠杆：资产负债率 63.6%，利率上行直接吞噬净利；
4. 电力市场化竞价压缩火电毛利：新能源挤压利用小时。

结论：暂不介入

公司资产优质、煤电一体化协同扎实、锡电提供真实增量，但当前 4.20 元价格已透支未来 2–3 年乐观预期，中性测算内在价值仅 2.61 元，风险收益不对称。仅当回落至 2.80 元以下或锡电超产 + 煤价回升被验证时，才具备重新评估价值。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • 类型A 行业调整剩者红利：煤炭保供政策下中小矿出清，公司作为省属核心平台份额提升 → 验证点：产能核增批复、份额数据。
  • 类型B 政策反转期权：容量电价上调或煤价触底回升 → 重估弹性：若煤价回 800 元 + 电价改善，净利可上探 18 亿（乐观 4.70 元）。验证点：容量电价政策发文、煤价指数。
  • 类型C 市场错杀修复：若因情绪导致跌破 2.5 元（PB<1.3x），估值分位极低 → 修复触发点：煤价企稳 + 锡电达产公告。
  • 类型D 技术突破期权：超超临界 + 掺烧/绿电耦合技术降本 → 硬验证点：煤耗指标、掺烧比例。证伪信号：利用小时持续低于设计值。

    上调至"纳入观察/重点关注"的条件：锡电达产验证（单季发电量达设计 80%）+ 现价回落至 3 元以下，或煤价回升至 750 元/吨以上且电价改善。
