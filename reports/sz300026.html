第一步：公司是干什么的？

一句话定位：国内中药配方颗粒三强之一（旗下"康仁堂"为行业第二），同时手握独家中药注射剂大单品"血必净"，并延伸布局原辅料、医疗器械、医疗健康服务与药械智慧供应链。

核心产品：
- 中药配方颗粒及饮片（康仁堂品牌）：单味中药饮片经水提、浓缩、干燥、制粒而成，即冲即服，是中药现代化核心剂型。
- 血必净注射液：公司独家品种，用于脓毒症/全身炎症反应综合征，已被纳入国际权威指南，毛利率高达 81.64%。
- 原辅料（药用辅料与原料）、医疗器械、中医医疗服务连锁。

主要客户／下游：公立中医医院与综合医院中医科、基层医疗机构、医药商业配送商。终端受医保支付与医院采购政策强约束。

境内外收入占比：以境内为主。区域结构：华北 5.82 亿（26.60%）、华东 5.39 亿（24.61%）、华中 3.50 亿（16.00%）、其余区域合计 7.17 亿（32.78%）——全国化布局、无单一区域依赖，这是相对优势。境外收入占比极小，未单独披露。

股东背景：天津红日药业股份有限公司，创业板老牌中药企业，无明确央企控股背景（实控人结构以年报披露为准）。

政策判断（必须区分"鼓励"与"压价"两股力量）：
- 鼓励侧（真实利好）：十五五规划把基层中医药服务扩容写进国家战略，县级中医医院、中医馆、中医阁建设直接扩大配方颗粒的使用场景；414 个国标落地意味着行业规范化完成，头部企业（含康仁堂）的标准与渠道壁垒反而加固；江西等省医保乙类支付打开增量。
- 压价侧（真实利空）：零差率（国办 2026-04）是行业盈利模式的根本性重构——医疗机构配方颗粒业务从"利润中心"变成"成本中心"，直接压制终端用量与价格；集采平均降幅 50%+；第二批饮片集采 41 品种持续推进。
- 净效果：短期阵痛、长期集中。这就是为什么公司营收 −21.72% 但毛利率 +5.54pct——砍掉的是低毛利渠道业务，留下的是高毛利但被压价的制造业务。

（3）产业链传导

上游：中药材（天然药材）为主，其次为药用辅料、包材。中药材价格 2025–2026 整体处于下行/低位区间（前期扩产供给释放），这构成公司毛利率同比 +5.54pct 的重要来源之一。上游议价权：中等（公司规模采购 + 60 个高标准原料基地政策导向）。

下游：公立医院（中医科/中医院） + 医药商业。零差率后医院无加价动力，议价权由医院转向医保与集采平台。公司议价权：分品种分化——
- 血必净（独家、进国际指南）：议价权强（毛利率 81.64% 且在收入 −13.50% 时毛利率仍提升）
- 配方颗粒（康仁堂）：议价权中等偏弱（CR3 79% 有壁垒，但集采降价 40%+ 阈值、零差率压制，毛利率 −1.34pct）

产业链位置：位于"中药材种植 → 配方颗粒/中成药制造 → 医院/零售终端"的中游制造端，上游有成本波动、下游有政策压价，是典型的"两头受挤、靠规模与独家品种突围"位置。

因子3 库存与采购节奏（timing）
- 存货周转率仅 0.34 次（半年口径），中药材存货周期长达 2–3 年，公司存在显著的"囤货节奏"效应。
- 低价囤货收益：2024–2025 药材价格高位时采购的库存，若在 2026 仍在消化，会压制毛利；反之 2025 下半年起药材价格回落，新采购低成本药材在 2026–2027 释放成本红利。2026H1 毛利率 +5.54pct 中应包含一部分前期低价药材库存的兑现——该收益会随库存周转完毕而回落，不得视为真实盈利能力的永久性提升。
- 高价接货损失风险：存货账面规模大（周转 0.34 次），若药材价格继续下行，将触发存货跌价准备计提——这是 H2 及 2027 的潜在利润杀手。
- 对冲：公司无公开披露的药材套保或长协比例，属裸敞口。
- 验证点：半年报/年报的存货余额、存货跌价准备计提金额、毛利率环比走势。证伪信号：若 2027 年毛利率回落至 52% 以下而收入未明显恶化，即证明 H1 的高毛利含库存红利、不可持续。

准亏损从严：正常化净利润法 + 利润塌陷三问

公司当期为正（归母 0.78 亿），但归母净利率 3.57%、ROE 0.91%、PE(TTM) 532x 属分母塌陷型失真。按规则，凡以正常化净利润法为主估值锚的，均须写本小节（三问改写为"为什么利润塌陷 / 靠什么恢复 / 生存能力"）。

三问之一：为什么利润塌陷？
1. 零差率政策（国办 2026-04）重构盈利模式：医疗机构失去加价动力，配方颗粒从"利润中心"变"成本中心"，终端用量与价格双压。
2. 集采降价：15 省联盟集采降价阈值 40%，第四批中成药集采平均降幅超 50%。
3. 配方颗粒国标切换 + 合规成本：414 个国标推高质控成本；销售合规整治（国家医保局曝光回扣案）推高合规成本、压低带金销售模式效率。
4. 低毛利业务拖累：药械智慧供应链在收缩前大幅拉低综合毛利率。
5. 康仁堂 2025 年净利转亏 −0.84 亿（2021 年曾 6.64 亿）——核心子公司的盈利能力被政策直接击穿。

三问之二：靠什么恢复？触发时点在哪一年？
- 路径 A（确定性最高）：结构出清——低毛利供应链业务砍完后，综合毛利率从 51% 台阶抬到 56%–57% 台阶，并保持。已基本完成（2026H1 验证）。
- 路径 B：以量补价——江西医保乙类支付（2026-08-01）+ 基层中医药扩容（十五五），若更多省份跟进医保支付，配方颗粒销量可对冲降价。
- 路径 C：血必净放量——国际权威指南背书，若转化为临床用量，9.5 亿收入 × 80% 毛利率是利润的压舱石。
- 路径 D（期权）：中药创新药/经典名方转化——未过验证点，不计入中性。
- 费用杠杆：费用绝对额从 23.3 亿降至 18.8 亿（−19%）是利润恢复的最大贡献项，但依赖持续的费用管控，不确定。
- 触发时点：2028 年（集采降价冲击基本出清 + 费用管控见效 + 基层扩容放量）；若 2027 年医保支付省份大幅扩容，可提前至 2027。

三问之三：生存能力（亏得起吗）？
- 资产负债率仅 15.89%（2026Q1），有息负债率 31.33%，速动比率 3.62、流动比率 4.70，财务结构极稳健。
- 归母净资产 85.3 亿，经营现金流年化约 7 亿，无任何生存风险。
- 但反面：极低杠杆 + 庞大净资产 = ROE 弹性极弱。85.3 亿净资产只产生 1.5–3.0 亿利润，ROE 仅 1.8%–3.5%，这是压制估值中枢的根本原因，也是"PB 1.12x"的市场定价逻辑——市场给的不是破产折价，而是低 ROE 折价。

  2. 算正常化净利率（三者取保守）：

  4. 公司历史最好年份净利率：2022 年 6.24/66.50 = 9.4%
  5. 产能爬坡/政策出清后理论净利率：配方颗粒集采后 6%–8%，加权约 7.0%

第四步进阶：重资产 / 周期股三道校正

校正1 资产质量折扣（PB 近 1 的原因必须说明）
- 公司 PB 1.12x，未破净但极度接近。必须回答"为什么市场只给 1.1 倍净资产"：
- 核心原因是 ROE 极低（0.91%），而非资产质量差。85.3 亿净资产只创造不到 1 亿利润，市场按"低盈利能力资产"定价，属公允定价，不是错杀。
- 资产构成风险点：①商誉——公司历史上多次并购（康仁堂等），商誉余额需关注，若配方颗粒持续不达预期将触发减值；②存货——周转率 0.34 次，中药材跌价风险；③应收账款——医院回款周期长。
- 不存在"金融资产未重估型破净"的安全边际：公司无持有上市公司股权的重大浮盈（若有参股，规模未达可重估标准），不能凭"PB 接近 1"推导空间大。
- → 正确的逻辑是：PB 1.12x 的修复必须靠 ROE 修复驱动，而非靠"资产便宜"驱动。

校正2 周期位置校正（周期归一化）
- 公司不是产能周期股，但受中药政策周期强驱动，必须标注周期位置：
- 当前周期位置：中药配方颗粒"政策冲击期"的中后段——价格底已现（2026-04 零差率落地为标志性事件），但盈利底未确认（康仁堂 2025 净利 −0.84 亿，2026H1 母公司整体微利）。
- 中性净利禁止用"2022 年 6.24 亿"作为起点（那是集采前的好年景，含渠道加价红利，已被零差率永久消灭）；也禁止把 2026H1 扣非 +16.67% 当作拐点年化（其中含一次性结构效应与库存红利）。
- 周期归一化结果：正常化净利率 7.5%（介于历史最好 9.4% 与政策出清后理论 7.0% 之间，取保守）。
- 验证点：综合毛利率能否稳定在 56% 以上、配方颗粒收入同比是否转正。证伪：若 2027 年综合毛利率跌回 52% 以下且配方颗粒收入继续下滑 → 周期位置需下修至"更深的盈利底"，中性目标价下调至 3.0 元以下。

校正3 杠杆下行情景（低杠杆，但仍需负面情景）
- 资产负债率 15.89%，远低于 60% 阈值，无财务杠杆风险，不触发"高负债必附负面情景"的强制条款。
- 但仍给出需求下行情景：若①配方颗粒在核心省份再降 20%、②零差率导致终端用量下滑 10%、③中药材价格上涨 15%（传导率 0.62 → 毛利承压 5.7pct），则 2029E 营收降至 34 亿、毛利率降至 51%、费用仅压到 20 亿 → 归母约 0.7 亿，PE 25x 仅 17.5 亿市值，此时 PB 0.9x × 88 亿 = 79 亿（2.63 元）成为有效托底。
- 结论：下行情景下空间约 −17%（2.63～2.78 元），净资产提供有效保护，但不支持"大空间"结论。

期权纪律：中药创新药/经典名方获批、医保乙类多省扩容、资产注入、行业出清后份额跳升——未过验证点的一律不计入中性净利，仅进乐观栏（乐观情景 5.27 元已部分包含医保扩容与份额回升，但不含创新药）。

- 中性远期 3.57 元 → 空间 +12.3%，不满足"重点关注"的 >50% 门槛
- 悲观 2.78 元 → 下行 −12.6%（净资产托底，下行有限）
- 乐观 5.27 元 → +65.7%（需医保扩容 + 血必净放量 + 出清后份额回升同时发生）
- 风险收益比：上行 12.3%（中性）/ 65.7%（乐观） vs 下行 12.6%（悲观）——中性情景下风险收益接近对称，但下行有净资产硬保护，属于"低赔率、低风险"类型

介入条件
1. 现价 3.18 元可小仓位建仓观察仓，但不构成"重点配置"。
2. 加仓价位：回落至 2.90 元以下（PB < 1.02x，接近净资产）为较好安全边际；2.75 元以下（PB < 0.97x，破净）为强安全边际。
3. 加仓信号（需同时满足两条）：① 综合毛利率连续两个半年度 ≥ 56%（证明结构改善可持续）；② 配方颗粒收入同比转正或降幅收窄至 5% 以内；③ 第三个及以上省份落地配方颗粒医保乙类支付。
4. 观察指标：季度毛利率、存货跌价准备计提、康仁堂半年度净利、各省集采中选价、中药材价格指数。

最大风险（最可能破坏逻辑的因素）
1. 零差率 + 集采二次杀价（首要）：国办零差率已重构盈利模式，若省级集采在中选价基础上再降 20%+，配方颗粒毛利率将从 58.8% 跌向 50% 以下，利润修复逻辑直接证伪。
2. H1 高毛利含一次性成分：+5.54pct 中约 4.9pct 来自砍低毛利业务、1.0–1.5pct 来自药材库存红利，均不可重复。若市场误读为趋势性改善，将形成严重高估。
3. Q2 已现走弱：单季归母 1237 万、环比 −81.17%，H1 利润高度集中 Q1，H2 存在低于预期风险。
4. 低 ROE 陷阱：85.3 亿净资产对应 1.8%–3.5% 的 ROE，即使利润修复到 3 亿，ROE 也仅 3.5%，估值中枢难以系统性抬升。
5. 商誉与存货减值：并购商誉 + 周转 0.34 次的药材存货，是资产负债表中的两颗雷。

结论：纳入观察

理由：① 中性远期空间 +12.3%，>0 但不达"重点关注"的 >50% 门槛 → 归为"纳入观察"；② 公司质地有明确加分项：资产负债率 15.89%、经营现金流年化 7 亿、净现比 458.57%、扣非 > 归母（无利润空心化）、血必净毛利率 81.64% 且进国际指南、配方颗粒行业第二（16.8%）；③ 核心矛盾是政策压价（零差率 + 集采）与低 ROE（0.91%）——下有 88 亿净资产托底（每股 2.93 元），上有 ROE 天花板压制；④ 不是回避标的：主业非萎缩（是主动收缩低毛利业务）、现金流充沛、无生存风险。
核心跟踪点：季度毛利率能否守住 56%、配方颗粒收入同比能否转正、医保乙类支付省份扩容数量。
操作建议：现价可小仓位观察，2.90 元以下加仓；若 2027 年毛利率跌回 52% 以下应立即重估。
