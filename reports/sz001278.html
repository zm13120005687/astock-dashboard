第一步：公司是干什么的？

一句话定位：国内乘用车内外饰塑料件与金属件 Tier-1 供应商，正从传统合资品牌配套向新能源整车厂转型，并切入新能源"铜排 / 高压电缆"新赛道，目前处于转型爬坡期亏损阶段。

主要客户 / 下游：下游为乘用车整车厂。2024 年前以日系等合资品牌为主，2024 年起主动开拓国内新能源整车厂（客户结构调整期）。子公司层面覆盖一汽丰田系（一彬丰田）、广汽系（广州翼宇）、上汽/通用五菱系等。

实控人 / 股东背景：民营企业，实控人王氏家族（董事长王建华）。上市于 2023 年深交所主板，无国资背景，融资高度依赖银行借款。

（3）产业链传导

上游：塑料粒子（PP/ABS）、钢材、铜（新能源铜排）。议价权中等偏弱——塑料件毛利率仅 8.10%，成本传导不畅；金属件毛利率 22.07% 较好。铜价上行对新能源铜排业务形成成本压力。
下游：整车厂强势，年降压力常态化；客户结构调整期（合资 → 国内新能源）致单价与毛利率双降。
议价权判断：中偏弱，佐证为塑料件毛利率 8.10%、连续两年毛利率下滑、应收账款增至 7.51 亿（同比 +7.45%）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（转嫁系数）：塑料件转嫁系数 ≈ 0.2（上游粒子涨价多由公司承担，毛利被吃）；金属件转嫁系数 ≈ 0.6（部分转嫁）；铜排业务因客户认证期，短期转嫁系数 ≈ 0.3。综合转嫁系数低是毛利率仅 10–13% 的根因。
  • 因子2 毛利结构再平衡：塑料件占营收 64% 但毛利率仅 8.10%，金属件占 26% 毛利率 22.07%——提高金属件 / 模具（29.36%）占比是扭亏关键杠杆。若金属件占比由 26% 提升至 35%，综合毛利率可抬升约 2pct。
  • 因子3 库存与采购节奏：存货 7.41 亿（占总资产 17%），2025 计提存货跌价 2440 万；存在高价接货损失风险。无长协套保公开披露，timing 收益不明显。
  • 因子4 政策 / 市场锚点：① 以旧换新政策托底整车销量（利好需求）；② 整治"内卷式"竞争有望缓解年降（毛利修复期权）；③ 铜价（新能源铜排成本）受全球供需与关税影响；④ 无出口管制直接冲击（境外占比 <2%）。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：内外饰塑料件行业分散，公司全国布局 12 家分支机构，产能充足；
  • 客户份额：从日系合资转向国内新能源整车厂，短期份额丢失（合资下滑）、长期份额待验证；
  • 技术代际：模具 29.36% 高毛利，具备同步开发能力；
  • 成本曲线：金属件盈利优于塑料件，结构迁移改善成本曲线；
  • 份额加速度：新能源客户开拓处 S 曲线早期。三档：保守守住现有 21 亿营收（验证点：国内新能源客户定点公告）；中性小幅提升（验证点：新能源营收占比 >30%）；乐观抢份额（验证点：进入头部新能源供应链）。
  • 层2 扩展业务：主业迁移空间（新能源铜排）：能力可迁移（金属加工同源）、新 TAM（新能源车高压连接大几倍）、卡位早期、认证门槛高（既是护城河也是阻力）。未过验证点，仅作中期期权，不计入中性净利。验证点：铜排大额订单公告、新能源营收占比跳升。
  • 层3 证伪信号：塑料件毛利率持续 <8%、新基地连续两年亏损、新能源铜排无正式订单、银行抽贷致现金流断裂。

第四步：估值锚定（自下而上，正常化净利润法）

亏损股方法：无正净利可锚，改用正常化净利润法（估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价）。当前亏损源于转型爬坡 + 减值 + 财务费用，非主业崩塌。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵（短期）。现价 16.76 元对应 2026 年仍亏损、PB 1.87x，短期无业绩支撑。

安全边际：
- 中性远期 18.2 元 → 空间 +8.6%，不达"重点关注" >50% 门槛；
- 悲观 11.7 元 → 下行 −30.2%；
- 乐观 28.8 元 → +71.8%（需新能源突破）；
- 下行保护：每股净资产约 8.95 元（11.07 亿 / 1.237 亿股），PB 1.87x；高负债率 74.3% 削弱安全垫。

介入条件：
1. 等扭亏验证：2026H2 或 2027H1 归母净利转正，且新基地（芜湖/盐城/湖州）单厂扭亏；
2. 加仓信号：① 新能源铜排 / 高压电缆获头部客户大额定点订单；② 金属件营收占比升至 >32%（毛利结构改善）；③ 经营现金流转正、财务费用率下降；
3. 价格锚：回落至 13 元以下（PB <1.5x）才具安全边际。

最大风险（最可能破坏逻辑的因素）：
1. 转型期持续失血：2026H1 亏损已扩大至 −1.02 亿，若新基地与新能源迟迟不达预期，亏损延续；
2. 高杠杆脆弱性：资产负债率 74.3%、有息借款约 10.44 亿（短借 6.74 亿+长借 3.70 亿），2026H1 经营现金流 −0.51 亿、靠筹资 +3.52 亿续命，利率上行或银行抽贷致现金流断裂；
3. 毛利率修复不及预期：塑料件转嫁系数低（≈0.2），若年降持续、粒子涨价，毛利难回 12%+；
4. 存货跌价：存货 7.41 亿，若需求下滑计提扩大。

亏损股三问：
1. 为什么亏：客户结构从日系合资转向国内新能源致毛利率下降 + 应收增加信用减值 + 银行借款增财务费用 + 2025 计提减值 3315 万 + 一彬新能源及多家新基地（芜湖/盐城/湖州/广州翼宇搬迁）爬坡期亏损。属"转型爬坡 + 减值 + 财务费用"型亏损，非主业崩溃。
2. 靠什么扭亏·触发时点：① 新基地达产形成规模效应（2027–2028）；② 新能源铜排 / 高压电缆放量（验证点：大额订单）；③ 减值冲回与毛利率随整治"内卷"修复；④ 金属件高毛利占比提升。预计 2027 年有望扭亏，2029 年稳态正常化净利 ~1.13 亿。
3. 亏得起吗：账上现金 6.90 亿 + 经营资产（应收 7.51 亿、存货 7.41 亿可变现），可覆盖短借 6.74 亿；但 2026H1 经营现金流转负、投资仍净流出 3.15 亿，依赖再融资。短期（1–2 年）靠续贷可撑，但若持续亏损 + 利率上行 + 抽贷则风险陡增——生存能力中等偏脆弱。

第五步进阶：上行想象力情景（四类，对冲系统性保守偏置）

  • A 行业调整剩者红利：汽车"内卷式"竞争整治 + 以旧换新托底，份额向已上市配套厂集中，公司塑料件毛利率有望由 8.10% 修复至 12%+。验证点：整治内卷政策落地、塑料件毛利率回升。证伪：年降持续、毛利率破 8%。
  • B 政策反转期权：2026 以旧换新 2500 亿国债延续、新能源渗透率破 60%，整车销量企稳带动配套需求。验证点：2027 以旧换新政策延续、新能源渗透率 >60%。证伪：政策退坡。
  • C 市场错杀修复：当前 PB 1.87x 因亏损被压制，若 2026H2/2027H1 扭亏，估值修复弹性大。验证点：扭亏公告。证伪：继续亏损。
  • D 技术突破 / 代际跃迁期权：新能源铜排 / 高压电缆从 0 到 1 投产，切入新能源车高压连接新赛道。验证点：头部客户大额定点 + 量产成本优于旧路线。证伪：良率不达标、客户流失。

上调至"重点关注"的条件：2026H2 或 2027H1 归母转正 + 新基地（芜湖/盐城/湖州）单厂扭亏 + 新能源铜排获大额定点订单，使中性远期空间突破 +50%。

结论：纳入观察（扭亏验证前安全边际不足，等 H2 扭亏或新基地达产信号再上调）

公司主业（内外饰件）仍具客户与产能基础，亏损为转型爬坡阶段性现象；但亏损加深、杠杆高、现金流转负，需以"2027 扭亏"为硬验证点。中性远期空间仅 +8.6%，不满足重点关注门槛；若新能源铜排突破（乐观 +71.8%）则具备上调条件。
