一句话定位：以高分子材料、树脂基复合材料、金属材料为核心的专用防护装置及装备零部件研发生产商，是国内弹药贮运防护领域核心供应商、国家级专精特新"小巨人"。

（3）产业链传导

上游：高分子材料、树脂基复合材料、金属材料。成本受树脂 / 金属价格影响。公司正向上游自研自产配套（核心原料自主可控），长期压降采购成本。下游：兵器 / 兵装集团，军工审价定价，需求稳定。

议价权：对下游——中等（军工核心配套、客户粘性强，但受审价约束）；对上游——中等偏弱（原料被动接受，正通过自研配套改善）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（转嫁系数）：军工装备多为成本加成 / 审价定价，原料涨价传导系数约 0.5–0.6（部分可审价调整但滞后），综合毛利守稳 35% 印证传导基本覆盖。
  • 因子2 毛利结构再平衡：防护装置 35.10%（占 96.54%）为盈利主体；装备零部件 45.62%（占比仅 2.29%，毛利高但体量小）；天秦智合复合材料（天线罩）毛利更高但当前未并表利润。禁止用单一综合毛利 35% 代表全结构——零部件与复合材料的高毛利尚未在收入结构中体现。
  • 因子3 库存与采购节奏：军工按计划采购，原料库存适中；新厂区引入自动上料 + 全封闭集中供料系统，优化采购节奏、压降原料波动。
  • 因子4 政策 / 市场锚点（成本驱动变量）：①市场层——树脂 / 金属（铝 / 钢）价格、运费；②政策层——军品定价改革（审价调整节奏）、军工供应链自主可控（自研原料降本）、环保 / 能耗双控（抬升高分子料成本）。验证点：审价调整公告、原材料价格走势、自研原料降本兑现；证伪：原料大涨且审价未调、毛利破 32%。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：产能瓶颈刚突破（此前营收骤降系搬迁而非需求），满产后供给能力跃升；
  • 客户份额：兵器 / 兵装集团核心供应商，份额稳固；
  • 技术代际差：树脂基复合防护技术领先；
  • 成本曲线：自研原料配套 + 自动产线，成本左移；
  • 份额二阶导数：产能释放初期，份额加速回补。
    三档：保守守住（恢复至 2025 水平）/ 中性小幅提升（新厂区满产）/ 乐观抢份额（复合材料放量）。
  • 层2 扩展业务：主业迁移空间（防护 → 透波复合材料，航空 / 航天 / 无人装备）：能力可迁移（复合材料同源）、新 TAM（航空 / 航天配套远大于地面防护）、切入早（天秦智合已建产线）、认证门槛高（军工配套资质）。未过验证点（客户批量验证 / 大额订单）仅作中期期权。
  • 层3 风险折扣（证伪信号）：新厂区爬坡不及预期、复合材料客户验证失败、审价大幅压价、核心客户流失。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（破净原因）：不适用——PB 2.93x，未破净；且账面现金 + 金融资产 4.78 亿占总资产 41%，资产质量扎实，无隐含负债。
  • 校正2 周期位置校正：军工防护非强周期，需求由国防预算（刚性 +6.9%）与装备费占比提升驱动，当前处稳健上行通道，无周期顶部风险。
  • 校正3 杠杆下行情景：不适用——资产负债率仅 14%、无有息负债，不存在杠杆反噬。最大下行来自产能爬坡节奏与审价，已在悲观情景体现。

交叉校验：现价 18.01 元对应 TTM PE 83x，中性远期 17.40 元（−3.4%）——现价已基本反映产能恢复预期；乐观情景（+52%）需复合材料验证兑现方成立。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵。现价已接近中性远期（−3.4%），但较悲观情景（9.6 元）仍有 47% 下行，安全垫不厚。

安全边际：中性远期 −3.4%；乐观 +52%（需复合材料验证）；悲观 −47%。下行保护来自净现金 4.78 亿（每股约 3 元）+ 无负债。

介入条件：① 回落至 14 元以下（对应 2029 中性 PE 约 28x）具安全边际；② 天秦智合复合材料获航空 / 航天客户批量订单公告（上调至重点关注）；③ 2026 三季报确认新厂区营收恢复至 1.5 亿+ 单季。

最大风险：① 新厂区爬坡 / 订单恢复不及预期（首要）；② 军工审价压价侵蚀毛利；③ 天秦智合复合材料验证失败（期权证伪）；④ 客户高度集中（兵器 / 兵装）的单一风险。

结论：暂不介入（中性远期空间 −3.4% 为负，当前估值未提供安全边际；逻辑正确、底盘扎实，但产能恢复与复合材料期权尚未验证，待复合材料批量订单落地或现价回落至 14 元以下再重估）。

第五步进阶：上行想象力四类情景

  • A 行业出清剩者红利：军工防护集中度提升，公司为核心供应商，新厂区满产后份额加速回补。验证点：单季营收恢复至 2025 水平、份额跳升；证伪：爬坡持续低于预期。
  • B 政策反转期权：国防预算 +6.9%、装备费占比 >41%、弹药消耗属性强化，需求端持续加码。验证点：装备费增速、弹药采购放量；重估弹性：乐观 27.4 元（+52%）。未过验证点仅作机会情景。
  • C 市场错杀修复：军工板块风格切换 / 系统性回调错杀（现价已接近中性）。验证点：板块企稳、基本面未恶化。
  • D 技术突破 / 代际跃迁期权：天秦智合高性能透波复合材料（天线罩 / 硅基头罩）从 0 到 1 投产，切入航空 / 航天 / 无人装备。三要素：政策（新域新质力量）+ 趋势（复合材料替代）+ 落地（客户验证 + 批量供货 + 成本优于旧路线）。硬验证点缺一则只作机会情景。触发上调重点关注条件：复合材料获正式批量订单且并表利润兑现。
