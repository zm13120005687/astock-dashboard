第一步：公司是干什么的？

一句话定位：安徽国资背景的氯碱化工一体化企业，以"PVC + 烧碱"为核心，配套原盐/灰岩开采、电石制备、发电与水泥，构建循环经济，但当前处于 PVC 景气低谷、主业失血阶段。

主要客户/下游：PVC 供管材/型材/地板等地产链；烧碱供氧化铝/化工/造纸；灰岩供建材。下游高度绑定房地产与基建周期。

（3）产业链传导

上游：原盐（自采）、灰岩（自采）、煤炭（发电/电石）、电石——能源与电石成本决定 PVC 成本；议价权中等（部分自供）。
下游：PVC→地产链（弱）、烧碱→氧化铝/化工（强）；下游需求分化，"碱强氯弱"。
议价权：周期品，对下游议价权弱；一体化（自供盐/灰岩/电）部分对冲成本。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：PVC 为大宗，成本（电石/煤/电）难向下游顺价（传导率≈0.2–0.3），价格跌时毛利直接被吃；烧碱传导率较高（≈0.5）。综合毛利对能源/电石价格极敏感。
  • 因子2 毛利结构再平衡：烧碱（55.71% 毛利、占 24%）补贴 PVC（−10.59%、占 56%）亏损，灰岩（50.52%）补充；结构高度依赖"碱强"抵"氯弱"，若烧碱回落则整体转差。
  • 因子3 库存与采购节奏：PVC 存货 3.27 亿（+45.85%，需求低迷累库），库存跌价风险上升；电石随采随用，无显著囤货收益。
  • 因子4 政策/市场锚点：① 市场层——PVC/烧碱价格、电石/煤价、房地产新开工；② 政策层——能耗双控（抬升电石法成本、淘汰落后）、环保整改、地产托底。情景：PVC 价格回升 + 电石成本下降 → 验证点看 PVC 期货、电石价格。

  • 层1 现有业务·份额变量：
  • 供给侧份额：华东氯碱重要产能，能耗约束下份额趋稳；
  • 客户份额：氧化铝/建材客户稳定；

  • 层2 扩展业务·主业迁移空间：从"通用 PVC"向"可降解塑料/高端改性 PVC"迁移，能力可迁移（同源氯碱化工），新 TAM（新材料）弹性中等；切入时点早，认证门槛中等。未过规模验证仅作中期期权。
  • 层3 风险折扣（证伪信号）：PVC 价格再跌、电石/煤价上涨、烧碱景气回落、存货跌价 → 下调增量。

第四步：估值锚定（自下而上，正常化净利润法）

亏损股估值方法（RULES 第四节）：亏损期无正净利可锚，改用三步推导——① 估稳态营收（满产 + 价格中性）；② 算正常化净利率（行业正常 / 历史最好 / 爬坡后理论，取保守）；③ 正常化净利润 × 远期 PE = 目标市值 → 目标价。

第五步：综合赔率判断（买不买？）

亏损股三问（必须回答）

① 为什么亏：核心在 PVC——电石法成本高于售价（2026H1 PVC 毛利率 −10.59%，单板块毛利亏损约 1.29 亿），叠加行业产能过剩、房地产需求疲软、'碱强氯弱'格局；同时 PVC 存货累库（+45.85% 至 3.27 亿）隐含跌价风险。烧碱虽强（毛利 55.71%），但体量不足以完全覆盖 PVC 失血，整体归母 −0.76 亿。属"行业周期底部 + 主业（PVC）持续承压"型亏损，非一次性减值。

② 靠什么扭亏，触发时点：a) PVC 价格回升或电石/煤/电成本下降（公司供电标煤耗已改善、综合成本 −7%+）；b) 烧碱高景气延续提供现金流底盘；c) 可降解塑料 / 高端改性 PVC 新材料（研发 1.10 亿，+14.35%）逐步形成增量；d) 全要素成本管控持续见效。触发时点：2027–2028 年——若 PVC 价格温和回升至盈亏平衡上方 + 成本管控兑现，公司可由亏转盈（中性正常化 2.5 亿）。

③ 亏得起吗：亏得起。经营现金流已转正（+1.57 亿，同比由 −0.61 亿改善），账面归母净资产 58.80 亿、负债率仅 36.9%、安徽省国资背书融资能力强，无短期偿债与退市风险。现金流足以支撑到行业拐点，不会"倒在黎明前"。

当前价格位置：偏高（相对正常化价值）。现价 2.33 元已隐含乐观情景（2.50 元），中性正常化内在价值仅 1.04 元。

安全边际：
- 中性远期 1.04 元 → 空间 −55.4%；
- 悲观 0.17 元 → −92.7%；
- 乐观 2.50 元 → +7.3%（需 PVC 强复苏）；
- 下行保护：PB 1.43x、净资产 58.8 亿、经营现金流转正、国资信用。

介入条件：
1. 不追高。等 PVC 价格确认回升（期货站上成本线）+ 公司单季扭亏验证后，回落至 1.8 元以下再考虑；
2. 加仓信号：① PVC 单季毛利率转正；② 存货去化（库存下降）；③ 可降解/改性 PVC 营收规模化；
3. 观察指标：PVC/烧碱价格、电石成本、逐季净利、经营现金流。

最大风险：
1. PVC 价格持续倒挂（首要）：地产链弱 + 产能过剩，PVC 毛利长期为负则扭亏遥遥无期；
2. 存货跌价：PVC 累库 3.27 亿，价格下行需计提减值；
3. 烧碱景气回落：若碱强转弱，现金牛失守；
4. 原材料（电石/煤）涨价：进一步吞噬 PVC 毛利。

结论：暂不介入

华塑股份亏损源于 PVC 周期底部（毛利率 −10.59%），但"亏得起"（现金流转正、净资产厚、国资背书）且存在明确扭亏路径（成本管控 + 烧碱底盘 + PVC 价格回升 + 新材料），不构成"确无扭亏可能"的回避条件。然而当前 2.33 元已定价乐观情景，中性正常化价值仅 1.04 元，风险收益不对称。若 PVC 价格连续回升 + 单季扭亏验证，可上调至"纳入观察"。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • 类型A 行业调整剩者红利：能耗双控淘汰电石法落后产能，剩者（公司自有资源/电）份额与定价权提升 → 验证点：产能出清、PVC 价格。
  • 类型B 政策反转期权：地产托底见效 + PVC 需求回升，或环保淘汰令供给收缩 → 重估弹性：PVC 毛利转正，净利冲 5 亿（乐观 2.50 元）。验证点：地产新开工、PVC 价格站上成本线。
  • 类型C 市场错杀修复：若随大盘回落至 PB<1.0x（<1.6 元），破净提供安全边际 → 修复触发点：PVC 拐点 + 现金流证伪恐慌。
  • 类型D 技术突破期权：可降解塑料/高端改性 PVC 从中试转量产、成本优于旧路线 → 硬验证点：客户定点、良率达标、成本优势。证伪：量产失败、需求不足。

    上调至"纳入观察"的条件：PVC 价格连续两季回升至盈亏平衡上方 + 公司单季归母扭亏 + 存货去化，三者验证后重新评估。
