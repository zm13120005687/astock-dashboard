第一步：公司是干什么的？

一句话定位：中国历史最悠久的柴油发动机制造商之一（前身上海柴油机厂，1947 年创立，1958 年造出中国第一台 6135 柴油机），如今是国内仅有的三家具备兆瓦级大功率发动机能力的厂商之一，靠"传统多缸柴油机基本盘 + AIDC 数据中心备用电源大功率发动机（自主 VK 系列 + 合资菱重）"双轮驱动。

（3）产业链传导——原料成本 → 毛利结构（四因子）

柴油机的核心"原料"是钢材（机体 / 缸盖铸件）、曲轴、增压器、电机电控与铜铝，成本占比较高；但本股真正的利润变量在产品结构（传统机 vs 大功率 AIDC 机）。

因子 1｜成本传导弹性（pass-through）
- 传统多缸柴油机（占收入约 7 成）：行业产能过剩、买方强势，传导率≈0.2–0.4（弱）——钢材涨价易被价格战吞掉。
- AIDC 大功率机组（12VK/16VK/S16R）：供不应求、客户为数据中心 EPC 与运营商，对交付周期与可靠性敏感度远高于价格，传导率≈0.8–1.0（强）——这是毛利率能同比 +4.45pct 的根因。
- 量化：钢材每上涨 5%，传统机毛利承压约 3–4pct，而大功率机凭强传导仅承压约 0.5–1pct。

因子 2｜毛利结构再平衡（分业务线敏感度）

业务线 收入权重 毛利率 原料（钢材）敏感度 利润贡献权重
传统道路 / 非道路发动机 高（约 60–70%） 低（约 8–12%） 高 低
AIDC 大功率自主 VK 中（快速上升） 高（约 15–20%） 中 中高
菱重 S16R（投资收益口径） 不计入收入 30–35% 中 高（近全部利润）
电池 Pack / 电驱桥 约 10% 低（8–11%） 低 低

结构迁移要点：公司利润结构正从"传统发动机微利"向"菱重大功率投资收益 + 自主 VK"剧烈迁移。若用单一"综合毛利率 10.28%"代表全结构，会严重低估 AIDC 业务的利润弹性；反之若把菱重 30–35% 的毛利率直接套到全公司，则会高估。必须分线给毛利、按权益法口径算菱重。

因子 3｜库存与采购节奏（timing）
- 2025 年公司完成上柴动力海安等基地产能梳理，原材料（钢材、铸件）采购以长约 + 现货组合为主，未披露套保比例——构成主要不确定源。
- 2026H1 营业成本 28.75 亿元（同比 +7.93%），成本增速低于营收增速（+13.29%），说明规模效应正在摊薄固定成本，非库存收益粉饰。
- → 当期与远期毛利可比性较好（本期无低价囤货型虚高）。

层 2｜扩展业务：主业迁移空间
- 能力可迁移性：高——柴油机平台（大排量、大功率、成熟工程平台、规模化制造）可平移至天然气 / 甲醇 / 氨发动机及数据中心成套机组；"从卖发动机到卖电站成套系统"是同一技术底座。
- 新 TAM 弹性：大——数据中心柴发 / 气发市场到 2030 年可达千亿元级，数倍于公司传统商用车发动机市场。
- 切入时点与卡位：早——国内仅 3 家具兆瓦级能力，公司在 AIDC 电源大功率赛道卡位靠前。
- 客户认证门槛：中高——数据中心对可靠性与认证（泰尔认证等）要求高，一旦进入粘性强。
- 信号验证：已有实质信号——2026H1 自主 VK +221.7%、菱重净利 +70%、上柴电力通过泰尔认证并交付首批订单。
- → 因部分信号已过验证点（销量、认证、订单），该迁移空间的确定性区间部分已计入中性（自主 VK 与菱重放量），20VK / 天然气机仍只放乐观情景。

层 3｜风险折扣：证伪信号
1. AIDC 资本开支降速或客户延期，自主 VK / 菱重销量不及预期。
2. 储能 + 燃气发电大规模替代柴发，兆瓦级需求见顶。
3. 传统发动机价格战致毛利率跌破 8%。
4. 上汽红岩持续亏损、长期拖累权益法投资收益。

命中任一项，对应增量剔除。

合计增量（中性口径）：传统机稳增 + 自主 VK 放量至约 18 亿元收入 + 菱重净利增长至约 5.0 亿元（权益 2.5 亿元）→ 2029 年中性归母约 7.0 亿元。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1｜资产质量折扣（PB 1.26，非破净但偏低）
- 公司不破净，PB 1.26x，每股净资产约 4.60 元。PB 偏低的原因是过去几年红岩重卡严重拖累（2024 年末资产负债率高达 73.41%），属"历史包袱型低 PB"，而非资产盈利能力差。
- 红岩出表后：合并负债从 97.1 亿元降至 43.7 亿元，净资产从 35.2 亿元升至 63.8 亿元，每股净资产从 2.53 元升至 4.60 元，报表已实质修复。
- 发动机产线为专用设备，清算价值低于账面，重置成本不构成硬底；但 4.60 元/股净资产提供一定缓冲（对应现价 −21%）。
- → 结论：PB 1.26x 属"修复型"而非"低估型"，不构成安全边际的核心，估值锚须落在盈利上。

校正 2｜周期位置校正（中性净利用周期归一化）
- 柴油发动机属中周期行业，当前处于周期上行段（发电机组用 +18.24%、AIDC 拉动兆瓦级供不应求），但传统道路 / 非道路机仍在价格竞争。
- 中性净利禁止用"单季扭亏年化"：2026Q2 归母 4329.82 万元，若简单年化得 1.73 亿元，低于本报告 2026E 的 2.60 亿元，说明本报告未依赖单季年化；亦禁止用 2025 年含 35.32 亿一次性收益的"好年景"。
- 本报告采用分部稳态盈利：传统机 2% 净利率（低于行业高景气年份）、自主 VK 12% 净利率（低于菱重 30–35% 毛利率对应的净利率）、菱重按 20–21% 净利率。
- 当前周期位置：上行早中段。

校正 3｜杠杆下行情景
- 资产负债率 40.65%（2025 年末），较 2024 年末的 73.41% 大幅下降，财务杠杆已显著改善。
- 但经营杠杆高：传统发动机固定成本重、AIDC 需求若不及预期，产能利用率下滑将快速吞噬利润；上汽红岩（14.66%）仍在亏损，构成负向拖累。
- 负面情景（悲观 3.03 元，−48.1%）即体现此风险。因杠杆可控，最悲观情景空间为负但不至于"坚决回避"。

期权纪律：20VK 3MW 机组、天然气 / 甲醇 / 氨多燃料发动机、海外 VK 认证、上汽红岩扭亏、国资资产运作——五项均为未过验证点的期权，一律不计入中性净利，只放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低（相对远期），但当期 PE 不便宜。现价 5.84 元对应 PE(TTM) 2.49x 属口径假象；按剔除一次性后的 2026E 归母 2.60 亿元计算，当前 PE 约 31x，PB 1.26x。市场已开始定价 AIDC 逻辑，但远期利润台阶（2028–2029）尚未充分反映。

安全边际：
- 中性远期 9.58 元 → 空间 +64.0%，超过"重点关注"的 >50% 门槛
- 悲观情景 3.03 元 → 下行 −48.1%（AIDC 降速 + 传统机价格战）
- 乐观情景 17.44 元 → +198.6%（20VK 落地 + 海外放量 + 红岩扭亏）
- 下行保护：PB 1.26x、每股净资产 4.60 元（约 −21%）、资产负债率降至 40.65%、2026H1 经营现金流 +1.54 亿元

介入条件：
1. 可逢放量确认后介入。现价 5.84 元对应 2026E PE 约 31x，处于合理区间；建议在 5.5 元以下分批建仓（对应 2026E PE < 29x）。
2. 加仓信号：① 菱重 2026 年 1600 台目标季度兑现；② 自主 VK 单季出货加速、20VK 取得客户定点；③ 上柴电力数据中心成套机组大额订单公告；④ 上汽红岩季度亏损大幅收窄。
3. 观察指标：逐季"投资收益 / 营业利润"占比——若 AIDC 自主 VK 收入占比持续提升且主业毛利率站稳 10% 以上，则中性上修。

最大风险（最可能破坏逻辑的因素）：
1. 利润过度依赖 50% 合营的菱重（首要）：2026H1 投资收益 7921 万元 ≈ 全部归母净利，公司不控制菱重，若菱重销量 / 盈利波动，利润直接受损。
2. AIDC 需求兑现节奏不确定：兆瓦级发动机放量依赖数据中心资本开支，若算力投资降速或储能 / 燃气发电替代柴发，弹性落空。
3. 传统发动机基本盘盈利薄弱：占收入约 7 成但净利率极低，价格战下易转亏。
4. 上汽红岩持续拖累：14.66% 权益法核算下 4–6 月已拖累 1262 万元，恢复期不确定。
5. PE(TTM) 2.49x 的误导性：投资者若以低 PE 买入而未识别一次性处置收益，将严重误判估值。

结论：重点关注

理由：中性远期空间 +64.0%，乐观情景 +198.6%，风险收益不对称偏正。
公司与潍柴、玉柴并列国内仅有的三家兆瓦级发动机厂商，AIDC 数据中心备用电源是 2026–2029 年确定性最高的高端制造需求之一；红岩出表后报表彻底修复（负债率 73%→41%、每股净资产 2.53→4.60 元），主业轻装上阵。关键纪律：PE(TTM) 2.49x 是一次性处置收益造成的假象，投资逻辑必须建立在"菱重放量 + 自主 VK 放量 + 传统机稳增"三条自下而上主线上。
核心跟踪点：菱重季度销量、自主 VK 出货结构、数据中心成套机组订单、上汽红岩减亏进度。
