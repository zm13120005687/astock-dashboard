聆达股份（300125）五步法分析报告

队列标注：无（核实：归母扭亏但扣非仍亏损，2026H1 归母 +2540 万元、扣非 −1770 万元）

第一步：公司是干什么的？

一句话定位：曾用名"*ST 聆达"，2025 年完成破产重整、剥离深陷亏损的光伏电池制造主业，转型为"光伏电站发电 + 光伏 EPC 工程"双轮驱动的重整壳股；多次易主，当前无控股股东、无实际控制人。

（3）产业链传导

上游：光伏组件、逆变器、EPC 施工（组件价格大跌降低电站建设与 EPC 成本，利好）；下游：电站投资方/电网（电价与消纳约束）。

议价权：弱。公司营收体量极小，EPC 为低毛利工程，无产业链话语权；光伏电站发电为特许经营/电网结算，现金流稳定但天花板低（仅 53MW）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：EPC 业务对组件/施工成本传导率约 0.5–0.7（工程合同多为总价或成本加成，组件降价可部分转化为毛利）；电站发电无原料成本，毛利稳定。
  • 因子2 毛利结构再平衡：发电业务毛利率 60.75%（2025）远高于 EPC 低毛利，但发电收入占比仅 17%，综合毛利率被 EPC 拉低，不能用发电高毛利代表全结构。
  • 因子3 库存与采购节奏：电站无库存；EPC 需关注组件采购时点（组件降价期采购成本下降），无重大囤货风险。
  • 因子4 政策/市场锚点：组件价格（行业出清进度）、电价/消纳政策。验证点：格尔木电站技改后发电量/收入、EPC 新签合同额。证伪信号：EPC 订单断档、电站收入不及预期。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 现有业务 = 市场容量 × 份额变量：光伏 EPC 市场巨大但竞争极度红海，公司体量小、无技术/资质壁垒，份额几乎可忽略（二阶导数无弹性）；电站发电为存量资产，无份额变量。
  • 层2 主业迁移空间（光伏 → 半导体材料/先进智造）：重整计划曾提"电致变色半导体膜等新材料"，产业投资人彭骞（精测电子）与众凌科技（精密金属掩膜版）有半导体资产背景。能力可迁移性低（光伏与半导体材料不直接同源）、新 TAM 弹性高、切入卡位未定、认证门槛高。完全未过验证点，仅作中期期权，不计入中性净利。
  • 层3 证伪信号：无资产注入正式公告、EPC 订单持续下滑、电站技改不达预期、无实控人致治理失序。

第四步：估值锚定（自下而上，非增速外推）

方法说明：聆达股份归母扭亏但扣非持续亏损、主营规模极小，PE 无意义。以正常化净利润法为主锚（估稳态营收 → 保守正常化净利率 → 合理 PE/净资产 → 目标市值 → 目标价），并辅以 PB 校验。

总股本：6.64 亿股（重整转增后；现价 9.05 元对应市值约 60.1 亿）

准亏损从严：正常化净利润法 + 三问

三问之一·为什么"亏"（扣非口径）：光伏电池制造主业（金寨嘉悦）2024-03 起停产，营收从 2023 年 8.39 亿萎缩至 2025 年 1.25 亿，主业几乎归零；2024 年因电池产线停产计提巨额减值，全年巨亏 9.50 亿、净资产转负（−2.01 元/股）。重整后归母靠重组收益扭亏，但扣非仍亏（2026H1 −1770 万）。

三问之二·靠什么扭亏、触发时点：① 主业切换至光伏发电 + EPC（发电毛利率高、现金流稳，但规模太小）；② 格尔木 53MW 电站技改（2026 年）提升发电收入；③ 真正的"弹性"在半导体资产注入（众凌科技等）——但无方案、无时间表。经营层面稳态扭亏（扣非转正）需 EPC 放量 + 电站技改见效，触发时点不明朗。

三问之三·亏得起吗：重整后净资产转正 10.78 亿，交易性金融资产约 4.7 亿（现金/理财），2026H1 归母净资产 10.78 亿、每股净资产约 1.62 元。短期无流动性危机，亏得起；但长期若 EPC 不达预期 + 无资产注入，将陷入"低营收 + 壳价值耗散"。

第四步进阶：重资产/周期股估值校正三道闸

  • 校正1 资产质量折扣：PB 5.58x 是"高估"而非"破净"，需回答的是"为什么这么贵"——答案：壳价值 + 注入预期。净资产 10.78 亿中现金类约 4.7 亿（质量尚可），但光伏电站/EPC 经营资产盈利能力弱（扣非亏损），不构成"低 PB 高安全边际"型机会。
  • 校正2 周期位置：光伏制造处于产能出清底部（公司已退出制造端，规避了价格战）；电站/EPC 处于平稳。正常化净利未用"单季扭亏年化"（2026H1 归母 +2540 万靠非经常损益，不能年化当稳态）。
  • 校正3 杠杆下行情景：重整后资产负债率大幅下降（2026H1 末约 39% 以下），无重大偿债风险；但无实控人 + 多次易主是治理层面的隐性杠杆，负面情景（资产注入落空、EPC 萎缩）下净资产会逐步耗散。
  • 期权纪律：众凌科技（半导体掩膜版）等资产注入完全未过验证点，不计入中性 NAV/净利，仅列示于乐观/机会栏。

第五步：综合赔率判断（买不买？）

当前价格位置：极度高估（按主业价值）。现价 9.05 元对应 PB 5.58x、市值 60.1 亿，而公司净资产仅 10.78 亿、正常化净利约 0.35 亿、扣非仍亏损。现价完全脱离基本面，是"壳 + 资产注入预期"的纯博弈定价。

安全边际：
- 中性远期目标价 1.81 元 → 空间 −80.0%（巨大负空间）
- 悲观 1.20 元 → −86.7%；乐观（不含注入）2.41 元 → −73.4%
- 无论哪种情景，现价均大幅高估；唯一支撑是"未验证的注入预期"

介入条件（具体价格/信号）：
1. 现价坚决不参与。即便博弈注入，也需等实质资产注入公告落地后方可评估重估空间
2. 重新评估信号：① 众凌科技等半导体资产注入正式方案/证监会受理；② 明确新实控人 + 治理稳定；③ EPC 业务放量、扣非转正
3. 证伪信号：长期无注入进展、EPC 萎缩、无实控人持续、现金被低效消耗

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 注入预期落空：多次易主（4 次）、无实控人，资产注入始终无正式方案，60 亿市值的核心假设可能长期不兑现
2. 壳价值耗散：若注册制下壳价值持续走低 + 监管趋严，估值中枢下移
3. 扣非持续亏损：主营（光伏发电 + EPC）体量太小，无法支撑独立上市公司的盈利规模
4. 治理失序：无控股股东/实控人，公司战略与经营稳定性存重大不确定性

上行想象力情景（不计入中性锚）：
- 类型A 行业出清剩者红利：不适用（公司已退出光伏制造，无"剩者"逻辑）。
- 类型B 政策反转期权：若并购重组/壳资源政策边际放松，注入通道打开——验证点：重组新规发文。
- 类型C 市场错杀修复：不适用（现价非错杀，而是高估，无"错杀证据"）。
- 类型D 技术代际跃迁期权：众凌科技（精密金属掩膜版，OLED 核心耗材）若注入，属"先进智造"全新曲线——硬验证点：注入方案落地 + 标的盈利/订单验证；三者未达成前仅作机会情景，不计入中性锚。

上调至"重点关注"的条件：仅在资产注入正式落地且标的资产盈利可验证、实控人稳定后，才重新评估；在此之前，现价无任何基本面安全边际。

结论：暂不介入（远期空间 −80%，严重透支壳 + 注入预期，扣非仍亏损）
