第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（转嫁系数）
- 理论传导率：行业 2026 年 1 月出厂价格指数 65.5% vs 购进价格指数 85.5% → 净传导缺口 20pct，行业层面传导率约 0.6–0.7，但涨价潮结束后不可持续（佳木斯防爆电机研究所明确判断"涨价策略恐难以持续"）。
- 公司实测：Q1 毛利率 29.14%（同比 +6.01pct，靠产品结构优化而非提价）→ Q2 毛利率 22.46%（环比 −6.68pct）。说明提价传导在 Q2 已基本失效。
- 公司已"初步建立战略供应商库"，估计年度锁价比例约 30–40%。
- 综合传导率取 0.45：上游原料涨 10%，公司实际毛利承压 5.5%。
- 验证点：逐季毛利率是否守住 22%；公司是否发布提价公告。证伪信号：单季毛利率跌破 20% 且营收继续同比下滑。

因子3 库存与采购节奏（timing）
- 存货周转率仅 0.43 次（2026H1）、1.98 次（2025 全年）→ 订单式生产，存货以原材料+在产为主，周转慢。
- 在原料单边上涨期，慢周转 = 被动"高价接货"（前期低价订单还在生产，当期采购已是高价）。
- 无套期保值披露。公司已"启动存货与应收账款专项清理工作，对长账龄款项和呆滞库存进行排查梳理"。
- H1 计提信用减值和资产减值合计 623.82 万元（减少利润总额 623.82 万），接近 H1 归母净利（470.15 万）的 1.33 倍——减值对利润的侵蚀非常显著。
- 结论：H1 不存在"低价囤货推高毛利"的水分，反而是高价接货 + 减值双压，真实经营质量比账面更难看。

第四步：估值锚定（自下而上，非增速外推）

方法说明：本股当期净利已塌陷至盈亏平衡（TTM 归母 37.56 万元），PE 11504x 无意义，禁止使用当前 PE；同时禁止用 2023 年（归母 4320.70 万）/2022 年（5158.68 万）的好年景外推。采用 正常化净利润法：估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价。

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

  • 校正1 资产质量折扣：PB 6.59x，远高于 1，不破净，反向触发"高估"警示。资产结构本身是干净的——2026H1 总资产 11.23 亿、归母净资产 6.56 亿、资产负债率 41.56%、有息负债仅 251.8 万元（几乎零杠杆）、速动比率 1.67、现金比率 61.33%、经营现金流 +6898 万（同比 +458.54%）。即：资产质量无瑕疵，问题 100% 出在价格而非资产。
  • 校正2 周期位置校正：电机属弱周期，但当前处于 "原料成本上行 + 传统工业需求疲弱"的底部区域（电气机械和器材制造业 H1 利润 −8.6%）。中性净利已用正常化法（近 5 年中值 + 行业均值 + 历史最好三者取保守），规避了"用 2022/2023 好年景外推"与"用 2026Q1 单季 +7.21% 拐点年化"两种常见错误。
  • 校正3 杠杆下行情景：资产负债率 41.56% < 60% 阈值，有息负债几乎为零 → 不触发强制负面情景。财务安全性极高（这是本股唯一的确定性优点）：零有息负债 + 6.56 亿净资产 + 正经营现金流，不存在"倒在黎明前"的生存风险。因此即使中性空间 −80.6%，也不判"坚决回避"。
  • 期权纪律（关键）：资源双主业（北京高地资源、中德银泰、中科电能源/中科聚能）未过任何验证点——无公告、无标的、无金额、无决议，仅管理层口头表述"前期考察和可行性研究"，严格不计入中性 NAV/中性净利，只放在乐观情景。

准亏损从严：正常化净利润法 + 盈利塌陷三问

本报告对本股按「盈利塌陷 + 类亏损」从严处理（当期 TTM 归母仅 37.56 万元，已实质处于盈亏平衡线，PE 11504x 无意义），故按亏损股纪律完整回答三问：

1）为什么亏（利润为什么塌陷到盈亏平衡线）？
- 减值是直接主因（可量化）：2026H1 计提信用减值与资产减值合计 623.82 万元，达到 H1 归母净利（470.15 万）的 1.33 倍 —— 当期利润几乎被减值吃光；
- 需求端：营收 −17.95%，传统工业电机下游（冶金、起重、风机水泵）资本开支疲弱，电气机械和器材制造业 H1 利润 −8.6%；
- 成本端：Q2 单季毛利率环比 −6.68pct 至 22.46%，硅钢 / 铜 / 铝涨价未能完全转嫁（传导率不足，见第二步进阶因子1）。
→ 定性：属「减值 + 需求疲弱 + 原料挤压」三重叠加的周期性塌陷，既非一次性会计事故，也非主业永久性毁灭——故可做正常化，但仍需从严。

2）靠什么扭亏（恢复）？触发时点在哪一年？
- 靠减值出清后的主业恢复：2025 年已充分计提，2027 年起减值基数消失，营收恢复至 6.8 亿 × 正常化净利率 4.0% 即可回到 0.27–0.30 亿量级；
- 靠产品结构升级：高效电机 / 永磁直驱 / 防爆电机替代传统异步电机，受电机能效强制标准与《电机能效提升计划（2025—2027）》驱动；
- 触发时点（中性）：2027H2–2028 看到营收同比转正且毛利率回升至 26% 以上。
- 期权纪律：市场定价的"资源转型"预期无任何正式公告，不计入中性锚，仅入乐观 / 机会情景。

3）亏得起吗（能否撑到恢复那天）？
- 完全亏得起，无生存风险：2026H1 资产负债率仅 41.56%、有息负债 251.8 万元（近乎零杠杆）、速动比率 1.67、现金比率 61.33%、经营现金流 +6898 万（同比 +458.54%）、归母净资产 6.56 亿。
- 即便在"利润归零"的最差状态下，公司也无任何偿债压力，不存在"倒在黎明前"风险。
→ 结论：资产端与现金流端是安全的，问题 100% 出在价格（PB 6.59x、正常化 PE 约 174x），而非经营存续。

第五步：综合赔率判断（买不买？）

当前价格位置：极度偏高。现价 18.37 元对应 PB 6.59x（每股净资产仅 2.79 元）、正常化 PE 约 174x（0.30 亿稳态净利）。市场定价的不是电机业务，而是"资源转型 + 小盘壳"预期。

安全边际：
- 远期中性 3.57 元 → 空间 −80.6%
- 悲观 1.12 元 → 下行 −93.9%
- 乐观 22.11 元 → 上行 +20.4%（且需资源资产并表净利达 1.7 亿/年，属极小概率）
- 唯一的下行保护：零有息负债 + 6.56 亿净资产 + 正现金流 + 连续分红（上市累计派现 5.55 亿，派现募资比 186.43%）→ 公司不会倒闭，但股价可以跌很多

介入条件：
1. 基本面介入价：3.5 元以下（对应正常化 PE 28x 附近）。现价距此有 80% 下跌空间，不具备任何基本面意义上的介入价值
2. 若坚持博弈资源转型，必须等硬信号：① 董事会正式决议公告；② 明确的标的名称 + 交易金额 + 股权比例；③ 标的的资源储量/品位/盈利数据（第三方报告）；④ 若构成重大资产重组，需交易所问询函回复披露
3. 在硬信号出现之前，任何买入都是对"管理层一句话"定价

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 资源转型证伪（首要）：管理层仅表述为"前期考察和可行性研究""后续如有相关事项将严格履行审议程序及信息披露义务"——这是标准的不承诺表述。若 2027 年底前无实质动作，34.8 亿期权溢价将快速蒸发
2. 主业持续塌陷：Q2 单季归母 20.02 万，若 H2 转亏（2025Q4 曾单季亏 857.01 万），全年归母可能归零甚至转负
3. 原料成本失控：行业"高进低出"格局延续，2026 年前两月电机行业因原料失控的订单违约率升至 4.5%（2018 年以来新高）
4. 减值风险：H1 已计提 623.82 万，应收与存货规模行业性上升，后续仍有计提空间
5. 高估值下的流动性风险：市值 43.21 亿但真实盈利仅百万级，一旦风格切换，回撤幅度没有基本面支撑位

结论：暂不介入

理由：① 基本面价值 8.4 亿 vs 市值 43.21 亿，80.5% 的市值是无公告支撑的资源转型期权，中性远期空间 −80.6%，远不满足"重点关注"（>+50%）或"纳入观察"（>0）的正空间门槛；② 主业 Q2 单季归母仅 20.02 万，已实质盈亏平衡，无任何可量化的新增产能或在手订单；③ 但公司资产干净、零有息负债、持续分红、不存在生存风险，不符合"确无扭亏可能/纯概念炒作"的"坚决回避"标准（电机是真实业务，6.56 亿净资产、800 名员工、4000MW 产能、H1 经营现金流 +6898 万）。
定位：这是一只"资产无瑕疵、价格有泡沫"的转型预期股。正确的做法是放在观察池最末端，等资源项目的正式公告，用公告里的数字重新定价，而不是为管理层的一句"前期考察"支付 34.8 亿。
