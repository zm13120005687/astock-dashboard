核心业务与产品：
- 功率半导体（吉莱微）：晶闸管、保护器件芯片，拟重点开发高性能 ESD 保护器件、MOSFET 器件；车规级产品已进入头部客户供应链（公司口径："契合国产替代方向"）。
- 芯片设计（神州龙芯）：自主 CPU 芯片设计（2026-09-07 因"CPU 概念"异动直线涨停，公司被归为 CPU 概念标的）。
- 太阳能电站 / 环保设备：存量运营与设备制造。
- 股权投资：公司三大核心业务之一，但 2026H1 收入占比不足 10%。

并购吉莱微（关键事件）：2025 年公司以现金增资 2.2 亿元取得江苏吉莱微电子 45.2807% 股份，并由原实控人之一李大威将 828.71 万股表决权委托给综艺股份，合计控制表决权超 50%，吉莱微成为控股子公司。评估基准日 2025-03-31：吉莱微经审计净资产 2.2265 亿元，评估值 2.6715 亿元（增值率 19.99%），采用资产基础法结论；吉莱微 2024 年营业收入 2.5618 亿元、资产总额 6.4423 亿元。

业绩承诺（重要）：标的公司 2025 / 2026 / 2027 / 2028 年承诺净利 2,600 / 3,300 / 4,100 / 5,000 万元（累计不低于 1.5 亿元）；若累计实际净利未达承诺 80%（1.2 亿元），业绩承诺方须一次性补偿（补偿上限 1.704 亿元）。2025 年度承诺实现情况的专项核查意见已由独立财务顾问（兴业证券）出具，具体实现数请以公司公告为准。

股东结构风险点：截至 2026-08-14，股权质押总比例 17.18%（2.23 亿股，12 笔）；2026-07-09 至 08-23 期间，股东海安瑞海城镇化投资建设有限公司减持 250 万股。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性：功率半导体处于涨价周期，传导率 > 1（产品销售价上涨快于上游材料涨价，行业整体扩利）。但吉莱微的产品结构中保护器件/晶闸管占比高，此类产品价格弹性弱于 IGBT/MOSFET，且公司未披露分产品毛利率与提价公告。验证点：公司季度毛利率变化、是否有提价公告；证伪信号：行业涨价而公司毛利率未改善（说明产品结构与客户议价弱）。

因子2 毛利结构再平衡：三条业务线毛利率差异显著——半导体 IDM（重资产、毛利率中等但弹性大）、太阳能电站（稳定但微利运营）、环保设备及材料（制造业，毛利率中等）。2026H1 半导体收入占比从不足 30% 跃升至 59.18%，利润结构已从"投资 + 电站"切换为"半导体制造"。结论：不能用历史综合毛利率外推——2026 年起的毛利率须以半导体业务为主导重建，而公司尚未披露半导体分部毛利率，这是估值的主要不确定源。

因子3 库存与采购节奏：功率半导体涨价周期中，低价晶圆/成品库存会形成库存收益（当期毛利率虚高）；同时应收账款 +39.04% 反映渠道扩张期的信用放宽。结论：须警惕"涨价周期 + 并表整合"叠加带来的当期利润虚高，远期毛利率应取涨价周期消退后的稳态值。 验证点：存货规模与周转、应收账款账龄；证伪信号：存货激增而周转下降。

因子4 政策/市场锚点（成本/需求驱动变量）：①车规认证补贴（广州市 30% 认证费用补助，上限 200 万元/年）——直接降低认证成本、加速车规产品导入；②工信部汽车芯片标准（2026-05）——标准落地利于国产车规芯片放量；③充电桩三年倍增（2027 年底 2,800 万个）——MOSFET/IGBT/SiC 增量需求；④行业涨价周期（延续至 2027 年）——直接影响毛利率；⑤AI 数据中心电源——功率器件新增量场景。验证点：吉莱微车规产品定点/出货公告、公司季度毛利率；证伪信号：2027 年后产能集中释放导致涨价周期提前结束（行业已提示该风险）。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务：市场容量 × 份额变量
- 供给侧份额：吉莱微为晶闸管/保护器件细分中小厂商，在功率半导体总量中份额极小（对比士兰微全球 3.3%、比亚迪 3.1%）；份额提升空间存在但依赖于产品升级（ESD 保护器件、MOSFET）。
- 需求侧/客户份额：车规级产品已进入头部客户供应链（公司口径），但未披露客户名称与供货规模；功率器件认证周期 12–24 个月 = 粘性强。
- 技术代际差：处于追赶位——主流车规 IGBT/SiC 由头部厂商主导，吉莱微以晶闸管、保护器件为主，技术代际落后于第一梯队；拟开发的 ESD/MOSFET 属中端切入。
- 成本曲线位置：IDM 重资产模式，规模小 → 单位成本高于头部；但 2026 年行业涨价周期提供以价换量的窗口。
- 份额二阶导数：加速渗透中但基数低——半导体板块营收 +260% 说明份额/收入在快速提升，但该增速主要来自并表口径变化（吉莱微 2025-09 才并表），并非同口径份额跃升，须扣除并表因素后重估。
- 三档验证点：保守（吉莱微完成承诺下限）/ 中性（完成 2026 年 3,300 万承诺）/ 乐观（ESD/MOSFET 放量超承诺）。

层2 扩展业务：主业迁移空间（新易盛范式）
1. 能力可迁移性：中——晶闸管/保护器件的 IDM 制造能力（晶圆制造 + 封装）可向 ESD/MOSFET 延伸，技术同源；但向车规 IGBT/SiC 升级需大额资本开支与长时间验证。
2. 新 TAM 弹性：大——中国功率半导体 2,080 亿元市场、碳化硅/氮化镓为高速增量。
3. 切入时点与卡位：中——功率半导体已进入涨价周期与国产替代加速期，但公司体量小、切入偏晚。
4. 客户认证门槛：高（车规认证 12–24 个月，公司已"进入头部客户供应链"，属初步卡位）。
5. 信号验证：部分已过验证点（并表已落地、车规客户已进入）→ 可计入中性；未过验证点的部分（ESD/MOSFET 车规放量、剩余股权收购、神州龙芯 CPU）→ 不计入中性。

层3 风险折扣：证伪信号
① 吉莱微 2026 年净利未达承诺（触发补偿条款）；② 行业涨价周期于 2027 年后因产能集中释放提前结束；③ 应收账款持续高增、回款恶化；④ 股权质押（17.18%）触发平仓；⑤ 神州龙芯等期权长期无收入落地。命中则下调增量与毛利率假设。

方法说明：不使用"历史增速外推"。按半导体（吉莱微 IDM + 芯片设计）/ 太阳能电站 / 环保设备及材料 / 股权投资四条线测算，半导体业务以业绩承诺 + 在手订单 + 车规认证进度为基准，并扣除并表口径的一次性放大效应。总股本：13.00 亿股。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 2.15x > 1，不属破净。但须说明 PB 2.15x 的成色：公司资产以太阳能电站（重资产、回报率低）、吉莱微少数股权（45.28%，账面按成本法/权益法）、股权投资为主——吉莱微净资产仅 2.2265 亿元（评估 2.6715 亿元），公司权益对应约 1.21 亿元，而市场为其支付数十亿元市值溢价。"半导体平台"的估值绝大部分是商誉式预期，而非账面净资产支撑。 验证点：吉莱微实际净利与承诺的偏离度；证伪信号：业绩承诺触发补偿。
  • 校正2 周期位置校正：本股受功率半导体涨价周期驱动，当前处于涨价周期中段（机构预判延续至 2027 年）。中性净利不得采用 2026H1（含并表放大 + 涨价周期 + 库存收益）年化——本报告已显式将 2029E 中性净利下调至 0.82 亿元（低于 2026E 的 1.10 亿元），反映"涨价周期消退 + 无一次性并表放大"的稳态，并明确标注当前处于功率半导体涨价周期偏中后段位置。
  • 校正3 杠杆下行情景：资产负债率与有息负债未在公开摘要中完整披露（构成主要不确定源）；但股权质押 17.18%（2.23 亿股）是明确的杠杆信号。负面情景：若股价大幅下跌触及质押平仓线，或行业涨价周期提前结束 → 2029E 净利降至 1.00 亿元，目标价 1.92 元（−65.9%），已列悲观情景。
  • 期权纪律：剩余股权收购（2029 后）、神州龙芯 CPU 放量、股权投资变现——均未过验证点，不得计入中性净利/NAV，仅置于乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：明显高估。PE(TTM) 53.67x、中性 2029E PE 达 89x；现价 5.63 元高于基准目标价 3.38 元（+66.6%）。

安全边际：
- 中性远期 2.52 元 → 空间 −55.2%，基本面安全边际为负
- 悲观 1.92 元 → 下行 −65.9%
- 乐观 7.62 元 → +35.3%（需吉莱微大幅超承诺 + 剩余股权并表 + CPU 概念落地）
- 下行保护：PB 2.15x（但成色依赖吉莱微预期）、经营现金流 +3,849 万（+901.19%）改善明显、吉莱微业绩承诺含补偿条款（1.704 亿元上限兜底）

介入条件：
1. 不参与。现价 5.63 元较中性合理价 2.52 元溢价 123%，除非股价回落至 3.0 元以下（接近基准 2026E 40x PE）方具基本面支撑
2. 事件驱动信号（可择机博弈，但须严格控仓）：① 吉莱微车规 ESD/MOSFET 大额订单/定点公告；② 公司启动剩余股权收购；③ 神州龙芯出现实质收入/合作落地
3. 观察指标：吉莱微季度净利 vs 业绩承诺、应收账款账龄、股权质押比例变化、行业涨价周期

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 估值完全脱离业绩承诺口径（首要）：按承诺测算，吉莱微 2029E 权益净利仅约 2,264 万元，而当前市值为其支付数十亿元溢价——一旦市场回归业绩承诺定价，回撤空间超 50%
2. 业绩承诺不达标：吉莱微 2024 年营收仅 2.56 亿元、2025 上半年营收同比 −3.32%~+5.08%（增速平淡），而承诺净利增速要求 2025 年 +76.32%——承诺与历史基础存在落差，触发补偿（报告书已提示"业绩承诺无法实现的风险"）
3. 并表口径放大被误读为内生增长：半导体板块 +260% 中含并表因素，同口径增速需扣除
4. 应收账款 +39.04% 快于收入：回款质量恶化风险
5. 股权质押 17.18% + 股东减持：治理与筹码风险
6. 概念化定价：2026-09-07 因"CPU 概念"（GPT-6 Astra 模型驱动 CPU 需求）直线涨停——属概念驱动，与公司实际业绩无直接关系

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：功率半导体行业国产替代加速（中国厂商全球市占首破 25%，车规 IGBT 自给率 >35%），国际巨头份额持续下滑（英飞凌 −2.9pct）——吉莱微作为国内 IDM 可分享"进口替代"红利。验证点：吉莱微车规产品出货量、国产替代订单；弹性：已部分含于中性。
  • 类型B 政策反转期权：车规认证补贴（广州 30%，上限 200 万元/年）+ 工信部汽车芯片标准——降低认证成本、加速车规产品导入。验证点：公司获 AEC-Q 认证公告；重估弹性：车规产品毛利率高于工业/消费级，可推升整体毛利率。已部分含于中性。
  • 类型C 市场错杀修复：不适用——本股属"概念错涨"而非"错杀"（2026-09-07 CPU 概念涨停），无修复空间。
  • 类型D 技术突破/技术代际跃迁期权：① 吉莱微 ESD 保护器件/MOSFET 车规放量——三要素中"政策驱动"（汽车芯片标准 + 认证补贴）与"行业趋势"（车规功率半导体全球 481 亿元 → 2032 年 1,681.6 亿元）已现，公司"投产落地"部分过验证点（车规产品已进入头部客户供应链），但无量级数据。硬验证点：车规大额定点公告 + 该品类收入占比跳升 + 良率达标。② 神州龙芯自主 CPU 受益 AI 智能体——硬验证点：大额订单/收入落地；证伪信号：龙芯生态持续亏损（参考龙芯中科 2026H1 归母 −2.24 亿元，行业生态仍未盈利）。两者均只作机会情景，不计入中性。

什么条件出现才上调至"重点关注"：① 吉莱微连续两期净利超承诺且车规产品收入占比跳升且② 公司启动剩余股权收购并披露定价且③ 股价回落至 4 元以下——三者同时满足，方由"暂不介入"上调。

结论：暂不介入

逻辑：公司通过并购吉莱微成功切入功率半导体 IDM，2026H1 半导体收入占比跃升至 59.18%、营收 +55.18%、归母 +136.92%、经营现金流 +901.19%，方向正确且行业景气（国产替代 + 涨价周期 + 车规补贴）。但估值已严重脱离业绩承诺口径——按吉莱微 2028 年承诺净利 5,000 万元测算，公司权益贡献仅约 2,264 万元，而当前 73.19 亿市值为其支付数十亿元溢价；本报告中性 2029E 归母 0.82 亿元对应 PE 89x，现价较中性合理价高估 123%。叠加业绩承诺与历史基础存在落差、应收账款 +39.04%、股权质押 17.18%、概念化定价等风险，风险收益严重不对称，不参与。
核心跟踪点：① 吉莱微季度净利 vs 业绩承诺；② 车规 ESD/MOSFET 订单；③ 剩余股权收购进展；④ 股权质押与减持。
