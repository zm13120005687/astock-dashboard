久祺股份（300994）五步法分析报告

分析日期：2026-09-19 ｜ 现价 10.90 元（2026-09-18 收盘）｜ 总市值 约 25.8 亿 ｜ PE(TTM) 约 17.4x（按 2025 全年） ｜ PB(LF) 约 2.33x ｜ 总股本 约 2.37 亿股 ｜ 行业：自行车 / 电助力车出口（ODM 为主）｜ 板块：创业板
盈利股：2026H1 归母净利润 2366.78 万元（虽同比 −72.83% 腰斩，仍为正），按盈利股自下而上估值；但盈利质量因汇兑与爬坡显著恶化，须保守。

第一步：公司是干什么的？

一句话定位：杭州民营自行车整车出口龙头，以 ODM 为主、OBM 为辅，产品涵盖传统自行车、电助力车（e-bike）、山地车、童车等，销往全球 80+ 国家，境外收入占比超 98%。

（3）产业链传导

上游：钢材、铝材、轮胎、电池（e-bike 锂电 + BMS）、电子元件。电池与金属占成本大头，随大宗 / 锂电价格波動。

下游：海外分销商 / 电商 / 终端消费者。下游分散、品牌渠道为王，公司对海外大客户有一定粘性但无强定价权，议价权中等偏弱（OEM/ODM 属性）。

议价权：中等偏弱。出口代工模式，客户集中海外，受贸易政策与客户压价双重影响；电助力车自研 BMS 提升部分附加值。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：钢铝 / 锂电涨价时传导率约 0.4–0.6（代工模式难全额转嫁），因海外客户强势；2026H1 毛利率仅微升，转嫁能力有限。
  • 因子2 毛利结构再平衡：儿童自行车毛利 22.72%（最高）、成人 13.5%、配件 11.5%、e-bike 12.23%；e-bike 高增速但毛利偏低，结构向低毛迁移部分抵消量增，加权毛利率仅 14%。
  • 因子3 库存与采购节奏（timing）：锂电 / 金属低位囤货可获库存收益；天津基地投产初期效率爬坡，timing 与爬坡成本叠加影响当期。
  • 因子4 政策 / 市场锚点：钢铝 / 锂价（市场层）、欧盟反倾销税 + 美关税（政策层，核心逆风）、人民币汇率（市场层，2026H1 汇兑损失 2704 万为显性锚点）。情景：人民币贬值→利润增厚；关税升级→成本升。验证点：LME 金属、欧盟税率公告、美元兑人民币。证伪：原料暴涨 + 汇率持续不利 + 关税升级。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：全球自行车产能中国主导，公司份额中等，天津扩产提升供给能力。
  • 需求侧：80+ 国客户分散，e-bike 客户认证粘性中高。
  • 技术代际：自研 BMS 使 e-bike 处国内中上代，领先纯代工厂。
  • 成本曲线：天津自产使成本曲线左移，可降价扩份额。
  • 份额加速度：e-bike 欧洲渗透早期，份额可加速。
  • 三档：保守（营收 30 亿）/ 中性（33 亿）/ 乐观（38 亿 + e-bike 放量）。验证点：季度 e-bike 营收、天津产量。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：从"传统自行车 ODM"迁移至"电助力车 + 智能化（BMS/GPS）"——技术同源（整车制造）、新 TAM 弹性大（e-bike 全球高景气）、切入早（欧洲渗透期），但认证与贸易壁垒是阻力，未完全放量前仅作渐进增量，不计入中性爆发性。
  • 层3 风险折扣（证伪信号）：欧盟反倾销加码、e-bike 增速回落、天津爬坡不及预期 → 下调增量。

第四步：估值锚定（自下而上，非增速外推）

盈利股方法：分业务 / 产能自下而上测算，结合毛利率与费用趋势，严禁历史增速外推（尤其不能用 2025 年 1.48 亿净利外推）。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（破净原因）：PB=2.33（未破净），但资产负债率 ~48.8%、有息负债 1.89 亿（同比 +142.6%，项目借款增加），资产含较大有息负债，净资产质量打折。
  • 校正2 周期位置校正：自行车出口属外贸弱周期 + 汇率周期，当前受汇兑逆风（2026H1 损失 2704 万）与天津爬坡双重压制，中性净利已按"汇兑中性 + 爬坡完成"保守测算，未外推 2025 年 4.4% 净利率高点。
  • 校正3 杠杆下行情景（高负债 + 汇率必附）：资产负债率 ~49%、有息负债快速增长，叠加汇兑损益高度敏感（单季可 ±2700 万）。若美元贬值 + 反倾销加码 + 需求下行，净利可骤降至 0.66 亿甚至转负，悲观情景 3.6 元（−66.9%）即双杀结果——该负面情景使空间大幅转负，不得标"大空间 / 重点关注"，至多"暂不介入"且须注明高贝塔 + 汇率属性。
  • 期权纪律：e-bike 第三国产能规避反倾销、智能化（BMS/GPS）新品类未完全放量，不计入中性 NAV，仅放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：估值偏高（盈利腰斩 + 汇率敏感）。现价 10.90 元对应 2026E 深度 depressed PE ~50x、2029E 中性 PE ~21x，而盈利因汇兑与爬坡结构性承压，中性锚较现价低 22.9%。

安全边际：中性远期 8.4 元 → 空间 −22.9%；乐观 13.0 元（+19.3%）；悲观 3.6 元（−66.9%）。下行受净资产 11.07 亿（PB 底线 ~4.7 元/股）支撑，但汇率 + 杠杆放大下行。

介入条件：
1. 现价不介入。
2. 重新考虑的价格：回落至 8 元以下（接近中性锚、PB≈1.7），且需同步出现：① 汇兑由损转益；② 单季归母恢复至 2025 同期水平（季度 ~4000 万+）；③ e-bike 营收占比持续跳升。
3. 上调至"纳入观察"条件：盈利恢复至年化 1 亿+、汇率企稳。

最大风险（最可能破坏逻辑的因素）：
1. 汇率持续不利（2026H1 已验证汇兑损失 2704 万吞噬利润）；
2. 欧盟反倾销税加码 / 贸易壁垒（对欧出口成本与份额风险）；
3. 天津基地爬坡不及预期 + 费用刚性（管理费用 +15%）；
4. 高负债 + 项目借款（有息负债 +142%，利率上行压力）。

结论：暂不介入

公司有真实 e-bike 增长曲线（2026H1 +60%）与天津产能支撑，但2026 盈利腰斩为结构性（汇兑 + 爬坡）而非一次性，估值较正常化盈利偏高、汇率与贸易壁垒双敏感。遵循"估值已高 / 空间有限 / 不确定性大 → 暂不介入"。等待盈利恢复、汇率企稳且价格回归后再评估。

第五步进阶：上行想象力情景（四类，仅进机会栏，不进中性锚）

  • 类型A 行业出清剩者红利：中小自行车出口厂出清，龙头凭天津成本曲线 + 多区域份额提升。验证点：出口份额、天津产量；证伪：份额流失。
  • 类型B 政策反转期权：欧盟反倾销缓和 / 中美关税降级降低贸易成本，或国内促消费加码。验证点：税率公告、政策发文；证伪：壁垒升级。
  • 类型C 市场错杀修复：若因汇率风格杀跌至 PB≈1.5（~7 元）且基本面未恶化，估值分位极低。验证点：价格回落 + 汇兑回正；证伪：基本面恶化。
  • 类型D 技术突破 / 代际跃迁：自研 BMS + 智能电控（GPS / 防盗 / 电池监测）从 0 到 1 量产，e-bike 智能化重构附加值。硬验证点：BMS 量产成本优于外采 + 大客户定点；证伪：成本 / 良率不达标。

    上调至"重点关注"的条件：A/D 中"盈利年化恢复 1 亿+ + e-bike 营收占比破 25% + 汇率转有利"三项验证，且价格仍在 8 元以下——届时正常化净利与估值重估，空间可转正。
