第一步：公司是干什么的？

一句话定位：无锡国资旗下"装备制造 + 项目运营 + 工程服务"三位一体的环保能源平台——以锅炉装备制造起家，已转型为"地方热电联产 + 垃圾焚烧发电运营"为主的现金牛公司，正在培育氢能电解槽等第二增长曲线。

（3）产业链传导（四因子）——以燃料成本与钢材为核心变量

因子 1｜成本传导弹性（pass-through）——热电运营有联动、装备靠订单
- 热电运营（收入占比约 52%）：燃料（天然气约 1.1GW、燃煤 180MW）是最大成本项。天然气热电受气价与热价联动机制约束，传导有联动但滞后；无锡热网垄断 + 供热需求刚性使公司在煤热/气热联动中有较强转嫁力（传导率约 0.7–0.8），且公司可在大热网内按"燃气与燃煤季节性价差"优化机组负荷分配（气煤切换调度）来平滑成本。
- 垃圾焚烧运营：燃料成本为零（垃圾是"负成本原料"），主要成本为折旧与人工，对上游原料不敏感，毛利结构最稳。
- 装备制造：钢材占锅炉成本约 50–60%，2026 年钢价温和，公司通过集中采购 + 智能制造压降成本（2026H1 装备毛利率 +2.40pct）；海外订单（菲律宾、赞比亚、科特迪瓦等）报价机制可覆盖钢价波动（传导率约 0.8），但执行期跨年有敞口。

因子 2｜毛利结构再平衡（分业务线敏感度）
- 三块业务毛利率梯度：运营（热电/垃圾，约 25–30% 且稳定）> 装备制造（15.5%）> 工程（随设计占比波动，2026H1 已回升至 24.8% 因高毛利勘察设计占比提升）。
- 公司 2026H1 毛利率 +2.75pct 的结构性含义：低毛利工程业务收缩（营收 −18.78% 主因电站工程 −85%、市政工程 −36%）、高毛利运营与装备占比被动抬升——"以价换质"的结构优化，而非经营性涨价。估值时应按"运营利润占比约七成"的公用属性给 PE，而非按工程公司估值。

因子 3｜库存与采购节奏（timing）
- 煤炭/天然气采购：公司煤炭采购渠道通畅、有稳定长协供应（年报表述），通过大热网调度实现燃煤/燃气机组的季节性经济切换——长协 + 调度双缓冲平滑燃料成本；
- 装备销售 2026H1 受出货与收款周期影响致 H1 经营现金流仅 0.10 亿（上年同期 2.8 亿），属交付节奏问题而非需求问题（在手订单 21.3 亿同比增加），下半年收款节奏是观察点。

因子 4｜政策/市场锚点（成本与收益的双向变量）
- 成本侧：天然气价格市场化改革（门站价浮动）与煤炭长协价（2026 年电煤长协履约）→ 验证点为燃气/燃煤采购均价环比；国际 LNG 价格 2026 年高位 → 1.1GW 燃气机组的燃料成本敏感性是运营毛利第一变量，情景 A（气价回落）→ 热电毛利修复，情景 B（气价继续上行）→ 联动机制滞后转嫁、毛利承压；
- 收益侧：绿证价格（2026 年电量绿证均价 5.84 元/个）、CCER 碳价（约 70 元/吨）、垃圾处理费与供热价格调整机制——垃圾焚烧厂"吨垃圾综合盈利"在新模型下可增厚 75 元/吨级。验证点：公司绿证/CCER 收入首次披露金额、垃圾处理费调价公告。

层 1：现有业务 = 市场容量 × 份额变量

五锚点评估（以锅炉装备与环保运营为对象）：
1. 供给侧份额：垃圾/固废焚烧炉细分龙头（国内累计出货领先），高效节能锅炉细分市占率高——存量赛道内公司已是头部，增量依赖市场扩容与海外；
2. 需求侧/客户份额：军信环保、伟明环保等头部垃圾运营商为核心客户（认证壁垒=复购粘性），海外近 40 国；在手订单 21.3 亿同比增加是客户份额稳固的直接证据；
3. 技术代际差：煤粉预热燃烧（火改）、1500Nm³/h 高压电解槽均达国际领先/国内最高水平——技术处于行业前沿代际；
4. 成本曲线位置：锅炉制造通过智能制造 + 集中采购持续左移（毛利率 +2.4pct）；热电运营管损 <5% 为行业最低；
5. 份额加速度：装备与运营均处渗透成熟期（S 曲线平台段），弹性有限、胜在稳定；加速度在海外（一带一路锅炉订单）与氢能（0→1）。

层 2：扩展业务 = 主业迁移空间（装备 → 氢能/绿醇，期权验证中）

按五点检验：①能力可迁移性——锅炉/压力容器制造能力与电解槽（压力容器类装备）同源，迁移成本低，已建成 500MW 产线；②新 TAM 弹性——绿氢电解槽与绿色甲醇（加压生物质气化）市场处于 0→1 阶段，远期空间数倍于锅炉存量市场；③切入卡位——公司在"高压碱性槽（3.2MPa）+ 大标方"差异化卡位，2026 年正值国内绿氢项目设备交付潮；④认证门槛——电解槽需示范项目验证（中能建松原已运行），门槛中等；⑤信号验证——产线投产 + 首批商用设备下线（硬证据），但尚未见批量销售订单金额披露。结论：氢能按"中期期权"处理，未过"批量订单"验证点前不计入中性净利，只放乐观档（火改订单同理）。

层 3：风险折扣（证伪信号）

  • 市政/电站工程继续萎缩超预期（政府投资持续放缓）→ 工程板块收入下修；
  • 天然气价格持续高位、热价联动滞后 → 热电运营毛利率跌破阈值；
  • 电解槽/火改 2027 年仍无批量订单公告 → 中期期权降级，估值溢价收缩；
  • 装备收款周期拉长（H1 现金流已示警）→ 应收账款减值风险上升。

产能校验：热电装机 1.3GW + 存量垃圾焚烧产能可支撑运营收入增长（无新建依赖）；装备 24 亿收入对应在手订单周转与海外新签，需年均新签 20 亿+ 维持——以在手 21.3 亿为基数合理，若海外订单断档则落入悲观档。一次性因素已剔除（2024 年约 3.2 亿非经常性收益不属常态）。

重资产/高负债校正（运营重资产 + 负债率 60.7% 必做）：
- 公司非"破净"情形（PB 1.39–1.71），但净资产中大量为运营项目专用资产（热网、焚烧炉、电站），清算价值低于账面——PB 不构成强安全垫；
- 高负债负面情景：有息负债 83.2 亿，若利率上行 100bp → 年利息增约 0.8 亿；叠加供热需求下行或气价超预期，悲观档净利（5.0 亿）即此情形——经营杠杆 + 财务杠杆双高下净利下行弹性大；
- 周期位置：工程业务（EPC）处下行收缩期、运营处成熟稳定期、装备处海外扩张期，三块周期错位平滑了整体波动，中性净利不依赖单一年景。

基准（2026E）

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（预期定价）。现价对应 2026E PE 约 23–24x、PB（归母口径）约 1.71x，高于热电/环保运营可比公司中枢（12–18x）。近期股价上行已计入氢能量产与毛利率改善的乐观叙事。

安全边际：
- 中性远期 11.04 元 → 空间 −28.5%
- 悲观情景 6.31 元 → −59.1%
- 乐观情景 17.03 元 → +10.4%（期权全部兑现也只有小正空间）
- 现金牛底：2025 年经营现金流 13.9 亿、热力回款率近 100%、供热区域垄断——公司质地优秀，但质地好 ≠ 现价有安全边际

介入条件：
1. 现价回落至 13.0 元以下（2026E PE < 20x、归母口径 PB < 1.45）才具备介入价值；12 元以下（PE < 19x）安全边际较足；
2. 上调至"重点关注"的条件：2029E 中性净利需 ≥10 亿才能提供 +50% 远期空间——这要求氢能电解槽（500MW 产线满产对应收入体量可观）+ 火电灵活性改造同时放量并贡献 3 亿级净利。触发信号：①公司披露单笔 ≥2 亿元电解槽或火改订单；②CCER/绿证收入在定期报告中单列且达 0.5 亿+/年；③海外锅炉在手订单突破 30 亿。三者出现前维持观察不追高；
3. 跟踪指标：H2 经营现金流转正幅度、锅炉在手订单环比、环保运营收入增速、气价与热价联动执行。

最大风险（最可能破坏逻辑的因素）：
1. 估值回摆（首要）：现价把氢能/火改期权大部分计入了价格，若 2026–2027 年期权未如期放量（无批量订单公告），23x 的估值溢价会向 16–18x 公用估值回归，仅估值收缩就有 20%+ 下行；
2. 天然气价格高企 + 热价联动滞后 → 1.1GW 燃气热电毛利持续受压；
3. 工程板块持续失血（政府投资放缓）→ 收入结构改善的边际递减；
4. H1 经营现金流骤降（0.10 亿）若延续至全年 → 装备收款与应收账款风险显性化。

上行想象力（仅进乐观栏，不进中性锚）——类型 D 技术突破/代际跃迁期权（氢能电解槽）：
- 三要素共振度：①政策驱动（"十五五"绿氢项目补贴、绿色甲醇示范）已具备；②行业趋势向高压大标方碱性槽收敛（公司 3.2MPa 为国内最高，处于成本曲线与技术代际领先位置）；③公司落地证据——500MW 产线投产、中能建松原项目稳定运行、1500Nm³/h 产品下线（中试与客户验证已过），但距"批量订单 + 量产成本显著跑赢旧路线"的硬验证点还差最后一步。叠加火电灵活性改造（煤粉预热燃烧技术）与 CCER/绿证对运营利润的增厚，乐观档 +10.4% 仍偏克制——一旦电解槽订单兑现，市场将按成长设备股而非公用股重估，届时存在估值体系切换的可能。
- 什么条件出现才上调至"重点关注"：出现单笔 2 亿级以上电解槽/火改订单 + 运营端 CCER/绿证收益落地披露，两条件驱动 2029E 中性净利上修至 9–10 亿，远期空间才能越过 +50% 门槛。

结论：暂不介入

逻辑：公司质地扎实（区域热电垄断 + 垃圾焚烧龙头 + 锅炉出海 + 氢能期权），但现价 146.7 亿市值对应 2026E PE 约 24x，已把氢能/CCER 等期权大部分计入价格；中性（2029E 净利 7.0 亿、15x）目标价 11.04 元，远期空间 −28.5%，乐观情景也仅 +10.4%——风险收益比不佳。等价格回落至 13 元下方，或电解槽批量订单/CCER 收益等硬验证点出现后再介入。
