（3）产业链传导 —— 原料成本→毛利结构四因子

因子1 成本传导弹性（pass-through）：
- 上游：中药材（三七、银杏叶等）。关键反常：中药材价格大幅下滑，本应利好毛利率，但公司毛利率反而崩塌 —— 因为高价库存 + 集采降价 = 传导率为负。
- 传导率测算：集采品种传导率 ≈ 0（政府定价，成本下降的好处全部让渡给终端，甚至因降价超成本降幅而转负）；中药材贸易传导率 ≈ 0（现货随行就市，高价库存只能亏本卖）；院外零售/口服独家品种传导率 ≈ 0.6~0.8（唯一有定价权的品类）。
- 这是本股最致命的结构问题：公司 90% 以上收入集中在传导率≈0 的品类，仅 10% 左右在传导率高的品类。

因子2 毛利结构再平衡（分业务线，禁单一综合毛利率）：

因子3 库存与采购节奏（timing）—— 本股的核心失血点：
- 高价囤货 → 库存损失：公司前期储备的中药材市场价格大幅下滑，2026H1 进行了销售 → 当期确认亏损（毛利率 −14.59%）。这是"高价接货损失"，不是真实盈利能力。
- 存货 12.94 亿，周转天数 842.58 天（较 2025 年末 +230 天），意味着高价库存尚未出清完毕，未来仍有跌价压力。
- 预付款 2.23 亿，前五名占 84%，主要为与金九药业的品种经销协议预付款 —— 会计师无法确认是否涉及控股股东资金占用，属"准损失"。
- 无长协/套保：中药材为公司贸易品种，未见套保安排。
- 一次性因素须剔除但规模巨大：2026H1 新增信用减值损失约 1.52 亿（应收账款约 23.2 亿），这是亏损 2.71 亿中的最大单项，但考虑到应收账款周转 1484 天，这并非"一次性"，而是持续性的资产质量恶化。

第四步进阶：重资产 / 高杠杆 / 破净三道校正闸

校正1 资产质量折扣（破净原因必须说明） —— 本股核心：
- 为什么破净：① 资产盈利能力差：ROE −19.33%（2025）、−4.41%（2026H1），净资产在持续缩水；② 资产专用性 + 减值风险：应收账款 23.2 亿（周转 1484 天）、存货 12.94 亿（周转 843 天）、鸡西三期在建（三次延期）—— 账面价值严重虚高；③ 隐含负债与治理风险：控股股东资金占用约 2.99 亿、3 亿募集资金无法归还、预付款 2.23 亿性质存疑。
- 不属于"金融资产未重估型真破净"：公司持有的主要是经营性资产 + 巨额应收/存货，无隐藏的上市股权或投资性房地产重估空间。
- 结论：PB 0.82x 是公允定价甚至仍偏高，不构成安全边际，禁止单凭 PB<1 推导"空间大"。

校正2 周期位置校正：
- 中药不属于强周期行业，但公司处于政策冲击的单向下行通道（非周期波动，是结构性萎缩）。
- 中性净利已用正常化净利率 9%（低于历史最好 16.14%、高于产能爬坡理论值 5%~7%），属合理保守。
- 禁止使用的三种做法在本股均已规避：未用 2024 年（好年景 4.38 亿）作基准、未用近三年均值（因 2023—2025 剧烈下行，均值无意义）、未把单季环比改善年化。

校正3 杠杆下行情景（必附）：
- 有息负债 31.18 亿（2025 年末），资产负债率约 41%，年化财务费用约 1.14 亿。
- 负面情景：经营亏损 + 财务费用刚性 → 净资产以每年 4~5 亿速度消耗；若银行抽贷或 3 亿募集资金违规坐实触发交叉违约，现金流可能断裂。

期权纪律：创新中药管线、鸡西三期投产、院外渠道爆发 —— 全部未过验证点，一律不计入中性净利。

交叉校验：现价 5.24 元 = 市值 49.27 亿，是正常化净利润法测算值（22.4 亿）的 2.2 倍、是调整后净资产（37.2 亿）的 1.32 倍。即便按最宽松的"净资产完全不减值 + PB 1.0x"，也仅对应 6.38 元。市场当前定价隐含了"应收账款全额回收 + 主业快速恢复"的双重乐观假设，与公开证据不符。

第五步：综合赔率判断（买不买？）

亏损股必答三问

① 为什么亏？
1. 中成药集采全覆盖 + 中药注射剂临床管控（外因，主因）：14 个品规中标但大幅降价，核心品种注射用血塞通、舒血宁注射液量价双降，营收从 27.07 亿（2024）→ 7.98 亿（2025）→ H1 年化 5.9 亿。
2. 中药材贸易亏本出货（主动去库存）：毛利率 −14.59%，收入 +58.53% 反而加速失血。
3. 信用减值损失：H1 新增约 1.52 亿，应收账款 23.2 亿、周转 1484 天 —— 这不是一次性，是持续性资产质量恶化。
4. 产能利用率极低 + 财务费用刚性：年化财务费用约 1.14 亿，营收腰斩后固定成本无法摊薄。
5. 不是财务费用拖累单一因素，也不是单纯行业周期底部 —— 是政策结构性冲击 + 资产质量恶化 + 治理缺陷三重叠加。

② 靠什么扭亏？触发时点在哪一年？
| 路径 | 可行性 | 时点 |
|---|---|---|
| 停止中药材贸易亏本出货 | 高（管理层已在做，存货出清后自然消失） | 2026H2—2027 |
| 三项费用继续压缩 | 中（H1 销售费用已 −58.94%，空间收窄） | 2026—2027 |
| 院外零售渠道放量 | 中低（"院外占比持续提升"但无绝对值披露） | 2028+ |
| 应收账款回收减少减值 | 低（周转 1484 天，会计师保留意见） | 不确定 |
| 创新中药/生物药管线 | 低（无关键数据披露） | 2029+ |
| 综合判断 | 单季扣非转正最早 2028 年，中性 2029 年；全年归母转正大概率在 2029—2030 年 | |

盈亏平衡点测算：年化固定成本（财务费用 1.14 亿 + 折旧摊销 + 刚性管理销售费用）约 4.5~5.0 亿；按 2026H1 综合毛利率 5.53% 计算，需要营收约 85 亿才能盈亏平衡（不可能）；若毛利率修复至 35%（接近行业正常水平），盈亏平衡营收约 13~14 亿 —— 即营收需从当前年化 5.9 亿恢复到 13~14 亿（+120%）才可能扭亏，这是极高的门槛，也解释了为什么中性只给 0.80 亿正常化净利。

③ 亏得起吗？
- 账面：归母净资产 59.95 亿、总资产 102.68 亿，短期不会倒。
- 现金流：H1 经营活动现金流 +1.03 亿（上年 −0.62 亿，+266%），有所改善。
- 但风险点密集：① 有息负债 31.18 亿；② 3 亿募集资金无法按期归还（明确信号）；③ 控股股东持股 96.53% 质押 且自身 H1 亏 6.42 亿 → 通过上市公司再融资/担保输血的通道基本关闭；④ 公司称正"通过出售闲置资产、银行贷款、股权融资筹措资金" → 说明现金已紧张。
- 结论："勉强亏得起，但融资能力已实质受损"。倒在黎明前的风险中等偏高（3~4 年维度内现金可支撑，但若应收账款继续计提 + 银行收缩授信则存在变数）。

当前价格位置：高估。市值 49.27 亿对应正常化净利（0.80 亿）的 PE 高达 62x；对应调整后净资产（37.2 亿）的 PB 为 1.32x，而该净资产仍存在治理性与减值性风险。

安全边际：
- 中性远期 3.60 元 → 空间 −31.3%
- 悲观 1.86 元 → 下行 −64.5%
- 乐观 5.80 元（需净资产零减值 + PB 1.0x）→ 上行 +10.7%
- 风险收益严重不对称：上行最多 +10.7%，下行可达 −64.5%

介入条件：
1. 现价不介入。需同时满足以下三条才考虑：① 应收账款回收率得到会计师认可（年报审计意见由保留改为标准无保留）；② 控股股东资金占用事项核查完毕且被证明无损失、质押率降至 50% 以下；③ 单季扣非净利润转正。
2. 若仅满足审计意见改善 + 资金占用澄清，观察价位 3.5~4.0 元（对应调整后净资产 PB 0.9~1.0x）。
3. 观察指标：季度应收账款周转天数、经营现金流、审计意见类型、控股股东质押比例、3 亿募集资金归还进展。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 应收账款坏账集中爆发（首要）：23.2 亿应收 + 6.3 亿其他应收，若一次性大额计提，净资产将再腰斩
2. ⚠️ 控股股东风险传导：96.53% 质押 + 自身 H1 亏 6.42 亿 + 资金占用 ~2.99 亿 + 会计师"暂无法判断" → 若被监管认定违规，可能触发 ST 或其他风险警示
3. 3 亿募集资金无法归还：已构成事实违约，可能引发监管处罚
4. 营收继续下滑：H1 −58.60%，尚无止跌迹象
5. 存货跌价：12.94 亿存货、周转 843 天，中药材价格若继续下跌将二次计提

类型A 行业调整剩者红利（机会情景）
- 逻辑：中成药集采"全覆盖"后，中小中药企业因无法承受降价而退出，14 个品规持续中标的公司反而可能获得份额集中红利。
- 弹性：若行业出清 30% 产能，公司工业收入有望在 2029 年回到 10 亿以上（而非中性的 6.5 亿），正常化净利升至 1.2~1.5 亿。
- 验证点：中成药集采后续批次中"弃标/流标"企业数量；行业中小药企注销/退出公告；公司工业收入环比转正。
- 证伪信号：集采继续降价且公司份额下滑；工业收入环比继续负增长。

类型B 政策反转期权（机会情景）
- 逻辑：① 中药注射剂若出现政策纠偏/重新评估（如真实世界研究证明安全性后放宽使用限制）；② 国家中医药扶持政策加码（院内中药使用比例考核）；③ 中药材收储/价格托底政策。
- 弹性：中药注射剂管控若放松，公司核心品种可恢复至 2024 年收入的 50%~60%。
- 验证点：国家中医药管理局/药监局的注射剂再评价政策文件；中药材战略收储公告。
- 证伪信号：管控进一步收紧（如部分品种退出医保）；中药注射剂被纳入限制使用目录。

类型C 市场错杀修复（机会情景）
- 逻辑：PB 0.82x 若因市场恐慌（而非基本面）超跌，存在修复弹性。
- 错杀证据检验：不成立 —— 破净有明确基本面原因（ROE −19.33%、应收/存货质量差、审计保留意见、治理缺陷），不属于错杀，属于合理定价。
- 结论：本类不适用，不计入。
- 证伪信号：若审计意见转为标准无保留 + 应收账款大幅回收 + 控股股东质押解除，则可重新评估为错杀。

- 硬验证点检验：① 中试/临床达标 —— 未披露（未通过）；② 客户定点/大额订单 —— 无（未通过）；③ 量产成本优于旧路线 —— 不适用（未通过）。

什么条件出现才把结论上调至"重点关注"：需同时满足 —— ① 年报审计意见由保留改为标准无保留；② 控股股东资金占用核查完毕且质押率降至 50% 以下；③ 单季扣非净利润转正且营收环比连续两个季度正增长；④ 应收账款周转天数降至 500 天以内。四者缺一，维持"暂不介入"；若第①②项反向恶化（被认定违规），则下调至"坚决回避"。

结论：暂不介入

理由：① 亏损属实且扩大（H1 −2.71 亿，同比 −246.12%），非 TTM 误标；② 扭亏门槛极高（需营收回至 13~14 亿，即 +120%）；③ 上行空间最多 +10.7%，下行可达 −64.5%，风险收益严重不对称；④ 中性远期空间 −31.3%。
未判"坚决回避"的理由：公司仍有实质业务（2.95 亿营收、102.68 亿总资产、59.95 亿净资产、经营现金流 +1.03 亿），存在扭亏路径（药材贸易止亏、院外转型、费用压缩、减值出清），未满足"主业持续萎缩 + 无在手订单 + 无新项目 + 现金流枯竭 + 无重组预期"的逐项举证标准。
但治理风险（资金占用、保留意见、96.53% 质押、3 亿募集资无法归还）是首要否决项，在审计意见改善与控股股东质押解除之前，任何价格都不构成买点。
