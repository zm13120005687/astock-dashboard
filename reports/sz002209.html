第一步：公司是干什么的？

一句话定位：国内液态包装（PET 瓶）整线设备龙头，为饮用水、饮料、日化企业提供"吹瓶 + 灌装 + 吹灌旋一体 + 后段智能包装 + 机器人"交钥匙方案，已进入可口可乐、百事、怡宝、东鹏供应链，加速国产替代与出海。

（3）产业链传导

上游：钢材、铜、钨等关键金属（2026H1 价格中枢抬升、宽幅震荡）、PET 原料。成本占比显著，公司已签长协锁价 + 金融避险。

下游：饮料企业资本开支（扩产 / 更新）。下游竞争加剧但扩产持续，国产替代 + 出海打开空间。境外毛利率（34.75%）远高于境内，是盈利改善主源。

议价权：中强。整线集成 + 客户认证（可口可乐等）粘性高；但外资头部向中高端渗透、价格竞争双线博弈，中端议价权中等。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：设备按项目投标定价，钢 / 铜 / 钨涨部分可通过报价转嫁但滞后，传导率 约 0.5–0.6；长协锁价对冲部分。H1 毛利率仍 +1.47pct 说明转嫁 + 结构优化有效。
  • 因子2 毛利结构再平衡：设备主业（31.06% 产品口径，高）vs 代加工（0.57%，低，占比升至 7.94% 形成拖累）vs 境外（34.75%，高）。结构优化（境外 + 高附加值一体机占比升）推升综合毛利。禁单一 28.66% 综合毛利率。
  • 因子3 库存与采购节奏：长协锁核心原料价，区分当期 vs 远期；发出商品 6.81 亿待验收确认，收入确认节奏影响季度波动（非库存收益）。
  • 因子4 政策 / 市场锚点：① 市场层——铜 / 钨 / 钢价；② 政策层——设备更新补贴、出海政策、汇率（扩大跨境人民币结算）。情景：若金属价格 +15% 且传导 0.55，实际毛利承压约 3–4pct；验证点：我的钢铁网、公司套保公告、汇率。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：国产液态包装设备集中度低，公司龙头；
  • 需求侧：绑定可口可乐 / 百事 / 怡宝 / 东鹏（强认证粘性）；
  • 技术代际：72000 瓶/小时一体机国际领先，领先一代；
  • 成本曲线：国产成本优势（vs 克朗斯）左侧；
  • 份额加速度：境外 +15%、国产替代加速。
    三档：保守（营收年增 8%）/ 中性（12–15%）/ 乐观（出海加速 18%+）。验证点：逐季境外收入、合同负债。
  • 层2 扩展业务：主业迁移空间：由"单机"向"整厂智能方案 + 工业机器人"迁移（能力可迁移——自动化同源），已自研蜘蛛手 / 码垛机器人；客户认证高但已切入，信号部分验证（机器人配套产线），可作中期期权，谨慎计入乐观。
  • 层3 风险折扣（证伪信号）：经营现金流持续背离净利、华东收入连降、出口地缘 / 汇率致境外毛利率破 30%。命中则下调。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非重资产（轻资产装备），PB 2.87x 合理（高 ROE 13.28% H1）；无破净。
  • 校正2 周期位置校正：设备资本开支处上行（设备更新 + 出海），中性净利已用订单法（非单年好年景、非拐点年化），标注：上行周期。
  • 校正3 杠杆下行情景：资产负债率偏高（2026Q1 77.19%，但有息负债率仅 13%，短借 + 长借增加为扩产），若利率上行 + 需求下行，悲观情景空间 −10.5%，未转负；但经营现金流 −40% 是核心观察点（若持续背离则下修）。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。现价 13.23 元对应 2026E PE 14.2x、2029E PE 8.9x；小盘高成长设备，远期空间充足。

安全边际：中性远期 21.62 元 → 空间 +63.4%（> 50% 重点关注门槛）；悲观 11.84 元 → 仅 −10.5%；乐观 30.81 元 → +132.9%。

介入条件：现价可布局；12 元以下（2026E PE < 12x）加仓更优。加仓信号：① 合同负债连续两季 > 12 亿；② 境外收入占比突破 50%；③ 机器人 / 无菌产线批量订单。

最大风险：① 经营现金流持续背离净利（存货 / 应收占用）；② 铜钨涨价 + 汇率波动（财务费 +1521%）；③ 华东收入连降、国内竞争加剧；④ 小盘游资博弈（机器人概念）致波动大。

结论：重点关注（远期中性空间 +63.4% > 50% 且逻辑明确：合同负债高 + 出海 + 国产替代 + 股权激励）。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：饮料设备国产替代加速，公司凭一体机技术抢克朗斯份额；验证点：国内份额跳升 + 头部客户扩产。
  • B 政策反转期权：设备更新专项加码 + 出海政策延续，订单放量；验证点：设备更新清单 + 出口订单；重估见乐观 +132.9%。
  • C 市场错杀修复：若因现金流担忧被杀至 11 元以下，修复弹性大；验证点：经营现金流转正 + 业绩证伪。
  • D 技术突破 / 代际跃迁期权：72000 瓶/小时无菌一体机、自研机器人从 0 到 1 规模化——硬验证点 = 中试良率达标 + 客户定点 + 量产成本优（一体机已国际领先、机器人已配套产线，部分接近验证）→ 若批量落地计入乐观增量。

维持 / 上调重点关注：合同负债突破 13 亿 + 境外占比 > 50% + 经营现金流转正，中性上修至 3.8 亿以上。
