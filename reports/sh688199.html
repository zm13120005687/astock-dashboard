久日新材（688199）五步法分析报告

分析日期：2026-09-21 ｜ 现价 25.37 元 ｜ 总市值 40.90 亿 ｜ PE(TTM) 约 47x ｜ PB 约 1.57x ｜ 总股本 约 1.61 亿股
行业：光引发剂 / 电子化学品（UV 光固化 + 半导体材料）｜ 板块：科创板
数据基准：2026 年半年度报告（2026-08-26 披露）+ 公开政策与行业资料。
扭亏复核：队列未标亏，经核实 2026H1 归母净利 +4341.45 万元（同比扭亏，上年同期 −905.73 万），按盈利股完整分析。

第一步：公司是干什么的？

一句话定位：全球产量最大的光引发剂生产供应商，国内光固化材料龙头，向上游中间体延伸降本，并向半导体光刻胶及配套材料（第二成长曲线）拓展。

结构看点：光引发剂占绝对主体但处于"供大于求、弱复苏"格局；酰基膦氧（TPO 替代）与光刻胶（半导体）是未来高毛利增量。

（3）产业链传导

上游：芳烃基础原料（苯 / 甲苯 / 二甲苯）、三苯基膦、均三甲苯、取代苯甲醛等，受原油波动与园区蒸汽 / 危废处置成本传导明显。2026H1 原油涨价 → 部分原料与产品价格同步上行（量价齐升但成本端承压）。公司向上游延伸（内蒙古羟基酮、弘润 H4 酮打通 184/1173 全产业链）对冲。

下游：UV 涂料 / 油墨 / 3D 打印 / 电子级（PCB、显示、半导体）。下游需求稳中偏弱（木器涂料低迷），但 PCB、新能源、电子级增量支撑。

议价权结论：上游弱、下游中等，整体中等。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：芳烃 / 三苯基膦等占成本比高，原油涨价时传导率约 0.5–0.6（部分随产品价格上调转嫁）。依据：2026H1 价格回升使毛利改善，但原料同步上涨压缩部分空间。
  • 因子2 毛利结构再平衡：光引发剂（占比 77%，毛利率约 20% 历史）为主，精细化学品 / 中间体（上游延伸，降本）占比提升；高毛利半导体光刻胶（占比小）为结构升级方向。单一综合毛利率掩盖了"上游一体化降本 + 高端品占比提升"的结构优化。
  • 因子3 库存与采购节奏：原油涨价期低价原料库存带来阶段性收益；公司向上游中间体延伸（羟基酮 / H4 酮）锁定成本，平滑采购 timing。
  • 因子4 政策 / 市场锚点（原料成本驱动变量）：① 市场层——原油 / 芳烃价格周期；② 政策层——出口管制（关键中间体）、环保督察（中小产能出清利好头部）、REACH（TPO 替代红利）、GB 30981（绿色壁垒）。情景：原油高位 → 成本与价格双高、毛利中性；原油回落 + 供给出清 → 毛利扩张。验证点：原油 / 苯系价格、公司季度毛利率、中小产能出清公告。

本因子输出喂给第四步毛利率假设：光引发剂中性毛利率 18–22%（上游一体化 + 结构优化），半导体材料 30%+。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：全球产量最大，第一梯队；扬帆火灾、沃凯珑失信加速份额集中；
  • 需求侧份额：全球客户认证体系完备；
  • 技术代际差：电子级 / 低迁移产品领先；
  • 成本曲线：上游一体化（羟基酮 / H4 酮）左移；
  • 份额加速度：中小产能出清 + 合规壁垒 → CR5 提升。
    → 三档：保守（份额守成）/ 中性（头部集中小幅提升）/ 乐观（出清加速 + TPO 替代红利）。
  • 层2 扩展业务：主业迁移空间（光引发剂 → 半导体光刻胶）：能力可迁移性中高（同属光化学合成）；新 TAM（半导体 PAG）弹性大；切入卡位早（已建光刻胶产线）；客户认证门槛高（未完全跨过，认证 2–3 年）；信号验证（产线已建、营收起步）。→ 中期期权，不计入中性，仅放乐观情景。
  • 层3 证伪信号：光引发剂再陷价格战 / 毛利率破 15% / TPO 替代不及预期 / 半导体认证失败。命中则下调。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣：公司非重资产、非破净（PB 约 1.57x，净资产 26.09 亿），不适用破净校正；资产质量健康。
  • 校正2 周期位置校正：光引发剂处弱复苏 / 供大于求格局（非周期顶、非深底）。中性净利采用周期归一化（正常年份净利率 8–10%，非 2026H1 异常高或历史亏损年），当前位置中性偏谨慎。
  • 校正3 杠杆下行情景：资产负债率适中（精细化工轻–中等资产），但若价格战重现、需求下行，悲观情景净利降至 1.0 亿、空间 −56.0%，已体现；不构成"大空间"误导。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高。现价 25.37 元对应 2026E PE 约 41x、PB 1.57x，已反映扭亏与复苏预期。

安全边际：
- 中性远期 26.06 元 → 空间 +2.7%，不达"重点关注" >50% 门槛
- 悲观 11.17 元 → 下行 −56.0%（价格战 / 需求下行）
- 乐观 46.52 元 → +83.3%（半导体材料放量 + 出清加速）
- 下行保护：PB 1.57x 提供一定账面支撑

介入条件：
1. 不追高。回落至 18 元以下（2026E PE < 28x）才具安全边际
2. 加仓信号：① 酰基膦氧 / H4 酮新产能效益超预期（毛利率连续 >22%）；② 半导体光刻胶获大客户认证 / 批量订单；③ 行业出清加速（中小产能退出公告）
3. 观察指标：逐季光引发剂价格、TPO 替代进度、半导体材料营收占比

最大风险：
1. 光引发剂再陷价格战（行业供大于求未根本解决）
2. 原油回落致前期涨价红利消退、库存收益转负
3. 半导体光刻胶认证周期长（2–3 年），第二曲线兑现慢
4. 上游新建产能（羟基酮 / H4 酮）爬坡不及预期

结论：纳入观察（扭亏 + 龙头份额集中 + TPO 替代与半导体第二曲线逻辑成立，但当前估值已反映复苏、中性空间仅 +2.7%，需等价格回落或新产能效益 / 半导体认证超预期兑现；属"逻辑正确但短期估值略高、需等拐点"）

注：若半导体材料放量 + 行业出清使 2029 净利向乐观 3.0 亿靠拢，则具备上调至"重点关注"条件。
