第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：智能装备项目制（长周期投标），原材料涨价多在签约后由自身消化，转嫁系数约 0.2–0.3；电驱零部件随行就市、议价系数约 0.3–0.4。加权实际毛利承压较大。
  • 因子2 毛利结构再平衡：智能装备毛利率约 16–17%（略高于电驱），电驱占比 37.6% 且价格战压制；若高毛利智能装备（储能 / 飞行汽车 / 北美项目）占比提升，可抬升综合毛利。分业务线：装备 16%+ vs 电驱 14% 左右。
  • 因子3 库存与采购节奏：项目制以销定产，无囤货收益；但原材料（钢材 / 磁材）采购时点影响单项目毛利，低价锁单可增厚。
  • 因子4 政策 / 市场锚点（原料成本驱动变量）：①钢材 / 铜价下行 → 装备与电驱毛利改善；②稀土磁材出口管制 / 价格 → 电驱成本端风险；③储能 / 飞行汽车补贴与招标 → 需求端增量。验证点：季度毛利率、原材料价格指数。证伪信号：综合毛利率跌破 14%、电驱价格战加剧。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：汽车智能装备 + 电驱市场大（新能源扩产 + 储能 + 飞行汽车），公司份额中等。
  • 需求侧：绑定特斯拉 / 大众 / 沃尔沃 + 国内主流车企，客户认证壁垒高（粘性）。
    3.技术代际：六合一 / 高压异步电驱处行业主流代，无显著代差。
  • 成本曲线：规模 + 数字化降本（AI 全流程成本管控）左移。
  • 份额加速度：国际客户突破带动份额提升，处于上升期。
    → 三档：保守营收 48 亿 / 中性 58 亿 / 乐观 65 亿（2029E）。
  • 层2 扩展业务：主业迁移空间：从"汽车装备"向"储能装备 + 飞行汽车工厂 + 具身智能装备"迁移，能力同源（智能制造集成）；新 TAM（低空经济 + 储能）弹性大。信号验证：北美储能 / 飞行汽车项目已获。部分已过验证点（已获项目），可计入中性偏乐观增量。
  • 层3 风险折扣（证伪信号）：国际项目交付延期 / 地缘风险、大众定点放量不及预期、飞行汽车量产推迟 → 下调。

第四步进阶：重资产 / 周期股校正（三道闸）

  • 校正1 资产质量折扣：PB 1.40x，非破净（净资产 24.22 亿为正），无破净伪空间问题；但固定资产重、应收高（周转慢），清算价值打折，不支持高 PB。
  • 校正2 周期位置校正：公司处新能源扩产上行周期，但盈利仍薄（净利率 2%），中性净利未用单年好年景外推，已用 2029 稳态 5% 净利率（保守），标注当前处"新能源扩产 + 出海突破"上行中段。
  • 校正3 杠杆下行情景（高负债必附）：资产负债率 69.96%，经营 + 财务杠杆双高。若利率上行或需求下行，净利可数倍回落——悲观情景（需求下行 + 国际延期）净利降至 1.2 亿、空间 −47%，故不得标大空间，至多"暂不介入 / 纳入观察"。

第五步：综合赔率判断（买不买？）

当前价格位置：估值已偏高。现价 24.74 元对应 2026E PE 约 33.9x、PB 1.40x，已隐含 2027 年成长；基准（2026E）合理价仅 13.1–16.0 元，现价高出 50% 以上。

安全边际：
- 中性远期 27.0 元 → 空间 +9.1%，未达"重点关注" >50% 门槛
- 悲观 13.1 元 → 下行 −47.1%（高负债下行弹性大）
- 乐观 45.2 元 → +82.7%（需多重催化共振）
- 下行保护弱：PB 1.40x、资产负债率 70%、应收账款周转慢，安全垫薄

介入条件：
1. 回落至 16 元以下（2026E PE <22x）具性价比
2. 加仓信号：大众六合一电驱批量交付、北美储能 / 飞行汽车项目收入确认、净利率回升至 4%+
3. 观察指标：单季归母维持 Q2 增速、资产负债率是否下降

最大风险：①资产负债率 70% 高，利率 / 需求下行时净利数倍跳负；②国际项目（北美 / 飞行汽车）交付与地缘风险；③电驱价格战；④应收账款坏账。

结论：暂不介入

基本面逻辑通顺（装备 + 电驱双轮、国际客户突破、Q2 拐点），但当前 24.74 元已透支 2027–2028 成长，且 70% 负债率下下行风险不对称（悲观 −47%）。等回落至 16 元以下或盈利持续兑现再考虑"纳入观察"。
