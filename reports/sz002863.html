（3）产业链传导

上游：核心原料为原铝/铝合金锭（A356 等）、再生铝、镁锭、电力/天然气、模具钢材。铝价是最大的成本变量（占车轮成本约 50–60%）；能源成本（熔炼、热处理）在高耗能环节占比高。

下游：汽车主机厂（乘用车 + 新能源车）、摩托车厂、光伏组件厂（型材）。主机厂年降（年降 3–5%）是行业惯例，形成"成本上涨 → 售价年降"的双向挤压。

议价权判断：偏弱。
- 佐证 1：2026H1 营收 +18.25% 而归母仅 +9.36%，净利率 1.62% —— 规模增长未能带来利润的等比例增长；
- 佐证 2：汽轮毛利率 18.75% 显著高于摩轮 7.73%，说明产品结构决定议价权（高附加值大尺寸/旋压/再生铝才有溢价）；
- 佐证 3：海外采用 FOB 模式（关税由客户承担） —— 反而是海外议价条款优于国内（境外 +27.13% vs 境内 +15.04%）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1 成本传导弹性（pass-through）

板块 核心原料 议价权 转嫁系数（估计） 依据
汽轮 铝合金锭（占比约 50–60%）、能源 中偏弱 约 0.5–0.7 行业惯例为"铝价 + 加工费"定价 + 年度铝价联动条款；但对主机厂仍有年降压力，故非 100% 转嫁。2026H1 汽轮毛利率仍 +0.65pct → 传导有效
摩轮 铝合金锭、镁锭 中 约 0.6–0.7 大排量/仿锻轮为高毛利品类（+0.91pct），议价优于普通摩轮
铝型材 铝合金锭、电力 偏弱（光伏标准品）/ 中（汽车轻量化） 约 0.4–0.6 光伏边框为议价弱的标准品；新能源车结构件议价较强

量化：若铝价上涨 10%，按铝合金车轮板块（2026H1 收入 21.93 亿元）中铝成本占比 55% 估算，成本增厚约 1.21 亿元/半年；按 0.6 转嫁率，公司实际承压约 0.48 亿元/半年（相当于 2026H1 归母 4955 万元的近 1 倍）。这就是"薄净利率 + 高原料占比"的杠杆含义——铝价 10% 的波动就能吃掉半年利润。这是本股最核心的量化风险。

核心结论：公司毛利率抬升（13.59%，+1.01pct）来自"产品结构上移"而非"铝价友好"——汽轮靠旋压/大尺寸/再生铝提价、摩轮靠大排量/仿锻轮、型材靠新能源轻量化。这条结构迁移线必须单列：用 13.59% 的综合毛利率会把"汽轮 18.75% vs 摩轮 7.73%"的 11 个百分点差距抹平，而估值恰恰要靠"高毛利品类的占比提升"来驱动。

因子 3 库存与采购节奏（timing）
- 铝价 timing 对本股影响极大：公司持有铝合金原料与在制品库存，铝价上行期存在"低价囤货收益"（当期毛利虚高），下行期则为"高价接货损失"。
- 2026H1 判断：汽轮/摩轮毛利率同比小幅上升（+0.65pct / +0.91pct），幅度温和，更像产品结构改善而非库存收益，未观察到明显的囤货虚增。
- 警惕：若后续铝价快速上涨，短期毛利会因库存成本滞后而先升后降；不可把库存收益当真实盈利能力。
- 经营现金流 −83.88% 的提示：现金流大幅走弱可能对应原材料备货与应收增加，须在 2026H2 观察去化。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1 资产质量折扣（PB 与破净）
- 今飞 PB 1.01x，几乎贴着净资产（归母净资产 28.26 亿元，市值 28.54 亿元），尚未破净但已接近。按 RULES，必须先回答"为什么 PB 只有 1.01"：
- 原因 1（主因）：资产盈利能力差。2026E 归母 0.70 亿元 / 净资产 28.26 亿元 → ROE 仅约 2.5%；2026H1 加权 ROE 1.75%。ROE 远低于社会平均资本成本 → PB≈1 是公允定价，不是低估。
- 原因 2：资产专用性强。铝合金车轮铸锻产线、模具、热处理设备不能转产，清算价值远低于账面 → 净资产不构成硬兜底。
- 原因 3：高杠杆下的净资产虚高。资产负债率 70.80%，总资产 97.02 亿元中大量依赖负债，净资产对资产减值的缓冲极薄。
- 结论：禁止单凭"PB≈1"推导"空间大"。本股的 PB 1.01x 是"薄 ROE 的公允定价"，不是安全边际。

校正 2 周期位置校正（中性净利用周期归一化）
- 汽车零部件为中等周期（跟随汽车产销与铝价），当前处于新能源车渗透带来的结构性上行期，但铝价与年降构成双向挤压。
- 禁止：用单年好年景（如铝价低位年份）、近三年均值、或"2026H1 单季年化"。
- 本报告采用：归母净利率中枢 = 2.3%（介于公司 2024 年约 1.0%、2025 年 1.1%、2026H1 1.62% 的实际水平与公司历史曾经达到的 3%+ 之间，刻意取偏保守的中枢），配合 2029E 营收 78 亿元 → 归母 1.96 亿元。
- 交叉验证（PB–ROE 法）：假设 2029E ROE 达 6.9%（1.96 / 28.26），对应合理 PB 约 1.2–1.5x（汽车零部件行业常态）→ 目标市值 33.9–42.4 亿元 → 5.66–7.07 元，与 PE 法（5.23 元）同向，取较低者（5.23 元）作为中性锚，保守为上。
- 当前周期位置：中性偏上（结构上行 / 铝价扰动），故中性未过度悲观，但也未给周期顶部估值。

校正 3 杠杆下行情景（高负债必附负面情景）
- 资产负债率 70.80%（2026H1）、2025 年报 68.75%，显著偏高。
- 经营杠杆 + 财务杠杆双高：2026H1 营收 +18.25% 而归母仅 +9.36%，说明利润对收入/成本变动极度敏感；叠加利息支出后，下行时净利可几倍跳负。
- 负面情景（必附）：铝价上涨 10%（承压约 0.48 亿元/半年）叠加汽车需求下行 + 泰国产能利用不足 → 2029E 归母降至 1.20 亿元 → 目标价 2.40 元（−49.6%）。
- 判定：该负面情景使空间转负，按 RULES 不得标"大空间/重点关注"，至多"纳入观察"且须注明高贝塔属性。本报告据此将结论限定为"纳入观察"。

期权纪律
- 机器人压铸件/减速器、镁合金轻量化均未过验证点（无订单/定点公告） → 不计入中性 1.96 亿元，仅列乐观情景。
- 铝型材 + 免热处理材料已过验证点（型材占比已跳升至 19.47%、免热处理已量产）→ 可作为中性情景组成部分。

第五步：综合赔率判断（买不买？）

当前价格位置：PB 便宜、PE 贵、综合"合理偏低"。现价 4.76 元对应 PB 1.01x（贴近净资产）、PE(2026E) 约 40.7x。对一家 ROE 仅 2.5% 的重资产公司，PB 1.01x 是公允定价；但若 2029E ROE 修复至 6.9%，PB 1.2–1.5x 合理 → 对应 5.66–7.07 元。本股的赔率来自"ROE 修复"，而不是"估值便宜"。

安全边际：
- 中性远期 5.23 元 → 空间 +9.9%（PE 法，保守）；PB 法上限 7.07 元 → +48.5%；
- 悲观情景 2.40 元 → 下行 −49.6%（高杠杆反噬）；
- 乐观情景 9.01 元 → +89.3%（需机器人/镁合金期权 + CBAM 溢价兑现）；
- 下行保护：PB 1.01x 提供弱保护——因资产专用性强、ROE 低、杠杆高，PB≈1 不构成硬底（悲观情景对应 PB 约 0.51x）。

介入条件：
1. 可少量纳入观察仓，不建议重仓（高贝塔）；
2. 加仓信号：① 归母净利率从 1.62% 站上 2.5%（连续两个季度）；② 泰国基地产能利用率达 80% 以上或新增一线新能源客户定点公告；③ 锻造 60 万件产线投产并贡献收入；④ 经营现金流恢复正增长（当前 −83.88% 是警报）；⑤ 资产负债率降至 65% 以下；
3. 观察指标：沪铝主力合约（铝价 10% = 半年利润）+ 汽轮毛利率（跌破 16% 即证伪）+ 型材收入增速（跌破 10% 即下修）。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 铝价上行 + 转嫁受阻（首要）：铝占车轮成本 55%+，铝价 10% 的波动 ≈ 2026H1 归母的全部；若叠加主机厂年降，净利率可能被压回 1% 以下；
2. ⚠️ 高杠杆反噬：资产负债率 70.80%，经营杠杆 + 财务杠杆双高，下行时净利几倍跳负（悲观情景 −49.6%）；
3. 经营现金流大幅恶化：2026H1 −83.88%，若因原材料备货与应收堆积而非产能扩张，则盈利质量存疑；
4. 机器人业务是"故事"：减速器/人形机器人压铸件无订单公告，若长期不落地则乐观情景剔除；
5. 光伏型材的周期拖累：2026H1 组件产量 −35.1%，型材高增（+34.63%）能否延续存疑。

  • 类型 C 市场错杀修复：本股 PB 1.01x 已贴近净资产，且境外收入 +27.13%、型材 +34.63%、摩轮 +22.11% 三项高增被 1.62% 的薄净利率掩盖，市场按"微利重资产"给最低估值。错杀证据：三项高增业务合计已占收入约 30% 且在加速；但ROE 仅 2.5%、资产负债率 70.80% 说明 PB≈1 是公允而非错杀 → 本类适用性中等。修复触发点：净利率站上 2.5%、经营现金流转正、负债率下降。弹性：PB 从 1.01x 修复至 1.3x → +28.7%。

判定理由：本股是本批五只中基本面最扎实、赔率最正的一只：
① 双因子增量成立——"市场变大（新能源车轻量化 + CBAM 低碳铝）× 份额变高（型材 +34.63%、海外 +27.13%、摩轮 +22.11%）"同时发生；

③ 估值不贵——PB 1.01x 贴近净资产，处于历史低位区；
④ 上行期权丰富——CBAM 再生铝溢价、汽车改装新政、机器人压铸件/减速器代际跃迁。
但按 RULES「重资产/周期股校正」必须承认三项硬约束：资产质量折扣（ROE 仅 2.5%，PB≈1 是公允定价而非低估，且资产专用性强、净资产不兜底）、周期位置校正（净利率用归一化 2.3%，未用好年景）、杠杆下行情景（资产负债率 70.80%，悲观情景 −49.6% 使空间转负）。RULES 明确"该负面情景若使空间转负，则不得标大空间/重点关注，至多纳入观察且须注明高贝塔属性"。
