第一步：公司是干什么的？

核心产品：iEnter 智慧企业、iManu 智能制造（MES / APS / 电检 / 数字孪生）、iSupply 智慧供应链（OTD / WMS / SRM）、EP 智慧生态营销（CRM）、Connect 智能网联、DataValue 数据价值赋能；AI 全栈技术底座与汽车领域专有大模型；覆盖软件、基础硬件、应用软件及信创实验室的软硬一体信创解决方案；车联网安全与态势感知产品。

主要客户 / 下游：中国一汽及旗下解放、红旗、奔腾等整车企业为核心（营收 99%+ 来自境内、实质高度依赖一汽系）；正拓展装备制造、电力能源等大型国央企。2026-07-07 与一汽解放签署深化战略合作协议，围绕数智化、智能网联、智能制造、数据运营及 AI 大模型应用开展协同。

境内外收入占比：境内 99.26%（3.53 亿），境外可忽略。

股东背景：中国一汽为控股股东 / 实控人，具备央企数字化转型"最佳实践"输出能力；但客户高度集中，既是资源也是风险。

第二步：行业景气度 + 政策 / 市场数据

（1）政策端（近 6–12 个月）——强利好，国家级，已在执行

  • 信创替代：党政及重点行业信创由"试点"转向"全面铺开"，公司定位"国家信创工程主力军"，提供覆盖软件、基础硬件、应用软件及信创实验室的整体方案。
  • AI + 数据要素：部委持续推动"人工智能+"、制造业数字化转型、数据要素市场化。公司中报原文明确"人工智能与信创替代两大政策红利同步发力，推动行业信息化投资需求持续释放"。
  • 央企数智化：国资委推动央企建设智能工厂 / 数字化车间，一汽"七星云"工作台为标杆，公司为主力承建方。

（3）产业链传导

上游：核心"原料"是研发 / 实施人力（薪酬），软件外包与云资源为辅；无大宗原材料敞口，成本端受薪资通胀影响但不剧烈。
下游：汽车主机厂、装备制造企业 IT 预算；客户集中（一汽系）导致议价权不对等——公司议价权中偏弱（项目制定价、回款周期长、H1 经营现金流持续为负）。
议价权量化：人力成本转嫁系数约 0.25–0.30（项目合同锁价，薪资上涨自行消化），靠内部降本与产品化提效对冲。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：软件业核心成本是研发 / 实施人力。转嫁系数 ≈0.25（项目制合同锁价，人力涨自行消化）。2026H1 期间费用率 18.96%（+1.11pct），销售费用 +67.63%，印证成本端刚性、转嫁难。
  • 因子2 毛利结构再平衡：
    | 业务线 | 毛利率（估） | 原料敏感权重 |
    |---|---|---|
    | 管理软件及服务 | 35–40%（高毛利产品化） | 低（人力资本为主） |
    | 集成服务 | 15–20%（硬件 / 外采占比高） | 中（含外采设备成本） |
    | 汽车电子及服务 | 25–30% | 中 |
    | 信创 / AI 新业务 | 投入期，毛利率波动大 | 低但费用高 |
    结构风险：高毛利软件占比虽高，但集成服务拉低综合毛利率；产品化若慢，综合毛利率难回升。
  • 因子3 库存与采购节奏：无存货型囤货收益；但 AI 算力 / 云服务采购存在"高价接货"风险（算力涨价期锁价）；项目制收入确认节奏导致 Q4 集中确认、H1 现金流为负属常态，不可将 H1 亏损线性外推为全年。
  • 因子4 政策 / 市场锚点：政策是核心需求驱动（信创 / AI 国产化），非成本驱动。验证点：信创招标金额、一汽及央企数字化预算；证伪：信创节奏放缓、央企 IT 支出削减。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：制造业 IT 服务市场容量大但公司份额小（营收仅 ~7 亿 vs 行业数千亿）。份额锚点：① 供给侧——产能 = 人员规模，扩张靠招聘，瓶颈在人才；② 客户份额——一汽系内份额高、外部极低（<1%）；③ 技术代际——AI 大模型布局与头部厂商有代差；④ 成本曲线——产品化提升人效是扩份额关键；⑤ 份额加速度——外部拓展刚起步，加速度待验证。三档：保守守住一汽系基本盘 / 中性外部占比升至 15–20% / 乐观外部占比 30%+。验证点：外部客户公告、新签合同金额。
  • 层2 主业迁移空间（新易盛范式）：从"一汽内部 IT"迁移到"跨行业制造业数智化赋能商"。能力可迁移性中（行业知识壁垒强但绑定汽车）；新 TAM 弹性大（全制造业）；切入卡位早但认证门槛高（央企客户重新认证）；信号验证——目前仅框架合作，未有大额外部订单正式公告。→ 中期期权，不计入中性。
  • 层3 证伪信号：外部客户拓展连续无公告、AI 产品化收入占比 <5%、一汽 IT 预算削减、综合毛利率跌破 20%。

第四步进阶：重资产 / 周期股估值校正

本股非重资产、非强周期，但属微利高估值科技股，适用"盈利质量校正"：① 盈利质量——2026H1 归母 1541 万中政府补助 310 万占 20%，扣非仅 1252 万，盈利极薄；② 现金流——经营现金流持续大额为负（H1 −1.63 亿），盈利"纸面化"；③ 杠杆——无有息负债、资产结构轻，下行风险是估值压缩而非资不抵债。→ 高估值无安全边际，中性锚远低于现价。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。现价对应 2026E PE ~196x、PB 4.69x，已 price-in 信创 + AI 全部乐观预期。

安全边际：中性远期 6.52 元 → 空间 −60.0%；悲观 1.29 元（−92.1%）；乐观 17.13 元（+5.2%）。下行远高于上行，赔率极差。

介入条件：仅当回落至 6.5 元以下（对应 2029E 中性估值、PE<40x）才具配置价值；加仓需验证：① 外部客户大额订单公告（单笔 ≥5000 万）；② AI / 信创产品化收入占比突破 10%；③ 经营现金流转正。

最大风险：① 客户高度集中（一汽系），其 IT 预算波动直接冲击；② 盈利极薄（扣非 1252 万）且现金流为负，任何成本 / 回款恶化即转亏；③ 信创 / AI 预期落空引发估值戴维斯双杀；④ 行业巨头（华为 / 用友）挤压。

结论：暂不介入

公司基本面"尚可但平庸"——央企背景、政策赛道正确，但营收连续萎缩、盈利仅千万级、估值 196x 严重透支。中性锚下空间为负，仅乐观情景勉强持平现价，属典型"故事贵"标的。若外部订单与 AI 产品化实质兑现，可重新评估。

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：不适用（非过剩出清行业）。
  • 类型B 政策反转期权：信创 / AI 国产化全面加速，央企数字化预算超预期——若信创招标金额同比 +50% 以上，可上修外部收入；验证点：财政部 / 国资委信创采购目录与金额；未过验证点仅作机会情景。
  • 类型C 市场错杀修复：若因市场风格切换导致股价跌至 6.5 元以下，按中性锚即具备修复空间；触发点：估值分位回落后价值资金进场。
  • 类型D 技术突破 / 代际跃迁期权：汽车专有大模型 + 工业视觉 / 智能质检形成可复制产品，从"项目制"跃迁为"产品化平台"——硬验证点（中试良率达标 + 客户定点 + 量产成本优于旧路线）目前均未满足（产品化收入占比 <5%），仅作机会情景。
  • 上调至重点关注的条件：外部客户大额订单落地（年化 ≥1 亿）+ AI 产品化收入占比突破 10% + 经营现金流转正，使 2029E 净利上修至 1.5 亿以上。
