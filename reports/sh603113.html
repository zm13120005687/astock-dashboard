行业：资源综合利用型循环化工（石油化工 PDH + 煤化工焦化/炭黑 + 精细化工）｜ 板块：上交所主板
⚠️ 真实财报核查：队列标注"亏损（TTM 口径）"。经核查 2026 年半年报真实归母净利润 = −5.887 亿元（确为亏损），扣非 −6.10 亿元。本股按亏损股处理，执行完整五步法 + 正常化净利润法 + PB<1 资产质量折扣说明 + 强周期归一化 + 杠杆下行情景。

第一步：公司是干什么的？

一句话定位：山东老牌资源综合利用型、循环经济式综合化工企业——以全球单体规模最大的 180 万吨/年丙烷脱氢（PDH）装置为核心，配套 135 万吨/年聚丙烯、48 万吨/年炭黑，叠加齐河基地的煤焦化与精细化工，形成"PDH+PP+CB"循环产业链（PDH 副产氢气供炭黑作燃料、炭黑尾气产蒸汽反供 PDH）。

两大生产基地：
- 青岛董家口新材料基地：PDH 180 万吨/年（全球单体最大，采用 Lummus Catofin 工艺 + 科莱恩催化剂）、聚丙烯 135 万吨/年（Basell Spheripol/Spherizone 工艺，2×45 万吨 + 二期 2×45 万吨）、绿色炭黑 48 万吨/年。二期 2026 年 3–4 月投产，2026 年产能全部释放。
- 山东齐河基地：煤焦化 + 炭黑 + 精细化工（对甲酚、山梨酸钾）。

循环经济优势（真实成本壁垒）：PDH 富氢尾气 → 炭黑反应热源；炭黑尾气 → 9.8MPa 高温高压蒸汽 → PDH 压缩机驱动；余热余压 → 发电。公司披露该模式一年可降低成本约 3.5 亿元。

议价权判断：弱。
- 依据 1：烯烃毛利率 −10.47%（成本倒挂仍在生产，说明无法顺价）
- 依据 2：焦炭毛利率 −0.88%，焦煤涨 25.6% 而焦炭仅涨 10.2%，成本无法转嫁
- 依据 3：炭黑毛利率仅 3.32%，煤焦油涨价传导有限
- 依据 4：公司产品均为大宗化学品，价格由市场决定

因子3 库存与采购节奏（timing）——本例中极其重要
- 存货 21.55 亿元，较年初 +51.45%（主因原材料库存增加）；预付款 5.59 亿元，+185.45%（丙烷货到未结算）
→ 这是在丙烷高价区间大量备货，若 H2 丙烷继续回落，将产生存货跌价损失；反之若丙烷反弹则形成库存收益
→ 绝不可将 Q2 的毛利改善简单归因为"经营改善"——其中部分来自低价丙烷到货结算替换高价库存
- 期货套保损失 4,944.75 万元（处置衍生金融资产投资损失）→ 说明公司有套保但本轮套保失败（可能方向做反或规模不足），对冲比例与有效性存疑
- Q2 单季营收环比 +56.49%（33.24 → 52.00 亿），部分来自二期投产放量，部分来自高价原料对应的高价产品结算

1. ⚠️ 丙烷价格再度暴涨（首要且外生）：中东地缘冲突若再度升级、霍尔木兹海峡再关闭，丙烷回到 7,000+ 元/吨，PDH 立即再度倒挂。这是单一变量决定生死的风险
2. ⚠️ 流动性风险（最致命）：可动用现金 16.46 亿 vs 短期有息负债 76.19 亿（覆盖率 21.6%）；2026H1 经营现金流 −5.38 亿；担保余额 66.29 亿（占净资产 87.93%）；子公司诉讼冻结 4.12 亿。若银行抽贷或诉讼扩大，存在实质性流动性危机
3. ⚠️ 存货跌价：21.55 亿高价原料库存（+51.45%）+ 5.59 亿预付款，若丙烷继续回落需计提跌价
4. 焦炭/炭黑板块持续微亏：焦煤 +25.6% vs 焦炭 +10.2%，传导率仅 40%；下游粗钢 −3.0%
5. 国内聚丙烯产能过剩：行业内卷，通用料价格战
6. 财务费用高企：有息负债约 80 亿，利率上行 100bp 即吃掉 0.8 亿净利（相当于中性净利的 21%）

第五步进阶：上行想象力情景（四类）

类型A 行业调整剩者红利：PDH 行业在 2026H1 丙烷暴涨中经历强制性出清——据行业信息，油制、PDH 路线 1–4 月深度亏损导致国内 PDH 装置大幅降负检修。若高成本/无循环经济的中小 PDH 装置永久退出，行业集中度提升，剩者定价权与单位盈利中枢跳升。
- 验证点：国内 PDH 行业开工率与产能退出公告；行业 CR5 提升；PDH 单吨利润中枢上移幅度
- 证伪信号：PDH 新产能继续大规模投放；开工率快速回到 90%+ 但单吨利润未改善
- 弹性测算：若行业出清 15%、PDH 单吨利润中枢从 400 元升至 700 元 → 180 万吨 × 300 元 = +5.4 亿毛利 → 净利 +4.0 亿 → 2029E 归母 7.8 亿 → 目标价 13.8 元（+175%）
- ⚠️ 属机会情景，未完全过验证点，不计入中性锚

类型B 政策反转期权：
- ①丙烷进口关税/增值税加计抵减：2026H1 增值税进项加计抵减从 4,737 万降至 1,482 万，若政策恢复或加大 → 直接增厚利润约 0.3 亿/年
- ②能源安全战略下对 PDH 副产氢的支持：二期规划 6.5 亿 m³/年清洁氢，若氢能补贴/标准落地 → 副产氢从"废气"变"产品"
- ③焦化行业去产能：若焦化环保/能耗双控加码，焦炭供需改善、传导率提升
- 验证点：财政部/税务总局加计抵减政策文件；国家能源局氢能规划；工信部焦化产能置换方案
- 证伪信号：政策退坡；氢能标准不落地
- ⚠️ 未过验证点，仅作机会情景

类型C 市场错杀修复：
- 错杀证据：①PB 0.57x 已低于理论中枢 0.50–0.60x 的下沿；②PS 仅 0.25x（169 亿营收 vs 42.59 亿市值）；③Q2 单季毛利率环比 +18.6pct、归母转正，基本面已出现拐点但股价仍在下跌（2026-09-11 单日 −4.92%）；④青岛二期刚投产（产能全部释放），产量创新高（Q2 烯烃 +21.96%、精化 +48.51%）
- 修复触发点：三季报确认单季盈利持续；丙烷价格回落被市场定价
- 证伪信号：Q3 再度亏损；经营现金流继续为负
- 弹性：若 PB 修复至 0.75x（周期确认反转）→ 74.98 × 0.75 = 56.2 亿 → 6.62 元（+31.9%）
- ⚠️ 部分成立（Q2 拐点已现），可作为中性情景的支撑理由之一

类型D 技术突破/技术代际跃迁期权：高端改性聚丙烯（新能源/汽车材料）+ 循环经济技术代际优势
- ①政策驱动：新能源汽车轻量化、新材料首批次应用保险补偿（部分成立）
- ②行业趋势：通用料内卷 → 改性料是明确升级方向（成立）
- ③公司技术投产落地：硬验证点全部缺失——无中试良率、无客户定点/订单公告、无量产成本对比、无产能公告
- 硬验证点：车规/电池厂认证通过 + 定点公告 + 改性料收入单独披露
- 证伪信号：2027 年前无改性料产能公告；研发未转化为订单
- ⚠️ 三要素缺一，仅作机会情景，不计入中性锚
- 注：公司的"循环经济模式"是已兑现的真实成本优势（公司披露年降本 3.5 亿），已隐含在中性净利率 2.0% 中，不重复计入期权

什么条件下上调至"重点关注"：
1. 丙烷 CFR 华东月均价连续 3 个月 <5,200 元/吨 且 PDH 单吨利润 >600 元/吨（周期反转确认，2029E 归母上修至 6.5 亿 → 目标价 11.5 元，空间 +129%）
2. 单季归母连续 2 个季度 >1.5 亿 且 经营现金流同步转正
3. 资产负债率降至 55% 以下 + 短期借款下降 >10%（流动性风险解除，PE 可给到 18x）
4. 满足 1 或 2，且股价 ≤5.0 元 → 远期空间 >+100%，上调"重点关注"

在以上条件出现前，中性锚维持 3.80 亿归一化净利、6.72 元目标价。

结论：纳入观察（高贝塔，需严格控制仓位）

核心判断：这是一家周期底部、破净、高杠杆、高弹性的强周期化工企业。
✅ 看多理由：①Q2 已确认周期拐点（单季毛利率环比 +18.6pct、归母转正、PDH 单吨利润恢复至 300 元）；②青岛二期 2026 年 3–4 月投产、产能全部释放（PDH 180 万吨全球单体最大、PP 135 万吨）；③长期丙烷中枢有望下行（美国新增 130 万桶/天外运能力、库存 1.09 亿桶创历史新高、中东扩产）；④中国丙烯 2026 年后无新增产能规划、需求 +5.8%；⑤出口爆发（PP 出口 +29 倍、炭黑 +45%）；⑥循环经济真实降本 3.5 亿/年；⑦2025 年经营现金流 +5.48 亿证明正常年份能造血。
❌ 看空理由：①2024、2025 连续两年扣非为负，2026H1 扣非 −6.10 亿——主业长期在盈亏线上；②破净是公允定价（ROE 0.26%、资产专用性强、担保占净资产 87.93%），非安全边际；③流动性风险显著（可动用现金 16.46 亿 vs 短期有息负债 76.19 亿，覆盖率 21.6%）；④三项非经营性拖累（汇兑 0.63 亿 + 套保 0.49 亿 + 税收优惠减少 0.33 亿）暴露管理与财务脆弱性；⑤丙烷是单一生死变量，外生不可控。
为何不是"重点关注"：中性远期空间 +33.9% < 50% 门槛；且杠杆下行情景可使空间转负（−26.1%），按第四步进阶闸3，不得标"大空间/重点关注"。
为何不是"暂不介入/回避"：公司有真实产能、真实营收（169 亿）、真实成本优势、明确扭亏路径与已现的拐点信号，且PB 0.57x 已反映大部分悲观预期，远期空间为正。按规则不属"确无扭亏可能"（有明确的价格拐点 + 产能投产触发点）。
核心跟踪点（按优先级）：丙烷 CFR 华东月均价 → 单季归母是否连续转正 → 短期借款与资产负债率 → 经营现金流。
