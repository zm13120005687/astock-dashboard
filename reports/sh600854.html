第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）
- 空调段：委外生产，成本由代工方承担并转嫁，终端以价换量，传导率 ≈ 0.3–0.4（2026H1 营业成本 +83.81% 而收入 +123.27%，毛利率反降 8.34pct，证明传导不畅）。
- 电力段：煤价波动由电厂承担，公司被动接受股利（传导率 ≈ 0，公司无成本控制权）。
- 物业段：租金由市场定，传导率 ≈ 0.4。
→ 加权传导率约 0.3。公司对主营成本几乎无掌控力。

因子2 毛利结构再平衡
公司利润结构极端失衡：

业务线 毛利率 原料敏感要素 2026H1 收入权重 利润权重
空调器 约 3–5%（2025 年 3.05%） 铜/铝/压缩机 80.91% ≈0
物业租赁 较高（星威商厦租金 543 万） 折旧 19.09% 小
房地产 — — 0% 0

→ 综合毛利率 18.27% 是"低毛利空调主业 + 高毛利租赁"的加权，与利润结构完全脱节——利润几乎全部来自电力股利。禁止用"综合毛利率"或"空调收入 +123%"代表公司盈利能力。

因子3 库存与采购节奏（timing）
公司现金充裕（11.6 亿元），无原料囤货逻辑；空调为按需代工。真正的"库存"是房地产存量房（去化停滞，存在减值风险）与其他权益工具投资（电力股权）账面价值 5.17 亿元。2026H1 其他权益工具投资账面由 5.7129 亿元降至 5.1658 亿元，公允价值变动 −5471.17 万元，计入其他综合收益（不影响当期净利）——这一减值不计入利润表，但直接影响净资产。

因子4 政策/市场锚点
- 市场层：铜/铝价格指数、煤炭价格（秦皇岛动力煤）、空调销量与均价、泰州房价。
- 政策层：①电力市场化改革（容量电价 + 现货市场 + 新能源入市）——直接决定电力股利，是最强的负向政策变量；②家电以旧换新——微正向；③房地产止跌回稳政策——微正向但公司无土储；④国资重组/资产注入政策（国资委"提高上市公司质量"）——潜在正向期权。
- 验证点：季度投资收益金额、泰州电厂上网电价与利用小时、空调销量与毛利率、房地产去化数据。
- 证伪信号：电力股利连续两年下滑 >15%、空调业务终止或亏损扩大、房地产存货大额减值。

本因子输出直接喂给第四步：中性情景假设电力股利温和下滑（电力市场化改革压制），不沿用 2026H1 的 9479 万元股利水平。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

层1 现有业务：市场容量 × 份额变量
- 市场容量：空调行业销量 6282.2 万台（−5.6%），头部主导；电力行业受市场化改革重塑。
- 份额锚点①（供给侧）：公司已退出家用空调自有生产（2016 年起全部委外），供给侧份额接近零；电力为 10% 财务性持股，无经营份额。
- 份额锚点②（需求侧/客户）：空调依赖经销商与线上渠道，无品牌黏性；电力股利依赖国家能源集团的分红政策，无话语权。
- 份额锚点③（技术代际差）：技术代落后——无自有制造、无研发投入（2026H1 研发费用未见支持披露，公司自述"研发投入和人力资源跟不上"）。
- 份额锚点④（成本曲线位置）：代工 + 无规模 → 位于成本曲线最右端，行业降价时最先出局。
- 份额锚点⑤（二阶导）：份额已饱和并持续萎缩（营收从 2022 年 2.82 亿降至 2025 年 0.949 亿）。
- 三档假设：保守（空调收入年增 10%，毛利率维持 3%）／中性（空调收入持平，毛利率 4%）／乐观（空调放量至 2025 年的 2 倍）。验证点：季度空调毛利率能否由 3% 提升至 6% 以上。

层2 扩展业务：主业迁移空间（新易盛范式）
- 能力可迁移性：极低。无自有制造、无研发、无渠道壁垒，无可迁移的核心能力。
- 新 TAM 弹性：无明确新市场。
- 切入卡位：不存在。
- 认证门槛：无。
- 信号验证：无任何新业务收入占比跳升公告（半年报"重大变化"栏为"无"） → 迁移空间不存在，不计入中性情景。
- 唯一的"类迁移"：账面 11.6 亿元现金若被用于并购新业务——目前无公告，属纯期权。

层3 风险折扣：证伪信号
- 电力股利连续两年下滑 >15% → 利润锚下修
- 空调毛利率跌破 3% 或业务终止 → 主业归零
- 房地产存货大额减值 → 净资产下修
- 其他权益工具投资（电力股权）继续按公允价值下调 → 净资产缩水
- 长期无资产注入公告 → 期权价值归零

第四步：估值锚定（自下而上，非增速外推）

方法说明：不使用历史增速外推。公司是"资产型 + 股利驱动"结构，因此采用双口径交叉校验：①资产价值口径（NAV/SOTP）——现金 + 电力股权收益价值 + 物业 − 负债；②盈利口径——电力股利 + 主业微利。盈利为公司常态，无需采用亏损股专项估值口径。

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

校正1 资产质量折扣
公司PB 约 1.00x（不破净、亦无折价），资产质量逐项检验：① 现金 11.6 亿元真实、占总资产近半，是硬资产；② 电力股权账面 5.17 亿元——若按收益资本化（股利 7857 万 + 1622 万）显著高于账面（隐含收益率 15–19%），存在重估空间，但须注意"煤电周期 + 电力改革"可能使股利回归；③ 房地产存货与投资性房地产——去化停滞，存在减值可能，是资产质量的主要隐性风险；④ 资产负债率仅 6.41%，无有息负债压力，净资产质量总体良好。→ PB 约 1.0x 中性，不构成安全边际，亦不构成高估。禁止单凭"现金多、PB 低"推导大空间。

校正2 周期位置校正（中性净利用周期归一化）
公司利润本质上是煤电周期 + 电力政策的衍生品。当前煤电处于盈利相对高位（低煤价 + 容量电价），公司自述"盈利处于相对高位"，并预警未来可能下降。中性净利不得用 2026H1 的年化（1.97 亿）、也不得用 2025 年的高点（1.276 亿）外推，须取"电力股利温和下滑 + 主业微利 + 租赁稳定"的周期归一化值——中性锚定 1.00 亿元。明确标注：当前处于煤电盈利周期偏上位置，向下风险大于向上空间。

校正3 杠杆下行情景
本股财务杠杆极低：资产负债率 6.41%、有息负债仅 193 万元（2025），无财务杠杆风险——这是与多数底池标的的根本区别，提供良好的下行保护。但"资产端杠杆"存在：净值 24.6 亿中现金 11.6 亿虽安全，但电力股权与房地产存货约 10 亿+ 存在减值风险。下行情景：电力股利 −30% + 电力股权公允价值下调约 4 亿 + 房地产减值 2 亿 → 净资产降至约 17 亿 → 对应股价 3.30 元（−30.4%）。该负面情景幅度可控（约 −30%），不构成"深度转负"，故本股可保留"纳入观察"。

期权纪律
"资产注入/重组""现金并购新业务""电力股权按收益重估"均属未过验证点的中期期权，不计入中性 NAV / 中性净利，仅列入乐观情景（见第五步进阶）。

第五步：综合赔率判断（买不买？）

当前价格位置：合理。现价 4.74 元对应 PE(TTM) 23.0x、PB 1.00x，NAV 交叉校验 4.43–5.77 元，处于合理区间中枢。既无显著低估（主业空心化压制估值上限），也无显著高估（现金 + 电力股权提供资产底）。

安全边际：
- 中性远期 5.00 元 → 空间 +5.5%（PE 法）；NAV 上限口径（电力股权重估）可达 5.5–5.8 元（+16%～+22%）
- 悲观情景 3.30 元 → 下行 −30.4%（"电力股利 −30% + 电力股权公允价值下调 + 房地产减值"情景）
- 乐观情景 9.24 元 → +95.0%，需资产注入或电力股利维持高位
- 下行保护较实在：现金 11.6 亿（占总资产 47%）+ 资产负债率 6.41% + 无有息负债 + 电力股权收益价值

介入条件：
1. 可小仓位跟踪。现价接近净资产，资产底扎实，但缺乏成长催化
2. 加仓信号：① 控股股东/地方国资资产注入或重组方案正式公告；② 电力股利维持或提升（季度投资收益不减）；③ 空调毛利率由 3% 提升至 6% 以上
3. 观察指标：逐季投资收益金额、其他权益工具投资公允价值变动、房地产去化与减值、现金使用方向（是否有并购）

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 电力市场化改革（首要）：容量电价机制 + 现货市场 + 新能源入市可能压缩煤电盈利，公司自己明确提示分红水平可能下降——而利润 100% 依赖电力股利
2. ⚠️ 主业空心化：公司自述"主营将长期空心化，发展面临极大的风险"；空调无自有生产、无研发、市占率低；房地产无新增土储
3. 房地产存货减值：存量房去化停滞，存在计提减值风险
4. 利润单一结构：盈利结构单一、过度依赖投资收益，公司已自认风险

结论：纳入观察

理由：中性远期空间 +5.5%（PE 法），NAV 口径（含电力股权收益重估）可达 +16%～+22%，综合区间中枢满足"纳入观察"的 >0 门槛；公司资产负债率 6.41%、现金 11.6 亿、无有息负债，下行保护较实；但成长性缺失、主业空心化，不具备"重点关注"条件。
本股本质是"类债券资产包 + 重组期权"：向下有资产底（现金 + 电力股权 + 物业），向上需资产注入或电力红利延续。
核心跟踪点：① 电力股利/投资收益季度变化；② 资产注入或重组公告；③ 现金使用方向。
