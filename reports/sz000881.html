中广核技（000881）五步法分析报告

分析日期：2026-09-26 ｜ 现价 6.48 元 ｜ 总市值 61.26 亿 ｜ PE(TTM) −19.84x（亏损） ｜ PB 1.25x ｜ 总股本 约 9.45 亿股（61.26 亿 ÷ 6.48）
行业：化学制品 / 核技术应用（电子加速器、辐照加工、新材料、医疗健康）｜ 实控人：中国广核集团（央企）
亏损股核实：经 2026 年半年报核实，归母净利 −1.22 亿（同比增亏 21.76%，由 -0.998 亿扩至 -1.22 亿），TTM 标记"亏损"准确，非误标；按亏损股完整五步法 + 正常化净利润法处理。

第一步：公司是干什么的？

一句话定位：中广核集团旗下核技术产业化平台，以"新材料（改性塑料/线缆料）"为基本盘，叠加"电子加速器及辐照加工"高毛利增长极，并培育"医疗健康（质子治疗系统）"作为远期期权。

主要客户/下游：线缆、汽车、家电、医疗等制造业；辐照服务客户广；质子治疗系统面向医院（订单制）。

（3）产业链传导

上游：原油（新材料原料，如聚烯烃）→ 2026 国际油价上涨推高采购成本，毛利率承压；电子元器件/加速器部件。

下游：制造业（线缆/汽车/家电）、医疗机构。新材料对下游议价权弱（大宗商品属性、买方强势），成本难转嫁；辐照加工具一定技术壁垒，议价权中等；质子治疗系统为定制化高壁垒，但订单周期长。

议价权：新材料弱（成本接受者）；辐照/医疗中等偏强（技术壁垒）。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：新材料（占 83%）对下游传导系数≈0.2（原油涨 → 自担为主，毛利率降至 10.34%）；辐照加工传导系数≈0.6（技术壁垒可部分提价）。综合转嫁系数约 0.3，原油涨 10% 实际毛利承压约 7%。
  • 因子2 毛利结构再平衡：新材料低毛利（10.34%）占 83%，辐照高毛利（22%）占 10% 且增长 +18.6%，医疗（32.66%）极小。结构向高毛利迁移但体量不足，综合毛利率仍仅 11.84%。单一综合毛利率掩盖"主体新材料毛利塌陷、高毛利辐照爬坡"的结构迁移。
  • 因子3 库存与采购节奏：原油涨价期高价接货 → 当期毛利承压；若低位锁单则受益。公司通过供应链优化对冲（公告提及），套保比例未披露（不确定源）。
  • 因子4 政策/市场锚点（原料成本驱动变量）：市场层（布伦特原油、聚烯烃价格）；政策层（医用同位素/核技术产业规划利好辐照与医疗需求、新材料产业升级补贴降成本）。情景：若原油回落 → 新材料毛利率修复 1–2pct；若核技术规划加码 → 辐照/医疗需求提速。验证点：布油价格、辐照收入增速、质子订单确认公告。

自下而上增量测算（到 2029）：
- 新材料（基本盘）：营收稳于 42–45 亿（年化），若原油回落 + 结构升级，净费率由负修复至 2.5–3% → 净利 1.0–1.3 亿。
- 辐照加工（增长极）：营收由 5 亿（年化）增至 8–9 亿，维持 22% 毛利率、12% 净费率 → 净利 1.0 亿。
- 医疗健康（期权）：质子治疗若 2027+ 确认收入，中性不计入，乐观贡献 0.5–1 亿。
- 中性 2029 归母净利约 2.0–2.3 亿（未计入医疗期权）。

第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：辐照加工行业分散，公司具中广核品牌 + 加速器自研优势，份额可提升。
  • 需求侧：制造业回暖 + 医疗灭菌需求稳增。
  • 技术代际：加速器自研，技术代差正向。
  • 成本曲线：自研加速器降本，成本曲线左移。
  • 份额加速度：辐照收入 +18.6% 显示加速渗透。
    → 三档：保守净利 1.5 亿 / 中性 2.2 亿 / 乐观 3.5 亿。
  • 层2 主业迁移空间：从"新材料制造"迁移至"核技术高附加值服务（辐照+医疗）"，能力可迁移（加速器技术同源），新 TAM（医疗/高端制造）弹性大；质子治疗客户认证壁垒高（既是护城河也是阻力），信号验证未完成（订单未确认收入），仅作中期期权不计入中性。
  • 层3 证伪信号：原油持续高位致新材料毛利率破 9%、辐照增速降至个位数、质子订单无正式确认公告。命中则下调。

第四步进阶·校正（中广核技非重资产破净股，按实际执行）：
- 校正1 资产质量：PB 1.25x（未破净），净资产为设备+股权，无"破净须说明"情形，无金融资产未重估型安全边际诉求。
- 校正2 盈利位置校正：当前处"技术投入 + 原材料承压"盈利低谷，中性净利用正常化（原油回落 + 辐照放量假设），未将 H1 单季亏损年化、未用历史好年景外推。
- 校正3 杠杆下行情景：负债率 45.9%（适中），利率上行/需求下行负面情景下净利可转微利或续亏（悲观 5.19 元，−19.9%）。下行有限（PB 已近 1.1x 支撑）。

第五步：综合赔率判断（买不买？）

当前价格位置：估值中性偏高（PB 1.25x，业绩仍亏），当前价格已隐含一定反转预期。

安全边际：
- 中性远期 6.56 元 → 空间 +1.2%（近乎平价，无明确安全边际）
- 悲观情景 5.19 元 → −19.9%（下行有限但为负）
- 乐观情景 14.81 元 → +128.6%（质子治疗 + 原油回落期权）
- 下行保护：PB 1.25x、负债率适中、经营现金流转正，亏得起。

介入条件：
1. 现价 6.48 中性空间仅 +1.2%，不追高；等待回落至 5.5 元以下（PB<1.1x）或明确扭亏信号。
2. 加仓信号：① 质子治疗系统订单正式确认收入；② 单季归母扭亏（2026H2 或 2027Q1）；③ 新材料毛利率回升至 12% 以上（原油回落验证）。

最大风险：
1. 扭亏时点不确定（首要）：质子治疗订单确认慢、原油高位致新材料持续低毛利。
2. 远洋渔业等边缘业务波动。
3. 核技术医疗认证与订单落地不及预期。

结论：暂不介入

理由：中性远期空间仅 +1.2%，当前 PB 1.25x 已反映反转预期，缺乏安全边际；虽呈减亏趋势且现金流转正（亏得起），但扭亏路径尚待质子治疗收入确认或原油回落验证。属"等待拐点"标的。核心跟踪：单季扭亏、质子订单确认、新材料毛利率修复。

亏损股三问

  1. 为什么亏：① 新材料占 83%，国际原油涨价推高原料成本、毛利率降至 10.34%；② 医疗健康（质子治疗）新增订单未确认收入且持续研发投入亏损；③ 远洋渔业受非洲海域安全因素停产 + 燃油涨。属"成本承压 + 投入期"型，非主业崩塌（辐照仍 +18.6% 增长）。
  2. 靠什么扭亏，触发时点：① 原油回落 → 新材料毛利率修复；② 辐照加工持续放量（已 +18.6%）；③ 质子治疗系统订单确认收入（明确扭亏触发点）。中性预计 2027 年扭亏，2029 正常化净利 2.2 亿。
  3. 亏得起吗：经营现金流 2026H1 已转正（+0.64 亿），负债率仅 45.9%，央企背景融资无忧，亏得起，无退市/破产风险。

第五步进阶·上行想象力情景（四类）

  • A 行业调整剩者红利：核技术应用行业集中度提升，公司凭中广核背景 + 自研加速器份额提升（验证点：辐照收入增速；证伪：增速降至个位数）。
  • B 政策反转期权：核技术应用产业规划加码（医用同位素、辐照）提振需求与补贴（验证点：规划文件/补贴；证伪：政策空转）。
  • C 市场错杀修复：若因大盘情绪致 PB 跌至 1.0x 以下而基本面未恶化 → 修复（验证点：估值分位；证伪：亏损扩大）。
  • D 技术突破/代际跃迁：质子治疗系统从 0 到 1 获医院订单并确认收入，打开医疗设备新曲线；硬验证点=客户定点+订单确认+量产交付。未过验证点仅作机会情景（乐观 +128.6%），不计入中性。
  • 上调至纳入观察的条件：质子治疗订单正式确认收入，或单季归母扭亏且新材料毛利率回升至 12%+。
