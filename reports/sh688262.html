（3）产业链传导

上游：晶圆代工（Fabless 模式，无自有产线），成本受代工价格影响；IP 核自研（RISC-V CPU / AI NPU / 安全算法）降低授权依赖。

下游：车企（认证周期长、粘性强）、云服务器/AI 算力、信创/金融 POS。合同负债 11.43 亿 = 已收预付款待交付，订单确定性高。

议价权：中等。车企端因国产替代刚需具备议价空间；定制服务端客户预付款锁定需求；但芯片设计行业竞争激烈，毛利率受代工成本挤压（H1 综合毛利率 29.19%，−7.63pct）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（转嫁系数）：Fabless 模式主要成本为晶圆代工 + 封测，属卖方市场，公司转嫁系数低（≈0.3）；定制服务（AI ASIC）因全栈能力较强，毛利率更高（Q2 回升至 35%+）。验证点：季度毛利率（Q2 35.48% vs H1 29.19%）。
  • 因子2 毛利结构再平衡：分业务毛利率——定制服务（高，随量产爬坡提升）/ 自主芯片（中等）/ IP 授权（极高但体量小）。结构正从低毛利自主芯片向高毛利定制服务迁移（定制占比已超 50%）。禁止用单一综合毛利率：定制放量将抬升整体毛利。
  • 因子3 库存与采购节奏：芯片设计无重库存，以"预付款—交付"为主，合同负债增长即订单先行指标；无原料囤货收益/损失问题。
  • 因子4 政策/市场锚点：① 美国出口管制 → 国产替代加速（利好）；② 代工产能紧张/涨价 → 成本承压（风险）；③ 抗量子密码标准落地 → 新赛道放量（期权）。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：国产嵌入式 CPU/车规 MCU 国产化率低，进口替代空间大；
  • 客户侧：已进入 15+ 头部车企供应链，认证粘性；
  • 技术代际：CCRC4XXX 对标英飞凌 TC4x，具备 AI+抗量子差异化；
  • 成本曲线：RISC-V 自研 IP 降低授权成本；
  • 份额二阶导数：车规/定制均处加速渗透早期。
    → 中性：2029 汽车电子 + 定制服务双位数份额提升；保守守住 / 乐观抢份额。
  • 层2 扩展业务：主业迁移空间：从车规/安全芯片 → AI ASIC 定制（云侧算力），能力同源（CPU+NPU+安全）；新 TAM（AI 算力定制）弹性大；客户认证门槛高。CCRC4XXX 未过车规量产验证点，仅作中期期权。
  • 层3 风险折扣（证伪信号）：合同负债转化不及预期、车规认证延期、定制客户流失、毛利率持续下滑。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：Fabless 轻资产，无破净（PB 4.98x 偏高，反映期权溢价）；无金融资产未重估问题。高 PB 源于市场对标半导体成长股，须以订单转化验证。
  • 校正2 周期位置校正：半导体设计处"国产替代 + AI 定制"上行周期，非周期底部；中性净利以稳态（订单兑现后）计，未用单季好转年化。
  • 校正3 杠杆下行情景：账面现金充裕（经营现金流 +9725 万、合同负债预收款），负债率低；但研发费率 51.73% 若订单断层，费用刚性将致亏损扩大（悲观 −63.8%），故中性空间仅 +0.6%，不得标大空间。
