第一步：公司是干什么的？

一句话定位：国内中空纤维膜技术龙头（曾两获国家技术发明奖二等奖、2024 年获国家科技进步奖一等奖），构建"膜材料—膜组件—膜系统—运营服务"全链条，主攻市政给水/污水资源化、工业水处理及特种分离。

（3）产业链传导

上游：PVDF、聚砜、聚乙烯等高分子原料，2026 年产能充裕、价格低位运行 → 成本端友好，但公司盈利未受益（被售价承压对冲）。

下游：市政（财政资金紧、回款慢）、工业（钢铁/化工/电子等）。下游压价 + 项目制回款慢 → 公司议价权中等偏弱（技术强但客户强势、账期长）。

议价权判断：技术端强（国产替代标杆），商务端弱（买方市场 + 长账期），综合中。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数）
    上游 PVDF 等原料价格低位，公司采购成本走低，转嫁系数概念弱（成本已在低位，无上涨压力转嫁问题）；真正压力在下游售价：膜产品均价受行业竞争压制，公司无法将"技术溢价"完全转嫁给价格敏感的地方水务客户，转嫁系数 ≈0.3（仅高端定制化产品可部分溢价）。

  • 因子2 毛利结构再平衡
    分业务毛利率差异大：膜材料及设备（高，约 30%+）vs 工程/污水处理（低，约 10–15%）。2026H1 营收 +61.85% 主要由低毛利系统集成/工程拉动，高毛利膜产品销售占比相对下降 → 加权毛利率被结构拉低至 22.40%。这是"增量不增利"的结构性原因，而非单一综合毛利率可解释。

  • 因子3 库存与采购节奏
    膜组件可备货，原料低位时适度囤货有收益；但项目制交付使收入确认集中在完工节点，Q2 营收环比 −6.23%、归母 −536.79%，呈"接货/交付节奏"波动，非趋势性。

  • 因子4 政策 / 市场锚点
    政策变量：① 设备更新/节水改造（托底需求，利好）；② 地方财政紧（压制市政项目付款，利空回款）；③ 国产替代（高端膜进口替代空间，利好）。验证点：新签膜材料订单占比、海外订单验收确认；证伪：毛利率连续两季 <20%、应收账款继续恶化。

输出喂第四步：中性情景假设毛利率从 22.4% 修复至 28–30%（高毛利膜产品占比回升），悲观维持 20%。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：中空纤维膜国产替代空间大（复杂工业/纳滤进口替代低），公司技术国内领先，份额有提升空间；
  • 客户侧：已进入南水北调等国家级标杆，品牌强；
  • 技术代际：领先一代（国家科技进步一等奖），份额溢价可期；

  • 验证点：膜材料（非工程）收入占比回升、新签膜组件订单金额；三档：保守守份额 / 中性小幅提升 / 乐观抢高端进口替代。

  • 层2 扩展业务：主业迁移空间
    从"卖产品"迁移到"产品+系统+运营"全链条服务（运营服务毛利高、复购强），属同源能力迁移；但运营项目需大量资金垫资，当前现金承压 → 中期期权，未过"运营收入占比跳升"验证点前不计入中性。

  • 层3 风险折扣：证伪信号
    毛利率持续 <20%、市政回款恶化、海外订单未落地 → 下调中性增量。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非重资产（轻制造+技术），净资产约 5.37 亿（市值/ PB），以技术/商誉为主，无大额固定资产虚高；PB 4.77x 高溢价无盈利支撑，非破净误判，须靠盈利兑现消化。
  • 校正2 周期位置校正：膜行业非强周期，但受地方财政/招标节奏影响呈项目制波动；2026H1 亏损属"收入结构偏差+售价承压"非周期底部，中性净利取稳态（非单年好/坏年），已标注。
  • 校正3 杠杆下行情景：资产负债率未披露但经营现金流 −1546 万、应收账款高 → 若市政回款持续恶化、融资成本上行，净利可转负，中性市值下探至 5 亿（股价 <1.7 元）。
  • 期权纪律：运营服务、出海放量均未过验证点，仅计入乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高/透支。现价 8.49 元对应中性远期仅 4.07 元，PB 4.77x 在亏损且盈利未兑现下偏贵。

安全边际：中性远期 −52.1%，悲观 1.00 元（−88.2%）；下档无盈利安全垫，仅靠技术资产与国资背景支撑。

介入条件：
1. 不追高，等待盈利验证；
2. 关注信号：① 单季扣非转正且毛利率回升至 28%+；② 膜材料（非工程）新签订单金额披露；③ 海外订单确认收入；
3. 价格锚：回落至 4 元以下（市值 <12 亿、反映转型失败底线）才具赔率。

最大风险：① 行业价格战致毛利率破 20%；② 市政/工业回款恶化、现金流断裂；③ 新签订单断档；④ 技术优势无法转化为盈利。

结论：暂不介入（中性远景空间为负、盈利未验证，须等扣非转正与订单兑现）

三问（亏损股）：为什么亏——收入结构偏低毛利工程占比高 + 膜产品售价承压致毛利率同比 −13.17pct，2026H1 由盈转亏；靠什么扭亏——提升高毛利膜材料/设备销售占比、控费、出海突破，触发时点 2027–2028；亏得起吗——国资背景、无大额有息负债、技术资产厚实，短期生存无虞，但经营现金流为负需警惕回款。

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：环保水务出清 + 设备更新，技术龙头（国家奖背书）份额与定价权跳升；验证点=膜材料市占率数据、CR5 提升。
  • 类型B 政策反转期权：设备更新/节水改造专项资金加码、地方化债改善回款；验证点=政策发文+项目付款改善，未过仅机会情景。
  • 类型C 市场错杀修复：若单季扣非转正，当前"亏损"标签证伪，估值重估；验证点=连续两季盈利。
  • 类型D 技术突破/代际跃迁期权：高端纳滤/特种分离膜从 0 到 1 国产替代（突破东丽/旭化成垄断），硬验证点=高端膜批量订单+量产成本优于进口，未达成仅机会情景。

上调至重点关注的条件：连续两季扣非为正 + 膜材料新签年化订单 ≥3 亿 + 毛利率稳定 ≥28%，三者同时满足。
