第一步：公司是干什么的？

一句话定位：重庆起家的化学制剂企业，靠独家品种卡纳琳（纳米炭混悬注射液，国内首个获 CFDA 批准的淋巴示踪剂）守住细分独占地位，同时用"大输液 + 医药流通 + 抗感染"撑住收入规模——本质是一家被集采持续侵蚀毛利、正在靠新品引进和费用压缩找平衡点的转型期药企。

核心产品
- 卡纳琳（纳米炭混悬注射液）：公司自研自产，国内首家获 CFDA 批准的淋巴示踪剂，用于胃癌、乳腺癌、甲状腺癌、结直肠癌、胆管癌、头颈癌等肿瘤手术淋巴清扫，已成为国内甲状腺外科手术的常规一线用药；连续四年获"中国化学制药行业原研药、专利药优秀产品品牌"，曾获制造业单项冠军产品（2019—2021），2025 年入选重庆市首批未来产业标志性产品，2026 年获中国产学研合作促进会科技创新奖三等奖。
- 消化/肠外营养/抗肿瘤普药：艾司奥美拉唑（莱美舒，口服+注射）、雷莫司琼注射液、紫杉醇注射液、培美曲塞、磷酸氟达拉滨、替米沙坦、伏立康唑、甲泼尼龙等。
- 大输液：氨甲环酸氯化钠注射液、乳酸钠林格注射液、丙氨酰谷氨酰胺等。
- 拥有药品生产批文 181 个，国家认定企业技术中心、国家技术创新示范企业。

主要客户/下游：各级公立医院（三级医院为主）、国营/国资及上市大型医药商业公司配送体系；终端覆盖西南、华中、华东等区域。销售团队与大型商业公司合作销往医院终端，集采品种则随国家/省级联盟报量落地。

境内外收入占比：基本纯内需（2026H1 主营地区：西南 1.40 亿占 40.03%、华中 9528.78 万占 27.19%、华东 4217.98 万占 12.04%、其他区域 7269.77 万占 20.74%）。境外收入占比极低——卡纳琳出海尚处探索阶段，且受美国拟对专利及品牌药品加征关税的政策扰动。

股东背景 / 实控人：2020 年中恒集团（600252，广西梧州国资）成为控股股东，2021 年完成定向增发，当前持股约 23.43%。自然人股东邱宇持股 10.48%（截至 2026 年 3 月，其中部分股份处于质押状态，存在被动减持压力）。中恒集团旗下还有梧州制药、双钱产业、田七家化等资产，形成"集团内医药资产协同"的长期想象空间（属远期期权，见第五步）。

供需与竞争格局：
- 卡纳琳所在细分（淋巴示踪剂）为供给垄断格局——国内至今无第二个获批的纳米炭类淋巴示踪剂；替代技术路线为吲哚菁绿（ICG）荧光示踪与亚甲蓝，但各自适用模板不同，未形成直接替代。这是公司唯一确定的护城河。
- 然而 2026H1 特色专科类收入同比 −20.71% ——龙头品类自身在缩量，说明护城河能守住的"价"，守不住"量"（手术端受医保控费/手术量节奏/DRG 影响），这是最需要警惕的信号。
- 大输液、抗感染为完全竞争红海；医药流通为低毛利（28.94%）走量业务，增长快但几乎不贡献利润。

数据缺口声明：淋巴示踪剂细分市场容量、卡纳琳的销量与出厂价、湖南康源产能利用率等关键数据均未公开披露，构成本报告主要不确定源，以下测算相应放宽情景区间。

（3）产业链传导

上游：化学原料药（替米沙坦、伏立康唑、氨曲南、头孢类等）、中药提取/药用辅料、大输液包材（玻瓶/软袋、胶塞）、注射用辅料与溶媒。公司具备部分原料药自产能力（如酮咯酸氨丁三醇原料药已获注册批件、艾司奥美拉唑镁原料药已获批），可对冲部分成本，但整体仍为价格接受者。

下游：等级医院 + 集采报量 + 商业配送。终端支付方为国家医保基金，定价权实质上在医保局而非买卖双方。

议价权判断：弱（集采品种）/ 中等偏强（卡纳琳等独家品种）
- 佐证（弱）：综合毛利率由 2023 年 69.33% → 2024 年 64.39% → 2025 年 55.77% → 2026H1 51.90%，三年累降 17.4pct，为典型的"下游压价 + 上游难压"夹击形态。
- 佐证（独家）：特色专科类仍维持 63.82% 的超高毛利率，远高于其他所有板块，说明独家品种的价格体系未被击穿。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1：成本传导弹性（把议价权量化为转嫁系数）

产品线 价格决定机制 传导系数（p） 上游上涨 Δ 后公司实担
集采中标 / 接续品种（普药、部分大输液） 医保局定中选价，合同期内锁死 p ≈ 0.0–0.2 实担 80–100%，毛利被全额侵蚀
省级联盟中标品种 联盟议价，锁价 1–2 年 p ≈ 0.2–0.3 实担 70–80%
未集采普药 / 抗感染 挂网价联动，红黄标预警 p ≈ 0.3–0.5 实担 50–70%
卡纳琳及特色专科独家品 自主定价 + 学术壁垒 p ≈ 0.7–0.9 实担仅 10–30%，可自主调价维护毛利率
医药流通 进销差价，随行就市 p ≈ 0.9+ 基本完全转嫁（但因量大利薄，绝对利润薄）

依据：一个月度/季度可观测的代理变量是"特色专科毛利率维持在 63%+ vs 流通毛利率恒定在 29%"——两者的巨大且稳定的利差，就是传导系数差异的直接证据。验证点：后续是公司是否有提价/调挂网价公告、是否有新品纳入机制的公告。证伪信号：若特色专科毛利率跌破 58%，说明独家壁垒已被瓦解（替代技术或竞争批文出现）。

因子2：毛利结构再平衡——拆线条看，别用单一综合毛利率

业务线 占营收比重（2026H1） 毛利率 对整体毛利贡献占比（估） 原料敏感权重（估）
特色专科 32.64% 63.82% 约 40% 中（主要是 API 与辅料，但高价免疫API侵蚀）

结构性结论（关键）：收入权重正从"高毛利特色专科（−20.71%）"向"低毛利医药流通（+22.88%）"迁移。每 1 个百分点收入结构由特色专科转向流通，综合毛利率下降约 0.35pct。若该迁移按 2026H1 的速度再持续两年（结构移动约 10pct），仅此一项就带来约 −3.5pct 的综合毛利率拖累，即便各产品线自身毛利率不变。这是隐藏在"综合毛利率 −3.73pct"之下的真实结构恶化，也是本报告对盈利修复持保守态度的核心依据之一。

因子3：库存与采购节奏（timing）
- 2026H1 末存货账面价值 1.775 亿（占净资产 10.26%，较上年末 +1619.94 万），存货跌价准备 420.86 万，计提比例 2.32%（偏低）。
- 存货周转率 0.53 次（半年口径）、应收账款周转率 0.78 次（半年口径）——周转偏慢，产成品与渠道库存的消化节奏慢于 productions。
- 不存在明显的"低价囤货收益"：公司原料多为通用 API 与包材，无大宗囤积动机；H1 经营现金流改善主要来自应收票据及应收账款较上年末 −17.79%（回款），而非库存收益。
- Timing 判断：2026H1 的现金流改善是营运资本释放（应收 −17.79%），而非盈利质量改善（扣非仍 −2577.49 万）。不能把"回款带来的现金流入"当成扭亏能力——营运资本释放是一次性的，不可重复。
- 验证点：后续季度应收账款是否继续下降、经营现金流与扣非净利的差额是否收敛。

第四步进阶：重资产 / 周期 / 杠杆估值校正（三道闸）

校正1：资产质量折扣——本次为"高 PB"而非"破净"，更需要说明原因
- 公司并未破净（PB 3.15x，属于高位），因此不存在"破净陷阱"问题；反向地，必须说明这个 PB 为何成立。
- 净资产 17.5 亿中，货币资金 10.85 亿（占 62%）、固定资产 2.40 亿（13.7%）、无形资产 1.298 亿（7.4%）、长期股权投资约数亿——资产结构偏"类现金"，盈利性资产（生产+研发）仅占约 1/3。
- 含义：①这类资产没有重置价值兜底逻辑，也谈不上"清算价值远低于账面"（现金清算几乎无折价），因此下行有底（边界约 PB 1.2–1.5x）；②但同时，62% 的资产不产生经营利润，意味着整个 17.5 亿净资产对应的盈利能力极弱，扣非 ROE 长期为负，PB 3.15x 缺乏盈利支撑。
- 结论：不是"估值陷阱式破净"，而是"类现金资产被按成长股定价"，属于估值锚偏高而非偏低。 禁止反过来用"现金多"作为看多理由——现金只托底，不创造价值。

校正2：周期 / 经营位置校正
- 公司当前位置：长周期亏损的底部修复段（2023 −0.089 亿 → 2024 −0.878 亿 → 2025 −1.347 亿 → 2026H1 −0.234 亿）。
- 严禁把"2026H1 减亏 25.37%"直接年化为稳态扭亏——因为 2025 年的巨额亏损中明确包含两项一次性因素（据公司业绩预告）：无形资产减值准备约 6000 万元、联营企业投资损失约 2300 万元；剔除后 2025 的经营性亏损约 −0.52 亿，而 2026 年化后也约 −0.10 亿——真实改善幅度远小于表观 1.1 亿的减亏。
- 中性净利 0.75 亿的取值已剔除上述一次性因素，且低于 2029E 乐观线——因为它建立在"费用率降至 41%"的强假设上，本报告已对该假设做了折扣。

校正3：杠杆下行情景（本题负债率不高，但仍给出下行抵扣）
- 资产负债率 35.96%（明显低于 60% 警戒线），有息资产负债率 18.04%，流动比率 1.99、速动比率 1.78——不存在偿债风险，"亏得起"的结论成立。
- 但负债结构发生两处需跟踪的变化：2026H1 短期借款较上年末 +69.6%、长期借款 +84.99%（筹资活动现金流净额 +1.45 亿）。这说明公司在盈利未恢复时开始加杠杆补流。负面情景：若 2027 年仍未扭亏且利率上行 1pct，新增有息负债约 7 亿 → 年增利息约 700 万 → 直接吃掉相当于当年的全部预期利润。
- 亏得起吗？（三问之三）：货币资金 10.85 亿 + 经营现金流已转正 + 资产负债率仅 36% + 国资大股东支持 → 按当前 0.2–0.3 亿/年的亏损速度，可支撑 10 年以上；即便悲观情景下 −0.2 亿/年，亦可无限期存续。结论：亏得起，不存在"倒在黎明前"风险——这是本标的唯一确定的正面属性。

问 答
1. 为什么亏？ 三层叠加：①集采与价格治理使占收入大头的仿制药持续降价，综合毛利率从 69.33%（2023）一路降至 51.90%（2026H1）；②费用结构刚性——收入规模从 8.96 亿萎缩到 7.2 亿，而期间费用长期维持 52%+ 的费用率，毛利被费用全额吃掉；③一次性因素：2025 年计提无形资产减值约 6000 万 + 联营企业投资损失约 2300 万，占了当年 1.35 亿亏损的 62%。不是主业崩塌，是"毛利被政策压、费用没跟上压缩"的结构性亏损。
2. 靠什么扭亏？触发时点？ 三条路径：路径 A（已启动，确定性高）——压缩费用，2026H1 期间费用同比 −4492.72 万，费用率降 8.16pct；路径 B（进行中，确定性中）——新品获批放量（醋酸曲普瑞林、吸入乙酰半胱氨酸、酮咯酸氨丁三醇、氨曲南、乳酸钠林格等，合计潜在 1.5–2.0 亿/年）；路径 C（远期，确定性低）——纳米炭铁等创新管线 / 卡纳琳出海 / 中恒资产整合。触发时点：2026 年报大概率落在准盈亏平衡（−0.10~+0.10 亿）；真实正的利润要到 2027 年（预计 0.15–0.30 亿），稳定盈利需到 2028–2029 年。
3. 亏得起吗？ 亏得起。货币资金 10.85 亿、经营现金流 2026H1 转正 +2381.89 万、资产负债率仅 35.96%、有息负债率 18.04%、国资大股东背书。按当前亏损速度静态可支撑十年以上。无生存风险，主要风险是估值风险而非信用风险。

第五步：综合赔率判断（买不买？）

当前价格位置：明显偏贵。
- PB 3.15x，对应扣非 ROE 长期为负、2029E 中性 ROE 也仅约 4%——A 股给 4% ROE 的公司 3.15x PB 缺乏盈利支撑。
- PS（2026E）7.6x，对比同类负增长仿制药企业，属于高位。
- 2029E 中性目标 2.90 元 vs 现价 5.16 元，需 −43.8% 才回到合理锚；而 2026 年底基准目标 4.50 元也低于现价 12.8%。
- 唯一托底逻辑是"净现金 5.6 亿 + 卡纳琳独占 + 181 个批文"，但这些支撑的是下限（PB 1.2–1.5x ≈ 2.0–2.5 元），不是上限。

安全边际：不存在。中性情景空间为负，赔率结构不对称偏下行。

介入条件（具体到价格）
1. 价格条件：跌至 2.60 元以下（对应 PB ≈ 1.55x、接近"现金 + 净资产"底），此时下行由类现金资产承接、上行由扭亏弹性提供，才形成安全边际。
2. 基本面条件（比价格更重要）：连续两个季度"特色专科类"收入同比转正——这是唯一能证明 S 曲线未死、护城河仍在兑现的硬指标。
3. 加仓条件：① 2026 年报确认归母净利转正或接近转正且剔一次性因素后仍是如此；② 醋酸曲普瑞林/吸入乙酰半胱氨酸等新品的挂网省份数与入院家数披露并超预期；③ 纳米炭铁读出 II 期数据；④ 中恒集团体系内出现明确的资产整合公告。

最大风险（最可能破坏逻辑的因素）
1. ⚠️ 特色专科（卡纳琳）持续缩量——首要风险。 2026H1 该板块 −20.71%，若护城河只能守"价"不能守"量"，则公司从"有独占品种的药企"退化为"普通仿制药厂"，估值体系应整体从 PB 3x 降到 PB 1.2–1.5x。
2. 费用压缩红利是一次性的：2026H1 的销售费用 −22.3%、研发费用 −19.71%，短期利好报表，长期削弱产品竞争力。若费用率无法继续下行而收入仍不增，扭亏就在 2027 年见顶。
3. 经营现金流改善的质量存疑：主要来自应收账款 −17.79% 的一次性营运资本释放，非盈利质量改善（扣非仍亏损）。
4. 一次性因素可能重演：2025 年 6000 万无形资产减值、2300 万投资损失；账上仍有 1.30 亿无形资产 + 4495 万商誉，后续仍有减值可能。
5. 存货周转慢（0.53 次）+ 存货跌价准备仅 2.32%：近效期药品风险计提不足。

上调至"重点关注"的明确条件（防为看涨找理由）：必须同时满足 ——（1）股价回落至 3.2 元以下；（2）特色专科类收入连续两个季度同比转正；（3）纳米炭铁或卡纳琳出海至少命中一个硬验证点。三者缺一，不得上调。

结论：暂不介入

理由：中性远期目标 2.90 元，空间 −43.8%，远不满足"重点关注 >+50%"或"纳入观察 >0"的门槛。
公司不是没有救（扭亏路径清晰、现金充裕、不存在生存风险、品种批文丰富），但当前价格已经把 2029 年之后的稳态盈利 + 全部创新管线 + 中恒资产整合预期全部提前定价。属于典型的"好故事 + 贵价格"。
真正的机会在于：①等待价格向 PB 1.5x 附近回归；②等待"特色专科收入转正"这一唯一硬信号。二者出现其一即可重新评估，二者同时出现则直接上调至"重点关注"。
核心跟踪指标（每季度必看）：特色专科类收入同比、综合毛利率是否守住 48%、销售费用率能否继续下行、经营现金流是否由回款而非盈利驱动。
