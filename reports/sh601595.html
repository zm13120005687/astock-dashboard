第一步：公司是干什么的？

一句话定位：上海国资委旗下的"院线 + 内容 IP"双平台——运营全国第四的联和院线、直营 SFC 影城，并依托上影元（美影厂 IP）做 IP 授权商业化与 AI/XR 内容，逐步从"放映商"向"IP 运营商"转型。

（3）产业链传导

上游：内容制作/采购成本（分账给制片方约 43–52%），公司处下游放映+发行，成本端为分账与租金。

下游：观众注意力被短视频/短剧分流，单场产出下行；IP 授权下游为品牌方，需求稳。

议价权：中弱（放映）/ 中上（IP）。放映端同质化、对制片方分账被动；上影元经典 IP 具独占性、授权议价中上。

第二步进阶：成本 → 毛利结构四因子（影视适配）

  • 因子1 成本传导弹性：放映端分账比例固定（制片方拿走约一半票房），公司传导率≈0.3（租金/固定成本刚性，票房波动自己扛）；IP 授权传导率≈0.9（品牌方买单、顺价强）。
  • 因子2 毛利结构再平衡：放映毛利率低（H1 综合 21.43%，放映更薄）、IP 授权毛利率高（30%+）。估值须分"放映低毛利 + IP 高毛利 + 投资公允价值"三线，禁单一综合毛利率。2026H1 利润主要靠公允价值变动（股权增值）撑，主业扣非已亏。
  • 因子3 库存与采购节奏：影片内容无实物库存，但"档期 timing"决定收入（春节档/暑期档集中）；内容储备与排片节奏影响当期。
  • 因子4 政策/市场锚点：政策变量为"促消费/票根经济/文旅融合"（正向）；市场变量为"爆款供给"（决定票房总量）。验证点：单季票房、IP 授权 GMV、公允价值变动持续性。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 现有业务：院线份额变量——联和院线全国第四，市占率微升。①供给侧——放映端过剩、份额靠运营；②客户份额——加盟影院粘性；③技术代际——AI 排片/数字化领先；④成本曲线——直营影城固定成本高。三档：保守份额持平、中性微升、乐观并购扩份额。
  • 层2 扩展业务（主业迁移）：从"放映商"向"IP 运营商"迁移（新易盛范式）。能力可迁移（自有美影厂 IP）、新 TAM（授权+文旅+消费品远大于放映）、切入早（IP 商业化已跑通 GMV 9.5 亿）。中期期权，部分已验证（GMV 落地），可计入中性小比例。
  • 层3 风险折扣（证伪）：爆款断档致票房再降、IP 授权续约不及预期、投资标的股价下跌（公允价值回撤）。命中则下调。

第五步：综合赔率判断（买不买？）

当前价格位置：明显偏贵。现价 23.53 元隐含 2029E 中性 64x PE，已透支 IP 与 AI 全部预期。

安全边际：中性远期 14.8 元 → 空间 −37.1%；悲观 5.5 元（−76.6%）；乐观 28.3 元（+20.3%）需爆款+IP 双兑现。风险收益严重不对称。

介入条件：回落至 14 元以下（对应 2029E 中性 40x 以内）方具配置价值；加仓信号：①单季票房恢复至同比正增；②IP 授权 GMV 连续两季 >30% 增长；③投资收益标的（极视角等）业绩兑现。

最大风险：①行业票房持续"场增票减"、缺爆款；②扣非主业亏损扩大；③投资标的股价波动致公允价值回撤（2026H1 利润主要依赖此）；④短视频/短剧持续分流。

结论：暂不介入（估值过高、主业盈利弱、安全边际为负）

公司具稀缺 IP 与国企平台价值，IP 商业化与 AI/XR 是真实期权，但当前价格已充分甚至过度定价，中性空间 −37%，按规则判"暂不介入"，继续跟踪 IP GMV 与票房复苏。

第五步进阶：上行想象力四类情景（仅进机会栏）

  • 类型A 行业调整剩者红利：放映端过剩出清后，头部院线（联和全国第四）份额提升。验证点：市占率、单场产出。
  • 类型B 政策反转期权：促消费/票根经济加码、影视内容审核边际放松，票房修复。验证点：政策发文、单季票房转正。
  • 类型C 市场错杀修复：若随大盘风格切换跌至 14 元以下（PE<40x），修复弹性大。验证点：估值分位。
  • 类型D 技术突破/代际跃迁：AI 生成内容（AIGC）降本+XR 沉浸式新体验若成规模变现，打开新曲线（公司已有《童梦护卫队》AIGC、《大闹天宫》XR）。验证点：XR 项目复制数量、AIGC 内容商业化收入。三要素部分共振但缺"客户定点"硬验证，仅作机会情景。

    上调至"重点关注"的条件：现价回落至 14 元以下，且 IP 授权 GMV 连续高增使 2029E 净利上修至 3 亿+。
