第一步：公司是干什么的？

一句话定位：由烟标印刷转型而来的新型储能科技企业，主打"储能消防 + 储能系统 + 超级电容"差异化路线，当前储能消防为绝对主业。

核心产品/技术：
- 储能消防：并购千页科技后形成"预警—探测—灭火—防复燃"全流程闭环，PACK/簇/舱三级纵深防护。
- 超级电容："料—材—器—用"一体化布局，自主研发活性炭电极材料，量产单体内阻低至 0.18mΩ，循环寿命破百万次，已建成 60 万支中试线、300 万支全自动产线（2026-10 投产）。
- 复合储能："超级电容 + 锂电池"复合式储能系统，自研"功率—时间"二维解耦算法。
- 独立储能电站：广东 200MW/400MWh 项目（拟投资约 5 亿）。

主要客户/下游：发电侧（电网调频、AGC）、电网侧、工商业储能、风电变桨、电梯节能、数据中心备电等。

发展脉络：1996 汕头起家（烟标印刷）→2019 深交所上市→2021 成立金时新能进军新能源→2023 并购千页科技补储能消防→2024 储能系统产线落地→2025 布局复合储能→2026-05 摘帽、8 月获"中国储能产业卓越创新企业奖"。

第二步：行业景气度 + 政策/市场数据

（1）政策端（近 6–12 个月）——强利好，储能战略地位升级

政策 发布主体 力度 落地节奏
2026 年《政府工作报告》"发展新型储能、加快智能电网建设" 国务院 国家级，储能从"可选配建"升级为"能源安全刚需" 已定调
《新型储能规模化建设专项行动方案（2025—2027年）》 发改委、能源局 国家级专项，到 2027 年新型储能装机 1.8 亿千瓦以上、带动直接投资约 2500 亿 推进中
多省储能消防审验/监管新规（贵州、青海、广东等） 地方住建/能源部门 地方级，储能电站纳入消防审验与高危监管 2026 年密集落地

关键量化：截至 2025 年底全国新型储能装机 136GW/351GWh（+84%）；储能消防安全从"被动灭火"转向"主动防御"；消防行业市场规模预计 2026 年达 1.31 万亿元（CAGR 4.8%），储能安全为重要增长驱动。

（2）市场端（量价数据）

  • 储能行业结构性分化：强制配储政策退出、容量电价机制落地，行业由"政策驱动"转向"市场驱动"，呈现"总量过剩 + 高端产能不足"的结构性分化，低端市场价格战激烈。
  • 储能消防需求：随储能电站规模化建设，消防安全监管加码，储能消防成确定性赛道；公司储能消防收入 2026H1 同比 +42.44%。
  • 公司量价（2026H1）：营收 0.87 亿（−64.13%，主因储能设备收入从 1.84 亿骤降至 233 万）；归母净利 −497.46 万（减亏 76.73%）；扣非 −3817.76 万（亏损扩大 82.12%）；经营现金流 −6085 万。

（3）产业链传导（原料成本 → 毛利结构，四因子）

  • 因子1 成本传导弹性：储能消防上游为传感器、灭火介质、结构件，成本可控；超级电容上游核心材料（活性炭）公司自研，传导率较低。但公司当前规模小、议价权弱，成本转嫁能力有限。
  • 因子2 毛利结构再平衡：储能消防毛利率 23.01%（+6.27pct）明显高于储能设备（历史毛利较低），2026H1 收入结构向储能消防集中，综合毛利率从 9.65%（2025H1）升至 21.87%——这是结构切换的结果，而非全业务盈利能力提升。储能设备（系统集成）毛利率受价格战压制，是公司主动收缩的业务。
  • 因子3 库存与采购节奏：储能设备销售骤降致营业成本同比下降 68.92%，存货周转率仅 0.16 次（半年），存货与产能利用率极低，存在资产减值风险。
  • 因子4 政策/市场锚点：
  • 市场层：储能价格战、容量电价机制落地节奏、电网调频/数据中心配储需求。
  • 政策层：储能消防新规密集落地（贵州审验、青海高危监管、广东高层消防新规）→ 直接扩大储能消防 TAM。
  • 验证点：储能消防新签订单、超级电容产线投产放量、独立储能电站并网运营。
  • 证伪信号：储能消防收入增速回落、超级电容客户定点/大额订单缺失、储能电站项目停滞。

第三步：确定性增量量化（自下而上清单）

层1 现有业务：市场容量 × 份额变量

  • 储能消防：赛道随储能装机 + 消防监管加码扩张，公司为细分参与者（并购千页科技获消防资质）。
  • 保守：储能消防收入增速回落至 20%（2026 全年约 1.7 亿）
  • 中性：储能消防维持 35% 增长（2029 年约 3.5 亿）
  • 乐观：储能消防爆发 + 出海（东南亚/中东），2029 年约 5 亿

层2 扩展业务：主业迁移空间（超级电容 + 储能系统 + 独立储能电站）

  • 超级电容（技术迁移核心）：300 万支产线 2026-10 投产，目标电网调频、风电变桨、数据中心备电等高功率场景。能力可迁移（材料自研 → 器件 → 系统）、新 TAM 弹性大（超级电容在电网调频渗透提升），但尚处于投产初期，未获大额订单/客户定点验证，属中期期权，不计入中性净利。
  • 独立储能电站：广东 200MW/400MWh 项目拟投 5 亿，从"设备商"转向"设备+运营"双轮，电站建成后贡献稳定运营收益，但需 2027 年后才并网，为远期期权。

层3 风险折扣：证伪信号

  • 超级电容产线投产延期/良率不达标、储能消防新签订单萎缩、储能设备业务持续收缩至零、应收账款回款恶化。

第四步：估值锚定（自下而上，非增速外推）

方法说明：亏损股，用正常化净利润法（稳态营收 × 正常化净利率 × 远期 PE），不用增速外推。总股本约 4.031 亿股。

亏损三问

  1. 为什么亏：① 2025 年巨亏 2.38 亿主因历史包袱（烟标业务剥离、商誉/资产减值）；② 2026H1 扣非亏损 3818 万是主业规模不足 + 费用刚性（储能设备收入骤降，但销售费用 +34.96%、管理费用 +34.46%、研发 +34.42% 逆势扩张），营收仅 0.87 亿撑不住 0.55 亿期间费用 + 高研发投入。
  2. 靠什么扭亏 + 时点：靠储能消防放量 + 超级电容投产 + 独立储能电站运营三重驱动。储能消防需做到年收入 3 亿+ 才能覆盖费用刚性；乐观 2027 年主业盈亏平衡、2028–2029 年正常化盈利。
  3. 亏得起吗：亏得起。总资产 20.16 亿、资产负债率仅 21.63%（2026H1 末 23.03%），有息负债率 16.12%，账面金融资产充裕（2026H1 靠公允价值变动 + 出售股票获非经常性损益 3320 万），现金流虽为负但融资能力尚可，足以撑到扭亏。

⚠️ 交叉校验：现价 15.61 元对应总市值 62.92 亿，而 2026H1 营收仅 0.87 亿、扣非亏损 3818 万。即便按乐观情景 2029 年正常化净利 1.30 亿 × 32x = 41.6 亿，仍低于现价市值。现价已把储能转型的全部想象力 + 超级电容技术期权 + 摘帽情绪全部提前定价，远超任何可合理测算的正常化价值。

第五步：综合赔率判断（买不买？）

当前价格位置：严重高估。PB 4.18x、市值 62.92 亿对应 2026H1 营收 0.87 亿，市销率（年化）超过 35x。当前盈利全靠"炒股"（非经常性损益 3320 万），主业仍在失血。

安全边际：
- 中性远期目标 3.5 元 → 空间 −77.6%，安全边际严重为负
- 悲观 0.7 元 → 下行 −95.5%
- 乐观 10.3 元 → 仍 −34.0%，即便最乐观情景也不及现价
- 下行保护：每股净资产约 3.78 元（2025 年末）、PB 4.18x 处历史高位，一旦转型叙事证伪，估值向净资产回归的下跌空间巨大

介入条件：
1. 现价坚决不参与。等跌至 5 元以下（PB 回归 1.3x 附近，市值约 20 亿）才有博弈价值
2. 加仓信号（缺一不可）：① 超级电容 300 万支产线如期投产且获大额客户定点/订单；② 储能消防年收入突破 3 亿且毛利率稳于 23%+；③ 独立储能电站并网运营并产生稳定现金流
3. 观察指标：扣非净利能否转正（当前 −3818 万是真实主业亏损），储能消防订单能见度

最大风险（最可能破坏逻辑的因素）：
1. 主业持续失血：储能设备收入已近归零，储能消防体量太小（半年 0.83 亿），若新业务不达预期，公司长期亏损
2. 超级电容/储能电站证伪：技术投产延期、无客户定点、电站回报不及预期，转型叙事破灭
3. 估值回归风险：PB 4.18x 高位，一旦情绪退潮，估值向净资产（约 3.78 元）回归
4. 费用刚性：销售/管理/研发费用逆势扩张，吞噬本就微薄的毛利

上行想象力情景（只进乐观栏，不进中性锚）：
- 类型D 技术突破期权：超级电容"料—材—器—用"全链路自研 + 复合储能技术，若产线量产良率达标 + 获电网调频/数据中心大额订单，可从 0 到 1 打开超级电容新曲线。硬验证点：量产良率达标、客户定点/大额订单、成本优于现有方案——三者缺一仅作机会情景。
- 类型A 剩者红利：储能价格战出清低端产能后，具备消防闭环 + 技术壁垒的差异化企业（金时）份额跳升。验证点：行业出清、公司储能消防份额提升。

结论：暂不介入

理由：未命中"坚决回避"的排除标准（储能消防业务真实存在且 +42% 增长、超级电容有技术奖项背书、账上现金充裕亏得起），故不作回避。但现价 62.92 亿市值对应半年 0.87 亿营收、扣非亏损 3818 万，PB 4.18x，估值已把转型想象力提前透支殆尽。即便最乐观情景（2029 年正常化净利 1.3 亿）也仅值 10.3 元、仍低于现价。这是一只"故事已讲满、业绩远未到"的高风险转型股，必须等主业（储能消防 + 超级电容）真正落地、股价大幅回归后才值得重新评估。
