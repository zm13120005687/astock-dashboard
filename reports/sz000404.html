（3）产业链传导

上游：钢材、铜、铝、稀土磁材（电机）。铜/钢价波动影响成本；公司通过套保/长协对冲部分。

下游：冰箱冷柜整机厂（强议价，年降定价）；新能源车厂。出口受巴西反倾销调查（占 2025 营收 1.8%）。

议价权：全球销量第一具备规模与技术溢价，但下游整机厂强势 → 中等（靠规模与变频升级维持）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：铜/钢涨 → 通过套保 + 部分调价转嫁（传导率约 0.5–0.7）；整机厂年降削弱。验证点：毛利率（H1 14.33% +1.64pct，费用管控为主）；证伪：铜价大涨毛利率破 13%。
  • 因子2 毛利结构再平衡：活塞压缩机（14.77%）> 新能源压缩机（10.92%）> 配件（10.36%）。变频/商用（高毛利）占比提升可抬升结构；新能源压缩机短期毛利低。
  • 因子3 库存与采购节奏：套保对冲铜价；巴西反倾销（3190 万美元，占营收 1.8%）为局部风险。H1 毛利改善含费用压缩（销售 -35.7%、管理 -25.6%）。
  • 因子4 政策/市场锚点：铜价（市场层）、新能效标准（政策层，倒逼变频升级）。情景：新能效推升变频占比 → 结构升级；出口壁垒加剧 → 量增额降。验证点：铜价、变频渗透率、出口单价。

输出喂第四步：中性净利率取 4.5%（价格战 + 费用压降平衡）。

第三步进阶：份额变量与主业迁移空间

  • 层1 份额变量：全球销量第一（供给侧锚点）、配套头部品牌（客户份额粘性）、变频技术（代际差）、成本曲线左移（规模）。中性：守住全球第一；乐观：高端变频抢份额。验证点：全球销量排名、变频销量。
  • 层2 主业迁移：新能源空调压缩机（主业迁移至车热管理），新 TAM 弹性有限、短期量降价。未过验证点不计入中性。
  • 层3 证伪信号：价格战致毛利率破 13%、份额流失、出口壁垒扩大（巴西之外）。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。PE 9.78x 为成熟制造低估区间，全球龙头地位提供安全垫。

安全边际：
- 中性远期 8.91 元 → +29.9%（>0，<50%）
- 悲观 5.75 元 → −16.2%
- 乐观 14.08 元 → +105.2%（高端化 + 出口）
- PB 1.11x、低负债（2025 资产负债率 61.26%，有息负债率 19.85%）提供缓冲

介入条件：
1. 现价已合理，回落至 6.2 元以下（PE < 9x）更具安全边际
2. 加仓：变频销量占比跳升、出口单价回升、巴西反倾销缓和
3. 观察：毛利率能否守 14%+、商用/新能源压缩机放量

最大风险：
1. 行业产能过剩 + 价格战致毛利破 13%（首要）
2. 出口贸易壁垒（巴西反倾销扩围）
3. 新能源车压缩机拓展不及预期

结论：纳入观察（全球龙头 + 低估值，但价格战压制空间，<50%）

第五步进阶：上行想象力四类情景

  • A 行业调整剩者红利：产业准入细则淘汰 11 家低端企业 → 龙头份额与定价权提升。验证点：行业集中度、公司销量份额；触发上调重点关注：份额连续提升且毛利率破 15%。
  • B 政策反转期权：新能效标准（2026-06 实施）强制变频升级 → 结构性量价齐升。验证点：变频渗透率、一级能效产品占比。
  • C 市场错杀修复：价格战恐慌致低 PE，若出口单价回升则修复。验证点：出口金额增速转正。
  • D 技术突破期权：双转子变频/磁悬浮量产降本、新能源压缩机突破头部车企定点。硬验证点：大客户定点/量产成本优于旧线；未过验证点仅作机会情景。
