第二步：行业景气度 + 政策/市场数据

（1）政策端（近 6–12 个月）——中长期利好，但短期财政约束压制需求

  • 《美丽中国建设"十五五"规划》（国务院，2026-07）：生态环境领域首部以"美丽中国"命名的五年规划，设 9 项约束性指标、7 方面任务、20 项重大工程；明确提升监测现代化水平、推进监测网络数智化转型（天空地海一体化）、健全绿色低碳发展政策体系。
  • 生态环境监测数智化：生态环境部解读强调 AI / 大数据 / 物联网与治理融合，强化监测仪器装备自主可控——直接利好智慧环保 / 碳监测。
  • 双碳：2026 政府工作报告首提"设立国家低碳转型基金""实施碳排放双控制度""扩大碳市场覆盖"；深圳等地方生态环境专项资金（2026 年度）支持温室气体在线监测、碳金融等。
  • 财政约束（负面）：地方财政紧平衡、主要客户预算投入审慎，是压制公司短期需求的核心变量。

（3）产业链传导

  • 上游：传感器、物联网模组、云资源，标准化采购，对芯片 / 模组价格敏感（弱议价权）。
  • 下游：政府 / 国企甲方，账期长、回款受财政约束——2026H1 经营现金流 −569 万（较上年 −3188 万收窄 82%），"账面亏损但主业告别失血"。
  • 议价权：弱（乙方、政府甲方、行业低价竞争）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（≈0.15）：以软件 + 物联网集成为主，硬件（传感器 / 模组）涨价自担；政府项目固定总价，转嫁系数低。
  • 因子2 毛利结构再平衡：三业务毛利率分化显著——智慧双碳 56% > 智慧城市 38.4% > 智慧环保 17.2%。公司主动放弃低毛利环保订单，结构性向高毛利双碳 / 智慧城市迁移，是毛利率由 7.83% 跳升至 23.49% 的主因（非单一综合毛利率可掩盖）。
  • 因子3 库存与采购节奏：无大宗库存，以项目制备货；不存在囤货收益，反而因项目垫资产生现金流压力。H1 经营现金 −569 万已大幅收窄，但仍是净流出。
  • 因子4 政策 / 市场锚点：传感器 / 芯片进口替代与价格（关税、出口管制）是成本变量；碳监测设备财政补贴（如深圳专项资金）是直接需求催化。情景：若地方财政回暖 → 双碳 / 监测订单放量；证伪：财政持续紧 → 营收继续下滑。验证点：单季新签合同、专项债环保投向、碳监测招标。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务·市场容量 × 份额变量：环保物联网赛道分散，公司华北区域型；技术代际无显著领先。五锚点：供给侧无产能约束；客户份额集中政府、区域性强；技术代际跟随；成本曲线无优势；份额加速度弱。三档：保守营收 1.8 亿、中性 2.3 亿、乐观 3.0 亿。验证点：单季新签、区域外拓展。
  • 层2 扩展业务·主业迁移（双碳 / 智慧城市）：由"环保监测"向"双碳"迁移，能力可复用（物联网 + 数据），新 TAM（碳市场）更大；但认证门槛（政府 / 国企准入）高，未过验证点（无大额订单公告），仅作中期期权。
  • 层3 证伪信号：营收连续下滑跌破 1 亿 + 仍亏损 → 触发科创板营收利润组合退市风险警示（2025 营收 2.07 亿尚未触线，但安全边际薄）。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非重资产，PB 3.42x（净资产 5.42 亿），无破净，但净资产含较多应收与商誉，质量一般。
  • 校正2 周期位置校正：非强周期，不适用周期归一化。
  • 校正3 杠杆下行情景：资产负债率约 37%（总资产 8.62 亿、净资产 5.42 亿），杠杆不高；但最大下行风险是退市指标——若营收跌破 1 亿且持续亏损，将触发财务类退市风险警示，空间转负，不得标大空间。

亏损股三问

  1. 为什么亏：行业低价竞争 + 主要客户（政府 / 国企）财政资金紧张、预算审慎导致需求偏弱（营收 −24%）；同时研发投入 2534 万（资本化率 0，全额费用化）短期放大亏损；属"行业周期 + 战略出清"叠加，非主业崩坏。
  2. 靠什么扭亏，触发时点：① 毛利率已修复至 23.49%（结构向高毛利双碳 / 智慧城市迁移）；② 经营现金 −569 万大幅收窄，主业接近现金盈亏平衡；③ 若营收止跌回升 + 费用管控持续，2027 年有望扭亏为盈（中性假设）。
  3. 亏得起吗：总资产 8.62 亿、净资产 5.42 亿、账面现金较充裕（经营现金流出已显著收窄），短期不至资金链断裂；但连续多年亏损，若营收持续下滑触发退市指标则为首要风险。

第五步：综合赔率判断（买不买？）

当前价格位置：高估 + 高不确定性。现价 23.97 元对应中性正常化净利 80 倍 PE，且 2026 仍真实亏损。
安全边际：中性远期 8.92 元 → −62.8%；悲观 2.59 元 → −89.2%。仅乐观（20.37 元）仍低于现价。下行保护弱：PB 3.42x、连续亏损、退市指标风险。
介入条件：① 回落至 9 元以下（接近中性目标价）且出现营收止跌信号；② 加仓信号：单季营收同比转正、新签双碳 / 智慧城市大单（≥3000 万）、经营现金流转正；③ 观察：营收是否守住 1 亿红线。
最大风险：① 营收持续下滑触发科创板财务类退市风险警示；② 政府财政持续紧导致回款与订单双杀；③ 高估值 + 亏损的戴维斯双杀。
结论：暂不介入（估值高、实质亏损、退市指标风险；虽有毛利率 / 现金流拐点，但需先验证营收止跌，不足以构成买点）。
