新亚制程（002388）五步法分析报告

分析日期：2026-09-29 ｜ 现价 8.27 元（2026-09-29 收盘） ｜ 总市值 41.86 亿 ｜ PE(TTM) 负值（微亏） ｜ PB 4.44x ｜ 总股本 5.06 亿股
行业：电子 / 化工材料（电子制程服务 + 工业胶粘剂 + 锂电材料）｜ 板块：深市主板
数据校正：队列标"电子器件、TTM 亏损 PE −78.48、现价 6.28"——真实主业为电子制程方案服务 + 化工胶粘剂 + 锂离子电池材料；2026H1 真实归母净利 −1171 万（微亏），但扣非 +219 万已扭亏为盈，亏损主因为诉讼计提 + 汇兑非经常性。按亏损股规则做完整五步法 + 正常化净利润法 + 三问。

第一步：公司是干什么的？

一句话定位：电子制程综合服务商 + 工业胶粘剂高毛利制造商 + 锂电材料（六氟磷酸锂 / 电解液）参投者，三大业务协同的"新材料解决方案提供商"。

核心产品：① 电子制程设备 / 仪器 / 元器件一站式供应；② 工业胶粘剂（环氧胶、有机硅胶、丙烯酸胶，毛利率 45.91%）；③ 六氟磷酸锂、电解液（控股 51% 衢州杉杉）。
主要客户 / 下游：华为（胶粘剂第一大客户，营收占比 35.5%）、小米、OPPO、大疆（消费电子）；光宝、中达电子（AI 服务器电源，环氧胶 / 灌封胶切入）；比亚迪（动力电池 PACK 密封胶）。

股东背景：民营（原为王伟华等实控，2026-06 董事长离任）；2022 末新亚投资取得衢州杉杉 51% 股权布局锂电。

（1）政策端（近 6–12 个月）—— AI 算力 + 新能源双驱动

关键量化：2026H1 中国锂电池出货约 1.2TWh（+50%），电解液出货 142 万吨（+63%）；六氟磷酸锂价格上半年冲高至 16.5 万后回落至 9.5–10.5 万 / 吨。

（2）市场端（量价数据）

  • 电子胶粘剂：AI 服务器电源厂订单同比 +50% 以上，华为产业链稳定。
  • 锂电材料：六氟价格上半年冲高回落（半年跌 >40%），行业竞争白热化（多氟多、天际万吨级释放）。
  • 电子制程：电子信息制造业增加值 +14.8%，但公司该板块收入 −9.49%（元器件 / 仪器收缩）。

（3）产业链传导

  • 上游：有机硅 / 环氧树脂（胶粘剂原料）、碳酸锂 / 氢氟酸（六氟原料）。六氟价格剧烈波动直接传导至锂电板块毛利。
  • 下游：消费电子、AI 服务器、新能源整车——客户集中度高（华为占胶粘剂 35.5%）。
  • 议价权：胶粘剂强（高毛利 45.91%、客户粘性）；锂电材料弱（中小产能、议价权低）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：胶粘剂对有机硅涨价传导率约 60–70%（高毛利支撑）；六氟对碳酸锂 / 氢氟酸传导率≈0（中小产能、买方强势，自担波动）。
  • 因子2 毛利结构再平衡：胶粘剂毛利率 45.91%（高）、电解液及六氟 17.17%（中低）、电子制程 18.5%（稳）。结构优化方向——高毛利胶粘剂（尤其 AI 服务器增量）占比提升，对冲锂电周期。禁止用综合毛利率 16.06% 代表结构。
  • 因子3 库存与采购节奏：六氟高价接货损失已体现在 H1 毛利波动（Q2 毛利率 13.24% 环比 −5.85pct）；胶粘剂原料低位备货收益稳定。
  • 因子4 政策 / 市场锚点：① 碳酸锂 / 氢氟酸价格（市场层）决定六氟成本；② 关税 / 出口管制影响有机硅进口成本（政策层）；③ 算力补贴拉动胶需求（政策层）。验证点：六氟月均价、AI 服务器订单增速。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 市场容量 × 份额变量：① 供给侧——锂电六氟中小产能（7000 吨），行业话语权弱；② 客户份额——华为占胶粘剂 35.5%，深度绑定；③ 技术代际——高导热胶达 AI 服务器要求，领先中小同行；④ 成本曲线——胶粘剂高毛利左移；⑤ 份额二阶导数——AI 服务器胶渗透早期。三档：保守守住（华为基本盘）/ 中性提升（AI 服务器份额）/ 乐观抢份额（新能源胶放量）。
  • 层2 主业迁移空间：工业胶粘剂→AI 算力服务器高附加值胶（能力同源：环氧 / 有机硅配方），新 TAM（算力基建）数倍于消费电子。信号验证：光宝 / 中达订单、服务器电源厂认证。已过部分验证，计入中性小比例。
  • 层3 证伪信号：华为订单流失、AI 服务器认证失败、六氟价格战致锂电再亏。命中则下调。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 4.44x（非破净），但商誉 / 应收占比需关注；净资产 9.43 亿，轻资产特征。非重资产破净情形，不适用资产重置逻辑。
  • 校正2 周期位置校正：非强周期股，但锂电材料（六氟）处价格下行周期（2026H1 冲高回落）。中性净利未用六氟高点外推，取扣非稳态 + 胶粘剂增量。
  • 校正3 杠杆下行情景：短期借款 6.65 亿，资产负债率约 69%（偏高）。若治理风险（警示函 / 诉讼）发酵 + 需求下行，净利可转负（悲观 −85.6%）。高治理贝塔，结论谨慎。
  • 期权纪律：衢州杉杉 1.4 万吨技改（股权诉讼未解）、AI 服务器胶大单均未完全验证→部分计入中性、其余放乐观。

亏损股三问

  1. 为什么亏：2026H1 归母 −1171 万，主因① 诉讼计提预计损失约 1700 万（非经常性）；② 人民币升值汇兑损失约 600 万。属一次性扰动，扣非 +219 万已扭亏——主业（胶粘剂 + 电子制程）实际盈利。
  2. 靠什么扭亏，时点：扣非已于 2026H1 转正，扭亏已发生。持续验证靠① 胶粘剂 AI 服务器订单放量（光宝 / 中达）；② 锂电六氟技改达产 + 价格回暖；③ 诉讼 / 汇兑非经常因素消退。时点：2026H2 起归母随非经常出清转正。
  3. 亏得起吗：能撑。账面归母净资产 9.43 亿、经营现金流 H1 +1.30 亿（同比 +442.95%，大幅改善），无资金链风险；主要风险是治理（警示函）与诉讼，而非生存。

第五步：综合赔率判断（买不买？）

当前价格位置：合理略高（现价 8.27 已反映反转预期，中性远期仅 +7.5%）。
安全边际：破净非保护（PB 4.44）；中性 +7.5%，未达 >50%；悲观 −85.6%（治理风险极端）。
介入条件：等① 治理风险（警示函事项）出清信号；② AI 服务器胶订单正式公告放量；③ 回落至 6.5 元以下（PE<20x 对应稳态）。
最大风险：① 信披违规 / 诉讼扩大（已收警示函）；② 华为依赖度过高（胶粘剂 35.5%）；③ 六氟价格战致锂电再亏；④ 锂电产能股权诉讼阻碍释放。
结论：纳入观察（扣非已转正、胶粘剂 AI 增量真实，但治理风险与诉讼未消、当前估值已反映反转，等硬信号确认）。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：胶粘剂行业中小企业出清，公司凭华为绑定 + 技术卡位份额提升。验证点：份额数据、客户公告。
  • B 政策反转期权：算力补贴 / 国产替代加码→AI 服务器胶需求超预期。验证点：政策发文、大厂资本开支。
  • C 市场错杀修复：警示函情绪冲击后，扣非连续转正修复估值。验证点：连续季度扣非正、治理整改完成。
  • D 技术代际跃迁：高导热 / 灌封胶通过 AI 服务器客户认证从 0 到 1 放量。硬验证点：客户定点 + 批量订单 + 毛利维持 40%+。
  • 上调重点关注条件：AI 服务器胶年订单超 5 亿且治理风险出清、2027 净利 ≥1.5 亿。
