（3）产业链传导

上游：苗木、建材、施工分包。苗木自给率低（销售仅 43 万，且毛利为负），主要外购；建材受大宗影响。

下游：云南交投及政府业主，议价权强（买方）——工程类回款周期长、毛利率受控。公司依托控股股东形成"内部协同"粘性。

议价权判断：中（依赖股东）。对控股股东/政府具备渠道壁垒（拿单能力强），但工程结算价受控、回款节奏被动，毛利天花板明显（19–20%）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：工程类成本（苗木/建材/人工）涨价约 70% 自担（传导率 0.3），因业主结算价固定；仅材料调差条款可部分转嫁。测算：建材 +10% → 毛利承压约 1.5–2pct。
  • 因子2 毛利结构再平衡：业务高度集中于绿化改造工程（97.7%，毛利率 19.43%），苗木销售/租摆占比极小且毛利为负，无结构性对冲。原料敏感权重：建材 50%、苗木 20%、人工 30%。禁止用单一综合毛利率代表。
  • 因子3 库存与采购节奏（timing）：苗木非囤货型，无库存收益/损失显著波动；但工程"以终验/节点确认"致收入波动大（H1 +209% 含低基数与项目集中确认），毛利可比性受确认节奏影响。
  • 因子4 政策/市场锚点：① 绿美云南/交通投资节奏 → 订单量（情景：专项债+EOD 放量则订单增；验证点：新签合同）；② 建材价格（水泥/钢材）→ 成本（情景：基建材料降价降本；验证点：PPI）；③ 跨境生态（中老铁路）→ 新增市场（情景：口岸生态基建落地；验证点：跨境订单公告）。证伪信号：新签合同连续下滑、毛利率跌破 15%。

本因子输出喂给第四步毛利率假设：2029 年工程毛利率中性 18–20%（国资项目稳定），不假设持续扩张式提升。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量（5 锚点）
  • 供给侧份额：云南省内交通生态工程，依托云南交投独家渠道，份额领先但受区域总量约束。
  • 需求侧/客户份额：控股股东内部订单占比高 = 强粘性（但依赖单一大股东）。
  • 技术代际差：园林/生态修复技术同质化，无显著代际差。
  • 成本曲线位置：规模化施工 + 本地渠道降本，成本曲线中等。
  • 份额二阶导数：绿美云南处政策释放早期，份额稳步提升。
  • 三档：保守（省内基本盘）、中性（份额小幅提升）、乐观（跨境订单落地）。验证点：新签合同额、营收增速。
  • 层2 扩展业务：主业迁移空间：从省内园林向"全域生态环保 + 跨境绿美廊道"迁移，能力同源（生态工程），新 TAM（跨境+EOD）更大；切入卡位靠云南交投区位独家；信号验证：跨境项目尚无正式大单 = 未过验证点，中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：控股股东订单减少、新签合同连降、毛利率破 15%、回款恶化。命中则下调。

第四步：估值锚定（自下而上，非增速外推）

第四步进阶：重资产/周期股估值校正

  • 校正1 资产质量折扣：非重资产（园林施工），PB 2.38x 未破净，资产以应收/存货（工程类）为主，需关注回款质量（经营现金流 H1 仍 −3864 万）。
  • 校正2 周期位置校正：工程业务受地方财政/基建投资节奏影响，处政策释放期（非顶部）；中性净利取审慎值（0.99 亿），未用单季 +209% 外推。
  • 校正3 杠杆下行情景：资产负债率偏高（工程企业通病），若地方财政收紧/回款恶化，悲观净利降至 0.60 亿、股价 3.33 元（−50.1%）；下行风险大，不得标"重点关注"。
  • 期权纪律：跨境生态/EOD 未过正式大单验证点，不计入中性 NAV，仅列乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高。现价 6.68 元对应 2029E 中性 5.92 元（−11.4%），已提前定价未来 3 年业绩；且 2026H1 盈利近半为非经常性，质量存疑。

安全边际：
- 中性远期 5.92 元 → 空间 −11.4%（无安全边际）
- 乐观 8.65 元 → +29.5%（需跨境/EOD 突破）
- 悲观 3.33 元 → −50.1%（订单+回款恶化）
- 下行保护：PB 2.38x、国资背景，但经营现金流仍为负、应收高。

介入条件：
1. 等回落至 5.5 元以下（对应 2029E PE <23x）再考虑。
2. 加仓信号：① 新签合同额持续高增（验证订单转化）；② 单季扣非净利稳定 >1500 万；③ 跨境绿美廊道正式订单落地；④ 经营现金流转正。
3. 观察指标：新签合同、毛利率、经营现金流、应收账款周转。

最大风险：
1. 盈利质量：2026H1 近半为非经常性，扣非基础薄弱。
2. 回款/现金流：工程类回款慢，经营现金流为负。
3. 依赖控股股东单一客户，订单波动风险。
4. 地方财政/基建投资节奏放缓。

第五步进阶：上行想象力情景（四类，对冲系统性保守偏置）

框架前序进阶均为"往下拧"防泡沫机制，本进阶对称补回上行侧。四类情景只进乐观/机会栏、不进中性锚；每类配验证点 + 证伪信号，并写明上调至"重点关注"的条件。

  • 类型A 行业调整剩者红利：园林/生态环保行业弱资质民企出清，国资（云南交投体系）剩者份额提升。验证点：行业集中度提升、公司省内份额升；证伪：份额下滑。
  • 类型B 政策反转期权：绿美云南/跨境生态政策加码、EOD 模式与生态产品价值实现机制落地、专项债倾斜。验证点：新专项政策发文、EOD 项目批复方；证伪：地方财政收紧。重估弹性：若跨境+EOD 落地，2029 净利上限打开至 1.3 亿+。
  • 类型C 市场错杀修复：摘帽后若被错杀至 5.5 元以下（对应 2029E PE <23x）。验证点：市场企稳 + 基建板块修复；证伪：基本面恶化（回款恶化）。
  • 类型D 技术突破/代际跃迁期权：跨境绿美廊道（中老/中泰铁路）从 0 到 1 订单落地，由省内园林向跨境生态迁移。硬验证点：跨境大单签约 + 交付 + 毛利率达预期；三者缺一则仅作机会情景。证伪：跨境项目无正式合同。

上调至"重点关注"的条件：跨境绿美廊道正式订单落地且经营现金流转正，或新签合同持续高增使 2029 净利上修至 1.3 亿+、空间突破 +50%，则上调至重点关注。

结论：暂不介入（估值已反映 2029 预期、中性空间为负、2026 盈利质量偏弱；虽国资背景+政策强驱动逻辑正确，但当前赔率不利，等回调或订单/现金流验证后上调）。
