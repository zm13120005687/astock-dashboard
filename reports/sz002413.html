第二步进阶·原料成本→毛利结构（四因子）
- 因子1 成本传导弹性：军品审价制，成本传导率≈0.3（降价压力自担）；民品（反无雷达等）新兴，传导率≈0.6。实际毛利承压 = 元器件涨价×(1−传导率)。验证点：军品审定价、民品中标价。
- 因子2 毛利结构再平衡：分业务——雷达 20.51%（偏低、拖累）、智能控制 49.96%、卫星 36.64%、智算存储 50.91%（高、高增）。智算存储占比提升将结构性抬升综合毛利；雷达系统（占比最高）毛利偏低是减亏关键。禁止用综合 36.81% 代表全结构。原料敏感权重：雷达/智能控制对元器件敏感。
- 因子3 库存与采购节奏：军品交付节奏（按合同确认）造成季度波动；国产 GPU 长协/备货对冲。验证点：存货、合同负债。
- 因子4 政策/市场锚点：①市场层——电子元器件价格、军品交付节奏；②政策层——军费增长（利好）、低空/商业航天（需求）、国产算力补贴（降本）、出口管制（国产替代加速）。情景：军品订单放量+国产替代降本→毛利改善（正面）；审价降价→毛利破阈值（负面）。验证点：新增订单、军费预算。

第三步进阶·份额变量与主业迁移空间（三层法）
- 层1 现有业务：市场容量 × 份额变量：①供给侧——军工电子细分领域多（雷达/卫星/存储），份额分散，扩产靠研发；②需求侧——军方核心客户认证（高粘性）；③技术代际——新体制雷达领先；④成本曲线——国产 GPU 替代降本（左移）；⑤份额二阶导数——军工信息化渗透期（S 曲线早期）。三档：保守（守存量）、中性（军工修复+民品起量）、乐观（低空/商业航天抢份额）。验证点：新增订单、民品签单。
- 层2 扩展业务：主业迁移空间（民品新池塘）：①能力可迁移——雷达技术→民航/低空/农业/养老；②新 TAM——低空经济/商业航天/养老万亿级；③卡位——早期（反无雷达先发）；④认证门槛——行业资质（已齐）；⑤信号验证——鸟情系统交付、反无课题、探虫站点、生命雷达批量交付（已验证部分）。属"中期期权"，未完全过验证点仅作机会情景。
- 层3 证伪信号：军工订单续签落空、民品拓展缓慢、雷达毛利持续偏低、审价降价超预期 → 下调增量。

亏损股三问（必答）

① 为什么亏：多年商誉减值（历史商誉从 9.5 亿减值至 3.95 亿）+ 军工研发/费用高 + 军品交付节奏波动 + 雷达系统毛利率仅 20.51%（偏低）拖累。2026H1 亏幅已收窄至 −1812 万，接近扭亏。

② 靠什么扭亏，时点在哪：智算存储（国产 GPU，+45% 高增、毛利 50.91%）、卫星应用（+5.7%）、智能网联（+139%）高增；雷达系统由单机配套→系统方案（民航鸟情/低空反无/农业探虫/养老生命雷达）打开民品；费用管控（AI 降本）；军工"十四五"后期订单放量。扭亏时点：2026H2 或 2027 年（H1 −1812 万、Q2 仅 −218 万，拐点临近）。

③ 亏得起吗：净资产 33.13 亿、总资产规模大、军工背景融资能力强；商誉已减值至 3.95 亿（风险大部分释放）；经营现金流 H1 −1.47 亿但季节性（军品回款集中于下半年）。能撑到扭亏。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（已透支期权）。现价 8.78 对应中性 2029E 5.76 元（−34.4%），市场已计入低空/商业航天/国产算力三期权。

安全边际：
- 中性远期 5.76 元 → 空间 −34.4%（中性不达重点关注）
- 悲观 1.37 元 → 下行 −84.4%（军品续弱极端风险）
- 乐观 13.65 元 → +55.5%（三期权共振）
- 下行保护：PB 3.52x（偏高）、军工资质壁垒、减亏临近拐点

介入条件：
1. 不追高。等回落至 6.5 元以下（PB<2.6x） 或 2026H2 正式扭亏公告确认
2. 加仓信号：① 军工大单新增公告；② 低空反无雷达批量订单；③ 商业航天/国产 GPU 客户定点；④ 智算存储持续 >40% 高增
3. 观察指标：逐季净利（是否转正）、合同负债、毛利率

最大风险（最可能破坏逻辑的因素）：
1. 扭亏不及预期（首要）：军品交付波动、雷达毛利偏低，延后扭亏
2. 民品拓展缓慢：低空/商业航天落地慢于预期
3. 商誉/资产减值：历史减值风险未完全出清
4. 估值回撤：当前溢价高，期权证伪则大幅回撤

第五步进阶·上行想象力情景（四类，对冲系统性保守偏置）
- A 行业调整剩者红利：军工电子国产化剩者（资质/技术壁垒），"十四五"后期装备放量份额向龙头集中。验证点：军品新增订单。证伪：订单落空。
- B 政策反转期权：军工装备放量 + 低空经济（反无人机雷达）+ 商业航天（卫星应用）政策加码。验证点：政策发文、订单公告。证伪：政策退坡。
- C 市场错杀修复：从多年亏损（2022 −9.35 亿→2025 −0.87 亿）预期修复为扭亏，估值重估。验证点：2026H2 扭亏公告。证伪：再度转亏。
- D 技术突破/代际跃迁期权：国产 GPU 智算存储从 0 到 1、低空反无雷达新场景。政策（国产算力/低空）+ 趋势（渗透率拐点）+ 落地（已签单/批量交付）三要素共振。硬验证点：良率达标 + 客户定点 + 量产成本优。已部分满足，计入机会情景（非中性）。证伪：民品拓展落空/成本打不过旧路线。
