第一步：公司是干什么的？

一句话定位：冀中能源是总部位于河北的国有大型煤炭综合企业，以"稀缺焦煤 + 华北区位"为核心资产，业务横跨煤炭开采洗选、化工、新材料（建材）与现代服务四大板块，煤炭主业贡献近八成收入。

核心产品：主焦煤、1/3 焦煤、肥煤等国家保护性稀缺煤种；洗精煤、动力煤；PVC/烧碱等化工品（亏损）；石膏板等建材。

主要客户/下游：钢铁企业（炼焦煤下游，受钢铁景气直接影响）、电力集团（动力煤）、建材与化工企业。焦煤定价随钢铁周期波动。

境内外收入占比：基本内销，华北地区贡献 67.15 亿（90.64%），华东 5.38 亿（+19.19%）；出口极少。

股东背景：河北省国资委下属冀中能源集团控股，实控人为河北省国资委，具备区域保供与资源禀赋优势（河北、山西、内蒙古优质煤带 + 京津冀环渤海区位 + 铁路专线 + 铁水联运）。

（3）产业链传导

上游：煤炭开采成本以人工、安全投入、资源税为主。2026H1 税金及附加同比 +9.20% 至 4.58 亿（资源税 3.09 亿），成本端刚性上行。

下游：炼焦煤 → 钢铁。钢铁景气偏弱直接压制焦煤价格与销量弹性；动力煤 → 电力，需求刚性托底。

议价权：中等。公司作为河北稀缺焦煤供应商，对长协客户具备一定议价基础，但焦煤定价仍受钢铁周期主导，属"中等偏弱"——2026H1 煤炭毛利率 38.92% 与去年同期基本持平，未能随煤价中枢抬升而扩张，即为佐证。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：焦煤售价受钢铁周期主导，公司转嫁系数 ≈ 0.3~0.4（煤价上行时部分传导、下行时难以转嫁成本刚性）。依据：2026H1 煤炭毛利率持平、管理费用 +10.64%（薪酬 +31.9%）、资源税 +2648 万，成本端上行未能有效转嫁，毛利被挤压。

  • 因子2 毛利结构再平衡：煤炭（毛利率 38.92%，贡献绝大部分毛利）VS 化工（−7.97%，持续失血）VS 建材（7.72%，薄利）VS 电力（−80.52%，极小）。原料敏感权重高度集中于煤炭：煤炭板块毛利约 22.9 亿（H1），化工亏损吞噬约 0.66 亿。若焦煤价格下行 10%，煤炭毛利敏感下滑约 2.3 亿，整体净利弹性极大（因化工/电力不贡献）。

  • 因子3 库存与采购节奏：煤炭企业以长协为主（中长期合同锁定电煤），现货比例低，库存收益/接货损失波动较小；但化工原料（PVC/烧碱上游）随周期波动，2026H1 化工毛利率 −7.97% 即反映高价原料接货损失。

  • 因子4 政策/市场锚点：① 安全监管反超产 → 供给收缩托底煤价（利好）；② 资源税刚性上行 → 抬升成本曲线（利空，已兑现）；③ 钢铁"能耗双控/限产" → 压制焦煤需求（利空验证点：钢铁产量同比）。情景：若 2026H2 钢铁限产加码，焦煤中枢下移 5%~8%，煤炭毛利再降 1~2 亿；若保供放松、进口收紧，煤价回升。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：全国原煤产量 23.7 亿吨/半年，公司销量 1153 万吨/半年，份额约 0.5%，非龙头，扩产受资源与安监约束。
  • 客户份额：焦煤供应河北钢铁集群，区域粘性强但增量有限。
  • 技术代际：智能化矿井提升效率，但非代际领先。
  • 成本曲线：华北区位 + 铁路专线降物流成本，处行业中等成本线。

  • 份额加速度：份额基本稳定（销量同比 +0.21%），无加速渗透。
    → 三档：保守守住（份额 0.5%）、中性小幅提升（精煤比例优化）、乐观（资产注入/整合）。中性不支持份额扩张带来的增量。

  • 层2 扩展业务：主业迁移空间：煤炭企业向"煤化工/新能源"迁移门槛高、资本密集，公司化工板块当前亏损，未过验证点，仅作中期期权，不计入中性情景。

  • 层3 风险折扣（证伪信号）：焦煤价格跌破 2026 中枢 10% 且钢铁限产加码、化工减值扩大、安监导致停产——命中则下调中性净利。

第四步：估值锚定（自下而上，非增速外推）

方法说明：不使用历史增速外推。煤炭为强周期股，采用周期归一化净利润而非单年/TTM 净利。2026H1 归母净利 2.64 亿（年化约 5.3 亿）处周期偏弱区间，化工亏损拖累。中性情景取周期中值净利。

总股本：约 38.87 亿股（总市值÷现价推算）。

周期位置判断

当前煤炭处周期中下部：煤价中枢较 2021–2022 超级周期大幅回落，但高于 2020 底部；钢铁偏弱压制焦煤。公司历史盈利区间约 5 亿（谷）~40 亿+（峰），周期中值归母净利取 16~18 亿为中性稳态。

第四步进阶：重资产 / 周期股三道闸

  • 校正1 资产质量折扣（破净原因）：PB 0.90 破净，原因是资产盈利能力差（ROE 仅 1.39% H1，年化约 2.8%）+ 周期底部 + 化工拖累，并非金融资产未重估型（公司无大额上市公司持股）。因此破净是公允定价而非低估——禁止单凭 PB<1 推导大空间。净资产 191.58 亿中煤炭矿井为专用资产，清算价值 << 账面，重置成本不兜底。

  • 校正2 周期位置校正：中性净利 17 亿为周期中值，已避免用单年好年景或 TTM 低谷（5.3 亿）外推。当前处周期中下部，不过度悲观。

  • 校正3 杠杆下行情景：资产负债率约 53%（2026H1 总资产 545 亿 / 负债适中），杠杆中等；但经营杠杆高（固定成本刚性），煤价下行时净利几倍跳负。悲观情景空间 −47.5% 已体现，故不得标"大空间/重点关注"。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。现价 4.42 元对应 PB 0.90，已低于净资产 10%；但盈利处周期谷（TTM PE 32.5x 因盈利低而虚高），按周期中值净利 17 亿 / 11x 测算市值 187 亿，对应 4.81 元，当前略有安全边际。

安全边际：PB 0.90 + 国有煤炭资产 + 区位稀缺煤种，下行有资产锚保护（悲观 2.32 元对应 PB 0.48，极端）；中性远期 4.81 元（+8.8%），不达重点关注 >50% 门槛。

介入条件：① 现价 ≤ 4.20 元（PB ≤ 0.85x）开始具配置价值；② 加仓信号：焦煤价格连续两季回升、化工板块扭亏、2026H2 净利环比改善；③ 回避点：钢铁限产致焦煤破位。

最大风险：① 焦煤价格随钢铁景气继续下行（首要）；② 化工板块持续亏损甚至减值；③ 资源税/安监成本刚性上行；④ 国企治理效率偏低、分红波动。

上行想象力情景（四类）：
- A 行业调整剩者红利：中小煤矿安监退出，剩者份额提升——验证点：全国煤矿数量下降、公司份额上升；证伪：产量无变化。
- B 政策反转期权：若经济刺激加码拉动钢铁/基建，焦煤需求反转——验证点：钢铁产量同比转正、焦煤提价；证伪：限产延续。
- C 市场错杀修复：PB 破净 + 高股息预期，情绪修复——验证点：股息率 >5%、资金回流周期；证伪：盈利继续下滑。
- D 技术突破：智能化矿井降本、资产整合——未过验证点，仅作机会情景。

上调重点关注的条件：焦煤价格回升至使年化净利稳定在 20 亿以上 + 化工扭亏，对应市值 220 亿+（5.66 元，+28%），仍不足 50% 空间，故维持观察。

结论：纳入观察（PB 破净提供下行保护，但周期偏弱 + 化工拖累，中性空间仅 +8.8%，需等煤价/化工拐点）。
