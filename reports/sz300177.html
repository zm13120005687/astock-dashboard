分析日期：2026-09-16 ｜ 现价 6.12 元（2026-09-15 收盘价）｜ 总市值 约 45.5 亿 ｜ PE(TTM) −18 倍（亏损） ｜ PB(LF) 3.70 倍 ｜ 总股本 7.44 亿股
行业：高精度导航定位（北斗 / 智能驾驶 / 时空数据）｜ 板块：创业板

一句话定位：国内高精度 GNSS 导航定位龙头，业务覆盖"精准时空感知装备 + 北斗高精度行业应用 + 智能驾驶与导航控制"三大板块，正从国内安全监测向海外高毛利 + 智能驾驶定点双轮转型。

（3）产业链传导

上游：芯片 / 元器件（部分进口），成本占比中；汇率影响海外采购。

下游：政企（回款周期长、政策敏感）+ 车企（前装认证、量产节奏）+ 海外代理商（高毛利）。

议价权：中。装备端技术领先有溢价（海外毛利 62.71%）；政企端受预算 / 政策制约回款弱；车企端认证壁垒高但量产降价压力在。

第二步进阶：原料成本→毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：量化转嫁系数 ≈ 0.6–0.7（技术密集型，非原料主导）。成本以研发 / 人工 / 元器件为主，原料涨价传导有限但影响小；毛利波动主因产品结构而非原料。验证点：综合毛利率能否稳于 38%+。证伪：毛利率破 33%。
  • 因子2 毛利结构再平衡：高精度装备 39.13%（占比 87%，正且升）、时空数据 27.14%（占比降、收缩）；海外 62.71% vs 国内低毛利——结构正从"低毛利国内政企"向"高毛利海外 + 智能驾驶"迁移，加权毛利逆势升。禁单一综合毛利率。
  • 因子3 库存与采购节奏：无显著库存收益；H1 应收账款较年初 −1.12 亿（强回款），经营现金流 −704 万（同比改善 95.15%）属管理改善非库存。长协 / 套保：无大宗套保，汇率少量暴露。
  • 因子4 政策 / 市场锚点：①市场层——车企前装量产节奏、海外需求；②政策层——北斗规模化（托装备）、智能网联 / E-Call（托智能驾驶）、国内安全监测政策收紧（短期压制国内）。情景：智能网联政策加速 → 智能驾驶放量；国内监测政策放松 → 国内回暖。验证点：上汽通用量产进度、E-Call 落地。证伪：定点延期或政策放缓。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：RTK / 三维激光国内前列，产能随订单；
  • 需求侧：国铁 / 国能核心客户粘性强，海外代理商网络扩张；
  • 技术代际：全栈自主可控，铁路 / 电力安全防护先发；
  • 成本曲线：研发摊薄后边际成本低，规模效应明显；
  • 份额加速度：海外 +29%、智能驾驶 +44% 处加速期。
    → 保守守住 / 中性（海外 + 智能驾驶增量）/ 乐观（机器人 + 低空新场景）。验证点：海外收入占比、智能驾驶量产收入。
  • 层2 扩展业务：主业迁移空间：从测绘装备向"车载前装 + 机器人姿态感知"迁移，能力同源（高精度定位算法 / IMU 复用），新 TAM = 智能网联汽车前装（渗透率快速提升）+ 人形机器人；切入卡位早期（已获定点 / 中标）；认证门槛 = 车规级 IATF16949 + 客户定点；信号验证 = 上汽通用量产、机器人小批量交付。未过验证点仅作中期期权。
  • 层3 证伪信号：智能驾驶定点延期 / 流失、海外收入占比回落、国内收缩致营收继续下滑。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非破净（PB 3.70），净资产 12.49 亿多为技术 / 品牌 / 应收（轻资产为主），清算价值中等；PB 含研发与期权溢价，非资产低估。
  • 校正2 周期位置校正：北斗 / 智能驾驶处产业上行早期，但公司因国内政企收缩处个体下行；用正常化净利率（行业 8–10%）替代单年亏损，已标注"个体调整期"。
  • 校正3 杠杆下行情景：资产负债率 54.05%、借款规模稳定，杠杆适中；但若智能驾驶量产延期 + 国内继续收缩，净利转负、空间转负，不标大空间。
  • 期权纪律：人形机器人、低空经济未过验证点，不计入中性 NAV。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（主业视角）。现价 6.12 元隐含市值 45.5 亿，中性正常化价值 30.7 亿，溢价来自智能驾驶 / 机器人期权。

安全边际：中性远期 4.13 元 → 空间 −32.5%；乐观 7.06 元 → +15.4%（需智驾 + 机器人兑现）；下行悲观 1.21 元 → −80.2%。

介入条件：① 上汽通用定点正式量产且形成收入；② 海外收入占比升至 35%+ 且维持 60%+ 毛利；③ 单季归母转正（经营性）。价格回落至 4.5 元以下（接近基准 / 中性价值）才具安全边际。

最大风险：① 国内安全监测政策持续收紧致营收下滑；② 智能驾驶定点量产延期或客户压价；③ 应收账款回收风险（虽已改善）；④ 连续亏损致融资受限。

三问（亏损股必答）：
1. 为什么亏：国内安全监测 / 时空数据受行业政策调整需求减 + 主动战略收缩低回款业务，费用刚性；2025 大亏还含大额减值。
2. 靠什么扭亏、触发时点：智能驾驶定点量产（上汽通用 2026H2 起）+ 海外高毛利放量 + 铁路安防落地 + 费用优化；触发时点 2026H2–2027 年。
3. 亏得起吗：资产负债率 54%、总资产 26.5 亿、经营现金流大幅改善（−704 万 vs 去年同期 −1.45 亿），亏得起；需智驾量产兑现避免长期消耗。

结论：暂不介入（中性正常化空间为负；若上汽通用量产 + 海外高增兑现，乐观 +15.4% 可上调至纳入观察 / 重点关注）。
