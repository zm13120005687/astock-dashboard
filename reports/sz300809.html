第一步：公司是干什么的？

一句话定位：国内数控轧辊磨床细分领域领军企业（客户宝武 / 鞍钢、出口东南亚），正拓展丝杠磨床（滚珠 / 行星滚柱丝杠，人形机器人链）与自研智能磨削数控系统，打造"工业母机 + 机器人核心部件设备"第二曲线。

（2）市场端（量价数据）

  • 轧辊磨床为钢铁 / 有色金属刚需耗材设备，需求随钢厂资本开支周期波动（行业增速仅作背景，非公司增速外推依据）。
  • 丝杠磨床：人形机器人行星滚柱丝杠磨削设备处于 0→1 早期，单台价值量高（千万级），市场小但弹性大。
  • 公司 2026H1 营收 1.94 亿（同比 -27.28%），主因轧辊磨床验收数量下降、整机交付放缓；合同负债 2.12 亿（较期初 -19.3%）反映订单 / 预收走弱。

（3）产业链传导

上游：铸件 / 钢材、数控系统、功能部件（轴承 / 导轨）。
下游：钢厂、有色、半导体、新能源（丝杠）。
议价权：中（高端设备有技术溢价、毛利率 28–29%，但客户集中、验收节奏主导收入）。

（2）进阶 · 原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：转嫁系数 ≈ 0.6（高端定制设备有溢价但钢企客户压价，毛利率 28–29% 稳中略降）。
  • 因子2 毛利结构再平衡：收入 93% 集中于磨床设备（28.21%GM），结构单一；丝杠磨床（若放量）毛利率可能更高，将改善结构——但当前未贡献。
  • 因子3 库存与采购节奏：存货 3.04 亿（较期初 +7.7%，库存商品增加），为待验收整机；重型设备长交付周期，收入确认依赖验收节奏（致 Q2 营收环比降）。
  • 因子4 政策 / 市场锚点：钢材 / 铸铁价格（重资产原料）、工业母机税收优惠、人形机器人（丝杠需求）、半导体 / 新能源 capex。验证点：钢材价、丝杠磨床订单、合同负债；证伪：合同负债持续降、丝杠无订单。

（3）进阶 · 份额变量与主业迁移空间三层法

  • 层1 现有业务（份额变量）：轧辊磨床细分龙头，用 5 锚点——①供给侧（高端轧辊磨床产能集中）、②客户份额（宝武 / 鞍钢认证绑定）、③技术代际（亚微米级领先）、④成本曲线（规模化）、⑤份额加速度（钢铁资本开支周期）。验证点：出货量、合同负债；证伪：合同负债持续降、毛利率破 25%。
  • 层2 主业迁移（新易盛范式）：轧辊磨床 → 丝杠磨床（人形机器人核心部件设备），能力可迁移（精密磨削同源）、新 TAM 大（人形机器人）。未过验证点 → 中期期权，不计入中性净利。验证点：丝杠磨床客户定点 / 正式订单、营收占比跳升。
  • 层3 证伪：钢铁 capex 放缓、合同负债连降、丝杠磨床无正式订单、自研系统客户接受度低。

（4）进阶 · 重资产 / 周期股估值三道闸

  • 校正1 资产质量折扣：净资产 18.66 亿，其中交易性金融资产较上年末 +54.53%（金融资产已按公允价值计量，真实）；PB 3.33x 反映"丝杠期权"定价，非破净、无专用资产折价。
  • 校正2 周期位置校正：归母高增来自交易性金融资产公允价值变动（市场 / 牛市，非持续），中性净利用扣非（主业）剔除一次性；主业处验收放缓周期（营收 -27%、合同负债 -19%），不按 2025 峰值（归母 2.02 亿，含波动）外推。
  • 校正3 杠杆下行情景：负债率低、资产以金融资产为主，无高负债反噬；但公允价值变动随市场波动——若市场下行，非经常转负、归母大幅缩水，悲观情景空间 -50.7%。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（现价已含丝杠磨床期权预期；主业扣非仅 0.4 亿，2026E PE 约 61x）。

安全边际：净资产 18.66 亿（约 7.4 元 / 股）为底；中性远期 -36.9%；乐观 +7.1%（需丝杠磨床订单落地）。

介入条件：
1. ≤ 16 元（接近中性合理锚、2026E 扣非 PE < 50x）才具安全边际；
2. 上调至"重点关注"条件：丝杠磨床获人形机器人链客户正式定点 / 大额订单、合同负债回升 >2.5 亿、扣非净利连续两季转正增长。

最大风险：
1. 轧辊磨床验收持续放缓（合同负债走弱）；
2. 丝杠磨床商业化不及预期（中试 / 良率 / 客户定点未兑现）；
3. 金融资产公允价值变动随市场回撤（非经常转负）；
4. 钢铁 capex 周期性下行。

第五步进阶 · 上行想象力情景（四类，对冲系统性保守偏置）

  • 类型A 行业调整剩者红利：轧辊磨床高端细分集中，公司亚微米级技术领先，钢厂节能改造期份额提升。验证点：出货量、合同负债；证伪：合同负债持续降、毛利率破 25%。
  • 类型B 政策反转期权：工业母机税收优惠延续（2024—2027）+ 人形机器人政策加码，设备需求反转。验证点：政策发文、招标；仅作机会情景。
  • 类型C 市场错杀修复：若工业母机 / 机器人板块系统性回调错杀，净资产 18.66 亿（约 7.4 元 / 股）提供底。验证点：估值分位、市场企稳。
  • 类型D 技术突破 / 代际跃迁：丝杠磨床（行星滚柱，人形机器人链）中试良率达标 + 客户定点 + 量产成本优于旧路线，从 0→1 投产重构增长曲线。硬验证点：三要素共振；缺一则仅作机会情景，不计入中性。

上调至"重点关注"条件：丝杠磨床获人形机器人链客户正式定点 / 大额订单、合同负债回升 >2.5 亿、扣非连续两季正增长，中性远期空间转正并突破 +50%。

结论：暂不介入（主业扣非承压、归母靠公允价值变动、现价已透支丝杠期权；等回调至 16 元以下或丝杠磨床订单验证后 reconsider）。
