（3）产业链传导

上游 → 成本端：药品/保健品/器械供应商（工业 + 商业批发）。公司通过营采一体化 + 集中采购 + OEM 贴牌 + 直接进口/跨境购提升议价权：中药材毛利率 +2.4pct、非药品类 +4.47pct 即是证明。九部门《意见》明确"鼓励零售药店整合采购需求，开展联合采购，实现量价挂钩"，进一步支持向上游要毛利。

下游 → 收入端：C 端消费者（社区家庭、中老年、慢病人群）+ 线上 O2O（28.59%）。客流的决定权不在公司，而在医保政策与处方流向 —— 这是本股议价权被系统性削弱的根源。

议价权判断：弱 → 边际改善
- 弱：医保结算占比被动从 52% 降至 38.47%，收入和客流被政策外生决定；慢病资质门店被取消 222 家，公司只能被动接受
- 边际改善：非医保依赖品类（GLP-1 1.6 亿、达利雷生 800 万、LSI 1,000 万）由公司自主定价 → 议价权正在从"医保"向"自费"迁移，这是转型的实质

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）——把"医保依赖度"量化为传导率

医药零售的"成本"不是原料，而是采购进价 + 医保限价 + 合规成本。公司的"传导率"本质是把成本上涨转嫁给顾客的能力：
- 医保目录内药品：价格由医保局/集采决定 → 传导率 ≈ 0（公司只能被动接受，2022—2025 医保结算收入下降 8.11 亿即为此）
- 非医保创新药（GLP-1 等）：自主定价 → 传导率 ≈ 1.0（司美格鲁肽等 1.6 亿收入几乎全额传导）
- 中药材/非药品/OEM：自有供应链 → 传导率 >1.0（中药材毛利率 +2.4pct、非药品类 +4.47pct 证明）

加权验证：综合毛利率 36.30%（+0.61pct）—— 在公司医保占比下降 1.53pct（40%→38.47%）的背景下毛利率逆势提升，说明非医保品类的传导率不仅覆盖了医保品类传导失败的损失，还带来了净增益 0.61pct。
结论：公司的核心矛盾不是"成本涨"，而是"传导率为 0 的收入占比过高"。转型的本质是把收入结构从传导率 0 的池子搬到传导率 1.0 的池子。

因子3 库存与采购节奏（timing）
- 2026H1 经营活动现金流净额 5.95 亿（+7.99%），净现比 1,108.36%、营业收入现金比 102.80% —— 现金流远好于利润，主因是使用权资产折旧（租金摊销）、长期待摊费用摊销、资产减值等非付现成本（2026Q2 单季资产减值 −2,051.44 万）。
- 判断：本股利润被"非付现成本"严重压低，账面利润 ≠ 现金创造能力。 但反向看，这些折旧摊销对应的门店资产若持续亏损，未来会转为真实的资产减值 → 净资产存在虚高可能（见第四步校正1）。
- 采购节奏：公司加强营采一体化、集采参与、OEM 与直采，中药材与非药品类毛利率提升即源于此，属结构性改善而非 timing 收益。

为什么破净？逐项举证：

原因类别 具体证据 是否构成本股破净主因
① 资产盈利能力差（ROE 系统性低于权益成本） 2026H1 加权 ROE 仅 1.99%（年化约 4%）；2025 全年 ROE = 1.4815/26.7 ≈ 5.5%；2024 约 4.8%。ROE 长期 4%–5.5%，远低于权益成本（约 9%–10%） ✅ 主因。PB<1 是 ROE < COE 的必然数学结果（PB ≈ (ROE−g)/(COE−g)），属公允定价

④ 金融资产未按市价重估（真安全边际） 无法证明：公司未披露投资性房地产公允价值、未持有大额上市公司股权、无大额金融资产可供重估 ❌ 不成立

关键提醒：PB 0.96 与每股净资产 16.42 元看似"打折买资产"，但按第四步校正1 的举证，破净是 ROE 4%–5.5% 的公允结果，不是安全边际。真正的便宜来自"盈利恢复路径"，而非"资产折价"。

安全边际
- 中性远期 21.55 元 → +37.3%，不足"重点关注"的 +50% 门槛
- 悲观 9.12 元 → −41.9%；极端减值情景 11.58 元 → −26.2%
- 乐观 32.35 元 → +106.0%（需门诊统筹落地 + 并购启动）
- 下行保护：经营现金流 5.95 亿/半年、净资产 25.38 亿（每股 16.42 元）是软支撑；但因资产专用性强，清算价值远低于账面，硬支撑弱于绿田机械这类净现金制造股

介入条件
1. 现价 15.70 元已在基准区间（14.2–17.1 元）中部，可小仓位试探（不超过计划仓位的 1/3）
2. 加仓价位：回落至 13.5 元以下（2026E PE <19x、PB <0.82x）为较优配置区；12 元以下（PB <0.73x）为重仓区
3. 加仓信号：① Q3 或 Q4 单季营收同比转正；② 云南门诊统筹结算占比突破 2%；③ 综合毛利率突破 37%；④ 首单并购落地
4. 止损信号：营收同比降幅重新扩大至 −5% 以上；综合毛利率跌破 35.5%；经营现金流半年值跌破 4 亿

最大风险（最可能破坏逻辑的因素）
1. ⚠️ 门诊统筹政策落地遥遥无期（首要）：云南 2026H1 统筹占比仅 0.86%，公司 1,292 家门店有统筹资质却几乎无结算。若 2027—2028 仍不落地，中性情景的"营收企稳"假设将崩塌
2. 医保依赖度继续下降：医保结算占比已降至 38.47%，若跌破 35% 且非药补位不足，收入将持续下滑
3. 高杠杆 + 资产减值：资产负债率 72.6%，使用权资产与商誉若大额减值，净资产与利润双杀
4. 转型速度慢于费用刚性：非药/OEM/创新药当前增量（约 1.8 亿/半年）相对 41.83 亿营收仍太小，需 3 年以上才能对冲医保缺口
5. 行业需求侧持续疲弱：居民医疗保健支出增速仅 1.2%，行业 2026E 仍 −0.1%

第五步进阶：上行想象力情景（四类，对冲系统性保守偏置）

类型A 行业调整剩者红利（中高弹性，本股最扎实的上行来源）
- 逻辑：2024Q4 起全国药店闭店数量持续超过开店数量，总数持续减少（中康科技）。难以满足合规要求（追溯码、医保稽核、执业药师配备）的中小连锁与单体店加速出清。健之佳有 4,967 家医保资质门店（96.84%）、已投入 >2,600 万做合规系统，天然是"剩者"。
- 量化：若因出清带来客流回流使同店产出年增 +1.5pct（从中性 +1% 升至 +2.5%），2029 营收由 87.1 亿升至 91 亿，净利 +0.08 亿；叠加出清后促销力度下降带动毛利率 +0.8pct，净利再 +0.55 亿 → 合计 +0.63 亿，对应股价 +7.3 元。
- 验证点：① 中康/IQVIA 季度全国药店总数（持续下降）；② 公司同店（店均）营收增速转正；③ 区域竞争对手退出公告。
- 证伪：药店总数回升（出清结束）/ 公司同店增速持续为负 → 说明出清红利没落到公司头上。

类型B 政策反转期权（最高弹性，未过验证点）
- 逻辑：九部门《意见》（商消费函 2026 年第 12 号）明确"定点零售药店门诊统筹起付标准、支付比例、最高支付限额等，可执行本统筹地区基层医疗机构相同的医保待遇政策"。公司所处省区（云南统筹占比仅 0.86%）尚在探索期 —— 这意味着巨大的未兑现政策红利。
- 量化：若云南/川渝统筹占比由 0.86% 升至 5%（仍远低于部分已落实省区），按零售收入 90 亿、统筹占比 5% 计，新增统筹结算收入约 4.5 亿；按统筹品种毛利率约 25%、增量费用率 10% 计，增厚净利约 0.5–0.7 亿，对应股价 +5.8 至 +8.1 元。若升至 15%（乐观），弹性翻倍。
- 验证点：① 云南/四川/重庆医保局门诊统筹实施细则发文；② 公司季报披露的统筹结算收入占比；③ 统筹资质门店（1,292 家）实际开通结算数。
- 证伪：2027 年底统筹占比仍 <2% / 政策仅停留在《意见》层面无省级细则 → 该期权作废，中性下修。

类型C 市场错杀修复（中弹性，部分适用）
- "错杀"证据（部分成立）：① 现金流远好于利润（净现比 1,108%，经营现金流 5.95 亿/半年且 +7.99%），市场按账面利润定价低估了现金创造能力；② 营收降幅已连续收窄（Q1 −8.86% → Q2 −3.25%），但股价仍按"持续衰退"定价；③ PS 仅 0.29x，为零售行业极低分位。
- "非错杀"证据（必须承认）：① PB 0.96 是 ROE 4%–5.5% 的公允定价（见校正1）；② 资产负债率 72.6% 偏高；③ 行业确实在低速/负增长。
- 结论：属"部分错杀" —— 市场低估了现金流与企稳迹象，但对低 ROE 的定价是对的。修复触发点：连续两个季度营收同比转正 + 经营现金流维持 5 亿+/半年。
- 量化：若市场改用"现金流视角"（经营现金流年化 11.9 亿，给 3.5x P/OCF = 41.7 亿），股价 = 26.98 元（+71.9%）。此为机会情景，不计入中性锚（因经营现金流含大量非付现的租金/摊销，非真自由现金流）。

类型D 技术突破 / 技术代际跃迁期权（本股不适用）
- 医药零售不存在"技术路线代际跃迁"逻辑。数字化（佳 E 购、追溯码、AI 视频巡查）属效率工具而非技术代际变革，本类明确排除。
- 最接近的"迁移"已在第三步层2 讨论（药品销售 → 健康服务），属主业迁移（类型B 范式）而非技术跃迁，且"健康服务"尚未独立成收入科目 → 不计入中性。

↑ 什么条件出现才上调至"重点关注"？
同时满足以下三条中的两条：① 云南（或川渝）门诊统筹结算收入占比突破 5%；② 单季营收同比转正且综合毛利率突破 37.5%；③ 股价回落至 13 元以下（PB <0.79x）而上述基本面未恶化。
仅凭"破净修复"或"九部门政策"不足以支撑上调 —— 必须看到政策红利在报表上兑现（统筹结算占比）。

结论：纳入观察

定级理由：中性远期空间 +37.3%，落在"纳入观察"区间（0~50%），不达"重点关注"的 >50% 门槛；悲观 −41.9%、极端减值情景 −26.2%，且资产负债率 72.6% 偏高，风险收益虽正向但不足以支撑重仓。
三件对的事：① 政策拐点已明确（九部门《意见》+ "十五五"健康中国）；② 转型有真实数据（毛利率 +0.61pct、非药 +4.47pct、GLP-1 近 1.6 亿、费用连续 3 期下降）；③ 现金流强劲（5.95 亿/半年、净现比 1,108%），生存无忧。
三件压住赔率的事：① 破净是公允定价而非便宜（ROE 4%–5.5% 支撑不了 1x PB）；② 资产负债率 72.6%，使用权资产与商誉有减值风险；③ 门诊统筹在核心省区（云南 0.86%）迟迟不落地，最大的政策红利仍是"期权"。
核心跟踪点：季度营收同比能否转正 + 云南门诊统筹结算占比 + 综合毛利率能否守住 37%。
