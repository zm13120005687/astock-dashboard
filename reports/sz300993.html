玉马科技（300993）五步法分析报告

分析日期：2026-09-19 ｜ 现价 9.60 元（2026-09-18 收盘）｜ 总市值 约 29.6 亿 ｜ PE(TTM) 约 23.9x ｜ PB(LF) 约 1.96x ｜ 总股本 3.08 亿股（注册资本 30813.12 万元）｜ 行业：功能性遮阳材料（阳光面料 / 遮光面料 / 可调光面料）｜ 板块：创业板
盈利股：2026H1 归母净利润 5362.96 万元（虽同比 −27.61%，仍稳定盈利），按盈利股自下而上估值。

第一步：公司是干什么的？

一句话定位：国内功能性遮阳材料龙头（行业国标主编单位、业内唯一"中国驰名商标"），研发生产销售阳光面料、遮光面料、可调光面料等节能遮阳新材料，以出口为主（境外占比 ~66–70%）。

核心产品：阳光面料（玻纤 / 聚酯节能面料）、遮光面料、可调光（斑马）面料、功能性膜材料（在研 / 在建）。产品用于建筑遮阳、节能降耗。

主要客户 / 下游：海外建材经销商、窗帘成品商、工程客户，销往全球六大洲 70+ 国家和地区（欧洲、亚洲、美洲为主）；境内华东 / 华南。出口占比 ~70%。

股东背景：实控人孙承志（持股 26.58%）+ 玉马保丰投资（19.74%）+ 崔月青（11.39%），家族 / 一致行动人控股；高新技术企业。

第二步：行业景气度 + 政策/市场数据

（1）政策端（近 6–12 个月）——绿色建筑 + 节能降耗长期顺风

政策 / 趋势 方向 与公司的关联
绿色建筑 / 建筑节能强制标准（双碳目标下持续加码） 强利好 功能性遮阳是建筑节能重要手段，直接拉动渗透
消费品以旧换新 / 家居消费提振 中性偏利好 拉动境内遮阳窗饰需求
出口退税 / 外贸稳规模政策 利好 公司出口占比 70%，受益稳外贸
人民币升值 利空（2026H1 已体现） 汇兑损失 + 外币收入折算减少

关键背景：据行业数据，2024 年国内功能性遮阳渗透率不足 5%，而欧美发达国家已达 70% 以上——这是公司中长期最核心的需求锚，空间广阔、渗透斜率取决于政策与消费认知。

（3）产业链传导

上游：玻纤、聚酯纤维、PVC / TPU 膜、化工助剂。原料随大宗（原油 / 化工）波动；公司规模优势 + 长协部分对冲。

下游：海外建材渠道商、工程 / 终端消费者。下游分散、品牌渠道为王，公司议价权中等偏强（龙头 + 技术壁垒 + 国标主编）。

议价权：中等偏强。功能性遮阳材料有一定技术壁垒（织造 / 涂层工艺），且公司为行业标准制定者，对上游有规模议价、对下游凭品牌与交付能力保持毛利韧性（综合毛利率长期 34–40%）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：化工 / 纤维涨价时传导率约 0.6–0.8（龙头可部分提价），因产品差异化强于普通纺织品；2026H1 毛利率降主因汇兑而非原料，原料端可控。
  • 因子2 毛利结构再平衡：三大主面料毛利率 39–40% 高度均衡，其他业务仅 9.46% 拖累加权；阳光面料（39.44%、+25.49% 增速）占比提升，结构向高毛集中，长期稳毛利。
  • 因子3 库存与采购节奏（timing）：原料低位囤货可获库存收益；无大比例套保披露，但化工价格温和波动，timing 影响有限。
  • 因子4 政策 / 市场锚点：原油 / 化工品价格（市场层）、出口退税与贸易政策（政策层）、人民币汇率（市场层，2026H1 显性汇兑损失）。情景：人民币贬值→利润增厚；化工涨价→部分转嫁。验证点：布油 / 化纤价格、美元兑人民币、出口退税政策。证伪：原料暴涨无法转嫁 + 汇率持续不利。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：国内产能玉马领先，扩产节奏（1300 万㎡）领先同行。
  • 需求侧：全球 70+ 国家客户，分散；国内渗透率 <5% 为份额蓝海。
  • 技术代际：国标主编 + 中国驰名商标，处国内领先代。
  • 成本曲线：规模 + 自动化使成本曲线左移，可降价扩份额。
  • 份额加速度：国内渗透率从 5%→ 长期向 70% 收敛，S 曲线早期、加速度向上。
  • 三档：保守（营收 9 亿）/ 中性（10.5 亿）/ 乐观（12 亿 + 渗透加速）。验证点：季度营收、国内收入占比。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：从"出口为主"迁移至"国内渗透率提升 + 膜材料新品类"——能力可复用（材料同源）、新 TAM 弹性大（国内数倍空间）、切入早（渗透初期）。膜材料未量产验证前仅作中期期权，不计入中性营收。
  • 层3 风险折扣（证伪信号）：国内渗透不及预期、产能释放延期、毛利率破 30% → 下调增量。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（破净原因）：PB=1.96（未破净），资产以设备 + 土地 + 现金为主，制造业重资产但负债率低（9.18%），资产质量扎实，非伪破净。
  • 校正2 周期位置校正：功能性遮阳属消费 + 出口弱周期，非强周期；中性净利已按"产能释放 + 毛利率恢复至 37%"保守测算，未外推 2024 年 24% 净利率的高点。
  • 校正3 杠杆下行情景：资产负债率仅 9.18%，无高负债风险，无需杠杆下行情景；主要下行来自汇率（悲观情景已覆盖 −36.5%）。
  • 期权纪律：功能性膜材料、国内渗透率跃升未完全验证，不计入中性 NAV，仅放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：合理略偏高（过渡年扰动）。现价 9.60 元对应 2026E PE ~25x（含汇兑扰动）、2029E 中性 PE ~15x，估值处于合理区间，无明显泡沫。

安全边际：中性远期 11.7 元 → 空间 +21.9%；乐观 17.1 元（+78.1%）；悲观 6.1 元（−36.5%）。下行受低负债 + PB 1.96x 支撑，风险可控。

介入条件：
1. 现价可小仓位关注，但不追高。
2. 加仓价格：回落至 8.0 元以下（2026E PE < 18x、接近 PB 支撑）更具安全边际。
3. 上调至"重点关注"条件：① 国内渗透率政策强制（如建筑节能强制遮阳）+ 国内收入占比跳升；② 1300 万㎡项目达产带动营收破 12 亿；③ 膜材料形成规模化收入。

最大风险（最可能破坏逻辑的因素）：
1. 人民币持续升值（2026H1 已验证汇兑侵蚀利润）；
2. 国内渗透率提升慢于预期（核心成长锚）；
3. 产能释放不及预期 / 折旧拖累；
4. 海外需求波动 / 贸易壁垒。

结论：纳入观察

公司质地优良（低负债 9%、出口龙头、国内渗透率 <5%→70% 长坡厚雪），逻辑正确但短期受汇兑扰动、估值合理略高，中性远期空间 +21.9% 未达"重点关注 >50%"门槛。列入观察池，等价格回落至 8 元以下或渗透率加速信号再加仓。

第五步进阶：上行想象力情景（四类，仅进机会栏，不进中性锚）

  • 类型A 行业出清剩者红利：中小遮阳厂出清，龙头份额提升。验证点：行业集中度、公司份额；证伪：份额流失。
  • 类型B 政策反转期权：建筑节能强制标准 / 以旧换新加码，国内渗透率从 5% 加速向 70% 收敛。验证点：强制政策发文、国内收入占比跳升；证伪：政策落空。
  • 类型C 市场错杀修复：若因汇率风格杀跌至 PB≈1.5（~7 元）且基本面未恶化，估值分位极低。验证点：价格回落 + 汇兑回正；证伪：基本面恶化。
  • 类型D 技术突破 / 代际跃迁：功能性膜材料从 0 到 1 量产，打开新增长曲线。硬验证点：膜材料量产 + 客户定点 + 成本优于旧路线；证伪：良率 / 成本不达标。

    上调至"重点关注"的条件：B/D 中"国内强制节能政策落地 + 1300 万㎡达产营收破 12 亿（或膜材料规模化）"验证，且价格仍在 10 元以下——届时正常化净利与估值重估，空间可突破 +50%。
