（3）产业链传导

上游：BOPP 电容薄膜的原料是聚丙烯（PP）专用树脂（高端超薄膜需进口牌号）；传统气密/柔性材料的原料是聚酯/PVC 基布、TPU、涂层树脂。两者均属石化产业链，价格随原油波动。

下游：
- 气密材料 → 水上运动 / 休闲器材制造商（出口占比高，受海外消费与关税影响）
- 柔性材料 → 物流篷盖、户外广告（国内基建与广告景气相关）
- BOPP 电容薄膜 → 薄膜电容器厂 → AI 服务器 / 新能源车 / 光伏逆变器

议价权：传统业务中等偏弱（行业"增收不增利"、海外客户压价）；BOPP 新业务目前极弱（毛利率 −27.44%，处于"求客户验证"阶段，无定价权），若通过头部客户认证则议价权将显著跃升。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1 成本传导弹性（pass-through）
- 传统业务（气密/柔性）传导率 ≈ 0.5～0.6：毛利率 32.09% / 28.75% 保持健康，说明有一定传导能力，但"增收不增利"的行业特征说明传导不完全。
- BOPP 电容薄膜传导率 ≈ 0（完全无传导能力）：毛利率 −27.44%，每生产 1 元产品付出 1.27 元成本。原因不是原料涨价，而是产能爬坡期固定成本（折旧、人工）按低产量分摊导致单位成本畸高——这是产能利用率问题，不是原料问题。
- 依据：2026H1 综合毛利率 19.06%（同比 −10.04pct），Q2 单季 13.68%（同比 −15.02pct、环比 −10.15pct），环比断崖式下滑 10.15pct 只能用 BOPP 产能利用率与 Q2 出货结构解释。

因子 2 毛利结构再平衡（分业务线敏感权重）

业务线 收入占比 毛利率 对石化原料敏感权重 对产能利用率敏感权重 加权（原料）
气密材料 57.55% 32.09% 0.50 0.15 0.288
BOPP 电容薄膜 16.84% −27.44% 0.35 0.85（极高） 0.059
柔性材料 12.68% 28.75% 0.60 0.20 0.076
其他 12.94% — 0.50 0.20 0.065
加权综合 100% 19.06% 约 0.49 — —

→ 核心洞察：BOPP 的敏感权重不在原料端（0.35），而在产能利用率端（0.85）。这意味着：
- 原料涨价 10% 对 BOPP 的影响 = 10% × (1−0) × 0.35 = 3.5pct 毛利率（可控）
- 产能利用率从 30% 提升到 80% 的影响 = 单位固定成本下降约 60%，毛利率可从 −27.44% 修复至 +20% 以上（弹性极大）
- 因此 BOPP 的投资逻辑是纯粹的产能利用率 + 客户认证逻辑，不是原料逻辑。这决定了验证点应该是"出货量 / 产能利用率 / 客户认证"，而不是"PP 树脂价格"。

因子 3 库存与采购节奏（timing）
- BOPP 高价接货 / 爬坡损失（已发生）：新产线投产初期，良率与产能利用率双低，固定成本全额计入，形成"战略性亏损"。公司口径明确"因产能爬坡期固定成本分摊较高及公允价值变动损失增加，导致整体毛利与净利润承压"。
- 存货跌价准备 760.77 万元（同比大幅增加）：BOPP 产品试产/送样阶段的库存计提，属爬坡期正常现象，但需警惕若客户认证失败则转为实质损失。
- 公允价值变动损失 662.10 万元（外汇衍生工具）：境外收入占比仅 8.80% 却产生 662 万衍生工具损失，说明套保规模与实际敞口不匹配或方向做反，这是财务管理的负面信号。
- 验证点：存货跌价准备科目、公允价值变动损益科目、BOPP 月度出货量。
- 证伪信号：存货跌价准备连续两个报告期增加 → 客户认证失败、产品滞销。

层 2 扩展业务：主业迁移空间——"塑胶复合材料 → 电子薄膜材料"（新易盛范式）
1. 能力可迁移性：中低。拉丝气垫材料是纺织品 + 涂层复合工艺，BOPP 电容薄膜是双向拉伸聚丙烯薄膜工艺，两者在设备、工艺、原料上并非同源——这是本次迁移的最大隐忧，也解释了为什么爬坡如此痛苦（毛利率 −27.44%）。
2. 新 TAM 弹性：大。AI 服务器 + 新能源车 + 光伏三重驱动，薄膜电容年增速 >30%，高端 3μm 超薄膜进口依赖度高。
3. 切入卡位：早期。国内仅少数企业能量产 3μm 级，扩产周期 2—3 年，公司属于新增产能核心标的。
4. 客户认证门槛：高。薄膜电容器对介质材料可靠性要求极严，认证周期长（通常 1—2 年）——既是护城河也是阻力。
5. 信号验证：部分通过——① 5700 吨项目已投产并批量出货（量产跑通 ✓）；② 已送样大型头部客户测试（进入认证流程 ✓）；③ 尚未取得客户定点或大额订单公告（✗）；④ 毛利率 −27.44%，量产成本打不过旧路线（✗）。
→ 判定：主业迁移 + 技术跃迁双重属性，但硬验证点三缺二，仅作"中期期权 + 机会情景"，不计入中性锚。

层 3 风险折扣（证伪信号）
- BOPP 毛利率连续两个季度低于 −20%（Q2 单季整体 13.68%，BOPP 拖累扩大）→ 爬坡失败信号；
- 2027 年底前无客户定点 / 大额订单公告 → 认证失败，迁移证伪；
- 存货跌价准备继续大幅计提 → 产品滞销 / 认证失败；

超薄电容薄膜属"卡脖子"进口替代材料，若国家出台针对电子薄膜材料的专项扶持（如首批次应用保险补偿、国产化率强制要求、专项补贴），公司将直接受益。
- 弹性测算：若获得国产替代专项支持（补贴 + 优先采购），BOPP 认证周期缩短、毛利率提前转正 → 2029E 归母上修至 0.9 亿，PE 35x → 31.5 亿 → 18.6 元（+42.3%）。
- 验证点：工信部/发改委发布电子薄膜材料专项扶持文件；公司获得政府补助或专项补贴公告（2026H1 政府补助仅 11.12 万元，几乎为零）。
- 证伪信号：2027 年底前无相关文件；公司补助持续为零。

类型 C 市场错杀修复
部分成立。当前 PB 1.95x，相对公司历史（2023 年有息负债为 0、现金比率 2113% 的净现金状态）并不算极端；但净资产每股 6.77 元、零杠杆、账上现金充裕，若市场因 2026H1 转亏而恐慌抛售至 PB 1.0—1.2x（6.8—8.1 元），则构成典型错杀——因为亏损来自新业务爬坡而非主业崩塌，且公司完全无生存风险。
- 错杀证据：① 气密材料毛利率仍达 32.09%，基本盘健康；② 资产负债率 9.69%、有息负债 0.53 亿，无财务风险；③ 亏损主因是 BOPP 折旧分摊（会计现象），而非现金流枯竭。
- 验证点：股价 PB 分位、传统主业毛利率是否维持 30%+、经营现金流是否转正。
- 证伪信号（错杀证伪 = 基本面恶化）：气密材料毛利率跌破 25%；经营现金流连续两年为负；计提大额资产减值。

类型 D 技术突破 / 技术代际跃迁期权（本股核心上行来源，认真建模）
公司靠 4.7 亿元投产 5700 吨超薄特种电容薄膜产线，从"纺织复合材料"跨入"电子薄膜材料"，属公司不在原赛道、靠新产线/新工艺切入的技术路线跃迁，与"主业迁移（老技术换新市场）"严格区分。
- 三要素共振核查：
- ① 政策驱动技术路线：3μm 级超薄膜进口替代属《重点新材料首批次应用示范指导目录》类导向 ✓（但无专项强制政策，力度偏弱）
- ② 行业趋势向该技术收敛：AI 服务器（Rubin 平台单机薄膜电容用量翻倍）、新能源车、光伏逆变器三重驱动，薄膜电容年增速 >30%，高端超薄膜供需缺口扩大 ✓（强）
- ③ 公司技术投产落地：5700 吨项目已建成、投产并批量出货，两条进口生产线运转，产品已送样大型头部客户 ✓（量产跑通）
- 硬验证点（防画饼，三缺一不可）：
- 中试/量产良率达标 → 未公开披露，Q2 毛利率 −27.44% 反向暗示良率或利用率不达标 ✗
- 客户定点 / 大额订单 → 至今无公告 ✗
- 量产成本优于旧路线 → 毛利率 −27.44%，成本打不过 ✗
- → 判定：三要素共振成立，但硬验证点三缺三（或至多 0.5/3）。依 RULES 纪律，本项只作"机会情景"，不计入中性锚。
- 证伪信号（明确写出）：中试失败 / 良率长期不达标 / 头部客户流失或认证被拒 / 量产成本打不过进口（毛利率长期为负）/ 政策退坡早于量产 / 15000 吨项目投产后利用率 <30%。

⬆️ 什么条件下上调至"重点关注"？
必须同时满足：① 公告通过至少 1 家大型头部客户的定点或大额订单（硬门槛）；② 单季 BOPP 毛利率转正且爬升至 15% 以上；③ 股价回落至 9.5 元以下或中性净利上修至 0.9 亿元以上（使中性空间 >+50%）。若①③满足，中性可达 18.6 元（+42.3%）以上，乐观 26.5 元（+102.8%），届时可上调至"重点关注"。在现价 13.07 元且未过任何硬验证点的情况下，中性空间 −27.3%，不具备上调条件。

结论：暂不介入

判定依据：中性远期空间 −27.3%，≤0，故判"暂不介入"（不属"坚决回避"——公司业务真实、零杠杆、净资产托底，不符合 RULES.md 第三节任何排除标准）。
这是一只"下行有底、上行很美、但目前买贵了"的转型股：
- 看多的理由真实存在：赛道（3μm 超薄电容膜 + AI/新能源/光伏）景气度极高；5700 吨产线已实实在在建成投产并批量出货；公司零杠杆、净资产每股 6.77 元、完全亏得起；气密材料毛利率 32.09% 说明传统业务仍有竞争力。
- 但不能按现价买入：① 硬验证点一个都没过——无客户定点公告、毛利率 −27.44% 说明成本打不过旧路线、良率未披露；② 技术可迁移性存疑——纺织涂层复合 → BOPP 双向拉伸并非同源工艺，爬坡痛苦程度（Q2 毛利率环比 −10.15pct）已印证；③ 传统主业连续 4 年下滑，基本盘并不稳；④ 现价 PB 1.95x 已把转型成功完整定价，而中性 ROE 仅 4.4%，估值与盈利不匹配。
核心跟踪点（按重要性排序）：① 头部客户定点 / 大额订单公告；② 单季 BOPP 毛利率是否转正；③ 15000 吨项目投产后的利用率。价格锚：9.5 元以下开始看，8 元以下（接近净资产）才有真安全边际。
