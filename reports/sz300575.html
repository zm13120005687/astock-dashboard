（3）产业链传导

上游：石油化工 / 基础化工原料（中间体成本）。2026 上半年地缘冲突推高原油价格，带动中间体成本上涨（成本 + 需求双重涨价）。

下游：全球农业种植。我国农药超八成用于出口，巴西为除草剂第一大市场，非洲 / 拉美占出口量 69%。

议价权判断：中等偏强——中旗聚焦少数主力产品、以"市场份额第一"为目标，通过规模摊薄成本使产品成本达行业最低，原药毛利率半年修复 8.28pct 印证其成本领先与定价能力。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）
    原药端：原油 / 中间体涨价 ×（1 − 传导率）。中旗凭借成本领先 + 规模，传导率约 0.6–0.7（部分转嫁、部分自担但靠降本对冲）；制剂端（毛利率 27.22%）传导率更高约 0.7–0.8（品牌 / 渠道溢价）。整体 H1 原药毛利率逆势 +8.28pct，说明传导 + 降本成功。

  • 因子2 毛利结构再平衡
    原药（14.71%，占比 76.71%）是利润主引擎；制剂（27.22%）高毛利但占比仅 9.25%；中间体（26.79%）占比 3.83%。不能单一"综合毛利率 15.77%"代表全结构——原药修复是主因，制剂/中间体占比小未能完全拉动综合毛利率。随着宁亿泰原药产能释放，原药占比与毛利双升将主导结构。

  • 因子3 库存与采购节奏（timing）
    H1 行业"先扬后抑"，Q2 价格环比回升，存在低价囤货收益可能；但 6 月指数已回落，需区分当期 vs 远期毛利可比性。公司"严格管控各环节费用、成本达行业最低"表明其以降本而非库存收益为主，毛利修复更扎实。

  • 因子4 政策 / 市场锚点（原料成本驱动变量）
    政策层："一证一品"淘汰约 30% 产品 → 合规龙头份额释放（直接改供需）；出口退税取消风险（印度产能竞争）为成本 / 价格变量。市场层：原油价格（地缘）推高中间体；南美 / 非洲种植旺季驱动除草剂量价。情景：若 2027 年原药价格中枢较 2026Q2 峰值回落 10–15%，毛利结构回吐部分修复。验证点：中农立华指数月度走势、公司季度毛利率。证伪信号：原药毛利率跌回 10% 以下、份额流失。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：原药 + 中间体设计产能 2.37 万吨、在建 1.45 万吨，宁亿泰达产后总产能大幅扩张。
  • 需求侧 / 客户份额：绑定科迪华 / 拜耳 / 先正达 / 巴斯夫 / 住友，客户份额稳固；"一证一品"淘汰 30% 竞品 → 合规龙头份额提升。
  • 技术代际差：仿制为主，但创制能力（5 款进入登记）领先国内同行一代。
  • 成本曲线：规模 + 降本使成本行业最低，位于成本曲线左端。

  • 份额二阶导数：仿制原药处稳定渗透期，创制农药打开新 S 曲线。
    → 三档：保守（价格回落、份额守成）、中性（宁亿泰爬坡 + 份额小升）、乐观（创制放量 + 多产品满产）。

  • 层2 扩展业务：主业迁移空间（创制农药范式）
    能力可迁移性：从仿制到创制，技术同源（合成 / 登记能力复用），迁移成本低。新 TAM 弹性：创制农药专利保护 + 高毛利，新市场弹性数倍。切入卡位：国内农药上市公司中首家具备创制能力 + 规模 + 跨国合作的企业。客户认证门槛：新农药登记周期长（护城河）。信号验证：FG001 已申请登记、多款完成中试，信号部分兑现。→ 创制农药部分过验证点（中试 + 登记申请），可作中期期权计入乐观情景，但放量仍需时间，不计入中性。

  • 层3 风险折扣：证伪信号
    原药价格持续回落至 H1 前低位；宁亿泰投产延期；创制登记审批不及预期；印度产能竞争 + 出口退税取消冲击外销。命中则下调增量。

第五步：综合赔率判断（买不买？）

当前价格位置：明显低估。现价 6.35 元对应 PB 1.51x（破净边缘）、2026E PE 约 28x，处于农药周期复苏起点，市场尚未充分定价宁亿泰达产与创制农药期权。

安全边际：
- 中性远期 10.03 元 → 空间 +57.9%，满足"重点关注" >50% 门槛
- 悲观 5.64 元 → 下行 −11.2%（有限，PB 1.5x 提供缓冲）
- 乐观 14.63 元 → +130.4%（创制农药 + 满产）
- 下行保护：PB 1.51x、净资产 20.08 亿、经营现金流 H1 +1.67 亿（同比转正），财务扎实

介入条件：
1. 现价即可介入（6.35 元低于基准 7.20 元），分批建仓。
2. 加仓信号：① 宁亿泰二 / 三期投产公告；② 创制农药 FG001 取得登记证；③ 原药价格中枢稳于 H1 水平之上；④ 定增预案获批落地。
3. 观察指标：逐季原药毛利率、宁亿泰产量、创制登记进度、外销退税政策。

最大风险（最可能破坏逻辑的因素）：
1. 原药价格回落超预期（首要）——若 2027 年价格跌回 H1 前低位，毛利修复回吐。
2. 宁亿泰 / 定增投产延期，产能释放不及预期。
3. 创制农药审批与放量慢于预期（2027–2033 跨度长）。
4. 外销风险：出口退税取消、印度产能竞争。

结论：重点关注

理由：中性远期空间 +57.9% > 50%，行业景气复苏（一证一品 + 补库 + 价格修复）+ 宁亿泰大型产能释放 + 创制农药第二曲线三重驱动，估值 PB 1.51x 偏低，财务稳健（现金流转正、净资产厚）。TTM 负值为 2025 全年亏损的误标，2026H1 已真实扭亏，不构成排除理由。
核心跟踪点：宁亿泰达产进度 + 创制农药登记落地 + 原药价格中枢。
