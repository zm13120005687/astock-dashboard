第一步：公司是干什么的？

一句话定位：国内果蔬一体化冷链供应链服务商（"公司+基地+农户"协议基地模式 + 出口资质），2026 年 6 月以 7.00052 亿元收购江西施美药业 41.128% 股权并表，转型"果蔬 + 医药"双主业。

（3）产业链传导

上游（果蔬）：农户/协议基地（"公司+基地+农户"）、农药化肥、包装、冷链设备。
上游（医药）：原料药、辅料（手性药物需手性拆分/不对称合成，技术壁垒高）。
下游（果蔬）：商超、批发商、出口客户（美国、加拿大、东南亚、中国香港）。
下游（医药）：医院、零售药店、国家集采渠道（施美力健 1–8 批集采续标中选至 2028 年底）。

议价权判断：
- 果蔬端：弱。佐证：毛利率长期 9% 左右，营收连续三年下滑，无任何提价能力；损耗率与冷链成本受气候、油价影响大。
- 医药端：中等偏强。佐证：施美净利率 40.8%、资产负债率仅 13.2%、手性药物国家地方工程研究中心、首仿地位 + 集采中选（量有保障）。但集采意味着价格由医保局定，超额利润存在政策天花板。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）

业务线 上游变动 产品端传导 传导率 判读
果蔬流通 收购价（农户/基地）随气候与季节波动；冷链能耗、运输燃油 终端售价由商超/批发市场竞争决定 约 20–30% 弱议价权：气候减产 → 收购价涨 → 无法完全转嫁 → 毛利被压缩。2025 年毛利率仅 9.06% 即是明证
医药（施美） 原料药/辅料 集采中标价锁定至 2028 年底 约 0（价格锁定） 成本上升完全由公司承担；但手性药物原料成本低、占营收比重小，敏感度低

→ 结论：果蔬传导率 20–30%（弱），医药传导率 0 但原料敏感度低。并表后公司整体成本敏感结构显著改善 —— 这是并购的真实价值之一（2026H1 综合毛利率从 9.06% 跃升至 16.22% 即体现此点）。

因子2 毛利结构再平衡（禁止用单一综合毛利率）

业务线 2026H1 收入占比（估算） 毛利率 毛利贡献 原料敏感权重
果蔬（自营流通+出口） 约 88%（并表仅 1 个月，H1 主体仍是果蔬） 约 9–10%（2025 年为 9.06%） 约 80% 高（农产品收购价 + 冷链能耗 + 燃油）

→ 结构迁移判读（关键）：2027 年施美全年并表后，收入结构将变为果蔬约 75% / 医药约 25%，但毛利结构将变为果蔬约 25% / 医药约 75%。 单一"综合毛利率 16.22%"完全掩盖了这一剧变——必须用分部估值的根本理由正在于此。若 2029 年施美收入增至 5 亿（占比约 33%），毛利贡献将超过 85%，届时公司实质上是一家医药公司，估值体系应整体切换。

因子3 库存与采购节奏（timing）

  • 存货：2026H1 末存货账面价值 1.17 亿元，占净资产 8.13%，较上年末减少 4161.22 万元；存货跌价准备仅 115.43 万元（计提比例 0.98%）。
  • 果蔬是强季节性 + 易腐品类，库存周转快，不存在"低价囤货博行情"的空间（与工业品不同）。
  • 经营现金流 +0.9365 亿（+146.81%），净现比 1811.77%、营业收入现金比 100.31% → 回款质量良好，无通过放宽信用虚增收入。
  • → 判读：果蔬端无库存收益失真问题；现金流改善是真实的。

  • 能力可迁移性：低。果蔬冷链流通与手性药物研发无技术同源性。本次迁移是资本运作（现金收购），不是能力延伸。但控股股东层面的能力与资源（苏州国资 AMC）是可迁移的——即"找项目、做整合"的能力。
  • 新 TAM 弹性：高。中国医药市场数万亿，手性药物/心脑血管是大赛道；施美 2025 年营收仅 3.55 亿，天花板远未触及。
  • 切入时点与卡位：早期偏中段。施美已是细分（手性降压药）头部（首仿 + 集采中选 + 国家级研发平台），不是从 0 开始，卡位不错。
  • 客户认证门槛：已跨过。施美力健已中选 1–8 批国采，渠道认证已完成——这是相对第三步"层1"的重大优势。

  • → 判读：本次迁移因"已完成交割 + 标的已盈利 + 渠道已认证"，确定性显著高于一般的主业迁移期权，故本报告在中性情景中计入施美的现有业务贡献（非增量期权），但不计入管线放量、增持剩余股权、国资注入等未验证部分。

什么条件下调至"重点关注"：必须同时满足：① 公司公告增持施美至控股比例（>50%）或苏州资管发布正式资产注入方案；且 ② 施美 2027 年净利超 1.7 亿（验证 40.8% 净利率的可持续性）；且 ③ 果蔬营收止跌回升（同比转正）。三者同时满足时，2029E 中性归母可上修至 1.5 亿以上，远期空间可转正并超过 +50%。

结论：暂不介入

按 RULES 不判"坚决回避"：公司有实质主业（果蔬流通 10 亿营收、真实出口资质与现金流 0.94 亿）、有已完成交割的盈利资产（施美药业 2025 年净利 1.45 亿、净利率 40.8%、收购 PE 仅 11.7x）、有国资背景实控人 —— 不符合"主业持续萎缩 + 无在手订单 + 无新项目 + 现金流枯竭 + 无重组预期"的排除标准（缺"无新项目""现金流枯竭"两项，且并购本身即为重大新项目）。
