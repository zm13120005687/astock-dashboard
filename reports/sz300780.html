第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（pass-through）：公司标准件占比高、客户分散，传导率≈0.3–0.4（弱议价权），钢材/铝涨价多数自行消化。验证点：2026H1 毛利率仅 10.93% 印证弱传导；证伪信号：若钢价下行而毛利率未回升，说明问题在需求/费用而非成本。
  • 因子2 毛利结构再平衡：传动件（毛利率 12.42%）与非标定制件（7.21%）敏感度不同。非标定制件毛利率由 2025 年 1.75% 跳升至 7.21%，是结构修复主力；但若回归低毛利坯件接单，结构将恶化。须分业务线跟踪，禁单一综合毛利率代表全结构。
  • 因子3 库存与采购节奏（timing）：屏山基地投产初期低价备货可能虚增短期毛利，远期随产能利用率提升折旧摊薄；反之高价接货将承压。公司未披露套保比例，默认无系统性对冲。
  • 因子4 政策/市场锚点：钢材价格受产能调控 + 基建投资节奏驱动；"十五五"智能制造投资若加码，将托底下游设备需求。情景：基建/设备更新加码→需求回暖→毛利率修复；钢价反弹→毛利再承压。验证点：螺纹钢/铝价走势、PMI 新订单。

第三步进阶：份额变量与主业迁移三层法

  • 层1 现有业务（市场容量 × 份额变量）：
  • 供给侧：公司产能完整但利用率偏低（屏山爬坡），扩产节奏慢。
  • 客户份额：产品销往 40+ 国、50+ 行业，客户分散，单一客户占比低；认证周期中等。
  • 技术代际：传统铸造/机加工技术成熟但非领先一代；成本曲线位置中等（自有铸造略优）。
  • 份额加速度：标准件份额稳定、增长靠行业贝塔；非标定制件份额小幅提升。
  • 三档：保守守住（份额持平）、中性小幅提升（非标定制件扩展）、乐观抢份额（新能源汽配放量）。
  • 层2 扩展业务（主业迁移）：从"标准传动件"向"非标定制 + 机器人/机床 + 平台服务"迁移。能力可迁移（同源机加工），但机器人/机床红海、毛利率薄（6–8%），新 TAM 弹性有限；平台服务属轻资产迁移，但收入尚未起量。未过验证点，仅作中期期权。
  • 层3 风险折扣（证伪信号）：屏山持续亏损且减亏不及预期、毛利率重回下滑、机器人/机床订单无正式公告——命中则下调增量。

第四步进阶：重资产/周期股三道闸

  • 校正1 资产质量折扣：PB 2.96x 高于 1，非破净，但市值 28.6 亿对应净资产约 9.7 亿、净值比 2.96x，溢价来自期权而非资产；无金融资产未重估型安全边际。
  • 校正2 周期位置：通用设备处弱周期底部，中性净利已用保守正常化值，未用单年好年景。
  • 校正3 杠杆下行：资产负债率中等（无有息负债高企证据），但屏山持续亏损放大经营杠杆，下行情景空间可转负（悲观 −91%）。

亏损股三问

  1. 为什么亏：① 屏山新基地投产初期产能利用率不足、折旧与运营成本高（2026H1 屏山亏 −2748 万，是集团亏损主源）；② 2025 年对存货/应收账款计提约 7000 万减值（一次性，已出清）；③ 主动缩减低效益订单致收入 −10.64%；④ 研发（商业航天/机器人/工业互联网）短期拖累。
  2. 靠什么扭亏，触发时点：屏山基地产能利用率提升 + 毛利率修复（非标定制件已从 1.75%→7.21%）+ 参股投资收益稳定（年化约 0.4~0.5 亿）。触发时点：2026 下半年至 2027 年，若屏山扭亏则集团归母转正。
  3. 亏得起吗：2026H1 经营现金流 +2612 万（同比 +119.76%，已大幅转正），账面净资产约 9.7 亿，无恶化迹象；但屏山仍需持续投入，安全垫中等，能撑到扭亏。

第五步：综合赔率判断（买不买？）

当前价格位置：显著偏高（透支期权）。现价 19.50 元对应正常化净利 PE 57x，已反映机器人/商业航天预期。

安全边际：中性远期 8.50 元 → 空间 −56.4%；悲观 1.70 元（−91.3%）；乐观 17.03 元（−12.6%）——三情景均低于现价，下行保护极弱。

介入条件：① 股价回落至 8 元以下（接近中性估值）才具安全边际；② 加仓信号：屏山基地单季扭亏公告、机器人/商业航天正式大额订单落地、参股投资收益持续兑现。

最大风险：① 屏山减亏不及预期，亏损持续；② 机器人/商业航天期权始终无正式订单验证（纯概念）；③ 毛利率修复逆转；④ 通用设备需求长期疲软。

上行想象力四类情景（仅进乐观栏，不进中性锚）：
- A 行业剩者红利：通用设备出清后份额提升——验证点：行业集中度数据、公司份额公告；证伪：份额连降。
- B 政策反转期权："十五五"智能制造/设备更新加码托底需求——验证点：设备更新投资落地；证伪：政策力度不及预期。
- C 市场错杀修复：当前非错杀（基本面确实亏损），不适用。
- D 技术代际跃迁期权：商业航天发动机装配线 + 人形机器人核心传动件从 0 到 1——硬验证点（防画饼）：中试/量产线跑通 + 客户定点大额订单 + 量产成本优于旧路线，三者缺一则仅作机会情景。证伪：无正式公告、良率不达标、成本打不过旧路线。
- 上调至"重点关注"的条件：机器人/商业航天正式订单落地且 2029E 净利上修至 ≥1.5 亿（对应股价 ≥25 元、空间 >+25%），且屏山已持续扭亏。

结论：暂不介入（中性远期空间 −56.4% ≤ +50%，且三情景均低于现价；当前价格已透支未验证期权，须等回调或期权验证）。
