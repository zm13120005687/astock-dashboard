（3）产业链传导

上游：商品采购（生鲜、食品、日用百货、服饰化妆品）。2026H1 公司扩大产地与品牌厂家直采规模，新增 20 余家优质合作方，粮油自有商品实现工厂直采——去中间化是毛利率提升的核心来源（超市毛利率 +2.09pct）。

下游：新疆城乡居民消费者。收入增速目标（城镇 +7%/农村 +8%）高于 GDP，构成需求端支撑。

议价权判断：区域内中等偏强，但对上游供应商强、对消费者弱。
- 对上游：强——区域龙头采购规模 + 直采去中间化，议价权提升（超市毛利率 +2.09pct 是证据）
- 对消费者：弱——零售是充分竞争，百货以价换量（毛利率 −4.5pct）
- 自有物业是真正的护城河：物业租赁毛利率 91.50%，贡献约 26% 的毛利却仅占 9.8% 收入——这是公司相对纯租赁经营同行的结构性优势

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）：传导率约 0.7–0.8（较强）。
- 依据：零售终端可自由调价，且超市可通过品类结构替换（出清滞销 SKU 2,300 支、引进新品 2,000 支）实现"不涨价但提毛利"的软传导
- 佐证：2026H1 新品营收贡献达 10%、毛利贡献超 11% —— 新品毛利率高于均值，是"软传导"的直接证据
- → 上游（生鲜/食品）每涨 10%，公司实际毛利承压约 2–3%，可通过品类调整再消化 1–2%

因子2 毛利结构再平衡（分业务线，禁单一综合毛利率）：

业务线 2026H1 毛利率 毛利贡献占比 商品成本敏感度
商超百货商品销售（81.4% 收入） 26.20% 61.0% 极高（全部为采购成本）
物业租赁（9.8% 收入） 91.50% 25.6% 零
其他（4.3%） 45.47% 4.2% 中
物业服务（2.7%） 65.95% 5.1% 低

→ 综合毛利率 34.96% 完全掩盖了结构分化：
- 超市毛利率 21.80%（+2.09pct，改善中）
- 百货毛利率约 37.3%（−4.5pct，恶化中）
- 物业租赁 91.50%（零成本敏感，是真正的利润压舱石）
→ 零敏感业务（租赁 + 促销服务）贡献 27.9% 毛利却只占 10.9% 收入 —— 这是本股被低估的结构性优势。估值必须分业务测算，用单一综合毛利率外推会严重误判。

因子3 库存与采购节奏（timing）：
- 零售存货周转快（食品/生鲜为主），不存在大宗囤货收益
- 但存在"直采比例提升"的 timing 效应：2026H1 新增 20 余家直采方 + 粮油工厂直采，这部分毛利提升是一次性的渠道去中间化红利，不可持续年复一年
- → 不能把超市毛利率 +2.09pct 全部外推到未来三年；2027 年后直采红利将逐步衰减，需靠自有品牌/自有商品接力（公司已提出"粮油自有商品"方向）
- 验证点：超市毛利率环比变化、自有品牌销售占比披露

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务：市场容量 × 份额变量
- 市场容量：新疆 2026H1 社零 1,871.09 亿元，全年约 3,800 亿元；2026 目标 +6%，2029 按政策目标累计约 +19% → 约 4,500 亿元（按政府目标线性累加，非历史增速外推）
- 公司份额（五锚点）：
1. 供给侧份额：9 城门店网络 + 自有物业，区域零售供给刚性（新进入者建店周期 2–3 年）
2. 需求侧/客户份额：进店人次 +36.30%、会员活跃度与消费贡献占比提升；但会员数据未披露绝对额
3. 技术代际差：数智化转型（即时零售、线上商城、直播电商、全域积分互通）—— 相对本地同行（友好集团等）领先半代，相对全国性连锁（永辉、胖东来模式）落后一代
4. 成本曲线位置：自有物业（租赁毛利率 91.5%）+ 生鲜直采 → 处于区域成本曲线左侧（优势位）
5. 份额二阶导数：乌鲁木齐收入 +17.66% vs 全疆社零 +6% → 在核心市场加速渗透（S 曲线中段）；但百货仍 −7.61% → 份额提升主要靠超市而非百货
- 三档份额假设（新疆社零市占）：保守守住 0.65% / 中性 0.72% / 乐观 0.80%（2025 公司营收 24.5 亿 / 新疆社零约 3,700 亿 ≈ 0.66%）
- 验证点：① 季度超市/百货分业态收入与毛利率；② 进店人次同比；③ 门店数量与营业面积变化；④ 乌鲁木齐以外城市（库尔勒、昌吉）的收入增速
- 证伪信号：超市毛利率环比回落（说明调改红利是一次性）；进店人次增速回落至个位数；百货降幅重新扩大

层2 扩展业务：主业迁移空间
- 能力可迁移性：中——零售运营能力可迁移至：①南疆等下沉市场（政府"把南疆发展摆在突出位置"）；②即时零售/前置仓（线上化）；③自有品牌（从"卖别人的货"到"卖自己的货"）
- 新 TAM 弹性：即时零售（新疆限上公共网络零售 +40.7%、电商企业 +136%）弹性大；自有品牌毛利率通常比代理品牌高 5–10pct
- 切入卡位：即时零售属红海（美团闪购、京东秒送、抖音均已进入新疆）；南疆下沉属早期（阿克苏 2025 收入仅 0.19 亿）
- 客户认证门槛：低（零售无认证壁垒），但也意味着护城河浅
- 信号验证：即时零售收入占比未披露、南疆开店无公告 → 未过验证点，仅作中期期权，不计入中性

层3 风险折扣：证伪信号

第五步：综合赔率判断（买不买？）

当前价格位置：合理略偏高。现价 7.57 元对应 2026E PE 24.6x、PB 2.43x、PE(TTM) 32.97x。对一个高负债（68.33%）、区域集中（乌鲁木齐 47.4%）、净利率 7.4% 的区域零售商，24.6x 的 2026E PE 不算便宜——但考虑到 +88.6% 的利润增速与 2.57 亿经营现金流（2.6 倍于净利），也不算离谱。

安全边际：
- 中性远期 8.67 元 → 空间 +14.5%（>0，但远未达"重点关注"的 >50% 门槛）
- 悲观 5.31 元 → 下行 −29.9%
- 乐观 14.97 元 → +97.7%（需南疆下沉 + 即时零售 + 自有品牌三线同时兑现）
- 风险收益不对称偏负：上行 +97.7% vs 下行 −29.9%，但中位仅 +14.5%
- 下行保护：经营现金流 2.57 亿（2.6 倍净利）+ 合同负债 6.29 亿 + 自持物业隐性重估价值，构成一定安全垫；但商誉 1.40 亿与负债率 68.33% 削弱了这个垫子

介入条件：
1. 6.20 元以下（2026E PE < 20x、PB < 2.0）才具安全边际
2. 6.80–7.60 元：小仓位观察仓，等三季报验证调改红利可持续性
3. 加仓信号（需满足其二）：① 2026 三季报/年报超市毛利率维持在 22% 以上（证明调改红利非一次性）；② 资产负债率降至 65% 以下；③ 进店人次同比维持 +20% 以上；④ 即时零售收入占比披露且 >5%
4. 明确规避：在商誉减值风险未消除 + 负债率未降至 65% 以下期间，不加杠杆买入

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 超市调改红利是一次性（首要）：2026H1 超市毛利率 +2.09pct（Q2 单季 +5.2pct）主要来自生鲜直采去中间化 + 上年同期 17.95% 低基数。直采红利不可重复（已合作的 20 余家直采方不会年年新增），2027 年后毛利率提升必须靠自有品牌接力，但目前自有品牌仅"粮油"一个方向、规模未披露
2. ⚠️ 高杠杆 + 商誉双压（结构性）：资产负债率 68.33%，商誉 1.3968 亿（占净资产 9.5%）。一旦新疆消费转弱，利润下滑 + 商誉减值将同时发生，净资产快速缩水
3. 区域集中度过高：乌鲁木齐占 47.4%，新疆单一市场占 100%。新疆经济与政策高度绑定（政府工作报告目标），若"以旧换新"等补贴退坡、或人口/收入增速不及目标，将直接冲击
4. 即时零售的侵蚀：新疆限上公共网络零售 +40.7%、电商企业 +136%，但公司线上收入占比未披露。即时零售对传统商超是"客流分流 + 抽佣侵蚀"的双刃剑
5. 百货业态持续萎缩：百货收入 −7.61%，Q2 毛利率 −4.5pct 至 37.3%（以价换量）。百货是公司高毛利业态（37% vs 超市 22%），其萎缩将持续拖累结构

第五步进阶：上行想象力情景（四类）

类型A 行业调整剩者红利：新疆零售市场相对封闭，本地竞争者（友好集团等）同样承压。若区域中小零售在即时零售冲击与消费分级中出清，汇嘉作为龙头份额将被动提升。验证点：新疆限额以上零售企业数量变化、公司进店人次 vs 全疆社零增速的差值（+36.3% vs +6%，已显示份额在提升）、CR3 集中度。证伪：全国性连锁（永辉、盒马、山姆）大规模进入新疆。若成立，公司份额可从 0.72% 升至 0.85%，中性归母上修至 2.8 亿，目标价 10.1 元（+33.4%）。不计入中性锚。

类型B 政策反转期权：促消费已成为中长期制度安排（《扩大消费"十五五"规划》28 项任务 + 新疆 15 条举措）。增量反转机会：①南疆战略——自治区政府工作报告明确"把南疆发展摆在突出位置"，若出台南疆商业网点建设补贴或税收优惠，公司在阿克苏（2025 收入仅 0.19 亿）等南疆城市的布局将获得政策杠杆；②商业地产 REITs——若消费基础设施 REITs 扩容至区域零售物业，公司自持物业（租赁毛利率 91.5%）可实现价值重估与轻资产化。反转信号：南疆商业网点补贴政策；消费基础设施 REITs 扩容至区域零售商。重估弹性：自持物业重估若释放 5 亿价值，相当于每股 1.06 元。未过验证点，仅作机会情景。

类型C 市场错杀修复：部分成立。证据：① PE(TTM) 32.97x 看似高，但 2026E PE 仅 24.6x、2029E PE 17x；② 经营现金流 2.57 亿是归母净利的 2.6 倍，利润质量极高，不存在"纸面利润"；③ 券商给予 2026 年 26x PE、合理价值 10.77 元（较现价 +42%）；④ 板块整体估值偏低。修复触发点：三季报确认增长可持续 + 高现金流资产风格回归。证伪：若三季报超市毛利率环比回落，则"错杀"不成立。修复弹性：修复至券商目标 10.77 元对应 +42.3%，但需业绩持续验证。

类型D 技术突破/技术代际跃迁期权：本股不适用严格意义上的技术跃迁。最接近的是数智化转型（即时零售、线上商城、直播电商、全域积分互通、65 项标准化增值服务）——但这属于"渠道迁移"而非"技术代际跃迁"，且三要素中的"落地"要素数据未披露（线上收入占比未知）。硬验证点：线上/即时零售收入占比披露且 >5%、单客价值（会员 ARPU）提升数据。证伪：线上业务增收不增利（平台抽佣 >5%）、会员活跃度未提升。仅作机会情景，不计入中性。

什么条件出现才上调至"重点关注"：需同时满足① 资产负债率降至 65% 以下（解除杠杆下行情景约束）；② 2026 年报确认超市毛利率维持 22% 以上（证明调改红利可持续而非一次性）；③ 股价回落至 6.2 元以下（2026E PE<20x）。三者满足其二可上调至"重点关注"，当前仅满足 0 项。

结论：纳入观察

理由：中性远期空间 +14.5%，为正但远未达"重点关注"的 >50% 门槛；且资产负债率 68.33% 触发杠杆下行情景（−6.5% 至 −32.4%），按规则最高只能给"纳入观察"。
公司经营层面确实在改善（归母 +46.40%、扣非 +47.10%、经营现金流 +98.69%、进店人次 +36.30%、超市毛利率 +2.09pct、降杠杆 2.88 亿），不属"暂不介入"；
但核心问题是：① 现价 2026E PE 24.6x 已部分反映增长预期；② 调改红利含明显的一次性成分（直采去中间化 + 低基数）；③ 高杠杆 + 商誉 1.40 亿削弱安全垫。
属性标注：高贝塔区域消费股，与新疆政策与消费景气高度绑定，不适合作为核心底仓。
核心跟踪点：超市毛利率环比（判断调改红利可持续性）+ 资产负债率 + 商誉减值测试。
