第一步：公司是干什么的？

一句话定位：昆山国资旗下的中小尺寸 LCD 面板厂，主营 a-Si / LTPS 液晶显示面板，下游覆盖手机、笔电、车载、工控等，是强周期、重资产制造业。

第二步：行业景气度 + 政策/市场数据

（1）政策端（近 6–12 个月）——间接利好（国产替代）+ 无直接补贴

  • LCD 国产主导：2026H1 中国大陆厂商电视 LCD 全球出货占比 72.4%（同比 +1.9pct），京东方 27.0% + TCL 华星 24.5% 双寡头；台韩产能持续退出，中长期向 80% 靠拢。公司中小尺寸非电视主战场，受益行业格局出清有限。
  • 控产挺价共识：行业告别"满产满销、低价倾销"，转向"按需生产"，2026 年面板厂计划通过 10 月调控稼动率稳价。
  • 无专项补贴：面板属市场化竞争，无直接财政补贴；关税 / 出口管制主要影响上游材料与设备。

（3）产业链传导

  • 上游：玻璃基板、驱动 IC、偏光片、光刻胶、膜材；IC / 存储芯片 2026 上半年涨价传导至模组端成本上升（成本端承压）。
  • 下游：终端品牌（手机 / 笔电 / 车载），需求偏弱约束涨价空间——AVC Revo 预测 2026Q3 全球 TV 出货同比 −3%。
  • 议价权：弱（标准化面板、产能过剩、买方强势），成本难以向下游转嫁。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（≈0.2）：面板是成本竞争行业，IC / 膜材涨价基本自担（转嫁系数低），仅行业整体控产挺价时部分传导。
  • 因子2 毛利结构再平衡：公司 91.5% 收入来自 TFT-LCD（毛利率仅 1.35%），结构单一、无高毛利业务对冲；车载 / 工控（增速 12% / 9%）是潜在结构性改善点，但当前占比小。
  • 因子3 库存与采购节奏：面板厂存在面板价格周期下的库存收益 / 损失 timing——Q1 涨价期低价库存受益，Q3 跌价期高价接货损失；H1 毛利率 2.16% 含部分低价库存红利，不可视为真实盈利能力。
  • 因子4 政策 / 市场锚点：① 关税 / 出口管制（半导体设备、材料）抬升资本开支与成本；② 国产替代（玻璃基板、光刻胶）降本；③ 控产挺价（行业自律）是直接价格变量。情景：10 月稼动率下调成功 → 价格企稳；证伪：需求持续弱 + 新增产能（天马 8.6 代）释放 → 价格再跌、毛利转负。验证点：月度面板报价、行业稼动率公告。

自下而上测算：2026H1 营收 9.58 亿（年化 ~19 亿，下滑）。中性假设 2029 年营收恢复至 38–42 亿（行业面积需求微增 + 车载 / 工控增量 + 稼动率回升），稳态净利率 3–5%（面板中周期正常水平）→ 2029 年净利 1.2–2.0 亿。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务·市场容量 × 份额变量：中小尺寸 LCD 红海，公司份额小、无代际领先；五锚点均偏弱（供给无约束但价格战、客户份额低、技术跟随、成本曲线无优势、份额加速度负）。三档：保守营收 35 亿、中性 40 亿、乐观 48 亿。验证点：月度出货、车载客户定点。
  • 层2 扩展业务·主业迁移：由手机 / 笔电面板向车载 / 工控迁移，能力可复用（同产线），新 TAM（车载显示）增速更高；但认证门槛高（车规级），未过验证点，仅作中期期权。
  • 层3 证伪信号：面板价格再破位、IT 面板受 OLED 替代加速、车载定点无进展 → 下调增量。

第四步：估值锚定（自下而上，亏损股正常化 + 周期校正）

方法（规则四 + 第四步进阶）：强周期股，中性净利须用周期归一化（多年 trough-to-peak 中值），禁单年好年景 / 拐点年化；并做三道闸校正。

⚠️ 交叉校验：现价 3.73 元对应市值 124.33 亿，是中性正常化净利（1.6 亿）的 78 倍、是乐观净利（2.4 亿）的 52 倍。即便按面板景气高峰（净利率 8% → 3.2 亿 ×15x = 48 亿）也仅对应 1.44 元，仍远低于现价。更关键：PB 3.20x 对一家亏损面板厂显著偏高（面板业底部通常 PB<1.5x 甚至破净），当前价格并非低估而是高估。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 3.20x 但 2026H1 亏损 1.88 亿、ROE −4.72%，破净边缘的面板厂给 3.2 倍 PB 缺乏支撑；净资产 38.89 亿含产线设备（专用性强、清算价值 << 账面），重置成本不兜底。非"金融资产未重估型真破净"，不能标大空间。
  • 校正2 周期位置校正：已标注——当前底部偏弱复苏，中性净利取周期中值 4%（非底部 1%、非景气 8%），避免拐点年化误导。
  • 校正3 杠杆下行情景：资产负债率 = (66.63−38.89)/66.63 ≈ 41.7%，杠杆中等；但重资产 + 经营杠杆高，若价格再破位，净利可几倍跳负（悲观情景净利 0.4 亿已反映），空间转负，不得标大空间。

亏损股三问

  1. 为什么亏：面板行业价格低位运行 + 产能结构性调整 + IT 面板受新增 8.6 代线挤压，毛利率仅 2.16%（Q2 1.81%），费用率 17.87% 高于毛利覆盖——属行业周期底部 + 结构性供过于求，非主业崩坏。
  2. 靠什么扭亏，触发时点：① 行业控产挺价（10 月稼动率调控）若成功 → 价格企稳回升；② 车载 / 工控高增速赛道增量；③ 中性假设 2027–2028 年随周期回暖扭亏（净利率回到 4% 中值）。
  3. 亏得起吗：总资产 66.63 亿、净资产 38.89 亿、经营现金流 H1 +2408 万（仍为正），国资背景融资渠道通畅，短期不会资金链断裂；但连续亏损消耗净资产，若价格长期低位则净资产持续走低。

第五步：综合赔率判断（买不买？）

当前价格位置：明显高估。现价 3.73 元对应市值 124 亿，中性正常化净利仅支撑 19 亿（0.58 元），且 PB 3.2x 对亏损面板厂偏高。
安全边际：中性远期 0.58 元 → −84.5%；悲观 0.12 元 → −96.8%。下行保护极弱。
介入条件：① 回落至 1.0 元以下（接近 PB 破净、对应周期中值估值）；② 加仓信号：面板价格趋势性回升（月度报价连涨 3 月）、车载定点公告、净利率转正；③ 观察：行业稼动率与 TV/IT 面板报价。
最大风险：① 面板价格再破位、行业供过于求加剧；② OLED 对中尺寸 LCD 替代加速；③ 连续亏损侵蚀净资产 + 高 PB 戴维斯双杀。
结论：暂不介入（估值偏离正常化盈利与资产质量，周期底部亏损且 PB 偏高；仅作面板周期反转期权观察）。
