（3）产业链传导

上游：土地（自有/存量）、建材（价格下行利好开发成本）、融资成本（国企低利率）。

下游：企业租户（AI/硬科技扩张为增量）、购房者（政策松绑释放）。

议价权：核心区稀缺物业强（租金溢价）；开发业务弱（房价下行被动）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：开发业务房价由市场定（传导率≈0，毛利被房价下行吃）；租赁业务定价权强（核心区 80% 毛利）。
  • 因子2 毛利结构再平衡：物业租赁（80% 毛利，稳定）vs 房产开发（15% 毛利，波动大）。开发亏损拖累整体，租赁为利润压舱石。
  • 因子3 库存与采购节奏：开发存货（历史高地价项目）跌价风险；现低价拿地/盘活降低边际成本。
  • 因子4 政策/市场锚点：商办首付/利率（政策层）、北京写字楼租金（市场层）。情景：政策反转 + 租金筑底 → 开发减值收窄、NAV 修复。验证点：北京核心区租金、出租率。

输出喂第四步：正常化净利以租赁现金牛为基 + 开发企稳。

第三步进阶：份额变量与主业迁移空间

  • 层1 份额变量：核心区优质资产稀缺（供给侧锚点），AI/硬科技租户扩张（需求侧）。中性：守住核心；乐观：核心区份额提升。验证点：核心区空置率、租金。
  • 层2 主业迁移："商改办/商改产业园"业态转换（存量资产重估），新 TAM 有限，属存量优化。未过验证点不计入中性。
  • 层3 证伪信号：北京写字楼租金继续下行、出租率破 20%、开发存货再减值。

第四步：估值锚定（正常化净利润法 + 三道闸）

总股本：约 29.89 亿股；归母净资产 214.22 亿，每股净资产 7.17 元，PB 0.40；总资产 1106 亿 → 资产负债率 80.6%（极高）。

第四进阶·三道闸

校正1 资产质量折扣（破净原因）：PB 0.40 破净，原因 = 重资产地产，账面价值（历史成本）远高于公允价值（商办价格下跌、出租率/租金下行），NAV 大幅低于账面 → 破净是公允定价（资产虚高），非未重估金融资产安全边际。不可单凭 PB<1 推大空间。

校正2 周期位置校正：地产处周期底部、政策反转初期；中性净利用周期归一化（开发企稳 + 租赁稳健），禁单年好年景/拐点年化。中性稳态：开发亏损收窄至微利 + 租赁年贡献 ~10 亿毛利 → 归母 ~10 亿。

校正3 杠杆下行情景：资产负债率 80.6% 极高，利率上行/需求下行 → 净利可转负、NAV 再折价，空间转负 → 不得标大空间。悲观情景体现。

亏损股三问

  1. 为什么亏：开发业务毛利率仅 15%（房价下行、存货跌价），Q2 开发集中结转亏损 -4.32 亿；物业租赁稳健但被开发拖累。属地产周期底部 + 开发低毛利/减值，非主业消失。
  2. 靠什么扭亏·触发时点：① 开发去化 + 房价企稳（政策止跌回稳）；② 物业租赁稳定现金流（80% 毛利，年贡献 ~10 亿毛利）；③ 商办去库存政策（首付 30%）；④ 城市更新盘活重估。触发：2026H2–2027 开发亏损收窄，2027 全年扭亏。
  3. 亏得起吗：物业租赁年现金流强（毛利率 80%），H1 经营现金流 +5.87 亿（转正）；但总资产负债率 80.6% 高，靠经营现金流 + 西城区国资背景融资。能撑，但杠杆极高需警惕。

第五步：综合赔率判断（买不买？）

当前价格位置：PB 0.40 破净（NAV 虚高，公允定价）；现价处历史低位，已反映较悲观预期。

安全边际：
- 中性远期 3.01 元 → +14.4%（>0，<50%）
- 悲观 1.34 元 → −49.0%（高杠杆 + NAV 再折价）
- 乐观 5.35 元 → +103.4%（政策反转）
- PB 0.40x 有资产面缓冲但清算价值低

介入条件：
1. 待开发业务确认减亏（Q3 单季扭亏信号）
2. 加仓：北京核心区租金筑底 + 出租率回升 + NAV 折价收敛
3. 止损：资产负债率恶化、开发存货再大额减值

最大风险：
1. 资产负债率 80.6% 极高，利率/需求下行反噬（首要）
2. 商办价格继续下跌，NAV 再折价
3. H2 开发结转亏损扩大（Q2 已 -4.32 亿）

结论：纳入观察（逻辑为减亏 + 政策反转期权，但高杠杆下行风险大，需等拐点确认）
