永安林业（000663）五步法分析报告

分析日期：2026-09-26 ｜ 现价 6.08 元 ｜ 总市值 20.45 亿 ｜ PE(TTM) 亏损 ｜ PB(LF) 约 2.25x ｜ 总股本 约 3.36 亿股
行业：林业 / 人造板 / 碳汇 / 家居 ｜ 板块：深市主板
关键判定：2026H1 真实归母净利 −1933.62 万元（亏损），按亏损股处理，采用正常化净利润法估值。
特别提示：2026-09-24 公司起诉 4 名前高管追偿 3276 万元（证券虚假陈述案），计入营业外不影响主业判断。

第一步：公司是干什么的？

一句话定位：中林集团旗下唯一 A 股上市林业平台，主营森林经营（国储林 / 碳汇）与板材家居（人造板制造），正从"砍树卖材"向"种树卖碳"战略重塑。

核心产品：中 / 高密度纤维板（门板、装饰线条板、家具板、地板基材、钢琴板）、种苗（青龙桉、巨桉、互叶白千层、金线莲）、"永林蓝豹"地板、福人空间（独占许可）全屋定制。

主要客户 / 下游：建材家居渠道、工程项目（厦门翔安新机场入选）、终端消费者；林木业务面向碳汇交易与国储林。

资源禀赋：拥有约 117 万亩林地资源；国储林莆田项目（进度 42.13%）、漳州项目（进度 67.48%）；VCS 国际核证碳汇 28.7 万吨减排量已完成销售，三明林业碳票 10307 吨 CO₂ 当量已备案。

股东背景：控股股东中国林业集团（央企，由中国长江三峡集团托管）；2026 年 3 月提出避免同业竞争具体措施。

（3）产业链传导

上游：木材原料、胶粘剂；H1 原材料采购与国储林收储支出致经营现金流 −3139 万（同比 −465%）。

下游：建材家居、工程、碳交易市场。碳汇业务下游为全国碳市场控排企业，需求刚性上升。

议价权：中。人造板竞争激烈、议价偏弱；但林地 / 碳汇资源具稀缺性与排他性（中林唯一上市平台），政策议价权强。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：人造板对木材 / 胶黏剂涨价传导率约 0.4–0.5（竞争强，难全转嫁）；碳汇业务无原料成本，毛利近 100%。→ 综合传导率约 0.4。
  • 因子2 毛利结构再平衡：人造板毛利率约 12%（H1 综合），碳汇 / 种苗毛利极高但体量小；未来碳汇占比提升将结构性抬升综合毛利。分业务给毛利率，禁用单一综合值。
  • 因子3 库存与采购节奏：原料囤货低位可获收益；国储林收储为长期资产投入，不计入当期毛利。
  • 因子4 政策 / 市场锚点：碳价（全国碳市场 CEA 价格）、国储林补贴政策。验证点：碳价走势、补贴发文；证伪：碳价大跌、补贴退坡。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 现有业务（市场容量 × 份额变量）：人造板充分竞争，公司份额小且底部；林业碳汇份额取决于资源禀赋（117 万亩稀缺）。三档：保守（守住）→ 中性（国储林收获小幅提升）→ 乐观（中林注入跃升）。验证点：国储林收获量、碳汇成交量。
  • 层2 扩展业务（主业迁移空间）：从"木材采运"迁移至"碳汇 + 生态修复 + 全屋定制"，能力可迁移（同源林地资源），新 TAM（碳市场）弹性大。未过验证点仅作中期期权。
  • 层3 风险折扣（证伪信号）：中林注入延期 / 落空、国储林收获不及预期、碳价大跌 → 下调或剔除增量。

第四步：估值锚定（自下而上，非增速外推）

亏损股估值法：正常化净利润法。2026H1 仍亏，用资产整合 + 稳态主业推导正常化净利。

总股本：约 3.36 亿股（总市值 20.45 亿 ÷ 现价 6.08）。归母净资产 9.10 亿，负债率约 37%（低），现金厚。

亏损股三问

  1. 为什么亏：人造板行业底部 + 原料采购致现金流负 + 光大银行股公允 −363 万 + 生物质能减值 685 万（部分一次性）。
  2. 靠什么扭亏：国储林 2027 收获 + 碳汇交易放量 + 中林资产注入 + 家居品牌溢价。触发时点：2027 年起。
  3. 亏得起吗：净资产 9.10 亿厚、负债率仅 37%、现金充裕，安全边际充足，可撑至拐点。

第四步进阶：重资产 / 周期股校正

  • 校正1 资产质量折扣：PB 2.25x，但 117 万亩林地 + 国储林资产权属清晰（首张不动产权证），清算价值有支撑，非伪破净。
  • 校正2 周期位置：人造板处周期底部，中性净利已按底部保守计，不过度悲观。
  • 校正3 杠杆下行情景：负债率低，下行空间有限；若注入延期，悲观情景 −58.9% 已体现。
  • 期权纪律：中林资产注入为未过验证点期权，仅放乐观情景，不计入中性锚。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高。现价 6.08 元对应中性远期 3.93 元（空间 −35.4%），已部分透支整合预期。

安全边际：中性 −35.4%；乐观 +83.6%（需注入落地）；悲观 −58.9%。不对称——上行依赖未落地期权。

介入条件：现价不追高；① 中林资产注入预案正式披露 → 上调至重点关注；② 国储林收获量 / 碳汇成交量连续两季兑现；③ 股价回落至 4.0 元以下（接近中性价值）增强安全垫。

最大风险：① 中林整合延期 / 落空（同业竞争承诺已收警示函）；② 人造板持续底部；③ 前高管诉讼追偿执行不确定；④ 三峡托管解除时间存疑。

结论：纳入观察

逻辑正确（中林唯一上市平台 + 国储林 / 碳汇真实资产 + 低负债安全垫），但中性估值低于现价，价值兑现依赖未落地的资产注入。待注入预案披露即具备上调至"重点关注"的条件（乐观情景 +83.6% 空间）。
