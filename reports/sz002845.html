上游：显示模组上游为面板 + 驱动 IC + 背光/偏光片；摄像头上游为 CMOS 图像传感器（Sony/豪威）+ 镜头 + VCM；封测上游为晶圆（12 寸）+ 金靶材/化学品。2026H1 显示驱动 IC 与面板价格相对平稳，CMOS 价格趋稳。上游议价权判断：弱（模组厂在面板厂与品牌商之间夹心，2026H1 财务费用 3,010 万、研发费用 7,914 万吞掉微薄毛利）。

产业链位置与议价权：模组环节弱（薄利、无定价权）；封测环节中等偏强（OSAT 模式，28nm 能力稀缺，日月同芯产能满产、报价上行）。结构迁移方向：从"低毛利模组"向"高价值封测"迁移，是公司唯一的利润结构改善路径。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1 · 成本传导弹性（pass-through）
- 显示模组：传导率 ≈ 0.4–0.5（弱）。面板+驱动 IC 占成本 80%+，模组厂对品牌商无定价权，成本上涨仅能部分转嫁。依据：10.37% 薄毛利。
- 摄像头模组：传导率 ≈ 0.3（很弱）。同质化严重、价格战，5.65% 毛利即为佐证。
- 封测（日月同芯）：传导率 ≈ 0.7–0.8（强）。OSAT 产能紧俏 + 日月光涨价 20%，公司可跟随调价。
- 加权转嫁系数 ≈ 0.45：上游面板/CMOS/晶圆涨 10%，综合毛利承压约 5.5%。

层 2 · 扩展业务：主业迁移空间（新易盛范式）
- 能力可迁移性：中高——模组制造 → 封测（同为精密制造，但封测技术门槛更高），公司通过与日月光合资获得技术注入
- 新 TAM 弹性：大——先进封测市场（半导体）远大于模组制造，且景气上行
- 切入卡位：较早——2021 年即设立日月同芯，2026 年已满产，先发红利
- 认证门槛：高——封测客户认证周期长（豪威、集创北方、格科微等），粘性强
- 信号验证：已过部分——满产、月产能破 1.95 万片、2026 产值目标翻倍
- 结论：迁移路径清晰、部分验证点已过，可部分计入中性情景

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1 · 资产质量折扣：公司 PB 1.77x，未破净。但资产负债率 73.47% 偏高，有息负债约 16.2 亿（2025 年报）、速动比率 0.76、流动比率 1.01——营运资金紧平衡，且 2026H1 经营现金流 −5.24 亿。净资产质量需打折（大额应收 + 存货占款）。无"股权未重估型破净"情形。

校正 2 · 周期位置校正：显示模组属面板产业链，有面板周期属性（当前处于控产保价、需求温和复苏的上行初期）；封测属半导体周期，景气上行（日月光涨价 20%）。中性情景未对周期高点做假设（净利率仅 1.0–1.5% 的模组线近乎保守），安全垫充足。当前周期位置：面板=上行初期，封测=景气上行。

校正 3 · 杠杆下行情景：资产负债率 73.47%（高），2026H1 财务费用 3,010 万、经营现金流 −5.24 亿。负面情景：若下游需求下行 + 模组价格战 + 封测延产，高杠杆放大净利下行，悲观 8.85 元（−34.9%）。但公司无短期偿债危机迹象（有息负债率 23.40%，且筹资现金流 +3.36 亿）。因杠杆偏高，中性空间有限，结论至多"纳入观察"。

期权纪律：CoWoS 前道延伸、Chiplet/混合键合/TSV、封测三期等未过验证点的期权不计入中性，仅列乐观情景；日月同芯二期因已扩建、已过部分验证点，计入中性。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵。现价 13.59 元对应 2026E PE 约 59x（微利）、PS 0.44x、PB 1.77x。市场按"营收规模 + 封测期权"定价。

- 中性远期 15.88 元 → 空间 +16.9%，满足"纳入观察 >0"，不满足"重点关注 >50%"
- 悲观远期 8.85 元 → 下行 −34.9%，风险不对称偏负

第五步进阶：上行想象力情景（四类）

类型 A · 行业调整剩者红利（中等弹性）

类型 B · 政策反转期权（中等弹性）
半导体自主可控 + 大基金三期 + 先进封装国家战略 → 国产驱动 IC 封测需求提升，日月同芯直接受益；以旧换新国补若加码，消费电子需求上行。

类型 C · 市场错杀修复（中等弹性）
公司因 TTM PE 高（54.79x）被部分资金回避，若市场认识到封测业务（日月同芯）价值被低估（满产 + 28nm 领先 + 日月光背书），存在估值修复空间。

类型 D · 技术突破 / 技术代际跃迁期权（强弹性）
封测从"显示驱动"向"AI 算力先进封装"跃迁：① 政策驱动（先进封装国家战略）；② 行业趋势（AI 算力爆发，2.5D/3D 先进封装是后摩尔破局技术，日月光涨价 20%）；③ 公司落地（已具备金凸块批量能力，正在研发混合键合、TSV——3D 封装核心工艺，直接关联 AI 芯片/HBM）。
硬验证点：① 中试/量产良率达标（金凸块已满足）；② 客户定点/大额订单（部分满足，封测已满产）；③ 量产成本优于旧路线（未验证）；④ 混合键合/TSV 从 0 到 1 投产（未验证）。前两项已过 → 可部分计入中性；后两项若过 → 上调重点关注。

什么条件出现才上调至重点关注：① 封测业务收入占比 >15% 且单独盈利；② 混合键合/TSV 或非显示类封测（Chiplet）获客户定点；③ 资产负债率降至 65% 以下、经营现金流转正。三者同时满足 → 上调为重点关注（远期空间将 >50%）。

结论：纳入观察
