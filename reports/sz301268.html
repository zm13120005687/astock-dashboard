第一步：公司是干什么的？

一句话定位：一站式精密结构件供应商，以精密压铸/注塑/型材冲压/五金冲压技术，为新能源汽车、光伏、储能三大主业提供金属及塑胶结构件，并布局液冷散热、机器人新兴领域。

核心产品：新能源汽车结构件（电池托盘、壳体等）、光伏逆变器结构件、储能结构件、液冷散热结构件、机器人结构件。

主要客户/下游：新能源汽车（第一营收主力，深度配套国内外头部客户）、光伏（逆变器结构件核心工艺）、储能（海内外需求高增）。国家级制造业单项冠军（光伏逆变器精密结构件，第九批）。

境内外收入占比：国内为主 + 海外基地（匈牙利、墨西哥）建设中；海外基地处投入/爬坡期，阶段性亏损。

股东背景：民营控股；2022 年上市，发行可转债（余额约数亿，利息负担重）。2026-02 终止肇庆新能源关键零部件项目（审慎收缩）。

（3）产业链传导

上游：铝锭（压铸/冲压主材）、钢材、塑料粒子。铝价 2026 维持高位，直接侵蚀毛利。公司采购以现货/长协结合，部分转嫁但弱（买方/客户强势）。

下游：整车厂、光伏逆变器厂、储能集成商。客户集中度高、议价强，结构件同质化竞争致转嫁难。

议价权：弱。证据：① 毛利率仅个位数（压铸 4.36%、冲压 6.52%），说明成本无法有效转嫁；② 客户集中、行业分散、价格战；③ 海外基地未达规模，成本曲线右移。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数）：铝锭占压铸/冲压成本主体，公司转嫁系数 ≈ 0.3–0.5（弱议价），铝价上涨大部分自吞；塑料粒子转嫁系数 ≈ 0.4。结论：原料涨 → 毛利被吃，当前毛利结构脆弱。
  • 因子2 毛利结构再平衡：压铸（44.9% 营收）毛利率 4.36% 且下滑，冲压（38.75%）6.52% 改善，注塑（13.4%）下滑。结构迁移：冲压（新能源车身/电池结构件）毛利改善是亮点，压铸受光伏/铝价拖累。单一综合毛利率 8.6% 掩盖了"压铸失血、冲压回血"的结构分化。
  • 因子3 库存与采购节奏（timing）：铝价高位下，无显著囤货收益；海外基地（匈牙利/墨西哥）处于投入/爬坡，产生阶段性库存与接货损失（产能未释放、固定成本摊薄不足）。当期毛利含海外基地亏损，不可比后期稳态。
  • 因子4 政策/市场锚点（原料成本驱动变量）：① 铝价（市场层）：高位震荡，若回落则毛利修复；② 关税/本地化（政策层）：美/欧关税逼迫海外建厂，短期抬成本、长期避关税；③ 汇率（市场层）：人民币升值致汇兑损失（H1 财务费 +120.91%）。验证点：铝价、海外基地产能利用率、汇率。证伪信号：铝价持续高位 + 海外基地利用率 <50% 致毛利长期破 5%。

增量逻辑（自下而上）：远期增量 = 三大主业产能释放（新能源/储能增长 + 光伏修复）× 海外基地达产（从失血转盈利）。2026H1 营收 17.36 亿，全年 ~37 亿；2029 中性假设海外基地达产 + 储能高增 → 营收 ~55 亿。

第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：精密结构件分散，公司为新能源车/光伏头部客户核心供应商，单项冠军背书。
  • 客户份额：深度配套国内外头部客户，存量项目放量 + 新项目落地。
  • 技术代际差：压铸/注塑/冲压一体化能力，单项冠军。
  • 成本曲线：规模 + 海外本地化改善成本，但当前右移（爬坡）。
  • 份额加速度：储能新客户拓展拉动。
    → 中性：主业份额稳中升。验证点：季度营收、海外基地产能利用率、新客户公告。
  • 层2 扩展业务：主业迁移空间——由新能源/光伏结构件向液冷散热（AI 算力）+ 机器人结构件迁移，能力可迁移（精密制造同源），新 TAM 弹性大。但处早期、未过验证点，仅作中期期权，不计入中性。
  • 层3 证伪信号：海外基地利用率长期 <50%、铝价持续高位、核心客户订单流失、储能价格战致毛利破阈。

第四步：估值锚定（自下而上，非增速外推 · 亏损股正常化法）

方法说明：亏损股无正净利可锚，采用正常化净利润法：① 估稳态营收（产能满产+在手订单）；② 算正常化净利率（取历史最好/行业正常/产能爬坡理论之保守值）；③ 正常化净利 × 远期合理 PE。总股本 4.008 亿股。

核心假设（自下而上）：
- 稳态营收：2029 中性 ~55 亿（海外基地达产 + 储能/新能源增长 + 光伏修复）；悲观 45 亿；乐观 65 亿
- 正常化净利率（保守）：取历史正常年份与产能爬坡理论之低值。2022（高峰）净利率 12.5%、2023 为 7.9%，但考虑结构件行业平均偏低 + 海外基地达产后折旧，保守取中性 5.5%、悲观 4%、乐观 7%
- 合理 PE（精密制造/新能源链，扭亏后）：中性 22x、悲观 18x、乐观 25x

亏损股三问（必答）

  1. 为什么亏：四重叠加——① 海外基地（匈牙利/墨西哥）处投入/爬坡期，产能未释放、固定成本摊薄不足 + 阶段性亏损；② 光伏去库存致客户结构调整、竞争加剧、毛利率维持低位；③ 高负债（可转债 + 融资）利息重，H1 财务费 7914 万（+120.91%，含汇兑损失）；④ 谨慎计提存货/应收减值。属"产能爬坡期 + 周期底部 + 财务费用拖累"型亏损，非主业持续恶化。
  2. 靠什么扭亏，触发时点：① 海外基地产能释放（匈牙利/墨西哥达产，从失血转盈利）——核心扭亏点，预计 2027–2028 年；② 光伏供需改善、核心客户订单修复；③ 储能高增 + 新客户；④ 财务费用随可转债转股/降息回落；⑤ 减值减少。中性假设 2027 年大幅减亏、2028 年扭亏为盈。
  3. 亏得起吗：净资产 14.87 亿（2026H1，同比 −7.15%，仍为正，未资不抵债）；账面现金 + 银行授信 + 剩余可转债募资可覆盖中短期亏损；但 H1 经营现金流 −1.95 亿（净流出），短期靠融资与授信续命，若亏损延续超 2 年或海外基地持续失血则压力上升。结论：中短期亏得起，但杠杆与现金流是首要风险，须跟踪经营现金流转正时点。

第四步进阶·重资产/周期股估值校正

  • 校正1 资产质量折扣：PB 3.37（未破净），净资产为正，无破净折价问题；但需警惕若持续亏损致净资产进一步下滑。
  • 校正2 周期位置校正：新能源/储能处上行周期，光伏处底部回升。正常化净利 3.03 亿 已用周期归一化（取保守净利率 5.5%，非 2022 高峰 12.5%），标注当前周期位置为"新能源上行 + 光伏底部回升 + 海外爬坡"。
  • 校正3 杠杆下行情景：资产负债率偏高、财务费重。悲观情景正常化净利降至 1.8 亿、市值 32.4 亿对应 8.08 元（−31.6%），若叠加周期下行（新能源价格战）致正常化净利转负，则空间进一步下探，不得标"大空间/重点关注"。下行保护弱（经营现金流负、杠杆高），须注明高贝塔属性。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（按 2026 正常化锚）。现价 11.82 元对应 2026E 正常化市值 47 亿，远高于基准正常化锚 5.5–7.0 元区间——市场已提前定价 2028+ 扭亏。按远期 2029 中性 16.64 元，当前仍有 +40.8% 空间。

安全边际：
- 中性远期 16.64 元 → 空间 +40.8%
- 悲观 8.08 元 → 下行 −31.6%，高杠杆放大下行
- 乐观 28.38 元 → +140.1%，需扭亏 + 海外达产 + 储能高增三击

介入条件：
1. 安全边际区间：回落至 8.5 元以下（接近悲观情景、2026 正常化锚上沿）才具实质安全边际
2. 加仓/转重点关注信号：① 海外基地产能利用率确认 >70%、由亏转盈；② 单季度归母转正（2027 起）；③ 经营现金流由负转正；④ 铝价回落 + 毛利率回升至 10%+
3. 观察指标：海外基地进度、单季净利率、财务费、经营现金流

最大风险：① 海外基地持续失血、达产不及预期（首要）；② 高负债 + 经营现金流负，融资环境收紧致流动性风险；③ 铝价高位 + 价格战致毛利率长期低位；④ 核心客户订单流失。

结论：纳入观察（典型扭亏拐点标的，远期空间 +41%、弹性大，但 2026 仍亏、杠杆高、现金流负，须等海外基地扭亏与现金流转正验证，严禁按题材追高）

上调至"重点关注"的条件：海外基地确认盈利（单季归母转正）+ 经营现金流转正 + 毛利率回升至 10%+，则正常化净利可上修、乐观情景（28 元）可信度提升。

第五步进阶·上行想象力情景（四类）

  • 类型A 行业调整剩者红利：新能源/光伏结构件出清，头部（单项冠军）份额提升、定价权修复。验证点：行业集中度、公司份额、毛利率。重估弹性：净利率由 5.5%→8%。
  • 类型B 政策反转期权：新能源车/储能政策加码、光伏供需彻底改善，订单放量。验证点：装机/装机政策、客户订单。未过验证点仅作机会情景。
  • 类型C 市场错杀修复：当前按亏损 + 高负债被压制，若 2027 扭亏兑现，估值从"亏损折价"重估为正常制造 PE。验证点：扭亏公告、季报转正。
  • 类型D 技术突破/代际跃迁期权：液冷散热（AI 算力）+ 机器人结构件从 0 到 1 量产，打开全新曲线。硬验证点：客户定点/大额订单 + 量产成本优于旧路线（当前早期，未完全验证），暂作机会情景，不计入中性。
