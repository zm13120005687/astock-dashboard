第二步：行业景气度 + 政策/市场数据

（1）政策端（近 6–12 个月）——强利好，国家级强制替代窗口

  • 信创深水区：2026 年信创从试点全面进入"真替真用"深水区，央国企 / 政务系统国产化加速冲刺；国资委 79 号文目标 2027 年核心系统 100% 国产化。
  • 中间件国产化硬指标：政策明确金融、电信、能源等八大行业 2027 年前国产中间件市场占有率超 70%；2026 年金融 / 政务行业信创替代率预计达 85%+。
  • "十五五"基础软件攻关：2026 政府工作报告强调"实施产业基础再造工程"对中间件等基础软件专项支持；政策由"鼓励研发"升级为"强制采购 + 供应链成熟度评价"。
  • 信创安全产品目录更新（2026）：中间件多类新增入选，国产替代成熟度提升。

（3）产业链传导

  • 上游：无大宗原料，主要成本是人力（研发）与云资源；受算力 / 芯片（华为昇腾等）价格影响弱（软件业）。
  • 下游：电信 / 金融 / 政企甲方，信创强制采购托底需求；但云厂商自有中间件（开源 + 自研）形成替代竞争。
  • 议价权：中（国产替代政策护城河）但受云厂商价格战挤压，呈中等偏弱。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（≈0.3）：软件业无原材料成本，主要"成本"是研发人力；信创强制采购给予一定定价权，但云厂商低价 / 捆绑模式压制，转嫁系数中等。
  • 因子2 毛利结构再平衡：中间件（80%+）为高毛利主体，智能运维（60–70%）、AI 大数据（50–60%）毛利递减；若低毛利新业务占比提升，综合毛利率结构性下行（需分业务看，禁单一综合毛利率）。
  • 因子3 库存与采购节奏：无库存概念，以项目交付；不存在囤货收益，但存在大项目验收节奏导致的收入波动（timing）。
  • 因子4 政策 / 市场锚点：① 信创强制采购节奏（2027 节点）是直接需求变量；② 云厂商自研中间件（开源）是价格 / 份额压制变量；③ 国产 CPU / OS 适配生态。情景：2027 节点前行业信创冲刺 → 订单放量；证伪：云厂商低价替代加速、电信 / 金融集采压价 → 毛利率破 60%。验证点：信创集采中标公告、年报营收增速。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务·市场容量 × 份额变量：中间件国产替代空间大（2027 前超 70%），公司居头部；五锚点：供给侧无约束、客户份额（电信 / 金融核心）中高、技术代际（国产第一梯队）、成本曲线（规模效应潜力）、份额加速度中高（政策驱动）。三档：保守营收 2.5 亿、中性 3.0 亿、乐观 4.0 亿。验证点：信创集采中标、金融 / 电信客户扩容。
  • 层2 扩展业务·主业迁移：由"中间件"向"云原生 / AI 原生全栈 + AIOps"迁移，能力可复用（同基础软件），新 TAM（AI 基础设施）更大；认证门槛（客户生态适配）中，未过验证点（AI 大数据仍场景化落地期），仅作中期期权。
  • 层3 证伪信号：信创集采份额流失、云厂商低价替代、营收增速转负、费用率反弹 → 下调增量。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非重资产，PB 3.10x（净资产 5.92 亿），无破净，净资产以现金 / 理财为主，质量较好。
  • 校正2 周期位置校正：非强周期，不适用。
  • 校正3 杠杆下行情景：资产负债率 = (6.29−5.92)/6.29 ≈ 5.9%，极低杠杆；但经营杠杆高（研发刚性），若信创订单不及预期，净利可转负（悲观情景已反映），空间转负（−67.4%），不得标大空间。

亏损股三问

  1. 为什么亏：营收规模仍小（年化约 1.9 亿）+ 研发投入占营收 45.19%（全额费用化）+ 销售费用，费用率远高于毛利率覆盖；属"高研发投入期 + 规模未起量"，非主业崩坏。
  2. 靠什么扭亏，触发时点：① 营收随信创 2027 节点放量（电信 / 金融核心系统替代）；② 费用率随规模效应回落（研发占比已从 55.69% 降至 45.19%）；③ 中性假设 2027–2028 年扭亏（净利率回到 14% 中值）。
  3. 亏得起吗：总资产 6.29 亿、净资产 5.92 亿、经营现金流 H1 −227 万（较去年 −1253 万大幅改善），账面现金充裕，短期不至资金链断裂；民营无国资兜底，但低杠杆 + 现金厚，可支撑至扭亏。

第五步：综合赔率判断（买不买？）

当前价格位置：高估 + 高不确定性。现价 24.23 元对应中性正常化净利 44 倍 PE，且 2026 仍真实亏损。
安全边际：中性远期 16.61 元 → −31.4%；悲观 7.91 元 → −67.4%。仅乐观（36.92 元，+52.4%）反超现价。
介入条件：① 回落至 16 元以下（接近中性目标价）且出现营收加速 / 减亏信号；② 加仓信号：信创集采大单中标、单季归母扭亏、费用率继续下行；③ 观察：信创 2027 节点前订单落地节奏。
最大风险：① 云厂商（阿里 / 华为）自研中间件低价替代，份额与毛利率双杀；② 信创订单兑现不及预期、集采压价；③ 高估值 + 持续亏损的戴维斯双杀。
结论：暂不介入（估值高、实质亏损、信创竞争激烈；乐观情景虽具 +52% 弹性，但中性偏负，需先验证订单落地，不足以构成买点）。
