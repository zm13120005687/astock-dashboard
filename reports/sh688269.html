第一步：公司是干什么的？

一句话定位：国内精细化工贵金属催化剂龙头（炭载/均相贵金属催化剂），构建"研发—中试—产业化—废旧贵金属回收"全产业链，向高端非贵金属催化剂与 HNBR 氢化丁腈橡胶新材料转型。

（3）产业链传导

上游：铂/钯/铑/钌等贵金属（占成本绝大部分），价格随全球大宗商品波动；公司废旧催化剂回收业务对冲部分成本。

下游：医药/农药/化工/环保新能源，需求刚性且新药/品质升级带动催化剂放量（医药 +122.60%）。

议价权：中等偏弱。贵金属成本占比极高，原料涨价难以转嫁（转嫁系数 ≈0.3）；加工业务（33.84% 毛利）议价相对好；回收闭环提供一定成本缓冲。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（转嫁系数）：贵金属原料占催化剂成本主导，公司对下游转嫁系数低（≈0.3），Q2 毛利率 −13.87pct 即成本/结构双杀印证。验证点：季度毛利率（H1 8.36% vs 2025 全年 11.96%）。
  • 因子2 毛利结构再平衡：分业务毛利率——催化剂销售 7.36% / 加工 33.84% / HNBR −71.54%（爬坡）/ 技术服务 82.22%。综合毛利被低毛利贵金属销售摊薄；加工 + 技术服务 + 非贵金属（高毛利）占比提升才能修复结构。禁止用单一综合毛利率。
  • 因子3 库存与采购节奏：贵金属库存随行就市，低价囤货收益 / 高价接货损失显著；2026H1 经营现金流 −3.83 亿（贵金属原料采购占用）。需区分：现金流为负主因营运资金（贵金属），非经营恶化。
  • 因子4 政策/市场锚点：① 贵金属（铂钯铑钌）期货价格 → 直接成本变量；② PVC 无汞化政策 → 铜系催化剂新需求（利好）；③ 出口管制/收储 → 贵金属供给风险；④ 能耗双控 → 精细化工开工影响需求。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：精细化工贵金属催化剂龙头，单项冠军，产能随基地释放；
  • 客户侧：近千家客户、百余家 A 股公司，粘性高；
  • 技术代际：贵金属等效减量迭代领先；
  • 成本曲线：回收闭环 + 非贵金属降贵金属含量，成本左移；
  • 份额二阶导数：医药/环保新能源仍加速渗透。
    → 中性：2029 营收 40 亿；保守 32 亿（基础化工替换周期延续）/ 乐观 48 亿。
  • 层2 扩展业务：主业迁移空间：从贵金属催化剂 → HNBR（高端弹性体，锂电/航空航天/油田）+ 非贵金属催化剂（进口替代）。能力可迁移（催化→高分子材料）；新 TAM（HNBR 进口替代）弹性大；认证门槛中。HNBR 一期刚投产、盈亏平衡未过验证点，仅作中期期权。
  • 层3 风险折扣（证伪信号）：贵金属价格暴跌致库存损失、基础化工替换周期长期缺席、HNBR 放量不及预期、负债率继续攀升。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：固定资产 + 贵金属存货占比高，非破净（PB 3.45x）；资产以贵金属存货（可变现）为主，质量尚可，但营运资金占用大（经营现金流 −3.83 亿）。
  • 校正2 周期位置校正：贵金属价格 + 精细化工资本开支处中等周期；中性净利以 2029 产能达产 + 毛利修复计，未用 Q2 低谷年化；当前周期位置"结构承压但非底部"。
  • 校正3 杠杆下行情景：资产负债率 58.16%，财务 + 经营杠杆双高；若贵金属价格下行 + 需求走弱，净利可大幅下滑（悲观 −34.6%，接近转负），故中性空间仅 +10%，不得标"大空间/重点关注"过激——但正向成长（HNBR+进口替代）仍支撑。下行情景空间 −34.6% 未转负，保留评级资格但须提示高贝塔。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵（2026E PE 24.5x，低毛利模式已不便宜）。

安全边际：
- 中性远期 31.0 元 → 空间 +10.2%（中性温和）
- 悲观 18.4 元 → 下行 −34.6%（高负债 + 贵金属波动）
- 乐观 48.2 元 → +71.3%（进口替代 + HNBR 超预期）

介入条件：
1. 回落至 18 元以下（2026E PE < 16x，接近悲观/安全边际）
2. 加仓信号：HNBR 单吨盈利转正、PVC 无汞催化剂大单、负债率下降、经营现金流转正
3. 观察指标：季度毛利率（回升至 10%+）、资产负债率、贵金属价格

最大风险：
1. 资产负债率 58.16% + 经营现金流为负，高贝塔属性
2. 贵金属价格大幅波动致库存损益
3. HNBR/非贵金属进口替代进度不及预期
4. 基础化工替换周期长期缺席

结论：暂不介入（低毛利 + 高负债 + 中性空间仅 +10%，风险收益不对称；若 HNBR 盈利兑现 + 负债率回落可上调至纳入观察）
