（3）产业链传导

上游：芯片 / 摄像机模组 / 云服务算力。硬件成本随电子周期波动；AI 算力成本上升。

下游：政企招投标（预算波动大）、医疗 / 教育 / 广电。高度依赖大型政企项目制，回款周期长。

议价权判断：偏弱——互联网巨头（腾讯会议 / 钉钉 / 飞书）以免费 / 低价 SaaS 抢占中小客户，会畅被迫在政企项目端竞争，价格战压制毛利率；硬件端（明日实业）凭借供应链与客户基础相对稳健，但同样承压。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）
    软件 / SaaS 端：边际成本极低，定价受互联网巨头压制，传导率接近 0（价格战自担）。硬件端：芯片 / 模组涨价 ×（1 − 传导率），传导率约 0.4–0.5（项目制定价，部分转嫁但竞争激烈）。整体 H1 毛利率 −5.76pct 印证弱传导。

  • 因子2 毛利结构再平衡
    软件平台（高毛利、轻资产）与硬件终端（明日实业，74.8% 收入）毛利结构不同。H1 综合毛利率降 5.76pct，主因收入规模下降摊薄固定成本 + 价格战，且高毛利的软件占比未提升（硬件仍主导）。不能单一"综合 29.70%"代表全结构——需区分软件（弹性大）与硬件（规模敏感）。

  • 因子3 库存与采购节奏（timing）
    硬件按订单生产，库存影响有限；但项目制前期垫资 + 回款周期拉长，营运资金占用加大，非库存收益问题而是现金流问题（H1 经营现金流 −5188 万）。

  • 因子4 政策 / 市场锚点（原料成本驱动变量）
    政策层：信创国产化（央国企私有云刚性需求）为需求变量，但财政预算波动直接冲击订单；AI+"行动为机器人新业务需求变量。市场层：互联网巨头价格战是最大成本 / 价格变量。情景：若信创订单回暖 + 财政扩张，主业企稳；若价格战延续，毛利破 25%。验证点：政企订单公告、毛利率企稳。证伪信号：毛利率连续跌破 25%、营收继续双位数下滑。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：云视频赛道集中度低，互联网巨头挤压，会畅份额承压。
  • 需求侧 / 客户份额：政企 / 医疗客户粘性强（资质 + 私有云壁垒），但新增订单受财政节奏影响。
  • 技术代际差：从"连接"向"智能协同"演进，会畅布局早但落地慢。
  • 成本曲线：规模小、固定费用刚性，成本高。

  • 份额二阶导数：传统云视频处饱和下行，靠信创刚性需求维持。
    → 三档：保守（营收零增长）、中性（信创小幅回暖）、乐观（信创放量 + 财政扩张）。

  • 层2 扩展业务：主业迁移空间（人机智能协同范式）
    能力可迁移性：从音视频向 AI 智能体 / 机器人，技术部分同源（图像 / 声学算法 + 云架构复用），但机器人属跨界，迁移成本中高。新 TAM 弹性：AI 终端 / 机器人市场空间大。切入卡位：已设奥洛机器人公司，布局早。客户认证门槛：消费级机器人认证 / 渠道门槛高。信号验证：尚无收入、无量产客户定点，仅产品亮相。→ 未过验证点，仅作中期期权，不计入中性。

  • 层3 风险折扣：证伪信号
    营收连续双位数下滑；毛利率破 25%；AI 机器人研发无商业化里程碑；应收账款减值扩大；信创订单持续落空。命中则下调 / 剔除增量。

第四步：估值锚定（自下而上，非增速外推）

方法说明：会畅 2026H1 真实亏损（−3051 万）、2025 全年亦亏，按正常化净利润法估值（亏损股标准方法）。亏损主因=营收下滑 + 费用刚性（研发 +22.5%）+ 汇兑，新业务未贡献；但无大额债务、净资产厚实（11.34 亿），亏得起。AI / 机器人期权不计入中性。

亏损股三问

  1. 为什么亏：① 营收 −15.89%（行业价格战 + 企业 IT 支出收缩 + 政企招投标节奏）；② 费用刚性——研发 +22.52% 至 3859 万（押注人机智能协同）、销售 +13.73% 至 2365 万；③ 财务费用由收益转支出 244 万（汇兑损失）；④ 新业务（机器人 / 办公智能体）尚在投入期、零收入。2025 全年已亏 1387 万，连续亏损。
  2. 靠什么扭亏，触发时点：① 信创国产化刚需订单回暖（央国企私有云 / 混合云），主业企稳；② 费用管控（研发转化、销售提效）使费用率回落；③ AI 机器人若商业化落地贡献增量（期权）。中性扭亏时点看 2027–2028 年（主业企稳 + 费用正常化），前提是信创订单兑现。
  3. 亏得起吗：账上总资产 12.93 亿、净资产 11.34 亿、资产负债率约 12%，无有息负债、无大额债务；H1 经营现金流 −5188 万但投资活动 −2.94 亿主要为购买银行理财（说明账面有现金类资产），现金流未枯竭，可支撑到扭亏，不存在退市 / 破产警示风险。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵 / 已透支反转与 AI 期权。现价 15.15 元对应 PB 2.65x、隐含 PE（中性）~79x，市场把信创反转 + AI 机器人成功视为大概率定价。

安全边际：
- 中性远期 5.05 元 → 空间 −66.7%（主业企稳价值支撑弱）
- 悲观 3.50 元 → 下行 −76.9%
- 乐观 18.00 元 → +18.8%（需信创放量 + AI 商业化，属期权）
- 下行保护：PB 2.65x、净资产 11.34 亿（每股净资产约 5.72 元），但亏损期 PB 不提供强安全边际

介入条件：
1. 不追高。当前价等于押注未验证的 AI 机器人与信创反转。
2. 介入 / 加仓信号：① 信创 / 政企大订单公告（验证主业企稳）；② 毛利率连续两季回升至 28%+；③ 经营现金流转正；④ AI 机器人获得量产客户定点 / 收入公告；⑤ 股价回落至 8 元以下（接近净资产、PB<1.5x）。
3. 观察指标：逐季营收增速、毛利率、经营现金流、应收账款周转、AI 业务里程碑。

最大风险（最可能破坏逻辑的因素）：
1. AI 机器人落空 / 投入转化周期拉长（首要）——研发高增但零收入，若证伪则期权归零。
2. 主业持续萎缩：价格战 + 互联网巨头挤压，营收继续双位数下滑。
3. 现金流恶化：项目制垫资 + 回款周期长，应收账款减值风险。
4. 信创订单不及预期，财政预算波动致订单落空。

结论：暂不介入

理由：中性锚（5.05 元，−66.7%）远低于现价，当前价格已把信创反转 + AI 机器人期权近乎"确定性"定价；而 AI 业务未产生收入、未过验证点，依规则不得计入中性。公司无大额债务、净资产厚实、信创刚需构成扭亏路径，不构成"确无扭亏可能"，故非坚决回避。若信创订单回暖兑现或 AI 机器人获定点 / 收入，中性假设需上修，可上调至"纳入观察"。
核心跟踪点：信创大订单公告 + 毛利率企稳 + AI 机器人商业化里程碑。
