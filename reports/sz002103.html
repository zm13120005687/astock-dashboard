第一步：公司是干什么的？

一句话定位：以文教办公用品（文具、办公直销）为核心的制造+渠道龙头，叠加 IP 文创潮玩衍生品与少量跨境电商，是一家“渠道型办公用品平台 + IP 衍生品”双轮公司。

（2）市场端（量价数据）

  • 国内文具行业进入存量竞争，传统基础文具需求平稳；IP 文创及功能型产品需求提升，线下传统分销渠道承压。
  • 潮玩行业维持高景气，但竞争加剧（同质化授权产品涌入）。
  • 跨境电商板块 2026H1 收入 2847 万，同比 −17.35%，板块在收缩，非主引擎。
  • 价格端：办公直销类毛利率仅 4.53%（强竞争、弱议价），办公用品类 29.45%、创意类 42.09%（有 IP 溢价、议价权较强）。

（3）产业链传导

  • 上游：纸张、塑料粒子、包装材料。价格整体平稳，无单边大涨，但办公直销类因客户集采压价、毛利率极薄（4.53%），对纸价波动敏感。
  • 下游：企事业单位集采（价格敏感）、零售消费者（IP 溢价可接受）。自有品牌出海占比提升，部分转嫁汇率与运费。
  • 议价权判断：中弱——办公直销环节近乎代采，议价权弱；IP/创意产品有授权壁垒，议价权中等偏强。整体综合议价权中等偏弱，体现在境内业务毛利率同比 −1.31pct 至 8.36%。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（量化转嫁系数）：
  • 办公直销类：转嫁系数 ≈ 0.2（客户集采年框锁价，纸价上行基本自担），毛利承压直接。
  • 办公用品类/创意类：转嫁系数 ≈ 0.6–0.8（IP 溢价+品牌，可提价），毛利较稳。
  • 综合加权转嫁系数 ≈ 0.4，即上游涨 10% 约 6% 由广博自担。
  • 因子2 毛利结构再平衡：高毛利品类（创意 42%、休闲 39%）合计仅约 15% 营收，低毛利直销（4.53%）占 55%。结构错配：即便高毛利品类增长 20%+，对整体毛利率拉动有限。测算：若 2029 高毛利品类占比升至 25%、直销占比降至 45%，综合毛利率可由 17.5% 抬升至约 20%。
  • 因子3 库存与采购节奏：文具非大宗商品，无囤货收益/接货损失型的库存博弈；但纸浆/塑料粒子有阶段性采购锁价，2026H1 营业成本增速（15.25%）> 收入增速（14.20%）即体现采购端小幅承压。
  • 因子4 政策/市场锚点（原料成本驱动变量）：① 出口退税政策（影响境外业务净利，情景：退税率下调则境外净利 −1~2pct）；② 欧美反规避/贸易合规（情景：加税则出海成本升，验证点=关税公告）；③ 纸浆价格周期（情景：浆价上行压制直销毛利，验证点=纸浆期货）。以上直接喂给第四步毛利率假设（分业务敏感性）。

合计增量测算（自下而上，非增速外推）：
- 以 2025 营收 27.46 亿为基数，按分业务单价×销量：直销/办公用品维持低双位数增长，创意/IP 中双位数，跨境电商小幅收缩。
- 2029E 营收 ≈ 31–34 亿（CAGR 约 3–5%，远低于历史外推，符合“渠道平台低增速”常识）。
- 新增利润来自结构升级（高毛利占比提升）而非单纯规模，2029E 归母净利 ≈ 1.7–1.9 亿（见第四步）。

第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：文具行业高度分散，广博属第一梯队但并非绝对龙头，产能无瓶颈，扩产靠渠道而非重资产。
  • 需求侧/客户份额：办公直销绑定企事业集采客户（粘性中）；IP 创意靠授权迭代，份额随热门 IP 波动。
  • 技术代际差：文具制造技术代际差异小，无代际溢价。
  • 成本曲线：规模集采带来采购成本优势（左移），可小幅以价换量。
  • 份额二阶导数：传统文具份额近饱和（S 曲线平台期），IP 衍生品处渗透早期。
  • 三档：保守守住（份额持平）/中性小幅提升（IP 渠道下沉）/乐观抢份额（爆款 IP 独家授权）。验证点=逐季 IP 品类营收占比、山姆/好想来铺货数。
  • 层2 扩展业务：主业迁移空间（新易盛范式）
  • 能力可迁移性：文具→IP 衍生品同源（设计+渠道），迁移成本低。
  • 新 TAM 弹性：潮玩/文创市场远大于传统文具单品，弹性 2–3 倍。
  • 切入卡位：已获头部 IP 授权，先发卡位中等。
  • 客户认证门槛：IP 授权需持续续约，是护城河也是阻力。
  • 信号验证：Fizz 进山姆、三丽鸥进好想来为已验证信号。
  • 结论：IP/潮玩属“中期成长期权”，但当前仅占营收 5.36%，未过“营收占比跳升”验证点，不计入中性净利，仅作乐观情景。
  • 层3 风险折扣（证伪信号）：IP 授权到期未续、潮玩竞争致毛利破 35%、直销客户流失致营收连降。命中则下调增量。

交叉校验

  • 现价 6.69 元对应 2026E PE = 35.74/1.20 = 29.8x，高于基准合理 21x；对应 TTM PE 25.86x（TTM 净利约 1.38 亿）。
  • 现价已隐含“IP 成功+汇兑好转”的乐观预期，当前价格偏贵，安全边际不足。
  • 远期中性 7.12 元仅 +6.4%，说明若仅按中性基本面，三年复合空间有限。

第四步进阶·三道闸（轻资产消费，约束较弱但须交代）

  • 校正1 资产质量：PB 2.75x > 1，非破净，无资产虚高风险；品牌/IP 为表外无形资产，未重估但属正向。
  • 校正2 周期位置：非强周期，消费文具需求平滑，无周期归一化需要；但营收处低增速平台期，不可按历史高增外推。
  • 校正3 杠杆下行：资产负债率 39.70%，流动比率 1.85，财务稳健；下行情景（悲观）空间 −44.5% 主要来自盈利不及预期而非杠杆反噬。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 6.69 元对应 2026E PE 约 30x、TTM PE 25.86x，已反映 IP/出海乐观预期。

安全边际：
- 中性远期 7.12 元 → 空间 +6.4%，三年复合约 2%，弹性有限。
- 悲观 3.71 元 → 下行 −44.5%，不对称偏负。
- 乐观 9.48 元 → +41.7%，需 IP 爆款验证。
- 支撑位：2026E 合理价 4.72 元（约 0.7x 透支）、PB 2x 约 4.86 元附近为强支撑。

介入条件：
1. 不追高，等回落至 5.0 元以下（对应 2026E PE < 21x、接近基准合理区）再分批。
2. 加仓信号：① IP/创意产品营收占比连续两季 > 20%；② 综合毛利率回升至 20%+；③ 汇兑由负转正、财务费用回归常态。
3. 观察指标：逐季境外收入增速、山姆/好想来铺货数、IP 授权续约公告。

最大风险：
1. 汇兑损失持续（人民币升值）侵蚀净利——2026H1 已证伪式冲击。
2. IP 潮玩竞争加剧致高毛利品类毛利破阈值。
3. 办公直销客户流失、集采压价超预期。

结论：纳入观察（估值偏贵，等回调至 5 元以下；若 IP 结构升级兑现，中性空间可上修至重点关注）。
