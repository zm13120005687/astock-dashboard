（3）产业链传导

上游：纺织面料、箱包材料（PP / PC / 五金）。原材料成本占比高，随大宗商品波动。

下游：全球品牌商（运动 / 出行）。客户集中度高但粘性强（长协 + 认证），议价权中等偏强（印尼成本优势 + 自动化精益管理构筑壁垒）。

议价权判断：代工端中等（品牌商强势，但开润凭印尼成本优势 + 多客户矩阵具备转嫁与议价能力）；汇率波动为主要利润扰动（H1 其他综合收益 −1.81 亿为外币折算差额）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）
    面料 / 箱包材料变动 ×（1 − 传导率）。代工长协通常可部分转嫁（传导率 0.5–0.6）；但低毛利服装占比提升（毛利率 23.76% 降 0.9pct）显示短期传导不充分，靠规模与印尼降本对冲。长期印尼人工 / 电价 / 关税优势构成结构性成本护城河。

  • 因子2 毛利结构再平衡
    分业务：箱包代工毛利率较高，服装代工净利率仅 4.0%（上海嘉乐）、品牌经营调整中。H1 综合毛利率降 0.9pct 主因服装（低毛利）占比提升的结构迁移，而非各业务恶化。不能单一"综合 23.76%"代表全结构——服装利用率从 50.73%→60.57% 是未来毛利修复关键。

  • 因子3 库存与采购节奏（timing）
    代工按订单生产（存货周转 78 天，−7 天），库存收益 / 损失不显著；原材料低位囤货可短期抬利，但影响有限。H1 现金流 −51.92% 主因票据到期兑付 + 采购现金流出，非库存虚高。

  • 因子4 政策 / 市场锚点（原料成本驱动变量）
    政策层：印尼"制造 4.0" + 美国关税豁免（印尼 0% vs 中国 8%+）直接改成本曲线，是核心优势变量。市场层：棉价 / 石化（箱包材料）波动；汇率（印尼盾 / 美元）影响折算。情景：若印尼关税优势延续 + 产能扩建，成本曲线持续左移。验证点：印尼工厂净利率、产能利用率。证伪信号：贸易政策逆转（印尼被加税）、客户订单转移。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：服装产能利用率仅 60.57%，存量产能即可支撑近 40% 增量，无需新建即有大弹性。
  • 需求侧 / 客户份额：绑定全球头部品牌，品类延展（同客户多品类）提升份额。
  • 技术代际差：自动化 / 精益管理 + 印尼成本曲线左移，行业降价时以价换量。
  • 成本曲线：印尼人工 1/4、关税 0%，位于全球代工成本曲线极左端。

  • 份额二阶导数：服装代工处渗透加速期（利用率快速提升）。
    → 三档：保守（利用率 70%）、中性（80%）、乐观（满产 + 品类延展）。

  • 层2 扩展业务：主业迁移空间（服装范式）
    能力可迁移性：从箱包到服装，制造工艺 / 供应链 / 工厂管理高度协同，迁移成本低（已验证：嘉乐整合生效）。新 TAM 弹性：服装市场为箱包近十倍。切入卡位：嘉乐为优衣库十余年核心供应商，卡位极佳。客户认证门槛：品牌商认证周期长（护城河）。信号验证：嘉乐 26H1 营收 6.49 亿、净利 2569 万，信号已兑现。→ 服装代工已过验证点，计入中性（第二曲线确定性高）。

  • 层3 风险折扣：证伪信号
    服装产能利用率停滞 < 60%；印尼贸易政策逆转；大客户订单转移；汇率大幅波动致净资产缩水。命中则下调。

第五步：综合赔率判断（买不买？）

当前价格位置：低估 / 明显便宜。现价 20.13 元对应 PE 13.6x、PB 2.27x，forward PE 仅 11.5x，而盈利 +13%、ROE 近 20%、第二曲线清晰。

安全边际：
- 中性远期 36.70 元 → 空间 +82.3%，满足"重点关注" >50% 门槛
- 悲观 23.40 元 → 下行仅 +16.2%（仍为正，保护极强）
- 乐观 52.50 元 → +160.8%
- 下行保护：PB 2.27x、净资产 21.29 亿、经营现金流虽降但仍正、无大额债务

介入条件：
1. 现价即可配置（20.13 元低于基准 26.30 元），分批建仓。
2. 加仓信号：① 服装产能利用率站上 70%；② 印尼扩建项目投产公告；③ 品牌业务净利率回升；④ 新增大客户 / 品类公告。
3. 观察指标：逐季服装代工收入与利用率、印尼工厂净利率、汇率对净资产影响。

最大风险（最可能破坏逻辑的因素）：
1. 汇率风险（首要）——H1 其他综合收益 −1.81 亿（外币折算），净资产受印尼盾 / 美元波动影响。
2. 品牌业务持续下滑（−27%），若调整不及预期拖累整体。
3. 印尼贸易 / 政策逆转（关税优势消失）。
4. 大客户订单波动（运动品牌去库存周期）。

结论：重点关注

理由：中性远期空间 +82.3% > 50%，PE 13.6x（forward 11.5x）、PB 2.27x 显著低估，盈利 +13%、ROE 近 20%；服装第二曲线（嘉乐）已过验证点、产能利用率 60%→80% 弹性大，印尼成本优势构筑护城河。风险可控（无大额债务、净资产厚）。
核心跟踪点：服装产能利用率 + 印尼扩产进度 + 汇率对净资产影响。
