力盛体育（002858）五步法分析报告

分析日期：2026-10-01 ｜ 现价 11.63 元（2026-09-30 收盘）｜ 总市值 21.71 亿 ｜ PE(TTM) −364.6x（TTM 亏损） ｜ PB 2.55x ｜ 总股本 约 1.8668 亿股 ｜ 流通市值 17.14 亿
行业：体育（赛事运营 / 体育空间运营）｜ 板块：深市主板（原中小板）
盈亏口径校正：TTM 归母为负（PE −364.6x），系 2025 全年归母 −664.85 万元 拖累；2026H1 归母净利 +1601.75 万元（同比 +4.53%）、扣非 +1648.56 万元（同比 +46.45%），已实现半年度盈利，创近 5 年同期新高 —— 本报告按盈利股框架分析，但因盈利体量偏小、TTM 仍为负，第四步同时给出正常化口径交叉验证。

第一步：公司是干什么的？

一句话定位：A 股稀缺的"赛事 IP 运营商"——独家运营 CTCC 中国汽车场地职业联赛、China GT 中国超级跑车锦标赛、中国男子职业高尔夫球巡回赛（中巡赛）等头部赛事，并自营赛车场（上海天马赛车场等）与赛事营销服务。

（3）产业链传导

上游（成本端）：赛事运营的核心成本是赛事承办费、场地租金、赛事执行与人力、媒体制作，无大宗原材料敞口——这与制造业公司有本质区别，不存在"原料涨价吃掉毛利"的传导链条，成本弹性主要来自"赛事场次 × 单场执行成本"。

下游（收入端）：收入来自品牌赞助、赛事报名、版权与门票、地方政府文旅合作、赛事整合营销。下游景气与消费复苏 + 汽车消费 + 文旅强相关；国办文件明确"跟着赛事去旅行"，支持体育流量转化为文旅消费。

产业链位置与议价权：力盛处于赛事产业链最上游的 IP 端——掌握赛事运营权即掌握稀缺资产。
- 对下游品牌方：议价权中偏强（2026H1 市场营销服务收入 +309.86% 佐证商业化变现能力提升）。
- 对上游执行/场地方：议价权中（场地为重要成本项，公司自持赛车场部分对冲）。
- 综合判断：议价权中等偏强，盈利质量的瓶颈在"赛事规模（场次）"而非"单位价格"。

第二步进阶：原料成本 → 毛利结构传导（四因子）

力盛属轻资产服务型公司，无大宗原料敞口，但"成本→毛利结构"的框架依然适用，只是核心成本变量从"原料"换成"赛事承办与场地成本"，逐因子拆解如下：

因子 1 成本传导弹性（pass-through）
- 力盛的成本几乎全部为赛事执行类人力与场地，不与商品价格挂钩，因此不存在"上游涨价→毛利被吃"的传导问题。
- 议价权量化：对赞助商侧的转嫁率≈0.6–0.8（提高赞助权益包单价、加售衍生权益可在 1–2 个赛季内转嫁人力成本上涨）；对场地侧的转嫁率≈0.3（自持赛车场部分锁定了核心成本）。
- 结论：无原料冲击风险，毛利波动的真正来源是"低收入赛季 vs 高固定成本"，即经营杠杆，不是成本传导。

因子 2 毛利结构再平衡（分业务线毛利率）

业务线 2026H1 毛利率 对"固定成本占比"的敏感度 利润贡献趋势
体育赛事经营 29.38% 高（赛事执行费用固定，场次越多摊薄越薄） ↑ 主导（占比 76.94%）
体育场馆经营 8.42% 极高（折旧 + 场地维护为刚性） ↓ 收缩（−55.63%）
市场营销服务 15.95% 低（人力密集，边际成本低） ↑ 高增（+309.86%）
体育装备制造 10.55% 中（有小额物料成本） 平稳（+61.03%，基数极小）

关键：若用"综合毛利率 24.79%"一把尺子看力盛，会漏掉结构性利好——低毛利场馆业务（8.42%）占比从 55%+ 砍到 11.37%，而高毛利赛事经营（29.38%）升到 76.94%，加权毛利率被动抬升。估值必须按分业务线净利，不能用历史综合毛利率。

因子 3 库存与采购节奏（timing）
- 力盛无存货型囤货收益/损失，此项不适用（区别于制造业）。
- 但存在"预收/预付节奏"的类 timing 因素：赛事赞助款多按赛季预付（合同负债），报名费在开赛前集中收取——现金流季节性领先于收入确认，2026H1 经营现金流 +1707.84 万元（虽然同比 −57.04%，但仍为正），说明商业化回款健康。
- 警惕点：2026H1 归母 1602 万元中包含股份支付费用（扣除股份支付影响后净利 1869 万元，同比 +22%），股份支付属非现金的经常性但在估值上应视为一次性扰动，测算 2026E 时应还原。

因子 4 政策 / 市场锚点（成本与收入的双向驱动）
- 市场层：汽车运动热度（小米等新势力品牌入局赛车营销）、高尔夫职业巡回赛商业化、文旅"跟着赛事去旅行"。
- 政策层：赛事经济专项政策（审批简化）、地方政府赛事补贴与文旅配套采购、体育消费券/贷款贴息。
- 情景与验证点：
- 情景 A（基准）：中巡赛完整赛季 + 赛车赞助稳定，2026 全年归母 0.30–0.36 亿元；验证点 = 2026Q3 单季归母确认、中巡赛赞助商名单。
- 情景 B（乐观）：赛事经济专项政策落地 + 地方文旅采购放量，2027 年起净利率抬升至 10%+；验证点 = 新增 1–2 个政府/文旅类整包合同公告。
- 证伪信号：2026Q3/Q4 单季归母再度转负（如既往 Q4 减值重演）、中巡赛赞助商未续约、赛事场次下降。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

层 1 现有业务：市场容量 × 份额变量

力盛的"份额"不是产能份额，而是赛事 IP 运营权的覆盖率，用五类锚点逼近：

锚点 力盛现状 三档份额假设 可观测验证点
① 供给侧份额 国内最高级别场地职业联赛（CTCC）+ 超跑锦标赛（China GT）+ 国家级高尔夫巡回赛运营权 保守：守住现有 3 个 IP；中性：新增 1 个赛事 IP；乐观：新增 2–3 个跨品类 IP（如摩托、拉力、路跑） 赛事运营权中标/授权公告
② 客户/需求侧份额 赞助商含小米等头部品牌；营销服务 +309.86% 保守：头部赞助续约；中性：新增 2–3 家车企/消费品赞助商；乐观：单赛事冠名费阶梯上台阶 赛季赞助商名单、单赛事招商额
③ 技术代际差 赛事数据、转播制作、赛事数字化能力 中性：直播/版权变现能力提升；乐观：数字体育形成独立收入线 版权销售公告、数字体育收入（当前仅 3.77 万元）
④ 成本曲线位置 自持赛车场，部分锁定场地成本 保守：场地成本刚性；中性：场馆利用率提升摊薄；乐观：场馆资产盘活（城市更新政策） 场馆利用率、场馆业务毛利率（当前 8.42%）
⑤ 份额二阶导 赛事场次 46 场（H1），场馆业务在收缩 中性：场次温和增长；乐观：场次 + 赛事品类双升 逐季赛事场次披露

层 2 扩展业务：主业迁移空间（新易盛范式检验）

  • 能力可迁移性：高。赛事运营的核心能力是"IP 获取 + 商业化招商 + 现场执行 + 媒体分发"，这套能力可跨运动品类复用（赛车 → 高尔夫已被验证，中巡赛即迁移成功案例）。
  • 新 TAM 弹性：高尔夫、路跑、摩托、电竞、户外等品类的赛事运营市场远大于单一赛车品类；叠加国办文件"赛事经济"专项政策，新池塘显著放大。
  • 切入时点与卡位：中巡赛卡位极佳（国家级巡回赛独家运营，2025-04 切入，属早期先发）。
  • 客户认证门槛：赛事运营权需经协会/政府授权，一旦获得即形成排他性壁垒（护城河）；反之切换成本高。
  • 信号验证：已过初步验证（中巡赛已运营 16 场次、境外收入占比 42.74%、营销服务 +309.86%）；但尚未出现"单一大额赛事合同公告"的强验证，故迁移空间仍按中期期权处理，不计入中性锚。

层 3 风险折扣：证伪信号
- 赛事运营权到期未续约（尤其 CTCC / 中巡赛）；
- 场馆业务毛利率继续下滑且无盘活方案；
- Q4 再度出现大额减值（2024Q4 −5297 万、2025Q4 −2867 万，历史两连击）；
- 收入规模连续两年不增长，仅靠结构改善撑利润（改善空间会被耗尽）。
- 命中任一 → 中性情景必须下修。

第四步：估值锚定（自下而上，非增速外推）

方法说明：不使用任何"历史增速外推"。按赛事经营 / 场馆 / 营销服务 / 其它四条线分别测算收入与净利率，用已披露的赛事场次、定增资金、境外收入占比校验，并给出三情景。因公司盈利体量小、且 TTM 为负，同时用正常化净利润法交叉验证。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1 资产质量折扣（PB 与破净分析）
- 力盛 PB 2.55x，非破净，不存在"单凭 PB<1 推大空间"的问题；反而应警惕PB 偏高：净资产约 8.5 亿元（21.71 / 2.55），对应 2026E 归母 0.34 亿元的 ROE 仅约 4.0%，净资产盈利能力弱是 PB 高企的对立面（市场给的是"赛事 IP 稀缺性溢价"，不是资产重置价值）。
- 结论：不适用"真破净安全边际"逻辑，估值锚必须落在盈利（IP 变现）而非净资产上。

校正 2 周期位置校正（中性净利用周期归一化）
- 力盛属弱周期、强季节 + 强事件驱动型公司，不适用钢铁/有色式周期归一化；
- 但必须处理"Q4 减值规律"：2024Q4 归母 −5297 万、2025Q4 −2867 万，连续两年把前三季利润抹平。因此中性净利不得用任一单季年化，本报告的 2029E 中性净利已按"剔除非经常性减值后"的稳态口径给出（0.70 亿元），并在悲观情景中重演减值（0.38 亿元）。
- 当前周期位置：盈利拐点初期/底部回升（首个半年度盈利、近 5 年同期新高），按规则底部不过度悲观，故未剔除乐观情景。

校正 3 杠杆下行情景（高负债必附负面情景）
- 2026 年定增后财务结构显著改善：募资净额 3.20 亿元到账，资产负债率处于低位、无重大有息负债压力（2026H1 经营现金流 +1707.84 万元仍为正）。
- 负面情景：若赛事停摆/赞助退坡，固定成本（场馆折旧、赛事执行团队）刚性 → 收入下行时净利快速转负（2023 年 −1.93 亿元即为先例）。
- 判定：杠杆风险低，但经营杠杆高，故悲观情景给到 −54.4%，属合理尾部。未因此下调中性结论，但限制了"大空间"标签。

期权纪律：中巡赛之外的新赛事 IP 迁移、数字体育、场馆盘活均未过验证点（无正式合同公告），故不计入中性 0.70 亿元，仅列乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 11.63 元对应 2026E PE 约 63.9x、PB 2.55x，中性远期（2029E）目标价 12.00 元仅对应 +3.2% 空间——市场已把"政策 + 扭亏 + 赛事稀缺性"定价得相当充分。

安全边际：
- 中性远期 12.00 元 → 空间 +3.2%，几乎无安全边际；
- 悲观情景 5.30 元 → 下行 −54.4%，风险收益明显不对称；
- 乐观情景 19.13 元 → +64.5%，但依赖"新增赛事 IP + 政府整包合同"两个未过验证点的期权；
- 下行保护有限：PB 2.55x（净资产 8.5 亿元）并不构成硬支撑，2026E ROE 仅约 4%。

介入条件：
1. 不追高。现价缺乏安全边际，等回落至 9.5 元以下（对应 2026E PE < 52x）才具备赔率；
2. 加仓信号：① 中巡赛单赛季赞助额/冠名合同正式公告；② 新增一个跨品类赛事 IP 运营权（摩托/路跑/户外）；③ 2026Q4 不出现减值（连续两年 Q4 暴雷的规律被打破）；
3. 观察指标：逐季"赛事运营场次 + 单场平均收入"——若场次增长但单场收入下降，说明在打价格战抢 IP，中性情景须下修。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ Q4 减值规律（首要）：2024Q4、2025Q4 连续大额减值，若 2026Q4 重演，全年归母可能再度接近盈亏平衡线，"扭亏"证伪；
2. 盈利体量太小：2026H1 归母仅 1602 万元，任何单一赛事招商不及预期都会显著扰动全年利润；
3. 赛事 IP 续约风险：CTCC / 中巡赛运营权具有期限，续约失败 = 核心资产流失；
4. 估值透支：PE(TTM) 负、PE(2026E) 约 64x，若政策落地节奏低于预期，估值将剧烈回撤。

第五步进阶：上行想象力情景（四类）

  • 类型 A 行业调整剩者红利：体育赛事运营是极度分散且出清中的行业，大量中小赛事公司因赞助退坡退出。力盛凭 CTCC / China GT / 中巡赛三个头部 IP 成为剩者，行业集中度提升直接表现为单赛事冠名费与赞助溢价上行。验证点：单赛事招商额、头部赞助商数量；证伪：赞助商流失、赛事场次下滑。
  • 类型 B 政策反转 / 政策催化期权：国办《关于释放体育消费潜力…的意见》明确"出台赛事经济专项政策"，另有《扩大消费"十五五"规划》支持自主 IP 赛事品牌。反转信号：赛事经济专项政策发文、赛事审批简化细则、地方文旅赛事采购合同。重估弹性：若赛事运营净利率从 9% 抬至 13%，中性净利 0.70 亿 → 1.05 亿，对应 +50% 市值弹性。未过验证点，仅作机会情景。
  • 类型 C 市场错杀修复：力盛因 TTM 归母为负、PE −364.6x 被部分量化/价值筛选器直接剔除，这是典型的"口径错杀"——基本面实际已在 2026H1 转正（+1601.75 万元），扣非增速 +46.45%。错杀证据：PB 2.55x 对一家无有息负债、账上新增 3.20 亿元定增资金的轻资产 IP 公司并不算贵；修复触发点：2026 年报确认全年盈利、TTM 归母转正、被重新纳入盈利筛选池。弹性：TTM 转正后 PE 口径切换，估值中枢有望上移 20–30%。
  • 类型 D 技术突破 / 代际跃迁期权：不适用。力盛为服务业，无"新技术路线从 0 到 1 投产"的路径。可对标的是"赛事数字化/数字体育"（当前收入仅 3.77 万元），若形成版权/数据变现的第二收入曲线，属"主业延伸"而非技术跃迁，硬验证点（中试/定点/量产成本）不适用，明确不计入中性。

⛔ 纪律自查：以上四类全部只进乐观/机会栏，不进中性锚；每类均配验证点与证伪信号。什么条件出现才上调至"重点关注"：① 中巡赛或新增 IP 的单赛季合同额正式公告且 ≥5000 万元；② 2026 全年归母 ≥0.40 亿元且无 Q4 减值；③ 中性远期空间修复至 >+50%。三条同时满足，方可从"暂不介入"上调。

结论：暂不介入

判定理由：公司质地确实稀缺（A 股少见的赛事 IP 运营商、政策强驱动、2026H1 已扭亏且创近 5 年同期新高、账上新增 3.20 亿元定增资金），但 ① 当前 PE(2026E) 约 63.9x 已把好消息定价完；② 中性远期空间仅 +3.2%，缺乏安全边际；③ 悲观情景 −54.4%，连续两年 Q4 减值的规律尚未打破。按 RULES 五级排序，"基本面尚可但估值已高 / 空间有限"对应 暂不介入（远期空间 +3.2% ≤ +50%，符合一致性规则）。
核心跟踪点：中巡赛商业化合同额 + 2026Q4 是否减值 + 新增赛事 IP 品类。
