第一步：公司是干什么的？

一句话定位：一家"从缝衣服到造飞机"的全球化材料连接加工设备集团——以德国杜克普爱华（Dürkopp Adler）、毛瑟、百福（PFAFF）等百年品牌做高端工业缝制设备，以"蝴蝶""飞人"做家用缝纫机与低空经济，并横跨汽车内饰件、通用航空与物流服务的混合型制造平台。

一句话拆解业务重心：缝制设备（失血中）＋ 汽车零部件（毛利率骤降）＋ 物流服务（稳）＋ 轻型飞机（投入期），四条线中两条在拖累利润。

（3）产业链传导——原料成本 → 毛利结构（四因子）

公司的核心"原料"是钢材、铸件、电机、电控、伺服系统与汽车内饰原材料（PP/ABS 粒子、面料）；但 2026 年的毛利恶化并非单一原料涨价，而是"欧洲订单结构塌陷 + 汽车零部件成本失控"的双重挤压。

因子 1｜成本传导弹性（pass-through）
- 工业缝纫机（高端 DA / 毛瑟，占收入 26.84%）：面对欧洲奢侈品供应链客户，品牌溢价可支撑部分传导，传导率≈0.5–0.7；但订单量下滑时固定成本无法摊薄，实际毛利仍被吃。
- 汽车内饰件（占收入 23.62%）：面对整车厂（Tier1 转嫁链），传导率≈0.1–0.2（极弱）——2026H1 成本 +23.09% 而收入仅 +13.85%，毛利率骤降 7.02pct 至 6.46%，典型"自己扛"。
- 家用缝纫机（4.20%）：消费品属性，传导率≈0.7–0.8。
- → 加权看，公司整体传导率约 0.35–0.45（中等偏弱），汽车零部件线是毛利失血的定量主因。

因子 2｜毛利结构再平衡（分业务线敏感度）

业务线 收入权重 毛利率 对成本敏感度 利润贡献权重
工业缝纫机（DA/毛瑟） 26.84% 25.11%（−3.43pct） 中 由正转弱（欧洲订单减少）
汽车内饰件及模具 23.62% 6.46%（−7.02pct） 极高 由盈转亏（上工飞尔净亏 2095 万）

结构迁移要点：收入占比最大的两块（缝制设备 38.9% + 汽车零部件 23.62%）恰好是毛利率下滑最严重的两块，而稳定的物流服务（33.7%）薄利。禁止用"综合毛利率 14.68%"代表全结构——公司的真实问题是两条主力线同时失血，且汽车零部件由盈转亏是 2026H1 亏损扩大的核心变量。

因子 3｜库存与采购节奏（timing）
- 2026H1 存货仅 +0.81%（基本持平），未见低价囤货型虚高毛利——毛利率下滑是真实经营恶化。
- 应收账款 +32.67% 而收入仅 +0.89%，回款周期恶化，是经营现金流 −2.79 亿元的重要来源。
- 公司未披露套保 / 长协安排，钢价、粒子价格波动直接冲击汽车零部件成本。
- → 当期与远期毛利可比性尚可（无粉饰），但现金流转负是比亏损更危险的信号。

层 2｜扩展业务：主业迁移空间（"连接技术"的自然延伸）
- 能力可迁移性：高——从"柔性材料缝制连接"到"刚性复合材料结构件加工 + 超声波焊接"，技术底层逻辑一脉相承（DA 设备已用于航空复材加工）。
- 新 TAM 弹性：极大——低空经济（通用航空）若放量，市场空间数倍于缝制设备；航空复材结构件加工同样是大市场。
- 切入时点与卡位：早期——2025 年 5 月设威海制造总部、9 月与光威新材合资，先发但尚早。
- 客户认证门槛：极高——轻型飞机需适航取证（CAAC/FAA），周期长、门槛高（既是护城河也是阻力）。
- 信号验证：目前仅为"签约设立 + 飞北美首秀（F2-M160）"，无适航取证、无量产、无订单披露。
- → 按纪律，该迁移空间不计入中性情景，仅放乐观情景。

层 3｜风险折扣：证伪信号
1. 欧洲需求持续下滑、工业缝纫机收入连续多季负增。
2. 汽车零部件毛利率跌破 5% 且上工飞尔持续亏损。
3. 低空经济业务长期无适航取证、无订单、无投产。
4. 经营现金流持续大额净流出、货币资金快速消耗。

命中任一项，对应增量剔除。

合计增量（中性口径）：假设欧洲需求 2027 年企稳、汽车零部件成本修复、物流稳定 → 2029 年稳态营收约 48 亿元，正常化归母约 1.6 亿元。

第四步：估值锚定（自下而上，非增速外推）

方法说明：公司当前亏损，无正净利可锚，采用正常化净利润法：①估稳态营收（现有业务满产 + 已投项目达产）；②算正常化净利率（行业平均 / 公司历史最好 / 爬坡后理论值，三者取保守）；③正常化净利 × 远期合理 PE = 目标市值 → 目标价。不使用历史增速外推，低空经济等期权只放乐观情景。

总股本：713,166,480 股（约 7.1317 亿股） ｜ 2026H1 末归母净资产 26.57 亿元（每股净资产约 3.73 元），商誉仅 4813 万元（无大额减值风险，这点优于多数并购型公司），资产负债率约 54.08%。

亏损股三问

问 1｜为什么亏？
1. 欧洲需求塌陷 + 贸易摩擦：德国子公司 DA 与汽车安全件 / 内饰件相关的中厚料缝制设备、特种缝制工作站订单大幅减少，工业缝纫机收入 −8.78%。
2. 汽车零部件成本失控：占收入 23.62% 的汽车内饰件业务成本 +23.09% 远超收入 +13.85%，毛利率骤降 7.02pct 至 6.46%，子公司上工飞尔净亏 2095.23 万元——这是亏损扩大的核心变量。
3. 轻型飞机仍在投入期：美国 SGIA 净亏 2042.66 万元。
4. 刚性成本上升：人工、合规成本持续走高，收入下滑时无法摊薄。

问 2｜靠什么扭亏？触发时点在哪一年？
- 路径 A（主）：欧洲需求企稳 + 高端缝制设备订单恢复——欧盟 2027 年机械指令实施前的抢装 + 服装产能向印度 / 南亚转移带来的设备需求，触发时点 2027 年。
- 路径 B：汽车零部件毛利修复——成本控制、产品结构调整、国产替代降本，毛利率从 6.46% 回升至 10% 以上，触发时点 2027–2028 年。
- 路径 C：低空经济业务放量——威海基地投产 + 适航取证 + 订单落地，触发时点 2028–2029 年（未验证）。
- 盈亏平衡点测算：按 2026H1 毛利率 14.68%、期间费用约刚性的口径，公司需营收站上 约 24–25 亿元/半年（即全年约 48–50 亿元） 且综合毛利率回升至 17% 以上 才能覆盖固定成本 + 财务费用 → 中性假设下 2027–2028 年扭亏，2029 年恢复正常化利润 1.6 亿元。

问 3｜亏得起吗？
- 净资产雄厚：归母净资产 26.57 亿元，每股净资产 3.73 元，商誉仅 0.48 亿元——账面净资产相对干净，不存在大额商誉悬顶。
- 负债率可控：资产负债率约 54.08%，具备银行融资与债务滚动能力；浦东国资背景提供信用支持。
- 现金流是最大风险：2026H1 经营现金流 −2.79 亿元，货币资金较上年末 −21.02%，应收账款 +32.67%。若欧洲需求 2027 年仍不企稳，现金流将持续消耗，可能被迫收缩或处置资产。
- → 结论："亏得起"——净资产与国资背景可支撑 2–3 年亏损期，但必须以 2027 年欧洲需求企稳为前提；现金流是倒计时的关键变量。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1｜资产质量折扣（PB 1.95，属溢价而非破净）
- 公司不破净（PB 1.95x），因此不涉及"破净原因"问题；反而需警惕溢价：市场为"低空经济 + 人形机器人 + 老字号"支付了近 2 倍净资产。
- 资产质量尚可：商誉仅 0.48 亿元，无大额减值风险；但德国子公司（DA / PFAFF）资产为专用设备，清算价值显著低于账面，重置成本不兜底。
- → 结论：估值锚只能落在盈利上，净资产（3.73 元/股）提供的是下限参照而非安全边际。

校正 2｜周期位置校正（中性净利用正常化口径）
- 缝制机械属中周期、与服装厂资本开支强相关的行业，当前处于周期下行段（服装厂利润 −28.08%、出口金额多数品类下滑）。
- 正常化净利禁止用"最好年份"或"单季年化"：本报告取稳态营收 48.5 亿 × 保守净利率 2.5%，并考虑少数股东权益，得 1.60 亿元——该口径显著低于行业龙头的净利率水平（8–10%），属保守。
- 当前周期位置：底部区域（内销触底、外销底部震荡）——按纪律，底部不过度悲观，故给予 18x 而非更低。

校正 3｜杠杆下行情景
- 资产负债率约 54.08%，属中等；无高杠杆反噬的极端风险，但经营杠杆高（固定成本重，收入下滑即放大亏损）。
- 负面情景（悲观 0.63 元） 即体现"欧洲需求不复苏 + 汽车零部件毛利率跌破 5%"双杀情形——此时净资产也将因持续亏损而侵蚀。
- → 因杠杆中等，最悲观情景虽空间极负，但不构成"坚决回避"（公司仍有真实业务、真实品牌、真实订单，非纯概念炒作）。

期权纪律：低空经济（ICON / FD 本地化 + 碳纤维复材）、人形机器人 + AI 缝制技术、汽车零部件反转——三项均为未过验证点的期权，一律不计入中性净利，只放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。现价 7.27 元对应 PB 1.95x、PS(TTM) 约 1.12x；按正常化净利 1.60 亿元测算，PE 达 32x。市场已把"低空经济 + 人形机器人 + 老字号"全部定价，而扣非亏损仍在扩大。

安全边际：
- 中性远期 4.04 元 → 空间 −44.4%，为负空间，不满足"纳入观察"的 >0 门槛
- 悲观情景 0.63 元 → 下行 −91.3%（欧洲不复苏 + 汽车零部件破位）
- 乐观情景 9.87 元 → +35.8%（需低空经济适航取证 + 量产）
- 下行保护：归母净资产 26.57 亿元（每股 3.73 元，对应 −48.7%）、商誉仅 0.48 亿元、浦东国资背景

介入条件：
1. 不追高。现价 7.27 元距中性合理价 4.04 元有 44% 下修空间，当前不具备安全边际。
2. 重新评估的信号（出现任一才考虑上调）：① 单季扣非亏损连续两个季度收窄至 2000 万元以内；② 汽车零部件毛利率回升至 10% 以上；③ 经营现金流转正；④ 低空经济业务取得适航取证或大额订单公告；⑤ 现价回落至 4.5 元以下（对应 PB 1.2x）。
3. 观察指标：逐季工业缝纫机与汽车零部件收入 / 毛利率、欧洲订单、经营现金流。

最大风险（最可能破坏逻辑的因素）：
1. 现金流持续失血（首要）：经营现金流 −2.79 亿元、货币资金 −21.02%，若欧洲需求 2027 年仍不企稳，将被迫收缩。
2. 汽车零部件毛利率失控：成本 +23.09% vs 收入 +13.85%，由盈转亏，是亏损扩大的核心变量。
3. 低空经济"故事"迟迟不落地：适航取证周期长，若长期无进展，估值溢价将回吐。
4. 非经常性损益掩盖真实亏损：归母减亏靠处置损益 + 政府补助（合计 4113 万元），扣非反而扩大，不可误读为"经营改善"。

结论：暂不介入

理由：中性远期空间 −44.4%，悲观下行 −91.3%，风险收益不对称偏负。
公司有真实的全球化资产（DA / 毛瑟 / PFAFF 品牌、26.57 亿元净资产、0.48 亿元低商誉）与真实的低空经济卡位（威海制造总部 + 光威复材合资），是 A 股稀缺的"缝制设备 + 通航双主线"标的；但扣非亏损同比扩大、经营现金流 −2.79 亿元、归母减亏靠一次性处置收益，且现价给了约 2 倍净资产溢价。当前价格把"低空经济"这个尚未验证的故事定完了。
核心跟踪点：欧洲订单与工业缝纫机收入、汽车零部件毛利率、经营现金流、低空经济适航取证进度。
