（3）产业链传导

上游（负债端/资金成本）：存款付息率下行（存款利率多轮下调 + 禁止手工补息 + 存款定期化被高息资产置换对冲），支撑净息差降幅收窄；但息差从 1.80%（2024）→ 1.64%（2025）→ 1.52%（2026H1）仍在单边下行。
- 议价权判断：弱。作为区域性中小行，定价跟随大行与自律机制，无资产端提价能力，只能靠负债成本管控与资产结构调整对冲。

下游（资产端/客户需求）：河南省「十五五」开局基建与制造业投资提供项目储备；但全省优质信贷资产争夺激烈，郑银贷款增速仅 2.08%、远低于存款增速 11.02%，且增量主要靠票据与批发类资产（票据贴现、福费廷），收益率偏低。
- 议价权判断：弱偏中。对公贷款占比 71.27%，客户以地方平台与中小微为主，利率敏感度高，议价能力有限。

产业链位置：位于金融链条末端，无上游资源属性；其「原材料」是存款资金，「产品」是信贷与非息服务，两头均受监管定价约束。核心矛盾不是规模，而是「高风险成本 + 低资本充足率 + 低 ROE」三重压制。

第二步进阶：成本 → 收入结构传导（银行版四因子，与制造业口径一一对应）

银行无「原料→毛利」链条，映射为「负债成本/信用成本 → 收入与利润结构」四因子，方法完全同构。

因子 1 · 成本传导弹性（pass-through，量化为转嫁系数）
- 负债成本传导率 ≈ 0.85：存款利率下调可较快传导至付息率（2026H1 存款 +11.02% 而利息支出未同步扩张，利息净收入仍 +3.29% 至 55.27 亿元），说明负债端降本大部分被自身留存，形成息差缓冲。
- 资产端传导率 ≈ 1.0（反向）：LPR 下调几乎 100% 传导给客户，公司无法拒绝重定价。→ 综合转嫁系数约 0.45，即市场利率每下行 10bp，净息差约承压 5–6bp。依据：净息差从 1.80% 降至 1.52%（−28bp）对应同期 LPR 累计下行约 45–50bp，实测弹性约 0.55–0.62，与估计一致。
- 验证点：2026H2 存款平均付息率与净息差季报披露值；证伪信号：息差单季再降超 8bp 且存款成本未同步下降。

因子 2 · 收入结构再平衡（禁单一综合指标掩盖结构迁移）
- 公司银行 62.99%（+19.94%）、资金业务 26.88%（−4.24%）、零售银行 9.59%（−47.60%）。
- 结构正在向「对公 + 自营资金」单极集中，零售大幅失血。零售收入占比从 2025H1 的约 18% 降至 9.59%，是本行利润增速大幅跑输城商行板块的直接原因之一（2026H1 城商行营收 +8.1% vs 郑银 +1.04%）。
- 利息净收入占营收 81.76%，非息贡献极低 → 收入结构单一、对息差弹性最大。
- 验证点：2026 年报零售银行收入是否止跌；证伪信号：零售收入连续两个报告期同比降幅 >30%。

因子 3 · 资产久期与「库存」节奏（timing，别把浮盈当真实盈利）
- 银行版「库存」= 债券投资组合 + 拨备池。
- 拨备池是最大的「蓄水池」：拨备覆盖率 193.61%（+7.80pct），贷款拨备率 3.26%。若未来少提拨备 10pct 覆盖率即可释放约 13.6 亿元税前利润——但这是存量缓冲的一次性释放，不能当作持续盈利能力。
- 债券组合：2026H1 债权投资较年初 −12.16%、买入返售金融资产 +403.92%、拆出资金 +59.21% → 资产配置明显向短久期、高流动性倾斜，主动放弃长久期债券浮盈去保流动性与资本。2026H1 资金业务收入 −4.24% 印证。
- 验证点：季报中「其他综合收益/公允价值变动」与债券投资规模变化；证伪信号：靠处置债券浮盈充利润（投资收益单季异常跳升）而未改善核心息差。

层 2 · 扩展业务：主业迁移空间（银行版「新池塘」）
1. 能力可迁移性：县域渠道 + 惠农站点体系可迁移至乡村振兴金融、涉农供应链金融、县域消费信贷，技术同源度高（渠道复用，边际成本低）。
2. 新 TAM 弹性：河南涉农贷款市场与县域消费金融市场体量远大于郑银存量；但单位收益率低、风险成本高，TAM 大而利润率薄。
3. 切入时点与卡位：涉农贷款 559.19 亿元已具规模、科技贷款 333.08 亿元尚小 → 处于早期卡位阶段。
4. 客户认证门槛：银行牌照 + 1400 余户产业链客户 + 15 地市网点，渠道即护城河，但产品同质化严重。
5. 信号验证：科技贷款增速（2025 年 +25.57% → 2026H1 仅 +3.36%）已明显减速，迁移信号转弱。
→ 结论：迁移空间成立但弹性有限，仅作中期期权，不计入中性净利。

层 3 · 风险折扣：证伪信号
- 净息差单季再降超 8bp 且存款成本未同步下降 → 息差逻辑证伪
- 贷款增速持续低于 3% 而存款维持两位数增长 → 「资产荒」固化，规模不经济
- 核心一级资本充足率跌破 8.0% → 触发再融资，摊薄股东
- 不良生成率反弹 / 拨备覆盖率掉头向下 → 资产质量改善逻辑证伪
- 连续两年零分红 → 股东回报逻辑持续缺位

第四步进阶：重资产/周期股估值校正（三道闸 + 期权纪律）

校正 1 · 资产质量折扣（破净原因必须说明）

郑州银行 PB 0.34x，必须先回答「为什么破净」：

破净原因 是否成立 证据
资产盈利能力差（ROE 低） ✅ 成立 归属普通股股东加权 ROE 仅 3.16%（2025），远低于 COE 10%；PB = ROE/COE ≈ 0.32x，与现价 0.34x 吻合
隐含负债 / 净资产虚高 ✅ 部分成立 贷款拨备率 3.26%、拨备覆盖率 193.61%（同业偏低）；逾期贷款占比 3.12%，存量风险仍在出清；关注类贷款迁徙率 3.23%
资本缺口压制 ✅ 成立 核心一级资本充足率 8.20%，仅高于监管红线 0.7pct，A 股上市银行垫底；90.92 亿股中以 1.74 元计，每补充 1pct 核心一级需约 55 亿元，必然摊薄
「金融资产未按市价重估」型真破净 ❌ 不成立 郑银不持有大量上市股权；其债券投资已按公允价值计量并已反映在净资产中。不存在隐藏的重估空间

→ 结论：本股破净为「低 ROE + 资本缺口 + 高信用成本」的公允定价，不构成安全边际。禁止单凭 PB<1 推导大空间。 若未来 ROE 回升至 6%（需信用成本大幅下降），公允 PB 方可达 0.6x，届时对应股价约 3.1 元。

校正 2 · 周期位置校正（中性净利用周期归一化）

银行不属典型强周期，但信用周期特征显著。中性净利禁止用单年好年景或近三年均值（2023–2025 归母分别为约 18.8/18.8/18.95 亿元，正处于信用成本高位、利润被压制的底部平台，非上行）。

  • 周期归一化口径：以「信用成本归一化」为核心——历史上郑银信用成本波动区间约 1.2%–2.4%，取中枢 1.35%（略偏保守，因存量不良尚未出清完毕）。
  • 当前周期位置标注：信用成本高位、利润底部、资产质量边际改善的「底部偏右侧」。此位置下中性不过度悲观（资产质量三项指标已改善），但也不应假设快速均值回归。
  • 验证点：不良生成率、核销规模、逾期贷款占比（3.12% 是否继续下降）。
  • 证伪信号：逾期占比反弹至 4% 以上，则周期位置判断错误，中性须下调至 22–23 亿元。

校正 3 · 杠杆下行情景（高负债必附负面情景）

  • 银行业天然高杠杆（杠杆率 6.41%，总资产/净资产约 13.5 倍）。
  • 负面情景：①LPR 再下行 30bp 而存款成本下行受阻 → 净息差跌至 1.35%，年化减少利息净收入约 11 亿元；②河南城投与地产风险二次暴露 → 信用成本从 1.35% 反弹至 2.0%，年化增加计提约 34 亿元。
  • 二者叠加下，2029E 归母可转负约 −10 亿元，空间转负至 −100%（理论退市风险）。
  • 该负面情景若成立，本股不得标「大空间/重点关注」——本报告结论仅为「纳入观察」并明确标注高贝塔、高政策敏感性属性。

期权纪律（接第三步进阶）
- 「核心一级资本补充」「恢复现金分红」「银行板块估值修复（行业 beta）」三项均未过验证点（定增/配股无公告、连续不分红、板块 beta 不可控），一律不计入中性 27.0 亿元净利与 1.93 元目标价，仅置于乐观情景（3.13 元）。

第五步：综合赔率判断（买不买？）

当前价格位置：破净但不算便宜。现价 1.74 元对应 2026E PE 7.79x、PB 0.34x。对一个归属普通股 ROE 仅 3.16%、核心一级资本充足率同业垫底、连续六年五次零分红的城商行而言，0.34x PB 与其「公允 PB ≈ 0.32x」基本对齐——市场定价是理性的，不是错杀。

安全边际：
- 中性远期 1.93 元 → 空间 +10.9%，远低于「重点关注」的 >50% 门槛
- 悲观情景 1.15 元 → 下行 −33.9%，风险收益比不对称偏负
- 乐观情景 3.13 元 → +79.9%，但需信用成本降至 1.10% + 恢复分红双重条件
- 下行保护有限：每股净资产 5.16 元虽提供账面支撑，但资产端以信贷为主、无重估空间，净资产≠清算价值；拨备覆盖率 193.61% 在同业中偏低，缓冲垫不厚

介入条件：
1. 价格条件：不参与现价。需跌至 1.45 元以下（对应 PB 0.28x、2026E PE 6.5x）方具初步安全边际；1.20 元以下（PB 0.23x）为深度价值区
2. 信号条件（任一触发方可考虑）：① 恢复现金分红（或明确中期分红时间表）——这是 PB 重估的第一触发器；② 核心一级资本充足率回升至 8.6% 以上（证明扩表能力解锁）；③ 信用成本连续两个季度低于 1.4%（利润弹性释放）
3. 观察指标：逐季净息差、逾期贷款占比、单季归母净利（重点看 H2 是否再度被计提吞没）

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 资本充足率触线（首要）：核心一级 8.20%，仅高于 7.5% 红线 0.7pct。一旦扩表或风险资产上升，将被迫定增/配股，直接摊薄 90.92 亿股股东
2. ⚠️ 长期不分红：2020–2023 连续四年、2025 年度及 2026 中期均不分红，六年五次零现金分红，中证投服中心曾就分红问题发出质询函 → 股东回报机制缺失，估值修复无从触发
3. H2 利润结构性塌陷：2025Q4 单季归母为负、全年 H2 仅 2.68 亿元，说明账面利润的持续性依赖「H1 冲量 + H2 计提」的会计节奏，不可外推
4. 收入结构单极 + 零售失血：利息净收入占 81.76%，零售银行收入同比 −47.60%，板块 beta 下行时无对冲
5. 区域集中风险：资产几乎全部集中在河南省，区域经济与财政状况即信用风险的上限

类型 C · 市场错杀修复
- 错杀证据：部分成立。PB 0.34x 处历史极低分位、H 股折算 PB 约 0.15x（折算价计），A/H 折价显著；2026H1 不良率、拨备覆盖率、逾期贷款「三项改善」，基本面并未恶化。
- 但错杀程度不足以支撑大空间：公允价值 PB ≈ 0.32x 与现价 0.34x 基本一致，不存在明显低估缺口。
- 修复触发点：银行板块风格回归 + 郑银恢复分红。
- 验证点：板块 PB 分位、郑银分红公告。证伪信号：基本面恶化（逾期反弹）即错杀证伪。
- 上调至「重点关注」的条件：PB 回落至 0.25x 以下（约 1.29 元）同时基本面未恶化。

类型 D · 技术突破/技术代际跃迁期权
- 本类不成立。银行无「技术路线从 0 到 1 重构竞争格局」的载体：数字化（智慧银行）属效率工具而非新赛道，且郑银数字化投入与头部城商行存在代际差。硬验证点（中试良率、客户定点、量产成本）在银行语境下无对应物。
- 唯一近似项：科技金融（科技贷款 333.08 亿元）+ 投贷联动若形成独立盈利模式，可视为「新业务曲线」。但 2026H1 科技贷款增速仅 +3.36%（2025 年 +25.57%），信号已转弱。
- 结论：仅作观察，不计入任何情景。

什么条件出现才把结论上调至重点关注：
① 恢复常态化现金分红（分红率 ≥ 20%） 且 ② 信用成本连续两季低于 1.4% 且 ③ 核心一级资本充足率回升至 8.6% 以上——三者同时满足，方可将结论由「纳入观察」上调至「重点关注」，届时中性目标价可上修至 2.60–3.00 元。

结论：纳入观察

理由：破净属「低 ROE + 资本缺口 + 高信用成本」的公允定价，非错杀；中性远期空间仅 +10.9%，不满足「重点关注」门槛；悲观情景下行 −33.9%，赔率不对称偏负。
但不必回避：资产质量三项指标（不良率、拨备覆盖率、逾期贷款）已连续改善，逾期余额半年压降 26.01%，2026H1 营收利润双增，且成本收入比 20.73% 为同业优秀水平。一旦分红恢复 + 信用成本拐点确认，存在 PB 从 0.34x 修复至 0.6x 的弹性（乐观 +79.9%）。
核心跟踪点：① 是否恢复现金分红；② 核心一级资本充足率；③ 信用成本与逾期贷款占比的季度趋势。
