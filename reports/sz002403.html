股东背景：民营控股，实控人陈合林家族；控股钱江机器人。

【第二步进阶：原料成本 → 毛利结构四因子】

  • 因子① 成本传导弹性（转嫁系数）：炊电对铝/不锈钢敏感，内销品牌转嫁系数 ≈ 0.5、外销商超 ≈ 0.3（2026H1 原料涨 + 汇兑致外销亏损）；机器人对核心零部件敏感，转嫁系数 ≈ 0.3（毛利率降至 16.22%）。加权转嫁系数 ≈ 0.4。
  • 因子② 毛利结构再平衡（分业务线）：炊电（33.85%，占比 84%）+ 小家电（约 25%）+ 机器人（16.22%，占比 12% 且下滑）。结构恶化信号：高毛利炊电占比稳但机器人低毛利占比升 → 加权毛利被稀释。禁单一综合毛利率：机器人毛利率下滑掩盖结构压力。
  • 因子③ 库存与采购节奏（timing）：铝/不锈钢低价囤货可降成本，但 2026H1 原料整体上行，无库存收益；汇兑损失为账面（timing）。
  • 因子④ 政策/市场锚点：① 市场层——铝/不锈钢价格；② 政策层——人民币升值（汇兑）；③ 政策层——美国关税（外销）；④ 政策层——以旧换新（内销托底）+ 人形机器人（新赛道）。情景：若人民币回落、铝价稳，炊电利润修复（验证点：美元中间价、LME 铝价）。

【第三步进阶：份额变量与主业迁移三层法】

  • 层1 现有业务：市场容量 × 份额变量：① 供给侧——炊电产能充足；② 客户侧——欧美商超认证 + 线上渠道高增长（直播 +40.93%）；③ 技术代际——钛材质升级风口；④ 成本曲线——规模 + 品牌；⑤ 份额加速度——线上份额加速、外销待恢复。三档：保守守住（炊电 CAGR 5%）、中性小幅提升（8%）、乐观抢份额（12%，外销恢复 + 线上高增）。验证点：下季度线上/外销出货。
  • 层2 扩展业务：主业迁移空间：从"炊电"迁移至"工业机器人 → 人形机器人"，新 TAM（具身智能）远大于炊电；能力可迁移（制造/控制）；切入时点早（2026 量产元年）；认证门槛高；信号验证=四足机器狗部署中但未规模商业化。→ 中期期权，未过验证点不计入中性净利。
  • 层3 风险折扣（证伪信号）：外销持续亏损、机器人毛利率破 15%、人形机器人无订单。命中则下调。

第四步：估值锚定（自下而上，正常化净利润法）

方法说明：亏损股不能用 PE。按"估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价"。亏损三问见后。

总股本：约 3.41 亿股（gtimg 总股本 340,638,579 股）

正常化净利润推导（2029E 中性）

  • 稳态营收：炊电 ~12 亿（恢复）+ 小家电 ~1.5 亿 + 机器人 ~3.5 亿（规模减亏）= 约 17 亿
  • 保守正常化净利率（取三者最低）：炊电历史最好约 8%、机器人达规模后盈亏平衡、整体取 6%（保守）
  • 正常化净利润 = 17 亿 × 6% ≈ 1.5 亿（中性）；乐观机器人扭亏贡献则 2.0–2.6 亿

基准（2026E）：仍亏损

  • H1 归母 −9341 万；H2 假设外销好转 + 费用管控，亏损收窄至约 −4000 万
  • 2026E 归母净利 ≈ −1.3 亿（仍亏），无正 PE 锚；基准价参考 2027E 扭亏预期

【第四步进阶：亏损股估值校正】
- 资产质量：PB 2.67x 未破净，净资产 13.07 亿为有效制造资产；非金融资产未重估型破净，当前安全。
- 周期位置：炊电为消费弱周期，当前处于外销逆风 + 机器人培育期底部，非顶部。
- 杠杆下行：经营现金流 −2528 万（承压但非枯竭），无高负债危机；若需求下行净利可更负，但净资产厚、可撑 2–3 年。
- 期权纪律：人形机器人期权未商业化验证，不计入中性净利，仅放乐观情景。

亏损股三问：
1. 为什么亏：① 外销（美国为主）恢复不及预期 + 人民币升值汇兑损失（财务费 +80.7% 至 4284 万）；② 铝/不锈钢原料成本上升；③ 机器人板块营收增但毛利率降至 16.22%、亏损扩大；④ 销售费 +25.96%（营销投入）+ 资产减值 +61.38%（存货跌价）。属"外销逆风 + 培育期投入"型亏损，非资产减值黑洞。
2. 靠什么扭亏 / 时点：炊电基本盘（毛利 33.85%）恢复 + 外销 H2 好转（公司指引）+ 汇兑平稳 → 集团 2026H2 逼近盈亏平衡；机器人规模效应减亏；时点：2027 全年经营扭亏（2026 仍亏、2027 转盈）。
3. 亏得起吗：归母净资产 13.07 亿、经营现金流 −2528 万（承压但非枯竭）、无重大有息危机；账面可支撑 2–3 年培育期，亏得起。

交叉校验：现价 10.23 元对应中性正常化 9.68 元，已略高于中性（市场定价含机器人期权）；乐观 21.35 元需机器人实质性扭亏。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（已含机器人预期）。现价 10.23 元 > 中性正常化 9.68 元，市场已提前定价人形机器人期权。

安全边际：
- 中性远期 9.68 元 → −5.4%（当前价已透支中性）
- 悲观 3.17 元 → −69.0%（若机器人持续亏损、外销恶化）
- 乐观 21.35 元 → +108.7%（机器人扭亏 + 人形定点）
- 下行保护：PB 2.67x、净资产 13 亿厚、炊电现金牛

介入条件：
1. 9.7 元以下（中性目标价）分批，或更优 7 元以下（接近 2027E 扭亏预期）
2. 加仓信号：① 季报验证炊电净利率回升至 8%+；② 机器人亏损收窄/人形机器人获正式定点；③ 外销恢复 + 人民币贬值
3. 观察指标：逐季归母盈亏、机器人毛利率、经营现金流转正

最大风险：① 外销持续亏损；② 机器人长期不兑现象（烧钱无产出）；③ 人形机器人商业化证伪；④ 人民币继续升值。

结论：纳入观察（当前价已含期权预期，等回调至中性 9.7 元以下或扭亏信号验证；不上调重点关注因中性空间为负）

爱仕达有清晰扭亏路径（炊电现金牛 + 外销 H2 好转 + 机器人减亏），且亏得起（净资产厚）。但现价 10.23 元已高于中性正常化 9.68 元，机器人期权尚未验证。宜"纳入观察、等回调/等验证"。

【第五步进阶：上行想象力情景（四类）】
- A 行业调整剩者红利：炊电中小企业（无品牌/无线上）出清，爱仕达品牌 + 直播电商份额提升（验证点：份额公告；证伪：份额连降）。
- B 政策反转期权：人民币贬值（汇兑收益）+ 美国关税缓和（外销恢复）（硬验证点：美元中间价 7.1+、关税公告；证伪：续升/加码）。
- C 市场错杀修复：2026H1 因汇兑 + 机器人投入杀估值，若 H2 扭亏信号出现估值修复（验证点：季报扭亏；证伪：续亏）。
- D 技术突破/代际跃迁期权：人形机器人（四足机器狗）从 0 到 1 获工业/零售场景定点量产，具身智能 TAM 远超炊电。三要素：政策（实景实训专项行动）+ 趋势（2026 量产元年）+ 落地（携手智元、部署中）。硬验证点=送样通过+客户定点+量产成本优，三者缺一则仅作机会情景、不计入中性。→ 上调重点关注条件：人形机器人获正式大额定点且量产成本验证、机器人板块整体扭亏。
