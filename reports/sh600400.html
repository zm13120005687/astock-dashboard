（3）产业链传导：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：红豆以品牌零售+自产+外协混合模式，面料（棉/化纤）成本占服装成本约 60–70%，对上游议价权一般；但对终端消费者提价能力弱（大众性价比定位），成本传导系数约 0.3–0.5。棉花价格 2025–2026 平稳，原料并非主要矛盾，真正的成本是渠道刚性费用（租金、人员、商场扣点）——销售费用率 34.4%，吞噬全部毛利。验证点：毛利率（2026H1 37.65%，同比小幅回升）与销售费用率。
  • 因子2 毛利结构再平衡：分线看，贴牌加工毛利低（约 10–15%）但不背渠道费用、净贡献稳；男装门店 GM 高（直营约 60%+）但每店分摊租金人员后净利为负（关店 97 家仍改善不了亏损即为证据）；红豆居家线上 GM 中等但流量成本高。收入结构向贴牌迁移会拉低综合毛利率但改善净利率——这是当前唯一"有质量"的增长（H1 +27%）。验证点：分部毛利率与门店坪效。
  • 因子3 库存与采购节奏：存货 2.16 亿（较年初略降），计提存货跌价准备占比 25%（2025 年报口径），无囤货虚增毛利问题；当期盈利（亏损）基本反映经营实质。
  • 因子4 政策/市场锚点：市场层——大众休闲男装需求疲软+线上流量成本上升是收入端持续失血的主因；政策层——服装以旧换新/消费券若落地对大众服饰是直接利好（公司价位段受益），但政策落地节奏不可控，属机会情景。验证点：以旧换新是否扩围至服装品类；证伪：政策未覆盖 → 需求端无边际改善。

产能约束校验：无产能瓶颈，增长约束在渠道盈利模型——按当前门店数即使收入回到 2024 年水平也无法覆盖 34% 的销售费用率，必须先减店、再谈增长。

层1 现有业务：市场容量 × 份额变量

  • 市场容量：男装大盘 6,300 亿+但大众休闲细分零增长；公司在其中份额低且持续流失（收入增速 −16.7% vs 行业规上 −2.8%）。
  • 供给侧/需求侧：门店 818 家 vs 海澜同价位竞品 5,000+ 家，规模与品牌心智均处劣势；红豆困于"老一辈衬衫品牌"认知，年轻客群渗透不足。
  • 成本曲线位置：直营比例高（对比加盟为重的同行），关店后固定成本刚性仍在。
  • 份额二阶导：负——份额在加速下滑而非企稳。保守=2029 男装收入再降 20%；中性=2027 年后止跌企稳；乐观=产品/渠道改革见效重返增长。
  • 验证点：门店数与同店销售；证伪：关店后单店收入仍下滑 → 中性假设下修。

层2 主业迁移空间（按中期期权处理）

  • 能力可迁移性一般：男装运营能力向居家线上迁移已由收购落地（2025-12-31 并表），但目前线上同样下滑（−14.8%）；
  • 贴牌加工（+27%）是当前唯一验证通过的增长极，但属低毛利代工、天花板有限；
  • 集团体系内 10.55 亿股权投资（财务公司、小贷、保理等）理论上存在资产整合/退出期权，未过验证点（无公告、无处置），一律不计入中性估值。
  • 信号验证：贴牌收入占比跳升、联营亏损收窄、新增资产处置公告。

层3 风险折扣：证伪信号

  • 男装同店销售持续为负且关店速度放缓 → 减亏逻辑失效；
  • 联营（小贷/保理）减值继续放大 → 净资产进一步缩水；
  • 控股股东质押比例居高（57.31%）+ 关联资金占用 → 治理风险暴露时估值系统性下移。

第四步：估值锚定（自下而上，非增速外推）

方法说明：亏损股用正常化净利润法——估稳态营收 → 算保守正常化净利率 → 正常化净利 × 远期 PE。另以净资产/PB 作交叉校验，未过验证点的资产整合期权不计入中性。

亏损三问（为什么亏 / 靠什么扭亏 / 亏得起吗）

  1. 为什么亏：①主业萎缩+毛利下滑：2025 年营收 −20.1%、毛利率 −3.04pct，毛利额减少 2.46 亿（行业大众休闲疲软 + 主动关店）；②渠道刚性费用：销售费用率约 34%（2026H1 销售费用 3.54 亿 vs 毛利 3.87 亿），门店收入规模撑不起直营网络；③联营企业失血：阿福科贷/阿福保理等联营投资 2025 年确认损失 7,021 万（同比大增）；④政府补助减少、资产处置收益减少等一次性因素。属主业持续恶化型亏损，非一次性减值主导。
  2. 靠什么扭亏、触发时点：路径=关店止损（818→~700 家）+ 贴牌加工扩张 + 联营处置止血。贴牌已是唯一正增长引擎（H1 +27%）；居家线上 2027 年前难以盈利。预计 2027–2028 年减亏至盈亏平衡边缘（中性 2029 微利 0.7 亿）。触发验证点：单季归母转正、门店店效回升、联营投资损失收窄至 0。
  3. 亏得起吗：短期能撑住，中期偏紧。现金 5.27 亿基本覆盖短贷 4.69 亿；2025 年经营现金流 +2.81 亿转正、2026H1 +0.26 亿，主业不烧现金（亏的是折旧+权益法损失等非现金项）；但累计未分配利润 −1.36 亿已无法分红，控股股东质押 57.31%、关联资金占用与集团财务公司存款风险构成治理层面的"或有出血点"——若集团体系信用事件暴露，可能被迫计提。

交叉校验

现价 3.20 元 = PB 5.71x，对一家持续亏损、净资产质量差（82% 沉淀为低收益长期股权投资）、无法分红的服装企业，估值隐含的是"品牌+壳+整合期权"溢价。即使乐观情景（1.6 亿净利）也只支撑 2.10 元（−34%），当前价格相对基本面高度透支。

第五步：综合赔率判断（买不买？）

当前价格位置：明显高估（基本面口径）。中性正常化价值 0.86 元、乐观情景 2.10 元，均低于现价；市场在交易题材而非业绩（2026-09-07 涨停 +10.1% 上龙虎榜，买一为游资席位开源证券西安西大街，无基本面公告支撑）。

安全边际：
- 中性远期 0.86 元 → −73.1%；乐观也仅 −34.4%
- 净资产 12.85 亿（每股 0.56 元）是硬底参考，但其中 10.55 亿低收益股权投资变现价值存疑
- 3 元以上的任何价格都无基本面安全边际

介入条件：
1. 1.2 元以下（PB < 2.2x）才谈得上用净资产折扣价博弈反转
2. 或等待经营拐点确认：单季归母转正 + 门店店效回升 + 联营损失止血三信号同现后再评估
3. 当前价位无介入价值，题材波动（游资龙虎榜）属博弈而非投资

最大风险（最可能破坏逻辑的因素）：
1. 主业持续萎缩：男装同店负增长 + 关店带来的收入螺旋，2027 年前看不到利润拐点
2. 净资产进一步缩水：联营小贷/保理资产质量恶化，或集团财务公司存款/资金占用问题暴露
3. 治理风险：股权质押 57.31%、关联资金占用、带强调事项段审计意见——单一事件即触发估值崩塌
4. 题材退潮：9-7 涨停式异动无业绩支撑，游资撤离后股价向基本面回归

上行想象力情景（显式建模，仅供跟踪）：
- 类型A 行业剩者红利：大众休闲男装尾部出清（行业亏损面 22.6%）后，红豆作为"活下来的老品牌"承接部分份额——但目前红豆自身即是出清对象，该逻辑不成立，不下注。
- 类型B 政策反转期权：服装以旧换新/消费券若覆盖大众服饰，红豆价格带（100–500 元）最受益。反转信号：补贴目录含服装品类；弹性：需求 +10% ≈ 红豆 +2 亿收入。未过验证点仅作机会情景。
- 类型C 市场错杀修复：不适用——当前为题材溢价而非错杀，反向风险更大。
- 类型D 资产整合期权（唯一可想象的上行）：集团体系内 10.55 亿股权投资（财务公司/小贷/保理）若被置出/换入盈利资产，或红豆集团资产注入上市平台，可重构估值。硬验证点：正式重组/处置公告 + 交易对价 > 账面 + 置入资产盈利。三者齐备前不计入任何估值情景。
- 什么条件出现才上调"重点关注"：现实路径上极难——需单季归母转正、联营止血、并出现大股东资产整合的正式公告，且股价回到 1.5 元以下。当前不具备任何上调条件。
