（3）产业链传导

上游：工程师人力（最大成本）、算力 / 云资源（转嫁客户）、办公场地。下游：金融 / 互联网 / 汽车等头部企业，客户强势、年降 / 压价常态。

议价权：对下游——中等偏弱（IT 服务充分竞争、客户压价）；对上游——中等（云资源可转嫁客户，人力不可转嫁）。盈利提升靠 AI / 信创高附加值占比上升，非涨价。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（转嫁系数）：人力成本（工程师薪酬）传导系数约 0.25（客户压价、难转嫁），是综合毛利由 17.76% 降至 16.60% 的主因；云 / 算力成本可转嫁（系数 ~0.9）。
  • 因子2 毛利结构再平衡：通用 16.83% ≈ 创新 16.22%，两者毛利接近、无显著结构迁移——创新业务增长快但尚未体现毛利溢价（规模效应未显）。禁止用单一综合毛利 16.6% 代表全结构，需分业务跟踪创新业务毛利能否随 AI 占比提升而上台阶。
  • 因子3 库存与采购节奏：轻资产、无原料库存；人力为当期费用，无囤货收益 / 接货损失；但应收账款（人工垫付）形成负向现金流。
  • 因子4 政策 / 市场锚点（成本驱动变量）：①市场层——工程师薪酬通胀、汇率（海外）、云资源价；②政策层——信创 / AI / 数据要素（需求驱动，利好收入但亦推高研发投入）。验证点：工程师薪酬、AI 收入占比、海外汇率；证伪：人力成本失控致毛利破 15%、AI 收入未放量。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：IT 服务充分竞争（竞争对手 610+），份额分散；
  • 客户份额：金融 / 互联网头部覆盖，银行 TOP50 覆盖率提升；
  • 技术代际差：鸿蒙 / AI 智能体领先同业；
  • 成本曲线：人员结构优化（本科以上 +23pct）、规模效应；
  • 份额二阶导数：稳健渗透，非爆发。
    三档：保守守住 / 中性小幅提升（行业 Know-how 壁垒）/ 乐观抢份额（AI 先发）。
  • 层2 扩展业务：主业迁移空间（传统 IT 服务 → 智能化解决方案 / AI Agent）：能力可迁移（软件工程同源）、新 TAM（AI 支出 2.59 万亿美元）、切入早（FarAgent 已发布）、认证门槛中（客户生态）。未过验证点（AI 收入占比跳升 / 毛利改善兑现）仅作中期期权。
  • 层3 风险折扣（证伪信号）：AI 转型不及预期、人力成本失控、大客户流失、经营现金流持续恶化。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（破净原因）：不适用——PB 2.66x 未破净，轻资产模式。但净资产 22.49 亿中含大额应收账款，质量需打折看待。
  • 校正2 周期位置校正：IT 服务非强周期，需求由企业数字化支出驱动，当前处 AI 渗透早期，无周期顶部。
  • 校正3 杠杆 / 现金流下行情景：虽无有息负债高杠杆，但 2026H1 经营现金流 −4.24 亿（人工垫付 + 应收），若大客户回款延迟或行业需求下行，盈利与现金流双杀——已在悲观情景体现（空间 −44.9%），故不得标"大空间 / 重点关注"。

交叉校验：现价 13.98 元对应 TTM PE 69x、中性远期 15.40 元（+10%）——现价已部分反映 AI / 信创预期；真正重估需净利率由 1.4% 向 2.2%+ 改善兑现。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵。现价 13.98 元接近中性远期（仅 +10%），但 PB 2.66x、净利率仅 1.4%、现金流为负，估值安全垫薄。

安全边际：中性远期 +10.2%；乐观 +86.7%（需 AI 净利率改善）；悲观 −44.9%。下行保护弱（资产含应收、现金流为负）。

介入条件：① 回落至 11 元以下（对应 2029 中性 PE 约 22x 打折）；② AI / 创新业务毛利改善兑现（净利率由 1.4% 回升至 2%+）；③ 经营现金流转正且大客户订单持续（上调至重点关注）。

最大风险：① 人力成本刚性上涨吞噬本就微薄的净利率（首要）；② 经营现金流持续为负、应收账款坏账；③ IT 服务充分竞争致客户压价 / 年降；④ AI 转型不及预期，期权证伪。

结论：纳入观察（逻辑正确、增长稳健，但净利率过低 + 现金流恶化，AI 转型验证前不追高）。

第五步进阶：上行想象力四类情景

  • A 行业出信创剩者红利：IT 服务行业整合，头部（法本）凭人员规模 + 行业 Know-how 剩者，份额提升。验证点：研发费用率优化、人均产出跳升；证伪：份额流失。
  • B 政策反转期权：信创 / AI / 数据要素政策加码（"人工智能+"行动、鸿蒙强制渗透）。验证点：政策细则、国产替代订单放量；重估弹性：乐观 26.1 元（+87%）。未过验证点仅作机会情景。
  • C 市场错杀修复：软件 / AI 板块系统性回调错杀（估值分位回撤）。验证点：板块企稳、基本面未恶化。
  • D 技术突破 / 代际跃迁期权：FarAgent 企业级智能体 + AI+ERP 从 0 到 1 规模化，重构交付模式、抬升净利率。三要素：政策（人工智能+）+ 趋势（AI 支出 +47%）+ 落地（客户定点 + 规模化交付 + 成本优于旧模式）。硬验证点缺一则只作机会情景。触发上调重点关注条件：AI 收入占比跳升且净利率回升至 2% 以上。
