第一步：公司是干什么的？

一句话定位：深圳起家的民营城乡规划设计与城市运营服务商，给地方政府做国土空间规划、城市更新、TOD、景观市政等"空间资产"顶层设计与全程咨询，并延伸智慧城乡、城市运营、投资业务。

股东背景：实控人王富海（规划行业资深专家），民营控股，无央企 / 国资背景。

（3）产业链传导

上游：人力（规划师薪酬）、数据外包、差旅——轻资产，成本端主要是人工刚性，收入下滑时成本无法同比例压缩（费用率飙升的根因）。

下游：地方政府 / 城投。下游"没钱"直接导致：① 新签金额小且慢；② 已签项目回款拉长（2026H1 经营现金流 −3191 万虽同比改善，但仍为负）；③ 为抢单被动降价→毛利率崩。

议价权：弱。客户为强势甲方（政府），且行业供给过剩、民营设计院众多，公司无定价权，属"乙方中的乙方"。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：≈ 0。规划设计无实物原料，核心成本是人工，属于刚性固定成本，无法向客户转嫁；收入下滑时毛利被费用吞噬。转嫁系数≈0，与"弱议价权"一致。
  • 因子2 毛利结构再平衡：业务高度单一（规划设计 92%），无多产品线对冲；毛利率从 45% 量级骤降至 12%，是全结构塌方而非某一产线问题，加权后利润贡献近乎归零。
  • 因子3 库存与采购节奏（timing）：无存货型库存收益 / 损失问题（轻资产服务），但存在已发生人工成本 vs 收入确认滞后的"在产未结"timing——收入确认慢于成本发生，加剧当期亏损。
  • 因子4 政策 / 市场锚点：直接驱动变量是地方财政 / 土地出让收入与政府投资节奏（市场层），以及"十五五"规划、城市更新、低效用地再开发等（政策层）。情景：若 2027–2028 地方财政企稳 + 规划集中编制，订单与毛利率修复；若财政继续收紧，亏损延续。
  • 验证点：各季度新签合同金额、经营现金流转正、毛利率重回 30%+。
  • 证伪信号：连续两季营收同比仍 −30% 以上、毛利率持续低于 20%、应收账款 / 现金流恶化。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：民营规划院产能过剩，价格战；公司份额稳定在民营梯队中游。
  • 需求侧：前五大客户为地方政府，分散，无单一大客户粘性。
  • 技术代际：规划编制技术同质化，无代际差。
  • 成本曲线：人工成本刚性，规模不经济。
  • 份额加速度：行业收缩期份额难扩张。
  • 三档：保守（份额守住，营收回 2.5 亿）/ 中性（回 3.0 亿）/ 乐观（财政强刺激回 3.5 亿）。验证点：季度新签金额。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：城市运营 / 低空规划 / AI 工具为潜在迁移，但均处概念期、无客户认证与订单，按期权纪律不计入中性。
  • 层3 风险折扣（证伪信号）：地方财政继续恶化、规划预算砍单、毛利率持续 <20% → 下调 / 剔除增量。

第四步：估值锚定（自下而上，非增速外推）

亏损股方法：无正净利可锚，采用正常化净利润法（估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价）。严禁历史增速外推——下文全部基于产能 / 订单 / 政策结构与 2026H1 已验证的盈利能力。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（破净原因）：公司 PB>1（3.5x），非破净，但轻资产设计公司的净资产以应收账款 + 货币资金为主，地方政府应收账款存在回款不确定性，真实可变现净资产应打折——这解释了为何不能用账面价值支撑估值。
  • 校正2 周期位置校正：规划设计属强政策 / 财政周期，当前处于周期底部（财政最紧），中性净利已按底部修复后的保守净利率测算，未乐观外推。
  • 校正3 杠杆下行情景：资产负债率仅 ~15.5%，无高负债风险，无需杠杆下行情景，但收入端下行（财政再恶化）可直接将净利打为负，悲观情景已覆盖（0.71 元）。
  • 期权纪律：低空经济 / AI 规划 / 城市运营等"中期期权"均未过验证点，不计入中性 NAV，仅放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：严重高估。现价 15.75 元对应正常化净利 133 倍 PE、净资产 3.5 倍 PB，与 2026H1 营收 −40%、毛利率崩至 12%、深亏的基本面完全背离——是典型的"政策题材溢价 + 历史高位估值残留"。

安全边际：中性远期 2.5 元 → 空间 −84.1%；即使乐观 4.6 元仍 −70.8%。下行保护极弱，唯一锚是净资产 9.45 亿（打折后约 4–5 元/股），现价已远超。

介入条件：
1. 不追高，现价绝不介入。
2. 重新考虑的价格：回落至 4.5 元以下（接近净资产、PB≈1），且需同步出现：① 单季营收同比转正；② 毛利率重回 30%+；③ 经营现金流转正。
3. 上调至"纳入观察"的条件：十五五规划编制订单在 2027 年集中释放、新签金额显著放量。

最大风险（最可能破坏逻辑的因素）：
1. 地方财政持续收紧——这是公司景气度的唯一命门，2026H1 已验证订单断档；
2. 毛利率长期低位（轻资产 + 人工刚性，收入不恢复则利润难修复）；
3. 应收账款回款风险（地方政府回款慢，资产质量打折）；
4. 题材退潮——现价靠"智慧城市 / 低空 / 十五五"题材支撑，一旦风险偏好下降，估值回归残酷。

结论：暂不介入

公司非"确无扭亏可能"（仍有真实规划业务、净资产厚、负债低，财政回暖可修复），但当前价格已彻底透支任何合理正常化估值，中性锚较现价低 84%。遵循"估值已高 / 空间有限 / 不确定性大 → 暂不介入"原则。唯一安全买点是价格回落至净资产附近（4–5 元）且基本面出现拐点信号。

第五步进阶：上行想象力情景（四类，仅进机会栏，不进中性锚）

  • 类型A 行业出清剩者红利：规划设计行业过剩、民营院出清后，头部优质院份额与定价权回升。验证点：行业产能退出数据、公司新签份额提升；证伪：份额继续流失。
  • 类型B 政策反转期权：地方财政 / 土地出让企稳 + 城市更新 / 十五五 大规模编制启动，订单与毛利率双修复。验证点：季度新签金额跳升、毛利率回 30%+；证伪：财政继续恶化。
  • 类型C 市场错杀修复：若因系统性风格切换被错杀至 PB≈1，估值分位极低。验证点：价格回落至 4–5 元且基本面未进一步恶化；证伪：基本面继续恶化。
  • 类型D 技术突破 / 代际跃迁：AI 规划工具、低空经济空间规划从 0 到 1 落地，重构增长曲线。硬验证点：自研工具量产 / 大额低空规划订单；证伪：概念无订单。

    上调至"重点关注"的条件：上述 B/C 中"地方财政企稳 + 新签放量 + 毛利率回 30%+"三项同时验证，且价格仍在 5 元以下——届时正常化净利与估值重估，空间可转正。
