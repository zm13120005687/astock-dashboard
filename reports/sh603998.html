（3）产业链传导

上游：中药材（三七、血竭、藤黄、玄参等）、化学原料药、药用辅料与包材。2026 上半年原辅包材采购价格下降是毛利率提升 5.51pct 的核心来源之一。中药材价格 2023–2024 曾大幅上涨，2025–2026 高位回落，公司作为采购方受益。

下游：医院（集采/医保）、零售药店、电商。院内端受集采与"一科一辅式"的用药治理约束，价格刚性下行但量有以价换量效应；电商端是新增量且毛利率更高。

议价权：院内偏弱（集采与医保定价），OTC/电商偏强（自主定价）。公司当前收入结构以院内为主，故整体议价权判定为中等偏弱——这也是销售费用率必须维持 36%+ 的原因。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）
  • 集采品种（依折麦布片、藤黄健骨片）：传导率 ≈ 0。集采中标价在采购周期内锁定（至 2028 年底），原料涨价 100% 自担，原料跌价 100% 留存为利润 → 本轮毛利率 +5.51pct 中相当部分是"原料降价 + 售价锁定"的被动红利，不可外推。
  • 非集采/OTC 品种（养血祛风止痛颗粒、玄七健骨片、龙血竭散）：传导率 ≈ 0.6–0.7，可通过规格调整、渠道切换部分转嫁。
  • 电商直营品种：传导率 ≈ 0.9（自主定价）。

  • → 综合传导率约 0.35–0.45（按收入加权），即上游降价 10%，公司留存 5.5%–6.5% 的毛利改善；反之上游涨价 10%，公司自担 5.5%–6.5%。毛利率对原料价格是双向高敏感。

  • 因子2 毛利结构再平衡（分业务线，禁单一综合毛利率）

→ 结构迁移结论：综合毛利率 75.81% 完全掩盖了"两大高毛利主业撑起 74% 毛利、四个中小品类集体萎缩"的真实结构。估值必须用分业务净利：心脑血管与骨骼肌肉是估值主体，其余四个品类应给清算式估值而非成长估值。中药材价格是本股毛利率的第一敏感变量。

  • 因子3 库存与采购节奏（timing）
  • 存货周转率仅 0.33 次（半年），存货约 14–15 亿元量级的备货规模，中药材囤货属性强。
  • 中药材 2023–2024 涨价周期中公司若在 2024 年高位接货，2026 年消化的是高价库存——但 2026H1 毛利率反而 +5.51pct，说明高价库存已基本消化完毕，当前用的是回落后的新采购价。
  • 反过来：当前的高毛利中含有"高价库存出清完毕"的一次性修复成分，2027 年后毛利率进一步扩张的空间收窄。

  • 公司未披露套保（中药材通常无标准期货），长协采购比例未披露 → 该因子构成主要不确定源。

  • 因子4 政策/市场锚点（原料成本驱动变量）

层2 扩展业务 = 主业迁移空间（新易盛范式）
1. 能力可迁移性：中药研发/注册/院内准入能力 → 可复用到新的中药创新药（健胃祛痛丸、蛭龙通络片）；OTC 品牌与电商运营能力可复用到新品类。
2. 新 TAM 弹性：中药创新药市场 + 罕见病药（司来帕格，肺动脉高压）市场远大于公司现有 OTC 盘子。
3. 切入卡位：养血祛风止痛颗粒已获批并进医保 → 公司已完成从"仿制/普药"到"中药创新药"的卡位切换，属早期红利。
4. 客户认证门槛：院内准入（医保、基药、集采、诊疗共识）门槛高但一旦进入粘性强——养血祛风已进医保 + 进诊疗专家共识，双门槛已过。
5. 信号验证：2026H1 心脑血管 +50.01%、三个新品年内上市——已有部分验证。

→ 纪律判定：养血祛风止痛颗粒已通过"获批 + 医保 + 诊疗共识"验证点，可计入中性；健胃祛痛丸/蛭龙通络片（III 期）未获批，仅作乐观期权，不计入中性。

层3 风险折扣：证伪信号
- 心脑血管收入同比增速跌破 10%（大单品动能衰竭）
- 销售费用率突破 40%（营销依赖加深，合规风险）
- 主力品种在后续省级联盟集采中未中选（直接丢失院内市场）

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 2.71x 不破净，不适用破净纪律。但须查资产结构：
  • 固定资产 10.35 亿 + 在建工程 0.84 亿 + 无形资产 2.51 亿 = 13.70 亿，占总资产 30.56 亿 的 44.8% —— 属偏重资产药企（自建生产基地+ GAP 药材基地）。
  • 商誉未单列披露，历史上无大额并购商誉爆雷记录 → 资产虚高风险低。
  • 存货规模大（周转率 0.33 次/半年），中药材存货存在跌价可能，但中药材具保值属性，跌价风险小于普通制造业。

  • → 结论：不额外加资产质量折扣，但因重资产导致经营杠杆偏高，中性 PE 不给超过 15x。

  • 校正2 周期位置校正：医药制造业非强周期。2026H1 规上医药制造业营收持平、利润 +4.2%，行业处于低速平稳期（非底部亦非顶部）。方盛 +14.8% 的增速来自 α（结构与新品），不是行业 beta。中性净利 5.0 亿未用单年好年景、未用近三年均值（2023–2025 归母 1.87/2.55/3.06 亿，三年均值 2.49 亿，若用均值将严重低估），而是 2029 年品种级加总后折让。当前周期位置：平稳期。

  • 校正3 杠杆下行情景（必附）：资产负债率 41.0%，未达 60% 高负债阈值，但短期偿债指标偏紧：

  • 有息负债 4.32 亿，货币资金 2.76 亿，流动比率 0.88（<1）、速动比率 0.59 → 存在短期流动性瑕疵。

  • → 结论：杠杆负面情景未使空间转负，故维持较高评级；但须注明流动比率 0.88 <1 的短期偿债瑕疵，若 2027 年前不能改善，需下调。
