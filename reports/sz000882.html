（3）产业链传导

上游：商业物业（自持，无采购成本）、人员/能耗/营销费用。影院上游为影片发行方（分账）。

下游：消费者（到店）、品牌租户（租金敏感度上升）、电影观众。对租户议价权弱（空置率上行、招商竞争激烈）；对消费者为价格接受者。

议价权：弱——消费疲软下租户谈判力强，租金增幅收窄甚至退租，公司被动。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：商业运营无原材料，核心"成本"是固定费用（折旧、人工、能耗、营销）。收入端（租金）对消费景气度传导系数≈1（消费降 → 租金降、空置升），公司几乎无法转嫁，毛利直接承压。影院成本（分账 + 固定）刚性，票房降 40% 致毛利塌方。
  • 因子2 毛利结构再平衡：租赁+物业占 71.6%（毛利 42.7%）、影院占 4.9%（毛利 57.7% 但规模塌缩 -46%）。高毛利影院占比萎缩、低毛利租赁占比上升 + 租赁自身毛利下滑，结构向低毛利迁移。单一综合毛利率 46.4% 掩盖"租赁毛利塌 + 影院规模崩"的双重恶化。
  • 因子3 库存与采购节奏：无存货周期；但公司 2026H1 出售龙德置地 50% 股权回笼现金（投资现金流 +8.74 亿），属"资产处置收益 timing"——一次性改善流动性但确认投资损失 1.11 亿，非经营盈利，不可持续。
  • 因子4 政策/市场锚点（成本驱动变量）：市场层（社会消费零售总额增速、票房大盘、空置率）；政策层（消费基础设施 REITs 决定资产出表变现能力、消费刺激政策决定客流租金）。情景：若 REITs 成功发行 → 资产盘活、流动性改善；若票房持续低迷 → 影院继续拖累。验证点：REITs 获批公告、月度社零、票房数据。

第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：社区商业区域密集，公司区域份额稳定但无扩张。
  • 需求侧：周边居民刚性消费，份额取决于区位，难大幅提升。
  • 技术代际：商业运营无技术代差。
  • 成本曲线：自持物业折旧刚性，成本曲线无优势。
  • 份额加速度：S 曲线饱和，无加速渗透。
    → 三档：保守净利 0.3 亿 / 中性 0.8 亿 / 乐观 1.5 亿。
  • 层2 主业迁移空间：从"自持运营"迁移至"轻资产输出管理 + REITs 资本运作"，能力可迁移（运营经验同源），新 TAM（资管服务费）弹性有限；REITs 出表为"资产变现"而非持续盈利迁移。信号验证：龙德 REITs 申报中（进行中），未完全过验证点，仅作中期期权。
  • 层3 证伪信号：REITs 申报中止、租金继续下滑、空置率攀升、影院持续亏损。命中则下调。

第四步：估值锚定（自下而上，非增速外推 · 亏损股正常化净利润法）

亏损股方法：先按正常化净利润法测算盈利支撑，再叠加资产重估（校正1 例外情形）锚定真实安全边际。

总股本：约 27.37 亿股；净资产 63.28 亿（BPS 2.31 元），当前 PB 0.65x（破净）。

资产重估法（校正1 例外情形·金融资产/股权未重估型）

公司总资产 122.70 亿（主要为按成本法计量的商业不动产），归母净资产 63.28 亿，总市值 41.06 亿 < 净资产 → 账面已破净。但商业物业若按市价/收益法重估，公允价值或高于账面（"未重估型真破净"），且龙德广场 REITs 申报若成功，资产出表可兑现隐含价值。

第四步进阶·重资产/周期股三道闸（商业不动产为重资产，必做）：
- 校正1 资产质量折扣（破净原因必须说明）：PB 0.65 破净主因"资产盈利能力差（ROE -3.94%、扣非 -1.45 亿）+ 资产专用性（商业物业清算价值 << 账面）+ 隐含减值风险（投资性房地产减值 3009 万、消费下行空置）"，属公允定价型破净。但公司持有商业不动产按成本法计量，若按市价重估 NAV 或高于账面（总市值 41 亿 vs 净资产 63 亿，差额即市场对资产质量/流动性的折价），属"金融资产/股权未重估型"潜在安全边际——已列示：总资产 122.70 亿、净资产 63.28 亿、总市值 41.06 亿，REITs 成功可验证重估价值。
- 校正2 周期位置校正：当前处"消费弱复苏 + 线下零售出清"周期底部，中性估值未用单年好年景、未将 H1 一次性股权损失年化，采用资产 PB 周期归一化（历史商业 PB 中枢 1.0–1.5x）。
- 校正3 杠杆下行情景：负债率 48.4%（适中），若消费再降 + 资产减值扩大，PB 可跌至 0.55（悲观 1.27 元，−15.3%）；因下行情景转负，不得标"大空间/重点关注"，至多"暂不介入/纳入观察"。

第五步：综合赔率判断（买不买？）

当前价格位置：破净（PB 0.65），但盈利无法支撑——价格由资产价值与 REITs 预期驱动，而非经营利润。

安全边际：
- 中性远期 1.96 元 → 空间 +30.7%（资产 PB 修复逻辑）
- 悲观情景 1.27 元 → −15.3%（REITs 失败 + 减值）
- 乐观情景 2.31 元 → +54.0%（REITs 成功 + 消费复苏）
- 下行保护：总资产 122.7 亿、净资产 63.28 亿兜底，但流动性/空置风险限制。

介入条件：
1. 现价 1.50（PB 0.65）已反映悲观，但盈利支撑仅 0.47 元，须等资产催化：龙德广场 REITs 成功发行公告为关键介入信号。
2. 加仓信号：① REITs 获批/上市；② 单季扣非扭亏；③ 租金空置率改善、票房回暖。
3. 价格条件：回落至 1.30 元以下（PB<0.57）或更安全。

最大风险：
1. REITs 申报失败/推迟（首要）：资产盘活逻辑证伪，回归盈利定价（0.47 元）。
2. 消费持续疲软致租金下滑、空置率升、投资性房地产进一步减值。
3. 影院业务长期低迷。

结论：暂不介入

理由：盈利支撑仅 0.47 元（正常化净利法），当前价格完全依赖资产/REITs 预期；中性 +30.7% 来自 PB 修复但下行情景 −15.3%（校正3 限制），且 REITs 尚未落地、主业扣非仍亏。属"资产期权等待催化"标的，待 REITs 成功发行或单季扣非扭亏后再上修。核心跟踪：龙德 REITs 审批进展、租金空置率、票房。

亏损股三问

  1. 为什么亏：① 消费复苏乏力 + 上半年票房 -40% → 影院收入腰斩；② 出售龙德置地 50% 股权确认投资损失 ~1.11 亿；③ 投资性房地产减值 3009 万；④ 费用率升至 63.79%。扣非仍亏 1.45 亿，主业确实承压。属"周期底部 + 一次性资产处置损失"型。
  2. 靠什么扭亏，触发时点：① 消费弱复苏 → 租金/客流回升；② 影院随档期回暖；③ 龙德广场 REITs 成功发行 → 资产出表、流动性与估值重估（关键触发点）。中性预计 2027 年扣非扭亏，2029 正常化净利 0.8 亿。
  3. 亏得起吗：总资产 122.7 亿、净资产 63.28 亿厚实，经营现金流 +1.71 亿（出售股权回笼），负债率仅 48.4%，亏得起，无退市/破产风险。

第五步进阶·上行想象力情景（四类）

  • A 行业调整剩者红利：线下零售出清后优质社区商业份额提升（验证点：空置率、招商率；证伪：持续退租）。
  • B 政策反转期权（核心）：消费基础设施 REITs 常态化 + 消费刺激加码 → 龙德广场 REITs 成功发行，资产价值重估（验证点：REITs 获批公告；证伪：申报中止/估值未重估）。未过验证点仅作机会情景。
  • C 市场错杀修复：若消费数据回暖带动板块情绪，破净零售股修复（验证点：社零增速、板块估值分位；证伪：基本面恶化）。
  • D 技术突破/代际跃迁：不适用（非技术型公司）。
  • 上调至纳入观察的条件：龙德广场 REITs 成功发行获批，或单季扣非扭亏且租金空置率改善。
