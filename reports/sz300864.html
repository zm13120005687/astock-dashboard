第一步：公司是干什么的？

一句话定位：依托南京大学科研背景的"诊断—方案—实施—运营"全链条环保服务商，主营环境调查与鉴定、研究咨询与设计、装备研制与系统集成、能源环保协同与资源化四大板块。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：咨询服务转嫁系数高（毛利率 41–43% 稳）；装备业务转嫁系数中（毛利率 24%，受分包成本影响）。
  • 因子2 毛利结构再平衡：高毛利咨询（71% 收入、42% 毛利）为利润主体，装备（20%、24%）增速快但毛利低——结构向"低毛利装备"迁移，整体净利率承压。禁单一综合毛利率 37.86% 掩盖。
  • 因子3 库存与采购节奏：工程类按项目确认，无显著库存收益；现金流为负主因垫资+回款周期，非盈利质量假象但需警惕。
  • 因子4 政策/市场锚点：财政支出/环保预算（需求锚）、新能源/半导体扩产（装备需求锚）。情景：地方财政收紧→订单确认放缓（证伪：在手订单转化率低）；证伪：应收账款坏账计提跳升。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：①供给侧——江苏环保咨询头部；②需求侧——政府+工业客户粘性；③技术代际——南大科研领先；④成本曲线——咨询轻资产；⑤份额加速度——省内饱和、省外加速初期。三档：保守守住/中性小幅提升（省外突破）/乐观抢全国份额。
  • 层2 扩展业务（主业迁移）：从"咨询"迁移至"智能装备+资源化"——能力可迁移（技术同源）、新 TAM（新能源/半导体废气）弹性中、卡位早、认证中、信号验证（装备 +37%）。已部分兑现，计入但毛利较低。
  • 层3 证伪信号：在手订单转化率<80%、省外拓展停滞、应收账款坏账跳升、装备毛利破 20%。

第四步：估值锚定（自下而上，非增速外推）

方法：以在手订单节奏为锚，分业务（咨询/装备/资源化）自下而上，三情景取中性。严禁增速外推（增长靠订单而非历史 CAGR）。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非重资产、PB 3.09>1（不破净）、负债率约 30%，无资产虚高，无需破净折扣（高 PB 反映的是轻资产高 ROE 溢价，非真破净）。
  • 校正2 周期位置校正：非强周期股，中性净利用在手订单节奏（非峰值年化），增长平稳而非周期波动。
  • 校正3 杠杆下行情景：负债率约 30% 偏低，无高负债下行压力；主要风险为现金流/应收账款，已体现在悲观情景（-38.1%）。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵。现价 25.60 ≈ 远期中性目标价 25.07 元，基准（2026E）仅 20.43 元，基准空间 −20.1%。

安全边际：
- 中性远期 25.07 元 → 空间 −2.1%（基本持平，无上行）
- 悲观 15.84 元 → 下行 −38.1%
- 乐观 33.25 元 → +29.8%（需省外突破）
- 下行保护：PB 3.09x（偏高）、经营现金流为负、应收高，安全边际薄

介入条件：
1. 不追高。等回落至 ≤ 22.0 元（对应 2026E PE < 18x、2029E 中性 < 17x）
2. 上调至重点关注需：① 省外收入占比突破 25%；② 经营现金流转正；③ 装备业务毛利率守 25%+且收入占比>25%
3. 观察指标：在手订单转化率、应收账款周转、季度扣非增速

最大风险：
1. 增长平缓+估值偏贵（首要）：订单驱动但增速低，PB 3.09x 已贵
2. 现金流/应收账款：经营现金流 −0.63 亿、应收超 3.4 亿，回款风险
3. 区域集中：江苏占 83.67%，省外拓展不及预期则天花板明显
4. 传统业务萎缩：咨询/调查收入已小幅下滑，竞争加剧

结论：暂不介入（估值偏贵、增长平缓、现金流承压，待 ≤22 元且验证点出现）

南大环境是稀缺的全链条环保服务商，11.85 亿在手订单提供收入可见度，但增长平缓（2029 中性仅 +23% 净利）、PB 3.09x 偏贵、经营现金流持续为负。当前价格已无安全边际，仅适合在 ≤22 元（2026E PE<18x）且现金流改善信号出现后布局。

第五步进阶：上行想象力情景（四类，对称于下行校正）

  • 类型A 行业调整剩者红利：环保咨询与治理行业小散出清、集中度提升，南大凭"南大科研背景+全链条"差异化占优，剩者份额与项目获取力跳升。验证点：行业集中度数据、中标份额；证伪：份额连降。

  • 类型B 政策反转期权：美丽中国"十五五"规划加码、无废城市/新污染物治理专项落地，订单边界外扩。属机会情景，不计入中性。验证点：专项规划发文、地方项目招标放量；证伪：地方财政收紧致订单确认放缓。

  • 类型C 市场错杀修复：高 PB（3.09x）但稳态盈利，若经营现金流转正 + 省外突破，市场从"现金流折价"重估。验证点：经营现金流转正、估值分位回升；证伪：应收坏账计提跳升证明非错杀。

  • 类型D 技术突破/代际跃迁期权：AI+环保智能装备、半导体/新能源高浓度有机废气治理装备从 0 到 1 放量（H1 装备 +37.17% 已初步验证，毛利率 24.12%）。硬验证点：装备毛利率守 25%+、收入占比 >25%、新客户（半导体/新能源）定点。已部分兑现可计入乐观。

上调至重点关注的条件：① 省外收入占比突破 25%；② 经营现金流净额转正；③ 装备业务毛利率守 25%+ 且收入占比 >25%。三者齐备方可上调。
