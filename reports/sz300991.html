第一步：公司是干什么的？

一句话定位：深圳民营精密互连产品制造商，给 5G 通信、AI 服务器、新能源汽车、数据存储、消费电子做精密连接器、连接线、精密结构件，处于电子元器件"小而专"赛道。

（3）产业链传导

上游：铜 / 合金、塑胶、电镀材料。原材料成本占比高，价格随大宗波动；公司规模小，对上游议价权中等偏弱，部分可向下游传导。

下游：AI 服务器 / 数据中心（强需求、高议价方）、新能源汽车（强）、消费电子（弱、买方强势）。下游分化：AI 端需求强但认证壁垒高、客户集中；消费端需求弱且压价。

议价权：中等偏弱。中小连接器厂，对头部客户依赖度高，无强定价权；唯一优势是 112G 高速产品的先发技术积累。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：铜价上涨时传导率约 0.5–0.7（部分转嫁、部分自扛），因客户集中且竞争充分；新能源连接器（毛利仅 7.9%）传导能力最弱，接近自扛。
  • 因子2 毛利结构再平衡：五大产品线毛利率从 7.9%（新能源）到 33%（数据存储）跨度极大。2026H1 高毛的数据存储占比下滑、低毛的新能源/消费电子占比上升，加权毛利率结构性下移至 18.63%——是典型的"结构再平衡"拖累，非单一线问题。
  • 因子3 库存与采购节奏（timing）：铜价低位时囤货可获库存收益，反之接货损失；公司无披露大比例套保，timing 影响当期毛利但不改变趋势。
  • 因子4 政策 / 市场锚点：铜价（市场层）、关税（出口料 / 成品，政策层）、AI 算力投资强度（市场层驱动高速连接器需求）。情景：铜价上行→毛利承压；AI 投资持续→高速连接器放量对冲。验证点：LME 铜价、AI 服务器出货量、公司高速产品营收占比。证伪：铜价暴涨且无法转嫁、AI 订单未落地。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：连接器行业头部集中，公司份额小（TTM 营收 6.65 亿 vs 行业巨头数百亿），扩产节奏取决于定增。
  • 需求侧：前五大客户集中，晟碟案例显示单客户变动可令出货 −50%，粘性高但风险大。
  • 技术代际：112G 量产、224G 在研，处于国内第二梯队，领先部分友商。
  • 成本曲线：规模小，成本曲线偏右，降价时被动。
  • 份额加速度：AI 高速连接器若获定点，份额可加速；否则在传统红海流失。
  • 三档：保守（份额守 6.5 亿营收）/ 中性（7.5 亿）/ 乐观（定增满产 10 亿）。验证点：季度新签订单、高速产品营收占比。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：从消费 / 存储连接器迁移至 AI 高速连接器——技术同源（精密互连）、新 TAM 大数倍（AI 算力）、切入时点早（112G 量产），但客户认证门槛高（既是护城河也是阻力），未获大客户定点前仅作中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：定增终止 / 发行失败、AI 订单无正式定点公告、传统业务继续下滑 → 下调 / 剔除增量。

第四步：估值锚定（自下而上，非增速外推）

亏损股方法：采用正常化净利润法（估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价）。严禁历史增速外推。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（破净原因）：PB=7.15（远高于 1），非破净；但轻制造资产以设备 + 应收为主，高 PB 反映的是"AI 期权溢价"而非资产质量，一旦期权证伪将剧烈回归。
  • 校正2 周期位置校正：连接器行业处结构性分化周期（AI 上行、消费下行），中性净利已按"传统企稳 + 新业务部分释放"保守测算，未外推 AI 高景气。
  • 校正3 杠杆下行情景：定增前资产负债率可控、经营现金流为正（+4791 万），但定增含"补流还债"说明存在资金压力；若定增失败且传统业务继续恶化，净利可转更大负，悲观情景 3.4 元已覆盖。
  • 期权纪律：6 亿定增高速 / 新能源产能、224G 客户定点均未过验证点，不计入中性 NAV，仅放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：严重高估（期权溢价）。现价 31.41 元对应 77 倍中性正常化 PE、7.15 倍 PB，已把"定增成功 + AI 高速连接器放量"的最乐观剧本提前定价。

安全边际：中性远期 10.9 元 → 空间 −65.3%；乐观 22.2 元仍 −29.3%。下行保护弱，仅有净资产 6.48 亿（PB 底线约 4.5 元/股）作锚。

介入条件：
1. 现价不介入。
2. 重新考虑的价格：回落至 20 元以下（对应市值 ~29 亿，接近乐观情景），且需同步出现：① 定增成功发行；② 高速数据通讯产品营收占比跃升至 10%+；③ 单季归母转正。
3. 上调至"纳入观察"条件：定增落地 + AI 高速连接器获主流客户定点公告。

最大风险（最可能破坏逻辑的因素）：
1. 定增失败 / 进度不及预期（已受理未发行，6 亿资金不到位则扩产落空）；
2. AI 高速连接器客户定点落空——这是估值核心支柱，无正式定点则中性锚失效；
3. 传统业务继续恶化（消费 / 存储客户流失，如晟碟案例重演）；
4. 罗马仕类坏账（应收账款减值，2025 已计提 2026 万）。

结论：暂不介入

公司有真实的 AI 高速连接器 + 新能源增长期权（非"确无扭亏可能"），但现价已透支最乐观预期，中性锚较现价低 65%。遵循"估值已高 / 空间有限 / 不确定性大 → 暂不介入"。等待定增落地与业绩验证、价格回归后再评估。

第五步进阶：上行想象力情景（四类，仅进机会栏，不进中性锚）

  • 类型A 行业出清剩者红利：连接器中小厂出清，公司凭 112G 技术卡位份额提升。验证点：份额数据、新签订单；证伪：份额流失。
  • 类型B 政策反转期权：AI 算力补贴 / 设备更新加码推动高速连接器需求超预期。验证点：AI 服务器出货量、政策发文；证伪：AI 投资退潮。
  • 类型C 市场错杀修复：若因风格切换跌至 PB≈2（~13 元）且基本面未恶化，估值分位极低。验证点：价格回落 + 基本面企稳；证伪：基本面恶化。
  • 类型D 技术突破 / 代际跃迁：224G 高速连接器从 0 到 1 获主流 AI 服务器客户定点量产，重构增长曲线。硬验证点：中试良率达标 + 客户定点 + 量产成本优于旧路线；证伪：良率不达标 / 客户流失。

    上调至"重点关注"的条件：B/D 中"定增成功发行 + 224G 获主流客户定点 + 单季归母持续转正"三项验证，且价格仍在 20 元以下——届时正常化净利与估值重估，空间可显著转正。
