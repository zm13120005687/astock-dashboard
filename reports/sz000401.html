金隅冀东（000401）五步法分析报告

分析日期：2026-09-25 ｜ 现价 3.55 元（2026-09-24 收盘）｜ 总市值 94.29 亿 ｜ PE(TTM) −16.12x ｜ PB 0.36x ｜ 总股本 约 26.56 亿股
行业：水泥 / 建材（强周期）｜ 板块：深市主板
亏损股处理：2026H1 归母 −9.57 亿（确亏，TTM 标记无误标）→ 走完整五步法 + 正常化净利润法 + 三问 + 第四进阶三道闸
结论等级：纳入观察（远期中性空间 +27.3%，>0 但 <50%）

第一步：公司是干什么的？

一句话定位：华北/东北水泥龙头（金隅集团与冀东水泥整合体），主营水泥熟料、各类硅酸盐水泥及砂石骨料、环保、矿粉、外加剂、新材料，是"反内卷"错峰生产受益的区域整合者。

核心产品：硅酸盐水泥（P.O42.5 等）、熟料、商品混凝土、骨料、水泥窑协同处置（危废/污泥）。

主要客户/下游：基建（交通/水利/城市基建）、房地产（商住）、农村市场、重点工程项目。东北区域整合后区域定价权提升。

境内外收入占比（2026H1）：国内为主（水泥短腿属性，运输半径限制）；海外出口增长（2026H1 全国水泥出口 +53.7%、熟料 +534.8%，公司受益有限但趋势向好）。

股东背景：金隅集团（北京市属国资）为控股股东，央企/地方国企背景，融资与资源整合能力强。

（3）产业链传导

上游：煤炭、电力（燃料成本占水泥成本 50%+）。煤价下行利好成本，但售价降幅更大致亏损。

下游：基建（政策托底）+ 地产（仍弱）。需求端决定价格弹性。

议价权：区域整合后中等偏强（东北/华北协同提价），但全国产能过剩削弱整体定价权。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：水泥售价由区域协同决定（传导率≈0 对成本，毛利被煤价与售价双向夹击）；Q2 毛利率回升源于"稳价 + 降本"而非成本转嫁。验证点：区域水泥均价；证伪：价格战重启毛利率破 10%。
  • 因子2 毛利结构再平衡：水泥熟料（低毛利、量大）为主，骨料/环保（高毛利）占比小。结构升级（"水泥+骨料+砂浆+商混"生态链，如重庆江津项目）可抬升综合毛利，但短期占比低。
  • 因子3 库存与采购节奏：低价煤炭库存收益 vs 高价接货损失；错峰生产降低库存压力。H1 毛利率环比 Q2 +14.72pct 含季节与复产因素。
  • 因子4 政策/市场锚点：煤价（市场层）、错峰/反内卷（政策层）。情景：煤价下行 + 错峰严格执行 → 毛利修复；需求再降 → 破净加深。验证点：煤价、全国水泥均价、错峰执行率。

输出喂第四步毛利率假设：正常化净利率取保守 5.5%（周期中位）。

第三步进阶：份额变量与主业迁移空间

  • 层1 份额变量：东北区域整合 → 区域份额提升（供给侧锚点）；错峰协同 → 定价权。保守守住 / 中性小幅提升 / 乐观抢份额。验证点：区域水泥均价、公司销量份额。
  • 层2 主业迁移：向"综合建材服务商"（骨料/商混/环保）迁移，新 TAM 弹性有限，属存量延伸，非中观期权。未过大额验证点不计入中性。
  • 层3 证伪信号：价格战重启、错峰执行不力、区域需求再降 → 下调。

第四步：估值锚定（正常化净利润法 + 三道闸）

亏损股方法：估稳态营收 → 保守正常化净利率 → × 远期合理 PE → 目标市值 → 目标价。

总股本：约 26.56 亿股；净资产约 261.9 亿（市值/PB），每股净资产 9.86 元。

第四进阶·三道闸

校正1 资产质量折扣（破净原因）：PB 0.36 破净，原因 = 周期底部 ROE 为负 + 资产专用性强（熟料线/水泥窑不能转产，清算价值 << 账面） → 破净是公允定价，非真安全边际。非金融资产未重估型（无大量持股上市公司），故不可单凭 PB<1 推大空间。→ 估值以盈利面（正常化净利）为主，PB 仅作基准参考。

校正2 周期位置校正：当前处于周期底部（需求下行、价格探底），中性净利用周期归一化（多年 trough-to-peak 中值），禁单年好年景/拐点年化。中性稳态：营收 220 亿（正常年景未满产）× 正常化净利率 5.5% = 12.1 亿（非 peak 28 亿，非 2026 亏损）。

校正3 杠杆下行情景：资产负债率约 60%（高负债）。利率上行 / 需求再降 → 净利可转负，空间转负 → 不得标大空间。悲观情景已体现。

亏损股三问

  1. 为什么亏：行业需求持续下降（量价齐跌），水泥&熟料售价同比降、销量同比减；成本费用降幅难覆盖售价降幅。属周期底部主业亏损（非一次性减值为主，H1 毛利率 14.4% 仍正但费用率高）。Q1 亏 9.94 亿为全年主体。
  2. 靠什么扭亏·触发时点：① 反内卷 + 错峰常态化稳价提价（2026H2"前低后高"）；② 东北区域整合提升集中度与定价权；③ 降本增效（成本&费用双降已见效，Q2 单季已 +3698 万）。触发：2026H2 环比改善，2027 全年有望扭亏。
  3. 亏得起吗：Q2 经营现金流 +3.25 亿（H1 转正），成本费用的现金管控有效；背靠金隅集团（北京市属国资）融资能力强；资产负债率 ~60% 可控。能撑到扭亏。

第五步：综合赔率判断（买不买？）

当前价格位置：破净 PB 0.36，但破净为周期底部公允定价（资产专用性），非错杀安全边际。现价处历史低位。

安全边际：
- 中性远期 4.52 元 → +27.3%（>0，<50%）
- 悲观 1.36 元 → −61.7%（杠杆 + 周期下行）
- 乐观 9.04 元 → +154.6%（反内卷成功）
- PB 0.36x 提供一定资产面缓冲，但清算价值低

介入条件：
1. 现价已反映较悲观预期，但需确认 2026H2 减亏趋势 → 待 Q3 扭亏信号
2. 加仓：区域水泥均价持续回升 + 单季净利连续转正
3. 止损：错峰失效、价格战重启

最大风险：
1. 地产/基建需求再降，价格破底（首要）
2. 高负债（60%）利率上行 → 财务承压
3. 资产专用性致破净非安全边际

结论：纳入观察（远期中性 +27.3%，逻辑为周期底 + 政策反转期权，但高杠杆下行风险大）
