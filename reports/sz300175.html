（3）产业链传导

上游：葡萄干（新疆产地直采）、松子（东北产地直采）、鲜果，原料成本占营业成本 96.02%（H1 原材料 1.62 亿，同比 +88.10%）。农产品价格与运费波动是直接成本驱动。

下游：出口欧美 / 中东 / 东南亚大宗订单 + 国内烘焙 B 端代工 + C 端新零售。下游品牌客户强势，短期提价传导难。

议价权：弱。毛利率低（2–6%）且 H1 毛利率同比再降 9.31pct，佐证对上游原料涨价与下游压价两头承压；唯一缓冲是产地直采锁源 + 政府运费 / 退稅补贴。

第二步进阶：原料成本→毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：量化转嫁系数 ≈ 0.1–0.2。原料涨 88% 时综合毛利率由 11.7% 降至 2.39%，即约 80% 成本压力由公司自扛（传导率≈0.2）。依据：H1 毛利率 −9.31pct 而同期无成功提价公告；出口长协占比高、调价滞后。验证点：后续季度毛利率能否回升至 5% 以上（产地锁源 + 提价见效）。证伪：毛利率持续 <3% 则成本端失控。
  • 因子2 毛利结构再平衡：分业务线毛利率——果干 1.99%（基本盘但薄）、坚果果仁 −1.87%（放量但亏损，规模未起）、鲜果 6.34%（最高但占比小）。原料敏感权重：果干 / 坚果对葡萄干、松子价格敏感，鲜果对海运 + 产地价敏感。当前结构"低毛利果干为主 + 亏损坚果为辅"，加权净利为负；若高毛利的鲜果精品出口 + C 端大包装占比提升，结构才改善。禁单一综合毛利率。
  • 因子3 库存与采购节奏（timing）：H1 存货 1.21 亿（较期初 −33.9%），果干 / 果仁去化；鲜果库存 +556.77%（生产 > 销售节奏）。无显著低价囤货收益，反而鲜果库存沉淀占用资金。长协 / 套保：未披露套保，依赖产地直采锁源，非金融对冲。
  • 因子4 政策 / 市场锚点：①市场层——土耳其葡萄干产量与海运运费；②政策层——龙口出口退稅提速（降成本）、冷链运费补贴（对冲海运涨）、技改补贴（降资本开支）。情景：退稅 / 补贴足额到账→成本降 1–2pct；海运继续涨→鲜果毛利再承压。验证点：退稅到账节奏、运费补贴申报额。证伪：补贴退坡或原料继续大涨。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：6 万吨冷库 + 龙口厂区产能，属区域中型，扩产靠技改非新建；
  • 需求侧：前五大客户占 41.54%，BRUEGGEN 等境外客户粘性强；内销头部品牌认证周期 = 粘性；
  • 技术代际：农产品加工技术同质，无代际差；
  • 成本曲线：产地直采 + 补贴使其略优，但规模小难言左移；
  • 份额加速度：坚果果仁销量 +123.97% 处渗透早期。
    → 保守守住（维持现有出口份额）/ 中性小幅提升（内销代工落地）/ 乐观抢份额（3–5 家大单 + C 端放量）。验证点：下季度内销收入占比、坚果果仁毛利率转正。
  • 层2 扩展业务：主业迁移空间：从 OEM 出口向"三位一体（加工 + 供应链配送 + 终端零售）"迁移，能力可迁移（渠道复用），新 TAM = 国内烘焙 B 端 + C 端零食；切入卡位早期；认证门槛 = 头部品牌供应商认证；信号验证 = 新增代工大单公告、C 端营收占比跳升。未过验证点仅作中期期权。
  • 层3 证伪信号：内销大单无正式公告、坚果果仁毛利率连续为负、鲜果库存持续高企占用现金。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非破净（PB 5.26），但 PB 高源于壳溢价而非资产盈利（ROE −2.71%）。净资产 4.90 亿多数为冷库、厂房、存货，专用性中等，清算价值低于账面。禁单凭 PB 推空间。
  • 校正2 周期位置校正：农副产品加工非强周期，用正常化净利率（行业保守值）替代单年亏损，已标注当前处于"减亏未扭亏"阶段。
  • 校正3 杠杆下行情景：负债合计仅 4738 万、无短期借款，杠杆风险极低；但累计未分配利润 −1.38 亿，持续经营依赖内销放量兑现。下行情景（内销失败）空间转负，不得标大空间。
  • 期权纪律：IDC 轻资产盘活、重组注入预期未过验证点，不计入中性 NAV。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估（主业视角）。现价 5.46 元隐含市值 25.7 亿，而主业正常化价值仅约 5 亿，溢价来自壳 / 摘帽 / IDC 期权。

安全边际：中性远期 1.06 元 → 空间 −80.6%；乐观 2.12 元仍 −61.2%；下行无业绩支撑，纯靠壳溢价博弈。

介入条件：① 内销代工大单正式公告且金额 ≥ 1 亿；② 坚果果仁毛利率转正、综合毛利率回升至 5% 以上；③ IDC 存量资产盘活产生实质利润。三者兑现任二者才考虑，且价格回落至 3 元以下（PB 回到 3x 内）。

最大风险：① 主业毛利率长期低位、内销放量不及预期；② 农产品原料 / 海运涨价吞噬利润；③ 壳溢价退潮（创业板小市值审美变化）；④ 历史虚增营收处罚带来的治理瑕疵余波。

三问（亏损股必答）：
1. 为什么亏：农副产品加工毛利率仅 2–6%，原料成本占 96% 且 H1 涨 88%，叠加汇兑损失（财务费用 +654%）+ 规模不经济；剥离 IDC 后聚焦主业但结构仍弱。
2. 靠什么扭亏、触发时点：内销 B 端代工大单 + C 端新零售放量 + 产地直采锁源降成本 + 政府补贴 + 财务费压降；触发时点 2026H2–2027 年逐步减亏、争取扭亏。
3. 亏得起吗：账面现金 8358 万 + H1 经营现金流 6461 万，负债仅 4738 万、无短借，财务底盘稳健，亏得起；但累计未分配利润 −1.38 亿，需内销兑现否则长期消耗现金。

结论：暂不介入（主业正常化价值远低于现价，当前为壳 / 摘帽期权定价；待内销大单与扭亏信号验证后再评估）。
