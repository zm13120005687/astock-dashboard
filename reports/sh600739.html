第一步：公司是干什么的？

一句话定位：一家被广发证券权益法投资收益"喂养"的多元控股平台——业务名义上横跨医药医疗、金融投资、供应链贸易、能源开发，但利润的绝对大头来自持有广发证券约 17.5% 股权带来的投资收益；主业（疫苗 + 大宗贸易）合计贡献仅约 0.4 亿元。

主要客户 / 下游：券商客户与资本市场（广发）、疾控中心与接种机构（疫苗）、钢铁/粮食/纺织品的上下游贸易商（贸易）。

境内外收入占比：以境内为主；成大生物疫苗"产品远销三十多个国家和地区"，全面推进疫苗出海（占比未单独披露，属结构性增量）。

股东结构（关键风险点）：前十大股东为韶关市高腾（16.28%）、辽宁省国有资产经营（11.16%）、广西鑫益信（8.56%）、吉林敖东（6.78%）、张跃军（1.27%）等——股权高度分散、无控股股东与实际控制人，这是长期估值折价的重要来源之一。

一句话风险画像：公司是"一篮子金融与医药股权 + 一条薄利贸易业务 + 一个停产能源包袱"，利润几乎完全由广发证券一家的市场行情决定；有息负债 158.61 亿元、财务费用连续三年超 3 亿元（2026H1 为 3.13 亿元），是压在收益上的刚性成本。

（3）产业链传导

上游（成本端）：公司是控股平台，没有统一"原料"，成本由四条曲线构成——① 资金成本（有息负债 158.61 亿、财务费用 6.26 亿/年，是最大的刚性成本）；② 疫苗生产成本（培养基、佐剂、能耗、研发投入）；③ 贸易采购成本（钢铁/粮食/纺织品进价）；④ 券商人力和 IT 成本（间接影响广发净利，进而影响权益法）。

下游（收入端）：① 资本市场行情（决定广发收入与权益法收益，是最敏感变量）；② 疾控与接种需求（疫苗，刚需且量在企稳）；③ 大宗商品下游（钢铁建材需求疲弱、粮食与纺织品出口承压）；④ 保险承保与投资（中华保险）。

议价权判断：券商业务强（牌照 + 头部地位）；疫苗业务强（全球狂犬疫苗龙头、批签发壁垒）；贸易业务弱（代理型、毛利率极低、上下游均强势）；保险业务中。整体议价权中偏强，但利润的 117% 依赖参股券商，属"外部行情决定型"而非"内生议价型"。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子 1 · 成本传导弹性（把议价权量化成转嫁系数）
  • 贸易端（占收入 84%）：代理型大宗贸易，采购成本几乎全额随行就市转嫁，但毛利率天然极薄（1%–2%） → 转嫁系数 ≈ 0.9，但"高转嫁 ≠ 高毛利"，成本上行时利润绝对额被进一步压缩（H1 净利 −48.97% 即为佐证）。
  • 疫苗端（占收入 15%）：招标/集采定价 + 增值税政策调整 → 转嫁系数 ≈ 0.3–0.4，政策一变毛利立刻受损（H1 净利 −72.79%）。这是全公司唯一"成本/政策敏感、且价格无法自主"的实体业务。
  • 券商端：无原料概念，收入直接随市场交易活跃度与自营/投行景气波动 → "转嫁系数"概念不适用，改用"市场敏感度 ≈ 1.0"。

  • 资金端：有息负债 158.61 亿、财务费用 3.13 亿/半年且连续三年超 3 亿元 → 利率敏感度高，降息直接增厚净利。

  • 因子 2 · 毛利结构再平衡（分业务线，禁用单一综合毛利率）

业务线 收入权重 毛利率特征 对关键变量的敏感权重
大宗贸易 84.0% 极低（1%–3%） 商品价差 0.9；汇率/运费 0.4
生物医药（成大生物） 15.3% 高（疫苗毛利率通常 80% 上下） 增值税政策 0.8；批签发量 0.7；研发费用 0.5
金融投资（权益法） 0（走投资收益） 不适用毛利率 资本市场行情 1.0；利率 0.3

→ 公司综合毛利率 15.04%（2026H1）严重失真：84% 的收入来自毛利仅 1%–3% 的贸易，把高毛利的疫苗业务完全淹没。"收入结构"与"利润结构"严重错配——这是本股最容易被误读的地方：看收入会以为它是一家贸易公司，看利润才知道它是一家券商影子股。
→ 结构迁移方向：贸易收入占比若从 84% 降至 70%（主动收缩低效业务），疫苗与创新药占比升至 25%，则综合毛利率可从 15% 抬升至 25% 以上，利润结构不受影响（因为利润本就来自权益法），但"报表观感"会显著改善。

  • 因子 3 · 库存与采购节奏（timing）
  • 贸易存货的价格节奏：钢铁、粮食属价格波动品种，低价囤货时贸易毛利虚高、高价接货时亏损——H1 贸易净利 −48.97% 部分即为价格节奏不利所致。须与远期可比性切割。
  • 疫苗的"研发资产化"节奏：开发支出 6.22 亿 → 0、转入无形资产 8.21 亿（+336.31%）——这是会计口径切换（费用资本化转摊销），未来将新增无形资产摊销，压低成大生物账面利润，须在预测中考虑折旧摊销增量。
  • 权益法收益的"行情 timing"：2026H1 广发净利 116.52 亿（+80%）属高景气年景，权益法收益 19.41 亿不可外推为常态（2025H1 仅 10.76 亿）。

  • → 结论：本股不存在库存收益被当真实盈利的问题，但存在"高景气年份权益法收益被当年化"的巨大风险。

  • 因子 4 · 政策/市场锚点（驱动变量，市场层 + 政策层）

  • 市场层：A 股成交额与两融余额（决定广发业绩）、券商板块估值（决定资产重估空间）、大宗商品价格与运费、疫苗批签发量与中标价。
  • 政策层：① "活跃资本市场"政策组合 + 并购六条（→ 广发业绩与估值双升，是最强正向变量）；② 疫苗增值税政策调整（→ 直接压低成大生物利润，已发生）；③ 《全链条支持创新药发展实施方案》（→ 成大生物创新药第二曲线）；④ 大宗商品关税/出口管制（→ 贸易板块波动）；⑤ 利率（→ 财务费用）。
  • 情景：乐观=资本市场高景气延续 + 券商估值修复 → 权益法收益与资产重估双击；中性=市场回归常态，广发净利回落至 150–180 亿，权益法收益约 26–31 亿；悲观=市场下行，广发净利降至 80–100 亿，权益法收益 14–17 亿，同时财务费用刚性。
  • 验证点：广发证券季度净利与股价、A 股日均成交额、成大生物批签发量与新品放量、公司有息负债规模变化。
  • 证伪信号：广发连续两个季度净利同比负增长；成大生物新品上市一年内未转化为收入；疫苗增值税负面影响延续超两年；有息负债不降反升。

四因子小结：公司的"毛利结构"是一个双漏斗——收入漏斗是贸易（84% 收入、1% 毛利），利润漏斗是券商（117% 利润、0 收入）。任何只看综合毛利率或只看营收的判断都会失真。估值必须用"分部资产重估 + 权益法收益正常化"双轨法。

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

校正 1 · 资产质量折扣（破净原因必须说明 + 真破净举证）
- 为什么破净（PB 0.55x）：
1. 资产变现能力受限——所持广发证券股权中，2.05 亿股已划转至可交换债（EB）担保与信托专户（25 成大 E1/E2），大量股份已用于融资质押；作为广发重要股东，减持受监管与市场约束，账面价值难以快速变现；
2. 有息负债高达 158.61 亿元（vs 货币资金 + 交易性金融资产 83.96 亿，净负债约 74.7 亿），财务费用连续三年超 3 亿元/半年，刚性侵蚀；
3. 无实际控制人（第一大股东仅 16.28%），治理折价与战略不确定性；
4. 能源包袱（新疆宝明长期停产）与主业薄利（贸易净利率不足 0.3%）。
- 是否属"未重估型真破净"：是。举证（RULES 要求列持股数量 × 市价 vs 总市值）：广发证券 13.67 亿股 × 21.72 元 ≈ 290 亿元 + 成大生物 2.28 亿股 × 20.33 元 ≈ 46 亿元 = 约 336 亿元，为总市值 164.11 亿元的 2.05 倍；账面净资产中广发按权益法计价（约 241 亿元）低于市价对应份额（约 290 亿元）约 49 亿元。
- 结论：破净主要不是资产盈利能力问题，而是变现能力与治理折价问题。因此可以保留"安全边际"的判断，但不得把 SOTP 的 285–300 亿 NAV 直接当作目标市值（那等于假设折价完全消失）。
- 验证点：有息负债能否逐年下降；广发股权质押/EB 规模变化；是否出现控制权变动或战略投资者引入。证伪信号：有息负债继续上升、广发股权被进一步质押/减持。

校正 2 · 周期位置校正
- 本股是典型的强周期 + 高 Beta：利润的 117% 来自券商权益法收益，本质是对资本市场行情的杠杆化暴露。
- 当前周期位置：券商行业处于景气上行段（2026H1 广发归母 116.52 亿，+80%；板块 ROE 回升），但上行已进行了一段时间，不能假设持续。
- 中性净利必须周期归一化：本报告未使用 2026H1 年化的 32.4 亿（属单年好年景），未使用近三年均值，未使用拐点年化；而是按广发年均归母 150–180 亿的中枢水平反推权益法收益 26–31 亿，再扣费用与税，得中性 26 亿。
- 证伪信号：若广发连续两个季度净利同比负增长，则需下调中性净利至 20 亿以下。

校正 3 · 杠杆下行情景（必附负面情景）
- 资产负债率约 34.5%–41.6%（口径差异源于是否计入全部负债），未达 >60% 的高杠杆阈值；但有息负债 158.61 亿、净负债 74.7 亿、财务费用 6.26 亿/年相对其主业盈利（贸易 + 疫苗合计仅约 0.5 亿）而言属重杠杆。
- 负面情景：若资本市场转熊，广发年均净利降至 80–100 亿 → 权益法收益 14–17 亿；同时成大生物新品不达预期 → 2029E 归母降至 14 亿，按 8x = 112 亿 → 7.36 元（−31.7%）。
- 纪律：该负面情景使悲观情景空间转负（−31.7%），因此本报告不标注"重点关注"，最终结论为"纳入观察"并明确标注高贝塔属性（利润随资本市场行情几倍波动）。

期权纪律：成大生物创新药双平台（上海成大致远 10 亿 + 生物医药产业基金 5.02 亿）、广发证券估值修复至 PB 1.5x、控制权变动/战略投资者引入——三者均未过正式验证点（无临床数据读出、无 BD 授权公告、无控制权变动公告），一律不计入 2029E 中性净利 26 亿，仅置于乐观情景（+143.8%）或单独列示。

第五步：综合赔率判断（买不买？）

当前价格位置：明显低估，但折价有现实理由。现价 10.78 元对应 PB 0.55x、2026E PE 约 6.5x；仅广发 + 成大生物持股市值（约 336 亿）就是自身市值的 2.05 倍。便宜是真实的，但便宜的原因（变现受限、有息负债、无实控人、高 Beta）同样真实，且这些折价因子未必会收敛。

安全边际：
- 中性远期 15.37 元 → 空间 +42.6%，未达"重点关注"的 >50% 门槛；
- 悲观情景 7.36 元 → 下行 −31.7%，风险收益比约 1.34 : 1，略有优势但远非卓越；
- 下行保护：PB 0.55x、账面归母净资产约 299 亿（每股 19.64 元）、成大生物新股获批带来的基本面改善、经营现金流已转正（+0.688 亿）。但须注意：账面净资产的"变现价值"受制于有息负债与股权质押，不能按面值信任。

介入条件：
1. 价格：回落至 9.2 元以下（PB < 0.47x、2026E PE < 5.6x）才具备明确安全边际；现价可观察，不追高。
2. 加仓信号：① 有息负债规模连续两个季度下降（最关键，直接决定折价能否收敛）；② 广发证券季度净利同比继续正增长；③ 成大生物新品销售收入环比放量；④ 出现控制权变动/战略投资者引入公告。
3. 观察指标：广发证券季度净利与股价、A 股日均成交额、成大生物批签发量、公司有息负债与财务费用。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 资本市场转向（首要）：利润的 117% 来自广发权益法收益，熊市下收益腰斩 + 广发股价下跌将双杀（盈利与资产重估同时恶化），悲观情景空间 −31.7%；
2. 有息负债刚性：158.61 亿有息负债、6.26 亿/年财务费用，而主业（贸易 + 疫苗）合计仅约 0.5 亿利润——杠杆成本几乎必然要由权益法收益来覆盖；
3. 无实际控制人：股权高度分散（第一大股东 16.28%），治理与战略执行存在不确定性，资产变现与重估缺乏推动者；
4. 资产变现受限：广发股份已有 2.05 亿股划转至 EB 担保与信托专户，减持受监管与市场约束；
5. 成大生物利润塌陷：2026H1 净利 −72.79%，增值税政策调整与成本费用上升尚未消化，新品放量节奏存在不确定；
6. 能源包袱：新疆宝明长期停产，处置进展长期无实质推进。

第五步进阶：上行想象力情景（四类，与下行校正对称）

类型 A · 行业调整剩者红利
- 建模：券商行业正处于供给侧整合（并购六条支持头部券商做优做强、行业并购案例增多），中小券商被整合、头部集中度提升。广发证券作为行业头部，在财富管理、交易及机构、投资管理、投资银行四大业务线上均居前列，若行业 CR5 提升，广发的份额与定价权将同步提升，辽宁成大作为其重要股东直接受益于权益法收益与股权价值双升。同时，疫苗行业在批签发趋严、集中度提升下，成大生物作为全球狂犬疫苗龙头的"剩者红利"同样明确。

- 证伪信号：广发行业排名下滑、行业整合未惠及广发、成大生物份额被新进入者蚕食。

类型 C · 市场错杀修复
- 错杀证据：① PB 0.55x，处于历史极低分位；② 所持广发 + 成大生物市值（约 336 亿）为自身市值（164 亿）的 2.05 倍，即市场对"其余全部资产"给出负估值；③ 年初至今股价仅 −2.27%，相对行业并未错杀过度，但绝对折价巨大；④ 基本面未恶化（2026H1 归母 +125.77%、经营现金流转正）。
- 修复触发点：① 市场风格回归深度价值/破净资产；② 公司启动回购或提高分红；③ 有息负债显著下降；④ 披露分部资产公允价值。
- 证伪信号：广发连续两个季度净利负增长（则"错杀"证伪，属基本面恶化）。

类型 D · 技术突破/技术代际跃迁期权
- 建模：成大生物的冻干人用狂犬病疫苗（人二倍体细胞）属对传统 Vero 细胞路线的代际升级（免疫原性更好、不良反应更低），若在 3–5 年内替代存量 Vero 细胞市场，成大生物的量价结构将重构；叠加"简易 4 针法"（国内首家同时具备三种免疫程序）提升接种依从性，可能带来渗透率跃迁。此外，上海成大致远（10 亿元投资）若在创新药赛道取得管线突破，将打开全新增长曲线。
- 三要素共振检查：① 政策驱动（《全链条支持创新药发展实施方案》✓）；② 行业趋势（疫苗代际升级方向明确 ✓）；③ 公司落地（两个新品已获批上市、开发支出已完成资产化结转 ✓，但尚无销售收入放量数据、创新药子公司尚无管线读出）。
- 硬验证点：中试/量产良率达标 + 客户（接种机构/CDC）采购放量 + 量产成本优于旧路线（Vero 细胞）——目前仅"获批上市"一项达成，放量与成本优势尚未验证。
- 纪律：只作机会情景，不计入中性锚。证伪信号：新品上市一年内销售收入无环比放量、创Vero细胞路线成本持续占优、创新药子公司长期无管线公告。

什么条件出现才上调至"重点关注"：需同时满足——① 有息负债连续两个季度下降（折价收敛的必要条件）；② 广发证券季度净利同比持续正增长；③ 成大生物新品收入出现明确放量；④ 远期中性空间上修至 >50%（对应中性净利 ≥ 31 亿或 PE 上修至 10x）。四条中命中三条，方把结论由"纳入观察"上调为"重点关注"。

结论：纳入观察

理由：中性远期空间 +42.6%，不满足"重点关注"的 >50% 门槛；且高 Beta 属性使悲观情景空间转负（−31.7%），风险收益比仅约 1.34 : 1。
本股是全批 6 只中"账面最便宜"的一只——PB 0.55x，仅广发 + 成大生物持股市值（约 336 亿）就是自身市值（164 亿）的 2.05 倍，账面广发股权按权益法计价低于市价约 49 亿，属典型的未重估型真破净，安全边际真实存在。
但必须诚实面对三件事：① 利润的 117% 来自广发一家，本质是对资本市场行情的杠杆化暴露，熊市双杀；② 158.61 亿有息负债、6.26 亿/年财务费用，而主业合计仅约 0.5 亿利润，杠杆成本全靠权益法收益覆盖；③ 无实际控制人，股权高度分散，缺少推动资产重估与折价收敛的力量。
核心跟踪点：① 有息负债规模变化；② 广发证券季度净利与股价；③ 成大生物新品放量节奏；④ 是否出现控制权变动或战略投资者引入。
