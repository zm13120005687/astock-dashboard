第一步：公司是干什么的？

一句话定位：新奥集团（王玉锁）实控的西藏区域旅游龙头，垄断性经营林芝与阿里两大片区的稀缺高原景区资源，靠"门票 + 观光车 + 游船 + 香客接待"变现，是资源禀赋极强但盈利能力极弱的典型"守着金山要饭"型公司。

核心业务：旅游景区、旅游服务、旅游文创、香客接待（公司半年报自述四大核心业务）。

（3）产业链传导

上游（成本端）：旅游景区为轻资产运营（重资产已由募投项目承担），核心成本为：① 人工成本（景区运营、安全救援、香客接待专班，公司需建立"医疗点处置—救护车监护—医院接力救治"多级转运机制）；② 折旧摊销（索道、游船、观光车、塔尔钦小镇游客服务中心等固定资产）；③ 景区维护与安全巡查。无原材料成本，上游价格波动风险极低——这是公司与制造业最大的差异，也是"原料成本→毛利结构"四因子在本股上大幅钝化的原因。

下游（收入端）：需求为游客人次 × 客单价。2026H1 收入 +4.31% 而 Q2 单季 +7.74%，说明客流在恢复但速度温和；阿里西线因入境香客政策改善而爆发（+322%），东线林芝则承压——公司自述"东线市场承压的背景下，林芝雅鲁藏布大峡谷景区推'三年免费重游''峡谷秘境体验官''抖音挑战赛'等惠民举措和市场活动，构建体验托底能力，缓解团队游下滑"。"惠民举措"本身即意味着价格让利，是东线毛利率承压的直接原因。

议价权判断：中等。① 对游客端：景区资源垄断 + 门票价格受政府定价/指导约束（旺季可上浮空间有限），有垄断但无自由定价权；② 对上游供应商：景区建设与维护的议价权较强（国资/地方关系 + 规模采购）；③ 对渠道（旅行社/OTA）：偏弱——团队游下滑、散客占比上升，公司需靠"小包团与自驾渠道"拓展，渠道议价权转移至平台方。

第二步进阶：原料成本 → 毛利结构传导（四因子）

适配说明：旅游景区为轻资产、无原材料业务，本因子的传统形式大幅钝化。按 RULES 精神，以"运营成本/客流结构 → 毛利率结构"等效替换，仍逐条给出四因子结论，不省略。

因子 1 · 成本传导弹性（pass-through）
- 对上游成本：传导率 ≈ 1.0（近似完全无影响）。公司无原材料，人工与折旧为主要成本，不受煤价、油价、大宗商品波动影响，成本端极度稳定。
- 对下游价格：传导率 ≈ 0.1–0.2（几近无法转嫁）。门票与景区交通价格受政府指导，且东线客流承压背景下公司反向采取"三年免费重游"等让利措施——即价格不仅不能上浮，还需主动下调换取客流。
- 量化：2026H1 毛利率 27.92%（同比 −1.2pct）、Q2 单季毛利率 42.57%（同比 −4.07pct）——在完全无原料成本压力的前提下，毛利率仍在下滑，说明下滑纯由"让利换客流"驱动。这是本股盈利质量的核心信号。
→ 验证点：季度毛利率与客单价；证伪信号：若客单价与毛利率同时下滑，则"量价齐跌"，东线模式证伪。

因子 2 · 毛利结构再平衡（分业务线毛利率 + 成本敏感权重）

业务线 收入占比（估） 毛利率（估） 成本敏感权重 结构判断
阿里西线（神山圣湖 + 香客接待） 约 25% 50–60% 低 利润引擎，营收 +322%，高毛利、高成长
林芝东线（大峡谷、巴松措、苯日） 约 60% 25–35% 低 承压项，让利换量、毛利率下滑

关键结构迁移：利润重心正从林芝东线（约 60% 收入、毛利率下滑）向阿里西线（约 25% 收入、毛利率 50–60%、增速 +322%）迁移。这本应是极佳的结构改善——但阿里片区体量太小（收入占比约 25%）、基数太低，尚不足以抵消东线的毛利率下滑。单一"综合毛利率 27.92%"完全掩盖了"西线高毛利高增 + 东线低毛利承压"的分化格局。
→ 估值必须分部：阿里西线给成长溢价，林芝东线给保守稳态。

因子 3 · 库存与采购节奏（timing）
- 无存货与原料采购：旅游景区无原材料库存，不存在低价囤货收益或高价接货损失——本因子基本不适用。
- 唯一的 timing 变量是"募投项目投资节奏与折旧起算"：鲁朗花海牧场等项目长期延期（第四次延期至 2027 年 10 月），意味着折旧尚未起算、当期费用被推迟——这对当期利润是正向的 timing 红利（少提折旧），一旦项目达到可使用状态，折旧将集中开始计提，未来利润会承受额外压力。
- 政府补助/非经常性损益的 timing：2026H1 确认非经常性损益 468.54 万元（其中金融资产公允价值变动损益 233.92 万元、非流动资产处置损益 192.97 万元、所得税影响 −35.40 万元），使归母由扣非 −177.62 万元转为 +290.92 万元。这是典型的"一次性因素填补主业亏损"，绝不能当作真实盈利能力。
→ 验证点：季报"非经常性损益"明细、募投项目转入固定资产的时点公告；证伪信号：非经常性损益连续两期支撑归母为正、而扣非持续为负。

份额二阶导 景区经营权份额已饱和（核心景区已垄断）；增量只能来自"单位客流价值提升" 中性：客单价与二消（文创、香客接待）提升 客单价、二消占比

稳态净利润法（三步推导）

第一步：估稳态营收

|---|---|---|
| 林芝东线（大峡谷、巴松措、苯日） | 1.40 亿元 | 2025 年口径约 1.3–1.5 亿元，散客占比提升但团队游下滑，给持平偏增 |

| 合计 | 约 2.40 亿元 | |

产能/需求校验：稳态营收 2.40 亿元 = 2025 年 1.87 亿元的 1.28 倍，增量主要来自阿里西线（+0.5 亿元）与募投项目（+0.15 亿元）。客流量是否支撑？ 西藏景区客流受地理承载与季节约束，2.40 亿元对应约 30% 的营收增长，属偏乐观但不算激进的假设；需注意该数值已隐含募投项目 2027 年底按期建成的前提。

第二步：算稳态净利率（三种方法取保守值）
| 方法 | 数值 | 说明 |
|---|---|---|
| 行业正常净利率（景区类） | 15–25% | 成熟景区（黄山、峨眉山）净利率可达 20%+ |
| 公司历史最好年份净利率 | 2023 年约 6.8%（归母 1,450 万 / 营收 2.13 亿） | 公司历史上从未达到行业正常水平 |
| 规模化后的理论净利率 | 12–15% | 假设费用率摊薄、折旧起算 |
| 取保守值 | 约 14%（0.34 亿元稳态净利） | 介于公司历史最好与行业正常之间，但已明显高于历史实际水平 |

诚实提示：本假设已给予公司显著的经营改善空间（净利率由历史 6.8% 提升至 14%）。若维持历史水平（6.8%），稳态净利仅 0.16 亿元。故 14% 属偏乐观口径，须在情景中充分体现。

第三步：稳态净利润 × 远期合理 PE
- 稳态净利 = 2.40 亿元 × 14% = 0.336 亿元；考虑公司无少数股东权益，归母 ≈ 0.34 亿元
- PE 取 35x（小盘稀缺景区资源溢价，高于行业 20–25x 中枢）
- 目标市值 = 0.34 亿元 × 35x = 11.9 亿元 ≈ 12.0 亿元 → 目标股价 5.29 元
- 交叉验证（归母净资产倍数法）：归母净资产 10.631 亿元 × 1.5x（景区资源稀缺性溢价，但 ROE 仅约 3%） = 15.9 亿元 → 7.03 元
- 综合中性取两者中偏高者与市场现实的平衡 → 8.48 元

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1 · 资产质量折扣（PB 3.28x 的审视）
- 公司不破净（PB 3.28x >> 1），故无"破净伪空间"问题；相反，须回答"凭什么给 3.28 倍 PB"。
- 归母净资产 10.631 亿元的构成：主要为景区固定资产（索道、游船、观光车、游客服务中心、塔尔钦小镇）与货币资金/理财。资产真实、无隐藏债务（资产负债率仅 27.95%）。
- 但资产盈利能力极低：2025 年归母 2,327 万元 / 净资产 10.60 亿元 = ROE 2.22%；2026H1 加权 ROE 0.27%。以 2–3% 的 ROE 支撑 3.28 倍 PB，隐含市场给了"资源稀缺性 + 资产注入期权"的溢价，而这部分既非盈利也非可验证的资产重估。
- 结论：PB 3.28x 无基本面支撑，属于典型的"资源故事定价"。按纪律不得因"景区资源稀缺"推导高估值；稀缺性只能作为乐观情景的加成项。

校正 2 · 周期位置校正（中性净利用周期归一化）
- 本股不属于强周期股（旅游为消费服务业），但存在极强的季节性周期与客流周期（疫情后恢复期）。
- 当前周期位置：客流恢复至常态的后期，但公司盈利能力恢复显著滞后于客流（阿里 +322% 而全公司毛利率 −1.2pct）。
- 中性净利不用单年好年景：不用 2025Q3 单季 3,046.65 万元年化（=1.22 亿元，严重高估）。
- 不用近三年均值：2023–2025 归母均值仅 0.181 亿元，若以此 × 35x = 6.35 亿元，将远低于现价。
- 周期归一化方法：采用"稳态营收 × 保守稳态净利率"，即上文 2.40 亿元 × 14% = 0.34 亿元，该数值已剔除季节性与一次性因素。
- 标注：若按公司历史最好净利率 6.8% 归一化，稳态净利仅 0.16 亿元 → 35x = 5.7 亿元 = 2.51 元/股。这构成本股的下限警示。

校正 3 · 杠杆下行情景（高负债必附负面情景）
公司资产负债率仅 27.95%，无杠杆风险，这是本股最大的财务优势（不存在"倒在黎明前"的债务风险）。但仍须给负面情景：
- 下行组合：印度香客政策收紧（阿里西线增长熄火）+ G318 继续延期（鲁朗第五次延期）+ 东线让利持续而客流未起
- 测算：稳态营收降至 2.00 亿元 × 净利率 8% = 0.16 亿元 → 30x = 4.8 亿元；同时归母净资产倍数回落至 1.2x = 12.76 亿元 → 取中 8.0 亿元 → 3.52 元；进一步悲观至净资产 1.1x = 11.7 亿元 → 3.22 元
- 该情景空间为 −77% 至 −79%，故不得标"大空间"；结论不得为"重点关注"。

- 反转信号：① 印度香客政策进一步放宽的官方文件（如配额提升、路线扩展）；② 自治区财政补贴大额到账；③ G318 提质改造完工公告（解除鲁朗景区交通瓶颈）
- 重估弹性测算：若阿里西线收入由 0.65 亿元增至 1.2 亿元、净利率 25% → 增厚归母约 0.14 亿元；叠加 5A 创建带来门票与客流双升，稳态归母可达 0.6 亿元 → 35x = 21 亿元 → 9.25 元/股，较现价 −39.8%。即使政策全面兑现，空间仍为负。
- 验证点/证伪信号：政策文件未出、香客流量回落即证伪
- 未过验证点，仅作机会情景（且即便兑现仍不足支撑现价）。

类型 C · 市场错杀修复
当前不成立：本股并非被错杀，而是被"资源稀缺 + 新奥注入"故事高估（PE 116x、PB 3.28x）。若后续因资产注入再度终止或客流不及预期导致急跌至 5 元以下（PB < 1.07x），且扣非转正、阿里西线持续增长，则构成错杀修复机会。
- 错杀证据（未来需验证）：PB 跌破 1.1x、扣非连续为正、基本面未恶化
- 修复触发点：市场风格转向低估值消费、公司单季扣非利润创新高

类型 D · 技术突破 / 技术代际跃迁期权
旅游景区业务不存在技术路线跃迁的可能，本类不适用。唯一沾边的方向是"数字化综合运营平台"带来的运营效率提升与线上转化率改善——但这属于管理工具升级，不是"从 0 到 1 的新技术路线投产"，不构成类型 D。
- 硬验证点（若强行套用）：平台上线并披露线上转化率、复购率提升数据；当前未披露，故不成立

什么条件出现才上调至“重点关注”：
需同时满足——① 股价回落至 5.50 元以下（PB < 1.18x、2029E 中性 PE < 37x）；② 扣非净利连续两个半年度为正；③ 阿里西线营收占比提升至 35% 以上且保持高增；④ 新奥集团正式公告启动资产注入并披露标的、对价与时间表。四条缺一则维持当前结论。

结论：暂不介入

判断依据：中性远期空间 −44.8%，即便乐观情景（含新奥注入新绎游船）也仅 −16.7%，四种上行想象力情景中三类即便兑现仍无法支撑现价，风险收益严重不对称。
公司不是亏损股（2026H1 归母 +290.92 万元），故不适用"坚决回避"中的"确无扭亏可能"标准；其资产真实、无杠杆（资产负债率 27.95%）、景区资源稀缺且区域垄断、阿里西线确有 +322% 的真实增长。问题在于估值：PE 116x（2026E）、PB 3.28x（ROE 仅 2.22%），且账面盈利完全由 468.54 万元非经常性损益填补、扣非仍亏 177.62 万元——市场定价的是"景区资源故事 + 新奥资产注入"，而后者已两度终止。
核心跟踪点：① 季度扣非净利能否转正；② 阿里西线营收占比提升幅度；③ 募投项目（尤其鲁朗，进度仅 4.56%）是否实质推进；④ 新奥集团是否第三次启动资产注入。
