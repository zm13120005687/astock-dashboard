（3）产业链传导 + 原料成本→毛利结构四因子

  • 因子1 成本传导弹性（量化）：铜占成本约 70-80%。行业惯例为"铜价 + 加工费"定价，铜价波动原则上转嫁给客户（铜价传导率≈1），公司赚加工费。2026H1 营收 +29.06% 而销量仅 +0.76%，证明铜价被基本传导。但传导存在时滞与折价：H1 毛利率仍降 0.24pct，财务费用 +29.22%（票据贴现利息 + 汇兑损失），即铜价上行期营运资金被抽血、财务费用吃掉部分传导收益，实际传导率约 0.85-0.9。
  • 因子2 毛利结构再平衡（分业务线）：
业务线 毛利率水平 铜价敏感权重 趋势
传统漆包线（家电/工业电机） 约 4-4.5% 高（铜占比高） 稳定现金牛，份额提升
新能源车扁线 约 28.7% 中 权重快速抬升（4.8 万吨→7 万吨扩产）
特种导体（恒丰特导） 约 12-15% 中（合金/镀层工艺占比高） 权重抬升最快，AI 驱动
裸铜/铜杆 约 1-2% 极高 纯过手

加权看：扁线 + 特种导体合计利润贡献已超 40%（H1 子公司口径：恒丰特导 5021 万 + 扁线相关基地），估值必须按利润结构而非收入结构给——这是"综合毛利率 5.6%"掩盖的关键事实。
- 因子3 库存与采购节奏：铜价上行期高价原料进库存 → 当期毛利率被压（H1 即此状态，属"接货损失"型而非盈利能力恶化）；公司"总部集采 + MES 订单驱动弹性排产"控制库存水位。铜价若快速回落，会出现一次性库存损失 + 收入基数缩水（市场往往误读为经营恶化）；铜价温和区间（震荡）最有利于加工费模式。
- 因子4 政策/市场锚点：①"人工智能+"行动 → 镀银导体需求情景（验证点 = 恒丰特导逐季营收、订单公告）；②新能源车 800V 平台渗透 → 扁线量（验证点 = 扁线产线爬坡进度、新定点公告）；③铜价全球供需与地缘因素（验证点 = LME/沪铜走势、公司套保披露）；④出口关税风险小（越南基地可对冲）。

议价权判断：对下游中等偏强（头部客户深度绑定 + 定制化技术方案 + 行业标准制定者）；对铜价被动（只能传导不能规避，靠周转率赚钱）。

层1 市场容量 × 份额变量（五锚点）：
1. 供给侧份额：电磁线产能超 30 万吨，行业第一梯队；中小厂在铜价高位 + 回款周期拉长下退出 → 份额被动提升（验证点：行业集中度数据、竞对减产公告）
2. 客户份额：特斯拉独家扁线定点 + 华为光伏供应链 + 安费诺/泰科/立讯认证——认证周期即粘性（验证点：新定点公告）
3. 技术代际差：800V 高压扁线（自研多级渐变式压方成型工艺全流程国产化）、112G/224G 镀银绞线均领先国内同行一代（验证点：行业标准牵头制定——公司牵头国内首个 AI 数据中心镀银导体标准）
4. 成本曲线位置：四大基地 + 越南，规模与良率领先（恒丰良品率高出行业均值约 4pct），行业降价时可用加工费韧性以价换量
5. 份额二阶导：扁线渗透处 S 曲线中段（加速期），传统漆包线处成熟期（靠出清提份额）
→ 三档：保守守住现有份额（扁线/导体仅兑现已披露产能）；中性小幅提升（出清 + 新客户）；乐观抢份额（AI 导体超预期 + 铝代铜领先）。验证点均为季报销量结构与子公司净利。

层2 主业迁移空间（新易盛范式）：电磁线 → AI 高速导体 = "铜加工能力同源迁移"，技术同源度高、迁移成本低，且已过信号验证（恒丰特导 H1 营收 9.77 亿、认证与订单公告齐备）→ 可计入中性。电磁线 → 超导（聚变/超导输电）= 新技术曲线，未过中试良率 + 客户定点 + 成本优于旧路线的硬验证点 → 仅作机会情景，不计入中性。

层3 证伪信号：① 恒丰特导营收增速转负或客户认证丢失；② 扁线毛利率跌破 20%；③ 铜价急跌引发一次性库存损失 + 加工费竞争性下调；④ 经营现金流持续为负 + 应收扩张失控；⑤ 可转债申报停滞导致扩产资金断档。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵。2026E PE 26.3x，基准目标价 7.84 元低于现价；中性远期 +15.4%。

安全边际：
- 中性远期 9.52 元 → 空间 +15.4%，>0 但不达"重点关注"门槛（>50%）
- 悲观情景 6.10 元 → 下行 −26.1%
- 乐观情景 14.79 元 → +79.3%，依赖 AI 导体持续超预期
- 下行保护：扁线 + 特种导体利润占比过半且有认证壁垒；但 PB 2.9x、负债率 61.1%、现金流承压，安全边际一般

上行想象力情景（四类，均不进中性锚）：
- A 行业调整剩者红利：铜价高位 + 回款恶化出清中小电磁线厂，龙头份额与加工费定价权跳升。验证点 = 行业 CR 数据、竞对退出公告；证伪 = 加工费战开打。
- B 政策反转期权："人工智能+"行动加码、算力投资超预期 → 镀银导体需求弹性重估（2026H1 订单口径 +217% 即为信号）。验证点 = 恒丰特导逐季营收、新基地投产进度；证伪 = AI 资本开支退坡、铜连接被光连接替代加速。
- C 市场错杀修复：铜价急跌时市场会把"收入缩水"误读为经营恶化 → 出现错杀买点（历史上铜价下行期电磁线股常被错杀）。验证点 = 股价急跌但子公司净利稳定；证伪 = 加工费同步收缩。
- D 技术代际跃迁期权：可控核聚变卢瑟福电缆 + 参股上海超导（二代高温超导带材批量产能）。硬验证点未齐（中试良率达标 + 客户定点规模化 + 量产成本优于旧路线），仅作机会情景；验证点 = 聚变项目大额订单公告、上海超导上市/融资进展；证伪 = 超导输电成本长期打不过常规电缆。

什么条件出现才上调重点关注：① 恒丰特导 2027 年净利≥2 亿且常州基地投产超预期；② 扁线市占率进一步提升（新整车定点）；③ 超导业务出现硬验证点订单——三者中两条兑现，远期空间看 +50% 以上。

介入条件：
1. 不追高。现价 8.25 元对应基准估值上沿，回落至 7.5 元以下（2026E PE < 24x）再介入
2. 加仓信号：恒丰特导新基地投产公告、可转债获批、扁线新定点
3. 观察指标：恒丰特导季度营收增速、经营现金流转正、毛利率企稳 5.6% 以上

最大风险（最可能破坏逻辑的因素）：
1. AI 算力铜连接需求退坡或被光连接替代——特种导体是估值溢价的主要来源，一旦退火估值双杀（首要）
2. 铜价高位致现金流持续为负、负债率 61.1% 叠加可转债融资不顺
3. "增收不增利"被市场证伪定价：铜价上涨掩盖量增停滞（+0.76%），若铜价回落收入负增长
4. 扁线竞争加剧（同行大规模扩产）导致 28.7% 毛利率中枢下移

结论：纳入观察

理由：中性远期空间 +15.4%，逻辑正确（AI 导体已过验证点、扁线产能落地），但现价已定价大部分确定性，且现金流/负债约束限制安全边际。回落至 7.5 元以下或恒丰新基地投产超预期时再升级。
