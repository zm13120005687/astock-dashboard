西安银行（600928）五步法分析报告

数据基准：2026 年半年度报告（2026-08-28 披露）

第一步：公司是干什么的？

一句话定位：总部位于西安的区域性城市商业银行，扎根陕西、辐射西北，以公司银行 + 零售银行 + 金融市场为主业，是地方基建、城投与中小企业的核心信贷供给方。

（3）产业链传导

上游（负债端）：存款成本（受降息利好下行），同业负债成本随市场利率波动；议价权中等（区域存款竞争）。
下游（资产端）：对公（基建/城投/制造）、零售（按揭/消费）；贷款定价受 LPR 与区域竞争约束，议价权中等偏弱。
议价权：负债端受益区域网点优势（结算存款沉淀），资产端偏弱（优质客户被大行争夺）。NIM 1.99% 优于行业，体现区域深耕与负债结构优化。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：银行存款"原料"= 存款成本。LPR/贷款收益率下行时，若存款成本同步下行（降息+自律机制），NIM 可维持（传导率≈0.6–0.8）；2026H1 存款成本下行带动 NIM +0.29pct，传导顺畅。
  • 因子2 毛利结构再平衡：利息净收入占比升至 85%（+23.65%），非息占比降至 15%（公允价值拖累）；结构从"息差+非息均衡"回到"息差主导"，盈利稳定性增强但费收弹性下降。
  • 因子3 库存与采购节奏：无库存，但"期限错配"类似——资产久期（贷款）vs 负债久期（存款），重定价节奏决定 NIM timing；H1 负债端重定价快于资产端，利好 NIM。
  • 因子4 政策/市场锚点：① 市场层——市场利率（DR007）、债券收益率（影响公允价值/投资收益）；② 政策层——LPR、存款自律上限、化债政策、地产纾困。情景：存款成本再降 10bp → 验证点看季度 NIM、存款利率。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务·份额变量：
  • 供给侧份额：西安区域存款/贷款份额领先（地方法人银行优势）；
  • 客户份额：财政资金、城投、本地企业主账户粘性高；
  • 技术代际：数字银行中等；
  • 成本曲线：区域网点 + 结算存款带来低成本负债，处行业左侧；
  • 份额加速度：区域份额稳定，无快速扩张。
    → 中性份额稳定，验证点：存贷款市占率、NIM 季度数据。
  • 层2 扩展业务·主业迁移空间：从"对公信贷"向"财富管理 + 零售"迁移，能力可迁移（同源客群），新 TAM（居民财富）弹性大；切入时点中等（红海竞争）。未过验证点仅作中期期权。
  • 层3 风险折扣（证伪信号）：不良率突破 2%、拨备覆盖率跌破 200%、区域地产/城投风险暴露 → 下调增量。

第四步：估值锚定（自下而上，非增速外推）

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：银行"资产"为贷款（有信用风险），PB 0.44x 已隐含资产质量折价；需验证不良率（1.76%）与拨备覆盖率（261%）是否充足——当前拨备厚实，破净非"伪安全边际"而是风险折价，但安全垫（261% 拨备）真实。
  • 校正2 周期位置校正：银行处净息差周期底部回升 + 化债推进期，中性净利未用单年高点，已考虑 NIM 温和，周期位置标注为"息差企稳、资产质量筑底"。
  • 校正3 杠杆下行情景：银行天然高杠杆（资本充足率 13.57%），区域地产/城投若恶化，减值跳升可令净利腰斩（悲观 3.15 元，−12%），须提示高贝塔与区域集中度风险。

第五步：综合赔率判断（买不买？）

当前价格位置：明显低估（破净）。现价 3.58 元对应 PB 0.44x、PE 5.93x，处历史低位，市场过度定价区域风险。

安全边际：
- 中性远期 4.73 元 → 空间 +32.1%；
- 悲观 3.15 元 → 下行 −12.0%（有拨备/破净底保护）；
- 乐观 6.62 元 → +84.9%；
- 下行保护：PB 0.44x（破净）+ 拨备覆盖率 261% + 核心一级资本充足率 9.28%，底线扎实。

介入条件：
1. 可分批建仓。现价 3.58 元（PB 0.44x）已具安全边际；回落至 3.2 元以下（PB<0.4x）加大仓位；
2. 加仓信号：① 不良率稳住或下降、拨备覆盖率维持 250%+；② NIM 连续两季回升；③ 化债实质推进、区域地产企稳；
3. 观察指标：逐季不良率、关注类贷款、NIM、存贷款增速。

最大风险：
1. 区域地产/城投风险暴露（首要）：陕西区域城投与地产链若恶化，减值跳升直接冲击利润；
2. 净息差再次收窄：存款成本刚性 + 贷款定价竞争；
3. 非息收入持续疲软：公允价值/手续费恢复不及预期；
4. 区域集中度：单一区域风险难以分散。

结论：纳入观察

西安银行破净（PB 0.44x）+ 低 PE（5.93x）+ 厚拨备（261%）构成明显安全边际，中性修复至 4.73 元（+32%）逻辑通顺。但区域集中度与地产/城投风险尚未完全出清，不宜重仓，宜分批观察、等资产质量进一步确认后加仓。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • 类型A 行业调整剩者红利：中小银行出清/合并，区域份额向头部城商行集中 → 验证点：区域存贷款份额、并购公告。
  • 类型B 政策反转期权：化债实质见效 + 地产企稳 + 存款利率再降 → 重估弹性：减值回拨 + NIM 回升，净利冲 42 亿（乐观 6.62 元）。验证点：化债额度落地、不良率拐点。
  • 类型C 市场错杀修复：破净银行随市场风格切换（高股息/低估值）修复 → 修复触发点：PB 回到 0.6x 以上、股息率吸引配置盘。
  • 类型D 技术突破期权：数字银行/零售转型降本增效 → 硬验证点：零售 AUM 占比、成本收入比下降。证伪：份额流失、风险事件。

    上调至"重点关注"的条件：不良率连续两季下降且拨备覆盖率维持 250%+，或现价回落至 3.2 元以下（PB<0.4x）安全边际极厚。
