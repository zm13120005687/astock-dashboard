（3）产业链传导

上游：钢材、数控系统、功能部件——公司部分自研数控系统（秦川数控），但高端轴承/系统仍外购；成本端受钢价影响（转嫁系数中等 ~0.5，可通过高端产品溢价传导）。

下游：汽车/新能源、航空航天、军工、机器人、风电——需求受制造升级 + 国产替代 + 人形机器人爆发驱动，景气上行。

议价权判断：中强（高端细分垄断）。齿轮磨床/丝杠磨床等高端品类进口替代、精度达国际水平，具定价权；通用机床竞争激烈、议价一般。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（转嫁系数）：高端机床/减速器（进口替代、精度壁垒）转嫁系数 ≈ 0.7–0.9，可转嫁钢/部件涨价；通用机床/刀具转嫁系数 <0.4。结构分化。
  • 因子2 毛利结构再平衡：高毛利（>40%）航天/精密设备占比提升将抬升综合毛利；当前综合约 18%–20%，若 RV 减速器/五轴放量，毛利结构向"高端主导"迁移（不能用单一综合毛利率代表）。
  • 因子3 库存与采购节奏：装备制造按订单生产（MTS/MTO），存货以在产与备料为主，低价囤货收益有限；无系统性套保。股份支付费用（2026H1 影响约 1944 万）为一次性人工成本，剔除后盈利质量更高。
  • 因子4 政策/市场锚点：① 工业母机专项资金（补贴降研发成本，正项）；② 人形机器人量产节奏（RV 减速器需求，正项）；③ 军工/航天预算（正项）；④ 钢价/数控系统进口（成本项）。验证点：专项补贴公告、RV 减速器订单、机器人量产进度。证伪：补贴退坡 + 机器人量产延迟 → 毛利破阈。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：① 供给侧——齿轮磨床已占 60%+、军工 75%，份额高但总量受机床行业周期约束；② 客户份额——比亚迪/航天/库卡认证粘性高（验证点：逐季订单/客户公告）；③ 技术代际——精度达国际水平、替代克林贝格；④ 份额加速度——RV 减速器从"验证"向"放量"渗透（验证点：RV 出货量/人形机器人客户定点）。
  • 层2 扩展业务（主业迁移空间·新易盛范式）：RV 减速器 + 丝杠磨床从"机床厂"迁移至"人形机器人核心部件供应商"，新 TAM（机器人万亿赛道）远大于旧机床市场，能力同源（磨床技术 → 减速器/丝杠），属强迁移。但未过"RV 营收占比跳升 + 人形定点"验证点，仅作中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：人形机器人量产延迟、专项补贴退坡、机床行业周期下行、RV 减速器客户认证失败 → 下调增量。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵（已定价部分未来）。现价 9.61 介于基准 6.55 与中性远期 12.11 之间，市场已提前反映工业母机/机器人预期。

安全边际：
- 中性远期 12.11 元 → 空间 +26.0%；乐观 22.34 元 → +132.5%；
- 下行保护：PB 1.98x、经营现金流转正（+9286 万）、国资链主；悲观 3.77 元（−60.8%）为周期+机器人双杀情景；
- 上行期权显著（人形机器人核心部件稀缺标的）。

介入条件：
1. 可逢低布局。现价 9.61 已具中期配置价值；若回落至 8 元以下（对应 2029 中性 PE < 25x）加仓更安全；
2. 加仓信号：① RV 减速器获人形机器人头部定点/大额订单；② 五轴/磨齿机订单增速 >30%；③ 净利率连续两季 >5%；
3. 观察指标：逐季归母净利（剔除股份支付）、RV 减速器出货量、专项补贴公告、人形机器人量产进度。

最大风险：
1. 盈利兑现不及预期（首要）：当前净利率仅 0.2%，若高端放量慢、费用高企，2029 净利远低于 3.2 亿；
2. 人形机器人量产延迟：RV 减速器/丝杠需求是核心期权，延迟则成长逻辑打折；
3. 机床行业周期下行（宏观经济/固定资产投资走弱）；
4. 专项补贴退坡 / 估值高波动（PE 178x 对预期极敏感）。

结论：纳入观察（中性远期 +26%、未达重点关注 >50% 门槛；但工业母机战略 + 人形机器人期权明确，若盈利兑现/机器人定点落地可上调至重点关注）。

上行想象力情景（第五步进阶，仅进机会栏）：
- A 行业调整剩者红利：工业母机国产化率提升 + 中小机床厂出清，链主（秦川）份额与定价权提升（验证点：国产化率/订单集中度）。
- B 政策反转期权：不适用（已是政策支持对象）；反向——若专项资金加码，研发成本进一步下降。
- C 市场错杀修复：若风格切换错杀至 8 元以下（PB<1.7x），战略资产修复弹性大。
- D 技术突破/代际跃迁期权：RV 减速器 + 丝杠磨床切入人形机器人核心部件（国内唯一同时自主研制高精度齿轮磨床与螺纹磨床，设备—部件闭环，成本较同行低 20%），属"主业向万亿机器人赛道迁移"，硬验证点=人形机器人头部定点 + RV 出货量跳升 + 量产成本优于旧路线，否则仅机会情景。
上调至重点关注的条件：RV 减速器获人形机器人头部大额定点、2027 归母净利兑现 2 亿+（净利率 >5%），使中性目标价上修至 15 元以上（空间 >50%）。
