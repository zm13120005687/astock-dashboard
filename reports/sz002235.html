第一步：公司是干什么的？

一句话定位：从传统商务信息用纸向"防伪溯源 + 版权综合服务 + 商务用纸"数字化转型的综合服务商，2026 年实控人变更为 AI 智算平台商，开启"数字版权 + AI 智算"转型预期。

核心产品 / 服务：① 商务信息用纸（热敏纸、无碳纸等，"安妮""王者"品牌，服务百胜、海底捞、肯德基等）；② 防伪溯源系统（物联网 / AI / 大数据标签，客户含嘉实多、农夫山泉、联合利华、RIO，及国家彩票中心）；③ 版权综合服务（"版权家"平台，确权—授权—维权全链条，牵头两项区块链国标）；④ 彩票印制（多省份福彩高市占）。

主要客户 / 下游：快消（润滑油、日化、酒水饮料）、政务、出版、福彩；防伪溯源客户多为头部品牌。

境内外收入占比：境内为主（华东 41.07%、华北 40.62%、华南 12.10%）。

股东背景：原控股股东向北京晟世天安转让 15.92% 股份过户完成，晟世天安成控股股东，实控人李宁 / 王磊（科技背景，原日立数据、联想、戴尔、惠普高管）。晟世天安专注"行业智算及具身智能"，2024 营收 2.84 亿、净利 1743 万，锁定期延长至 36 个月。

第二步：行业景气度 + 政策 / 市场数据

  • 数据要素 / 版权保护：国家持续推进数据要素市场化、版权强国建设，区块链确权受政策支持；公司牵头两项区块链国标获批。
  • AI 国产化："人工智能+"行动推动行业智算渗透，晟世天安智算一体机 / 行业大模型契合方向。
  • 防伪溯源：食品药品追溯、品牌保护政策持续强化，高频 / 超高频 RFID 标签需求增长。

（3）产业链传导

上游：纸浆 / 原纸（商务用纸成本）、RFID 芯片 / 标签材料（防伪溯源成本）、算力硬件（智算业务）。纸浆价格随全球供需波动。
下游：快消品牌、政务、出版、福彩；防伪溯源与版权服务需求受企业数字化预算影响。
议价权：传统用纸竞争激烈、议价权弱；防伪溯源 / 版权具一定资质壁垒（国标牵头、福彩资质），议价权中等。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：商务用纸转嫁系数 ≈0.4（浆价上涨难全转嫁）；防伪溯源 / 版权服务转嫁系数 ≈0.6（资质壁垒支撑）。综合毛利率由 19.5% 降至 13.71%，反映成本 / 价格双压。
  • 因子2 毛利结构再平衡：
    | 业务线 | 毛利率（估） | 原料敏感权重 |
    |---|---|---|
    | 商务信息用纸 | 10–15%（纸浆敏感） | 高 |
    | 防伪溯源系统 | 20–30%（芯片 / 材料敏感） | 中 |
    | 版权服务 | 40–50%（轻资产高毛利） | 低 |
    | 智算（拟注入） | 待验证 | — |
    结构风险：高毛利版权服务占比低（未单列收入），主体仍是低毛利用纸，综合毛利被拖累。
  • 因子3 库存与采购节奏：纸浆存在"低价囤货 / 高价接货"timing；2026H1 经营现金流 −5872 万，或反映备货 / 应收占用，须警惕库存损失。
  • 因子4 政策 / 市场锚点：① 数据要素 / 版权政策利好版权服务需求；② AI 算力补贴 / 国产化政策利好智算业务；③ 纸浆价格（全球供需、运费）影响用纸成本。验证点：版权服务收入占比、智算资产注入进展、浆价；证伪：主业毛利率持续 <12%、现金流持续为负。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：① 供给侧——防伪 / 版权赛道分散，公司具国标与资质壁垒；② 客户份额——快消头部客户稳定但份额有限；③ 技术代际——区块链 / RFID 技术中上；④ 成本曲线——轻资产服务占优；⑤ 份额加速度——缓慢。三档：保守守住存量 / 中性份额微升 / 乐观政策驱动放量。验证点：版权服务收入占比、防伪客户公告。
  • 层2 主业迁移空间（新易盛范式）：从"用纸 + 版权"迁移到"数字版权 + AI 智算"。能力可迁移性中（场景 / 数据赋能）；新 TAM 弹性大（智算蓝海）；切入卡位早（实控人即智算商）；认证门槛高（AI 落地需客户验证）；信号验证——仅完成控制权变更，无资产注入正式方案公告。→ 中期期权，不计入中性。
  • 层3 证伪信号：智算注入无实质方案、主业毛利率继续下滑、经营现金流持续为负、版权服务收入无跳升。

第四步进阶：重资产 / 周期股估值校正

本股非重资产（轻资产服务），但适用"盈利质量 + 期权校正"：① 盈利质量——归母微利全靠非经常性，扣非为负，PE 估值失真；② 资产质量——净资产 7.32 亿、PB 6.07x 已隐含极高预期；③ 期权纪律——晟世天安智算注入为未过验证点中期期权，不计入中性 NAV / 净利，仅列乐观情景。④ 杠杆——负债率未披露偏高但轻资产，下行风险为估值压缩（非资不抵债）。

第五步：综合赔率判断（买不买？）

当前价格位置：严重高估 / 纯预期驱动。现价 7.67 元、PB 6.07x，主业年化盈利近乎为零，price-in 了"智算注入"全部想象。

安全边际：中性远期 0.78 元 → 空间 −89.8%；悲观 0.86 元（−88.8%）；乐观 6.90 元（−10.0%，仍为负）。三重情景均低于现价，赔率极差。

介入条件：仅当回落至 1.0 元以下（对应主业 PE 合理 + 保留期权价值）才具博弈价值；加仓需验证：① 智算资产注入正式方案公告；② 版权 / 防伪服务收入占比跳升、毛利率回升至 18%+；③ 经营现金流转正。

最大风险：① 智算注入仅"预期"无实质方案，证伪即戴维斯双杀；② 主业扣非持续亏损、现金流恶化；③ 原用纸业务受浆价 / 需求挤压；④ 跨界定增 / 重组审批与整合不确定性。

结论：暂不介入

公司 2026H1 虽归母转正（TTM 亏损标记为误标），但扣非仍亏、盈利靠非经常性，主业孱弱。当前 6.07x PB 完全由"晟世天安智算注入"预期支撑，该期权未过验证点，不得计入中性。中性锚远低于现价，属典型"概念溢价"标的。若智算资产注入正式落地并兑现业绩，可重新评估。

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：不适用（非过剩出清行业）。
  • 类型B 政策反转期权：数据要素 / 版权 / AI 国产化政策加码，提振版权与智算需求。列具体政策名（数据二十条、AI+行动）+ 反转信号（细则落地、预算下发）；未过验证点仅作机会情景。
  • 类型C 市场错杀修复：不适用（当前非错杀，而是溢价）。
  • 类型D 技术突破 / 代际跃迁期权（核心）：实控人晟世天安将"行业智算 + 大模型 + 具身智能"资产注入，推动"版权 × AI × 智算"重构——硬验证点（中试 / 客户定点 / 量产成本优于旧路线）目前均未满足（仅完成控制权变更，无注入方案）。未过验证点，仅作机会情景，不计入中性。
  • 上调至重点关注的条件：智算资产注入正式方案公告 + 承诺业绩 + 主业扣非扭亏，使 2029E 净利上修至 1 亿以上、远期空间转正并突破 +50%。
