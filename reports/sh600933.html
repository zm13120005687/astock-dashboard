第一步：公司是干什么的？

一句话定位：全球汽车铝合金精密压铸隐形冠军，为新能源整车、电驱、热管理、智能驾驶提供高附加值铝/锌/镁合金压铸件，并切入具身智能结构件与 AI 光模块散热器，全球化产能就近配套。

（3）产业链传导

上游：铝价（受大宗影响）、锌/镁、汇率（外销 51%）；公司通过长协 + 套保 + 海外本地采购对冲。
下游：新能源整车/电驱/热管理/智能驾驶，需求高增且客户认证壁垒高；外销受关税/贸易政策影响（墨西哥本地化规避）。
议价权：对主机厂议价权中等（年降压力），但高附加值 + 技术壁垒 + 全球化就近配套增强粘性，认证周期长形成护城河。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：铝价上涨部分通过产品调价/套保传导（传导率≈0.5–0.7），但主机厂年降压力限制顺价；汇率端（外销 51%）受美元波动影响大（2026H1 汇兑损失 7218 万即体现）。
  • 因子2 毛利结构再平衡：高毛利汽车类（新能源）占比提升，具身智能/光模块散热器等更高附加值订单占比上升 → 整体毛利结构优化；但短期受铝价 + 汇率 + 行业竞争拖累，毛利率 −2.35pct。
  • 因子3 库存与采购节奏：铝为原料，低价囤货收益有限（套保为主）；海外本地采购（墨西哥/马来）对冲汇率与运费 timing。
  • 因子4 政策/市场锚点：① 市场层——LME 铝价、美元汇率、运费；② 政策层——关税（倒逼墨西哥本地化，公司已布局）、新能源补贴、具身智能政策。情景：铝价回落 + 美元走强 → 验证点看铝价/汇率。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务·份额变量：
  • 供给侧份额：精密压铸头部，产能扩张匹配需求；
  • 客户份额：全球头部主机厂 + Tier-1，认证壁垒高、粘性强；
  • 技术代际：半固态/超薄壁（0.45mm）/液冷领先；
  • 成本曲线：规模化 + 海外垂直整合，处左侧；
  • 份额加速度：新能源 + 出海份额提升。
    → 中性份额提升，验证点：逐季营收、客户定点公告。
  • 层2 扩展业务·主业迁移空间（新易盛范式）：从"汽车压铸"向"具身智能结构件 + AI 光模块散热器"迁移，能力可迁移（同源精密压铸 + 工艺），新 TAM（机器人/算力）弹性数倍；切入时点早（先发），认证门槛高。信号验证：新订单占比跳升（具身智能 6%、光模块 6%）→ 中期期权，未过规模验证不计入中性净利。
  • 层3 风险折扣（证伪信号）：铝价大涨 + 汇率恶化、新订单放量不及预期、墨西哥/马来投产延期、年降超预期 → 下调增量。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：制造业中等重资产（模具/压铸机），PP&E 真实可用、无破净（PB 1.37x），全球化产能（墨西哥/马来）具真实产出，非虚估资产。
  • 校正2 周期位置校正：汽零处新能源上行周期（非周期底部），中性净利未用单季高点（已剔除汇兑一次性），周期位置标注为"新能源轻量化上行 + 短期汇率逆风"。
  • 校正3 杠杆下行情景：资产负债率适中（<40%，财务稳健），但经营杠杆存在（产能扩张期折旧上升）；悲观情景（汇率+年降）空间仍 +6.4%，下行有限，非高贝塔毁灭型。

第五步：综合赔率判断（买不买？）

当前价格位置：低估。现价 12.77 元对应 2026E PE 12.2x、2029E 中性 PE 9.2x，处新能源精密压铸合理估值（18–25x）下沿，安全边际充足。

安全边际：
- 中性远期 23.10 元 → 空间 +80.9%（>50% 重点关注门槛）；
- 悲观 13.59 元 → 仅 +6.4%（下行有限）；
- 乐观 34.95 元 → +173.6%；
- 下行保护：PB 1.37x、净现金/低负债、全球化产能真实、订单饱满（101.85 亿）。

介入条件：
1. 当前即可建仓。现价 12.77 元（2026E PE 12x）已具安全边际；回落至 11 元以下加大仓位；
2. 加仓信号：① 墨西哥二期达产、马来西亚订单放量；② 具身智能/光模块散热器营收占比跳升；③ 汇兑回正、毛利率回升至 28%+；
3. 观察指标：逐季营收、外销占比、新定点公告、毛利率。

最大风险：
1. 汇率波动（首要）：外销 51%，美元走弱直接侵蚀利润（2026H1 汇兑损失 7218 万已现）；
2. 原材料（铝）涨价 + 主机厂年降：双向挤压毛利率；
3. 新业务量产不及预期：具身智能/光模块仍小基数；
4. 出海地缘政治/关税：墨西哥政策变化。

结论：重点关注

爱柯迪订单饱满（101.85 亿全生命周期）、全球化产能就位、具身智能与光模块散热器打开第二曲线，业绩增长明确且行业景气向上；现价 12.77 元对应 2026E 仅 12x PE，中性远期 23.10 元（+80.9%）空间充足，符合"重点关注"标准。核心跟踪汇率与新兴业务放量。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • 类型A 行业调整剩者红利：精密压铸出清，头部份额集中 → 验证点：公司市占率、订单份额。
  • 类型B 政策反转期权：新能源/具身智能/算力政策加码 → 重估弹性：新兴订单放量，净利冲 18 亿（乐观 34.95 元）。验证点：机器人/算力政策、客户定点。
  • 类型C 市场错杀修复：若因汇率/大盘回落至 PB<1.1x（<11 元），估值分位极低 → 修复触发点：汇兑回正 + 毛利率证伪恐慌。
  • 类型D 技术突破期权：半固态/超薄壁（0.45mm）/液冷工艺量产降本 → 硬验证点：良率达标、客户定点、成本优于旧路线。证伪：良率不达标、客户流失。

    维持/上调"重点关注"的条件：墨西哥二期达产 + 新兴业务营收占比跳升验证，或现价回落至 11 元以下安全边际更厚（已满足重点关注，持续跟踪即可）。
