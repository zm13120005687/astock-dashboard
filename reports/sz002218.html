一句话定位：老牌纯太阳能企业（2008 年上市），"光伏玻璃 + 晶体硅电池/组件 + 自持电站（电费）"垂直一体化，2026 年起战略切入"光储一体化"（储能系统制造 + 独立储能电站）。

（3）产业链传导

上游：硅料、玻璃原片、纯碱。玻璃原片价格低位但公司玻璃毛利率仍为负，反映供过于求 + 自身成本曲线偏右。

下游：电站装机、组件出口、国内装机（不及预期）。电站端受电力市场化交易 + 限电双重压力，但 2026H1 暂被消化。

议价权：弱。玻璃环节产能过剩、买方强势，转嫁系数≈0（成本上涨自己扛、价格下跌也难提价）；电站端因自持高电价区域资产，议价权中等（电价由政策+市场决定）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：玻璃原料（纯碱/石英砂/天然气）占成本主导，行业过剩使公司转嫁系数≈0.1（几乎自扛）。测算：纯碱涨 10% → 玻璃毛利率再降 1–2pct，亏损扩大。
  • 因子2 毛利结构再平衡：收入 39.83% 来自玻璃（毛利率 −12.93%），38% 来自电站（毛利率 +49.27%）。结构错配=规模越大玻璃亏越多，而电站年化收入天花板约 3.6 亿。扭亏数学前提：玻璃毛利率回 0 以上。
  • 因子3 库存与采购节奏：玻璃原片低价囤货收益有限（行业通缩）；无显著长协套保披露。库存收益非盈利来源。
  • 因子4 政策/市场锚点：① 能耗标准加速玻璃落后产能出清（供给收缩→价格修复，市场层）；② 加拿大取消双反（出口放松）；③ 储能容量电价（政策层，直接托底新业务收益）。验证点：3.2mm/2.0mm 玻璃报价月报、公司玻璃毛利率环比；证伪：玻璃报价续跌或毛利率未收窄。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：玻璃环节市场份额小、无份额提升锚点（产能过剩）；电站份额取决于自持装机，增长靠新建/配储。三档：保守（玻璃微亏、电站稳）、中性（玻璃减亏至 0 附近）、乐观（玻璃转正 + 储能放量）。验证点：玻璃毛利率、储能并网容量。
  • 层2 主业迁移空间（光储融合）：从"光伏制造+电站"迁移到"储能系统集成+独立储能运营"——能力可迁移（同源电力电子/项目开发），新 TAM 弹性大（新型储能十五五高景气）。但储能订单/产能消纳未正式公告跳升，未过验证点，仅作中期期权，不计入中性。
  • 层3 证伪信号：玻璃毛利率连续两季仍为负、储能项目无量化订单/并网延期、实控人股权纠纷反复 → 下调。

亏损股三问（必答）

  1. 为什么亏：光伏行业产能过剩、主链价格战，最大收入板块光伏玻璃毛利率 −12.93% 持续失血；2025 全年归母 −1.99 亿为过去 10 年首亏，2026H1 续亏 −5788 万但同比减亏 3.86%。属"行业周期底部 + 制造端失血"，非主业持续恶化（电站仍高盈利）。
  2. 靠什么扭亏、触发时点：① 组件毛利率已转正（+1.63%）；② 行业自律涨价 + 能耗标准出清落后产能，玻璃毛利修复（关键，2027 年有望减亏至微利）；③ 陕西 150MW/600MWh 储能电站 2026Q4–2027 并网享容量电价，贡献新增利润；④ 限电减少 + 分布式扩容提升电站收益。中性判断 2027 年扭亏为盈。
  3. 亏得起吗：亏得起。货币资金 7.53 亿、资产负债率仅 37.66%、流动比率 3.04/速动 2.71、连续 12 年经营现金流为正（2026H1 +1.28 亿），有息负债约 17.78 亿（长期借款为主，久期匹配电站）。短期偿债无虞，可撑至行业拐点。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 3.68 元对应 PB 1.32x，高于中性盈利锚（2.52 元）与 PB 1.1x 锚（3.10 元），市场已计入"减亏+储能"温和预期。

安全边际：中性远期 2.52 元 → 空间 −31.5%（负面）；悲观 2.81 元（−23.6%）；乐观 4.32 元（+17.4%，需储能+玻璃双兑现）。下行保护仅来自电站现金流与净资产（PB 接近 1）。

介入条件：① 跌破 3.00 元（PB≈1.1x，电站现金流价值锚）才具安全边际；② 加仓信号：玻璃毛利率转正、陕西储能电站并网+容量电价确认、2GWh 产线获量化订单；③ 实控人家族股权纠纷彻底落地（2026-09 已撤诉，待最终安排）。

最大风险：① 光伏玻璃亏损持续恶化（毛利率 −12.93% 未收窄）；② 三季报亏损超预期；③ 实控人家族股权安排反复扰动；④ 电价市场化 + 限电侵蚀电站盈利；⑤ 应收账款 12.07 亿（超年营收）回款风险；⑥ 股东户数激增、筹码散户化放大波动。

结论：暂不介入

虽"亏得起"且减亏趋势明确，但现价已透支中性预期，盈利锚（2.52 元）低于现价逾 30%。真正机会在玻璃毛利拐点 + 储能订单验证后的右侧，而非当前左侧。

第五步进阶：上行想象力情景（四类）

  • 类型A 行业调整剩者红利：光伏产能出清后玻璃价格修复、剩者定价权提升。验证点：玻璃报价回升、公司玻璃毛利率转正；证伪：报价续跌。触发上调重点关注条件：玻璃毛利率连续两季 >0 且储能并网≥100MW。
  • 类型B 政策反转期权：储能容量电价（165 元/kW·年，3 年）直接托底收益，陕西首批清单已入选。验证点：并网容量、容量电费入账；重估弹性：若储能规模化，市值可重估至 60 亿+。
  • 类型C 市场错杀修复：PB 1.32x 处历史低位，若三季报证实亏损收窄，估值修复至 PB 1.5x（4.2 元）。验证点：单季扭亏。
  • 类型D 技术/业务代际跃迁期权：光储一体化从 0 到 1（2GWh 产线 + 独立储能），政策+趋势+落地三要素共振。硬验证点：产线获大额订单、电站并网、容量电价兑现——三者缺一则仅作机会情景。
