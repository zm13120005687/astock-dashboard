（3）产业链传导

上游：钢材、铝镁合金、钛合金、高温合金。议价权中等——轴类/球头拉杆/转向节毛利率 21–24%，但轮毂轴承仅 11.68%（价格竞争）。2026H1 汇兑损失 + 存货跌价压制利润。
下游：全球百强零部件商 + 头部整车厂，客户优质但年降压力存在。
议价权判断：中等，佐证为高毛利产品（轴类 23.93%）与低毛利产品（轮毂轴承 11.68%）分化，整体受年降影响。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：钢/铝锻件转嫁系数 ≈ 0.5（部分年降承担）；高附加值（轴类、转向节）转嫁系数 ≈ 0.65；外销毛利率 23.87%（同比 −4.57pct）显示海外传导亦承压。
  • 因子2 毛利结构再平衡：轮毂轴承占 28% 但毛利率仅 11.68%，轴类/球头/转向节（占 43%）毛利率 21–24%——提升高毛利传动/转向件占比、压降低毛利轮毂轴承依赖是毛利修复杠杆。
  • 因子3 库存与采购节奏：存货 4.41 亿，2026H1 计提存货跌价（利润下滑因素之一）；无公开长协套保，钢价波动直接传导。
  • 因子4 政策 / 市场锚点：① 钢/铝价格（影响成本）；② 汇率（外销 38%，人民币升值致汇兑损失）；③ 新能源渗透率（需求增量）；④ 人形机器人/商业航天政策（新赛道需求）。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：四大基地 + 摩洛哥工厂，产能充足；
  • 客户份额：已进入博世/采埃孚/麦格纳核心供应链，新能源客户（比亚迪/小米/理想/蔚来）拓展中；
  • 技术代际：国家级小巨人，212 项专利，工艺领先；
  • 成本曲线：规模 + 自动化左移成本曲线；
  • 份额加速度：新能源占比由 29%→36%（S 曲线上升期）。三档：保守守住（验证点：新能源占比 >40%）；中性小幅提升（验证点：外销订单续增 +20%）；乐观抢份额（验证点：进入特斯拉/头部机器人供应链）。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：依托锻造/精密加工同源能力，迁移至①人形机器人（丝杠/减速器/关节模组）、②航空航天高温合金叶片、③AI 液冷。新 TAM 远大于汽车锻件。但均处验证点之前（样件/小批量/试产），仅作中期期权，不计入中性净利。验证点：大额定点订单、量产良率达标。
  • 层3 证伪信号：募投项目持续亏损（汽车轻量化一期已 −0.17 亿）、机器人/叶片无正式批量订单、新能源客户开拓停滞、毛利率跌破 17%。

第四步：估值锚定（自下而上，非增速外推）

总股本：2.22 亿股｜ 重资产校正（三道闸）

固定资产 11.16 亿 + 在建工程 2.67 亿，占总资产 49%，属重资产；募投项目部分未达预期效益（汽车轻量化一期 −0.17 亿），资产质量需折扣。资产质量折扣：PB 2.26x 未破净，但重资产 + 部分产能闲置/未达预期，真实盈利能力低于账面，估值不应用 PB 简单外推。周期位置：汽车锻件处传统需求平稳 + 新能源上行期，非强周期底部；但 2026H1 盈利下滑提示短期承压。杠杆下行情景：资产负债率 41.1%（适中），短借 7.65 亿，利率上行/需求下行负面情景下净利波动但难转负（主业仍盈利），不阻断中性。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵（短期）。现价 16.74 元已包含部分新业务期权溢价，中性基本面仅支撑 15.3 元。

安全边际：
- 中性远期 15.3 元 → 空间 −8.6%；
- 悲观 8.1 元 → −51.6%；
- 乐观 27.0 元 → +61.3%（需机器人/航空突破，期权属性）；
- 下行保护：PB 2.26x、负债率 41%（适中），每股净资产 7.42 元。

介入条件：
1. 等期权验证：机器人关节模组/谐波减速器获大额定点、高温合金叶片 2026 年底试产转正、液冷业务营收占比 >5%；
2. 价格锚：回落至 13 元以下（PB <1.8x） 才具安全边际；
3. 加仓信号：新能源营收占比 >45%、轻量化一期扭亏、汇兑改善。

最大风险：
1. 募投持续不达预期：汽车轻量化一期已 −0.17 亿，重资产折旧拖累；
2. 传统业务下滑：轮毂轴承等低毛利品价格战、年降；
3. 新业务培育失败：机器人/航空技术门槛高、研发与市场风险（公司自陈）；
4. 汇兑 + 存货跌价：外销 38% + 存货 4.41 亿。

第五步进阶：上行想象力情景（四类，对冲系统性保守偏置）

  • A 行业调整剩者红利：锻造行业分散，国家级小巨人（工艺/客户壁垒）在整合中份额提升，新能源占比由 36% 向 45%+ 迈进。验证点：新能源营收占比 >45%。证伪：传统锻件价格战、份额流失。
  • B 政策反转期权：设备更新、人形机器人、低空经济 / 商业航天政策加码，新赛道需求爆发。验证点：相关政策细则落地、补贴出台。证伪：政策无实质推进。
  • C 市场错杀修复：当前价格已含期权溢价，若 2026H2 盈利回升 + 轻量化项目扭亏，估值修复。验证点：单季净利同比转正。证伪：盈利继续下滑。
  • D 技术突破 / 代际跃迁期权：机器人滚柱丝杠 / 谐波减速器 / 关节模组、高温合金叶片、AI 液冷从 0 到 1 投产，打开全新增长曲线（新 TAM 远大于汽车锻件）。验证点：大额定点订单 + 量产良率达标。证伪：样件失败、客户流失、成本打不过旧路线。

上调至"重点关注"的条件：机器人关节模组 / 高温合金叶片获大额定点（或量产良率达标）、汽车轻量化一期扭亏，使中性（含期权）远期空间突破 +50%。

结论：暂不介入（当前价格已包含未验证期权溢价，中性基本面空间为负，待期权硬验证后再评估）

公司锻造工艺壁垒 + 优质客户 + 新能源占比持续提升构成基本盘；机器人/航空/液冷为弹性期权（乐观 +61.3%）。但中性情景（不含期权）远期空间 −8.6%，现价 16.74 元已提前定价期权，安全边际不足。按规则远期空间为负不得标"纳入观察"——须等机器人关节模组/高温合金叶片获大额定点、或回落至 13 元以下（PB <1.8x）方具备介入价值，届时再上调至重点关注。
