第一步：公司是干什么的？

一句话定位：新中国第一家化学合成制药企业（1943 年创立），全球重要解热镇痛药生产与出口基地，形成"医药中间体—原料药—制剂"全产业链，正推进"原料药-制剂"一体化与高端 API、创新药转型。

核心产品：解热镇痛类原料药（布洛芬、阿司匹林、咖啡因等）、心脑血管/抗感染/神经系统/甾体激素类制剂；化学原料药年产能 5 万吨、中间体 50 万吨、固体制剂 320 亿片（粒）、注射剂 15 亿支。

股东背景：实控人山东省国资委（华鲁控股集团），A+H 两地上市，央企/地方国资信用背书。

（3）产业链传导

上游：化工原料/动力（煤炭、蒸汽、化工中间体）。原料药成本受化工大宗价格影响，但公司通过降本增效（42 项创新举措、技经指标优化）部分对冲。

下游：制剂面向医院/药店（集采定价），原料药面向制剂厂与出口。议价权中偏弱——原料药面临产能过剩、买方强势（转嫁系数≈0.3，成本难向下游传导）；制剂受集采压价（转嫁系数≈0.5）。

议价权量化：原料药板块毛利率 36.17% 但同比承压，价格战中公司只能被动接受；制剂毛利率 18.34%，集采下提升空间有限。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：原料药转嫁系数≈0.3（产能过剩、客户强势，成本上涨自己扛）；制剂转嫁系数≈0.5（集采限价）。上游化工原料涨价 → 实际毛利承压约 70%（原料药）/50%（制剂）。
  • 因子2 毛利结构再平衡：三板块毛利率分化极大——原料药 36.17%、制剂 18.34%、中间体仅 2.16%。当前利润结构依赖高毛利原料药，但原料药收入 -16.42%，占比下滑；中间体低毛利占比升至 26.41%，结构向低毛利迁移，加权毛利率承压。
  • 因子3 库存与采购节奏：原料药价格下行周期中，公司低价备货享成本红利，但产成品跌价风险上升；无长协/套保对冲披露，timing 收益不可持续。
  • 因子4 政策/市场锚点：① 集采续标（压价变量，验证点：续标中标价）；② 原料药环保/能耗双控（抬升合规成本，验证点：限产政策）；③ 出口管制/关税（美洲 -35% 已现，验证点：海外需求数据）；④ 创新药审批加速（利好，验证点：临床/上市批件）。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：① 供给侧：原料药年产能 5 万吨，居全球前列，份额稳固；② 客户份额：200+ 跨国药企合作，通过拜耳/默克全球质量审计，认证壁垒高（粘性）；③ 技术代际：解热镇痛类处成熟代，无代差优势；④ 成本曲线：规模+一体化左侧，集采中以价换量；⑤ 份额加速度：原料药价格战致份额稳但价跌，S 曲线成熟。中性：份额守成、单价下行。
  • 层2 扩展业务（主业迁移空间）：从"大宗原料药"向"高端 API + 制剂 + 创新药"迁移。能力可迁移性中（同一化学合成平台）；新 TAM：高端制剂/创新药弹性大；切入卡位中（已有 15 个新品批件）；客户认证门槛高（既是护城河也是阻力）；信号验证：制剂新品 +92.58%、鱼油 EPA 海外突破、高端 API 中心在建。判定：中期期权，部分已验证（制剂新品），创新药未过验证点不计入中性。
  • 层3 风险折扣（证伪信号）：原料药价格战加剧致毛利率破 30%、制剂集采续标丢标、创新药临床失败。命中则下修。

第四步：估值锚定（自下而上，非增速外推）

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣：PB 1.84x 未破净，净资产 52.71 亿（厂房/设备/土地）真实，非伪破净；但固定资产占比高，重资产属性削弱估值弹性。

  • 校正3 杠杆下行情景：资产负债率 39.3% 稳健，无高负债风险；但盈利下行致 PE 被动抬升，下行空间由盈利预期决定（悲观 −59.8%）。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 13.92 元对应 2026E PE 33x、TTM PE 45x，远超行业合理 15–20x，估值已透支盈利修复预期。

安全边际：
- 中性远期 9.33 元 → 空间 −33.0%（显著为负）
- 悲观 5.60 元 → 下行 −59.8%
- 乐观 15.80 元 → +13.5%（需创新药/高端 API 突破）
- 下行保护：PB 1.84x、国资背景、现金充裕（经营现金流 1.61 亿）、分红记录

介入条件：
1. 不追高。回落至 9.0 元以下（对应 2026E PE <20x、PB <1.2）方具安全边际
2. 加仓信号：① 原料药价格触底反弹（验证点：布洛芬等报价上行）；② 高端 API 中心投产且订单落地；③ 创新药临床重大进展
3. 观察指标：单季毛利率是否止跌、制剂新品收入增速、美洲收入恢复

最大风险：① 原料药产能过剩价格战长期化；② 集采续标中标价进一步下压；③ 国际化受地缘/贸易壁垒冲击（美洲已 -35%）；④ 创新药研发投入产出不及预期。

结论：暂不介入

公司是优质老牌药企，全产业链+国资+创新药管线提供长期期权，但当前 45x TTM / 33x 2026E PE 严重透支，中性远期空间 −33%。需等待价格回落至 9 元以下（估值回归合理）或原料药价格反转/高端 API 兑现的明确信号，方可上调至"纳入观察"。
