（3）产业链传导

上游：晶圆代工（台积电 / 中芯等）、封测，Fabless 模式，成本随代工与封测价格 / 汇率波动。
下游：消费电子 / 汽车 / 算力客户，价格敏感。
议价权：中等偏弱——Fabless 对代工议价有限，对下游终端客户转嫁能力一般；靠产品差异化（车规、AI 电源）提升。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：Fabless 成本主要为晶圆代工 + 封测，代工涨价难转嫁（转嫁系数 ~0.2–0.3）；但车规 / AI 高价值产品溢价强（~0.5+）。
  • 因子2 毛利结构再平衡：综合毛利率 28.77%，分业务线：车规 / AI 电源毛利高于消费电子传统产品；AF/OIS（委外比例提升）放量改善结构。分业务线：车规 > 电源 > 传统消费。
  • 因子3 库存与采购节奏：Fabless 按订单 + 安全库存投片，无囤货收益；诚芯微并表增加产能协同。
  • 因子4 政策 / 市场锚点（原料成本驱动变量）：①晶圆代工产能松紧 / 价格（成本端）；②出口管制（先进制程获取，影响小）；③国产替代补贴 + 信创 / 车规政策（需求端强驱动）。验证点：季度毛利率、车规营收占比。证伪信号：毛利率跌破 25%、价格战加剧。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：模拟芯片国产化率 <15%，份额极低、国产替代空间巨大。
  • 需求侧：进入 Meta / 比亚迪 / 联想 / 吉利等供应链，认证壁垒高（粘性）。
  • 技术代际：车规 + AI 电源处国产第一梯队。
  • 成本曲线：规模 + 研发效率优化，左移。
  • 份额加速度：国产替代加速期。
    → 三档：保守营收 15 亿 / 中性 20 亿 / 乐观 26 亿（2029E）。
  • 层2 扩展业务：主业迁移空间：从"消费电子模拟"向"汽车电子 + AI 云端 / 终端电源"迁移，能力同源（模拟 / 电源管理）；新 TAM（车规 + AI）弹性极大。信号验证：车规批量出货、高低边开关车企定点、AI POL 批量供货。部分已过验证点，可计入中性增量。
  • 层3 风险折扣（证伪信号）：消费电子需求持续承压、价格战、车规 / AI 放量不及预期 → 下调。

  • 校正1 资产质量折扣：PB 3.65x，净资产 15.56 亿为正、Fabless 轻资产，无破净；资产质量扎实（现金充裕），非伪空间。

第五步：综合赔率判断（买不买？）

当前价格位置：合理、略偏低。现价 13.17 元对应 2029 中性 18.7 元有 +42% 空间，市场已定价减亏但中线成长未充分透支。

安全边际：
- 中性远期 18.7 元 → 空间 +42.0%，未达"重点关注" >50% 门槛
- 悲观 6.9 元 → 下行 −47.6%（消费 / 车规不及预期）
- 乐观 36.2 元 → +175%（需车规 + AI 爆发）
- 下行保护：PB 3.65x、净资产 15.56 亿、资产负债率 36.4%、现金充裕

介入条件：
1. 现价 13.17 元已具性价比，可分批；破 11 元（PS <4.5x）加仓
2. 加仓信号：单季扭亏兑现、车规营收占比跳升、AI POL 规模化、诚芯微协同超预期
3. 观察指标：季度毛利率维持 28%+、经营现金流转正、研发费率优化

最大风险：①消费电子总量承压；②模拟芯片价格战；③车规 / AI 放量不及预期；④商誉 / 并购整合（诚芯微）。

亏损股三问：
1. 为什么亏：消费电子承压 + 高研发投入（占 19%）+ 并购整合 + 价格竞争；2025 营收高增但净利率 −15%，规模效应未显。
2. 靠什么扭亏、时点：营收规模扩大（AF/OIS 放量 + 诚芯微并表）+ 费用管控（研发 / 管理同比降）+ 车规 / AI 云端批量出货提升毛利；预计 2027 年扭亏。
3. 亏得起吗：净资产 15.56 亿、资产负债率 36.4%、现金充裕（上市募资 + 定增），经营现金流 H1 −858 万但改善，完全可支撑至扭亏，无退市风险（PB 为正、未分配利润为负但非资不抵债）。

结论：纳入观察

模拟芯片国产替代核心标的，减亏趋势明确（H1 减亏 32%）、端云车三线放量逻辑清晰，中性 +42% 空间且估值未透支；但盈利兑现待验证，等单季扭亏或破 11 元加仓。
