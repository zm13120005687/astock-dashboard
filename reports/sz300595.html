（3）产业链传导

上游：OK 镜原材料（高透氧硅水凝胶等，部分进口）、生产设备——成本占比低、供给稳定，公司转嫁能力强于成本端。下游：公立/民营眼科机构及终端消费者。当前政策强力压制终端价（集采/零加价），公司向下游转嫁系数低（≈0.2），毛利被政策直接压缩。议价权：对上游强、对下游（政策）弱。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（转嫁系数）：OK 镜原材料成本占售价极低（毛利 80%），但政策（集采/零加价）直接压终端零售价，公司无法转嫁、只能被动接受——转嫁系数 ≈ 0.2（仅能通过高透氧新材料微量提价对冲）。验证点：单季 OK 镜出厂/终端价；证伪：集采扩围致 OK 镜毛利率破 75%。

  • 因子2 毛利结构再平衡：OK 镜（~80% 毛利）占比由历史更高降至 37%，医疗服务（~50% 毛利）升至 22%、护理（~60%）12%。OK 镜占比下降 + 其自身毛利下滑 → 综合毛利承压（已由 ~73% 降至 69.55%）。若医疗服务占比持续提升，可部分对冲，但医疗服务毛利低于 OK 镜，结构再平衡整体拉低中枢。

  • 因子3 库存与采购节奏（timing）：医疗器械库存低、无囤货收益问题；但视光服务扩张（诊所）带来前期装修/设备投入，短期折旧压制利润（非库存问题，属 CapEx 节奏）。

  • 因子4 政策/市场锚点（原料成本驱动变量）：

  • 集采（强压价）：2026 多省纳入，情景：全面集采 → OK 镜出厂价 −15% → 净利 −20%+；验证点：各省集采中标公告。
  • 零加价/技耗分离：公立医院禁加价，倒逼公司转向"技术服务费"模式（价减量增）；验证点：公立渠道出货量 vs 民营诊所。
  • 阿托品/离焦软镜竞争：替代性竞品（政策未集采但限制推广）抢份额；验证点：竞品市占。
  • 正向锚：下沉市场渗透率 <3%（量增空间）、青少年近视率 >53%（刚需）。

本因子输出喂给第四步毛利率假设：中性取综合毛利率 67–69%（OK 镜缓降+服务占比升），悲观取 63%（集采扩围）。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 市场容量 × 份额变量（OK 镜 55.6 亿市场）：
  • 供给侧份额：欧普为国产 OK 镜市占第一（梦戴维），进口 Euclid/CRT/Alpha 等竞争；国产替代趋势下份额有望稳中略升。
  • 需求侧/客户份额：签约眼科机构数量为核心壁垒（认证周期长）。
  • 技术代际差：高透氧新材料领先一代，享溢价。
  • 成本曲线：规模化+自产材料使成本左移。
  • 份额二阶导数：OK 镜主业处"集采+竞争"下的 S 曲线平台/微降期（公司 −9.13% 印证）。

  • 三档：保守（份额微降，OK 镜收入 CAGR −5%）/ 中性（−2%）/ 乐观（+3%，验证点：季度 OK 镜收入转正）。

  • 层2 主业迁移空间：能力可迁移性高（眼科渠道同源），新 TAM=阿托品（药品，更大市场）+ 巩膜镜（新适应症）+ 视光服务（服务化）。切入卡位：已有眼科终端网络（强渠道）。信号验证：阿托品尚在临床/审评、未获批；巩膜镜早期——均未过商业化验证点，仅作中期期权。

  • 层3 证伪信号：① OK 镜收入连续两季降幅 >10%；② 综合毛利率破 65%；③ 阿托品临床失败/集采扩至全国；④ 华东大本营政策恶化致区域收入骤降。命中则下修。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。PE 19–21x 对应仍 25%+ 净利率、70% 毛利的优质器械龙头，已从高位大幅回落；但主业确在下滑。

安全边际：中性远期 8.72 元 → −12.6%（中性偏负，因主业仍降）；悲观 5.37 元 → −46.2%；乐观 14.54 元 → +45.7%（需阿托品/巩膜镜兑现）。下行有 PB 1.95x、现金充裕托底，7 元以下（PB<1.4x）为强支撑。

介入条件：① 现价 9.98 元已接近合理，但中性仍负——等 OK 镜收入降幅收窄（单季同比转正）或阿托品/巩膜镜获批里程碑再加仓；② 安全买点：8.5 元以下（PB<1.7x、2026E PE<18x）；③ 观察：季度 OK 镜收入、综合毛利率守住 67%、在研管线审评进度。

最大风险：① 集采从地方试点扩至全国、零加价全面执行致 OK 镜出厂价大跌；② 低浓度阿托品/离焦软镜/功能框架镜竞品分流；③ 高端消费持续疲软；④ 在研管线审评不及预期（期权落空）。

结论：暂不介入（远期中性空间 −12.6% 为负，按规则"负空间一律判暂不介入"，下调自纳入观察；待 OK镜企稳或在研管线获批再评估）

公司是 OK 镜赛道稀缺龙头，盈利质量仍高、估值已回落至历史低位、现金充裕；但核心主业处于政策压制+竞争的红海期，中性远期空间为负。属"低估但需等拐点（OK 镜企稳或在研获批）"的纳入观察品种，不宜追高。

第五步进阶：上行想象力四类

  • A 行业调整剩者红利：集采/零加价洗牌中小品牌，龙头凭渠道+材料自产抢份额、以价换量。验证点：CR5 提升、公司 OK 镜出货份额；证伪：份额流失。
  • B 政策反转期权：若集采节奏放缓或"技耗分离"后技术服务费定价机制明确、民营诊所放量，估值重估。验证点：政策纠偏表态、服务收入占比跳升；证伪：集采全面扩围。
  • C 市场错杀修复：若股价跌至 7 元以下（PB<1.4x）而 OK 镜仅缓降未崩，修复弹性大；验证点：估值分位、基本面未恶化。
  • D 技术突破/代际跃迁：低浓度阿托品获批 + 巩膜镜 + 新一代高透氧 OK 镜从 0 到 1 商业化，重构增长曲线。硬验证点：①阿托品 NMPA 获批；②巩膜镜量产且客户定点；③放量成本优于旧路线。当前仅阿托品在研、未获批，缺硬验证点，仅作机会情景不计入中性。

上调重点关注的触发条件：① OK 镜单季收入同比转正且综合毛利率 ≥68%；② 低浓度阿托品获 NMPA 注册证；③ 任一在研新品营收占比突破 5%。三者满足其一可重估至重点关注。
