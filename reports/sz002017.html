盈亏核实：2026H1 归母净利 +8607 万元（盈利，同比 +6.97%），TTM 非负，非亏损股；高 PE 源于盈利基数小叠加 eSIM 成长预期，而非误标亏损。

第一步：公司是干什么的？

一句话定位：中国电科旗下"数字身份安全"龙头，主业由智能卡（SIM 卡、金融社保卡、数字人民币硬钱包）向 eSIM 远程配置平台、车规级安全模块、量子安全 SIM、AI+可信数字身份等"云-边-端-芯"全栈式可信连接方案升级。

境内外收入占比：海外智能卡业务已拓展至中东、非洲、东南亚，金融产品出货量大幅增长，RSP 平台导入东南亚多国；境内以运营商、社保、金融为主。半年报强调"海外销售额同比增长、结构持续优化"，具体占比未单列但出海权重抬升。

股东背景：实控人中国电子科技集团（央企），参与雄安无线电创新院、政务云等国家级项目，订单稳定性与政策资源行业领先。

（3）产业链传导

上游：安全芯片（国产芯替代，512K 国产芯获 GSMA eSA 认证）、晶圆代工。公司向上游延伸（参股广州晟芯科技，eSIM/量子芯片通过运营商认证），降低对外依赖。

下游：运营商（强议价但长期合作）、银行/政务（高粘性）、车企（车规认证壁垒高）。eSIM 从"卖卡"转向"卖订阅服务费"，收入模式由一次性向持续性迁移。

议价权：境内运营商端中等（集采压价），海外、车规与政务端较强（认证壁垒 + 安全属性），数字人民币硬钱包具先发与牌照优势。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（转嫁系数）：安全芯片占硬件成本主体，国产芯替代使采购成本可控；eSIM 平台服务（软件）边际成本近乎零，毛利率 44.89%，传导率≈1（服务费定价权强）。传统智能卡硬件毛利率 31.88%，受晶圆价格与集采双重挤压，传导率≈0.6。
  • 因子2 毛利结构再平衡：2026H1 数字安全及平台毛利率 44.89% vs 智能卡 31.88%，结构升级使综合毛利率 +1.17pct。按收入权重测算，数字安全占比每升 10pct，综合毛利约 +1.3pct。
  • 因子3 库存与采购节奏：芯片备货受全球半导体周期影响，公司未披露大额套保，以销定产为主，库存损益波动小，无显著囤货收益/接货损失。
  • 因子4 政策/市场锚点：①市场层——全球半导体价格、晶圆代工产能；②政策层——国产芯替代补贴（降成本）、数字人民币推广（托需求）。情景：若国产芯良率提升使智能卡成本降 5%，对应净利弹性约 +800 万。验证点：广州晟芯出货、芯片自给率；证伪：晶圆涨价致智能卡毛利破 30%。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 现有业务（市场容量 × 份额变量）：全球 eSIM 连接设备 20 亿+，公司 RSP 平台接入超 200 万物联网设备（2025 相关收入 +250%）。份额锚点：①供给侧——国产 eSIM 芯片认证领先；②客户份额——移动/电信/联通/邮储全覆盖；③技术代际——国内唯一 GSMA eSIM 双认证 + 全球首个 eIM 认证；④成本曲线——国产芯降本；⑤份额加速度——处于渗透早期。三档：保守守住 5% / 中性小幅提升至 8% / 乐观 12%。验证点：下季度 RSP 订阅设备数、移动订单确认额。
  • 层2 扩展业务（主业迁移空间·新易盛范式）：从"卖卡"迁移至"卖持续服务费"（eSIM 订阅、ES 平台）。能力可迁移（同源安全技术）；新 TAM（全球连接订阅市场数倍于制卡）；切入时点早（eSIM 商用初期）；认证门槛高（GSMA 认证 = 护城河）。信号验证：移动订单、澳门 ES、车载出海。未过全面验证点前仅作中期期权，不计入中性净利。
  • 层3 风险折扣（证伪信号）：eSIM 手机商用推迟、移动订单确认低于预期、智能卡价格战致毛利破 30%、海外拓展不及预期。命中则下调增量。

第四步进阶：重资产/周期股校正三道闸

  • 校正1 资产质量折扣：轻资产（总资产 30.7 亿、净资产 18.2 亿，无重大专用重资产），不适用破净问题；PB 4.5x 反映成长预期而非资产折价。
  • 校正2 周期位置：非强周期，处 eSIM 渗透早周期（上行），中性净利不采用周期归一化。
  • 校正3 杠杆下行：资产负债率约 40%（总资产 30.7 亿、净资产 18.2 亿），无高负债风险，下行主要来自估值压缩（悲观情景已体现）。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 14.20 元对应 2026E PE 约 47x、2029E 中性 PE（按中性目标价 11.0 元反推）约 25x，已充分定价 eSIM 成长故事。

安全边际：中性远期 11.0 元 → 空间 −22.5%；悲观 7.2 元 → −49.3%；乐观 17.4 元 → +22.5%。当前价格缺乏安全边际，下行保护弱。

介入条件：回落至 11 元以下（对应 2029E 中性 PE < 25x、2026E PE < 37x）方具安全边际；加仓信号：①移动 eSIM 订单确认额达中值 2.5 亿+；②数字安全收入占比突破 45%；③eSIM 手机商用正式获批带动订阅放量。

最大风险：①估值压缩（高 PE 成长股杀估值）；②eSIM 手机商用进度不及预期；③智能卡传统业务价格战；④移动订单确认节奏延迟。

结论：暂不介入（中性远期空间 −22.5%，不满足 >0；虽为优质数字身份龙头，但现价已透支中期成长，待回落至 11 元以下或订单超预期再评估）。

第五步进阶：上行想象力情景四类

  • A 行业调整剩者红利：不适用（非出清行业）。
  • B 政策反转期权：eSIM 手机商用试验获批 → 若正式商用，订阅服务市场扩容数倍。验证点：工信部正式商用发文；重估弹性：乐观情景 +22.5%。证伪：商用再推迟。
  • C 市场错杀修复：若因风格切换股价跌至 10 元以下（PE < 35x），具备修复弹性。验证点：估值分位回落至历史 30% 以下。
  • D 技术突破/代际跃迁期权：量子安全 SIM、区块链 BSIM 卡（数字人民币跨境）从 0 到 1 量产。硬验证点：批量订单 + 跨境试点扩大。未过验证点仅作机会情景。

上调至重点关注的条件：eSIM 正式商用 + 数字安全收入占比 >50% + 2029E 净利上修至 3.5 亿+，使中性远期空间 >+50%。
