皖能电力（000543）五步法分析报告

分析日期：2026-09-25 ｜ 现价 7.15 元（2026-09-24 收盘）｜ 总市值 162.08 亿 ｜ PE(TTM) 9.82x ｜ PB(LF) 0.90x（破净）｜ 总股本 22.67 亿股
行业：火电 + 新能源（安徽区域）｜ 实控人：安徽省国资委（皖能集团）
重资产 / 破净 / 周期股专项：资产质量折扣 + 周期位置校正 + 杠杆下行情景三道闸齐备；稳定盈利 + 高现金流，破净偏轻。

第一步：公司是干什么的？

一句话定位：安徽省能源龙头，以火电为压舱石、风电 / 光伏 / 垃圾处理等多元补充，盈利韧性强（2026H1 仍赚 8.25 亿）、经营现金流充沛，当前破净（PB 0.90）主要反映电价市场化下行的预期折让。

（3）产业链传导

上游：动力煤（火电燃料）。煤价 2025 大跌 18% 至 703 元/吨，2026H1 略反弹但仍低位，燃料成本可控。

下游：安徽电网 + 市场交易。需求端稳健，电价随市场温和下行，议价权中（区域龙头）。

议价权：中等（区域垄断 + 容量电价托底），优于粤电力（广东竞争更激烈）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数）：煤电电量电价随市场，但煤价低位 + 容量电价托底，综合 α≈0.5（优于粤电力）。验证点：煤价与毛利率；证伪：煤价涨毛利不降。
  • 因子2 毛利结构再平衡：电力（14.66%，主力）、煤炭贸易（0.56%，低利）、运输（26.24%）、垃圾（80.86%）。高毛利垃圾处理 + 运输占比小；电力对煤价敏感。分业务毛利结构稳定，无双负。验证点：分业务毛利率；证伪：电力毛利跌破 10%。
  • 因子3 库存与采购节奏：长协煤 + 库存调节对冲煤价；2026H1 煤价略反弹形成小幅成本压力。验证点：燃料成本率；证伪：煤价降成本不降。
  • 因子4 政策 / 市场锚点：① 容量电价（政策层，托底）；② 煤价（市场层，低位利好）；③ 安徽交易电价（市场层，温和下行）。情景：煤价低位 + 容量电价 → 盈利稳；煤价大涨 → 恶化。验证点：煤价、容量电费。

输出：第四步净利率假设采用正常化 9%~10%（回归 2025 水平），高于粤电力（因安徽煤价低位 + 盈利结构优）。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（容量 × 份额）：安徽用电需求稳健，公司区域份额稳固。五锚点均中性偏正（区域垄断、成本曲线优、份额稳）。三档：保守（电量 +5%）、中性（+8%）、乐观（+12%）。验证点：上网电量。
  • 层2 主业迁移空间：由火电向新能源迁移（已进行），计入中性但打折。
  • 层3 证伪信号：安徽电价加速下行、煤价大涨、利用小时降。

第四步进阶：重资产 / 周期股校正（三道闸）

  • 校正1 资产质量折扣（破净原因）：PB 0.90 轻度破净，原因是电价市场化下行预期折让；但公司盈利正（2026H1 8.25 亿）、ROE 约 8.9%（年化）、现金流强劲，非资产盈利能力崩溃型破净（区别于绿发 0.76、且与粤电力不同——粤电 2026H1 真实亏损）。无金融资产未重估，但盈利扎实使破净偏"估值折让"而非"价值陷阱"。说明：破净有解释但不构成深度安全边际。
  • 校正2 周期位置校正：当前处于电价下行周期，但煤价低位 + 容量电价托底使盈利仍稳（中性净利 15.6 亿接近 2025 水平）。未用 2026H1 年化、未用高点外推，标注：周期位置 = 温和下行。
  • 校正3 杠杆下行情景：资产负债率（电力重资产）偏高，利率上行 / 电价大降 → 净利降至 11 亿，悲观 −45.7%，已附。

期权纪律：新能源放量、估值修复未过验证点，仅放乐观情景（10.59 元）。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低（破净 + 稳定盈利 + 高现金流）。现价 7.15 元对应 PE 9.82x、PB 0.90；中性远期 6.88 元基本持平（−3.8%），乐观 10.59 元（+48.1%）提供显著上行弹性。破净 + 高股息（盈利稳）使其具备"价值底"。

安全边际：中性远期 6.88 元 → −3.8%（接近持平）；悲观 3.88 元 → −45.7%；乐观 10.59 元 → +48.1%。下行有净资产保护、上行弹性大，风险收益对称偏正。

介入条件：现价 7.15 元已具吸引力，但更优在 6.5 元以下（PB 0.82x、接近悲观与中性之间）；加仓信号：① 安徽交易电价企稳；② 煤价维持低位；③ 单季净利环比回升。当前可"逢低布局"。

最大风险：① 安徽电价市场化加速下行；② 煤价大涨吞噬燃料成本优势；③ 利率上行加重财务负担（重资产）；④ 新能源扩张不及预期。

结论：纳入观察

理由：破净（0.90）+ 稳定正盈利（2026H1 8.25 亿）+ 强劲经营现金流（32.72 亿）+ 容量电价托底，估值已反映悲观预期；中性锚基本持平、乐观锚 +48%，风险收益对称偏正。当前价可逢低关注，待 6.5 元以下或电价企稳加仓。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：电价下行期中小火电出清，皖能区域龙头份额与议价改善。验证点：行业装机增速放缓、交易电价企稳；证伪：价格战持续。
  • B 政策反转期权：容量电价进一步提升 / 煤价低位延续 / 电力现货价格回升。验证点：容量电价加码、煤价低位；重估弹性：乐观净利 20 亿 → 10.59 元。
  • C 市场错杀修复：PB 0.90 低分位，若市场过度担忧电价，估值修复至 1.0~1.1x PB（7.9~8.7 元）弹性大。验证点：盈利稳、分红稳；证伪：盈利下滑。
  • D 技术突破期权：不适用（火电 / 新能源无代际跃迁）。

上调至"重点关注"的条件：煤价维持低位 + 安徽交易电价企稳 + 单季净利环比回升，使 2029 净利站上 20 亿（乐观情景），对应 10.59 元（+48%）并具持续性，届时上调。
