中化装备（600579）五步法分析报告

分析日期：2026-09-09 ｜ 现价 7.26 元（2026-09-09 收盘，腾讯行情核实）｜ 总市值 35.8 亿 ｜ PE(TTM) −21.7x ｜ PB 2.4x ｜ 总股本 约 4.936 亿股（重组发行约 1.96 亿股 + 配套募资发行后约 7.4 亿股）
行业：机械行业（化工装备 + 橡胶机械）｜ 板块：沪市主板
口径定性（重要）：队列"亏损"列经真实财报核实并非误标——2026H1 归母净利 −0.66 亿（上年同期 −0.18 亿），扣非 −0.57 亿，为真实亏损股，按亏损股完整五步法 + 正常化净利润法 + 三问处理。

第一步：公司是干什么的？

一句话定位：中国中化旗下化工装备上市平台（原"克劳斯玛菲股份"，2025 年 1 月更名），剥离海外克劳斯玛菲主业后，以天华院（干燥/化工单元设备）为盈利主体，正推进注入益阳橡机、北化机，重塑为"化工装备 + 橡胶机械"央企装备平台。

主要客户/下游：石油化工、煤化工、新材料/新能源（焙烧、干燥）、"双碳"绿色改造项目、橡胶轮胎企业。央企系统内协同（中国中化体系）是订单重要来源。

境内外收入占比：剥离克劳斯玛菲海外业务后以国内为主；KM 集团为欧洲参股资产。

股东背景/实控人：间接控股股东中国中化（央企），控股股东装备环球。央企背景 = 重组注入与资源协同的核心逻辑，也是偿债信用的支撑。

（3）产业链传导 + 原料成本→毛利结构四因子

  • 因子1 成本传导弹性：原材料为钢材/锻件/标准件，占成本约 70%。装备行业通常"排产定价 + 钢价联动"条款覆盖大单（传导率约 0.7-0.8），但订单签约到交付有 6-12 个月时滞，钢价快速上涨期毛利率先压后补。2026H1 毛利率 19.0%（上年同期 18.1%），钢价温和背景下毛利率稳定。
  • 因子2 毛利结构再平衡：天华院（干燥/余热）毛利率约 25-30%，橡机（硫化机）毛利率约 15-20% 且处亏损整合期，KM 集团权益法拖累净利率约 3-5pct。收入缩量 33% 的同时新签 +18%，意味着未来收入结构中高毛利的天华院新装备（新能源焙烧/新材料干燥/余热回收）占比将上升——毛利结构在改善，只是当期报表还在消化旧订单低交付。
  • 因子3 库存与采购节奏：存货 8.34 亿（较年初 +27.33%，占净资产 55.5%），预付款 +243%——是备产备货而非滞销（在手订单 +19.9% 佐证），存货跌价准备计提 7.33%。验证点 = 后续存货随交付消化、合同负债转化；证伪信号 = 存货继续攀升而收入不回来。
  • 因子4 政策/市场锚点：①石化资本开支节奏（验证点 = 五大央企石化年度资本开支计划、炼化项目开工数）；②设备更新政策专项资金落地（验证点 = 改造项目招标量）；③重组注册批复后的发行实施进度（验证点 = 发行结果公告）；④钢价走势（验证点 = 沪螺价格）。情景：若 2027 年石化资本开支企稳 + 设备更新专项资金放量 → 订单交付节奏回归正常；证伪信号 = 在手订单交付再次延期、合同负债不升反降。

议价权判断：细分市场中等（天华院细分龙头 + 央企系统内协同），但下游央企/大石化集团强势（预付款激增说明要垫资备产，付款条款偏不利）。

层1 市场容量 × 份额变量：
1. 供给侧：干燥装备细分国内竞争格局稳定，天华院居第一梯队，份额锚点 = 新签订单 +35.9% 在行业收入普降背景下的相对优势
2. 客户份额：央企系统内"总对总"协同 + 新能源/新材料新客户签约（验证点 = 季度新签订单公告）
3. 技术代际：新能源焙烧、余热回收属政策鼓励的节能装备，公司卡位早于多数同行（验证点 = 相关订单占比披露）
4. 成本曲线：吸收合并橡机后费用摊薄，交付规模化后单位成本下移
5. 份额二阶导：订单增速（+18.4%）已连续高于收入增速，S 曲线在订单侧先拐
→ 三档：保守 = 在手订单按期交付不再新增（只兑现存量）；中性 = 天华院年新签维持 8-9 亿；乐观 = 石化资本开支回升 + 绿色改造放量，新签跳升。验证点均为季度新签/在手订单数据。

层2 主业迁移空间：从"石化干燥设备"向"新能源/新材料干燥焙烧装备"迁移 = 老技术换新市场，已过信号验证（相关订单大幅增长公告），可计入中性；向橡机绿色化迁移未过验证点，仅作远期期权。

层3 证伪信号：① 在手订单交付再度大面积延期（2026H1 已经发生一次，若复发说明下游资金链问题深化）；② 存货/预付款继续膨胀而合同负债不增；③ 重组发行实施受阻或标的资产业绩不达承诺；④ KM 集团亏损扩大。

自下而上收入推导：2026E 收入 ≈ 在手订单中 2026 年内可交付部分约 9-10 亿（H1 仅 4.38 亿，交付后置主要压在 H2 与 2027）→ 2026E 营收约 9.5-10.5 亿；2027 年重组并表（益阳橡机 + 北化机）叠加订单正常化 → 约 14-16 亿；2029E 稳态约 15-17 亿（产能与订单支撑校验：在手 16.68 亿 + 年新签 8-9 亿可覆盖）。

第四步：估值锚定（自下而上，非增速外推）

方法说明：亏损股，用正常化净利润法：①估稳态营收 → ②取保守正常化净利率 → ③×远期合理 PE。禁用 PE(TTM) 硬套。

总股本：现约 4.936 亿股；重组发行 1.964 亿股（发行价 6.12 元/股）+ 配套募资后约 7.4 亿股——远期每股测算按摊薄后 7.4 亿股计。

亏损三问（亏损股必答）

一问：为什么亏？
1. 下游石化资本开支放缓 → 在手订单排产交付、收入确认延后，收入 −33.5% 但固定成本刚性
2. 中化橡机吸收合并的一次性员工辞退福利、人员安置及离职补偿费用（2026 年按计划计提）
3. 参股 KM 集团（9.24%）权益法分担欧洲主业亏损
→ 三项中第 2 项明确一次性、第 1 项是节奏而非丢单（新签 +18.4% 佐证）、第 3 项外部变量。亏损性质 = 收入空窗 + 一次性重组费用，非主业坏死。

二问：靠什么扭亏，触发时点在哪一年？
1. 在手订单 16.68 亿（≈1.7 倍年化收入）2026H2-2027 集中交付确认 → 收入回补
2. 一次性安置费用 2026 年出清，2027 年起费用基数下降
3. 重组注入益阳橡机 + 北化机 2027 年并表（益神橡机业绩承诺 2026-2029 年：1709 万/1823 万/1792 万/1809 万；北化机分项业绩承诺单独考核）
4. 吸收合并后管理费用摊薄
→ 触发时点：2027 年（收入回补 + 一次性费用出清 + 并表三因素同年共振）。2026 年预计仍亏（H2 收入回补但不足以覆盖全年 H1 缺口与一次性费用）。

三问：亏得起吗？
- 净资产 15.04 亿（2026H1 末），资产负债率 61.1%；货币资金较年初 −35.4%，经营现金流 −0.79 亿（同比多流出 0.37 亿）
- 流动比率 1.3、速动比率 0.9；短期借款较年初 −48.7%（在压降有息负债）
- 配套募资 3 亿元 100% 用于补充流动资金/偿债
→ 判断：能撑到扭亏，但现金偏紧（货币资金约 2 亿量级），安全垫依赖两条：央企母公司信用 + 重组配套募资落地。若重组实施延迟超过一年，流动性压力将显著上升。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。PB 2.4x + 亏损状态 + 中性正常化每股价值 3.55 元，现价透支重组与扭亏预期。

安全边际：
- 中性远期 3.55 元 → 空间 −51.1%
- 悲观情景 1.42 元 → 下行 −80.4%
- 乐观情景 6.49 元 → 仍 −10.6%
- 下行保护：仅央企信用 + 净资产 15 亿（PB 2.4x 已无资产托底意义）；扭亏路径存在但价格已预支

上行想象力情景（四类，均不进中性锚）：
- A 行业调整剩者红利：石化装备行业出清后，央企平台（天华院 + 注入的益阳橡机/北化机）份额与定价权提升。验证点 = 重组完成后合并口径新签订单、行业集中度；证伪 = 出清后订单仍不增长。
- B 政策反转期权：石化化工稳增长方案加码 + 大规模设备更新专项资金放量 → 下游资本开支反转，订单弹性大（装备是后周期弹性最大的环节）。验证点 = 央企石化资本开支计划上调、招标量回升；证伪 = 资本开支继续收缩。
- C 市场错杀修复：不成立——当前是溢价而非错杀（PB 2.4x 在亏损装备股中显著偏贵），本类情景不适用。
- D 重组/注入期权（本股最大的看涨叙事）：益阳橡机 + 北化机注入已获证监会注册批复，属确定性较高事件；但并表后的实际盈利贡献未过验证点（业绩承诺仅覆盖益神橡机 1700-1800 万/年量级），且重组摊薄 40% 股本。硬验证点 = 发行实施完成 + 2027 年并表后利润兑现；证伪 = 实施延迟、标的业绩不达承诺触发补偿。

什么条件出现才上调：① 重组发行实施完成且 2027 年中报并表后归母净利转正≥0.5 亿；② 天华院在手订单交付节奏恢复正常且新签继续 +20% 以上；③ 股价回落至 4 元以下（对应中性正常化价值的安全边际打开）——三者至少满足前两条再重估。

介入条件：现价无介入价值。观察价位 4.0 元以下（≈中性正常化价值的 1.1 倍、PB 约 1.3x）且重组实施落地。

最大风险（最可能破坏逻辑的因素）：
1. 高估值 + 亏损的双重脆弱性：任何交付延期、重组波折都会引发估值与业绩双杀（悲观情景 −80%）
2. 在手订单交付节奏已延后一次（2026H1 收入 −33.5%），下游石化客户付款与项目进度不可控
3. KM 集团权益法亏损是外部不可控变量（欧洲制造业疲软短期难反转）
4. 货币资金趋紧，若重组配套募资延迟，流动性承压
5. 重组摊薄：总股本从 4.94 亿增至约 7.4 亿股，每股价值被稀释

结论：暂不介入

理由：真实亏损股（非 TTM 误标），扭亏路径清晰（订单 + 重组 + 一次性费用出清，触发点 2027 年），央企背景保证"死不了"；但现价 PB 2.4x 已透支扭亏后的中性盈利，三档情景远期空间全为负（−10.6% 至 −80.4%），赔率极差。属于"好事件、坏价格"——等重组实施落地 + 股价大幅回落后的错杀机会。
