第一步：公司是干什么的？

一句话定位：国内化学合成多肽龙头（深圳），深耕多肽 28 年，核心业务为 GLP-1 等多肽原料药全球供应+制剂国际化+小核酸/CRDMO，是 GLP-1"卖铲人"。

核心产品：GLP-1 原料药（利拉鲁肽、司美格鲁肽、替尔泊肽）、醋酸格拉替雷、多肽注射剂；在研 HY3003 三靶点减重创新药。

主要客户/下游：全球仿制药企（美国/欧洲/南美/中东等 90+ 国家）、规范市场制剂客户；与土耳其 MCG Pharma 签授权。

股东背景：民营控股，多肽技术平台型公司。

（3）产业链传导

上游：氨基酸、保护氨基酸、树脂等多肽合成原料。规模化合成技术降本（公司专有技术），成本随产能爬坡下降。
下游：全球仿制药企+规范市场制剂。需求由 GLP-1 终端爆发驱动，公司处"卖铲人"卡位。
议价权：强（全球规范市场通行证 20 美 DMF+4 欧 DMF+6 CEP+14 中 DMF，高壁垒稀缺）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：多肽合成原料占成本比高，但公司凭规模化+专有技术具 转嫁系数≈0.7（成本上涨可部分转嫁至原料药客户）；规范市场客户对质量敏感度>价格，溢价能力强。验证点：原料药毛利率 67.45% 高位。
  • 因子2 毛利结构再平衡：原料药（67% 毛利、79% 收入）主导，制剂（待放量）、客户肽（高增）为辅。若未来原料药竞争致毛利降，制剂出海（格拉替雷、利拉鲁肽、替尔泊肽）可补结构。禁以单一综合毛利代表。
  • 因子3 库存与采购节奏：武汉基地"边建边售"满产，无显著低价囤货收益；产能爬坡期单位成本下行是真实规模效应。
  • 因子4 政策/市场锚点：① 司美/替尔泊专利到期节奏（市场层=需求释放）；② 美国 FDA 审批（政策层）；③ 全球多肽产能扩张致价格战（风险变量）。验证点：专利到期日、FDA 批件、行业新增产能。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：
  • 供给侧：全球多肽 API 产能扩张中，公司凭 cGMP 认证处第一梯队；
  • 需求侧：礼来/诺和供应商体系，客户黏性强；
  • 技术代际：化学合成多肽国内领先，代际不落后；
  • 成本曲线：规模化+专有技术处左侧；
  • 份额加速度：GLP-1 仿制药渗透早期，份额快速提升。
    → 三档：保守/中性/乐观（按 API 渗透率）。
  • 层2 扩展业务（主业迁移空间）：从"卖原料"向"原料+制剂协同出海"迁移（新 TAM=全球规范制剂市场数倍于 API）。能力可迁移（合成同源），卡位已建（FDA 批件），信号验证中（格拉替雷发美）。部分过验证点，但放量未完全确认，仅部分计入中性。
  • 层3 风险折扣（证伪信号）：行业产能过剩价格战、FDA 审批延迟、大客户流失。命中则下调。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（已透支）。23.59 元 PB 24.44x、2026E PE 41.6x，市场按高成长定价，容错率低。

安全边际：中性远期 23.78 元 → 空间 +0.8%，未达重点关注门槛；悲观 7.47 元 → 下行 −68.3%（高估值下杀弹性大）；乐观 47.56 元（+101.5%，需替尔泊肽期权兑现）。

介入条件：① 回落至 18–19 元以下（2026E PE<40x、PB<20x）；② 加仓信号=替尔泊肽 ANDA 获批、格拉替雷/利拉鲁肽美国销售数据超预期、原料药新增大额订单。

最大风险：① 全球多肽产能 2027+ 过剩致价格战、毛利率崩；② 估值高、任何不及预期即戴维斯双杀；③ FDA/海外审批延迟；④ 大客户集中与订单波动。

结论：纳入观察（赛道优秀、业绩高增，但估值已充分，待回调或放量确认后介入）。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：GLP-1 仿制药爆发后，规范市场"卖铲人"集中度提升，公司凭 cGMP 通行证剩者红利。验证点：行业 CR+公司份额。
  • B 政策反转期权：国内 GLP-1 减重适应症审批提速+医保覆盖扩围。验证点：司美减重国内获批、医保纳入。
  • C 市场错杀修复：若板块系统性回调但基本面未恶化，估值分位回归。验证点：估值分位。
  • D 技术突破/代际跃迁期权：替尔泊肽 ANDA 首仿从 0 到 1 投产（全球尚无仿制药上市），重构增长曲线。三要素共振：① 政策=专利到期；② 趋势=GLP-1 需求爆发；③ 落地=FDA 受理+首仿资格+武汉产能。硬验证点：ANDA 获批+客户定点+量产成本优于旧路线。未获批前不计入中性。

上调至"重点关注"的条件：替尔泊肽 ANDA 获批且美国销售兑现，使 2029 净利达 10 亿+，或价格回落至 18 元以下提供安全边际。
