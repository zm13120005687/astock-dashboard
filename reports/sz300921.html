第一步：公司是干什么的？

一句话定位：国内"云 + 网 + 安全"一体化数字基础设施服务商，主要为世界 500 强、央国企等大中型企业提供 SD-WAN、SASE、MDR（托管检测与响应）及边缘算力服务。

核心产品 / 服务：自研 SD-WAN / SASE 融合管理平台、MDR 安全运营（SOC / NOC 双中心 7×24）、边缘计算（凌云边缘将算力部署于全球 SASE POP 节点）、企业级 CPU / GPU 算力租赁、数字化工程集成。

主要客户 / 下游：世界 500 强、央国企、金融、制造、新能源；已获中国航天、中国航空、中国物流、国家电网、中国船舶等国央企，以及智能汽车、生物医药、无人机、半导体等高端制造业客户验证。

技术壁垒 / 股东背景：自研 SD-WAN / SASE 在网月租占比 >60%、客户数占比 >65%（已超海外品牌总和）；拥有跨地区因特网虚拟专用网（VPN）牌照（全国首批仅两家）；SD-WAN 全栈国产化、国密二级认证、全线支持 IPv6；连续五年研发投入超 5000 万、营收占比 >9%；实控人为董事长陈树林团队。

（3）产业链传导

上游：带宽 / 机房 / 光纤租赁 + 工程师人力。带宽结算价为运营商定价，人力成本（工程师薪酬）为最大成本项且刚性。下游为企事业客户，需求受企业数字化转型、信创、数据安全驱动。

议价权：对运营商带宽——中等偏弱（结算价被动接受）；对客户——中等偏强（自主可控 + 国央企黏性 + 全栈国产替代稀缺性），但人力成本无法转嫁，毛利率提升主要靠高毛利凌云服务占比上升而非涨价。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（转嫁系数）：带宽成本传导系数约 0.4（部分年度长协锁定、难即时转嫁）；人力成本传导系数约 0.2（工程师薪酬上涨几乎无法转嫁）。综合实际毛利承压，靠业务结构优化对冲。
  • 因子2 毛利结构再平衡：凌云 42.13% ＞ 凌网 34.56% ＞ 数字化工程 16.25%。凌云占比由 2025 年约 26% 升至 28%，是综合毛利提升主因；数字化工程占比 8% 但毛利仅 16%，若其扩张将拖累结构——禁止用单一综合毛利率 35% 代表全结构。
  • 因子3 库存与采购节奏：轻资产模式，无原料库存；带宽多为年度长协平滑波动；人力为当期费用，无囤货收益 / 接货损失问题。
  • 因子4 政策 / 市场锚点（成本驱动变量）：①市场层——一线城市机房 / 带宽结算价、工程师薪酬通胀；②政策层——信创国产化（利好自研替代外资、降本）、数据安全法规（推 MDR 需求）、算力互联互通节点（新增需求）。验证点：公司是否正式中标 / 参与区域或行业节点、自研月租占比是否持续 >60%；证伪：自研占比回落、节点落空、人力成本失控致综合毛利破 30%。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：跨地区 VPN 牌照全国首批仅两家，稀缺度高；
  • 客户份额：央国企自主可控需求，已进航天 / 航空 / 电网等核心供应链；
  • 技术代际差：SD-WAN 全栈国产替代，领先外资依赖路线；
  • 成本曲线：规模效应 + 自研降本；
  • 份额二阶导数：月租占比破 60%，仍在加速渗透。
    三档：保守守住（维持 60%）/ 中性小幅提升至 65% / 乐观抢份额至 70%+。
  • 层2 扩展业务：主业迁移空间（云网安 → 算力网络 + 安全运营）：能力可迁移（SD-WAN / SASE 同源）、新 TAM = 算力调度 + AI 安全、切入早（算力互联互通政策风口）、认证门槛高（VPN 牌照 + 国央企资质）。未过验证点（正式节点中标 / 大客户算力调度落地）仅作中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：自研月租占比回落、算力节点未参与、人力成本失控致综合毛利破 30%、大客户流失。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。PE(TTM) 118x，中性远期目标 11.70 元低于现价 27%，估值已透支未来 3 年主业稳态盈利。

安全边际：负安全边际。中性远期空间 −27%，悲观情景 −60%；仅乐观情景（需节点中标）才转正。账面支撑弱（PB 5.0x，净资产 8.25 亿，市值 41 亿）。

介入条件：① 回落至 11 元以下（对应 2029 中性 PE 40x 打折）具安全边际；② 算力互联互通节点正式中标 / 大客户算力调度合同落地（重估触发，上调至纳入观察 / 重点关注）；③ 自研月租占比持续 >65% 且综合毛利守稳 35%。

最大风险：① 估值回归（PE 从 118x 向 40x 收敛）；② 人力成本刚性上涨吞噬毛利；③ 算力互联互通节点落空，期权证伪；④ 增长证伪（H1 高增长源于低基数）。

结论：暂不介入（估值已高、中性空间为负，待估值回归或节点落地再评估）。

第五步进阶：上行想象力四类情景

  • A 行业出清剩者红利：网安 / SD-WAN 行业洗牌，公司凭全栈国产 + VPN 牌照稀缺性成为剩者，份额由 60% 提至 70%+。验证点：外资份额持续流失、公司在网月租占比跳升；证伪：自研占比回落。
  • B 政策反转期权：信创 / 算力互联互通政策加码，公司获区域或行业节点运营主体资格。验证点：正式中标公告；重估弹性：乐观情景 21 元（+31%）。未过验证点仅作机会情景。
  • C 市场错杀修复：若 AI / 算力板块系统性回调错杀（估值分位回撤），公司作为真国产替代标的修复。验证点：板块企稳、基本面未恶化。
  • D 技术突破 / 代际跃迁期权：算力调度平台 + AI 安全从 0 到 1 投产，重构增长曲线。三要素：政策（算力互联互通）+ 趋势（AI 支出 +47%）+ 落地（节点中标 + 客户定点 + 调度成本优于旧路线）。硬验证点缺一则只作机会情景。触发上调重点关注条件：算力节点正式中标且算力调度收入兑现。
