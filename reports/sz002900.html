（3）产业链传导

上游：原料药（API）与药用辅料、玻璃瓶 / 胶塞 / 输液袋等包材、能源。公司具备"原料 + 制剂"一体化布局（2.08% 收入来自自产原料药），对 API 涨价具备部分内部对冲；但能源与人工属刚性成本，公司自述"人工薪酬、设备折旧等固定成本刚性较强"。

下游：公立医疗机构（集采执行主体）、基层医疗、零售药店。需求总量稳定（输液与慢病用药刚需），但支付端由医保主导、价格由集采决定，公司几乎无定价权。

议价权判断：弱。佐证：① 2025 年营收 −30% 而销量并未同步下滑，说明是单价被打崩；② 期间费用率 53.76% 远高于毛利率 37.65%，成本刚性 + 售价下行形成"剪刀差"；③ 渠道为公立医院，集采中选价即为结算价，公司只能被动接受。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1｜成本传导弹性（pass-through，量化转嫁系数）
哈三联的成本端主要是原料药、包材、能源与人工折旧，其中只有原料药与包材属可变成本（约占营业成本 55–60%），人工 + 折旧约占 25–30% 且刚性。对集采品种，价格由医保集采锁定，传导率 ≈ 0（上游变动 100% 由公司自行承担）；对非集采品种（固体制剂、部分注射剂），公司有一定自主定价空间，传导率约 0.4–0.6。加权后综合传导率约 0.25。
→ 含义：若上游原料成本上行 10%，公司实际毛利率承压约 0.10 × 营业成本占收入比重（62.3%）≈ 0.75pct 毛利率。这就是 2025 年毛利率从 51.21% 塌到 37.73% 的机制之一（叠加集采降价）。
验证点：原料药采购价指数（API 价格指数）、包材（玻璃 / 胶塞）价格。
证伪信号：若原料成本下行 10% 而毛利率未改善 ≥0.5pct，说明传导机制失效、降价压力更强。

验证点：固体制剂 + 小容量注射剂合计收入占比逐季变化、米氮平片 / 罗沙司他销量。

因子 3｜库存与采购节奏（timing）
2025 年公司集中计提存货跌价 3916 万元（核心导火索为注射用炎琥宁被要求加"黑框警示"后滞销），属高价接货 + 政策突变型损失。2026H1 反向操作：销售前期已计提跌价的存货并转销对应跌价准备，叠加部分产品售价回升转回跌价准备，合计影响约 850 万元，资产减值损失同比减少约 1950 万元。
→ 关键判断：2026H1 减亏中的减值转回部分属于"一次性 timing 收益"，不可外推为持续盈利能力。剥掉该项，公司经营性亏损收窄幅度将从 −52% 降至约 −30%。

因子 4｜政策 / 市场锚点（原料成本驱动变量）
- 市场层：API 与包材价格随石化 / 农产品周期波动，2026 年整体平稳偏弱，对成本端略偏正面。
- 政策层：① 集采"反内卷"新规（价差锚点由最低价改为入围均价的 50%）→ 直接抬高最低中标价，是公司大输液毛利率修复的最重要政策变量；② 未过评未中选药品"红黄标"预警 → 挤压非集采品种价格空间，负面；③ 大输液最小制剂单位挂网价 ≤ 2 元可豁免红黄标 → 对大输液小幅正面；④ 环保 / 能耗双控 → 抬升原料药与包材成本，负面但幅度可控。
- 情景假设：乐观（大输液续标价企稳、毛利率回到 15–20%，固体制剂占比升至 25%）／中性（大输液毛利率 12–15%，固体制剂占比 20–22%）／悲观（大输液毛利率维持 8–10%，非集采品种继续降价）。
- 每个假设的验证点：各省集采续标中选价格公告、公司季度毛利率拆分、固体制剂收入占比。

第三步进阶：份额变量与主业迁移空间（三层法）

层 1｜现有业务：市场容量 × 份额变量
- ① 供给侧份额：大输液行业总产能过剩，公司产能利用率未披露；2025 年收入 −31.93% 说明份额与价格双降。保守（守住东北基本盘）／中性（东北份额维持、华东华南小幅提升）／乐观（凭一体化成本优势抢占区域集采份额）。
- ② 需求侧 / 客户份额：公立医院覆盖率东北 >90%，属"存量守成"；米氮平片 37.07% 份额是其唯一具备提价话语权的品种。
- ③ 技术代际差：化药仿制药无代际领先，属同质化竞争，落后风险不适用但溢价也不存在。
- ④ 成本曲线位置：自有原料药 + 规模化制剂产线，成本曲线中位偏左，但固定成本刚性导致开工不足时单位成本上升。
- ⑤ 份额二阶导：大输液份额已饱和（S 曲线平台期），固体制剂份额仍在爬坡（罗沙司他 / 非奈利酮新上市）。
→ 三档验证点：季度分部收入占比、米氮平片销量、集采续标中选区域数量。

层 2｜扩展业务：主业迁移空间（新易盛范式的可迁移性检验）
- 能力可迁移性：中等。大输液的 GMP 生产、无菌灌装能力可迁移至小容量注射剂、冻干粉针；但不具备创新药 / 生物药的研发能力迁移（2025 年研发投入 1.33 亿，仅取得罗沙司他胶囊等 4 项生产批件，均为仿制 / 改良）。
- 新 TAM 弹性：小。动保、大健康、原料药均为百元级细分市场，即便做到 1 亿元收入量级也不改变公司整体利润形状。
- 切入时点与卡位：动保 / 生物制造属后进者，无先发红利。
- 客户认证门槛：医院与药店渠道已建立，迁移成本低，但也意味着没有新客户增量。

→ 结论：主业迁移空间不成立，全额作为中期期权，不计入中性情景。

亏损三问（RULES 第四节强制）

一问：为什么亏？
三层原因叠加：① 价格被打崩——集采常态化 + 非集采制剂内卷，2025 年大输液毛利率由约 33% 塌至 8.49%，2025 年营收 −30% 至 7.89 亿；② 固定成本刚性——人工薪酬、设备折旧不随售价下降，2026H1 期间费用率高达 53.76%，毛利（37.65%）无法覆盖期间费用，这是"报告期净利润为负值的直接原因"（公司业绩预告原文）；③ 一次性洗表——2025 年集中计提存货跌价 3916 万元、往来单位信用减值 2462.60 万元、石四药公允价值损失 1131 万元，把历史包袱一次性出清。

二问：靠什么扭亏，触发时点？
四条路径，按确定性排序：
1. 结构切换（核心）：固体制剂（毛利率 74.99%）+ 小容量注射剂（65.45%）合计占比由 33.0% 提升至 45% 以上，加权毛利即可覆盖期间费用。触发时点：2027 年（需固体制剂收入由 0.76 亿 / 半年增至 1.5 亿 / 半年）。
2. 大输液毛利率修复：集采"反内卷"新规（价差锚点由最低价改为入围均价 50%）+ 价格企稳，毛利率由 8.49% 回到 15% 以上。触发时点：2026H2–2027 年续标窗口。
3. 费用台阶已兑现：销售 / 管理费用分别 −13.48% / −16.96%，营业总成本同比减少近 1000 万元——已发生，但不可再压缩第二次。
4. 动保 / 大健康扭亏 + 敷尔佳权益法收益：年化约 0.20–0.25 亿元的稳定正贡献。触发时点：2027–2028 年。

三问：亏得起吗？
亏得起。 佐证：① 归母净资产 17.29 亿元（每股 5.46 元），2025 年巨亏 3.40 亿后净资产仅从 21.64 亿降至 17.75 亿，缓冲垫仍厚；② 资产负债率 45.93%，无重大刚性有息债务披露；③ 2026H1 经营活动现金流 +6862.8 万元（同比 +56.38%），已转正——现金流比利润表更早改善，说明"失血"正在止住；④ 流动比率 0.72、速动比率 0.49 偏紧，但账上有可调配资产（敷尔佳 4.5% 股权、石四药持股）。
→ 结论：不存在倒在黎明前的生存风险，但净资产回报仍为负（2026H1 加权 ROE −2.52%）。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1｜资产质量折扣（PB 2.37x，非破净，但需反向校正"资产虚高"）
公司并非破净，而是高 PB：现价 12.97 元对应 PB 2.37x，而 2026H1 加权 ROE 为 −2.52%。按 RULES"资产盈利能力差 → 破净是公允定价"的镜像逻辑，低 ROE 支撑不起高 PB，2.37x 属估值溢价而非资产折价保护。
资产端须扣除：① 商誉 839.85 万元（占比极小，无减值风险）；② 存货（周转天数 164 天，2025 年已计提跌价 3916 万元，存在进一步减值可能）；③ 应收账款（2025 年已全额计提某往来单位信用减值 2462.60 万元，账期 35 天尚可）。
→ 结论：不含"未重估金融资产型破净"的安全边际逻辑，PB 2.37x 无法作为下行保护，仅每股净资产 5.46 元可作为软性参考底（对应 −57.9%）。

校正 2｜周期位置校正
化药制剂属政策周期而非景气周期：2023–2025 为集采冲击的深度下行，2025 年年报是业绩底（大额减值 + 最大降幅），2026H1 为"减亏但未扭亏"的筑底期。当前周期位置：底部区域的右侧起点，但尚未进入上行。
→ 中性净利不得使用 2025 年"单年好年景"（本就是巨亏），也不得把 2026Q2 的单季减亏年化（Q2 毛利率环比 −6.92pct，环比转差），更不得用近三年均值（含 2025 年 −3.40 亿的极端值）。本报告采用分部稳态收入 × 历史最好年份净利率（向下取整）的归一化方法，符合规则。

校正 3｜杠杆下行情景
资产负债率 45.93%，流动比率 0.72、速动比率 0.49 —— 短期偿债指标偏紧。若 2027 年集采续标价再降 10% 且固体制剂放量不及预期：
- 悲观情景 2029E 正常化净利 0.70 亿，PE 20x → 14.0 亿元市值 → 4.43 元（−65.8%），即净资产 PB 降至 0.81x
- 该负面情景下空间为负 → 依规则不得标注"大空间 / 重点关注"，本报告结论为"暂不介入"，符合约束。

期权纪律：敷尔佳 4.5% 股权处置（预计一次性 3.6–4.5 亿元）、动保 / 大健康扭亏，均未过验证点（无处置公告、无扭亏公告），不计入中性净利与中性 NAV，仅列入乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。 现价 12.97 元对应 PB 2.37x、PE(TTM) −14.08x。中性远期（2029E）目标价 7.21 元，较现价低 44.4%；即便乐观情景（含敷尔佳股权处置一次性收益）也仅 15.43 元（+19.0%）。市场当前定价隐含的是"快速扭亏 + 大输液毛利率大幅修复 + 敷尔佳股权高位处置"三重乐观假设同时成立。

安全边际：不足。
- 中性远期 7.21 元 → 空间 −44.4%，为负
- 悲观 4.43 元 → −65.8%
- 乐观 15.43 元 → +19.0%（且依赖一次性处置收益）
- 下行保护：每股净资产 5.46 元（PB 1.0x）为理论软底；经营现金流已转正（H1 +6862.8 万元）说明"失血"止住，但止住失血 ≠ 创造利润
- 上行天花板：2023 年净利高点 0.74 亿、2024 年 0.59 亿——公司近五年最好年份的净利也不足 0.75 亿元，对应 24x 也仅 17.8 亿元市值（5.63 元 / 股）。这是最残酷的一条：现价 41 亿市值需要公司盈利能力超越历史最好水平 50% 以上才能自洽。

介入条件：
1. 价格：回落至 6.5 元以下（对应 PB 1.19x、中性正常化 PE 21x）方具安全边际
2. 信号加仓：① 单季归母净利转正（连续两个季度）；② 大输液毛利率站上 18%；③ 固体制剂 + 小容量注射剂合计收入占比突破 40%；④ 敷尔佳股权处置公告落地（一次性收益确认）
3. 观察指标：季度扣非净利（剔除补助与减值转回的一次性扰动）、动保板块盈亏平衡进度

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 一次性因素被误读为趋势（首要）：2026H1 减亏 52% 中，政府补助贡献 1000 余万元、减值转回贡献约 1950 万元，剥掉后经营性改善仅约 −30%。若投资者把"减亏"当"扭亏"，将严重高估修复斜率。
2. 集采续标价继续下探：第十一批虽提出"反内卷"（价差锚点由最低价改为入围均价 50%），但执行效果待验证；大输液仍有单独的地方联盟集采风险。
3. 石四药集团公允价值持续放血：已连续三年亏损（1463 万 / 1131 万 / 1005 万元），持仓约 1430 万股，若继续下跌将持续侵蚀利润。
4. 治理与内控瑕疵：2025 年因关联方资金划转未履行程序被黑龙江证监局警示，家族控制 56.7%，中小股东保护存在不确定性。
5. 流动比率 0.72 偏低：短期偿债依赖经营现金流与资产处置，若集采继续压制将面临再融资压力。

第五步进阶：上行想象力情景（四类，仅进乐观 / 机会栏）

类型 A｜行业调整剩者红利
大输液行业在集采与环保压力下持续出清，区域性中小厂退出。哈三联作为东北覆盖率 >90% 的剩者，若区域产能出清至 CR3 >70%，可获得区域定价权修复，大输液毛利率从 8.49% 回到 20% 以上。
- 上行锚定：大输液毛利率 20%（+11.5pct）× 稳态收入 2.80 亿 → 增毛利 0.32 亿元
- 验证点：东北区域输液企业关停公告 / 公司大输液毛利率连续两季 >18%
- 证伪信号：区域新增产能投产、集采续标价再降

类型 B｜政策反转期权
被集采砸到底的仿制药板块，政策纠偏信号已现雏形——第十一批集采首次把 "反内卷" 写入规则，明确不再简单以最低报价为价差锚点（模拟测算 1/4 品种锚点平均上调 34%），并首次设"年采购额 1 亿元"入围门槛为小品种留出成长空间。

- 验证点：2026H2–2027 年续标中选价公告、医保局"反内卷"落地案例
- 证伪信号：续标价继续两位数下降、纠偏仅停留在口头

类型 C｜市场错杀修复
不成立。公司股价并非错杀——PB 2.37x、近五年最好净利不足 0.75 亿元，估值处于历史偏高区间而非低位，无"错杀证据"（估值分位不高、相对行业无折价、基本面确已恶化）。
- 结论：本类型不适用，不予建模。

类型 D｜技术突破 / 技术代际跃迁期权
基本不成立。2025 年研发投入 1.33 亿元，成果为罗沙司他胶囊等 4 项生产批件（仿制 / 改良型），属"仿制跟进"而非"技术代际跃迁"。缺乏自研创新药、无中试良率 / 客户定点 / 量产成本优越于旧路线三项硬验证点的任何一项。
- 唯一可归入本类的线索：2025 年收购的免疫抑制剂原料药（他克莫司等）生物公司，若能形成高壁垒原料药 + 制剂一体化，属能力迁移而非技术突变
- 硬验证点：原料药获批上市 + 对应制剂通过一致性评价 + 毛利贡献 >1000 万元
- 证伪信号：研发投入继续以仿制批件为主、无创新药 IND

什么条件出现才上调至"重点关注"？
需同时满足：① 2027 年归母净利转正且年化 ≥1.5 亿元（意味着盈利超越近五年最好年份一倍）；② 大输液毛利率稳定站上 18%；③ 股价回落至 7 元以下（对应中性正常化 PE ≤ 23x）。当前三者均未出现，不上调。

结论：暂不介入

理由：① 2026H1 真实归母净利 −4419.39 万元，仍处亏损；正常化净利润法给出中性远期（2029E）目标价 7.21 元，较现价 −44.4%，空间为负；② 现价 PB 2.37x 对应 ROE −2.52%，且公司近五年最好年份净利也不足 0.75 亿元，41 亿元市值严重透支；③ 2026H1 减亏质量不高（补助 + 减值转回贡献约 2950 万元），主业尚未真正反转。
公司并非"确无扭亏可能"（经营现金流已转正、负债率 45.93%、净资产 17.29 亿），故不适用"坚决回避"；但也远未到"纳入观察"的性价比门槛。等 2026 年报的毛利率与大输液续标价说话，届时若固体制剂占比与毛利率双双验证，再重新评估。
