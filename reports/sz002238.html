（3）产业链传导

上游：内容版权采购、带宽/传输成本、机顶盒/终端设备。基础业务成本中固定网络折旧 + 内容成本占比高，向下游（用户）传导能力弱（用户流失背景下涨价空间为零，甚至需降价保用户）。

下游：家庭用户（价格敏感、可替代性强，被手机短视频分流）、政企/国企（相对稳定、有预算）。

议价权：对 C 端弱（用户用脚投票，套娃治理进一步削弱收费能力）；对 B 端政企/国企中等偏强（本地牌照垄断 + 国资背书）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

本股"原料"主要表现为内容/带宽采购成本、设备折旧、能源与物业运营成本，而非大宗商品。四因子适配如下：

  • 因子1 成本传导弹性（转嫁系数）：
  • C 端基础业务转嫁系数 ≈ 0（用户流失 + 强监管限价，成本无法转嫁，公司自行吸收）；
  • B 端政企/网安业务转嫁系数 ≈ 0.6–0.8（项目制定价，部分成本可纳入报价）；

  • 商业地产租金转嫁系数 ≈ 1（租约锁定，成本波动由租户间接承担）。
    → 综合转嫁系数偏低，成本上升主要侵蚀 C 端毛利。

  • 因子2 毛利结构再平衡：

  • 基础业务（有线电视/宽带）：毛利率低且持续下滑（整体毛利率 20.50%，同比 −1.36pct），为"失血"板块；
  • 商业地产（物业租赁）：租金属性，毛利率高且稳定，是利润"压舱石"；
  • 政企/网安监管：毛利率中高，政策驱动增量；

  • 视频购物：低毛利、收缩中。
    → 结构再平衡方向：高毛利地产/政企占比被动提升，但低毛利基础业务体量仍过半，加权毛利率难系统性改善。

  • 因子3 库存与采购节奏（timing）：

  • 网络设备的集中采购（如一体化电视适配器、超高清设备）属资本开支前置，短期抬高折旧、压制利润；
  • 内容版权多为年框采购，无显著囤货收益/损失；

  • 无大宗原料库存波动问题。

  • 因子4 政策/市场锚点（成本驱动变量）：

  • 正向：超高清设备国产采购价同比 −40%、一体化电视推广带来一次性设备/服务增量（政策托底）；
  • 负向："套娃"收费治理常态化（压减收费包、取消开机广告）直接削减 C 端 ARPU，等同于"监管性降本收入"；
  • 验证点：2026-10-01 后运营服务管理规定落地细则、深圳本地一体化电视推广节奏；
  • 证伪信号：用户流失未遏制、ARPU 继续下滑、设备增量未转化为收入。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：深圳本地有线网络具区域牌照垄断，份额近 100%（本地无竞争），但总盘（用户数）在收缩——份额守得住、总量在掉；
  • 需求侧：家庭用户份额被 IPTV/OTT/手机短视频持续蚕食，C 端份额变量为负；
  • 技术代际：超高清/一体化电视为"防守性升级"，非领先代际；
  • 成本曲线：本地网络规模效应递减（用户越少单位成本越高）；

  • 二阶导数：C 端处于 S 曲线下行段，B 端/网安处于上行初期。
    → 中性假设：C 端年降 5–8%、B 端/地产年增 3–5%，总量缓慢下滑。

  • 层2 扩展业务：主业迁移空间（新易盛范式）

  • 能力可迁移：广电网络运维 → 政企专网/网安监管（技术同源，已落地）；
  • 新 TAM：网络安全监管、智慧城市运维市场远大于传统收视；
  • 卡位：深圳国资背书，先发；
  • 验证点：网安监管收入占比跳升、政企项目中标公告；

  • 结论：迁移在进行但未过"收入占比跳升"验证点，仅作中期期权，不计入中性。

  • 层3 风险折扣（证伪信号）：用户流失加速（开机率继续下滑）、ARPU 破阈、政企订单无实质公告、地产租赁空置率上升 → 触发则下调增量。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣（破净原因说明）：公司未破净（PB 3.16x），但市值远高于经营正常化估值，溢价来自①商业地产按历史成本计、若市价重估 NAV 或更高；②深圳国资壳/整合预期。若仅看经营资产（网络专用性强、用户流失），清算价值 << 账面，PB 3.16x 含溢价泡沫。结论：高 PB 不意味低估，反显经营支撑不足。
  • 校正2 周期位置校正：有线网络非强周期，但处于"用户结构性下行"长周期，中性已按温和下滑处理，未用任何好转外推。
  • 校正3 杠杆下行情景：资产负债率约 45%（总资产 34.89 亿、净资产 19.27 亿），经营杠杆有限；但若是"用户持续流失 + 设备资本开支前置"双压，净利可转负更深，悲观情景已体现（−85%）。
  • 期权纪律：深圳国资资产整合/商业地产重估属未过验证点期权，不计入中性，仅放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估（经营视角）。7.59 元对应经营正常化估值 2.74 元，溢价约 177%，主要由壳/资产/整合期权支撑。

安全边际：中性远期 2.74 元 → 空间 −63.9%；悲观 1.12 元 → −85.3%；乐观 8.7 元（含整合期权）→ +14.6%。经营基本面无安全边际，下行保护完全依赖资产重估与国资预期。

介入条件：
1. 现价严重透支，不建议介入；
2. 若回落至 3 元以下（接近资产底 + 经营正常化估值），且出现①深圳国资整合实质公告、②商业地产重估验证、③C 端用户流失企稳信号，可重新评估；
3. 观察指标：逐季用户数、ARPU、经营现金流转正持续性、政企/网安收入占比。

最大风险（最可能破坏逻辑的因素）：
1. C 端用户加速流失，基础业务"失血"速度超过降本；
2. 现价依赖的壳/整合期权长期不兑现，估值向经营面回归（−60% 以上空间）；
3. 设备资本开支前置 + 套娃治理持续压制 ARPU，扭亏时点一再推迟。

亏损股三问：
1. 为什么亏：传统有线电视/宽带基础业务受用户流失 + 套娃收费治理 + 价格战三重压制，收入 −22.28%，而固定网络折旧与内容成本刚性，导致毛利转负、费用率上升；属主业持续恶化 + 行业结构性下行，非一次性减值。
2. 靠什么扭亏，时点：①商业地产租金 + 政企/网安监管提供稳定正利润（已部分对冲）；②降本增效 + 视频购物收缩止损；③超高清/一体化电视推广带来设备/服务增量。中性预计 2027–2028 年可依靠地产+政企实现微利扭亏（归母转正 0.5–1 亿量级），但难回历史盈利高峰。
3. 亏得起吗：能。经营现金流 2026H1 已转正（+2628 万），总资产 34.89 亿、净资产 19.27 亿、无重大有息负债压力，账上资产与现金可支撑数年转型，不存在现金流枯竭或退市风险（非 ST）。

结论：暂不介入（基本面经营支撑不足，现价含过多未验证壳/资产期权；非"坚决回避"——公司有偿付能力且有明确扭亏路径，但未到性价比窗口）。

说明：未命中任何排除标准（非 ST、有扭亏路径、现金流为正），故不判"坚决回避"；但中性经营空间 −63.9% 远未达关注门槛，判"暂不介入"。
