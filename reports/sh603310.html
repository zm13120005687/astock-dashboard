（3）产业链传导

上游：氯气、氢氟酸（萤石→HF）、甲苯、苯系芳烃、液氯。萤石与氢氟酸是核心成本变量（受萤石配额与环保限产影响）。公司位于杭州湾上虞经开区，园区配套完善但原料外购为主，无自有萤石矿。

下游：跨国农化巨头（BAYER/BASF/FMC）、农药制剂企业、制冷剂客户。下游议价权强——佐证：公司明确表述"原材料价格上升，成本向下游传导存在压力"，即传导不畅，自己吃下了大部分成本上涨。

议价权判断：弱（周期底部 + 下游巨头 + 产品同质化）。这是本股盈利能力崩塌的根源。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）
量化转嫁系数：传导率 ≈ 0.2–0.3（行业底部、下游巨头强势、产品同质化）。
- 佐证：公司半年报原话"原材料价格上升，成本向下游传导存在压力，综合毛利率有所下降，部分产品盈利空间收窄"。
- 计算：上游原料每涨 10%，公司实际毛利承压 10% × (1−0.25) = 7.5%，按 2026H1 营业成本 5.73 亿计，约吃掉毛利 0.43 亿——这解释了毛利率从 23.97% 崩至 18.05% 的大部分。
- 传导率提升的观察点：反内卷政策生效、行业产能实质性退出、HFO 制冷剂供不应求（新产能可获高传导率）。

→ 单一"综合毛利率 18.05%"完全掩盖了结构迁移：成熟线还在赚钱（20%+），但新投产的三氟甲基吡啶线以 −7.38% 的毛利率稀释了整体。这是"并购+扩产型公司"在周期底部的典型特征——营收涨、毛利崩。估值必须分线给利润。

因子3 库存与采购节奏（timing）
- 2026H1 存货周转率 0.68 次（年化 1.36 次），2025 全年 3.32 次 → 周转明显放缓，存在高价原料库存积压；
- 2026H1 经营现金流净额 仅 1488.81 万（上年同期 −194.31 万），净利润现金含量 71.70% → 盈利质量偏差；
- 无公开套保披露；汇兑敞口：人民币升值造成较大汇兑损失（未披露具体金额，但列为四大利润拖累项之一）。
→ 结论：当前毛利率被"高价库存 + 爬坡固定成本"双重压制，属 timing 性亏损成分，不应全部视为长期盈利能力丧失。这是周期归一化估值的核心依据。

锚点 现状 三档假设 可观测验证点

层2 扩展业务：主业迁移空间（"中间体→原药→制冷剂"三段式迁移）
- 能力可迁移性：极高。含氟中间体 → 原药（禾裕泰）是同一氟化学工艺树的下游延伸；→ 制冷剂（HFO）同属氟化工，技术同源。
- 新 TAM 弹性：全球农药原药市场约 700 亿美元、第四代制冷剂（HFO）市场 2030 年有望超 50 亿美元，均数倍于中间体 TAM。
- 切入卡位：早期偏中段。HFO 处于 HFC 削减替代的早期窗口，先发有红利。
- 客户认证门槛：原药需登记证（禾裕泰已持证，门槛已跨过）；制冷剂需 ASHRAE 认证与客户验证（门槛未过）。
- 信号验证：禾裕泰已扭亏（已过验证点）；三氟甲基吡啶完成试生产验收（已过）；HFO 仅试生产，未过验证点。
→ 结论：中间体→原药迁移已验证，可计入中性；→制冷剂未过验证点，仅作中期期权，不计入中性净利。

层3 风险折扣：证伪信号
① 三氟甲基吡啶毛利率连续 2 年不转正；② HFO 试生产 12 个月内未出合格品或无客户订单；③ 禾裕泰重新亏损；④ 综合毛利率跌破 15%。命中两条 → 中性下修 25%。

第四步：估值锚定（自下而上，非增速外推）

方法说明：本股为强周期 + 准亏损（扣非极薄），按 RULES 采用 正常化净利润法 + 周期归一化：① 估稳态营收（现有产能满产 + 在建项目达产 + 并表兑现）；② 算周期归一化净利率（trough-to-peak 中值，禁用单年好年景、近三年均值、拐点年化）；③ 正常化净利 × 远期合理 PE → 目标市值 → 目标价。严禁历史增速外推。

亏损股三问（准亏损必答）

① 为什么亏（实为"为什么薄利到准亏损"）：公司 2026H1 归母 +7133.87 万表面上没亏，但扣非仅 +2247.86 万（同比 −69.95%）、扣非净利率仅 3.2%，归母中 4833.75 万来自金融资产公允价值变动（非经营、不可持续）。薄利的三层原因：
- 周期位置（主因）：核心产品氯甲苯 / 三氟甲基苯中间体价格处于 trough，净利率从 2023 年 PEAK 的 33.59% 一路滑到 2026H1 的 9.39%，属于行业景气底部而非公司竞争力崩塌；
- 产能爬坡期折旧：2024 年 IPO 募投项目（18500 吨甲苯氯化氟化物等）陆续转固，新增折旧摊销压制当期毛利，产能利用率尚未打满；
- 并表摊薄：2026 年 1 月并表的禾裕泰（农药原药）处盈亏平衡线附近，H1 仅 810.06 万，稀释了原有高毛利中间体占比。
→ 结论：属"周期底部 + 爬坡期"型薄利，不是主业萎缩型亏损，与"现金流枯竭、无订单、无项目"的确无扭亏可能有本质区别。

② 靠什么扭亏，触发时点：扭亏（恢复常态盈利）路径全部落在已披露项目的产能兑现上，不依赖任何历史增速外推：
| 扭亏驱动 | 状态 | 时点 |
|---|---|---|
| 18500 吨甲苯氯化氟化物主力线 | 已投产，2029 满产 | 2027 起爬坡放量 |
| 三氟甲基吡啶（2.22 万吨） | 已完成试生产验收 | 2027–2028 达产 |
| 氟虫腈（4900 吨原药） | 试生产中 | 2028 |

- 触发时点：2027 年——行业供需边际改善叠加三大项目同步爬坡，扣非净利率有望从 3.2% 回到 10% 以上；2029 年达到周期归一化后的 13.5% 正常化水平（对应中性归母 3.50 亿）。
- 验证点：季度扣非净利率环比转正并站上 8%、中间体价格指数回升、禾裕泰单季净利超 1000 万。
- 证伪信号：中间体价格继续下探致扣非净利率跌破 2%、HFO 中试良率长期不达标、禾裕泰再度亏损。

③ 亏得起吗：完全亏得起，生存风险为零——这是本股最重要的安全垫。
- 2025 年末资产负债率仅 14.68%、无有息负债、现金比率 474.99%、速动比率 6.19，账上现金极充裕；
- 每股净资产 11.67 元 vs 现价 14.86 元（PB 1.27x），净资产 40.30 亿中大量为未投产募投项目，下行有净资产托底；
- 2026H1 经营现金流净额 +1488.81 万（上年同期 −194.31 万），虽薄但已转正，不依赖外部输血即可撑到 2027 年扭亏触发点。
→ 真正的风险不是"亏不起"，而是"长期薄利导致估值中枢下移"：若行业出清缓慢、价格长期低迷，公司会长期停留在"净资产扎实但 ROE 极低"的状态，这类标的的杀估值风险大于破产风险。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正1 资产质量折扣：PB 1.27x，不破净。但需穿透：净资产 40.30 亿中，IPO 募集资金占比高，且已投向 18500 吨、2.22 万吨、4900 吨等在建项目（在建工程/固定资产形态）。这些资产是通用化工装置（非专用不可转产），清算价值优于高炉/路产，且公司资产负债率仅约 28%、无有息负债压力（2025 年末有息负债仅 1560 万）→ 资产质量无折扣，1.27x PB 具备一定安全边际。

校正2 周期位置校正（本股最关键）：当前明确处于周期底部（TROUGH）。证据：毛利率 45.64% → 31.15% → 23.97% → 18.05%，四连降；归母净利 4.995 → 2.536 → 1.692 亿，三连降；Q2 毛利率环比 +1.37pct，已现企稳迹象。
按 RULES：底部时不过度悲观，故中性净利率取 13.5%（高于 trough 的 9.39%），而非按 2026H1 年化（那会把周期底部当稳态，属"拐点年化"错误）。同时禁止用 2023 峰值 33.59% 或近三年均值——已规避。

校正3 杠杆下行情景：资产负债率约 28%、有息负债 1560 万，不属于高负债，利率上行情景不适用。反而需注意：总资产 55.93 亿中大量为在建工程，若项目延期将产生折旧压力（爬坡期固定成本分摊已在拖累毛利）。

期权纪律：① HFO 第四代制冷剂（未过验证点）不计入中性；② 金融资产公允价值变动 4833.75 万属一次性，剔除；③ 基茵达股权等财务投资不计入。

第五步：综合赔率判断（买不买？）

当前价格位置：PB 合理、PE 偏贵。14.86 元对应 PB 1.27x（净资产托底明确）但 2026E 扣非 PE 高达 86x——市场已在为"周期回暖 + 项目达产"提前定价。

安全边际：
- 中性远期 18.24 元 → +22.7%，不达"重点关注"的 >50% 门槛
- 悲观 11.70 元 → −21.3%，由 0.9×PB 兜底，下行可控
- 乐观 31.27 元 → +110.6%，需周期回中周期中枢 + HFO 放量共振
- 赔率结构：略正偏（上行 +22.7%、下行 −21.3%，约 1.07:1），不够陡峭

介入条件：
1. 现价不宜追。等回落至 13.0 元以下（PB < 1.12x）具备安全边际
2. 加仓信号：① 三氟甲基吡啶系列毛利率转正（中报/年报分部数据）；② 单季综合毛利率连续两季环比回升且站上 22%；③ HFO 拿到首批客户订单并公告；④ 禾裕泰全年净利超 2000 万
3. 下调信号：综合毛利率跌破 15%；禾裕泰重新亏损；HFO 试产 12 个月无合格品

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 周期底部比预期更长（首要）：公司自述"供需格局未发生实质性改善"，若 2027–2028 农化去库存未完成，中性净利 3.50 亿将下修至 2.2 亿以下，目标价降至 11.5 元
2. 新项目爬坡失败：三氟甲基吡啶毛利率 −7.38%，若 2028 仍不转正，则"扩产=扩亏"
3. 营收虚胖：+59.83% 的增长来自并表而非内生，母公司口径实际在下滑
4. 汇率：出口占比高，人民币继续升值将持续侵蚀利润（2026H1 已明确列为四大拖累之一）

结论：纳入观察

理由：周期底部 + PB 1.27x + 无有息负债 + 一体化迁移逻辑成立，具备中周期的反转弹性；但当前价格已部分反映回暖预期（扣非 PE 86x），中性远期空间 +22.7% 不足 50% 门槛，且爬坡与汇兑不确定性高。

第五步进阶：上行想象力情景（四类，对冲保守偏置）

类型A 行业调整剩者红利

类型B 政策反转期权（本股最强上行来源）

- 纪律：HFO 未过验证点，仅作机会情景，不计入中性锚

类型C 市场错杀修复
现价 PB 1.27x，每股净资产 11.67 元，而公司无有息负债、现金比率极高——这是一个"净资产扎实但盈利被周期压到极致"的组合。量化策略按 PE 32x / 扣非 PE 86x 会直接剔除，形成错杀。
- 错杀证据：PB 1.27x 接近历史低位；净资产 40.30 亿 vs 市值 51.32 亿，溢价仅 27%
- 修复触发点：2026 年报/2027 中报显示单季毛利率连续回升；反内卷政策见效
- 证伪信号：毛利率继续下探、计提在建工程减值

类型D 技术突破 / 代际跃迁期权
公司已投产全球首套康宁万吨级 G5 微通道反应器，实现重氮化、水解及分离纯化全连续自动化——这是从"间歇釜式"到"连续流"的工艺代际跃迁，属于工艺革命而非市场迁移。
- 三要素共振检查：① 政策驱动：安全环保政策强制推动连续化（是）；② 行业趋势：连续流是精细化工必然方向（是）；③ 落地：已投产并稳定运行（是，2025 年报披露）
- 硬验证点：已达成两条（中试跑通 + 量产），第三条"量产成本曲线真优于旧路线"待验证——需看单位能耗/收率数据是否披露
- 弹性：若连续化使单位成本低于同行 15–20%，则行业价格战中公司最后流血、最先修复，可在下一轮周期拿到超额份额
- 证伪信号：连续化产线运行不稳定、收率不及间歇釜、专利被绕开
