第一步：公司是干什么的？

一句话定位：浙江金华老牌"建材 + 医药"双主业集团，左手在浙江/湖北/云南/贵州做水泥、骨料、商砼，右手通过尖峰药业做仿制药与原料药，同时是一家持有大量未上市股权与上市公司股票的投资平台——主业长期不赚钱，利润主要来自参股企业的权益法投资收益。

净资产与对外投资结构（关键）：归母净资产 54.03 亿元，其中长期股权投资 19.02 亿元（天士力集团 12.66 亿元/持股 20.76%、金华南方尖峰水泥 5.31 亿元/持股 33.34% 等）、其他权益工具投资 1.31 亿元（天山股份 3606.89 万股）、交易性金融资产 0.50 亿元；在建工程 4.17 亿元（较期初 +83.36%）；货币资金 1.90 亿元。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1｜成本传导弹性（pass-through）——水泥 ≈ 0，医药 ≈ 0.1
- 水泥：2026 年 8 月煤价环比 +7.32%，同期水泥均价环比 −4.08 元/吨。成本涨、价格跌 → 实际传导率为 0 甚至为负。依据：区域市场竞争激烈、库存高企（水泥库容比 72.4%）、下游资金紧张，涨价函无法落地。
- 医药：集采品种价格由招标决定，成本上涨无法转嫁 → 传导率 ≈ 0.1。
- 量化含义：煤价每上涨 10%，公司水泥吨成本上升约 8.7 元/吨；若传导率为 0，全部由公司承担，按年销量约 500 万吨估算，年化毛利承压约 4000–4500 万元。

骨料/商砼 约 20–25% 中（运输半径、砂石成本） 约 12% 约 15%

  • 合并综合毛利率 2026H1 为 17.15%，较 2025 全年 22.27% 下滑 5.12pct。
  • 结构迁移含义：煤炭涨价吃的是水泥毛利，但医药毛利率更高、权重已接近半壁——若医药新品放量、集采冲击见底，综合毛利率存在结构性修复空间。禁止用"综合毛利率 17%"单一数字外推，第四步必须分线给毛利率。

因子 3｜库存与采购节奏（timing）
- 存货由 2025 年末 4.12 亿降至 2026H1 末 3.87 亿（−6.1%），无低价囤货型库存收益，也无高价接货型大额损失——当期毛利即真实毛利，无 timing 虚增。
- 煤炭采购：公司未披露长协比例，行业普遍为"长协 + 现货"混合；公司推广替代燃料与光伏发电以降能耗成本（2026H1 研发费用同比 −31.01%，部分反映投入节奏调整）。
- 验证点：年报披露的煤炭长协比例、替代燃料替代率。

层 2｜扩展业务 = 主业迁移空间（新易盛范式）
- 能力可迁移性：水泥→骨料→商砼的纵向延伸（同一区域、同一客户、同一渠道），迁移成本低、已在执行（云南骨料线 + 普洱商砼），属"已验证的迁移"，可计入中性。
- 医药→大健康/创新药：能力迁移性弱（仿制药团队做创新药需重构），JFAN-1001 属全新赛道，未过验证点，仅作中期期权，不计入中性。
- 水泥→新能源/新材料：无实质动作，不成立。
- 新 TAM 弹性：骨料+商砼合计市场容量约为水泥的 0.6–0.8 倍，属"同一池塘的深水区"而非新池塘，弹性有限。

层 3｜风险折扣：证伪信号
1. 水泥价格连续 2 个季度同比跌幅扩大 → 份额与价格双杀，剔除水泥增量；
2. 尖峰药业集采中选价再降、毛利率跌破 28% → 医药板块增量归零；
3. 尖峰大展 4000 吨线投产延期至 2028 年后 → 剔除建材增量；
4. 天士力集团长期股权投资出现减值迹象 → 净资产与投资收益双杀。

第四步：估值锚定（自下而上，非增速外推）

方法说明：2026H1 归母为负（−895 万），采用正常化净利润法：①估稳态营收（现有产能满产 + 在建项目达产 + 订单兑现）→ ②算正常化净利率（行业正常水平 / 公司历史最好水平 / 产能爬坡理论值，三者取保守）→ ③正常化净利润 × 远期合理 PE = 目标市值 → 目标价。不使用任何历史增速外推。

亏损三问

问 1：为什么亏？
1. 投资收益高基数消失（核心）：2025H1 参股联营企业天士力集团出售股权贡献非经常性收益，投资收益高达 5.99 亿元；2026H1 该事项不再发生，投资收益骤降至 1855 万元（−96.9%），其中权益法联营收益仅 447 万元。这是"由盈转亏"的第一原因。
2. 水泥周期性底部：全国水泥产量 −8.0%、CEMPI 同比 −12.87%，贵州尖峰亏 2962 万、云南尖峰仅赚 156 万。
3. 医药集采冲击：尖峰药业净利 −3909 万（由盈转亏），上海北卡 −4216 万。
4. 公允价值变动损失：所持天山股份股价下跌，计入其他综合收益的公允价值变动损失 −6095 万元。
5. 一次性/周期性 vs 结构性：2025 全年归母 +4.12 亿，但扣非为 −2.51 亿——说明公司主业长期不赚钱，利润长期依赖投资收益，这是结构性问题；而 2026H1 归母微亏主要是周期性与一次性因素（扣非亏损已由上年同期 −5451 万大幅收窄至 −1262 万）。

问 2：靠什么扭亏，触发时点在哪一年？
- 2026H2 即已现拐点：2026Q2 单季归母 +937.05 万元（Q1 为 −1832 万），扣非亏损持续收窄。
- 2026 年（触发年）：投资收益低基数 + 水泥旺季 + 医药新品，全年归母有望回到 0.3–0.6 亿微利区间。
- 2027 年（实质修复年）：①水泥"反内卷"（超备案出清 + 碳市场 + 环保提标）推动价格企稳；②尖峰大展 4000 吨熟料线、云南 300 万吨骨料线投产；③医药获批品种放量。
- 2028–2029 年（稳态年）：水泥周期中枢修复 + 骨料商砼贡献 + 医药稳态。

问 3：亏得起吗？——亏得起，安全垫厚
- 货币资金 1.90 亿元（较期初 +32.55%，主因赎回大额银行存单）；
- 经营活动现金流净额 +5493 万元（连续为正，同比仅 −0.90%），主业造血能力尚存；
- 资产负债率仅 27.42%（2025 年末 24.95%），行业最低区间，有息负债压力小；
- 长期股权投资 19.02 亿 + 其他权益工具 1.31 亿 + 交易性金融资产 0.50 亿 = 约 20.83 亿元可盘活资产；
- 结论：不存在倒在黎明前的风险，且具备逆周期加杠杆的空间。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1｜资产质量折扣——为什么破净（PB 0.57）？

净资产构成（54.03 亿元） 金额 是否可按市价验证
长期股权投资 19.02 亿 ❌ 天士力集团（12.66 亿，非上市股权，其核心资产为天士力医药约 2% 股份 + 国台酒业等未上市股权）；南方尖峰水泥（5.31 亿，非上市）
其他权益工具投资 1.31 亿 ✅ 天山股份 3606.89 万股 × 3.74 元 = 1.35 亿元（已计入累计公允价值变动 −3.34 亿）
交易性金融资产 0.50 亿 ✅ 银行存单/理财
固定资产 + 在建工程 + 存货等实体资产 约 33 亿 ❌ 水泥窑线/粉磨站专用性强、重置成本不兜底；医药产线受集采压制

破净原因：①水泥实体资产处于周期底部，ROE 为负 → 破净是公允定价；②医药仿制药资产被集采压制；③长期股权投资主体为非上市股权，流动性折价。
"持股数量 × 市价 vs 总市值"证明：可辨认、有市价的金融资产仅天山股份 1.35 亿元，占总市值（31.1 亿）仅 4.3%；银行理财/存单约 0.50 亿元（1.6%）。合计不足 6%。
→ 结论：本股属"非典型未重估型破净"，不能用"金融资产未重估 ≈ 总市值"来证明真安全边际。破净提供的是有限保护，而非无风险套利。禁止单凭 PB 0.57 推导大空间。

校正 2｜周期位置校正（中性净利用周期归一化）
- 当前周期位置：水泥处于周期底部（CEMPI 91.39、同比 −12.87%；板块指数年内 −18.15%；行业大面积亏损）。
- 归一化方法：不用单年好年景（2021）、不用近三年均值（含 2024–2025 双低年）、不用拐点年化（Q2 单季 +937 万的年化）。改用周期 trough-to-peak 中枢：
- 水泥吨净利中枢：区域龙头在正常年份约 20–35 元/吨，底部约 0 至负、顶部约 60–80 元/吨 → 取中枢 25 元/吨，按年销量约 500 万吨（含新线）→ 约 1.25 亿；
- 骨料/商砼：约 0.4 亿；
- 医药：集采后稳态约 0.6 亿；
- 权益法经常性投资收益：约 1.0 亿；
- 周期归一化中性净利 ≈ 3.25 亿，与上表 3.2 亿一致。
- 验证点：CEMPI 连续 2 季度同比转正、吨水泥煤炭价差回升至 180 元/吨以上。证伪信号：价格再破 88 点、价差跌破 140 元/吨。

校正 3｜杠杆下行情景（本股负债率仅 27.42%，风险有限）
- 资产负债率 27.42%（行业最低区间），无高杠杆反噬风险；
- 但需附需求下行负面情景：若房地产新开工再降 15% + 水泥价格再跌 10%，水泥板块由盈亏平衡转为亏损，正常化净利降至 2.0 亿 → 目标价 4.84 元（−35.8%）；
- 该负面情景下空间转负，故不得标注"大空间"，至多"纳入观察"。

期权纪律：天士力集团剩余股权处置（一次性收益）、JFAN-1001 创新药、天山股份股价回升带来的其他综合收益——三者均未过验证点，不计入中性净利/中性 NAV，仅列入乐观情景与机会情景。

第五步：综合赔率判断（买不买？）

当前价格位置：低估（但低估的成色不足）。PB 0.57x、2029E 中性正常化 PE 9.7x 表面便宜；但正常化净利的 25–37% 来自无法按市价验证的非上市股权，且主业 2025 年扣非为 −2.51 亿，低估部分依赖周期与股权价值的乐观假设。

安全边际：
- 中性远期 9.30 元 → 空间 +23.3%，不达"重点关注"的 >50% 门槛；
- 悲观情景 4.84 元 → 下行 −35.8%，风险收益不对称偏负；
- 乐观情景 18.89 元 → +150.5%，需水泥提价 + 股权处置 + 医药放量三重兑现；
- 下行保护：资产负债率 27.42%、经营现金流连续为正、PB 0.57x、货币资金 1.90 亿，5.0 元附近（PB 0.38x）为强支撑。

介入条件：
1. 不追高。现价 7.54 元对应中性空间仅 +23.3%，等回落至 6.5 元以下（PB < 0.50x）才具足够安全边际；
2. 加仓信号：① CEMPI 连续 2 个月环比回升；② 公司扣非连续 2 个季度转正；③ 尖峰大展 4000 吨线点火投产公告；④ 天士力集团剩余股权处置公告落地；
3. 观察指标：逐季水泥销量与吨毛利、尖峰药业毛利率（是否守住 28%）、权益法投资收益。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 投资收益的可持续性（首要）：正常化净利的 25–37% 依赖权益法投资收益，而 2025 年该收益主要来自天士力集团出售股权的一次性收益，2026H1 权益法收益已骤降至 447 万——若该收益常态化在 0.3 亿以下，中性净利需下修至 2.5 亿；
2. 水泥价格继续探底：煤价同比 +27.35% 而水泥价同比 −12.87%，剪刀差若继续扩大，水泥板块将长期亏损；
3. 医药集采持续压价：尖峰药业 2026H1 已由盈转亏，若集采规则进一步收紧，医药板块将失去利润贡献；
4. 非上市股权减值风险：天士力集团 12.66 亿长期股权投资若出现减值，净资产与投资收益双杀。

第五步进阶：上行想象力情景（四类，与下行校正对称）

类型 A｜行业调整剩者红利
- 逻辑：水泥行业"严禁新增 + 超备案出清 + 碳市场 + 环保提标"四重供给约束下，低效产能 2028 年前集中退出（环保修改单要求现有企业 2028 年初全面执行），区域龙头剩者份额与定价权跳升。
- 锚定：熟料 CR10 已达 61.88%；浙江/湖北/云南区域中小窑线退出后，公司区域份额有望提升 1–3pct。
- 验证点：各省产能置换公示数量、熟料运转率跌破 35%（=出清加速）、公司水泥销量增速转正。
- 证伪信号：出清进度停滞、运转率回升至 55% 以上。

类型 B｜政策反转期权
- 逻辑：① 水泥"反内卷"（中国水泥协会自律 + 错峰生产）若从"纸面涨价"转为"实际落地"，价格弹性大；② 医药集采规则若从"唯低价"转向"质量优先/报量优化"，仿制药价格见底。
- 重估弹性测算：水泥均价每回升 20 元/吨 → 年化毛利增厚约 1.0 亿元 → 净利增厚约 0.75 亿 → 目标市值增厚约 9 亿（对应 +2.2 元/股）。
- 验证点：CEMPI 连续 2 月环比上行、集采中选价企稳公告。证伪信号：涨价函继续空转。

类型 C｜市场错杀修复
- 逻辑：PE(TTM) −14.33x、PB 0.57x，市场按"水泥亏损 + 投资收益断供"给最悲观定价，但经营现金流连续为正、负债率仅 27.42%，基本面并未恶化到该估值。
- 错杀证据：PB 分位处于上市以来极低区间；水泥板块指数年内 −18.15%，公司跟随板块超跌。
- 修复触发点：扣非单季转正、市场风格切向低估值高分红、水泥板块指数企稳。
- 证伪信号：扣非继续扩大亏损、经营现金流转负。

类型 D｜技术突破 / 技术代际跃迁期权
- 逻辑：抗肿瘤创新药 JFAN-1001（自研 1 类新药，临床研究阶段）+ 甲基多巴原料药获批（2026-09-01）——若创新药从 0 到 1 落地，可重构医药板块估值。
- 硬验证点（三者缺一即不计入中性）：① 临床 II/III 期数据达标；② 获得上市许可或对外授权（BD）大额订单；③ 商业化成本优于现有疗法。
- 证伪信号：临床失败、授权无进展、研发费用持续收缩（2026H1 研发费用已同比 −31.01%，是负面信号）。

什么条件出现才把结论上调至"重点关注"：① CEMPI 连续 2 个季度同比转正且公司扣非连续 2 个季度为正；② 尖峰大展 4000 吨线 + 云南 300 万吨骨料线按期投产并贡献利润；③ 天士力集团剩余股权处置落地、权益法经常性投资收益稳定在 1.0 亿以上。三者同时满足时，中性空间将从 +23.3% 抬升至 +50% 以上。

结论：纳入观察

理由：公司亏得起（负债率 27.42%、经营现金流为正、20.83 亿可盘活金融资产），扭亏路径清晰且已见拐点（2026Q2 单季已转正），PB 0.57x 提供有限安全边际。但① 正常化净利的 25–37% 来自无法按市价验证的非上市股权，② 破净属"周期底部 + 资产专用性强"的公允定价而非真套利（有市价金融资产仅占总市值 6%），③ 中性远期空间仅 +23.3%、悲观下行 −35.8%，风险收益不对称。故不追高，等回落至 6.5 元以下或扣非连续两季转正后再评估。
