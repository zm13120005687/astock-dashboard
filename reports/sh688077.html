（3）产业链传导

上游：镨钕合金、镝、铽等稀土金属——占生产成本比重高（>50%）。2026H1 原料价格 +72%，成本端剧增，公司成本传导弹性中等偏弱（磁材加工环节议价权有限，涨价难全转嫁，H1 毛利率不升反降验证）。

下游：新能源 / 机器人 / 风电电机厂，需求旺但压价，议价权中（磁材同质化竞争）。

议价权：中偏弱。原材料大涨时毛利被吃（H1 印证）；仅高端牌号 / 磁组件具一定溢价。

第二步进阶·原料成本 → 毛利结构（四因子）
- 因子1 成本传导弹性（转嫁系数≈0.4–0.6）：稀土原料占成本 >50%，涨价时仅能转嫁 40–60%，其余吃毛利（H1 毛利率 −3.67pct 实证）。验证点：毛利率能否随稀土涨价回升；证伪：稀土续涨而毛利率破 15%。
- 因子2 毛利结构再平衡：烧结钕铁硼 75.65%（毛利受稀土价主导）、磁组件 / 注塑磁 21%（毛利较高、具溢价）。结构优化=提升磁组件占比以降对原料敏感度。验证点：磁组件营收占比。
- 因子3 库存与采购节奏：H1 经营现金流 −68% 系"购买商品支付现金大增"——若低位囤稀土原料则享库存收益（当期毛利虚高），若高位接货则后续毛利承压。当前稀土高位，存在"高价接货"风险。验证点：存货跌价准备、Q3 毛利。
- 因子4 政策 / 市场锚点：原料成本驱动=①《稀土管理条例》总量管控（托底价，正面）；②出口管制（抬升海外价、外溢国内，正面但推高成本）；③双控 / 收储（战略收储托底）。情景：稀土价格回落至 50 万/吨中枢 = 毛利修复但售价降；验证点：氧化镨钕月度价格、总量指标公告。

（3）第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：
  • 供给侧：国内钕铁硼产能充足（行业产能过剩），大地熊份额中等；产能利用率提升=增量来源（验证点：产量）。
  • 需求侧 / 客户份额：绑定新能源 / 机器人电机厂，份额稳但非垄断。
  • 成本曲线位置：规模 + 工艺影响成本，但原料占比高，成本曲线左移空间有限。
  • 三档：保守（营收 CAGR 8%）/ 中性（12%）/ 乐观（18%，机器人爆发）。验证点：季度出货量。
  • 层2 主业迁移空间：从"磁钢"→"磁组件 / 电机核心部件"，能力可迁移（材料→部件），新 TAM 弹性中等。未过验证点（磁组件占比仍小），仅作中期期权。
  • 层3 证伪信号：稀土价格暴跌（存货损失）、新能源 / 机器人需求转弱、毛利率破 15% → 下调增量。

第四步进阶·重资产 / 周期股校正（三道闸）
- 校正1 资产质量折扣：重资产（固定资产 + 在建占比高），PB 2.78 非破净；但资产专用性一般（磁材产线可转产），净资产无显著虚高。不构成"真破净安全边际"，仅正常重资产定价。
- 校正2 周期位置校正：当前稀土价格处周期高位（74 万 vs 中枢 50 万），毛利被成本吃、但营收 inflated。中性净利已用"周期归一化（稀土中高位）"而非"2026 单年好年景"或"近三年均值（含低谷）"，标注周期位置=上行高位区，谨慎。若误用单年好年景，净利虚高、估值失真。验证点：氧化镨钕价格走势。
- 校正3 杠杆下行情景：货币资金 2.08 亿 vs 短期借款 7.74 亿，流动比率 1.18、速动 0.67——高负债。悲观情景（稀土跌 + 需求弱 + 存货损失）净利可降至 0.36 亿甚至转负，空间 −76.6%。因下行极深且杠杆高，不得标"大空间 / 重点关注"，至多暂不介入。
- 期权纪律：磁组件 / 机器人高弹性未过验证点，不计入中性。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵 / 周期高位。现价 26.90 元对应周期中性目标 19.0 元（−29.4%），且处稀土价格高位、负债率高，安全边际薄。

安全边际：中性 −29.4%；悲观 −76.6%（高负债 + 稀土下行可转负）；乐观 +21.7%（稀土高位 + 机器人放量）。下行保护弱（高负债）。

介入条件：①回落至 18 元以下（接近周期中性市值、PB 2x 以下）才具安全边际；②加仓信号：稀土价格回落至 50–55 万中枢（毛利修复且去库存风险释放）、短债压降、磁组件占比升至 30%+；③观察指标：氧化镨钕月度价、毛利率、资产负债率。

最大风险：①稀土价格高位回落致存货跌价 + 售价降（首要）；②高负债（短债 7.74 亿）在需求下行时反噬；③新能源 / 机器人需求不及预期；④磁材同质化价格战。

结论：暂不介入（周期顶部 + 高负债 + 估值偏贵，中性空间 −29.4%，杠杆下行可转负）

第五步进阶·上行想象力情景（四类）
- A 行业调整剩者红利：稀土管控 + 能耗双控淘汰中小磁材厂，头部（大地熊等）份额与定价权跳升。验证点：行业集中度、份额数据。
- B 政策反转期权：稀土出口管制放松 / 收储提价，原料成本锚上移同时溢价传导顺畅。验证点：出口许可、收储公告；证伪：管制放松致价格崩。
- C 市场错杀修复：若因周期恐慌被错杀至 PB 1.5x 以下，凭产能与客户的修复弹性。验证点：估值分位。
- D 技术突破 / 代际跃迁期权：高牌号 / 低重稀土磁体（降镝铽）从 0 到 1 量产，成本曲线左移 + 打开机器人 / 人形机器人新 TAM。硬验证点：中试良率达标 + 客户定点 + 量产成本优于旧路线。当前未过验证点，仅作机会情景。
