- 对比剂已基本全部纳入集采——这意味着降价冲击的最大阶段已过。公司口径："经过近两年的调整，公司已逐步克服碘对比剂主打产品管线受集采价格下降带来的挑战，逐渐显现回暖趋势"
- 集采对公司的净效应已从"利空"转为"中性偏利多"：① 以价换量，销量增长对冲价格下降；② 集采是份额重新分配的窗口，原研（GE、拜耳、博莱科）在低价下退出，国产龙头承接份额；③ 原料药自给的一体化企业在低价竞争中具备成本优势
- 2026 年 5 月碘普罗胺纳入第十二批预填报是最后一个靴子，落地后公司主力品种全部完成集采覆盖 → 2027 年起进入"集采后稳态经营期"

（3）产业链传导

上游：碘（碘造影剂核心原料，全球主要产自智利/日本）、钆类稀土、化工中间体、药用辅料。
- 关键动作：公司通过控股海昌药业（51.05%）实现碘类原料药自给，通过沧州分公司实现钆类原料药自给 → 这是"原料药+制剂"一体化战略的核心，直接对冲上游碘价波动
- 碘价风险：碘是稀缺资源，价格受全球供给（智利硝石矿、日本天然气田副产）影响大，历史上出现过大幅上涨

下游：公立医院（集采渠道）、零售药店、海外经销商。
- 议价权：弱（对医保局）/ 中（对海外）。集采下价格由医保局主导，公司无定价权；但海外市场是市场化定价，且公司有 EU-GMP/ANVISA 认证的稀缺性 → 海外议价权显著强于国内

产业链位置与议价权总结：中游制剂 + 上游原料药一体化
- 集采环境下，一体化是唯一活路——没有原料药自给的企业在集采低价下会亏损，北陆通过一体化保住了利润空间
- 这是本股最核心的竞争壁垒

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）：传导率 ≈ 0.15–0.25（极弱，因集采锁价）
- 国内集采品种：传导率 ≈ 0。集采中标价在协议期内（通常 2–3 年）锁定，上游涨价 100% 由公司承担，无法转嫁
- 海外 + 原料药：传导率 ≈ 0.6–0.7。市场化定价，可随碘价调整报价，有议价空间
- 加权利率：国内收入占 82.3%、海外 17.7% → 综合传导率 ≈ 0.15
- 验证点：① 上游碘价走势；② 海昌药业原料药毛利率（自给率越高，集团综合成本越可控）；③ 海外业务毛利率
- 证伪信号：碘价上涨 20% 而公司综合毛利率下滑超 3pct（说明自给率对冲失效）

因子2 毛利结构再平衡（分业务线 + 原料敏感权重）

业务线 2025 营收权重 毛利率特征 对碘价/稀土敏感权重 2026H1 趋势
对比剂制剂 56.49% 集采后下降（公司明确："对比剂板块毛利率较上年同期下降"） 高（碘/钆成本占比较高） 收入 +19.89%，毛利率承压
中药制剂 19.97% 提升（"受益于主要原材料价格回落，本期毛利率同比提升"） 低（中药材，非碘） 收入增速放缓，毛利率改善
原料药 11.58% 提升（"产销两旺，规模效应提升，叠加有效的成本管控措施，毛利率增长"） 极高（但是受益方）——碘价上涨对原料药业务是利好（可提价） 收入 +82.91%，毛利率增长
降糖类 10.57% 稳定，集采成熟品种 低 收入 +1.14%，平稳
海外合计 16.58% 高于国内（市场化定价 + 认证稀缺性） 中 收入 +59.85%

最重要的结构性发现：碘价波动对公司是"内部对冲"而非单向冲击——
- 碘价上涨 → 对比剂制剂毛利率受损（成本上升，售价被集采锁死）
- 但海昌药业的原料药业务受益（可市场化提价，且海外客户接受涨价）
- 2026H1 原料药收入 +82.91% 且毛利率增长，正是这一对冲机制在起作用

若只用"综合毛利率"会完全掩盖这个内部对冲结构。分业务看才能发现：一体化不是口号，是真实的成本对冲机制。

因子3 库存与采购节奏（timing）
- ⚠️ 关键警示：2026Q2 公司"对部分存货计提了减值准备"，对利润造成影响。这说明存货管理存在压力
- 碘原料的战略采购：碘价波动大，公司是否做了战略储备未披露。若在高价点位囤碘，将形成库存损失；若在低价位囤货，则形成库存收益
- 区分当期 vs 远期毛利：2026Q2 的存货减值是一次性冲击，不是稳态盈利能力——但需警惕：若 Q3/Q4 继续计提，说明存货管理存在系统性问题
- 验证点：后续季度是否继续计提存货减值；存货周转天数
- 证伪信号：连续三个季度计提存货减值 → 说明采购节奏失控，需下调盈利预测

校正3 杠杆下行情景（高负债？）
- 资产负债率 30.8%，远低于 60% 阈值，不适用高杠杆负面情景
- 但做一个负向压力测试：若集采降价超预期 + 碘价上涨 30%，2029E 营收降至 19 亿、净利率降至 8.5% → 归母 1.45 亿 → PE 18x → 26.1 亿 → 4.49 元 → −44.4%（即悲观情景）
- 该情景下空间转负，但幅度可控（−44.4% 而非毁灭性下跌），因为公司无债务压力、现金流为正

期权纪律执行：
- 世和基因 16.38% 股权——资产存在但未重估、无退出时点 → 不计入中性净利，单独列示为安全边际
- 在研管线 15 个 CDE 审评项目——未获批 → 不计入
- 九味镇心颗粒泰国注册——未获批 → 不计入
- 亳州陆芝葆——在建但投产时点明确（2027H1）且有募集资金到位 → 按产能法部分计入中性（这是"已确定的产能"而非"可能的期权"）

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高（短期），偏低（远期）
- 现价 8.07 元对应 2026E PE 32.4x，高于 A 股同类一体化药企 20–28x 的中枢 → 短期已充分定价 2026 年业绩弹性
- 但对应 2029E PE 仅 16.2x → 远期成长未被定价
- PB 1.88x + 世和基因隐性资产（每股 1.41–2.25 元）→ 下行有实物资产托底

安全边际：
- 中性远期 11.47 元 → 空间 +42.1%（3 年，年化约 12.4%），加上约 0.7% 股息率 → 总回报约 +44%
- 悲观情景 4.49 元 → 下行 −44.4%
- 乐观情景 17.88 元 → 上行 +121.6%
- 风险收益比：上行 42.1% / 下行 44.4% ≈ 0.95 : 1——风险收益基本对称，不占明显优势，这是不给"重点关注"的关键原因
- 下行保护：① 资产负债率仅 30.8%，无债务风险；② 经营现金流 1.34 亿，净现比 168%；③ 世和基因股权（每股 1.41–2.25 元）；④ 密云欧盟标准产能（重置成本高）

介入条件（具体）：
1. 理想介入区：6.5 元以下（对应 2026E PE < 26x、2029E PE < 13x），此时中性空间扩至 +76%
2. 次优介入区：6.5–7.8 元，可分批建仓
3. 观望区：7.8–9.0 元（当前位置），等待更好的价格或更强的验证信号
4. 不追高区：9.0 元以上（2026E PE > 36x）
5. 加仓信号：① 第十二批集采（碘普罗胺）中标价好于预期（降幅 <40%）；② 海昌药业产能利用率披露超 50%；③ 亳州陆芝葆 2027H1 如期投产公告；④ 海外收入占比突破 22%

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 集采降价超预期（首要）：第十二批集采（碘普罗胺）若降价超 50%，将直接压制对比剂板块（占营收 56%+）利润。这是最大的单点风险
2. ⚠️ 2026H1 的高增速不可持续：+166.13% 的净利增速来自"低基数 + 转债摘牌 + 海昌扭亏"三重叠加，Q2 环比已下滑 22.7%。2027 年增速大概率回落至 20% 以下，市场若按 2026 增速线性外推将严重误判
3. ⚠️ 存货减值持续性：2026Q2 已计提部分存货减值。若 Q3/Q4 继续计提，说明库存管理失控，需下调盈利预测
4. 碘价波动：碘价暴涨 30%+ 而集采价锁死 → 一体化对冲部分失效
5. 商誉减值：海昌药业、天原药业收购形成的商誉，若业务不达预期将产生减值
6. 少数股东损益扩大：海昌药业（49% 少数股东）盈利改善后，少数股东分走的利润增加，会稀释归母增速

第五步进阶：上行想象力情景（四类）

类型A 行业调整剩者红利（中等概率，值得认真建模）
- 逻辑：集采是行业出清机器。对比剂集采后，原研（GE Healthcare、Bayer、Bracco）在低价下逐步退出公立医院市场，国产企业承接份额。公司口径："对比剂行业形成了新的竞争格局……公司的市场份额和品牌影响力进一步提升"
- 份额变量锚定：北陆国内对比剂份额从 2026 年约 5.6% → 2029 年 7.0%（中性）→ 9%（乐观，若原研加速退出）
- 剩者红利测算：若份额达 9%，国内对比剂收入 = 120 亿 × 9% = 10.8 亿（vs 中性 8.3 亿，多 2.5 亿），按 13.2% 净利率 × 0.93 = 0.31 亿额外净利，23x PE = 7.1 亿市值 = 每股 +1.22 元
- 可验证触发点：① 抽样医院数据显示原研份额下降；② 公司集采执标量超预期；③ 新省份/新联盟集采中标
- 证伪信号：原研通过降价保住份额；国产同行（司太立、恒瑞）抢份额更快
- 纪律：份额 7% 已计入中性，9% 部分仅进乐观情景

类型B 政策反转期权（部分适用：集采"反内卷"）
- 具体政策：国家医保局自第十一批国采起强调"稳临床、保质量、防围标、反内卷"，不再单纯以最低价中标
- 反转信号：① 第十二批集采（碘普罗胺）实际降幅低于前几批；② 集采续标价格企稳或回升
- 重估弹性测算：若集采降价幅度从"50%+"收敛至"30%"，对比剂板块净利率可提升 3–4pct → 2029E 归母净利从 2.90 亿升至约 3.4 亿，23x PE → 78.2 亿 → 13.44 元（+66.5%）
- 纪律执行：政策转向尚未在碘普罗胺上验证 → 仅作机会情景，不计入中性锚
- 证伪信号：碘普罗胺第十二批降幅仍超 50%；续标价格继续下探

类型C 市场错杀修复（不适用）
- 错杀证据检查：① 估值分位——PE(TTM) 32.94x、2026E PE 32.4x，处于偏高位置，不是低估；② 相对行业折价——高于同类一体化药企 20–28x 中枢，无折价；③ 基本面——基本面在改善且在加速，不存在"基本面未恶化却被错杀"的情形
- 判断：不存在错杀。本类不适用

类型D 技术突破/技术代际跃迁期权（不适用，但有"技术迁移"的弱版本）
- 严格定义检查：公司没有从 0 到 1 自研突破一条全新技术路线。对比剂是成熟品类，公司做的是"工艺优化 + 一体化 + 国际化"
- 三要素检查：① 政策驱动技术路线——弱（无强制替代/标准升级）；② 行业趋势向该技术收敛——弱（无成本曲线交叉）；③ 公司技术投产落地——部分成立（海昌 1000 吨产能、欧盟标准产线），但这是产能扩张而非技术跃迁
- 判断：本类不适用，属"主业迁移（类型B 的变体：出海）"而非"技术突破"
- 可归入的机会："认证稀缺性"带来的出海红利已在层2 主业迁移中处理（部分计入中性）

什么条件出现才上调至"重点关注"：
1. 价格条件：股价回落至 6.5 元以下（2026E PE < 26x），中性空间自然扩至 +76%
2. 基本面条件（需满足两项）：① 第十二批集采（碘普罗胺）降幅 <40%；② 海昌药业产能利用率披露 >50%；③ 海外收入占比突破 22%；④ 单季综合毛利率回升
3. 期权条件（硬验证点）：① 世和基因 IPO/并购退出公告（释放每股 1.41–2.25 元价值）；② 亳州陆芝葆 2027H1 如期投产且当年贡献收入 >1 亿元
4. 满足价格条件 或 同时满足两项基本面条件即可上调

结论：纳入观察

核心理由：
① 中性远期空间 +42.1%，未达"重点关注"的 >50% 门槛（差 8pct）；
② 风险收益比约 0.95:1（上行 42.1% / 下行 44.4%），基本对称，不占优势——这是不给"重点关注"的决定性因素；
③ 现价 2026E PE 32.4x 高于同类 20–28x 中枢，短期已定价业绩弹性；
④ 但公司质地扎实：低负债（30.8%）、强现金流（净现比 168%）、一体化对冲、出海认证齐备、集采冲击接近尾声 → 属于"逻辑正确但需等更好价格"的典型；
⑤ 下行有实物资产托底（世和基因股权 + 密云欧盟标准产能 + 低负债），悲观情景 −44.4% 而非毁灭性下跌。

为什么不是"重点关注"：空间差 8pct，且风险收益对称。若股价回落至 6.5 元以下，或集采降幅好于预期，立即上调。
为什么不是"暂不介入"：基本面明确向上（出海 +59.85%、原料药 +82.91%、财务费用永久性下降），远期空间 +42.1% 显著为正，且下行有资产托底。

核心跟踪点：① 第十二批集采碘普罗胺中标价；② 海昌药业产能利用率；③ 亳州陆芝葆 2027H1 投产；④ 季度存货减值计提；⑤ 世和基因资本运作进展。
