（3）产业链传导

上游：电子元器件（IGBT/MCU，部分依赖进口、交期曾 >26 周）、钣金、传感器。成本随电子价格小幅波动，国产化降低采购成本但公司规模小议价弱。

下游：油气/化工/市政（强周期、项目制、账期长）。议价权弱——客户为大型国企，压价 + 长账期，毛利率（尤其油气服务 14%）偏低。

议价权判断：弱。中小型工控集成商，在头部（中控/和利时）与下游大客户双重挤压下，议价权低；油气周期下行进一步削弱。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • ① 成本传导弹性（转嫁系数）：主要成本为电子元器件 + 人工 + 项目交付，对下游大客户转嫁系数≈0.2（弱）——项目制招标定价，成本自行消化；油气服务毛利率仅 14% 印证。
  • ② 毛利结构再平衡：分业务毛利率——数字经济（其他）73.81%（高但占比仅 10.75%）、自动化 26%、油气服务 14.08%（主体之一，毛利承压）。结构分化：高毛利的数字经济占比小，低毛利的油气服务占比 42.59% 且下滑，加权毛利被拉低；若新能源/微电网（潜在中高毛利）放量可修复。
  • ③ 库存与采购节奏（timing）：项目制有原材料/在制库存，2026H1 营收大降、现金流为负说明回款慢于采购付款（非库存收益，是占用）；无长协/套保披露。
  • ④ 政策/市场锚点（成本驱动变量）：a) 工控国产化（政策层）：若电子元器件国产替代加速，采购成本下降（验证点=国产 MCU/IGBT 采购占比）；b) 油气资本开支（市场层）：国际油价波动 → 国内油气勘探开发投资预算，直接影响下游订单（情景：油价下行→CAPEX 缩减→订单延后，验证点=油气企业 CAPEX 指引）；c) 设备更新补贴/强制替代（政策层）：2027 前 80 万台套 OS 更新创造订单（验证点=国企集采中标）。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：工控市场 2800 亿、PLC 180 亿，公司产能（营收 2 亿级）占比极小（<0.1%）。
  • 需求侧/客户份额：油气主干客户认证壁垒高，但公司份额趋势向下（营收连降）。
  • 技术代际差：RTU/PLC 处行业中游，落后头部（中控/和利时）一代（验证点=中标项目技术参数）。
  • 成本曲线位置：规模小、毛利低（油气服务 14%），成本曲线劣势。
  • 份额二阶导数：主业处于萎缩段（油气周期下行 + 竞争）。
    → 三档：保守守住（营收 2.2 亿）/ 中性小幅（2.6 亿）/ 乐观抢份额（难，3.5 亿+）。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：从"油气工控"迁移到"新能源微电网 + 数字经济"，TAM 扩至新能源（更大）。五点：① 能力可迁移（同源工控，中）；② 新 TAM 弹性（新能源数倍）；③ 切入卡位（早早期）；④ 客户认证门槛（新市场新门槛）；⑤ 信号验证（微电网仅试点、收入未成规模 = 未过验证点）。→ 计入中期期权，不计入中性净利。
  • 层3 风险折扣（证伪信号）：营收持续下滑、工控集采连续未中标、毛利率破 20%、诉讼赔付超预期。命中则下调。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：资产负债率 60.7%（偏高），净资产 4.09 亿但含应收账款（回款风险）、商誉/长期资产；非破净（PB 8.07x，市值远高于净资产），但高 PB 反映壳/题材溢价而非资产质量。无金融资产未重估型托底（未披露持股上市公司）。→ 不适用"破净真便宜"逻辑。
  • 校正2 周期位置校正：油气工控处油气资本开支下行周期（国际油价波动 → 国内勘探开发投资放缓、项目暂缓/回款延迟），非底部反转；国产化替代是政策小周期，公司受益程度待验证。中性净利已取保守企稳值，未假设反转。
  • 校正3 杠杆下行情景：资产负债率 60.7% + 经营现金流为负（−0.51 亿）+ 诉讼赔付不确定，经营杠杆 + 财务杠杆 + 法律风险三重叠加；若油气持续下行 + 诉讼判赔，亏损放大且净资产侵蚀，悲观情景市值可跌至 3 亿（0.19 元），空间 −91%，故不得标"大空间/重点关注"。
  • 期权纪律：新能源微电网/数字经济迁移未过收入规模验证点，仅作乐观情景，不计入中性 NAV/净利。

亏损股三问

  1. 为什么亏：2026H1 归母 −0.49 亿、全年预计 −0.85 亿（扩大），主因油气周期下行（勘探开发投资放缓、项目暂缓/回款延迟）+ 三块业务营收全降 + 诉讼赔付不确定；属"周期 + 主业弱化型亏损"。
  2. 靠什么扭亏·触发时点：路径仅靠国产化替代政策红利 + 潜在重整/重组，均未经确证公告；中性假设 2026–2028 难实质扭亏。
  3. 亏得起吗：净资产 4.09 亿、资产负债率 60.7%、经营现金流 −0.51 亿、诉讼未结案；虽未到资不抵债，但现金消耗 + 负债偏高，抗风险能力弱，亏得较勉强、依赖再融资/题材预期支撑。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估（脱离基本面）。现价 2.11 元（市值 33 亿）对应净资产 8x PB、营收 13.8x PS（年化 2.4 亿），基本面支撑仅为壳/题材预期。

安全边际：中性远期 0.28 元 → 空间 −86.7%；悲观 0.19 元（−91.0%）；乐观 0.96 元（−54.5%，需国产替代+新能源双兑现）。无任何安全边际。

介入条件：
1. 原则上不介入。仅当出现以下确证信号才 reconsider：① 正式公告重大资产重组/国资资产注入；② 连续两季度扭亏且营收恢复正增长；③ 工控国产化大单（≥0.5 亿）中标公告；④ 诉讼结案且赔付可控。
2. 当前价位严禁追高——估值锚缺失，下行风险为本金大幅损失。

最大风险（最可能破坏逻辑的因素）：
1. 基本面持续恶化（首要）：营收三块全降、亏损扩大，油气周期下行 + 头部挤压使主业难企稳。
2. 诉讼赔付风险：前期信披违规引发中小股东诉讼未结案，赔付金额不确定，可能冲击净资产。
3. 负债与现金流：资产负债率 60.7%、经营现金流为负，若融资收紧则生存压力上升。
4. 壳/题材预期落空：市值靠国产化/重整预期支撑，一旦证伪，戴维斯双杀至清算价值。

结论：暂不介入（基本面弱、估值高、诉讼风险未明、无明确扭亏路径；非"坚决回避"因存在国产化政策期权与潜在重整可能，但均无确证，不构成买入理由）。

与"坚决回避"的区别：安控虽基本面羸弱，但未达"净资产趋零/连续大额亏损致生存危机"的确证回避阈值（净资产仍 4 亿）；其风险更多体现为"高估 + 不确定"。故判暂不介入——等待确证信号（扭亏/重组/大单）再评估，期间严禁追高。
