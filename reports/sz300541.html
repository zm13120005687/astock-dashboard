（3）产业链传导

上游：服务器、存储、网络设备、数据库/中间件（华为、腾讯云等）。上游国产化供应链成熟，公司对上游议价权中等（集采规模决定）。

下游：银行/互联网/烟草。银行端需求刚性（政策强制），互联网端波动大（2026H1 骤降）。

议价权判断：中等偏弱。项目制 + 客户集中，基础设施毛利率仅 7.94% 反映低价竞争；软件解决方案毛利率 34.65% 体现一定技术壁垒。银行信创核心攻坚期客户粘性增强，但价格战仍存。

第二步进阶·原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：金融 IT 无实物原料，"成本"为人力 + 软硬件采购。人力成本刚性（转嫁系数低 ~0.3），硬件外采可部分转嫁。验证点：毛利率、人均产出；证伪：毛利率持续低于 10%。
  • 因子2 毛利结构再平衡：高毛利软件解决方案（34.65%）占比仅 10.66%，低毛利基础设施（7.94%）占 79.62%——结构失衡是盈利脆弱主因。改善方向：提升软件/AI 平台占比。验证点：软件收入占比；证伪：结构进一步恶化。
  • 因子3 库存与采购节奏：存货 15.56 亿（+23.67%，部分合同未达确认），无原料囤货收益；研发投入资本化低。验证点：存货周转、合同履约义务；证伪：存货减值。
  • 因子4 政策/市场锚点：政策层——信创强制替代、AI 安全应用指导意见直接驱动银行 IT 预算；市场层——互联网客户资本开支周期（2026H1 收缩）。情景：银行信创加码利好、互联网复苏利好。验证点：招标数据、客户 Capex；证伪：信创推进不及预期。

第三步进阶·份额变量与主业迁移空间三层法

  • 层1 市场容量 × 份额变量：金融信创 3000 亿市场、核心系统国产化率仅 20%（提升空间大）；先进数通在股份行/城商行有客户基础，份额假设：保守守住 / 中性随行业 beta 小幅提升 / 乐观抢信创份额。验证点：中标公告、核心系统订单。
  • 层2 主业迁移空间：从"基础设施集成"迁移至"AI 大模型金融软件平台"——能力可迁移（多年金融软件积累），新 TAM（AI 代码助手/智能风控）弹性大；处验证点前（研发转化中），计中期期权，不计入中性。
  • 层3 证伪信号：互联网端持续萎缩、基础设施毛利率跌破 7%、在手订单交付不及预期、AI 平台无商业化订单。

第四步：估值锚定（正常化净利润法——亏损股主估值法）

为什么用正常化净利润法：2026H1 实际亏损，PE 估值无意义。按 RULES 三步：估稳态营收 → 保守正常化净利率 → ×远期合理 PE → 目标市值 → 目标价。总股本 约 4.26 亿股。

三问（亏损股必答）

  1. 为什么亏（业绩塌陷主因）：① 互联网行业客户需求骤降 36.29%（4.43 亿→），IT 基础设施营收与毛利率同步下降，毛利较上年减 4157 万；② 软件方案收入降 + 运维成本增，两项合计毛利减 1624 万；③ 研发投入 4984.87 万（+35.88%）前置；④ 投资收益由 +145 万转 −539 万。属"需求波动 + 研发投入前置"型亏损，非主业永久性恶化。
  2. 靠什么扭亏（拐点/触发时点）：银行/区域性银行收入已逆势高增（+26%/+22%），金融信创核心攻坚 2026–2027 为强制窗口；在手订单 24.96 亿创新高提供收入底座；AI 大模型平台提升软件高毛利占比。触发时点：2026H2–2027 随银行信创订单确认 + 互联网端企稳，净利回正。
  3. 亏得起吗（生存能力）：货币资金 1.99 亿（较年初 −75.87%，因归还短借/票据），短期借款 5.15 亿（−34.77%），经营现金流 −3.27 亿（较上年 −9.11 亿改善 64%）；存货 15.56 亿可交付变现。整体靠银行授信 + 订单周转可撑至扭亏，但货币资金大幅下降需警惕流动性。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高。现价对应正常化 2029 PE 约 21x，已计入扭亏与信创预期。

安全边际：中性远期 9.56 元 → 空间 +3.0%；悲观 4.23 元 → −54.4%；乐观 16.43 元 → +77.0%。下行风险显著（互联网端 + 流动性），上行靠信创 + AI。

介入条件：① 现价附近可小仓观察，回落至 7.5 元以下（正常化 PE < 17x）加仓；② 加仓信号：银行核心系统大单公告、AI 平台商业化订单、互联网端同比转正、经营现金流转正；③ 观察：货币资金余额、存货去化。

最大风险：① 互联网客户需求持续收缩；② 金融信创价格战致毛利率破阈；③ 货币资金紧张引发流动性压力；④ AI 研发转化不及预期。

结论：纳入观察（远期空间 +3.0%，0<空间≤50%，扭亏路径清晰但估值已反映）

第五步进阶·上行想象力四类
- A 行业调整剩者红利：金融信创集中度提升，头部+特色厂商份额上行——验证点：中标份额；证伪：份额流失。
- B 政策反转期权：信创强制替代 + AI 安全应用指导意见加码——验证点：招标规模、政策发文；重估弹性：银行 IT 预算上行。
- C 市场错杀修复：若因亏损被错杀至 7 元以下（正常化 PE < 15x），估值分位极低——验证点：相对行业折价 + 基本面未恶化。
- D 技术突破/代际跃迁：Starring AI+ 金融大模型平台从研发到规模商用——硬验证点：客户定点 + 量产成本优于旧路线（未完全满足），计机会情景。
- 上调重点关注的触发条件：银行核心系统大单 + AI 平台商业化使 2029 净利上修至 2.5 亿+（市值 55 亿+，空间 > 50%）。
