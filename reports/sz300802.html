盈亏判定：盈利股（2026H1 归母 +0.622 亿，同比 +24.19%；队列未标亏）

一句话定位：工业机器视觉检测（AOI）设备龙头，叠加控制线缆组件与半导体设备电气盘柜（控制单元），受益 AI 服务器 / 光模块 / 半导体国产化三条高景气主线。

（2）市场端（量价数据）

  • 机器视觉 / AOI：受 AI 服务器、高速通信、半导体封测驱动，高精度检测需求高景气（行业增速数据仅作背景，非公司增速外推依据）。
  • 光模块：2026 市场持续景气，公司 AVI 将检测延伸至成品外观环节，打开增量。
  • 半导体设备电气盘柜：国产半导体 capex 旺盛，公司该业务收入 +150.32%，是核心增长引擎。
  • 价格：机器视觉毛利率 45% 维持高位；控制线缆 / 控制单元毛利率仅 16% 左右（低毛利业务占比提升致综合毛利率 Q2 降至 24.17%）。

（3）产业链传导

上游：机器视觉 = 工业相机 / 光学镜头 / FPGA；控制线缆 = 铜（成本敏感）；控制单元 = 电气元件 / 铜 / 钣金。
下游：电子制造 / 半导体封测 / 光模块厂（客户集中度高、议价强）。
议价权：机器视觉 强（技术壁垒 + AI 溢价，毛利率 45%）；控制线缆 / 控制单元 弱（标准化、铜价难传导）。

（2）进阶 · 原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：机器视觉 转嫁系数 ≈ 0.9（高毛利印证强议价）；控制线缆 转嫁系数 ≈ 0.3–0.5（铜价上涨难向客户传导，毛利率仅 17%）；控制单元 ≈ 0.4（半导体盘柜定制但元件成本刚性）。
  • 因子2 毛利结构再平衡：综合毛利率 28.74% 由机器视觉（45%）拉高，但低毛利控制单元（16%）收入 +150% 使结构权重下移——2026Q2 综合毛利率已降至 24.17%。加权利润贡献向"高量低利"的控制单元迁移，需警惕结构摊薄。
  • 因子3 库存与采购节奏：铜价高位时线缆成本承压；公司未披露大额套保，当期毛利反映现货铜价（无低价囤货虚增证据）；马来西亚基地本地化降低部分贸易成本。
  • 因子4 政策 / 市场锚点：铜价（线缆成本驱动）、半导体国产化节奏（控制单元需求）、AI / 光模块 capex（机器视觉需求）、汇率（汇兑损益）。验证点：铜价、半导体设备招标、公司汇兑损益；证伪：铜价大涨传导失败致线缆毛利率破 14%、半导体 capex 放缓。

（3）进阶 · 份额变量与主业迁移空间三层法

  • 层1 现有业务（份额变量）：机器视觉 AOI 国产替代窗口，用 5 锚点——①供给侧（国产 AOI 产能）、②客户份额（半导体封测 / 光模块厂认证）、③技术代际（AI 推理模型领先）、④成本曲线（规模化）、⑤份额加速度（渗透率提升期）。验证点：出货量、客户公告；证伪：价格战致机器视觉毛利率破 40%。
  • 层2 主业迁移（新易盛范式）：机器视觉 → 光模块 AVI 成品检测（技术同源，已推出）；控制单元 → 半导体设备配套（新 TAM 大，已 +150% 验证）。部分已验证，可作中期偏实期权，但 2029 中性仍按保守爬坡计、不计入爆发。验证点：AVI 大额订单、半导体客户份额公告。
  • 层3 证伪：半导体 capex 放缓、AI 资本开支退潮、机器视觉价格战、汇兑持续大额损失。

第四步：估值锚定（自下而上，非增速外推）

方法：按三条业务线分别测算（机器视觉高毛利稳态 + 控制单元放量 + 线缆平稳），用产能 / 订单节奏校验，不采用历史增速外推。当前 PE(TTM) 约 65–80x，已显著反映成长预期。

（4）进阶 · 重资产 / 周期股估值三道闸

  • 校正1 资产质量折扣：净资产 15.0 亿，PB 5.41x（高溢价反映成长预期，非破净）；轻资产、现金充裕，无资产折价。高 PB 是"成长定价"而非"低估信号"。
  • 校正2 周期位置校正：机器视觉 / 半导体处 AI capex 上行周期，非顶部；但半导体 / 光模块具强周期属性，中性净利用中性爬坡（不按 2026 高增长年化）。
  • 校正3 杠杆下行情景：资产负债率 25.86% 适中，无高负债下行；但汇兑（利率 / 汇率）是明确下行情景——2026H1 已因汇兑损失 1712 万侵蚀利润，若人民币升值持续，悲观情景空间可至 -42%。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（2026E PE 约 63x，已透支未来 2–3 年成长）。

安全边际：中性远期 -8.2%（现价已超合理锚）；乐观 +46.4% 需半导体 / 光模块超预期；悲观 -42.2%（汇兑 + 周期下行）。

介入条件：
1. 回调至 ≤ 22 元（2026E PE < 50x、2029E PE < 28x）才具安全边际；
2. 上调至"重点关注"条件：控制单元连续 4 个季度保持 >80% 增长、AVI 获光模块大厂正式订单、机器视觉毛利率稳守 >42%。

最大风险：
1. 半导体 / 光模块 capex 周期性退潮（高景气反转）；
2. 低毛利控制单元占比提升摊薄综合毛利率；
3. 汇兑损失持续（利率 / 汇率下行情景）；
4. 机器视觉价格战致高毛利业务毛利率破 40%。

第五步进阶 · 上行想象力情景（四类，对冲系统性保守偏置）

  • 类型A 行业调整剩者红利：机器视觉 AOI 国产替代，行业集中度提升，公司凭 AI 推理模型领先份额跃升。验证点：出货量、客户公告；证伪：价格战致机器视觉毛利率破 40%。
  • 类型B 政策反转期权：半导体设备国产化（大基金三期）、AI 算力建设加码，控制单元（电气盘柜）与 AOI 需求超预期。验证点：半导体设备招标、政策发文；仅作机会情景。
  • 类型C 市场错杀修复：若半导体 / 光模块系统性回调错杀，公司全球布局 + 马来西亚基地提供估值修复弹性。验证点：市场企稳、风格回归。
  • 类型D 技术突破 / 代际跃迁：AVI 光模块成品检测、AI 推理模型泛化获大厂定点，重构检测格局。硬验证点：客户定点 + 量产成本优于旧路线；缺一则仅作机会情景，不计入中性。

上调至"重点关注"条件：控制单元连续 4 季 >80% 增长、AVI 获光模块大厂正式订单、机器视觉毛利率稳守 >42%，中性远期空间转正并突破 +50%。

结论：暂不介入（现价 80x TTM 已充分定价成长，中性远期空间为负；等回调至 22 元以下或增长验证后 reconsider）。
