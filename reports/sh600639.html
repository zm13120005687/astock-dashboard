（3）产业链传导 + 第二步进阶：成本/收入 → 毛利结构（四因子，园区口径）

  • 因子1 成本传导弹性：租金端转嫁系数≈0（空置率 22%+、租户强势）；成本端建安与融资成本下行（LPR 低位）部分对冲——公司实际毛利承压主要来自"收入降价"而非"成本涨价"。议价权弱转稳。
  • 因子2 毛利结构再平衡：H1 综合毛利率 46.86%（同比 −10.87pct）：高毛利租赁（收入 −6.53%）占比收缩 + 低毛利住宅销售结转（碧云澧悦，毛利率 ~20%）占比升至 18.5% + 壹中心新增折旧 0.26 亿——结构性毛利率下移，非经营恶化。分业务毛利率：租赁 ~60%+、销售 ~20%、酒店公寓中等。估值必须分业务算利润：住宅销售贡献 H1 归母的 32.56%（金桥房产净利 0.40 亿）。
  • 因子3 库存与去化节奏（timing）：合同负债 33.82 亿（较年初 +12.7%），其中碧云北外滩累计收款 30.07 亿——"已售未结"底仓厚实，H2 交付结转是全年业绩主引擎；上半年无新增土储与竣工，碧云综合体东地块开工——拿地节奏收缩控制风险。
  • 因子4 政策/市场锚点（情景 + 验证点）：①沪八条后金九银十成交（验证点：9–10 月上海新房网签环比，证伪=环比回落 >20%）；②写字楼租金环比转正（验证点：仲量联行 Q3/Q4 租金指数，证伪=跌幅重新扩大至 −2% 以上）；③REITs/大宗交易估值锚（验证点：上海大宗成交额维持 200 亿+/半年，证伪=资本化率大幅上行）。证伪信号：出租率跌破 68%、租赁收入单季同比跌幅超 −10%、碧云北外滩交付延期。

进阶·增量拆解三层法

  • 层1 现有业务：市场容量 × 份额变量：①市场容量：上海产业园区/写字楼需求 2026H1 净吸纳量 44.5 万㎡（同比 +135%），AI 产业链是主引擎；②份额变量锚点——供给侧：金桥开发区产业定位（汽车电子+通信+智造）与 TMT/AI 需求扩张方向重合，智造类载体 80%+ 出租率（行业甲级 77.5% 空置率口径下的相对稀缺）；客户份额：碧云品牌对外籍/中产客群粘性（服务式公寓续租）；技术代际：壹中心为新一代载体，升级型需求受益者。三档：保守=出租率守住 70%、中性=2027 年回升至 75%、乐观=80%+（验证点=逐季出租率与租赁收入环比）。二阶导：净吸纳量已连续两季上行（S 曲线早段回升）。
  • 层2 主业迁移空间（中期期权，未过验证点不计中性）："园区房东→产业生态组织者+投资人"（双轮驱动战略）：能力可迁移性高（园区招商即产业组织）、新 TAM 弹性大（基金化投资收益 + 硬科技退出）、但当前处于布局期（金桥投资合伙 H1 净亏 157 万、基金未退出）。信号验证=单只基金实现退出收益 >1 亿或产业投资收益占利润总额 >10%，达标前仅作期权。
  • 层3 证伪信号：①出租率连续两季下滑跌破 68%；②碧云北外滩交付延期或后续无新盘接续（2027 年销售弹药断档）；③新通信产业园招商去化低于 50%；④AI 需求退潮致 TMT 租赁占比回落。

第四步进阶·三道校正

  • 校正1 资产质量折扣（破净原因必须说明）：PB 0.72x 破净。原因：①园区/商业地产估值中枢随资本化率上行系统性下移，市场担心投资性房地产与存货隐性减值；②租赁收入连续下滑（−6.53%）压制 ROE（2025 年 7.3% → 2026H1 年化 ~1.6%，主因壹中心折旧前置）；③60% 负债率下利率敏感性折价。部分属于"资产未按市价重估"的对冲证据：2026H1 上海大宗交易 233 亿（+47%）、首批商业不动产 REITs 上市——优质园区资产的公开市场退出通道已打开，若公司以 REITs/ABS 方式处置壹中心等资产且定价不低于账面，破净即属真安全边际。验证点：公司资产证券化公告或大宗出售成交价；证伪：后续计提投资性房地产减值。综合判断：破净为"半真"安全边际——净资产可部分信任（国资平台、资产位于上海、大宗市场回暖），但需打折使用，禁止单凭 PB<1 推大空间。
  • 校正2 周期位置：上海园区/写字楼处周期底部（空置率回落、租金跌幅收窄、净吸纳量反弹），中性净利按"租金企稳"而非"租金反转"假设，未把 2026H1 的 44.5 万㎡净吸纳量反弹外推为租金上涨。
  • 校正3 杠杆下行情景（负债率 60.11%、有息负债 203.9 亿，必做）：短债占比 38.2%。若利率上行 100bp + 租金再跌 5%，利息支出 +2 亿、租赁毛利 −1 亿，净利可降至 6.5–7 亿，PE 下修至 10x（市值 68 亿，股价 6.06 元，−36%）——负面情景空间转负，故不得标"重点关注"，至多"纳入观察"并注明高贝塔属性。
  • 期权纪律：产业投资基金退出收益、"6G+AI&卫星通信"产业集群估值溢价均未过验证点，不计入中性净利/NAV，仅进乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：便宜但非深度便宜。9.49 元 = 2026E PE 13.0x / PB 0.72x，高于基准估值 9.2 元约 3%，低于中性远期 10.78 元约 12%——市场已定价了部分租金下行，未定价 2027 年后的租赁修复。

安全边际：
- 中性远期 10.78 元 → 空间 +13.6%，不达"重点关注" >50% 门槛
- 悲观 6.24 元（−34.2%）vs 乐观 16.04 元（+69.0%）：赔率分布右偏但左尾不浅（杠杆 + 供应压力）
- 下行缓冲：合同负债 33.82 亿（已收款待结转）、每股净资产约 13.4 元、国资平台融资信用、H1 经营现金流 8.89 亿大幅转正（上年同期 −10.35 亿）

上行想象力情景（只进乐观/机会栏，不进中性锚）：
- 类型A 剩者红利：上海园区市场出清后，国资平台凭低成本资金与产业资源逆势收资产、扩份额。验证点：公司新增收并购/拿地公告；证伪：持续零拿地零并购。
- 类型B 政策反转期权：商业不动产 REITs 扩容——若公司将壹中心/碧云资产打包申报 REITs（政策已明确支持），一次性重估 + 轻资产化。重估弹性：按 3.5%–4.5% 分派率反推，资产估值可较账面上浮 10–20%，市值弹性 +15–30 亿。验证点：REITs 申报受理公告；证伪：公司明确表态不做资产证券化。
- 类型C 市场错杀修复：地产链情绪压制下园区平台整体折价，若 2027 年租金数据转正引发板块修复，PB 0.72x→0.85x（11.4 元，+20%）。触发点：仲量联行季度租金环比转正 + 板块PE 修复至 15x。
- 类型D 技术突破期权：不适用。
- 上调至重点关注的条件：①REITs 申报落地；②出租率连续两季 ≥78% 且租赁收入同比转正；③产业基金实现首个退出收益 >1 亿。三者有其二即上调。

介入条件：①价格回落至 8.6 元以下（2026E PE 12x / PB 0.65x）安全边际增厚；②或验证信号出现——Q3 出租率回升 + 碧云北外滩如期交付结转公告后右侧介入。
最大风险（最可能破坏逻辑的因素）：①2027 年销售结转断档（北外滩之后无大体量待结项目）；②写字楼下半年 52 万㎡新供应压制租金继续下行；③203.9 亿有息负债的利率与再融资风险。

结论：纳入观察

理由：逻辑正确（现金流大幅转正 + 北外滩锁定结转 + 租赁市场筑底 + 国资信用），但中性空间 +13.6% 不足 50%，且 60% 负债率负面情景空间转负，按规则至多"纳入观察"并设条件单。核心跟踪点：Q3/Q4 出租率与租赁收入环比、碧云北外滩交付进度、REITs 政策催化。
