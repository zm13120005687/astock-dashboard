第一步：公司是干什么的？

一句话定位：原玩具制造商，已彻底转型为"酒类销售 + 智能算力租赁 + 物业租赁"三轮驱动，其中酒类为现金牛、智算为高弹性成长引擎（与腾讯的算力合同为核心变量）。

核心产品：中高端白酒（线上电商+直播+线下团购批发）；GPU 算力租赁（自建智算中心）；工业园区/高端物业租赁。

主要客户/下游：酒类—中高端白酒品牌方与团购渠道；智算—互联网头部客户（腾讯，据公告）；物业—汕头澄海工业区及杭州项目租户。

境内外收入占比：基本境内。

股东背景：原实控人王叁寿（2024 年配合调查，未在上市公司任职）；现经营管理层主导转型。

（3）产业链传导

上游：智算业务上游为 GPU 服务器/电力，公司自建合规高性能算力资源，上游成本刚性；酒类上游为酒厂，进价随名酒价格波动。

下游：智算下游为互联网大厂（腾讯等），客户集中度高、议价权在客户；酒类下游为 C 端+团购。

议价权：智算端弱（依赖单一头部客户续约）；酒类端中（渠道品牌运营）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：智算—GPU/电力成本刚性，公司几乎无转嫁能力（传导率≈0），毛利取决于与客户合同定价；酒类—进价波动部分可转嫁但竞争激烈，传导率≈0.3–0.5。
  • 因子2 毛利结构再平衡：分业务看，物业高毛利（稳定）、智算高毛利（但 H1 计提减值 −4089 万致整体净利率 −21.95%）、酒类低毛利。综合毛利率 4.67% 掩盖了"智算高毛利但被减值吞噬"的结构。
  • 因子3 库存与采购节奏：酒类存在渠道库存周期（行业去库存）；智算为资本开支前置（2024 建成智算中心），折旧/减值在 H1 集中体现。
  • 因子4 政策/市场锚点：①算力政策（政策层）—国产算力需求政策驱动，验证点：杭州 AI 产业政策、大厂 Capex；②GPU 供给（市场层）—H20/国产 GPU 供给与价格；③白酒库存（市场层）—渠道库存去化进度。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量：智算市场高速扩容（算力需求年增 30%+），公司份额小（营收仅 0.3 亿 vs 行业千亿级），份额提升锚点：①供给侧—自有算力稀缺性；②客户份额—腾讯单客户依赖（风险）；③技术代际—合规高性能算力；④成本曲线—自建 vs 租赁；⑤份额加速度—H1 +70% 显示加速。验证点：续约公告、新增客户。
  • 层2 扩展业务：主业迁移空间：从玩具→酒类→智算，属"能力不相关迁移"，智算成功依赖算力运营能力（已初步验证增速），但未过"多客户+持续盈利"验证点，仅作中期期权。
  • 层3 风险折扣（证伪信号）：腾讯不续约、智算减值扩大、酒类库存恶化——命中则下调。

第四步：估值锚定（自下而上，非增速外推）

方法说明：本报告不使用历史增速外推。群兴为亏损股，采用正常化净利润法：估稳态营收（酒类+智算+物业）→ 保守正常化净利率 → × 远期合理 PE。亏损股三问见后。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 3.83 高，因轻资产转型 + 概念溢价，但 2026H1 净资产仅 7.99 亿、仍亏损，高 PB 是预期而非资产安全垫，不得据此推空间。
  • 校正2 周期位置校正：算力处扩产周期（供给过剩隐忧），白酒处去库存周期底部；中性净利已按"续签平稳"归一化，未用单季高增外推。
  • 校正3 杠杆下行情景：资产负债率约 9%（低负债），但客户集中（腾讯单点）使经营杠杆极高；若续约失败，智算收入断崖、减值扩大，净利转负、空间转负——不得标大空间。

亏损股三问

  1. 为什么亏：智算业务 H1 计提资产减值 −4089 万（合同末期/资产重估）+ 酒类低毛利；营收增但利润被减值吞噬。
  2. 靠什么扭亏·触发时点：腾讯算力合同续签（2026 年 9 月底到期）是核心；续签且金额≥现约 → 智算稳利，2027 年可扭亏。
  3. 亏得起吗：总资产 8.79 亿、净资产 7.99 亿、资产负债率约 9%，现金充沛，短期不致命；但持续减值会侵蚀净资产。

第五步：综合赔率判断（买不买？）

当前价格位置：显著偏贵/投机。现价 5.05 元已隐含腾讯续约+智算扩容的乐观预期，正常化 PE 远超合理区间。

安全边际：
- 中性远期 2.83 元 → 空间 −44.0%
- 悲观 1.40 元 → 下行 −72.3%
- 乐观 5.60 元 → +10.9%（需腾讯续约扩容，确定性低）
- 下行保护弱：高 PB 无资产兜底，价值全在预期

介入条件：
1. 现价 不追高。等回落至 3.0 元以下（对应正常化 PE<25x）
2. 加仓信号：①腾讯算力合同正式续签且金额≥现约；②新增第二/第三大智算客户；③智算减值计提完毕、净利率转正

最大风险：
1. 腾讯合同到期不续签或大幅降价（首要，9 月底窗口）——智算收入断崖
2. 智算资产持续减值
3. 白酒去库存延长、酒类毛利下滑
4. 概念退潮后高 PB 估值回归

结论：暂不介入

理由：当前价格已透支乐观情景，中性远期空间 −44.0%；唯一向上驱动是腾讯续约这一单点变量，且截至分析日未确认。属"事件博弈"而非价值标的。若腾讯合同续签且金额不低于现约，可重估至"纳入观察"。

第五步进阶：上行想象力情景（四类，仅进乐观/机会栏）

  • A 行业出清剩者红利：算力租赁行业洗牌加速，中小算力运营商（高能耗、无客户）出清，合规高性能算力稀缺性提升；公司若凭已建智算中心资质留存可获份额。验证点：行业出清公告、公司算力利用率。证伪：客户集中单一+减值扩大。→ 上调重点关注条件：腾讯续约且金额≥现约 + 新增第二/第三大客户 + 智算减值计提完毕净利率转正。
  • B 政策反转期权："人工智能+"行动、算力网（"十五五"全国一体化算力网新增直接投资超 4 万亿元）、杭州定位"全国 AI 第一城"政策持续加码，智算需求扩容。验证点：政策发文、大厂 Capex 指引。重估弹性：智算租赁量价齐升。→ 上调条件：政策拉动下游需求 + 公司算力合同扩容。
  • C 市场错杀修复：若腾讯合同正式续签落地，市场从"亏损概念"修复为"确定性现金流"，估值回归正常化 PE（25–30x）。验证点：续约公告、单季净利转正。→ 上调条件：续约公告 + 2027 年扭亏且可持续。
  • D 技术突破/代际跃迁期权：算力从纯租赁 → 智算服务/AI 应用，若自研算力调度平台或拿下大模型训练集群订单（从 0 到 1）。硬验证点：新客户定点 + 量产交付 + 服务溢价高于纯租赁。当前未过验证点，仅作机会情景，不计入中性锚。
