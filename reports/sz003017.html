第一步：公司是干什么的？

一句话定位：国家专精特新"小巨人"，以无机钾盐（碳酸钾/碳酸氢钾）为支柱、兽药原料药（盐酸氨丙啉）与含氟精细化学品协同的"一体两翼"化学原料制造企业，是全球主要碳酸氢钾生产商、国内主要轻质碳酸钾生产商之一。

核心产品：
- 碳酸钾/碳酸氢钾（食品级、饲料级、工业级多规格）：轻质碳酸钾堆积密度小、比表面积大，用于农药、食品、医药；核心专利"高堆积密度大比表面积碳酸钾"入选浙江省重点新材料首批次应用示范目录。
- 盐酸氨丙啉（抗球虫兽药原料药）：通过国内 GMP 与美国 FDA 认证，国家火炬计划产业化示范项目，主供欧美、东南亚。
- 含氟精细化学品：2-氯-6-氟苯甲醛、氟苯、对氟苯甲醛等，氟苯/对氟苯甲醛是 PEEK 关键中间体 4,4′-二氟二苯甲酮的原料。

主要客户/下游：已与扬农化工、长青股份、OUROFINO SAUDE 等二十多家国内外上市公司合作，产品出口法国、英国、印尼、西班牙、美国、墨西哥等 50 多个国家和地区。下游为农药、食品、医药、兽药、新材料（PEEK/半导体）。

境内外收入占比（2026H1）：国内销售 4.45 亿（约 79.6%，+13.11%，主要增长引擎）；出口约 1.14 亿（约 20.4%）。

股东背景：实控人陈阳贵及其一致行动人（汪贤玉、仇永生等），陈阳贵直接持股约 8.86%，股权分散，无单一绝对控股股东。

（2）市场端（量价数据）

  • 碳酸钾/碳酸氢钾：公司 2026H1 碳酸钾销量与销售均价同比双增，产销量创历史新高。氯化钾原料高位背景下，公司凭借离子交换法技术（含氨氮废水零外排）与成本管控维持盈利。
  • 盐酸氨丙啉：2026H1 满产满销，销售单价同比提升；一季度价格较 2025 年略有上涨，出口美国销量增长（但受人民币升值、美元贬值影响，汇兑形成压力）。原辉宝客户部分转向公司采购。
  • 竞争格局：全球碳酸氢钾主要生产商之一、国内轻质碳酸钾主要企业之一，品牌"大化牌"为浙江名牌。行业集中度中等，公司在细颗粒轻质碳酸钾与食品级领域有技术差异化。

（3）产业链传导（原料成本 → 毛利结构，四因子）

  • 因子1 成本传导弹性（pass-through）：主原料氯化钾占碳酸钾成本大头。碳酸钾行业定价跟随氯化钾 + 加工费，传导率约 0.6–0.8——公司议价权中等，通过"离子交换闭路循环"技术降低能耗与辅料依赖，但氯化钾涨价仍部分自担。依据：2026H1 综合毛利率 23.02%（−1.29pct），即原料涨价时毛利小幅承压而非完全转嫁。
  • 因子2 毛利结构再平衡：精细化工（盐酸氨丙啉 + 含氟）毛利率 49.13%（+13.43pct），显著高于无机盐（约 22%）。原料氯化钾涨价 → 无机盐毛利受压，但精细化工高价、满产满销 → 利润贡献向高毛利精细化工迁移，支撑整体净利率 10.19%（+0.12pct）。
  • 因子3 库存与采购节奏（timing）：公司精准研判氯化钾价格——2026Q1 价格相对低位时适度增加战略储备，Q2 高位时控制采购节奏。这是低价囤货的库存收益，当季平滑了成本、但推高了营运资金占用（Q1 经营现金流转负、H1 净现比 89.83% 且现金流同比 −54.46%）。验证点：未来季度氯化钾价格回落时，高价库存的滞后成本需消化。
  • 因子4 政策/市场锚点：氯化钾价格由"保供稳价政策（限价红线、国储投放）+ 老挝钾增量 + 全球寡头控量"共同决定。情景假设：乐观（老挝钾持续放量 + 国储投放，氯化钾回落至 3000 元/吨下方）→ 碳酸钾成本改善、毛利扩张；中性（双轨行情延续，氯化钾 3100–3300 元/吨高位震荡）→ 毛利平稳；悲观（全球地缘扰动 + 春耕集中采购，氯化钾突破 3500 元/吨）→ 无机盐毛利进一步承压。证伪信号：碳酸钾毛利率跌破 18%、精细化工毛利率跌破 40%。

层2 扩展业务：主业迁移空间（新易盛范式）

主业迁移 = 从无机钾盐/兽药 → PEEK 新材料 + 半导体耗材，能力可迁移性中等（氟苯—氟酮—PEEK 全产业链具备化学同源性），新 TAM（PEEK、半导体高纯陶瓷）弹性大。但均处早期，未过验证点，不计入中性情景：
- PEEK 项目：拟投 1.93 亿建年产 2000 吨 PEEK 及关键中间体 4,4′-二氟二苯甲酮，依托大连理工技术，构建氟苯—氟酮—PEEK 全产业链。前期筹备阶段，许可备案手续耗时，为远期期权。
- 半导体材料（芯之纯）：持股 30%，主营半导体高纯陶瓷耗材（晶圆承载、气体输送），已进入试生产、部分产品送样验证。客户验证周期长，短期无批量订单。

第五步：综合赔率判断（买不买？）

当前价格位置：合理，略偏贵。现价 22.63 元对应 2026E PE 19.8x，已高于基准目标价 21.68 元；化工原料小盘股给 19–20x 属中性偏上，无安全边际。

安全边际：
- 中性远期 27.33 元 → 空间 +20.8%，不达"重点关注" >50% 门槛。
- 悲观 18.22 元 → 下行 −19.5%，风险收益基本对称。
- 乐观 39.21 元 → +73.3%，但依赖 PEEK/半导体期权与二期重质碳酸钾。
- 下行保护：PB 2.00x、资产负债率约 37.6%（2026Q1）、每股净资产约 13.9 元，19 元附近（PB 1.4x）有支撑；公司连续分红（H1 拟 10 派 3 元）。

上行想象力情景（仅进乐观栏，不进中性锚）：
- 类型D 技术突破期权：PEEK 全产业链（氟苯—氟酮—PEEK）若 2027–2029 落地，切入人形机器人/医疗/半导体高端材料，TAM 弹性大。硬验证点：PEEK 项目完成备案并开工、氟酮中试良率达标、获下游客户定点。证伪：项目长期停留筹备、氟酮成本打不过旧路线。
- 类型A 剩者红利：碳酸钾行业环保趋严（含氨氮废水零外排为壁垒），公司技术领先有望在行业出清中提升份额。验证点：行业小产能退出、公司碳酸钾份额提升。

介入条件：
1. 回落至 20 元以下（2026E PE < 17.5x）具安全边际。
2. 加仓信号：① 山东一期 3 万吨轻质碳酸钾 2026Q4 顺利试产且 2027 满产；② 三氟乙酰 3800 吨 2027 放量且毛利率达标；③ PEEK 项目获得正式备案并开工。
3. 观察指标：逐季精细化工营收占比与毛利率（若跌破 40% 需下修）、氯化钾采购节奏（高价库存消化情况）。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 三氟乙酰三度延期的执行风险：该项目已三次延期（原 1.98 亿追加至 2.18 亿），是最大不确定源，若再延期则 2027 增量落空。
2. 氯化钾原料高位侵蚀毛利：无机盐占收入 72%，氯化钾若突破 3500 元/吨且传导不畅，毛利率承压。
3. 汇兑损失：出口收入占比约 20%，人民币升值对出口利润形成压制。
4. 营运资金占用：Q1 备货推高存货与预付款，经营现金流同比 −54%，若氯化钾跌价则存货有减值风险。

结论：纳入观察（中性远期空间 +20.8%，不达 >50% 门槛；公司质地稳健、分红好、有 PEEK/半导体期权想象空间，但当前价格无安全边际，需等回落或等山东/三氟乙酰项目验证）。
