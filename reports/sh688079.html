第一步：公司是干什么的？

一句话定位："光学 + 半导体工艺深度融合"的精密制造平台，用半导体工艺（光刻 / 镀膜 / 键合 / TGV 玻璃通孔）做光学与声学器件，卡位 AI 先进封装玻璃基板（TGV）、AR/MR 微纳光学、CIS/射频/功率半导体封测，客户含台积电、三星、苹果、汇顶、舜宇、海康、京瓷、索尼、佳能、AGC、富士康。

（3）产业链传导

上游：半导体设备、光学玻璃材料（与 AGC 等合作）、光刻胶。部分材料外购，成本传导弹性中（先进封装 / AR 高毛利环节可转嫁，传统光学难）。

下游：台积电 / 三星（先进封装）、消费电子 / 汽车 / 安防品牌厂，议价权中（头部客户认证壁垒高但压价）。

议价权：中偏强（稀缺 TGV 量产 + 头部客户认证壁垒），但传统光学环节竞争充分。

第二步进阶·原料成本 → 毛利结构（四因子）
- 因子1 成本传导弹性（转嫁系数≈0.6）：先进封装 / AR 高毛利环节转嫁系数高（≈0.8），传统光学 / 封测低（≈0.4）；H1 综合毛利率 −4.67pct 反映传统环节降价 + 折旧摊薄。验证点：毛利率能否回 20%+；证伪：破 14%。
- 因子2 毛利结构再平衡：半导体声光学 18.34%（高）、半导体封测 23.83%（中高）、精密光学 23.01%（中）、其他 34.82%（含微纳光学，毛利分化）。结构优化方向=提升半导体 / 微纳高毛利占比（验证点：各板块毛利率）。
- 因子3 库存与采购节奏：H1 折旧增 3564 万为"产能爬坡期"固定成本，非库存收益；产能利用率低时毛利虚低，爬坡后改善。验证点：Q3 毛利率、产能利用率。
- 因子4 政策 / 市场锚点：原料成本驱动=①半导体材料国产替代补贴（正面降本）；②出口管制（高端光学材料供应风险）；③汇率（出口用）。情景：消费电子需求疲软=传统光学承压；验证点：下游终端出货。

（3）第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务（市场容量 × 份额变量）：
  • 供给侧：TGV 玻璃基板全球第三方合规量产极稀缺（美迪凯 + 康宁 / AGC），份额领先（验证点：台积电订单量）。
  • 需求侧 / 客户份额：绑定台积电 / 三星核心供应链（认证周期 1–3 年），粘性高（验证点：重复订单）。
  • 技术代际差：12 寸晶圆叠加光学 / 声学层能力国内极少（验证点：良率 / 客户认证）。
  • 三档：保守（传统光学稳、半导体缓爬坡）/ 中性（TGV+键合棱镜规模量产）/ 乐观（AR/CPO 爆发）。
  • 层2 主业迁移空间（新易盛范式）：从"传统光学"→"半导体光学 + AI 封装"跨市场迁移，能力（纳米级加工）可复用、TAM 弹性大（AI 封装千亿级）。部分已过验证点（台积电供货），但 AR/CPO 放量未完全验证，作中期期权。
  • 层3 证伪信号：台积电 / 三星订单不及预期、产能利用率持续低、毛利率破 14%、定增失败致资金紧 → 下调增量。

亏损股三问

  1. 为什么亏：新产能（玻璃基板 / MicroLED / 键合棱镜）集中投产处爬坡期，折旧费用同比 +3564 万（全年 2 亿+）、利息支出 4000 万+、股份支付，叠加传统光学毛利下滑（综合 15.90%，−4.67pct）。属"战略性投入期"亏损，非主业恶化（营收 +23%、经营现金流转正）。
  2. 靠什么扭亏，触发时点：①产能利用率提升（台积电玻璃基板 / 键合棱镜 / MicroLED 放量）摊薄折旧；②高毛利半导体 / 微纳占比提升带动综合毛利回 22%+；③定增 7 亿缓解财务压力。中性触发扭亏时点 2027–2028 年（中邮预测 2027 微利、2028 净利 2.0 亿）。
  3. 亏得起吗：亏得起但财务杠杆高。经营现金流 +7569 万（正，自身造血）；但资产负债率 61.2%、流动比率 0.58、有息负债约 16 亿——短期偿债紧张，依赖定增（7 亿推进中）与再融资续命。若定增落地则安全，否则再融资风险上升。

第四步进阶·重资产 / 周期股校正（三道闸）
- 校正1 资产质量折扣：重资产（固定资产 + 在建约 25 亿），PB 5.72 高系净资产 12.12 亿相对市值偏小 + 期权溢价；非破净，但高 PB 反映"AI 封装 / AR 期权"定价，若新品不及预期则 PB 虚高。验证点：产能利用率 / 良率。
- 校正2 周期位置校正：受消费电子 + 半导体周期影响，当前处"AI 封装 / AR 预期高位"但传统光学景气弱。中性净利已用"爬坡后稳态"而非"单季亏损年化"或"近三年均值"，标注周期位置=预期高位、传统端弱。
- 校正3 杠杆下行情景：资产负债率 61.2%、流动比率 0.58、有息负债 ~16 亿——高负债。悲观情景（产能利用率低 + 价格战）净利可降至 0.54 亿甚至转负，空间 −80.5%。因下行极深且杠杆高，不得标"大空间 / 重点关注"，至多暂不介入。
- 期权纪律：AR/CPO/TGV 爆发未完全验证，不计入中性净利（仅乐观情景含部分）。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵 / 预期透支。现价 16.84 元对应中性目标 11.22 元（−33.4%），PB 5.72x 远高于行业，已提前定价 AR/CPO 期权。

安全边际：中性 −33.4%；悲观 −80.5%（高负债 + 产能不及预期可近乎腰斩再腰斩）；乐观 +26.2%（AR/CPO 爆发）。下行保护弱（高负债、流动比率 0.58）。

介入条件：①回落至 10 元以下（接近保守 NAV、PB 2x 以下）才具安全边际；②加仓信号：定增落地、台积电玻璃基板订单跳升、键合棱镜 / MicroLED 规模放量、毛利率回 22%+；③观察指标：产能利用率、Q3 亏损收窄、负债率。

最大风险：①产能利用率持续低、折旧吞噬利润（首要）；②高负债（流动比率 0.58）再融资风险；③AR/CPO 需求不及预期、客户导入放缓；④消费电子疲软 + 价格战。

结论：暂不介入（高负债 + 估值透支 + 中性空间 −33.4%，杠杆下行可转负；须等产能爬坡兑现盈利或估值回落）

上调至纳入观察 / 重点关注的触发条件：2027 扭亏且毛利率回 22%+，台积电玻璃基板订单规模化、AR 光学占比跳升，使 2029 正常化净利上修至 2.5 亿+（目标市值 ≥70 亿，空间转正并趋 +50%）。

第五步进阶·上行想象力情景（四类）
- A 行业调整剩者红利：先进封装玻璃基板全球第三方合规产能极稀缺，美迪凯成"剩者"独享国产替代红利。验证点：台积电 / 三星订单量。
- B 政策反转期权：半导体设备材料国产化加码 + 算力基建补贴，订单与补贴双增。验证点：大基金 / 补贴公告；证伪：补贴退坡。
- C 市场错杀修复：若因风格切换被错杀至 PB 2x 以下（~5.9 元），凭正经营现金流 + 头部客户修复弹性大。验证点：估值分位。
- D 技术突破 / 代际跃迁期权：TGV 玻璃基板从 0 到 1 成 AI 先进封装刚需（渗透率 <1%→30%），叠加键合棱镜 / MicroLED 重构 AR 供应链。三要素共振：①政策（算力国产替代）；②趋势（AI 封装渗透率拐点）；③落地（台积电审厂通过 + 批量供货 + 良率达标）。硬验证点：中试良率达标 + 客户定点（台积电 / 三星）+ 量产成本优于旧路线（玻璃 vs ABF）。当前"台积电批量供货"硬验证点已部分兑现，但 AR/CPO 放量仍待验证，计入乐观情景。
