第二步进阶 · 原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：国废涨 → 纸价跟涨，转嫁系数中高（库存低、需求旺时顺畅顺价）；但长期看产能过剩，转嫁不可持续，传导率约 0.6–0.8。
  • 因子2 毛利结构再平衡：原纸 69% 对废纸敏感；再生浆板 12.96%（+431% 高增）改善结构、毛利较优；生活用纸 11.76% 稳健。
  • 因子3 库存与采购节奏：低价废纸库存收益（H1 毛利改善部分含库存收益），须区分"当期 vs 远期"毛利可比性，避免把库存收益当真实盈利能力。
  • 因子4 政策 / 市场锚点（原料成本驱动变量）：① 市场层——国废雨季供给、美废价格、木浆（阔叶 4586 / 针叶 5055 元/吨）；② 政策层——进口纸减量（利好）、以旧换新（需求）。情景：乐观——旺季 + 出口持续、纸价稳涨；悲观——纸价回落、国废成本升。验证点：箱板 / 瓦楞均价、纸厂库存天数、出口订单；证伪：纸价回落破 3500 / 毛利率破 8%。

第三步进阶 · 份额变量与主业迁移空间（三层法）

  • 层1 现有业务 份额变量：包装纸行业供给出清、公司华东基地受益。五锚点：供给侧（2023–2025 新增产能放缓）、客户份额（出口包装客户）、技术代际（普通）、成本曲线（区域废纸来源优势）、份额加速度（出清期）。验证点：公司出货量份额、出口订单；三档配验证点。
  • 层2 扩展业务 主业迁移空间（新易盛范式）：再生浆板新曲线已跳升（收入占比 12.96%、+431%），可视作"中期已部分验证"的迁移；但整体仍属包装纸池内，TAM 弹性有限，未过完全验证点，部分计入、不计入中性满分。
  • 层3 风险折扣 证伪信号：纸价回落、国废成本升、地产需求弱致包装订单证伪、再生浆板高增不可持续。

第四步：估值锚定（自下而上，非增速外推）

方法说明：盈利股，但破净须做资产质量折扣闸 + 周期位置校正。按"周期归一化净利"测算，不取 2026H1 年化（避免拐点年化）。

总股本：14.748 亿股

资产质量折扣闸（破净必答）

  • 破净原因：① 重资产（造纸产线专用，清算折价大）；② 历史低 ROE（2022–2025 归母仅 0.55–1.18 亿，ROE 2–4%）；③ 周期波动大。净资产 67.8 亿中含大量专用纸机 / 厂房，二手清算价值远低于账面 → PB<1 属公允定价，非真低估（与"金融资产未重估型破净"相反）。
  • 但：2026 盈利修复（H1 1.39 亿）、经营现金流 6.01 亿强劲，主业未失血，破净非资不抵债。

周期位置校正

  • 箱板瓦楞纸处景气上行（库存低位、提价），但价格仍处 2014 以来 30% 分位（底部偏上），非顶部。
  • 周期归一化净利：取 2022–2025 中值 ~0.9 亿与 2026 复苏折中，中性稳态 1.8 亿（保守，未年化 H1）。
  • 合理 PE：周期股 10–12x → 市值 18–22 亿 → 股价 1.2–1.5 元；若景气持续（2027 净利 3 亿），12x → 36 亿 → 2.4 元。

第四步进阶 · 重资产 / 周期股估值校正

  • 资产质量折扣：已答（专用资产清算折价，PB<1 公允）。
  • 周期位置校正：已标注（底部偏上，中性净利用周期归一化，未取 H1 年化）。
  • 杠杆下行情景：负债率中等，无极端高负债；若纸价回落 + 国废成本升，净利可大幅下滑（悲观 −84.8%），不得标大空间。

第五步：综合赔率判断（买不买？）

当前价格位置：账面破净但盈利视角偏贵（PE 21x 于复苏年）。破净非真低估。
安全边际：中性远期 1.36 元 → 空间 −66.0%；乐观 2.44 元仍 −39.0%；下行保护：PB 0.87 提供一定账面缓冲，但盈利视角弱。
介入条件：① 回落至 3.0 元以下（PB < 0.7）且纸价维持高位；② 加仓信号：纸价连续季度稳涨、出口订单高增、ROE 回升至 6%+。
最大风险：① 纸价回落（产能复产 / 需求弱）；② 国废成本上升吞噬毛利；③ 地产 / 包装需求证伪；④ 2026 复苏不可持续、回归微利。
结论：暂不介入（破净因重资产低 ROE 属公允定价，按周期归一化净利估值安全边际不足；若景气持续且回落至 3 元以下可上调至纳入观察）。

第五步进阶 · 上行想象力情景（四类，只进乐观 / 机会栏）

  • A 行业调整剩者红利：包装纸出清后剩者份额与定价权跳升。验证点：行业集中度、公司出货份额、纸价稳涨。
  • B 政策反转期权：不适用（非政策打压行业）。
  • C 市场错杀修复：PB 回归 1x（≈4.7 元）需 ROE 提升至 6%+；验证点：盈利持续、ROE 改善。
  • D 技术突破期权：不适用（无代际跃迁）。
  • 上调重点关注条件：纸价连续两季稳涨且 2027 净利稳定 > 2.5 亿（对应市值 30 亿 +、股价 > 2 元且 PB 修复）。
