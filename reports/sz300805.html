  • 数字零售：货架电商（天猫 / 京东 / 拼多多）2026H1 收入 2.86 亿 +98.61%；京喜通 B2B 1.62 亿 +110.39%；即时零售 0.63 亿 +70.27%——渠道红利明确。

（3）产业链传导

上游：人力（执行 / 路演人员）、媒体流量采买（抖音 / 天猫等平台抽成）、场地。
下游：品牌广告主（强势买方，账期长、压价）。
议价权：弱（服务同质化、毛利率仅 9.89% 印证）。

（2）进阶 · 原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：转嫁系数 ≈ 0.2–0.3（服务行业难向客户传导人工 / 流量成本，毛利率仅 9.89%）。
  • 因子2 毛利结构再平衡：数字零售（占 55%，增速 50%+、毛利率待披露但代运营偏薄）vs 传统营销服务（终端管理 / 品牌传播 / 互动展示，毛利率更低）。加权利润高度依赖规模摊薄，结构向低毛利数字零售倾斜。
  • 因子3 库存与采购节奏：营销无存货；流量采买多为预付（致 2026H1 经营现金流 -7949 万，预付款项增加），属经营性占款而非库存收益。
  • 因子4 政策 / 市场锚点：促消费政策（广告主预算）、平台规则与抽成（抖音 / 天猫费率）、AI 降本（AIGC 剪辑降人工）。验证点：消费社零增速、平台费率、公司现金流；证伪：消费走弱致数字零售增速 <20%、现金流持续大额负。

（4）进阶 · 重资产 / 周期股估值三道闸

  • 校正1 资产质量折扣：净资产 15.66 亿，其中现金 8.48 亿（占 54%），资产质量真实、流动性高，PB 2.25x 有现金兜底（非破净、无专用资产折价）。
  • 校正2 周期位置校正：营销服务顺消费周期，当前消费弱复苏；中性净利用扣非稳态（剔除理财收益 / 政府补贴一次性），不按 2025 高基数外推。
  • 校正3 杠杆下行情景：资产负债率约 30%，现金充裕无杠杆风险；但经营现金流持续负（-7949 万）是质量下行信号（预付款占款），悲观情景空间 -47.7%。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（主业 2026E PE 约 67x，估值依赖数字零售成长兑现；现金 2.0 元 / 股兜底）。

安全边际：现金底约 2.0 元 / 股；中性远期 -26.1%（按保守 SOTP）；乐观 +26.4%（数字零售超预期）。

介入条件：
1. ≤ 7.0 元（更接近现金底 + 保守业务值）才具安全边际；
2. 上调至"重点关注"条件：数字零售净利率稳守 >2.5%、经营现金流转正、营收占比 >65% 且增速 >30%。

最大风险：
1. 消费走弱致广告主预算收缩、数字零售增速骤降；
2. 净利率长期 <1.5%、经营现金流持续大额负；
3. 大客户流失（依赖头部快消品牌）；
4. 平台费率上升挤压代运营毛利。

第五步进阶 · 上行想象力情景（四类，对冲系统性保守偏置）

  • 类型A 行业调整剩者红利：体验营销行业分散，头部（全国 300+ 地级市网络）在消费回暖期份额集中。验证点：数字零售营收占比、客户公告；证伪：数字零售增速 <20%。
  • 类型B 政策反转期权：促消费 / 扩大内需加码，广告主预算回升带动营销需求。验证点：社零增速、政策发文；仅作机会情景。
  • 类型C 市场错杀修复：账面现金 8.48 亿（约 2.0 元 / 股）兜底，若消费回暖估值修复弹性大。验证点：现金底支撑、估值分位。
  • 类型D 技术突破 / 代际跃迁：AIGC 剪辑 / AI 编导提效，数字零售净利率跳升；科技驱动营销重构客单价。硬验证点：净利率稳守 >2.5% + 经营现金流转正；未达仅作机会情景。

上调至"重点关注"条件：数字零售净利率稳守 >2.5%、经营现金流转正、营收占比 >65% 且增速 >30%，中性远期空间转正并突破 +50%。

结论：暂不介入（现金兜底但主业盈利极薄、经营现金流为负，中性远期空间为负；等回调至 7 元以下（接近现金底）或盈利质量（净利率 / 现金流转正）验证后才 reconsider）。
