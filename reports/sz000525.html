第一步：公司是干什么的？

一句话定位：全球吡啶碱全产业链龙头、最大百草枯原药供应商，以农药化工为主业，依托吡啶碱核心技术向合成生物与新材料「两翼」延伸。

（3）产业链传导

上游：生物质原料、化工原料（吡啶碱自给，成本可控）。全产业链一体化 → 成本壁垒强。

下游：全球植保（农户/渠道），需求刚性；百草枯在拉美/非洲/东南亚为主流除草剂。

议价权判断：强（吡啶碱全产业链 + 全球最大百草枯原药供应商 + 登记资质三重护城河；供给收缩后议价权进一步提升）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性
  • 吡啶碱自给 → 中间体成本基本自担可控，向下游（原药/制剂）转嫁系数 ≈ 0.8（供给收缩下原药涨价可传导）。
  • 验证点：百草枯/3-甲基吡啶价格 vs 毛利率（H1 毛利率 +16.7pct 已验证）；证伪：价格涨而毛利未升 = 传导失败。
  • 因子2 毛利结构再平衡
  • 农药化工占 98.84%，几乎单一结构；细分中百草枯（46%）毛利弹性最大，吡啶碱中间体（外售）毛利高。
  • 原料敏感权重：集中于吡啶碱原料+能源。结构迁移看高毛利原药/制剂占比 + 海外（23.57% 毛利）占比提升。
  • 禁单一综合毛利率：22.70% 综合毛利率掩盖百草枯（高弹性）与其他产品差异。
  • 因子3 库存与采购节奏
  • 吡啶碱自给 + 各基地统一调度，库存节奏可控；H1 毛利率跳升部分来自价格改善而非囤货。
  • 验证点：季度毛利率；证伪：毛利异常跳升无价格佐证 = 库存收益。
  • 因子4 政策 / 市场锚点
  • 市场层：百草枯全球供需、原粮价格（植保需求）。
  • 政策层：先正达停产（已落地）、出口管制、登记办法、出口退税取消。
  • 情景：先正达停产→订单转移红太阳（乐观，已验证）；贸易摩擦冲击出口（悲观）。验证点：海外订单能见度、先正达产能退出确认。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：全球百草枯有效产能收缩 10–12%，红太阳为全球最大供应商，份额直接提升。
  • 需求侧：大客户战略订单落地（美国汉姆等），拉美/阿根廷反弹。
  • 技术代际：吡啶碱全产业链领先，代际优势。
  • 成本曲线：全产业链左移，降价时以价换量。
  • 份额二阶导：供给出清早期，份额加速。三档：保守守住 / 中性份额 +3–5pct / 乐观承接先正达退出份额。
  • 层2 扩展业务：主业迁移空间
  • 新材料（吡啶季铵盐/液流电池电解液）：从农药→电化学材料，能力部分可迁移，新 TAM 大，但未过验证点（仅布局）→ 仅中期期权，不计入中性。
  • 合成生物（虾青素等）：早期研发，未过验证点 → 期权。
  • 制造出口（非洲/老挝基地）：从产品出口→制造出口，已过初步验证（老挝 10+ 登记放量），计中期期权。
  • 层3 证伪信号
  • 百草枯价格回落、海外订单能见度转差、债务重组反复、财务费用未降 → 中性下修。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：非重资产（轻资产农药化工），PB 2.22 不破净，无破净误判风险。
  • 校正2 周期位置校正：农药处复苏早期（供给收缩+价格修复），中性净利取周期归一化（2024 年 3.88 亿为较好年，中性取 2.8 亿保守），非底部年化（扣非亏）。
  • 校正3 杠杆下行情景：资产负债率 58.62%、流动比率仅 0.61，高负债+短期偿债压力。附利率/需求下行情景：悲观净利 1.5 亿 → 1.62 元（−63.8%）。若化债失败致财务费反弹，则中性下修。

亏损股三问（扣非仍亏，须明确回答）

  1. 为什么亏（扣非）：历史债务包袱（存量有息债务 8.68 亿）致财务费用高 + 行业周期底部；2026H1 扣非 −3793 万，但 Q2 仅亏 230.9 万，主业已近单季盈亏平衡，亏损在快速收敛。
  2. 靠什么扭亏·触发时点：① 百草枯全球供给收缩（先正达 2026-06 底停产 10–12% 产能）→ 量价齐升，红太阳直接承接；② 吡啶碱全产业链成本优势；③ 海外高毛利（23.57%）占比提升；④ 降本增效 + 债务重组降财务费用（宁波 AMC 削减负债 2.17 亿）。触发时点：2026H2 至 2027 年扣非有望持续转正。
  3. 亏得起吗：经营现金流 1.48 亿（正），国资股东（曲靖国资）治理支持，化债专项小组推进（展期缓冲+经营造血→征信修复）；但短期偿债压力仍大（短期借款 4.58 亿 > 货币资金，流动比率 0.61），存量债务 8.68 亿逐步化解中，短期靠经营现金流+再融资续命，中期看化债落地。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。现价 4.47 元对应 PB 2.22x，中性远期 4.53 元基本持平，市场已部分 price-in 扭亏预期但未完全反映供给收缩弹性。

安全边际：中性远期 4.53 元 → 空间 +1.3%（>0，达纳入观察门槛）；悲观 1.62 元 → −63.8%（若化债/复苏失败）；乐观 7.28 元 → +62.9%（承接先正达份额）。

介入条件：① 连续两季扣非为正（确认主业扭亏）；② 化债进展公告（征信修复/再融资）；③ 百草枯价格与海外订单持续验证。现价可小仓位左侧布局，等扣非转正确认加仓。

最大风险：
1. 高负债（58.62%）+ 短期偿债压力（流动比率 0.61），化债若反复则财务费反弹；
2. 百草枯为限制性农药，长期需求受替代（敌草快/草铵膦）挤压；
3. 贸易摩擦冲击出口（占收入 45.84%）；
4. 两翼（合成生物/新材料）落地不及预期。

结论：纳入观察

归母已扭亏（TTM 误标）、强行业催化（先正达停产→供给收缩）、主业 Q2 近平衡，中性远期 +1.3%（>0）。但扣非仍亏+高负债，须等扣非转正确认与化债落地才上调重点关注。属「扭亏拐点待确认」型。
