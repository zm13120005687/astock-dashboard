一句话定位：金隅集团旗下水泥装备制造 / 维修 / 工程全产业链服务商，主业高度依赖关联方冀东水泥（金隅系）订单，低盈利、高负债、小市值国企，市场隐含"资产注入 / 重组"期权溢价。

股东背景：北京金隅集团股份有限公司（北京市国资委）为实控人，央企 / 地方国企系。

（3）产业链传导

上游：钢材、电机、备件（占成本大头），价格随钢价波动。
下游：水泥企业资本开支（强周期、买方强势），金隅 / 冀东体系内订单稳定但价格受压。
议价权：弱。客户集中且为关联方，毛利率长期 7–8%，转嫁能力低。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：转嫁系数 ≈ 0.3–0.5（弱议价，钢价涨多自担）。依据：毛利率长期 7–8%，2026H1 仅 8.10%，成本端难转嫁。
  • 因子2 毛利结构再平衡：分业务线毛利率——机械设备及备件（较高，约 10–12%）、土建安装（约 6–8%）、矿山工程（约 5–7%）。原料（钢 / 电）敏感权重集中于机械设备 + 土建（合计 63%），结构薄利。
  • 因子3 库存与采购节奏：未披露显著囤货；2026H1 经营现金流 +2783 万（同比转正，回款改善）。验证点：毛利率与现金流。
  • 因子4 政策 / 市场锚点：钢材受钢价周期（市场层）影响；水泥产能置换 / 能效政策（政策层）影响技改需求。情景：钢价上涨 → 毛利承压；证伪信号：综合毛利率跌破 7%。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量：水泥装备存量市场（产能过剩），公司在金隅体系内份额高，外部 / 海外为份额增量。三档：保守守住（体系内）、中性小幅提升（外部合同增）、乐观抢份额（海外突破）。验证点：外部营收占比、海外营收披露。
  • 层2 扩展业务：主业迁移空间（跨行业 / 出海）：从水泥装备向"跨行业工程 + 海外"迁移，新 TAM 更大但早期（海外占比仅 0.37%），未过验证点，仅中期期权，不计入中性。
  • 层3 风险折扣：证伪信号：关联方订单下滑、外部拓展停滞、毛利率破 7% → 下调增量。

第四步进阶：重资产 / 周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 4.74 远高于 1，但净资产仅 4.21 亿、市值 20 亿，高 PB 反映市场对"金隅系资产注入 / 重组"的期权溢价，而非主业盈利能力（主业 ROE 仅 1.5%）。主业清算价值低（专用设备、负债率高），禁止单凭"小市值"推导大空间。
  • 校正2 周期位置校正：强周期（水泥装备跟随水泥资本开支），当前水泥需求下行、行业底部。中性净利已用保守净利率（1.0–1.3%）而非好年景外推。
  • 校正3 杠杆下行情景：资产负债率约 82%，经营杠杆 + 财务杠杆双高；若关联交易下滑或需求下行，净利可大幅跳负（悲观情景已 −80%）。下行保护极弱，不得标"大空间"。

第五步：综合赔率判断（买不买？）

当前价格位置：显著偏贵（相对主业锚）。现价 8.81 元对应主业中性锚 2.90 元，PE(TTM) 93x、PB 4.74，已充分计入重组 / 资产注入期权。
安全边际：中性 −67.1%，悲观 −80.0%；乐观 −30.0%（仍低于现价，需重组兑现）。主业层面风险收益严重不对称偏负。
介入条件：① 仅适合博弈"金隅系资产重组 / 注入"期权者，非主业价值投资；② 若重组无实质进展，< 3 元（接近主业锚）才具安全边际。
最大风险：① 主业盈利微薄、关联交易依赖（68.75%）集中度高；② 高负债（82%）下行脆弱；③ 重组 / 资产注入预期落空（期权证伪则估值回归主业）。
结论：暂不介入（主业中性空间 −67%，估值不具吸引力；现价实为重组期权定价，确定性不足，仅适合事件驱动博弈）。

亏损股三问（不适用，非亏损，但列风险）：主业微利非亏损，核心风险为"高 PB 期权落空"；若重组无进展，估值向主业锚 2.9 元回归。
