（3）产业链传导

上游：电子元件、机柜/钣金、IP 授权费。IP 授权费刚性（与热门 IP 方分成）。

下游：商业综合体、连锁游乐场（大玩家等）、C 端玩家。下游游乐场扩张放缓 + 价格战，反向压制设备售价与回款。

议价权判断：中等。设备技术/IP 有壁垒，但下游连锁客户集中、账期长；大玩家破产暴露强客户依赖风险。转嫁系数约 0.4（降价自扛）。

第二步进阶·原料成本→毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数）：硬件 BOM 占设备成本约 60–70%，下游游乐场价格战致设备降价，公司吸收为主，转嫁系数约 0.4。动漫衍生毛利率从 42.75% 降至 40.31% 印证承压。
  • 因子2 毛利结构再平衡：分业务——动漫衍生 40.31%（最高、占 37%）、游戏设备 28.88%（占 46%）、游乐场运营 −5.94%（失血、占 12%）。游乐场运营持续负毛利是结构最大拖累，须压缩或转型；设备 + 衍生为利润核心。禁止用综合毛利率掩盖运营业务失血。
  • 因子3 库存与采购节奏：以销定产 + IP 卡片按需投放，无大幅囤货；但对外投放设备（联营）形成资产，大玩家破产后计提减值 74.71 万 + 应收全额坏账，暴露投放模式风险。
  • 因子4 政策/市场锚点（原料成本驱动变量）：①市场层——IP 授权费年涨、电子料价格平稳；②政策层——文旅促消费暖风（托底需求）、但消费意愿回落（压制）。验证点：季度设备单价、游乐场新开店数、IP 新作流水；证伪信号：设备毛利率破 25%、游乐场运营毛利率持续为负。

第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：商用游戏游艺设备龙头，产能与技术领先；
  • 客户侧：大玩家破产暴露客户集中风险，须分散；
  • 技术代际：音游/赛车自研领先；
  • 成本曲线：规模 + IP 资源；
  • 份额加速度：行业出清后剩者份额可提升。
  • 三档验证点：海外出货、新客户公告、IP 新作流水。
  • 层2 扩展业务：主业迁移空间：从硬件设备 → IP 衍生（同源 IP 运营，新 TAM 大）→ 游乐场运营/授权。IP 衍生已规模变现（3.69 亿），但游乐场运营负毛利须重构。属中期期权。
  • 层3 风险折扣（证伪信号）：大客户继续破产、IP 授权流失、游乐场运营持续失血。命中则下调。

第五步：综合赔率判断（买不买？）——亏损股生存能力评估

亏损股三问：
1. 为什么亏：① 大玩家客户破产→应收 6421.56 万全额坏账 + 设备减值，合计减利 4864 万（一次性但暴露客户风险）；② 行业需求弱化（下游游乐场扩张放缓、价格战、消费意愿回落）致营收 −30.59%；③ 游乐场运营毛利率 −28.84% 持续失血。
2. 靠什么扭亏 / 触发时点：① 大玩家减值一次性，2027 不再有；② 海外增长（2025 +25%）；③ IP 衍生（《宝可梦》《三国幻战》）持续；④ 下游出清后剩者红利。触发时点 2027。
3. 亏得起吗：净资产 8.28 亿、无重大有息负债，账面可撑；但 2026H1 经营现金流 −4916 万转负，须看 H2 回款与减值出清节奏，短期生存无虞但造血转弱。

当前价格位置：严重高估（已 price-in 历史盈利，忽略 2026 塌方）。现价 15.60 远高于中性 6.52 元。

安全边际：中性远期 6.52 元 → −58.2%；悲观 2.26 元 → −85.5%；乐观 10.65 元 → −31.7%（仍为负）。

介入条件：
1. 现价回避。仅当回落至 7 元以下（对应 2029E 约 21x、接近乐观）且出现扭亏信号；
2. 上调至"纳入观察"触发点：① 2026H2 归母环比显著减亏、减值出清；② 2027 净利重回 0.5 亿以上；③ 海外 + IP 衍生收入连续两季双位数增长。

最大风险：
1. 下游游乐场继续出清、新增客户破产（客户集中风险未解）；
2. 游乐场运营负毛利持续、资产进一步减值；
3. IP 授权到期或流水不及预期；
4. 估值戴维斯双杀（盈利下修 + 估值压缩）。

结论：暂不介入（主业失速 + 大额减值 + 估值严重偏高；仅作观察，待下游出清、减值出清与扭亏信号明确后重估）。
