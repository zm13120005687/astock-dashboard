第一步：公司是干什么的？

一句话定位：国产工业机器人领军企业、国家机器人产业链链主，核心零部件 → 整机 → 高端系统集成全产业链自主可控，正从"替代进口"向"智能化 / 具身智能"升级。

核心产品：工业机器人全系列（SCARA、多关节、大负载 ER300–ER700、防爆喷涂、重载 SCARA）；自研驱控一体化控制柜；人形机器人 Yobot R2V1/V2/W2；智能机器人通用技术底座（HumanGPT、大衍数据、墨斗 IDE、OpenmindOS）。

主要客户 / 下游：新能源（出货占比 ~30%，+80% YoY）、电子制造（~40%）、汽车及汽车零部件、锂电、光伏；海外德系头部企业超 3000 万欧元大额订单履约中。

境内外收入占比：以境内为主，出口欧洲毛利率 >40%；欧洲系统集成业务重组减亏中。

资产结构：资产负债率 65.5%，净资产约 11.6 亿（PB 高因累计亏损侵蚀账面），属重资产 + 高研发。

（3）产业链传导

上游：减速器、伺服、控制器等核心零部件（公司已 100% 自主可控），受钢材 / 电子料价格影响。
下游：新能源、电子、汽车，需求回暖但价格敏感。
议价权：中等——整机量增但价格战，靠高价值机型与品牌向上改善；出口欧洲毛利 >40% 体现高端议价。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：核心零部件自产后，成本端以钢材 / 电子料为主，整机价格受内卷压制、转嫁系数约 0.3–0.4；但高价值机型（防爆、喷涂、大负载）溢价强，转嫁系数可达 0.6+。
  • 因子2 毛利结构再平衡：毛利率从 5% → 15% 的结构跃升，源于高价值机型占比提升 + 低毛利集成业务收缩。分业务线：出口 / 高价值机器人毛利 >40%，国内标准机 ~12–15%，系统集成偏低。结构再平衡是盈利修复主因。
  • 因子3 库存与采购节奏：自产核心部件，按订单 + 安全库存采购；无大规模囤货；超级工厂 2026 年底投产将降本。
  • 因子4 政策 / 市场锚点（原料成本驱动变量）：①钢材 / 芯片价格下行 → 毛利改善；②出口管制 / 关税影响欧洲业务；③国产替代补贴 + 人形机器人政策 → 需求端。验证点：季度毛利率、超级工厂投产进度。证伪信号：毛利率回落至 <12%、价格战加剧。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：国内工业机器人市场外资仍占部分份额，国产替代空间大；公司排名第 5、份额上行。
  • 需求侧：新能源 + 电子 + 汽车头部客户认证壁垒高（粘性）。
  • 技术代际：核心零部件 100% 自主，处国产第一梯队。
  • 成本曲线：自产 + 超级工厂降本，左移。
  • 份额加速度：国产替代加速期，份额上行。
    → 三档：保守营收 16 亿 / 中性 24 亿 / 乐观 32 亿（2029E）。
  • 层2 扩展业务：主业迁移空间：从"工业机器人"向"具身智能 / 人形机器人 + 智能化增量"迁移，技术底座（HumanGPT 等）自研；新 TAM（人形机器人）弹性极大。信号验证：Yobot 已发布并场景部署、医疗导诊落地。未过规模商业化验证点，仅作中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：销量增长不及预期、毛利率回落、海外（欧洲）需求二次恶化 → 下调。

第四步进阶：重资产 / 周期股校正（三道闸）

  • 校正1 资产质量折扣：PB 6.63x 偏高，但这是因累计亏损侵蚀账面净资产（每股净资产仅 2.23 元）、市场定价 turnaround，并非破净伪空间；属"账面未重估型"但非金融资产，须以盈利兑现证明。
  • 校正2 周期位置校正：工业机器人处国产替代上行 + 价格内卷并存，当前毛利率从底部 5% 修复至 15%，标注"修复中段"，中性净利未用单年好年景（仍亏损），用 2029 稳态 7%。
  • 校正3 杠杆下行情景（高负债必附）：资产负债率 65.5%，若需求下行 / 价格战加剧，亏损可扩大，悲观情景空间 −75%，故中性不得标大空间；期权（人形机器人）不计入中性。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高、已较充分反映 turnaround。现价 14.78 元对应 2029 中性 15.5 元仅 +4.5%，市场已定价扭亏预期。

安全边际：
- 中性远期 15.5 元 → 空间 +4.5%，未达"重点关注" >50% 门槛
- 悲观 3.7 元 → 下行 −75.0%（高负债 + 仍未盈利，下行极不对称）
- 乐观 28.7 元 → +94.2%（需具身智能放量）
- 下行保护弱：PB 6.63x、累计未弥补亏损 14.7 亿、资产负债率 65.5%

介入条件：
1. 回落至 11 元以下（PS <4x）增厚安全边际
2. 加仓信号：单季扭亏兑现、毛利率稳站 18%+、超级工厂投产降本、人形机器人规模订单
3. 观察指标：季度销量、毛利率、经营现金流持续性

最大风险：①2020 上市以来累计亏损 12.36 亿、截至 H1 累计未弥补亏损 14.7 亿（超实收股本 1/3，长期摊薄风险）；②价格内卷致毛利率反复；③欧洲地缘政治；④高负债财务压力。

亏损股三问：
1. 为什么亏：行业价格内卷 + 高研发投入（占 16%）+ 海外（欧洲）业务重组亏损；2020 上市以来持续亏损。
2. 靠什么扭亏、时点："品牌向上"战略（高价值机型占比提升 → 毛利率 5%→15%→目标 20%+）、销量放量（2026 预计 >20000 台）、降本控费、欧洲重组减亏、超级工厂 2026 年底投产降本；预计 2027 单季扭亏、2028 全年扭亏。
3. 亏得起吗：2026H1 经营现金流已转正（+2712 万）是积极信号，但资产负债率 65.5% 偏高；账面资金 + 融资能力可支撑至扭亏，无 ST（科创板未盈利上市适用不同规则），但须关注累计亏损摊薄。

结论：纳入观察

国产机器人链主，turnaround 信号明确（减亏 62%、毛利率修复、现金流转正），但当前价格已较充分反映、且高负债下下行极不对称（悲观 −75%）。等单季扭亏兑现或回落至 11 元以下再重点考虑。
