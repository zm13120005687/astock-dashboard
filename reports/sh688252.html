（3）产业链传导

上游（成本端）：晶圆代工（中芯等）+ 封测。代工产能紧张时成本上升，但公司通过供应链协同、设计降本、动态定价平滑（2026Q1 涨价后传导部分成本）。

下游（收入端）：手机/平板/穿戴终端（周期波动）、零售（ESL 稳健增长）、工控（增量）。ESL 客户为零售巨头，订单长协稳定。

议价权：强（ESL 垄断）/ 中（TDDI 竞争）——ESL 全球 80% 份额具定价权；TDDI 处国产阵营前列但竞争激烈，部分转嫁成本能力。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：晶圆代工涨价时，ESL（垄断、客户价格敏感度低）传导率≈0.8–1.0（可转嫁）；TDDI（竞争）传导率≈0.3–0.5（部分自己扛）。验证点：代工报价走势 + 公司产品提价公告。
  • 因子2 毛利结构再平衡：分产品——ESL（高毛利，垄断溢价）、AMOLED DDIC（中高，国产替代溢价）、TDDI（中，竞争）、快充（中高）。禁单一 24.5% 综合毛利率掩盖结构：ESL 占比提升 + 多色/中大尺寸电子纸在研将结构性抬高毛利。验证点：ESL 收入占比、AMOLED 占比。
  • 因子3 库存与采购节奏：晶圆产能紧张期锁定产能（公司长期稳定产能储备）享交付优势；产能宽松期成本下降。2026H1 应付账款 +29.31%、合同负债增至 2511 万（预收增），显示订单与排产上行。
  • 因子4 政策/市场锚点：①半导体国产化补贴（降成本/增订单）；②出口管制（先进制程受限变量）；③零售数字化政策（ESL 需求驱动）；④车载电子纸（元太携手宝马，行业扩容期权）。情景：乐观——国产化+ESL 渗透加速+车载落地；悲观——终端需求疲软+价格战。验证点：DDIC 国产份额、ESL 出货量、车载电子纸定点。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：ESL 全球 80% 份额（绝对龙头），TDDI 国产 18%→20%+；
  • 需求侧：零售巨头（家乐福/麦德龙/山姆）认证壁垒高=强粘性；
  • 技术代际：四色电子纸全球领先，窄边框 GIP 架构拓展车载；
  • 成本曲线：规模+设计降本，毛利率优化；
  • 份额加速度：ESL 处渗透早期（中国 CAGR 20%），份额稳升。
    → 三档：保守守住 ESL 80%、中性 TDDI 升至 25%、乐观抢全球 DDIC 份额。验证点：ESL 出货量、TDDI 市占率。
  • 层2 扩展业务：主业迁移空间（车载电子纸 + 多色中大尺寸）：从"零售 ESL"迁移至"车载/多场景电子纸"，TAM 显著扩容（元太×宝马催化）。信号验证：窄边框 GIP 架构研发 + 车载场景突破 → 已初步验证，计入中期增量。
  • 层3 风险折扣（证伪信号）：终端需求疲软、TDDI 价格战致毛利率破 20%、ESL 份额降至 70% 以下、车载落地失败 → 触发则下调。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。现价 21.42 对应 2026E PE 约 28x，已低于基准 27.3 元；全球 ESL 垄断 + 低负债 + 高 ROE 支撑溢价。

安全边际：
- 中性远期 33.4 元 → 空间 +55.9%（>50% 门槛）
- 悲观 16.1 元 → 下行 −24.9%（有限，低负债护体）
- 下行保护：净资产 25 亿、资产负债率 17.3%、经营现金流 +3.14 亿

介入条件：
1. 现价可布局：21.42 已低于基准，分批买入
2. 加仓信号：ESL 多色/车载落地、TDDI 市占突破 25%、单季毛利率稳于 25%+

最大风险：
1. 终端需求波动（首要）：手机/平板周期影响 TDDI 出货
2. TDDI 价格战：国产阵营竞争致毛利率承压
3. 技术迭代：OLED/Micro LED 路线变化

上行想象力四类情景：
- A 行业调整剩者红利：显示驱动国产替代加速，份额向头部集中（验证点：国产 DDIC 份额）
- B 政策反转期权：消费电子补贴加码 + 半导体国产化提速（验证点：补贴规模、国产采购比例）
- C 市场错杀修复：若因消费电子周期被错杀，景气回升即修复（Q2 已环比翻倍印证）
- D 技术突破期权：车载电子纸从 0 到 1（元太×宝马催化）+ 多色中大尺寸电子纸量产，重构 TAM（硬验证点：客户定点/量产成本优——研发已突破、待车载定点，计入乐观/中性偏乐观）

结论：重点关注。全球 ESL 垄断（80% 份额）+ 显示驱动国产替代 + 低负债高 ROE，现价 21.42 已低于基准 27.3 元，中性远期空间 +55.9% 超 50% 门槛且确定性高（Q2 环比净利 +99.79% 印证景气回升）。车载电子纸落地可进一步上调。
