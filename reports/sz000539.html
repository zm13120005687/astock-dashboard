粤电力Ａ（000539）五步法分析报告

分析日期：2026-09-25 ｜ 现价 4.95 元（2026-09-24 收盘）｜ 总市值 259.89 亿（A 股流通市值 126.49 亿）｜ PE(TTM) −2381x（亏损）｜ PB(LF) 1.14x ｜ 总股本 52.50 亿股（A 股流通 25.55 亿）
行业：火电 + 气电 + 新能源发电（广东区域龙头）｜ 实控人：广东省国资委
强周期 + 真实亏损专项：经核对 2026 年半年报，2026H1 归母净利 −5.46 亿元（真实亏损），按周期位置校正 + 三情景处理，非 TTM 误标。

第一步：公司是干什么的？

一句话定位：广东省能源龙头，以煤电、气电为压舱石，正加速向风光新能源转型（清洁能源装机占比已近 50%）；当前处于"电价市场化下行 + 燃料成本波动 + 新机组折旧"三重挤压的周期底部。

（3）产业链传导

上游：动力煤（煤电燃料，占比成本 ~60%）、天然气（气电）。煤价 2025 已跌 18% 至 703 元/吨，2026H1 同比有所反弹抬升燃料成本；气价随国际波动。

下游：广东电网 + 市场交易。需求端工业用电强劲，但电价由交易竞争决定，公司议价权中（区域龙头但受市场化压制）。

议价权：中等偏弱——电量电价随市场下行，仅容量电价为政策托底刚性。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数）：煤电"电量电价"由市场交易决定，煤价上涨无法完全转嫁（α≈0.4，部分靠容量电价 + 长协煤缓冲）；气电 α 更低。验证点：煤价与毛利率背离；证伪：煤价涨但毛利率稳（说明传导改善）。
  • 因子2 毛利结构再平衡：煤电（H1 亏）、气电（H1 亏）、新能源（H1 亏）三负，仅本部投资正。分业务看，煤电对煤价敏感、气电对气价敏感、新能源对交易电价敏感；无正毛利业务对冲。验证点：分板块扭亏；证伪：板块持续亏损。
  • 因子3 库存与采购节奏：长协煤 + 库存调节部分对冲煤价波动；2026H1 高价接货（煤价反弹）形成成本压力。验证点：燃料成本率；证伪：煤价回落成本不降。
  • 因子4 政策 / 市场锚点：① 容量电价（政策层，托底）；② 煤价（市场层）；③ 广东交易电价（市场层，已 −5.1%）；④ 气价（市场层）。情景：煤价低位 + 容量电价 → 煤电修复；煤价反弹 + 电价续降 → 恶化。验证点：煤价、容量电费确认。

输出：第四步采用周期归一化净利率，中性假设煤价低位 + 容量电价托底 + 电价微降。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（容量 × 份额）：广东用电需求韧性强（工业 +9.1%），公司区域龙头份额稳固。五锚点：① 供给侧份额（装机增）；② 客户份额=电网，稳；③ 技术代际无差异；④ 成本曲线（煤价低位）；⑤ 份额加速度正。三档：保守（电量 +10%）、中性（+18%）、乐观（+25%）。验证点：上网电量公告。
  • 层2 主业迁移空间：由煤电向新能源（风光）迁移，清洁能源占比 47.66%→目标 40%+ 新能源装机增量，已验证（新能源电量高增），计入中性但打折。
  • 层3 证伪信号：电价加速下行、煤价大涨、新能源利用小时续降。

第四步：估值锚定（自下而上，非增速外推 + 周期校正）

方法说明：2026H1 真实亏损，但 2025 全年仍盈利 6.00 亿，属周期底部而非永久劣化。采用周期归一化净利（不用 2026H1 年化 −10.9 亿，也不用 2025 高电价年简单外推），取煤价低位 + 容量电价托底 + 电价微降的稳态。

总股本：52.50 亿股；当前总市值 259.89 亿；归母净资产约 228 亿（PB 1.14）。

第四步进阶：重资产 / 周期股校正（三道闸）

  • 校正1 资产质量折扣：PB 1.14 未破净，资产以火电 / 新能源机组为主（专用但持续经营价值在），无金融资产未重估问题。当前溢价温和，合理。
  • 校正2 周期位置校正：当前处于周期底部偏左（2026H1 真实亏损，电价下行 + 煤价反弹 + 新机组折旧），但煤价 2025 已跌 18%、容量电价 165 元托底，向下空间有限。中性净利取周期归一化 10.2 亿，未用 2026H1 年化、未用 2025 外推。标注：周期位置 = 底部。
  • 校正3 杠杆下行情景：资产负债率偏高（电力重资产），利率上行 / 需求下行 → 净利可降至 5 亿，悲观情景 −80.8%，不标大空间。

期权纪律：新能源转型放量、煤电修复均未过验证点，仅放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（周期底部定价未充分反映修复，但也未给安全边际）。现价 4.95 元对应总市值 259.89 亿，而周期归一化中性目标价仅 2.33 元；即使乐观情景 5.14 元也仅 +3.8%。市场已计入较多"周期修复 + 区域龙头"溢价。

安全边际：中性远期 2.33 元 → −52.9%；悲观 0.95 元 → −80.8%；乐观 5.14 元 → +3.8%。上行极薄、下行深，典型周期股底部但仍贵。

介入条件：回落至 3.5 元以下（接近悲观与中性之间、PB 0.8x）且出现：① 煤价维持低位；② 广东交易电价企稳；③ 单季主业扭亏。当前 4.95 元不满足。

最大风险：① 电价市场化持续下行（广东交易均价已 −5.1%）；② 煤价 / 气价反弹吞噬燃料成本优势；③ 新能源利用小时不及预期；④ 新机组折旧 + 财务费用压制（重资产）。

结论：暂不介入

理由：2026H1 真实亏损、中性周期归一化锚（2.33 元）远低于现价、乐观情景也仅 +3.8%，安全边际缺失。公司是优质区域龙头、周期底部确有容量电价托底，但当前价格未给介入安全垫。作为"周期底部观察候选"，待 3.5 元以下或主业单季扭亏信号再评估。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：电价下行期中小电厂出清，粤电作为区域龙头份额与议价改善。验证点：行业装机增速放缓、交易电价企稳；证伪：价格战持续。
  • B 政策反转期权：容量电价进一步提升 / 煤价低位延续 / 电力现货价格回升。验证点：容量电价加码、煤价低位；重估弹性：乐观净利 18 亿 → 5.14 元。
  • C 市场错杀修复：若市场过度担忧 2026H1 亏损，PB 1.14 提供修复弹性。验证点：主业单季扭亏；证伪：续亏。
  • D 技术突破期权：不适用（火电 / 新能源无代际跃迁）。

上调至"重点关注"的条件：煤价维持低位 + 广东交易电价企稳 + 单季主业扭亏且 2029 净利站上 18 亿（乐观情景兑现），对应 5.14 元并具持续性，届时重新评估。
