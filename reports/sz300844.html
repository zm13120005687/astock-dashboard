（3）产业链传导

上游：设计行业成本以人力（设计师薪酬）为主（占比最高），辅之以苗木、建材、效果图渲染外包。人力成本刚性上行，苗木 / 建材随大宗商品波动。

下游：① 房企——信用走弱、付款周期拉长、设计费压价（弱议价，回款风险高）；② 政府 / 平台——回款相对有保障但预算收紧、招投标低价竞争。综合议价权中等偏弱。

议价权量化：设计费占项目总投资比例低（通常 1–3%），甲方强、乙方卷，转嫁系数低（≈0.2–0.3），成本与降价压力主要由设计方承担。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（pass-through）：设计业核心成本是人力，几乎不可转嫁（转嫁系数 ≈0.25）。当下游（房企）压价时，毛利率被直接吃掉。验证点：H1 综合毛利率 37.18%（−7.83pct），社区景观毛利率 36.60%（同比下滑），印证弱传导。政策锚点（政府项目）付款条件较好但限价，转嫁系数略高（≈0.4）。
  • 因子2 毛利结构再平衡：分业务线毛利率差异大——居住建筑 44.72% > 商业空间 43.62% > 社区景观 36.60% > 文旅 19.33%。当高毛利的文旅 / 市政占比提升、低毛利的地产社区景观占比下降时，结构毛利改善。禁单一综合毛利率：H1 综合 37.18% 掩盖了"地产配套占比仍 71%"的结构脆弱。若市政 / 文旅占比升至 30%+，加权毛利率可上修 2–4pct。
  • 因子3 库存与采购节奏（timing）：设计业无实物库存，但存在"已发生人工成本未确认收入"的合同履约成本（存货性质）。H1 经营现金流 −5244 万（同比 −24.81%）反映回款慢于成本支出；信用减值损失 −2283 万（应收账款坏账）是关键拖累，非真实盈利能力但消耗现金。
  • 因子4 政策 / 市场锚点（原料成本驱动变量）：① 市场层——房企信用风险（坏账计提）是直接成本变量；② 政策层——政府项目回款改善（城市更新配套融资机制）可降低减值；"数字住建 / AI 设计"降本提效（减少重复劳动）是毛利正向变量。情景：若城市更新订单落地且回款改善，减值转回 + 结构毛利上修；证伪信号：地产违约扩散、政府项目拖欠加剧致减值继续扩大。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：景观设计极度分散，公司属头部梯队，份额提升靠并购 / 区域扩张。
  • 需求侧：政府客户（市政 / 生态修复）占比提升 → 客户结构优化，但政府项目单价低、账期长。
  • 技术代际：数字景观 / AI 设计领先者可溢价（公司处第一梯队）。
  • 成本曲线：AI 提效使单位设计成本左移，可"以价换量"抢份额。
  • 份额加速度：地产配套份额在流失，市政 / 生态修复份额在爬升（S 曲线早期）。
    → 三档：保守守住（营收 4.0 亿）/ 中性小幅提升（4.8 亿）/ 乐观抢份额（6.0 亿）。验证点：逐季市政 + 文旅收入占比、新签政府订单金额。
  • 层2 扩展业务：主业迁移空间（新易盛范式）：从"地产配套设计"迁移到"城市更新 / 生态修复 / 数字景观"——能力同源（设计能力复用），新 TAM（5 万亿级）远大于旧池塘，但客户认证门槛高（政府资质、业绩门槛）。信号验证：市政 / 文旅营收占比跳升（当前仅 ~6%，未过验证点）→ 仅作中期期权，不计入中性。
  • 层3 风险折扣（证伪信号）：地产违约致减值扩大、政府项目回款恶化、市政订单招标不及预期、AI 提效未兑现致费用率居高。命中则下调增量。

方法说明：山水比德为亏损股，不适用 PE 估值，采用正常化净利润法（估稳态营收 → 保守正常化净利率 → ×远期合理 PE → 目标市值 → 目标价）。严禁用历史增速外推。

总股本：约 0.932 亿股 ｜ 净资产 7.69 亿 ｜ 负债率约 24.7%（轻资产、低负债）。

准亏损从严：正常化净利润法 + 亏损股三问

为什么亏：① 地产配套景观需求收缩（社区景观收入 −11.58%），高毛利业务占比下降；② 毛利率同比 −7.83pct（成本刚性 + 降价）；③ 信用减值损失 −2283 万（房企应收账款坏账计提）；④ 费用刚性（管理 + 研发）在收入下滑时摊薄效应反转。本质是行业周期 + 地产信用风险叠加，非主业崩塌。

靠什么扭亏，触发时点：① 城市更新 / 生态修复 / 乡村振兴订单落地（2026-09 政策刚发布，2026H2–2027 招标放量）提升市政 / 文旅占比；② 居住建筑 / 商业空间已回暖（H1 +166.77%）补位；③ AI / 数字景观降本（人工成本降 10–20%）。触发时点：2027 年——若 H2 接单延续、减值收敛，2027 全年有望扭亏；2026 全年仍大概率亏损。

亏得起吗：总资产 10.22 亿、净资产 7.69 亿、负债率仅 24.7%，无有息负债压力；账面资金充裕（上市超募 1.82 亿未大幅消耗）。经营现金流 H1 −5244 万（回款节奏问题，非失血性），亏得起，不会倒在黎明前。但连续亏损消耗现金，需关注回款改善。

第五步：综合赔率判断（买不买？）

当前价格位置：显著偏高。现价对应正常化净利 22x 目标市值的 2.6 倍溢价，属"故事定价"而非"盈利定价"。

介入条件：① 不追高，等回落至 12 元以下（对应市值 ~11 亿、接近中性目标）才具安全边际；② 加仓信号：市政 + 文旅收入占比连续两季 >20%、减值计提收敛、2027 全年扭亏确认。

最大风险：① 地产违约扩散致减值继续扩大；② 城市更新 / 生态修复订单落地慢于预期、政府回款恶化；③ 行业低价内卷致毛利率进一步下滑；④ 连续亏损对现金的持续消耗。

结论：暂不介入（估值已大幅透支转型预期，需等盈利拐点或价格回落至 12 元以下再观察）。

公司质地不差（轻资产、低负债、品牌强、政策顺风），但当前价格隐含的"城市更新 + AI 设计"预期过于饱满，基本面尚在亏损。真正的机会在于：若 2027 年扭亏且市政 / 生态修复订单放量（乐观情景 16.74 元），则具备重新上调至"纳入观察 / 重点关注"的条件。
