第一步：公司是干什么的？

一句话定位：以市政/工业环保运营（BOT、委托运营）为现金牛，正向生物天然气、生物燃油（UCO→SAF）、数据中心制冷等生物能源与节能新赛道转型的"运营+能源"双轮公司（2026-06 由"维尔利环保科技集团"更名为"维尔利科技集团"）。

核心产品/服务：环保工程 EPC、BOT/委托运营、UCO（废弃食用油）预处理工厂、生物天然气项目、数据中心/算力中心冷却系统。

主要客户/下游：地方政府（市政环保）、工业企业（化工/PVA/醋酸）、航运/清洁燃料（中国船舶燃料）、东南亚市场（出海）。

股东背景：民营控股，无央企背景；2026H1 归母净资产约 31.3 亿（较期初 +18.97%，主要系回款与权益变动）。

（3）产业链传导

上游：UCO 原料（废食用油）、工程设备、天然气。UCO 价格随 SAF 需求上行，公司通过"华东+东北两处预处理工厂"锁定原料、健全供应链，部分对冲成本。

下游：市政（BOT 回款）、工业企业（能效改造付费）、航运/清洁燃料（中船燃料长约）、欧盟（ISCC 认证溢价）。下游需求刚性且向上。

议价权：运营端中等（BOT 长约锁价），生物能源端中偏弱（原料采购竞争激烈，但认证壁垒提供溢价）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：UCO 原料涨 → 终端 SAF/生物天然气价格联动上行，转嫁系数≈0.6（认证溢价+长约部分传导）；工程端人工/设备成本转嫁弱（≈0.2）。依据：2026H1 收缩低毛利工程、提升高毛利运营，综合毛利率 26.04% 企稳。
  • 因子2 毛利结构再平衡：环保工程（低毛利、波动）占比下降，BOT 运营（稳、高毛利）与生物能源（高毛利、增量）占比上升 → 结构向利润倾斜。验证：2026H1 经营现金流 +315% 远超利润，运营质量改善。
  • 因子3 库存与采购节奏：UCO 原料存"低价囤货收益"，需区分当期毛利与真实盈利能力；预处理工厂布局降低断料风险。
  • 因子4 政策/市场锚点：欧盟 RED/IMO 航运脱碳为需求侧强驱动；证伪：欧盟认证政策退坡、UCO 价格暴涨致毛利破阈值。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：①供给侧——环保运营区域集中度有限，但 BOT 存量构成护城河；②需求侧——市政/工业客户粘性强；③技术代际——UCO 预处理+ISCC 认证领先中小同行；④成本曲线——两处工厂降本；⑤份额二阶导——生物能源处早期渗透。三档：保守守住（营收 7 亿）/中性（9 亿）/乐观（12 亿）。
  • 层2 扩展业务（主业迁移·新易盛范式）：环保运营 → 生物能源，能力可迁移（资源化技术同源），新 TAM（SAF 全球千亿级）弹性大，卡位早期（认证壁垒），客户认证门槛高（ISCC+中船）。信号验证：ISCC 获证、中船框架。中期期权，未过营收跳升验证前不计入中性。
  • 层3 证伪信号：UCO 价格暴涨、ISCC 认证未转化为批量订单、现金流再恶化 → 下调。

亏损股口径说明与扭亏三问（按真实财报订正）

  1. 为什么亏（2025 全年 −3684 万）：① 低毛利市政工程占比高、行业竞争致毛利率承压；② 应收账款减值拖累；③ 生物能源尚处投入期未贡献。此即 TTM 负 PE 来源。
  2. 靠什么扭亏，触发时点：2026H1 已靠①成本管控/人员优化、②应收账款催收+坏账冲回、③高毛利运营占比提升实现扭亏（+3219 万）；生物天然气/UCO 项目 2027–2029 陆续投产为可持续盈利支点。触发时点：2026 已兑现、2027 起进入放量期。
  3. 亏得起吗（现盈利，复盘生存能力）：净资产约 31 亿、PB 仅 1.14、经营现金流 +2.49 亿大幅改善，无生存之忧；当前价格已含反转预期。

第四步进阶：重资产/周期股校正（三道闸）

  • 校正1 资产质量折扣：PB 1.14 接近破净，但非"真破净"——净资产含 BOT 项目公允价值与运营资产，且 2026H1 净资产较期初 +18.97%，资产质量未恶化；破净主要为市场对其工程历史与负债的折价，非低估信号。
  • 校正2 周期位置校正：环保/生物能源处"运营替代工程 + 生物能源起步"拐点，中性净利取稳态 1.4 亿（非 2025 亏损年、亦非单季扭亏年化）。
  • 校正3 杠杆下行情景：资产负债率约 55–60%（偏高），利率/需求下行时净利可承压 → 悲观 3.0 元（−22.1%），故中性不得标"大空间"。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏高。现价 3.85 对应 PB 1.14（贴近净资产），但前瞻盈利（2026E 0.7 亿）仅支撑约 14 亿市值，当前 36 亿主要定价"生物能源第二曲线"期权。

安全边际：中性远期 4.0 元 → 空间 +3.9%；悲观 3.0 元 → −22.1%（有净资产+运营现金流托底，下行有限）；乐观 6.5 元 → +68.8%（生物能源放量）。

介入条件：① 价格回落至 3.4 元以下（PB<1） 方具安全边际；② 加仓信号：生物天然气项目单季营收跳升、UCO 工厂满产、中船燃料订单落地；③ 观察：经营现金流持续为正、负债率下降。

最大风险：① 生物能源项目投产与认证溢价兑现不及预期；② UCO 原料价格暴涨挤压毛利；③ 资产负债率偏高、工程回款再恶化；④ 名称"去环保化"转型执行风险。

结论：纳入观察（反转已确认、资产底扎实，但现价已反映预期、空间有限；待价格回落至 PB<1 或生物能源营收验证后介入）。

上行想象力（第五步进阶·四类情景，仅进乐观/机会栏）：
- A 行业调整剩者红利：环保工程出清后运营龙头份额提升 → 验证点：BOT 中标公告。
- B 政策反转期权：欧盟 RED/IMO 航运脱碳加码、CCER 重启抬升生物能源盈利 → 验证点：政策发文+认证溢价落地。
- C 市场错杀修复：TTM 负 PE 误标致市场错杀，H1 扭亏后修复 → 验证点：财报扭亏、机构重新覆盖。
- D 技术代际跃迁期权：UCO→SAF 从 0 到 1 投产 + ISCC 认证 + 中船定点三要素共振 → 硬验证点：中试(预处理)满产、客户定点订单、量产成本优于旧路线。达到则上调至"重点关注"。
