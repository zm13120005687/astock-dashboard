（3）产业链传导

上游：钢材、液压件、发动机、电控。2025 年以来钢材价格中枢下移，但公司毛利率反而大幅下滑，说明成本红利未留在公司手上，被价格战让给了客户。

下游：基建（两重/城市更新/地下管网）是政策托底项；房地产链（塔机等）持续拖累；矿山（无人矿卡/绿色矿山）是唯一高增长方向；出口（非洲 +51.7%、大洋洲 +33.4%、南美 +32.7%）是最强引擎。

议价权：弱。佐证：① 2026H1 营收 +14.75% 而毛利率 −8.24pct；② 应收账款余额 7.41 亿元、坏账准备 3.09 亿元（单项计提 3.37 亿元、计提比例 88.93%），前五大客户应收占比 50.10%；③ 盾构租赁受地铁建设放缓，收入 −1,644.86 万元且毛利率"由正转负"。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1 成本传导弹性（pass-through）
钢材约占工程机械整机制造成本 20–25%。行业处于"内卷式"低价竞争，且厦工规模远小于三一/徐工/中联，传导率仅约 0.3–0.4（行业均值 0.4–0.5）。含义：钢材每下跌 10%，公司毛利率理论上改善不足 1pct，而实际 2026H1 毛利率同比 −8.24pct——说明"成本没降多少、售价降更多"，真正吞噬毛利的是价格战而非原料。

验证点：季度毛利率与钢材价格指数是否同向；证伪信号：钢价上行且毛利率继续下滑（传导率<0.3）。

因子 2 毛利结构再平衡（分业务线，禁用单一综合毛利率）

业务线 2026H1 收入 毛利率方向 关键原料敏感度
土石方机械 1.38 亿元（存量基本盘） 下行（竞争白热化、产品同质化） 钢材敏感度高
隧道掘进机械 0.775 亿元（爆发） 较高（凿岩台车推进梁总成属定制件） 钢材敏感度中
矿山机械（智能矿卡） 0.442 亿元（全新） 较高（智能化/新能源溢价） 钢材 + 锂电（电池成本敏感）
装备租赁 0.210 亿元 由正转负（折旧刚性、开工不足） 无直接原料，折旧敏感
配件及其他 0.704 亿元 中性 钢材敏感度低

结论：综合毛利率 8.70% 掩盖了结构剧变——低毛利土石方+租赁在拖累，高毛利掘进/矿卡在抬升，加权后仍是下行。估值必须分业务给毛利，不能沿用历史 12.83%（2025）或 23.84%（2024）。

因子 3 库存与采购节奏（timing）
2026H1 经营现金流 −2.03 亿元（同比多流出 1.39 亿元），公司自述因"隧道掘进机械及智能矿卡业务支付备料款项；现有业务收款放缓"。含义：当期现金流恶化部分是"为新业务主动备料"，不完全等于基本面恶化；但收款放缓与信用减值计提 1,664.98 万元（上年为转回收益 877.35 万元）是真实的质量问题。无套保披露，汇兑损失使财务费用由 −367.88 万元转为 +441.79 万元。

验证点：存货周转与经营现金流是否在 2026H2 改善；证伪信号：备料转为滞销存货，需计提跌价。

因子 4 政策 / 市场锚点（原料成本驱动变量）
- 市场层：钢材价格指数、锂电（碳酸锂）价格——矿卡电动化抬升电池成本敏感度；运费与出口关税影响海外毛利。
- 政策层：① 国四排放升级与 2,000 亿元设备更新国债 → 提升"淘汰换新"需求密度；② 矿山智能化标准（2026 年收官）→ 直接催化无人矿卡采购；③ "两重"与城市更新资金 8,000 亿 + 2,570 亿 → 决定掘进机械需求；④ 关税/贸易保护 → 海外扩张的达摩克利斯之剑（公司自述"出口销售增长乏力"）。

验证点：季度行业销量与公司订单；证伪信号：政策资金下达但公司新签订单未跟（渠道/资质劣势）。

层 2 扩展业务：主业迁移空间（"旧池塘→新池塘"）
- 能力可迁移性：中高。工程机械的底盘、液压、电控、结构件能力可直接复用到矿卡与掘进设备（技术同源）。
- 新 TAM 弹性：高。无人矿卡市场 56 亿元（2026）→223 亿元（2030）；绿色矿山整体市场 2035 年看 1,200 亿元。
- 切入时点与卡位：早期（渗透率 18%），但公司是主机厂而非智驾方案商，无人驾驶核心算法多由第三方提供，先发红利有限。
- 客户认证门槛：矿区认证周期长（安全/可靠性），已覆盖 300+ 矿区的是宇通等，厦工尚在起步。
- 信号验证：2026H1 矿山机械收入从 0 到 4,424.78 万元 = 首个可验证信号已出现；但占营收仅 12.4%，未过"占比跳升"门槛，只能算中期期权。

层 3 风险折扣：证伪信号
① 土石方机械毛利率若跌破盈亏线（当前综合 8.70%）→ 基本盘失血；
② 盾构租赁若继续亏损（2026Q1 毛利率已转负）→ 被动计提折旧拖累；
③ 应收账款/信用减值若继续大额计提（单项计提比例已 88.93%）→ 侵蚀净资产；
④ 矿卡/掘进新业务若不能连续两个季度维持放量 → 成长故事证伪。

第四步：估值锚定（自下而上，非增速外推）

方法说明：公司当前亏损，无正 PE 可锚，采用亏损股专项估值口径（正常化净利润法）三步推导：估稳态营收 → 取保守正常化净利率 → 乘远期合理 PE → 目标市值 → 目标价。不使用历史增速外推；营收按"土石方 + 掘进 + 矿卡 + 租赁 + 配件"五条线分别测算，用已披露在手订单与产能校验。

亏损股必答三问

  1. 为什么亏？ ① 盾构租赁受城市地铁建设放缓，收入 −1,644.86 万元且毛利率由正转负（设备折旧刚性）；② 土石方机械价格战，毛利率下降；③ 汇兑损失使财务费用由 −367.88 万元转为 +441.79 万元；④ 信用减值计提 1,664.98 万元（上年为转回收益 877.35 万元，一正一负形成约 2,542 万元利润缺口）；⑤ 历史呆坏账清欠回款与理财收益减少。
  2. 靠什么扭亏、何时？ 三条路径：A. 隧道掘进机械（在手订单 2.4 亿，2026H1 已放量）；B. 矿山机械（智能矿卡）（从 0 到 1，行业渗透率 18%→52%）；C. 装备租赁收缩减亏。触发时点：若新业务收入占比在 2027 年突破 35% 并稳住毛利率，2027–2028 年有望接近盈亏平衡。但需注意：2026Q2 营收环比 −28.92%、Q2 毛利率仅 6.08%，扭亏时间点存在后移风险。
  3. 亏得起吗？ 亏得起。2025 年末总资产 24.08 亿元、负债 7.13 亿元，资产负债率仅 29.62%、有息负债 1.65 亿元（有息负债率 23.08%），现金比率 54.88%、速动比率 2.24。间接控股股东为世界 500 强厦门国贸控股，融资与资源支持有保障。生存风险低，但"低杠杆"不等于"低估"。

第四步进阶：重资产 / 周期股估值校正（三道闸 + 期权纪律）

校正 1 资产质量折扣（PB 4.55x，属"高 PB"而非破净，须说明高 PB 来源）
公司 PB 高达 4.55x（每股净资产仅 0.794 元，每股未分配利润 −2.68 元），净资产已被历史亏损大幅侵蚀。高 PB 的唯一解释是主题溢价（无人矿卡），而非资产质量。反向提示：净资产 14.1 亿元只提供约 0.79 元/股的"账面兜底"，且其中含 7.41 亿元应收账款（已计提 3.09 亿元坏账），真实清算价值更低。→ 禁止用"PB 高 = 资产好"倒推价值。

验证点：应收减值是否继续大额计提；证伪信号：净资产因减值跌破 0.7 元/股。

校正 2 周期位置校正（中性净利用周期归一化）
工程机械正处上行周期早中段（2026H1 行业销量 +18.3%，更新周期 + 出口双驱动），但公司自身份额与盈利未同步。中性净利采用行业正常净利率 4.5%（非单年好年景、非近三年均值——近三年恰为亏损/微利低谷，也不取拐点年化），符合周期归一化要求。

验证点：行业工作时长/开工率与公司毛利率是否同向回升；证伪信号："销量涨、开工低"背离延续至 2027。

校正 3 杠杆下行情景（低负债，但须防"低杠杆高估值"）
资产负债率 29.62%，杠杆风险低，不构成强制负面情景。但需附估值下行情景：若 2027 年矿卡/掘进未兑现且价格战延续，PB 可能从 4.55x 回归机械行业中枢 1.5–2.0x → 股价 1.2–1.6 元（较现价 −56% ~ −67%）。

期权纪律：甲醇挖掘机、纯电矿卡、VCU 自研等未过验证点，一律只放"乐观情景"，不计入中性。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。现价 3.61 元对应 2026E 仍亏损、PB 4.55x、PS(TTM) 约 9x；中性远期目标 0.83 元对应 −77.0% 空间。64 亿元市值对应不足 0.6 亿元的正常化盈利，隐含 PE 逾 100x。

安全边际：
- 中性远期 0.83 元 → 空间 −77.0%，风险收益严重不对称
- 乐观情景 1.70 元 → 仍 −52.9%，即"最好的想象"也不足以支撑现价
- 悲观 0.20 元 → −94.4%
- 下行保护：账面净资产 0.79 元/股（且含高额已计提坏账），不构成有效支撑

介入条件：
1. 不介入。现价隐含 PE 逾 100x，任何"业绩兑现"都难以匹配估值。
2. 潜在观察信号（仅列示，不构成买入）：① 矿山机械收入占比连续两季度突破 20%；② 综合毛利率回升至 15% 以上；③ 装备租赁业务止血（毛利率转正）。
3. 观察指标：单季营收环比、应收减值计提、盾构租赁毛利率。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 估值与业绩的极端背离（首要）：64 亿元市值 vs 不足 0.6 亿元正常化盈利，主题溢价随时可能回归。
2. 主题交易退潮：2026-09-08 冲高至 4.42 元（收 4.18）后，9/9 单日 −9.8%、9/10 再 −4.2%，两天累计回撤约 13.6%——主题资金已现松动。
3. 资产负债表质量：应收账款 7.41 亿元、坏账计提比例高（单项 88.93%），仍可能继续计提。
4. 新业务不确定：在手订单仅约 3.4 亿元，矿卡业务尚在起步，认证与份额均未验证。

结论：暂不介入

公司并非"无扭亏路径"（掘进机械 + 智能矿卡真实放量、低负债、国资背景），因此不判"坚决回避"；但现价 64 亿元市值为不足 0.6 亿元的正常化盈利支付了逾 100 倍估值，中性远期空间 −77.0%，乐观情景亦为 −52.9%，赔率远超可接受范围。
什么条件出现才上调至"重点关注"：股价回落至 1.2 元以下（PB ≈ 1.5x、对应乐观情景有正空间），且矿山机械收入占比连续两季 >20%、综合毛利率回升至 15% 以上。
