（3）产业链传导

  • 上游：IP 授权费（环球、NBA、聚星动力等）、模具与开模费、毛绒/塑胶/贵金属等原材料、供应链代工产能、新媒体流量采买成本。
  • 下游：B 端为企业市场部预算（顺经济周期、可被削减）；C 端为个人消费者的可选消费（顺消费信心）。
  • 议价权判断：
  • 对上游 弱：IP 方是强授权方（保底授权金+分成），代工厂可替代，原材料随行就市。
  • 对 B 端客户 弱偏中：大客户（尤其金融/快消巨头）压价能力强，可随时切换供应商；公司靠设计获奖与供应链速度维持份额。
  • 对 C 端消费者 尚未形成：新品牌无定价权，靠 IP 热度与渠道铺货，毛利被渠道（山姆/TOPTOY 等）分走。
  • 产业链位置结论：处在 IP 产业链的「中游加工/分发」位置，上下游双向受挤压；唯一的突围方式是从「代工+服务」升维到「自有品牌 + 自有 IP 运营」——这正是「元隆元创」要做的事，但难度与投入都不小。

第二步进阶：原料成本 → 毛利结构传导（四因子）

元隆雅图的「原料」不是铜、锂这类大宗，而是IP 授权费 + 供应链采购 + 流量成本。四因子按此改写。

因子1 成本传导弹性（pass-through）
- IP 授权成本：与版权方签的是保底+分成，基本无法向下游转嫁（C 端新品定价受竞品锚定）。转嫁系数 ≈ 0.2——IP 涨价 10%，公司实际毛利承压约 8%。
- 供应链（毛绒/塑胶/五金）成本：礼赠品业务对 B 端客户多为「方案报价制」，可部分随行就市调整报价，转嫁系数 ≈ 0.5。
- 新媒体流量采买：完全市场化，且公司是买方，成本上涨需自扛，转嫁系数 ≈ 0.1。
- 综合转嫁系数 ≈ 0.3（弱议价权）。验证点：IP 授权合同续约条款、礼赠品报价与成本指数背离度。

因子2 毛利结构再平衡（分业务线，禁用单一综合毛利率）

业务线 2026H1 毛利率 同比 毛利额贡献 成本敏感对象
礼赠品 14.95% +3.58pct 0.77 亿（约 49%） 塑胶/毛绒/五金 + 开模
促销服务 10.71% +2.77pct 0.25 亿（约 16%） 人力 + 场地
新媒体营销 15.48% −4.43pct 0.57 亿（约 36%） 流量采买（最敏感）
特许纪念品 下滑 91.52% — 忽略 —

结构迁移的方向是「好的」：低毛利的促销服务被动收缩（−49.16%），高毛利的礼赠品与新业务占比提升，推动加权毛利率由 12.54% 升至 14.96%。但要注意：新媒体营销虽增长 38.94%，其毛利率却下滑 4.43pct——说明增长靠低价换量，这是「增量不增质」的信号，必须单独盯。

因子3 库存与采购节奏（timing）
- 公司 2026H1 计提资产减值损失 951.13 万元（上年同期 2640.63 万元，大幅收窄），信用减值损失转回 48.46 万元。
- 关键 timing 事实：账面商誉原值 1.71 亿元（子公司谦玛网络）已于以前年度全额计提减值，本期商誉账面价值为零——即减值风险已充分释放，这是「为什么亏」中最重要的一条，也是 2026 年减亏的直接原因。
- 世界杯 IP 产品为 2026H2 集中铺货，存在备货前置：若 Q4 动销不及预期，2026 年报可能出现存货跌价——这是 2026H2 最需要盯的 timing 风险。

因子4 政策/市场锚点（原料成本驱动变量）
- 市场层：IP 授权金议价（环球等国际 IP 方通常要求 3–5 年保底增长）、流量价格（抖音/小红书的 CPM 走势）、毛绒/塑胶原料（PP/ABS 价格）。
- 政策层：促消费政策（正向）、赛事审批与版权保护（正向）、广告/直播监管（负向）。
- 情景 + 验证点：①若 IP 授权金年涨 10%，按转嫁系数 0.2 计，将侵蚀毛利约 0.8pct；②若流量成本上行 15%，新媒体营销毛利再降 3pct 左右。证伪信号：新媒体营销毛利率若跌破 12%，该板块的增长应视为「无效增长」，估值中不予加分。

本因子输出（直接喂给第四步）：中性情景假设综合毛利率仅温和修复至 15.5–16.0%（不沿用历史高点），新媒体营销毛利率不再下滑；这是估值里最脆弱的一环。

层2 扩展业务：主业迁移空间（新易盛范式检验）——「B 端礼赠品/供应链设计能力」→「C 端 IP 文创品牌运营」

检验点 判断 证据
①能力可迁移性 部分可迁移 设计、IP 授权谈判、供应链管理可直接复用；但品牌运营、零售选址、会员复购、库存周转完全不同——这是最大的能力缺口
②新 TAM 弹性 大 IP 文创/潮玩约 1000 亿市场，是公司当前 IP 收入的 200 倍以上；公司原有礼赠品市场仅个位数增长
③切入时点与卡位 偏晚但未定型 泡泡玛特/TOPTOY 已跑出规模；公司 2025 年才推「元隆元创」，属后来者，但有独家 IP（世界杯国家队、环球长期合作）作为差异化卡位
④客户认证门槛 低（面向消费者） 无需大客户认证；真正的门槛是渠道位与 IP 热度，公司已进山姆/沃尔玛/TOPTOY/KKV，渠道位已打通
⑤信号验证 初步有信号，未过关键点 IP 文创收入 +134.48% 是信号；但绝对额仅 4641.80 万，单店模型、复购率、库存周转均未披露——未过验证点

结论：IP 文创是典型的中期期权——TAM 大、能力部分可迁移、卡位已建立、渠道已打通，但规模验证（收入跨过 3–5 亿）尚未发生。按 RULES.md 期权纪律，不计入中性情景，只放乐观情景。

层3 风险折扣：证伪信号
1. 毛利破阈：新媒体营销毛利率跌破 12% → 该板块增长无效，收入增长不再加分。
2. 份额连降：促销服务收入连续两个季度同比降幅超过 30% → B 端基本盘在流失，而非主动收缩。
3. 认证/订单无正式公告：IP 文创若在 2026 年报仍停留在 1 亿以下且无单店模型披露 → 迁移失败，期权价值归零。
4. IP 授权不续：与环球/聚星动力的核心 IP 合作未续约 → 迁移的「独家卡位」逻辑被抽走。
5. 存货跌价：2026 年报若因世界杯备货计提大额存货跌价 → 说明 C 端动销证伪。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正1 资产质量折扣（是否破净？为什么？）
- PB = 2.63x，不破净，因此不适用「破净安全边际」逻辑，反过来要警惕「溢价买轻资产」。
- 资产质量核查：总资产 20.60 亿、归母净资产 12.64 亿。主要资产为应收账款 5.65 亿（占总资产 27.44%，已较上年末下降 5.23pct）、货币资金 4.20 亿、理财 1.50 亿。商誉账面已为零（原值 1.71 亿已全额减值）——这是资产端最干净的一点。
- 折扣结论：轻资产服务/零售公司，账面资产不构成安全垫；估值必须靠盈利能力。禁止用「净资产 12.64 亿」为现价 33.22 亿市值辩护。

校正2 周期位置校正
- 公司业绩的「周期」有二：①B 端营销预算周期（2026 处于收缩尾部）；②IP/潮玩景气周期（2025—2026 处上行，世界杯年是高点）。
- 中性净利不使用 2022 年（冬奥高基数、约 1.67 亿）作为锚，也不用 2023—2025 的低点直接外推，而是用稳态业务结构（B 端 24 亿 + IP 文创 6 亿）自下而上重算，得 1.62 亿。
- 当前周期位置标注：B 端底部区域、C 端上行早段——底部不意味着即刻反转，故中性只给 12.3% 空间。

校正3 杠杆下行情景
- 资产负债率 37.83%（已降），净现金约 +1.77 亿元，有息负债主要为 3.75 亿短期借款，财务费用仅 511.24 万元（占收入 0.44%）。不属高杠杆。
- 但需附需求下行负面情景：若 B 端营销预算再降 20%（收入降至 18 亿、净利率 2.5%）+ IP 文创不达预期（2 亿 × 8%），2029E 净利仅 0.61 亿 × 18x = 11.0 亿 → 4.20 元（−66.9%）。该情景为极端下界，已计入悲观区间之下；因公司无债务风险，不触发「空间转负即降级」的硬约束，但足以说明这不是一个可以「闭眼拿」的标的。

期权纪律：IP 文创规模化（6 亿→10 亿）属未过验证点的中期期权，仅计入乐观情景，不进中性锚。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵。现价 12.68 元 / 市值 33.22 亿，对应 2026E（基本盈亏平衡）无意义 PE、对应中性 2029E 正常化净利 1.62 亿为 20.5x，PB 2.63x（高于历史中枢）。市场已为「IP 文创转型」预付了期权费。

安全边际
- 中性远期 14.24 元 → +12.3%，安全边际薄
- 悲观 6.18 元 → −51.3%，下行风险显著大于上行空间（赔率不对称偏负）
- 乐观 27.36 元 → +115.8%，但需 IP 文创收入从 0.46 亿（半年）做到 10 亿（2029），跨度极大
- 下行保护：净资产 12.64 亿元（每股约 4.82 元）、净现金约 1.77 亿元、经营现金流 +1.32 亿元、资产负债率 37.83%。极端的净资产底约 4.8–5.5 元，但这意味着从现价仍有 55%+ 的理论回撤空间。

介入条件（具体到价格）
1. 不追高：现价 12.68 元缺乏安全边际。
2. 可介入区间：9.5 元以下（对应市值约 24.9 亿、PB 约 1.97x、中性 2029E 正常化 PE 约 15.4x）——此时赔率才转正。
3. 右侧加仓信号（任一）：① 年报 IP 文创分部收入突破 2 亿元且披露单店模型/复购数据；② 促销服务收入同比降幅收窄至 15% 以内（B 端止跌）；③ 综合毛利率站上 16%；④ 元隆元创线下门店数披露且达到 10 家以上。
4. 观察指标：季度销售费用率（是否见顶回落）、新媒体营销毛利率（能否守住 15%）、存货规模（世界杯备货是否积压）。

最大风险（最可能破坏逻辑的因素）
1. ⚠️ IP 文创「起量不起利」（首要）：2026H1 IP 文创收入 4641.80 万、占营收仅 4%，单店模型/复购/库存周转均未披露。若渠道铺开但动销不畅，C 端转型将变成「增收不增利的第二只费用黑洞」。
2. B 端基本盘持续失血：促销服务 −49.16% 尚未见底，礼赠品 −18.20%。B 端若继续下滑，将吞掉 IP 文创的全部增量。
3. 世界杯备货的 timing 风险：2026H2 集中铺货，若 Q4 动销不及预期，年报存在存货跌价与费用结转压力。
4. 历史治理瑕疵：公司曾披露一名销售人员伪造合同虚增收入（涉及 2023—2025 年多个报告期），内控与收入真实性需持续验证。
5. 股本/质押：控股股东质押 764 万股、孙震质押 2276.97 万股，需关注质押比例变化。

第五步进阶：上行想象力情景（四类，显式建模）

类型A 行业调整剩者红利
- B 端礼赠品/促销行业极度分散（CR10 < 10%），在品牌方预算收缩期，小供应商先出清，头部服务商份额被动提升。
- 上行锚定：若行业出清使公司礼赠品份额从不足 1% 提升至 1.5%，按 3000 亿市场计对应约 45 亿收入空间。
- 验证点：公司礼赠品收入同比转正 + 行业中小供应商数量下降。
- 证伪信号：礼赠品收入连续两季继续双位数下滑。

类型B 政策反转期权
- 具体政策名：《关于提振消费专项行动方案》及各地「新型消费/首发经济/谷子经济」支持政策；体育赛事审批与版权保护强化。
- 反转信号：地方对潮玩零售首店给出补贴/租金减免；世界杯周边版权保护专项行动落地。
- 重估弹性：若 C 端零售获政策催化、IP 文创收入超预期至 10 亿，乐观情景对应 +115.8%。
- 纪律：未过验证点（政策文件未落地到公司层面），仅作机会情景，不计入中性锚。

类型C 市场错杀修复
- 错杀证据：① 现价 12.68 元低于 2026Q1 末户均持股市值对应的股价水平（户均持股市值由 10.36 万元降至 7.88 万元，−23.90%），筹码大幅换手；② 商誉减值已全额出清（账面为零），但市场仍按「减值风险股」定价；③ 经营现金流 +40.05%，与归母亏损背离。
- 修复触发点：2026 年报确认扭亏（归母转正）+ 世界杯动销数据公布。
- 重估弹性：PB 从 2.63x 修复至 3.0x 对应约 14.5 元（+14%）。
- 证伪信号：2026 年报仍亏损且经营现金流转负（则「错杀」证伪=基本面确实恶化）。

类型D 技术突破 / 技术代际跃迁期权
- 本类判定：暂不成立。公司为轻资产品牌/服务商，无自研硬科技路线。「大IP+科技」中的「科技」目前仅指数字化营销工具与供应链系统，不构成从 0 到 1 的技术代际跃迁。
- 若未来出现「自有 IP 孵化 + AI 生成内容/设计」的自研能力落地（中试即模型可用、客户付费、成本优于外采），方可归入本类。
- 硬验证点：AI 设计工具在自营产品中的占比、单位设计成本下降幅度。未过验证点前，本类不作为上行来源。

什么条件出现才把结论上调至「重点关注」

需同时满足两条：① 2026 年报确认归母转正（扭亏落地）；② IP 文创分部年收入 ≥ 2 亿元且披露可验证的单店/复购模型。此时中性情景可上修至 2.0 亿+ 正常化净利，远期空间有望突破 50%。

结论：纳入观察

理由：① 亏损性质是「转型期 + 历史减值已出清」而非主业崩塌，亏得起（净现金 1.77 亿、经营现金流 +1.32 亿、未用授信 9.85 亿），具扭亏路径与明确触发时点（2027 年归母转正）；② 中性远期空间 +12.3%（> 0），满足「纳入观察」门槛，但不达「重点关注」的 >50%；③ 悲观情景 −51.3%，赔率不对称偏负，安全边际不足；④ IP 文创是真实的期权（TAM 大、卡位已建、渠道已通），但收入体量尚未验证，按期权纪律不计入中性锚。
核心跟踪点：IP 文创分部收入与单店模型、促销服务收入降幅、销售费用率、世界杯备货动销。
