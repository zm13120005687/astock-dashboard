（3）产业链传导

上游：电气元器件、铜、铝等。成本受铜铝价格影响。下游：中车主机厂、地铁公司、车辆段。轨交客户议价强（招投标），公司处配套层、议价中等偏弱。

议价权：对下游——中等偏弱（主机厂 / 地铁公司强势招投标）；对上游——中等偏弱（元器件被动接受，铜铝部分传导）。盈利靠非标定制壁垒与成本管控。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（转嫁系数）：铜 / 铝等金属传导系数约 0.5（部分长协 / 调价机制滞后），电气元器件被动接受（系数 ~0.3）。综合毛利守稳 26–28% 印证传导基本覆盖。
  • 因子2 毛利结构再平衡：车辆电气 26.37%、检修 28.41%、其他（服务）35.27%。检修占比由 2025 年 37.6% 骤降至 H1 22.7%（结构性收缩），高毛利检修让位于低占比服务——禁止用单一综合毛利代表全结构，结构正由高毛利检修向低体量服务迁移。
  • 因子3 库存与采购节奏：按订单采购，原料库存适中；H1 推动闲置物料合规复用、盘活积压库存降本。
  • 因子4 政策 / 市场锚点（成本驱动变量）：①市场层——铜 / 铝价格、元器件供应；②政策层——修程修制改革（直接决定检修周期与产值）、铁路投资节奏、能耗双控（抬升铜铝成本）。验证点：铜铝价格、检修恢复节奏；证伪：原料大涨且无法转嫁、检修持续低迷。

第三步进阶：份额变量与主业迁移空间三层法

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：轨交电气非标定制资质壁垒高，参与者少；
  • 客户份额：覆盖国内所有城轨地铁 + 中车六大主机厂，份额稳固；
  • 技术代际差：119 项专利、非标快速响应领先；
  • 成本曲线：规模化 + 物料异常管理平台降本；
  • 份额二阶导数：基本盘稳定，增量在海外 / 服务。
    三档：保守守住 / 中性小幅提升（海外 + 服务）/ 乐观抢份额（海外放量）。
  • 层2 扩展业务：主业迁移空间（设备商 → 全生命周期服务商）：能力可迁移（电气技术同源）、新 TAM（检修 + 服务 + 海外远大于纯设备）、切入早（已布局）、认证门槛高（轨交资质）。未过验证点（海外订单规模化 / 服务占比跳升）仅作中期期权。
  • 层3 风险折扣（证伪信号）：检修持续低迷（修程改革深化）、应收账款坏账（4.95 亿）、新造继续下滑、海外交付延期。

第四步进阶：重资产 / 周期股估值校正

  • 校正1 资产质量折扣（破净原因）：不适用——PB 1.63x 未破净；但应收账款 4.95 亿（占总资产近四成）为潜在减值隐忧，需打折看待净资产质量。
  • 校正2 周期位置校正：轨交装备非强周期，需求由铁路投资（稳）与存量车队（扩）驱动；当前处检修改革阵痛期，中性净利已按改革后新平衡测算，未过度乐观。
  • 校正3 杠杆下行情景：资产负债率不高，但应收账款集中（前五大客户占比高），若主机厂回款延迟则现金流 / 减值下行——已在悲观情景体现。

交叉校验：现价 23.14 元对应 TTM PE 74x、中性远期 18.30 元（−20.9%）——现价已透支检修恢复与海外预期；仅乐观情景（+25%）勉强覆盖。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价高于中性远期 21%，PE(TTM) 74x，检修结构性承压未充分反映。

安全边际：中性远期 −20.9%；乐观 +24.9%（需检修恢复 + 海外放量）；悲观 −56%。账面支撑：PB 1.63x、净资产 11.16 亿，但应收账款隐忧削弱安全边际。

介入条件：① 回落至 18 元以下（对应 2029 中性 PE 32x 打折）具安全边际；② 检修业务恢复信号（单季检修交付回升至 40 列+）；③ 海外大额订单公告 + 服务占比跳升（上调至纳入观察）。

最大风险：① 修程修制改革深化致检修长期低迷（结构性首要风险）；② 应收账款 4.95 亿坏账；③ 新造车辆电气继续下滑；④ 海外交付延期 / 汇率。

结论：暂不介入（估值偏高、检修结构性承压，待检修恢复与海外订单验证）。

第五步进阶：上行想象力四类情景

  • A 行业出清剩者红利：轨交电气细分集中度高，公司小巨人剩者，存量车队扩大后市场份额稳固。验证点：检修交付回升、份额跳升；证伪：份额连降。
  • B 政策反转期权：修程修制改革若优化 / 后市场扩容，叠加铁路投资 8500 亿、十五五 200 组/年动车组需求。验证点：改革细则调整、动车组招标放量；重估弹性：乐观 28.9 元（+25%）。未过验证点仅作机会情景。
  • C 市场错杀修复：轨交 / 基建板块风格切换错杀。验证点：板块企稳、基本面未恶化、PB 贴近 1.3x。
  • D 技术突破 / 代际跃迁期权：AI Agent 私有化 + 数字化管控 + 智能运维从 0 到 1，转型全生命周期服务商。三要素：政策（交通强国）+ 趋势（智能运维渗透）+ 落地（海外订单 + 服务占比跳升 + 成本优于旧模式）。硬验证点缺一则只作机会情景。触发上调重点关注条件：海外订单规模化且服务收入占比跳升。
