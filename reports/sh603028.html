第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）——议价权量化
- 2026H1 钢索：原料（盘条/锌）因地缘冲突上行 + 下游电梯厂压价 → 售价同比回落 + 成本同比上升，双杀 → 毛利率 −3.92pct
- 传导率测算：设原料成本占钢索营业成本约 70%。若原料涨 8%、售价降 3%，理论毛利率冲击 = 70% × 11% ≈ 7.7pct；实际降 3.92pct → 实际传导率 ≈ 0.49（约一半压力被公司自扛，一半通过产品结构/长协对冲消化）
- 光伏：售价跌幅 > 成本跌幅 → 传导率为负（−0.3 左右），即成本还能降但售价降更快，这是毛利倒挂的根源
- 验证点：季度毛利率、公司调价公告、长协比例披露
- 证伪信号：毛利率跌破 0 或钢索毛利率跌破 10%

因子2 毛利结构再平衡（分业务线，禁单一综合毛利率）

因子3 库存与采购节奏（timing）
- 存货 2026H1 2.34 亿，较上年末 +39.09%（公司称"开展业务合理备货"），占净资产 53.19%，存货跌价准备计提比例仅 2.9%
- 风险：在硅片/电池片价格持续下跌周期中高价接货 → 公司已在风险披露中新增"跌价则可能引发库存减值"表述，与存货 +39.09% 形成呼应
- 长协/套保：公司称采用"长协锁定与供应链管控"，但未披露对冲比例
- 验证点：中报/年报存货跌价准备计提金额、存货周转天数
- 证伪信号：单季计提存货跌价准备 > 2000 万元 → 说明高价库存实锤

因子4 政策/市场锚点（原料成本驱动变量）
- 硅料/硅片价格：受《光伏行业成本核算模型通则》+ 市场监管总局价格合规指导影响，若价格回到参考成本以上 → 电池片毛利转正
- 钢铁/盘条：受铁矿石、焦炭、地缘冲突（公司明确提及）影响；能耗双控对高耗能线材有成本抬升作用
- 出口管制/关税：海外收入占 33.58%（马来西亚/中东/俄罗斯/东南亚），若目标市场加征反倾销税 → 出口受阻
- 情景：悲观（硅片价格维持低位 + 盘条涨 5%）→ 综合毛利率 7.5%；中性（电池片价格回到成本线上 + 盘条平稳）→ 11.0%；乐观（反内卷执法落地、电池片毛利回到 10% + 盘条回落）→ 15.0%
- 验证点：CPIA 周度价格指数、市场监管总局执法案例公告、盘条（线材）期货/现货价

本因子输出：2029E 中性综合毛利率 11.0%，喂给第四步。

③ 产能爬坡后理论净利率 毛利率 11.0% − 期间费用率 8.5% = 2.5% 见下

中性正常化净利率：取三者保守值 → 3.5%
（依据：毛利率 11.0%〔第二步进阶输出〕− 销售 1.2% − 管理 4.5% − 研发 3.0% − 财务 2.8% ≈ −0.5%；但考虑规模效应与财务费用随债务结构改善下降，取 3.5% 需建立在"光伏毛利率修复至 6% + 钢索修复至 15.5%"的中性假设上）

盈亏平衡点测算（重要）：
- 期间费用刚性约 1.77 亿/年（管理 0.70 + 销售 0.17 + 研发 0.51 + 财务 0.39，按 2026H1 年化）
- 需要综合毛利 ≥ 1.77 亿才能盈亏平衡 → 在营收 15.5 亿下需综合毛利率 ≥ 11.4%
- → 结论：公司的盈亏平衡点 = 光伏毛利率回到约 +8%（钢索维持 15.5% 时：8.0×8% + 6.5×15.5% + 1.0×5% = 0.64+1.01+0.05 = 1.70 亿，接近但不达 1.77 亿；需光伏毛利率约 +9% 才真正打平）
- 🔴 这是极脆弱的平衡——光伏毛利率每差 1pct，净利变动 800 万元。

第四步进阶：重资产/周期股估值校正（三道闸）

校正1 资产质量折扣（PB 4.48x — 非破净，但须论证是否严重透支）
- 🔴 PB 4.48x 对应 ROE −7.13%（2026H1 年化 −14.3%）——这是典型的高估信号，不是安全边际。
- 净资产仅 4.396 亿，而市值 19.69 亿：市场为"光伏转型 + 具身机器人 + 深海经济"三个期权支付了 15.3 亿溢价。
- 资产质量三重折扣：①核心子公司安徽美达伦净资产 −2.274 亿（资不抵债）；②存货 2.34 亿占净资产 53.19%，跌价准备仅计提 2.9%（隐含负债）；③应收票据及应收账款虽较年末 −13.5%，但 2025 年报曾 +65.27%，回款质量存疑；④担保总额/净资产 129.76%（或有负债远超净资产）。
- 结论：PB 4.48x 是估值透支，不是低估。禁止单凭"小市值 + 转型"推导大空间。
- 验证点：净资产环比、存货跌价计提、担保余额；证伪：净资产连续 2 季下滑且无重组方案。

校正2 周期位置校正（中性净利用周期归一化）
- 双主业均处周期底部：光伏连续 11 个季度全行业亏损（26 家中仅 4 家盈利）；钢索受地产/电梯链下行拖累。
- 明令禁止：把 2026Q2 单季或 2025 年减亏 76% 当拐点年化。
- 周期归一化做法：用 2023 年（最近一个完整盈利年）净利率 1.98% 作为基准锚，叠加光伏出清后的修复溢价 → 中性 3.5% 已属偏乐观取值（是 2023 年的 1.77 倍）。
- 当前周期位置标注：底部（出清前夜），但公司自身可能在行业出清完成前先被出清。

校正3 杠杆下行情景（必须附）
- 资产负债率：总资产 24.73 亿 / 净资产 4.396 亿 → 归母口径资产负债率约 82.2%（含少数股东权益后约 82%）；极高杠杆
- 短期借款 5.43 亿 + 一年内到期 1.68 亿 = 7.11 亿，而流动比率仅 0.57、速动比率 0.44 → 流动资产不足以覆盖流动负债
- 利率/需求下行负面情景：若利率上行 100bp，年增利息约 700 万元；若光伏价格再跌 10%，光伏板块毛利减少 0.8 亿 → 净利从 +0.54 亿直接转为 −0.4 亿以下，空间转负
- 🔴 规则裁定：该负面情景使空间转负，不得标注"大空间 / 重点关注"，至多"纳入观察"且须注明高贝塔属性。本报告进一步下调至"暂不介入"（中性空间已为负）。

期权纪律：具身机器人（50 万订单）、BC/钙钛矿、绿建 BIPV、可能的资产重组 —— 全部未过验证点，一律不计入中性净利，仅在乐观情景中体现。

第五步：综合赔率判断（买不买？）

亏损股三问（必须回答）

① 为什么亏？
- 主因：光伏电池片毛利倒挂（−2.58%，较上年 −0.50% 恶化），行业产能过剩（1100GW 产能 vs 536GW 需求）+ 新增装机 −66% → 量价齐跌
- 次因：电梯用钢丝绳板块亏损（售价同比回落 + 原料成本因 geopolitics 上行，双杀，毛利率 −3.92pct）
- 三因：费用刚性增长（管理 +15.93%、财务 +31.14%），收入腰斩而费用不降
- 四因：改造期停产直接冲击当期收入
- 性质判定：行业周期底部 + 产能爬坡/改造期 + 财务费用拖累三者叠加，不是一次性减值

② 靠什么扭亏？触发时点在哪一年？
- 路径一（决定性）：光伏"反内卷"落地 → 电池片价格回到《成本核算模型通则》参考成本之上 → 光伏毛利率从 −2.58% 修复至 +8% 以上。触发时点：2027—2028 年（取决于执法力度与产能出清速度）
- 路径二：产线改造完成达产（TOPCon 26.6%+，单瓦成本已下降）→ 触发时点 2027 年
- 路径三：钢索板块结构优化（提升工程机械/海工/港口占比，降低电梯敞口）→ 已在执行
- 路径四：剥离/关停亏损的绿建 EPC（毛利率 −37%）与资不抵债的美达伦部分产线 → 尚未有公告
- 综合触发时点：2028 年（中性）。乐观 2027 年，悲观 2029 年后甚至不能扭亏。

③ 亏得起吗？（倒在黎明前是首要风险）
- 🔴 结论：勉强撑得住，但缓冲极薄，风险显著
- 正面：净资产 4.40 亿；2026H1 筹资活动现金流净额 +0.816 亿（同比 +2.8 亿），说明仍能获得融资；货币资金较上年末 +15.35%；无 ST 风险（净资产为正）
- 负面：经营现金流 −0.719 亿（由 +1.81 亿转负）；流动比率 0.57 / 速动 0.44；短期债务 7.11 亿；担保/净资产 129.76%；核心子公司已资不抵债
- 压力测试：按 2026H1 亏损速度（−0.32 亿/半年）计，净资产可支撑约 7 个半年（3.5 年）；但若光伏价格再跌 10%，年亏或达 1.0 亿以上 → 支撑期缩短至 2 年，且需持续再融资（流动比率 0.57 意味着每一笔短期借款的续作都是生存前提）

当前价格位置：显著高估。现价 6.86 元 = 中性正常化估值 5.65 元的 1.21 倍；PB 4.48x 对应负 ROE；PS(2025 营收 17.17 亿) 1.15x 高于困境制造业合理水平（0.6—0.9x）。

安全边际：为负。中性远期 5.65 元 → −17.6%；悲观 3.05 元 → −55.5%。

介入条件：
1. 现价不介入。等 PB 回落至 3.0x 以下（对应股价约 4.6—5.0 元）且出现以下任一信号再评估
2. 转正信号：① 光伏板块单季毛利率转正（>0）；② 单季经营活动现金流转正；③ 短期借款下降且流动比率回到 0.8 以上；④ 安徽美达伦净资产负值收窄
3. 重组/资产注入信号：若出现国资主导的资产重组或美达伦剥离公告，需重新建模（当前无任何正式公告，不得臆测）

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 流动性风险（首要）：流动比率 0.57、速动 0.44、短期债务 7.11 亿 vs 净资产 4.40 亿、担保/净资产 129.76% —— 任何一笔短期借款续作失败都可能触发连锁反应
2. 光伏出清时点晚于公司承受极限：行业连续 11 季度亏损，若 2028 年前价格未修复，公司可能在行业回暖前先被出清
3. 存货减值：存货 2.34 亿（占净资产 53.19%）在跌价周期中，跌价准备仅 2.9%，补提风险大
4. 安徽美达伦资不抵债扩大：−2.274 亿且仍在亏损（2026H1 −0.402 亿）
5. 跨界期权证伪：具身机器人 2025 年订单仅 50 万元、2026H1 零披露，市场若按"机器人概念"定价则存在巨大预期差

第五步进阶：上行想象力情景（对冲系统性保守偏置）

类型A 行业调整剩者红利（概率中，最重要）
- 逻辑：光伏行业连续 11 季度亏损，1100GW 产能 vs 536GW 需求。《成本核算模型通则》2026-07 实施 + 市场监管总局价格合规执法 → 低于成本销售被认定 → 低效产能加速出清 → 剩者份额与定价权跳升。
- 量化：若电池片行业产能出清 30%，公司 TOPCon 效率 26.6%+（行业中上）可存活，光伏毛利率从 −2.58% 回到 +10% → 8 亿收入贡献毛利 0.80 亿（较中性 +0.32 亿），净利增至约 1.0 亿
- 验证点：CPIA 月度电池片价格与行业参考成本对比、落后产能关停公告、电池片行业 CR5 提升
- 证伪信号：价格持续低于参考成本 2 个季度以上无执法案例；公司光伏毛利率连续 2 季为负

类型B 政策反转期权（概率中）
- 逻辑：超长期特别国债持续支持设备更新、新能源基建、深海开发——公司钢索板块的工程机械、海洋工程（CCS 船用认证）、港口业务直接受益
- 量化：若海工/港口订单放量，钢索收入从 6.5 亿升至 7.5 亿，毛利率 16% → 增量净利约 0.16 亿
- 验证点：深海经济/深海开发专项政策发文、公司重大合同公告、海工板块季度收入
- 证伪信号：特别国债投向不含深海/海工；公司无新增重大合同

类型C 市场错杀修复（概率低）
- 无错杀证据：PB 4.48x、PS 1.15x 均处于公司历史偏高位置，且基本面在恶化（收入 −43.89%、现金流转负）。本类不成立——现价不是被错杀，而是被"转型概念"溢价支撑。
- 证伪/反向信号：若 PB 回落至 2.0x 以下且重组预期明确，届时才具备错杀修复条件

类型D 技术突破 / 技术代际跃迁期权（概率低，但弹性极大）
- 逻辑：①政策驱动：BC / 钙钛矿叠层属国家鼓励的下一代光伏技术；②行业趋势：TOPCon 效率已接近理论极限，BC 与钙钛矿叠层是行业收敛方向；③公司落地：TOPCon 量产效率 26.6%+、高端 27%、单瓦成本同比下降；BC、钙钛矿叠层处于研发储备
- 硬验证点检查（三缺一）：中试线跑通且良率达标 ❌（未披露）；客户定点/大额订单 ❌；量产成本曲线优于旧路线 ⚠️（单瓦成本下降已确认，但未与行业对标）
- 处置：🔴 只作机会情景，不计入中性锚
- 证伪信号：中试失败/良率长期不达标、研发费用下降、核心技术人员流失

什么条件出现才上调至"重点关注"：① 光伏板块单季毛利率转正并有连续 2 季验证；② 经营活动现金流由负转正且短期借款下降、流动比率回到 0.8+；③ 具身机器人/深海索具拿到正式公告的大额订单。三者同时满足，中性净利可上修至 1.0 亿以上，PB 可给到 5x（对应 20 亿+净资产路径），远期空间将超过 +50%。当前一条都未满足。

结论：暂不介入

理由：① 中性远期空间 −17.6%（为负），不满足任何看涨门槛；② PB 4.48x 对应负 ROE，估值透支而非低估；③ 流动比率 0.57 + 速动 0.44 + 短期债务 7.11 亿 + 担保/净资产 129.76%，流动性风险是当前最大的现实威胁；④ 扭亏触发时点在 2028 年，且高度依赖外部行业出清节奏，公司自身无法控制。
不是"坚决回避"的理由：公司主业真实（钢索有 70 年积淀 + 头部客户配套）、净资产为正、仍能获得融资（2026H1 筹资净流入 0.816 亿）、行业底部反转逻辑清晰，存在扭亏路径，故不判回避。
核心跟踪点：光伏板块季度毛利率是否转正 + 经营活动现金流 + 短期借款与流动比率。
