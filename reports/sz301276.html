嘉曼服饰（301276）五步法分析报告

分析日期：2026-09-20 ｜ 现价 17.08 元（腾讯实测，2026-09-18 收盘）｜ 总市值 22.14 亿 ｜ PE(TTM) 21.36x ｜ PB 1.04x ｜ 总股本 1.296 亿股（129,600,000 股）
行业：中高端品牌服饰（童装 + 男女装 + 鞋履）｜ 板块：创业板 ｜ 是否真亏：否（2026H1 归母 +6217 万，盈利；归母微降主因非经常性扰动，扣非 +19.10%）
方法声明：业绩预测采用自下而上（多品牌矩阵 × 全渠道 × 品类结构），严禁用历史增速外推。

第一步：公司是干什么的？

一句话定位：中高端品牌服饰运营商，以"自有 + 授权 + 代理"多品牌矩阵，覆盖童装、男女装及鞋履的研发设计、品牌运营与全渠道销售。

核心产品/品类：外套（38.43%）、上衣（36.19%）、裤子（15.51%）、裙子、家居服、鞋履。

主要品牌：自有品牌水孩儿；授权品牌暇步士（Hush Puppies）、哈吉斯（HAZZYS）；国际零售代理 EMPORIO ARMANI、HUGO BOSS 等。授权 + 代理品牌贡献高毛利（男女装毛利率 72.54%）。

渠道结构（2026H1）：电商 57.46%（3.21 亿，+20.67%）、直营 1.83 亿（毛利率 73.55%，提升）、加盟。线上线下 + 直营加盟并行。

境内外收入：国内为主（华北 18.94%、华东 9.69%、电商全国）。

股东背景：民营控股；2022 年上市。资产负债率仅 15.04%（低杠杆），财务结构稳健。

（3）产业链传导

上游（"原料"）：面料（棉/化纤/羽绒）、辅料、成衣加工费。棉花等原料占成本比例中等，公司以外包生产 + 品牌运营为主（轻资产）。

下游：终端消费者（C 端），线上线下全渠道。品牌溢价决定定价权。

议价权：中强（品牌端）/ 中（供应链端）。证据：① 综合毛利率 66% 高位，品牌溢价显著，对消费者转嫁系数高；② 但外包生产模式下对代工厂议价中等；③ 授权品牌（暇步士/哈吉斯）续约风险是隐忧。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（转嫁系数）：品牌服饰对终端消费者转嫁系数 ≈ 0.8（品牌溢价 + 调价能力），原料（棉/羽绒）涨价可部分转嫁；但促销季（电商大促）会主动让利，实际转嫁波动。授权品牌定价权更强（毛利率 72.54%）。
  • 因子2 毛利结构再平衡：童装 63.74%、男女装 72.54%、直营 73.55%。结构迁移方向：高毛利的男女装（第二曲线，+43.58%）与直营占比提升，拉动综合毛利。单一综合毛利率 66% 掩盖了"童装承压、男女装高增"的结构分化。
  • 因子3 库存与采购节奏（timing）：服饰存货风险高（季换 + 时尚淘汰），公司存货余额同比减少约 8048 万（周转优化），但 H1 电商促销多致电商毛利率回落，含"促销让利"timing 因素，须区分真实盈利能力与促销扰动。
  • 因子4 政策/市场锚点（原料成本驱动变量）：① 棉价/羽绒价（市场层）：波动影响成本；② 关税（政策层）：进口面料/代理品牌成本；③ 生育政策（政策层）：影响童装需求总量。验证点：棉价、童装营收增速、电商毛利率。证伪信号：童装营收连续下滑、授权品牌续约失败、存货跌价扩大。

增量逻辑（自下而上）：远期增量不靠行业增速外推，而靠"童装守成 + 男女装第二曲线放量 + 电商/直营占比提升 + 鞋履扩品类"。2026H1 营收 5.58 亿，全年 ~11.5 亿；2029 中性假设男女装 CAGR ~20%、童装微增、电商占比 65% → 营收 ~14.5 亿。

第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：中高端童装/服饰分散，水孩儿区域品牌；授权品牌依托国际 IP。
  • 客户份额：会员/复购（童装/视光式粘性强）。
  • 技术代际差：设计 + 品牌运营能力，非技术驱动。
  • 成本曲线：轻资产外包，规模 + 渠道效率。
  • 份额加速度：男女装 +43.58% 显示份额提升。
    → 中性：男女装份额提升、童装守成。验证点：男女装营收、电商占比、同店产出。
  • 层2 扩展业务：主业迁移空间——由童装向男女装 + 鞋履全品类迁移（新易盛范式），能力可迁移（品牌运营同源），新 TAM 弹性 2–3 倍，已初步验证（男女装 +43.58%）。但鞋履/新品牌未完全跑通，中期期权，谨慎计入中性（仅确认部分计入）。
  • 层3 证伪信号：童装营收加速下滑、授权品牌（暇步士/哈吉斯）续约失败、电商毛利率持续破 60%、存货跌价扩大。

第四步：估值锚定（自下而上，非增速外推）

方法说明：不按历史增速外推。按"童装守成 + 男女装放量 + 渠道结构"测算营收，按品类毛利率 − 费用率测算净利。总股本 1.296 亿股。

核心假设：2029 中性营收 14.5 亿（童装 ~8 亿微增、男女装 ~4.5 亿 CAGR20%、鞋履/其他 ~2 亿）；综合净利率中性 10%（高毛利结构 + 费用控制）；2026E 营收 ~11.5 亿、归母 ~1.15 亿（扣非为主）。

第四步进阶·重资产/周期股估值校正

  • 校正1 资产质量折扣（PB 1.04 接近破净须说明）：PB 1.04 贴近 1，但非破净、非资产质量恶化——系低增长成熟品牌的市场折价（轻资产、高毛利、低负债）。净资产含金量高（现金 + 存货 + 品牌商誉），不构成"伪空间"，可保留估值，但须注明增长预期低。
  • 校正2 周期位置校正：服饰非强周期，但受居民消费周期影响。当前处消费温和期，中性净利率 10% 已计入谨慎，非景气顶部外推。
  • 校正3 杠杆下行情景：资产负债率仅 15.04%，无高杠杆下行风险；悲观情景净利仍正（1.04 亿），空间转负仅因市值 14.6 亿对应 11.2 元（−34.4%），不构成大下行。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏贵（按基准）/ 合理（按远期）。现价 17.08 高于基准中值 14.5 元，但低于远期中性 20.1 元。

安全边际：
- 中性远期 20.1 元 → 空间 +17.6%，未达"重点关注 >50%"门槛
- 悲观 11.2 元 → 下行 −34.4%（童装 + 授权续约风险）
- 乐观 28.8 元 → +68.6%，需双曲线 + 授权续约

介入条件：
1. 性价比区间：回落至 14 元以下（2026E PE < 15x、接近基准下沿）安全边际充足
2. 加仓信号：① 男女装营收增速维持 30%+；② 电商占比突破 65% 且毛利率稳；③ 授权品牌（暇步士/哈吉斯）续约落地；④ 经营现金流回正（H1 −4887 万须改善）
3. 观察指标：童装营收、男女装增速、电商毛利率、存货、诉讼冻结资金进展

最大风险：① 新生儿下降长期压制童装（70% 营收基本盘）；② 授权品牌续约失败（高毛利男女装来源）；③ 经营现金流承压（补助减少 + 诉讼保全）；④ 电商促销致毛利率回落、存货跌价。

结论：暂不介入（优质低负债高毛利品牌，但远期空间仅 +18%、童装人口天花板 + 授权续约风险，性价比不足；回落至 14 元以下或男女装加速再评估）

上调至"重点关注"的条件：男女装营收增速稳定 30%+ 且鞋履新曲线跑通、授权品牌续约确认、经营现金流转正，则 2029 净利可上修至 1.7 亿+，目标价 25 元+，空间破 50%。

第五步进阶·上行想象力情景（四类）

  • 类型A 行业调整剩者红利：童装/服饰出清，中小品牌退出，头部（授权 + 自有矩阵）份额提升。验证点：行业集中度、公司份额。重估弹性：净利率 10%→12%。
  • 类型B 政策反转期权：生育支持政策加码（补贴/个税减免）提振童装需求；促消费政策拉动。验证点：生育补贴落地、社零回暖。未过验证点仅作机会情景。
  • 类型C 市场错杀修复：当前 PE 21x 在低增长品牌中合理，但因现金流/诉讼被压制；若现金流回正 + 童装企稳，估值修复。验证点：现金流、童装营收止跌。
  • 类型D 技术突破/模式跃迁期权：全渠道数字化 + 私域运营 + 新授权品牌矩阵扩张，从"童装单核"跃迁为"全品类品牌运营平台"。硬验证点：线上占比破 65% + 新授权品牌落地 + 鞋履放量（部分满足，平台化未完全验证），暂作机会情景。
