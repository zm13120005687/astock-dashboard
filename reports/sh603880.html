第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1：成本传导弹性（pass-through 系数）
- 观察：2026H1 收入 −11.51%，毛利率 10.35%（同比 +0.08pct，几乎持平）；2026Q2 单季毛利率 12.04%（环比 +2.95pct，同比 −0.37pct）。
- 结论：公司在收入大幅萎缩的情况下仍守住了毛利率，说明其 ODM 报价含有一定的成本联动条款；但毛利率仅 10% 出头，意味着传导后的"加工费"薄如刀片。
- 传导率测算：ODM 模式 + 品牌商强势 + 公司订单在流失（议价地位进一步恶化），传导率估计 0.6–0.7（高于永悦这类纯现货化工，因存在年度框架价）；但传导后留存给公司的绝对加工利润极低。
- 实际毛利承压 = 上游变动 ×（1 − 0.65）= 35% × 0.35 ≈ 12.25pct 需自行消化——但公司毛利率仅 10.35%，任何一轮 10% 以上的原料上涨且传导失败，都会直接击穿毛利线。

毛利结构迁移的核心事实：公司"综合毛利率 10.35%"这一数字严重掩盖了结构撕裂——传统敷料线（约 62% 收入）贡献全部毛利，而防护用品线（31% 收入）净亏 1897 万元，相当于把传统线的毛利全部吃掉后还倒欠。
原料敏感权重：丁腈胶乳一条线即占公司总成本的约 25–30%（31.4% 收入 × 60%+ 料占比 × 成本收入比），因此丁腈胶乳涨价 10% → 防护用品线毛利率下降约 6pct → 公司整体净利下降约 1500 万元/年（若完全无法传导）。这与安徽南卫半年亏 1897 万的实际量级吻合。
结构性结论：剥离/重组安徽南卫，是公司毛利结构回归健康的唯一路径。

因子 3：库存与采购节奏（timing）
- 存货 1.23 亿元，占净资产 77.18%，较上年末减少 1578.38 万；存货跌价准备 1431.02 万，计提比例 10.42%。
- 存货周转率 1.85 次（H1），年化约 3.7 次 → 周转天数约 98 天，对 ODM 代工业偏慢，存在成品积压。
- 高价接货损失：安徽南卫在丁腈手套价格下行周期投产，前期为配套产线投入形成的较高固定分摊成本是半年报明确点名的亏损原因 → 不是库存收益问题，是产能错配问题。
- 未披露任何套保/长协 → 原料波动 100% 暴露。
- 结论：存货跌价准备 1431 万已部分反映积压损失，但安徽南卫的产能错配损失无法通过库存管理解决，只能通过剥离或行业出清解决。

层 1 结论（严酷）：五个锚点中，④、⑤ 明确为负，①、② 无正向证据，③ 无差异。份额变量对公司的方向是"负贡献"，这与"市场变大 + 份额变高"的双正向假设完全相反。 因此本报告不给予任何份额扩张带来的增量，中性情景只假设"份额止跌、收入企稳"。

层 2：扩展业务 = 主业迁移空间
- 能力可迁移性：公司在涂胶、分切、复合、灭菌等工艺上有积累，理论上可迁移至医用贴剂、功能性敷料、运动防护等相邻品类——但这些都是低值、低壁垒、同样内卷的品类，TAM 弹性小。
- 新 TAM 弹性：未发现公司有任何高端化（如高端功能性敷料、生物材料、IVD）布局。
- 切入卡位：研发费用同比 −17.56%，在收缩而非投入，无卡位动作。
- 客户认证门槛：低值敷料认证门槛低 → 既是护城河低，也意味着迁移阻力小但无壁垒。
- 信号验证：未过任何验证点——无新客户公告、无新品类收入占比跳升、无产能投向转移（研发反而在降）。
- 结论：主业迁移空间评估为"不成立"，不计入中性，也不计入乐观（与永悦的碳纤维期权不同，本股连"试水"动作都没有）。

层 3：风险折扣（证伪信号）
- 安徽南卫 12 个月内无剥离/停产公告 → 中性情景下修至悲观；
- 短期借款 3.42 亿出现续贷失败或银行授信收紧 → 立即触发流动性危机；
- 归母净资产跌破 1 亿元 → 接近资不抵债，退市风险警示概率大幅上升；
- 股价跌破质押预警线 6.26 元 / 平仓线 5.48 元 → 强平负反馈；
- 参股公司投资收益转负 → 亏损进一步扩大。

第四步：估值锚定（自下而上，非增速外推）

方法说明：公司连续亏损且净资产极低（1.594 亿），PE 与 PB 均已失去锚定意义（PE 为负、PB 17.62x）。采用 RULES.md 规定的正常化净利润法（Normalized Earnings）：估稳态营收 → 算保守正常化净利率 → 正常化净利润 × 远期合理 PE → 目标市值 → 目标价；并与"破产清算 / 重整价值"做双向校验。全程不使用历史增速外推。

总股本：2.8904 亿股（2026H1 归母净资产 1.594 亿元，每股净资产 0.551 元，PB 17.62x）

亏损股三问

① 为什么亏？
1. 安徽南卫（丁腈手套）产能错配 —— 最大单一出血点：子公司净资产 −2.96 亿元（资不抵债），2026H1 亏损 1897 万元。业绩预告原文点名："全资子公司安徽南卫医疗用品有限公司丁腈手套业务受行业市场环境影响，产能未能充分释放，加之前期产线配套投入形成较高固定分摊成本"。即在手套价格下行周期投产，固定成本刚性 + 产能闲置。
2. 出口订单萎缩：业绩预告点名"受国际贸易政策、地缘局势及跨境物流综合成本上行等因素影响，公司部分出口订单同比缩减"。境外收入 H1 5603 万（−10%）。
3. 三大主力品类全面下滑：创可贴 −7%、胶布胶带及绷带 −20%、防护用品 −15%、敷贴 −22%——无一条线幸免，属系统性萎缩而非个别客户流失。
4. ODM 模式毛利率极低（10.35%）：附加值有限，原料与人工成本无法有效转嫁；规模效应消失后单位固定成本上升。
5. 财务费用刚性吞噬：利息支出 1055 万/半年、财务费用 1239 万/半年（+10.32%），利息/营收从 3.7% 升至 4.6%。
6. 管理费用刚性：收入 −11.51% 而管理费用 +1.28%，折旧摊销 979 万占管理费用 43.5%。

② 靠什么扭亏？触发时点在哪一年？
- 路径 A（决定性）：止血安徽南卫。剥离/关停/减产，年化减亏约 3800 万元（H1 1897 万 × 2）。时点：取决于管理层决心，最快 2027 年；但截至 2026-09 无任何正式公告。
- 路径 B：债务重组降息。有息债务 4.33 亿，若通过债务重组/引入战投降至 2.5 亿、利率降至 3.5%，年省利息约 600–800 万元。时点：不确定，无公告。
- 路径 C：行业出清后手套价格修复。丁腈手套全球产能过剩，中小产能退出需 1–3 年。时点：2027–2029，且公司未必活到那天。
- 路径 D：参股公司投资收益（+477 万/半年）。不可持续、不可控、持股仅 10%，按纪律剔除，不作为扭亏依据。
- 综合判断：扭亏的最早现实时点为 2028 年，且必须同时满足"安徽南卫止血 + 债务重组"两项前置条件。

③ 亏得起吗？
- 账上现金：广义货币资金 5795 万元；短期债务 3.73 亿元；广义货币资金/短期债务 = 0.16（安全线通常 ≥1.0）。
- 偿债指标：流动比率 0.45、速动比率 0.26（健康线分别 2.0 / 1.0）→ 短期偿债能力严重不足，完全依赖银行续贷滚动。
- 经营现金流：2026H1 +3012 万元（同比 −14.42%），为正且是唯一的正面信号；但年化约 6000 万，扣除资本开支与利息（年化约 2100 万利息）后可动用现金极少。
- 净资产侵蚀速度：归母净资产从 2025 年末 1.7719 亿降至 2026H1 末 1.594 亿，半年 −1779 万（−10.04%）。按此速率，静态约 4.5 年净资产归零；若安徽南卫继续亏（年化 3800 万）而传统线仅微利，侵蚀速度将加快至 2–3 年。
- 或有负债：原控股股东李平 4710 万元罚没款尚未缴纳（历史遗留问题）。
- 结论：短期（12 个月）靠续贷可维持，中期（2–3 年）"亏不起"——公司必须在 2027–2028 年前完成止血 + 重组，否则将触及净资产为负 / 审计非标 / 退市风险警示的实质门槛。

正常化净利润法测算

第 1 步：估稳态营收
- 2026H1 营收 2.7085 亿 → 年化约 5.42 亿。
- 假设安徽南卫剥离后：防护用品线（H1 8509.93 万，年化 1.70 亿）减少约 60%（保留部分外包/贸易），即减 1.02 亿；
- 传统敷料线（创可贴 + 胶布胶带绷带 + 敷贴 + 急救包 + 贴膏剂，H1 1.8576 亿，年化 3.72 亿）假设止跌企稳并微增 5% → 3.90 亿；
- 中性稳态营收 = 3.90 + 0.68 = 约 4.58 亿元（取整 4.60 亿）。
- 悲观：传统线继续 −5%/年 → 稳态 3.90 亿；乐观：止血 + 出口恢复 → 5.60 亿。

第 2 步：算正常化净利率（三者取保守）
- 行业正常净利率：低值医用敷料 ODM 行业正常净利率约 5–8%；但公司毛利率仅 10.35%、同业排名 139 位 → 行业平均不适用。
- 公司历史最好水平：疫情防护用品高峰（2020–2021）曾高盈利，但属极端异常年份，不得作为正常化基准。
- 产能爬坡后理论值：剥离安徽南卫后，固定资产折旧压力下降（折旧摊销 979 万/半年中大部分来自安徽南卫），假设稳态毛利率回升至 14%、期间费用率降至 12%（管理费用随收入企稳摊薄 + 财务费用因债务降至 2.5 亿而减半）→ 营业利润率约 2%，税后净利率约 1.5%。
- 三者取保守 → 正常化净利率 = 1.5%（悲观 0.5% / 中性 1.5% / 乐观 4.0%）。

关键说明：1.5% 的正常化净利率意味着公司即便"成功扭亏"，稳态净利也只有约 690 万元/年——这个量级的盈利能力，按任何合理 PE 都无法支撑 28.09 亿市值。 这是本股估值结论的核心来源。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1：资产质量折扣（本股为超高 PB，需反向压力测试；同时评估隐含负债）
- 本股 PB 17.62x，且净资产仅 1.594 亿。若按制造业 1.0–1.5x PB 定价，合理市值 1.6–2.4 亿元（0.55–0.83 元）。
- 资产专用性折扣：安徽南卫的丁腈手套产线属高度专用资产，行业产能过剩下清算价值远低于账面（净资产已 −2.96 亿即为明证）→ 重置成本完全不兜底。
- 隐含负债（净资产虚高）：① 存货 1.23 亿已提跌价 1431 万（10.42%），若手套进一步跌价需补提；② 原控股股东 4710 万罚没款未缴的或有风险；③ 应收账款与票据（H1 减少 20.22%）仍有账龄延长风险。扣除上述隐含损失后，有效净资产可能低于 1.0 亿元。
- 反向证明（是否为"金融资产未重估型"真安全边际）：参股公司江苏省医药 10% 股权，权益法贡献 H1 +477 万，倒算其年化净利约 9540 万，10% 股权按 10x PE 估值约 0.95 亿元——远不足以解释 28.09 亿市值，不构成真安全边际。
- 结论：禁止单凭任何指标推导"空间大"；本股的高 PB 是分母（净资产）被亏损侵蚀出来的，不是分子（价值）被低估。

校正 2：周期位置校正（中性净利用周期归一化）
- 丁腈手套是典型强周期品：2020–2021 疫情超级景气 → 2022–2026 深度过剩。当前周期位置：底部区域但尚未出清。
- 按纪律，禁止用 2020–2021 好年景的净利率（会得出荒谬的高估值），也禁止用"拐点年化"（公司 Q2 单季毛利率环比 +2.95pct 只是季节性/结构波动，不能年化为稳态）。
- 采用周期归一化：以"剥离安徽南卫后、手套业务不再拖累"为中性假设，等价于公司退出手套周期，稳态净利率取 1.5%（传统敷料的周期中值）。已明确标注当前周期位置为底部。
- 底部位置的正确含义：不过度悲观（故中性仍给正净利而非负），但也不给"周期反转"溢价（手套价格修复只进乐观情景）。

校正 3：杠杆下行情景（高负债必附负面情景 —— 本股为全组最严重）
- 起始状态：资产负债率 81.31%、有息债务 4.33 亿、短期借款 3.42 亿（占 79%）、货币资金 5795 万、流动比率 0.45、速动比率 0.26。
- 负面情景 A（利率/授信上行）：若银行收紧授信、短期借款利率上浮 200bp，年增利息约 680 万元 → 直接吃掉中性情景下 690 万正常化净利的 99%，净利归零并转负。
- 负面情景 B（需求下行 + 续贷失败）：若续贷失败需一次性偿付 3.42 亿，而货币资金仅 5795 万 → 立即触发债务违约 → 账户冻结 → 供应商断供 → 停产 → 审计非标 → 退市风险警示。这是本股最可能破坏逻辑的单一事件。
- 负面情景 C（质押强平负反馈）：股价跌破预警线 6.26 元（距现价 −35.6%）或平仓线 5.48 元（−43.6%），核心股东质押占其持股 54.28% → 强平 → 股价进一步下跌 → 控制权变更。
- 结论：该负面情景使空间大幅转负 → 按纪律不得标"大空间 / 重点关注"；结合经营杠杆（折旧摊销刚性）+ 财务杠杆（4.33 亿有息）双高，本股属高贝塔负凸性标的。

期权纪律：安徽南卫剥离（无公告）、债务重组（无公告）、战投引入/资产注入（无公告）、手套价格反转（未过验证点）——全部不计入中性净利。中性市值 11.5 亿中的 9.8 亿"壳/重整期权"已单独列示并标注未过验证点。

第五步：综合赔率判断（买不买？）

当前价格位置：极度脱离基本面。现价 9.72 元、市值 28.09 亿；主业正常化价值仅约 1.7 亿，占市值 6%；剩余 94% 是对"壳 + 重整"的定价。PB 17.62x、ROE −10.57%、ROIC −1.29%、流动比率 0.45——这是一张"赌重组"的票，不是一桩"买生意"的投资。

安全边际
- 中性远期 3.98 元 → 空间 −59.1%，无任何安全边际；
- 悲观 2.20 元 → 下行 −77.4%；
- 乐观 11.00 元 → 上行 +13.2%（且需四项条件同时兑现）；
- 赔率结构：下行 77% vs 上行 13%，极端负赔率。

介入条件
1. 不介入当前价格。任何基于"小市值 + 低价 + 亏损反转"的博弈逻辑，在本股的杠杆结构下都是负凸性下注；
2. 重新评估的三个硬信号：① 安徽南卫正式剥离/关停公告（减亏 3800 万/年）；② 债务重组方案落地（有息债务降至 2.5 亿以下或引入战投）；③ 股价跌至 3.0 元以下（市值 ≤8.7 亿，接近净壳重置价值）；
3. 明确排除条件：若出现短期借款续贷失败、审计非标、退市风险警示中的任一情形，从"暂不介入"直接转"坚决回避"。

最大风险（最可能破坏逻辑的因素）
1. ⚠️ 流动性断裂（首要，概率最高的致命风险）：短期借款 3.42 亿 + 一年内到期非流动负债，货币资金仅 5795 万，覆盖比 0.16，流动比率 0.45。完全依赖银行续贷维持运转，任何一次授信收紧即为终局性事件。
2. ⚠️ 安徽南卫持续失血无解：净资产 −2.96 亿、半年亏 1897 万、产能无法释放、行业无强制去产能政策。若无剥离动作，将逐年吞噬母公司净资产。
3. 质押强平负反馈：核心股东质押占其持股 54.28%，预警线 6.26 元（距现价仅 −35.6%）。
4. 治理风险：原控股股东李平 4710 万罚没款未缴；三大股东质押比例分别为 74.39%/100%/61.82% → 高质押低控股结构，掏空风险需警惕。
5. 出口与内需双杀：国际贸易政策 + 地缘 + 跨境物流成本上行（出口 −10%）叠加国内低值耗材集采压价（境内 −12%）。

第五步进阶：上行想象力情景（与下行校正对称）

类型 A：行业调整剩者红利
- 逻辑：丁腈手套行业若完成市场化出清（中小产能退出 20%+），价格中枢修复，剩者份额与定价权同步提升。
- 本股适用性受限：公司子公司安徽南卫净资产 −2.96 亿、产能利用率低，处于"被出清方"而非"剩者"。要享受剩者红利，前提是"活到出清完成那天"，而流动性状况（覆盖比 0.16）使这一点高度存疑。
- 弹性测算：若手套价格修复 30% 且安徽南卫产能利用率达 80%，该线可从半年亏 1897 万转为半年盈约 500 万，年化改善约 4800 万元。
- 验证点：丁腈手套出口均价（海关月度）连续两个季度上行；安徽南卫产能利用率披露 ≥70%。
- 证伪信号：手套价格继续下行；安徽南卫产能利用率未见改善且无剥离动作。

类型 B：政策反转期权
- 逻辑：若中美关税缓和/出口退税上调/低值耗材集采纠偏，公司出口与内销同步受益。
- 本股特殊性：这是本股最现实的上行期权——业绩预告明确将亏损首因归为"国际贸易政策、地缘局势及跨境物流成本"。若关税下调，境外收入（H1 5603 万）的价格竞争力恢复。
- 弹性测算：若关税下调 10pct 且订单恢复至 2024 年水平，境外收入可回升约 1500–2500 万，按 12% 毛利率约 +180–300 万元毛利。
- 验证点：中美关税实质性调整公告；公司季度境外收入同比转正。
- 证伪信号：关税进一步加码；境外收入连续 4 个季度同比下滑。
- 纪律：未过验证点，仅作机会情景，不计入中性锚。

类型 C：市场错杀修复
- 本股不适用：PB 17.62x、ROE −10.57%、同业排名 139/140，估值分位与基本面恶化方向一致，不存在错杀证据。按纪律不虚构该情景。

类型 D：技术突破 / 技术代际跃迁期权
- 本股不适用：低值医用敷料为成熟同质化品类，研发费用同比 −17.56%（在收缩），无任何新技术、新产线、新专利布局披露。硬验证点（中试良率 + 客户定点 + 成本优于旧路线）三要素全缺。
- 证伪信号：研发费用继续下滑；无新产品收入披露。

什么条件出现才把结论上调至"重点关注"？

必须同时满足：① 安徽南卫剥离/关停正式公告且交割完成；② 债务重组落地（有息债务降至 2.5 亿以下，或引入战投增资 ≥3 亿元）；③ 连续两个季度扣非归母转正；④ 股价 ≤3.0 元（市值 ≤8.7 亿）。四条同时满足才上调；仅凭"超跌反弹"或"重组传闻"不构成上调理由。

结论：暂不介入

理由：中性远期空间 −59.1%；赔率结构为"下行 77% vs 上行 13%"的极端负赔率；现价中 94% 是对未公告的壳/重整定价，而公司流动性（货币资金/短期债务 = 0.16）使其能否活到重组兑现高度存疑。
之所以不判"坚决回避"：公司经营现金流仍为正（H1 +3012 万）、拥有创可贴等真实产能与品牌渠道、参股公司持续贡献投资收益，且存在"剥离安徽南卫 + 债务重组"两条明确的止损路径——尚未满足"确无扭亏可能"的逐项举证要求（尤其"现金流枯竭"一项不成立）。
⚠️ 下调触发条件（明确的观察清单）：若 2026 年报出现 ① 短期借款续贷失败的蛛丝马迹（货币资金进一步下降 / 借款结构恶化）；② 审计意见非标；③ 归母净资产跌破 1 亿元；④ 安徽南卫在 2027 年中前仍无任何处置动作——满足任一即下调至"坚决回避"。
