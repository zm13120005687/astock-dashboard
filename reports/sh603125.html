第一步：公司是干什么的？

一句话定位：做"用量极小、作用极大"的高分子新材料特种单体与专用助剂——为离子交换树脂、绝缘材料、电子化学品、尼龙材料、光刻胶提供关键"卡脖子"原料，走的是"国际先进、国内空白"的进口替代路线。

（3）产业链传导

上游（原料成本）：纯苯、乙烯、丙烯、萘、碳九馏分等石化基础原料，价格锚定原油。2026H1 原油上涨带动原料成本上行，但公司毛利率不降反升 3.81pct——说明公司处于成本曲线左侧，具备顺周期提价能力。

下游（需求）：离子交换树脂（含核电/核废水处理）、电子化学品（光刻胶）、尼龙 66（己二腈国产化）、特种橡胶、绝缘材料、阻尼材料、环境友好材料。

议价权判断：中等偏强。佐证：①二乙烯苯国内市占率超 60%（近乎定价权）；②专用助剂产能利用率连续超 100%（卖方市场）；③2026H1 原料涨价周期中毛利率反而提升 3.81pct（传导率 >1）；④亚磷酸酯 PL-30 与齐翔腾达深度绑定（客户粘性）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）：
- 上游变动 ×（1 − 传导率）= 实际毛利承压。传导率估算 1.1–1.2（>1，即超额传导）。
- 依据：2026H1 原油与石化原料价格上行（化工产品价格指数上行），公司综合毛利率由 26.51% 升至 30.32%（+3.81pct），净利率 +5.32pct。若传导率 ≤1，毛利率应持平或下滑。
- 传导率 >1 的结构来源：①高市占率品种（二乙烯苯 60%+）具备定价权；②专用助剂产能利用率 >100%，属缺货状态；③高附加值新品（无酚亚磷酸酯、2-VN）占比提升，摊薄原料敏感度。
- 但需警惕：Q2 单季毛利率 28.83%，较 Q1（约 31.6%）环比 −2.7pct —— 传导能力在季度间存在波动，不是永久属性。

因子2 毛利结构再平衡（禁止单一综合毛利率掩盖结构迁移）：

产品族 估算毛利率 原料敏感品种 原料敏感权重 2026H1 边际变化
特种单体（DVB / AMS / 二异丙烯基苯） 32–36% 纯苯、乙烯、碳九 高（直接石油化工原料） 市占率稳固，价格随行就市，毛利扩张
专用助剂（亚磷酸酯系列，含 PL-30） 28–32% 亚磷酸、酚/醇 中 产能利用率 >100%，4 万吨/年己二腈配套已投产，量增为主

结构迁移结论：综合毛利率 30.32% 是"传统单体（高敏感）+ 助剂（中敏感）+ 电子级新品（低敏感）"的加权结果。真正决定远期估值的是电子级新品占比——它毛利率最高、原料敏感度最低，若能上量，综合毛利率可在原料上行周期中继续扩张。禁止用"30.32% 综合毛利率"线性外推未来。

因子3 库存与采购节奏（timing）：
- 公司采用"以销定产"模式，提前与下游（光刻胶厂商等）沟通需求，主动降低库存风险 → 库存收益/损失对当期毛利的扰动小于同行，2026H1 的毛利率改善更可能是真实议价能力而非库存收益。
- 这是本股区别于周期股的关键正面因素：无大规模低价囤货行为，当期毛利可比性较高。
- 验证点：季报存货余额与周转天数。若存货周转天数显著拉长且毛利率同步走高，则需警惕囤货收益。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务：市场容量 × 份额变量（5 锚点）
1. 供给侧份额：二乙烯苯国内市占率 >60%，属绝对龙头；但份额已高度饱和，向上空间有限（S 曲线顶部）。
2. 需求侧/客户份额：杜邦、朗盛等国际客户已导入（认证周期长 = 粘性强）；齐翔腾达深度绑定（己二腈国产化）。
3. 技术代际差："一步法烷基化 + 同分异构体择型"为独家工艺，纯度 >99.9%，在特种单体领域领先国内一代。
4. 成本曲线位置：左侧（产能利用率 >100% + 高市占率 + 顺周期提价能力），行业降价时能以价换量。
5. 份额二阶导数：传统品种（DVB/AMS）已饱和、份额二阶导为负；新品类（电子级单体、泰州含氧单体）处于加速渗透初期、二阶导为正。
→ 三档：保守（守住在售品种份额，仅靠行业自然增长）／中性（新品类爬坡 + 泰州一阶段投产）／乐观（承接日欧退出份额 + 2-VN 放量）。验证点：季度"营业收入同比 + 毛利率"组合（若收入增而毛利率降，说明是以价换量；若收入增且毛利率稳，说明是真实份额提升）。

层2 扩展业务：主业迁移空间（"旧池塘→新池塘"）
1. 能力可迁移性：强。公司核心能力 = 烷基化 / 择型分离 / 高纯提纯工艺。从"特种单体"迁移到"芳香族含氧单体（苯二酚、偏苯三酸酐）"属技术同源（依托已掌握的氧化工艺），迁移成本低。
2. 新 TAM 弹性：大。高端光刻胶单体此前全球仅日本企业可商业化，国产化率不足 10%；己二腈国产化带动尼龙 66 产业链扩容；含氧特种单体是高端工程塑料/电子材料的关键原料。
3. 切入卡位：早期。2-VN 为"A 股唯一布局"，尚无国内竞争对手。
4. 客户认证门槛：高（既是护城河也是阻力）。光刻胶厂商需通过稳定性与批次一致性测试，客户为彤程新材、南大光电、晶瑞电材等，认证周期通常 12–24 个月。
5. 信号验证：未过验证点——无客户定点公告、无 2-VN 收入单列披露、无大额订单公告。
→ 迁移空间仅作中期期权，不计入中性情景。 硬验证点 = ①2-VN 中试/量产良率达标公告；②拿到光刻胶厂商定点或大额订单；③量产成本曲线优于进口品。

层3 风险折扣（证伪信号）：①综合毛利率跌破 27%（传导失败或竞争加剧）；②连续两个季度营收环比下滑（Q2 已环比 −18.56%，需观察 Q3）；③2-VN 客户验证失败或良率长期不达标；④泰州项目因可转债未获批而延期；⑤行业新增产能集中投放致价格战重启。

第四步：估值锚定（自下而上，非增速外推）

第四步进阶：重资产 / 周期股估值校正三道闸

校正1 资产质量折扣（本股为 PB 3.55x 溢价，须论证贵得有没有道理）：
- 本股非破净，不存在"PB<1 伪空间"问题；但 PB 3.55x 需论证合理性。
- 支持溢价的证据：①ROE 2026H1 已达 5.56%（年化约 11%），2029E ROE 可达 4.30/30 = 14.3%，PB/ROE 匹配度尚可（3.55/14.3% ≈ 24.8x 隐含 PE，与 25x 相符）；②净资产 25.73 亿中无大规模商誉（商誉数据未披露，但公司以外延极少，内生建设为主）；③资产负债率仅 7.4%，资产无杠杆虚高。
- 不支持溢价的证据：泰州项目 28.55 亿投资将在 2027–2029 形成大额新增折旧，若爬坡不及预期，将显著拖累 ROE。
- 结论：PB 3.55x 基本合理但无安全垫，属"定价充分"而非"明显高估"。

校正2 周期位置校正（中性净利须周期归一化）：

当前价格位置：合理偏贵。现价 22.55 元对应 2026E PE 32.0x、2029E PE 21.2x、PB 3.55x（较行业指数溢价 37%）。基本面确实优秀（H1 净利翻倍、经营现金流转正、负债率 7.4%、产能爬坡明确），但价格已把这些好消息定得差不多了。

- 中性远期 26.55 元 → 空间 +17.7%（三年维度，年化约 5.6%）——不达"重点关注"的 >50% 门槛
- 悲观 13.34 元 → 下行 −40.8%

介入条件：
1. 不追高。现价距基准估值 23.23 元仅差 3%，无安全边际。

3. 加仓信号：①2-VN 或 TBS 拿到光刻胶厂商定点/大额订单公告（期权转确定性，可上调至"重点关注"）；②泰州项目可转债获证监会注册批复；③2026 年报确认全年净利 ≥3.0 亿且 Q4 毛利率环比回升。
4. 观察指标：季度营收环比（Q2 已环比 −18.56%，Q3 若继续环比下滑需下调中性）；综合毛利率能否守住 28% 以上。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ Q2 环比已回落（首要）：Q2 营收 3.1683 亿（环比 −18.56%）、归母 0.5861 亿（环比 −27.92%）、毛利率 28.83%（环比 −2.7pct）。Q1 的高增长含新品集中确认因素，不宜视为常态。若 Q3 继续环比下滑，中性情景需下修。

- 当前不存在错杀（PB 3.55x 高于行业中枢）。但若系统性调整导致股价回落至 18 元以下（PB < 2.9x、2026E PE < 26x），而基本面（产能爬坡、毛利率）未恶化，则构成错杀修复机会。
- 错杀证据（需届时验证）：估值分位回落至历史 30% 以下 + 季度毛利率仍 ≥28% + 营收同比仍正增长。修复触发点：化工板块景气确认 + 泰州项目进展公告。

类型D 技术突破 / 技术代际跃迁期权 —— 2-VN 光刻胶单体：
- 三要素共振检查：
- ①政策驱动技术路线：高端光刻胶国产化是国家战略，KrF/ArF 光刻胶国产化率不足 10%，属强制替代逻辑 ✅
- ②行业趋势向该技术收敛：AI 算力扩张带动电子氟化工、高纯电子化学品需求放量；中国光刻胶市场年增速超 15% ✅
- ③公司技术投产落地：⚠️ 部分达成——工艺已自主掌握（一步法烷基化 + 同分异构体择型，纯度 >99.9%），但中试/量产良率未公告、客户定点未公告、量产成本未验证
- 硬验证点（防画饼）：①中试线跑通且良率达标公告；②拿到客户定点或大额订单（彤程新材、南大光电、晶瑞电材等）；③量产成本曲线优于进口品。
- 三缺一（当前缺 ①②③）→ 只作机会情景，不计入中性锚。
- 弹性测算（若全部达成）：2-VN 规划 500 吨/年，若单价 300–500 万元/吨（高端电子级），满产收入 15–25 亿，净利率 40%+ → 净利 6–10 亿。这是乐观情景（2029E 6.00 亿）的主要来源。证伪信号：中试失败 / 良率长期不达标 / 客户流失 / 成本打不过进口品 / 光刻胶国产化政策退坡早于量产。

什么条件出现才把结论上调至"重点关注"：①2-VN 或 TBS 拿到客户定点/大额订单正式公告（期权转确定性，中性净利可上调至 5.5 亿以上，空间 >+50%）；或 ②股价回落至 18.5 元以下且 2026 年报确认净利 ≥3.0 亿。二者满足其一即可上调。
