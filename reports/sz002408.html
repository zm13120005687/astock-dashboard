（3）产业链传导

上游（原料成本）：正丁烷、混合 C4、原油。原料随国际能源价格大幅波动，公司是成本接受者为主（大宗定价）。下游：不饱和树脂（顺酐，自身亏损、对高价接受度有限）、涂料/胶黏剂（甲乙酮，需求稳健）、新能源（胶乳，高增长）。议价权：甲乙酮/顺酐为全球定价权重厂商，中等偏强（部分转嫁）；国际贸易板块靠渠道与长单。

第二步进阶·原料成本→毛利结构（四因子）
- 因子1 成本传导弹性（pass-through）：大宗 C4 品定价随行就市，向上游转嫁系数≈0.75（议价权来自全球第一份额，但下游不饱和树脂亏损限制高价接受度）。实际毛利承压 = 原料变动 ×(1−0.75)=原料变动×25% 由公司对冲。验证点：顺酐单吨价差公告、甲乙酮挂牌价。证伪：原油飙涨而产品提价失败→毛利破阈值。
- 因子2 毛利结构再平衡：分业务线——化工制造毛利率 7.38%（高弹性、波动大），国际贸易 3.36%（稳定低毛利）。正丁烷/原油上涨时，化工制造毛利塌、利润贡献向贸易倾斜，禁止用单一综合毛利率 5.71% 代表全结构。原料敏感权重：化工制造对正丁烷敏感度高，贸易对运费/汇率敏感。验证点：两板块各自毛利率逐季披露。
- 因子3 库存与采购节奏（timing）：2025 底行业去库存尾声，2026H1 低价原料库存收益 + 价差修复推高当期毛利（虚高成分）；正丁烷长协/套保对冲部分波动。须区分"当期 vs 远期"可比性，避免把库存收益当真实盈利。验证点：存货周转、采购均价。
- 因子4 政策/市场锚点：①市场层——原油价格中枢（正丁烷关联）、全球供需、运费；②政策层——能耗双控（抬升高耗能料成本）、出口管制/海外产能出清（供给缺口利好出口）、设备更新补贴（技改受益）、关税（出口成本）。情景：原油中枢上行→价差收窄（负面）；海外出清延续→出口溢价（正面）。验证点：原油价格、出口量、设备更新招标。

第三步进阶·份额变量与主业迁移空间（三层法）
- 层1 现有业务：市场容量 × 份额变量：①供给侧——甲乙酮国内份额 >60%、顺酐 >35%，均为全球第一，扩产节奏可控（产能稳定）；②需求侧——国际头部客户深化，海外贸易渠道壁垒高；③技术代际——C4 深加工工艺领先一代（PDH 改造全球首次）；④成本曲线——山能赋能降本，位于成本曲线左端；⑤份额二阶导数——成熟大宗品份额已饱和（S 曲线顶部），增量靠"价差+出口"而非份额提升。三档：保守（份额守成）、中性（小幅提升出口）、乐观（海外缺口抢份额）。验证点：出货份额、出口量、价差。
- 层2 扩展业务：主业迁移空间（高端精细化工）：①能力可迁移——C4 技术同源，切入催化剂/香料成本低；②新 TAM——高端香料/催化剂市场数十亿级、增速高；③卡位——早期（国产替代）；④认证门槛——客户认证（已打破进口，验证通过）；⑤信号验证——已投产+打破进口依赖。属"中期期权"，计入中性偏乐观，未过完全验证点仅作机会情景。
- 层3 证伪信号：顺酐高价下游（不饱和树脂）持续亏损致成交萎缩、原油飙涨侵蚀价差、贸易板块收缩、高端品客户定点落空 → 下调/剔除该增量。

第四步进阶·重资产/周期股估值校正（三道闸）
- 校正1 资产质量折扣：PB 1.29（未破净），净资产 112.07 亿，资产为化工装置（专用性中等，但持续盈利），无破净伪空间问题。商誉 6.41 亿（已从历史高位减值，风险大部分释放）。
- 校正2 周期位置校正：当前处于周期底部修复初期（上行）。中性净利 13 亿采用周期归一化中值（非 2017–2021 峰值 20–23 亿、非 2025 trough −5.75 亿）。顶部时须下调、底部不过度悲观——现取中值保守。验证点：顺酐/甲乙酮价差、油价。
- 校正3 杠杆下行情景：资产负债率约 53%（总资产 237 亿 / 净资产 112 亿），中等。负面情景（利率上行+需求下行+原油飙涨）可使净利转负 → 悲观情景 3.09 元（−39.3%），不得标大空间，至多"纳入观察"。
- 期权纪律：高端香料/催化剂国产替代为已验证中期期权，计入中性偏乐观；低空/新能源应用（占比小）仅作机会情景，不计入中性净利。

⚠️ 交叉校验：现价 5.09 对应市值 144.74 亿，已隐含 2029E ~13 亿 × 11x 的修复预期——当前价已基本透支 2026–2028 复苏，基准（2026E）内在价仅 3.16 元（空间 −37.9%）。

第五步：综合赔率判断（买不买？）

当前价格位置：已不便宜。现价 5.09 对应 PB 1.29、前瞻 2029E ~11x，已反映复苏预期；基准（2026E）内在 3.16 元，当前溢价明显。

安全边际：
- 中性远期 5.94 元 → 空间 +16.7%（不达"重点关注">50% 门槛）
- 悲观 3.09 元 → 下行 −39.3%（周期反复风险大）
- 乐观 11.60 元 → +127.9%（顺酐高景气+贸易高增）
- 下行保护：PB 1.29x、净资产 112 亿、山能国企背书，4.0 元（PB<1.1x）为强支撑

介入条件：
1. 不追高。等回落至 4.0 元以下（PB<1.1x，接近净资产） 才具安全边际
2. 加仓信号：① 顺酐持续涨价且单吨价差扩大验证；② 甲乙酮出口量创新高；③ 高端香料/催化剂客户大额定点公告
3. 观察指标：逐季化工制造毛利率（现 7.38%）、国际贸易净利、油价中枢

最大风险（最可能破坏逻辑的因素）：
1. 周期反复（首要）：原油飙涨侵蚀 C4 价差，顺酐高价下游不接受 → 毛利破阈值
2. 下游需求疲：不饱和树脂等行业持续亏损，高价货源成交受限
3. 贸易板块波动：海外贸易受汇率/关税/地缘影响
4. 负债率中等：利率上行加重财务压力

第五步进阶·上行想象力情景（四类，对冲系统性保守偏置）
- A 行业调整剩者红利：海外 C4 产能出清致供给缺口未填，齐翔（甲乙酮国内 >60%、顺酐 >35%，均全球第一）作为剩者份额与定价权跳升。验证点：海外出清公告、出货份额数据。证伪：海外产能复产、份额流失。
- B 政策反转期权：《石化化工老旧装置更新改造行动方案（2026—2029）》+ 山能赋能融资成本下降。验证点：设备更新招标、融资利率下行。证伪：政策力度不及预期。
- C 市场错杀修复：2025 全年 −5.75 亿 → 2026H1 扭亏 +1.16 亿，预期从"亏损股"修复为"周期修复股"。验证点：连续季度盈利确认。证伪：再度转亏。
- D 技术突破/代际跃迁期权：高端醛基香料（新洋茉莉醛/茴香基丙醛）国产替代从 0 到 1 投产打破进口、PDH 全球首次纯丙烷脱氢改混合脱氢。硬验证点：已投产 + 打破进口依赖 + 客户定点。三者已满足两项，计入机会情景（非中性）。证伪：客户定点落空/成本不优。
- 上调"重点关注"条件：顺酐持续涨价且单吨价差扩大 + 甲乙酮出口量创新高 + 贸易高增验证 → 中性情景上修至乐观（+127.9%）。

结论：纳入观察

理由：中性远期空间仅 +16.7%，不满足"重点关注" >50% 门槛；且基准（2026E）内在价 3.16 元，当前价已透支复苏。但公司作为全球 C4 龙头、山能赋能、周期上行 + 高端精细化工期权，具备"周期剩者红利 + 技术代际跃迁"上行想象力。真正的机会在于：若顺酐持续涨价 + 贸易高增验证（乐观情景 +127.9%），则具备上调至"重点关注"的条件。
核心跟踪点：顺酐/甲乙酮价差走势 + 国际贸易出货 + 高端品定点。
