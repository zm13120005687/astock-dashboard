健友股份（603707）五步法分析报告

分析日期：2026-09-13 ｜ 现价 7.43 元（2026-09-11 收盘，腾讯行情实时复查值，与收盘一致）｜ 总市值 120.04 亿 ｜ PE(TTM) 24.86x ｜ PB 1.73x ｜ 总股本 16.1565 亿股
行业：医药制造业（无菌注射剂 / 肝素原料药 / CDMO / 生物类似药）｜ 战略定位："立足中美，放眼全球"
业绩预测方法：自下而上（ANDA 批件→品种→单品收入→产能校验），全文无历史增速外推；周期品部分（肝素 API）做周期归一化处理。

第一步：公司是干什么的？

一句话定位：以无菌注射剂为核心剂型的国际化制药企业，靠"美国子公司 Meitheal 自建渠道 + 100 余项境外批件 + 12 条 FDA 认证产线"，把中国制造的注射剂直接卖进美国与欧洲主流市场，并正向生物类似药升级。

结构性巨变：肝素原料药收入占比从 2025H1 的约 15% 压缩到 2026H1 的 4.37%。这不是选择，是肝素 API 价格周期崩塌被动造成的结果。公司已从"肝素原料药企业"完成向"制剂出海企业"的身份切换 —— 这既是护身符（原料药拖累接近尾声），也是新挑战（制剂端要独自承担增长重任）。

核心产品：
- 肝素类：肝素钠注射液、依诺肝素钠注射液（获批美德英瑞典巴西等 10 国）、达肝素钠注射液、那屈肝素钙注射液
- 非肝素注射剂：苯磺顺阿曲库铵、左亚叶酸钙、度骨化醇、米力农、博莱霉素、丙泊酚乳状注射液、紫杉醇、注射用达托霉素、瑞加诺生、磺达肝癸钠、比伐芦定、米卡芬净等，超 70 个产品在美国销售
- 生物类似药：阿达木单抗（中国首家获 FDA 完全批准）、利拉鲁肽（2025-04 FDA 批准）、白蛋白紫杉醇生物类似药、门冬胰岛素（2026-07 获批）
- 创新药：XTMAB-16（全球首创抗肺结节病单抗，II 期完成并获 FDA 孤儿药资格，III 期推进中）、CONTEPO 注射用磷霉素（FDA NDA 批准，首个自研在美获批抗感染新药）

主要客户/下游：美国 GPO/三大批发商体系 + Meitheal 自营渠道；欧洲各国经销商（英国/德国/瑞典/西班牙/波兰等）；国内院内市场（累计 >30 项批件）。合作方含辉瑞、赛诺菲、诺华山德士等。

境内外收入占比：海外收入占比 >80%（2025 全年口径）。

股东与治理：法定代表人唐咏群；注册资本对应总股本 16.1565 亿股；2025 年度分红 10 派 1.00 元（分红率约 27.8%，偏保守）。资产负债率 36.26%，归母净资产 69.40 亿。

（3）产业链传导

上游 → 成本端：肝素粗品（猪小肠黏膜）→ 肝素原料药 → 制剂。粗品价格跟随生猪出栏周期。API 价格崩塌使公司"粗品—API—制剂"一体化的纵向优势大幅贬值：过去高价 API 库存是利润，现在低价 API 反而压缩了自用原料的机会收益。
其余原料（辅料、包材、预充针、胶塞）价格相对平稳。

下游 → 收入端：
- 美国：GPO 集中采购 + 三大批发商，价格谈判能力强、年降常态化
- 欧洲/新兴市场：规模小但增速快（2025 欧洲 +70.88%）
- 国内：集采压价，靠"中美双报"品种首获批上市占位

议价权：中偏弱。证据：制剂毛利率 34.70%（对比顾家级别品牌溢价不可比，但对比纯代工已属中上）；API 毛利率仅 14.58%（全球买方市场 + 印度低价竞品冲击，几乎无定价权）。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 分析
① 成本传导弹性（转嫁系数） 分线差异极大：
· 肝素 API：传导率 ≈ 0。API 出口价由全球供需（印度竞品 + 跨国客户去库存）决定，公司是价格接受者。证据：出口均价从 15,849 → <3,000 美元/kg，毛利率随之跌至 14.58%。（原文含无关字符已清理）
· 美国仿制制剂：传导率 ≈ 0.3–0.5。GPO 年度合同价，成本上涨难以年中传导；美国新增关税由进口商承担（公司作为供应商需分担一部分）。
· 生物类似药：传导率 ≈ 0.8+。竞争格局好（参与者少）、有品牌属性，是未来毛利修复的主力。
验证点：季度 API 出口均价（海关）、Meitheal 收入增速与制剂毛利率的背离度。
证伪：API 价格跌破 2,500 美元/kg；或制剂毛利率连续两季低于 33%。
② 毛利结构再平衡 三条线敏感度完全不同：
· 制剂 94.42% 占比 / 34.70% 毛利率 → 占毛利总额约 97.6%
· API 4.37% 占比 / 14.58% 毛利率 → 占毛利约 1.9%
· CDMO 0.85% 占比 / 7.93% 毛利率 → 占毛利约 0.2%
→ "综合毛利率 33.59%"掩盖了关键事实：API 已从"毛利贡献者"变成"毛利拖累者"（其毛利率低于费用率，实为负贡献）。若仅看综合毛利率 −3.9pct，会误判为整体恶化；实际是结构迁移 + 制剂自身降价两个问题叠加。
→ 更重要的推论：API 继续下跌的空间已经很小（收入占比已不足 5%），未来毛利率的主导变量是制剂，尤其是生物类似药占比提升带来的结构性改善。这是 2027–2029 毛利修复的根本依据。
③ 库存与采购节奏（timing） 这是本股最重要也最容易被误读的一点。
· 2024 年归母 8.26 亿的历史峰值，高度依赖高价肝素 API 库存的兑现收益（当时出口均价仍在 4,805 美元/kg 附近）。
· 2025–2026 年，高价库存出清完毕，进入"低价接货"阶段 → 当期毛利被低价产品压制，但同时存货跌价准备可能已计提。
· 2026H1 经营现金流 7.34 亿 ≫ 净利 1.88 亿，净现比 3.9x → 强烈暗示存货大幅去化，即报表利润已被库存节奏压低，真实经营质量优于利润表。
→ 不可把 2024 年的峰值利润当稳态，也不可把 2026 年的低位利润当趋势终点。这就是周期归一化必须做的原因。
④ 政策 / 市场锚点 市场层：全球肝素去库存周期（2023–2024 跨国药企过量囤货 → 2025–2026 去库存，原预期 2025 年底结束但延后）；印度低价竞品加入出口竞争。
政策层：① 美国对中国医药差异化高关税 → 倒逼供应链本地化（公司在美有销售子公司但生产在中国，属风险敞口）；② 美国 Section 232 药品关税调查（若落地将直接抬升中国产制剂成本）；③ 国内集采 → 境内低分子肝素均价已降 60%–65%；④ 国务院 2025-01 医械监管改革意见 → 利好出海注册提速。
情景：
· 悲观：API 均价跌破 2,500 美元/kg 且维持，美国对中国制剂加征关税落地 → API 收入 <1.2 亿、制剂毛利率 32%
· 中性：API 均价回升至 3,500–4,000 美元/kg（中信建投"温和复苏"），美国关税维持现状 → 制剂毛利率 35%–36%
· 乐观：API 均价回升至 4,500+，生物类似药放量占制剂收入 25%+ → 综合毛利率回到 38%+

第三步：确定性增量量化（自下而上清单）

公司 2025 年末在建工程仅 472.48 万元 —— 这是一个极其重要的信息：产能建设周期已基本结束，12 条 FDA 产线已建成待用。这意味着未来增量不来自"新建的产能"，而来自"已建成产能的利用率提升 × 新获批品种的上市"。增量必须按品种而非按"产能"来算。

第三步进阶：份额变量与主业迁移空间（三层法）

层 1：现有业务 = 市场容量 × 份额变量

锚点 现状 三档假设 可观测验证点
供给侧份额 12 条 FDA 产线、>70 品种在美在售，属美国仿制注射剂中型供应商 保守：守住现有品种份额；中性：随 ANDA 数增加稳步提升 季度 Meitheal 收入、在美品种数

层 2：扩展业务 = 主业迁移空间
- 能力可迁移性（强）：无菌注射剂工艺 + FDA/cGMP 体系 + Meitheal 美国商业化平台 + 全球注册能力，这套能力可以承载任何注射剂品种，从肝素 → 抗肿瘤 → 麻醉 → 生物类似药。这是典型的高可迁移性组合。
- 新 TAM 弹性（大）：全球高端无菌注射剂市场 + 生物类似药市场，规模远超公司当前 40 亿营收；全球 CDMO 2028 年 1,684 亿美元（虽然公司 CDMO 目前微不足道）
- 切入卡位（中）：生物类似药在美国属早期渗透阶段（而非红海），但每个品种都面临安进/山德士等巨头的专利诉讼
- 客户认证门槛：每新增一个 ANDA/生物类似药都需 FDA 单独批准 —— 这既是护城河（挡住后来者），也是阻力（放量慢）。公司已用 "每年 17 个获批"证明其通关能力。
- 信号验证：✅ 阿达木单抗 FDA 完全批准（已达成）✅ 利拉鲁肽 FDA 批准（已达成）✅ 门冬胰岛素获批（已达成）⚠️ 但营收结构中生物类似药占比尚未披露，未见跳升 → 尚未完全通过"营收占比"验证
- → 结论：迁移已通过"技术/获批"验证，尚未通过"收入占比"验证。按纪律，仅部分计入中性（已获批三品种给保守收入），诸如 XTMAB-16 这类 与未获批管线全部进入乐观情景。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 美国仿制药价格竞争的持续性（首要）：2026H1 制剂收入 +10% 但毛利率 −3.7pct，说明增量是"以价换量"换来的。若这种状态持续，收入增长将无法转化为利润增长，中性情景的 12% 净利率假设就不成立
