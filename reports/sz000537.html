绿发电力（000537）五步法分析报告

分析日期：2026-09-25 ｜ 现价 7.30 元（2026-09-24 收盘）｜ 总市值 150.07 亿 ｜ PE(TTM) 25.56x ｜ PB(LF) 0.76x（破净）｜ 总股本 20.56 亿股
行业：新能源发电（风电 + 光伏 + 储能）｜ 实控人：中国绿发投资集团
重资产 / 破净 / 强周期（电价）专项：资产质量折扣 + 周期位置校正 + 杠杆下行情景三道闸齐备。

第一步：公司是干什么的？

一句话定位：中国绿发旗下的新能源发电唯一上市平台，主营风能、太阳能电站的投资、开发、运营，装机规模已跻身国内新能源第一梯队（在运超 2100 万千瓦），但正遭遇新能源全面入市后的电价下行与高负债压力。

核心产品：风电（陆上 + 海上）、光伏、储能电站的电力销售。

主要客户 / 下游：国家电网、南方电网及各省电力交易中心（统购统销 + 市场化交易）；下游为工商业与居民用电，高度依赖电网消纳与交易电价。

境内外收入占比：境内为主（项目分布于新疆、青海、广东、江苏等）。

股东背景：中国绿发（央企），集团新能源资产整合平台定位，存在资产注入预期。

结构警示：资产负债率 73.81%、流动比率 0.98（短期借款 33.76 亿 + 一年内到期非流动负债 54.35 亿），短期偿债压力显著。

（3）产业链传导

上游：无燃料成本（风光零边际燃料），主要"成本"为初始 capex 与财务费用；设备（风机 / 组件）价格下行利好新项目 IRR。

下游：电网消纳 + 电力市场交易。需求侧用电增长平稳，但消纳瓶颈 + 市场化电价下行是当前核心矛盾。

议价权：弱（电价由交易市场竞争决定，新能源占比提升反而压价；无议价能力）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：风光发电无变动燃料，但"上网电价"即其售价，由市场竞价决定，传导系数对成本端不适用，核心在售价端弹性 α≈0（被动接受交易电价）。验证点：各省交易电价；证伪：电价企稳回升。
  • 因子2 毛利结构再平衡：风电（资源好、利用小时高）与光伏（午间大发、价格塌陷）毛利分化；公司光伏占比高（1683 万 kW），受午间低价冲击更大。分业务看，光伏毛利率敏感度高于风电，原料（组件）降价红利被电价下行吃掉。验证点：分电源毛利率；证伪：光伏毛利转负。
  • 因子3 库存与采购节奏：无库存概念；capex 节奏（组件 / 风机低价期抢装）影响未来成本，当前低价设备利好新项目但转固即增折旧。
  • 因子4 政策 / 市场锚点：① 136 号文机制电价（政策层，托底但退坡）；② 弃电率 / 消纳（市场层，限电直接减收入）；③ 东数西算绿电直连（政策层，改善消纳溢价）。情景：机制电价退坡 + 弃电率升 → 收入再降；验证点：各省竞价结果、弃电率。

输出：第四步净利率假设采用 10%~12%（低于 2025 的 16.4%），反映电价下行。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务（容量 × 份额）：新能源装机全国扩张，绿发依托集团资源获取指标能力强（2025 获 636 万 kW）。五锚点：① 供给侧份额提升（集团平台）；② 客户份额=电网统购，稳定；③ 技术代际无差异；④ 成本曲线（西北低电价区）；⑤ 份额加速度正（装机高增）。三档：保守（装机 +20%）、中性（+40%）、乐观（+60%）。验证点：新增并网容量公告。
  • 层2 主业迁移空间：由光伏向风电 / 储能 / 绿电直连（东数西算）迁移，属同业主业延伸，已部分验证（风电占比提升、储能在建），可计入中性但须打折。
  • 层3 证伪信号：弃电率持续升、电价加速下行、装机投产不及预期。

第四步进阶：重资产 / 周期股校正（三道闸）

  • 校正1 资产质量折扣（破净原因）：PB 0.76，破净合理——原因是新能源电价下行（136 号文）+ 新增装机转固折旧 + 限电弃电率升，资产盈利能力预期下降（2026H1 年化 ROE 仅约 2.9%）。非金融资产未重估型破净（无持股上市公司），不构成真安全边际，禁止单凭 PB<1 推大空间。
  • 校正2 周期位置校正：新能源电价处于下行周期（机制竞价普降、弃电率升），非底部反转。中性净利已采用低于 2025 的净利率（11% vs 16.4%），未用 2025 高电价年份外推。
  • 校正3 杠杆下行情景：资产负债率 73.81%、流动比率 0.98，高负债。利率上行 / 电价进一步下行 → 净利可降至 4 亿以下，悲观情景空间 −68%，不得标大空间。

期权纪律：东数西算 / 绿电直连 / 集团资产注入未过验证点，仅放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（破净但合理）。现价 7.30 元对应 2026E PE 27x、PB 0.76；破净反映资产盈利预期下修，但中性远期（5.16 元）低于现价，市场已提前透支装机增长。

安全边际：中性远期 5.16 元 → −29.3%；悲观 2.33 元 → −68.1%；乐观 8.56 元 → +17.3%。下行保护弱（高负债 + 电价下行），风险收益不对称偏负。

介入条件：回落至 5.0 元以下（接近中性锚、PB 0.65x）且出现：① 弃电率见顶回落；② 机制电价退坡预期缓和；③ 装机投产兑现。当前 7.30 元不满足。

最大风险：① 电价市场化持续下行（136 号文远期退坡）；② 弃电率 / 限电上升吞噬电量；③ 高负债下利率上行 + 短期偿债压力（流动比率 0.98）；④ 装机投产不及预期。

结论：暂不介入

理由：破净有合理基本面解释（电价下行 + 高负债），中性远期锚 −29.3% 低于现价，悲观情景 −68%。公司装机 pipeline 充裕、集团背景强，但短期盈利承压且估值未给安全边际。待 5 元以下或电价 / 消纳拐点确认再评估，可转为"纳入观察"。

第五步进阶：上行想象力情景（四类）

  • A 行业调整剩者红利：新能源供给侧出清（低效项目停建），剩者（央企绿发）份额与电价议价改善。验证点：行业装机增速放缓、弃电率回落；证伪：价格战持续。
  • B 政策反转期权：机制电价退坡节奏放缓 / 绿电直连（东数西算）放量带来溢价。验证点：政策纠偏、绿电溢价合同；重估弹性：若电价企稳，净利可回 11 亿（乐观情景）。
  • C 市场错杀修复：若市场过度担忧电价，PB 0.76 低分位提供修复弹性。验证点：电价企稳、盈利拐点；证伪：盈利继续下滑。
  • D 技术突破期权：长时储能 / 自同步电压源技术降本增利。硬验证点：技术量产 + 成本优于存量；当前未达，仅机会情景。

上调至"重点关注"的条件：弃电率明确见顶 + 机制电价退坡预期缓和 + 装机如期投产使 2029 净利站上 11 亿（乐观情景兑现），对应目标价 8.56 元（+17%）并具持续性。
