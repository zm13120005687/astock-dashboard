一句话定位：拥有中华老字号"古汉养生精"的湘药中药企业，聚焦医药大健康（中药、化药、保健食品三大板块），2025 年易主江琎（恒昌医药系）后正推进渠道重构与全国化。

核心产品：古汉养生精（浓缩丸/口服液，独家品种、国家中药保护品种）、部分化药、保健食品。

主要客户/下游：药店连锁、院边药房、电商及恒昌医药等流通渠道；历史上渠道局限于湖南及区域市场。

境内外收入：基本国内。

股东/关联交易：控股股东湖南赛乐仙（江琎），2026 年预计与关联方恒昌医药（江琎旗下）发生日常经营性关联交易不超 3.8 亿，2026H1 实际发生 5932.65 万——渠道赋能是核心变量。

（3）产业链传导

上游（成本端）：中药材（部分品种价格波动）、化药原料、包材。中药材价格近年波动上行，成本端有压力。

下游（收入端）：药店/流通渠道，买方（连锁药房）强势；集采压制医院端价格。公司议价权弱（区域品牌、渠道局限）。

议价权：弱（区域品牌）。古汉养生精为独家老字号有一定品牌溢价，但渠道局限于区域、全国化未成，对大连锁议价能力有限。佐证：营收 -5.8%、经营现金流转负。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性：中药材占成本较大，涨价时公司对终端（零售价受管控+竞争）传导率约 0.4–0.5。量化：若药材综合涨 10%，实际毛利承压 ≈ 10%×(1−0.45)=5.5%。集采品种传导率≈0（价格由医保定）。
  • 因子2 毛利结构再平衡：分业务毛利率——中药（古汉养生精，高毛利、核心）、化药（中低毛利、集采压制）、保健食品（中毛利）。结构风险：若高毛利中药占比下降、低毛利化药/保健占比升，加权毛利率下移。当前营收 -5.8% 主因核心中药增长乏力。
  • 因子3 库存与采购节奏：中药材可低价囤货（库存收益），但 2026H1 存货 +1212 万至 1.22 亿（占净资产 22.85%），存在跌价风险（已计提 563 万）；采购节奏影响成本但非主导。
  • 因子4 政策/市场锚点：① 市场层——中药材价格指数（康美/天地网）、终端零售价；② 政策层——中成药集采扩围（压制价格）、保健品监管、老字号扶持政策。验证点：集采目录、药材价格、渠道铺货数据。证伪：集采纳入核心品种、药材暴涨致毛利破阈值。

输出：第三步毛利率假设——核心中药毛利稳、化药受集采压制，综合毛利率维持中性，靠收入放量而非提价。

自下而上增量测算（非增速外推）：
- 年化营收（H1×2）约 2.69 亿，考虑季节性约 2.6–2.8 亿稳态。
- 增量核心：恒昌医药渠道（预计 3.8 亿关联交易额度）若有效转化，可驱动营收跳升至 4–5 亿；新品贡献增量。
- 中性 2029 营收 ~3.5 亿（恒昌部分赋能+核心企稳），正常化净利率 8% → 归母约 0.28 亿。
- 悲观：渠道赋能不及预期、营收 2.5 亿、净利率 4% → 归母 0.10 亿。
- 乐观（机会）：恒昌全面放量，营收 5 亿、净利率 10% → 归母 0.50 亿（未计入中性）。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧份额：中药OTC 市场分散，古汉养生精为区域老字号，全国份额极低。
  • 需求侧/客户份额：依赖区域渠道，恒昌医药（全国流通网络）为份额跃升关键。
  • 技术代际差：独家品种有壁垒，但非技术代际领先。
  • 成本曲线：规模小，无显著成本优势。
  • 份额二阶导数：全国化处极早期（S 曲线起点）。
    → 三档：保守 2029 归母 0.10 亿 / 中性 0.28 亿 / 乐观 0.50 亿。
  • 层2 主业迁移空间（渠道迁移）：从"区域中药"向"全国大健康渠道"迁移——能力可迁移（老字号产品力）、新 TAM 弹性大（全国OTC市场）、认证门槛中（渠道认证）、信号验证（恒昌关联交易 5932 万落地）。→ 中期期权，未全国化不计入中性。
  • 层3 证伪信号：恒昌关联交易无持续增长、核心产品收入连降、现金流持续为负。命中则下调。

第四步：估值锚定（正常化净利润法，亏损股专用）

方法：亏损股无正净利可锚，采用正常化净利润法（估稳态营收 → 保守正常化净利率 → ×远期合理 PE → 目标市值 → 目标价）。严禁硬套 PE。

亏损股三问

  1. 为什么亏：① 集采压制部分产品价格；② 产品结构单一（古汉养生精独木难支）、渠道长期局限区域；③ 内部运营效率未跟上；④ 2026H1 经营现金流 -2219 万（由正转负）、货币资金 -40%，造血恶化。属"主业阶段性造血不足+投入期"亏损，非一次性减值。
  2. 靠什么扭亏·触发时点：① 恒昌医药渠道赋能（关联交易额度 3.8 亿）放量，推动核心产品全国渗透；② 新产品上线贡献；③ 降本增效。触发时点：2026H2 减亏、2027 年有望扭亏为盈（中性假设，依赖渠道落地）。
  3. 亏得起吗：净资产 5.326 亿、资产负债率仅 38.4%，账面尚能支撑；但经营现金流转负、货币资金骤减 40%，依赖控股股东支持与再融资撑到扭亏。若 2027 仍不扭亏，将侵蚀净资产、逼近风险区，但暂未触及退市警示（非 ST）。

第四步进阶：重资产/周期股估值校正（三道闸）

  • 校正1 资产质量折扣：PB 4.03x（高溢价，非破净），反映"易主重生"预期而非资产价值。净资产 5.33 亿对应市值 21.48 亿，溢价 4 倍——属"重组预期型"，一旦渠道证伪将剧烈回撤。非金融资产未重估型安全边际。
  • 校正2 周期位置校正：中药消费属弱周期，当前处"公司自身调整阵痛期"，非行业周期底部。中性净利取保守正常化 8%，未用拐点年化。
  • 校正3 杠杆下行情景：资产负债率 38.4%（低），但经营现金流为负、货币资金骤减，若渠道赋能失败+再融资受阻，悲观情景股价 0.84 元（−90.6%），空间深度转负，故不得标大空间，至多"暂不介入"。扭亏/渠道期权未过验证点不计入中性。

第五步：综合赔率判断（买不买？）

当前价格位置：严重高估（重组预期溢价）。现价 8.97 元隐含正常化净利需达 0.50 亿（乐观）才勉强接近，中性合理价仅 2.92 元。

安全边际：
- 中性远期 2.92 元 → 空间 −67.4%（无安全边际，深度偏离）
- 悲观 0.84 元 → 下行 −90.6%
- 乐观 6.26 元 → 仍 −30.2%（需渠道全面验证）
- 下行保护：几乎无（高溢价+亏损+现金流恶化）。

介入条件：
1. 不介入。仅当回落至 3.0 元以下（接近正常化价值）且出现扭亏信号（单季扣非转正、恒昌关联交易持续高增）才考虑。
2. 加仓信号：① 单季归母净利润转正；② 恒昌关联交易逐季高增（接近 3.8 亿额度）；③ 古汉养生精收入恢复正增长。
3. 观察指标：经营现金流转正、货币资金回升、核心产品营收。

最大风险：
1. 重组/渠道预期退潮致估值回归（首要，空间 -67%）。
2. 恒昌渠道赋能不及预期，扭亏延后。
3. 经营现金流恶化、再融资受阻。
4. 集采扩围压制核心品种。

结论：暂不介入

公司确为亏损（2026H1 -1497 万，非 TTM 误标），正常化稳态价值（中性 2.92 元）较现价 8.97 元低估 67%，当前价格由"易主+恒昌渠道重生"预期驱动、严重偏离基本面。扭亏路径（恒昌赋能）可见但未验证，估值层面暂不介入，等回落至 3 元以下+扭亏信号。

第五步进阶：上行想象力情景（四类，仅进机会栏）

  • 类型A 行业调整剩者红利：中药老字号集中度提升、小厂出清，公司守稳独家品种受益。→ 中性部分含。
  • 类型B 政策反转期权：若集采对独家老字号温和、老字号扶持加码，估值修复。验证点：政策发文。→ 计入乐观（机会）。
  • 类型C 市场错杀修复：不适用（当前为溢价非错杀）。
  • 类型D 技术突破/代际跃迁：无重大技术代际突变；核心为"渠道重生"而非技术跃迁。不适用，仅渠道期权。

上调至"纳入观察"的条件：恒昌关联交易连续两季高增且核心产品收入转正、单季扣非扭亏，使中性远期空间收窄至可接受区间。
