一句话定位：中国工业车辆（叉车）双龙头之一，围绕"整机 + 零部件 + 智能物流 + 后市场"四大板块协同发展，2026H1 整机销量 25.80 万台（行业市占率约 29.93%）、海外收入占比 45%、电动化产品占比约 74%，远期目标为"全球一流工业车辆及智能物流系统集成商"。

（3）产业链传导（原料成本 → 毛利结构）

叉车的主要"原料"为钢材（车架、门架、配重）、锂电池电芯与"三电"系统、液压件、发动机（内燃机型）、铸件；钢材与锂电成本是核心敏感项。

第二步进阶：原料成本 → 毛利结构传导（四因子）

  • 因子1 成本传导弹性（pass-through）：叉车是充分竞争制造业，成本转嫁率因市场而异——海外市场传导率≈0.7–0.8（海外毛利率 30.10%、同比 +4.27pct，说明提价能力较强、品牌与渠道议价权高）；国内市场传导率≈0.3–0.5（国内毛利率 17.82%、同比 −3.50pct，价格战下成本上涨难以转嫁）。加权传导率约 0.5。依据：2026H1 钢价与锂价总体平稳（营业成本 +12.83% 略高于营收 +12.11%），毛利率仅 −0.49pct，说明成本冲击主要通过海外提价部分消化。
  • 验证点：季度毛利率分化（海外 vs 国内）、钢材与碳酸锂价格走势。

  • 证伪信号：国内毛利率跌破 16%、或海外毛利率跌破 28%（说明转嫁能力破坏）。

  • 因子2 毛利结构再平衡（分业务线毛利率 + 敏感权重）：禁止用"综合毛利率 22.86%"掩盖结构迁移：

  • 整机（国内）：毛利率约 17.82%（2025 年），对钢材价格敏感度中高（车架/门架/配重占整机成本大头）；价格战下毛利最易被侵蚀。
  • 整机（海外）：毛利率约 30.10%（2025 年），对汇率敏感度极高（收入以美元/欧元计价，成本以人民币为主）——这是本股当期利润的核心扰动源，也是海外占比提升能对冲国内价格战的机制。
  • 零部件（+28%）：毛利率中等，对钢材与铸件成本敏感。
  • 后市场（+23%）：毛利率最高（服务与配件，对原料敏感度低），是最优质的结构迁移方向。
  • 智能物流（合力宇锋）：毛利率为负（培育期降价抢市场 + 研发投入），拖累合并毛利率约需承担 0.79 亿元亏损。
  • 结构迁移方向：国内低毛利整机占比下降、海外高毛利整机 + 后市场 + 零部件占比上升 → 加权毛利率本应上行，但被国内价格战与汇兑抵消，故 2026H1 仅 −0.49pct。
  • 验证点：分地区毛利率披露、海外收入占比、后市场收入占比。

  • 证伪信号：海外占比停滞、国内毛利率继续下滑、后市场增速放缓。

  • 因子3 库存与采购节奏（timing）：① 汇兑损益的 timing——2025H1 录得 1.30 亿元汇兑收益（人民币贬值期），2026H1 转为 1.01 亿元损失，两年合计波动 2.31 亿元，属"靠汇率吃饭"的不可持续项，须从趋势盈利中剔除；② 锂电成本 timing——锂价 2023 年以来大幅下行使电动叉车成本下降，是电动化渗透率提升的经济基础；若锂价反弹，电动化经济性会削弱；③ 应收账款 timing——期末应收款项（含票据/账款/预付）52.34 亿元、较上年末 +35.91%，增速显著高于收入（+12.11%），1 年以内账龄占 94.60%，账龄尚健康但须监控营运资金占用。

  • 验证点：季度汇兑损益、应收款项/收入比、有息负债变化。

  • 证伪信号：应收款项增速持续高于收入增速 20pct 以上。

  • 因子4 政策/市场锚点（成本驱动变量）

  • 市场层：钢材价格（车架/门架/配重）、碳酸锂价格（锂电池）、人民币汇率（海外收入）、海运费（出口）。
  • 政策层：① 2,000 亿元超长期特别国债支持设备更新 → 直接刺激存量燃油叉车替换为电动叉车（需求端政策）；② 碳排放双控 + 国四排放标准 + 地方淘汰补贴（报废叉车 6,000 元–3.5 万元、购新能源叉车 1 万–4.2 万元） → 抬高燃油叉车使用成本、降低电动叉车购置成本（成本端政策）；③ 出口退税率 13% → 直接增厚出口毛利；④ 《场（厂）内专用机动车辆安全技术规程》 → 淘汰落后产能、提升行业门槛。
  • 情景假设：中性——国内价格竞争延续但边际趋缓、海外继续放量、汇率中性；乐观——设备更新补贴加速落地 + 出口关税环境稳定 + 智能物流减亏；悲观——国内价格战加剧 + 人民币持续升值（汇兑损失延续）+ 出口关税抬升。
  • 验证点：季度行业销量、地方补贴落地项目数、人民币汇率、出口退税率政策变化。
  • 证伪信号：行业销量增速转负、国内毛利率跌破 16%、出口关税显著抬升。

第三步进阶：份额变量与主业迁移空间（增量拆解三层法）

层1 现有业务：市场容量 × 份额变量（5 锚点）

  1. 供给侧份额：行业 2026H1 销量 86.19 万台（+16.58%），公司 25.80 万台 → 市占率约 29.93%，与杭叉集团构成双龙头（CR2 约 50%+）。公司销量增速（+22%）> 行业（+16.58%），份额在提升。行业在"电动引领、内燃承压"下加速出清中小厂商。
  2. 需求侧/客户份额：海外代理商 400 余家、覆盖 180 多个国家，在 30 余个海外市场占有率第一；客户认证周期长、渠道壁垒高，粘性强。
  3. 技术代际差：电动化（锂电）与智能化（AGV/无人叉车）为行业主流代际；公司电动化占比 74%（+6pct）、自研"三电"与 AGV 调度系统，处于主流代际且部分领先（"三转"：内燃转电动、铅酸转锂电、传统能源转新能源）。
  4. 成本曲线位置：规模（整机 25.8 万台/半年）+ 垂直一体化（零部件 + 铸造件）使其成本曲线靠左；国内价格战下仍能维持规模效应与正现金流（2026H1 经营现金流 +6.22 亿元），成本位置占优。
  5. 份额变化的二阶导：份额处于加速渗透期（销量增速持续高于行业、电动化占比每年 +6pct）；三档假设：保守——份额守住 29.9% / 中性——份额小幅提升至 31%–32% / 乐观——受益于行业出清与出海，份额提升至 34% 以上。

层2 扩展业务：主业迁移空间（新易盛范式）

  • ①能力可迁移性：从"整机制造"迁移至智能物流系统集成（AGV/AMR + WMS 调度），技术同源（电机、电控、导航、调度算法）、供应链可共用（合力宇锋产业园即依托集团制造技术、供应链体系与全球市场服务），迁移成本低。
  • ②新 TAM 弹性：智能仓储机器人/无人叉车对应的是仓储自动化市场，TAM 显著大于传统叉车；公司产业园年产值规模设计 20 亿元以上。
  • ③切入时点与卡位：早期偏有利——与华为"天工实验室"、江淮前沿中心"天枢实验室"合作，具身智能方向卡位较早。
  • ④客户认证门槛：从"卖设备"转向"卖解决方案"，客户（黑灯工厂、智能仓储）要求系统集成能力与交付验证，门槛中等偏高。

校正1 资产质量折扣（PB 1.34x 未破净，但须审查资产质量）：
- 商誉仅 6,849 万元（占总资产比例极低）——无商誉减值风险，加分项。

- 有息负债主动压降：短期借款 2.41 亿元（−62.74%）、长期借款 3.73 亿元（−34.93%），筹资活动现金流净额 −10.32 亿元——主动去杠杆，资产质量改善。
- 境外资产 29.08 亿元、占总资产 13.93%（2025 年末 27.56 亿元、13.88%），随泰国工厂建设继续扩大，存在海外资产与汇率双重敞口。
- 结论：PB 1.34x 对应 ROE 约 11%（2025 年 11.58%、2026H1 年化约 12%），按"PB = ROE/COE"（COE 9.5%）测算公允 PB 约 1.2–1.3x——现价 PB 1.34x 略高于公允值，但 PE 仅 11.8x（2026E），说明资产的盈利质量（ROE 11%+）足以支撑当前 PB，不构成资产质量折扣问题。

校正2 周期位置校正（中性净利用周期归一化）：
- 叉车行业并非典型强周期（下游分散于制造业与物流，需求相对平稳），其"周期"体现为制造业资本开支周期 + 电动化渗透周期 + 设备更新政策周期三者的叠加。
- 当前周期位置：处于电动化渗透上行期（占比 74%、每年 +6pct）+ 设备更新政策红利期（2,000 亿元国债）+ 国内价格竞争加剧的下行压力期三者并存。行业销量仍正增长（+16.58%），非周期底部。
- 归一化处理：中性净利 不使用 2026H1 含汇兑损失的单期值，也不使用 2025 年含汇兑收益的年度值，而采用"汇兑中性 + 国内价格竞争延续 + 海外占比提升至约 50%"的正常化组合 = 17.0 亿元；且不把中国叉车行业 2026H1 的 16.58% 销量增速直接外推（用行业量价与公司份额一步步推）。
- 验证点：行业季度销量、公司季度份额、国内/海外毛利率分化。
- 证伪信号：行业销量增速转负、国内毛利率跌破 16%。

校正3 杠杆下行情景（本股杠杆最低）：
- 资产负债率仅 42.27%，有息负债合计约 6.14 亿元（短 2.41 + 长 3.73），杠杆极低；经营现金流 +6.22 亿元（同比 +6.75%），造血能力为正。
- 下行情景：若国内价格战加剧使毛利率跌破 16%、同时人民币持续升值（汇兑损失延续）、智能物流亏损扩大，2029E 归母可跌至 12.0 亿元，PB 下修至 1.0x（对应股价约 12.4 元，空间 −25%）。
- 因杠杆低、现金流转正，该负面情景空间虽转负但幅度可控（约 −25%），不同于高杠杆公司的"几倍跳负"；本股仍可标"重点关注"，但须在本表内明示该下行情景。
- 缓解因素：海外高毛利占比提升天然对冲国内价格战；设备更新政策提供需求托底；泰国工厂降低关税与运费成本。

第五步：综合赔率判断（买不买？）

当前价格位置：低估。现价 16.57 元对应 2026E PE 约 11.8x（低于合理区间 12–15x 下沿）、2029E 中性 PE 仅 8.7x、PB 1.34x（公允约 1.2–1.3x，ROE 11%+ 支撑）。市场已定价汇兑一次性拖累、国内价格战与智能物流亏损三重悲观。

安全边际：
- 中性远期 25.77 元 → 空间 +55.5%，满足"重点关注"（>+50%）门槛。
- 悲观情景 14.82 元 → 下行仅 −10.6%（因低杠杆、正现金流、海外高毛利对冲），风险收益显著不对称偏正（下行 0.19 : 上行 1.0）。
- 乐观情景 39.53 元 → +138.6%。
- 下行保护：PE 11.8x、资产负债率 42.27%、有息负债仅约 6.14 亿元、经营现金流 +6.22 亿元、中期分红已实施（每 10 股派 1.00 元）、海外毛利率 30%+。
- 上行触发：H2 汇兑压力释放、智能物流减亏、设备更新补贴落地。

介入条件：
1. 价格：现价即可介入（PE 低于合理区间下沿）；加仓区间 15.0 元以下（对应 2026E PE <10.7x）。
2. 信号：① 2026 三季报汇兑影响消除、归母同比降幅收窄至 5% 以内；② 国内毛利率止跌（≥17%）且海外毛利率维持 29% 以上；③ 合力宇锋单季亏损收窄（环比改善）；④ 泰国工厂投产时间明确、出口销量维持 20%+ 增速。
3. 观察指标：季度行业销量与公司份额、国内/海外毛利率分化、应收款项/收入比、汇兑损益、智能物流板块收入与盈亏。

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 国内价格竞争持续加剧（首要）：2025 年国内毛利率已 −3.50pct 至 17.82%，2026H1 综合毛利率再 −0.49pct；若跌破 16%，国内整机的盈利将被完全侵蚀。
2. 汇率波动：2026H1 汇兑损失 1.01 亿元（上年为收益 1.30 亿元），变动 2.31 亿元；人民币持续升值将持续压制海外盈利。
3. 智能物流持续亏损：合力宇锋净亏 7,917.01 万元、同比 −420.20%，若无法扭亏将长期拖累合并利润。
4. 出口关税与地缘风险：海外占比 45%，关税抬升或地缘冲突将直接冲击出口。
5. 应收款项增速快于收入：+35.91% vs +12.11%，营运资金占用扩大。

结论：重点关注

本股是叉车双龙头 + 电动化/国际化结构升级 + 低估值 + 下行有保护的组合：中性远期空间 +55.5%（>50%），悲观下行仅 −10.6%（低杠杆、正现金流、海外高毛利对冲），风险收益显著不对称偏正，符合"重点关注"的四项标准（业绩增长明确——剔除汇兑后经营性利润 +12%；行业景气向上——销量 +16.58%；估值合理偏低——2026E PE 11.8x；远期空间 >50%），故判重点关注。

  • 类型A 行业调整剩者红利：叉车行业在国四排放标准 + 双碳 + 安全技术规程 + 地方淘汰补贴的多重约束下加速出清落后产能，行业向"电动引领"重构；公司与杭叉集团构成双龙头（市占率 29.93%），是典型剩者。验证点：行业集中度数据、公司份额持续提升（销量增速持续高于行业）；证伪信号：份额下滑、行业销量负增长。重估弹性：若份额提升至 34%，整机收入与利润将同步抬升约 15%。
