（3）产业链传导

上游：GPU / 服务器 / 电力 / 带宽 / 机房。GPU 受供应链瓶颈（高端算力结构性紧缺）、电价与绿电要求抬升成本。

下游：AI 大模型厂、互联网、金融政务——需求刚性且高增长。综合议价权中等（云厂商面对大客户有折扣压力，但智算供给紧俏时溢价能力回升）。

议价权量化：通用云转嫁系数 ≈0.4（价格战），智算云转嫁系数 ≈0.7（供给紧俏、客户愿付溢价）。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性（pass-through）：核心成本是 GPU 折旧 + 电力 + 带宽。智算云供需紧俏，转嫁系数 ≈0.7（涨价可传导）；通用云 / IDC 过剩，转嫁系数 ≈0.4（自己扛）。验证点：H1 毛利率 +4.48pct，源于高毛利智算占比提升 + 结构优化。
  • 因子2 毛利结构再平衡：分业务线——云主机（智算）高毛利、IDC（老旧机柜）低毛利且收缩。H1 云主机占比升至 65.9%，加权毛利改善。禁单一综合毛利率：若智算占比继续升至 80%+，整体毛利率可上修至 22–25%。
  • 因子3 库存与采购节奏（timing）：无实物库存，但 GPU / 服务器capex 前置、折旧刚性；低价锁卡收益 / 高价接货损失体现在折旧与利用率。H1 经营现金流转正 +1.39 亿，反映回款与运营改善，非库存收益。
  • 因子4 政策 / 市场锚点：① 市场层——GPU 供应链瓶颈（高端算力紧缺抬价）、电力承载力（北美 AI 电力缺口 7–14GW）；② 政策层——绿电占比要求（抬成本但利好西部绿电枢纽）、算力网调度（提升上架率）。情景：智算需求持续 + 上架率提升 → 毛利改善；证伪：GPU 供给缓解致租赁价跌、绿电成本超预期的毛利破阈。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：八大枢纽智算占比超 80%，公司需卡位枢纽节点。
  • 需求侧：AI 大模型厂 / 互联网为客户（份额取决于算力性价比 + 服务）。
  • 技术代际：智算云（GPU）相对通用云领先一代，溢价高。
  • 成本曲线：绿电长协 + 西部枢纽布局使单位算力成本左移。
  • 份额加速度：智算渗透率早期（S 曲线上升）。
    → 三档：保守守住（营收 14 亿）/ 中性小幅提升（23 亿）/ 乐观抢份额（30 亿）。验证点：逐季云主机收入、智算上架率、大客户签约。
  • 层2 扩展业务：主业迁移空间：从"通用云 + IDC"迁移到"智算云 + AI 推理"——能力同源（云架构复用），新 TAM（AI 算力）远大于旧。信号验证：智算收入占比、推理客户落地——已部分兑现（云主机占比 65.9%），但盈利兑现仍处验证期，仅部分计入中性。
  • 层3 风险折扣（证伪信号）：GPU 供给缓解致租赁价崩、大客户流失、上架率不及预期、再融资失败致 capex 中断。命中则下调。

第四步：估值锚定（自下而上，非增速外推）

方法说明：首都在线为亏损股（减亏中），采用正常化净利润法（估稳态营收 → 保守正常化净利率 → ×远期合理 PE）。公司重资产（IDC / 智算 capex）+ 高负债（64.6%），须做第四步进阶三道校正。

总股本：约 5.03 亿股 ｜ 净资产 7.65 亿 ｜ 负债率约 64.6%（高）。

准亏损从严：正常化净利润法 + 亏损股三问

为什么亏：① 历史 IDC 低功率机柜过剩 + 价格战，IDC 收入 −24.5%；② 智算云处于 capex 前置、折旧爬坡期，规模效应未充分释放；③ 财务费用 + 研发 + 销售投入高于收入（H1 虽减亏但仍亏）。本质是战略投入期 + 业务结构切换，非需求崩塌（云主机 +39.67%、毛利改善）。

靠什么扭亏，触发时点：① 智算云占比提升 + 上架率提高（全国 71.4%）→ 规模效应释放；② IDC 出清老旧机柜、结构优化；③ 经营现金流已 +1.39 亿，造血改善。触发时点：2026H2–2027 年——若减亏延续，2027 全年有望经营性扭亏。

亏得起吗：总资产 21.62 亿、净资产 7.65 亿、负债率 64.6%——负债偏高。但经营现金流转正 +1.39 亿、推进再融资，短期偿债靠经营现金流 + 股权融资，可撑到扭亏，但高杠杆放大下行（见下校正）。

第四步进阶：重资产 / 高负债估值三道校正

  • 校正1 资产质量折扣：PB 13.3x（市值 101.5 亿 / 净资产 7.65 亿），未破净，估值高源于成长期权而非账面。IDC / 智算固定资产为重，但专用性强（机房不能转产），重置成本不兜底——高 PB 不证明低估，反提示预期饱满。
  • 校正2 周期位置校正：算力处于 AI 资本开支超级周期上行段（智算 +177%），中性净利未用单年好年景外推，而是用稳态净利率 8% 折算，已保守。
  • 校正3 杠杆下行情景（高负债必附）：负债率 64.6%，经营 + 财务杠杆双高。若利率上行 / AI 算力需求不及预期（GPU 供给缓解致租赁价跌），净利可几倍跳负，悲观情景已至 3.12 元（−84.5%）→ 空间转负，不得标大空间 / 重点关注，至多"纳入观察"。

交叉校验：现价 20.17 元对应市值 101.5 亿，是中性目标市值 64.4 亿的 1.58 倍；乐观情景 23.84 元才略高于现价，需智算净利达 3 亿（近乎翻倍于中性）才能兑现。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高但含合理成长期权。现价已反映部分智算成长，但扭亏尚未兑现、杠杆偏高。

安全边际：中性远期 12.80 元 → 空间 −36.5%；乐观 23.84 元（+18.2%）；悲观 3.12 元（−84.5%）。下行不对称显著（高杠杆），但上行有真实 AI 云催化。

介入条件：① 等经营性扭亏确认（2026 年报或 2027H1 归母转正）再考虑；② 价格回落至 15 元以下（对应市值 ~75 亿、接近中性目标上沿）才具安全边际；③ 加仓信号：智算收入占比 >75%、经营现金流持续为正、再融资落地。

最大风险：① 高负债（64.6%）+ 利率上行致财务杠杆反噬；② 智算租赁价因 GPU 供给缓解而下跌；③ 再融资不及预期、capex 中断；④ 扭亏时点晚于预期。

结论：暂不介入（中性远期空间 −36.5% ≤ 0，不满足"纳入观察需 >0"门槛；AI 云高景气 + 减亏明确仍成立，但短期仍亏、估值偏高、杠杆大，需等盈利拐点与价格回落至 15 元以下再观察）。

若 2027 年经营性扭亏且智算净利达 2.5 亿+（乐观情景 23.84 元附近），具备上调至"重点关注"的条件。当前不追高，设条件单跟踪。
