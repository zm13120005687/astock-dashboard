（3）产业链传导

上游：算力/大模型 API（DeepSeek、通义、文心开放平价接口，成本下探）；素材/数据服务商。公司对上游议价权强（API 标准化、可替换）。
下游：广告主预算。议价权中等——品牌方预算波动大，但全链路服务能力增强粘性。
议价权判断：从中单次执行向多年深度战略合作转型，增强黏性但难提价的"夹心"格局。

第二步进阶：原料成本 → 毛利结构四因子

  • 因子1 成本传导弹性：营销服务商无实物原料，主要"成本"= 算力 API + 人力。算力成本随国产模型降价而下行（传导率利于公司，成本下降直接增厚毛利）。验证点：毛利率未因算力涨价受损；证伪：若大模型 API 涨价且无法转嫁。
  • 因子2 毛利结构再平衡：品牌营销（高毛利）vs 红人/数字营销（低毛利流水型）。公司主动缩降低毛利流水业务、聚焦高附加值全案，结构优化中。须分业务线盯毛利率，禁单一综合毛利率。
  • 因子3 库存与采购节奏：无库存概念；但人力与算力投入具前置性，AI 研发期费用先行、收入滞后，致 Q2 利润率波动。
  • 因子4 政策/市场锚点：监管合规（AI 广告标识）抬高准入门槛→利好头部；补贴政策→刺激需求。情景：合规趋严→集中度提升（利好）；补贴退坡→需求回落。验证点：合规政策落地、头部订单份额。

第三步进阶：份额变量与主业迁移三层法

  • 层1 现有业务（市场容量 × 份额变量）：
  • 供给侧：AI 营销 636 亿市场、CR 低，头部 10% 占 60% 订单，集中度上行。
  • 客户份额：新增荣耀/抖音/可口可乐/长城，客户层级跃升。
  • 技术代际：自研 AI 体系领先多数中小代理，代际差正向。
  • 份额加速度：行业向头部集中 + 公司获重量级客户，份额加速。
  • 三档：保守守住、中性小幅提升、乐观抢份额（AI 营销放量）。
  • 层2 扩展业务（主业迁移）：从"广告代理"向"AI 营销技术平台 + GEO"迁移，能力可迁移（同源创意+技术），新 TAM（GEO 90 亿、AI 营销 3700 亿）弹性大；切入卡位早（先发红利）；认证门槛低（客户验证即可）。部分已验证（客户落地），但收入占比仍小，计入中性须谨慎，仅部分计入。
  • 层3 风险折扣（证伪信号）：重量级客户流失、AI 投入未转化为利润、毛利率持续下滑——命中则下调。

第四步进阶：重资产/周期股三道闸

  • 校正1 资产质量折扣：轻资产（净资产 5.57 亿、无重资产），PB 7.89x 高溢价来自品牌/客户/技术无形资产，非资产兜底；无破净。
  • 校正2 周期位置：广告业随宏观周期波动（beta 高），中性净利已用保守值，未用单年好年景。
  • 校正3 杠杆下行：资产负债率低，但高 beta 属性下宏观需求下行时净利可大幅波动；悲观情景空间 −65.5% 已体现。

第五步：综合赔率判断（买不买？）

当前价格位置：偏高（透支 AI 预期）。现价 26.45 元对应 2029E 中性 PE 43x，已反映 AI 营销高成长。

安全边际：中性远期 18.27 元 → 空间 −30.9%；悲观 9.13 元（−65.5%）；乐观 32.89 元（+24.4%）——中性与悲观均低于现价。

介入条件：① 股价回落至 18 元以下（接近中性估值）才具安全边际；② 加仓信号：AI 营销收入占比跳升、重量级客户续约公告、毛利率企稳回升。

最大风险：① AI 投入回报不及预期（增收难增效）；② 重量级客户流失；③ 广告预算宏观下行；④ 高估值消化压力（PB 7.89x）。

上行想象力四类情景（仅进乐观栏，不进中性锚）：
- A 行业剩者红利：合规趋严 + 集中度提升，头部 10% 占 60% 订单，公司卡位受益——验证点：头部订单份额数据；证伪：份额流失。
- B 政策反转期权：上海"AI+广告"补贴、地方数字产业扶持扩围——验证点：补贴政策落地、采购订单；证伪：政策退坡。
- C 市场错杀修复：若随大盘/创业板风格杀跌至 18 元以下，具修复弹性——验证点：估值分位、基本面未恶化；证伪：盈利证伪。
- D 技术代际跃迁期权：自研营销 AI 体系 + GEO 从 0 到 1 重构营销 workflow——硬验证点：AI 产品规模化付费、客户续约率跳升、毛利结构性提升；证伪：研发投入未转化。
- 上调至"重点关注"的条件：2029E 净利上修至 ≥1.8 亿（乐观情景兑现）且现价回落至 20 元以下，使中性空间 >+50%。

结论：暂不介入（中性远期空间 −30.9% ≤ +50%，且现价已高估值；须等回调至 18 元以下或 AI 变现验证）。
