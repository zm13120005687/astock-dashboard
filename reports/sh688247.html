宣泰医药（688247）五步法分析报告

分析日期：2026-09-21 ｜ 现价 9.96 元 ｜ 总市值 45.15 亿 ｜ PE(TTM) 约 140x（2025 弱基期） ｜ PB 3.42x ｜ 总股本 约 4.53 亿股
行业：高端仿制药 + CRO/CDMO（创新药一体化服务）｜ 板块：科创板
重要判定：2026H1 归母净利 +2970.18 万（真实最新财报为正），属盈利股，去掉队列表"亏损"误标，按盈利股完整五步法估值。业绩阶段性承压（−34.84%）主因集采降价 + 研发前置，非趋势恶化。

一句话定位：以研发为核心、深度参与全球市场竞争的创新型高端化学制药企业，聚焦高端仿制药研发产业化 + 创新药 CRO/CMO 一体化，核心品种集采放量 + 国际化（FDA/EU）双轮驱动。

财务状况（2026H1）：总资产 14.75 亿，归母净资产 13.19 亿，资产负债率约 10.6%（极低）；研发投入 3199.84 万（占营收 16.74%，+24.49%）；毛利率 41.53%（+0.3pct）；净利率 15.54%；经营现金流 +0.85 亿（+73.64%，回款质量优）。

（3）产业链传导

上游（成本端）：原料药（API）价格 + 辅料 + 包材。复杂制剂（注射剂）对 API 纯度要求高，成本受化工原料波动影响。

下游（收入端）：国内医院/零售（集采渠道，价格被压）、海外药企/经销商（溢价高）。集采下对国内下游议价权弱（被动降价），但差异化品种 + 海外自主定价权强。

议价权：中——集采品种国内弱、海外与差异化品种强（FDA/EU 认证壁垒）。毛利率 41.53% 维持稳健印证结构尚可。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：集采品种传导率≈0（降价自己扛），但海外自主定价品种传导率≈1（可转嫁）。验证点：海外收入占比是否升至 30%+。
  • 因子2 毛利结构再平衡：分业务——产品（仿制药，集采压制毛利率）、CRO/CMO（服务，毛利率较高）、权益分成（高毛利）。禁单一 41.53% 掩盖结构：估值须按高毛利 CRO/CMO + 海外占比提升给结构改善。验证点：CRO/CMO + 海外收入占比。
  • 因子3 库存与采购节奏：原料药低位囤货可享成本收益，高价接货承压；长协/套保比例未知（待披露）。需区分当期毛利是否含囤货收益。
  • 因子4 政策/市场锚点：①集采降价（压制国内价格，变量）；②关税/出口（美国市场托法替布已上市，关税为成本变量）；③国产替代补贴/创新药支持（上行期权）。情景：乐观——集采以价换量超预期 + 海外获批加速；悲观——集采续约降价超预期 + 关税抬升出海成本。验证点：集采续约价格、FDA 新批品种数。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：高端仿制药产能有限，复杂制剂车间投产扩供给；
  • 需求侧：集采以价换量提升份额（碳酸司维拉姆等加速放量）；
  • 技术代际：三大制剂技术平台 + 国际化申报能力领先；
  • 成本曲线：工艺优化 + 供应链管理控成本；
  • 份额加速度：海外新获批驱动份额跳升（早期）。
    → 三档：保守守住、中性海外占比升至 30%、乐观抢全球仿制药份额。验证点：海外收入占比、集采品种销量。
  • 层2 扩展业务：主业迁移空间（高端注射剂 + 改良型新药）：从口服仿制药迁移至高壁垒复杂注射剂（TAM 更大、竞品少），XT-0043 为"仿创结合"转型标志。信号验证：复杂制剂车间认证 + III 期达终点 → 已部分过验证，计入中期增量。
  • 层3 风险折扣（证伪信号）：集采续约降价超预期、海外获批延迟、XT-0043 临床失败、研发转化收入持续不达里程碑 → 触发则下调。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵（已透支国际化与管线预期）。现价 9.96 对应中性远期 9.8 元，安全边际薄；PE TTM 140x 居高。

安全边际：
- 中性远期 9.8 元 → 空间 −1.6%（基本持平）
- 悲观 2.8 元 → 下行 −72.3%
- 下行保护：净资产 13.19 亿（PB 3.42x），资产负债率仅 10.6%，现金充裕，无破产风险

介入条件：
1. 等回调：回落至 8 元以下（对应 2029E PE <30x）才具吸引力
2. 加仓信号：海外收入占比破 30%、复杂制剂车间通过认证、XT-0043 NDA 受理

最大风险：
1. 估值高位（首要）：现价已含满预期，任一年报不及预期即杀估值
2. 集采降价超预期：续约价格若大幅下探，国内产品毛利承压
3. 研发转化不及预期：技术成果转化收入已 −854 万，若持续将拖累

上行想象力四类情景：
- A 行业调整剩者红利：集采洗牌中具国际化注册能力者集中度提升（验证点：份额数据）
- B 政策反转期权：创新药/改良型新药审批加速 + 商业健康险支付扩容（验证点：XT-0043 NDA 受理）
- C 市场错杀修复：若因短期业绩承压被错杀至 8 元以下，修复弹性大
- D 技术突破期权：XT-0043 改良型新药从 III 期到达 NDA/获批，重构成长曲线（硬验证点：临床终点已达、NDA 受理、量产成本优——临床已达标，待 NDA，计入乐观情景）

结论：暂不介入。公司质地优良（盈利、现金充裕、全球化加速、管线清晰），但现价 9.96 已等于中性远期 9.8 元，安全边际不足、远期空间 −1.6%（中性预测下无上行），短期估值偏高。等回调至 8 元以下（对应 2029E PE <30x）或海外/复杂制剂放量验证后再重新评估介入。
