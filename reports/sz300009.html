第一步：公司是干什么的？

一句话定位：国内基因工程药老牌厂商，靠「生长激素（安苏萌）+ 人干扰素 α2b」两条自产主线起家，在集采与医保谈判把存量价格打下去之后，正在用「自研创新管线 + 独家代理新品」两条腿做二次创业。

核心产品：
- 自产：注射用人生长激素（安苏萌，粉针 / 水剂 / 预充式）、人干扰素 α2b（注射液、栓剂、乳膏、滴眼液）、注射用曲妥珠单抗（新增产线注册审评中）、重组胶原蛋白（设备调试中）
- 子公司苏豪逸明（多肽原料药）：醋酸特利加压素已获批上市、醋酸奥曲肽获 CEP 证书、卡贝缩宫素与醋酸去氨加压素递交上市申请
- 独家代理：晟诺娃（长效绒促卵泡激素 α N01 注射液，宝济药业 2659.HK，辅助生殖）、维臻高（注射用隆培生长激素，维昇药业 2561.HK，2026-07 全国首批处方）、小金娃（枸地氯雷他定口服溶液，2026-07 达成独家经销）

主要客户/下游：儿科内分泌 / 生长发育门诊、辅助生殖中心、三甲医院与大量私立诊所（生长激素历史上私立渠道占比约 67.1%）、皮肤科与抗病毒用药科室。客户极度分散，无单一大客户依赖。

境内外收入占比（2026H1）：中国大陆 10.46 亿（99.66%），境外收入不足 0.4%——几乎纯内销，这是一把双刃剑：不用承担出海合规成本，但也享受不到海外定价。

股东背景 / 治理：实控人兼董事长宋礼华（创始人）。2026 年引入双高管：窦昌林博士任联席 CEO 兼首席科学官（统筹创新药研发体系）、袁春任联席 CEO 兼首席商务官。2026H1 受让鑫华坤 20.088% 股权（持股 73.22%→93.30%）、受让瀚科迈博 11.96% 股权、对外投资泌光生物 2000 万取得 40% 股权。参股博生吉安科（CD7-CAR-T「PA3-17 注射液」）、元宋生物（溶瘤腺病毒 YSCH01）。

（3）产业链传导

上游（培养基、层析填料、药用辅料、预灌封注射器/卡式瓶、中药材、多肽原料）：公司原液自产，成本端敏感项主要是包材（预灌封/卡式瓶）与中成药中药材。中药材 2025–2026 年整体偏强，直接压制中成药毛利率（−6.66pct 可作印证）。

下游（医院、私立诊所、患者）：行政定价主导。议价权判定：弱——集采与医保谈判是外部定价，公司无法把上游成本上涨转嫁给终端，只能通过内部降本消化。

产业链位置：中游制造 + 自研，品牌与渠道在儿科内分泌科有一定沉淀，但定价权不在自己手里。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）
- 生物制品线：传导系数 ≈ 0（行政定价，成本涨了自己扛），但通过「原液自产 + 收率提升 + 包材国产化」内部消化 → 2026H1 毛利率 82.45%（−0.41pct），几乎无损传导，等效传导率约 0.95（内部化）。
- 中成药线：传导系数 ≈ 0.2（外用贴膏属 OTC/普药，中药材涨价只能小幅提价，且提价即丢量）→ 毛利率 −6.66pct，是本次毛利塌方的全部来源。
- 依据：生物制品与中成药毛利率变动的巨大分化（−0.41pct vs −6.66pct）本身就是两条线传导能力差异的直接证据。

因子2 毛利结构再平衡（分业务线，禁单一综合毛利率）

业务线 2025H1 毛利（测算） 2026H1 毛利 毛利占比变化
生物制品 约 8.03 亿 6.874 亿 86.9% → 88.72%（+1.8pct）
中成药 约 1.21 亿 0.843 亿 13.1% → 10.88%（−2.2pct）

→ 结论：综合毛利率 75.82% 掩盖了结构迁移——中成药这条低传导、高波动的线正在快速萎缩，利润贡献向生物制品集中。第四步的毛利率假设必须分线给：生物制品按 82.5% 稳住、中成药按 76% 承压不再回升。

因子3 库存与采购节奏（timing）
- 存货周转率 0.48 次（2026H1），2025 全年 2.34 次，处于正常季节性水平；未发现低价囤货带来的虚高毛利。
- 应收账款周转率 1.33 次（H1），2025 全年 6.23 次，回款节奏正常。
- 正面信号：合同负债较期初 +56.25%（预收货款增加），说明下游打款意愿未恶化。
- 结论：2026H1 的 82.45% 毛利率是真实盈利能力，不是库存收益，可用于第四步假设。

因子4 政策 / 市场锚点（原料成本驱动变量）
| 变量 | 情景假设 | 验证点 | 证伪信号 |
|---|---|---|---|
| 中药材价格（中成药成本） | 中性：高位震荡；悲观：继续上行 10% | 中药材天地网综合指数季度走势 | 指数突破前高且中成药毛利率跌破 73% |
| 预灌封/卡式瓶包材 | 中性：国产替代推进、单价年降 3–5% | 公司预充式产线爬坡公告、包材招标价 | 包材涨价且生物制品毛利率跌破 80% |
| 医保适应症限定（需求侧准入门槛） | 中性：2027 前维持 GHD 限定；乐观：放宽至 ISS | 2027 版医保目录调整方案 | 2027 目录未放宽且公立渠道放量不及预期 |
| 生物医药「新兴支柱产业」定位（补贴/审评） | 中性：延续支持 | 公司政府补助金额、获批品种数 | 补助大幅退坡 |

→ 喂给第四步：生物制品毛利率 2027–2029 按 82.5% 假设（稳住不回升）；中成药毛利率按 75% 假设（继续小幅承压）；代理新品因毛利率低于自产，单独按净利口径测算。

第三步进阶：份额变量与主业迁移空间（三层法）

层1 现有业务：市场容量 × 份额变量（五锚点 + 三档）

锚点 现状 判断
① 供给侧份额 安科在生长激素细分份额约 10–15%（生物科技板块市占 7.47%，该口径含非生长激素） 第三梯队，前有长春高新全剂型矩阵
② 需求侧/客户份额 无大客户依赖；安苏萌全剂型进医保、粉针 4.5IU 医保支付价同类最低（1.5mg 规格 74.17 元/盒） 公立渠道准入在加速
③ 技术代际差 短效（粉针+水剂）自产，长效靠代理维臻高 + 自研 AK2017（III 期） 落后一代，长春高新已粉/水/长效全矩阵，还在研月制剂与口服
④ 成本曲线位置 生物制品毛利率 82.45% vs 长春高新 83.54% 成本曲线接近，但规模劣势使单位费用更高
⑤ 份额二阶导数 2026H1 生物制品 −13.98%，而行业生物科技板块 −3.0% → 跑输 11pct 份额正在流失，S 曲线处于被挤压段

三档假设（2027–2029 存量生物制品营收）：
- 保守守住：年 0%，2029 年 16.3 亿（市占继续小幅流失，被价格战对冲）
- 中性小幅修复：年 +2.4%，2029 年 17.5 亿（医保放量对冲降价，份额止跌）
- 乐观抢份额：年 +7%，2029 年 19.9 亿（CR3 集中 + 长效代理放量）
→ 验证点：单季生物制品营收同比转正、维臻高在公立医院准入数量、CR3 是否升至 80%+。证伪信号：生物制品营收连续 3 个季度同比降幅扩大、销售费用压缩但收入未止跌。

层2 扩展业务：主业迁移空间（五点）
1. 能力可迁移性：高。儿科内分泌 / 生长发育 / 辅助生殖科室的学术推广团队、医院准入关系、冷链与处方药渠道，可直接复用到晟诺娃（辅助生殖）、小金娃（儿科抗过敏）——这是「同一批医生、同一批科室」的迁移，迁移成本极低。
2. 新 TAM 弹性：大。辅助生殖用药 + 儿科抗过敏 + 长效生长激素，合计对应的国内市场规模是现有短效生长激素自产业务的 2–3 倍。
3. 切入卡位：早期。晟诺娃、维臻高均为 2026 年才启动商业化，赛道未红海。
4. 认证门槛：中。代理品种已完成 NMPA 获批，无需重新做临床，但需逐院准入（6–12 个月周期）。
5. 信号验证：维臻高 2026-07 全国首批处方（已过）；但「新品类营收占比跳升」这一硬指标尚未通过（2026H1 公司明确披露新品「收入贡献有限」）。
→ 定性：中期期权，未过验证点，不计入中性锚，仅计入乐观情景。

层3 风险折扣：证伪信号清单
- 生物制品营收同比降幅连续 3 季度扩大 → 下调份额假设至「保守守住」
- 3 个代理品种 2027 年合计营收占比未达 8% → 迁移期权归零
- 销售费用率已压至 27.2%（2.99/10.98），继续压缩空间有限 → 净利降幅将向营收降幅收敛（即恶化）
- 中成药营收跌破 2 亿/年 → 该板块毛利贡献进一步萎缩

第四步：估值锚定（自下而上，非增速外推）

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正1 资产质量折扣：PB 3.17，远高于 1，不存在破净，无需解释破净原因。反向检查 PB 是否泡沫化：2025 年加权 ROE 17.50%，PB 3.17 ÷ ROE 17.50% → 隐含 PE 18.1x，与 PE(TTM) 19.23x 基本一致 → PB 与 ROE 匹配，不存在估值泡沫。资产质量佐证：总资产 51.26 亿、净资产 42.60 亿、资产负债率约 14.6%、有息负债仅 0.33 亿（2025 年报）、无有息负债压力、经营现金流 2025 年 8.63 亿（净利现金含量 115.51%）。资产质量优，PB 高是 ROE 高的结果。

校正2 周期位置校正：生物制药非典型强周期，但公司正处在「政策降价周期」的中后段——2022 年广东联盟集采（首次）、2024 年多省扩面、2026-01 长效进医保（最大幅度降价）已全部落地。当前周期位置判断：政策冲击的中后段、接近价格底部区域。中性净利 7.0 亿对应的是「降价已充分反映 + 新品爬坡」的稳态，不是周期顶部的乐观年景，符合周期归一化要求（未使用单年好年景，也未把 2023 年 8.47 亿的历史峰值当基准）。

校正3 杠杆下行情景：资产负债率 14.6%、有息负债 0.33 亿，几乎零杠杆，经营杠杆与财务杠杆双高的风险不适用。下行情景的来源是政策（降价扩面）而非资产负债表——悲观情景（5.93 元，−26.5%）不会因杠杆被放大成资不抵债，这是本股相对其他医保受损标的的重要安全垫。

期权纪律：AK2017（III 期）、AK2024（I 期）、参股 CAR-T/溶瘤病毒、东区二期产能——全部未过硬验证点，不计入中性净利，只在乐观情景体现。

交叉校验：现价 8.07 元 / 2026E 净利 6.80 亿 → 2026E PE 19.9x；对应 2029E 中性净利 7.0 亿 → 前瞻 PE 19.3x。对一家 ROE 17.5%、资产负债率 14.6%、但营收仍在下滑的生物制药公司，19–20x 属于「不贵也不便宜」的合理区间——市场已经把「集采砸业绩」这件事定价了，但还没有给「代理新品放量」任何溢价。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低，但缺乏向上弹性。现价 8.07 元对应 2026E PE 19.9x、PB 3.17x（隐含 PE 18.1x），位于公司自身与生物制药板块的估值低位。但「便宜」不等于「有空间」——2029E 中性净利 7.0 亿仅比 2025 年的 7.35 亿略低，意味着未来三年公司大概率是「利润先降后平」，估值弹性才是主要收益来源。

安全边际：
- 中性远期 9.64 元 → 空间 +19.5%，不达「重点关注」>50% 的门槛
- 悲观 5.93 元 → 下行 −26.5%（零杠杆使下行不至于失控）
- 乐观 14.21 元 → +76.1%，需医保适应症放宽 + 代理品种大超预期
- 下行硬支撑：净资产 42.60 亿 / 16.71 亿股 = 每股净资产 2.55 元，若跌至 PB 2.5x（对应股价 6.4 元、2026E PE 15.7x）为较强支撑区；现金与无有息负债意味着「跌不动到破产」

介入条件（具体价格）：
1. 7.0 元以下（2026E PE < 17.3x、PB < 2.75x）具备安全边际，可分批建仓
2. 加仓信号：① 生物制品单季营收同比转正（份额流失止住）；② 三个代理品种单季合计营收占比 >8%；③ 2027 版医保目录将 ISS 纳入报销
3. 观察指标：逐季「生物制品营收同比」与「销售费用率」——若销售费用率已降至 27% 以下而营收仍双位数下滑，说明压费用换利润的空间耗尽，中性情景需下修

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 份额持续流失（首要）：2026H1 生物制品 −13.98% vs 行业 −3.0%，跑输 11pct，说明公司不是「行业不行」而是「自己被抢份额」。长春高新降价 75% 后，安科的低价优势被大幅削弱。
2. ⚠️ 压费用撑利润不可持续：销售费用已 −24.44% 至 2.99 亿（费用率 27.2%），净利降幅小于营收降幅全靠这一项。2027 年新品推广期销售费用必然回升，届时净利与营收降幅将收敛（即净利降幅扩大）。
3. 代理新品兑现慢：公司自己在中报里明确写「新品整体尚处于市场培育初期……暂未形成足够销售规模对冲存量业务波动」——这是管理层给出的、最权威的兑现节奏警告。
4. 长效代际落后：公司长效靠代理 + 自研 III 期，而行业 2030 年长效占比将达 73.8%。若 AK2017 进度落后，公司将被锁死在低价值的短效市场。

第五步进阶：上行想象力情景（四类）

类型A 行业调整剩者红利：集采+医保把价格打到低位后，中小厂商与无规模优势的玩家退出，生长激素 CR3 已从 70% 升至 75%。用层1 的份额变量锚定上行：若 CR3 继续升至 80%+ 且安科凭「全剂型进医保 + 同类最低价」守住并小幅提升份额，存量生物制品营收可回到 19.9 亿（乐观档，对应 2029E 净利 8.2 亿）。
- 验证点：CR3 数据、安科生物制品单季营收同比转正、公立医院准入数量。证伪信号：份额继续流失、营收降幅扩大。

类型B 政策反转期权：医保报销适应症目前严格限定 GHD（发病率约 1/10000–1/4000），而 ISS（特发性矮身材）占矮小症群体的 60–80%，尚未纳入医保。若 2027 版医保目录放宽至 ISS，可报销人群将数倍扩容，是最大的单一上行变量。
- 重估弹性测算：ISS 若纳入，按行业渗透率提升 3–5pct 测算，2030 年市场规模可上修至 350 亿以上（vs 286 亿基准），安科对应营收弹性 +30–40%。
- 验证点：2027 版医保目录调整方案、医保局关于适应症的表态。证伪信号：2027 目录未放宽、或新增更严格用药前检查要求。→ 未过验证点，仅作机会情景，不计入中性锚。

类型C 市场错杀修复：当前 PE(TTM) 19.23x、PB 隐含 PE 18.1x，处于公司历史与医药板块的估值低位分位；公司 ROE 17.5%、资产负债率 14.6%、2025 年经营现金流 8.63 亿，基本面并未出现资产负债表恶化（总资产与净资产下降是分红与大额对外投资所致，非经营塌陷）。若医药板块风格回归，估值修复至 25x 对应市值 175 亿（10.47 元，+29.7%）。
- 验证点：医药板块估值分位回升、公司营收降幅收窄。证伪信号：营收降幅扩大（那不是错杀，是真杀）。→ 机会情景。

类型D 技术突破 / 技术代际跃迁期权：AK2017（重组人生长激素-Fc 融合蛋白）ISS 适应症已完成 III 期入组、GHD 适应症启动 III 期；AK2024 被定义为曲妥珠单抗及 HER2-ADC 的潜在最佳「Booster」，2026 AACR 壁报。三要素共振检查：① 政策驱动（创新药支持、生物医药列为新兴支柱产业）✔；② 行业趋势向长效收敛（2030 年长效占比 73.8%）✔；③ 公司技术投产落地——III 期完成入组但未读出数据，未拿到达标良率/客户定点等价验证 ✘。
- 硬验证点：AK2017 III 期数据读出达标 + 上市申请获受理 + 生产成本优于现有长效路线。
- 证伪信号：III 期数据不及预期、研发进度延期、AK2024 II 期失败。→ 三要素缺一，只作机会情景，不计入中性锚。

纪律声明：以上四类想象情景全部只进乐观/机会栏，不进中性锚。中性 9.64 元只由「存量企稳 + 代理新品 5 亿 + 中成药自然衰减」构成。

什么条件出现才上调至「重点关注」：① 三个代理品种合计营收占比 >15% 且 生物制品单季营收同比转正；② AK2017 III 期数据读出达标并递交上市申请；③ 生物制品毛利率企稳回升至 83% 以上。三者中至少两项同时满足时，远期空间有望上修至 +50% 以上，届时上调结论。

结论：纳入观察

理由：中性远期空间 +19.5%，不满足「重点关注」>50% 的门槛；悲观情景存在 −26.5% 下行，赔率不够吸引。但公司质地确实扎实（ROE 17.5%、资产负债率 14.6%、有息负债仅 0.33 亿、经营现金流优秀、零杠杆使下行不致命），且 2026Q2 单季归母已同比转正 +4.59%，说明最坏的降价冲击可能已在 2026H1 出清。
这是一家「不会死、但当下也跑不快」的公司，机会在于代理新品能否在 2027 年兑现——这是唯一的观察锚点。
核心跟踪点：（1）逐季生物制品营收同比是否止跌；（2）维臻高 + 晟诺娃 + 小金娃合计营收占比；（3）2027 版医保目录是否放宽 ISS 适应症。
