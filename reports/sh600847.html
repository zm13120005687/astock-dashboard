第一步：公司是干什么的？

一句话定位：中国铅酸蓄电池行业首家上市公司（前身 1943 年重庆蓄电池总厂，1994 年上市），一家产品高度单一（铅酸蓄电池占收入 96%）、主业持续萎缩、正试图借锂电 / 光储充转型的"壳型"小市值公司。

主营地区构成（2026H1）：境内 2.11 亿元（99.16%）；境外 178.42 万元（0.84%）——几乎纯内销，且高度依赖汽车起动启停市场。

核心产品与应用：铅酸蓄电池（AGM、EFB、驻车空调、免维护等系列），配套汽车起动启停领域；亦应用于电动自行车、电动三轮车及储能等。拥有"万里""华丰""力比得"等注册商标，通过 IATF16949 等体系认证，配套多家汽车制造企业。

（3）产业链传导——原料成本 → 毛利结构（四因子）

公司的核心"原料"是铅（含再生铅）与塑料外壳、隔板、电解液；铅价占铅酸蓄电池成本的 60% 以上。产品端极度单一（96.31%），故毛利结构高度取决于铅价与售价的错配。

因子 1｜成本传导弹性（pass-through）
- 铅酸起动电池（占收入 96.31%）：面对整车厂（Tier1 转嫁链）与替换市场，行业价格战激烈、规模小无议价权，传导率≈0.2–0.3（弱）——铅价上行时公司自行消化。2026H1 毛利率 3.44%（−1.79pct）、Q2 仅 1.52% 即为佐证。
- 替换市场（售后）：价格敏感度稍低，传导率≈0.4–0.5，但公司规模小于骆驼股份等龙头，话语权弱。
- → 加权传导率约 0.25–0.35（弱），这是公司长期微亏的结构性原因。

因子 2｜毛利结构再平衡（分业务线敏感度）

业务线 收入权重 毛利率 铅价敏感度 利润贡献权重
铅酸蓄电池 96.31% 2.9% 极高（铅占成本 60%+） 绝对主体但近乎不赚钱
新能源（锂电 / 光储充） 不足 4% 未单列（投入期） 低 负贡献（研发投入）

结构迁移要点：公司几乎没有"毛利结构"可言——96.31% 的收入来自一个毛利率不足 3% 的单一产品，不存在"高毛利产线对冲低毛利产线"的再平衡空间。唯一的边际变量是新能源业务能否从"负贡献"转为"正贡献"，而这尚未验证。禁止用"未来锂电转型成功"代表当期盈利能力。

因子 3｜库存与采购节奏（timing）
- 铅价波动直接影响成本：若低价囤铅，当期毛利虚高；若高价接货，当期毛利承压。公司未披露铅的长协 / 套保安排，构成主要不确定源。
- 行业库存快速去化（2026Q1 期末库存 −46.18%）——行业主动去库存，说明下游需求疲弱。
- 公司存货周转率 2025 年 4.27 次，周转较快，无明显囤货型虚高毛利。
- → 当期与远期毛利可比性尚可，但 2.9% 的毛利率本身已在盈亏线附近，任何铅价上行都会立刻转负。

层 2｜扩展业务：主业迁移空间（铅酸 → 锂电 / 光储充）
- 能力可迁移性：低——铅酸电池与锂电池在材料、工艺、BMS 上技术不通用，属跨技术路线而非同源迁移。
- 新 TAM 弹性：大——储能 / 光储充 / 换电市场空间远超铅酸起动电池。
- 切入时点与卡位：极晚——2025 年才通过收购普凯世纪储能切入，红海竞争、无先发优势。
- 客户认证门槛：高——储能 / 车用锂电需长周期认证与产能背书，公司无产能、无认证。
- 信号验证：目前为零（无标的盈利数据、无订单、无量产）。
- → 按纪律，该迁移空间不计入中性情景，仅放乐观情景。

层 3｜风险折扣：证伪信号
1. 铅酸收入连续多季双位数下滑。
2. 毛利率跌破 2%（已在 Q2 触及 1.52%）。
3. 普凯世纪储能收购未完成，或完成后标的持续亏损。
4. 资产注入预期长期无任何公告。

命中任一项，对应增量剔除。

合计增量（中性口径）：铅酸主业稳态微利 + 新能源小幅贡献 → 2029 年稳态营收约 5.5 亿元，正常化归母约 0.22 亿元。

第四步：估值锚定（自下而上，非增速外推）

方法说明：公司当前亏损（连续 5 年），无正净利可锚，采用正常化净利润法：①估稳态营收（现有产能 + 已布局新业务）；②算正常化净利率（行业平均 / 公司历史最好 / 理论值，三者取保守）；③正常化净利 × 远期合理 PE。不使用历史增速外推，普凯世纪储能与资产注入只放乐观情景。

总股本：153,287,400 股（约 1.5329 亿股） ｜ 2026H1 末归母净资产 4.57 亿元（每股净资产约 2.98 元），2025 年末资产负债率仅 12.90%、现金比率 160%，累计未分配利润约 −4.2 亿元。

正常化归母取 0.22 亿元（对应稳态毛利率需从当前 3.44% 回升至约 9–10% 才能实现，属保守但需改善的前提）。

  • H1 已亏损 3666.34 万元；H2 铅酸淡旺季差异不大，新能源投入持续。
  • 2026E 归母仍亏损约 −0.65 亿至 −0.80 亿元，取 −0.70 亿元。

亏损股三问

问 1｜为什么亏？
1. 主业结构性衰退：铅酸蓄电池在乘用车新车配套领域面临趋势性需求压缩（新能源乘用车渗透率超 50%），2026H1 铅酸收入 −14.61%。
2. 行业产能过剩 + 价格战：竞争持续内卷，公司规模小、毛利率仅 2.9%，Q2 单季仅 1.52%，已无利润空间。
3. 转型投入吞噬利润：2026Q1 研发费用 578.19 万元，已超 2025 年全年的 309.80 万元（同比 +439.94%）。
4. 收入下滑致固定成本摊薄压力加大：亏损逐季加剧（Q1 −1440 万 → Q2 −2226 万）。

问 2｜靠什么扭亏？触发时点在哪一年？
- 路径 A（主）：铅酸主业毛利率修复——需综合毛利率从当前 3.44% 回升至 9–10%（铅价平稳 + 产品结构向替换市场 / 高附加值型号倾斜），但在行业价格战下难度极大，触发窗口 2027–2028 年。
- 路径 B：新能源 / 光储充业务放量——收购普凯世纪储能（光储充一体化）+ 万锂再生资源（再生铅回收），但标的规模与盈利未披露，且属红海竞争，触发窗口 2028–2029 年（未验证）。
- 路径 C：资产注入 / 借壳重组——莫天全（房天下 / 中国家居控股）背景下的资产运作，无方案、无时间表，触发时点不可预测。
- 盈亏平衡点测算：按 2026H1 毛利率 3.44%、期间费用相对刚性，公司需铅酸毛利率回升至约 9–10% 或收入规模恢复至 6.5 亿元以上才能覆盖固定成本 + 研发费用 → 中性假设下 2028 年前难以稳定盈利。

问 3｜亏得起吗？
- 财务上"亏得起"：资产负债率仅 12.90%（2025 年末），有息负债率 2.07%，流动比率 5.70、现金比率 160.03%，归母净资产 4.57 亿元——无债务危机之虞。
- 但造血能力弱：2026H1 经营现金流 −3845.04 万元，且净流出收窄源于业务收缩而非经营性改善。
- 无退市风险：每股净资产 2.98 元、净资产为正，不触及退市风险警示。
- → 结论："亏得起"——低负债 + 4.57 亿元净资产可支撑多年亏损，短期内无生存危机；但这是一家"靠家底活着"的公司，主业造血能力持续弱化。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1｜资产质量折扣（PB 4.31，非破净而是极高溢价）
- 公司不破净，反而 PB 高达 4.31x——归母净资产 4.57 亿元，市值 19.70 亿元。市场为"重组预期"支付了 4.3 倍净资产。
- 资产质量：公司资产以固定资产（蓄电池产线）+ 应收账款 + 存货为主；累计未分配利润约 −4.2 亿元（每股未分配利润 −2.75 元），历史持续吞噬净资产。
- → 结论：4.31x PB 毫无基本面支撑，其溢价完全来自未验证的重组 / 转型期权。 一旦期权落空，估值将向净资产（2.98 元/股）回归，对应 −77%。

校正 2｜周期位置校正（中性净利用正常化口径）
- 铅酸蓄电池属衰退型成熟行业，当前处于结构性下滑段（不是周期性底部，而是趋势性压缩）。
- 中性净利禁止用：①单季 / 单年最好水平年化（公司近 5 年均亏损）；②"行业复苏"假设。
- 本报告采用稳态营收 5.5 亿 × 保守正常化净利率 4%，得归母 0.22 亿元——该口径要求毛利率从 3.44% 回升至约 9–10%，本身已隐含改善假设，属乐观偏保守的取值。
- 当前"周期位置"：结构性衰退中段（非周期底部，不宜按周期股底部给弹性）。

校正 3｜杠杆下行情景
- 资产负债率仅 12.90%，财务杠杆极低，无债务反噬风险——这是本股唯一的强保护。
- 但经营杠杆高：固定成本 + 研发投入刚性，收入下滑即放大亏损（2026H1 已现）。
- → 因杠杆低，负面情景即使空间极负，也不构成"坚决回避"（公司有真实业务、真实资产、无债务危机）；但因中性空间深度为负，结论上限为"暂不介入"。

期权纪律：普凯世纪储能（光储充）、万锂再生资源（再生铅回收）、锂电 / 换电业务、大型游乐设施、莫天全资产注入——五项均为未过验证点的期权，一律不计入中性净利，只放乐观情景。

第五步：综合赔率判断（买不买？）

当前价格位置：显著高估。现价 12.85 元对应 PB 4.31x、PS(TTM) 约 4.14x；按 2029E 中性正常化归母 0.22 亿元计算 PE 高达 90x。市场完全按"重组 / 转型期权"定价，而铅酸主业在持续萎缩、亏损逐季扩大。

安全边际：
- 中性远期 3.59 元 → 空间 −72.1%，深度负空间，不满足"纳入观察"的 >0 门槛
- 悲观情景 2.39 元 → 下行 −81.4%（向净资产回归）
- 乐观情景 13.70 元 → +6.6%（需普凯世纪储能放量 + 资产注入双实现）
- 下行保护：资产负债率 12.90%、现金比率 160%、无有息负债压力——但净资产仅 2.98 元/股（对应 −76.8%）

介入条件：
1. 不追高。现价 12.85 元距中性合理价 3.59 元有 72% 下修空间，当前毫无基本面安全边际，纯属期权博弈。
2. 重新评估的信号（出现任一才考虑上调）：① 铅酸主业单季毛利率回升至 8% 以上且收入止跌；② 普凯世纪储能收购完成并披露标的盈利数据、开始贡献正利润；③ 莫天全正式公告资产注入 / 重大重组方案（这是唯一可能支撑 4.3x PB 的事项）；④ 经营现金流持续转正；⑤ 现价回落至 4 元以下。
3. 观察指标：铅酸季度销量与毛利率、新能源业务收入占比、经营现金流、是否有重组公告。

最大风险（最可能破坏逻辑的因素）：
1. 估值全靠未验证的重组期权（首要）：PB 4.31x、90x 正常化 PE，一旦重组预期落空，估值向净资产（2.98 元）回归，下行 −77%。
2. 主业结构性衰退不可逆：铅酸在乘用车新车配套领域被锂电趋势性替代。
3. 亏损逐季加剧：Q1 −1440 万 → Q2 −2226 万，转型投入进一步吞噬利润。
4. 转型缺乏技术积累：铅酸→锂电属跨技术路线，公司无产能、无认证、无客户，红海竞争。
5. 历史重组两度受挫：2022–2023 年特瑞电池重组终止，与老股东诉讼仲裁未了结。

结论：暂不介入

理由：中性远期空间 −72.1%，悲观下行 −81.4%，风险收益高度不对称偏负。
公司不属于"坚决回避"：它仍有真实业务（铅酸蓄电池，中国首家上市蓄电池企业）、真实资产（4.57 亿元净资产）、稳健财务（资产负债率 12.90%、现金比率 160%、无有息负债压力），且存在真实的转型动作与实控人资源（莫天全），并非无实质业务的纯概念股。
但投资与"赌重组"是两回事：现价 12.85 元对应 PB 4.31x、正常化 PE 90x，已把"重组成功"的期权按接近兑现的价格定价；而主业在结构性衰退、亏损逐季加剧、转型无技术积累。以当前价格买入，赔率极差。
核心跟踪点：是否有实质重组公告、普凯世纪储能经营数据、铅酸毛利率、经营现金流。
