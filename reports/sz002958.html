（3）产业链传导（银行的"原料—产品"链条）

上游（负债端／"原料成本"）：存款是银行的核心原材料。2026 年两轮存款利率自律下调 + 长期高息存款到期重定价 → 负债成本改善。本行净息差逆势 +2BP 至 1.62%，优于农商行同业，说明负债成本管控见效。

下游（资产端／"产品收入"）：贷款投放对象为青岛及山东区域的中小微、涉农主体与房地产链企业。LPR 持续低位 + 信贷需求偏弱 → 资产收益率下行，导致营收 −7.57%。规模扩张（贷款 +2.45%）不足以对冲价格下行（净息差在低基数上仅微升）。

议价权判断：弱。佐证：①农商行客群下沉，对大客户与优质资产缺乏定价权，只能通过利率竞争获客；②营收连续负增长说明"以量补价"失败；③在存款端受大行下沉挤压，付息成本刚性强于大行；④资产质量受区域经济（房地产链）约束。唯一相对优势是在支农支小再贷款口径下享有更低的资金成本（1.25%）。

第二步进阶：原料成本 → 毛利结构传导（四因子，银行口径适配）

因子 1 · 成本传导弹性（pass-through）
银行的"原料"为存款、下游"售价"为贷款利率。当前处于资产端收益率下行快于负债端成本下行的阶段：
- 资产端：LPR 低位 → 贷款收益率下行，传导即时
- 负债端：存款利率下行 → 但受"存款定期化 + 客户粘性"制约，改善滞后 1~2 个季度，且单次下调幅度受自律机制约束
→ 实测"负债成本改善留存率"约 0.5~0.6（即资产端收益率每下行 10BP，净息差约承压 4~5BP）。本行 2026 年通过存款到期重定价实现净息差 +2BP，传导效率优于同业，是本票少数正面变量。

因子 2 · 毛利结构再平衡（收入结构）
银行无"分产品毛利率"，但有收入结构：利息净收入（主体）+ 手续费及佣金净收入 + 投资收益。
- 营收 −7.57% 但利润总额 +8.77% → 说明非息收入（债券投资收益等）与费用管控对利润形成对冲
- 结构迁移方向：从"利差依赖"向"非息 + 轻资本"迁移仍处早期
→ 关键提示：禁止用"综合净利润率 41.28%"（=21.95/53.16）代表银行真实盈利能力——该比率异常高，正是拨备反哺的结果，反映的是减值计提节奏而非经营效率。

因子 3 · 库存与采购节奏（timing）
银行的"库存"有两项：
- 债券投资组合：利率下行期浮盈 → 兑现为投资收益可补充非息收入（当期 vs 远期可比性差）
- 拨备余额（减值准备）：这是最关键的 timing 项。 本行拨备覆盖率半年内下降 36.12pct，消耗约 18 亿元拨备支撑利润。这属于典型的"用存量缓冲垫补当期利润"，必须与真实盈利能力区分——若按上年末 261.01% 的覆盖率回溯，2026H1 归母净利将显著低于 21.95 亿元。
→ 严禁把拨备反哺当作真实盈利趋势。 本报告 2029E 中性净利已假设拨备覆盖率稳定在 220%~240% 区间，不继续释放。

层 2 · 扩展业务：主业迁移空间（新易盛范式）
银行的"迁移"= 从重资本利差业务向轻资本中间业务迁移（财富管理、交易银行、结算、投行）。
- 能力可迁移性：客户基础与账户体系可复用 ✓
- 新 TAM 弹性：中间业务（不消耗资本、不占风险资产）空间大 ✓
- 切入时点与卡位：早期，且明显落后于头部城商行（如宁波、江苏银行）✗
- 客户认证门槛：无"认证"概念，但需牌照与投研能力积累 ✗
- 信号验证：手续费及佣金净收入占比未披露 → 未过验证点
→ 结论：轻资本迁移空间仅作中期期权，不计入中性。

第四步进阶：重资产 / 周期股估值校正（三道闸）

校正 1 · 资产质量折扣——⚠️ 破净原因必须逐项说明

本票 PB 0.43x，属典型破净股。按纪律，严禁单凭"PB<1"直接推导"空间大"。破净原因逐项排查：

排查项 结论
① 资产盈利能力 ROE 7.94%（2025）、10.72%（2026H1 年化），中等偏低，但并非无盈利能力；PB 0.43 隐含市场认为其 ROE 不可持续
② 资产专用性 银行贷款资产不可转产、清算价值远低于账面，重置成本不兜底 → 破净具公允性成分
③ 隐含负债 拨备覆盖率从 261.01% 骤降至 224.89%，风险缓冲显著收窄，净资产质量存在瑕疵；另有对公房地产历史包袱（最高不良率 23.00%）
④ 金融资产未重估型真破净 不适用。本行债券投资以摊余成本/公允价值计量，不存在"持股上市公司市值≈总市值"式的未重估金融资产
⑤ 区域与股东风险 经营区域高度集中于青岛/山东，与房地产链绑定；原主要股东巴龙系债务处置事件（涉 9 亿元）
⑥ 流动性与板块折价 农商行板块整体折价（常熟约 0.8x、苏农约 0.6x），本行 0.43x 处板块底部

→ 结论：本行的破净"部分公允、部分折价"。 公允部分：区域集中、拨备消耗、营收负增长；折价部分：市场对历史包袱的过度惩罚（房地产不良已从 23.00% 压降至 3.31%）。因此本报告中性情景仅允许 PB 维持 0.45x（不修复），"修复至 0.6x 同业水平"被严格归入乐观情景。 这一处理与"银行估值修复属行业 beta、不计入中性"的期权纪律一致。

校正 2 · 周期位置校正
银行业当前周期位置判定：息差下行周期的尾部（底部企稳）。
- 商业银行净息差 1.40%（2026Q1）为历史低位；农商行 1.58%（2026Q1）亦处低位
- 但拐点信号已现：2026 年 1 月结构性降息（支农支小 1.25%）、两轮存款利率自律下调、长期高息存款到期重定价 → 负债成本改善通道已打开
- 本行净息差 1.62%，较年初 +2BP，已先于同业企稳
→ 中性净利必须用归一化净息差（1.60%~1.70%），禁止用单年最好年景，也不过度悲观。本报告未假设息差继续上行，属保守处理。

校正 3 · 杠杆下行情景
银行资产负债率 91.35%（存款即负债，为行业常态，非异常）。但银行是高杠杆经营体，资产端 1% 的损失可吞噬 10% 以上的净资产。
→ 负面情景：若区域房地产风险二次暴露（对公房地产不良率从 3.31% 反弹至 10%）+ 零售贷款质量恶化，需大幅补提拨备，2029E BPS 降至 8.30 元、PB 压至 0.34x → 目标价 2.82 元（−4.1%）。
→ 该负面情景下远期空间转负（−4.1%），故本报告不标"大空间/重点关注"，仅给"纳入观察"并注明其低估值防御属性 + 有限下行。

期权纪律：
- 银行估值修复（PB 0.43x → 0.60x）属行业 beta，未过验证点，不计入中性 NAV；
- 轻资本中间业务迁移（未披露手续费收入占比）不计入中性；
- 中小银行合并重组预期不计入中性。

第五步：综合赔率判断（买不买？）

当前价格位置：低估（PB 0.43x），但低估有原因，属"折价型低估"而非"错杀型低估"。现价 2.94 元对应 2026E PE 约 5.0x、PB 0.43x，处农商行板块底部；相对净资产折价 57%。但营收 −7.57%、拨备覆盖率半年降 36.12pct，折价有基本面依据。

安全边际：
- 中性远期 4.05 元 → +37.8%（三年，年均约 11%，叠加约 4% 股息率 → 年化约 15%）
- 悲观情景 2.82 元 → −4.1%，下行极其有限（低估值 + 拨备仍厚 + 风险已出清大半）
- 乐观情景 5.77 元 → +96.3%，需营收转正 + 估值修复
- 下行保护：PB 0.43x、每股净资产 6.84 元、2025 年每股股利 0.12 元（股息率约 4.1%）、不良率稳定在 1.74%、对公房地产最大风险已出清（23.00%→3.31%）
- 风险收益结构：下行约 −4%、上行约 +38%（中性），赔率约为 9:1（以概率加权前）

介入条件：
1. 可小仓位配置型介入。现价 2.94 元处板块底部，破净 + 高股息提供防御；但不具备"重点关注"的进攻属性
2. 加仓信号：① 营业收入恢复正增长（单季同比转正）；② 拨备覆盖率止跌回升（重回 240% 以上）；③ 净息差连续两个季度走阔
3. 观察指标：逐季拨备覆盖率（当前 224.89%）与不良率（当前 1.74%）；2026 年 11 月巴龙集团股份司法拍卖结果（含流拍可能）

最大风险（最可能破坏逻辑的因素）：
1. ⚠️ 拨备反哺不可持续（首要）：2026H1 归母 +2.84% 是在营收 −7.57% 的背景下取得的，靠的是拨备覆盖率下降 36.12pct 释放的约 18 亿元缓冲。一旦拨备覆盖率降至监管安全线附近，利润将直接转负
2. 营收持续负增长：连续负增长（2025 年 −9.12%、2026H1 −7.57%）说明息差与规模双弱，"以量补价"失灵
3. 区域集中风险：经营区域绑定青岛及山东房地产链，对公房地产历史不良率曾达 23.00%
4. 股东与治理风险：巴龙系债务处置虽近尾声，但仍存股权拍卖流拍等不确定性
5. 高杠杆放大：资产负债率 91.35%，资产端 1% 的额外损失将吞噬超 10% 的净资产

结论：纳入观察

理由：①中性远期空间 +37.8%，满足"纳入观察"（>0）但不满足"重点关注"（>50%）；②按期权纪律，银行估值修复属行业 beta，不计入中性，中性仅假设 PB 维持 0.45x（不修复）；③破净原因逐项排查后判定为"部分公允、部分折价"，不得单凭 PB 0.43x 标大空间；④悲观情景下空间转负（−4.1%），故不得标"重点关注"，须注明高贝塔／低弹性防御属性；⑤但相对同业（0.6~0.8x）确有三成以上折价，叠加 4%+ 股息率与已出清大半的历史包袱，估值安全边际真实存在。
核心跟踪点：营业收入增速能否转正 + 拨备覆盖率能否止跌 + 净息差能否持续走阔。

- 结论：未过验证点，仅作机会情景，不计入中性锚

类型 B · 政策反转期权
本行是"政策反转"最典型的潜在受益者：被低息差与房地产链压制到底，政策转向（LPR 企稳回升、存款利率继续下调、房地产止跌回稳、化债落地）将触发息差反转与估值重估。
- 具体政策名：支农支小再贷款利率下调（1.25%）、存款利率自律机制、地方债务化解、房地产止跌回稳政策
- 反转信号：① 单季净息差同比转正；② 营收同比转正；③ 拨备覆盖率止跌回升；④ LPR 停止下行
- 重估弹性测算：PB 从 0.43x 修复至 0.60x（对标苏农银行）→ 对应股价 4.10 元（+39.5%）；修复至 0.80x（对标常熟银行）→ 5.47 元（+86.1%）
- 结论：未过验证点，仅作机会情景；但这是本票最主要的上行来源（已反映于乐观情景）

类型 C · 市场错杀修复
- 错杀证据（部分成立）：PB 0.43x 处历史低位与农商行板块底部、相对同业折价 30%+、不良率稳定、最大历史包袱（对公房地产不良率 23%→3.31%）已出清
- 错杀证据（不成立的部分）：营收 −7.57% 与拨备消耗 36pct 属基本面实质瑕疵，不是情绪错杀
- 修复触发点：市场风格回归低估值红利、银行板块整体估值修复、2026Q3/Q4 营收环比改善
- 结论：部分成立，已部分反映于中性情景的"维持 0.45x PB"，不额外计入

类型 D · 技术突破 / 技术代际跃迁期权
银行业无"技术路线从 0 到 1"的跃迁属性；数字普惠、AI 风控仅为效率工具，不构成竞争格局重构。
- 结论：不适用，不计入

什么条件出现才上调至重点关注：① 营业收入连续两个季度同比正增长；② 拨备覆盖率止跌并回升至 240% 以上；③ 不良率继续下行至 1.70% 以下；④ 净息差连续两季走阔。四项均为基本面硬条件，不靠股价下跌触发。
