第一步：公司是干什么的？

（3）产业链传导

上游：国际原糖（期货定价）、包材（PET、糖包）。制糖业为「采购原糖 → 精炼 → 销售」加工模式，原糖涨 → 成本几乎全额传导给公司，议价权弱。饮料上游为糖、包材，可通过品牌溢价部分转嫁。园区上游为物业折旧与运维，成本刚性弱。

下游：食品加工、餐饮、民用消费，需求平稳刚性强；园区租户需求受经济活跃度影响。

议价权判断：制糖 弱（加工型，原糖定价权在国际，毛利率仅 2.43% 佐证）；饮料 中（「广氏」区域品牌，44% 毛利但份额小）；园区 中（长协租约，但出租率下滑）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）
  • 制糖转嫁系数 ≈ 0.2：原糖涨 10%，公司仅能向客户转嫁约 2%，其余 8% 吃毛利（加工型无定价权，佐证毛利率 2.43%）。
  • 饮料转嫁系数 ≈ 0.5：品牌溢价可转嫁约一半，其余自担。
  • 园区转嫁系数 ≈ 0.8：租金长协，成本端（折旧/运维）波动小，毛利稳。

  • 验证点：原糖期货价格 vs 公司制糖毛利率；证伪：原糖大涨而制糖毛利率未破 2% 则传导系数被低估。

  • 因子2 毛利结构再平衡

  • 制糖占收入 68% 但仅贡献毛利 7.25×2.43% ≈ 0.18 亿；饮料占 21% 贡献 2.26×44% ≈ 0.99 亿；园区占 7% 贡献 0.77×21% ≈ 0.16 亿。
  • 原料敏感权重高度集中于制糖（68%）：原糖波动主要冲击这块「微利大饼」，对整体利润影响被饮料高毛利缓冲。

  • 禁单一综合毛利率：14.38% 综合毛利率掩盖「制糖微利 + 饮料厚利」结构；估值须分业务给净利率。

  • 因子3 库存与采购节奏

  • 低价囤货：原糖低位时建库 → 当期精炼毛利虚高；高价接货：原糖高位接货 → 毛利承压。
  • 公司 H1 经营现金流 2.07 亿（−37.94%，因支付银行承兑汇票货款），库存节奏影响当期可比性。

  • 验证点：季度制糖毛利率波动；证伪：毛利率异常跳升却无原糖跌价佐证 = 囤货收益非真实盈利。

  • 因子4 政策 / 市场锚点

  • 市场层：原糖期货（ICE No.11）、巴西中南部降雨、印度出口政策。
  • 政策层：进口关税配额、国储糖投放（托底/平抑）、厄尔尼诺减产预期。
  • 情景：原糖持续 >20 美分 → 制糖毛利承压（悲观）；国储投放 + 原糖回落 → 成本改善（乐观）。验证点：原糖期价、国储投放公告。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：国内食糖产量约 1000 万吨，公司为区域精炼商，份额小且稳定；饮料为区域小品牌，份额低。
  • 需求侧：食品加工/餐饮需求稳，无显著份额提升锚点。
  • 技术代际：制糖为成熟工艺，无代际差；饮料无技术壁垒。
  • 成本曲线：制糖加工型，成本受原糖主导，无显著左移空间。
  • 份额二阶导数：基本饱和（S 曲线尾部）。三档：保守守住 / 中性微增（饮料渠道拓展）/ 乐观（品牌放量）——均不支撑高弹性。
  • 层2 扩展业务：主业迁移空间
  • 无明确「旧池塘→新池塘」迁移；园区资产盘活属存量运营优化，非新 TAM 扩张。信号验证：未过（无新品类营收占比跳升公告）。→ 仅作中期期权，不计入中性。
  • 层3 证伪信号
  • 原糖持续高位 + 园区出租率续降 + 饮料收入加速下滑 → 中性情景下修。

第五步：综合赔率判断（买不买？）

当前价格位置：明显高估。现价 3.29 元已远超主业合理估值区间（1.2–1.4 元），PE 49.5x(TTM) 反映题材溢价。

安全边际：中性远期 1.20 元 → 空间 −63.5%；悲观 0.75 元 → −77.2%。下行风险大，几无安全边际。

介入条件：仅当回落至 1.4 元以下（对应主业 PE < 20x）且出现「园区资产重估落地 / 糖业周期实质传导 / 饮料收入提速」信号时，才具备配置价值。

最大风险：
1. 制糖毛利率仅 2.43%，原糖高位直接吞噬利润；
2. 园区租赁收入持续下滑（H1 −21.48%）；
3. 题材退潮后估值回归主业（59 亿 → 20 亿量级）；
4. 非经常性收益不可持续，扣非主业增长乏力。

结论：暂不介入

主业年化扣非净利仅约 0.9 亿，对应合理市值约 20 亿，现价隐含约 3 倍溢价。虽具园区土地隐性资产期权，但中性不计入，远期空间深度为负，不满足「重点关注 / 纳入观察」门槛。
