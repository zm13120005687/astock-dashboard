（3）产业链传导

上游：生猪/禽苗（农产品周期定价）、进口冻品（国际价）。价格低位 → 养殖端亏损，但贸易端成本降。

下游：餐饮/团餐/零售，需求稳但压价。

议价权判断：贸易 中（规模+国企信誉为基）；养殖种业 弱（周期品，无定价权）；冷链物业 中（区位稀缺）。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性
  • 冻品贸易转嫁系数 ≈ 0.4：进口价+渠道结构调整时，部分成本自担（H1 冻品收入 −18.53% 佐证承压）。
  • 养殖/种业转嫁系数 ≈ 0.1：周期品价格由市场定，几乎无传导。
  • 配送/物业 ≈ 0.7：服务合同可调价。
  • 验证点：猪价/进口冻品价 vs 公司毛利率；证伪：猪价涨而养殖毛利未修复。
  • 因子2 毛利结构再平衡
  • 冻品占 60% 但毛利薄且下滑；混合食材占 11% 高增（+38%）；种禽/肉猪占 16% 周期波动。
  • 原料敏感权重：集中于冻品（进口价）+ 养殖（猪价）。结构迁移看混合食材/配送占比提升。
  • 禁单一综合毛利率：须分业务看，冻品承压、配送高增是结构性机会。
  • 因子3 库存与采购节奏
  • 冻品低价囤货 → 后续毛利受益；高价接货 → 损失。H1 经营现金流为负（囤货+渠道投入）。
  • 验证点：冻品库存周转 + 猪价；证伪：低价囤货未兑现毛利改善。
  • 因子4 政策 / 市场锚点
  • 市场层：猪周期、国际冻品价、鸡苗价。
  • 政策层：生猪产能调控、冷链补贴、团餐准入。
  • 情景：猪价反转+冻品渠道出清 → 主业修复（乐观）；底部延续 → 扣非续亏（悲观）。验证点：猪粮比、农业部产能数据。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：冻品贸易分散，国企背书获大客户；需求侧：团餐/校园 B 端份额提升（96 校 → 扩面）。
  • 技术代际：无；成本曲线：冷链网络规模降配送成本。
  • 份额二阶导：配送处渗透早期。三档：保守守住 / 中性 B 端份额提升 / 乐观全国供应链网。
  • 层2 扩展业务：主业迁移空间
  • 从「贸易」→「贸易+配送+自有产品」协同（怀乡鸡/种业蛋导入校园），能力可迁移，新 TAM（团餐万亿）。信号验证：配送收入高增、学校数跳升 → 部分过验证点，计中期期权。
  • 层3 证伪信号
  • 猪价/鸡苗持续低位 + 冻品渠道恶化 + 配送增速回落 → 主业修复证伪，中性下修。

第四步进阶：重资产 / 破净校正（三道闸）

  • 校正1 资产质量折扣（破净原因）
  • PB 0.91 破净，主因净资产含大量广州老牌土地/物业/冷库（未市价重估），且主业周期底部扣非亏损。属「金融资产/物业未重估型破净」——若土地物业按市价重估，真实 PB 或 <0.6，存在真安全边际，可保留，但须证明：公司持广州核心区冷库/园区物业（广弘食品、粤桥园区），账面值远低于市场价。
  • 校正2 周期位置校正
  • 生猪/冻品处周期底部（猪价近十年新低），中性净利取周期归一化（行业正常年 1.2–1.5 亿），非底部年化（扣非亏）。
  • 校正3 杠杆下行情景
  • 负债率约 53.7%（38.45/71.63），附利率/需求下行情景：悲观净利 0.6 亿 → 1.26 元（−74.6%），若主业持续亏损则安全边际依赖资产重估。

第五步：综合赔率判断（买不买？）

当前价格位置：偏低（破净+资产重估期权）但主业未修复。现价 4.97 元对应 PB 0.91x，含隐性物业价值；但主业扣非亏损，盈利质量弱。

安全边际：中性远期 5.26 元 → 空间 +5.9%（>0，达纳入观察门槛）；悲观 1.26 元 → −74.6%（若周期延续+无资产重估）；乐观 8.49 元 → +70.8%。

介入条件：① 猪价/冻品周期反转信号（猪粮比回升）；② 扣非扭亏（连续两季为正）；③ 资产重估/盘活公告落地。现价破净具备一定安全垫，但需等主业拐点确认。

最大风险：
1. 主业扣非持续亏损，若周期底部延长则靠处置撑利润不可持续；
2. 冻品进口冲击+渠道调整延续；
3. 资产处置一次性收益耗尽后归母转负（届时按亏损股重估）；
4. 高负债（53.7%）+ 现金流为负。

结论：纳入观察

破净（PB 0.91）+ 广州物业隐性资产构成安全边际，中性远期 +5.9%（>0）。但主业扣非亏损、周期底部，须等猪价/冻品反转+扣非扭亏确认后才上调。属「低估待拐点」型。
