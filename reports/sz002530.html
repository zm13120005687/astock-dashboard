第一步：公司是干什么的？

一句话定位：国内金属热处理全产业链龙头（唯一同时获「国家制造业单项冠军示范企业」+「国家科学技术进步二等奖」），以热处理装备制造、商业热处理加工、精密耐热合金、轴承及零部件制造五大业务构成「材料—工艺—装备—服务」一体化闭环，下游覆盖新能源汽车、工业机器人、风电、航空航天、核工业。

股东背景：第一大股东江苏东润金财投资管理有限公司；2026 年新任总经理杨墨（原国君计算机首席）主导「产业链上下游整合延伸」战略。

第二步：行业景气度 + 政策/市场数据

（1）政策端（近 6–12 个月）——强利好，国家级 + 行业规划，已在执行

  • 《热处理行业"十四五"发展规划》收官 + "十五五"设备更新延续：据第五届热处理装备用户调查（2026 年初发布），"十四五"全行业在役设备约 30 万台（套）、年营业额约 500 亿元；"十五五"期间数字化改造与互联（57.3%）、节能环保新设备（40.7%）、真空热处理炉（30.1%）投资延续，工艺装备数控化率目标 95%，真空热处理设备年均需求增速 15%–20%。
  • 《机械行业稳增长工作方案》（六部门联合）：明确"加快关键基础零部件国产化替代步伐"，精密轴承纳入重点发展领域——直接利好公司轴承业务国产替代。
  • "两新"设备更新政策：大规模设备更新刺激"十四五"设备投资高峰，公司热处理装备直接受益。
  • 《新一代煤电升级专项行动实施方案（2025–2027）》等能源政策带动火电/核电装备热处理需求。

（3）产业链传导

  • 上游：钢材、耐热合金料（镍/铬系）、电炉能耗。公司控股无锡福爱尔（耐热合金工装自产）向上游延伸，降低外购依赖；前 5 供应商占比仅 17.72%（议价中性）。
  • 下游：新能源/机器人/风电资本开支高景气 → 热处理加工与设备订单刚性增长。
  • 议价权：中偏强——细分领域单项冠军、客户认证壁垒（IATF16949/Nadcap 航空体系），加工服务网点稀缺性赋予定价权；但轴承新业务尚处爬坡、议价偏弱（毛利率仅 15.5%）。

第二步进阶·原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性（pass-through）：热处理加工服务按工艺计费，电费/合金料涨价可通过调价部分转嫁（转嫁系数约 0.6–0.7）；装备制造为项目制投标，原材料波动在报价中锁定（系数 ~0.8）；轴承制造（并表初期）转嫁系数低 ~0.4（客户认证期，自己扛）。综合转嫁系数约 0.65 → 上游涨价实际毛利承压约 35%。
  • 因子2 毛利结构再平衡：五大业务毛利率差异大（加工 32.8% / 设备 34.7% / 合金 25.5% / 售后 39.2% / 轴承 15.5%）。2026H1 因低毛利轴承并表，综合毛利率 -1.09pct。测算：轴承营收占比每升 5pct，综合毛利率约降 0.8pct——估值须用分业务净利而非单一综合毛利率。
  • 因子3 库存与采购节奏：钢材/合金为标准化采购，无显著囤货收益；但福爱尔自产工装使"料重工轻"环节内部化，平滑外购波动。无长协套保披露 → 视常规采购。
  • 因子4 政策/市场锚点：① 镍/铬等特钢价格受能耗双控与出口管制影响（上行情景：特钢涨价 10% → 合金业务毛利率 -1.5pct；验证点：LME 镍价）；② 电价市场化改革抬升电炉成本（验证点：工商业电价）；③ 国产替代补贴利好轴承（验证点：首台套/专精特新补贴发文）。证伪信号：特钢持续跌价→成本红利；轴承客户认证失败→增量落空。

第三步进阶·份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量
  • 供给侧：热处理装备市场 205 亿（2026E），公司为单项冠军，份额稳居前列；轴承市场 2468 亿，无锡三立份额极小（<0.5%）→ 提升空间大。
  • 需求侧/客户份额：工业机器人轴承进入艾迪精密/秦川机床供应链（认证壁垒=粘性）。
  • 技术代际差：真空渗碳/等离子渗氮达国际先进，P2 级精度领先国内。
  • 成本曲线：全产业链一体化（自产工装+加工+设备）左移成本。
  • 份额加速度：轴承处 0→1 渗透早期（S 曲线底部）。
    → 三档：保守（轴承份额 1%）、中性（2%）、乐观（3.5%+机器人部件工厂放量）。
  • 层2 扩展业务：主业迁移（新易盛范式）：热处理→机器人/RV 减速器轴承，能力（精密制造+热处理工艺）可迁移，新 TAM（轴承 2468 亿）远大于旧池塘；切人卡位早期（先发）；认证门槛高（既是护城河也是阻力）；信号验证=客户公告+产能投向轴承。未过"机器人功能部件工厂"量产验证点前仅作中期期权，不计入中性净利。
  • 层3 证伪信号：轴承客户流失/认证延期、机器人产量增速跌破 +15%、海外贸易壁垒致出口转负。

第四步进阶·重资产/周期股校正

  • 校正1 资产质量：固定资产占比不高（轻资产服务+制造），PB 4.06x 未破净，无资产质量折扣问题。
  • 校正2 周期位置：热处理属稳健设备服务，非强周期；当前处制造业升级上行期，中性净利未做周期归一化（已保守）。
  • 校正3 杠杆下行情景：资产负债率约 40%（较低），无高负债反噬；但若机器人/轴承需求证伪，乐观情景落空 → 股价回悲观 3.67 元（−48%）。
  • 期权纪律：机器人功能部件新工厂、海外翻倍均作期权，仅入乐观情景，不计入中性。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 7.07 元 > 基准 6.03 元，中性远期仅 +14.5%，当前 72.95x PE 已透支部分成长。

安全边际：中性 8.09 元（+14.5%）未达重点关注 >50% 门槛；悲观 3.67 元（−48.1%）下行空间显著；乐观 14.38 元（+103%）需机器人/轴承大放量。

介入条件：① < 6.0 元（对应 2026E PE < 45x）才具安全边际；② 加仓信号：机器人功能部件工厂投产、轴承营收破 2 亿、海外占比破 15%。

最大风险：① 当前高 PE（72.95x）对成长确定性强依赖，若轴承整合/机器人需求不及预期将双杀；② 轴承新业务毛利率仅 15.5%，爬坡不及预期拖累整体；③ 综合毛利率受低毛利业务并表结构性拉低。

结论：暂不介入（估值偏高，中性远期空间仅 +14.5% 且当前价已超基准，缺乏安全边际；高 PE 小盘股波动大。待回调至 6 元以下或机器人/轴承增量获验证后转「纳入观察」）。

第五步进阶·上行想象力情景（四类）

  • A 行业调整剩者红利：热处理低端产能出清（能耗双控），单项冠军份额提升 → 验证点：行业集中度数据。
  • B 政策反转期权：工业母机/基础零部件国产化补贴加码 → 重估弹性，不计入中性。
  • C 市场错杀修复：若因大盘风格切换错杀至 5 元以下，估值分位极低 → 修复触发点：市场企稳+业绩证伪恐慌解除。
  • D 技术突破/代际跃迁：机器人功能部件工厂从 0 到 1 投产，切入人形机器人轴承（硬验证点=中试良率达标+客户定点+量产成本优旧路线）。当前仅过"收购并表"未过"新工厂量产"，属机会情景不计入中性。
  • 上调至重点关注的条件：机器人部件工厂获大额定点订单 + 2029 中性净利上修至 3 亿以上 + 远期空间破 +50%。
