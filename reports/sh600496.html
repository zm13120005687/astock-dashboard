（3）产业链传导（原料成本 → 毛利结构，四因子）

  • 因子1 成本传导弹性：原料为钢材（中厚板、型钢、热卷），占成本约 60–70%。工程合同多为"按投标时钢价锁定单价、工期 6–12 个月"模式，投标至采购存在敞口，转嫁系数约 0.4–0.6（部分合同含钢价调差条款，大型总包项目可谈调差）。佐证：2026H1 毛利率 11.81%（+1.21pct），主因钢价低位 + 海外高毛利订单占比提升；一旦钢价快速上行且调差滞后，毛利将阶段性承压。
  • 因子2 毛利结构再平衡：分业务毛利率梯队——海外工业建筑（显著高于国内，回款条件更优）＞国内工业建筑（周期性最好、现金流健康）＞公共建筑（竞争激烈、毛利低）＞集成及 EPC/BIPV（前期低毛利培育、规模化后抬升）。2026H1 海外收入占比升至 21.73%，直接拉动综合毛利率 +1.21pct——这是结构改善而非加工提价，估利润必须按"国内/海外/新兴业务"三条线分开看。
  • 因子3 库存与采购节奏：钢结构企业钢材库存低（按项目分批采购），钢价上行时的库存收益小，主要风险是"已锁价未采购"的敞口。2026H1 经营现金流 −2.64 亿、Q2 −1.80 亿，主因是项目回款周期与集中备货错位（上年同期有集中回款），需跟踪回款而非单季利润。
  • 因子4 政策/市场锚点（原料驱动）：上游钢铁行业"反内卷/粗钢产量调控"若落地 → 钢价反弹 → 在无调差条款的项目上侵蚀毛利（负面情景，钢价 +15% 且调差失败时毛利率或跌破 10%）；若钢价维持低位 → 毛利率有支撑。市场层：热卷/中厚板社会库存、表观需求。验证点：月度钢价、新签订单毛利率变化、公司调差/涨价公告；证伪信号：钢价上行且公司综合毛利率连续两季跌破 10%。

层1 现有业务：市场容量 × 份额变量（五锚点）

  1. 供给侧份额：行业 1.09 亿吨加工量、精工销量约 190–200 万吨/年，份额不足 2%——行业极其分散，"大行业、小公司"格局下龙头提份额空间大但节奏慢（低端产能靠价格竞争出清）。验证点：年销量增速 vs 行业增速。
  2. 客户份额：靠老客户复购（比亚迪、尚太、恒力）——进入核心客户供应链后粘性高，工业厂房跟随客户扩产。验证点：前五大客户复购订单公告。
  3. 技术代际差：在重型/复杂钢结构（机场、超高层、大型厂房）+ 智能建造上领先，无代际差风险。
  4. 成本曲线位置：规模采购 + 多地工厂贴近项目供货，成本位于行业左侧；行业出清后头部有望"以质换价"。验证点：新签订单毛利率。
  5. 份额二阶导：行业处"低端出清、集中度提升"的早期（2026 年行业洗牌加剧、竞争态势缓解是公司表述），渗透率仍在爬坡。验证点：行业 CR5、公司销量占比。

层2 扩展业务：主业迁移空间

①能力可迁移性：钢结构分包 → EPC 总包/装配式（技术同源、客户复用），迁移成本低；②新 TAM：EPC/装配式对应"好房子+城市更新+工业园区"市场，体量数倍于纯分包；③切入时点：政策窗口开启初期（"十五五"纲要明确促进装配式规模化），卡位领先；④客户认证门槛：住宅与公共建筑需资质与样板工程，门槛中等；⑤信号验证：EPC 新签订单 +38.6%、颛桥住宅项目开工、自研装配式体系推广。EPC/装配式已过初步验证点，可按一定比例计入中性（仅按在手订单可执行部分），BIPV 尚处培育期计为期权。

层3 风险折扣：证伪信号

  • 国内传统公共建筑/房建继续下行拖累整体订单；海外局势恶化致项目取消；
  • 综合毛利率跌破 10%（钢价上行且调差不畅）；
  • 经营现金流持续为负（回款恶化、应收/合同资产减值抬头）；
  • 新签订单同比转负、销量增速连续下滑。

总股本 19.90 亿股。估值采用"销量（在手订单驱动）× 吨净利 + 新兴业务贡献"的自下而上法，不做整体打包外推。

重资产/周期股三道校正

  • 校正1 破净原因必须说明（本股关键）：PB 0.72 并非"价值被低估"，而是——①资产盈利能力低：2025 年 ROE 约 6.6%、净利率约 2.9%，低毛利制造业资产破净是公允定价而非错杀；②营运资产占比高、质量打折：应收票据/账款 + 合同资产规模大（资产负债率 67.1%），钢结构施工回款周期长，净资产含较多"账期资产"；③专用设备+在建基地重置价值低于账面。因此禁止单凭 PB<1 推导大空间，中性估值按 PE 与盈利路径锚定，而非 PB 回归。
  • 校正2 周期位置：钢结构需求处"房建下行 vs 工业/海外上行"的结构性切换期，中性净利取 8.5 亿（行业中枢偏下），未采用 2022 年 6.99 亿/单年峰值做线性假设，也避免把 Q2 单季销量高增直接年化。
  • 校正3 杠杆下行情景：负债率 67.1%、含转债（精工转债 110086），必附负面情景：若利率上行 + 地产/海外需求同步下行 → 经营杠杆 + 财务杠杆双高 → 悲观情景目标市值 49.5 亿（空间 −25.9%），尚不致转负，故结论封顶为"纳入观察"，不标"重点关注/大空间"。
  • 期权纪律：BIPV 规模化、海外公共建筑大单、数据中心厂房订单均未达"持续贡献"验证点，只计入乐观栏；中性仅计工业建筑订单 + EPC 在手部分。

交叉校验：现价 3.36 元对应 2026E PE 约 9.6x、股息率（按 ≥70% 分红承诺与 4 亿元孰高）约 6.5–7.4%——股价已有较厚股息保护；中性远期 4.70 元隐含 PB 约 0.9–1.0x（净资产届时约 100 亿），对 ROE 8% 上下的企业属公允。

第五步：综合赔率判断（买不买？）

当前价格位置：合理偏低。PB 0.72 破净 + 2026E PE 约 9.6x + 股息率约 7%，具备防御价值；但需清醒认识"破净合理"（低毛利+营运资金重），上行靠盈利改善而非估值修复。

安全边际：
- 中性远期 4.70 元 → 空间 +39.9%（低于"重点关注"所需 +50% 门槛）
- 悲观 2.49 元 → −25.9%；乐观 6.63 元 → +97.3%
- 股息率约 7% 提供时间价值；下行保护为分红承诺（2025–2027 年 ≥70% 或 ≥4 亿元孰高）。

介入条件：
1. 现价附近可开始建仓（股息托底 + 破净），3.0 元以下（对应 2026E PE<8.5x）加仓；
2. 上调至"重点关注"的信号：①海外新签订单同比增速回正且占比持续提升；②经营性现金流连续两季回正；③新签订单毛利率站稳 12% 以上；
3. 证伪信号：经营现金流连续大幅为负、应收/合同资产减值抬头、新签订单转负。

上行想象力（显式建模）：本股主要属类型A 行业出清剩者红利——钢结构行业集中度极低（龙头 <2%）、低端产能靠价格血拼，2026 年公司已表述"行业洗牌与产能逐步出清、竞争态势有望缓解"。若出清兑现，龙头份额与单位盈利双升（乐观情景 +97.3%）；叠加类型B 政策（"十五五"纲要 + 好房子 + 数据中心等新质厂房）温和利多。上调至"重点关注"的条件：行业出清使公司新签订单毛利率回升至 13% 以上 + 海外收入占比升至 30% + 经营性现金流转正——三者同时兑现才成立。

最大风险：
1. 应收账款/合同资产质量（首要）：H1 经营现金流 −2.64 亿，若回款持续恶化将引发减值与现金流双重压力；
2. 钢价快速上行而调差不畅，毛利率破 10%；
3. 海外地缘/项目执行风险（部分项目已延迟）；
4. 传统建筑需求拖累公共建筑订单。

结论：纳入观察

判断依据：中性远期空间 +39.9%（>0，具备正赔率），但未达"重点关注"的 +50% 门槛；破净原因系低毛利营运重资产（合理非错杀）+ 负债率 67% 高杠杆，按校正纪律结论封顶为纳入观察。股息率约 7% 提供持有保护，工业建筑订单与海外扩张逻辑成立——核心跟踪海外订单、现金流与毛利率三指标。
