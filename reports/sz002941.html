（3）产业链传导

上游：钢材、水泥、沥青、砂石骨料、机械设备租赁与人工。2026 年钢材与水泥价格低位震荡、沥青随原油波动 → 成本端总体平稳，但项目开工集中期会出现区域性砂石与机械价格上行。

下游：新疆自治区及地州交通建设主管部门、铁路局、政府平台 → 单一买方属性强，账期长。
- 议价权判断：弱。施工承包商在中标价锁定后面临「业主压工期 + 材料涨价 + 分包议价」三重挤压，2026H1 毛利率再降 2.68pct 即为议价权弱的直接佐证。经营现金流 −18.5 亿元进一步印证——收入确认与现金回收严重脱节。

产业链位置：位于建筑工程产业链中游施工环节，上游受制于材料与设备，下游受制于单一业主，「两头受挤」。唯一优势是区域资质与属地关系（新疆本地龙头、参与「四轴四廊十六联」与「一带一路」通道），但这类优势更多体现为「能拿到活」，而非「能赚到钱」。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子 1 · 成本传导弹性（pass-through，量化为转嫁系数）

业务线 转嫁系数 依据
施工业（总价承包合同） 0.10–0.20 中标价在合同期内锁定，材料涨价几乎无法转嫁（仅在部分项目「材料调差条款」下可部分调整）；2026H1 毛利率 10.20%（−2.68pct）即为印证
贸易 0.80–0.90 贸易业务随行就市（毛利率 48.93%，体量小）
勘测设计/试验检测 0.60–0.70 服务类，有一定议价
加权综合转嫁系数 约 0.18 极低——建筑业是本批次所有标的中转嫁能力最弱的一档

→ 实际毛利承压 = 上游变动 ×（1 − 0.18）= 上游变动 × 0.82。即材料价格涨 10%，公司综合毛利率约承压 3.5–4.5pct（按材料占营业成本 55–60% 测算）——对一家净利率仅 5.18% 的公司，材料涨 10% 即可把净利率打到接近零。这是本股最脆弱的杠杆点。
- 验证点：季报毛利率、新疆水泥/钢材/沥青价格指数；证伪信号：材料涨价 10% 而毛利率下降超 5pct（调差条款失效）。

业务线 2026H1 收入占比 毛利率 原料敏感权重 利润贡献占比（估）
施工业 97.62% 10.20% 极高（钢材/水泥/沥青/砂石） 约 94%
勘测设计与试验检测及车辆通行 1.02% 约 40–50%（估） 低 约 4%
贸易 0.71% 48.93% 低 约 3%

→ 结构特征：97.62% 的收入与约 94% 的利润集中在「毛利率仅 10.20% 且对原料极度敏感的施工业」。贸易与勘测设计虽毛利率高（48.93% / 40–50%），但合计收入占比不足 2%，完全无法充当利润缓冲垫。
- 估值含义：公司没有第二条利润曲线，综合毛利率 ≈ 施工毛利率，任何原料波动都直接穿透到净利。这与「多业务线可以对冲」的公司完全不同——本股的经营杠杆是单向的。
- 验证点：半年报/年报分业务收入与毛利率；证伪信号：贸易收入占比进一步萎缩至 0.5% 以下（缓冲垫消失）。

因子 3 · 库存与采购节奏（timing，别把一次性收益当盈利）

  • 建筑业无「低价囤货/高价接货」的典型库存收益；真正的「库存」是存货（已完工未结算工程）+ 合同资产 + 应收账款。
  • ⚠️ 关键 timing 分析：2026H1 经营现金流净额 −18.50 亿元（上年同期 −4.33 亿元），而营收仅 34.30 亿元——相当于每赚 1 元收入，净流出约 0.54 元现金。这说明：
  • 收入确认大幅领先现金回收（业主付款滞后、质保金留存）
  • 备料与分包款预付增加（承接 21 亿元铁路订单的前期投入）
  • 利润的「含金量」极低——账面 1.82 亿元归母利润对应 −18.5 亿元现金流，利润是「纸面」的
  • 非经常性收益的 timing：2025H1 存在较大额非经常性收益，导致 2026H1 归母同比 −28.52%（而扣非 +45.20%）。去年同期的高基数属一次性，不可外推；本期扣非增长才是真实趋势，但也被现金流恶化所抵消。
  • 纪律：不得把「营收高增 + 扣非高增」当成利润质量改善——在经营现金流 −18.5 亿元面前，利润增速的解释力有限。
  • 验证点：季报经营现金流、应收账款与合同资产余额、收现比；证伪信号：应收/合同资产增速持续高于营收增速。

第四步进阶：重资产/周期股估值校正（三道闸 + 期权纪律）

校正 1 · 资产质量折扣（本股不破净，但须证明净资产的可回收性）

  • 本股 PB(LF) 1.19x，不属于破净股（部分行情商显示 1.6–1.7x，按扣其他权益工具口径）。但净资产的「含金量」必须打折：
  • 资产构成以「应收账款 + 合同资产 + 存货（已完工未结算）」为主，而非现金或可变现资产。这类资产的可回收性完全依赖业主（地方政府与平台）的付款能力，重置成本不兜底。
  • 经营现金流净额 −18.50 亿元是净资产质量的直接反证：净资产的增加（+3.35%）并未伴随现金流入，而是应收/合同资产的膨胀。
  • 资产专用性强：施工设备、在建项目权益不能转产，清算价值 << 账面。
  • 隐含负债：工程质保金、农民工工资保证金、未决诉讼与潜亏项目。
  • → 结论：1.19x PB 不构成安全边际。禁止单凭「PB 接近 1」推导空间。 若按「有形可回收净资产」折价 30% 计，隐含 PB 约 1.70x，估值并不便宜。
  • 验证点：应收账款账龄结构、合同资产减值准备、经营现金流；证伪信号：应收增速持续高于营收增速、坏账计提上升。

校正 2 · 周期位置校正（中性净利用周期归一化）

  • 本股为本批次最典型的强周期标的（基建投资周期 + 地方财政周期）。
  • 禁止用单年好年景（2025 年归母 4.72 亿元含较大额非经常性收益；2026H1 归母 1.82 亿元受去年同期高基数压制）或近三年均值（若恰逢投资上行）作中性锚。
  • 周期归一化口径：采用多年 trough-to-peak 中值 + 行业正常单位盈利双重校验：
  • 归母净利中枢：结合 2025 年 4.72 亿（含一次性）与 2026E 4.32 亿（毛利率下滑），正常化归母中枢取 4.0–4.5 亿元；
  • 行业正常单位盈利：地方路桥施工企业正常净利率约 2–5%，公司 5.18% 处于上沿 → 中性应按 4.0–4.5% 净利率取值（而非 5.18%）。
  • 本报告已在 2029E 中性中采用 3.8% 施工净利率，属保守取值。
  • 当前周期位置标注：新疆基建投资处于上行周期的相对高位（900 亿/年硬指标），但施工企业盈利周期已进入「增收不增利」的下行段（毛利率连续下滑、现金流恶化）。投资周期上行 ≠ 施工企业盈利上行——这是本股最需警惕的错位。
  • 验证点：毛利率、经营现金流、新签合同额；证伪信号：毛利率跌破 9% 则周期位置判断为「顶部」而非「上行」。

校正 3 · 杠杆下行情景（高负债必附负面情景）

  • 资产负债率 71.11%，显著高于 60% 阈值，强制触发负面情景。建筑业属「经营杠杆 + 财务杠杆」双高：收入下滑时毛利率骤降，而财务费用刚性 → 净利几倍跳负。
  • 负面情景测算：
  • 新疆投资完成低于计划 15%（765 亿）+ 毛利率降至 8.5% + 财务费用刚性 → 2029E 归母降至 3.2 亿元 → 悲观目标价 4.39 元（−58.4%）
  • 极限情景：若经营现金流持续 −20 亿元/年，需持续新增有息负债，利息支出吞噬净利；叠加应收坏账计提 → 2029E 归母可降至 1.5 亿元 → 约 2.1 元（−80%）
  • 该负面情景若成立，空间显著转负（−58.4% 至 −80%）→ 按规则，本股不得标「大空间 / 重点关注」，至多「纳入观察」且须注明高贝塔属性。本报告结论进一步下调至「暂不介入」，因中性情景本身即为负空间。

- 反转/强化信号：自治区年度投资目标上调、跨天山通道项目开工公告、中亚口岸通道获批。
- 重估弹性：若公司中标「四轴四廊十六联」主干线大标（单标 ≥30 亿元），叠加毛利率回升至 11% → 2029E 归母 8.0 亿元 × 12x = 96 亿元 → 13.16 元（+24.9%）。
- 验证点：中标公告、投资完成进度。证伪信号：投资完成低于计划 15%、项目审批持续延后。
- 政策已出但公司份额未验证，仅作机会情景。

类型 C · 市场错杀修复
- 错杀证据：不成立。现价 2026E PE 17.8x 相对同类地方路桥施工企业（8–12x）是溢价而非折价；基本面（现金流、毛利率、新签）确在恶化，非市场误判。
- 若股价跌至 6 元以下（PB < 0.68x）且上述三项信号条件同时改善，届时方构成"错杀"。
- 结论：本类不提供现价支撑，反而是估值回归的向下动力。

类型 D · 技术突破/技术代际跃迁期权
- 本类基本不成立。路桥施工技术成熟稳定，不存在「全新技术路线重构竞争格局」的载体；装配式桥梁、BIM、智能建造属效率工具而非技术代际跃迁。
- 唯一近似项：高原/高寒/极端地质条件下的特大桥隧施工能力（如天山胜利隧道类工程）——若形成不可替代的技术壁垒，可获溢价。但硬验证点（中试良率、客户定点、量产成本优于旧路线）在施工语境下无对应物，且公司未披露此类专有技术。
- 结论：仅作观察，不计入任何情景。

什么条件出现才把结论上调至重点关注：
本股不适合上调至「重点关注」（即使乐观情景也仅 +24.9%，远低于 >50% 门槛）。若需重新评估，须同时满足：① 单季经营现金流转正且累计现金流转正；② 季度新签合同额回升至 15 亿元以上；③ 毛利率连续两季不低于 10.5%——届时可将结论由「暂不介入」上调至「纳入观察」，中性目标价可上修至 9.5–10.0 元（对应现价仍有约 −5% 至 −10% 空间，仍不足以「重点关注」）。

结论：暂不介入

理由：① 中性远期空间为负（−18.9%），乐观情景也仅 +24.9%，而悲观情景 −58.4%，赔率严重不对称；② 现价 2026E PE 17.8x 对一家净利率 5.18%、毛利率下滑 2.68pct、经营现金流 −18.5 亿元、资产负债率 71.11% 的地方路桥施工企业明显偏高（同类 8–12x）；③ 归母净资产以应收/合同资产为主，1.19x PB 不构成安全边际。
不判「坚决回避」的原因：公司并非「确无扭亏可能」——新疆 900 亿元/年交通固投是真实、可验证的量化政策，公司在手订单（伊阿铁路 21 亿元联合体 + 中标未签约 9.1 亿元）真实存在，扣非净利同比 +45.20% 显示主营在改善，且已实施中期分红（10 派 0.5 元）。基本面无实质恶化到需要回避的程度，只是价格与价值不匹配。
核心跟踪点：① 季度新签合同额（判断订单断档是季节性还是趋势性）；② 经营现金流（判断利润含金量）；③ 毛利率是否企稳。
