第一步：公司是干什么的？

一句话定位：安徽国企背景的高端纺织制造商（棉 / 麻 / 毛 / 丝 / 聚乳酸纤维纱线），同时持有约 15 亿金融资产（含券商股权），"纺织主业 + 金融投资"双轮，但主业盈利偏弱、重资产、低 ROE。

股东背景：安徽华茂集团有限公司（国有法人）持股 46.40%，实控人安庆市国资委；公司本身为国有控股上市平台。

（3）产业链传导

上游：棉花、麻、化纤等原料（占成本大头），2025 原料市场剧烈波动，公司改用"后点价"采购模式降风险。
下游：服装 / 家纺 / 产业用，需求受消费与出口影响。
议价权：中偏弱。纺织制造产能过剩、买方强势，毛利率长期 12–15%；差异化品种（融合纺等）提升溢价但占比仍小。

第二步进阶：原料成本 → 毛利结构（四因子）

  • 因子1 成本传导弹性：纺织业转嫁系数 ≈ 0.3–0.5（弱议价，原料涨多靠自身消化）。依据：2025 毛利率仅 12.79%、净利率 5.89%，原料波动直接侵蚀利润；公司改用后点价采购仅为"降风险"而非"转嫁"。
  • 因子2 毛利结构再平衡：分业务线——纱线（主营 60.82%，毛利率约 13–15%）、布（30%，毛利率约 10–12%）、无纺布（产能利用率提升，毛利率改善）、印染（加工费低毛利）。原料（棉花 / 化纤）敏感权重集中于纱线 + 布（合计 90%+），结构性毛利脆弱。
  • 因子3 库存与采购节奏：后点价采购模式平滑了部分原料波动，但 2026H1 经营现金流 −1.05 亿（同比扩大），显示营运资金占用上升，无显著低价囤货收益。验证点：后续毛利率与现金流。
  • 因子4 政策 / 市场锚点：棉花受国储 / 进口配额 / 国际棉价影响（市场层）；化纤受原油价格传导；聚乳酸受"限塑令"政策驱动（政策层，降本方向）。情景：棉价上涨 → 毛利承压；证伪信号：综合毛利率跌破 12%。

第三步进阶：份额变量与主业迁移空间（三层法）

  • 层1 现有业务：市场容量 × 份额变量：纺织制造为成熟存量行业，华茂全国市占率低个位数。增量来自①差异化品种抢份额（认证周期短、粘性中）②出口份额（亚洲 / 欧洲）。三档：保守守住、中性小幅提升（新客户转化）、乐观抢份额（PLA 差异化突围）。验证点：季度纱线毛利率、出口营收占比。
  • 层2 扩展业务：主业迁移空间（聚乳酸）：从传统棉纺向 PLA 可降解纤维迁移，新 TAM（可降解材料）数倍于传统纱线，但商业化早期（2025 新元纤系列推进中），未过"批量订单 / 营收占比跳升"验证点，仅中期期权，不计入中性。
  • 层3 风险折扣：证伪信号：纱线毛利率跌破 12%、出口下滑、PLA 无批量订单 → 下调增量。

第五步：综合赔率判断（买不买？）

当前价格位置：偏贵。现价 5.12 已高于中性锚 4.0 元，主业 PE 约 25x 对弱周期纺织偏高。
安全边际：中性 −21.9%，悲观 −48.2%；下行有净资产（46 亿）与金融资产（15 亿市价）兜底，PB 1.06 提供有限保护但非"深度安全垫"。
介入条件：① 股价 < 4.5 元（主业 PB < 1 或金融资产重估确认）；② 加仓信号：扣非净利连续双位数增长、PLA 批量订单落地、金融资产重估公告。
最大风险：① 金融资产公允价值继续波动（−9881 万式拖累重现）；② 纺织主业周期下行、毛利率破 12%；③ PLA 商业化慢于预期。
结论：暂不介入（中性远期空间 −21.9%，估值不具吸引力；净资产 + 金融资产提供下行底线，但上行需 PLA 或金融重估兑现，确定性不足）。

核心跟踪点：扣非净利持续性、金融资产构成与市值、PLA 订单落地。
