（3）产业链传导

上游（管制药品）：自有种植（TB 20 英亩温室 + 户外）+ 外部采购。成本构成：种植（能耗、人工、肥料）、加工提取、合规与检测（TGA 认证）、包装。公司有自有种植 = 部分成本自控，这是相对纯分销商的cost advantage。

上游（纸包装）：原纸、油墨、铝箔等，挂钩纸价。该业务正在出清，重要性下降。

下游：澳洲 1,800+ 药房（Phytoca 直销 + 分销混合）、医院/诊所；国内酒企（茅台/习酒/舍得）。

议价权：
- Phytoca（品牌运营商）：中等偏强——自有品牌 Phytoca/Pouch，直接面向药房，有定价权；衍生品类（精油/雾化）毛利率更高，翻倍增长即证明。
- TB（种植 + 零售）：中等——零售额占比 >70% 说明直接触达终端，但受"市场波动"影响（H1 营收 −5.22%）说明澳洲干花价格有下行压力。
- 纸包装：弱——同质化低价竞争，这是出清的根本原因。

第二步进阶：原料成本 → 毛利结构传导（四因子）

因子1 成本传导弹性（pass-through）：
- 管制药品（自有品牌）：传导率估 0.7–0.8。依据：Phytoca 自有品牌 + 药房渠道，品牌溢价支撑提价能力；衍生品类（精油/雾化）毛利率高于干花，且翻倍增长 → 结构向高毛利迁移即证明有定价权。
- 管制药品（种植端 TB）：传导率估 0.3–0.4。依据：H1 收割 5 吨但营收 −5.22% —— 量持平而价跌，说明澳洲干花市场供过于求、价格下行，种植端是价格接受者。⚠️ 这是关键信号：澳洲医用大麻干花环节正在经历价格战。
- 纸包装：传导率估 0.2（弱，出清中）。

结构迁移（核心结论）：综合毛利率 32.52% 看起来健康，但这是"纸包装出清 + 高毛利管制药品占比被动提升"的结果，而非盈利能力提升。一旦拆开：
- 高毛利（45–50%）的 Phytoca 占比仅 30.9%
- 价格战承压的 TB 占 18.9%
- 合计毛利 1.16 亿，但期间费用约 1.41 亿（倒推自扣非 −0.25 亿）→ 费用率高达 39.5%
→ 结论：当前收入规模（3.57 亿/半年）撑不起当前的费用结构。这是扣非亏损的真正原因。

因子3 库存与采购节奏（timing）：
- 医用大麻干花有保质期与 potency 衰减问题，囤货风险高。TB "完成收割 5 吨"但营收 −5.22% → 若 5 吨未全部售出，将形成库存积压；若干花价格继续下行，需计提存货跌价准备。
- ⚠️ 这是本报告识别的隐性风险点：澳洲干花价格下行 + 收割 5 吨 = 潜在跌价风险。需跟踪存货与减值科目。
- 纸包装出清过程中可能存在低价甩卖库存。

层2 主业迁移空间（能力可迁移性）——本标的最关键也最需警惕的一环
1. 能力可迁移性：
- ✅ 纸包装 → IP 衍生品：印包工艺 + 供应链 → 潮玩/IP 衍生品生产，技术同源性强（都是"设计 + 印刷 + 制造 + 渠道"）。上海卡匠已完成"IP 授权—设计开发—全渠道销售"链条。

方法说明：本报告不使用历史 CAGR 外推（明确拒绝"未来三年营收复合增速约 8%"这类券商外推口径）。因主业扣非真实亏损，采用 RULES.md 规定的正常化净利润法：①估稳态营收 → ②保守正常化净利率 → ③× 远期合理 PE → 目标市值 → 目标价。同时按"期权纪律"剔除 AIGC/IP 衍生品与金融资产收益。

亏损股必答三问

Q1：为什么亏？
不是"行业周期底部"，也不是"产能爬坡期"，而是转型期的结构性错配：
- 旧引擎（烟草包装）主动熄火：收入 −60.57%，但固定费用（人员、设备折旧、管理费用）刚性，无法同步出清
- 新引擎（管制药品）收入翻倍但尚未形成规模效应：期间费用率高达 39.5%（倒推自毛利 1.16 亿 + 扣非 −0.25 亿）
- 新业务（AIGC/IP）处于净投入期，只出不进
- 澳洲干花价格战（TB 营收 −5.22%）侵蚀新引擎毛利

Q2：靠什么扭亏？触发时点在哪一年？
三条路径，按确定性排序：
1. 纸包装出清完成 + 费用结构优化（2026H2–2027）：出清后固定费用下降，费用率从 39.5% 向 25% 收敛。这是最确定的扭亏路径，触发时点 2027 年。
2. 管制药品规模效应（2027–2028）：收入从年化 4.6 亿向 7–8 亿爬坡，摊薄固定费用；Phytoca 高毛利衍生品占比提升。触发时点 2027–2028 年。
3. AIGC/IP 商业化（2028–2029，不确定）：未过验证点，不计入中性。

Q3：亏得起吗？
- 2025 年末总资产 21.33 亿、净资产 11.94 亿、有息负债 3.965 亿、资产负债率 35.72% → 杠杆不高

- 结论：亏得起。 半年扣非亏损仅 2,522 万，账上有现金与金融资产，经营现金流为正，不存在"倒在黎明前"的风险（对比紫燕的经营现金流转负 + 短期借款翻倍）。✓

类型A 行业调整剩者红利（强，本标的最独特的上行来源）
- 逻辑：公司已明确披露"随着澳洲管制药品行业监管趋严，合规头部企业市场份额持续提升，公司作为少数拥有全产业链布局的参与者，竞争优势进一步凸显"。澳洲医用大麻行业早期参与者众多、良莠不齐，TGA 监管趋严正在系统性出清非合规小厂。
- 弹性测算：假设澳洲持牌企业数量 2026–2029 出清 30%，公司（Phytoca + TB + Aeris，全产业链 + 1,800 药房 + 7 分销仓）承接 20% 的退出份额 → 管制药品收入从 2029E 的 8.1 亿升至 11.0 亿；且出清后价格企稳，净利率从 11.5% 升至 15% → 净利 1.65 亿 × 30x = 49.5 亿 + 金融资产 5 亿 = 54.5 亿 → 13.14 元（+36.3%）。
- 验证点：①澳洲 TGA 新规发布；②澳洲持牌医用大麻企业数量变化；③公司药房数与 SKU 数增长；④TB 干花单价企稳（当前 −5.22% 是反向信号，需转正）。
- 证伪：TB 营收连续 3 季下滑（价格战持续）、药房数停止增长、澳洲监管放松导致新进入者激增。

类型B 政策反转期权（强，跨市场扩张期权）
- 逻辑：全球医用大麻合法化正在推进（德国 2024 年部分合法化、英国/加拿大已合法、更多欧洲国家在评估）。若德国/英国等大型市场进一步放开，公司在澳洲跑通的"种植—加工—品牌—药房渠道"全产业链模式可复制输出。
- 重估弹性测算（仅供乐观栏）：若 2029 年成功进入一个年规模 10 亿人民币级别的新市场、取得 5% 份额 = 0.5 亿收入，加上澳洲主业 → 净利 +0.15 亿；但更重要的是估值范式从"澳洲区域公司"切换为"全球医用大麻平台"，PE 从 27x 提升至 40x → 1.35 亿 × 40x = 54 亿 + 7 亿 = 61 亿 → 14.71 元（+52.6%）。
- 验证点：①德国/英国等国医用大麻法规进一步放开；②公司公告境外新市场牌照申请或并购；③公司海外收入地区结构出现"澳大利亚"以外的第二地区。
- 证伪：24 个月内无跨市场动作、澳洲模式无法复制（因牌照/种植气候差异）。

类型C 市场错杀修复（弱）
- 错杀证据检验：PB 3.15x、PE(TTM) 37.18x —— 估值处于高位，不存在错杀。
- 但存在一类认知差：市场可能把"归母 +8,192 万（+44.72%）"当作盈利能力改善，从而给出溢价——这实际上是高估而非错杀。当市场识破"扣非 −2,522 万"的真相时，可能反向杀估值。
- → 本类型不构成上行来源，反而构成下行风险。

类型D 技术突破 / 技术代际跃迁期权（中等，有一条真线索）
- 逻辑：自研 Agent 智能体系统实现"智能剧本创作 + 一键成片"的工业化 AIGC 生产，配合海外 H5 独立站覆盖 11 个主要市场、支持多语言自动翻译。这不是简单的"用 AI 做短剧"，而是把内容生产从"手工作坊"变成"流水线"——如果跑通，边际成本趋近于零，且可直接输出到海外 11 国。
- 三要素共振检验：
- ①政策驱动——微短剧是广电总局重点扶持的"网络视听新业态"，但监管也在趋严（分类分层审核）⚠️；
- ②行业趋势——AI 生成内容成本曲线已与传统制作交叉，2026 年是 AIGC 短剧工业化元年 ✅；
- ③公司落地——已建成工业化 AIGC 生产线，累计 135 部作品、上线 33 部、爆款播放 2,000 万+ ✅。
- 硬验证点（防画饼）：①中试/产线跑通 ✅（135 部已产出，工业化产线已建成）；②客户定点/大额订单 ❌（"暂未形成规模化收入贡献"）；③量产成本优于旧路线 ⚠️（未披露单位成本对比，且无收入则无法验证）。
- → 三缺一（订单/收入未验证）→ 只作机会情景，不计入中性锚。 ✓ 本报告已遵守。
- 弹性（仅供乐观栏）：若 2029 年 AIGC 收入 3 亿、净利率 15% → 0.45 亿净利；叠加主业 1.20 亿 → 1.65 亿 × 32x = 52.8 亿 + 金融资产 7 亿 = 59.8 亿 → 14.42 元（+49.6%）。这是乐观情景 18.00 元的重要组成部分（乐观情景还叠加了澳洲监管出清 + 跨市场扩张）。
- 证伪：连续 4 个季度无收入确认、平台分账政策恶化、AI 生成内容被平台限流或监管叫停。

什么条件出现才上调至"重点关注"

需同时满足任意两条：①单季扣非净利润转正（最重要，证明主业真实盈利）；②澳洲管制药品监管出清加速（持牌企业数下降 20%+）；③AIGC/IP 产生可确认收入 >5,000 万；④股价回落至 6.5 元以下使中性空间重回 +40% 以上。
→ 当前满足 0 条。第①条是 2026H2–2027 的核心观察点。

结论：暂不介入

理由：公司在做一件难度大但方向未必错的事——用澳洲管制药品（+102.06%，1,800 家药房，全产业链）替换正在消亡的烟草包装。且亏得起（资产负债率 35.72%、经营现金流 +0.69 亿、持有大额金融资产），不存在"倒在黎明前"的风险。
但是：①主业真实亏损——2026Q1、Q2 连续两季扣非亏损，H1 扣非 −2,521.72 万，归母 +8,191.90 万全部来自交易性金融资产公允价值变动（+1.07 亿），这是必须剔除的一次性因素；②期间费用率高达 39.5%，收入规模撑不起费用结构；③澳洲干花价格战已现（TB 收割 5 吨但营收 −5.22%）；④AIGC 135 部作品、IP 衍生品多个 IP，均"暂未形成规模化收入"；⑤四个完全不同的业务（澳洲药品 + 贵州包装 + 重庆 AIGC + 上海 IP）管理跨度极大。
中性远期空间 −4.6%（负值），悲观 −42.9%，现价 9.64 元对应 2029E 中性扣非 1.20 亿的 PE 33.3x 明显偏高。
核心跟踪点：单季扣非净利润能否转正（唯一核心）+ 澳洲干花价格与 TB 营收 + 非经常性损益规模。
